# 模型接口协议插件化改造调研报告

## 一、现状分析

### 1.1 当前架构问题

通过代码审查发现以下核心问题：

#### 问题1: 协议硬编码严重
在 `backend/internal/service/provider.go` 中,所有协议处理逻辑都通过 `switch-case` 硬编码:

```go
// 当前实现方式
if input.Config.InterfaceType == string(model.ChannelInterfaceMiniMaxVideo) {
    return runMiniMaxVideoTask(ctx, input)
}
if input.Config.InterfaceType == string(model.ChannelInterfaceVolcengineJiMengVideo) {
    return runVolcengineJiMengVideoTask(ctx, input)
}
// ...更多硬编码判断
```

**影响**:
- 每新增一个协议需要修改核心代码
- 测试回归成本高
- 代码耦合度高,难以维护

#### 问题2: 参数转换逻辑分散
不同协议的参数转换函数散落在各处:
- `normalizeXAIVideoDuration()` - xAI专用
- `normalizeMiniMaxDuration()` - MiniMax专用
- `normalizeSeedanceDuration()` - Seedance专用
- `normalizeNovitaVideoDuration()` - Novita专用

**影响**:
- 重复代码多(duration归一化逻辑至少4个版本)
- 新协议需要重新写一套转换逻辑
- 缺乏统一的参数映射机制

#### 问题3: 轮询逻辑重复
异步协议的轮询逻辑高度相似但各自实现:

```go
// MiniMax轮询
for deadline := providerPollingDeadline(ctx); time.Now().Before(deadline); {
    // 查询状态
    // 判断完成/失败
    // 下载结果
}

// Novita轮询 - 几乎相同的逻辑
for deadline := providerPollingDeadline(ctx); time.Now().Before(deadline); {
    // 查询状态
    // 判断完成/失败
    // 下载结果
}
```

**影响**:
- 代码重复率>70%
- 轮询策略调整需要修改多处

#### 问题4: 缺乏协议能力声明
当前 `ChannelInterfaceType` 枚举定义协议类型,但:
- 没有协议元数据(支持的能力、参数映射规则)
- 无法动态扩展
- 协议之间的差异性没有结构化描述

### 1.2 现有插件系统分析

项目已有初步的插件机制(`backend/internal/provider/interface.go`):

```go
type ModelCatalogPlugin interface {
    GetProviderID() string
    Match(baseURL string, headers map[string]string) bool
    AdditionalModels(config DiscoveryConfig) []Model
    GetMetadata() ProviderMetadata
}
```

**现状**:
- 仅用于模型目录发现(Model Catalog)
- 未应用到API协议转换层
- 缺少协议执行接口定义

### 1.3 业界最佳实践调研

#### A. OpenAI兼容层模式 (One API / New API)
**核心思想**: 统一入口协议 + 后端适配器

```
用户请求(OpenAI格式)
    ↓
协议适配器路由
    ↓
├─ OpenAI原生 → 直通
├─ Anthropic → Claude适配器
├─ Google → Gemini适配器
└─ 自定义 → 插件适配器
```

**优点**:
- 用户侧统一标准
- 适配逻辑解耦

**缺点**:
- 强制OpenAI协议可能丢失厂商特性
- 不适合平台内部多协议并存场景

#### B. Apache Camel 模式 (企业集成模式)
**核心思想**: 管道 + 转换器

```
Source Protocol → Transformer → Unified Model → Transformer → Target Protocol
```

**优点**:
- 高度灵活
- 支持复杂转换链

**缺点**:
- 对于AI API场景过于复杂
- 性能开销大

#### C. Kubernetes CRI/CSI 插件模式 (推荐采用)
**核心思想**: 接口标准化 + 插件实现

```go
type RuntimeInterface interface {
    CreateContainer(spec ContainerSpec) (Container, error)
    // ...标准接口
}

// 不同运行时实现该接口
type DockerRuntime implements RuntimeInterface
type ContainerdRuntime implements RuntimeInterface
```

**优点**:
- 接口清晰,易于实现
- 插件间完全解耦
- 易于测试和替换

**为什么适合我们**:
1. AI模型API操作有限且标准(生成、查询、下载)
2. 需要支持多种协议共存
3. 需要动态加载能力

#### D. Terraform Provider 模式
**核心思想**: Schema + CRUD + 生命周期管理

```go
type Provider struct {
    Schema   Schema           // 参数定义
    ConfigureFunc func(d *ResourceData) error
    ResourcesMap  map[string]*Resource
}
```

**优点**:
- Schema驱动,自动验证
- 声明式参数映射

**适用场景分析**:
- 适合资源管理场景
- 对我们来说Schema机制可借鉴用于参数映射

## 二、插件化改造方案

### 2.1 设计原则

1. **最小侵入**: 现有代码逐步迁移,支持新旧协议共存
2. **向后兼容**: 已有的硬编码协议仍可运行
3. **渐进增强**: 先支持视频协议插件化,再扩展到图片/音频
4. **开发友好**: 新增协议只需实现接口,不修改核心代码

### 2.2 核心架构设计

#### 2.2.1 统一内部协议(Internal Protocol Contract)

定义平台内部标准请求/响应格式:

```go
// backend/internal/protocol/types.go
package protocol

// GenerationRequest 统一生成请求
type GenerationRequest struct {
    // 基础字段
    Model     string
    Prompt    string

    // 媒体输入
    Images    []MediaInput
    Videos    []MediaInput
    Audios    []MediaInput

    // 通用参数(标准化命名)
    Duration      int      // 秒数
    AspectRatio   string   // 16:9 / 9:16 / 1:1
    Resolution    string   // 720p / 1080p / 4k
    Quality       string   // low / medium / high
    GenerateAudio bool     // 是否生成音频
    Watermark     bool     // 是否添加水印

    // 扩展参数
    Extra map[string]interface{}
}

// GenerationResponse 统一生成响应
type GenerationResponse struct {
    TaskID        string
    Status        TaskStatus
    Result        *GenerationResult
    EstimatedTime int // 预计完成时间(秒)
    Error         *ProtocolError
}

type GenerationResult struct {
    Videos []MediaOutput
    Images []MediaOutput
    Audios []MediaOutput
}

type TaskStatus string
const (
    TaskPending    TaskStatus = "pending"
    TaskProcessing TaskStatus = "processing"
    TaskCompleted  TaskStatus = "completed"
    TaskFailed     TaskStatus = "failed"
)
```

#### 2.2.2 协议适配器接口

```go
// backend/internal/protocol/adapter.go
package protocol

// ProtocolAdapter 协议适配器接口
type ProtocolAdapter interface {
    // 元数据
    GetMetadata() AdapterMetadata

    // 参数映射
    MapRequest(internal GenerationRequest) (vendorRequest interface{}, err error)
    MapResponse(vendorResponse interface{}) (internal GenerationResponse, err error)

    // 协议执行
    Submit(ctx context.Context, request GenerationRequest) (taskID string, err error)
    Query(ctx context.Context, taskID string) (response GenerationResponse, err error)
    Download(ctx context.Context, taskID string) (data []byte, mimeType string, err error)

    // 能力声明
    Capabilities() ProtocolCapabilities
}

// AdapterMetadata 适配器元数据
type AdapterMetadata struct {
    ID          string   // 唯一标识,如 "minimax-video"
    Name        string   // 显示名称
    Version     string   // 版本号
    Provider    string   // 提供商,如 "MiniMax"
    Description string   // 描述
    Author      string   // 作者
    Capabilities []string // 支持的能力: video, image, audio
}

// ProtocolCapabilities 协议能力声明
type ProtocolCapabilities struct {
    SupportedModes     []string          // video, image, audio
    AsyncMode          bool              // 是否异步
    SupportsWebhook    bool              // 是否支持Webhook
    MaxMediaInputs     MediaLimits       // 媒体输入限制
    ParameterSchema    ParameterSchema   // 参数Schema
}

type MediaLimits struct {
    MaxImages int
    MaxVideos int
    MaxAudios int
}

type ParameterSchema struct {
    Duration      ParameterDef
    AspectRatio   ParameterDef
    Resolution    ParameterDef
    Quality       ParameterDef
    // ...
}

type ParameterDef struct {
    Supported     bool
    Required      bool
    DefaultValue  string
    AllowedValues []string
    Mapper        ParameterMapper  // 参数映射器
}

// ParameterMapper 参数映射器
type ParameterMapper interface {
    // 将内部标准值映射为厂商值
    ToVendor(internal string) (vendor interface{}, err error)
    // 将厂商值映射为内部标准值
    FromVendor(vendor interface{}) (internal string, err error)
}
```

#### 2.2.3 协议注册中心

```go
// backend/internal/protocol/registry.go
package protocol

type Registry struct {
    adapters map[string]ProtocolAdapter
    mu       sync.RWMutex
}

var globalRegistry = &Registry{
    adapters: make(map[string]ProtocolAdapter),
}

// Register 注册协议适配器
func Register(adapter ProtocolAdapter) error {
    metadata := adapter.GetMetadata()
    if metadata.ID == "" {
        return errors.New("adapter ID cannot be empty")
    }

    globalRegistry.mu.Lock()
    defer globalRegistry.mu.Unlock()

    if _, exists := globalRegistry.adapters[metadata.ID]; exists {
        return fmt.Errorf("adapter %s already registered", metadata.ID)
    }

    globalRegistry.adapters[metadata.ID] = adapter
    return nil
}

// Get 获取协议适配器
func Get(adapterID string) (ProtocolAdapter, error) {
    globalRegistry.mu.RLock()
    defer globalRegistry.mu.RUnlock()

    adapter, exists := globalRegistry.adapters[adapterID]
    if !exists {
        return nil, fmt.Errorf("adapter %s not found", adapterID)
    }
    return adapter, nil
}

// List 列出所有适配器
func List() []AdapterMetadata {
    globalRegistry.mu.RLock()
    defer globalRegistry.mu.RUnlock()

    result := make([]AdapterMetadata, 0, len(globalRegistry.adapters))
    for _, adapter := range globalRegistry.adapters {
        result = append(result, adapter.GetMetadata())
    }
    return result
}
```

### 2.3 具体实现示例

#### 2.3.1 MiniMax协议适配器实现

```go
// backend/internal/protocol/adapters/minimax_video.go
package adapters

import (
    "context"
    "infinite-canvas/backend/internal/protocol"
)

type MiniMaxVideoAdapter struct {
    baseURL   string
    apiKey    string
    secretKey string
}

func NewMiniMaxVideoAdapter() *MiniMaxVideoAdapter {
    return &MiniMaxVideoAdapter{}
}

func (a *MiniMaxVideoAdapter) GetMetadata() protocol.AdapterMetadata {
    return protocol.AdapterMetadata{
        ID:          "minimax-video-h3",
        Name:        "MiniMax Video H3",
        Version:     "1.0.0",
        Provider:    "MiniMax",
        Description: "MiniMax H3 视频生成协议",
        Author:      "Yingce Platform",
        Capabilities: []string{"video"},
    }
}

func (a *MiniMaxVideoAdapter) Capabilities() protocol.ProtocolCapabilities {
    return protocol.ProtocolCapabilities{
        SupportedModes:  []string{"video"},
        AsyncMode:       true,
        SupportsWebhook: false,
        MaxMediaInputs: protocol.MediaLimits{
            MaxImages: 9,
            MaxVideos: 3,
            MaxAudios: 3,
        },
        ParameterSchema: protocol.ParameterSchema{
            Duration: protocol.ParameterDef{
                Supported:     true,
                Required:      false,
                DefaultValue:  "5",
                AllowedValues: []string{"4", "5", "6", "10", "15"},
                Mapper:        &miniMaxDurationMapper{},
            },
            AspectRatio: protocol.ParameterDef{
                Supported:     true,
                AllowedValues: []string{"16:9", "9:16", "1:1", "4:3", "3:4", "21:9"},
                Mapper:        &directMapper{},
            },
            Resolution: protocol.ParameterDef{
                Supported:     true,
                AllowedValues: []string{"768p", "1080p", "2k"},
                Mapper:        &miniMaxResolutionMapper{},
            },
        },
    }
}

func (a *MiniMaxVideoAdapter) MapRequest(req protocol.GenerationRequest) (interface{}, error) {
    // 构建MiniMax请求格式
    content := []miniMaxVideoContent{{Type: "text", Text: req.Prompt}}

    // 映射参考图片
    for i, img := range req.Images {
        role := "reference_image"
        if len(req.Videos) == 0 && len(req.Audios) == 0 && len(req.Images) <= 2 {
            if i == 0 {
                role = "first_frame"
            } else if i == 1 {
                role = "last_frame"
            }
        }
        content = append(content, miniMaxVideoContent{
            Type:     "image_url",
            ImageURL: &miniMaxMediaURL{URL: img.URL},
            Role:     role,
        })
    }

    // 参数映射
    resolution, _ := a.Capabilities().ParameterSchema.Resolution.Mapper.ToVendor(req.Resolution)
    duration, _ := a.Capabilities().ParameterSchema.Duration.Mapper.ToVendor(fmt.Sprint(req.Duration))
    aspectRatio, _ := a.Capabilities().ParameterSchema.AspectRatio.Mapper.ToVendor(req.AspectRatio)

    return miniMaxVideoRequest{
        Model:         req.Model,
        Content:       content,
        Resolution:    resolution.(string),
        Duration:      duration.(int),
        Ratio:         aspectRatio.(string),
        AIGCWatermark: &req.Watermark,
    }, nil
}

func (a *MiniMaxVideoAdapter) Submit(ctx context.Context, req protocol.GenerationRequest) (string, error) {
    vendorReq, err := a.MapRequest(req)
    if err != nil {
        return "", err
    }

    // 调用MiniMax API
    var created map[string]interface{}
    if err := a.postJSON(ctx, "/v2/video_generation", vendorReq, &created); err != nil {
        return "", err
    }

    taskID := firstNonEmptyString(stringField(created, "task_id"), stringField(created, "id"))
    if taskID == "" {
        return "", errors.New("未返回task_id")
    }

    return taskID, nil
}

func (a *MiniMaxVideoAdapter) Query(ctx context.Context, taskID string) (protocol.GenerationResponse, error) {
    var response map[string]interface{}
    if err := a.getJSON(ctx, "/v2/query/video_generation/"+url.PathEscape(taskID), &response); err != nil {
        return protocol.GenerationResponse{}, err
    }

    return a.MapResponse(response)
}

func (a *MiniMaxVideoAdapter) MapResponse(vendorResp interface{}) (protocol.GenerationResponse, error) {
    resp := vendorResp.(map[string]interface{})
    task, _ := resp["task"].(map[string]interface{})

    status := strings.ToLower(stringField(task, "status"))

    result := protocol.GenerationResponse{
        TaskID: stringField(task, "task_id"),
    }

    switch status {
    case "succeeded", "completed":
        result.Status = protocol.TaskCompleted
        contentValue, _ := task["content"].(map[string]interface{})
        videoURL := stringField(contentValue, "url")
        if videoURL != "" {
            result.Result = &protocol.GenerationResult{
                Videos: []protocol.MediaOutput{{URL: videoURL}},
            }
        }
    case "failed", "cancelled":
        result.Status = protocol.TaskFailed
        result.Error = &protocol.ProtocolError{
            Message: miniMaxTaskError(task),
        }
    default:
        result.Status = protocol.TaskProcessing
    }

    return result, nil
}

// 参数映射器实现
type miniMaxDurationMapper struct{}

func (m *miniMaxDurationMapper) ToVendor(internal string) (interface{}, error) {
    duration, err := strconv.Atoi(internal)
    if err != nil {
        return 5, nil
    }
    if duration < 4 {
        return 4, nil
    }
    if duration > 15 {
        return 15, nil
    }
    return duration, nil
}

func (m *miniMaxDurationMapper) FromVendor(vendor interface{}) (string, error) {
    return fmt.Sprint(vendor), nil
}

type miniMaxResolutionMapper struct{}

func (m *miniMaxResolutionMapper) ToVendor(internal string) (interface{}, error) {
    switch strings.ToLower(internal) {
    case "2k", "4k", "high", "1080p", "1440p", "2160p":
        return "2K", nil
    default:
        return "768P", nil
    }
}

func (m *miniMaxResolutionMapper) FromVendor(vendor interface{}) (string, error) {
    v := strings.ToUpper(fmt.Sprint(vendor))
    if v == "2K" {
        return "1080p", nil
    }
    return "720p", nil
}

func init() {
    // 自动注册
    protocol.Register(NewMiniMaxVideoAdapter())
}
```

### 2.7 兼容性策略

#### 2.7.1 渐进迁移

**阶段1**: 插件系统与硬编码协议共存
