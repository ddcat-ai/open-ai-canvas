# 站点多语言插件 (`supdance-i18n`)

本插件为 SupDance Canvas 提供热插拔站点多语言（i18n）能力，遵循 `yingce.plugin/v2` 插件契约与 SupDance 三层隔离架构。

## 核心能力

1. **六大核心语言支持**：
   - `zh-CN`（简体中文）
   - `en-US`（English / 英语）
   - `zh-TW`（繁體中文 / 繁体中文）
   - `ja-JP`（日本語 / 日文）
   - `ko-KR`（한국어 / 韩国语）
   - `es-ES`（Español / 西班牙语）
2. **后台插件管理与热插拔**：
   - 可在 `/admin/plugins` 统一开启或停用。
   - 停用后右上角语言切换图标立即隐藏，界面无损回退至原生默认中文。
3. **后台语言管理与词条修改**：
   - 语言管理设置页（`/admin/i18n/settings`）：配置默认语言、自动检测浏览器语言、切换器展示位置及单语种启停与排序。
   - 字段词条修改页（`/admin/i18n/entries`）：支持按模块筛选、六语种对照修改、随时新增自定义翻译词条及 JSON 词库导入导出。
