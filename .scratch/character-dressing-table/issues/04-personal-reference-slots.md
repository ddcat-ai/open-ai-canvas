# 04: 六槽位选择个人素材并生成

**What to build:** 用户在梳妆台为衣服、表情、姿势、配饰、发型和五官分别选择个人图片参考，必要时直接上传，加入提示词后生成并保存角色形象。按《角色卡梳妆台功能规格》复用同一素材选择器、图片预览和现有上传流程。

**Blocked by:** 01：个人素材支持六类业务分类；03：梳妆台最小闭环：提示词生成并保存形象。

**Status:** implemented-pending-acceptance

**实施记录：** 已实现六槽位、同图多用途去重、实际图序、参考上限和上传回填。本地完成六类选用、图片放大及上传后选中；组合任务实际传入基础人物加六类共七张参考图。

- [ ] 提供六个可选槽位，每槽最多一张参考图，支持预览、替换、清除，并显示名称和来源；不新增单槽多件叠加逻辑。
- [ ] 六槽共用现有素材选择器，打开时按槽位初始化业务分类，仅允许选择可访问图片，不能把角色实体、文本或视频自动当作参考图。
- [ ] 个人素材搜索、分页和远端条目选择遵循现有用户/空间权限，不以本机缓存是否加载决定可选性。
- [ ] 在选择流程中上传图片时默认归入当前槽位分类，服务端持久化成功后回填并选中，失败不能出现虚假可用条目。
- [ ] 无当前类别素材时复用空态，提供上传和前往现有素材库分类的入口；未分类资产不被删除或自动重分类。
- [ ] 有任意槽位参考时附加提示词可为空；六槽均为空时继续沿用 03 的提示词要求。
- [ ] 参考图按基础人物、衣服、表情、姿势、配饰、发型、五官顺序组装；相同资源只传一次，提示词中的用途与实际图序仍对应。
- [ ] 将基础身份、各槽用途、用户补充分段表达；未选择的外观尽量保留，五官槽描述指定特征调整，不将参考图人物作为新身份。
- [ ] 参考数量上限包含基础图，依据现有能力合同检查多参考图支持、上下限和模型参数；不支持或超限时明确阻止提交，不能静默截断图片。
- [ ] 提交前素材已删除、权限失效或读取失败时指出问题项，不发出残缺任务；服务端仍执行真实资源准入校验。
- [ ] 生成快照及保存的造型来源记录六类素材、稳定参考资源与提示词；提交后的选择变更不影响运行中任务。
- [ ] 六类各覆盖至少一次真实组件上的筛选与选用，并验证上传回填、重复图多用途、模型限制和保存来源往返；专项测试观察外部行为，不固定组件树或提示词全文。
- [ ] 沿用项目 token、资源图片、工作区状态与浮层边界，处理明暗主题、窄屏滚动和键盘焦点；同步用户说明及待验收记录。
