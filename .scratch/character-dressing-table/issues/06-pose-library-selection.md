# 06: 姿势库直接选入梳妆台

**What to build:** 用户从梳妆台姿势槽打开现有姿势库，搜索并选择具体姿势视角，确认后直接作为姿势参考参与图片生成和形象保存，不需要先插入临时画布图片节点。以《角色卡梳妆台功能规格》为依据，保留独立姿势库的管理与数据边界。

**Blocked by:** 04：六槽位选择个人素材并生成。

**Status:** implemented-pending-acceptance

**实施记录：** 已在原姿势库增加单张资源返回模式，保持原多选插入入口。本地真实姿势图选用、复制回填及组合生成通过，既有姿势库回归通过；多视角目录使用原逻辑，未额外构造真实多视角素材。

- [ ] 在姿势槽提供明确的姿势库入口，复用原库搜索、体系、分类、视角、分页和预览；普通官方姿势素材与独立姿势库入口可区分。
- [ ] 为已有姿势选择能力扩展返回资源的模式，不复制图库组件；梳妆模式只允许确认一个具体视角，原画布多选插入行为仍正常。
- [ ] 确认时通过既有复制接口获取当前用户资源，再回填姿势槽；不能为了选图创建临时画布节点或向外部图库发起浏览器请求。
- [ ] 复制遵守姿势可用状态、同步状态、当前操作者及资源权限；失败保留选择并可重试，不回填失效图片。
- [ ] 替换和清除姿势参考与其他槽位行为一致，取消选择不改变原姿势；复制成功但取消选用不误报任务生成或形象保存成功。
- [ ] 姿势体系内部分类不改为资产业务分类；梳妆快照记为 `pose` 用途，同时保留原姿势条目、视角及已复制资源的稳定标识。
- [ ] 姿势库图片继续由原后台管理，不迁移整库、不将图库文件打包进代码、不重复建立另一套姿势数据。
- [ ] 姿势可与个人或官方六类图片混用，仍受实际参考图数量上限及资源可访问性检查，并能完成生成、命名、保存及刷新选用。
- [ ] 覆盖真实姿势选择、视角切换、复制回填和组合生成流程；复用原复制授权测试补充不可用条目、权限失效与失败重试，回归原画布插入模式。
- [ ] 同步姿势库与梳妆台用户说明、代码地图和待验收记录。
