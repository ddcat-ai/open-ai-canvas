# 01: 个人素材支持六类业务分类

**What to build:** 用户在现有个人素材库新增、编辑或批量上传图片时，可以指定衣服、表情、姿势、配饰、发型、五官分类，随后按分类查找；刷新、重新登录、导入或共享后，分类仍保持正确。本任务以《角色卡梳妆台功能规格》为范围依据，复用现有单值业务分类、表单、筛选和同步能力。

**Blocked by:** None (can start immediately).

**Status:** implemented-pending-acceptance

**实施记录：** 已实现六类公共合同、个人分类入口、规范化及写入校验；前后端专项通过。本地逐类筛选与上传已验证，真实账号切换和跨团队素材流转仍待验收。

- [ ] 前后端统一支持 `clothing`（衣服）、`expression`（表情）、`pose`（姿势）、`accessory`（配饰）、`hairstyle`（发型）、`facial_features`（五官）；业务分类与媒体类型、标签、文件夹保持独立。
- [ ] 现有新增、编辑、批量上传表单提供六类选项；写入成功后服务端实体分类与客户端载荷一致，刷新及重新登录可读回。
- [ ] 现有个人素材列表支持按新分类筛选、分页、搜索和显示计数，未归类素材仍可在原库找到。
- [ ] `accessory` 作为合法新分类保留，历史 `wardrobe` 输入归入 `clothing`；已经归入 `prop` 的资产不自动重分类。
- [ ] 写入合同拒绝未知分类，不将新的合法分类静默降级为“其他”；更新既有旧枚举测试期望。
- [ ] 个人素材同步、导入导出、项目关联和团队共享中实际经过分类解析的链路保留六类值；用现有业务入口或专项测试验证往返。
- [ ] 方舟认证分类继续由系统管理，用户不能手动设置或绕过认证锁定；合法副本不复制原认证身份。
- [ ] 素材仍受用户及空间权限约束，写失败向上传递，不把本地缓存成功显示为服务端保存成功。
- [ ] 分类显示和选择复用已有组件及分类定义，不新建分类配置后台，不新增批量改分类功能。
- [ ] 扩展既有前后端分类及用户资产测试，覆盖六类往返、历史映射、非法写入和认证锁定；同步分类相关 API、数据库专题与待验收记录。
