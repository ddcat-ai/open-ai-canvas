# 05: 官方素材配置与梳妆台选用

**What to build:** 管理员通过现有官方素材后台配置六类梳妆图片，用户在梳妆台按类别浏览官方内容，导入后直接用于生成并保存角色形象。以《角色卡梳妆台功能规格》为依据，复用官方素材发布、导入、资源授权和现有选择器来源切换。

**Blocked by:** 04：六槽位选择个人素材并生成。

**Status:** implemented-pending-acceptance

**实施记录：** 已复用官方后台分类定义、发布与导入 API，增加素材选择器的固定分类及导入个人库模式。六类测试图片经管理员 API 配置发布并在真实选择器选用；后台表单的逐项人工验收及正式素材授权仍待确认。

- [ ] 管理员在既有官方素材后台完成六类图片的上传/资源绑定、命名、说明、标签、来源和授权信息编辑、排序、发布与下架，不新增专用管理后台或素材表。
- [ ] 官方素材 API、分类筛选及计数支持六类值，管理员不能任意扩展产品分类枚举；非管理员写入由服务端拒绝。
- [ ] 梳妆台同一素材选择器支持“官方素材”和“我的素材”，按当前槽位筛选官方图片，搜索、分页、排序和预览沿用原能力。
- [ ] 官方来源遵守原插件启用与用户授权；插件不可用、库为空或请求失败时显示可行动状态，仍可切换个人素材完成生成。
- [ ] 仅已发布且有效的素材对用户可见；未发布、已下架或无权访问的详情与新导入均受服务端校验。
- [ ] 用户选中官方图片后沿用导入个人库流程，再将当前用户可访问的资源填入槽位；不将管理员资源地址直接提交模型。
- [ ] 重复选用同一官方素材复用现有导入结果，不重复创建资产；导入失败不回填为选中成功。
- [ ] 下架停止新导入，已导入副本遵循现有保留规则；官方只读条目不会因用户梳妆操作被修改。
- [ ] 官方与个人图片可以混合参与同一任务，参考顺序、限制和来源记录遵循 04 的合同，生成后仍可命名保存到原角色。
- [ ] 用可控测试图片演示“后台配置发布 → 用户分类查找 → 导入选中 → 生成 → 保存”；复用官方素材路由、导入与权限测试覆盖插件、状态、幂等和资源授权。
- [ ] 同步官方素材管理、用户选用及 API 合同说明和待验收记录；面向上线的六类正式初始内容由 08 交付。
