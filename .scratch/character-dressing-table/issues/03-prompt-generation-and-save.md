# 03: 梳妆台最小闭环：提示词生成并保存形象

**What to build:** 用户从角色卡可发现的梳妆台按钮进入现有角色工作室，以节点当前形象为基础，填写提示词、选择图片模型并提交统一生成任务，预览后将一张结果命名保存为该角色的新形象。本任务完成《角色卡梳妆台功能规格》的最小生成闭环，素材槽位由后续任务扩展。

**Blocked by:** 02：角色形象安全新增与命名。

**Status:** implemented-pending-acceptance

**实施记录：** 已在真实角色卡和工作室接入原模型选择器、图片参数及统一任务。本地测试上游的生成、预览、命名保存和刷新选用通过；该结果不能证明真实供应商的画面效果。

- [ ] 在真实角色卡提供可点击且可通过键盘操作的梳妆台入口，在现有工作室和浮层体系承载内容，不制作独立页面或静态 HTML 替代真实组件。
- [ ] 打开时读取最新角色详情，显示人物名称和当前节点选中形象；通过既有形象选择能力可调整基础图，无可用图时引导现有上传/绑定流程。
- [ ] 首版没有槽位参考时要求附加提示词非空；角色基础图不可访问或角色不可编辑时明确提示并阻止无效提交。
- [ ] 复用 ModelPicker 和现有图片参数合同，校验模型支持图像参考；模型切换按原合同重置参数，不能将不支持参考图的模型降级为纯文生图。
- [ ] 输入包含基础人物图、身份设定和用户提示词；表达保留未指定特征的意图，不承诺模型必然精确保持身份。
- [ ] 使用统一后端图片任务入口，沿用资源准入、任务幂等、渠道、额度、价格与计费；不复制供应商调用或新增独立队列。
- [ ] 提交冻结角色、画布/节点、基础造型、角色版本、提示词、模型参数与参考资源的稳定 ID 快照，不存密钥或临时签名地址。
- [ ] 显示真实排队/生成进度、错误和取消结果；运行时修改输入只影响下一次任务，重复提交使用同一操作标识，主动再次生成产生新操作。
- [ ] 产出沿用现有资源物化流程，资源尚未就绪时不开放保存；默认一张，若原模型支持多张则可预览并明确选一张保存。
- [ ] 用户命名后复用 02 的保存能力新增造型，记录来源任务、输出资源与输入快照；后端验证任务、输出、角色及当前操作者的真实权限和关联关系。
- [ ] 保存失败只重试角色写入，保留结果和名称，不创建新生成任务或产生第二次生成费用；成功后当前节点选用新形象，其他节点保持选择。
- [ ] 沿用现有造型管理可查看来源、再次命名和选用，后续操作不会丢弃来源信息；历史结果的产出模型不随当前模型下拉变化。
- [ ] 在真实应用组件上验证“基础图 + 提示词 → 任务 → 预览 → 命名保存 → 刷新选用”，扩展现有任务/角色测试；同步功能与代码地图、API/数据库变化及待验收记录。
