# 07: 关闭、刷新后的任务与结果恢复

**What to build:** 用户关闭梳妆台或刷新页面后，仍可找到之前提交的任务和待保存图片，恢复后继续预览、命名和保存；取消、失败、角色变化及重复事件均不会导致重复生成、重复保存或丢失产出。复用现有任务中心、资源物化和持久消费去重能力，遵循《角色卡梳妆台功能规格》。

**Blocked by:** 03：梳妆台最小闭环：提示词生成并保存形象。

**Status:** implemented-pending-acceptance

**实施记录：** 已实现按角色筛选后分页、更早任务游标、恢复及已保存状态。专项覆盖无关新任务不挤掉历史和用户隔离；本地生成中刷新、待保存恢复、已保存恢复及并发声音更新后的冲突重试通过。

- [ ] 任务关联通过稳定的角色、画布/节点、基础造型、输入快照及输出标识持久化，重开面板或刷新后从服务端任务与现有同步链路恢复，不依赖组件内存。
- [ ] 恢复排队中、运行中、失败、已取消、结果处理中、待保存及已保存状态，展示遵循服务端事实，不单凭本地超时推断终止。
- [ ] 关闭面板不取消任务；取消调用现有任务取消机制，处理与任务完成竞争时以实际终态和资源结果为准。
- [ ] 任务成功而资源尚未物化完成时继续等待；资源可用后恢复预览与保存入口，不自动将产出写入角色造型库。
- [ ] 失败或取消的任务不会新增造型；重新生成是新操作，恢复或单独重试保存不会再次触发图片模型。
- [ ] 消费重复事件、重放成功状态或并发打开多个页面不产生重复资源消费效果、造型或角色版本；保存幂等由服务端保证。
- [ ] 角色被其他会话更新时恢复结果仍可预览，保存返回冲突后可读取新版本并重新操作，不覆盖新增造型。
- [ ] 角色被删除或失去写权限时明确说明无法保存到该角色；任务结果仍可在有权访问的任务记录中找到，不能越权保存。
- [ ] 发起节点删除后不丢失任务产出，不重建节点；角色仍可写时可以从恢复入口继续保存到角色库。
- [ ] 账号或空间切换遵守现有缓存隔离和权限合同，不能串出其他账号任务、参考或生成结果。
- [ ] 来源恢复按已持久化快照读取，不硬编码提示词模式；03 的基础人物加文字任务可独立验收，未来含六类参考的相同快照能原样保留。
- [ ] 扩展既有任务持久恢复、素材恢复、消费去重、取消和权限测试，覆盖刷新、重放、保存响应丢失及冲突后重试；同步任务行为说明与待验收记录。
