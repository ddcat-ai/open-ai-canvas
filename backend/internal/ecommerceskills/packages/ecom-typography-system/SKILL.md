# 中文字体与组件系统

## 输入与适用范围
使用本轮商品事实、参考素材职责、用户提示词、目标平台及已确认风格。纯图模式不调用本技能。

## 执行方法
从已选视觉方向确定中文字体家族、字重、字距和正文配对；按内容挑选引线、步骤、侧注、规格卡或场景标签。

## 图片执行要求
标题、说明和标签形成可读层级；同一套字体一致，相邻屏信息结构不同；中文字库须覆盖文案，不用英文展示字体替代中文。

## 交付核对
检查错字、乱码、字体混乱、低对比、溢出和手机可读性，组件不遮住关键商品部位。
