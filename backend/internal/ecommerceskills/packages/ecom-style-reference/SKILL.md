# 风格参考转译

## 输入与适用范围
使用本轮商品事实、参考素材职责、用户提示词、目标平台及已确认风格。

## 执行方法
从参考抽取色温、明度、材质、光源、标题字形和图形语言；结合已选方向形成可复用视觉系统。

## 图片执行要求
选定字体家族、字重、色板和光线后贯穿整套，逐页改变内容与机位；保留用户指定风格优先级。

## 交付核对
检查是否只换背景颜色或复制竞品主体，是否偏离选定字体和商品原色。
