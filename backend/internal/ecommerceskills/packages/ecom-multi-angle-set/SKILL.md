# 商品多角度系列

## 输入与适用范围
使用本轮商品事实、参考素材职责、用户提示词、目标平台及已确认风格。

## 执行方法
先确认哪些角度有证据，安排正面、三分之四、侧面或局部特写；未知背面和内部结构不新增零件。

## 图片执行要求
所有视角共享本色、轮廓与Logo位置，变换机位和主体朝向；三视图保持中性背景且无新增广告文字。

## 交付核对
对照接口、图案、部件数量，排除镜像Logo、错位印字和凭空生成的背面结构。
