# 版式参考拆解

## 输入与适用范围
使用本轮商品事实、参考素材职责、用户提示词、目标平台及已确认风格。

## 执行方法
读取参考中的真实屏数、阅读路径、主次比例、标题位置与信息组件；以本商品内容重组，不照搬竞品文案。

## 图片执行要求
长图逐屏参考按用户模式保留对应关系；布局借鉴只传递结构、留白与层级，不改变本轮尺寸或事实。

## 交付核对
核对参考屏与生成屏对应，商品占比合理，原图中的规格和承诺没有被复制。
