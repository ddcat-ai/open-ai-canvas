# 已知尺寸与规格图

## 输入与适用范围
使用本轮商品事实、参考素材职责、用户提示词、目标平台及已确认风格。纯图模式不调用本技能。

## 执行方法
仅使用卖家提供或清晰可辨的尺寸与单位，分清整机、部件和包装；按用途选择尺寸线、规格卡或服饰尺码表。

## 图片执行要求
尺寸引线端点落在真实边界，表格行列对齐，数字逐字对应资料；单位换算明确，缺失数值不猜。

## 交付核对
检查每个数值、单位、尺寸方向和尺码对应，不把示例尺寸、误差或参考物大小当真实规格。
