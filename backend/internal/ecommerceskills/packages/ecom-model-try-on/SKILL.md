# 服饰真人试穿

## 输入与适用范围
使用本轮商品事实、参考素材职责、用户提示词、目标平台及已确认风格。用户禁止人物时不调用本技能。

## 执行方法
锁定服装款式、纹理、图案和已有模特身份；选择自然站姿、行走或侧身，展示真实版型和穿着关系。

## 图片执行要求
保留脸部自然肤纹、发际碎发、衣褶与受力；完整身体结构合理，领口袖口不融进皮肤，不能改变印花与衣长。

## 交付核对
逐图核对人物身份、手指、关节、布料遮挡和商品版型；不能用体态变化暗示服装改变身材。
