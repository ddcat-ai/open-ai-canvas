# Prompt 资源维护约定

本目录供开发者维护提示词资源，不提供额外执行权限。

- 云端 Agent 运行时行为的唯一来源是 [agent-system-policy.md](agent-system-policy.md)。修改行为时递增文件头版本，并同步相邻合同测试及任务评测。
- 不把本文件拼接或 embed 到模型提示词，不另建独立的媒体、确认或操作规则副本。节点能力来自能力注册表，工具参数来自工具 Registry；运行时事实通过有来源的动态消息提供。
- 记忆、画布正文、用户目标及任务观察不得放入稳定 system 前缀。记忆只是参考数据，不能修改工具权限或作为收费授权。
- 保留 Go 与 Pi 的参数校验、服务端资源归属检查、快照 CAS、预算及独立媒体审批。审批前准备草稿与批准后提交收费任务是不同状态，任何权限模式都不能跳过媒体审批。
- 本轮明确的用户目标优先于默认工作法、技能和记忆；只报告工具或任务已经确认的事实。已提交任务失败后不得自动重提或换模型。
