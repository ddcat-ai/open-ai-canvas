## 〇、宪章

### 0.1 测量原则（一切判断的地基）

1. **好坏以观众端可观测效应定义。** 评价故事不引用作者意图，只看观众身上发生了什么：是否想看下去、是否在乎、是否动了情绪、是否带走了东西。
2. **创作者是第一观众。** 自己都不想看的故事不要往下写。只服务第一观众是傲慢，只讨好后续观众是谄媚，两个都是病。
3. **「好」由定位裁决。** 不存在唯一的好故事标准，只存在「配比是否兑现定位契约」。拿文艺片标准给微短剧打分是错的，反过来也错。**没有定位声明，不输出任何好坏判断。**
4. **轴是效应，组件是来源。** 人物、世界、情节、对白不是评价维度，是给效应轴供能的来源。诊断动作永远是两步：先定位哪条轴亏，再反查哪个来源断。

### 0.2 依赖铁律

* 本skill不知道任何项目的存在。项目专属内容只能以输入（项目brief、定位声明）或本skill产出文档的形式存在于项目侧。
* 不假设任何上下游skill存在。若环境中有套件skill，标准协作：人物两清单 → 角色设计；节拍表 → 色彩剧本 / editorial / 分镜；价值主张 → 总导演。
* 按需取用：用户只要logline就走到第2步，只要诊断就走诊断模式。但凡涉及好坏判断，定位声明不可省。

### 0.3 元规则（系统自我修正）

遇到评价体系解释不了的公认好故事：不打补丁，先问「哪个二元判断其实是被压扁的轴」，升维处理。（先例：抓力门槛→吸引力轴；余味有无→确认↔重组光谱。）

### 0.4 输出纪律

结论先行，短句直说，不堆术语，不绕。诊断输出按「影响大小 × 修复成本」排序，每个问题给位置、病因、修法。

## 一、评价体系（速查版，详解见 references/01-coordinate-system.md）

### 1.1 三门槛——坏一条，全盘不合格

门槛只有合格与缺陷，没有高分。轴是调配比的，门槛是修缺陷的。

| 门槛      | 标准                 | 合格线                             | 典型崩法         |
| ------- | ------------------ | ------------------------------- | ------------ |
| **完整**  | 挖的坑都有回应            | 回应 \= 回答 / 明确不答 / 转化为新问题。开放结局合格 | 烂尾：坑被遗忘      |
| **自洽**  | 守自己立的规矩            | 世界规则 / 人物性格 / 因果三层自洽。不要求写实      | 机械降神；人物OOC   |
| **可追随** | 观众随时能答：谁、要什么、发生了什么 | 能重建即可，不要求容易                     | 动机不明；时空乱跳无锚点 |

### 1.2 四轴——好故事同时做到四件事

| 轴       | 观众端效应           | 刻度                 | 供能来源                       |
| ------- | --------------- | ------------------ | -------------------------- |
| **吸引力** | 想一直看下去          | 五通道各自强度            | 问题 / 世界 / 人物魅力 / 概念 / 类型承诺 |
| **在乎**  | 在乎故事里的人         | 深度 × 广度 × 指向       | 六机制（references/02）         |
| **情绪**  | 真的笑 / 哭 / 爽 / 怕 | 类型 × 强度 × 丰富度 × 节奏 | 四来源按深浅：在乎 > 谜题 > 奇观 > 直接刺激 |
| **意义**  | 看完带走东西          | 清晰度 × 确认↔重组 × 半衰期  | 价值主张 + 情绪积累                |

**依赖关系（不是时间先后）**：吸引力从第一秒到最后一秒都得在线；情绪的强度受限于事件发生前已建立的在乎；意义靠情绪积累成立——被体验的才算，被告知的是说教。

**四种衔接故障**：

1. 类型承诺没兑现（吸引力开的票，情绪轴拒付）
2. 没建立在乎就煽情（尬煽、奇观疲劳）
3. 有情绪没沉淀（好看但空）
4. 有主张没情绪（说教）

## 二、生成工序（七步）

### 第0步 定位声明

开工前先填。没有定位声明不准动笔，也不准评价。

形态/时长：（长片 / 剧集×集数 / 短片 / 微短剧 / 游戏叙事 / ...） 受众： 类型承诺：（观众来看什么：爽 / 哭 / 笑 / 怕 / 解谜 / 奇观 / 陪伴 / ...） 四轴配比：（四条轴各标 高/中/低，指明主轴；配比无对错，只有是否兑现） 对标作品：（2-3部，可选）

### 第1步 核心三件

* **概念**：what if 一句话。检验：这个设定本身有没有人想看？
* **渴望**：谁、拼命想要什么、为什么现在必须要。检验：够具体吗？有期限吗？
* **价值主张**：故事想论证什么。走确认（让观众更信他已信的）还是重组（让观众换个角度看世界）。

三件分别是吸引力、在乎、意义的种子。**至少一件必须强。** 三件都平庸，回炉，不进下一步。

### 第2步 Logline

主角 + 处境 + 目标 + 障碍 + 钩子，一句话。

自检三问：渴望具体吗；障碍比主角强吗；钩子挂在吸引力哪条通道上。30秒讲不清就回炉。

### 第3步 人物配置

* 主角两张清单分开填（机制详见 references/02）：
  * **为什么想看他**：魅力五机制（矛盾同体 / 某维拉满 / 猜不到但事后合理 / 说做风格化 / 替观众越界）选2-3条，写出具体落点
  * **为什么心疼他**：在乎六机制（渴望 / 亏欠 / 缺口 / 投入 / 连带 / 代入）选2-3条，写出具体落点
* 反派至少配魅力。只有功能没有魅力的反派撑不起对抗。
* 每个配角写一句存在理由，写不出就删。
* 产出「人物两清单」，这是给角色设计skill的接口。

### 第4步 节拍表

节拍表回答五件事：什么时候发生什么事，动用观众对谁的在乎，触发什么情绪，开了什么坑，还了什么坑。

| # | 节拍 | 事件（谁做了什么） | 动用的在乎 | 情绪（类型/强度1-5/来源） | 坑（开/还/转） |
| - | -- | --------- | ----- | --------------- | -------- |

结构脚手架按定位从锚点库选（references/03）。**锚点是脚手架，不是标准答案**——节拍表填完用四轴检验，不用模板检验。

整表四查：

1. 情绪曲线有形状：最高峰在结尾前；中段有起伏，不能平
2. 丰富度对照定位：合家欢palette要宽，类型片允许窄而深
3. 每个坑都有归宿（对照门槛·完整）
4. 意义是被事件演出来的，不是被台词说出来的

### 第5步 Treatment（到此为止，剧本交 screenwriter）

按节拍表展开成 treatment：散文、现在时、到场不到镜头，把每场的事件、情绪、转折讲清楚。这是本skill的终点产物。

**剧本（场景/动作/对白）由 screenwriter 接手**——它负责把 treatment 写成有潜台词的对白、晚进早出的场景、可视化的动作。本skill不写剧本，但要把"主题靠体验不靠台词说"这条意义轴纪律传递给它（见第六章意义轴）。

### 第6步 自审（循环4-6步，直到通过）

按 references/04 清单走：门槛 → 轴 → 衔接 → 配比对照定位声明。

通过标准：三门槛零缺陷；主轴达到定位声明的目标值；四种衔接故障一个都没有。

## 三、诊断模式（用户拿现成故事来）

输入可以是任何颗粒度：一句梗概、大纲、节拍表、完整剧本、成片描述。

流程固定五步：

1. **先问定位**。用户没给就先问形态、受众、类型承诺。没有定位不评好坏。
2. **三门槛扫描**：不完整 / 不自洽 / 跟不上。有门槛缺陷先报告并停在这里——门槛没修好，谈轴没有意义。
3. **四轴逐条**：每条轴给状态（强/正常/亏）+ 证据（指向具体位置）。
4. **衔接四查**：承诺兑现 / 在乎先于煽情 / 情绪有沉淀 / 主张有体验。
5. **输出**：问题按「影响大小 × 修复成本」排序。每个问题三件套：位置（哪场/哪个节拍）、病因（哪条轴/门槛，哪个来源断了）、修法（具体建议，不止说"加强"）。

常见病症对照表见 references/04-diagnostic-checklist.md。

## 四、自审规则（评审纪律）

* 对片不对人。只指出问题，修法给建议，最终决定权在用户。
* 诊断顺序铁律：先门槛，再轴，再衔接。门槛坏了不谈轴。
* 不拿单一模板当裁判（"不符合Save the Cat"不是问题，"中段没有情绪起伏"才是问题）。
* 遇到模型外的反例，走0.3元规则升维，不硬套。

## 五、输出接口（字段进套件数据schema）

| 产物      | 字段                           | 下游                |
| ------- | ---------------------------- | ----------------- |
| 定位声明    | 形态/时长/受众/类型承诺/四轴配比/对标        | 全套件               |
| Logline | 一句话（主角+处境+目标+障碍+钩子）          | 总导演               |
| 人物两清单   | 每角色：功能/渴望/魅力机制×n/在乎机制×n/缺口   | 角色设计              |
| 节拍表     | 节拍/事件/在乎/情绪（类型·强度·来源）/坑      | 色彩剧本、editorial、分镜 |
| 价值主张    | 一句话 + 确认/重组 + 论证线（哪几个节拍完成论证） | 总导演               |

## 六、反模式（永远不做）

1. 没有定位声明就动笔或评价
2. 拿模板当答案——锚点是脚手架，四轴才是裁判
3. 主角没有具体渴望就往下写
4. 没建立在乎就堆大事件
5. 用台词说主题
6. 坑开了不管
7. 第三幕冒出没铺垫的能力救场
8. 把「我想表达」凌驾于「观众能体验」
9. 诊断时绕过门槛直接谈轴
10. 输出绕弯卖弄——结论直说

## references/01-coordinate-system

## 坐标系详解 — 三门槛 + 四轴

本文件是评价体系的完整版。速查版在 SKILL.md 第一章。

### 一、测量原则

**好坏住在观众身上，不在文本里。** 文本是源码，观众心里的体验是运行结果。所以每一条评价维度都必须对应一个可在观众身上观测到的效应，否则就是行业迷信——「必须有三幕」属于此类：三幕是手段，不是效应。

**创作者是第一观众。** 发心和表达欲不需要另立标准：它们就是第一观众的在乎与意义需求。两种病一把尺子量：只服务第一观众、无视后续观众 \= 傲慢；只讨好后续观众、第一观众自己都不信 \= 谄媚。

**「好」由定位裁决。** 好故事是坐标空间里的一个区域，不是一个点。《疯狂的麦克斯》《东京物语》《让子弹飞》配比相距甚远，但都成立。判断标准永远是：实际配比是否兑现了定位声明的契约。

### 二、三门槛详解

门槛与轴的分工：**门槛坏一条，四条轴全部失效**；门槛没有「更完整」「更自洽」的高分，只有合格与缺陷。

### 2.1 完整

**标准**：挖的坑都有回应。回应有三种合法形式——回答、明确不答（故事承认这个问题存在且选择不答）、转化（旧问题变成新问题）。

| 案例              | 判定                 |
| --------------- | ------------------ |
| 《花样年华》开放结局      | 合格——问题被郑重对待，只是不给答案 |
| 烂尾剧：前期伏笔后期当没发生过 | 缺陷——坑被遗忘           |

**检查法**：把全片打开过的问题列成清单（谁杀的、能不能在一起、宝物在哪、他会不会原谅），逐条找归宿。

### 2.2 自洽

**标准**：守自己立的规矩。与写实无关——荒诞故事一样可以自洽。

三个层面：

1. **世界规则自洽**：魔法世界可以有龙，但第三幕不能突然冒出从未铺垫的新能力救场（机械降神）。规则可以升级，但升级要有铺垫。
2. **人物自洽**：行为符合已建立的性格与动机。为了情节需要让人物做出他不会做的事 \= OOC，自洽崩。
3. **因果自洽**：事件有因有果，巧合可以用来制造麻烦，不可以用来解决麻烦。

| 案例               | 判定            |
| ---------------- | ------------- |
| 《大话西游》荒诞设定       | 合格——规矩荒诞但全程遵守 |
| 平庸网剧：反派智商随剧情需要波动 | 缺陷——人物自洽崩     |

### 2.3 可追随

**标准**：观众在任何时刻被暂停提问，都能回答三件事——谁、他要什么、现在发生了什么。门槛是「能重建」，不是「容易」。

《信条》贴着这条线走：观众可以暂时不懂机制，但始终知道主角要阻止什么。允许难，不允许断。

**检查法**：在节拍表任意三处暂停，模拟观众回答三问。答不出的位置就是断点，断点通常出在：动机交代缺失、视点切换无锚、信息该给不给。

### 三、四轴详解

### 3.1 吸引力——想一直看下去

**效应**：观众持续往下看的动力。从第一秒到最后一秒都得在线，它不是「开头的事」。

**五通道**（来源，可叠加）：

| 通道   | 动力           | 强例                    | 易塌点          |
| ---- | ------------ | --------------------- | ------------ |
| 问题   | 想知道答案        | 悬疑、谜团、还没还的坑           | 答案不值钩子的重量    |
| 世界   | 想待在这里        | 《千与千寻》汤屋、武侠江湖         | 设定堆砌但无生活感    |
| 人物魅力 | 想跟着他         | 杰克船长（详见references/02） | 主角平庸靠配角续命    |
| 概念   | what if 的新奇  | 《楚门的世界》《心迷宫》          | 概念耗尽后没故事接棒   |
| 类型承诺 | 知道会爽/笑/怕，等兑现 | 类型片海报即承诺              | 承诺了不给（衔接故障1） |

**全作品吸引力预算**：一部作品的吸引力由故事层和媒介层（画面/表演/音乐）共同出资。故事可以有意把负载转移给媒介层（《龙猫》：低悬念，吸引力压在世界魅力与美术氛围上）。本skill只对故事层负责，但定位声明里要写明转移意图，给总导演和视觉侧。

### 3.2 在乎——在乎故事里的人

**效应**：观众希望某人得到什么、免于什么。它不是当下的激烈感受，是让感受成为可能的前提。

**刻度**：深度（愿意为他揪心到什么程度）× 广度（几个投入点）× 指向（观众能否说出「我希望他\_\_\_」——说不出就是指向模糊）。

**两条通道**：把他当别人疼（机制1-5）；把他当自己活（机制6代入）。文艺片走前者，爽文走后者，商业大片两头都要。六机制详见 references/02。

**关键纪律**：情绪强度受限于事件发生前已建立的在乎。在乎是预先要攒的，事件只负责触发。

### 3.3 情绪——真的笑、哭、爽、怕

**效应**：观众实际被牵动的情绪体验。

**刻度**：

* **类型（palette）**：笑/哭/爽/怕/燃/暖/惊讶/敬畏…… 定位决定宽窄：合家欢动画palette要宽（皮克斯单片常跨敬畏-爆笑-哀伤-温暖），恐怖片允许窄而深。
* **强度**：1-5标定。
* **丰富度**：palette实际用了几色。
* **节奏**：情绪曲线的形状——最高峰位置、起伏密度、留白。

**四种来源，按深浅排**：

| 来源   | 深度 | 特性                  |
| ---- | -- | ------------------- |
| 在乎触发 | 最深 | 可累积、可复利，结尾大放只能靠它    |
| 谜题解开 | 中  | 智力快感，不经过在乎也成立（本格推理） |
| 奇观惊叹 | 中浅 | 世界与场面供给，消退较快        |
| 直接刺激 | 最浅 | 惊吓、段子——速效，消退快，攒不起来  |

**形态配比规律**：微短剧靠浅来源高频率；长片必须有深来源，全靠浅来源的长片必然中段崩（奇观疲劳）。

### 3.4 意义——看完带走东西

**效应**：观众对人与世界的理解发生了变化，或已有的信念被有力地确认。

**刻度**：

* **清晰度**：故事是否真的论证了一个具体的价值主张。「善有善报」被完整演出来，也是合格的清晰。
* **确认 ↔ 重组**：确认型让观众更信他已信的（爽文、合家欢——即时满足）；重组型让观众换角度看世界（文艺片——后劲）。两端都是真实效应，无高下，看定位。
* **半衰期**：意义效应的持续时间。确认型以小时计，重组型以年计。定位决定需要哪种。

**铁律**：意义的说服力来自情绪积累。观众相信「善有善报」是因为亲身感受过那份不公与释放——**被体验的才算数，被告知的是说教**。检查法：把直接陈述主题的台词全部删掉，主张还立得住吗？

### 四、轴间依赖与衔接故障

依赖链：吸引力把人留在故事里 → 在乎让人把感情放进来 → 事件触发情绪 → 情绪积累让意义立住。

四种衔接故障（诊断高发区）：

| 故障      | 症状             | 病灶           |
| ------- | -------------- | ------------ |
| 承诺不兑现   | 类型片观众骂「不爽」「被骗」 | 吸引力开的票，情绪轴没付 |
| 在乎未建先煽情 | 尬煽；爆炸再大也无感     | 事件强度超过已攒的在乎  |
| 有情绪无沉淀  | 「好看但空」「看完就忘」   | 情绪没有汇入价值主张   |
| 有主张无情绪  | 说教感            | 主张被告知，未被体验   |

### 五、九形态验证记录（跨形态测试存档）

| 形态    | 代表      | 结论                    |
| ----- | ------- | --------------------- |
| 合家欢动画 | 《寻梦环游记》 | 四轴全开，基准               |
| 生活流   | 《步履不停》  | 低悬念高纯度，吸引力走人物与真实细节，成立 |
| 本格推理  | 阿加莎式    | 证明情绪可由谜题供能、不经在乎       |
| 恐怖    | 《闪灵》    | 惊吓走浅来源，持续恐惧必须在乎       |
| 段子喜剧  | 《武林外传》  | 单集靠浅来源，十年重看靠在乎        |
| 微短剧   | 战神归来类   | 在乎走代入通道，人物薄是功能不是缺陷    |
| 纪录片   | 《徒手攀岩》  | 非虚构适用，在乎天然成立          |
| 无对白短片 | 《鹬》     | 模型不依赖语言               |
| 非线性   | 《低俗小说》  | 模型测观众心理，不测情节顺序        |

边界划定：审美愉悦主要由媒介层供给（归visual-director等）；「想住在这个世界里」的归属感归IP/系列层（单故事坐标系不管）。

## references/02-character-mechanisms

## 人物机制详表 — 为什么想看他 / 为什么心疼他

人物在坐标系里是来源不是轴：同一个人物给两条轴供能——魅力供吸引力（想看他），在乎机制供在乎轴（心疼他）。两者正交，可以独立变化：

|         | 高在乎              | 低在乎         |
| ------- | ---------------- | ----------- |
| **高魅力** | 顶级主角（孙悟空、千寻、钢铁侠） | 好反派（灭霸、汉尼拔） |
| **低魅力** | 纪实苦难型主角（《素媛》）    | 工具人         |

设计主角时两张清单分开填，各选2-3条机制，不必全占。反派至少配魅力。

### 一、魅力五机制（为什么想看他）

本质一句话：有魅力的人物，本身是一道持续出新题的谜，而且每个答案都好看。

#### 1. 矛盾同体

两种不该共存的特质在一个人身上。优雅的食人医生（汉尼拔）、讲哲学的屠夫（灭霸）、想当好人的魔丸（哪吒）、好色又仗义（韦小宝）。

* 设计要点：两个特质要真矛盾，且共存要有内在解释（不解释\=人设散）。
* 过量风险：堆三个以上矛盾，人物碎掉。

#### 2. 某维拉满

在一个维度做到极端：最聪明（夏洛克）、最自由（孙悟空）、最不要脸（韦小宝）。极端保证"他下一步做什么"永远值得看。

* 设计要点：拉满的维度必须能持续出戏；无敌要配限制（紧箍咒、毒瘾、社交障碍），否则无戏可看。
* 过量风险：纯爽无碍\=剧情张力归零。

#### 3. 猜不到，但事后合理

每一步出乎意料，回头看全符合他的逻辑（杰克船长）。猜不到是惊喜，合理是可信。

* 设计要点：底层动机要稳定，意外来自手段不是动机漂移。
* 过量风险：只有猜不到没有合理\=噪音，不是魅力。

#### 4. 说做风格化

台词和动作有独属于他的腔调，可引用、可模仿（周星驰角色、Deadpool）。

* 设计要点：给人物2-3个语言/行为签名（口头禅、习惯动作、独特逻辑），全程一致。
* 过量风险：签名密度过高\=油。

#### 5. 替观众越界

做观众不敢做的事：说真话、掀桌子、无视规则（Joker、大闹天宫、张麻子）。

* 设计要点：越的界必须是观众真实压抑的界，越界要付代价（不付代价\=价值观风险，中国市场注意审查）。
* 过量风险：纯破坏无立场，观众爽完反感。

### 二、在乎六机制（为什么心疼他）

两条通道：**把他当别人疼**（机制1-5，文艺片主路）；**把他当自己活**（机制6，爽文主路）。商业大片两头都要。

#### 1. 渴望

他强烈地想要一个具体的东西（千寻要救父母）。观众会接住人物的目标当自己的目标；没有渴望的人物，观众无处用力——很多文艺片主角的病根在这条。

* 设计要点：具体、有期限、有代价。外部目标（想要的）和内在需要（缺的）可以错位，错位本身就是弧光的引擎。
* 缺失症状：观众说"不知道他到底想干嘛"。

#### 2. 亏欠

他受了不该受的苦（萧峰被冤），或付出得不到回报（许三观卖血）。不公平感直接触发保护欲。

* 设计要点：苦要"不该受"，该受的苦不触发亏欠。
* 过量风险：卖惨。苦难密度超过观众承受力，同情变疲劳。

#### 3. 缺口

他有看得见的伤口或软肋：卡尔的丧偶、瓦力的孤独、钢铁侠的心脏。完美的人没法疼，缺口是感情的入口。

* 设计要点：缺口必须影响行动（决策、回避、代偿），贴标签式的缺口（"他有点自卑"但行为看不出）无效。
* 过量风险：缺口压倒能力\=软弱惹烦。

#### 4. 投入

观众陪他走得越久、看他为目标付的代价越多，感情越深。长剧角色像家人是这条在起作用。

* 设计要点：让观众看见代价（时间、尊严、身体、关系）。
* 形态修正：短内容先天吃亏，用高密度事件压缩（开场五分钟让他付一次大代价）。

#### 5. 连带

有人依赖他，或他和我们已在乎的人绑定。《这个杀手不太冷》：先在乎玛蒂尔达，连带在乎里昂。

* 设计要点：依赖关系要具体（接送、喂药、承诺），不能只是口头宣称"他很重要"。
* 用法：给难以直接讨喜的角色（杀手、混蛋、怪物）接入在乎的标准路径。

#### 6. 代入

观众把他当成自己。爽文主角故意写薄，方便观众穿上。

* 设计要点：代入需要两个条件——空位（少给主角强烈个性与外貌特写）+ 普遍欲望（被尊重、逆袭、被爱）。
* 代价：人物本身不可记忆，换个壳就忘。走这条通道是定位选择，不是缺陷；但想要人物成为IP资产，不能只走这条。

### 三、人物两清单（输出模板，接口给角色设计skill）

角色名： 功能（一句话，写不出就删角色）： 渴望：想要\_*\_，因为\_*\_，不惜\_\_\_ 为什么想看他（魅力机制，选2-3，写具体落点）： 为什么心疼他（在乎机制，选2-3，写具体落点）： 缺口（影响行动的那种）： 语言/行为签名（2-3个）：

配角规则：每个配角至少占一条机制或一个功能；既无机制也无功能的配角删掉。 反派规则：至少配魅力2条；顶级反派加一条在乎机制（灭霸献祭卡魔拉的瞬间）。

## references/03-structure-anchors

## 结构锚点库 — 成熟方法论与选用规则

### 使用规则（先读这个）

1. **锚点是脚手架，不是标准答案。** 它们是坐标空间里被验证过的点，不是轴。节拍表搭完用四轴检验，不用模板检验。
2. **按定位选锚点**，见文末对照表。
3. "不符合某模板"永远不构成问题；"中段没有情绪起伏"才构成问题。
4. 比例一律按总时长百分比给，跨形态通用。

### 一、三幕结构

| 幕  | 占比      | 任务                                        |
| -- | ------- | ----------------------------------------- |
| 一幕 | 0-25%   | 建立人物与日常 → 打破日常的事件（激励事件，最迟15%处出现）→ 主角无法回头  |
| 二幕 | 25-75%  | 障碍升级；50%处中点（假胜利或假失败，目标升级或真相翻转）；70-75%处最低谷 |
| 三幕 | 75-100% | 内在转变 → 最终对决 → 新平衡                         |

最常用、最稳，也最容易写平。三幕只保证骨架不散，不保证好看。

### 二、Save the Cat 十五节拍

| #  | 节拍   | 位置     | 内容                      |
| -- | ---- | ------ | ----------------------- |
| 1  | 开场画面 | 0-1%   | 定调，与结尾画面呼应              |
| 2  | 主题陈述 | \~5%   | 主题借台词埋下（埋，不是讲）          |
| 3  | 铺设   | 0-10%  | 日常世界、人物缺陷               |
| 4  | 催化剂  | \~10%  | 打破日常的事件                 |
| 5  | 犹豫   | 10-22% | 主角抗拒/挣扎                 |
| 6  | 进入二幕 | \~22%  | 主动选择，跨入新世界              |
| 7  | B故事  | \~27%  | 情感支线引入（常承载主题）           |
| 8  | 游戏时间 | 27-50% | 兑现类型承诺的主战场（爽点/笑点/惊悚密集区） |
| 9  | 中点   | 50%    | 假胜利或假失败，赌注升级            |
| 10 | 反派逼近 | 50-68% | 外部施压+内部裂痕               |
| 11 | 一无所有 | \~68%  | 最低谷，常有"死亡气息"            |
| 12 | 灵魂黑夜 | 68-77% | 内在崩溃与领悟                 |
| 13 | 进入三幕 | \~77%  | 找到关键认知，A线B线合流           |
| 14 | 终局   | 77-99% | 最终对决，分五步打               |
| 15 | 结尾画面 | 100%   | 与开场对照，证明变化发生            |

商业类型片最顺手的脚手架。注意：8「游戏时间」直接对应四轴的类型承诺兑现，这段写弱，类型片必死。

### 三、英雄之旅（十二阶段）

平凡世界 → 冒险召唤 → 拒绝召唤 → 遇见导师 → 跨越第一道门槛 → 考验·伙伴·敌人 → 接近最深的洞穴 → 磨难 → 获得奖赏 → 归途 → 复活（终极考验）→ 带着灵药归来。

适合神话感、成长弧强的故事（奇幻、冒险、合家欢动画）。注意它是环形：出发的世界和归来的世界是同一个，但人变了。

### 四、Story Circle（八步，Dan Harmon）

1 舒适区里的你 → 2 你想要某物 → 3 进入陌生境地 → 4 适应它 → 5 得到所求 → 6 付出沉重代价 → 7 回归熟悉 → 8 你已改变。

英雄之旅的精简版，剧集单集结构利器（每集走一圈）。

### 五、起承转合

| 段 | 任务                      |
| - | ----------------------- |
| 起 | 立人、立境、立常态               |
| 承 | 展开与深化——不要求冲突升级，积累细节与关系  |
| 转 | 翻转——可以是认知/视角的翻转，不必是冲突爆发 |
| 合 | 收束于新的平衡或余韵              |

东方叙事传统，低冲突故事的主脚手架（生活流、散文叙事、《步履不停》一类）。核心差异：西方结构靠冲突推进，起承转合靠"转"的认知落差推进。配四轴使用时：吸引力主走世界与人物通道，情绪走低强度高纯度路线。

### 六、麦基场景法（微观层）

以上都是宏观结构，这条管单场戏：

* **场景 \= 最小价值变化单位。** 每场戏至少一个价值极性翻转（希望→绝望、信任→怀疑、+→-或-→+）。一场戏价值没动，这场戏可删。
* **鸿沟**：人物行动与世界回应之间的落差。期望与结果的落差是故事前进的引擎。
* 节拍表的每一行，本质都该是一次价值翻转。

### 七、序列法（八段）

把长片切成8段，每段12-15分钟，各有局部目标和小三幕。适合控制长片中段（二幕松散是长片头号病，序列法把60分钟的二幕切成4个有目标的单元）。

### 八、微短剧节拍

| 规则    | 标准                     |
| ----- | ---------------------- |
| 5秒钩子  | 第1集前5秒必须抓人（冲突/悬念/奇观直给） |
| 每集反转  | 1-3分钟内至少1个反转或钩子        |
| 付费点   | 5-7集处设最大钩子（上头点）        |
| 结尾连环钩 | 每集结尾开新坑                |

四轴特征：高频浅放电+代入通道在乎+确认型意义。按它自己的契约检验，不按长片标准。

### 九、短片结构

时长越短，越靠单轴打穿：一个问题、一次翻转、一个意象闭环（《鹬》：怕水→入水→水下是奇观）。短片不要贪轴，选一条主轴拉满，其余维持不破。

### 形态 → 锚点对照表

| 定位      | 首选锚点                 | 配合              |
| ------- | -------------------- | --------------- |
| 院线类型片   | Save the Cat         | 麦基场景法           |
| 合家欢动画长片 | STC 或 英雄之旅           | 情绪palette拉宽     |
| 文艺片/生活流 | 起承转合                 | 麦基（价值翻转弱化为认知翻转） |
| 剧集      | 序列法思维+每集Story Circle | 季弧用三幕           |
| 微短剧     | 微短剧节拍                | 代入通道在乎          |
| 短片      | 短片结构                 | 单轴打穿            |
| 游戏叙事    | Story Circle（循环匹配关卡） | 渴望必须由玩家行动承载     |

## references/04-diagnostic-checklist

## 诊断清单 — 自审与剧本医生用

诊断顺序铁律：**定位 → 门槛 → 轴 → 衔接 → 配比核对**。门槛坏了先修门槛，不谈轴。

### 一、门槛清单

**完整**

* 列出全片打开过的所有问题（坑清单），逐条有归宿？（回答/明确不答/转化）
* 主角的渴望线有结局？（达成/失败/放弃，都行，悬空不行）

**自洽**

* 世界规则前后一致？第三幕用到的每个能力/设定，前面有铺垫？
* 每个关键决策符合该人物已建立的性格与动机？（找OOC）
* 巧合只用来制造麻烦，没用来解决麻烦？

**可追随**

* 在三个随机点暂停，能答出：谁、要什么、发生了什么？
* 每次视点/时空切换有锚（观众知道现在在哪、何时）？

### 二、四轴清单

**吸引力**

* 此刻悬着的问题是什么？（任何时刻都该有至少一个未还的坑）
* 五通道（问题/世界/人物/概念/类型承诺）至少两条在工作？
* 开头10%能让目标观众决定看下去？钩子挂在哪条通道？

**在乎**

* 观众能说出"我希望主角\_\_\_"？（说不出\=指向模糊）
* 大事件发生前，在乎攒够了吗？（第一个大情绪点前，至少2条在乎机制已落地）
* 在乎走哪条通道（当别人疼/当自己活）？与定位匹配？

**情绪**

* 情绪曲线画出来有形状？（最高峰在结尾前；中段有起伏）
* palette宽度符合定位？（合家欢要宽，类型片可窄而深）
* 深浅来源配比符合形态？（长片必须有深来源；全靠惊吓/段子/奇观的长片中段必崩）

**意义**

* 用一句话说出这个故事论证了什么？（说不出\=清晰度不够）
* 删掉所有直接陈述主题的台词，主张还立得住？（立不住\=被告知未被体验）
* 确认型还是重组型？与定位匹配？

### 三、衔接四查

* 类型承诺逐条兑现了？（承诺了爽给爽了吗，承诺了哭给哭了吗）
* 每个大情绪点之前，对应的在乎已建立？
* 情绪高点汇入价值主张？（还是放完就散）
* 主张是被事件演出来的？

### 四、配比核对

把实际四轴状态与定位声明的目标配比并排：主轴达标了吗？允许低的轴破门槛了吗（低≠烂，门槛仍要守）？

### 五、常见病症对照表

| 症状（观众端） | 先查       | 常见病因                 | 修法方向                    |
| ------- | -------- | -------------------- | ----------------------- |
| 开头弃坑    | 吸引力、可追随  | 钩子弱/出场人物过多/前10%全是铺设  | 钩子前移；砍出场人物；铺设藏进事件       |
| 中段拖     | 情绪节奏、吸引力 | 坑都还完了没开新坑；事件不动用在乎    | 中点翻转升级赌注；用序列法切段         |
| 尬煽      | 在乎→情绪衔接  | 事件强度超过已攒的在乎          | 前移在乎机制（亏欠/缺口/投入），或降事件强度 |
| 好看但空    | 情绪→意义衔接  | 无价值主张，或情绪没汇入主张       | 补第1步价值主张，把高潮改写成对主张的裁决   |
| 说教感     | 意义       | 主题从台词出               | 删主题台词；让主张由结局事件裁决        |
| 主角立不住   | 人物两清单    | 渴望缺失最常见；两清单全空\=工具人主角 | 先补渴望；再各补2条机制            |
| 反派弱     | 人物魅力     | 只有功能没有魅力             | 从魅力五机制补2条               |
| 不爽（类型片） | 衔接1      | 游戏时间段写弱；承诺的快感被跳过     | 重写承诺兑现段，把爽点做足时长         |
| 结尾崩     | 门槛       | 机械降神/烂尾/OOC          | 回去补铺垫，或换不依赖新设定的解法       |
| 看不懂     | 可追随      | 信息该给不给；切换无锚          | 补信息锚点；降同时在场的线数          |
| 看完就忘    | 意义半衰期    | 全浅来源情绪+确认型意义         | 是否要改取决于定位——微短剧不修，长片要修   |

### 六、升维操作（遇到模型外反例时）

1. 确认效应真实存在（公认好故事在观众身上确实发生了什么）
2. 找到现有体系里哪个二元判断装不下它
3. 把那个二元判断升成轴或刻度（参考先例：抓力门槛→吸引力轴；余味有无→确认↔重组光谱）
4. 新轴/刻度必须通过准入测试：调节它会改变好坏吗？对应观众端可观测效应吗？

不允许的做法：为单个案例打补丁（"除了X类型以外"）。
