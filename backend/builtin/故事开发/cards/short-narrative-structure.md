# 短片与微短剧结构

用户要做短片提示词、竖屏短剧、多镜一致性锁定或 IP 风险处置时读本卡。规则优先于模板；用户明确指定的时长、风格、禁项和参考职责优先于默认值。

## 默认决策

- 未指定时长时按 1-3 分钟设计。
- 五阶段可以压缩，但不能跳过。极短时长内必须至少完成一个可指认的变化。
- 结尾默认留一个可回味的收口，少解释，不用旁白补答案。
- 交付前确认：变化明确、阶段可指认、时长内讲得完、结尾不过度解释。

## 五段式提示词

| 段落 | 必填内容 |
|---|---|
| 核心主题 | 3-6 个标签，用 `|` 分隔；写清类型承诺和情绪方向 |
| 角色与场景 | 主体的脸、发型、服装和关键配件；场景地点与时间 |
| 氛围与质感 | 视觉基底、色板、光线、材质和媒介质感 |
| 镜头规则 | 单镜或多镜、机位、角度、运动、景别和呼吸感 |
| 分镜 | 按镜或按秒切片，每镜只保留一个主要动作和构图目的 |

信息不全时最多问 2-3 个真正影响结果的问题；其余先合理假设并给出一版可迭代草稿。五段结构跨模型通用，模型差异只放末尾一行注，例如 Seedance 对 IP 名更严格、可灵相对宽松、Sora 偏好简洁。写完后最多解释 2-3 个最可能被调整的写作选择。

分镜粒度：时长不超过 10 秒时按镜切；超过 10 秒时按秒切，避免一个镜头承担过多叙事动作。

## 竖屏短剧三件套

1. **黄金 3 秒钩子**：开场直接给冲突、悬念或反常识状态，不铺垫。钩子必须同时可见或可听。
2. **正反打对话**：对话戏默认用 shot-reverse-shot；每镜一个方向和一个主体，守住 180° 轴线，反应镜头只给当前说话者的对面角色。
3. **集尾断章**：停在反转前一刻、悬念、狠话或关键细节上，明确下一集要解决的问题。

9:16 竖屏构图把主体放在中线附近偏上位置；重要信息、脸和字幕避开顶部约 12% 与底部约 18% 的平台 UI 安全区。

## 多镜两把锁

任何 3 镜以上的叙事、广告或短剧，写第一镜前先完成两把锁。

### 主体登记表

每个出场主体登记至少 5 项跨镜不变特征，例如脸型、发型发色、服装单品、标志配件、体型或材质。参考图、身份块和每镜主体描述都从登记表抄写，不临场改写。

### 氛围锁定

写明全片色板与色温、主光性质与对比度、媒介与质感。每镜的氛围词只能从锁定区取；摄影机运动、人物动作和构图可以在镜头内变化。

交付前逐镜扫描锁外主体特征和锁外氛围词。发现漂移时回到登记表或氛围锁定区修正，不在单镜里临时补设定。

## 类型模板分支

类型模板提供该类型的深骨架和专用措辞，不覆盖本卡规则。优先从下列 21 类中选最强匹配：

- 单镜变形、多镜剪辑叙事、情感叙事、产品广告、食物 ASMR、动物 Vlog、电影预告、赛博城市氛围。
- 黏土动画、自然延时、CCTV 伪纪录恐怖、动画改真人、MV 表演、运动慢动作、时尚片、旅拍 Vlog。
- 无人机 FPV、竖屏短剧、科幻太空、汽车广告、宠物一生式跨时段叙事。

多个类型同样合理时，先给用户 2-3 个候选及差异，再选分支。黏土动画和伪纪录等类型可以刻意打破常规呼吸感；这是类型语言，不是失误。3 镜以上仍必须走两把锁。

## IP 安全处置

1. 扫描 IP、品牌、明星、电影和游戏专名，形成专名清单。
2. 为每个专名写功能等价的自创触发短语，保留它在原提示词中的戏剧作用，不裸写专名。
3. 参考桥段时只保留节拍、机位和节奏，去掉专名、标志性台词和可识别符号。
4. 多平台分发时按平台容忍度分别改写，不把可灵、Seedance、Sora 的规则混用。
5. 生成失败且疑似审核时，先查专名和敏感词，再查其他参数。

## 执行顺序

先判断输入是否齐全并定下时长与类型，再选模板分支。多镜任务先完成主体登记和氛围锁定，随后按五段式组装提示词并切片。竖屏短剧额外检查钩子、轴线和断章，最后做 IP 扫描、时长压缩和结尾收口。
