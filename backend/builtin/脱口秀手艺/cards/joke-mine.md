## I — Interpretation

The Joke Mine is the second half of the Joke Prospector. Given a setup, it systematically **mines punches** instead of waiting for inspiration:

1. **List assumptions** the setup implies.
2. **Pick a target assumption** (the most breakable) → locate its **connection point** (the setup element that made you assume it).
3. **List reinterpretations** of that connection point (other ways to read it).
4. **Pick a reinterpretation** that builds a coherent **2nd story** (surprising yet logical).
5. **Write the punch** that reveals the 2nd story.

The "secret passage" is that a single setup has *many* assumption→reinterpretation channels. One setup can yield dozens of punches. This is why joke-writing is engineering, not luck.

## S — Stance & Motif ★

- **一句话立场**: The laugh is excavated by process, not inspiration.
- **核心主张**: 1) A setup hides many breakable assumptions; 2) the connection point is the joke's "trigger."
- **典型敌人**: "I'm not inspired" / "I only have one punch for this."

## A1 — Past Application

### Case: The 5K run
- **Problem**: Setup "I run 5 kilometers every morning." List assumptions → health, discipline, vanity…
- **Methodology**: Target assumption "for health"; connection point "every morning"; reinterpretation "to avoid my wife." 2nd story = running away from her. Punch reveals it.
- **Result**: One setup → multiple punch channels demonstrated.

### Case: Ch4 tags
- **Problem**: A joke landed; milk it for more.
- **Methodology**: Apply Mine to the original assumption list again for consecutive punches (tags).

## E — Execution

1. **Write a setup; list every assumption it implies.**
   - Done: ≥3 assumptions listed.
2. **Pick the most breakable target assumption; name its connection point.**
   - Done: connection point (the setup phrase) identified.
3. **List reinterpretations of that connection point.**
   - Done: ≥3 alternate readings, each logical yet surprising.
4. **Pick one that forms a 2nd story; write the punch.**
   - Done: punch reveals 2nd story and breaks the target assumption.
5. **To mass-produce**: re-run steps 2–4 with a different target assumption or reinterpretation.
   - Stop when: enough punches; else iterate.

## B — Boundary (三层约束) ★

### 🔴 硬约束
- A reinterpretation **unrelated to the setup** (2nd story makes no sense) is not a joke. The connection point MUST be in the setup.

### 🟡 软约束
- Picking an obscure/trivial connection point yields a weak punch. Cost = audience can't follow the logic.

### 🟢 自设约束
- "One setup = one joke." False; the Mine's whole point is many channels per setup.

### Failure modes
- Reinterpretation not grounded in the connection point; stopping after one channel.

### Nearby
- `joke-structure`, `joke-map`, `polish-joke`.
