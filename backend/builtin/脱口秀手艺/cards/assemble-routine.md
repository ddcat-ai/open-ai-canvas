## I — Interpretation

A routine is jokes arranged with intent:

1. **Index cards**: one joke per card (physically separable).
2. **Categorize** by subject/themes.
3. **Order** by a story line (a sequence that feels like it goes somewhere).
4. **Introduce & transition**: three ways to lead into a joke—(a) statement, (b) state the *joke premise* (honest), (c) state the *setup premise* (mislead, often strongest).
5. **Read aloud, rewrite**: rhythm only shows when spoken.

The key insight: bits gain power from *sequence and misdirection*, not just individually. The misleading introduction (setup premise) primes the audience's 1st story before the punch shatters it.

## S — Stance & Motif ★

- **一句话立场**: A set is architecture, not a dump of bits.
- **核心主张**: 1) Group, then order by through-line; 2) the misleading intro is a setup.
- **典型敌人**: "Just do your best bits in any order."
- **最适合议题**: Building a 5–15 min set; fixing a disjointed show.
- **母题风洞**: Motif "Assumption → Shatter"; the intro plants the assumption the bit breaks. (非 N/S 层)

## A1 — Past Application

### Case: The post-office set
- **Problem**: Loose post-office bits with no flow.
- **Methodology**: Cards grouped (waiting line, clerk, forms); ordered by story line; misleading intro stating the setup premise; read aloud, trimmed. Became a tight routine.
- **Result**: Same jokes, coherent set.

## E — Execution

1. **One joke per index card.**
   - Done: each bit isolated.
2. **Group by subject.**
   - Done: clusters formed.
3. **Order each cluster by a story line.**
   - Done: a sequence with direction.
4. **Write an intro per joke**; prefer the misleading setup-premise intro.**
   - Done: each bit primed.
5. **Read aloud; cut/reorder until it flows.**
   - Done: spoken rhythm confirmed.

## B — Boundary (三层约束) ★

### 🔴 硬约束
- No through-line (pure random order) = the audience can't track you; the set collapses. Order must mean something.

### 🟡 软约束
- Over-explaining transitions eats time. Cost: fewer laughs per minute.

### 🟢 自设约束
- "Always open with your strongest." Sometimes a misleading soft opener sets up a bigger later hit.

### Failure modes
- Piling quantity without categorization; using questions as transitions (gives away the setup).

### Nearby
- `joke-map`, `peak-performance`, `polish-joke`.
