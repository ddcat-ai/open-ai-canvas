## 〇、宪章

### 0.1 顶层定义与测量

**世界设定要做的事：为一个故事，建造一个本身就成立的世界。**

这句话有两个目标：世界作为客体要自身成立（可信、独特），世界作为叙事载体要为故事服务（表意、情绪基调）。世界是系统不是单一主体，所以没有像角色"彻底是自己"那样的单一根。

测量原则沿用套件惯例：好坏以观众端可观测效应定义。世界的好体现为四种观众反应——相信它（可信）、记住它（独特）、读懂它在说什么（表意）、被它的氛围感染（情绪基调）。

### 0.2 双目标结构（四轴分两组，可信是地基）

| 组               | 轴       | 性质  |
| --------------- | ------- | --- |
| 世界自身属性（脱离故事也成立） | 可信、独特   | 描述性 |
| 世界叙事功能（依附具体故事）  | 表意、情绪基调 | 目的性 |

**可信是地基**：内部一致性一旦崩塌，会同时摧毁其余三轴——自相矛盾的世界，独特沦为随意、表意沦为说教、情绪无法稳定。四轴不平权，可信在最底层。

### 0.3 依赖铁律

* 本skill不知道任何项目的存在。项目信息（故事、主题、定位、画风）一律从输入进来。
* 不假设上下游skill存在。有套件时：接 story-developer 的世界规则+主题，产出 world bible 给分镜/资产生图，场景图交 visual-director 注质感。无套件时独立可用（裸设定进，world bible 出）。
* 按需取用：用户只要一个场景就做单场景；要全片世界就出 world bible。

### 0.4 生图落地三原则（出场景图必守，详见 references/03）

1. 双语隔离：坐标/轴/概念只在脑内，最终 prompt 只写具象词（空间/光影/材质/建筑样式/画家名/镜头）。
2. 设计→画面翻译：世界设定概念不进 prompt，只进它的视觉证据（「衰败」→「锈蚀的金属、爬满裂缝的墙、积水的街」）。
3. 画面构建先于质感：出 prompt 先定视角/光/焦点/空间纵深/氛围。

### 0.5 输出纪律

结论先行，平实。每个设定决定可追溯——能回答"它服务哪条轴"。世界靠环境展示，不靠解说交代（show don't tell）。

## 一、四轴（速查，详见 references/01）

| 轴        | 观众效应     | 来源                            | 刻度/检验                 |
| -------- | -------- | ----------------------------- | --------------------- |
| **可信**   | 相信、能住进去  | 一致性 + 完整性                     | Watsonian自检；冰山（构建>展示） |
| **独特**   | 认得出、记得住  | invention（对现实默认设定的替换）         | 四级：命名→表层→系统→本体        |
| **表意**   | 读懂世界在说什么 | 主题做成可见的物证                     | 删掉解说，主张是否还立得住         |
| **情绪基调** | 被氛围感染    | spatial expression（形/尺度/光/密度） | 世界的情绪底色，先感到后理解        |

四轴关系：可信是地基；独特在可信之上做加法；表意、情绪由故事需求驱动、贯穿到每个细节。

## 二、三层设计结构（速查，详见 references/02）

| 层       | 内容                                    | 定什么     |
| ------- | ------------------------------------- | ------- |
| **内核层** | 核心法则、主题立场、情绪基调定位                      | 这是个什么世界 |
| **系统层** | 地理/自然/历史/族谱势力/社会/经济/技术或魔法/文化/语言/神话/哲学 | 世界怎么运转  |
| **视觉层** | 建筑/服装/器物/色彩/地标/视觉母题                   | 世界长什么样  |

轴×层连接（操作核心）：可信←系统层自洽完整+视觉层生活痕迹；独特←内核层invention深度+视觉层识别度；表意←内核层主题贯穿视觉层母题；情绪基调←内核层定位+视觉层spatial expression。 核心机制是叙事地层：把历史、文化、情绪层层叠进物理空间。高级标准是一元供给多轴——一个元素同时服务多条轴（一道磨损的石阶＝生活痕迹+衰败主题+沧桑情绪）。

## 三、生成工序（六步）

### 第0步 输入

故事输入：world 的叙事规则（story-developer 定的世界运作规则）、主题/价值主张；或裸设定想法 定位：形态/受众/类型/对标 画风状态：已定（引用影像宪法）/未定

### 第1步 内核定盘

核心法则：这个世界最根本的规则（invention 最高级发生在这里） invention 深度：定到哪一级（命名/表层/系统/本体），匹配故事，非越高越好 主题立场：世界要论证什么（来自故事主题，翻译成世界层） 情绪基调定位：世界给人什么底色感受

### 第2步 系统层展开

按基础设施清单（references/02）展开，**按需取用不是全填**——匹配故事尺度。一个发生在单城的故事不需要全球地理。冰山：构建多于展示，但构建量也匹配尺度。重点查基础设施之间的勾连（经济影响阶层、地理影响文化）。

### 第3步 视觉层设计

建筑/服装/器物/色彩/地标/视觉母题。每个视觉决定回答"它服务哪条轴"。视觉母题反复出现，承载表意。

### 第4步 轴×层检查

四轴是否都被供给（对照 references/01）；有没有元素能一元供给多轴；可信的两支（一致+完整）是否到位。

### 第5步 场景设定图 prompt

按 references/03 出图。场景图分工程图（布局/结构，信息优先）和表现图（氛围/概念，质感优先）。守生图落地三原则。

### 第6步 输出 world bible

world bible（世界宪法，下游共用）： - 内核档案（核心法则/invention深度/主题立场/情绪基调定位） - 系统档案（已展开的基础设施 + 勾连关系） - 视觉设定（建筑/服装/器物/色彩/地标/母题 + 锁定项） - 场景设定图 / prompt - 情绪基调说明（给 color script 与 visual-director）

## 四、诊断模式（用户拿现成世界设定来）

1. **先问定位**：这个世界服务什么故事、什么形态。没有定位不评。
2. **四轴检测**：哪轴弱——不可信/不独特/没表意/没氛围。先查可信（地基，崩了其余白搭）。
3. **反查三层**：弱轴对应的层有没有料（可信弱→系统层不自洽或不完整；独特弱→invention太浅或视觉无识别度；表意弱→主题没贯穿到视觉；情绪弱→spatial expression 没设计）。
4. **输出**：问题按影响排序，每个给三件套——哪轴弱、对应哪层缺、怎么补。

常见病症对照表见 references/04。

## 五、场景设定图（速查，详见 references/03）

* 场景图画环境（区别于角色白底图）。两级：工程图（空间布局/结构/平面，均匀信息）vs 表现图（氛围/概念，戏剧光与质感）。
* 守生图落地三原则：设定概念翻成画面证据；先构建画面（视角/光/焦点/纵深/氛围）再注质感。
* 画风槽位 {STYLE} 留空，项目侧或 visual-director 填。
* 叙事地层落地：场景里放能讲故事的细节（生活痕迹、历史痕迹、势力标记），不堆无意义的装饰。

## 六、接口（详见 references/04）

| 方向                    | 内容                                     |
| --------------------- | -------------------------------------- |
| 上游 story-developer    | 世界叙事规则→系统层；主题→表意轴；定位声明→invention/完整性取舍 |
| 下游 character-designer | 服装/器物/阶层逻辑                             |
| 下游 color script       | 情绪基调定位                                 |
| 下游 分镜/资产生图            | world bible + 场景设定图                    |
| 横向 visual-director    | 场景图 prompt 注质感/审图；情绪来源→画面实现            |

三组关键边界（必须分清）：

* 表意 vs 故事主题：故事定主题，世界承载主题。
* 情绪基调 vs color script：世界定情绪底色（空间常量），color script 定逐场曲线（时间变量）。
* 情绪基调 vs visual-director：世界定情绪来源，visual-director 定画面实现。

## 七、反模式（永远不做）

1. 没有定位就开始搭世界
2. 把基础设施全填满——不匹配故事尺度的堆砌
3. invention 越深越好——不顾一致性和完整性的牵制
4. 用解说交代世界（违反 show don't tell）
5. 视觉元素只为好看，不服务任何轴（装饰性堆砌）
6. 一致性破绽用"剧情需要"搪塞（违反 Watsonian）
7. 情绪基调和 color script 抢活——本skill定底色不定逐场曲线
8. 场景图当角色图做白底——场景要画环境
9. 最终 prompt 混进坐标/轴/概念等内部语言

# references/01-four-axes

# 四轴详解 — 双目标结构、轴×层连接、叙事地层

## 一、双目标结构

世界设定的顶层定义：为一个故事，建造一个本身就成立的世界。两个目标产生两组轴。

| 组      | 轴       | 回答的问题              | 对应专业框架                            |
| ------ | ------- | ------------------ | --------------------------------- |
| 世界自身属性 | 可信、独特   | 这是不是一个好世界（脱离故事也成立） | Mark J.P. Wolf 的 subcreation 学术框架 |
| 世界叙事功能 | 表意、情绪基调 | 这个世界对这个故事好不好（依附故事） | 影视/游戏的环境叙事                        |

世界同时服务两个主人：世界本身的完整自洽，和故事的需要。这是它没有单一根、必须多轴的原因（角色是单一主体，故有单一根）。

可信是地基。一致性崩塌会连锁摧毁其余三轴：自相矛盾→独特沦为随意、表意沦为说教、情绪无法稳定。

## 二、轴一 可信

观众相信世界是真的、能住进去。两个来源（Wolf 把它们分开处理，世界设计要分别检查）：

### 一致性 consistency

细节合理、无内部矛盾，每个东西能用世界自身逻辑解释。

* **Watsonian 自检**：问"在这个世界内部，为什么会这样"。答得出（世界内部逻辑）\= 成立；答"因为剧情需要 / 因为这样好看"\= 破绽。
* 一致性是可信的硬地基，优先级最高。

### 完整性 completeness

细节密度够、覆盖实际生活、缺口少。

* 检查清单：这个世界的人怎么吃穿住？经济怎么运转？谁管事（治理）？普通人怎么打发日子？
* Wolf：世界几乎必然不完整，但当它包含看似不必要的细节、处理实际生活问题时，显得更完整可信。
* 实现方法是冰山：构建的远多于展示的。展示部分之所以可信，因为背后有未展示的体系支撑。但构建量匹配故事尺度，不是无限堆。

## 三、轴二 独特

观众认得出、记得住，世界区别于通用类型（通用奇幻、通用赛博朋克、通用废土）。

独特的实质是 invention——对现实默认设定做了多少有意义的替换（Wolf）。不是表面长得不一样，是对世界默认规则的替换深度。

**invention 四级**（由浅到深）：

| 级   | 改什么            | 例                 |
| --- | -------------- | ----------------- |
| 命名级 | 只换名字，本质不变      | 警察叫"治安官"、货币改个名    |
| 表层级 | 外观、风俗、制度       | 独特的服饰、礼仪、政体形式     |
| 系统级 | 社会运行逻辑、技术或自然体系 | 一套自洽的魔法经济、生态系统    |
| 本体级 | 物理法则本身         | 魔法改写因果、重力可变、时间非线性 |

等级越高越独特，但越难维持一致性和完整性——三者互相牵制（改了物理法则，整个系统都要重新自洽）。

**纪律**：定这个世界 invent 到哪一级，匹配故事需要，不是越高越好。很多优秀的现实题材世界停在表层级（靠完整性和情绪基调取胜，不靠 invention）。

## 四、轴三 表意

世界本身在表达主题，不是中立容器。世界的构成可以是故事观点的物证。

* 例：瓦力的地球被垃圾掩埋，这个设定本身就是消费主义后果的论证，不需要台词；机器人总动员的真理号无菌全白，是人类退化的物证。
* 实现靠环境，不靠解说。世界把主题做成可见的物，观众从物里读出观点。
* **检验**：删掉所有解说性台词，世界本身还能不能传达主题。传达不了 \= 表意没做进世界，只是被讲出来。
* 上游是 story-developer 定的主题（价值主张）。世界设计不发明主题，把主题翻译成世界的物证。

## 五、轴四 情绪基调

世界散发的弥漫情绪，独立于主题。一个世界可以表意弱但氛围强（海街日记的镰仓），也可以表意强但氛围中性（很多概念先行的科幻）——两者独立变化，所以是两条轴。

* 通过 spatial expression 起作用：形状、尺度、光线、密度先让人感到某种情绪，之后才被理性理解。拥挤+潮湿+昏暗→压抑；开阔+明亮+疏朗→自由。
* 它是世界的情绪底色，相对全片恒定。
* 落地在视觉层，下游和 color script、visual-director 协作（见 references/04 边界）。

## 六、轴 × 层连接（四轴从哪里生出来）

每个轴不是凭空评判，由特定层的特定元素供给：

| 轴    | 主要来源层                  | 辅助来源层                   |
| ---- | ---------------------- | ----------------------- |
| 可信   | 系统层（基础设施自洽完整）          | 视觉层（生活痕迹、磨损、使用感）        |
| 独特   | 内核层（核心法则 invention 深度） | 视觉层（造型识别度）              |
| 表意   | 内核层（主题立场）              | 视觉层（母题反复出现）             |
| 情绪基调 | 内核层（情绪定位）              | 视觉层（spatial expression） |

诊断时反向用：哪条轴弱，去查它的来源层缺了什么。

## 七、叙事地层（连接机制）

narrative stratigraphy：把历史、文化、情绪一层层叠进物理空间。这是连接四轴和视觉层的核心机制。

一个具体的物可以同时供给多条轴。一道磨损的石阶：

* 生活痕迹 → 可信
* 衰败主题的物证 → 表意
* 沧桑情绪 → 情绪基调

**高级标准**：世界设计追求每个视觉元素同时供给多条轴，而不是一个元素只干一件事。一面墙上的弹孔、褪色的旧标语、新贴的告示，三层信息叠在同一面墙上，同时讲了历史、政治、当下。

## 八、六世界验证记录（四轴完备性测试存档）

| 世界       | 可信       | 独特 | 表意 | 情绪基调  |
| -------- | -------- | -- | -- | ----- |
| 银翼杀手 洛杉矶 | 高        | 极高 | 高  | 潮湿忧郁  |
| 千与千寻 汤屋  | 高        | 高  | 高  | 暧昧的丰饶 |
| 纪念碑谷     | 低（物理不可信） | 极高 | 中  | 静谧    |
| 指环王 中土   | 极高       | 高  | 高  | 史诗苍茫  |
| 海街日记 镰仓  | 高        | 中  | 中  | 温润怀旧  |
| 寂静岭      | 高（心理逻辑）  | 高  | 高  | 压抑恐惧  |

结论：四轴覆盖所有样本；纪念碑谷证明可信是轴不是门槛（它可信低但其余高，仍是好世界）；海街日记证明情绪基调是独立轴（它靠氛围动人，独特和表意都不突出）。

# references/02-three-layers

# 三层设计结构 — 内核 / 系统 / 视觉

世界从抽象到具体分三层，和角色设计同构。设计自上而下（内核定基调→系统展开→视觉落地），诊断自下而上（视觉有问题反查系统、内核）。

## 一、内核层（这是个什么世界）

定三件事：

* **核心法则**：这个世界最根本的规则。invention 的最高级发生在这里（本体级\=改物理法则）。例：盗梦空间的"梦中梦时间膨胀"、寂静岭的"心理外化为实体空间"。
* **主题立场**：世界要论证什么。来自 story-developer 的主题，翻译成世界层（不是世界自己发明主题）。
* **情绪基调定位**：世界给人的底色感受，一两个词锁定（潮湿忧郁 / 温润怀旧 / 史诗苍茫 / 压抑恐惧）。

内核层是 world bible 的第一页，后面所有设计都对它负责。

## 二、系统层（世界怎么运转）

按基础设施清单展开（Mark J.P. Wolf 的 infrastructures）：

| 基础设施    | 内容                 |
| ------- | ------------------ |
| 地理      | 地形、气候、空间格局         |
| 自然      | 生态、物种、资源           |
| 历史时间线   | 关键事件、纪元、现状是哪些过去的结果 |
| 族谱与势力   | 权力结构、派系、家族、阵营      |
| 社会结构    | 阶层、身份、流动性          |
| 经济      | 生产、贸易、货币、谁富谁穷      |
| 技术或魔法体系 | 能做什么不能做什么、代价、规则    |
| 文化      | 习俗、信仰、节庆、禁忌        |
| 语言      | 命名逻辑、文字、方言         |
| 神话      | 起源故事、传说、集体记忆       |
| 哲学      | 这个世界的人怎么看待生死、价值、意义 |

**两条纪律**：

1. **按需取用，不是全填**。匹配故事尺度——单城故事不需要全球地理；战争故事重点在势力和历史，日常故事重点在文化和经济。不相关的基础设施可以浅，但相关的必须深。
2. **查勾连**。世界的深度不在单项填得多满，在基础设施之间的相互影响：地理决定经济（沿海则贸易），经济决定阶层，历史决定现在的势力格局。勾连密 \= 世界活；各项孤立 \= 设定集，不是世界。

语言、神话、哲学最容易被跳过，但它们是深度的真正来源。托尔金的中土是先有精灵语、再有世界。这三项哪怕只做一点，世界的"年代感"和"自成体系感"立刻不同。

## 三、视觉层（世界长什么样）

把内核和系统翻译成可见的东西：

* **建筑**：样式、材料、尺度——反映技术、阶层、气候、信仰
* **服装**：反映阶层、职业、气候、文化（这一项输出给 character-designer）
* **器物**：日常用具、工具、武器——反映技术和生活方式
* **色彩**：世界的整体色彩倾向（这一项和 color script 协作，本skill定底色）
* **地标**：标志性建筑或自然景观——独特轴的主要载体，世界的记忆点
* **视觉母题**：反复出现的形状、符号、图案——表意轴的载体（母题携带主题）

视觉层每个决定都要回答"它服务哪条轴"。靠叙事地层（references/01 第七节）让单个视觉元素同时供给多条轴。

## 四、invention 四级（独特轴的设计刻度，详见 references/01）

定这个世界的 invention 深度，主要落在内核层的核心法则：

* 命名级：只改名
* 表层级：改外观、风俗、制度（落在视觉层和系统层的文化项）
* 系统级：改社会逻辑、技术或自然体系（落在系统层）
* 本体级：改物理法则（落在内核层核心法则）

越深越独特，越难维持一致性和完整性。匹配故事，不是越深越好。

## 五、工作纪律

* **冰山**：构建的多于展示的，但构建量匹配故事尺度。完整性的来源，不是无限堆设定。
* **show don't tell**：世界通过环境、器物、痕迹展示，不靠旁白或台词解说。
* **Watsonian 自检**：每个设定问"世界内部为什么会这样"，答"剧情需要"就是破绽。
* **一元供给多轴**：好的设定元素同时服务多条轴（见叙事地层）。
* **匹配而非堆砌**：invention 深度、完整性密度都匹配故事需要，三个世界自身属性（invention/完整/一致）互相牵制，不能都拉满。

# references/03-scene-prompts

# 场景设定图 prompt

## 〇、总纪律

1. **场景图画环境**，区别于角色设定图的白底。场景就是世界的一块，要画出空间、光、氛围。
2. **两级用途**：
   * 工程图（空间布局图 / 平面图 / 结构图）：信息优先，均匀光、视角清楚、比例可读，给分镜和制作定位用。
   * 表现图（概念氛围图 / 气氛稿 / key location）：质感优先，戏剧光、空气感、情绪，交 visual-director 注质感。  两种 prompt 纪律不混用。
3. **画风槽位 {STYLE} 留空**，项目侧或 visual-director 填。本skill不定画风。
4. **守生图落地三原则**（下面第二节展开）。

## 一、场景图类型

| 图      | 用途              | 纪律           |
| ------ | --------------- | ------------ |
| 全景气氛图  | 定一个场景的整体氛围和空间感  | 表现图，情绪基调优先   |
| 空间布局图  | 场景的平面/结构/动线     | 工程图，信息优先     |
| 地标设计图  | 标志性建筑或景观（独特轴载体） | 可表现可工程，看用途   |
| 细节设定图  | 建筑构件/器物/材质      | 工程图，清楚可参考    |
| 同场景多时段 | 同一场景不同光线/天气/时间  | 一致性基准，结构固定光变 |

## 二、生图落地三原则在场景图的落地

### 原则1 双语隔离

最终 prompt 只写具象词：空间结构、建筑样式、材质、光影现象、镜头视角、画家/流派名。坐标、轴名、"表意""情绪基调"这类内部词不进 prompt。

### 原则2 设计→画面翻译

世界设定概念翻译成场景里看得见的东西：

| 设定概念（不进prompt） | 画面证据（进prompt）                |
| -------------- | ---------------------------- |
| 衰败             | 锈蚀金属、墙面裂缝渗水、杂草从地砖缝里长出、褪色的旧招牌 |
| 阶层森严           | 高墙、岗哨、上城与下城的垂直分隔、材质的贵贱对比     |
| 高科技低生活         | 霓虹广告覆盖破败街区、先进设备旁的脏乱、电线如蛛网    |
| 历史厚重           | 不同年代的建筑层叠、磨损的石阶、墙上几代人的痕迹     |
| 信仰中心           | 全城朝向的地标、反复出现的宗教符号、街角神龛       |

### 原则3 画面构建先于质感

出 prompt 前先定五件事（和 visual-director 9.2 阶段一一致）：

* 视角：俯瞰/平视/仰视，远景/中景，定观众怎么看这个空间
* 光：光从哪来、什么时间、明暗分布
* 焦点：画面第一眼落在哪（地标？人物？光源？）
* 空间纵深：前中后景如何分层，纵深感怎么建立
* 氛围：天气、空气介质（雾/尘/雨）、氛围元素

## 三、prompt 槽位结构

\[空间类型与尺度]：什么场景 + 大小（例：拥挤的下城市集街道，狭窄逼仄） \[建筑与构成]：建筑样式/材料/排布 \[叙事地层细节]：生活痕迹+历史痕迹+势力标记（让场景讲故事，不堆装饰） \[视角与镜头]：俯/平/仰 + 景别 + 焦段 \[光与时间]：光源方向/时段/明暗 \[空间纵深]：前中后景分层 \[氛围]：天气/空气介质/氛围元素 {STYLE}：留空 \[负面]：抗趋同与抗糖水（按需）

## 四、范例（烂 vs 好）

场景：一个高科技低生活的下城市集（设定\=阶层森严、高科技低生活、衰败）。

**烂 prompt**： 一个赛博朋克城市街道，霓虹灯，下雨，很多人，科技感 病：通用赛博朋克，设定没翻译成画面，没有视角和焦点，出来是套路图。

**好 prompt**： 狭窄拥挤的下城市集街道，两侧是锈蚀的金属棚屋和加建的违章楼层，头顶交错的电线和滴水的管道几乎遮住天空；巨大的全息广告从上城的高墙投下冷光，照亮下面脏乱的摊位和积水的地面（高墙把上城和下城垂直分隔）；低机位平视，沿街道纵深望向远处被雾笼罩的上城塔楼，焦点在街道尽头的光；黄昏向夜过渡，霓虹的冷光与摊位暖灯对比；前景湿漉漉的摊位、中景人群剪影、远景雾中塔楼三层纵深；空气里有蒸汽和细雨。{STYLE}。负面：干净整洁、均匀照明、空旷无人。

拆解：

* 阶层森严 → 高墙垂直分隔上城下城
* 高科技低生活 → 全息广告的冷光 vs 脏乱摊位
* 衰败 → 锈蚀金属、违章加建、滴水管道、积水
* 画面构建：视角（低机位平视纵深）/光（黄昏转夜，冷暖对比）/焦点（街道尽头的光）/纵深（前中后三层）/氛围（蒸汽细雨）
* 无一句内部黑话

# references/04-review-checklist

# 自审与诊断 + 接口边界

## 一、自审清单（出 world bible / 场景图前）

### 门槛级（不过直接打回）

* 有没有定位？（服务什么故事、什么形态——没有不评不做）
* 一致性：每个设定能用世界内部逻辑解释，没有"剧情需要"式破绽（Watsonian 自检过一遍）

### 四轴

* 可信：系统层自洽吗、完整吗（吃穿住经济治理覆盖了吗）、基础设施之间有勾连吗、视觉层有生活痕迹吗
* 独特：invention 到了该到的深度吗、地标和造型有识别度吗、还是落进了通用类型（通用奇幻/赛博/废土）
* 表意：主题贯穿到视觉母题了吗、删掉解说还能传达吗
* 情绪基调：定位明确吗、spatial expression（形/尺度/光/密度）落地了吗

### 轴×层与机制

* 弱轴反查来源层补过了吗
* 有没有一元供给多轴的元素（叙事地层用了吗），还是元素都只干一件事
* 系统层按需取用了吗，还是不分主次全填/全空

### 生图

* 场景图画环境（不是白底）、工程图与表现图纪律没混
* 设定概念翻译成画面证据了吗、prompt 有没有混进内部黑话
* 出 prompt 前定了视角/光/焦点/纵深/氛围五件事

## 二、常见病症对照表（诊断模式用）

| 症状         | 先查           | 病因                         | 修法                           |
| ---------- | ------------ | -------------------------- | ---------------------------- |
| 不可信、出戏     | 一致性          | 有"剧情需要"式破绽、规则自相矛盾          | Watsonian 逐条过，补世界内部解释或改设定    |
| 空、单薄、像景片   | 完整性          | 只做了展示的部分，背后没体系；基础设施孤立无勾连   | 补冰山（吃穿住经济治理）、补勾连             |
| 套路、似曾相识    | 独特/invention | invention 太浅（停在命名级）、落进通用类型 | 提 invention 深度，或在视觉层做独特地标和造型 |
| 好看但没意思     | 表意           | 世界是中立容器，没承载主题              | 把主题翻译成视觉母题，让构成成为物证           |
| 没气氛、平      | 情绪基调         | 没定位、spatial expression 没设计 | 定情绪底色，用形/尺度/光/密度落地           |
| 设定集而非世界    | 勾连           | 各项填得满但互相孤立                 | 建立基础设施之间的因果（地理→经济→阶层）        |
| 设定过载、喧宾夺主  | 匹配           | 不分主次全做深，淹没故事               | 按故事尺度砍，相关的深、无关的浅             |
| 场景图像通用概念图  | 叙事地层         | 场景只有氛围没有故事细节               | 加生活/历史/势力痕迹，让场景讲世界的故事        |
| 世界很全但和故事无关 | 双目标          | 只做了世界自身属性，没做叙事功能           | 回到主题和情绪基调，让世界为这个故事服务         |

world bible 是本skill的核心交付物，地位等同 visual-director 的影像宪法、color script 的色彩总谱，下游共用，防止设定漂移。
