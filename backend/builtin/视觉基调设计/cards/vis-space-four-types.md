## I — 方法论骨架 (Interpretation)

布洛克把"银幕空间"从默认背景变成**可主动选型的四种谱系**，按"深度线索（让人觉得有纵深的视觉信号）有多少"来分：

- **纵深空间（deep space）**：保留透视、近大远小、会聚线，屏上有明显前后纵深。情绪上制造"距离感/心理疏离"——子女在画面远处，就显代际隔阂。
- **平面空间（flat space）**：清除透视，元素压在同一个平面（像合影、年画）。情绪上显"平等/亲密/秩序"，适合温馨群像。
- **有限空间（limited space）**：正平面堆叠但元素之间有区分（框中框、门窗分割）。情绪上显"羁绊/包围/家庭感"——客厅、院子最常用。
- **模糊空间（ambiguous space）**：大小、前后关系不可辨，观众搞不清谁在前谁在后。情绪上制造"误会/悬疑/错位"，适合反套路误认桥段。

关键：**空间不是拍到什么就是什么，而是你选的**。深度线索（透视、影调分离、色彩分离）是全部旋钮（g11）；影调/色彩分离既能造纵深也能让主体从背景跳出（g40）。

落到：宅院用有限空间显家庭羁绊（客厅框中框），社区/居委会用平面空间做温馨群像合影，模糊空间做误认某物的悬疑式反套路，纵深空间做代际心理疏离（子女在屏上方远处）。缺横向纵深，可用影调/色彩分离低成本造"前亮后暗"的纵深错觉。

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者用四选型定义空间谱系本身
- **问题**: 学生把"空间"当不可控的背景，不知可设计。
- **方法论的使用**: 按深度线索多少分出纵深/平面/有限/模糊四类，并指明空间是选型而非默认。
- **结论**: 每场戏的空间类型应服务情绪，而非随手拍到什么算什么。
- **结果**: 成为第三章核心框架，指导后续深度线索与影调/色彩分离的运用。

### 案例 2: 深度线索作为情绪距离旋钮（g11 论证）
- **问题**: 如何在二维屏上表达"心理距离"？
- **方法论的使用**: 加深度线索（透视/近大远小/影调色彩分离）显疏离；清除它们显亲密。
- **结论**: 深度线索量 = 情绪距离量，是可调的。
- **结果**: 支撑"子女远在屏上方=代际疏离"的用法。

### 案例 3: 影调/色彩分离兼作深度与焦点（g40 论证）
- **问题**: 低成本如何让主体跳出又显纵深？
- **方法论的使用**: 暖亮主体 + 冷暗背景，既分离出焦点又造纵深错觉。
- **结论**: 一处操作同时解决"看哪"和"有多深"两个问题。
- **结果**: 成为低成本双效技巧。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 定宅院/社区/超市等场景的空间基调（亲密/疏离/悬疑）。
2. 想用空间表达家庭羁绊或代际心理距离。
3. 设计反套路误认/悬疑桥段，需要"看不清谁前谁后"的模糊空间。
4. 想靠影调/色彩分离低成本造纵深与焦点。

### 语言信号 (用户的话里出现这些就应激活)

- "这集宅院/客厅用哪种空间显家庭感"
- "怎么用空间表现代际疏离/子女离得远"
- "误认那段想要模糊空间制造误会"
- "纵深/平面/有限/模糊空间怎么选，深度线索怎么用"
- "four types of space / depth cue / ambiguous space / 影调分离造纵深"

### 与相邻 skill 的区分

- 与 `vis-frame-aspect-ratio` 的区别: 画幅管"边框宽高比决定的空间容量"（能装多少），本 skill 管"空间类型的选型"（纵深/平面/有限/模糊）。相关但不同轴。
- 与 `vis-seven-elements` 的区别: 七元素是总清单，本 skill 是"空间"这一项的细法。
- 与 `vis-line-shape` 的区别: 线形管轮廓方向情绪，本 skill 管空间深度谱系。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **为本集场景选一种空间类型并写理由**
   - 完成标准: 明确选"纵深/平面/有限/模糊"之一，并说明服务什么情绪（如"客厅=有限空间显羁绊"）。不允许"随手拍"式不选。

2. **列出该类型的深度线索操作**
   - 完成标准: 给出至少 2 个具体深度线索手段（透视会聚 / 近大远小 / 影调分离 / 色彩分离），并标明下用哪条（小屏优先影调/色彩分离）。
   - 判停条件: 若选"模糊空间"却所有线索都清晰（观众能辨前后），回到步骤 1 重选或削弱线索至不可辨。

3. **核对焦点与情绪是否达成**
   - 完成标准: 确认主体（）通过影调/色彩分离从背景跳出（g40），且空间类型与当集情绪一致；输出"空间类型+深度线索+焦点"三件套。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只问七元素总清单 → 转 `vis-seven-elements`。
- 只问强度总开关（强/弱）→ 转 `vis-contrast-affinity`。
- 只问画幅/边框宽高比 → 转 `vis-frame-aspect-ratio`。
- 只问线形方向情绪 → 转 `vis-line-shape`。

### 作者在书中警告的失败模式

- **空间默认化（忘了选型）**: 以为拍到什么空间就是什么，结果情绪与故事错位；空间必须主动选。
- **模糊空间失效**: 想造悬疑却线索太清晰，观众一眼辨前后，误会/悬疑落空（见步骤 2 判停）。
- **ce09（不控制=最差选择）**: 放任空间自组织，纵深错觉可能乱给观众错误距离感。

### 作者的盲点 / 时代局限
### 容易混淆的邻近方法论

- `vis-frame-aspect-ratio`（易混：都涉及"空间"，但一个是类型选型、一个是边框容量）。
- `vis-line-shape`（易混：透视会聚线既是深度线索也是线性主题，但本 skill 关注其"造纵深"而非"方向情绪"）。
