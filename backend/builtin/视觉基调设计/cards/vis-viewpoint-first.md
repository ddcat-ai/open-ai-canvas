## I — 方法论骨架 (Interpretation)

视角是视觉结构的**根**——布洛克把"先定视角"列为建视觉结构的第一步，甚至是唯一不可省略的一步：

- **视角＝观众怎么感知主题（fw14）**：先决定"我想让观众以什么方式感受这个故事"，再据此选空间/线/形/影调/色/运动/节奏。没有视角，就没有视觉结构——其余所有元素都是它的下游。
- **反套路决策支点**：同一桩"被诈骗/被子女忽视"的窘境——用"黑色幽默视角"拍（夸张、错位、她自己制造尴尬）就是喜剧；用"悲情视角"拍（慢镜、冷调、委屈特写）就是苦情。视觉基调（暖亮 vs 冷暗、快节拍 vs 慢拖）由视角一句话定调。
- **四选法落地（g39）**：从视角到具体元素的四种路径——直觉法、主观法、研究法、分析选择法。直觉居首但须防愚弄。
- **最差选择＝不选择（ce09）**：不控制视觉元素，它们自组织且常偏离故事；"随手拍"最危险。
- **防直觉愚弄（ce10）**：别用"以前这样拍过"替代理性设计。

落到：每集开机先定视角（如"不服老的倔强视角""代际错位喜剧视角"），所有视觉基调（暖调、有限空间、慢节奏）从它长出；切忌无视角随手拍。批量产出时用四选法——常规集靠直觉/主观，卡壳集用分析选择法逐元素诊断。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《奇爱博士》vs《奇幻核子战》——视角定悲喜剧（c24 铁证）
- **问题**: 同一核大战题材，为何一部喜剧一部悲剧。
- **方法论的使用**: 作者指出二者仅视角不同——前者黑色幽默视角，后者悲情视角，视觉结构随之完全不同。
- **结论**: 视角决定基调，而非题材决定基调。

### 案例 2: 《现代启示录》vs《巴顿将军》——视角定战争含义（c23 对照）
- **问题**: 同一战争题材，视觉结构迥异。
- **方法论的使用**: 作者对比——梦魇视角 vs 责任视角，空间/影调/运动全不同。
- **结论**: 视角是筛选所有视觉元素的总过滤器。
- **结果**: 支撑"先定视角再选元素"的工作顺序。

### 案例 3: 四选法从视角落地（g39 论证）
- **问题**: 定了视角，怎么落成具体画面。
- **方法论的使用**: 作者给四种路径（直觉/主观/研究/分析），直觉快但须防碎片直觉愚弄（ce10）。
- **结论**: 落地有可操作路径，不必全靠天赋。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

2. 同一事件在"喜剧还是苦情"间摇摆（被诈骗/被忽视拍成笑还是惨）。
3. 想用四选法（直觉/主观/研究/分析）把视角落成具体视觉。
4. 怕"随手拍无视角"或"被旧直觉愚弄"（ce09/ce10）。

### 语言信号 (用户的话里出现这些就应激活)

- "这集整体用什么视角/基调拍，喜剧还是苦情"
- "被诈骗这段，我想拍成笑还是拍成惨"
- "先定视角再选视觉元素，这集视角怎么定"
- "同一窘境黑色幽默视角和悲情视角画面差在哪"
- "viewpoint first / POV / no viewpoint no visual structure / 四选法 / 视角决定喜剧悲剧"

### 与相邻 skill 的区分

- 与 `vis-seven-elements` 等子 skill 的区别: 本 skill 是"根"——决定为什么这么拍；七元素/影调/色彩/运动/节奏/故事映射都是"视角定下后怎么落地"。问"整体基调/喜剧苦情"优先本 skill，问"具体元素"转子 skill。
- 与 `vis-contrast-affinity` 的区别: 对比相似是强度总阀；本 skill 是比强度更上游的"视角根"。
- 与 `vis-story-visual-map` 的区别: 故事映射把四段译成视觉；本 skill 先定"以什么视角感这个故事"，是映射的前提。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定本集/本剧视角（悲喜剧基调决策）**
   - 完成标准: 输出明确视角句（如"代际错位黑色幽默视角"），并显式声明该视角下"同一窘境"的基调选择（喜剧错位 vs 悲情委屈）；禁止出现"无视角随手拍"（ce09）。

2. **用四选法把视角落成视觉基调**
   - 完成标准: 选一种落地路径（直觉/主观/研究/分析，g39），给出本集视觉基调方向（暖亮喜剧 or 冷暗苦情、快节拍 or 慢拖）；若凭直觉须标注"防愚弄"检查点（ce10）。
   - 判停条件: 若发现具体视觉与视角冲突（如悲情视角却暖亮快剪），回到步骤 1 重定视角或重配基调。

3. **向本书衍生子 skill 分发（不让本 skill 抢细节）**
   - 完成标准: 把"视角+基调"交给对应子 skill 落地（空间/线/影调/色/运动/节奏/七元素/故事映射），本 skill 只守"根"不进单元素细法；给一处可即兴突破点（见 B）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 视角已定、只问"某单一元素怎么调"（影调/色彩/运动/节奏/空间/线形/画幅/七元素/故事映射）→ 转对应子 skill。
- 用户问的是"强度总开关" → 转 `vis-contrast-affinity`。

### 作者在书中警告的失败模式

- **ce09（最差选择＝不选择）**: 不控制视觉元素，它们自组织且常偏离故事；"随手拍"最危险——每集必须有意定视角。
- **ce10（被直觉愚弄）**: 用"以前这样拍过"替代理性设计；卡壳时回四选法中的"分析选择法"逐元素诊断，别拿旧习惯当理由。
- **视角缺失即无视觉结构（fw14）**: 跳过视角直接调元素，等于没根——所有本书衍生选择都会飘。

### 作者的盲点 / 时代局限
### 容易混淆的邻近方法论

- `vis-story-visual-map`（易混：把"定视角"和"四段映射"混为一谈——视角是映射的前提/根，映射是视角的叙事落地）。
- `vis-contrast-affinity`（易混：以为"定基调"就是定强弱——基调的根是视角，强弱只是其表现之一）。
