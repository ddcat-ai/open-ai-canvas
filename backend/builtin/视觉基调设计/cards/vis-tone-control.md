## I — 方法论骨架 (Interpretation)

影调就是画面的"灰度明暗阶"。布洛克给了一套谁管明暗的分工表，以及明暗怎么当"注意力开关"：

- **三控法（fw09）**：①反射光——被摄物自身的亮度，由美术/服装/场景定（穿亮色围裙、暖墙漆），这是你**最能自由控制**的一档；②入射光——打在她身上的灯光；③曝光——摄影机整体调亮调暗，**不能选局部**。结论：想低成本控明暗，优先动"反射光"（服装/道具/背景），别一上来依赖灯光和后期。
- **最亮区＝注意力（p16）**：观众先看最亮处，尤其画面静止无动作时，明暗是唯一引导器。小屏更是如此——想让观众看哪，就把哪打亮、把别处压暗。
- **影调同步＝喜剧可读性（p17）**：让主体比环境更清楚（同步），观众才知道看哪、包袱才抖得清；非同步是主动把主体藏进暗部。
- **影调分离＝焦点+纵深（g40）**：让主体亮度与背景拉开，既把它从背景"抠"出来当焦点，又制造深度错觉。

落到：温情段用暖亮反射光（亮色单品），被子女冷落的冷场段压低她的反射光亮度制造落差；不靠灯不靠后期也能定调。

## A1 — 书中的应用 (Past Application)

### 案例 1: 影调引导注意力到最亮区（p16 论证）
- **问题**: 静态或无动作画面里，观众不知该看哪。
- **方法论的使用**: 作者指出观众注意力自动被最亮区域吸引，影调是最廉价也最隐蔽的注意力分配手段。
- **结论**: 想引导视线就制造"最亮区"，想隐藏就压暗。
- **结果**: 成为所有"焦点引导"任务的首选杠杆——尤其小屏低成本场景。

### 案例 2: 喜剧依赖影调同步抖包袱（p17 论证）
- **问题**: 喜剧笑点需要被看清才能"响"，可是新手常把主体拍暗。
- **方法论的使用**: 作者强调喜剧用影调同步让主体清楚，包袱抖得明白。
- **结论**: 同步（主体亮于环境）是喜剧可读性的硬门槛。
- **结果**: 支撑喜剧段"表情必须清晰"，否则丢包袱。

### 案例 3: 影调分离同时解决焦点与纵深（g40 论证）
- **问题**: 既要让主体跳出背景，又想制造空间纵深。
- **方法论的使用**: 作者把影调分离列为深度线索，同时当焦点分离手段（亮主体+暗背景）。
- **结论**: 一招两用，低成本即可实现。
- **结果**: 让从灰调社区跳出的标准妙招。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 本集要定"暖亮温情"还是"冷暗压抑"的明暗基调。
2. 画面重点丢、观众看不清表情/关键道具，怀疑明暗没设计（焦点引导）。
3. 喜剧密集对白，怕包袱抖不响——需要影调同步保证可读性。
4. 低成本，想靠服装/背景（反射光）定调而非灯光后期。

### 语言信号 (用户的话里出现这些就应激活)

- "这集明暗基调怎么定，暖亮还是冷暗"
- "观众看不清表情/包袱，是不是太暗了"
- "低成本怎么靠服装背景定影调，不靠灯"
- "怎么让观众视线落在我想要的焦点上"
- "tone / brightness / 影调同步 / tone separation / 最亮区引导"

### 与相邻 skill 的区分

- 与 `vis-color-mapping` 的区别: 影调只管明暗灰阶（亮不亮、看清没），颜色（色相/冷暖/饱和度）归 color-mapping。用户问"暖调冷调"优先 color-mapping，问"亮不亮/看清没"优先本 skill。
- 与 `vis-contrast-affinity` 的区别: 对比相似是强度总开关；本 skill 是"明暗"这一具体元素的控法。
- 与 `vis-viewpoint-first` 的区别: 视角决定"为什么这么拍"，影调决定"明暗具体怎么落"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定本集影调基调 + 选控法杠杆**
   - 完成标准: 输出本集主影调（暖亮/冷暗/中性）及优先使用的控法（低成本默认"反射光"——列明服装/道具/背景亮度决策），注明灯光/曝光仅作辅助。

2. **设最亮区＝焦点落点（影调同步）**
   - 完成标准: 标出本集每一关键镜的"最亮区"必须落在表情或关键道具上；主体亮于环境（同步），保证包袱可读（p17）。
   - 判停条件: 若发现某喜剧/对白段主体被压暗（非同步），回到步骤 1 提亮反射光，除非是悬疑短段刻意藏（ce08 例外）。

3. **用影调分离抠焦点＋造纵深**
   - 完成标准: 给出至少 1 处"亮主体+暗背景"分离方案，同时解决焦点与空间纵深（g40）；给出本集一处可即兴突破点（见 B）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是"色相/冷暖/饱和度"（那归 `vis-color-mapping`）。
- 用户问的是"强弱总开关"（归 `vis-contrast-affinity`）。
- 用户问的是"看世界的角度/视角"（归 `vis-viewpoint-first`）。

### 作者在书中警告的失败模式

- **ce08（不该藏主体时误用影调非同步）**: 需要观众看清主体/笑点的场景（尤其喜剧）却把主体藏进暗部，包袱直接丢失。喜剧段主体必须清晰——表情昏暗=丢包袱；非同步只留给悬疑短段落。
- **ce09（不控制=最差选择）**: 放任影调自组织，结果偏离故事；"随便拍"最危险，每集必须有意定调。
- **三控法优先级误用**: 曝光是整体调不可选局部，新手却总想靠后期"整体提亮"解决局部看不清——应优先动反射光（服装/背景亮度）。

### 作者的盲点 / 时代局限
### 容易混淆的邻近方法论

- `vis-color-mapping`（易混：用户说"暗"有时指色彩沉、有时指明度低——明度低归本 skill，色相沉归 color-mapping）。
- `vis-contrast-affinity`（易混：把"做明暗对比"误当独立 skill，实则它是具体元素的对比用法，强度总阀归对比相似）。
