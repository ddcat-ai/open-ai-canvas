## I — 方法论骨架 (Interpretation)

布洛克把"形状"和"线条方向"都变成可拨的情绪旋钮，分两块：

**一、三基本形状的情绪性格**（任何物体都能归进去，但是"联想"非"定规"）：
- **圆**：最温和、被动、无害——适合可爱、亲和（的圆框眼镜、圆围裙）。
- **方**：稳定、坚固、有序——适合秩序、规矩（居委会、方格背景）。
- **三角**：唯一含斜线，最具动感、激進——适合冲突、爆发（发飙时的尖领、三角手势）。

**二、线性主题（线条方向→张力）**：把一场戏里所有线条组织成统一方向系统——
- **水平/垂直**：平静、稳定、秩序。
- **斜线**：动感最强、张力最高。
- 先眯眼识别画面主线条，再用光/运动/构图控制其方向，让一场戏（无论飙车还是唠嗑）的张力被线条和谐控制。

落到：人设用圆（温和可爱）与三角（发飙反套路）切换；社区/居委会用方显秩序，反套路"破局"用三角打破方形秩序；安静唠嗑用水平垂直线，闹翻天用斜线（楼梯扶手、斜倚身体）；可用服装条纹、家具边线低成本搭线性主题。

**警告**：形状/线条联想是俗套温床（见 B 段 ce03），高级用法是建立自有的视觉-情绪关系，而非贴标签。

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者定义三基本形状的情绪谱系
- **问题**: 学生不知"形状"能承载情绪。
- **方法论的使用**: 把任意物体归圆/方/三角，对应温和/稳定/动感，并提醒这是联想非定规、易成俗套。
- **结论**: 形状是情绪性格的快捷旋钮，但须防标签化。
- **结果**: 成为第四章核心，指导角色/场景的视觉人设。

### 案例 2: 作者用线性主题控制一场戏张力（fw08）
- **问题**: 同一场戏有时张力忽高忽低，不统一。
- **方法论的使用**: 把线条组织成固定方向系统（水平/垂直/斜线），用光/运动/构图控制主线条方向。
- **结论**: 线条对比/相似能和谐衔接任意强度的戏，斜线动感最强。
- **结果**: 提供"眯眼识别主线条→定向控制"的实操法。

### 案例 3: 红色=危险之类俗套警示（ce03 关联）
- **问题**: 约定俗成的视觉联想有效但低级。
- **方法论的使用**: 指出红=危险等套路陈旧、最低级；应建自有关系。
- **结论**: 形状/线条情绪同理——圆=好、三角=坏是廉价联想，须自定义。
- **结果**: 约束本 skill 的使用边界，防俗套。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用形状切换表达人设（圆=可爱、三角=发飙反套路）。
2. 用线条方向控一场戏张力（安静水平垂直、爆发斜线）。
3. 社区/居委会用方显秩序，反套路破局用三角打破。
4. 想用服装条纹/家具边线低成本搭线性主题。

### 语言信号 (用户的话里出现这些就应激活)

- "发飙这场用三角/斜线撑张力，平时用圆显可爱"
- "这场戏线条怎么组织，水平还是斜线"
- "居委会场景用方形显秩序，破局用三角打破"
- "圆形方形三角形、线性主题、line and shape、visual tension"
- "用服装条纹/家具边线搭线条方向"

### 与相邻 skill 的区分

- 与 `vis-space-four-types` 的区别: 该 skill 的透视会聚线关注"造纵深"，本 skill 的线条关注"方向→张力"，关注点不同。
- 与 `vis-frame-aspect-ratio` 的区别: 画幅管边框容量，本 skill 管框内线条/形状情绪。
- 与 `vis-contrast-affinity` 的区别: 强度轴管强弱，本 skill 管"线形"这一元素的情绪性格。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **给关键角色/场景定形状性格**
   - 完成标准: 写明本集（及反派/秩序方）用圆/方/三角中哪种，并说明情绪意图（如"平时圆=可爱，发飙切三角=反套路"）。避免无形状设计。

2. **定本集线性主题方向**
   - 完成标准: 选水平/垂直（平静）或斜线（张力）之一作为主线条方向，并列出可落地的线条源（服装条纹、家具边线、楼梯扶手、身体斜倚）。
   - 判停条件: 若一场戏既要平静又要强张力却线条方向打架（水平线与斜线混用无主次），回到步骤 2 定单一主方向或排优先级。

3. **核对俗套边界**
   - 完成标准: 确认形状/线条用法是"自有视觉-情绪关系"而非贴标签（如非"圆=好/三角=坏"廉价联想），输出"形状+线条方向+情绪"三件套并标注是否避开了 ce03 俗套。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只问空间类型选型（纵深/平面/有限/模糊）→ 转 `vis-space-four-types`。
- 只问画幅/边框 → 转 `vis-frame-aspect-ratio`。
- 只问强度总开关（强/弱）→ 转 `vis-contrast-affinity`。
- 只问七元素总清单 → 转 `vis-seven-elements`。

### 作者在书中警告的失败模式

- **ce03（视觉俗套）**: 红=危险、圆=好/三角=坏等约定俗成联想有效但低级、易陈旧；形状/线条情绪须建自有关系，忌贴标签。
- **形状=定规的误解**: 布洛克明确形状情绪是"联想非定规"，不能机械判定"三角必坏"，否则落入俗套。
- **线条方向打架**: 一场戏水平线与斜线无主次混用，张力混乱（见步骤 2 判停）。

### 作者的盲点 / 时代局限
### 容易混淆的邻近方法论

- `vis-space-four-types`（易混：透视会聚线既是深度线索也是线性主题，但本 skill 关注其"方向张力"而非"造纵深"）。
- `vis-contrast-affinity`（易混：线条对比/相似驱动强度，但本 skill 专讲线形情绪这一元素）。
