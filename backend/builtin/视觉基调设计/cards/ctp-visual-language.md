## I — 方法论骨架 (Interpretation)

1. **八组织力**：统一/平衡/张力/节奏/比例/对比/质感/方向性，共同引导观眼。
2. **平衡与张力**：平衡给稳定，张力给动态；二者权衡。
3. **视觉隐喻**：让画面元素象征意义（非直白）。
4. **连续性与轴线**：守 180° 轴线，匹配 eyeline，跨镜空间不乱。
5. **cinematic = 叠层意义**：技术须服务于"让内容更有层次"。

## A1 — 书中的应用 (Past Application)

### 案例
- POV/establishing 先定空间；对话匹配 eyeline 与 axis。
- 用方向性(如光/线条指向主体)引导注意力。
- 结论：视觉语言是"用画面讲第二层意思"的纪律。

## E — 可执行步骤 (Execution)

1. **用八组织力**：构图时检查统一/平衡/张力等。
2. **造张力/方向性**：引导观眼到该看处。
3. **建视觉隐喻**：让元素承载意义。
4. **守轴线/连续**：覆盖时匹配 eyeline 与 180°。
5. **追叠层意义**：每项技术问"它给内容加了什么"。

## B — 边界 (Boundary) ★

- **不只"好看"**：技术须服务故事，否则炫技。
- **连续性是剪辑逻辑但镜头阶段就规划**：轴线在拍摄时定。
- **Tier B**：只抽视觉语言机制；不转引书中名画/长片分析。
