## I — 方法论骨架 (Interpretation)

节奏不是剪辑师的专利，布洛克把它列为独立视觉元素——画面本身就有"快慢"。把听觉节奏的三零件平移到视觉：

- **三元素（fw12）**：间隔（alternation，动静/明暗交替）、重复（repetition，元素规律再现）、节拍（tempo，整体快慢）。剪辑与运动只是产节奏的手段之一，静止构图也能产节奏。
- **矩形数＝节拍（p27）**：把画面想象成被分割成多少块"矩形区域"——区域多=节拍快且不规律，区域少/居中=节拍慢而规律。这是可视化节奏的尺子：慢唠嗑段大留白少分割，混战段多元素密集分割。
- **空镜头＝白噪音（ce15）**：画面空无一物或均匀无变化，等于没有节奏。单集忌空镜/绝对均匀，构图须有分割与主体落点。
- **静止也出拍（g34）**：物体把景框分割成强拍（中央/正空间，主导）与弱拍（左右/负空间），静止构图自带强弱拍交替。可用占中央强拍、留白/子女在弱拍，制造"谁主导这帧"的喜剧权力关系。

落到：节拍=镜头长度+剪辑频率+元素重复快慢；日常用重复（routine 循环）撞突发反套路对比造喜剧节拍，避免全程一个速度。

## A1 — 书中的应用 (Past Application)

### 案例 1: 矩形数量控制节拍（p27 论证）
- **问题**: 如何直观判断一个画面"快还是慢"。
- **方法论的使用**: 作者用"景框被分割成多少矩形区域"量化节奏——多分割=快拍。
- **结论**: 节奏可被构图分割数可视化、可控。
- **结果**: 成为调速尺——前景遮挡物即可制造分割区域调速。

### 案例 2: 空镜头无节奏（ce15 反例）
- **问题**: 为何有些镜头"看着什么都没发生、很闷"。
- **方法论的使用**: 作者指出空无一物=白噪音，无间隔/重复/节拍。
- **结论**: 空镜/绝对均匀=节奏缺失，观众失拍。
- **结果**: 支撑"每帧须有分割与主体落点"。

### 案例 3: 静止构图的强拍弱拍（g34 术语）
- **问题**: 静态镜头如何也有节奏。
- **方法论的使用**: 物体分割景框成中央强拍（正空间）与左右弱拍（负空间）。
- **结论**: 静止画面靠位置分配强弱拍。
- **结果**: 静态构图也能出"谁主导帧"的喜剧关系。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 本集快慢起伏设计——慢唠嗑段 vs 混战段怎么调速。
2. 全集成一个速度、拖沓催眠，需要节拍变化。
3. 日常想用"重复撞突发"造喜剧节拍。
4. 静态构图想出节奏（强弱拍/正空间负空间）。

### 语言信号 (用户的话里出现这些就应激活)

- "这集节奏太拖沓/太吵，节拍怎么调"
- "镜头长度和剪辑频率怎么配出快慢"
- "静态镜头怎么也有节奏感"
- "重复和间隔怎么造喜剧节拍"
- "visual rhythm / tempo / 强拍弱拍 / 正空间负空间 / alternation"

### 与相邻 skill 的区分

- 与 `vis-movement-design` 的区别: 节奏管"动的间隔/重复/快慢"（时间维）；运动管"谁动、动因"。问"动多快/多规律"优先本 skill，问"怎么动"优先 movement-design。
- 与 `vis-tone-control` / `vis-color-mapping` 的区别: 那些管静止画面的明暗/色彩；本 skill 管节奏这一独立元素（含静止构图的强弱拍）。
- 与 `vis-viewpoint-first` 的区别: 视角决定"为什么这个节拍"，节奏决定"具体快慢"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **画本集节拍曲线（矩形分割法）**
   - 完成标准: 输出本集节拍起伏（慢段=少分割大留白，快段=多元素密集分割，p27）；禁止出现全程单一速度或空镜白噪音（ce15）。

2. **用重复撞突发造喜剧节拍**
   - 完成标准: 标出本集"日常重复段（routine 循环）"与"突发反套路对比点"，二者交替构成喜剧节拍；至少 1 处静止构图用强拍弱拍（g34：占中央正空间、子女弱拍）出权力关系。
   - 判停条件: 若发现某段空镜/绝对均匀（ce15），回到步骤 1 加分割与主体落点。

3. **标注节拍与剪辑/运动的配合 + 即兴点**
   - 完成标准: 说明镜头长度+剪辑频率如何支撑上述节拍，并给一处可即兴突破点（见 B）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是"谁在动/怎么动"（成因动源）→ 转 `vis-movement-design`。
- 用户问的是"明暗/色彩焦点"（静止画面）→ 转 `vis-tone-control` / `vis-color-mapping`。
- 用户问的是"视角" → 转 `vis-viewpoint-first`。

### 作者在书中警告的失败模式

- **ce15（空镜头=白噪音）**: 画面空无或绝对均匀，无间隔/重复/节拍，观众失拍。单集忌空镜，每帧须有分割与主体落点。
- **p03（纯相似催眠/纯对比过载）**: 全程一个速度（纯相似）催眠，或全程强对比（纯对比）刺眼；须做"相似铺垫→对比爆发→相似回落"的起伏。
- **ce09（不控制=最差选择）**: 放任节奏自组织，结果偏离故事。

### 作者的盲点 / 时代局限
### 容易混淆的邻近方法论

- `vis-movement-design`（易混：把"让画面动起来"和"控制动的节拍"混为一谈——动法是 movement-design，节拍是 rhythm-design）。
- `vis-contrast-affinity`（易混：节拍起伏本质靠对比/相似交替，但强度总阀归对比相似，本 skill 聚焦时间维节奏）。
