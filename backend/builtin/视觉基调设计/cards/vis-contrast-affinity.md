## I — 方法论骨架 (Interpretation)

布洛克全书最底层的一根轴：**几乎所有"画面好不好、有没有劲"的问题，都可以还原成「差异多还是一致多」**。

- **对比（contrast）** = 画面里各元素互相不一样：明暗差、冷暖差、动静差、大小差。差异越多越大，观众眼睛越被刺激、越觉得"有戏、有动感"。
- **相似（affinity）** = 画面里各元素互相靠拢：都灰、都静、都暖、都居中。一致越多，画面越平静、越催眠、越温馨。
- 这个旋钮不是"开/关"，而是一个**连续滑杆**：从"全对比"到"全相似"之间任意位置都能停。七视觉元素（空间/线/形/影调/色/运动/节奏）每一个都受这根轴支配——你调任一元素，本质上都在调对比或相似。
- 实操铁律：**先定"这一镜/这一集要强还是弱"，再往下选元素**。不拨这个旋钮就直接拍，结果通常两头极端跑（见 B 段 ce01/ce02）。
- 落到：宅院日常用相似（平静温馨不刺眼），反套路揭穿/发飙瞬间切强对比，全剧情绪曲线就是这一个旋钮的一句话定调。

## A1 — 书中的应用 (Past Application)

### 案例 1: 黑白交替片段过载（纯对比的灾难）
- **问题**: 作者要演示"对比拉到极致"会怎样。
- **方法论的使用**: 一组黑白画面连续急速交替几分钟，全程纯对比无相似喘息。
- **结论**: 对比过载＝生理上难以忍受，观众抓狂而非被吸引。
- **结果**: 证明"纯对比"是失败的极端，必须掺相似做节奏。

### 案例 2: 全灰单调片段催眠（纯相似的灾难）
- **问题**: 作者要演示"相似拉到极致"会怎样。
- **方法论的使用**: 每格都是同一灰调、无任何视觉变化，全程纯相似。
- **结论**: 相似过载＝无聊到看不下去，观众失去注意力。
- **结果**: 证明"纯相似"同样是失败的极端，必须掺对比防催眠。

### 案例 3: 作者自述「对比＝强度高 / 相似＝强度弱」总公式
- **问题**: 全书需要一根能统摄七元素的总原则。
- **方法论的使用**: 把七元素每一个的"差异/一致"统一抽象成对比与相似。
- **结论**: 任一视觉安排本质都是在该轴上拨旋钮，复杂度递增不过是"对比递增"。
- **结果**: 成为后续每章（空间、线形、影调、色、运动、节奏）的母原理。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 开拍/写分镜前想定"这一集整体什么调子"——平静温馨还是炸裂反套路。
2. 成片出来发现"太吵、晃眼、观众累"或"太闷、拖、看着想睡"，要诊断原因。
3. 九宫格构图前，先决定这一帧要强对比还是相似统一。
4. 想给单集做"铺垫→爆发→回落"的视觉起伏曲线，匹配喜剧节拍。

### 语言信号 (用户的话里出现这些就应激活)

- "这集整体情绪基调怎么定？想温馨还是炸裂？"
- "画面是不是太吵/太刺眼了，观众看着累"
- "怎么避免一集平到催眠、或者全程强对比吵死人"
- "对比和相似到底怎么用，视觉强度怎么控制"
- "contrast vs affinity / 视觉强度旋钮 / 这一镜要强还是弱"

### 与相邻 skill 的区分

- 与 `vis-seven-elements` 的区别: 本 skill 只管"总开关——强还是弱"；`vis-seven-elements` 是七个具体旋钮的清单。先用本 skill 定强弱，再用七元素落地。
- 与 `vis-viewpoint-first` 的区别: 视角（看世界的角度）决定"拍什么内容"，对比相似决定"内容有多强"。视角在先，强度在后。
- 与 `vis-color-mapping` / `vis-rhythm-design` 等子 skill 的区别: 那些是具体元素的调法；本 skill 是它们的元原则，不进细节。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **给本镜/本集定一个强度档位**
   - 完成标准: 用一句话写明"这一镜要相似（弱）还是对比（强）"，并给出理由（如"发飙揭露真相=强对比"）。若用户没指定，默认给"相似铺垫"并标注待确认。

2. **扫描当前画面七元素，标出对比/相似落点**
   - 完成标准: 对空间/线/形/影调/色/运动/节奏逐项判"现在是偏对比还是偏相似"，至少 3 项有明确判断。
   - 判停条件: 若扫描发现"全程纯对比"或"全程纯相似"（见 B 段 ce01/ce02），直接跳到步骤 3 做调配，不再继续。

3. **做有节奏的调配，输出对比/相似曲线**
   - 完成标准: 给出"相似铺垫→对比爆发→相似回落"的起伏设计（如集内至少一处明显对比爆发点），并指明下用哪个元素（如亮色道具、斜线、快剪）实现该对比。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要的是"空间/线/形/影调/色/运动/节奏"某一具体元素怎么调 → 转 `vis-seven-elements` 及其子 skill（vis-space-four-types / vis-line-shape / vis-color-mapping / vis-tone-control / vis-movement-design / vis-rhythm-design）。
- 需要的是"看世界的角度/视角"而非强度 → 转 `vis-viewpoint-first`。

### 作者在书中警告的失败模式

- **ce02（纯相似催眠）**: 全场同一灰调无变化会让观众无聊到看不下去——家常戏忌一集毫无视觉变化，要在重复中塞小对比（突然的亮色道具）防催眠。
- **ce09（不控制=最差选择）**: "随便拍"不等于没视觉，元素仍按对比/相似自动组织，结果往往偏离故事。每集必须有意定调。

### 作者的盲点 / 时代局限
### 容易混淆的邻近方法论

- `vis-seven-elements`（本 skill 是元原则，七元素是落地清单；易混：以为"定强度"就是"调完七元素"）。
- `vis-rhythm-design`（节奏是七元素之一，由对比/相似驱动，但本 skill 不展开节奏设计）。

## 相关 skills (阶段 3 填充)

### depends-on（使用前需先理解）
- `vis-viewpoint-first`：先定视角（喜剧/悲剧基调），才知道本集该把强度旋钮拨向"强对比"还是"弱相似"。

### contrasts-with（易混淆，注意区分）
- 本 skill 是覆盖全部元素的"强度总开关"，与七元素及各元素 skill 是"总阀 vs 具体旋钮"的上下位关系，并非二选一的方案对照。真正的易混对照在 `vis-tone-control` ↔ `vis-color-mapping`（明暗 vs 色相）与 `vis-movement-design` ↔ `vis-rhythm-design`（动法 vs 节拍）。

### composes-with（常配合使用）
- `vis-seven-elements`：定完强弱后用七元素逐项落地（总表逐项承接强度轴）。
- `vis-tone-control` / `vis-color-mapping` / `vis-rhythm-design`：这三个元素里"对比/相似"恰是主导旋钮（明暗对比、饱和度对比、节拍对比），与元原则配合最紧。
- `vis-story-visual-map` / `vis-visual-progression`：把强度轴沿故事四段 / 复杂度台阶展开。
