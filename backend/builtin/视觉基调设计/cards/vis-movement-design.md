## I — 方法论骨架 (Interpretation)

运动是屏幕世界里"谁在动、为什么看起来在动"的学问。布洛克先分运动**成因**四型，再分屏幕**能动的角色**三源：

- **四型（fw11）**：
  - 实际运动——物体真的在屏上位移（走动）。
  - 表象运动——物体没动但看起来在动（如频闪、逐格）。
  - 诱导运动——一个物体在动，让静止物体"显得"在动（云动月不动）。
  - 相对运动——关键定义：运动本质是**物体相对景框位置的变化**。
- **三动源（fw11）**：屏幕上只有三样能"动"——被摄物、摄影机、观众的视线（关注点）。最便宜的是后两者：让被摄物小幅动，或用视线引导把"动"交给观众眼睛。
- **核心公式（p23）**：只有当物体相对边框位置变了，才有视觉运动。绕摄影机转圈却恒居中对框 = 观众看不到动。这直接决定构图——主体小幅横移/上下即明显运动，不必大调度。

落到：多用被摄物运动（转身/小动作）+ 视线引导（焦点切子女表情），摄影机动作为情绪强调；预算低靠被摄物小幅横移即可。

## A1 — 书中的应用 (Past Application)

### 案例 1: 运动＝相对景框位置变化（p23 论证）
- **问题**: 学生以为"物体在动"就必然产生视觉运动。
- **方法论的使用**: 作者点破——若物体相对边框位置不变（如恒居中心被跟拍），观众看不到运动。
- **结论**: 视觉运动的判据是"相对边框"，不是"真实位移"。
- **结果**: 支撑"主体小幅横移即明显运动"，避免无效大调度。

### 案例 2: 屏幕三动源分工（fw11 论证）
- **问题**: 创作者以为运动只靠被摄物或摄影机。
- **方法论的使用**: 作者列出第三种动源——观众视线（关注点的移动），它本身制造运动感。
- **结论**: 不拍动也能"动"，靠引导视线。
- **结果**: 群像可用视线引导代替摄影机运动，低成本出戏。

### 案例 3: 诱导运动（fw11 四型之一）
- **问题**: 如何让静止物体显得在动。
- **方法论的使用**: 作者用诱导运动——让附近物体动，静止物显得反向动。
- **结论**: 运动是相对的，可利用邻物制造。
- **结果**: 可作 comedy 错位（不动、背景人群涌动显得她"被时代甩开"）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想让走动/转身/小动作产生喜剧运动，但构图紧、不敢大调度。
2. 想用视线引导（焦点切到子女表情）代替昂贵的摄影机运动。
3. 发现"跟拍却主体恒居中心，看起来没动"。
4. 预算低，想靠被摄物小幅运动而非摄影机动。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么让动起来又不用大调度"
- "能不能靠观众视线引导代替摄影机运动"
- "我跟拍但看起来没动，怎么回事"
- "低成本怎么制造画面运动感"
- "movement / 相对运动 / camera vs subject motion / eye-trace"

### 与相邻 skill 的区分

- 与 `vis-rhythm-design` 的区别: 运动管"谁动、动因"（四型三源）；节奏管"动的间隔/重复/快慢"。问"怎么动"优先本 skill，问"动多快/多规律"优先 rhythm-design。
- 与 `vis-tone-control` / `vis-color-mapping` 的区别: 那些管静止画面的明暗/色彩焦点；本 skill 管运动这一独立元素。
- 与 `vis-viewpoint-first` 的区别: 视角决定"为什么动"，运动决定"具体怎么动"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **选动源 + 定运动类型**
   - 完成标准: 输出本集主导动源（被摄物/摄影机/视线，默认被摄物+视线）及至少 1 处运动类型（实际/表象/诱导/相对）；注明避免"主体恒居中心"的伪运动（p23）。

2. **用相对景框位置变化制造可见运动**
   - 完成标准: 确认本集运动都落实为"物体相对边框位置的改变"（横移/上下/出画入画），而非原地转动或对中心跟拍；给出 1 处视线引导替代摄影机运动的方案。
   - 判停条件: 若发现某段"物体在动但相对边框没变"（如中心跟拍），回到步骤 1 改为偏移构图或让背景动（诱导运动）。

3. **标注低成本运动边界 + 即兴点**
   - 完成标准: 给出本集"被摄物小幅运动即可"的低成本清单，并注明何处可加摄影机运动作情绪强调（见 B）；给一处可即兴突破点。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是"明暗/色彩焦点"（静止画面）→ 转 `vis-tone-control` / `vis-color-mapping`。
- 用户问的是"动的快慢/规律" → 转 `vis-rhythm-design`。
- 用户问的是"视角" → 转 `vis-viewpoint-first`。

### 作者在书中警告的失败模式

- **p23 伪运动**：物体真实在动却相对边框位置不变（恒居中心跟拍），观众看不到运动——白白调度。须让主体相对边框位移。
- **ce09（不控制=最差选择）**：放任运动自组织，结果偏离故事；"随便拍"最危险。
- **动源错配**：为"动感"滥用摄影机运动，忽略更便宜的视线引导与被摄物小幅运动，反而乱且贵。

### 作者的盲点 / 时代局限
### 容易混淆的邻近方法论

- `vis-rhythm-design`（易混：把"让画面动起来"和"控制动的节拍"混为一谈——动法是本 skill，节拍是 rhythm-design）。
- `vis-seven-elements`（运动是七元素之一，本 skill 是其细法）。
