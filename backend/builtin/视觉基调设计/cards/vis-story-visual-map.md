## I — 方法论骨架 (Interpretation)

视觉结构不是孤立好看，它必须**平行服务于故事结构**。布洛克给了一张映射表加一条公式：

- **四段映射（fw13）**：故事的四段（开端/冲突/高潮/结局）一对一映射成视觉四段。不是各拍各的，而是视觉随故事同呼吸。
- **核心公式**：对比↑ → 视觉张力↑；相似↑ → 视觉张力↓。想让某段紧张/炸裂，就拉大该段视觉元素的对比（暖亮焦点 vs 暗背景、斜线 vs 水平）；想让某段压抑/平静，就用相似（灰调平面小空间、元素趋同）。
- **视觉开端同步（p30）**：开场就要确立视觉基调（空间/线/影调/色/运动的选择），并最好与故事、音乐开端**同时**出现——视觉开端即"视觉基调"的首次定义。
- **张力图表（c09）**：希区柯克《西北偏北》用"故事次序表 + 张力图表"把整片张力可视化，总统山段是全片峰值。这是把四段映射画成曲线的标准模板。

落到：每集先画故事张力曲线，再逐段配视觉张力——受委屈段用相似（压抑平面小空间），反击/反套路段用强对比（暖亮焦点+斜线爆发），视觉冲顶与"爽感"高潮同步；集首 3 秒暖平空间+特写+家常音效同步定调。

## A1 — 书中的应用 (Past Application)

### 案例 1: 故事四段映射视觉四段（fw13 论证）
- **问题**: 视觉设计常脱离故事，各拍各的。
- **方法论的使用**: 作者把故事开端/冲突/高潮/结局对应到视觉四段，用对比↑张力↑、相似↑张力↓统一调控。
- **结论**: 视觉张力曲线应平行故事张力曲线。
- **结果**: 成为每集"故事→视觉"翻译的总方法。

### 案例 2: 《大白鲨》视觉开端＝故事/音乐同出（c08 示范）
- **问题**: 如何确立全片基调。
- **方法论的使用**: 斯皮尔伯格让音乐、视觉、故事开端同时出现（水下镜头随不祥主题乐缓慢移动）。
- **结论**: 视觉开端须与故事/音乐同步，一次定义基调。

### 案例 3: 《西北偏北》张力图表（c09 示范）
- **问题**: 如何把整片张力可视化、可控。
- **方法论的使用**: 希区柯克用故事次序表+张力图表，峰值（总统山）清晰可定位。
- **结论**: 张力可画成曲线，峰值即视觉冲顶处。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 每集想先画故事张力曲线，再逐段配视觉张力（受委屈段 vs 反击段）。
2. 集首 3 秒视觉基调怎么定，且要与故事/音乐同出。
3. 想把整集张力画成"张力图表"模板，定位视觉峰值。
4. 担心视觉与故事脱节（高潮不炸、低谷不抑）。

### 语言信号 (用户的话里出现这些就应激活)

- "这集故事张力怎么翻译成视觉张力"
- "受委屈段用什么视觉、反击段怎么炸"
- "集首 3 秒怎么定视觉基调，和故事音乐同步"
- "能不能画个张力曲线模板定位视觉高潮"
- "story to visual / 视觉开端 / tension curve / 对比相似随叙事"

### 与相邻 skill 的区分

- 与 `vis-seven-elements` 的区别: 七元素是单集静态七旋钮清单（横向元素）；本 skill 是把七元素随故事四段推进成曲线（纵向叙事）。问"逐段怎么变"优先本 skill，问"单集各元素默认值"优先 seven-elements。
- 与 `vis-contrast-affinity` 的区别: 对比相似是强度总阀；本 skill 是用它"随叙事分段调控"。
- 与 `vis-viewpoint-first` 的区别: 视角决定"为什么这么映射"，本 skill 决定"四段具体怎么对应"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **画本集故事四段 + 张力曲线**
   - 完成标准: 输出本集开端/冲突/高潮/结局四段，并标出每段故事张力高低（参考 c09 张力图表模板）；禁止视觉与故事脱节。

2. **逐段配视觉张力（对比/相似公式）**
   - 完成标准: 对每段给出视觉方案——高潮/反击段拉对比（暖亮焦点+斜线爆发），受委屈/压抑段用相似（灰调平面小空间）；确保视觉张力曲线平行故事曲线（fw13）。
   - 判停条件: 若某段"高潮却视觉平淡"或"低谷却强对比"，回到步骤 1 重调该段对比/相似强度。

3. **定视觉开端（与故事/音乐同出）**
   - 完成标准: 给出集首 3 秒方案——空间/线/影调/色/运动选择 + 与故事/家常音效同步出现（p30/c08）；并给一处可即兴突破点（见 B）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只问"单一元素怎么调"（影调/色彩/运动/节奏/空间/线形/画幅）→ 转对应子 skill。
- 用户问的是"视角" → 转 `vis-viewpoint-first`。
- 用户问的是"强度总开关" → 转 `vis-contrast-affinity`。

### 作者在书中警告的失败模式

- **视觉与故事脱节**：高潮段视觉平淡或低谷段强对比，违背"对比↑张力↑"公式（fw13）；须逐段对齐。
- **p03（纯对比过载/纯相似催眠）**: 全段强对比刺眼或全段相似催眠；四段内也要做起伏，非全程一味强/弱。
- **ce09（不控制=最差选择）**: 放任视觉自组织，结果偏离故事。

### 作者的盲点 / 时代局限

- 原书张力图表按长片多场戏粒度；每集 1–3 分钟，四段常被压缩进单集甚至单镜，须把"四段映射"轻量化成"单集内的张力起伏"而非严格四幕。

### 容易混淆的邻近方法论

- `vis-seven-elements`（易混：把"单集七元素清单"误当"故事映射"——前者静态横向，后者动态纵向）。
- `vis-contrast-affinity`（易混：四段调控本质靠对比/相似，但本 skill 聚焦"随叙事分段"，强度总阀归对比相似）。

## 相关 skills (阶段 3 填充)

### depends-on（使用前需先理解）
- `vis-seven-elements`：映射须把七元素在故事四段上逐项赋值，先认得这七元素。

### contrasts-with（易混淆，注意区分）
- `vis-seven-elements`：本 skill 是"四段叙事映射"（纵向，随故事推进），七元素是"单集静态七旋钮清单"（横向，单集默认值）。问"逐段怎么变"优先本 skill，问"单集各元素默认值"优先 seven-elements。

### composes-with（常配合使用）
- `vis-contrast-affinity`：四段调控的核心公式就是"对比↑张力↑、相似↑张力↓"，强度轴全程驱动映射。
- `vis-viewpoint-first`：视角是映射的前提/根——先定"以什么视角感这个故事"，再谈四段怎么对应；本 skill 是视角的叙事落地。
