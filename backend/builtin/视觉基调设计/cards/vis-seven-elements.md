## I — 方法论骨架 (Interpretation)

布洛克把"画面好看"这件事从玄学变成一张可勾的清单：**任何一帧画面，都能拆成 7 个组成零件**——

1. **空间**（二维屏上的纵深错觉）
2. **线条**（画里所有边的方向）
3. **形状**（圆/方/三角等轮廓）
4. **影调**（明暗灰度阶）
5. **色彩**（色相/亮度/饱和度/冷暖）
6. **运动**（谁在屏上动）
7. **节奏**（静止与运动的间隔/重复/节拍）

关键认知有三条：

- **屏幕没有真空（p05）**：即便一片空白，也含着空间、线、形、影调、运动；即便一格静止，也含着节奏。不主动设计它们也会自组织，而且通常对故事不利——"不决策"本身就是糟糕决策。
- **视觉结构不是数学，但有章可循（p06）**：这 7 个不是公式，是经验法则；可以套用，但要给作者 voice 和即兴留空间，别把每集填表变机械。
- **屏幕世界 ≠ 真实世界（g06）**：屏是二维错觉，真实的三维动作在屏上只剩二维投影，必须按屏幕世界规则构图，不能凭现实直觉。

落到：每集开机前用这 7 格逐项自检——本集空间选哪种、线往哪走、影调明暗、冷暖、动静、节拍各多少；小屏低成本也能逐项检视，不靠"凭感觉"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者用七元素给任何图像做结构拆解
- **问题**: 读者常觉得"画面好看"说不清道不明，无法传授。
- **方法论的使用**: 作者把任意画面还原成空间/线/形/影调/色/运动/节奏七零件，逐一可指认。
- **结论**: 视觉结构可被拆解、被教学、被有意控制，七元素是总目录。
- **结果**: 成为全书后续各章（空间、线形、影调、色、运动、节奏）的框架母本。

### 案例 2: 作者强调"屏幕没有真空"（p05 的论证）
- **问题**: 学生以为"留白/静止"就可以不管视觉。
- **方法论的使用**: 指出空白仍含空间线形影调运动、静止仍含节奏，放任即自组织且常偏离故事（呼应 ce09）。
- **结论**: 不控制=最差选择；每集必须有意定调。
- **结果**: 支撑"开机即自检"的工作纪律。

### 案例 3: 作者提醒"不是数学但有章法"（p06 的论证）
- **问题**: 两种极端——把视觉当纯玄学（不可学）或当死公式（可算）。
- **方法论的使用**: 给出"概念、指导方针、通行规则"而非计算式。
- **结论**: 七元素是可套用的经验法则，但保留作者判断空间。
- **结果**: 防止把自检表变成机械填表（对照 ce04 边界）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 每集开机前想系统盘一遍"本集视觉基调各元素怎么定"，避免凭感觉。
2. 成片出来"信息乱、重点丢、观众抓不住"，怀疑是某元素没设计。
3. 小屏想低成本逐项自检（空间/线/形/影调/色/运动/节奏）。
4. 想建立可复用的"每集视觉自检表"流程。

### 语言信号 (用户的话里出现这些就应激活)

- "这集画面怎么系统定调，别凭感觉拍"
- "每集视觉基调能不能给我做个自检表"
- "观众抓不住重点，是不是画面元素没设计"
- "空间线条形状影调色彩运动节奏分别怎么定"
- "seven visual elements / 视觉自检 / screen has no vacuum"

### 与相邻 skill 的区分

- 与 `vis-contrast-affinity` 的区别: 本 skill 是"七旋钮清单 + 自检流程"；对比相似是"强度总开关"。先用对比相似定强弱，再用本 skill 逐项落地。
- 与 `vis-space-four-types` / `vis-line-shape` / `vis-color-mapping` 等子 skill 的区别: 那些展开单元素细法；本 skill 只列清单、不进细节，聚焦"哪 7 个 + 怎么逐个勾"。
- 与 `vis-viewpoint-first` 的区别: 视角决定"拍什么"，七元素决定"拍出来的画面由哪些零件构成"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列七元素自检表，逐项给本集默认值**
   - 完成标准: 输出 7 行表格（空间/线/形/影调/色/运动/节奏），每行至少一个明确选择（如"空间=有限封闭客厅；影调=暖亮"）。不允许留空——留空即违反 p05。

2. **核对"屏幕世界"与重点落点**
   - 完成标准: 确认下每个元素按二维错觉规则设计（非现实直觉），且至少标出 1 个"观众该看哪"的焦点落点（影调/色彩/位置）。
   - 判停条件: 若发现某元素"未决策/全靠自发"（如 g06 误用现实直觉、p05 真空），回到步骤 1 补该元素决策。

3. **标注经验法则边界，保留即兴空间**
   - 完成标准: 在表中注明哪些项是"硬规则"、哪些留作者 voice（避免 p06 的机械填表），并给出本集一处可即兴突破点。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只问"强度强还是弱的总开关" → 转 `vis-contrast-affinity`。
- 只问某一单一元素怎么调（如"本集空间选纵深还是平面"）→ 转对应子 skill（vis-space-four-types / vis-line-shape / vis-frame-aspect-ratio / vis-color-mapping / vis-tone-control / vis-movement-design / vis-rhythm-design）。
- 只问"看世界的角度/视角" → 转 `vis-viewpoint-first`。

### 作者在书中警告的失败模式

- **ce09（不控制=最差选择）**: 放任七元素自组织，结果偏离故事；每集必须有意定调，尤其"随便拍"最危险。
- **p05 违反（屏幕真空错觉）**: 以为留白/静止就能不管视觉，实则元素仍在反应，须逐项设计。
- **ce10（被直觉愚弄）**: 用"以前这样拍过"替代理性自检；卡壳时回七元素框架落地，别拿旧习惯当理由。

### 作者的盲点 / 时代局限
### 容易混淆的邻近方法论

- `vis-contrast-affinity`（易混：本 skill 是清单，对比相似是强度轴；常误以为"做完七元素=定完基调"其实还差强度）。
- `vis-story-visual-map`（七元素是单集静态清单，故事-视觉映射是把七元素随故事四段推进）。
