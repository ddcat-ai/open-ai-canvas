## I — 方法论骨架 (Interpretation)

色彩不是"好看就行"，布洛克把它拆成可拨的三个旋钮，外加一个冷暖轴：

- **三维 + 冷暖（fw10）**：色相（什么颜色）、亮度（明暗）、饱和度（纯不纯）；暖色（红橙黄）冷色（蓝绿青）。对比/相似可分别作用在三维度上。
- **饱和度对比＝焦点（p20）**：纯色夹灰，视线立刻被纯色钉住。这是最便宜的焦点术——让的亮色围巾/单品在灰调社区里成唯一饱和点。
- **反用俗套（p07/ce03）**：红=危险是低级把戏；高级用法是建立自有的"色彩-含义"关系。反套路正好用它——一身红却最安全，色彩错位强化反差喜剧。
- **互补色陷阱（ce13）**：互补色（红↔青）互混会互相去饱和直至变灰，想突出焦点时别让背景大面积铺互补色，否则画面发灰、焦点丢失。
- **冷暖非死律（ce14）**：品红随红蓝比例可暖可冷，别把"暖=好/亲、冷=坏/疏"当公式——冷色也能表达"被冷落"的反套路错位。
- **色彩延展度（g29）**：同色占多大面积决定视觉权重；给设专属色后，让这色常占足够面积强化主角地位。

落到：暖调基底（亲情）偶尔插冷色反套路场；饱和度上让成全剧最亮（饱和）的人。

## A1 — 书中的应用 (Past Application)

### 案例 1: 饱和度对比制造焦点（p20 论证）
- **问题**: 画面有多个物体，观众不知先看谁。
- **方法论的使用**: 作者指出纯色与非饱和色并置=饱和度对比，视线自然落在纯色上。
- **结论**: 想突出某物，让它比周围更饱和，而非更鲜艳花哨。
- **结果**: 成为"低成本焦点术"——亮单品在灰调中即焦点。

### 案例 2: 反用"红=危险"俗套（p07/ce03 论证）
- **问题**: 新手用红色贴"生气/危险"标签，陈旧低级。
- **方法论的使用**: 作者批评约定俗成联想是最没创造性的用法，主张自建色彩-含义关系。
- **结论**: 高级色彩是"作者定义"而非"文化默认"。
- **结果**: 支撑反套路——红围裙=安全温暖，错位喜剧。

### 案例 3: 《呼喊与细语》单色贯穿（c19 示范）
- **问题**: 如何用一个颜色撑起整片色彩结构。
- **方法论的使用**: 伯格曼整片基于红色明暗/饱和变化，而非多色拼贴。
- **结论**: 单色相的明暗/饱和变化即可构成整套色彩结构。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 本集定"暖调亲情"还是"冷色反套路场"（被冷落/智能设备蓝屏）。
2. 想让在灰调社区成视觉焦点（饱和度对比）。
3. 想打破色彩俗套——红衣却最安全、暖色却疏离等反套路错位。
4. 想给全剧/某集设专属色母题或控色彩延展度。

### 语言信号 (用户的话里出现这些就应激活)

- "这集冷暖怎么配，暖亲情还是冷反套路"
- "怎么让在灰背景里跳出来当焦点"
- "红=危险太俗了，能不能反着用"
- "全剧专属色母题怎么设，色彩延展度怎么控"
- "color / saturation focus / 饱和度对比 / warm-cool / anti-trope color"

### 与相邻 skill 的区分

- 与 `vis-tone-control` 的区别: 色彩管色相/冷暖/饱和度；影调管明暗灰阶。用户说"暗"若指明度低归本 skill（饱和度/明度维度），若指整体看不清归 tone-control。
- 与 `vis-contrast-affinity` 的区别: 对比相似是强度总阀；本 skill 是"色彩"这一元素的控法。
- 与 `vis-viewpoint-first` 的区别: 视角决定"为什么用这色"，色彩决定"具体怎么调"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定本集色彩基调（冷暖 + 饱和度策略）**
   - 完成标准: 输出本集主色相倾向（暖基底/冷反套路场）、冷暖比例，及饱和度策略（全片适度同饱和=统一，或局部高饱和=焦点）；注明避开互补色对冲（ce13）。

2. **用饱和度对比钉焦点 + 反用俗套**
   - 完成标准: 标出本集的"专属饱和点"（亮色单品），确保其在灰调中成唯一高饱和焦点（p20）；至少 1 处刻意反用色彩俗套（如红衣=安全）强化反套路。
   - 判停条件: 若发现焦点背景铺了大面积互补色导致发灰（ce13），回到步骤 1 调整背景色相。

3. **设专属色母题 + 控延展度**
   - 完成标准: 给出全剧/本集专属色（如暖橙）及其明暗/饱和变化方案（c19），并用延展度（g29）说明该色应占画面足够面积强化主角地位；给出一处可即兴突破点（见 B）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问的是"亮不亮/看清没"（明暗灰阶）→ 转 `vis-tone-control`。
- 用户问的是"强弱总开关" → 转 `vis-contrast-affinity`。
- 用户问的是"视角" → 转 `vis-viewpoint-first`。

### 作者在书中警告的失败模式

- **ce13（互补色乱加变灰）**: 想突出焦点时背景铺大面积互补色（红衣+青绿背景），二者互混去饱和直至变灰，焦点丢失。须避免互补色对冲。
- **ce14（暖冷机械二分）**: 把"暖=好/亲、冷=坏/疏"当死律——冷色也可用于"被子女冷落"的反套路情绪错位，别无脑暖调。
- **ce03（红=危险俗套）**: 直接套用色彩文化联想贴标签，低级且陈旧；应自建"色彩-含义"关系。

### 作者的盲点 / 时代局限
### 容易混淆的邻近方法论

- `vis-tone-control`（易混：明度低 vs 纯灰阶——饱和度/明度维度归本 skill，纯灰阶明暗归 tone-control）。
- `vis-contrast-affinity`（易混：把"做色彩对比"误当独立 skill，实则强度总阀归对比相似）。
