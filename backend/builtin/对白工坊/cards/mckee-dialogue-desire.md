## I — 方法论骨架 (Interpretation)

角色对白的能量不来自辞藻，来自欲望。麦基把"欲望"从一个模糊的词拆成五个嵌套维度：**欲望对象**（这一场他具体想得到什么）、**超意图**（他对自己、对世界更深层的意象）、**动机**（为什么非要不可，通常是连角色自己都未必意识到的深层需求）、**场景意图**（这场戏的战术目标）、**背景欲望**（制约他一生选择的大环境压力）。五维可以彼此矛盾——场景意图与超意图打架，正是复杂角色的来源。

欲望之后是"欲望如何变成台词"的完整链条：**行为五步**——欲望（要什么）→觉察对抗（什么挡住我）→选择（我决定采取什么行动）→行动（用言语还是肢体执行）→表达（把行动编成对白）。现实中人一瞬完成五步，写作必须逐环显影：哪一环缺失，台词就无根。写对白前先填五维、走五步，是对白与故事咬合的坐标轴；反过来，已写场景出问题，也常是某一环薄弱导致。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《黑道家族》梅菲诊所对峙——均衡冲突中的欲望五维
- **问题**: 托尼向心理医生梅菲求爱被拒的13拍场景，一场戏的价值如何从"医患友情"跌到"憎恶"？
- **方法论的使用**: 麦基逐拍标注托尼的行动（施展魅力/提出要求/宣称无辜/争取同情/坦白说出/逼她到墙角/自我怀疑）与梅菲的反应（做好面对麻烦的准备/笑他是傻子/避免冲突/责备他/拖延时间/轻蔑他/出拳）。欲望五维在此显形：托尼的欲望对象是梅菲，场景意图是赢得好感，超意图是逃避自我认知、证明自己值得被爱，而真正的动机深埋在潜文本里从不明说；梅菲的场景意图则是守住专业边界、不越界。
- **结论**: 每拍行动都由欲望驱动，行动/反应节拍不断叠加；最后第13拍颠覆了整个模式——托尼因目击证人夺门而出。托尼五次"OK"的重复反而在蓄积愤怒。
- **结果**: 13拍构成医患友情→憎恶、自欺→自觉、危机→生存的价值弧光，证明"每句台词之下都有欲望、意向和行动"这一公理可逐拍兑现。

### 案例 2: 《理查三世》引诱安妮——动机与借口的分层
- **问题**: 理查自称"因畸形无人爱所以作恶"——这个"动机"可信吗？
- **方法论的使用**: 用五维分层：理查嘴上说的"畸形所以作恶"只是**借口**（表面的合理化与自欺）；他的欲望对象是王位，动机是对权力的深层野心。写作时让角色用表面有意识的借口说得通，去隐藏潜意识的动机；同时他用"把剑递给我让你杀"的引诱行动主动追求欲望对象。
- **结论**: 借口与动机分离——角色说出口的理由（借口）用来让别人相信，驱动行为的深层需求（动机）埋在潜文本里；二者缺一不可。
- **结果**: 理查赢得安妮芳心，动机与行动相配使角色可信；反之若把借口当动机，作品就沦为"缺动机的过度表达"的通俗剧。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写一场戏之前，角色"要什么"还没想清楚。
2. 写完后角色行为突兀，被问"他为什么要这么做"。
3. 场景冲突单薄——两个角色没有真正撞上的欲望。
4. 情绪爆发显得廉价、像通俗剧（有情绪量、没动机质）。
5. 觉得角色只是"为剧情服务的工具人"。

### 语言信号 (用户的话里出现这些就应激活)

- "这个角色为什么这么做 / 动机不够 / 他到底想要什么" / "why would he do that", "motivation is weak", "what does he want"
- "这场戏没冲突 / 吵不起来 / 没有引擎" / "this scene has no conflict", "nothing drives the scene"
- "角色像工具人 / 行为很突兀" / "the character just serves the plot", "his behavior comes out of nowhere"
- "欲望 / 渴望 / 想要什么" / "desire", "want"
- "太夸张 / 像俗套戏 / 情绪来得没道理" / "melodramatic", "over the top"

### 与相邻 skill 的区分

- 与 `mckee-dialogue-as-action` 的区别: 那是公理——写/查每句台词时问"这句话在做什么行动"（乞求/拒绝/引诱）；本 skill 是引擎——写前问"角色要什么、什么挡路、他选做什么"，把欲望五维与行为五步填满。
- 与 `mckee-dialogue-beats` 的区别: 那是拆已有场景，用动名词标记每个节拍的潜文本行动；本 skill 在动笔前用欲望五维+行为五步生成场景的驱动内核。
- 与 `mckee-dialogue-clinic` 的区别: 那是拿六项任务/四类瑕疵给对白做体检；本 skill 正向深挖动机层——"借口vs动机"在此交叠，但本 skill 从欲望五维构建而非诊断。
- 与 `mckee-dialogue-in-character` 的区别: 那是解决"怎么写台词"（入戏产出），本 skill 解决"写之前角色要什么"（欲望坐标）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **填写欲望五维（对每个驱动场景的角色）**
   - 完成标准: 能写出欲望对象/超意图/动机/场景意图/背景欲望五个答案，并标注哪两个维度在彼此矛盾（矛盾处就是复杂角色的引擎）。
   - 判停条件: 若任一维度答不出、或答案与剧情设定冲突 → 说明角色/故事设计本身有病，先回故事层修（见 `mckee-dialogue-last-step`），不硬写。

2. **走行为五步，生成一次口语行动的完整链条**
   - 完成标准: 对角色的一次关键行动，依次作答"欲望→觉察对抗→选择→行动→表达"，得到这一步的台词内容与策略。
   - 判停条件: 若发现场景里"没有人挡住角色"（对抗环节为空）→ 场景没有冲突引擎，先设计对抗力量，再谈对白。

3. **核对动机与借口的分层，并逐句验证欲望驱动**
   - 完成标准: 角色嘴上说的理由（借口）≠ 驱动他的深层动机（埋在潜文本里）；能对每句台词说出"它由欲望五维中哪一层驱动、执行什么行动"。
   - 判停条件: 若某句台词只能答出"传信息/解释剧情" → 说明退回"讲出来"了，回到步骤 2 为这一拍重新选择行动。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 非写实主义作品（神话、歌舞、闹剧、动画）：可省略潜文本，角色目标直接即可，深挖五维是浪费。
- 喜剧角色：被"盲目痴迷"驱动、自我意识缺席，痴迷本身就是欲望，别再挖更深层的心理动机。
- 功能性过渡对话/寒暄场景：不值得对每句话都过五步。

### 作者在书中警告的失败模式

- **借口冒充动机**（ce12）：用童年创伤、性侵等"心理捷径"冒充驱动行为的深层需求，行为没有诚实的欲望支撑。
- **通俗剧缺动机**（ce13）：焦灼显得致命、挫折像悲剧，但动机缺席——问题不是过度表达，而是缺乏动机。
- **空洞的字眼**（ce08）：读者在潜文本里找不到角色的动机，台词空转、场景做作。
- **设计不良的场景**（ce22）：欲望没有撞上对抗 → 价值负荷不变 → 非事件，"这些谈话是干吗的"。
- **日常对话录音**（ce01）：没有欲望驱动的对白，只复制闲聊的表层重复。

### 作者的盲点 / 时代局限

- 欲望五维与麦基前作《故事》的"自觉/不自觉欲望"大量重复，本书真正新增的只有五维拆解与节拍动名词标记（阶段0批判#4）。
- 动机是潜意识的、不可直接观察，"动机写对了没"缺乏可验证标准；作者也承认潜文本诠释因人而异，却以自己标注的潜文本行动作为示范（批判#3）。
- 动机模型以欧美个体心理学为样本，对高语境/集体主义文化中的角色，欲望形态与表达方式可能需要转译（批判#1/#6）。
- 麦基一面说"本书不提供公式"，一面给出五步清单——行为五步是诊断/分析工具，不是每次写台词都要机械数五步的模板（批判#5）。

### 容易混淆的邻近方法论

- "动机"不等于"角色嘴上说的理由"——角色说出口的通常是借口，真动机埋潜文本。
- 行为五步是慢动作分析工具；现实中角色一瞬间完成，但写作者必须逐环显影，而不是把它当成要照搬的说话流程。
