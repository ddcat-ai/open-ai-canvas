## I — 方法论骨架 (Interpretation)

1. 人设 = 清晰自我认知 + 边界 + 主动负责，是沟通体系坐标（非包装）。
2. 边界捍卫：面对无善意言论直接顶回（"关你啥事"），护生活界限；表达讨厌/不借钱设清晰边界。
3. 适配策略：笨蛋状态分层（反应慢就重复确认）、屁股决定脑袋（看对方岗位诉求）。
4. 自我定位：四象限法（能力×态度等）、放弃型（价值排序100%/0）、反向从不要什么开始。
5. 刻板印象：态度抽离 + 用结果碾轧，非对抗全世界。
6. 坦诚面对自己：不欺骗，碰撞后反思，接受自己。

## A1 — 书中的应用 (Past Application)

### 案例 1: 饭局大姐催婚"关你啥事"（c09）
- **问题**: 不熟的人干涉私生活。
- **方法论的使用**: 无善意直接顶回，捍卫生活界限。
- **结论**: 沟通目的=共识非场面好看。
- **结果**: 把自己当回事儿，沟通才是一回事儿。

### 案例 2: 不借钱原则（c07）
- **问题**: 朋友借钱的两难。
- **方法论的使用**: 清晰原则——救急可送不借，额外需求不借。
- **结论**: 边界意识给说"不"的勇气。
- **结果**: 朋友知态度，少困扰。

### 案例 3: 放弃型离开经纪人（c22）
- **问题**: 目标转移却握着好牌。
- **方法论的使用**: 果断放弃，承受有形无形损失，清空迎新。
- **结论**: 不是100%就是0，清空不再符合新目标的东西。
- **结果**: 为迎接新目标腾位。

### 案例 4: 刻板印象用事实碾轧（c21）
- **问题**: 被贴"心机重"标签。
- **方法论的使用**: 态度抽离 + 用结果超越。
- **结论**: 不在意是结构问题，转注意力到事上。
- **结果**: 事实让对方知道客观成就不骗人。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **明确自我：优势 / 不要什么 / 价值排序**
   - 完成标准：用四象限、反向从不要什么、放弃型任一种定位，自我清晰。
2. **设边界：无善意直接顶回，清晰原则**
   - 完成标准：表达讨厌 / 不借钱 / "关你啥事"，边界被尊重。
3. **适配对象：按状态 / 岗位调策略**
   - 完成标准：笨蛋分层（重复确认）、屁股决定脑袋（看岗位诉求）。
4. **护自己：刻板印象抽离 + 结果碾轧，坦诚不欺骗**
   - 完成标准：不对抗全世界，用结果超越；碰撞后反思接受自己。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需协作的职场上下级关系硬顶：先评估权力差，弱势方优先保护自己。

### 作者在书中警告的失败模式

- ce08 情感绑架：用付出/牺牲做筹码站道德高点提要求。
- ce10 试图改所有人刻板印象：越解释越显不坦然，反向效果。
- ce11 一套方法对所有人：不变沟通方式给笨蛋机会犯同样错。

### 作者的盲点 / 时代局限

- 视角为老板/经纪人（上位）："顶回/设边界"对弱势方成本更高，优先保护自己；人设非包装是真实边界与责任。

### 容易混淆的邻近方法论

- 与"包装人设"混淆：本书人设 = 真实边界与责任，非虚假表演。
