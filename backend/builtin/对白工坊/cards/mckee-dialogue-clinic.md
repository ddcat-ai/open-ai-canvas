## I — 方法论骨架 (Interpretation)

把对白当病人，诊断分三层进行：

①**六项任务评分卡**：有效的对白必须同时完成六项任务——每个口语表达执行一个内在行动；行动／反应节拍推进场景至转折点；陈述和暗示传达信息与观点；独特口语风格个性化角色；进展节拍抓住注意力；对场景和角色保持虚构真实。六项任一断裂，就对应一类瑕疵，可做逐句对照的评分卡。

②**四类瑕疵定位（可信性层）**：空洞的字眼（潜文本里找不到动机，常见于角色互诉彼此已知之事）；过度滥情（语言强度远超真实情感，读者觉得歇斯底里）；过于明白（作者把超出角色认知的知识塞进角色自觉意识，像拧着角色耳朵耳语）；借口冒充动机（表层合理化没有深层需求支撑）。

③**语言与内容深查**：写在鼻子上（把潜文本写成文本，最普遍最具毁灭性）；动机vs借口（动机埋在潜文本里，文本讲的是借口）；八种干巴巴清单（写实在非抽象／写熟悉非陌生／写短字／写直接非迂回／写主动非被动／写短句／写有表现力非模仿／删多余词）。

最后是病根分级：若场景本身价值没变、转折点缺失，病在故事层，反复改写台词治不好生病的场景——先转结构分析，再回字词。

## A1 — 书中的应用 (Past Application)

### 案例 1: 烛光晚餐"写在鼻子上"场景（作者以演员视角重演）
- **问题**: 一场两人互说"我爱你"的烛光晚餐戏，为什么演不了？
- **方法论的使用**: 麦基以演员身份示范自救：先反问"他俩为什么需要点蜡烛？顺利时没人点蜡烛，有困难才点"。潜文本于是浮现——他是恐慌失去她而重燃爱火，或是设宴甩掉她。
- **结论**: 这句对白把潜文本写成了文本，抹杀了可演性；写实主义永远需要潜文本。
- **结果**: 证明"写在鼻子上"是结构性错误而非措辞问题；演员救戏靠"找潜文本"，作者应反向把它写回去。

### 案例 2: 《杯酒人生》迈尔斯与玛雅——写在鼻子上的反例改写
- **问题**: 迈尔斯谈Pinot、玛雅谈酒的生命，底下在做什么？直接告白可行吗？
- **方法论的使用**: 麦基拆出底下的行动是"吹嘘与承诺"——两人都努力用酒比喻自己（迈尔斯"皮薄、难长、需呵护"暗示自己需人照顾；玛雅"一瓶酒仿佛一个生命"暗示自己正值巅峰）。他写"写在鼻子上"版本（"我是难了解的男人""请睡我吧"）证明其不可演。
- **结论**: 没有人会把如此难为情的痛苦大声说出；正确做法是让角色借第三件事（酒）含蓄行动。
- **结果**: 行动藏在酒的语言里而非直白宣告，迈尔斯的退缩（去厕所）与玛雅伸手均由潜文本驱动——诊断"直白病"后给出"换第三者承载潜文本"的修法。

### 案例 3: 《理查三世》借口伪装成动机
- **问题**: 理查说自己"因畸形无人爱所以作恶"，可信吗？
- **方法论的使用**: 麦基区分动机与借口：畸形是自欺的借口，驱动他的是权力野心；他一面自称情圣，一面用"把剑递给我让你杀"引诱仇人之寡妻安妮，行动暴露真动机。
- **结论**: 借口是表面合理化，动机是驱动行为的深层需求，必须埋在潜文本里。
- **结果**: 证明"动机与行动平衡"决定角色可信度；借口滥用会沦为缺动机的通俗剧。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户贴一段对白说"读着别扭／假／出戏"但说不出原因，需要系统诊断。
2. 用户问"这段是不是写在鼻子上／太直白了？怎么改含蓄？"
3. 用户问"角色说的这个理由站得住吗？这是动机还是借口？"
4. 用户想用"六项任务"评审自己或他人的对白，产出评分卡。

### 语言信号 (用户的话里出现这些就应激活)

- "这段对白哪里不对""帮我诊断一下"
- "台词太直白／太满／太假／空泛／滥情"
- "写在鼻子上""on the nose""六项任务""借口"
- "diagnose this dialogue" / "why does this feel fake" / "on-the-nose"

### 与相邻 skill 的区分

- 与 `mckee-dialogue-beats` 的区别: beats 是中性结构分析（怎么拆节拍、价值怎么变）；本 skill 是下诊断开药方（哪里坏了、属于哪类瑕疵、怎么修）。clinic 的节拍相关项复用 beats 的产出。
- 与 `mckee-dialogue-as-action` 的区别: as-action 是公理（对白为什么是行动）；本 skill 用公理做体检——六项任务第1项"内在行动"即以言行事。
- 与角色声音类 skill 的区别: 那是对症"所有角色说话一样"的处方（怎么写出专属语言），本 skill 是通用诊断器，两者可串用但对象不同。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **用六项任务评分**
   - 完成标准: 逐句／逐拍对照六项任务（内在行动/节拍推进/传信息/个性化/抓注意/可信），每句标出违反哪几条，产出六项评分卡。

2. **用四类瑕疵＋写在鼻子上＋动机vs借口定位病根**
   - 完成标准: 明确诊断出主要瑕疵类型（空洞/滥情/过于明白/借口/写在鼻子上），并引用具体台词作证；能区分"这句话的动机（深层需求）"与"借口（表面合理化）"。
   - 判停条件: 若发现病根在故事层（价值没变／转折点缺失／分岔），说明这是结构问题，转介 `mckee-dialogue-beats` 处理场景设计，本 skill 只继续给字词层方向。

3. **用八种干巴巴清单检查语言层并给修改方向**
   - 完成标准: 输出诊断报告——病根层级（故事层/潜文本层/语言层）＋具体瑕疵类型＋每处 1-2 句改写示范＋"让潜文本回来"的具体方法（多暗示、用三边对话、让行动代替宣言、动机埋回去）。至少示范改写一处。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户想从头学写对白、理解原理——先看 `mckee-dialogue-as-action` 再回来。
- 用户只是要拆节拍画弧线、定位转折点——那是 `mckee-dialogue-beats`。
- 用户要生成角色专属词汇库／改造统一腔调——用角色声音类 skill。
- 用户问的是"这句该用悬疑句还是累积句"——那是台词三设计（句法层），归解说/技巧类。

### 作者在书中警告的失败模式

- 写在鼻子上：把潜文本写成文本，角色直白宣告全部所想所感（第8章，最普遍最具毁灭性）。
- 空洞的字眼：潜文本找不到动机，最常见的例子是角色互诉彼此已知的事，只为满足作者的信息焦虑（第6章）。
- 过度滥情：语言强度远超真实情感，读者觉得角色歇斯底里或作者小题大做（第6章）。
- 过于明白：作者把超出角色认知的知识放进角色自觉意识，观众觉得作者拧着角色耳朵耳语（第6章）。
- 借口冒充动机 / 通俗剧：用童年创伤等心理捷径冒充动机，行为没有深层需求支撑；通俗剧缺的不是表达而是动机（第6章）。
- 陈腔滥调 / 干巴巴语言 / 多余词：老套句子、多音节大词、小碎嘴当写实（第7章）。
- 改写的陷阱：把对白的问题误诊为字的问题，一遍遍重写台词，结果越改越直白、潜文本被抹掉（第9章）。

### 作者的盲点 / 时代局限

- "不要公式"与"给清单"自相矛盾：一面声明"本书不会提出对白写作的公式"，一面给出六项任务、八种清单、瑕疵对照表；从"美学判定靠直觉"到"按清单操作"的桥梁架得较薄。
- 潜文本诠释依赖文化背景与个体经验，诊断标准有主观性——作者承认"你可能跟我诠释得不同"，但全书仍以自己标注的潜文本行动作示范。
- 英语样本局限：八种干巴巴清单里的"多音节词／盎格鲁-撒克逊词 vs 拉丁词根"完全基于英语双语历史，对中文等非拉丁语系写作无法直接迁移。

### 容易混淆的邻近方法论

- 与"话痨就为眼睛写作"（场景话痨转影像）：那是处方（用静默/动作替代言语），本 skill 是诊断（先定位病再给方向）。
- 与"消灭法则/重复"：重复是设计瑕疵之一，归六项任务第2项（节拍推进）的检查范围，不必单开诊断。
