## I — 方法论骨架 (Interpretation)

1. 直接很重要，但突如其来会击溃对方情绪，使内容白费。
2. 三步缓冲：①奠定基调（声明"接下来是心里话，可能不好听"）②把决定权交给对方（狠还是柔由他选）③让对方做好准备（"接下来可能不好听，还要继续吗"）。
3. 预期管理 = 把"直接"设缓冲区，照顾对方情绪。
4. 对方怕的不是直接本身，是"毫无准备"。
5. 适用：批评 / 坏消息 / 拒绝 / 分歧——凡需承接情绪的内容。

## A1 — 书中的应用 (Past Application)

### 案例 1: 解雇谈话开场（2-03）
- **问题**: 炒下属鱿鱼原因都不好听，零交流走人伤人也埋雷。
- **方法论的使用**: "你是希望我狠一点，还是温柔一点？"给选择。
- **结论**: 几乎都选"来吧"——怕的不是直接，是无法准备。
- **结果**: 缓冲后直接被接住，内容精准传达。

### 案例 2: 李诞合作（c01）
- **问题**: 拒绝节目组多个要求又不破坏合作。
- **方法论的使用**: 每个拒绝附理由+替代方案，艺人统"被打破设想却同意"。
- **结论**: 预期管理+方案前置同框，对方有心理主动权。
- **结果**: 录制顺利，团队成长。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要给同事/下属负面反馈或绩效谈话。
2. 要拒绝一个请求或告知坏消息。
3. 要表达分歧但怕关系破裂。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么开口不伤人"
- "怕他崩溃 / 怕场面僵"
- "要不要先铺垫一下"

### 与相邻 skill 的区分

- 与 `yt-direct-clarity` 的区别：预期管理管"情绪缓冲"，直接管"内容精准无歧义"，两者串联（先缓冲再直接）。
- 与 `yt-own-the-error` 的区别：坏消息若属认错，本卡管缓冲、yt-own-the-error 管三步结构。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **开口先奠定基调**
   - 完成标准：声明"接下来是我心里话，可能不好听"，让对方知语言来自性格非恶意。
2. **把决定权交给对方**
   - 完成标准：问"你希望我狠一点还是温柔一点"，对方选后照办。
3. **让对方做好准备**
   - 完成标准：尖锐内容前提醒"接下来可能不好听，还要继续吗"，对方情绪未崩、内容已接收。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯利好消息、无需情绪承接的纯信息：过度铺垫反而怪异。
- 对方已明确"直接说别绕"：此时省去缓冲，直接给内容。

### 作者在书中警告的失败模式

- ce02 情绪武器：把预期管理反向用成"先说软话再捅刀"的伪装，用崩溃逼事——这是情绪武器，非预期管理。
- 把预期管理当"绕弯子"：绕弯=内容模糊，预期管理=内容仍直接只是设缓冲（见 yt-direct-clarity）。

### 作者的盲点 / 时代局限

- 视角为老板/经纪人（上位）：弱势方要"顶回"时未必有空间做预期管理，应优先保护自己（见 yt-persona-boundary）。

### 容易混淆的邻近方法论

- 与"委婉绕弯"混淆：预期管理保内容直接，只缓冲情绪；绕弯模糊内容，是反模式。

## 相关 skills

本卡是"直接"的缓冲层，常与 yt-direct-clarity 串联。

- **composes-with `yt-direct-clarity`**：先缓冲（本卡）再直接（内容精准），标准组合。

- **composes-with `yt-persona-boundary`**：边界捍卫常先奠定基调再直接顶回。
- **contrasts-with `yt-sincerity-boundary`**：真诚是说什么的底色，预期管理是怎么说尖锐的缓冲。
