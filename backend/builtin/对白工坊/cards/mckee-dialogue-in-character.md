## I — 方法论骨架 (Interpretation)

写"这个角色会怎么说话"，最容易犯两种错：一是站在角色外**猜测**——"如果我的角色在这种情况，他会说什么"，得到的台词像作者隔着玻璃观察；二是把自己**换成**角色——"如果是我会怎么做"，得到的台词其实是作者自己。正确姿势是把两者都否定掉，问一个三段式的问题："如果**我是这个角色**、处于**这种情况**，我会怎么办？"——前两个前提锁定角色的知识、个性、处境，最后"怎么办"则逼你以角色的身份做出行动决策。

这个方法的本质是"编剧做角色的第一个演员"：入戏的程度越深，越能听见角色自己的语言。声音（风格）不是刻意寻找的结果，而是你深挖角色处境、欲望、内容之后自然涌出的——"声音是结果而非选择"。操作流程通常是由外向内（先搜集角色背景/欲望）→由内向外（化身角色试写）→再由外向内（以读者身份复查）。技法上可以像狄更斯那样照镜子做鬼脸、低声念白，把角色的想法演出来再落到纸上。

## A1 — 书中的应用 (Past Application)

### 案例 1: 狄更斯照镜子——在角色内写作的示范
- **问题**: 写作时如何真正"成为"角色，而不是隔着屏幕猜他说话？
- **方法论的使用**: 麦基引用狄更斯女儿玛丽回忆父亲的写作场景——狄更斯会突然从椅中跳起冲到镜子前，脸上做出惊人扭曲，然后飞快回桌、用低沉声音快速念白，"完全蜕化成他的角色，在自然的张力中忘了环境，完全进入行动中"。
- **结论**: 这就是"如果魔法"的极端示范：先把自己变成角色，让角色的想法涌满脑海，再落到纸上；写完再从外向内、以读者身份重看一遍。
- **结果**: 狄更斯凭此法写出《雾都孤儿》《双城记》等传世角色；麦基由此论证"表演是写对白的最好训练"，编剧应是角色的第一个演员。

### 案例 2: 《神迹奇案》——从角色内听对方的台词
- **问题**: 修女院长与心理学家的对话，为什么麦基能判断出哪句该在句尾给对手留反应时机？
- **方法论的使用**: 麦基拆解时没有站在作者视角，而是**代入角色耳朵**听每句台词：先展示佩尔梅尔把核心字眼放在说白最后的版本（干净的提示节奏），再亲手改写把核心词移到句中——意义没变，但他以角色身份"听"出提示时机乱了，动作/反应会停停走走。
- **结论**: 在角色内写作也包括"以每个角色的耳朵听对方的台词"——体会一句话如何在对方心里开启一个反应节拍。
- **结果**: 这个对照实验证明：只有钻进角色内部去感受台词，才能判断时机与节奏是否成立。

### 案例 3: 《埃尔泽小姐》——62岁作者写19岁少女
- **问题**: 施尼茨勒一个62岁男性，如何写出19岁少女埃尔泽的内心独白？
- **方法论的使用**: 麦基指出作者靠的是在角色内写作：短句投射恐惧（"这酒店好大""山也是，大得吓人"，平均4.1词），长句是批判自我接管后的自我鞭笞（平均14.5词）——他先成为埃尔泽，再让那个"说话的自我"与"沉默的自我"对谈。
- **结论**: 角色与作者差异越大，越要靠入戏而不是靠"我猜他会说什么"；句长与情绪的对应（情绪使句短）是入戏后自然流出的结果。
- **结果**: 十四句话的自反性冲突令人信服，成为内在独白的经典示范。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 某个角色总是写不出来，或写出来像自己/像所有其他角色。
2. 角色与作者差异极大——异性、异代、异文化、反派。
3. 要写一段关键台词/独白，但不知道"他这种人"会怎么说。
4. 对白被批"不像这个角色说的""演员没法演"。
5. 想提升角色声音但不知从何入手（不愿停留在贴标签）。

### 语言信号 (用户的话里出现这些就应激活)

- "我不知道他会说什么 / 想不出这个角色的台词" / "what would he say", "I don't know how she'd speak"
- "所有角色说话都一样 / 像我自己" / "all my characters sound the same", "they all sound like me"
- "帮我以这个角色的口吻写 / 代入角色" / "write in character", "in his voice"
- "这个反派要怎么写才像他" / "write the villain", "get inside this character"
- "角色和我差别太大 / 我是男的写女角" / "too different from me"

### 与相邻 skill 的区分

- 与 `mckee-character-voice` 的区别: 那是"语言指纹"的配方——词汇命名知识、修饰语表达个性，产出的是档案和规则；本 skill 是"入戏"的动作程序——怎么让角色自己的话从内往外冒出来。
- 与 `mckee-dialogue-desire` 的区别: 那是定"角色要什么"（欲望五维），回答的是内容层；本 skill 回答"以什么姿态/方式写出来"，两者常衔接使用。
- 与 `mckee-dialogue-clinic` 的区别: 那是事后诊断（写在鼻子上、两人对话等瑕疵）；本 skill 是写作时的正向技法，不负责挑错。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **由外向内：搜集角色的身份资料**
   - 完成标准: 能写出该角色的知识范围（决定词汇）、个性与世界观（决定修饰语）、所属文化圈与处境（决定表达习惯），以及这一场的欲望对象。
   - 判停条件: 若欲望/处境没定 → 先用 `mckee-dialogue-desire` 填欲望五维，再入戏；资料不足就动笔只会产出作者腔。

2. **由内向外：用"如果魔法"化身角色试写**
   - 完成标准: 以"如果我是这个角色处于这种情况，我会怎么办"为唯一问句，先用第一人称写下角色内心念头（可低声念出、做表情），再据此改写为对白；产出的台词应明显区别于"我自己的话"和"别的角色的话"。
   - 判停条件: 若写出来仍是作者腔 → 停下来重读角色资料，找出"哪条背景我没真正接受"，回到步骤 1。

3. **由外向内：以读者身份复查**
   - 完成标准: 跳出角色，以观众身份重读一遍，核对三条——这句台词是否只属于这个角色（删掉角色名仍能辨认）、演员是否演得出来（是否有潜文本可演）、是否与声音"是结果"一致（没有为不同而不同）。
   - 判停条件: 若复查发现台词其实在为作者自己发声 → 删掉重写，禁止把作者观点塞进角色嘴里。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只需"语言指纹"的配方分析——那是 `mckee-character-voice` 的活。
- 场景已写坏、要诊断瑕疵——先走 `mckee-dialogue-clinic`。
- 作品是非写实主义（歌舞、闹剧、荒诞剧）：角色可以是符号/面具，"入戏"反而碍事。
- 时间紧张的功能性过渡对白：不值得逐句入戏。

### 作者在书中警告的失败模式

- **角色中立语言**（ce15）：所有角色说同一种通用腔，受惊都喊"噢，天哪"，普遍性取代特殊性——正是"站在角色外猜"的产物。
- **过于明白的谈话**（ce10）：作者把自己的知识塞进角色自觉意识，观众觉得"作者拧着角色的耳朵在耳语"。
- **过度感知的言论**（ce11）：角色自我剖析比弗洛伊德还深刻，自觉性强到不像真人——作者把二十倍的研究资料一股脑灌进角色。
- **内心独白谬误**（ce07）：长篇独白沦为作者哲学思想的传声筒。
- **雕琢的语言**（ce16）：为写作而写作，观众一察觉技巧就出戏。

### 作者的盲点 / 时代局限

- 以斯坦尼斯拉夫斯基表演传统为样板，"入戏"对不擅长表演、偏理性构思的作者并不天然适用，麦基未给出替代训练路径（阶段0批判#2：舞台/银幕导向）。
- "声音是结果而非选择"给出了方向，但如何判定"内容研究透了"缺乏客观标准，仍依赖个人直觉（批判#5：美学判定靠直觉与清单操作之间桥梁薄）。
- 狄更斯式"演出来再写"示范性强，但对只写不演的小说/剧本写作者可能难以照搬（批判#2）。

### 容易混淆的邻近方法论

- "在角色内写作"不是"换位思考/共情"——共情是理解对方，入戏是**以对方的身份行动**，要产出的是那个角色的决策与语言，不是作者的体谅。
- "声音是结果"不等于"放弃打磨语言"——是先深挖内容让声音自然涌现，再回头修饰，不是跳过技法。
