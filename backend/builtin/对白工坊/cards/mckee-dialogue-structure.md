## I — 方法论骨架 (Interpretation)

两人面对面直白谈困境的"两人对话"是结构性陷阱，几乎总写僵，解药是把对白从两人扩成三边：

1. **两人对话为什么僵**：两个角色直接、明确、感情外露地谈当下困境，每句都写在鼻子上、没有被保留的"不可说"——潜文本无处安放，台词成了信息的直白宣告，演员没法演。
2. **三边对话**：在直接冲突之外找到第三者——物、人、文化符号、象征、不在场的人——作为两个角色的争斗出口。角色借谈论/争夺第三者来暗示真实欲望，潜文本活起来。
3. **重复是编剧大敌**：两种重复最伤戏——意外的文字回声（近似措辞反复，读出来才听见）与重复的行动节拍（同样的价值负荷在节拍间反复，正面×N或负面×N）。重复节拍是坏场景的最早征兆，即使换词不改行动仍算重复。
4. **受控重复的例外**：偶有控制的重复可蓄积力量（如托尼五次"OK"层层递进的愤怒），但这是例外不是默认。
5. **自反性冲突**：内在对白/意识流里，角色解决危机的努力反而成为恶化危机的因，因变果、果变因，两个自我互为因果地攻守——这是内在冲突场景的结构引擎。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《角斗士》牢房场景——两人对话的标本
- **问题**: 露西亚与马克西姆斯在牢房面对面直白谈论谋杀、悲伤与政治同盟，每句都摊开（"我儿子是无辜的""我的儿子……也是"）。
- **方法论的使用**: 麦基指出这是"两人对话"的典型失败——没有第三者作出口，所有潜文本都被说破，句句写在鼻子上。
- **结论**: 面对面直白谈困境杀死可演性，应改写为三边对话，借第三者让潜文本有出口。
- **结果**: 观众被剥夺"透过表面看真人性"的乐趣，成为麦基口中的反面教材。

### 案例 2: 《腿》金丝雀——三边对话的正面解法
- **问题**: 黑帮夫妇杰克与爱丽丝的怨恨如果直白对吼就僵硬如砖，如何表达"我爱你有几分"的极致恨意？
- **方法论的使用**: 让两只金丝雀作第三者出口——爱丽丝扭断小鸟脖子"这就是我爱你有几分！"；杰克捏死另一只塞进她胸口"我也爱你！"。
- **结论**: 怨恨不靠直白控诉，而靠对第三者施暴显影；潜文本借第三者活起来。
- **结果**: "写在鼻子上"的僵硬被彻底解构，夫妻仇恨以极端动作爆发，成为三边对话的范例。

### 案例 3: "我得和你谈谈"——重复节拍的改写示范
- **问题**: 角色A三次求B听他说话，B三次拒绝，换词不改行动仍是同一"乞求/拒绝"节拍。
- **方法论的使用**: 麦基展示看似聪明的改写——把拒绝改成"你站在那里就让我不爽"、乞求改成"我又没烦你"——但指出换词不换行动，仍是同一节拍。
- **结论**: 重复节拍比意外文字重复更隐蔽更伤戏；必须让每一行动/反应节拍有所推进。
- **结果**: 证明"写得不好的场景最早征兆就是重复节拍"，解药是反复即兴直到找到真正推进的选择。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写两人对白戏（谈判/摊牌/争吵/谈心）发现直白僵硬、像砖头。
2. 想要潜文本活起来，但不知如何含蓄——需要"第三者"作争斗出口。
3. 一场戏反复改还是觉得死气沉沉、情感原地打转（怀疑重复节拍）。
4. 写内心独白/意识流，想要两个自我有结构的攻守（自反性冲突）。
5. 多人对白场景想引入第三方角色/物件，但不确定它是否成为真正的"出口"。

### 语言信号 (用户的话里出现这些就应激活)

- "两人对话太干/太直白" / "two-hander feels stiff / on the nose"
- "怎么让潜文本活起来 / 借个东西吵架" / "give the subtext an outlet"
- "这场戏是不是在重复" / "is this scene repeating itself"
- "三边对话 / 第三者 / 三角关系对白" / "three-way dialogue, third party as outlet"
- "内心两个自己在打架 / 自我冲突" / "reflexive conflict, inner war"

### 与相邻 skill 的区分

- 与 `mckee-dialogue-beats` 的区别: 节拍拆解是"分析"工具（把已有场景拆成动名词节拍）；本 skill 是"设计"工具（把两人对话重构为三边、消灭重复节拍）。
- 与 `mckee-dialogue-clinic` 的区别: 诊所诊断所有六项任务瑕疵；本 skill 只处理两个具体结构病——两人对话与重复节拍。
- 与 `mckee-character-voice` 的区别: 角色声音管"每个角色用什么词说话"；本 skill 管"对话整体如何组织、潜文本往哪放"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **诊断现状：标记两人对话与重复节拍**
   - 完成标准: 把场景拆成行动/反应节拍，逐拍写动名词；标出①面对面直白摊牌的句子②重复的节拍（同一动名词反复）③意外文字回声；输出一张"病灶清单"。
   - 判停条件: 若场景已是多人对话且无重复节拍、无直白摊牌，跳到步骤3检查自反性。

2. **三边化改写：引入第三者**
   - 完成标准: 为每个"写在鼻子上"的直白节拍指定一个第三者（物/人/符号/不在场者），把"我恨你"式直白改为"借对第三者施为"的行动；改写后朗读一遍，确认没有每句都自我宣告。
   - 判停条件: 若找不到自然的第三者，优先选"不在场的人"或"双方的共有物件"，而不是硬塞一个说话的新角色（那会变成普通多人戏）。

3. **清理重复 + 检查自反性/收束**
   - 完成标准: 消灭意外的文字回声；重复节拍要么改写为推进性行动，要么确认为"受控蓄力"（有明确的递进梯度）；若属内在对白，确认两个自我呈"因变果、果变因"的自反循环而非单方独白。
   - 判停条件: 若重复节拍全部删掉后场景没有转折点（价值负荷不变），说明病根在故事设计而非对白——转交 `mckee-dialogue-beats` / 故事层处理。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 非写实主义/闹剧：允许减少或省略潜文本，直接了当的对话可能是风格选择而非瑕疵。
- 单角色独白/旁白：没有第二方就没有"两人对话"问题；内心独白应查的是自反性冲突或"内心独白谬误"。
- 用户问的是角色声音或解说投放——那是 `mckee-character-voice` / `mckee-dialogue-exposition` 的领域。
- 群像/多人戏本来就是三边以上，不需要"改写成三边"——但重复节拍检查仍然适用。

### 作者在书中警告的失败模式

- 两人对话（ce06）：面对面直抒胸臆，"有砖头般的僵硬感"，潜文本与文本完全重合。
- 重复的节拍（ce19）："第一个冰淇淋好吃，第二个就没那么好吃，第三个就快吐了"——同价值负荷反复、回报递减，换词不改行动。
- 意外的回声（ce20）：相似措辞滑过视觉检查、一朗读就露馅（如《阿甘正传》"洞穴虾"）。
- 内心独白谬误（ce07）：长话无人打断、无价值转换，角色沦为作者传声筒——自反性冲突若没建成"两个自我互斗"结构就会退化成这种独白。
- 分岔的场景（ce23）：潜文本与正文本不合拍，内在想法与外在行为脱节。

### 作者的盲点 / 时代局限

- "两人对话必僵"主要基于欧美写实剧作；在日本动漫/漫才等非写实传统里，直白的双人对谈可以是风格，规则不可一刀切。
- 三边对话的"第三者"选择高度依赖文化符号库（金丝雀、酒、戈多），跨文化创作时第三者的承载能力需按目标文化重新选择，不能照搬西方案例。
- 与《故事》重复的"节拍/价值负荷"概念占了一半篇幅，本 skill 真正新增的只有三边对话与自反性冲突两个机制。

### 容易混淆的邻近方法论

- 三边对话 ≠ 单纯加一个说话角色：第三者是"出口"不是"发言者"，否则只是三人对话。
- 重复节拍 ≠ 简单的字词重复：前者是价值负荷不动，后者是文字回声；诊断方式不同（标动名词 vs 朗读听声）。
- 自反性冲突 ≠ 一般内心挣扎：必须呈"努力→恶化→更努力"的循环因果，而非单方向的内心描写。
