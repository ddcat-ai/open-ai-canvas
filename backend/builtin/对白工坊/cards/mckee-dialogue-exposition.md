## I — 方法论骨架 (Interpretation)

解说（Exposition）= 读者理解故事所需的事实信息，它的艺术不在"说什么"而在"何时放、怎么放"：

1. **两个投放通道二选一**：叙事驱动——靠求知欲，信息一点一滴泄露，读者向前追"后来呢"；如武器般呈现——靠情感共鸣，角色把已知信息当武器在关键时刻打出，观众因同理心震动。核心要求是信息"不被察觉地被接收"。
2. **最小释放原则**：只放出读者绝对需要知道的信息，绝不提前释放。给太少一头雾水，给太多"早猜到了"坐立难安；只提供能让好奇心和同理心存续的最少信息。
3. **台词三设计控制提示时机**：悬疑句（核心字眼置尾/掉尾句）最戏剧化，制造好奇与反应提示；累积句（核心字眼置首）自由会话化；平衡句（核心字眼居中）平和稳重。冲突越强越倾向悬疑句——把核心字眼留到说白末尾，让对手在该反应处获得提示。
4. **解说不是要删光，而是要藏好**：它是场景的"弹药"，重要事实在转折点前重复强调、次要事实轻描淡写。
5. **演出来，别讲出来**：让信息在可信场景的欲望冲突中自然泄出，而不是让角色停住长篇讲述一生。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《第二十二条军规》——叙事驱动的解说
- **问题**: 约塞连想搞清"第二十二条军规"这个循环陷阱规则，作者要把它解说给读者而不打断场景。
- **方法论的使用**: 海勒在戏剧化对白中插入一段非直接对白解释规则，但因它发生在同一场景、成为约塞连计划瓦解的转折点，用的是"演"而非"讲"——读者明白规则的瞬间，好奇心推动叙事驱动。
- **结论**: 解说不打断场景，反而成为场景的戏剧引擎。
- **结果**: 读者在解密瞬间被叙事驱动卷入，往前猜测角色能否逃出钳制。

### 案例 2: 《星球大战》"我是你的父亲"——如武器般呈现
- **问题**: 黑武士是卢克父亲这一事实，如果早交代就毫无力量，如何释放？
- **方法论的使用**: 卢卡斯把这个秘密压在潜文本里，到《帝国反击》光剑决斗高潮、卢克性命攸关时才用"我是你的父亲"当武器射出。
- **结论**: 靠情感共鸣而非求知欲投放信息；武器化的揭露未收服儿子，反而推动儿子走向终局。
- **结果**: 隐藏两集的事实瞬间震惊观众，成为三部曲最著名的场景，把情绪推向终集。

### 案例 3: 《灵欲春宵》——背景故事作为武器
- **问题**: 乔治与玛莎虚构造儿子填补婚姻空虚的真相，如何在剧终释放出最大冲击？
- **方法论的使用**: 阿尔比让乔治用一长段"电报来了、儿子死了"的戏码折磨玛莎，玛莎从否认到崩溃，最后乔治"我吞掉了"电报——秘密在两人两难中曝光。
- **结论**: 用背景故事作关键转折点，比平铺直叙的行动招致更大冲击。
- **结果**: 秘密曝光时刻价值翻转，成为全剧最有力量的转折，示范"如武器般呈现"的极致。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写开场/第一幕，担心背景交代生硬、开头拖着"解释性大肚子"。
2. 有必须透露给读者的秘密/身世/过去，不确定何时揭开。
3. 写完对白后发现角色在互诉彼此已知的事实（强行解说）。
4. 想让某句关键台词在关键时刻有冲击力（揭露/反转）。
5. 希望一场戏的节奏有悬疑感，但不知如何控制信息释放的量与时机。

### 语言信号 (用户的话里出现这些就应激活)

- "背景交代太生硬" / "exposition feels forced" / "info dump"
- "怎么把设定自然讲出来" / "how to reveal backstory naturally"
- "秘密什么时候让读者知道" / "when to reveal the secret"
- "这段解说太直白/像说明书" / "this explanation is too on the nose"
- "掉尾句 / 把关键放句尾 / 悬疑句" / "periodic sentence, suspense line"

### 与相邻 skill 的区分

- 与 `mckee-dialogue-clinic` 的区别: 诊所是对已写对白的全面瑕疵诊断；本 skill 是"信息何时/何地/如何投放"的生成策略。
- 与 `mckee-dialogue-as-action` 的区别: 以言行事管"每句台词底下的行动是什么"；本 skill 专管"事实信息"这一类内容如何投放。
- 与《故事》的 `mckee-exposition` 的区别: 那是媒介/故事层的信息管理（弹药化、秘密进度、兴趣三模式）；本 skill 落到对白的台词设计（最小释放+悬疑句置尾），是可与之组合的对白层工具。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出必知信息清单**
   - 完成标准: 列出观众理解当前场景/后续必需的事实信息，每条标注"绝对必要/可以省略/可以延迟"三级。
   - 判停条件: 若清单里"绝对必要"超过3条且都挤在同一场，判定为信息过载，需把部分信息挪走或删除。

2. **为每条信息选投放技巧**
   - 完成标准: 每条信息明确标注用"叙事驱动"（设计成一点滴泄露、吊好奇心）还是"如武器般呈现"（藏到关键时刻打出）；改写后每句解说都能说清"谁在什么冲突中带出这条信息"。
   - 判停条件: 若某条信息找不到冲突场景来承载，说明它不该由对白讲出——改用影像/行动或干脆删掉。

3. **用台词三设计打磨提示时机**
   - 完成标准: 关键信息的核心字眼落在说白末尾（悬疑句）；大声朗读一遍，确认每个核心词都在句尾、对手在该反应处获得提示；全段混合三种设计避免单调。
   - 判停条件: 若某句核心字眼过早出现导致对手只能干等，重组句式把它移到句尾。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 非写实主义（神话/科幻/歌舞/动画/闹剧）：允许减少或省略潜文本，解说可以更直白。
- 用户问的是角色声音个性化或两人对话结构问题——那些是 `mckee-character-voice` / `mckee-dialogue-structure` 的领域。
- 纯粹的故事层"秘密进度"规划（跨多幕的弹药化、兴趣三模式）——那是《故事》`mckee-exposition` 的范畴。
- 每场戏都要释放信息的剧集/连载长篇：节奏与时机粒度需按集重校准。

### 作者在书中警告的失败模式

- 强行解说（ce03）：角色互诉彼此已知的事实，"迫使角色互相诉说彼此已知的事实，使故事节奏像跳过高栏杆后，一股脑摔进煤灰"。
- 讲出来代替演出来（ce04）："强迫角色停住一切，花长时间讲述一生的所思所念所爱所恨"——角色沦为作者扬声器。
- 解说节奏失控（ce05）："给的资讯太少，他会一头雾水；给的资讯太多又会把他噎死"——太少噎死、太多呛死、太早"早猜到了"。
- 错失时机的意义与提示（ce21）：核心字眼位置错位——"太晚"观众先猜中或跳过，"太快"兴趣消靡。
- 空洞的字眼（ce08）：角色告诉另一人两人都已知的事，只为满足作者传信息的焦虑。

### 作者的盲点 / 时代局限

- 全书以欧美（尤其英语）语言为样本：台词三设计依赖英语句法与词序（关键名词的位置），中文的语序与句式更灵活，"核心字眼置尾"需按中文习惯转译而非照搬。
- "读者会本能跳过文本猜到潜文本"缺乏可验证标准，潜文本解读高度依赖文化背景与个体经验——不同读者对"早猜到了"的阈值差异极大。
- 与《故事》大量重复：弹药化、秘密进度等概念完全复用其前作，本 skill 真正新增的只有"最小释放+台词三设计"这些对白层细节。

### 容易混淆的邻近方法论

- 与《故事》`mckee-exposition`：一个管故事层信息流，一个管对白层信息投放，应组合而非二选一。
- 与"演出来别讲出来"（`mckee-dialogue-beats`）: 那是潜文本行动的组织；本 skill 是解说信息本身如何被释放。
- 与"写在鼻子上"（`mckee-dialogue-clinic`）: 那是把潜文本说破的结构性错误；本 skill 是防止解说沦为直白宣告的正面策略。
