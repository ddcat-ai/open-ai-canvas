## I — 方法论骨架 (Interpretation)

对白不是角色"说的话"，而是角色"以言行事"的动作——说就是做。任何一句台词，无论对别人说、对自己说、还是对读者／观众说，都是角色在潜文本里执行一个欲望驱动的行动：请求、拒绝、试探、威胁、引诱、安抚……所以写作或检查台词时永远先问"这句话在做什么"，而不是"这句话说什么"。

表达内容分三层：已说（说出口的文本）、未说（角色明知但只对自己说的）、不能说（角色自己都不觉察的潜意识冲动）。可用"三个同心球体"想象：最内层搅拌着说不出口的，中层控制着没说出来的，外层释放说出的话语。台词写得太满，往往就是把后两层压进了第一层。

由此推出：同样的内容换一条路径（对别人／对自己／对读者），语言的形态、措辞、声调、质地完全不同，需要三种完全不同的写法。先确定"这句话从哪条路径发出"，是分配语言资源的起点。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《格拉斯医生》同一内容三种写法
- **问题**: 同一个"梦如意识"的内心内容，该怎么写？
- **方法论的使用**: 麦基取瑟德尔贝里日记中同一段独白，保持原样写成文学性叙事对白（冗长累积句、与自我阴暗面争辩）；再改写成医生直接对读者说话（短句、指导性口吻）；最后改写成格拉斯与马克尔的舞台对白（循环式句子、一问一答引出潜文本）。三路径各写一遍。
- **结论**: 三种方法内容相同，但形态、措辞、声调、质地完全不同。
- **结果**: 证明对白必须依"说话对象与媒介"量身改写，不存在放之四海皆准的写法。

### 案例 2: 《穿Prada的女魔头》"再得个肠胃炎"的未说层
- **问题**: 一句"时尚圈玩笑话"为何比整个故事流传更广？
- **方法论的使用**: 麦基用三层结构拆解：艾米莉表面说体重玩笑（已说），读者本能跳过字面猜到"她愿为事业牺牲健康并告诫安迪"（未说），更深处是"时尚世界逼迫我过厌食症人生"的潜意识警告（不能说）。
- **结论**: 文本承载的少，潜文本承载的多。
- **结果**: 一句玩笑因字下暗流而流传更广，证明"读者会本能跳过文本猜到潜文本"。

### 案例 3: 四段名言的潜文本行动练习
- **问题**: 同样表达"厌恶"，为什么四段台词听起来完全不同？
- **方法论的使用**: 麦基把《麦克白》《卡萨布兰卡》《白鲸记》《宋飞正传》四句名言并置，逐句标出底下行动：谴责存在本身／悼念失去的爱／责怪上帝的力量／嘲弄政治正确。
- **结论**: "说话"与"采取行动"是两回事——台词下的动作才是角色的本真面目。
- **结果**: 训练"从台词读行动"的耳朵，证明以言行事能解释性格差异。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户贴出一段对白说"太平了／没味道／不像人话"，想理解为什么、怎么让角色真正"在做事"。
2. 用户在写或改某一句台词，问"这句该怎么说才不像是念台词"。
3. 用户疑惑"角色对自己说话算不算对白""内心独白要不要当对白写"。
4. 用户想入门麦基的"对白=行动"核心原理，需要世界观级的解释。

### 语言信号 (用户的话里出现这些就应激活)

- "这句台词好像没在做什么"
- "对白太直白／太像陈述／像念稿"
- "说即是做""对白是行动""以言行事"
- "dialogue as action" / "speech acts" / "what is this line doing"

### 与相邻 skill 的区分

- 与 `mckee-dialogue-beats` 的区别: beats 把场景切成行动／反应节拍、用动名词标记，是"怎么拆"的操作工具；本 skill 解释"为什么对白是行动"，是本质公理。用户问"怎么拆这场戏"用 beats，问"对白到底是什么"用本 skill。
- 与 `mckee-dialogue-clinic` 的区别: clinic 用六项任务＋四类瑕疵诊断"坏在哪、怎么修"；本 skill 回答"对白是什么、怎样才算一句真台词"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **把用户的对白逐句列出**
   - 完成标准: 每句台词单独成行，标注说话者；若用户没给完整场景，先让用户补齐关键上下文（谁对谁说、目的是什么）。

2. **对每句台词做"以言行事"三问**
   - 完成标准: ①从哪条路径发出（对别人／对自己／对读者）？②落在三层结构哪一层（已说／未说／不能说）？③在潜文本里执行什么行动（必须能用动名词回答，如"试探"而非"说话"）？每句都标出一个动名词行动。
   - 判停条件: 若用户只想快速改写某一句、不需要完整逐句分析，可直接跳到第 3 步只处理那一句。

3. **输出行动清单与改写**
   - 完成标准: 产出逐句"行动清单"（这句在做什么＋从哪层来）；对"找不到行动"或"全落在已说层"的句子，给出 1-2 种改写方向（换路径，或把未说/不能说层下沉回潜文本），并示范改写至少一句，说明改写后这句执行什么行动。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户需要的是喜剧场景写笑点、欲望五维深挖动机、角色专属词汇设计——这些由各自的 skill 覆盖，本 skill 只管"对白是行动"这一层。
- 用户明确要"诊断这段对白哪里坏了、列瑕疵清单"——那是 `mckee-dialogue-clinic` 的活。
- 用户要的是逐拍拆解场景弧线——用 `mckee-dialogue-beats`。

### 作者在书中警告的失败模式

- 把对白当日常对话录音：作者在公交车／飞机上偷听聊天，照抄下来就以为"写实"，结果台词像闲聊一样重复、空转、没有意义集中度（第6章可信性瑕疵）。
- 讲出来代替演出来：强迫角色停下一切，花长时间讲述一生的所思所念，角色沦为作者观点的扬声器（第2章）。

### 作者的盲点 / 时代局限

- "已说／未说／不能说"三分法的可操作性存疑：演员、读者对潜文本的解读高度依赖文化背景与个体经验，作者也承认"你可能跟我诠释得不同"，但全书仍以自己标注的潜文本行动作为方法示范。
- 舞台／银幕导向，文学分析多为与戏剧的对照存在，对长篇小说作者的实操指导相对单薄。
- 与《故事》大量重复："欲望驱动行动"的体系在其前作《故事》已建立；本书真正的新贡献是"以言行事"的言语行为视角。

### 容易混淆的邻近方法论

- 与行为五步骤（欲望→觉察对抗→选择→行动→表达）：那是单句台词的生成链，属 `mckee-dialogue-desire` 的动机引擎；本 skill 只落在"言语即行动"这一公理层。
- 与解说投放（演出来vs讲出来）：解说强调"信息怎么放"，本 skill 强调"任何言语都是行动"——解说技巧是本 skill 公理在信息投放上的一个应用。
