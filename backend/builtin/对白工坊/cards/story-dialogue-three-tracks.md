## I — 方法论骨架 (Interpretation)

对白最大的两个误解：一是让对白肩负本该由故事结构承担的重任（结果台词生硬、像在念说明），二是误以为"好的对白=真实的对话"（结果拖沓、平庸、词不达意）。

特鲁比的对白观是**精心挑选**：对白听起来可能真实，但必须比现实对话更聪颖、更机敏、更具隐喻意味、更具说服力；角色做错事也要错得比现实更振振有词。

出色的对白是**交响曲**，在三条音轨上同步发声：

1. **故事对白（旋律）**：角色在做什么、情节如何推进。
2. **道德对白（和声）**：行动的善恶、价值取向的论辩（对错之争）。
3. **关键词 / 口号（重奏 / 主导旋律）**：同一句子在故事中重复出现，每次被附加新意义，直到成为故事的标志式句子。

打磨流程如同画肖像逐层叠加：先写故事对白打底，再加道德对白加深，最后用关键词点睛。**潜台词**由此产生——角色说出的只是水面上的部分，观众能同时听见水面下的真实意图（"你是……"式的存在级对白能瞬间加深场景）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《教父》开场——婚礼场景的三音轨同奏
- **问题**: 如果开场只写"波纳萨拉求教父伸张正义"的情节，场景会又短又单薄。
- **方法论的使用**: 特鲁比逐字剖析开场场景，三音轨同时运行——故事对白（波纳萨拉女儿被殴的经过）、道德对白（公义/友谊/忠诚的辩驳）、关键词音轨（"教父""美国""尊重"）。场景以"教父"一词和"有一天——我会请你有所回报"收束，等于浮士德式与魔鬼订约。
- **结论**: "如果这个场景只包含故事对白（第一音轨），篇幅会只剩一半，质量则只剩十分之一。"
- **结果**: 成为全书的示范性场景；同时证明关键词必须落在倒三角的顶点。

### 案例 2: 《卡萨布兰卡》的口号——关键词音轨的累积机制
- **问题**: 主题（爱国者/友谊）不能靠角色喊出来，怎么让它在故事里自己长出来？
- **方法论的使用**: 口号（如瑞克的"我不会为任何人冒险"）在故事中多次重复，每次被附加新意义；当瑞克最终为伊尔莎和拉兹洛牺牲自己时，那句口号显露出他转变后的虚伪与成长。
- **结论**: 口号是"表达主题的一种技巧"，既界定角色的起点，也丈量出他的终点。
- **结果**: 与《教父》《星球大战》等口号并列为"可收入教科书"的例子。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户说"我的对白全是交代剧情""角色说话像在念说明书"——信息搬运型对白。
2. 用户想让角色"说一套、想一套"，台词要有潜台词 / 潜文本。
3. 用户觉得对白"像现实聊天一样平淡"，想更有锐度与说服力。
4. 用户想要一句能贯穿全片/全书的口号、金句，并让它逐步累积意义。
5. 用户想让某一场戏同时推进情节和主题（而不只是单调的对话）。

### 语言信号 (用户的话里出现这些就应激活)

- "对白""台词""对话" / "dialogue" "lines"
- "潜台词""言外之意""话里有话" / "subtext" "between the lines" "implication"
- "口号""金句""标志台词" / "slogan" "catchphrase" "signature line" "tagline"
- "太直白""像念说明""交代剧情" / "too on the nose" "expository" "info dump"
- "像真实对话""很自然但没劲" / "naturalistic" "realistic dialogue"

### 与相邻 skill 的区分

- 与 `story-scene-structure` 的区别: 场景 skill 决定"这个场景的顶点/关键句放在哪里"；本 skill 决定"台词本身怎么写、几层音轨"——一场戏里两者配合使用。
- 与 `story-revelation-sequence` 的区别: 揭露 skill 管理"何时揭晓什么信息"；本 skill 的潜台词是"说出来的话掩盖了未说的话"，是台词层的结构而非信息层的编排。
- 与 `story-moral-argument` 的区别: 道德论点 skill 构建整个故事的价值观论证序列；本 skill 的道德对白只是把这种论辩**落实进一场戏的和声层**。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **剥离对白不该承担的任务**
   - 通读目标对白段落，标出每一句"单纯在传递背景/剧情/主题"的信息；判断这些信息能否改由结构承担（场景编排、动作、情节推进）。
   - 完成标准: 列出"信息搬运句"清单，并注明每条信息可转移到结构上的位置；对白中不再有角色互相"念说明书"的段落。
   - 判停条件: 若用户只想在某一场戏里加潜台词、不改动全局，则完成本步对那一场戏的剥离即可进入步骤2。

2. **按三音轨分层重写**
   - 先确认故事对白（旋律）成立；再叠加道德对白（和声）——角色就该行动的对错/价值观论辩几句；最后埋入关键词/口号。
   - 完成标准: 每个目标场景至少有两轨在同时发声（旋律+和声或+关键词）；单轨对白（只有情节信息）的场景被明确指出并给出三音轨改写版本。

3. **检查潜台词与口号累积**
   - 检查每句台词是否有"角色没说出但观众能听见"的层面（尤其"你是……"式的存在级对白）；检查口号若多次出现，每次是否附上新意义并在结尾达到顶点。
   - 完成标准: 输出修改后的对白稿 + 一句说明：潜台词落在哪里、口号在哪些位置重复并各附上了什么新意义。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户在问"这场戏该不该存在、顺序怎么排"——那是 `story-scene-structure`。
- 用户在问"这个信息什么时候揭晓"——那是 `story-revelation-sequence` 或 `story-plot-22-steps`。
- 用户在打磨旁白、独白作为微型故事的整体结构（独白有七大步骤）——那是别的执行层问题，不是三音轨能覆盖的。

### 作者在书中警告的失败模式

- 误以为好对白=真实对话 → "人们误以为，好的对白就是真实的对话。"（第10章）拖沓、平庸、词不达意。
- 让对白肩负故事结构的任务 → "大部分作者让对白肩负重大任务，但那其实应该是故事结构的任务。其结果就是，对白听起来不自然、牵强或虚假。"（第10章）
- 用对白说出主角的领悟（说教） → "不要让主角站出来说明他学到了什么。这么做太刻意、太说教。"（第3章）

### 作者的盲点 / 时代局限

- "交响曲三音轨"依赖**语言本身的机敏与隐喻**——对依赖翻译/字幕/配音跨语言传播的作品，音轨效果会打折（关键词音轨尤其明显）。
- 幽默感、妙语、语言风格属于语言天才层面，作者自己也承认无法程序化；本 skill 能检查音轨，不能凭空制造语言天赋。
- 对白观以**美国电影/戏剧**的紧凑为标杆，对慢节奏、留白式、非言语交流为主的文化叙事（如某些东亚作品）适用度有限。

### 容易混淆的邻近方法论

- **独白 (monologue)**：独白可以是一个微型故事（含七大步骤），而三音轨主要针对双人/多人对话场景；独白结构问题不归本 skill。
- **真实的对话记录**：采访实录、纪录片台词不是本 skill 的对象——本 skill 面向虚构叙事。
- **语言风格塑造**：让角色"有口癖/方言/说话方式"属于角色个性化，与本 skill 的音轨分层是两回事。
