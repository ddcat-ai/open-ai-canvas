## I — 方法论骨架 (Interpretation)

1. 每个角色分配一套"话语来源系统"（公文体／推销体／少儿宣传口号／市井泼辣），而非仅一套性格形容词。
2. 声口要在全剧高频复现，把角色语言"焊死"到可预测；可预测性不是缺陷而是资产。
3. 系统数 ≤ 角色数，一人只占一格；若两人抢同一格即"声口失焦"。
4. 声口的能量来自"读者能预判角色反应"，反差由预判落空自动产生。
5. 撑不住的声口（如硬凹深沉）会当场塌房，反向证明机制成立。

## A1 — 书中的应用 (Past Application)

### 案例 1: 傅老机关腔（第1集）
- **问题**: 如何让离退休老干部一开口即被辨认。
- **方法论的使用**: 分配"机关公文系统"——"退居二线当顾问""主持日常工作"。
- **结论**: 观众依此预判其每句话的体制腔。
- **结果**: 全剧贯穿，声口成为笑点地基。

### 案例 2: 志新吹牛腔（第1集）
- **问题**: 闲散二叔如何与傅老区分。
- **方法论的使用**: 分配"商业吹牛系统"——"挂两个单位、兼三个公司副总"。
- **结论**: 与傅老公文体正交，互不重叠。
- **结果**: 两人声口不混淆，反差自动成立。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写群像小说／剧本，读者反映"分不清谁在说话"。
2. 做多人播客／访谈脚本，想让每角色有辨识度。
3. 给虚拟角色／AI 配置稳定的说话风格。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么让角色一开口就被认出来"
- "几个人的对话老混在一起"
- "想给角色设计一个口头禅／固定句式"

### 与相邻 skill 的区分

- 与 `wojia-persona-contrast` 的区别：声口复用管"怎么说（语言商标）"，人设反差管"身份落差带来的冲突"，两者正交互补。
- 与 `wojia-bureaucratic-mismatch` 的区别：官腔错位管"语域降维"单一机制，声口复用管全角色语言系统的分配。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出角色并分配话语系统**
   - 完成标准：每个角色有专属系统，且两两不撞（系统间正交）。

2. **提炼标志性句式并首次落定**
   - 完成标准：每套系统有 1–2 个标志性句式／词汇，读者读完第一幕能预判该角色下次开口。

3. **全稿通查绑定唯一性**
   - 完成标准：扫完全文无"两人抢同一格（声口失焦）"；发现即重分配。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单人独白或纯信息说明文：无"谁在说"的辨识需求，声口机制无意义。
- 一次性出场角色：不值得分配专属系统。

### 作者在书中警告的失败模式

- ce03 声口失焦：两个角色共用同一话语系统，读者无法区分，反差消失。
- ce01 硬挠笑点：为搞笑强行给角色塞夸张口头禅，角色不自觉则笑点死。
- ce08 冗长铺垫：为立声口堆砌过多前戏，节奏拖垮。

### 作者的盲点 / 时代局限

- 台词本剥离表演后，纯台词笑点折损，声口不能直接当"搞笑配方"抄。
- 部分性别设定（女性多承担泼辣媳妇／保姆功能）带当时旧视角，复用需当代化。

### 容易混淆的邻近方法论

- 与"口头禅堆叠"混淆：口头禅是声口的子集，本机制要求的是整条话语来源系统的正交切分。
