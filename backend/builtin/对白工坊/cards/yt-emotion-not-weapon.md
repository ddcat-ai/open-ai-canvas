## I — 方法论骨架 (Interpretation)

1. 共情 = 情理（理解立场）非情绪（武器）；把对方放同侧，而非当敌人。
2. 纯情绪沟通 = 树洞 / 站队机器：倾听、说"我理解你"，无需建议。
3. 压力双源：直接源（某人施压）四步——自我预警 / 直接叫停 / 理清共识 / 寻求帮助；间接源（无形系统）三步自我沟通——会改吗 / 换方式还在吗 / 如何与相关方共识。
4. 情绪武器低级、易免疫、降实质内容。
5. 共情不意味无限承接对方情绪，需设自身边界（防情感绑架 ce08）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 狼人杀"贴脸"禁（c13）
- **问题**: 把情绪当武器（"拿人格担保我不是狼"）被禁。
- **方法论的使用**: 现实谈判哭诉、老板佯怒逼事，均属情绪武器。
- **结论**: 短期胜、长期建"情绪不稳"印象、周围人免疫。
- **结果**: 非共情，把对象当敌人。

### 案例 2: "多喝热水"无效安慰（c14）
- **问题**: 纯情绪问题给道理/建议。
- **方法论的使用**: 委屈加倍，对方觉不被理解。
- **结论**: 应做树洞，非说教者。
- **结果**: 先让情绪流出来，理性才回得来。

### 案例 3: 压力假眼球（4-04）
- **问题**: 无形系统施压（热搜误解），无处喊冤。
- **方法论的使用**: 自我沟通三步——问"会改吗/换方式还在吗/如何共识"，三天晒太阳能深度思考。
- **结论**: 间接压力源靠自我沟通疏解。
- **结果**: 沟通是解压良药，非捏假眼球。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 对方情绪激动，需要安慰而非建议。
2. 自己被施压，需要解压策略。
3. 想区分"共情"与"被情绪拖垮"。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么安慰人"
- "对方又崩了 / 我好累"
- "压力好大怎么办"

### 与相邻 skill 的区分

- 与 `yt-own-the-error` 的区别：道歉是修复（态度+自因+方案），本卡管情绪承接非武器。
- 与 `yt-direct-clarity` 的区别：纯情绪时不宜给指令，先树洞再谈内容。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别对方是纯情绪还是求方案**
   - 完成标准：纯情绪做树洞（倾听+"我理解你"），不急着给方案。
2. **共情 = 站对方立场理解，非承接情绪当武器**
   - 完成标准：把对方放同侧，理解其情理。
3. **直接压力源：自我预警 → 直接叫停 → 理清共识 → 寻求帮助**
   - 完成标准：明确告知"请别施压，否则我动作变形"。
4. **间接压力源：自我沟通三步**
   - 完成标准：问"会改吗 / 换方式还在吗 / 如何与相关方共识"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需决策 / 方案的纯事务场景：纯情绪模式拖延，先树洞再另约时间谈实质。

### 作者在书中警告的失败模式

- ce02 情绪武器：贴脸 / 崩溃逼事，短期胜长期建"情绪不稳"印象。
- ce08 情感绑架：共情被误用为无限承接，需设自身边界防被情绪消耗（见 yt-persona-boundary）。

### 作者的盲点 / 时代局限

- 共情不意味讨好或无限承接；弱势方优先设自身边界，防被情绪耗尽。

### 容易混淆的邻近方法论

- 与"安慰情绪"混淆：本书共情 = 立场理解（情理），非单纯哄情绪。
