## I — 方法论骨架 (Interpretation)

新手最大的直觉错误是"对白写不好→改对白"。麦基的诊断恰恰相反：**对白的毛病通常是故事的毛病**。场景失效时，根源多在事件与角色设计——价值没变、转折点缺失、动机缺席——而非字词。一遍遍重写台词，只会越写越直白、把潜文本磨光，戏更糟。

因此正确的写作次序是**自下而上**：先有故事层（诱发事件、欲望、对抗、转折点、节拍），再设计潜文本层（动机、策略），最后才写文本——文本只是"一层又一层潜文本上的糖霜"。除非你知道自己在说什么，否则无法知道角色会怎么说话。

这个 skill 还打包三个配套工具：**创作限制原理**（给自己设美学困境——限定词汇、句法、潜文本浓度——用限制逼出原创，无限制自由反而懒散）；**喜剧四技巧**（清晰/夸张/时机/不协调，喜剧对白最后打磨时的检查清单）；**关键问题清单**（写作前/中/后各从每个角色视点问一遍背景欲望、欲望对象、场景意图、动机、对抗、价值、潜文本、节拍、转折点等，是"从直觉到清单操作"的桥梁）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《杯酒人生》迈尔斯与玛雅——先定潜文本，再写文本
- **问题**: 迈尔斯谈Pinot、玛雅谈酒的生命，潜文本下他们真正在做什么？
- **方法论的使用**: 麦基先写了一个"写在鼻子上"的版本（"我是难了解的男人""请睡我吧"），证明它不可演；再展示正确做法——先确定潜文本行动：迈尔斯在**吹嘘**（用酒比喻自己"皮薄、难长、需呵护"，暗示自己需要被照顾），玛雅在**承诺**（用"一瓶酒仿佛一个生命"暗示自己正值巅峰）。
- **结论**: 对白不是先想好台词，而是先想好"角色在潜文本里做什么"，再用酒（第三者）含蓄地承载这个行动。
- **结果**: 迈尔斯借酒吹嘘、玛雅借酒承诺，两个角色用谈酒完成一场引诱——文本漂亮是因为底下潜文本先成立了。

### 案例 2: 《战略高手》警匪对话——先写坏版本做反证
- **问题**: 警匪调情怎么写才不落入"写在鼻子上"？
- **方法论的使用**: 麦基先自写一段坏对白（"我很困扰和害怕""我怕你会强暴我"）宣告其平庸，再展示伦纳德的写法并拆出六层：环境意象、熟悉情境意象、现实逃逸、回忆、禁忌欲望的潜文本、白日梦。好版本是**先搭潜文本层（六层意象）再落字**，还用了两个第三者（《秃鹰72小时》与初见回忆）构成三边对话。
- **结论**: 同一场戏，坏版本与好版本的差别不在文采，在潜文本层有没有先设计好。
- **结果**: 六层意象让一句闲谈承载整场悬疑（会相爱吗？会逮捕吗？），且"没人可以说出口之后还能保有暧昧"。

### 案例 3: 重复节拍"我得和你谈谈"——改台词救不了场景
- **问题**: A三次求B听他说话，B三次拒绝，怎么改？
- **方法论的使用**: 麦基先展示"看似聪明"的改写——换同义字、扭转行动/反应——然后指出：换词不换行动，仍是同一个"乞求/拒绝"节拍，没有推进。病根在节拍层（故事设计），不在字句层。
- **结论**: 无效重写台词治不好生病的角色和事件；必须先让行动/反应节拍真正推进，再谈文字。
- **结果**: 解药是反复即兴打磨直到找到真正推进的完美选择，而不是换词——这正说明"对白是最后一步"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一段对白改了很多遍还是不满意，甚至越改越差。
2. 台词单个看起来漂亮，但整场戏"没戏""没发生什么"。
3. 写作流程迷茫：该先写对白还是先搭结构/角色/潜文本。
4. 反复修改后对白变得直白、写在鼻子上，但不知道病根。
5. 要打磨喜剧对白，或想用一套清单系统性地检查自己的场景。

### 语言信号 (用户的话里出现这些就应激活)

- "这段对白改了很多遍还是不行 / 越改越糟" / "I've rewritten this dialogue many times", "it keeps getting worse"
- "台词挺好但场景没戏 / 没发生什么" / "the scene has nothing happening", "lines are fine but the scene is dead"
- "先写对白还是先搭结构 / 写作顺序" / "write dialogue first or structure first", "order of writing"
- "对白写不好是不是故事有问题 / 改台词救不了" / "is it the story", "rewriting lines won't fix it"
- "喜剧对白怎么写 / 关键问题清单 / 创作限制" / "comedy dialogue", "constraints", "question checklist"

### 与相邻 skill 的区分

- 与 `mckee-dialogue-clinic` 的区别: 那是拿六项任务/四类瑕疵**诊断**具体对白哪里不对；本 skill 是**工作次序**——诊断后告诉你该修故事层/潜文本层而不是磨字句。
- 与 `mckee-dialogue-beats` 的区别: 那是把已有场景**拆成节拍**找推进问题；本 skill 规定"节拍属于故事层，必须在对白之前修好"，是更上游的流程原则。
- 与 `mckee-dialogue-desire` 的区别: 那是填满欲望五维驱动对白；本 skill 把"欲望/对抗/价值"当作"写对白前必须先完成的故事层清单"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先查故事层（用关键问题清单前半段）**
   - 完成标准: 对场景能答出背景欲望、欲望对象、场景意图、动机、对抗力量、场景价值（开场正/负）、转折点位置；确认节拍由行动/反应构成且价值有变化。
   - 判停条件: 若发现价值不变（非事件）、无转折点、或动机缺席 → 停止动文本，先回故事层改设计（场景/节拍），完成后再进入步骤 2。

2. **再查潜文本层（每拍标出"真正的行动"）**
   - 完成标准: 用动名词给每个节拍标出潜文本行动与策略，确认动机埋在潜文本里、文本留有余地（不是写在鼻子上）。
   - 判停条件: 若发现潜文本与文本重合（直白）或脱节（分岔的场景）→ 先补潜文本或调正文本关系，仍不落字。

3. **最后才写/润色文本，并用限制+喜剧技巧+清单收尾**
   - 完成标准: 落字时主动设创作限制（限定词汇范围、句法、潜文本浓度）；若为喜剧场景用清晰/夸张/时机/不协调四技巧逐项核对；写完后用关键问题清单从每个角色视点复查一遍，确认改动没有破坏上面两层。
   - 判停条件: 若文本越写越"写在鼻子上"（潜文本被磨掉）→ 立即停下，回步骤 2 检查潜文本是否还在。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只是要单句润色/换个说法——那是表达层的轻量任务，不必走完整流程。
- 非写实主义作品（歌舞、闹剧、荒诞剧）：允许并期待把话说在明面上，"糖霜"可以没有下面的蛋糕层。
- 用户已明确是"句子不好听"的语言问题——先诊断再决定是否需要本 skill。

### 作者在书中警告的失败模式

- **改写的陷阱**（ce24）：新手老以为困难来自"字"，一遍遍改写错误对白，越改越直白、潜文本没了——场景失效时病根在事件与角色设计。
- **设计不良的场景**（ce22）：转折点太早/太晚/不出现，价值负荷不变，对白写得再好也是非事件。
- **分岔的场景**（ce23）：驱动潜文本与正文本不合拍，内在与外在脱节，戏不对劲。
- **写在鼻子上**（ce02）：把潜文本写成文本，角色全盘直白宣告——往往是过度改写的终点。
- **俚俗化掩盖无能**（ce25）：用大量脏话俚语掩盖无戏，字多≠戏热。

### 作者的盲点 / 时代局限

- 麦基一面说"本书不会提出公式"，一面给出五步流程+关键问题清单——从"美学判定靠直觉"到"按清单操作"之间的桥梁架得较薄，清单可能被机械执行（阶段0批判#5）。
- "对白是最后一步"是规范性理想，对以对白为第一驱动的先锋派/纯语言戏剧（如部分贝克特风格作品）未必成立（批判#2 舞台/银幕导向）。
- 潜文本的解读高度依赖文化背景与个体经验，"潜文本对了没"缺乏客观标准（批判#3）；喜剧四技巧也以特定西方幽默传统为样本（批判#6）。
- 创作限制原理与《故事》前作大量重复，理论独立性偏弱（批判#4）。

### 容易混淆的邻近方法论

- "对白是最后一步"≠"对白不重要"——它是最表面的糖霜，但正是读者最先尝到的一层。
- 创作限制≠"故意写难"——限制是为了激发想象力的**美学困境**，不是自我折磨的仪式。
- 关键问题清单≠填表交差——每次都要**从每个角色视点**问一遍，答案彼此咬合才算过关。
