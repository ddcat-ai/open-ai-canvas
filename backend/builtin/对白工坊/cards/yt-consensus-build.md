## I — 方法论骨架 (Interpretation)

1. 共识多维拆解：时间维度（拉长时间）/ 同行惯例（横向参照）/ 解决方案（具体可执行）。
2. "我们是一边的"锚：把多方化简成"我们 vs 他们"两方，从共同利益找最优。
3. "都是为我们好"对齐：共识须双方互动，起点终点都同意，非单方"为你好"。
4. 别让对错毁沟通：对错造封闭判断、源自信息差、阻止可能性。
5. 共识 = 互相淘汰 / 挑选：不强行洗脑，提供尝试可能。

## A1 — 书中的应用 (Past Application)

### 案例 1: 杂志封面广告语三维度（c17）
- **问题**: 广告语必毁封面，广告商话语权绝对。
- **方法论的使用**: 时间（十年后还正确吗）/ 同行（参照同水准杂志）/ 方案（透明封皮独立印广告）。
- **结论**: 小共识累积落地。
- **结果**: 各方都满意，经典封面保住。

### 案例 2: 演唱会多方平衡（c18）
- **问题**: 艺人/唱片/经纪/粉丝多方诉求冲突。
- **方法论的使用**: 梳诉求 → 拆关键目标平衡 → 定总基调（内容传播品宣）。
- **结论**: 首巡三场北京上海广州 + VR演唱会 + 粉丝套餐。
- **结果**: 多方合力。

### 案例 3: 离职谈话四步（c19）
- **问题**: "开除"单方碾轧伤感情。
- **方法论的使用**: 分析 → 拉时间维度找人生目标 → 共识大方向 → 给建议。
- **结论**: 让对方自得"该换工作"结论。
- **结果**: 体面高效。

### 案例 4: 大码女装互相淘汰（c20）
- **问题**: 产品选用户也被用户淘汰。
- **方法论的使用**: 不强行洗脑，提供尝试可能。
- **结论**: 共识 = 相互挑选。
- **结果**: 离开的注定离开，回来的会重逢。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **从最终目标反向拆小共识（时间/同行/方案三维）**
   - 完成标准：先达成阶段小共识，再累积大共识。
2. **建"我们是一边的"锚**
   - 完成标准：把多方化简成"我们 vs 他们"两方，从共同利益找最优。
3. **用"都是为我们好"替代"为你好"**
   - 完成标准：双方共坦诚、共思考、共表达，起点终点都同意。
4. **抓核心需求、需求切细点，避对错对立**
   - 完成标准：问"您一定要的"，把需求切成具体点。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 原则性根本对立（价值观冲突）：强行共识无意义，先尊重差异。

### 作者在书中警告的失败模式

- ce07 用对错制造对立：防盗门猛关阻断渠道。
- ce09 "都是为你好"认知偏差：单方立场炫耀理解、冒犯对方。

### 作者的盲点 / 时代局限

- 视角为老板/经纪人（上位）：弱势方在共识中易被"我们"裹挟，需评估是否真共赢，警惕被裹胁。

### 容易混淆的邻近方法论

- 与"一味求同"混淆：本书共识含互相淘汰，非所有人都留下。
