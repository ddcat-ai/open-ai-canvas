## I — 方法论骨架 (Interpretation)

节拍（beat）是场景中一个"行动＋反应"的最小单位，是场景设计的原子。行动展开节拍，反应结束节拍；理想情况下每拍盖在上一拍上并导向下一拍，直到价值负荷在转折点翻转。

标记法：把每句台词的潜文本行动写成动名词——A"恳求"，B"拒绝"，这轮交换就是"恳求／拒绝"。要点是标"行动"而非"行为"：说话、打牌、吃冰激凌只是表面行为；潜文本里真正在做的事（安抚、警告、试探、犒赏自己）才是行动，且必须用动名词表述。这个动作强制你看见文本之下在发生什么。

节拍有三大用途：①暴露重复节拍——同一动名词反复出现（乞求／拒绝连来三次），说明价值原地踏步、戏在空转，就算换词换句也一样；②定位转折点——转折点只能由"行动"或"揭露"二者之一创造，对白可以表达行动（"我要永远地离开了"）或信息（"我是为了钱才和你结婚的"）；③诊断非事件——一场戏若价值负荷从头到尾没变，只是充满信息泄露的"非事件"，连续非事件会拖垮故事。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《黑道家族》梅菲诊所对峙——13拍均衡冲突拆解
- **问题**: 一场医患求爱被拒的戏，怎么逐拍看清它如何推进、为何有力？
- **方法论的使用**: 麦基逐拍标注托尼的行动（施展魅力／提出要求／宣称无辜／争取同情／坦白说出／逼她到墙角／自我怀疑）与梅菲的反应（笑他是傻子／避免冲突／责备他／拖延时间／轻蔑他／出拳），并记录内容、长度、节奏的不对称（托尼句子不超十字，梅菲句子长达二十五字）。
- **结论**: 前12拍是"托尼行动／梅菲反应"的均衡拉锯，第13拍颠覆模式，托尼夺门而出。
- **结果**: 13拍构成完整价值弧光（医患友情→憎恶、自欺→自觉、危机→生存）；托尼五次"OK"的受控重复反而蓄积愤怒——重复不全是坏事。

### 案例 2: 重复节拍"我得和你谈谈"（作者示范改写）
- **问题**: 角色A三次求B听他说话，B三次拒绝——作者重写换词后还是没推进，为什么？
- **方法论的使用**: 麦基先展示原版"谈谈／听／听"对"离我远点／让我走／走开"，再展示看似聪明的改写（把拒绝改成"你站在那里就让我不爽"、乞求改成"我又没烦你"）。
- **结论**: 换词不换行动，仍是同一个"乞求／拒绝"节拍，没有推进。
- **结果**: 证明用动名词标记才能揪出"伪装成新对白的重复节拍"；解药是反复即兴打磨，直到找到真正推进的完美选择。

### 案例 3: 《日光下的葡萄干》早餐桌——16拍不对称冲突双转折点
- **问题**: 一场16拍的家常早餐戏，凭什么架构整部戏？
- **方法论的使用**: 麦基逐拍拆解沃尔特·李（邀约、坚持、责怪、引诱、证明、指责）与露丝（忽略、躲藏、投降、安抚、撤退）的行动/反应，并标出两个转折点——"那不是我们的钱"（道德大锤粉碎酒铺计划）与"有色男人中也有人做出事情"（逼沃尔特承担失败）。
- **结论**: 转折点只能由行动或揭露创造，且要放在准确位置（前置反高潮、后置观众早猜到、缺席成非事件）。
- **结果**: 16拍让希望→绝望、安全→危险、自我尊严→自我憎恨的价值全程翻转，并为全剧弧光埋线。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户有一场戏觉得"推不动／重复／拖沓"，想逐拍找出卡点。
2. 用户想知道一场戏的弧线：价值怎么变、转折点在哪、由什么创造。
3. 用户问"这句台词潜文本里在做什么行动"，需要动名词式回答。
4. 用户想学麦基的动名词标记法，拿自己或名作的场景练手。

### 语言信号 (用户的话里出现这些就应激活)

- "帮我拆一下这场戏的节拍／拍点"
- "这场景感觉一直在重复同一个东西"
- "动名词""价值负荷""转折点在哪"
- "break this scene into beats" / "what's the beat" / "does this beat advance"

### 与相邻 skill 的区分

- 与 `mckee-dialogue-as-action` 的区别: as-action 讲公理（对白为什么是行动），本 skill 讲操作（怎么把场景切成行动/反应单位）。用户问"这句话在做什么"可用本 skill 回答，但若问"对白到底是什么"用 as-action。
- 与 `mckee-dialogue-clinic` 的区别: clinic 是诊断器，按六项任务＋四类瑕疵给"坏在哪、怎么修"的结论；本 skill 是中性结构分析，拆完才知道坏没坏。clinic 的第2项任务（节拍推进）复用本 skill 的产出。
- 与 `mckee-dialogue-desire` 的区别: desire 深挖"为什么角色要这个"（欲望五维），本 skill 只管"这一轮行动/反应有没有推进价值"，层级不同。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **把场景切成节拍**
   - 完成标准: 把对话按"行动→反应"切成一拍一拍，每拍标注说话者与该拍的台词；能数出明确的拍数（如"共13拍"）。若一段话无法切成行动/反应对（全是一方独白、另一方无反应），记录下来不强行切。

2. **每拍用动名词标记潜文本行动，并记录价值负荷变化**
   - 完成标准: 每拍标出一个动名词（A在"乞求"、B在"拒绝"）；画出一场戏从开始到结束的价值轨迹（正/负、强/弱）；找出转折点，并说明它由"行动"还是"揭露"创造。
   - 判停条件: 若整场价值负荷无任何变化，直接输出"非事件"诊断，跳到第 3 步重点给结构改造建议；若用户只要节拍清单不要修改建议，输出清单即可停。

3. **输出诊断与修改**
   - 完成标准: 产出①节拍清单（逐拍动名词）②价值轨迹图③重复节拍定位（同一动名词反复处）④修改建议——重复节拍处建议换行动策略，非事件处建议重设转折点（太早/太晚/缺席三种病的改法），并示范改写至少一处节拍。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只想判断某句台词是否直白、要不要改含蓄——那是 `mckee-dialogue-clinic`（写在鼻子上）。
- 用户要设计角色专属词汇/语法（声音）——那是角色声音类 skill。
- 用户要写喜剧笑点（伏笔/分晓/夸张/时机/不协调）——那是喜剧冲突专用框架，本 skill 只拆结构不教笑点。
- 用户只想快速改一句台词的措辞——先问清楚是否涉及场景结构，否则用 clinic 或 as-action 更轻。

### 作者在书中警告的失败模式

- 重复的节拍：同一"乞求／拒绝"连来三次，价值负荷原地踏步（正面×N 或 负面×N），换词换句也死气沉沉（第9章）。
- 设计不良的场景：转折点太早（开场亮牌、一路反高潮）、太晚（观众十分钟前猜到了）、不出现（价值负荷从头到尾没变，"这些谈话是干吗的？"）（第9章）。
- 分岔的场景：驱动的潜文本与言行的正文本不合拍，内在想法与外在行为脱节，戏看起来不对劲（第9章）。
- 错失时机的提示：核心字眼过早出现，打乱对手的反应时机，演员被迫互相打断或虚假等待（第9章）。

### 作者的盲点 / 时代局限

- 与《故事》大量重复：转折点、价值负荷、行动主轴等核心概念完全复用其前作《故事》的体系；"节拍动名词标记"才是本书的新贡献，理论独立性偏弱。
- 动名词标注依赖作者个人对潜文本的诠释，演员、读者解读可能不同（作者也承认"你可能跟我诠释得不同"），方法示范不等于客观标准。
- 舞台／银幕导向：七场戏六场是影视／舞台文本，对小说（尤其叙述体对白）的逐拍适用性需转译。

### 容易混淆的邻近方法论

- 与"行为五步骤"（欲望→觉察对抗→选择→行动→表达）：五步骤是单句台词的生成链，节拍是场景的结构单位，两者层级不同；五步骤归 `mckee-dialogue-desire` 的动机引擎。
- 与"台词三设计"（悬疑/累积/平衡）：那是句内核心词位置的句法层（归解说/技巧类 skill），节拍是句与句之间的行动/反应层，二者互补不重叠。
