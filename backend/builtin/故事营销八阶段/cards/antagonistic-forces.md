## I — 方法论骨架 (Interpretation)

冲突是故事的引擎。把"挡在欲望对象前的障碍"落到四个具体层面，故事才有真实张力：

1. **物理层面**：事件/空间/自然/物体（时间不够、距离太远、龙卷风、破车…）
2. **社会层面**：机构与其中个人的力量（政府、企业、法律、宗教、学校、医院…权力金字塔）
3. **个人层面**：亲密关系的对抗（家庭、朋友、爱人间的喜悦与痛苦）
4. **内在层面**：意识与潜意识的矛盾（焦虑、身体问题、情感淹没理智）

**转折点**（turning point）= 意料之外的敌对力量违背期望，推动价值由正到负或由负到正的瞬间。两种产生途径：①人物行动+反馈 ②揭示秘密/未知事实+反应。每场戏应围绕一个转折点改变方向，否则是非事件、故事坍塌。转折同时带来理性效应（自行发现"为什么"）与情感效应（情感是变化的副产品）。

## A1 — 书中的应用 (Past Application)

### 案例 1：多芬"真美素描"的情感动态
- **问题**：展示转折如何在价值两极摆动。
- **方法论的使用**：激励事件=女性自我批评（负）；看到陌生人赞美素描（正）；怀疑他人（双重负）；战胜自我批评（双倍正）。转折落于内在+个人层面。
- **结论**：价值动态驱动情感参与。
- **结果**：观众随主角体验正面情感，引向购买。

### 案例 2：Always"#像女孩一样"
- **问题**：把贬低短语转为力量象征。
- **方法论的使用**：冲突落于内在（自我认知）+社会（文化贬低）层面；转折点让女孩们逆转发力。
- **结论**：四层冲突可组合使用。
- **结果**：YouTube 超 1 亿次，覆盖 150 国。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 故事"太顺、主角开挂、没看头"——缺对抗力量或只落单一层面。
2. 要设计反转/转折点让情节有重量。
3. 诊断"每场戏都平"——可能每场都没有转折点（非事件）。

### 语言信号 (用户的话里出现这些就应激活)
- "冲突/反转/转折点怎么写"
- "主角一路顺风没张力"
- "对抗力量从哪来"

### 与相邻 skill 的区分
- 与 `story-design-eight-stages` 的区别：八阶段列出"有什么"；本 skill 专讲第 3/6/7 阶段里"冲突从哪来、转折点怎么造"。
- 与 `core-value-binary` 的区别：core-value 定价值往哪摇摆；本 skill 定什么力量制造摇摆。

## E — 可执行步骤 (Execution)

1. **给欲望对象设至少一层对抗力量**
   - 完成标准：明确写出障碍来自物理/社会/个人/内在哪一（几）层。

2. **在每个关键场景埋一个转折点**
   - 完成标准：每场戏存在"期望悖反"的价值改变瞬间（行动/反馈或揭示秘密）。

3. **检验非事件**
   - 完成标准：删去任何"不改变价值负荷"的场景；连续非事件会让故事坍塌。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 纯信息/说明内容本就无人物挣扎，不必硬加冲突。
- 真实敏感议题（创伤、歧视）用作冲突时需尊重当事人，避免消费。

### 作者在书中警告的失败模式
- 营销故事回避冲突（见 `negation-principle` 负面恐惧症）：只给正面答案，无对抗力量 → 无聊。
- 反派≠对抗力量：作者提醒"对抗力量"不限于反派角色，勿把冲突窄化为"坏人"。

### 作者的盲点 / 时代局限
- 四层面模型源自戏剧学，迁移到 B2B 销售时对抗力量多为"机构惯性/法规"，需具体化（见 `storied-sales`）。

### 容易混淆的邻近方法论
- "冲突 = 坏人阻挡"：作者明确反对此窄化；对抗力量是多层障碍。
