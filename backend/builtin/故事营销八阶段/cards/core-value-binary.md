## I — 方法论骨架 (Interpretation)

故事的"意义"来自一条**可正负摇摆的价值轴**。作者给出两个操作要点：

1. **核心价值必须二元对立**：生/死、成功/失败、自我批评/自我欣赏、孤立/团结、公正/不公……故事的意义=价值由负转正或由正转负的因果解释。没有清晰价值轴，故事无方向、无张力。
2. **善意核心置于主角**：主角内心要散发"人性光辉"（常以"失败者感""弱势"呈现），这是移情与共鸣的磁石。世人尊重权力但不与之共情；能共鸣的是"觉得自己也是失败者"的普遍感受。

检验标准：能否用一句话说出"本故事的核心价值从 X 转到 Y"？主角是否让观众本能想"希望他得到想要的"？

## A1 — 书中的应用 (Past Application)

### 案例 1：多芬"自我批评/自我欣赏"
- **问题**：如何让女性与品牌建立情感连接。
- **方法论的使用**：锁定核心价值轴=自我批评↔自我欣赏；把善意核心放在"对自己苛刻却渴望被认可"的普通女性身上。
- **结论**：价值动态引发共鸣。
- **结果**：YouTube 近 1.63 亿播放，销售额近翻番。

### 案例 2：红牛"兴奋/无趣"
- **问题**：产品本身无故事可讲。
- **方法论的使用**：挖到受众深层需求="狂热的活力"，定核心价值=兴奋↔无趣，以极限运动主角承载。
- **结论**：价值轴与品牌绑定，无需讲产品。
- **结果**：官网零产品图却成内容营销标杆。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 定故事/品牌主题时，不知"冲突点"在哪、价值主轴是什么。
2. 诊断"故事没劲、记不住"——常因无清晰二元价值或主角不可共鸣。
3. 选主角视角（公司/产品/消费者）时，判断能否引发善意核心共鸣。

### 语言信号 (用户的话里出现这些就应激活)
- "故事的核心冲突/主题价值是什么"
- "怎么让主角让人共情"
- "品牌核心价值怎么定"

### 与相邻 skill 的区分
- 与 `story-design-eight-stages` 的区别：八阶段是结构；本 skill 是结构的"意义引擎"（价值轴）与"共鸣引擎"（善意核心）。
- 与 `antagonistic-forces` 的区别：本 skill 定"价值往哪摇摆"；antagonistic-forces 定"什么力量挡在中间制造摇摆"。

## E — 可执行步骤 (Execution)

1. **选一条二元价值轴**
   - 完成标准：写出"X ↔ Y"，且与品牌/受众真实相关（如成功/失败、安全/危险）。

2. **让价值在故事中摇摆**
   - 完成标准：能指出由负转正或由正转负的关键转折点（通常对应八阶段第 3/6 阶段）。

3. **把善意核心放进主角**
   - 完成标准：主角有可被普遍共鸣的人性弱点（弱势/失败者感），而非特权光环。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 纯说明性内容不需要情感价值轴。
- 受众为"特权阶级"自夸视角——世人对其无共情，应转弱势视角。

### 作者在书中警告的失败模式
- 主角以企业规模/财富/产品名望自我吹嘘（X12）：尊重≠共情，故事失效。
- 价值轴与品牌核心价值不符：公众感觉被背叛（口碑即时化）。

### 作者的盲点 / 时代局限
- 假设"失败者共鸣"普适；部分受众（如高端客）对权威/精英叙事仍有响应。

### 容易混淆的邻近方法论
- 品牌定位（positioning）：偏市场份额/差异化；本 skill 偏故事内部的情感价值引擎。
