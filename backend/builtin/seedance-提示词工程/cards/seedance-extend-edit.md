# 延长 / 编辑 / 融合三模式

## R — 原文要点 (Reading)

来源方法（MIT，整理自 seedance2-skill 中文版）。**向后延长**：`将 @视频1 延长15秒` + 分时段写新增内容；生成长度参数选「新增部分」的时长。**向前延长**：`向前延长10s` + 写前置画面。**定向编辑**：保留原片大部分，只改指定元素——改剧情（`颠覆 @视频1 里的剧情，男人眼神从温柔转为冰冷…`）、换角色（`视频1中的女主唱换成图片1的男主唱，动作完全模仿原视频，不要出现切镜`）、加元素（`将视频1女人发型变成红色长发，图片1中的大白鲨缓缓浮出半个脑袋`）。**视频融合**：`视频1中由粒子组成的马逐渐具象化…逐渐过渡到视频2`——用中间意象桥接两段素材。

## I — 方法论骨架 (Interpretation)

1. **延长 = 只写增量**：提示词只描述新增时段的画面；生成长度参数=新增时长（不是总时长）——两处有一处错就翻车。
2. **编辑 = 最小作用域**：明确「改什么」+「保留什么」（如动作完全模仿原视频/不要切镜）；对保留部分零描述就是最好的保留。
3. **换角色 = 双锚点**：被换者来自 @视频N、替换者来自 @图片N，动作继承关系显式声明。
4. **融合 = 找桥**：两段素材间需要一个中间意象（粒子/光影/运动方向）做过渡，硬切式融合描述易出鬼畜。

## A1 — 应用案例 (Past Application)

- 剧情反转编辑：仅描述「眼神转变+推人动作+一句台词」，其余剧情由原片承接——生成后前后衔接自然。
- 角色替换：男主唱形象来自图片 1，动作完全模仿原视频、不切镜——保住原片节奏只换人。

## A2 — 触发场景 (Future Trigger)

- 用户拿着生成好的视频要求「再来 5 秒」「把这个人换掉」「加个物体」。
- 两段素材要拼接成一支片子。
- 影策画布上对已有视频资产做二次加工。

## E — 可执行步骤 (Execution)

1. **判模式**：延长（向前/向后）/ 编辑（改内容）/ 融合（拼接）三选一。
   *完成标准*：模式判定明确。
2. **延长分支**：只写新增时段（分时段格式），生成长度参数=新增时长。
   *完成标准*：无对原有时段的重复描述，参数正确。
3. **编辑分支**：写明改动点+保留声明（动作模仿/不切镜等），改动点描述最小化。
   *完成标准*：改动与保留边界清晰。
4. **融合分支**：选定桥接意象，写过渡渐变逻辑。
   *完成标准*：桥接意象在两段素材中都有依据。
5. **红线自查**：换入素材无真人脸、引用语法合规（配合 seedance-at-reference-syntax）。
   *完成标准*：通过七坑终查。
