# @ 引用显式职责语法

## R — 原文要点 (Reading)

来源方法（MIT，整理自 seedance2-skill 中文版）：Seedance 2.0 用 `@` 指定素材用途——`@图片1 作为首帧`、`@图片2 作为尾帧`、`参考 @图片1 的人物形象`、`场景参考 @图片3`、`参考 @视频1 的运镜效果`、`完全参考 @视频1 的特效和转场`、`视频节奏参考 @视频1`、`旁白音色参考 @视频1`、`背景BGM参考 @音频1`、`穿着 @图片2 的服装`、`产品细节参考 @图片3` 等。素材约束：图片 ≤9 张（每张 <30MB）、视频 ≤3 个（每个 <50MB、总时长 2-15s）、音频 ≤3 个（每个 <15MB）、**总文件数 ≤12**；不支持写实真人脸部素材（会被系统拦截）；生成时长 4-15 秒。

## I — 方法论骨架 (Interpretation)

1. **零裸引用**：上传的每一个素材必须在提示词里有对应的 @ 引用**且说明用途**——「参考@视频1」这种模糊写法是第一大错误，必须说清参考什么（运镜？动作？特效？节奏？音色？）。
2. **一素材一职责**：一个素材通常承担一个主职责；需要它兼任（如既当首帧又当人物参考）要显式写出两个用途。
3. **名额经济学**：总文件数 ≤12，优先上传对画面/节奏影响最大的素材；用不上的素材不上传——占名额还分散模型注意力（对照经验：ref 5-8 张最优，塞满 9 张注意力分散）。
4. **红线前置**：写实真人脸的图/视频素材会被直接拦截，选素材阶段就要剔除。

## A1 — 应用案例 (Past Application)

- 人物一致性写法：`男人 @图片1 下班后疲惫地走在走廊…全程自然对话`——图片 1 承担人物形象职责。
- 组合写法：`@图片1 的人物作为主体，参考 @视频1 的运镜和动作编排，背景BGM参考 @音频1，场景参考 @图片2`——四素材四职责一行写清。

## A2 — 触发场景 (Future Trigger)

- 用户上传素材后要写生成提示词。
- 生成结果「没用上我传的图」的归因诊断。
- 影策 Agent 组装即梦/Seedance 多模态任务的 prompt 组装环节。

## E — 可执行步骤 (Execution)

1. **列素材清单**：盘点本次可用素材（图/视频/音频各几个）。
   *完成标准*：清单含数量与内容摘要，确认无真人脸素材。
2. **派职责**：为每个素材指定唯一明确用途（从用途词表选或自定义描述）。
   *完成标准*：素材→用途映射表完整，无"待定"项。
3. **写引用句**：按「@素材N + 用途短语」写进提示词相应位置。
   *完成标准*：每个上传素材在提示词中恰有一处显式引用。
4. **复核名额**：总文件数 ≤12；与画面/节奏无关的素材移除。
   *完成标准*：名额内且无冗余素材。
5. **模糊自检**：搜索提示词中所有「参考」字样，确认每处都说明了参考的具体维度。
   *完成标准*：零裸引用。
