# 四层强控提示词

## 何时用

- 用户要把文字想法写成可直接使用的图片或视频提示词。
- 提示词画面发散、动作含糊、镜内切镜失败或前后镜不连。
- 打戏、产品动作、复杂运镜需要把受力与时间写清。

## 四层结构

### 1. 素材说明层

逐个说明参考素材的职责、有效区间和不可继承项：

```text
图 1：只控制人物身份与发型，不控制背景；
图 2：只控制产品外形与配色，不控制构图；
视频 1：只借鉴运镜速度，不复制人物与场景。
```

不要让一张参考图同时承担互相冲突的身份、构图、光线和风格职责。

### 2. 整段目标层

用一句可验证的话说明这一条要完成什么，尽量少于 40 个汉字。目标只写结果，不在这里堆形容词。

### 3. 逐镜物理描述层

按时间码写清：

- 空间轴线与人物相对位置。
- 机位落点、景别与运动路径。
- 谁对什么施力，动作的起点、过程和结果。
- 画面中同时发生的动静反差。
- 上一镜后果如何进入本镜。
- 需要镜内切换时，明确写“硬切至……”以及切换后的新机位。

次要环境信息放括号内，避免抢占动作权重。文戏不要只写“悲伤、愤怒”，改写为行为目标、身体战术和微动作。

### 4. 全局硬约束层

把不随镜头变化的色彩、光线、材质、画幅、稳定性和禁止项放末尾。优先写正向视觉事实，少量否定词只用于模型确实容易犯的错。

重布光时，先匹配场景已有的暖/冷主光，再写补光；不要凭空新增第二主光。

## 图片提示词四要素

```text
主体：是谁/是什么，外观锁定短语
环境：地点、时间、天气、前景与背景层次
光线：主光方向、软硬、色温、反射与阴影
构图：画幅、视角、景别、镜头感、主体占比
```

## 视频提示词检查

- 时间码连续，不重叠，总和等于目标时长。
- 每个动作都给足准备、执行、结果中的必要部分。
- 镜头运动在物理上可行，主体路径与摄影机路径不冲突。
- 参考素材只借被授权的维度。
- 不自动添加 BGM、字幕、水印、品牌字或未指定人物。

## 一张事实表先对齐

复杂任务先让用户一次填全：画幅、总时长、主体、场景、动作目标、参考素材职责、禁止项、交付形式。信息够用就开工，不逐项反复追问。

## 验收

- 删掉风格词后，动作与空间仍能被理解。
- 每个时间码都有可见事件，不是空泛情绪。
- 每个参考素材只有清楚职责。
- 没有互相冲突的风格族、光线方向和摄影机运动。
