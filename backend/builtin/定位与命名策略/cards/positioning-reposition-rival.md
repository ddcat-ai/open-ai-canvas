## I — 方法论骨架 (Interpretation)

当品类里已经挤满了产品、六维扫描找不出空位时，还有最后一条路：**不是找空位，而是造空位**——把已经占着位置的那个认知挪走。

作者用哥伦布做类比。当时公众相信"大地是平的"，科学家要推广"大地是圆的"，不能靠数学论证，而要先**推翻旧观念**：他们指出水手在海上先看到的是对面船的桅杆，然后是船帆，最后才是船身；如果大地是平的，就该同时看到整条船。这个论据的力量不在于严密，而在于**任何人都能自己验证**。旧理念一旦被推翻，新理念的推广就变得简单至极——人们会主动寻找新理念去填补空白。

这就是方法的核心结构：

**第一步不是讲你有多好，而是给对手的强项配上一个顾客一旦知道就无法忽视的代价。**

泰诺的广告用了 60 个词讲阿司匹林伤胃、引发哮喘过敏、造成胃肠道隐性出血，才提到自己。它没有说"泰诺更好"，它说的是"有千百万人不应该服用阿司匹林"。这句话把阿司匹林从"止痛药"重新定位成了"一种有条件禁忌的药"，于是"给不能吃阿司匹林的人用的止痛药"这个位置凭空出现了——而泰诺已经站在那里。

三个必须同时满足的闸门：

1. **真实且顾客可自行验证**。像"先看到桅杆"那样，最好的论据是顾客自己能确认的。编造或夸大会被反噬。
2. **攻的是产品/方案的属性，不是人或公司**。攻属性是重新定位，攻人是人身攻击，后者激起的是同情而非改变。
3. **你必须能补上那个缺口**。你揭示了一个代价，就必须是那个不带这个代价的选项。否则你只是帮整个品类降温，最后获益的是第三方。

还有一条作者反复强调的观察：**被攻击方最好的应对是沉默**。拜耳花百万美元反驳泰诺，顾客的解读是"既然它这么紧张，那说明真有问题"。所以如果你是被重新定位的一方，请转 `positioning-leader-defense`。

## A1 — 书中的应用 (Past Application)

### 案例 1：泰诺重新定位阿司匹林
- **问题**：止痛药市场被阿司匹林（拜耳）主导，没有空位。
- **方法论的使用**：广告开头是"为千百万不应服用阿司匹林的人着想"，接着列举胃溃疡、哮喘、过敏、缺铁性贫血等禁忌，再讲阿司匹林刺激胃黏膜、造成胃肠道隐性微量出血——说了 60 个词之后才提到自己的产品。
- **结论**：不比较疗效，改变顾客对阿司匹林这个类别的理解。
- **结果**：泰诺成为镇痛药第一品牌，超过安乃近、拜耳、百服宁和 Excedrin。作者评价："一个简单但有效的重新定位战略便使它有了今天的地位。"

### 案例 2：拜耳的错误反击
- **问题**：拜耳打广告反驳泰诺的说法。
- **方法论的使用**：作者指出这是最坏的应对——反驳本身证实了指控的重要性。
- **结果**："既然拜耳的阿司匹林这么担心泰诺，居然花百万美元打广告反驳对方这些说法，那么阿司匹林会造成胃出血的观点肯定有一定的道理。"

### 案例 3：拜耳的第二次错误（品牌延伸式反击）
- **问题**：拜耳推出"不含阿司匹林的拜耳止痛药"，后又推"拜耳优质产品系列"（五种止痛药全都不含阿司匹林、全用拜耳命名）。
- **结论**：用一个以"阿司匹林"闻名的名字去卖"不含阿司匹林"的东西，是由内而外思维的极致。
- **结果**：花了 1.1 亿美元宣传，第一年销售额只有 2500 万美元。份额微不足道。

### 案例 4：Advil 重新定位整个品类
- **方法论的使用**："新一代止痛药"——不攻击某个品牌，直接把所有既有品牌一起定位成"上一代"。
- **结果**：成为第二号品牌。作者评价：而且是通过与大名鼎鼎的阿司匹林对抗来实现的，"不可思议！"

### 案例 5：哥伦布与"大地是圆的"
- **方法论的使用**：不靠数学理论，靠一个公众可以自己验证的观察（先看到桅杆）。
- **结论**："所有的数学理论都不如简单的观察结果，可以由公众自己来验证。"

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 用户要推广一个新方案，但顾客/团队已经认准了现行做法。
2. 六维空位扫描结论是"没有空位"。
3. 要说服团队弃用一个用了很久的工具/流程/框架。
4. 一个流行观念正在阻碍用户想做的事。
5. 后进产品在成熟品类里破局。
6. 科普/教育场景：现行做法有被忽视的代价需要让人意识到。
7. 用户自己正在**被**别人重新定位，想知道怎么办（此时应转 `positioning-leader-defense`）。

### 语言信号（用户的话里出现这些就应激活）

- "大家都已经习惯用 XX 了"
- "怎么让他们改变想法"
- "现有方案其实有问题，但没人在意"
- "这个市场已经没缝了"
- "怎么打破认知"
- "how do we displace the incumbent" / "everyone already uses X"

### 与相邻 skill 的区分

- 与 `positioning-against-the-leader` 的区别（**最重要的边界**）：关联定位**不评价对手**，只是站在它旁边或对面——"非可乐"从没说可乐不好。本 skill 是**主动改写顾客对对手的理解**——泰诺让人们重新看待阿司匹林。前者温和、低风险、可长期维持；后者攻击性强、有反噬风险、需要三道闸门。**决策顺序：先试关联定位，不够用再升级到本 skill。**
- 与 `positioning-find-the-hole` 的区别：`find-the-hole` 是找现成的空位，本 skill 是在没有空位时**制造**空位。前者是勘探，后者是拆迁。
- 与 `positioning-leader-defense` 的区别：镜像。本 skill 是攻方，后者是守方，且后者给出的答案通常是"不要回应"。
- 与 `positioning-outside-in` 的区别：`outside-in` 说"顺着对方已有的认知走，别硬改"，本 skill 说"先把旧认知挤掉"。看似矛盾，实则互补：本 skill 的正确用法恰恰是**用对方已有的认知（阿司匹林=药）来推翻另一个已有认知（阿司匹林=安全无害）**，即用认知打认知，而不是硬灌新观念。
- 与 `flaw-first-credibility` 的区别：后者是**主动暴露自己的缺点**来换取可信度，本 skill 是**揭示对手的隐藏代价**。方向相反，但可以组合使用（先自曝一个小缺点建立可信度，再指出对手的大代价）。

## E — 可执行步骤 (Execution)

1. **确认确实没有空位**
   - 先跑一遍 `positioning-find-the-hole` 的六维扫描。
   - 判停条件：若有独立空位，优先占空位——那条路风险低得多。

2. **找出对手强项自带的代价**
   - 问：让对手成为第一的那个属性，它的**结构性副作用**是什么？
   - 阿司匹林之所以有效正因为它是水杨酸类，而这正是它伤胃的原因——代价与强项同源，对手无法在保留强项的同时消除它。
   - 完成标准：找到一条与对手强项同源、因而无法被修补的代价。
   - 判停条件：若那个代价对手一个版本就能修掉，本 skill 无效，退回步骤 1。

3. **过三道闸门**
   - **① 真实可查**：这条代价能否被顾客自行验证或由独立第三方证实？（哥伦布的桅杆检验）
   - **② 攻属性不攻人**：措辞里有没有指向公司、创始人、员工的贬损？有则重写。
   - **③ 你能补上缺口**：你的方案是否确实不带这个代价？如果你也有同样的问题，立即停止——否则会引火烧身。
   - 完成标准：三项全过并留下书面结论。
   - **合规闸门（现代补充）**：检查表述是否符合广告法与不正当竞争相关规定，避免直接点名贬损；优先用品类描述替代竞品名。

4. **设计"顾客可自行验证"的证据**
   - 优先级：顾客亲身可感 > 第三方权威数据 > 自有实验数据 > 逻辑推演。
   - 完成标准：至少一条属于前两级。

5. **按"先破后立"排序表达**
   - 结构：①点出人群（"为那些……的人着想"）→ ②陈述代价（具体、可验证）→ ③停顿 → ④才提自己。
   - 泰诺用了 60 个词才提到自己的产品。**不要在第一句就推销自己**，那会把整段话降级为普通广告。
   - 完成标准：自我推销出现在整段表达的后 1/3。

6. **预演反噬**
   - 写出对手最可能的三种反击，以及你的应对。
   - 特别检查：如果对手选择**沉默**（正确应对），你的方案还成立吗？很多重新定位方案依赖对方接招，对方不接就落空。
   - 完成标准：有一条不依赖对手回应的独立价值主张。

7. **输出方案**
   - 含：空位扫描结论、对手强项与同源代价、三道闸门结论、合规检查、证据清单、表达顺序、反噬预案。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **还能找到独立空位时**。造空位的成本与风险远高于占空位。
- **代价不真实或你无法举证**。这会从定位问题变成法律与信誉问题。
- **你自己也带着同样的代价**。揭示它等于自曝。
- **涉及安全、健康、合规的严重问题**。这时不是营销问题，应走正式的举报、监管或披露渠道，用营销手法处理会被视为消费风险牟利。
- **对手是个人而非方案**。攻击具体的人会激起同情并把话题从事实转向道德，且有法律风险。
- **你是被攻击的一方**。转 `positioning-leader-defense`，答案通常是不回应。
- **政治、宗教、族群相关议题**。本 skill 只用于产品、方案、工具、方法论层面的认知重构。

### 作者在书中警告的失败模式

- **反驳即背书**：拜耳花百万美元反驳，反而坐实了指控。
- **用旧名字卖新概念**："不含阿司匹林的拜耳止痛药"——1.1 亿投入换 2500 万销售额。作者特意点出这是由内而外思维的产物。
- **靠理论而非可验证的观察**："所有的数学理论都不如简单的观察结果。"
- **害怕争执**：作者说"绝不要害怕争执。重新定位的关键在于从根本上动摇现有的观念、产品或人"。但这一条在今天需要打折，见下方时代局限。

### 作者的盲点 / 时代局限

- **"绝不要害怕争执"在今天风险高得多**。1980 年的冲突通过付费媒体单向传播，可控、可预算、可撤回。今天一条攻击性表述会被截图、二创、跨平台扩散，并在数年后仍可被检索。**现代修正：争执要设计，且必须预设"如果这段话被断章取义会怎样"。**
- **法律环境完全不同**。书中鼓励在广告中直接点名竞品并列举其缺陷；这在今天的多数司法辖区会触发商业诋毁、不正当竞争或虚假广告风险。中国《广告法》《反不正当竞争法》对贬低同行有明确限制。**本 skill 的合规闸门（步骤 3）是原书没有的，必须执行。**
- **作者混入了政治人物的举例**（尼克松、山姆·埃温、拉尔夫·纳德），用来说明"冲突能一夜成名"。这些例子在本 skill 中被**全部剔除**，仅保留产品与观念层面的案例。政治场景不在本 skill 适用范围内。
- **泰诺案例的归因过窄**。泰诺的成功同期还有医生推荐渠道、对乙酰氨基酚的真实临床优势、以及强生的分销能力。作者把它完全归给一段广告文案。
- **没有讨论"重新定位之后怎么办"**。泰诺占住了位置之后如何防守、如何应对 Advil 用同样手法把它一起定位成"上一代"，书中一笔带过。攻击者终将成为被攻击者。
- **幸存者偏差**：书中只记录了成功的重新定位（泰诺、Advil）和失败的**反击**（拜耳），但没有记录**失败的重新定位尝试**——即那些攻击了对手却没能自己占住位置的品牌，而这在实践中很常见（作者自己也在别处承认过 X23 类的失败）。

### 容易混淆的邻近方法论

- **对比广告**：直接主张"我比它好"，把顾客推入比较模式；重新定位是改变顾客对对手的**分类**，不做优劣比较。
- **负面营销 / 抹黑**：不以真实可验证的属性为基础，纯粹制造情绪。三道闸门就是用来隔开这两者的。
- **危机公关**：处理的是自己被指控时的应对，与本 skill 方向相反。
- **`flaw-first-credibility`（先曝缺点建立可信度）**：处理自己的缺点；本 skill 处理对手的代价。
