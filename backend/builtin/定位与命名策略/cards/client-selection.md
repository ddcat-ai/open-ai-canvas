## I — 方法论骨架 (Interpretation)

做客户不是"来活就接"，而是像投资一样筛选与配置，核心是一套红线 + 一套正向信号。

1. **定金是诚意筛子**：不交定金/首款的生意基本做不成——定金区分"真意向"与"白嫖"，把精力压给交了钱的人，形成百分百成交的良性循环。
2. **四种老板直接拒**：自吹天下第一（听不进意见）、用词华丽自恋（预算不足还绕弯）、不调查就问"你们有啥作品"（办事不严谨）、不打预付款想试用（劳斯莱斯会给你试驾吗）。
3. **创始人三大危险信号**：当众哭（文艺青年，快黄）、要卖房支持公司（不会算账、一意孤行）、频频露脸（公司缺钱了）——行为比财报更真实。
4. **用投资思维做客户**：与其月月做三个新客户，不如深耕老客户吃成长红利（如 5 年后上市收费翻 5 倍）；同时"莫欺少年穷"，有眼光地接初创客户就是对未来的投资。
5. 用法是**先红线后红利**：先用量化信号过滤掉必黄/必坑的，再把剩余客户当长期资产经营。

## A1 — 书中的应用 (Past Application)

### 案例 1：《奇迹·笨小孩》与买房团——"不交定金肯定黄"
- **问题**：乙方常因脸皮薄不敢提钱，结果客户无承诺、精力被无效消耗。
- **方法论的使用**：作者以电影情节和自述买房团为例——交 1 万定金后服务天差地别，不交连搭理都懒得搭理；确立"必须收定金，可少但必须有"，对不交者一概拒绝。
- **结论**：定金是筛选真客户、形成良性循环的关键机制。
- **结果**：进来的客户百分之百成交，形成正向循环。

### 案例 2：小米 / BOSS 直聘 / 铂爵——"莫欺少年穷"吃成长红利
- **问题**：初创客户其貌不扬、预算少，乙方要不要接？
- **方法论的使用**：作者用投资思维看客户，在小米（望京卷石大厦）、BOSS 直聘（几百人别墅办公）、铂爵（厦门小公司）还弱小时就合作，不吃眼前得失。
- **结论**：有勇气和初创品牌合作、不计眼前，就是对未来的投资。
- **结果**：三者后来都成行业头部，红制作吃到大额成长红利并长期合作（小米 8 年、BOSS 6 年）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 乙方/自由职业者收到新询盘，纠结"这单能不能接、要不要先收钱"。
2. 投资人/合伙人评估一家创业公司健康度，看创始人行为而非只看法报。
3. 服务商被要求"先免费试做一版看看"，不确定是否白嫖。
4. 销售/商务谈单，对方疯狂画饼说"以后让你入股"。
5. 想优化客户结构，决定该维护老客还是死磕新客。

### 语言信号（用户的话里出现这些就应激活）

- "这个客户/老板值不值得接 / 要不要先收定金 deposit？"
- "对方想先免费试用 / 白嫖，我该怎么拒绝？"
- "创始人老哭 / 要卖房 / 天天露脸，是不是要黄了 founder red flag？"
- "client selection / 怎么筛选客户 / 用投资思维做客户"
- "他说以后让我入股，靠谱吗？"

### 与相邻 skill 的区分

- 与 `trust-endorsement`（S07）的区别：本 skill 是"我该不该信/接这个客户"，信任背书是"我如何获得他人信任"，方向相反。
- 与 `brand-lifecycle`（S09）的区别：本 skill 看"具体客户/创始人"，生命周期看"行业周期 timing"。
- 与 `startup-zero-to-one`（S11）的区别：本 skill 站在接单方/投资方筛选别人，初创从零到一是站在创业者自己冷启动。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **过红线（拒单信号）**
   - 完成标准：逐条核对"四种老板不合作 + 不交定金 + 创始人三大危险信号"，列出命中项；命中任一条即建议拒绝或重谈条款。

2. **定合作条件**
   - 完成标准：给出明确定金/首款比例（可少但必须有）与"不交不启动"的底线话术；若对方要求免费试用，输出拒绝理由。
   - 判停条件：若命中创始人危险信号（当众哭/卖房/频露脸），直接建议放弃尽调，跳到步骤结束。

3. **配客户结构（投资思维）**
   - 完成标准：按"老客户吃红利 + 接有潜力的初创客户（莫欺少年穷）"给出客户结构建议，标注 1 个可深耕对象。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 已签约交付阶段，应转执行/项目管理，本 skill 只用于**接单前**筛选。
- 强平台型、标准化 SaaS 自助成交，无需人工定夺客户资质。
- 纯 To C 大众消费品获客，不适用"四种老板"等人治红线。

### 作者在书中警告的失败模式

- **不收定金的生意必黄**（ce16）：不交定金/首款，客户无承诺，精力被无效消耗，项目最终黄掉；文艺青年脸皮薄不敢提钱是主因。
- **四种不能合作的老板**（ce15）：自大、华丽词穷、不调查供应商、想白嫖试用，合作难成且付款无保障。
- **创始人三大危险信号**（ce14）：当众哭（文艺青年快黄）、卖房填坑（不会算账）、频频露脸（缺钱），都是公司出事前兆。

### 作者的盲点 / 时代局限

- **乙方视角偏见**：作者作为广告公司老板，把"收定金/拒客户"当绝对准则；对首次合作的弱势乙方，过于绝对拒单可能错失建立案例的机会，需结合发展阶段权衡。
- **"文艺青年=快黄"过于绝对**：创始人当众哭未必是死兆，也可能是抗压不足但产品过硬；信号仅作警示，不能单点定罪。

### 容易混淆的邻近方法论

- **定金为王 vs 僵化收钱**：定金是筛选机制不是目的，初创友好型合作可"少但必须有"，别因小失大拒掉潜力客户（莫欺少年穷）。
- **四种老板 vs 个人风格**：华丽辞藻可能是表达习惯而非不靠谱，需结合"不付预付款想试用"等硬信号综合判断。
