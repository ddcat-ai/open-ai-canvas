## I — 方法论骨架 (Interpretation)

这是定位理论里最反直觉的一条：**扩大目标受众通常会减少而不是增加你的受众。**

原因在心智的运作方式。一个人只能把你放进一个格子。如果你的表述让他判断不出你属于哪个格子，他不会给你开一个"通用"格子——他会**直接把你丢掉**。所以"什么人都能用"在传播上等价于"没人特别需要"。

Rheingold 啤酒是最清楚的演示。它想抢占纽约工人阶层市场，于是拍了一组制作精良的广告，分别展示不同族裔的人都在喝 Rheingold。逻辑上这覆盖了所有人。实际结果是"纽约市所有的民族都不会喝 Rheingold 啤酒"——因为**人们都有偏见，一个群体喝它，另一个群体不见得跟着喝**；而且更根本的是，这组广告没有回答"这瓶啤酒是给谁的"。同期 Schaefer 只说了一句"唯一一种喝了还想喝的啤酒"，明确占住"重度饮用者"这个位置，成功了。

诊断方法只有一个动作：**一句话回述测试**。找目标受众，让他们用自己的话说"这是什么/这是给谁的"。

- 得到高度一致的一个答案 → 定位清晰。
- 得到三个以上互不相干的答案 → 已经失焦。
- 得到"不知道 / 什么都能干吧" → 严重失焦。

治疗方法是收缩，而且要收缩两个维度，不是一个：

1. **人群维度**：从"所有需要 X 的人"收缩到一个能被指认的具体群体。
2. **用途维度**：从"什么都能做"收缩到一件事。

作者对个人的建议同样直接：定位工作中最难的一点是**选定某个具体的概念，把它与自己联系起来**。而"大多数人没有足够的信心为自己确立一个概念。他们犹豫不决，指望别人来给自己下定义。"

还有一个必须一起处理的陷阱：**过宽的定位即使建立起来也守不住**。作者说，想占据的定位太宽泛，"即使能建立，也无法防御来自像 Nyquil 这样定位更窄的产品的攻击"。宽定位是被窄定位一块块蚕食掉的。

## A1 — 书中的应用 (Past Application)

### 案例 1：Rheingold 啤酒
- **问题**：想抢占纽约工人阶层市场（重度饮用者多，是个不错的目标群体）。
- **方法论的使用**：作者分析——公司制作了"一些绝妙的广告"，分别宣传不同族裔的人都喝 Rheingold。执行质量没问题，定位逻辑有问题。
- **结论**："他们试图吸引所有人，结果什么人也没有吸引到。"
- **结果**：市场萎缩。同期 F&M Schaefer 认识到"重度饮用者"这个定位可行，立即抢占，用"唯一一种喝了还想喝的啤酒"成功。

### 案例 2：定位太宽守不住
- **问题**：感冒药品牌想占据整个"感冒药"这个宽位置。
- **方法论的使用**：作者指出宽定位"即使能建立，也无法防御来自像 Nyquil 这样定位更窄的产品的攻击"。
- **结果**：Nyquil 用"夜间感冒药"从宽定位里切走一块，成为该公司近年最成功的新品。

### 案例 3：灰狗与西部联盟
- **问题**：这类公司试图从一个明确的定位（长途巴士、电报）扩展成"综合运输/综合通讯"。
- **结论**：作者把它们归入定位模糊的一类——扩展了业务范围，丢失了心智位置。

### 案例 4：个人定位
- **问题**：作者虚构了一个律师说"我是达拉斯最好的律师"。
- **方法论的使用**：反问——"假如我们在达拉斯法律界做一次调查，你的名字会被提到多少次？"
- **结论**："定位工作中最难的一点是，选定某个具体的概念，把它与自己联系起来。你如果想穿过潜在客户漠不关心的壁垒，就必须这么做。"
- **补充**："大多数人没有足够的信心为自己确立一个概念。他们犹豫不决，指望别人来给自己下定义。"

### 案例 5：大型会员制组织的使命失焦
- **问题**：某大型会员制组织曾经代表着明确的"律法与秩序的维护者"这一定位。后来许多规章制度被认为多余而取缔，仪式与方法被随意改动，"灵活性取代了恪守常规"。
- **结论**：组织变得更包容、更灵活，但也变得无法被一句话概括。
- **结果**：作者将其作为使命表述失焦导致成员流失的案例。（原书此章讨论的是一个宗教机构，本 skill 只抽取其中"使命表述失焦→归属感下降"的沟通学机制，不涉及任何宗教立场评价。）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. PRD/BP 里的目标用户写成"所有需要 X 的人"或列了五类互不相干的人群。
2. 产品功能越加越多，但每个功能的使用率都很低。
3. 团队讨论"要不要扩大受众/放宽门槛"来求增长。
4. 简历、个人介绍、公司介绍面面俱到，读完不知道这个人/公司擅长什么。
5. 组织使命/价值观膨胀到包含一切美好的词。
6. 内容账号什么都发，粉丝涨了但互动率下降。
7. 一句话说不清"我们是什么"。

### 语言信号（用户的话里出现这些就应激活）

- "我们的用户是所有 XX 的人"
- "什么人都能用"
- "我们什么都能做"
- "想扩大一下受众"
- "别把自己限制死了"
- "多几个卖点总没坏处"
- "everyone can use it" / "our target market is huge" / "we do a bit of everything"

### 与相邻 skill 的区分

- 与 `positioning-line-extension-trap` 的区别（**关键**）：后者是**一个名字承载了多样东西**（品牌被摊薄，症状是"顾客不知道这个牌子是干什么的"）；本 skill 是**一个东西试图讨好所有人**（人群与用途被摊薄，症状是"顾客知道你干什么，但不知道这是给谁的、什么时候用"）。二者可同时发生，诊断入口不同。
- 与 `positioning-find-the-hole` 的区别：本 skill 诊断"你太宽了"并给出收缩方向的原则，`find-the-hole` 提供"具体收缩到哪个格子"的六维扫描。收缩确认后转它。
- 与 `positioning-oversimplified-message` 的区别：本 skill 收缩的是**受众与用途**（做什么、给谁），后者收缩的是**表达**（怎么说）。先定清楚给谁用，再削尖那句话。
- 与 `positioning-fwmts-trap` 的区别：都会导致失焦，但动因不同——本 skill 的动因是"贪心/怕错过"，`fwmts` 的动因是"腻了/想出新"。
- 与 `ability-simplification` 的区别：后者简化**用户的操作路径**（少填一栏、少点一步），本 skill 收缩**服务对象与用途范围**。前者是交互层，后者是战略层。
- 与 `habit-zone-screening` 的区别：后者判断某个行为值不值得做习惯设计，本 skill 判断定位有没有失焦。

## E — 可执行步骤 (Execution)

1. **做一句话回述测试**
   - 找 8-15 个目标受众，看完你的介绍/落地页/简历后，用自己的话回答两个问题：**"这是什么？"** 和 **"这是给谁用的？"**
   - 完成标准：拿到原始回答记录。
   - 判定：一致的一个答案 = 清晰；3 个以上互不相干的答案 = 失焦；"不知道/什么都能干" = 严重失焦。
   - 判停条件：若结果清晰，本 skill 不适用，问题在别处。

2. **拆出当前声称覆盖的人群清单与用途清单**
   - 把所有对外表述里出现过的目标人群和使用场景全部列出来。
   - 完成标准：两张清单，通常会长得让用户自己吃惊。

3. **人群维度收缩**
   - 判据：**这个群体能不能被一句话指认出来**（"纽约的重度啤酒饮用者"可以，"喜欢喝啤酒的人"不行）。
   - 优先保留：贡献最大价值的群体 > 最容易被说服的群体 > 最能带动其他群体的群体。
   - 完成标准：收缩到 1 个主群体（最多 1 主 1 次）。
   - 注意：**收缩的是传播的靶心，不是拒绝其他人购买。**大众甲壳虫定位"小"，不妨碍任何人买它。

4. **用途维度收缩**
   - 判据：**能不能说清"什么时候用它"**（Nyquil 的"夜里"）。
   - 完成标准：收缩到 1 个主用途。

5. **写"它是什么"的一句话并复测**
   - 格式建议：给【谁】在【什么时候】用的【什么】。
   - 拿这句话回到步骤 1 的受众那里复测回述一致率。
   - 完成标准：一致率明显提升（同一个答案占比 ≥70%）。
   - 判停条件：若仍不一致，回步骤 3 继续收缩。

6. **写"放弃清单"并确认代价**
   - 明确列出：这次收缩放弃了哪些人群和用途、预计损失多少、为什么值得。
   - 完成标准：用户明确知道自己在放弃什么。**不写放弃清单的收缩方案都是假收缩**——因为组织会在执行时把它们悄悄加回来。

7. **建立防御机制**
   - 宽定位会被窄定位蚕食（Nyquil 教训）。收缩后要问：还有没有更窄的位置能从我这里切走一块？
   - 完成标准：识别出至少一个潜在的更窄攻击点，并说明应对。

8. **输出诊断报告**
   - 含：回述测试原始结果与失焦判定、人群/用途清单、收缩后的靶心、一句话表述、复测结果、放弃清单、防御点。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **基础设施与通用工具**（数据库、编程语言、支付通道、操作系统）。这类产品的价值恰恰来自通用性，"什么场景都能用"是卖点而非缺陷。它们的定位在**能力维度**（最快的/最可靠的/最简单的）而不是人群维度。
- **平台型/多边市场产品**。同时服务买卖双方是结构需要，不是失焦。
- **已经聚焦但增长停滞**。此时问题可能是市场太小或产品不行，继续收缩会加速死亡。先确认是"太宽"还是"太窄"。
- **早期探索阶段**。还在找 PMF 时保持多个方向的试探是合理的，过早收缩会错过真正的方向。收缩应发生在**有了初步信号之后**。
- **政策/公共服务类必须普惠的场景**。这类服务的覆盖面是义务而非选择。

### 作者在书中警告的失败模式

- **Rheingold**：制作精良的广告 + 覆盖所有群体 = 谁也没吸引到。**执行质量救不了定位错误。**
- **宽定位守不住**：会被 Nyquil 式的窄定位一块块切走。
- **指望别人给自己下定义**："大多数人没有足够的信心为自己确立一个概念。"
- **自封的头衔**："我是达拉斯最好的律师"——作者的反问是"你的名字会被提到多少次"。定位是别人脑子里的事实，不是自我声明。
- **组织使命的软化**：为了包容而取消所有明确的规矩，结果失去了"我们是什么"的答案。

### 作者的盲点 / 时代局限

- **Rheingold 案例的解读值得商榷**。作者把失败归因于"人们都有偏见，一个民族喝它另一个民族不见得跟着喝"。这个解释在今天既不准确也不恰当——更可靠的解释是那组广告**没有回答"这瓶啤酒是给谁的、什么时候喝"**，而不是族群偏见本身。本 skill 采用后一种解释，并不采用原书的族群论述。
- **"聚焦即正确"被绝对化**。作者没有讨论聚焦的下界：收缩到一个太小的市场同样会死，而这在实践中和"太宽"一样常见。本 skill 的边界条款（"已经聚焦但停滞时不要用"）是原书没有的。
- **长尾与算法分发改变了经济学**。1980 年触达一个窄人群的单位成本极高，所以必须押注一个大群体或一个清晰群体；今天算法能低成本地把不同信息分发给不同人群，**"对不同人说不同的话"在技术上变得可行**。但要注意：这只解决了"触达"，没有解决"记忆"——一个人心里仍然只给你一个格子。所以现代修正是：**分发可以多元，定位仍需单一。**
- **平台与生态型产品完全不在作者视野内**。1980 年不存在需要同时服务开发者、商家、消费者的产品。
- **个人定位建议隐含"一个人只能有一个专业"的假设**。跨界组合（"会写代码的设计师"）在今天恰恰是稀缺定位——但注意这仍然符合本 skill 的原则：它是**一个**清晰的格子，只是这个格子由两个词组成。关键不是词的数量，是能否被一句话指认。
- **原书第19章的完整语境涉及宗教机构**，本 skill 只抽取沟通学机制，改用"大型会员制组织"表述，不涉及宗教评价。

### 容易混淆的邻近方法论

- **市场细分（Segmentation）**：把市场切成几块并可能同时服务多块，是内部的分析动作；本 skill 要求的是**对外表述里只出现一个靶心**。可以服务多个细分，但不能同时对所有细分讲同一套话。
- **最小可行受众 / 铁杆用户**：与本 skill 方向一致，但那是增长策略，本 skill 是认知策略。
- **`positioning-line-extension-trap`**：名字层的摊薄，不是人群层的摊薄。
- **"少即是多"的产品哲学**：讲的是功能删减；本 skill 讲的是对外表述的收缩。可以功能很多但表述聚焦（这恰恰是常见的正解）。
