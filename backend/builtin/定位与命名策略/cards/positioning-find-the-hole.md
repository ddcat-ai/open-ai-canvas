## I — 方法论骨架 (Interpretation)

跟随者的错误是把力气花在"把产品做得更好"上。正确的动作是**在顾客心智里找一个还没被占的位置，然后填进去**。

关键在于对"空位"的定义要足够冷酷：空位不是"我们做得比别人好的地方"，而是**顾客心智中一个还没有名字与之绑定的格子**。这个格子甚至可以看起来对顾客没有好处——劳力士是第一块昂贵的手表，雷登巴赫是第一种最贵的爆米花，米狮龙是第一份高价国产啤酒。"贵"对顾客有什么好处？但它们都成功了，因为它们第一个填了那个格子。

作者给了六类反复奏效的空位维度：

1. **尺寸空位**：往小里想（大众甲壳虫、索尼微型电视），或往大里做（投影电视）。
2. **高价空位**：第一个直接宣称"我们是高价品牌"（皇家芝华士、劳力士、雷登巴赫爆米花）。注意作者的严格条件——必须**第一个**、要有**有效的品牌故事**、且**品类本身允许高价**，否则只会吓跑顾客。而且高价定位要在广告里建立，不是在货架上。
3. **低价空位**：适合新品类（顾客觉得自己在碰运气，"不好用我也没赔多少"），如早期传真机 Qwip。
4. **性别空位**：万宝路第一个在香烟品类建立男性定位，十年内从第五升到第一。
5. **年龄空位**。
6. **时段/使用场景空位**：Nyquil 的"夜间感冒药"。（可延伸出渠道空位。）

找空位需要**逆向思考**：人人朝东走时看你能不能往西走。这与"更大更好"的本能直接冲突，所以最大的障碍是心理上的，不是分析上的。

但更重要的是后半段：**假空位检验**。书中反复出现的失败模式是占了一个心智里根本不存在的格子。所以每个候选空位必须过三关：

- **它在顾客脑子里存在吗**，还是只在你的分析表里存在？
- **有人试过并死过吗**？如果死过，死因是不是结构性的？
- **占住它能不能养活自己**？

## A1 — 书中的应用 (Past Application)

### 案例 1：大众甲壳虫的尺寸空位
- **问题**：底特律的车一年比一年长、一年比一年低，甲壳虫又短又宽、丑陋不堪。
- **方法论的使用**：常规做法是弱化弱点、找摄影师把它拍好看。大众反过来直接把弱点变成定位声明——"往小里想"（Think Small）。
- **结论**："在广告宣传中更重要的是，要使潜在客户知道你想填补什么样的空位，而不是宣传买该产品有哪些好处。"任何正规市场调查都会说人们想要比邻居更大的车——调查在这里是误导的。
- **结果**：抓住了"小"这个空位。当时市场上不是没有其他微型车，但没有一个抢先建立微型车定位。

### 案例 2：米狮龙的高价空位
- **问题**：安海斯-布希想找一个未开发的市场。
- **方法论的使用**：识别出"高价国产啤酒"这个空位——理论上施利茨、百威、蓝带都标着"高档"，但时间销蚀了它们的高价定位，格子空了出来。
- **结果**：米狮龙凭定位广告成功。但作者补了一刀：他们很快放弃了那句广告，换成"周末是为米狮龙创造的"这类毫无意义的概念（这是 `positioning-fwmts-trap` 的典型病例）。

### 案例 3：皇家芝华士——不是第一也能成功
- **问题**：市场上已有其他高价威士忌（如长颈 Haig&Haig）。
- **方法论的使用**：那些品牌任由自己的高价地位逐渐败落，皇家芝华士用一句直白的"我们是高价品牌"打入市场。
- **结论**："只要能创立一个你就是第一的认知，你不是第一也能成功。"
- **结果**：至今维持高价威士忌的领导地位。

### 案例 4：Nyquil 的时段空位
- **问题**：感冒药市场已有康泰克、Dristan。
- **方法论的使用**：不争"感冒药"，占"夜间感冒药"。
- **结果**：该公司近年最成功的新品。

### 案例 5：Advent 与 Qwip（反面）
- **问题**：两家都成功占了空位（投影电视 / 低价传真机），随后都想扩张。
- **结果**：Advent 要"打进家庭娱乐中心行业"，上了破产法院；Qwip 被埃克森用来推全套办公设备，办公系统分部持续赤字后关门。作者点评："一家汽油公司怎么会懂得办公用品呢？"——占住空位之后的最大风险是放弃它。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 新品/新服务/新栏目立项，需要确定切入方向。
2. 产品陷入同质化，用户说"我们跟竞品差不多，只能拼价格"。
3. 团队在讨论"我们的差异化卖点是什么"，但列出来的都是通用优点（质量好、服务好、性价比高）。
4. 个人在选职业细分方向，或自由职业者在定义自己的服务范围。
5. `positioning-mind-ladder` 诊断结论是"不在梯子上"或"挤不上去"，需要换赛道。
6. 内容创作者要选一个还没人做的选题方向。

### 语言信号（用户的话里出现这些就应激活）

- "我们的差异化在哪"
- "跟竞品比我们没什么特别的"
- "只能靠低价打"
- "想切一个细分但不知道切哪"
- "这个方向有人做了吗"
- "what's our differentiation" / "find a niche" / "we're too similar to competitors"

### 与相邻 skill 的区分

- 与 `positioning-mind-ladder` 的区别：`mind-ladder` 是诊断（我在第几级），本 skill 是处方（该往哪去）。诊断结论为②③档时才用本 skill。
- 与 `positioning-be-first` 的区别：`be-first` 判断"该不该另起品类"这个战略取舍，本 skill 提供"从哪六个维度切"的具体扫描法。前者决策，后者执行。
- 与 `positioning-against-the-leader` 的区别：本 skill 找的是**独立于对手的位置**（我占"小"、我占"贵"）；关联定位占的是**依附于对手的位置**（我是"非可乐"、我是"老二"）。当六维扫描全空、找不到独立空位时，才转关联定位。
- 与 `habit-zone-screening` 的区别：后者判断"这个东西值不值得做习惯设计/会不会高频使用"，本 skill 判断"心智里还有没有位子"。两者可叠加：先找到空位，再判断这个空位上的产品能否形成习惯。
- 与 `positioning-oversimplified-message` 的区别：本 skill 找位置，后者把位置压缩成一个能被记住的词。找到空位后转它。

## E — 可执行步骤 (Execution)

1. **确定品类口径与现有占位表**
   - 列出该品类目前每个"格子"已被谁占（谁是最贵的、谁是最便宜的、谁是最小的、谁是给男性的……）。
   - 完成标准：一张"维度 × 现占位者"的表，空格即候选。

2. **六维扫描，强制每一维都出候选**
   - **尺寸**：更小/更大/更轻/更短/更长的版本有人占了吗？
   - **高价**：这个品类里有没有一个公开的"最贵"？如果有，它的高价定位是否已被时间销蚀？
   - **低价**：这是不是一个顾客会"碰运气"的新品类？
   - **性别**：有没有明确的性别定位者？
   - **年龄**：有没有明确的年龄段定位者？
   - **时段/场景/渠道**：早上用的、夜里用的、通勤时用的、只在某渠道买得到的——有没有人占？
   - 完成标准：六维各产出至少 1 个候选（"该维度已被 X 牢固占据"也是有效结论）。
   - 判停条件：若六维全部被牢固占据，跳到步骤 5。

3. **对每个候选做"假空位三检验"**
   - **① 顾客侧存在性**：目标顾客能不能用自己的话说出"我想要一个更 X 的"？如果只有你的分析表里有这个维度，是假空位。
   - **② 尸体检验**：这个位置有人试过吗？死了吗？死因是执行问题还是结构问题（结构问题=真的没有需求）？
   - **③ 生意规模**：占住它的天花板能否支撑目标（一门生意/一个岗位/一个账号）？
   - 完成标准：每个候选给出三检验的明确结论，不过关的写清淘汰理由。

4. **对幸存候选排序**
   - 排序依据：占位后能否成为该窄格子的**第一**（优先）> 顾客能否一句话理解 > 与自身能力的匹配度。
   - 完成标准：给出唯一首选 + 一个备选。

5. **六维全无空位时的处理**
   - 转 `positioning-against-the-leader`（借对手的坐标站位）或 `positioning-reposition-rival`（改写对手的认知腾出位置）。
   - 明确告知用户："这个品类里没有独立空位"本身是一个有价值的结论，不要为了交差编一个。

6. **占位后的守则（写进方案）**
   - 明确写下"占住这个空位后不能做什么"：不要因为觉得空位太窄而扩张（Advent、Qwip 教训），不要放弃那句建立空位的话（米狮龙教训）。
   - 完成标准：方案中含一条明确的"不做清单"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **顾客不做选择的场景**：指定供应商、集采、内部工具。没有选择就没有心智格子。
- **底层能力尚未及格**。空位是给及格产品用的放大器，不是给不及格产品用的遮羞布。产品在核心指标上明显不达标时，找空位只会加速失败。
- **合规/安全/健康类关键属性**上找空位。"我们是最不安全但最便宜的疫苗"这种格子不该占。
- **品类正在消失**。在马车品类里找空位没有意义，应重构品类。

### 作者在书中警告的失败模式

- **假空位**：作者反复警告，光靠"人人都想要更 X"的推理找出来的位置往往在顾客脑子里不存在。
- **市场调查的误导**：任何正规调查都会说人们想要更大的车——大众如果听调查就没有甲壳虫。**调查能测已有认知，不能测尚不存在的空位。**
- **贪婪冒充定位**："卖高价不是致富之路。"必须是第一个、有有效品牌故事、且品类能接受高价，还得有真正的差异化支撑，否则只会把顾客吓跑。
- **占住之后放弃它**：Advent 打家庭娱乐中心破产、Qwip 变成埃克森办公设备关门、米狮龙换掉那句成功的广告语。
- **把公司名只用在最低价产品上**：安海斯-布希与福特都犯了这个错，导致名字与低价绑定。
- **名字起过头**："莱特"（Lite）与通用词"light"同音，米勒因此失去了商标专用权。占了空位却守不住名字（转 `positioning-name-power`）。

### 作者的盲点 / 时代局限

- **六维是归纳出来的经验清单，不是穷举**。1980 年的消费品世界里这六维覆盖度高；今天至少还应补上：**交付形态**（SaaS/买断/订阅）、**价值观/立场**（环保、国货、开源）、**服务边界**（只做一件事 vs 全包）、**技术路线**、**社群属性**。使用本 skill 时应把六维当起点而非终点。
- **"高价空位"论述隐含通胀期的消费升级假设**。书中把 3 万美元的奔驰涨到 7.5 万仍然畅销当作论据，这在特定经济周期成立；在消费降级周期里高价空位的窗口会明显收窄。
- **性别空位在今天有社会与合规风险**。万宝路的男性定位是 1960s 的产物，且是烟草。现代应用应谨慎处理性别绑定，避免刻板印象，并注意相关广告法规。
- **书中对"低价空位"的判断依据（顾客觉得在碰运气）只适用于耐用品新品类**，对服务、订阅、食品并不成立。
- **反例的记录方式有幸存者偏差**：作者只记录"占了空位后成功/放弃空位后失败"的案例，不记录"认真占了空位但市场根本不够大"的案例，而这在实践中是最常见的死法——所以本 skill 的检验③（生意规模）比原书更强调。

### 容易混淆的邻近方法论

- **STP 中的市场细分**是按顾客属性切人群（内部动作），空位是按顾客心智里的格子切位置（外部感知）。切了细分市场不等于占了空位。
- **USP（独特销售主张）**强调产品自身的独特利益点，空位强调的是**竞争格局里的相对位置**——一个空位可以完全不含任何顾客利益（"最贵"）。
- **蓝海战略的价值曲线**是重构行业要素组合，粒度比六维扫描粗，且更侧重成本结构而非记忆位置。
- **"差异化"这个词太滑**。产品差异化（功能不同）≠ 定位差异化（心智格子不同）。前者常常不被感知。
