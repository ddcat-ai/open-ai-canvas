## I — 方法论骨架 (Interpretation)

任何行业都按"风口期 → 内卷期 → 长尾期"三段演进，做品牌的投入产出比在三个阶段天差地别。

1. **风口期**（谁做谁挣、利润吓人）：此时做品牌一战定江山，是性价比最高的窗口；晚进场则接盘。
2. **内卷期**（聪明人多、利润降、死一批）：做品牌费用最高、成效最低；征兆是监管从严、ROI 下降服务变难、行业割韭菜培训变多。正确动作是"走为上"，或靠升维（生理→阶层→国民共鸣）而非降价破局。
3. **长尾期**（创始人财富自由、求稳）：做品牌纯属浪费钱，只需安全别出错。
4. **品牌自身也分五级**：产品→名牌→品牌→信仰→文明，逐级递进、饭一口一口吃，不能在"做产品阶段"就想做"文明"。
5. 用法是**先判期、再定投入**：判清行业与自身所处阶段，决定重金做品牌、低调活着、还是撤退。

## A1 — 书中的应用 (Past Application)

### 案例 1：诺基亚 / 摩托罗拉的品牌末期警示
- **问题**：昔日手机霸主在智能机时代为何节节败退？
- **方法论的使用**：作者用"品牌末期三动作"识别老化——从核心技术迭代退化为核心营销技术迭代（换壳、多版本、简配青春版），本质是创新乏力、用品牌势能蚕食对手。
- **结论**：错过风口期后，靠营销技术续命是衰退信号，应承认行业已进入长尾/末期。
- **结果**：诺基亚"以换壳为本"成笑谈，成为品牌末期经典警示。

### 案例 2：作者靠"内卷三征兆"七次脱身
- **问题**：如何避免在红海行业里越陷越深？
- **方法论的使用**：用"监管从严 / ROI 降低 / 培训割韭菜变多"三征兆判断行业到头，三十六计走为上；作者据此从白酒、药品、电信等 7 个消费周期的内卷中及时退出。
- **结论**：出现征兆就准备离场，越晚越被动。
- **结果**：多次避开内卷陷阱，把资源投向新窗口期。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 看到某个赛道爆火，纠结"现在进场还来不来得及"。
2. 所在行业利润下滑、对手疯狂价格战，犹豫要不要跟或撤。
3. 准备大笔预算做品牌建设，不确定时机对不对。
4. 公司处于"产品卖得动但想做品牌/文化"阶段，怕拔苗助长。
5. 投资人/合伙人问"这个行业还能不能投、什么时候退"。

### 语言信号（用户的话里出现这些就应激活）

- "现在入局 XX 行业晚不晚 / 是不是太晚了？"
- "我们行业是不是到头了 / 越来越卷了 / 该不该撤退？"
- "要不要趁现在重金做品牌 / 打品牌广告？"
- "brand lifecycle / 风口期 / 内卷期 / 长卷 involution / 长尾期"
- "我们还在做产品，但老板想做品牌文化，对吗？"

### 与相邻 skill 的区分

- 与 `trust-endorsement`（S07）的区别：本 skill 判"时机与阶段"，信任背书解决"凭什么被信"，二者可先后用（先判期，再补背书）。
- 与 `client-selection`（S10）的区别：本 skill 看"行业周期"，客户选择看"具体客户/创始人值不值得接"。
- 与 `startup-zero-to-one`（S11）的区别：本 skill 是宏观赛道 timing，初创从零到一是微观冷启动动作。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判行业三期**
   - 完成标准：对照"风口（高利润、谁做谁挣）/ 内卷（监管严、ROI降、培训多）/ 长尾（创始人求稳）"三特征，给出行业所处阶段及置信度。

2. **判自身五级**
   - 完成标准：按"产品→名牌→品牌→信仰→文明"定位用户当前维度，指出是否越级（如在产品阶段想做文明）。
   - 判停条件：若已越级规划，则先回到当前级，停止"做文明"类动作，转步骤 3。

3. **给投入/退出建议**
   - 完成标准：基于前两步行，明确"重金做品牌 / 低调活着 / 走为上 / 升维破局（非降价）"之一，并给出 1 条可落地动作。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只问单条文案/视觉执行，不涉及行业 timing——转 slogan / visual-hammer skill。
- 政策强制型或强周期受控行业（如公用事业），三阶段模型解释力弱。

### 作者在书中警告的失败模式

- **内卷期降价一波流**（ce11）：破局第一反应是降价，结果利润、品牌、行业全输，"降价就是个一波流"；应靠共鸣升维而非降价。
- **长尾期做品牌是浪费钱**（ce12）：行业已进入长尾期仍大投品牌，投入产出极低。
- **在行业"发烧时"进场必死**（ce20）：等全民狂热才入局必接盘，应在"发烧前夜"进场。
- **跨越阶段做品牌/文明**（ce31）：产品阶段就想做品牌、品牌阶段想做文明，地基未稳先飘，必夭折。

### 作者的盲点 / 时代局限

- **"风口期做品牌"假设流量红利仍在**：书成于 2020–2022，当下抖音算法、直播生态、AIGC 已改变"一战定江山"的成本结构，风口期窗口更短、更易被复制。
- **一刀切 timing**：作者把"长尾期做品牌=浪费"说死，但部分长尾行业靠品牌升级（如老字号国潮）仍可翻红，需结合品类判断。

### 容易混淆的邻近方法论

- **生命周期 vs 品牌五维度**：前者是行业外部周期，后者是品牌内部演进，常被混为一谈；一个看"赛道"，一个看"自己"。
- **内卷破局"升维" vs 盲目多元化**：升维是往国民共鸣走，不是融资后瞎扩张（见 ce21 揠苗助长）。
