## I — 方法论骨架 (Interpretation)

写广告语的核心不是"把产品说对"，而是"挖出潜台词、重新定义产品和用户的关系"。越正确（堆卖点、讲承诺）越无力，因为信息海洋里正确的话太多了。

作者给了两个可操作的达标尺：
- **封杀品类**：说出这句话，竞争对手就没法再说了（如"找工作我要跟老板谈"）。最狠的是彻底封死整条赛道。
- **熟悉又陌生**：基于一个普遍常识/洞察（熟悉），又是第一次被搬到台面上讲（陌生）。

还有一条常被忽视的写法铁律：**写个体宣言，不写上帝视角**。出圈的句子是"一个具体的人的真实独白"（如"我要站着把钱挣了"），不是替群体发声的官方通稿。用户要的是秒懂，不是被教育。

## A1 — 书中的应用 (Past Application)

### 案例 1：BOSS 直聘"找工作，我要跟老板谈"
- **问题**：招聘行业格局已定，初创 BOSS 直聘需要一句能颠覆行业的话。
- **方法论的使用**：用潜台词把求职者放到主动位（重新定义"求职者与平台"的关系），并用二元论封杀品类——说出后对手只能往"跟小兵谈"挤。
- **结论**：一句 9 字口号同时占住"主动"心智与赛道定义权。
- **结果**：品牌每年用户翻倍，5 年纳斯达克上市，市值超百亿美元。

### 案例 2：人头马"人头马一开，好运自然来"
- **问题**：白兰地赛道各家都在讲品质、年份。
- **方法论的使用**：用"好运/吉利"这个潜台词封杀赛道——占住后，其他品牌再没法讲好运，只能往家族传承、贵族风范挤。
- **结论**：最狠的广告语彻底封死赛道，逼对手无路可走。
- **结果**：在白兰地赛道封死"好运吉利"话术，成为品类经典 slogan。

### 案例 3：Ulike"高级女人用高级的"
- **问题**：脱毛仪赛道靠参数内卷，Ulike 市占率卡在 30% 左右。
- **方法论的使用**：不承诺痛点，而是用潜台词激活女性"追求更好自己"的行动力，并借"高级"拔高女性地位（熟悉=爱美，陌生=被第一次点破"高级"）。
- **结论**：一句不"正确"的话反而撬动了购买欲。
- **结果**：市占率 4 个月从 31% 升到 55%，成天猫脱毛仪品类冠军。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 给新品牌/新品想一句 slogan、口号、品牌主张。
2. 手头有句文案，但觉得"对但无聊、记不住、没效果"，要改。
3. 评审一句广告语是否值得投放，要一把可量化的尺。
4. 短视频/直播间的口播金句、钩子文案怎么写。
5. 想用一句"个体宣言"代替"企业宣言"来拉近距离。

### 语言信号（用户的话里出现这些就应激活）
- "帮我想句广告语/口号" / "write me a slogan / tagline"
- "这句话太正确了没人记，怎么改？" / "this copy is correct but boring"
- "怎么让 slogan 封杀品类？" / "how to make a category-killing line"
- "文案要有潜台词" / "the copy needs subtext"
- "写个体宣言别写官腔" / "make it a personal manifesto, not corporate"

### 与相邻 skill 的区分
- 与 `brand-naming` 的区别：本 skill 产出的是"一句话主张"，naming 产出的是"品牌/产品叫什么名字"；名字可等于品类，slogan 是句子。
- 与 `creative-chemistry` 的区别：本 skill 聚焦单句文案的达标（封杀品类/潜台词），creative-chemistry 聚焦整条内容为何没传播力（情绪/结构）。
- 与 `binary-positioning`（其他 agent 负责）的区别：二元论是定位武器，本 skill 把它当作写 slogan 的手法之一。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **挖潜台词：重新定义"产品与用户的关系"，而非罗列卖点**
   - 完成标准：写出一句"用户看了会换个态度/位置看待自己"的话，而不是"我们产品有 X 功能"。若仍停留在功能罗列，重做本步。

2. **用两把尺卡：封杀品类 + 熟悉又陌生**
   - 完成标准：①能说明"对手为何接不住这句话"（封杀品类）；②能说明"它基于什么常识、又第一次被讲出"（熟悉又陌生）。两把尺任一不过则回到第 1 步。

3. **改成个体宣言，去掉上帝视角与爹味**
   - 完成标准：句子读起来像"一个具体的人说的人话/独白"，不是群体宣言；可被目标用户秒懂，无教育口吻。
   - 判停条件：若用户品类为高客单价/专业服务且要求"高端克制"，则保留克制但须仍满足"熟悉又陌生"，不强行制造冲突。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 写长篇软文、公众号推文、产品说明书——本 skill 只管"一句主张"。
- 用户要的是纯视觉/包装 slogan 设计（交给视觉锤相关 skill）。
- 用"正确承诺堆砌"当作 KPI 验收（见下方反例）。

### 作者在书中警告的失败模式
- 过度追求"正确"导致广告无效（ce07）：堆卖点、讲老板情怀，结果无力疲软、毫无才华。
- 文案爹味十足火不了（ce25）：堆修辞炫技、试图教育用户而非秒懂。
- 站在上帝视角替群体说话=不是人话（ce26）：群体视角缺乏血肉，出不了圈。

### 作者的盲点 / 时代局限
- "越正确越没效果"贬低了策略严谨性与数据驱动，对投流 ROI 优化这种需严谨归因的场景有误导风险——该场景下"正确且可归因"的话术仍然必要。
- 书成于 2021–2022，短视频/直播话术生态此后变化很大，具体句式需结合当下平台习惯。

### 容易混淆的邻近方法论
- **潜台词 vs 正确承诺**：用户常把"把卖点写清楚"当成好文案，作者恰恰反对。
- 与 `brand-naming` 易混：名字是名词，slogan 是句子，二者验收标准不同（命名看"是否等于品类/卖点"，slogan 看"是否封杀品类"）。
