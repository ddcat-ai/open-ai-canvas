## I — 方法论骨架 (Interpretation)

蹭热点不是简单地转发一条热搜，而是一套"心态 + 手法"的组合拳。

1. **心态平、脸皮厚**：比你有势能的人/事更宽容，主动贴上去不会真计较，关键是克服"不好意思"。
2. **手法三动作——贴、靠、要**：贴上去（找到与热点的自然关联）、靠上去（借大事件/大人物/大平台的背书）、硬要（主动争取曝光位与互动）。
3. **为什么有效**：消费者有"选择性忽视"心理， ordinary 广告大多被无视；只有噪声、冲突、与热点的关联才被看见。不借势，你的素材每天被热点清零。
4. **决策核心**：不是"蹭不蹭"，而是"该不该蹭、怎么蹭才低成本且拿到信任背书、何时该止步"。能关联到品牌价值点才蹭，否则是浪费。

## A1 — 书中的应用 (Past Application)

### 案例 1: 东京奥运会期间国产品牌借势（c33）
- **问题**: 多个国产品牌并非奥运赞助商，想借赛事全球热度，却没有官方身份，又怕蹭得生硬、翻车。
- **方法论的使用**: 用"贴、靠、要"心法，写"显示准，才能射击精准""每一刻，都是伟大时刻"等关联文案，既蹭到赛事情绪，又拿捏分寸感。
- **结论**: 非赞助商也能用关联文案低成本借势，拿到参与感与信任背书。
- **结果**: 完成低成本信任背书，有参与感又不过界。

### 案例 2: 金枪大叔零投流借抖音（c17）
- **问题**: 红制作没投过一分钱广告费，作者需要为自身打造可对外背书的个人IP。
- **方法论的使用**: 不买流量，靠"一张嘴、几句金句"借抖音平台的流量之势，塑造"金枪大叔"形象，与红制作互为背书。
- **结论**: 借平台红利做零成本信任背书比硬买量更可持续。
- **结果**: 零买量获约 300 万粉丝，成为营销网红，与红制作互相背书。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 某个热搜/节日/大事件爆发，团队争论"我们要不要蹭、值不值得"。
2. 想借一个大公司、大人物、大平台的背书，但不好意思主动开口。
3. 热点来了，不确定怎么蹭才不尴尬、不引发反感。
4. 借势之后担心越界、侵权或违反平台规则。
5. 想用"评论家/第三方"策略低成本获取行业可信度。

### 语言信号 (用户的话里出现这些就应激活)

- "我们要不要蹭这个热点？"
- "这个事能不能借势 / 借力打力 / 贴靠要 一下？"
- "该不该借这个大V / 这个事件？"
- "should we ride this trend? / how to newsjack this topic?"
- "热点营销怎么做才不尴尬 / 不翻车？"

### 与相邻 skill 的区分

- 与 `marketing-event`（S14）的区别：S04 只判断"要不要蹭外部已有热点、怎么贴"，不负责策划品牌自有营销事件；S14 是从零策划自有事件。
- 与 `borrow-momentum-overview`（S01）的区别：S01 是借势总纲，S04 是总纲中"借万物/借噪声"的具体战术决策点。
- 与 `black-fan-noise`（S08）的区别：S08 是主动制造自有争议与噪声，S04 是借已存在的外部热点之势。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **判定热点是否可蹭**
   - 完成标准: 输出"关联点清单"（热点与品牌价值/人群/品类的自然连接），或明确写出"不蹭理由"。
   - 判停条件: 若热点涉政治敏感、版权不明、与品牌调性严重冲突、或已完全过时 → 直接判停，输出"放弃蹭势"，跳到步骤 3 收尾。

2. **用"贴、靠、要"设计借势动作**
   - 完成标准: 产出一条可发布的借势内容（文案/图/短视频），并标注借势对象与关联点；"贴"要有自然关联、"靠"要借到势主体、"要"要明确争取的曝光动作。

3. **控制分寸与风险后发布**
   - 完成标准: 借势内容通过"分寸感"自检（有参与感、不篡改原意、不碰版权、留好退路），方可发布；若任一不通过则回改或判停。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 品牌已有强自有声量，靠常规内容就能触达——借势边际收益低。
- 热点已过时（书中提醒：你的素材每天被热点清零）。
- 纯内部事务，与外部热点无逻辑关联。

### 作者在书中警告的失败模式

- **套用西方旧传播理论走弯路（ce19）**: 用上个世纪的强势媒介/古典传播逻辑操盘新媒介热点，方法与新媒介不产生化学反应，自然走弯路。蹭势必须适配当下平台生态。
- **蹭热点越界 / 版权风险（本书轻描淡写，需补边界）**: 书中"贴靠要"几乎不谈合规，但现实中篡改原意、碰版权、借敏感事件，会触发平台限流/封号与舆论反噬。这是使用本 skill 必须主动加的红线。

### 作者的盲点 / 时代局限

- 书中案例多为 2021 双十一、东京奥运（2021），此后抖音算法、直播生态、AIGC、平台治理（对过度营销/借势操纵的合规约束）剧变，"贴靠要"的具体玩法时效性很强。
- 作者对"平台规则与合规风险"着墨极少，把"脸皮厚硬要"当作普适心法，未充分提示越界代价。

### 容易混淆的邻近方法论

- 与 S14 营销事件策划：借外部热点 vs 造自有事件。
- 与 S08 黑粉噪声：借已有势 vs 造自有争议。
