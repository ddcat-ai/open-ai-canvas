## I — 方法论骨架 (Interpretation)

品牌延伸是"把一个知名产品的品牌用在一个新产品上"。作者称它是**搭便车陷阱的终极版本**，而且明确指出：**逻辑都在品牌延伸这一边，但真理不在。**

支持延伸的推理是完美的由内而外思维："我们的 Dial 肥皂卖得最好，顾客看到 Dial 除味剂就知道它了不起，会期待我们做出好的除味剂。"经济学理论支持它，行业认可它，它能降低广告成本、增加收入、有利于公司形象。

由外而内看则完全相反。在心智里拥有定位意味着什么？意味着**这个品牌名变成了某个通用名词的替代物**——"来一瓶可口可乐"、"拜耳放在哪儿"、"把 Dial 递给我"。定位越稳固，这种替代发生得越频繁。而一旦你让这个名字同时指向另一样东西，替代关系就断了：顾客说"把 Dial 递给我"时不知道你指的是肥皂还是除味剂，于是这个名字对两样东西都失去了指代能力。

这就是**跷跷板原则**：一头上去，另一头就下来。亨氏把自己从泡菜第一变成番茄沙司第一，代价是把泡菜的领先地位让给了 Vlasic。作者还补了一句更狠的观察："有名望的大公司通常难以竞争得过规模较小，但定位明确的公司。规模并不重要，重要的是定位。"

三个当场可做的检验：

- **购物单检验**：在购物单上写下这个品牌名。别人拿着单子去买，能买对吗？如果需要额外补一句说明，延伸就失败了。
- **酒保检验**：在嘈杂环境里对着别人喊出这个名字，对方递过来的是不是你想要的东西？
- **跷跷板检验**：如果新东西成功了，老东西会失去什么位置？把这个代价写出来。如果写不出来，说明你还没想清楚。

延伸确实有效的例外（作者在第13章给出）：**短期收割**（用现有声望快速铺货，接受长期稀释）、**品类已到天花板**（老位置本来也守不住了）、**同一心智格子内的自然延展**（强生婴儿洗发水到婴儿系列，格子还是"婴儿"）、**用真正独立的副品牌隔离**（新名字带新梯子，母品牌只做背书）。

## A1 — 书中的应用 (Past Application)

### 案例 1：施乐进计算机
- **问题**：施乐拥有复印机的心智定位，90% 业务来自复印机，想让施乐也代表计算机。
- **方法论的使用**：跷跷板原则——"施乐代表着复印机，不是计算机。就连施乐公司也知道这一点。"
- **结论**：要在计算机上成功，施乐就得让"施乐"代表计算机，这对一家 90% 业务来自复印机的公司显然不合适。
- **结果**：施乐计算机成为商业史上著名的失败。

### 案例 2：亨氏的泡菜与番茄沙司
- **问题**：亨氏原本拥有泡菜定位、市场份额最大，后来让亨氏代表番茄沙司，此举很成功。
- **方法论的使用**：作者追问"跷跷板的另一头怎么样呢？"
- **结果**：亨氏成为番茄沙司领导者，同时把泡菜的领先地位拱手让给了 Vlasic。作者补充：亨氏的规模和名望都超过 Vlasic 和 Gerber，但 Vlasic 的泡菜销量和 Gerber 的婴儿食品销量都超过了亨氏。

### 案例 3：Dial 肥皂 → Dial 除味剂
- **方法论的使用**：由内而外的完美推理 vs 由外而内的现实。
- **结果**：Dial 仍拥有庞大的肥皂份额，除味剂份额却非常小。

### 案例 4：不含阿司匹林的拜耳
- **问题**：拜耳想用自己的名字去卖对乙酰氨基酚。
- **结论**：作者形容为"成年男人围坐在董事会办公室的会议桌旁做出决定"。这个名字要求顾客同时接受"拜耳=阿司匹林"和"这个拜耳不含阿司匹林"。
- **结果**：份额微不足道。后续的"拜耳优质产品系列"花了 1.1 亿美元宣传，第一年销售额只有 2500 万美元。

### 案例 5：Advent 与 Qwip
- **Advent**：占住了投影电视这个空位，CEO 决定"把 Advent 及其分支业务从老路上带出来，打进家庭娱乐中心行业"。结果上了破产法院。
- **Qwip**：占住低价传真机空位（出租量超过其他所有品牌总和），后来埃克森决定用埃克森的名字推全套办公设备，办公系统分部持续赤字后关门。作者："一家汽油公司怎么会懂得办公用品呢？"

### 案例 6：Del Monte vs 都乐（延伸的相对性）
- **方法论的使用**：Del Monte 用一个品牌卖所有罐头水果蔬菜，也许是对的——**直到出现一个只做一件事的对手**。
- **结果**：在罐装菠萝上 Del Monte 根本不是都乐的对手，"都乐每个回合都赢"。而如果都乐再让自己代表香蕉，跷跷板就会在香蕉和菠萝之间摆动。

### 案例 7：李维斯（坚持的反面）
- **问题**：李维斯做品牌延伸进入休闲服饰领域。
- **结果**：它在牛仔服领域的基本定位受到"设计师标签"牛仔的冲击。作者总结："一旦定位丢失，品牌就是无锚之船，漂浮不定。"

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 有人提议"新品就用我们现有品牌名，省一笔推广费"。
2. 内容账号想从一个品类扩到另一个品类。
3. 公司要进新业务，默认用公司名。
4. 开源项目想把 scope 从一件事扩到一个平台。
5. 个人已经在某领域有标签，想再打一个新标签。
6. 已经占住一个空位，觉得"这个位置太窄了"想扩张。
7. 领导者要进新品类（`positioning-leader-defense` 的下游）。

### 语言信号（用户的话里出现这些就应激活）

- "直接用我们现有的牌子就行"
- "反正大家都认识我们"
- "能省一大笔广告费"
- "我们账号也做点别的内容"
- "这个位置太窄了，想扩一扩"
- "公司要转型做 XX"
- "should we launch under the same brand" / "brand extension"

### 与相邻 skill 的区分

- 与 `positioning-name-power` 的区别：本 skill 判断"**能不能沿用**旧名字"，`name-power` 解决"**新名字**该怎么起"。本 skill 的结论若是"不能沿用"，转 `name-power`。
- 与 `positioning-all-things-trap` 的区别（**关键**）：本 skill 处理**一个名字承载了多样东西**（品牌被摊薄）；`all-things-trap` 处理**一个东西试图讨好所有人**（人群与用途被摊薄）。二者可以同时发生但入口不同：如果症状是"顾客不知道我们这个牌子是干什么的"，用本 skill；如果症状是"顾客知道我们干什么，但不知道这是给谁的"，用 `all-things-trap`。
- 与 `positioning-fwmts-trap` 的区别：本 skill 是"往外摊"（增加新的意义），`fwmts` 是"把已有的丢掉"（放弃有效的旧意义）。都是稀释，方向相反。
- 与 `ability-simplification` 的区别：后者简化的是**用户要执行的操作步骤**（表单少一栏、流程少一步），本 skill 收敛的是**品牌承载的意义数量**。名字里都有"简化"的意思，但对象完全不同。
- 与 `positioning-leader-defense` 的区别：后者给出"领导者进新品类要用新品牌"这条原则，本 skill 提供判断这条原则是否适用于当前具体情况的检验工具。

## E — 可执行步骤 (Execution)

1. **写出母品牌当前代表的那一个词**
   - 问顾客/用户："说到【品牌名】，你想到什么？"要求答案收敛到一个词或一个短语。
   - 完成标准：拿到一个明确的词（施乐=复印机，Dial=肥皂）。
   - 判停条件：若顾客说不出一个词，说明母品牌本来就没有定位——那么延伸不会稀释什么，但也借不到什么力，本 skill 的风险判断不成立，转 `positioning-find-the-hole` 先建立定位。

2. **购物单检验**
   - 在纸上只写品牌名，交给一个不知情的人去取东西。
   - 完成标准：对方能取对，且不需要你补充说明。
   - 不通过 → 记 1 个失败项。

3. **酒保检验**
   - 在嘈杂环境中只喊出这个名字，看对方递过来什么。
   - 完成标准：递过来的是新产品而不是老产品（或至少对方会反问"哪一种"而不是默认给老的）。
   - 不通过 → 记 1 个失败项。

4. **跷跷板检验**
   - 明确写出：**如果新东西成功了，老东西会失去哪个位置？谁会接走它？**（亨氏→Vlasic）
   - 完成标准：写得出具体的位置与接盘者。
   - 判停条件：若这个代价大于新东西的预期收益，直接否决。
   - 写不出来 → 说明还没想清楚，不算通过。

5. **数失败项并分流**
   - **0 个失败项** → 这不是真正的延伸，而是同一心智格子内的自然延展（强生婴儿洗发水→婴儿系列）。可以做。
   - **1 个失败项** → 高风险。必须用副品牌隔离：新名字带新梯子，母品牌只在背面小字做背书。转 `positioning-name-power`。
   - **2-3 个失败项** → 否决。必须用独立新名字。转 `positioning-name-power`。

6. **检查四种有效例外**
   - **① 短期收割**：明确承认这是拿长期资产换短期铺货，并写下预计的稀释成本与退出时点。
   - **② 品类天花板**：老位置本来就守不住了（品类在消失），此时稀释成本趋近于零。
   - **③ 同格子延展**：新东西和老东西在顾客心里属于同一个"格子"。
   - **④ 副品牌隔离**：新名字是主角，母品牌只做信用背书。
   - 完成标准：若用户坚持延伸，必须落进这四种之一并写明属于哪一种。

7. **补充检查：逆向延伸**
   - 若发现产品名远比公司名有名，正确动作可能是**反过来**——把公司名改成产品名（而不是把公司名套到产品上）。
   - 完成标准：识别这种情形并给出建议。

8. **输出自检报告**
   - 含：母品牌代表的词、三检验结果、跷跷板代价、失败项数、结论（可做/副品牌/否决）、若做则属于哪种例外。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **母品牌本来就没有明确定位**。没有可稀释的资产，本 skill 的核心风险判断失效。
- **纯 SKU/型号扩展**（同一产品的不同容量、颜色、配置）。这不是品牌延伸，是产品线管理。
- **B2B 集团背书型架构**。在采购方看重"这家公司够不够大、能不能活下去"的场景里，集团名的背书价值可能高于品类聚焦的价值。
- **成本结构决定生死的场景**。如果独立品牌的营销成本会直接导致项目不可行，那么问题应先在商业模型层面解决，而不是在定位层面。
- **奢侈品与设计师品牌**。这类品牌的资产建立在"创始人/设计者的品味"而非"某个品类"上，延伸逻辑不同（见下方时代局限）。

### 作者在书中警告的失败模式

- **跷跷板**：亨氏拿泡菜换番茄沙司；施乐拿复印机赌计算机。
- **由内而外的完美推理**：Dial 的董事会逻辑。"逻辑都在品牌延伸这一边，但真理不在。"
- **占住空位后自己放弃**：Advent 破产、Qwip 关门、米狮龙换广告语。
- **用旧名字卖对立概念**："不含阿司匹林的拜耳"，1.1 亿换 2500 万。
- **多面手输给专一者**："有名望的大公司通常难以竞争得过规模较小，但定位明确的公司。规模并不重要，重要的是定位。"Del Monte 输给都乐，亨氏输给 Vlasic 和 Gerber。
- **定位丢失后无锚**：李维斯延伸到休闲服后，牛仔服本业被冲击。

### 作者的盲点 / 时代局限

- **最大的反例是作者写作之后才出现的：苹果**。Apple 从电脑延伸到音乐播放器、手机、手表、耳机、服务，几乎每一次都成功。同类还有维珍、小米、亚马逊、三星。这些案例说明：**当品牌代表的不是一个"品类"而是一种"能力承诺"或"生活方式"时，跷跷板原则会显著减弱。** 使用本 skill 时应先判断母品牌属于"品类型"（施乐=复印机）还是"承诺型"（苹果=好用的设计）——只有品类型品牌才严格适用。
- **作者的立场有商业利益**。特劳特与里斯经营定位咨询业务，"新品类需要新品牌"这个结论恰好意味着更多的命名与定位咨询需求。这不否定论证，但读者应知道这个激励结构的存在。
- **只算稀释成本，不算独立品牌的建立成本**。书中反复说延伸会稀释，但从未量化"另起一个品牌需要多少钱、多长时间、失败率多高"。在资源有限的现实里，一个被稀释但活着的品牌可能优于一个纯粹但死掉的新品牌。**本 skill 的例外①（短期收割）就是为补这个缺口而保留的。**
- **数字平台改变了成本结构**。1980 年建立一个新品牌意味着重新买一遍全国广告；今天在应用商店、社交平台、搜索引擎上建立一个新名字的边际成本大幅下降，这实际上**强化**了作者的建议（更应该用新名字），但也让"副品牌隔离"变得比当年更可行。
- **平台型与生态型产品不适用**。当产品本身的价值来自"什么都能做"（操作系统、超级 App、云平台），聚焦单一品类反而是劣势。
- **案例全部是美国快消品**，且都是事后挑选的。作者没有统计过品牌延伸的总体成功率，"绝大多数延伸失败"这个印象是案例选择造成的。

### 容易混淆的邻近方法论

- **品牌架构（Branded House vs House of Brands）**是完整的架构方法论，本 skill 只提供其中"该不该共用名字"这一个决策点的快速检验。
- **产品线扩展（line extension）与品牌延伸（brand extension）在学术上是两个概念**：前者是同品类内的变体，后者是跨品类。作者把两者混用，本 skill 通过"三检验"在操作上区分了它们——同品类变体通常三检验全过。
- **`positioning-all-things-trap`**：处理人群与用途的摊薄，不是名字的摊薄。
- **`ability-simplification`**：处理操作步骤的简化，与品牌无关。
