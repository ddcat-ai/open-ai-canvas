## I — 方法论骨架 (Interpretation)

占领心智需要"视觉符号 + 反复植入的词语"这一对组合拳，再加上用事件把它们钉进去。

1. **视觉锤**：一个具象、过目难忘的符号（如金枪大叔的白发、乌尼莫克），负责被记住。它不是抽象 logo，而是有画面感的人/物/动作。
2. **文字钉**：一个随阶段变化的重点词（如"解气""秀发更出众"），负责被传播。它会被反复钉入心智，不是一劳永逸的 slogan。
3. **锤 + 钉必须成套**：单有 logo 或单有口号都不够，两者要共同"钉"进大众心智。
4. **第三步是营销事件**：预算不足的反而是核心洞察——用创意做几个事件（甩头发、乌尼莫克救援），把符号和词语真正钉进公众记忆。没有事件，锤和钉都悬空。
5. **拒绝标识的语境**：年销售 1 亿以下，品牌名即标识，不必先烧钱做 logo；视觉锤+文字钉比抽象 VI 更省钱有效。

## A1 — 书中的应用 (Past Application)

### 案例 1: 金枪大叔个人IP（c17）
- **问题**: 作者要给红制作做零成本的对外背书，没有预算投流。
- **方法论的使用**: 以过目难忘的白发为视觉锤，配"解气""秀发更出众"等文字钉，再用甩头发、乌尼莫克救援等营销事件成形。
- **结论**: 视觉锤+文字钉+事件三步，零买量也能建立可背书的个人IP。
- **结果**: 零买量获约 300 万粉丝，与红制作互为背书。

### 案例 2: 小米从零开始的视觉锤/文字钉（c04）
- **问题**: 2013 年小米初创，员工还在望京卷石大厦，需要统一形象与对内思想。
- **方法论的使用**: 红制作十余天策划《100个梦想的赞助商》，后做品牌宣言《我们的时代》，用视觉化内容与统一话术把"为发烧而生"钉入粉丝心智。
- **结论**: 用视频事件+品牌宣言承载文字钉，对外统一形象、对内统一思想。
- **结果**: 小米成世界 500 强，红制作合作 8 年。

### 案例 3: 小米换标识的声量高度（c22）
- **问题**: 小米想用一次动作霸占媒体头条。
- **方法论的使用**: 花 200 万请原研哉把方标改圆标，用"视觉变更"这一强符号制造全网讨论（可视作一次视觉锤刷新的营销事件）。
- **结论**: 极致诉求的视觉动作能形成"流量黑洞"。
- **结果**: 换来全网超 72 小时流量黑洞，每个讨论者都成小米推手。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 个人/新品牌从零起盘，想要"被人记住"的识别系统，但预算极低。
2. 想打造创始人IP或个人账号，需要标志性视觉与口头禅。
3. 品牌已有名字但没人记得住，需要补视觉记忆点。
4. 准备策划几个低成本的营销事件来固化认知。
5. 分不清"视觉锤"和"logo"的区别，想知道没钱时先做什么。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么打造个人IP / 让人记住我？"
- "我的品牌需要一个视觉符号 / 标志动作"
- "从零开始怎么建品牌识别？"
- "visual hammer / verbal nail / build a personal brand / how to be memorable"
- "没钱做logo，先用什么让人记住？"

### 与相邻 skill 的区分

- 与 `slogan-generator`（S02）的区别：S02 产出一句广告语文案，S06 的"文字钉"是可随阶段替换、配套视觉锤反复植入的关键词，且必须和视觉锤+事件成套。
- 与 `marketing-event`（S14）的区别：S14 是策划事件的方法论，S06 把"做几个营销事件"当作视觉锤/文字钉落地的第三步，事件服务于识别系统。
- 与 `brand-naming`（S03）的区别：S03 解决"叫什么名字"，S06 解决"被记住的视觉+词语组合"。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **定义视觉锤**
   - 完成标准: 产出一个具象、过目难忘的视觉符号或标志性动作（人物特征/产品外形/固定行为），并说明它为何能被记住。

2. **定义文字钉**
   - 完成标准: 产出一个可反复强调的核心词/短句（随阶段可替换），并标注它将配套的视觉锤。

3. **策划 2–3 个营销事件把锤和钉钉进去**
   - 完成标准: 列出 2–3 个低成本事件（如标志性动作、救援/挑战、公开表达），每个事件都同时承载视觉锤与文字钉；预算不足被明确当作核心洞察。
   - 判停条件: 若用户已有成熟 VI 体系且仅需微调 → 转品牌设计建议，不必重建视觉锤。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 已有成熟 VI/logo 体系、只需局部优化（Visual hammer 价值有限）。
- 纯功能型 B2B 品牌，决策链看参数与案例，视觉符号边际价值低。
- 用户其实只想要一句 slogan（转 S02）。

### 作者在书中警告的失败模式

- **产品无"三性"必然失败（ce02）**：视觉锤/文字钉再强，若产品本身无社交性/知识性/娱乐性，用户凑不够图发朋友圈、无法裂变，品牌做不起来。锤钉是放大器，不是产品力的替代。
- **审美领先潮流过多会死（ce32）**：视觉锤若过度超前于大众审美（领先 10% 以上），用户"看不懂"反而成为传播障碍。视觉锤要过目难忘，不是怪异难懂。

### 作者的盲点 / 时代局限

- 书中视觉锤案例（白发、乌尼莫克）高度依赖作者个人特征与时代平台（抖音早期红利），可复制性因人而异；AIGC 时代视觉符号生产门槛骤降，"稀缺视觉"更难天然成立。
- "拒绝标识"（1 亿以下不需 logo）对需要专业信任背书的 To B/高客单品牌未必适用。

### 容易混淆的邻近方法论

- 与 S02 slogan-generator：文字钉 vs 广告语文案。
- 与 S14 marketing-event：事件落地 vs 事件策划方法论。
- 与 S03 brand-naming：名字 vs 识别组合。
