## I — 方法论骨架 (Interpretation)

营销不是说服理性大脑，而是找到每个人群"心智的软肋入口"——即他们自己都没说出口的欲望与焦虑。

1. **底层三弱点**：任性（我的地盘我做主）、贪心（爱性价比）、虚荣心（奢侈品/汽车基底）——一切产品与文案设计都应锚定其中之一。
2. **打开心智的三把钥匙**：利益（让他占便宜）、尊重（让他觉得智力高人一等）、习惯（指名购买、羊群效应）——至少占一把才能撬动购买。
3. **人群 profiling 框架**：把目标人群拆成"软肋清单"——富婆（怕失去/门槛高更兴奋/独立人格）、男人（补童年缺陷，且中年男人媳妇管钱）、女性（母爱/梦幻/自卑）、土豪（仗义/受不了温柔/冲动）、宝妈（一人花三份钱/购买治焦虑/走进一个=一群）、宅女（奶茶/虐文/剧/快递/漫展）、宅男（洛丽塔/智能硬件/游戏）。
4. **贩卖遗憾**：人不断失去（童年/青春/初恋）→ 遗憾生焦虑 → 焦虑促购买；"只剩最后一个"就是把遗憾变稀缺。
5. 用法是**先建软肋清单，再写话术**：进入任一人群前，先找它的心智入口，按入口设计诉求，而非堆功能参数。

## A1 — 书中的应用 (Past Application)

### 案例 1：特斯拉——用"虚荣心 + 超我"唤醒消费冲动
- **问题**：特斯拉作为新品牌，如何让人愿意为"飞火星"这种看似无用的愿景买单？
- **方法论的使用**：作者以特斯拉说明，借"人性弱点·虚荣心"与"超我生意"——宏大愿景（移民火星）、杰出事件营销（炸火箭/送跑车上太空）唤醒冲动，让百年车企成小弟。
- **结论**：戳中虚荣与宏大叙事，比讲参数更能驱动高净值人群。
- **结果**：特斯拉让传统车企成小弟，上海超级工厂助其熬过财务危机。

### 案例 2：上海迪士尼 / 北京环球影城——女性心智的"梦幻 + 社交性"
- **问题**：大型游乐场开业为何能成全民话题？
- **方法论的使用**：作者用其说明产品"社交性"（不发朋友圈不足以证明来过）与"女性心智·梦幻"（梦想可实现）——开园初期制造社交恐慌"这你都不知道你过时了"。
- **结论**：同时命中女性"梦幻"与"社交优越感"双入口，自然引爆打卡。
- **结果**：开园初期成躲不开的话题，带动打卡与消费。

### 案例 3：茅台 / 阿那亚——对症下药三货币
- **问题**：不同收入人群用什么"货币"打动？
- **方法论的使用**：作者以茅台（权力货币打动高收入、好赚不好骗）、阿那亚（社交货币打动中等收入、好骗又好赚）说明按收入分层用不同价值语言。
- **结论**：对高收入讲权力、对中等收入讲社交，货币用错则无效。
- **结果**：成为各自收入圈层的代表性成交案例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写投放/直播话术，不知道对目标人群该戳"怕失去"还是"占便宜"还是"优越感"。
2. 做母婴/美妆/男性向产品，想定位精准心智入口而非泛泛而谈。
3. 设计限时/限量/稀缺文案，想触发"遗憾→焦虑→购买"。
4. 私域/社群运营，想提高复购（习惯钥匙）或客单价（宝妈一人三份）。
5. 评估"我的用户到底是谁、他们真正想要什么"。

### 语言信号（用户的话里出现这些就应激活）

- "怎么戳中用户 / 怎么写转化话术 / audience psychology 心智软肋？"
- "宝妈 / 女性 / 富婆 / 中年男人 这个人群怎么打？"
- "人性弱点 / 消费心智钥匙 / 利益尊重习惯"
- "贩卖遗憾 scarcity / 只剩最后一个 / 叫卖话术怎么写？"
- "我的用户到底想要什么 / 怎么让人下单？"

### 与相邻 skill 的区分

- 与 `trust-endorsement`（S07）的区别：本 skill 戳"对方软肋促成单"，信任背书是"立自己可信度"；常先背书立信、再用人心软肋成交。
- 与 `brand-lifecycle`（S09）的区别：本 skill 是"对谁说、说什么"，生命周期是"行业 timing"，二者正交。
- 与 `slogan-generator`（S02，跨组）的区别：本 skill 给"人群软肋与话术方向"，slogan 给"具体广告语写法"；软肋是上游输入。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **建人群软肋清单**
   - 完成标准：明确目标人群（如宝妈/女性/富婆/中年男人），列出其 1–3 条心智软肋（母爱/梦幻/自卑/怕失去/补童年缺陷等），不写泛泛"爱便宜"。

2. **选钥匙 + 弱点**
   - 完成标准：从"利益/尊重/习惯"三钥匙与"任性/贪心/虚荣"三弱点中，各定 1 个主攻方向，且与步骤 1 软肋自洽。
   - 判停条件：若用户只做 B2B 技术选型、无消费心智维度，则停止，建议转其他 skill。

3. **写话术 / 钩子**
   - 完成标准：基于软肋+钥匙+弱点，产出≤3 条可落地话术或钩子（如"只剩最后一个"触发遗憾、"3、2、1 上链接"叫卖），标注命中哪条软肋。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯功能型 B2B 技术采购（决策靠参数与 ROI，非心智软肋）——转其他决策类 skill。
- 医疗/金融等强合规品类，利用焦虑/稀缺 manipulative 话术可能违规。
- 用户仅做品牌视觉，不涉及人群诉求。

### 作者在书中警告的失败模式

- **对中年男人直接营销无效**（ce35）：中年男人消费决策权在媳妇手中、本人缺乏消费动机；直投本人打错对象，应转向家庭决策链（媳妇/宝妈）。
- **"占领心智"是伪命题**（ce34）：用户心智会随更好对象转移，不能把"永久占领心智"当唯一 KPI，应聚焦"让用户占便宜"的真实驱动。

### 作者的盲点 / 时代局限

- **把"心智=软肋"工具化**：全书把人性弱点当可操控入口，弱化了理性决策与价值观认同；高知/高客单人群未必吃"贪心/虚荣"这套，需结合尊重与习惯钥匙。
- **时代局限**：书中案例多为 2021 双十一、东京奥运前后；当下平台对"制造焦虑/稀缺"的话术有合规收紧（如禁「最后的」虚假库存），照搬需合规校验。
- **样本偏差**：作者乙方视角下的人群画像（富婆/土豪/宅男宅女）偏流量操盘经验，未必覆盖全体真实用户，宜 A/B 验证而非照单全收。

### 容易混淆的邻近方法论

- **人性三弱点 vs 消费三钥匙**：弱点是"人本性"（任性/贪心/虚荣），钥匙是"撬动方式"（利益/尊重/习惯）；前者定方向，后者定手段，常配套使用。
- **各人群心智 vs 用户画像（ICP）**：本书"心智软肋"是心理入口，普通 ICP 是人口/行为属性；本 skill 补的是"为什么买"而非"是谁"。
