## I — 方法论骨架 (Interpretation)

信任背书是弱小品牌起步时最关键的一环——消费者"不买不行"的理由，本质来自六类可信度来源，而非单纯的产品功能。

1. **六类清单**：出身高贵（名校/名企背景）、财富（被验证过的成功）、奖项学历、人品（长期坚持的品格）、作品（拿得出手的代表作）、大佬推荐（关键人物的站台）。任何一类都能用，不必全有。
2. **缺啥补啥**：硬背书（出身、财富、学历）没有时，可用软背书替代——一部爆款作品、一次被权威转发、一段长期坚持的故事，都能成为"15分钟成名"式的终身背书。
3. **借来的背书**：背书可以主动"贴、靠、要"——借大事件、大人物、大平台的势能，比自己从零攒便宜得多。
4. **进阶梯子**：先用道德/情怀占领制高点，再占技术制高点，最终自然落到财富制高点；同时用资金、技术或时间抬高行业门槛，让"被信任"变成"难被替代"。
5. 用法是**自测 + 补短板**：先盘自己手上有哪几类，再决定下一步该积累哪一项。

## A1 — 书中的应用 (Past Application)

### 案例 1：红制作用"作品"做信任背书（零广告费起盘）
- **问题**：红制作是一家 5 人小公司，没有大投放预算，却要在 4A 广告公司面前抢客户，凭什么被相信？
- **方法论的使用**：作者把"作品"列为六大背书之一，用客单价 500 万以上的真实案例、陪跑小米/网易/BOSS 直聘等一线客户的成果，作为核心信任状；同时拒绝被乐视买断以保持独立背书。
- **结论**：小公司不必等"出身高贵"，用可验证的作品和头部客户结果就能建立信任。
- **结果**：人效比业内最高，产值相当于 400 人 4A 公司的 10 倍，并与红制作互为背书。

### 案例 2：温州朋友用"时间门槛"抬高信任与壁垒
- **问题**：一次性衣柜是低关注度、低毛利的小生意，同行陆续退出，凭什么做成世界第一？
- **方法论的使用**：作者在"抬高门槛"框架中指出，时间门槛（别人退出你坚持、剩者为王）是最容易被忽视的护城河；长期坚持本身就是一种可信度证明。
- **结论**：当资金、技术门槛都不高时，用"坚持 20 年"制造时间门槛，既抬信任又抬壁垒。
- **结果**：坚持 20 多年后，该公司一次性衣柜销量做到世界第一。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 个人 IP / 创始人要对外塑造人设，却说不清"我凭什么被关注"。
2. 初创品牌写融资 BP、招商手册，投资人/客户问"你们有什么背书"。
3. 乙方/服务商投标或提案，需要在没有大预算时证明自己靠谱。
4. 进入一个新行业/新平台，想快速借势建立可信度。
5. 发现竞品靠"大佬推荐/名校背景"碾压自己，想找自己的替代背书。

### 语言信号（用户的话里出现这些就应激活）

- "我该怎么让人相信我 / 怎么建立信任 trust？"
- "融资路演 / 招商材料里该写什么才显得靠谱？"
- "我没有大背景，只有作品，够不够？"
- "凭什么信我 / 我有什么背书 / 我有什么料可以讲？"
- "怎么借大佬 / 大平台的势给自己站台？"

### 与相邻 skill 的区分

- 与 `brand-lifecycle`（S09）的区别：本 skill 解决"我是谁、凭什么被信"，生命周期解决"我现在该不该重金做品牌、行业处在哪一期"。
- 与 `client-selection`（S10）的区别：本 skill 是"我如何获得他人信任"，客户选择是"我该不该信/接这个客户"。
- 与 `audience-psychology`（S12）的区别：本 skill 面向"建立可信度"，人群心智面向"戳中对方软肋转化"，二者可串联（先用背书立信，再用人心软肋成交）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **盘点六类背书**
   - 完成标准：列出"出身高贵 / 财富 / 奖项学历 / 人品 / 作品 / 大佬推荐"每一类下，用户当前已有与缺失的条目，缺口不超过两类未识别。

2. **选 1–2 项低成本补短板**
   - 完成标准：对缺失项给出可执行的积累动作（如整理一部代表作、争取一次权威转发、讲一段长期坚持的故事），并标注预期可信度提升。
   - 判停条件：若用户已有 ≥3 类硬背书，则跳到步骤 3，不必硬造软背书。

3. **借势 + 抬门槛**
   - 完成标准：给出"贴靠要"可借的外部势能（大事件/大人物/大平台），并判断能否用资金/技术/时间之一抬高门槛，形成"难被替代"的信任闭环。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 品牌已是行业头部、信任资产充足，只需做差异化表达而非自证——应转 `brand-lifecycle` / slogan 类 skill。
- 纯 To B 专业服务靠合同条款与交付能力成交，盲目堆"大佬推荐"反而显虚。
- 用户要的是功能卖点文案而非可信度证明——转 `slogan-generator`。

### 作者在书中警告的失败模式

- **"门槛低 = 割韭菜"**（ce29）：若有人说某行业"零门槛、上手快"，往往想割你韭菜；抬高门槛（资金/技术/时间）才是真护城河，别用"轻松速成"包装自己当背书。

### 作者的盲点 / 时代局限

- **乙方广告公司立场**：作者天然偏向"制造声量/事件背书"，弱化了产品力本身；背书能拉新，但留存与复购最终靠产品，不能把背书当经营全部。
- **合规风险着墨少**：书中大量"借势/借大佬/造噪声"玩法，在当下平台治理（限流、封号、虚假背书处罚）下有时效与合规约束，照搬需评估风险。
- **内部矛盾**：书中既说"品位是流量的敌人"（大众品牌先活着），又说高端要做"超我生意/高级趣味/占领道德制高点"——后者恰恰靠文化格调，对高端/小众品牌"贬品位"是错的。

### 容易混淆的邻近方法论

- **占领制高点 vs 道德绑架**：道德制高点是叙事工具，不是真做慈善；易与"真诚价值观"混淆，需防止空喊口号无技术/财富落地。
- **大佬推荐 vs 虚假代言**：借势需真实关联，伪造背书在合规与信任上都会反噬。
