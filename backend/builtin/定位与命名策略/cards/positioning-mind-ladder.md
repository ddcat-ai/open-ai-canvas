## I — 方法论骨架 (Interpretation)

人脑不是一个可以无限追加信息的容器，它是一组**分品类的、层数很少的排行榜**。每个品类一个梯子，梯子上从高到低码着几个品牌名。米勒的研究给出容量上限：同一品类里普通人能无提示说出的名字很少超过 7 个，绝大多数低关注度品类只有 1-2 个。

这带来一个反直觉的后果：**你的竞争不是发生在产品层面，而是发生在这几级台阶上**。如果你不在梯子上，那么无论你的产品多好、广告多贵，信息都会被过滤掉——因为心智没有空位来接住它。很多"钱花了但没水花"的营销，根本原因不是创意差，而是在一个自己不在场的梯子上喊话。

因此任何定位工作的第一步不是想说什么，而是**测量**：目标人群在这个品类下能无提示说出哪些名字、按什么顺序、你在不在里面。测出来只有三种结局：

1. **你在前两级** → 打法是守位与扩大品类总量（转 `positioning-leader-defense`）。
2. **你在第三级以下但在梯子上** → 硬往上挤的成功率极低（上方品牌地位牢固时几乎不可能），正解是关联定位或重新定位对手。
3. **你根本不在梯子上** → 别再往这个梯子上投钱，要么自带一个新梯子（新品类），要么换一个自己能进前二的更窄品类。

自带新梯子也有约束：**心智不接受与旧事物毫无关联的新事物**。所以新品类要用"参照旧品类"的方式介绍——第一辆汽车叫"不用马拉的车"，后来有"无铅"汽油、"无内胎"轮胎。告诉别人你**不是什么**，常常比告诉他们你是什么更管用。

## A1 — 书中的应用 (Past Application)

### 案例 1：可口可乐 vs 百事可乐
- **问题**：百事的营销活动连年获奖、声势浩大，为什么份额始终追不上？
- **方法论的使用**：作者不看广告质量，只看阶梯排位——第一个进入心智的品牌，长期份额通常是第二名的 2 倍、第三名的 4 倍，而且这个比例不轻易改变。
- **结论**：百事的问题不是广告不够好，是梯子的物理结构。
- **结果**：可乐每卖六瓶，百事最多卖四瓶。作者把同样的比例关系在赫兹/安飞士、通用汽车/福特、麦当劳/汉堡王上反复验证。

### 案例 2：IBM 进攻复印机
- **问题**：IBM 规模远大于施乐，技术、人力、财力全面占优，推出复印机线正面进攻。
- **方法论的使用**：施乐已经是"复印机"这个梯子的第一级，且地位牢固；IBM 不在这个梯子上。
- **结论**：资源优势不能兑换成心智台阶。
- **结果**：施乐在复印机市场保持了 10 倍于 IBM 的份额。同构的还有可口可乐用 Mr.Pibb 打佩珀博士——佩珀每卖六瓶，Mr.Pibb 最多卖一瓶。

### 案例 3：没有梯子的品类
- **问题**：棺材品类有一个真实的领导品牌（贝茨维尔），但没人记得住任何棺材品牌。
- **结论**：有些品类的心智阶梯层数为零，人们主动拒绝存储。
- **结果**：在这类品类里做品牌广告的投入回报接近于零，应转向渠道与决策链。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 产品/内容/服务已经运营一段时间，指标平稳但份额上不去，用户在讨论"要不要加预算"。
2. 用户准备正面对标一个明显更强的对手，说"我们的产品其实比它好"。
3. 要进入一个新市场/新赛道，判断"这个赛道还有没有位置"。
4. 个人或团队在问"别人提到 X 领域，会不会想到我们"。
5. 要做品牌重塑/换 slogan 之前，需要先知道当前认知基线。

### 语言信号（用户的话里出现这些就应激活）

- "我们产品明明更好，为什么卖不过它"
- "要不要再加点预算/再投一波"
- "这个赛道还有机会吗"
- "怎么让用户想起我们"
- "我们算这个行业第几"
- "how do we compete with the market leader" / "brand awareness is low"

### 与相邻 skill 的区分

- 与 `positioning-find-the-hole` 的区别：本 skill 回答"我现在在第几级、这个梯子还值不值得爬"，是**诊断**；`find-the-hole` 回答"该去占哪个新位置"，是**处方**。诊断结论为"不在梯子上/挤不上去"时才转 `find-the-hole`。
- 与 `positioning-be-first` 的区别：`be-first` 处理"能不能当第一、该不该硬拼"的战略取舍，本 skill 提供它所需要的排位数据。
- 与 `positioning-mind-mapping` 的区别：本 skill 是判断与决策，`mind-mapping` 是取原始数据的调研方法。只要拍板用本 skill，要做正式调研用 `mind-mapping`。
- 与 `borrow-momentum-overview` 的区别：后者讲如何借外部热点势能获取曝光，与"品类内排位"无关；本 skill 是在做曝光动作之前的结构判断。

## E — 可执行步骤 (Execution)

1. **锁定品类口径**
   - 明确"顾客在什么念头下会想到这一类东西"，用顾客的说法而不是行业术语（是"租车"不是"短期机动车辆租赁服务"）。
   - 完成标准：能用一句顾客口语说出品类名。
   - 判停条件：若同一产品能落进两个以上互不相干的品类口径，说明定位已失焦，跳到 `positioning-all-things-trap`。

2. **测无提示回忆**
   - 找 10-30 个目标人群，问："说到【品类】，你能想到哪些牌子/哪些人？"不给任何选项，记录顺序。
   - 完成标准：得到一张按提及率与提及顺序排的名单，含平均可回忆数量 N。
   - 需要正式调研方法时转 `positioning-mind-mapping`。

3. **定位自己的台阶**
   - 判断落在：①前二 ②第三至第 N 级 ③不在名单内。
   - 完成标准：给出明确档位与依据数据。

4. **按档位分流**
   - ①前二 → 转 `positioning-leader-defense`（守位四动作）。
   - ②三级以下 → 优先 `positioning-against-the-leader`（关联定位）或 `positioning-reposition-rival`（重新定位对手）；**明确告知用户"直接往上挤"的历史成功率极低**。
   - ③不在名单 → 转 `positioning-find-the-hole` 找一个自己能进前二的更窄品类；若要自带新梯子，进入步骤 5。
   - 完成标准：给出唯一下一步，而不是并列建议。

5. **自带新梯子时做"参照检验"**
   - 用"不是什么 / 类似什么但少了什么"的句式给新品类下定义，测试听者能否复述。
   - 完成标准：陌生人听一遍能原样复述该定义。
   - 判停条件：若无法用一句参照式定义说清，则该新品类不成立，退回步骤 4。

6. **输出诊断报告**
   - 含：品类口径、阶梯名单与排位、平均可回忆数 N、自身档位、被否决的选项及否决理由、唯一推荐动作。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **决策不经过"想起来"这一步的场景**。招标、集采、内部指定供应商、医生处方、算法分发的默认推荐——这些场景里顾客不是从记忆里捞名字，而是从一张既有清单里选。此时阶梯诊断给出的判断会误导。
- **心智阶梯层数为零的品类**（棺材式品类）。人们主动拒绝存储，做认知投入不如做渠道与销售流程。
- **纯执行问题**：转化率、客服响应、定价谈判、履约质量。阶梯诊断解释不了这些。
- **极早期、还没有可被记住的东西时**。连产品都没定型就测认知，只会得到噪声。

### 作者在书中警告的失败模式

- **在真空里做广告**：太多公司发起营销计划时无视竞争对手的位置，然后为劳而无功感到失望。
- **用规模换台阶**：IBM 打施乐、可口可乐打佩珀博士、可口可乐用 PowerAde 打佳得乐，全部失败。资源不能兑换排位。
- **"更好"陷阱**：跟随者以为把产品做得更好就能上位，实际上在改进产品的过程中浪费了时间窗口。
- **不稳定的并列**：两个品牌看似势均力敌时，那是暂时状态；该加力的时机恰恰是"局势不明"的时候，只用一年赢得的领先往往能维持几十年。

### 作者的盲点 / 时代局限

- **写作背景是 1970s 的三大电视网 + 报刊时代**。当时"进入心智"几乎等于"买到足够多的广告触点"，所以书中把预算和排位强绑定。今天算法分发、私域、社群与搜索改变了路径：一个小预算的垂直账号可以在极窄品类里成为第一，而不需要全国性投放。使用本 skill 时应把"品类"切得比原书更窄。
- **7±2 的引用略显草率**。米勒 1956 年的原始研究讲的是短时记忆的信息组块容量，作者把它直接类比成"品牌回忆上限"，这是类比而非证明。实际可回忆数量高度依赖品类卷入度，低卷入品类往往只有 1-2 个，高卷入品类（如手机、球鞋）可以远超 7 个。**不要把 7 当硬门槛，要实测 N。**
- **样本偏差**：书中论据几乎全是美国大众消费品，且是"事后能找到的成功案例"。同样在第三级以下的品牌里，也有靠渠道、供应链或价格结构翻盘的，作者不收录这类反例。
- **"长期份额 2 倍/4 倍"的比例**未给出统计来源，应作为经验直觉而非可引用的定律。

### 容易混淆的邻近方法论

- **市场份额 ≠ 心智份额**。份额可能来自渠道压货或价格战，而心智排位是独立的另一张表。两者背离时（份额高但无提示回忆低）恰恰是危险信号。
- **"品类第一"的自定义陷阱**：书中明确警告，不能用自己的标准定义领导地位（"密西西比河以东、售价 1000 美元以下的最畅销高保真音响"）。必须用顾客的品类口径。
- **NPS / 满意度调研**测的是已有用户的评价，与"未被想起"是两个完全不同的问题，不能互相替代。
