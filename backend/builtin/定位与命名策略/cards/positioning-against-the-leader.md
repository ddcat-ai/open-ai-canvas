## I — 方法论骨架 (Interpretation)

心智不接受与旧事物毫无关联的新事物。这对挑战者是坏消息也是好消息：坏消息是你无法凭空建立认知；好消息是**对手已经花巨资在顾客脑子里建好的坐标，你可以直接用**。

关联定位的本质是：不去争"我是谁"，而是定义"我相对于那个已知的东西是什么"。顾客不需要重新学习任何东西，只需要在已有的格子旁边加一个标签。

三种式样：

1. **对立式**——占据领导者结构上无法跟进的反面。七喜说自己是"非可乐"。它没有说自己更好喝，它说的是"当你不想喝可乐时"。这一句话把七喜从"柠檬汽水"这个没人关心的小梯子，搬到了"饮料"这个最大的梯子上，站在可乐的对面。关键在于**可乐永远不能说自己是非可乐**，这个位置是结构安全的。
2. **承认式**——公开承认自己不是第一，用它换取可信度与同情。安飞士说"我们是老二，所以我们更努力"。作者在第21章明确指出这不像广告而像营销战略，两者都是。承认弱点会让后面所有的话都更可信。
3. **并列/搭车式**——挂靠一个已知的强认知，让顾客用旧概念理解新东西。Taster's Choice 挂靠现磨咖啡的认知。同类的还有"不用马拉的车"、"无铅汽油"、"无内胎轮胎"——新概念参照老概念定位。

成立的三个必要条件，缺一就会变成给对手做免费广告：

- **对手在心智中足够强且定义清晰**。挂靠一个模糊的对象等于挂靠空气。
- **你必须真的承认自己不是第一**。假装平起平坐会让顾客把你直接归入"劣质仿品"。
- **你占的位置对手结构上无法跟进**。如果对手明天就能说同样的话，这个位置不属于你。

## A1 — 书中的应用 (Past Application)

### 案例 1：七喜"非可乐"
- **问题**：七喜是柠檬味汽水，在自己的小梯子上没人关心。作者在第21章点明："七喜的问题不是潜在顾客对柠檬类饮料的看法，而是在潜在顾客心智中占据绝对优势的可乐。"因为"给我来杯饮料"对大部分人意味着可口可乐或百事可乐。
- **方法论的使用**：考虑全局，把自己挂到"可乐"这个最强坐标的对立面。
- **结论**：不争柠檬汽水第一，争"可乐的替代选项"。
- **结果**：非可乐定位成功，七喜进入了饮料这个大梯子。

### 案例 2：安飞士"我们是老二"
- **问题**：租车业赫兹是牢固的第一。
- **方法论的使用**：不宣称更好，直接承认排名第二——"安飞士在租车业里仅排第二位，但为什么还要找我们？因为我们工作更努力。"
- **结论**：作者评价它"听上去不像广告，而是营销战略。实际上，两者都是"。
- **结果**：成为定位史上最著名的挑战者案例。**但作者同时记录了它的后续失败**——安飞士后来放弃了这句话（见 B 段）。

### 案例 3：Taster's Choice 挂靠现磨咖啡
- **方法论的使用**：速溶咖啡在心智中是"次一等的咖啡"，与其争速溶品类，不如挂靠"现磨咖啡"这个高价值认知，让顾客用旧概念理解新产品。

### 案例 4：新概念参照老概念
- 第一辆汽车称"不用马拉的车"；后来有"场外"下注、"无铅"汽油、"无内胎"轮胎。
- **结论**：作者总结——"你有了全新的产品后，告诉潜在顾客该产品不是什么，往往要比告诉他们该产品是什么还管用。"

### 案例 5：Rheingold 啤酒（反面对照）
- **问题**：想抢占纽约工人阶层市场，于是拍了一组广告，分别宣传不同族裔的人都喝 Rheingold。
- **结论**：这是关联定位的反面——它没有挂靠任何一个强坐标，而是试图吸引所有人。
- **结果**："他们试图吸引所有人，结果什么人也没有吸引到。"同期 Schaefer 用"唯一一种喝了还想喝的啤酒"占住"重度饮用者"位置，成功。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 用户是明确的后来者，说"这个市场被 XX 垄断了，我们怎么进"。
2. 顾客总是拿用户的产品和某个头部产品比较，用户不知道怎么接。
3. 六维空位扫描（`positioning-find-the-hole`）结论是"没有独立空位"。
4. 用户想说"我们和 XX 不一样"但说出来的都是功能参数差异。
5. 一个全新的产品/概念，顾客听不懂它是什么。
6. 开源项目要说明自己相对于某个商业产品的位置。
7. 新人进入一个有明确资深者的团队/领域，需要定义自己的角色。

### 语言信号（用户的话里出现这些就应激活）

- "我们打不过 XX，但是……"
- "怎么跟头部差异化"
- "客户老拿我们跟 XX 比"
- "我们是 XX 的替代品/平替"
- "这个东西怎么跟别人解释"
- "we're the alternative to X" / "how do we position against the incumbent"

### 与相邻 skill 的区分

- 与 `positioning-find-the-hole` 的区别：`find-the-hole` 找的是**独立于对手**的位置（我占"小"、我占"贵"），本 skill 占的是**依附于对手**的位置（我是"非可乐"）。**优先顺序：先找独立空位，找不到再用关联定位**，因为依附意味着你的位置随对手的兴衰而波动。
- 与 `positioning-reposition-rival` 的区别：本 skill **不评价对手**，只是站在它旁边或对面（"非可乐"没有说可乐不好）；`reposition-rival` 是**主动改写顾客对对手的理解**（泰诺让人们重新看待阿司匹林）。前者温和且低风险，后者攻击性强且有反噬风险。若关联定位不够用再升级到后者。
- 与 `positioning-leader-defense` 的区别：镜像关系。本 skill 是发起方，后者是被关联的一方该如何应对（答案通常是"不要回应"）。
- 与 `borrow-momentum-overview` 的**关键区别（必读）**：后者是**借外部热点、名人、事件的瞬时势能**求同框、求曝光，本质是搭顺风车；本 skill 是**借竞争对手在心智中已建立的稳定坐标**做站位，本质是立锚。二者机制相反：前者求"和它一起出现"，后者常常求"和它对立"。时间尺度也不同：热点是短期的，心智坐标是长期的。若用户要的是"蹭一波热度"，用 `borrow-momentum-overview`；若要的是"长期定义自己相对于谁"，用本 skill。
- 与 `anchor-first-offer` 的区别：后者是谈判中的数字锚定（先开价影响对方判断），与品牌站位无关，仅名字近似。

## E — 可执行步骤 (Execution)

1. **确认自己确实是后来者**
   - 用无提示回忆确认对手是第一且自己不是。
   - 判停条件：若自己是第一，转 `positioning-leader-defense`；若能找到独立空位，优先 `positioning-find-the-hole`。

2. **锁定挂靠对象，并检验它的"坐标强度"**
   - 问目标顾客："说到【品类】你首先想到什么？"以及"它代表什么？"
   - 完成标准：挂靠对象被绝大多数人首先提到，且大家对"它代表什么"的说法高度一致。
   - 判停条件：若顾客对该对象的描述五花八门，说明坐标模糊，关联定位无处可挂，退回步骤 1。

3. **考虑全局，找到真正的挂靠对象**
   - 关键动作：不要挂在自己所在的小品类上，要挂在顾客真正在做选择的那个大坐标上（七喜的对手不是柠檬汽水，是可乐；比利时航空的问题不是航空公司，是比利时这个国家）。
   - 完成标准：能说清"顾客在什么念头下会考虑我们的替代品"。

4. **三式选型**
   - **对立式**：适用于对手的强项自带一个结构性反面（含糖 vs 不含糖、复杂 vs 简单、企业级 vs 个人）。
   - **承认式**：适用于差距是公开事实、且你能给出一个可信的补偿理由（更努力、更专注、更便宜）。
   - **并列/搭车式**：适用于你的东西是全新概念，顾客需要一个旧概念做支架。
   - 完成标准：选定一式并写出那句话的草稿。

5. **过"结构安全三检验"**
   - **① 对手能不能说同样的话？** 可口可乐永远不能说自己是非可乐——这是七喜位置安全的根本。如果对手明天就能跟进，位置无效。
   - **② 你敢不敢公开承认自己不是第一？** 不敢就别用承认式。
   - **③ 这句话有没有替对手做广告？** 如果去掉对手的名字这句话就不成立、且顾客听完记住的是对手——是失败的关联定位。
   - 完成标准：三项全过。

6. **写"坚持条款"**
   - 明确写下：这句话要用多少年、什么情况下才允许改。关联定位最常见的死法不是被对手打败，而是自己放弃（安飞士教训，转 `positioning-fwmts-trap`）。
   - 完成标准：方案中含明确的坚持年限与改动触发条件。

7. **削尖它**
   - 把那句话压到能被一次听完复述。转 `positioning-oversimplified-message`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **你已经是第一或即将成为第一**。关联定位会把你自己降级为参照物的附属品。
- **挂靠对象在心智中模糊或正在衰落**。挂在一艘沉船上会一起沉。
- **能找到独立空位时**。依附性位置的天花板受制于对手，独立空位优先。
- **对手是负面对象**。挂靠一个顾客厌恶的东西，负面情绪会传导给你。
- **需要长期建立独立品牌资产的场景**。关联定位擅长快速进入心智，不擅长最终摆脱参照物——很多"XX 平替"永远停留在平替。

### 作者在书中警告的失败模式

- **安飞士放弃了自己的定位**：作者记录，安飞士后来弃用了"我们是老二"，改成"安飞士将成为第一"。这句话违背了承认式的全部前提——顾客知道你不是第一，宣称要当第一只会破坏可信度。这是关联定位最著名的自毁案例。
- **米狮龙同构错误**：占住空位后换成"周末是为米狮龙创造的"这类毫无意义的概念。
- **Rheingold 的"吸引所有人"**：不挂靠任何坐标，试图取悦每个群体，结果谁也没吸引到。
- **跟风不是关联定位**：作者严格区分——跟随者效仿领导者的做法"根本不是拦截，而是跟风行为"。关联定位是站在对手的坐标系里占一个对手占不了的点，跟风是站在对手的位置上做一个更差的复制品。
- **搭便车的终极版本是品牌延伸**：作者把品牌延伸称为"搭便车陷阱的终极版本"。挂靠外部对手的坐标是关联定位，挂靠自己旧品牌的坐标去做不相干的新品是自我稀释（转 `positioning-line-extension-trap`）。

### 作者的盲点 / 时代局限

- **法律与平台规则的变化**。1970s 的美国允许在广告中直接点名竞品做对比。今天在中国等市场，**广告法与不正当竞争相关规定对直接贬损或点名比较有明确限制**，多数平台的广告审核也会拦截。因此对立式在今天往往需要改用"品类描述"而非"竞品名"来实现（说"不含糖的碳酸饮料"而不是"非可口可乐"）。使用本 skill 必须先过合规检查。
- **"非可乐"的成功被过度归因**。七喜的增长同期还伴随健康意识上升、渠道扩张与可乐的自身波动，作者把全部功劳给了一句话。
- **只有成功案例的定义式论证**。作者用七喜、安飞士证明关联定位有效，但没有统计过有多少品牌用了同样的打法却失败——而"XX 的平替"是最常见也最常失败的定位。本 skill 的"结构安全三检验"是为弥补这个缺口而加的。
- **忽略了关联定位的天花板**。安飞士从未成为第一，七喜从未成为可乐。作者没有讨论"什么时候该从关联定位毕业、建立独立身份"，这是原书缺失的一整个环节。
- **单向传播假设**。当年对手无法即时回应，今天对手可以在几小时内在同一平台反击，对立式的风险显著上升。

### 容易混淆的邻近方法论

- **借势营销 / 蹭热点**（对应 `borrow-momentum-overview`）：借的是事件的瞬时流量，追求同框；关联定位借的是竞品的稳定认知，常常追求对立。
- **对比广告 / 比较营销**：直接主张"我比它好"，这是关联定位**明确反对**的做法——它把顾客推入比较模式，而领导者在比较中天然占优。
- **联合品牌 / 联名**：双方都同意的合作站位，关联定位是单方面的。
- **谈判锚定**（`anchor-first-offer`）：与本 skill 只有字面相似，机制无关。
