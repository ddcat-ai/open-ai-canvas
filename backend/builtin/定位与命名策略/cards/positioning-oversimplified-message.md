## I — 方法论骨架 (Interpretation)

作者把心智比作**一块滴水的海绵**：它已经饱和了，要装进新东西必须先挤掉旧的。所以传播的瓶颈不在你说了多少，而在对方能留下多少。

由此推出一个反直觉的工作定义：

> "你的工作不是普通意义上的'传播'。你的工作其实是筛选，筛选出那些最容易进入心智的材料。"

**削尖（sharpen）** 这个动词是全书最精确的比喻。削尖不是"把话说短"，而是把接触面积缩小到能刺穿防御的程度。一段 100 字的完整介绍和一个词的差别，不是长度差 100 倍，而是**能不能进去**的差别。

机制有三层：

1. **一词占领心智**。作者把简化推到极端，发展成"一词占领心智"理论：沃尔沃是"安全"，宝马是"驾驶"，联邦快递是"隔夜到达"，佳洁士是"防蛀"。注意这些都是**一个词**，不是一句话，更不是一段话。
2. **词是空罐子，含义由使用者赋予**。"文字本无含义。含义不是在词语里，而是在使用这些词语的人身上。"所以选词不是修辞问题，是**占位**问题——你选的这个词，现在归谁？
3. **拥有即须使用，否则失去**。"一旦在顾客的心智中拥有了一个词，你就得利用它，否则就会失去它。"削尖是一次性动作，守词是长期动作。

削尖的**判定标准只有一个**：听者一次听完后能不能原样复述。不能复述 = 没进心智 = 等于没说。这是本 skill 全部操作的收敛点。

作者在第22章补了一个反直觉的警告：**"如果一个想法显得非常巧妙或复杂，我们就该小心了。它也许行不通，因为它不够简单。"** 巧妙感是危险信号，不是质量信号。他引用凯特林挂在通用汽车研究中心墙上的牌子："问题一旦得到解决就变得简单了。"

还有一个常被忽略的操作要求：**广告本身就应该是战略**。作者讲了一个广告公司的故事——老板要求把营销战略贴在每份广告设计的背面，以便客户问起时能翻过来念。作者的评价是："广告应该简单到它自身就是战略的程度。这家广告公司犯了一个错误：它把设计图用反了。"**如果你的表达需要附一份说明才能被理解，说明削尖没完成。**

## A1 — 书中的应用 (Past Application)

### 案例 1：一词占领心智的四个样本
- **方法论的使用**：把整个品牌压缩到一个名词或一个动词上。
- **样本**：沃尔沃「安全」/ 宝马「驾驶」/ 联邦快递「隔夜到达」/ 佳洁士「防蛀」。
- **要点**：这四个词都**不描述产品**，只描述"顾客要的那一件事"。沃尔沃没说"三点式安全带与笼式车身"，只说"安全"。

### 案例 2：政治候选人的筛选工作
- **问题**：作者假设你在辅选一位政客。
- **观察**："在面见这位政客 5 分钟内，你对这位政客的了解会比普通选民未来 5 年对他的了解还要多。"
- **结论**：你掌握的信息量和受众能接收的信息量差着几个数量级，因此**你的工作是筛选，不是传播**。
- **本 skill 只取其中的信息量不对称原理，不涉及政治操作。**

### 案例 3：第22章列出的三条"行得通的简单想法"
- "来自加利福尼亚的提子干——大自然生产的糖果。"
- "汁多肉厚的盖氏汉堡——不装罐的罐装狗粮。"
- "波波洋——泡泡糖里的第一美味。"
- **共同结构**：采用简单的词语、直截了当地表达简单的概念；每条都只有**一个**主张，且都挂在一个已知概念上（糖果 / 罐装狗粮 / 第一）。

### 案例 4：贴在背面的战略
- **问题**：广告公司要求业务员把营销战略贴在广告设计背面备查。
- **作者的判断**："广告应该简单到它自身就是战略的程度。这家广告公司犯了一个错误：它把设计图用反了。"
- **可迁移的检验**：**任何需要附加解释才成立的表达，都还没削尖。**

### 案例 5：Rheingold 啤酒的反面（信息越多覆盖越小）
- **问题**：Rheingold 想抢占纽约工人阶层市场，于是分别宣传意大利人喝、黑人喝、爱尔兰人喝、犹太人喝。
- **结果**："他们试图吸引所有人，结果什么人也没有吸引到……看了这些广告，纽约市所有的民族都不会喝 Rheingold 啤酒。"
- **对照**：F&M Schaefer 只说一句"唯一一种喝了还想喝的啤酒"，锁定"重度饮用者"，成功。
- **要点**：多主张不是加法，是减法。

### 案例 6：500 个频道
- **观察**："既然普通消费者平时只看五六个频道，要 500 个频道有什么用呢？500 个频道？等到你找到想看的节目时，它已经结束了。"
- **推论**：供给端的丰富度增长不会带来接收端的容量增长，接收端容量是**恒定**的。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 要写 slogan / tagline / 一句话介绍，写了十版都不满意。
2. 电梯陈述、路演开场、融资 BP 第一页讲不清楚。
3. 产品有 8 个卖点，不知道主推哪个，于是全都写上。
4. PRD / OKR 的目标写了五条并列项。
5. 自我介绍、简历摘要、个人主页 bio 讲完对方记不住。
6. 汇报材料信息密度高但领导抓不住重点。
7. 内部对"我们到底是做什么的"没有统一口径，每个人讲法不一样。
8. 一个概念/新品类需要被口口相传，但现在没人能转述。

### 语言信号（用户的话里出现这些就应激活）

- "怎么用一句话说清楚"
- "我们的 slogan / 广告语该怎么写"
- "卖点太多了不知道主推哪个"
- "讲完了对方好像没记住"
- "帮我提炼一下核心信息"
- "这段太长了，能不能精简"
- "我们到底该强调什么"
- "one-liner" / "elevator pitch" / "what's the tagline"

### 与相邻 skill 的区分

- 与 `ability-simplification` 的区别（**易混，必读**）：后者简化的是**用户要做的动作**——少一步表单、少一次跳转、少一个必填项，目标是降低**行动成本**。本 skill 简化的是**要被记住的意义**——少一个概念、少一个主张，目标是降低**记忆成本**。判据：用户在抱怨"太麻烦/做不到"用前者；在抱怨"记不住/说不清"用本 skill。
- 与 `ra-hook`（短视频钩子）的区别：钩子求**停留**（前 3 秒不划走），削尖求**留存**（看完之后还记得一个词）。两者可叠加：钩子负责让人开始听，削尖负责让人事后能复述。判据：目标是完播率用 `ra-hook`，目标是被记住/被转述用本 skill。
- 与 `positioning-outside-in` 的区别：本 skill 解决**长度**问题，`outside-in` 解决**方向**问题。**方向错了压得再短也没用，所以永远先 `outside-in` 后本 skill。**
- 与 `positioning-name-power` 的区别：后者选的是**品牌名**（一个专有名词，法律上可注册、需长期绑定），本 skill 选的是**要占的那个词**（一个通用概念，如"安全""防蛀"）。理想状态是二者互相强化，但它们是两个决策。
- 与 `positioning-find-the-hole` 的区别：找空位是**先找到无人占据的位置**，削尖是**把这个位置压缩成一个词**。找空位在前，削尖在后。若削尖后发现这个词已被别人占，回到 `positioning-find-the-hole`。
- 与 `positioning-all-things-trap` 的区别：后者判断"你是不是想满足所有人"（**战略**层面的贪心），本 skill 处理"话怎么说才进得去"（**表达**层面的贪心）。Rheingold 案例两者都算，因为表达上的贪心通常是战略贪心的症状。

## E — 可执行步骤 (Execution)

1. **摊开全部候选主张**
   - 把现在想说的所有卖点/要点/优势逐条列出，一条一行，不筛选。
   - 完成标准：列表写完，通常 5-15 条。

2. **给每条打两个分（1-5）**
   - **A 分：对方在乎吗？**（不是"这条是不是事实"，是"对方会不会因为这条改变行为"）
   - **B 分：只有我们能说吗？**（竞品照抄这句话会不会同样成立？会 → 低分）
   - 完成标准：每条都有 A、B 两个分数。
   - 判定：A 或 B 任一为 1-2 分的条目直接划掉。

3. **强制砍到 1 条**
   - 从剩余里选 A×B 最高的**一条**。不允许"两条并列"。
   - 若确实无法在两条之间取舍，说明你在两个不同的定位之间摇摆 → 转 `positioning-find-the-hole` 重做，或接受这是两个产品。
   - 完成标准：白纸上只剩一条主张。

4. **压成一个词**
   - 把这条主张压到 **1 个词**（可退让到 2-4 字的短语）。
   - 参照物：安全 / 驾驶 / 隔夜到达 / 防蛀。
   - 完成标准：写出 3-5 个候选词。

5. **占位检查（关键闸门）**
   - 对每个候选词问：**这个词现在归谁？** 在目标品类里搜索该词，看第一联想是不是竞品。
   - 若这个词已被强势竞品占据 → 弃用。作者的原则是"不要试图改变心智"，抢一个别人已占的词是最贵的打法。
   - 若这个词太空（如"品质""创新""专业"）→ 弃用，空罐子装不进含义。
   - 完成标准：确定 1 个词，且能说清它当前归属状态。

6. **复述测试（唯一的通过标准）**
   - 找 3 个不了解背景的人，把最终表达**念一遍**（只念一遍，不解释、不重复、不展示 PPT）。
   - 隔 10 分钟以上，问："我刚才说的是什么？"
   - 完成标准：**3 人中至少 2 人能说出那个词或等价意思。**
   - 不通过 → 回步骤 4 换词，或回步骤 3 换主张。

7. **背面测试**
   - 问：这段表达需不需要附一份说明才成立？
   - 需要 → 没削完，回步骤 4。（作者：广告应该简单到它自身就是战略的程度。）

8. **巧妙度警报**
   - 问：团队里有人夸这个想法"很妙""很有巧思"吗？
   - 有 → 警惕。作者："如果一个想法显得非常巧妙或复杂，我们就该小心了。它也许行不通，因为它不够简单。"重跑步骤 6，用真人复述结果盖过内部审美。

9. **写守词计划**
   - 削尖是一次性的，占词是长期的。列出未来 12 个月所有对外触点（官网首屏、包装、开场白、销售话术、招聘 JD），确认这个词是否每处都出现。
   - 作者："一旦在顾客的心智中拥有了一个词，你就得利用它，否则就会失去它。"
   - 完成标准：触点清单 + 每处的落地写法。

10. **输出**
    - 含：候选主张全表与打分、选定主张、候选词、占位检查结论、最终一个词、复述测试原始记录（3 人各说了什么）、守词触点清单。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **合规、法律、医疗、安全告知文本**：这些场景的目标是**准确与完备**，不是被记住。削尖会造成信息隐瞒和法律风险。
- **技术文档、API 文档、操作手册**：读者是带着具体问题主动来查的，不存在"注意力争夺"，此时完备性 > 简洁性。
- **复杂决策需要的尽调材料**：董事会决议、投资备忘录、架构评审文档。这些的读者会反复阅读，简化会丢失判断依据。
- **教学与培训内容**：学习需要展开、需要例子、需要过程。压成一个词的是**结论**，不是**理解**。
- **方向尚未确定时**：不知道说什么就先别管怎么说短。先 `positioning-outside-in` 和 `positioning-find-the-hole`。
- **对方是主动来了解你的**（求职者研究公司、用户主动读文档、投资人做尽调）：防御是打开的，不需要削尖穿透。

### 作者在书中警告的失败模式

- **"辞藻华丽，千篇一律"**：作者说这在传播过度的社会已成为一种生活方式，但"且不说它们确有效果"——修辞不能替代削尖。
- **多主张并列**：Rheingold 逐一讨好每个族群，结果全部落空。
- **意义含糊、模棱两可的语词**：作者明确要求"抛弃"。今天最常见的空词是"品质""创新""专业""生态""赋能"。
- **巧妙压过简单**：显得很妙的方案往往不够简单。
- **靠附加说明补救**："把设计图用反了"。
- **占了词却不用**：拥有一个词而不持续使用，它会被别人拿走。
- **词太不符合实际会被拒绝**：作者提醒有限制——"如果一个词太不符合实际，人会干脆拒绝使用它。尽管牙膏皮上写着一个'大'字，但除了生产商之外，人人都叫它一'小管牙膏'。"**你不能靠宣称占词，只能靠事实支撑占词。**

### 作者的盲点 / 时代局限

- **"一个词"在搜索与算法分发时代不完全成立**。1980 年的接触点是电视和平面广告，一次曝光只有几秒；今天用户会主动搜索、会看评论、会读长测评。**长内容有了独立的生存空间**，"一切都要压成一个词"是过度推广。现代修正：**一个词负责入口与转述，长内容负责转化与信任**，两者不冲突，本 skill 只管前者。
- **"一词占领"的样本全是大预算品牌**。沃尔沃、宝马、联邦快递、佳洁士都是靠数十年巨额广告把一个词砸进心智的。**没有这个预算，"占词"往往只是内部自嗨。** 中小品牌更现实的目标是在**一个很窄的人群**里占一个词，而不是在全品类占词。这一点作者在第21章第四步（"你有足够的钱吗"）自己承认了，但在削尖这一章没有交叉提醒。
- **中文的"一个词"与英文不对等**。英文品类词（safety、driving）是单词，中文常需 2-4 字短语，且中文的谐音、多义、方言差异更复杂。机械追求"一个字"会牺牲清晰度。**本 skill 的操作放宽到 1 个词或 2-4 字短语。**
- **忽略了"可被搜索"这个现代维度**。今天一个好的定位词还必须满足：有人在搜、竞争度可承受、能与品牌名共现。这一整层在原书中不存在。
- **复述测试的样本量太小**。作者没给测试方法，本 skill 的 3 人复述测试是可操作化补充，但 3 人样本只能排除"完全记不住"的方案，不能证明"一定能记住"。**它是一道否决闸门，不是一份验收报告。**
- **对 B2B 与专业采购的适用性被高估**。作者自己承认定位理论起源于工业营销（1969 年《工业营销》杂志），但复杂 B2B 采购的决策链有多个角色，各自关心的"一个词"不同。单一词在这类场景可能需要按角色分层。

### 容易混淆的邻近方法论

- **`ability-simplification`（能力简化）**：减少动作步骤，不是减少概念。**本 skill 最常被误触发的邻居。**
- **`ra-hook`（短视频钩子）**：抢停留，不是抢记忆。
- **"精简文案"这个口号**：删形容词、去冗词是**编辑**工作；削尖是**取舍**工作——要放弃真实存在的卖点。前者不痛，后者一定痛。**如果这次简化过程你没觉得心疼，说明你只是在编辑，没有在削尖。**
- **金字塔原理 / 结论先行**：解决的是**结构**问题（先说什么后说什么），本 skill 解决的是**取舍**问题（哪些根本不说）。结论先行仍可以有五个论点；削尖只留一个。
- **Elevator Pitch 模板**（"我们为 X 提供 Y，不同于 Z"）：那是一个**填空格式**，本 skill 是一个**筛选流程**。模板可以在步骤 4 之后用来落地。
