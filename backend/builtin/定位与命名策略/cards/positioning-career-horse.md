## I — 方法论骨架 (Interpretation)

### 被拆掉的那个假设

作者要拆的是一个几乎所有勤奋者都持有的默认假设：**能力和努力才是最重要的**。他的原话很直白：

> "他们推销自己的战略往往建立在一个天真的假设上。即能力和努力才是最重要的。于是，他们更加埋头苦干，等待成功的到来。可是，那一天很少会到来。"

这不是在否定能力，而是在指出**乘法结构**：成就 = 你的能力 × 载体的势能。当载体势能接近零时，能力项再大也没用。作者的比喻锋利得近乎残酷：

> "泰坦尼克号上最好的船员到头来也得和最差的水手上同一条救生艇，而且他还得足够幸运没有落水才行。"

以及全章的收束：

> "获胜次数最多的未必是体重最轻、最聪明或体质最强壮的骑师。最好的骑师赢不了比赛。赢得比赛的通常是骑着最好的马的那位。"

### 与"你不能由此及彼"的连接

这一章不是独立的励志内容，它是第5章"你不能由此及彼"在个人层面的应用。作者在第5章举的例子就是个人的：**一位 55 岁的副总裁当不成总裁**——因为等现任 CEO 65 岁退休时，董事会会任命一位 48 岁的接班人。"要想得到这个提升机会，他必须比现任总裁至少年轻 10 岁才行。" 这是结构性的，不是努力能改变的。

**本 skill 的第一价值就是识别"你现在处在一个由此及彼到不了的位置上"，并且承认它，而不是加倍努力。**

### 六匹马

**第一匹马：你所在的公司**
- 问："你公司的发展方向是什么？或者不客气地说，它究竟有没有发展方向？"
- 关键判断：**"公司的成长机会低于一般水平"比"公司会失败"更糟**——因为"失败至少会给你第二次机会"，而缓慢平庸不给你任何转折点。
- 选择方向：作者指出选**成长性行业**，并特别提示"所有服务行业都比硬产品发展得快得多"。
- 一条重要的路径依赖警告："你在夕阳产业硬产品方面的经验会使你对完全不同的产品领域视而不见。"**你在减速的马上待得越久，越看不见其他马。**
- 换工作时的问法："别只关心它现在能付你多少工资。还要问它今后可能会付给你多少。"

**第二匹马：你的上司**
- "要永远争取为你能找到的最精明、最出色、最有能耐的人工作。"
- 反面："有些人确实愿意为无能的人工作……他们是想要鹤立鸡群的感觉。但是他们没有想到，最高管理层如果对某个业务部门不满意的话，往往会把整个部门撤销。"
- 作者给了一个求职话术的对照实验：
  - A 类人说："你们的确需要我，因为你们在我的特长方面很弱。"
  - B 类人说："你们在我的特长方面很强。你们做得太棒了，而我正想和最好的人共事。"
  - **"哪种更有可能得到这份工作？没错，是后一种人。"** 而管理层见到的却大多是前一种。

**第三匹马：朋友（商界朋友）**
- "许多商界人士有大量的私人朋友，却没有一个生意上的朋友。"
- "人一生中的大多数重大转折之所以发生，是因为有商界朋友的推荐。"
- **关键在于"操练"**："只交朋友还不够。你还得牵出友谊这匹马，间或操练它一番；否则的话，在你需要它的时候反而会用不上它。"
- 反例极其精准："如果有位 10 年没见的商界老友打电话约你吃午饭，你就知道会发生两件事情：(1) 你得为这顿饭买单；(2) 你的朋友要找工作。"
- 具体动作：把对方可能感兴趣的文章寄给他、升职时写贺信。作者提醒"别以为人们总能看到以这样或那样的方式提到他们的文章"。

**第四匹马：好的想法**
- 陷阱："人们不仅想要一个非常好的想法，而且希望别人都认可那是个非常好的想法。世上根本就没有这样的想法。"
- **"如果你想等到一个好想法能被人接受，那就太晚了。别人会在此之前就抢占这个想法的。"**
- 因此骑这匹马的代价是**必须准备好受人奚落**——"你必须准备好逆势而行"。
- 作者用自己举例：定位理论发表后被同行公开谴责，业内顶级广告公司总裁当众评价为"胡说八道"。
- 引心理学家奥斯古德的判据：**"一项原理是否可行的一个标志，是它所受反对的强烈与持久的程度。"** 无人反对的想法不是想法——"那不是想法，而是母爱、苹果馅饼和国旗"。
- 但也要"耐心等待时机成熟"。

**第五匹马：信心（对别人和别人的想法有信心）**
- "超越自我并且到外面寻找你的财富至关重要。"
- 案例：雷·克洛克在遇到麦当劳兄弟之前"已近暮年，并且一事无成"。那两兄弟有好主意却没有信心，于是"没要几个钱就把自己的想法连同名字都卖给了雷·克洛克"。
- 作者的结论：**"是一个外行人的眼光、勇气和恒心把麦当劳办成了一个成功的连锁企业。而不是那两位叫麦当劳的人。"**

**第六匹马：你自己**
- 作者的评价毫不留情："这是最后一匹马，它低劣、乖戾而且前途未卜。但是，人们经常想去骑它，尽管很少成功。"
- 更难得的是**作者拿自己当反例**：1989 年他们把这一章扩成一本书《人生定位》，"但市场表现很差。教训是我们在自我激励方面缺乏信任"。
- 理由："商业和生活一样，是一项社会活动，既要有合作，也要有竞争。以销售为例。你不能自己完成销售，必须有人来买才行。"

### 还有三条本章的配套原则

- **要能犯错误**："任何值得一做的事情都值得一试。"如果等到能做得尽善尽美再动手，"你就可能永远都做不成了"。作者对比了两位棒球运动员：泰·科布偷垒 134 次成功 96 次（70%）被人记住，麦克斯·凯里 53 次成功 51 次（96%）被人遗忘。**尝试次数 × 成功率 = 战绩，而人们记住的是绝对量。**
- **定义自己**：人和产品有同样的毛病——想让所有人都满意。"定位工作中最难的一点是，选定某个具体的概念，把它与自己联系起来。""大多数人没有足够的信心为自己确立一个概念。他们犹豫不决，指望别人来给自己下定义。"检验方式很具体：如果你说"我是本地最好的律师"，那么"假如我们在本地法律界做一次调查，你的名字会被提到多少次？"
- **名字与延伸**：本章也把命名和品牌延伸的原理用到个人身上——避免只用首字母缩写（"如果你正在步步高升……你需要的是一个名字，不是一组缩略字母"）、避免过于常见的名字（"混淆不清是成功定位的大敌"）、避免在知名长辈的名字后加"小"字（"称'小'的那位通常意味着永无出头之日"）。

## A1 — 书中的应用 (Past Application)

### 案例 1：雷·克洛克与麦当劳兄弟（第五匹马）
- **问题**：一个近暮年、一事无成的人如何逆转？
- **方法论的使用**：不是提升自己，而是**对别人的想法下注**——买下麦当劳兄弟的主意和名字。
- **结果**：麦当劳连锁帝国。作者强调成功归于"一个外行人的眼光、勇气和恒心"，而非那两位有好点子却没信心的兄弟。
- **可迁移点**：**有想法的人和把想法做成的人经常不是同一个人。** 认领这个角色也是一种定位。

### 案例 2：定位理论自己的传播史（第四匹马）
- **问题**：一个新概念如何存活？
- **过程**：文章发表后被同行撰文谴责，被业内顶级广告公司总裁当众评为"胡说八道"。
- **判据**：作者引奥斯古德——一个原理受到的反对越强烈持久，越说明它可行；被认为"显然是胡说八道、不堪一击"的原理，人们往往会**置之不理**而非攻击。
- **结果**：定位成为营销史上影响最大的概念之一。

### 案例 3：《人生定位》的失败（第六匹马，作者自曝）
- **事实**：1989 年作者把这一章扩成一本书，市场表现很差。
- **作者的归因**："我们在自我激励方面缺乏信任。不如让给托尼·罗宾斯和汤姆·彼得斯。"
- **可迁移点**：**作者在讲"骑自己这匹马很难成功"时，用的证据是他们自己骑这匹马失败了。** 这是全书最诚实的一处自我举证。

### 案例 4：55 岁副总裁（结构性天花板）
- **计算**：CEO 65 岁退休时董事会会挑一位 48 岁的接班人，因此候选人必须比现任年轻至少 10 岁。
- **结论**：这位副总裁"已经没有当总裁的机会了"，与他多努力无关。
- **要点**：**先算结构，再谈努力。**

### 案例 5：泰·科布 vs 麦克斯·凯里（要能犯错误）
- 泰·科布：偷垒 134 次成功 96 次，成功率 70%，被人记住。
- 麦克斯·凯里：53 次成功 51 次，成功率 96%，被人遗忘。
- **结论**：只做有把握的事，名声反而不如多次尝试偶有成功。

### 案例 6：赛马骑师阿尔卡罗
- 可能是有史以来最伟大的赛马骑师，"一连失败了 250 次后才获得第一次胜利"。

### 案例 7：十年不联系的老友（第三匹马的反例）
- 十年没见的商界老友突然约饭 = 你买单 + 他要找工作。
- **结论**："你在要找工作的时候再用这种办法，往往已为时太晚。"关系必须**定期操练**。

### 案例 8：改名的演艺人士（名字要合适）
- 莱奥纳德·斯莱 → 罗伊·罗杰斯；马里恩·莫里森 → 约翰·韦恩；伊苏尔·达尼埃洛维奇 → 科克·道格拉斯。
- 作者的诚实补充："多年来，我们曾建议许多商界人士改名字，至今还没有一个接受建议的。"
- 法律边界：作者明确提示不得用于欺诈——"别给自己起名为麦当劳，然后去开一家汉堡包店"；并举了一个改名参选被法官从候选名单划掉的例子。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 很努力但看不到上升空间，正在考虑"再拼一年"。
2. 手上有 2-3 个 offer / 方向，不知道怎么选。
3. 明明能力不差，但同龄人走得更快，想不通原因。
4. 在一家平稳但没什么增长的公司待了很久，犹豫要不要动。
5. 选创业合伙人 / 选跟谁做项目 / 选加入哪个团队。
6. 副业、自媒体、独立开发选方向。
7. 有一个别人都不看好的想法，纠结要不要坚持。
8. 学术方向、导师选择。
9. 自由职业者选接哪类单、绑定哪个平台。
10. 想给自己立一个"标签"但说不清自己是什么。

### 语言信号（用户的话里出现这些就应激活）

- "我该跳槽吗" / "要不要换个方向"
- "我已经很努力了，为什么还是这样"
- "明明我比他强，为什么升的是他"
- "感觉被困住了 / 一眼看到头"
- "在 A 和 B 之间选哪个"
- "跟这个老板还有前途吗"
- "我这个想法所有人都说不行"
- "副业该做什么方向"
- "should I switch jobs" / "stuck in my career" / "how do I choose between offers"

### 与相邻 skill 的区分

- 与 `de-wei-pipei`（德位匹配，易经乾卦"亢龙有悔"）的区别（**必须分清**）：
  - `de-wei-pipei` 处理的是**位子太高、能力/德行跟不上**的风险，动作是**自省与收敛**，方向**向内**。
  - 本 skill 处理的是**位子太低、载体势能不足**的问题，动作是**主动挑选外部载体**，方向**向外**。
  - **判据：用户在担心"我是不是不配这个位置/会不会翻车"用 `de-wei-pipei`；用户在抱怨"我明明可以但上不去"用本 skill。** 两者恰好是同一坐标轴的两端，误用会给出相反的建议。
- 与 `borrow-momentum-overview`（借势）的区别：后者是**品牌/营销层面借瞬时热点或外部事件**造声量，周期以周月计；本 skill 是**个人层面选长期载体**（公司、上司、关系、想法），周期以年计。判据：借一次势用前者，选一条路用本 skill。
- 与 `positioning-six-steps` 的区别：六步曲是**主体通用**的定位工作流（品牌/业务/团队/个人都能走），本 skill 专治个人，且多了一个六步曲没有的维度——**外部载体的势能**。**个人职业问题优先本 skill**；如果用户是要给"个人品牌/专业标签"做完整定位（我该被记住为什么），可以本 skill 选马 + `six-steps` 定位 + `positioning-oversimplified-message` 削尖，三者串用。
- 与 `positioning-name-power` 的区别：本章的"名字要合适 / 避开无名陷阱 / 避开品牌延伸陷阱"三节是 `name-power` 与 `line-extension-trap` 在个人身上的应用。若用户具体在问"我的笔名/艺名/账号名该怎么取"，转 `positioning-name-power`。
- 与 `huo-yue-zai-yuan` / `shi-ji-deng-dai`（易经系时机类）的区别：那些处理"该不该出手、时机到没到"，本 skill 处理"出手的话骑哪匹马"。时机判断在前，载体选择在后，可串用。
- 与 `outside-view-forecast` 的区别：如果用户问的是"这个方向成功概率多大 / 要几年"，那是基准率问题，用 `outside-view-forecast`。本 skill 只做**相对比较与选择**，不做概率估计。

## E — 可执行步骤 (Execution)

1. **先做结构检查（由此及彼测试）**
   - 问：在你现在的位置上，通向你想要的结果，**存不存在一条结构上成立的路径**？
   - 具体算：年龄/资历/晋升位次/名额/时间窗。参照 55 岁副总裁的算法——不是"我够不够格"，是"这个位置什么时候空、空的时候谁在候选名单上"。
   - 结论只有两种：**路径存在**（继续步骤 2，努力有意义）/ **路径不存在**（直接进步骤 3 换马，不要再加倍努力）。
   - **这一步必须在所有努力型方案之前做。** 它是本 skill 存在的理由。

2. **写下你现在的定位（一个概念）**
   - 问："你能用**一个概念**概括你自己的定位吗？"
   - 检验（作者的原版检验）：如果你声称"我是【范围】里最好的【角色】"，那么在这个范围里做一次调查，**你的名字会被提到几次？**
   - 若说不出一个概念 → 这本身是结论：你在别人心智中没有位置。可配合 `positioning-oversimplified-message` 削尖。
   - 警告：作者说"大多数人没有足够的信心为自己确立一个概念。他们犹豫不决，指望别人来给自己下定义。"**别人不会替你定义，只会忽略你。**

3. **给六匹马逐一打分（核心动作）**

   对每一匹马打两个分：**当前势能（1-5）** 和 **趋势（加速 +1 / 平 0 / 减速 -1）**。趋势比当前值重要。

   | 马 | 关键问法 | 危险信号 |
   |---|---|---|
   | **1 公司** | 它有没有发展方向？增速高于还是低于行业平均？三年后这个行业更大还是更小？ | **"低于一般水平的成长"比"会倒闭"更糟**——它不给你转折点 |
   | **2 上司** | 他/她有没有前程？如果没有，公司里谁有？我在为我能找到的最有能耐的人工作吗？ | 为无能的人工作图"鹤立鸡群"——管理层不满意会**整个部门撤销** |
   | **3 朋友** | 我有几个**商界**朋友（不是私人朋友）？上次主动联系是什么时候？ | 只在需要时才联系 = 这匹马已经不能骑了 |
   | **4 想法** | 我有没有一个别人还不认可的想法？它遭到的反对是强烈持久的，还是被置之不理？ | **无人反对 = 不是想法**；等所有人认可 = 已经太晚 |
   | **5 信心** | 我愿不愿意押注在**别人**的想法/事业上？我身边有没有"有好主意但没信心"的人？ | 只肯投资自己的想法，会错过所有克洛克式机会 |
   | **6 你自己** | 单靠自己能不能完成闭环？（作者：你不能自己完成销售，必须有人来买） | 六匹马里**最低劣、最不该优先**的一匹 |

   - 完成标准：六行分数 + 每行一句理由。
   - 判定：**若前五匹马的势能全部 ≤2 或趋势全为减速，问题不在你的能力，在你的整个环境。此时任何自我提升方案都是低效的。**

4. **趋势优先于当前值（关键判据）**
   - 一匹当前势能 4 但在减速的马，长期不如当前势能 3 但在加速的马。
   - 判断方法：看**这匹马过去 24 个月**的变化（公司增速、上司的职权范围、朋友圈层的活跃度、想法被讨论的频次），而不是它现在的绝对高度。
   - 路径依赖警告：**你在减速的马上待得越久，越看不见其他马**（作者原话：夕阳产业的经验会让你"对完全不同的产品领域视而不见"）。若你已在同一匹马上超过 5 年且它在减速，必须强制引入外部信息源（换圈子、见新人、看新行业）再做判断。

5. **换马的具体动作（按马分）**
   - **换公司**：优先成长性行业与服务型业务。面试时问的不是"现在给多少"，而是"今后可能给多少"。
   - **换上司**：先在公司内部找最有能耐的人，跟他/她做事，比换公司成本低。
   - **激活朋友这匹马**（最被低估、成本最低）：
     - 列出全部商界朋友，标注上次联系时间。
     - 立即恢复"操练"：把对他们有用的东西寄过去、升职时写贺信、定期低频问候。
     - **规则：在你不需要他们的时候联系他们。** 需要时才联系已太晚。
   - **骑想法这匹马**：接受被奚落是入场费。用奥斯古德判据自检——如果没人反对，说明这不是一个想法。同时"耐心等待时机成熟"。
   - **骑信心这匹马**：主动去找"有好主意但缺信心/缺执行力"的人，认领"把它做成"的角色。
   - **骑自己这匹马**：作者不推荐作为首选。若要骑，先回答"闭环里谁来买单"。

6. **要能犯错误（尝试量校准）**
   - 计算你过去 12 个月的**尝试次数**（投出去的方案、发起的对话、发布的作品、申请的机会）。
   - 参照：泰·科布 134 次尝试 70% 成功率被记住；麦克斯·凯里 53 次尝试 96% 成功率被遗忘。
   - 判定：如果你的成功率很高但尝试次数很少，**你在优化错误的指标**。提高尝试量比提高成功率更有效。
   - "任何值得做的事情都值得一试。如果是不值得做的，那就根本不该去做。"

7. **名字与延伸自检**（可选，配合 `positioning-name-power`）
   - 不要用首字母缩写代替名字（除非人人已知道你）。
   - 名字太常见 → 混淆是定位的大敌，考虑一个可区分的呼号/笔名/账号名。
   - 若你在知名前辈/家族/大厂标签的阴影下，检查你是不是在做"个人品牌延伸"——作者警告"称'小'的那位通常意味着永无出头之日"。
   - **法律边界：改名不得用于欺诈或冒名。**

8. **输出（一页纸）**
   - 结构检查结论（路径存在 / 不存在）
   - 你的一个概念 + 提及度检验结果
   - 六匹马评分表（势能 + 趋势 + 理由）
   - 最弱的一匹 & 最值得换的一匹
   - 未来 90 天的换马动作（具体到人、具体到动作）
   - 尝试次数目标
   - 复核人（找一个不在你行业里的人看一遍，避免路径依赖）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **用户在担心"我配不上现在的位置"时**：那是 `de-wei-pipei`，本 skill 会给出相反方向的建议（继续往外找更大的马），可能加重风险。
- **载体已经足够好，问题在自身能力时**：如果公司在高速增长、上司很强、机会很多，而你交付不出结果，那是能力与执行问题，本 skill 帮不上忙，且会给你一个逃避的借口。
- **需要长期深耕才有回报的专业路径**：基础科研、临床医学、手艺、法律等领域，**积累本身就是马**，频繁换载体会归零。本 skill 的换马逻辑在这些领域会造成严重损害。
- **有强约束条件时**：家庭、健康、签证、竞业限制、经济压力。这些是硬约束，不是"你不够勇敢"。
- **情绪性冲动时刻**：刚被批评、刚错过晋升、刚吵完架。此时做换马决策的失败率极高。至少隔两周再跑本 skill。
- **想找一个"努力没用"的理由时**：本 skill 最容易被误用的方式，就是拿来给不作为背书。它的正确用法是**换马**，不是**停止骑**。

### 作者在书中警告的失败模式

- **更加努力**："更加努力很少成为通往成功之路。""失败者往往认为问题的关键是更加努力。"（第5章）
- **建立在"能力和努力最重要"的天真假设上**。
- **跟随失败者**："如果你跟随失败者，那你多么出色都无济于事。"
- **待在低于平均成长水平的公司里**：比失败更糟，因为没有第二次机会。
- **为无能的人工作**：图鹤立鸡群，风险是整个部门被撤销。
- **只有私人朋友、没有商界朋友**。
- **需要时才联系朋友**：十年不见的老友约饭定律。
- **等一个人人都认可的好想法**："世上根本就没有这样的想法。"
- **只做有把握的事**：泰·科布 vs 麦克斯·凯里。
- **等到能做得尽善尽美再动手**："你就可能永远都做不成了。"
- **想满足所有人**："如果想满足所有人的所有要求，将会一事无成。最好聚焦自己的专业，让自己成为独一无二的专家，而不是什么都干的通才。"（第21章第二步）
- **指望别人给自己下定义**。
- **优先骑自己这匹马**：作者自己的《人生定位》就是反例。

### 作者的盲点 / 时代局限

- **幸存者偏差极重**。雷·克洛克是一个成功样本，但"押注别人的想法"的失败者不会被写进书里。**六匹马的评估法在逻辑上成立，但书中给出的证据全部是事后挑选的赢家。** 使用本 skill 时，六匹马当作**检查清单**用是安全的，当作**成功保证**用是危险的。
- **1980 年代美国大企业职业结构的强假设**。当时的默认路径是"进大公司—跟对老板—沿层级上升"。今天存在大量书中不存在的路径：独立开发者、创作者经济、开源社区声誉、远程与自由职业、平台型收入。**"公司"和"上司"两匹马的权重已明显下降，"想法"和"作品"的权重上升。现代修正：应增加第七匹马——公开可累积的作品/资产（代码、内容、产品、数据），它在原书中完全不存在，而它是唯一一匹你换公司时能带走的马。**
- **"人生的成功更多是要靠别人为你做些什么"这句话过强**。它准确地纠正了勤奋崇拜，但会被误读成"实力不重要"。**乘法结构意味着两项都不能为零**——能力为零时，最好的马也载不动你。作者为了修辞效果牺牲了准确性。
- **对结构性障碍完全无视**。书中把职业结果归因于"选择"，没有讨论出身、教育机会、地域、行业准入、歧视等外部约束。**"找匹马骑"预设了你有挑马的自由，而很多人没有。** 这是本 skill 在使用时必须自己加上的现实校正。
- **"朋友这匹马"的操作在今天需要重写**。作者的方法（寄杂志剪报、写贺信）在弱连接社交网络时代已经变形。核心机制（**在不需要的时候维护关系**）依然成立，但载体变成了公开输出、社区参与、互相引用。
- **奥斯古德判据（受到的反对越强越说明可行）是明显的可证伪性陷阱**。**大量错误想法同样遭到强烈持久的反对。** 这条判据只能排除"根本没人在意"的想法，**不能证明**一个想法是对的。作者用它为自己的理论辩护，属于自我服务式引用。使用时只当作**必要条件**，绝不能当作充分条件。
- **"绝对不要为无能的人工作"过于绝对**。现实中"上司弱但业务好、平台好、自主空间大"是相当常见且划算的组合。作者只看到了部门被撤销的风险，没看到自主权带来的机会。
- **对"公司会失败反而给你第二次机会"的乐观**：这在流动性强的就业市场成立，在流动性差的时期或地域不成立。
- **第20章的部分举例涉及政治与公众人物，且带有作者的个人立场**。本 skill 已全部剔除此类举例，只保留可迁移的机制部分。

### 容易混淆的邻近方法论

- **`de-wei-pipei`（德位匹配）**：向内收敛 vs 向外选载体。**本 skill 最需要防守的混淆点。**
- **`borrow-momentum-overview`（借势）**：品牌层借瞬时热点 vs 个人层选长期载体。
- **"选择大于努力"这句流行话**：结论相同，但流行话没有给出**怎么选**。本 skill 的价值全部在六匹马的具体评估维度和"趋势优先于当前值"的判据上。只记住结论等于没用。
- **职业规划 / 生涯咨询（如霍兰德、优势识别）**：那些工具向内测**你适合什么**，本 skill 向外测**载体值不值得上**。两者互补：先用前者定方向，再用本 skill 选载体。
- **"站在风口上"（雷军式表述）**：机制接近（借外部势能），但风口讲的是**行业级**的时点，本 skill 讲的是**六类具体载体**的可操作评估，且明确包含了人际关系和信心这两类风口论不涵盖的载体。
- **平台/杠杆理论（如 Naval 的"特定知识 + 杠杆"）**：更现代的同源思想，且补上了本 skill 缺的"作品即杠杆"一环。可视为本章的现代升级版。
