## I — 方法论骨架 (Interpretation)

FWMTS 是 "Forgot What Made Them Successful" 的缩写——**忘了当初是什么让他们成功的**。它有两种相反的表现，都是同一个病：

**病症 A（僵化型）**：把"我们一直这么做"当作理由，在世界已经变了之后继续沿用旧战术。
**病症 B（抛弃型）**：因为**内部**觉得腻了、新领导要出成绩、创意团队想拿奖，把一个仍在生效的核心资产换掉。

作者关注的重点是 B，因为它更隐蔽也更常见。核心判据只有一条：

> **"腻了"这个感受是从会议室里长出来的，不是从顾客那里长出来的。**

一个用了五年的口号，团队每天看它几十遍，早就厌倦了；而一个普通顾客一年可能只接触它几次。团队的疲劳度是顾客的几百倍。以团队的疲劳为依据去换掉它，等于用一个几乎无关的信号做决策。

正确的做法作者说得很清楚：**"这里面的窍门是，确定长期的基本战略并加以改进；寻找新的方法使它受人瞩目；设法去掉那些令人乏味的地方。"** 也就是——**战略不变，战术翻新**。万宝路牛仔骑马走入夕阳的画面用了几十年；佳洁士的防蛀定位进入了第二代孩子的心智。变的是每一年的执行，不变的是那一个词。

所以本 skill 的动作是：在换掉任何东西之前，**先分离"战略层"和"战术层"**，然后**只允许改战术**，除非有顾客侧的硬证据证明战略层确实失效了。

什么算硬证据？三种：①目标顾客的无提示回忆里，那个词已经不再和你绑定；②那个词本身在语言中过时了（"花花公子"这个词现在没人自称）；③品类结构变了，那个位置已经不存在。**内部投票、创意提案、新领导的偏好、"看着土"都不算。**

## A1 — 书中的应用 (Past Application)

### 案例 1：米狮龙放弃自己的成功广告
- **问题**：米狮龙凭"有史以来最出色的定位广告"占住了高价国产啤酒的空位。
- **方法论的使用**：作者记录——"但是他们很快放弃了这一广告，采用了像'周末是为米狮龙创造的'之类毫无意义的概念。"
- **结论**：换掉的不是表达形式，是那个定位本身。
- **结果**：作者把它作为放弃有效定位的典型案例。

### 案例 2：喜力弃用"美国进口啤酒第一品牌"
- **问题**：作为领导者，喜力放弃了宣示领导地位的那句话。
- **方法论的使用**：作者在 20 周年版中修正了自己早年"领导者不必喊第一"的说法——总有新顾客进入市场，他们不知道谁是第一。
- **结果**：喜力最终把进口啤酒的领导地位让给了科罗娜。

### 案例 3：安飞士放弃"我们是老二"
- **问题**：安飞士用"我们是老二，所以更努力"建立了定位史上最著名的挑战者位置，后来改成"安飞士将成为第一"。
- **结论**：这句新话违背了原定位的全部前提——承认式关联定位的力量来自坦白，宣称要当第一等于取消了那份坦白。
- **结果**：作者将其记录为自毁式抛弃的经典案例。

### 案例 4：坚持的正面样本
- **万宝路**：牛仔骑马走入夕阳的图案"大家看了多少年了"。
- **佳洁士**：长时间坚持防蛀定位，"其定位已经进入第二代孩子的心智中"。
- **可口可乐**："正宗货"（The real thing）被作者称为"堪称经典的广告战略，适用于任何一个领导者"。
- **麦当劳**：作者给出的战术翻新方法论——"找出新方法让罗纳德·麦当劳最终表演吃汉堡包"。战略是那个形象，战术是每年让它做点新事。

### 案例 5：人造黄油的 30 年
- **问题**：30 年前头一批成功的人造黄油品牌针对黄油给自己定位，广告说"口味和价格高昂的黄油一样"。
- **方法论的使用**：作者问"如今管用的是什么招数？"
- **结果**："竟然还是那些战略。"奇峰人造黄油的"欺骗'大自然母亲'可不好"用的是同一个定位。

### 案例 6：为跟上变化而乱动的废墟
- 作者列举：胜家公司试图在家庭用品上大展宏图、RCA 试图在计算机领域大发其财、通用食品试图让快餐店遍地开花，"且不提还有数以百计的公司纷纷抛弃自家的本名，去追逐昙花一现的缩略名称"。
- **对照组**：美泰克的耐用品、迪士尼的魔幻乐园、雅芳的化妆品——"那些坚持发挥自身最佳特点、不乱阵脚的公司"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 团队提出"这个 slogan/视觉/人设用太久了，该换了"。
2. 新的负责人/CMO/运营上任，想做一次"品牌焕新"证明自己。
3. 创意方案评审时，最出彩的提案要求放弃现有核心表达。
4. 用户说"我们一直都是这么做的"来拒绝一个明显必要的改变（病症 A）。
5. 数据下滑，团队第一反应是"换个说法试试"。
6. 内容创作者觉得自己的固定选题"没意思了"想转型。
7. 个人在一个领域已有标签，觉得腻了想换赛道。

### 语言信号（用户的话里出现这些就应激活）

- "这句话用了好几年了，该换换了"
- "看着有点土/过时"
- "想做个品牌升级/焕新"
- "大家都审美疲劳了"
- "新领导想搞点不一样的"
- "我们一直都是这么做的"（病症 A 信号）
- "this tagline feels stale" / "time for a rebrand"

### 与相邻 skill 的区分

- 与 `positioning-line-extension-trap` 的区别：后者是**往外摊**（给名字增加新的意义），本 skill 是**把已有的丢掉**（放弃有效的旧意义）。两者都是稀释，方向相反，可以同时发生。
- 与 `positioning-leader-defense` 的区别：后者是完整的领导者行动清单，其中"不断重复"那一条的展开就是本 skill。领导者最常见的自毁方式就是 FWMTS。
- 与 `self-herding-break` 的**张力（必读）**：`self-herding-break` 破的是"我上次就是这么做的"这种个人惯性——它教你**打破**重复；本 skill 恰恰警告不要因为腻了就丢掉有效资产——它教你**维持**重复。二者不矛盾，判据是**证据来源**：`self-herding-break` 针对的是"重复但从未验证过效果"的行为，本 skill 针对的是"重复且有顾客侧证据证明仍在生效"的资产。**先问"它还在生效吗"，答案为是则用本 skill，答案为否或不知道则用 `self-herding-break`。**
- 与 `positioning-mind-ladder` 的区别：本 skill 需要 `mind-ladder` 提供的无提示回忆数据来判断资产是否还在生效。
- 与 `positioning-all-things-trap` 的区别：后者处理"想讨好所有人"，本 skill 处理"想换点新的"。都会导致失焦，动因不同。

## E — 可执行步骤 (Execution)

1. **把要换掉的东西拆成战略层和战术层**
   - **战略层**：那一个词/那一个位置（"安全"、"防蛀"、"老二更努力"）。
   - **战术层**：具体的文案、画面、代言人、渠道、玩法。
   - 完成标准：能明确说出"这次要换的到底是哪一层"。
   - 判停条件：若只换战术层 → **直接放行**，本 skill 不阻拦，甚至鼓励（作者：寻找新的方法使它受人瞩目）。

2. **识别病症类型**
   - **病症 B（要丢掉）**：有人主张换掉战略层 → 继续步骤 3。
   - **病症 A（不肯变）**：有人用"我们一直这么做"拒绝改变战术层 → 跳到步骤 6。

3. **追问"腻了"的来源**
   - 直接问：这个判断来自谁？团队内部、领导、创意公司，还是顾客？
   - 完成标准：明确写下证据来源。
   - 判停条件：**若来源全部在公司内部，暂不允许换战略层**，进入步骤 4 取外部证据。

4. **取顾客侧硬证据（三选一，必须至少一条）**
   - **① 绑定失效**：目标顾客的无提示回忆里，那个词已经不再和你绑定（转 `positioning-mind-mapping` 取数）。
   - **② 语言过时**：那个词本身在目标人群的语言里已经不用了（"花花公子"式过时）。
   - **③ 结构消失**：品类变了，那个位置已经不存在。
   - 完成标准：拿到至少一条并附数据。
   - 判停条件：三条都拿不到 → **结论是"不要换"**，把资源转向步骤 5。

5. **改战术不改战略（默认输出）**
   - 产出 3 条在**不改变那个词**的前提下让它重新有趣的方案。
   - 参照物：让罗纳德·麦当劳表演吃汉堡包；万宝路每年换一片新的夕阳。
   - 完成标准：3 条方案中的核心词与原战略完全一致。

6. **病症 A 的处理（僵化）**
   - 分离出"哪些是真正的心智资产（必须留）"和"哪些只是历史习惯（可以改）"。
   - 判据：如果这件事**顾客根本感知不到**（内部流程、审批方式、排版规范、发布节奏），它就不是心智资产，"一直这么做"不构成保留理由。
   - 完成标准：产出一张"必须留 / 可以改"的两列表。

7. **若确实要换战略层，写"继承方案"**
   - 新定位必须说明：旧资产里的哪一部分被继承下来、顾客如何从旧认知过渡到新认知。
   - 明确警告：作者说"一旦放弃，就会发现不可能再拿回来"。
   - 完成标准：有明确的过渡路径，而不是直接切断。

8. **输出诊断报告**
   - 含：战略/战术分层、病症类型、"腻了"的来源、顾客侧证据（有/无）、结论（换/不换/只换战术）、以及若不换时的战术翻新方案。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **定位从未真正建立过**。没有资产就无所谓稀释，此时"换个说法"是低成本试错，应当鼓励。转 `positioning-find-the-hole`。
- **品类正在被技术或政策替代**。守住"最好的马车"没有意义，此时需要的是品类重构，不是坚持。
- **原定位包含事实错误、合规风险或已被证伪的主张**。这种情况必须换，而且要快。
- **早期产品/早期账号仍在寻找 PMF**。快速迭代表达是正确动作，本 skill 会给出错误的保守建议。
- **原定位建立在已经改变的社会共识上**（性别刻板印象、地域偏见等）。这类资产应当主动放弃。

### 作者在书中警告的失败模式

- **米狮龙**：换掉最出色的定位广告，改成"周末是为米狮龙创造的"。
- **喜力**：弃用"美国进口啤酒第一品牌"，让位科罗娜。
- **安飞士**：从"我们是老二"改成"将成为第一"，自毁定位前提。
- **为跟上变化而乱动**：胜家、RCA、通用食品，以及"数以百计"抛弃本名去追缩略名的公司。
- **创意压倒战略**：作者说得极重——"最大的传播悲剧之一是看着一个组织谨慎地、循序渐进地、使用表格和图表完成自己的计划，最后却将其战略交给'创意大师'执行……战略却在一团技术迷雾中消失，再也无法辨认。"以及："创意本身一文不值，只有为定位目标服务的创意才有意义。"
- **好时的相反错误**：因为地位强大而完全不投入，最终跌出前五。**坚持定位 ≠ 停止投入。**

### 作者的盲点 / 时代局限

- **"几乎永远不应该改变基本定位战略"这个绝对表述过强**。作者自己在书里就记录了大量必须改变的情形（名字会过时、词语会过时、《绅士》让位《花花公子》、《花花公子》让位 Maxim），却没有把它整合进"坚持"这条原则里。**本 skill 的步骤 4 三条硬证据就是为了补上这个缺失的判据。**
- **媒体节奏完全不同**。1980 年的一句广告语要靠数年的重复才能进入心智，所以"坚持"的收益极高。今天算法分发下内容的半衰期以天计，**表达形式必须高频迭代**才能获得触达——这使得"战略不变、战术翻新"这条区分比作者当年更加关键，而不是更不关键。
- **忽略了品牌资产的持有者会更替**。作者假定组织有连续的记忆，但实际上核心表达往往在人员更替时被丢掉，因为新人没有参与建立过程、不理解它为什么有效。**这是一个组织问题而非营销问题，本 skill 只能提供判据，无法解决权力动因。**
- **"顾客不会腻"的假设有边界**。低卷入品类（清洁剂、保险）确实如此，但高卷入的时尚、内容、娱乐品类里，受众的新鲜感需求是真实的，重复会真的失效。使用本 skill 时应先判断品类卷入度。
- **案例的挑选偏差**：书中列举的都是"换掉后失败"的案例。那些成功换掉旧定位实现转型的品牌（万宝路自己就是从女士香烟转成男性定位的）没有被同等对待——**作者用了万宝路转型后的成功来论证坚持，却没提它转型前也"换过"。**
- **作者的商业立场**：坚持定位意味着咨询建议的长期有效性，这与其业务模式一致。

### 容易混淆的邻近方法论

- **品牌焕新（brand refresh）**：通常指视觉与语言体系的现代化，属于战术层，本 skill 不反对。反对的是把战略层一起换掉。
- **`self-herding-break`**：破除未经验证的行为惯性。本 skill 维护已验证的资产。判据是"有没有顾客侧证据"。
- **A/B 测试驱动的文案迭代**：测的是战术层的转化效率，不能用来推翻战略层——因为战略层的效果是数年累积的，单次测试测不出来。
- **沉没成本谬误**：担心"投了这么多年不能丢"。本 skill 的理由**不是**沉没成本，而是"这项资产此刻仍在产生收益"。若资产已不产生收益，本 skill 明确支持放弃。
