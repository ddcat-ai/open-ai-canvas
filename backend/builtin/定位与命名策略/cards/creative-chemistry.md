## I — 方法论骨架 (Interpretation)

作者判定创意好坏的核心标准不是"逻辑对不对"，而是"有没有化学反应"——也就是能否调动情绪、让人记住、被人议论。

几条可操作的杠杆：
- **传播大师四点**：痛点（沟通桥梁）、笑点（影响大多数）、泪点（情感高潮）、尿点（过犹不及的留白）。缺任一点都会失衡。
- **情绪张力**：广告传播的是情绪不是真相；营销力是引导情绪、让流量从低处（大众）流向高处（品牌）的能力。先问"调动了什么情绪"，而非"说清了什么真相"。
- **制造不协调**：让人记住的都是突兀/奇怪/不协调的形象（同边手男孩比踢得最好的少年更难忘）。协调=中庸油腻=被忽略；不协调=潮=被记住。
- **去爹味、去上帝视角**：新一代要秒懂，不是被教育；群体视角空洞，个体独白才出圈。

"正确废话"是最大陷阱：逻辑满分但无聊，用户划走。

## A1 — 书中的应用 (Past Application)

### 案例 1：蜜雪冰城洗脑神曲"你爱我我爱你"
- **问题**：一款平价茶饮，产品本身普通，靠什么红遍全国？
- **方法论的使用**：用"娱乐性"制造化学反应——一首洗脑神曲把品牌变成全民吃瓜的谈资，调动的是情绪（快乐）而非参数。
- **结论**：营销的本质就是娱乐，让人吃瓜才有传播。
- **结果**：2021 年一首洗脑神曲红遍全国，成平价品牌娱乐化营销范本。

### 案例 2：新疆特克斯县"天山武林大会"
- **问题**：一个默默无闻的县城，怎么引发全民关注？
- **方法论的使用**：用"制造不协调 + 娱乐性"——概念独特（县城办武林大会）形成违和记忆点，在网络时代引发全民关注。
- **结论**：制造娱乐（造瓜能力）能让无名主体出圈。
- **结果**：概念独特引发全民关注，县城出圈。

### 案例 3：传播大师四点用于内容结构诊断
- **问题**：一条短视频/广告发了没人理。
- **方法论的使用**：对照痛点/笑点/泪点/尿点四元素排布情绪节奏，发现只高潮无留白（缺尿点）或只说教无笑点（缺笑点）。
- **结论**：四元素失衡导致内容没有化学反应。
- **结果**：补齐缺失元素后内容情绪节奏更完整、更易传播。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 写好的文案/视频"逻辑对但没人看、没转化"，要找病根。
2. 从零想一个有记忆点、能传播的创意点子。
3. 内容太平、太正、太协调，想加一个"违和点"提升记忆。
4. 文案被批"爹味十足/说教感重"，要改。
5. 评估一条内容是否调动了情绪、有无传播力。

### 语言信号（用户的话里出现这些就应激活）
- "我这文案为什么没效果？" / "why is my copy not working"
- "内容太正确了像废话" / "too correct, reads like nonsense"
- "怎么让创意有化学反应？" / "how to make creative chemistry"
- "文案爹味太重" / "the copy is too preachy"
- "怎么制造记忆点？" / "how to create a memory hook"

### 与相邻 skill 的区分
- 与 `slogan-generator` 的区别：本 skill 诊断"整条内容为何没传播力"（情绪/结构/不协调），slogan 只打磨"单句主张"。
- 与 `black-fan-noise` 的区别：本 skill 的"不协调"指向内容记忆点，black-fan-noise 的"不协调"指向黑粉/对立舆情。
- 与 `borrow-momentum-overview` 的区别：总论决定借哪类势，本 skill 是把"借感性/借噪声"落成有化学反应的内容。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **诊断：它是不是"正确废话"？**
   - 完成标准：回答"逻辑是否满分但无聊、是否只堆参数没调动情绪"。若是，标记为正确废话，进入第 2 步；若本就是情绪化内容，直接进第 2 步。
   - 判停条件：若用户场景是投流 ROI 归因优化（需严谨数据），则提示"正确且可归因"优先，本 skill 仅作辅助。

2. **补情绪结构与不协调：套传播大师四点 + 加一个违和点**
   - 完成标准：对照痛点/笑点/泪点/尿点标出已有与缺失项，并给出"加哪个违和点（不协调）"的具体建议。

3. **去爹味、改个体独白**
   - 完成标准：把"教育口吻/上帝视角"改成"一个个体的真实独白、可被秒懂"；输出修改前后对照。
   - 判停条件：若用户品类要求高端克制，则保留克制但须仍满足"熟悉又陌生"与情绪调动，不强行冲突。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 纯投放排期、媒介采购、竞价优化——本 skill 管内容创意，不管买量。
- 需要严谨数据归因的投流 ROI 场景（此时"正确且可归因"的话术更优先，见批判）。
- 用户要的是事实陈述/正式公文（如合同、说明书），不宜追求"化学反应"。

### 作者在书中警告的失败模式
- 过度追求"正确"导致广告无效（ce07）：逻辑严谨只写出正确废话，正确的承诺在信息海洋无力。
- 文案爹味十足火不了（ce25）：堆修辞炫技、试图教育用户而非秒懂。
- 站在上帝视角替群体说话=不是人话（ce26）：群体视角缺乏血肉，出不了圈、没人议论。

### 作者的盲点 / 时代局限
- **贬低策略严谨性与数据驱动**："创意是化学反应、逻辑严谨只写正确废话"对投流 ROI 优化、A/B 归因这类需严谨方法的场景有误导风险——该场景下"正确且可衡量"的话术仍是基本功。
- **时代局限**：书成于 2021–2022，短视频/直播的算法与内容形态此后变化很大，具体"洗脑/不协调"手法需结合当下平台习惯重新校验。

### 容易混淆的邻近方法论
- **化学反应 vs 正确废话**：用户常把"写清楚"当创意，作者恰恰主张"不清清楚楚才是化学"；但二者在投流归因场景需重新平衡。
- 与 `slogan-generator`、`black-fan-noise` 易混：三者都涉及"让内容被记住"，区别在颗粒度（单句 / 内容结构 / 黑粉对立）。
