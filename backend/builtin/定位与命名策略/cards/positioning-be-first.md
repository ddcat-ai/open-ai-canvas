## I — 方法论骨架 (Interpretation)

人对一个品类的记忆是**路径依赖**的：第一个占位的名字会被印刻下来，后来者即使更优秀也要额外付出巨大代价才能覆盖。作者用"印刻现象"作类比——刚出壳的幼鸭把第一眼看到的对象认成母亲，此后再难更改。

这条法则的实践含义不是"晚了就没戏"，而是**改变了竞争的提问方式**：

- 错误提问：我怎么把产品做得比头部更好？
- 正确提问：**有没有一个（更窄的）品类，我能成为里面的第一？**

因为"更好"是一个需要对方主动比较才能感知的属性，而"第一"是一个不需要比较就自动获得的存储位。在信息过载环境里，前者的传播成本远高于后者。

判定链条是三步：

1. **这个品类里已经有明确的第一了吗？**（用无提示回忆测，不是用份额数据测）
2. 如果有：**它的位置是牢固的还是局势未定的？** 局势未定（两家并驾齐驱、无人明显领先）是唯一值得全力正面投入的时刻——只用一年赢得的领先往往能维持几十年。位置牢固则正面进攻基本无解。
3. 如果位置牢固：**切一个更窄的品类，让自己成为那个品类的第一。** 切法必须让顾客能立刻理解，且这个窄品类要能撑起一门生意。

还有一条容易被忽略的推论：**成为第一不等于最早发明**。第一是指第一个进入**心智**的。技术上更早但没有让人记住的，不算数；而"只要能创立一个你就是第一的认知，你不是第一也能成功"——皇家芝华士不是第一个高价威士忌，但它是第一个直接喊"我们是高价品牌"的。

## A1 — 书中的应用 (Past Application)

### 案例 1：1923 年的 25 个第一
- **问题**：先发优势到底能持续多久？
- **方法论的使用**：作者取 1923 年在 25 个品类中位居第一的品牌，追踪到 77 年后的世纪之交。
- **结论**：先发进入心智的位置具有极强的抗侵蚀性。
- **结果**：25 个品牌中只有 3 个丢掉了领先地位（永备、Manhattan、棕榄）。

### 案例 2：DEC 想"在个人电脑上超过 IBM"
- **问题**：DEC 作为跟随者，选择把产品做得更好来追赶。
- **方法论的使用**：作者指出跟风者的重点错放在"更好"而不是"速度"上——必须趁局势不明发起进攻，而不是慢慢改进产品。
- **结论**："仅仅比竞争对手好是不够的。"
- **结果**：DEC 在改进中错过了开发台式计算机的窗口，最终被康柏收购。

### 案例 3：Nyquil 避开正面对抗
- **问题**：新感冒药要进入已被康泰克、Dristan 占据的市场。
- **方法论的使用**：不去争"感冒药"这个已有第一的梯子，改切"夜间感冒药"这个自己能当第一的窄品类。
- **结论**：让那两个品牌去争日用市场。
- **结果**：成为该公司近年最成功的新品。

### 案例 4：福特埃德塞尔（反面）
- **问题**：福特投入巨资推出中型豪华轿车埃德塞尔。
- **方法论的使用**：作者事后诊断——购车者心智中根本没有空间再容纳一个有着厚厚镀层的中型轿车，那个位置已被占满。
- **结果**：美国商业史上著名的失败案例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 用户说"这个赛道已经有 XX 了，我们做一个更好的"。
2. 立项评审时讨论"后发优势"、"我们可以做得更精细"。
3. 要给一个新产品、新栏目、新服务、新概念起方向。
4. 两个玩家目前势均力敌，纠结要不要现在重投入。
5. 个人在选专业方向/内容赛道，问"这个方向卷不卷"。

### 语言信号（用户的话里出现这些就应激活）

- "已经有人做了，但我们能做得更好"
- "后发优势 / 我们可以避开他们的坑"
- "这个赛道太卷了还有机会吗"
- "要不要现在 all in"
- "怎么切一个细分方向"
- "we can build a better version of X" / "is this market too crowded"

### 与相邻 skill 的区分

- 与 `positioning-mind-ladder` 的区别：`mind-ladder` 测"我现在第几"，本 skill 决"该不该拼、拼哪个"。前者是体检，后者是手术方案选择。
- 与 `positioning-find-the-hole` 的区别：本 skill 决定"要不要另起品类"，`find-the-hole` 提供"具体从哪六个维度切"的扫描法。判断完转执行。
- 与 `positioning-leader-defense` 的区别：完全相反的立场。本 skill 服务于挑战者/新进入者，`leader-defense` 服务于已经是第一的人。
- 与 `positioning-against-the-leader` 的区别：本 skill 的结论若是"位置牢固、切不出新品类"，则退而使用关联定位——不当第一，改当"第一的对立面"。
- 与 `outside-view-forecast` 的区别：后者用同类项目基准率纠正你对**成功概率的乐观估计**（卡尼曼式），本 skill 判断的是**竞争结构**。二者可以叠加使用但机制无关。

## E — 可执行步骤 (Execution)

1. **确认"第一"的存在性**
   - 用无提示回忆而非市场份额判定：目标人群说到这个品类时，是否有一个名字被绝大多数人首先提到。
   - 完成标准：得到"有明确第一 / 两强并列 / 无人占位"三选一的结论。

2. **若无人占位 → 全速抢占**
   - 判据：这是最高价值的情形。以速度而非完备度为第一优先，先占名字与定义权。
   - 完成标准：产出可对外传播的品类名 + 一句话定义。
   - 转 `positioning-name-power` 定名字，转 `positioning-oversimplified-message` 削尖那句话。

3. **若两强并列 → 判定"局势未定"窗口**
   - 判据：双方均无明显优势、顾客无法说出谁更强。此时**值得超额投入**（作者：喷气机起飞需要 110% 功率）。
   - 完成标准：明确说明窗口还剩多久、需要额外投入多少、以及窗口关闭后的止损线。
   - 判停条件：若已能明确排出第一第二，窗口已关，跳到步骤 4。

4. **若已有牢固第一 → 做"切窄品类"扫描**
   - 强制否决"做一个更好的 X"这条路，并向用户说明理由（DEC / IBM 打施乐 / 埃德塞尔）。
   - 沿维度切：使用时机（Nyquil 的"夜间"）、使用人群、使用场景、价格带、形态尺寸、渠道。详细扫描转 `positioning-find-the-hole`。
   - 完成标准：产出 2-3 个候选窄品类。

5. **对每个候选窄品类做"第一资格三检验"**
   - ① **可理解**：能否用一句参照式说法讲清（"X 里的 Y"、"不含 Z 的 X"）？
   - ② **可占据**：这个窄品类里目前确实没有第一？
   - ③ **可养活**：占住它能不能撑起一门生意/一个岗位/一个账号？
   - 完成标准：三项全过的候选才保留；全不过则结论是"不要进这个赛道"，并明确说出来。

6. **输出决策书**
   - 含：品类现状判定、被否决的路径与理由、推荐的窄品类、三检验结果、以及"如果三检验全不过"时的诚实结论。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **竞争胜负不由认知决定的领域**：牌照/资质壁垒、独家渠道、专利封锁、成本结构碾压、双边网络效应。这些场景里"谁先进入心智"不是主要变量。
- **B2B 大额定制交易**：决策由招标流程、关系与验收标准主导，"第一联想"影响有限。
- **纯内部工具/中台**：使用者被指定，不存在选择行为。
- **已经是第一、正在被侵蚀**：应使用 `positioning-leader-defense`，本 skill 会给出错误的进攻建议。

### 作者在书中警告的失败模式

- **跟风陷阱**：跟随者把资源投在"改进产品"上，广告投入少于领导者，还用公司名当新品牌名——三重错误叠加（DEC、IBM 复印机）。
- **假第一**：用自己定义的口径宣称领导地位（"密西西比河以东、1000 美元以下最畅销的高保真音响"），顾客不认。
- **抢占已满的位置**：埃德塞尔——那个位置在心智中已经没有空间了。
- **领导者进入新品类也会输**：可口可乐做 Mr.Pibb 打佩珀博士、PowerAde 打佳得乐，都没成功。第一法则对巨头同样成立。

### 作者的盲点 / 时代局限

- **幸存者偏差极重**。作者列举的都是"第一且成功"的案例，但商业史上大量第一进入者被后来者取代：MySpace→Facebook、诺基亚→iPhone、Friendster、AltaVista→Google。这些反例在 1980 年成书时尚未发生，但今天必须补上。**更准确的表述是：先发进入心智提供了一份可观但不是不可逆的资产，它会被品类定义的重构所摧毁。**
- **"第一"与"第一个把品类做对"被混为一谈**。iPhone 不是第一部智能手机，但它重新定义了品类因而变成了心智里的第一。这说明"重新定义品类"是一条书中没有系统化的、比"抢先"更强的路径。
- **1923-2000 的 25 品牌样本**取的是消费快消品，品类生命周期长、技术迭代慢。在技术品类中这个持久性远远达不到。
- **忽略了执行质量的门槛作用**。作者为了突出"第一胜过更好"，把"更好"贬得过低；实际上"第一 + 及格线以下的产品"照样会死，只是不会死于定位。

### 容易混淆的邻近方法论

- **先发优势（first-mover advantage）经济学概念**讲的是规模经济、学习曲线与转换成本，本 skill 讲的只是**记忆占位**，两者机制不同，可以独立成立或独立失效。
- **蓝海战略**关注的是重构价值曲线创造无竞争市场空间，本 skill 关注的是心智存储位。蓝海讲"做什么"，第一法则讲"能不能被记住"。
- **"细分市场"不等于"新品类"**。细分是内部的市场划分动作，顾客感知不到；新品类必须是顾客能说出口、能用来分类的东西。
