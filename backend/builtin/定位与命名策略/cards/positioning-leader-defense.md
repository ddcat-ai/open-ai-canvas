## I — 方法论骨架 (Interpretation)

领导者的处境有一个反直觉的结构：**你的最大威胁不是对手做了什么，而是你自己为了回应对手做了什么。**

原因在于心智的运作方式。第一名的位置是靠"顾客不用思考就选你"维持的。一旦你开始论证"我们比挑战者好"，你做了三件对自己不利的事：①承认挑战者值得被拿来比较；②把挑战者的名字送进了顾客的心智阶梯；③把顾客从"不用想"推进了"要想一想"。这就是为什么泰诺对拜耳的反驳广告反而**证实**了泰诺的说法——顾客的推理是"既然它花百万美元来反驳，那说明对方讲的有道理"。

领导者的正确动作是四个：

1. **不喊"我们是第一"，改为宣传品类的价值。** IBM 的广告谈的是计算机这个品类的价值，而不是打竞品。品类做大了，领导者按结构自动拿走最大一块。但有一个例外要注意：新进入市场的顾客不知道谁是第一，所以对**一部分**人群仍应传达领导地位（喜力放弃"美国进口啤酒第一品牌"这句话后，把领导地位让给了科罗娜）。
2. **不断重复那个已经生效的东西**。可口可乐的"正宗货"是所有领导者的经典战略。领导者最大的浪费是因为自己腻了而换掉有效资产（这条与 `positioning-fwmts-trap` 直接相连）。
3. **不要把对手赶尽杀绝**。领导者需要跟随者来形成品类。宝丽莱起诉柯达并把它赶出一次成像市场，结果自己的品类跟着一起萎缩，两败俱伤。
4. **用短期灵活性换长期稳定**：新品类出现时用**新品牌**去占（多品牌挡枪），而不是把老品牌名套上去。也包括主动用新品牌淘汰自己的旧品牌——让自己被自己取代，好过被别人取代。

同时有一条必须承认的边界：**领导者进入新品类，通常也赢不了。** 可口可乐打不过佳得乐，IBM 打不过施乐。所以领导者的扩张必须用新的名字带新的梯子，而不是靠现有声望平移。

## A1 — 书中的应用 (Past Application)

### 案例 1：IBM 的广告策略
- **问题**：作为计算机领导者，广告该说什么？
- **方法论的使用**：IBM 的广告通常对竞争对手闭口不提，专门宣传计算机品类的价值——而且是所有类型的计算机，不只是自己生产的类型。
- **结论**：把蛋糕做大，领导者按结构分到最大一块。
- **结果**：长期维持领导地位。

### 案例 2：宝丽莱起诉柯达
- **问题**：柯达进入一次成像照相市场，宝丽莱选择用法律手段把它彻底赶出去。
- **方法论的使用**：作者指出这违背了"领导者需要跟随者来形成品类"。
- **结果**：两败俱伤。柯达只拿到很小份额，代价是损失了相当大的传统照相机业务；而宝丽莱失去了共同做大品类的力量。

### 案例 3：喜力放弃领导地位宣言
- **问题**：喜力弃用了"美国进口啤酒第一品牌"这句话。
- **方法论的使用**：作者修正了自己早期"领导者不必喊第一"的绝对说法——总有新顾客进入市场，他们不知道谁是第一。
- **结果**：喜力最终把进口啤酒的领导地位让给了科罗娜。

### 案例 4：好时不做广告
- **问题**：好时因为自己在巧克力业中的定位强大，认为无需再做广告；玛氏则不敢这样想。
- **结果**：等好时最终决定打广告时为时已晚——它已不是销量最大的巧克力品牌，甚至排不进前五。

### 案例 5：可口可乐进新品类
- **问题**：可口可乐用 PowerAde 打佳得乐、用 Mr.Pibb 打佩珀博士。
- **结论**：领导者在新品类里没抢到第一，就会败在别人手下。
- **结果**：Mr.Pibb 仍是可怜的二流品牌，佩珀每卖六瓶它最多卖一瓶。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 用户是行业/品类第一，团队在讨论"要不要回应竞品的攻击性宣传"。
2. 有挑战者用"我们比 XX 更好/更便宜/更快"来对标，内部想反击。
3. 出现一个新品类/新玩法，用户在纠结"我们要不要也做一个、用什么名字做"。
4. 用户想把资源从"守"转向"攻"，准备起诉/封锁/挤压对手。
5. 团队里资深骨干感到"新人在抢自己的位置"，想证明自己更强。
6. 头部内容账号看到模仿者起量，想拍视频"回应"。

### 语言信号（用户的话里出现这些就应激活）

- "要不要发文回应一下"
- "他们在碰瓷我们"
- "我们其实比他们强，得说清楚"
- "友商出了个新东西，我们要不要跟"
- "怎么把他们挤出去"
- "should we respond to the competitor" / "they're comparing themselves to us"

### 与相邻 skill 的区分

- 与 `positioning-be-first` 的区别：立场相反。`be-first` 是挑战者/新进入者视角，本 skill 是在位者视角。用 `positioning-mind-ladder` 诊断出档位后再分流。
- 与 `positioning-against-the-leader` 的区别：本 skill 是**被关联定位的那一方**该怎么办。若用户正在被人用"非可乐"式打法攻击，本 skill 给出的答案通常是"不要回应"。
- 与 `positioning-fwmts-trap` 的区别：`fwmts` 处理的是"因为自己腻了而丢掉有效资产"这一种具体病；本 skill 是完整的领导者行动清单，`fwmts` 是其中"不断重复"那一条的展开。
- 与 `positioning-line-extension-trap` 的区别：本 skill 说领导者进新品类要用新品牌，`line-extension-trap` 提供判断"这次延伸会不会稀释母品牌"的三个具体检验。
- 与 `scarcity-reactance-guard` 的区别：后者处理"收回用户既得权益引发的逆反"，与竞争防御无关。

## E — 可执行步骤 (Execution)

1. **核验领导地位是否真实**
   - 用顾客口径的无提示回忆确认第一，而不是用自定义口径的份额数据。
   - 完成标准：得到顾客视角的排位证据。
   - 判停条件：若并非第一，立即转 `positioning-be-first` 或 `positioning-against-the-leader`，本 skill 的建议不适用。

2. **对"要不要回应"下判断**
   - 默认答案：**不回应**。回应会把对手的名字送进心智并把顾客推向比较模式。
   - 唯一例外：对手陈述的是**可证伪的事实错误**且已造成实际损害。此时回应的是事实本身，不提对方品牌名。
   - 完成标准：给出明确的"回应/不回应"结论与依据。

3. **检查"重复"是否还在做**
   - 找出那个已经生效的核心表达（一句话、一个符号、一个人物形象），确认它是否仍在高频使用。
   - 判停条件：若发现团队正因"审美疲劳"要换掉它，立即转 `positioning-fwmts-trap`。
   - 完成标准：核心资产被明确识别并确认继续使用。

4. **把火力从"打对手"转到"做大品类"**
   - 产出 2-3 条宣传品类价值的表达（讲这类东西为什么值得用，不讲自家型号）。
   - 同时保留一条面向新进入顾客的领导地位表达（喜力教训）。
   - 完成标准：宣传口径中竞品名出现次数为零。

5. **处理新品类/新玩法：用新名字，不用老名字**
   - 若新机会确实存在，用一个**新品牌名**去占，把它当独立的梯子建。
   - 明确告知用户：领导者靠老品牌名平移进新品类的历史成功率很低。
   - 完成标准：新机会有独立命名方案（转 `positioning-name-power`），或明确放弃。
   - 若团队坚持用老名字，强制走 `positioning-line-extension-trap` 三检验。

6. **审查"赶尽杀绝"冲动**
   - 若计划包含起诉、封锁渠道、独家排他、挤压对手生存空间，评估：品类总量会因此扩大还是萎缩？
   - 完成标准：若结论是品类会萎缩，给出替代方案（共同做大品类）。

7. **输出防御方案**
   - 含：地位核验结果、回应/不回应结论、核心资产清单、品类价值表达、新机会的处理方式、被否决的动作与理由。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **你不是第一**。本 skill 的所有建议在第二名身上会变成"消极挨打"。第二名的正解在 `positioning-against-the-leader`。
- **对手的攻击涉及安全、合规、健康的事实性指控**。这时是危机公关与事实澄清问题，不是定位问题，必须正面、快速、具体地回应。
- **品类正在被技术替代而非被对手蚕食**。守住"最好的马车"没有意义。这种情况下需要的是品类重构，不是防御。
- **早期市场、局势未定**。此时不是"守"，而是该用 110% 功率抢占（转 `positioning-be-first` 步骤 3）。

### 作者在书中警告的失败模式

- **回应即背书**：拜耳花百万美元反驳泰诺，反而让顾客相信"阿司匹林伤胃"这件事有道理。
- **躺在定位上不投入**：好时以为地位牢固不必做广告，等回过神来已跌出前五。
- **把跟随者赶尽杀绝**：宝丽莱诉柯达，品类一起萎缩。
- **用自己的标准定义领导地位**：顾客不认自定义口径的"第一"。
- **过度谦虚地放弃领导者宣言**：喜力弃用"第一品牌"表述，位置被科罗娜接走。
- **领导者用老品牌进新品类**：Mr.Pibb、PowerAde、IBM 复印机，全部失利。

### 作者的盲点 / 时代局限

- **"不要回应"这条规则的适用前提是单向大众媒体时代**。1980 年，对手的说法只能通过付费广告触达顾客，你的沉默不会被解读为默认。今天在社交平台上，沉默会被算法与舆论填充成"心虚"，且负面内容会被无限期检索到。**现代修正：区分"不进行品牌对标式回应"（仍然成立）与"不做事实澄清"（已不成立）。**
- **反垄断维度缺失**。作者建议领导者"多品牌挡枪""为所欲为"，甚至用"300 公斤大猩猩爱在哪睡在哪睡"和微软的例子来打比方，但只轻描淡写提了一句"他们确实听到联邦政府发话了"。今天大型平台的防御动作受到严格的竞争法约束，独家排他、捆绑、封锁渠道可能直接违法。**本 skill 的所有防御动作必须在合规前提下执行。**
- **"领导者需要跟随者"的论证是案例式的**，只举了宝丽莱一例，缺乏一般性证据。在赢家通吃的网络效应品类里，这条未必成立。
- **数据来源不透明**：1923→2000 的 25 品牌追踪、"第一名份额是第二名 2 倍"等结论都未给出统计口径。
- **只谈认知防御，不谈能力防御**。真正的领导者衰落往往同时有成本结构、组织僵化、技术路线错误等原因，把它们全归到"定位动作错了"是过度归因。

### 容易混淆的邻近方法论

- **军事防御战略（进攻/防御/侧翼/游击）**是同作者后来在《商战》中的框架，比本 skill 更细。本 skill 只覆盖认知层面的防御。
- **"不回应"不等于"不行动"**。作者的意思是不在传播上把对手抬起来，而不是在产品、渠道、定价上不作为。
- **公关危机响应**遵循完全相反的原则（快速、透明、正面回应），不要用本 skill 处理危机。
