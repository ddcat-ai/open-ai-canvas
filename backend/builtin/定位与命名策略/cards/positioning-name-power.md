## I — 方法论骨架 (Interpretation)

名字不是标签，它是**定位的启动装置**。在一个人还没了解你之前，名字已经替你完成了第一轮分类——它告诉对方"这属于哪个梯子、大概站在第几级"。所以作者说，在定位时代，命名是唯一最重要的营销决策。

评估一个名字有五项：

1. **口头可传播性**。名字首先是声音。人们要能听一遍就复述、拼写、搜索。这条淘汰掉大量"看起来漂亮、说出来卡壳"的名字。作者专门讲了**发音首字母缩写原则**：人们只在缩写能明显缩短音节时才会用它。"General Electric"六个音节→GE 两个音节，所以 GE 成立；"Western Union"和"WU"音节数其实一样多（Dou-ble-U U），所以没人用 WU。"Ford Motor"只需说一个音节的 Ford，所以没人叫它 FM。
2. **自带品类线索**。好名字能启动定位程序，一听就知道这是干什么的：海飞丝、呵护（Intensive Care）、亲近（Close Up）、锋利（Edge）、永久（DieHard）。
3. **不过度通用**。这是最微妙的一条：名字要"近乎通用但又不十分通用"。米勒的"莱特"（Lite）与通用词 light 同音，结果公众和新闻界把它叫成"米勒淡啤"，米勒因此**失去了把淡啤当商标的专用权**，最后被百威淡啤超过。而一个有分量、接近通用的描述性名字则能防止对手跟风挤进你的领地。作者甚至在 20 周年版里公开**收回**了自己早年的判断——他原先认为通用性的《新闻周刊》胜过《时代》，后来承认反了，是被后者表面的成功误导了。
4. **缩写资格**。首字母缩写是**成名之后**的特权，不是成名的手段。罗斯福和肯尼迪是先出名才用 FDR、JFK 的。想让人记住你，你需要的是一个名字，不是一组字母。政客们都懂这个：埃德蒙·杰拉尔德·布朗当上州长后自称杰里·布朗而不是 E.G. 布朗。
5. **词义所有权**。终极目标是让一个名字变成一个词的替代物——"拜耳放在哪儿"、"把 Dial 递给我"。但这也带来风险：通用化过头会失去商标（作者提醒小心"山姆大叔把你的东西没收"）。

还有一条底层逻辑支撑这一切：**词语本身没有含义，含义在使用它的人身上**。作者用糖罐做比喻——罐子在放糖之前只是空罐。所以名字的价值不在词典义，而在它能触发什么。"野马"让同一辆车显得更快更野。而如果罐子已经漏了（一个词被污染了、过时了），最好扔掉换一个新罐子，而不是坚持往里装。

## A1 — 书中的应用 (Past Application)

### 案例 1：米勒"莱特"起名过头
- **问题**：Lite 与通用词 light（淡啤）在英文中发音一致。
- **方法论的使用**：作者判定这是"名字起过了头"——含义过于接近产品内涵本身，变成了适用于全品类的通用名称。
- **结果**：莱特虽然是第一个进入心智的淡啤品牌，但公众与新闻界很快把它叫成"米勒淡啤"，米勒失去了对"淡啤"及其同音词的商标专用权，随后出现施利茨淡啤、安海斯-布希天然淡啤等一大批产品。该品牌后来改名"米勒莱特"，屈居百威淡啤之后。

### 案例 2：西部联盟 vs 通用电气
- **问题**：为什么 GE 通行而 WU 只在公司内部使用？
- **方法论的使用**：发音音节计算。"Western Union"与"Dou-ble-U U"音节数相同，缩写没有带来任何便利。
- **结论**：如果没有发音上的便利，人们不会去用首字母缩写。作者补充："把内部的行话翻译成局外人能明白的语言，这是广告和公关公司的工作之一。"（作者自称为该公司干了十多年。）

### 案例 3：《财富》500 强里的"无名"公司
- **问题**：1980 年成书时榜单上有 27 家用缩写做名字的公司，20 周年版时增至 44 家。
- **结论**：公司把内部节省打字时间的书面缩写误当成了"成功的代号"。
- **结果**：作者点名列举了一长串（AMP、CSX、TJX、TRW、USX、TIAA-CREF……），并挖苦"不知道 TIAA-CREF 怎样才能变成一个家喻户晓的名字"。

### 案例 4：名字会过时
- **问题**：《绅士》（Esquire）本是给爱玩的年轻男子的绝好名字，《游艇》曾是航海界第一杂志，《印者之墨》曾是广告界的好名字。
- **结论**："产品会过时，服务会过时，连名字也会过时。"《绅士》把领先地位交给了《花花公子》；《印者之墨》让位于《广告时代》；而《花花公子》自己后来又被 Maxim 超过——因为现在的花花公子们不会自称花花公子了。
- **应用**：聪明的公司不会把钱浪费在维护旧事物上，而是推出新品牌利用变化带来的机遇。

### 案例 5：个人改名
- 莱奥纳德·斯莱 → 罗伊·罗杰斯；马里恩·莫里森（放在彪悍牛仔身上有点女人气）→ 约翰·韦恩；伊苏尔·达尼埃洛维奇 → 科克·道格拉斯。
- **作者的诚实补充**："多年来，我们曾建议许多商界人士改名字，至今还没有一个接受建议的。"

### 案例 6：美孚 1（反面）
- **问题**：第一种发动机合成润滑油，营销概念很出色。
- **结论**："新概念需要有一个新名称，而不是一个合成的延伸名称。"
- **结果**：卖得不好。作者认为这个品类"依然在等待领导者"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 新产品/新公司/新栏目/新开源项目要起名，候选列表定不下来。
2. 团队想用首字母缩写（尤其是内部已经这么叫习惯了）。
3. 有人提议用一个"高级感"的造词或外语词。
4. 老名字用了几年，感觉不对劲/被人叫错/搜不到。
5. 个人要做 IP，纠结用真名还是艺名。
6. 已经找到空位，要给这个位置一个名字（`positioning-find-the-hole` 的下游）。
7. 领导者要用新品牌占新品类（`positioning-leader-defense` 的下游）。

### 语言信号（用户的话里出现这些就应激活）

- "这个名字怎么样"
- "叫 XX 还是叫 YY"
- "我们内部都叫它 ABC"
- "想要一个有科技感/高级感的名字"
- "别人老把我们名字念错"
- "what should we name this" / "is this a good brand name" / "naming ideas"

### 与相邻 skill 的区分

- 与 `positioning-find-the-hole` 的区别：先有位置再有名字。空位没定就起名，会起出一个漂亮但不指向任何位置的名字。**顺序：find-the-hole → name-power。**
- 与 `positioning-oversimplified-message` 的区别：本 skill 处理**名字**（一个词，长期不变，法律可保护）；后者处理**信息**（一句话，可迭代）。两者都追求"只占一个词"，但对象不同。名字定了之后用后者定那句话。
- 与 `positioning-line-extension-trap` 的区别：本 skill 决定"新东西该叫什么"，后者判断"能不能沿用旧名字"。当有人提议"就用我们现有品牌名"时，先跑后者的三检验，再回本 skill 起新名。
- 与 `positioning-career-horse` 的区别：后者是个人的方向选择，本 skill 只处理个人 IP 的名字部分。
- 本 skill **不做商标法律检索**。定位层评估通过后，仍需专业的商标查询与注册流程。

## E — 可执行步骤 (Execution)

1. **前置确认：位置先于名字**
   - 确认已经知道这个东西要占什么位置（哪个品类的哪个格子）。
   - 判停条件：位置不明确 → 先转 `positioning-find-the-hole`。名字无法弥补定位的空缺。

2. **做口述复述测试**
   - 把名字**只用嘴说一遍**（不给对方看字），让 5 个陌生人复述并写下来。
   - 完成标准：复述正确率与拼写正确率均 ≥80%。
   - 不通过的名字直接淘汰，不要试图用"多曝光几次就习惯了"来救。

3. **五项评估打分（每项 0/1/2 分）**

   | 项 | 检查 | 0 分 | 2 分 |
   |---|---|---|---|
   | ① 口头可传播 | 音节数、易读、易拼、易搜 | 需要拼写解释 | 一遍就对 |
   | ② 品类线索 | 听到名字能猜出是干什么的吗 | 完全无线索 | 自带定位启动 |
   | ③ 通用度 | 近乎通用但不十分通用 | 与通用词同音同形（莱特病） | 描述性强但可独占 |
   | ④ 缩写资格 | 是否想用首字母 | 未成名就用缩写 | 不用缩写，或缩写确实大幅省音节 |
   | ⑤ 词义所有权 | 想占的那个词有人占了吗 | 已被强品牌占据 | 空着且能占 |

   - 完成标准：总分 ≥7 且无 0 分项。

4. **做"过时检验"**
   - 问：这个名字绑定的是一个正在上升、稳定、还是正在退潮的词？（《游艇》《印者之墨》《绅士》都是绑在退潮词上的好名字。）
   - 完成标准：明确说明该名字的预期有效期与退潮信号。

5. **做"糖罐检验"（改名场景专用）**
   - 若是改名需求：现在这个名字这只罐子是**空的**（还没被赋予含义，可以继续装）还是**漏的/脏的**（已被污染、被误解、被绑定在错误的类别上）？
   - 罐子只是空的 → 不需要改名，需要往里装内容（转 `positioning-oversimplified-message`）。
   - 罐子漏了 → 换罐子，即改名。
   - 完成标准：给出明确的"改/不改"结论与依据。

6. **缩写请求的处理**
   - 若用户想用首字母缩写：计算音节数。若缩写音节 ≥ 全称音节，直接否决（WU 教训）。
   - 若音节确实大幅缩短，仍需说明：缩写是成名之后的特权，未成名时用缩写等于放弃被记住的机会。
   - 完成标准：给出音节计算过程与明确结论。

7. **输出命名评估报告**
   - 含：位置描述、候选名单、口述测试结果、五项打分表、过时检验、最终推荐 + 一个备选、以及"下一步需做商标检索"的提示。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **位置尚未确定**。名字是位置的载体，没有位置的名字只能评估形式不能评估效果。
- **名字已被法律或历史锁定**（家族企业、已注册多年的商标、监管备案名）。此时问题变成"如何在既有名字下建立定位"，而不是改名。
- **纯内部代号**（项目 A、迭代 v2）。不面向外部的名字不需要定位价值。
- **商标可注册性判断**。本 skill 只做定位层评估，法律层必须交给专业检索。
- **需要跨语言使用的名字**。本 skill 的音节规则是基于英语和中文的，跨语种的负面含义检查不在覆盖范围内。

### 作者在书中警告的失败模式

- **无名陷阱**：用首字母缩写做名字。1980 年 27 家、20 周年版 44 家《财富》500 强犯了这个错。
- **起名过头**：莱特/light 同音导致失去商标专用权，最终从第一跌到第三。
- **视觉导向而非听觉导向**：作者指出公司总在提升名字的视觉效果上费尽周折，"却没有考虑到它听上去如何"。
- **合成的延伸名称**：美孚 1——新概念需要新名称。
- **回头求助于历史**：用法国赛车手的名字（雪佛兰）、代表女儿的名字（梅塞德斯）。过去管用的东西现在未必管用。
- **名字过时却不换**：《绅士》《游艇》《印者之墨》。
- **偏执**："偏执是通往定位成功之路的障碍。"车在大众的工厂里生产，不代表它必须叫大众——中档豪华车需要"奥迪"这个新罐子。

### 作者的盲点 / 时代局限

- **发音缩写原则是基于英语音节的**。中文语境下规则不同：中文缩写往往取字而非首字母（"腾讯"不缩，"中国建设银行"→"建行"），且中文双音节词天然易记。**应用时应把"音节经济性"这条原则本身迁移过来，而不是照搬英文的字母规则。**
- **书中列举的"无名公司"清单里有大量至今仍成功的企业**（AT&T、CBS、CVS、EMC、TJX）。作者的论断被自己的数据部分证伪——缩写名的公司数量从 27 增到 44，说明市场并没有惩罚它们。更准确的表述是：**缩写不利于从零建立认知，但不妨碍已有认知的维持。**
- **搜索与域名维度完全缺失**。1980 年不存在"这个名字搜得到吗""域名/账号 ID 有没有被占""在应用商店里会不会和别人混淆"这些问题，而今天它们的权重可能高于音节数。**本 skill 的步骤 2 已把"易搜"并入口述测试，使用时应额外做一次搜索占位检查。**
- **作者自己承认过判断失误**（《时代》vs《新闻周刊》的正反两次表述），这提示命名评估中"通用度"这一项的判断可靠性最低，应更依赖实测而非直觉。
- **改名建议的实际采纳率为零**：作者自陈多年建议商界人士改名"至今还没有一个接受建议的"。这是一个诚实但也是重要的信号——**改名的组织阻力极高，评估时应把可执行性纳入考虑**，很多时候更现实的方案是给新业务起新名字，而不是改老名字。
- **性别相关的举例（"放在彪悍牛仔身上有点女人气"）是时代产物**，应用时不采用此类表述。

### 容易混淆的邻近方法论

- **通用起名法/头脑风暴取名**：追求好听、有寓意、独特。本 skill 追求的是**与心智阶梯的耦合**——名字能否启动正确的品类联想与位置。两者的评价标准不同。
- **商标可注册性**：法律标准（显著性、在先权利），与传播标准部分冲突——律师偏好造词（柯达、施乐），定位偏好近乎通用的描述性名字。作者明确记录了这个张力。
- **SEO/关键词命名**：优化的是被搜索到，与被记住是两件事。
- **`positioning-oversimplified-message`**：处理一句话，不是一个名字。
