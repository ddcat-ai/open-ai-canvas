## I — 方法论骨架 (Interpretation)

好名字是省广告费的：它能让用户秒懂你是干啥的，不用每次传播都解释一遍。作者给了一个可套用的"五等式"——名字尽量等于以下之一：

- **等于品类**：铂爵旅拍（一听就知道是旅拍）
- **等于卖点**：白加黑（一听就知道昼/夜分服）
- **等于优点**：安尔乐（一听就安心）
- **等于心智**：可口可乐（成了品类代称）
- **等于 APP/动作**：BOSS 直聘（等于"找工作"这个动作）

占住其中一格，传播成本就降一格；占不住，每传一次都费劲，做起来后还得改名重建认知。

配套原则 **拒绝标识**：年销售 1 亿以下的生意，别花钱做视觉 logo——标识是巨大的识别障碍，没钱推广时它毫无意义，品牌名本身就是标识。先老老实实用文字。

## A1 — 书中的应用 (Past Application)

### 案例 1：唱吧 K 歌宝改名（占品类、降传播成本）
- **问题**：原名叫"唱吧小巨蛋"，传播时必须补一句"能 K 歌的麦克风"，成本极高。
- **方法论的使用**：套"名字等于品类"，改成"唱吧 K 歌宝"，直接占有"K 歌宝"这个品类词。
- **结论**：改名后不再需要解释，一句话封死赛道。
- **结果**：完全占有"K 歌宝"品类，让竞争对手无路可走。

### 案例 2：Ulike 加"蓝宝石"（名字等于卖点/占心智）
- **问题**：Ulike 本身不是好名字，脱毛仪赛道内卷、市占率卡在 30%。
- **方法论的使用**：把产品特性"蓝宝石"植入名号，变成"Ulike 蓝宝石脱毛仪"，占住"高级"心智。
- **结论**：名字自带卖点+心智锚点，省下大量解释成本。
- **结果**：市占率从 31% 升到 55%，4 个月打爆市场。

### 案例 3：铂爵旅拍（名字等于品类）
- **问题**：厦门本土小公司，要和传统影楼差异化。
- **方法论的使用**：名字直接等于"旅拍"品类，并用"想去哪儿拍就去哪儿拍"讲清差异。
- **结论**：名字即定位，抢占旅拍心智。
- **结果**：业务遍布全球，成旅拍品类代表品牌。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 新品牌/新产品/新栏目要起名，纠结叫什么。
2. 现有名字每次都要解释，怀疑"是不是坏名字"。
3. 品牌做大了想改名，担心重建认知成本。
4. 想判断一个候选名"是否等于品类/卖点/心智"。
5. 早期团队纠结"要不要先花钱设计 logo"。

### 语言信号（用户的话里出现这些就应激活）
- "给我起个品牌名/产品名" / "help me name a brand / product"
- "这名字是不是太晦涩要解释？" / "is this name too obscure"
- "名字要不要等于品类？" / "should the name equal the category"
- "早期要不要先做 logo？" / "do I need a logo this early"
- "改名划算吗？" / "is renaming worth it"

### 与相邻 skill 的区分
- 与 `slogan-generator` 的区别：本 skill 产出"名词（叫什么）"，slogan 产出"句子（主张什么）"；命名看"是否等于品类/卖点"，slogan 看"是否封杀品类"。
- 与 `borrow-momentum-overview` 的区别：总论决定"借哪类认知"，本 skill 是把那类认知落成文字名字。
- 与 `visual-hammer-nail`（其他 agent 负责）的区别：拒绝标识原则主张早期只用文字，视觉锤是另一回事。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **用五等式检验候选名：它能等于品类/卖点/优点/心智/APP 中的哪一格？**
   - 完成标准：每个候选名标注它占了哪一格；占不住任何一格的列为"高传播成本名"并建议淘汰或改造。

2. **判断是否需要 logo：年销是否过 1 亿？**
   - 完成标准：若未过亿，明确建议"暂不做视觉标识，品牌名即标识"；若已过亿，可进入视觉锤设计。
   - 判停条件：若用户坚持要做 logo 且品类为高端/超我生意（靠文化格调），则允许做，但须先用第 1 步保证名字本身可懂。

3. **给出改名决策：现有名是否每次都要解释？**
   - 完成标准：若"是"，给出改名方案（套五等式）并提示重建认知成本；若"否"，保留并说明它占住的格。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 用户要的是一句广告语/slogan（交给 `slogan-generator`）。
- 用户只想要视觉 logo/包装设计，不涉及"名字本身传播成本"。
- 名字已等于品类且业务健康，仅因"不够洋气"想改——属老板个人品位干扰（见批判）。

### 作者在书中警告的失败模式
- 坏名字晦涩、反复改名浪费认知（ce24）：起名过于晦涩，每次传播都特别费劲、总需解释；做起来后被迫改名，向公众重建认知浪费巨大。

### 作者的盲点 / 时代局限
- **"拒绝标识"对高端/超我生意不完全适用**：高端品牌恰恰靠文化与格调（超我生意/高级趣味），完全无视觉标识可能损害高端感；书中"品位是流量的敌人"与此内部矛盾。
- 五等式偏向"秒懂型"大众传播，对需要制造神秘感/稀缺感的高端小众品牌未必最优。

### 容易混淆的邻近方法论
- **命名 vs 口号**：名字是名词、slogan 是句子，验收标准不同，常被用户混为一谈。
- **拒绝标识 vs 视觉锤**：作者主张早期只用文字，但视觉锤（具象记忆符号如白发）仍可在无 logo 时存在，二者不冲突。
