## I — 方法论骨架 (Interpretation)

本 skill 是全书的**编排层**：它不发明新机制，而是把前二十章的判断按正确顺序串成一条可执行的流水线，并给每一步装上**否决权**。

作者的核心设计是：这六问不是"要考虑的六个方面"，而是**六道闸门**。任一道不过，整个定位就该被枪毙，而不是打个折继续做。这是它区别于普通"品牌策划模板"的地方——模板求覆盖，六步曲求淘汰。

### 六步

**第一步：你拥有怎样的定位（现状）**
- "不要问自己是什么，要问自己在潜在顾客心智中是什么。"
- 必须**从市场取答案，不从营销经理取答案**。要撇开企业自尊。
- 要思路开阔、考虑全局：比利时航空的问题不是航空公司，是"比利时"这个国家；七喜的问题不是柠檬饮料，是可乐在心智中的绝对优势。
- **闸门**：如果你说不出"顾客现在认为我们是什么"，或者说的是内部希望的答案，第一步没过。取数用 `positioning-mind-mapping`。

**第二步：你想拥有怎样的定位（目标）**
- 关键词是**"拥有"**。太多广告宣传的是自己不可能抢占的定位，因为已经有人占了。
- 埃德塞尔失败的原因之一：购车者心智中根本没有空间再容纳一个有厚厚镀层的中型轿车。
- Nyquil 明智地避开正面对抗，让康泰克和 Dristan 去争日用感冒药，自己占"夜间感冒药"。
- 也不能太宽："即使能建立，也无法防御来自像 Nyquil 这样定位更窄的产品的攻击。"
- **闸门**：目标位置必须是**空的**且**可防守的**。找空位用 `positioning-find-the-hole`。

**第三步：谁是你必须超越的（对手）**
- "不要对市场领导者进行正面攻击。绕过障碍要比穿过它好得多。"
- 作者的橄榄球比喻：得分（确定定位）不难，难的是"在你和球门线之间还站着 11 个人"（实施定位）。
- 要从**竞争对手的角度**看自己的处境，不只从自己的角度。
- **闸门**：如果答案是"正面超越领导者"，直接否决。转 `positioning-against-the-leader` 或 `positioning-reposition-rival`。

**第四步：你有足够的钱吗（资源）**
- "抢占人们的心智需要金钱支持。建立定位同样需要金钱支持，保住已建立的定位同样需要金钱支持。"
- 作者用宝洁举例：押注新产品时"在桌子上轻放 2000 万美元，然后环顾一下对手们说：'你们下注吧。'"
- 解法不是放弃，是**缩小地域范围**："如果资金有限，在一个城市花足钱比在多个城市捉襟见肘要好得多。"
- **闸门**：这是最常被跳过、也最有杀伤力的一问。**很多定位在战略上完全正确，只是买不起。**

**第五步：你能坚持到底吗（时间）**
- "定位需要积累，利用的是广告的长期特性。需要年复一年地坚持。"
- "企业几乎永远不应该改变它的基本定位战略，这几乎毫无例外。能改变的只是它为实施长期战略采取的战术和短期的行动。"
- 窍门是："确定长期的基本战略并加以改进；寻找新方法使它受人瞩目；设法去掉那些令人乏味的地方。"
- "在心智中占据定位如同拥有价值连城的不动产。一旦放弃，就会发现不可能再拿回来。"
- **闸门**：如果这个定位需要三年而你只有一年耐心，选一个一年能做到的更窄的定位。

**第六步：你符合自己的定位吗（一致性）**
- "创意本身一文不值，只有为定位目标服务的创意才有意义。"
- 作者的原话很不客气：定位理论确实限制了创造性——而这是对的。
- 检验方式极其具体："你的衣着会告诉人们你是个银行家、律师抑或是艺术家吗？你会穿那些损害你的定位而有创意的衣服吗？"
- 安飞士"我们工作更努力"之所以有效，是因为**它听上去不像广告，而是营销战略**。
- **闸门**：所有对外触点（产品、包装、话术、招聘、办公室、创始人穿着）都必须与定位同向。任一处反向即是漏水。

### 三个贯穿全流程的态度（第22章）

- **要有眼光**：不要"转动方向盘去迎接每一次新浪潮"，要看五到十年。改变大公司方向"如同让一艘航空母舰转向"。
- **要有勇气**：领导地位靠的不是营销技巧甚至不是产品创新，而是**抢占先机**——"领导者通常是在形势未定的时候就投入了营销资金"。好时因为定位太强而不打广告，等它决定打广告时已跌出前五。
- **要客观**：**"一旦你觉得自己想到的那个简单的想法能够解决你的问题时，你已经失去了某样东西——你的客观性。"** 作者的对策是"定位就像打乒乓球一样，最好由两个人来玩"——本书由两人合写不是偶然。

## A1 — 书中的应用 (Past Application)

### 案例 1：七喜（六步走通的完整样本）
- **第一步**：七喜发现自己在心智中的问题不是"柠檬饮料排第几"，而是"给我来杯饮料"对大部分人意味着可口可乐或百事可乐。
- **第二步**：目标位置定为"非可乐"——一个当时空着的位置。
- **第三步**：不与可乐正面比口味，而是把两大可乐并成一类，自己站到类的外面。
- **第五步**：长期坚持这一条主张。
- **结论**：作者的总结是"考虑全局，七喜才建立了成功的非可乐定位"。

### 案例 2：Nyquil（第二步的正面样本）
- **问题**：新品进入已被康泰克、Dristan 占据的感冒药市场。
- **做法**：不抢日用感冒药，占"夜间感冒药"。
- **结果**："Nyquil 成了他们近些年推出的最成功的新品。"

### 案例 3：埃德塞尔（第二步的反面样本）
- **失败原因之一**："购车者心智中根本没有空间再容纳一个有着厚厚镀层的中型轿车。"
- **要点**：产品可以没问题，位置不存在就是不存在。

### 案例 4：Rheingold vs Schaefer（第二步"太宽"的代价）
- Rheingold 分别宣传各族群都喝，结果"试图吸引所有人，结果什么人也没有吸引到"。
- Schaefer 锁定"重度饮用者"，广告语"唯一一种喝了还想喝的啤酒"，成功。

### 案例 5：宝洁的下注（第四步）
- **描述**：宝洁押注新产品时放 2000 万美元在桌上，然后问对手"你们下注吧"。
- **推论**：定位竞争在很大程度上是**出价能力**的竞争。作者给出的现实解法是缩小地域范围逐城打透。

### 案例 6：李维斯（第五步的反面）
- **做法**：李维斯做品牌延伸进入休闲服饰。
- **结果**：它在牛仔服领域的基本定位随后受到"设计师标签"牛仔的冲击。
- **结论**："一旦定位丢失，品牌就是无锚之船，漂浮不定。"

### 案例 7：好时（勇气的反面）
- 好时认为自己在巧克力业的定位十分强大，无需广告；玛氏不敢这么想。
- 等好时决定打广告时已太晚——"好时已不是销量最大的巧克力品牌，甚至连前五位都排不上"。

### 案例 8：安飞士（第六步）
- "安飞士在租车业里仅排第二位，但为什么还要找我们？因为我们工作更努力。"
- 作者点评："这听上去不像广告，而是营销战略。实际上，两者都是。"

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 新品牌 / 新产品线 / 新业务从零做定位。
2. 老品牌年度品牌规划、定位复盘。
3. 业务增长停滞，怀疑是"定位问题"但说不清是哪一环。
4. 团队内部对"我们是谁"没有共识，每个人讲法不同。
5. 已经有一版定位方案，需要有人做压力测试（尤其是钱与坚持两问）。
6. 创业公司写 BP 前的战略梳理。
7. 部门/团队要向公司说明自己的独特价值（组织内部定位）。
8. 一个区域市场 / 一个细分人群的进入策略。

### 语言信号（用户的话里出现这些就应激活）

- "我们该怎么定位"
- "帮我做一下品牌定位"
- "定位流程是什么" / "从哪开始做定位"
- "这个定位方案你看能不能落地"
- "我们的战略是不是有问题"
- "团队对我们做什么没有共识"
- "brand positioning" / "positioning exercise" / "GTM positioning"

### 与相邻 skill 的区分

本 skill 是**编排层 / 入口**，其余定位类 skill 是它的子步骤。**如果用户的问题落在单一环节上，直接用对应的子 skill，不要走完整六步。**

| 用户实际在问 | 用哪个 |
|---|---|
| "我们现在在顾客心里排第几 / 是什么" | `positioning-mind-mapping`（取数）→ `positioning-mind-ladder`（判位） |
| "有什么位置是空的" | `positioning-find-the-hole` |
| "怎么打领导者" | `positioning-against-the-leader` / `positioning-reposition-rival` |
| "我们是领导者，怎么守" | `positioning-leader-defense` |
| "这句话怎么说才短" | `positioning-oversimplified-message` |
| "这个名字行不行" | `positioning-name-power` |
| "能不能用主品牌推新品" | `positioning-line-extension-trap` |
| "我的职业方向怎么选" | `positioning-career-horse` |
| **"从头到尾做一次 / 帮我检查整套方案"** | **本 skill** |

- 与 `positioning-mind-ladder` 的区别：阶梯是**诊断工具**（我在第几级），六步曲是**决策流程**（所以我该干什么）。阶梯是六步曲第一步的一部分。
- 与 `positioning-find-the-hole` 的区别：找空位是六步曲**第二步**的展开。若用户只问"有什么空位"，别拉他走完六步。
- 与 `positioning-career-horse` 的区别：后者是个人层面的选择法（选公司/老板/朋友/想法/信心/自己），本 skill 是主体（品牌/业务/团队/个人）通用的定位流程。**个人职业问题优先用 `career-horse`**，因为它多了"外部载体势能"这个本 skill 没有的维度。
- 与 `outside-view-forecast` 的区别：第四、五步涉及资源与时间的现实判断，但本 skill 只给否决闸门，不做概率估计。若用户需要"这个计划要多久/成功率多少"，那是 `outside-view-forecast`。

## E — 可执行步骤 (Execution)

> 每一步都有**通过条件**和**否决条件**。否决即停，回到指定 skill，不要带着未过的闸门往下走。

1. **第一步：你拥有怎样的定位**
   - 问法：**不是**"我们是什么"，**是**"潜在顾客心智中我们是什么"。
   - 取数要求：答案必须来自市场，不来自营销经理。至少访谈 8-10 位真实目标用户（含未购买者）。系统方法用 `positioning-mind-mapping`。
   - 同时做"全局视角检查"：问题会不会**根本不在你这一层**？（比利时航空的问题在"比利时"；七喜的问题在"可乐"。）
   - 通过条件：写出一句"顾客认为我们是＿＿"，且能拿出原话佐证。
   - 否决条件：只有内部说法 / 顾客说不上来（这本身是有效结论：定位模糊或不存在）。

2. **第二步：你想拥有怎样的定位**
   - 列 2-3 个候选目标位置。
   - 对每个位置做三检：**空吗？**（有没有人已占）**守得住吗？**（会不会被更窄的对手切）**够大吗？**（值不值得占）
   - 通过条件：有 1 个位置三检全过。
   - 否决条件：位置已被强占 → 转 `positioning-find-the-hole` 重找；位置太宽 → 收窄（Nyquil 式）；位置太窄以致市场不成立 → 记入第四步的经济性评估。
   - 提醒："拥有"是关键词。不要宣传一个你抢不到的位置。

3. **第三步：谁是你必须超越的**
   - 列出挡在你和这个位置之间的具体对手（不是"行业里所有人"）。
   - 从**对手视角**写一段："如果我是他，我会怎么反击？"
   - 通过条件：明确 1-2 个必须绕过的对手 + 一条绕行路线。
   - 否决条件：路线是"正面比他更好/更便宜/功能更多" → 否决，转 `positioning-against-the-leader`（借位）或 `positioning-reposition-rival`（挤位）。

4. **第四步：你有足够的钱吗**（最常被跳过的闸门）
   - 估算：让目标人群中 X% 形成认知，需要多少触达 × 多少频次 × 单位成本 × 多少个月。
   - 与竞品的营销投入做量级对比（不是精确对比，看**数量级**）。
   - 通过条件：预算与所需在同一数量级，或已按下条收窄。
   - 否决条件：差一个数量级以上 → **不要打折执行**，改为缩小范围：一个城市 / 一个渠道 / 一个人群 / 一个场景，把钱花透。作者："如果在一个地方成功了，就可以在其他地方推广了——如果第一个地点选择正确的话。"
   - 收窄后回到第二步重定位置。

5. **第五步：你能坚持到底吗**
   - 写出未来 36 个月的坚持承诺：这条主张在什么时间点之前不改。
   - 压力测试三问：换 CEO 会不会改？半年没起色会不会改？竞品出新概念会不会跟？
   - 区分**战略**与**战术**：战略不变，战术必须常新（"找出新方法让罗纳德·麦当劳最终表演吃汉堡包"）。
   - 通过条件：能写出"不变的那一条"+"可变的战术清单"。
   - 否决条件：无法承诺 12 个月以上 → 换一个 12 个月内能建立的更窄定位。

6. **第六步：你符合自己的定位吗**
   - 列出全部对外触点：产品本身、包装、官网首屏、销售话术、客服口径、招聘 JD、办公空间、创始人公开表达、内容选题、合作对象。
   - 逐项标记：**同向 / 无关 / 反向**。
   - 通过条件：无反向项。
   - 否决条件：存在反向项 → 先改触点，或承认定位不成立。
   - 创意检查：所有创意方案都要过一句问话——"这个创意在为定位服务，还是在为好看服务？"

7. **三态度复核**
   - **眼光**：这个定位五年后还成立吗？还是在追一个浪？
   - **勇气**：需要在形势未明时就投入吗？敢不敢？（好时的教训是"等确定了再投"通常太晚。）
   - **客观**：**做一次"失去客观性"自检——你是不是已经爱上自己想出来的那个简单想法了？** 作者要求找一个"篮板"：至少一位不参与该项目的人复核全流程。

8. **输出（定位一页纸）**
   - 现状认知（含用户原话）
   - 目标位置 + 三检结论
   - 必须绕过的对手 + 绕行路线
   - 预算量级判断 + 范围收窄决定
   - 36 个月不变承诺 + 可变战术清单
   - 触点一致性检查表（含反向项处置）
   - 复核人与复核意见
   - **每个否决闸门的通过/否决记录**（这是本工作流的核心产物，比结论本身更有价值）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **单一环节问题**：用户只问一个点，别拉他走六步（对照 A2 的分流表）。
- **产品尚未成立时**：连产品能不能做出来、有没有人用都不确定，定位是过早优化。先做需求验证。
- **纯效果广告 / 短期促销**：本 skill 服务的是长期认知资产，不服务本周的 ROI。
- **技术选型、组织架构、定价等非认知问题**：定位解决"顾客心里怎么想"，解决不了成本结构和交付能力。
- **危机公关**：需要的是事实澄清与止损，不是长期定位建设。
- **产品还在高速探索期、方向每月都在变**：第五步必然否决。此时应先收敛业务，再做定位。

### 作者在书中警告的失败模式

- **通盘思考前就想找解决之道**："通常人们在通盘思考问题前就想找到解决之道。"六步曲的第一价值就是拦住这个冲动。
- **从营销经理那里要答案**："要从市场中得到'我们的定位是什么？'的答案。"
- **企业自尊干扰第一步**：作者专门点出"要撇开企业自尊，这很重要"。
- **宣传一个抢不到的位置**：第二步的"拥有"是关键词。
- **正面攻击领导者**：第三步的明确禁令。
- **想得太多、定位太宽**："满足所有人需求"的陷阱，也无法防御更窄的对手。
- **投不起还硬投**：第四步。宝洁式对手会直接抢走你的概念。
- **不停改战略**："企业几乎永远不应该改变它的基本定位战略。"
- **把战略交给创意大师**：作者说这是"最大的传播悲剧之一"——组织谨慎地用表格图表做完计划，最后"战略却在一团技术迷雾中消失，再也无法辨认"。
- **爱上自己的想法**：客观性丧失的那一刻，就是你觉得自己想到了一个好点子的那一刻。

### 作者的盲点 / 时代局限

- **第四步的"钱"在今天不再是唯一稀缺资源**。1980 年心智份额基本可以用广告费买到。今天分发由算法决定，内容质量、社区、口碑、创始人 IP、开源、产品自传播都能替代部分预算。**现代修正：第四步应问"你有足够的钱**或**足够的非付费分发能力吗"，两者至少有一样。** 但作者的底层判断仍然成立：**心智份额不会免费到来，只是货币变了。**
- **第五步的"永不改变基本定位"过于绝对**。作者写作时品类生命周期以十年计，今天以年甚至月计。有大量成功的重新定位案例（Netflix 从邮寄 DVD 到流媒体、Slack 从游戏到协作工具、Shopify 从卖滑雪板到 SaaS）。**修正：不变的应该是"你在顾客心中解决的那个根本问题"，而不是"你说的那句话"。** 作者把两者混为一谈了。
- **六步曲缺少"验证"这一步**。全流程是一次性规划，没有小步验证、A/B、灰度的位置。这是前互联网时代规划方法的通病。**建议在第六步后加一步：用最小成本在一个渠道验证目标位置是否被接收，再全面投入。**
- **缺少退出与迭代条件**。作者只讲"坚持"，不讲"什么信号出现时应该承认定位错了"。这在实践中很危险——它让"坚持"和"固执"无法区分。**补充判据：坚持的前提是认知在缓慢改善；若 12 个月内目标人群的无提示回忆毫无变化，那不是耐心问题，是位置选错了。**
- **样本几乎全是美国 1970s 消费品**。B2B 复杂销售、开发者工具、平台双边市场、订阅制的定位逻辑与本流程有明显差异（决策链多角色、试用即验证、留存权重远高于认知）。
- **"局外人=客观"与作者自身的咨询业务立场一致**，第七步的"找个篮板"是对的，但"必须找广告公司/咨询公司"这个隐含结论应打折。
- **完全没有合规与伦理闸门**。第三步的"绕过对手"、第二步的"抢占位置"在今天需要叠加反不正当竞争、广告法、比较广告合规的检查。**本 skill 在第三步与第六步已内置提醒，使用时不得省略。**

### 容易混淆的邻近方法论

- **STP（细分-目标-定位）**：STP 是**市场侧**分析框架，先切市场再选人群；六步曲是**心智侧**决策流程，先看认知再定位置。STP 的"定位"是 STP 的最后一步，六步曲则把它整个展开。两者可以叠用：STP 定人群，六步曲定位置。
- **商业模式画布 / 精益画布**：覆盖价值主张、渠道、成本等九块，是**业务全貌**工具；六步曲只处理认知这一条线，但深得多（尤其钱与坚持两问）。
- **品牌屋 / Brand Key 等模板**：模板求填满，六步曲求淘汰。**如果一个方法没有让你毙掉任何东西，它就不是六步曲。**
- **`positioning-mind-ladder`**：诊断，不是流程。
- **OKR / 战略解码**：管的是目标与执行对齐，不管"顾客心里怎么想"。第六步与它有交集（触点一致性），但出发点不同。
