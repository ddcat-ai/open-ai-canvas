## I — 方法论骨架 (Interpretation)

资源匮乏者的冷启动不靠砸钱，而靠"识别符号 + 反复词语 + 创意事件"三步成形，同时警惕文艺青年式自毁。

1. **从零三步**：先找视觉锤（过目难忘的具象符号，如白发、乌尼莫克），再找文字钉（每个阶段一个被反复钉入心智的关键词，如"解气"），最后以"预算不足"为核心洞察做几个营销事件补足注意力。
2. **年轻是优势不是劣势**：没经验=无条条框框、没钱=逼出四两拨千斤的创造力、没房=能开疆辟土、学历低=包袱轻、没女友=不被缠住——"五无"反而是试错资本。
3. **莫欺少年穷**：苹果在车库、美的街道企业、大疆居民区起步；有眼光地接初创客户/自己起步，都是对未来的投资。
4. **最优路线分工**：新国货可把注册/营销/电商/供应链/测试拆到沪/京/杭/穗/蓉五城，取长补短而非堆一地。
5. **文艺青年三大缺陷（red flag）**：不会算账、高估自己审美、误解世界——用文艺思路做产品/品牌必败，需主动过滤这类声音。

## A1 — 书中的应用 (Past Application)

### 案例 1：金枪大叔抖音号——零投流冷启动样板
- **问题**：作者要做面向 To C 的个人 IP，却一分钱流量都不买，怎么起盘？
- **方法论的使用**：用"从零三步"——以过目难忘的白发做视觉锤，配"解气/秀发更出众"等文字钉，再用甩头发、乌尼莫克救援等营销事件成形；与红制作互为背书。
- **结论**：没钱靠创意事件，视觉锤+文字钉+事件三者缺一则做不大。
- **结果**：零买量获约 300 万粉丝，成为营销网红。

### 案例 2：锤子手机——文艺青年双重缺陷的反面教材
- **问题**：为何锤子手机从备受期待到失败？
- **方法论的使用**：作者归因于"两大错误"——创始团队是文艺青年 + 用户也是文艺青年；叠加不会算账、高估审美、误解世界三缺陷，规模上不去。
- **结论**：团队与用户双重文艺，靠情怀与审美而非算账驱动，专门做文艺青年生意一定做不大。
- **结果**：锤子手机失败，成为全书反复引用的"文艺青年必败"反例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 个人/小团队想做品牌或 IP，但预算几乎为零，不知从哪下手。
2. 刚毕业/年轻，自我怀疑"条件差能不能创业"。
3. 创业团队里有人坚持"我觉得美/有情怀"压倒算账与大众审美。
4. 想布局产业链，纠结公司/供应链放哪个城市。
5. 投资人看早期项目，想判断创始人是不是"文艺青年型"危险信号。

### 语言信号（用户的话里出现这些就应激活）

- "我没预算怎么做品牌 / zero to one 从零起步怎么办？"
- "视觉锤 visual hammer / 文字钉 nail / 营销事件怎么做？"
- "我还年轻没经验没钱，能创业吗 young founder advantage？"
- "我们团队就喜欢有审美有情怀，这有问题吗？"
- "文艺青年 / 初创客户 / 个人IP冷启动"

### 与相邻 skill 的区分

- 与 `trust-endorsement`（S07）的区别：本 skill 是"冷启动动作（锤/钉/事件）"，信任背书是"凭什么被信"；启动后可接背书 skill 补可信度。
- 与 `client-selection`（S10）的区别：本 skill 站在创业者自己起步，客户选择是接单方筛选别人。
- 与 `brand-lifecycle`（S09）的区别：本 skill 是微观从零动作，生命周期是宏观赛道 timing（先判期再启动）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定视觉锤 + 文字钉**
   - 完成标准：给出 1 个具象、过目难忘的视觉符号（非抽象 logo）和 1 个当前阶段核心文字钉，二者可配套记忆。

2. **策划 1–3 个营销事件**
   - 完成标准：基于"预算不足"洞察，列出≤3 个可被策划、能低成本获取注意力的具体事件（动作级，非"做个活动"）。
   - 判停条件：若用户已有稳定投放预算且视觉锤/文字钉清晰，则跳到步骤 3，不必硬造事件。

3. **排雷文艺青年 + 选址分工**
   - 完成标准：用"不会算账/高估审美/误解世界"三项自查团队决策；若做实体供应链，给出沪京杭穗蓉的分工建议。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 品牌已有成熟资产只做迭代，应转视觉锤/ slogan 类 skill 而非从零。
- 重资产、长周期科技研发，单靠"营销事件"无法补足产品力缺口。
- 纯融资模型/财务测算场景，本 skill 不解决资金结构。

### 作者在书中警告的失败模式

- **文艺青年三大致命缺陷**（ce03）：用文艺思路做产品——不会算账、高估审美、误解世界，导致做不大甚至做死；核心团队是文艺青年即 red flag。
- **锤子手机双重文艺失败**（ce04）：文艺青年团队 + 文艺青年用户，规模上不去，专做文艺青年生意必败。

### 作者的盲点 / 时代局限

- **"年轻五优势"浪漫化**：没房没女友在现实中是生存压力，"无经验"也可能意味着踩坑成本；该 framing 激励性强但弱化了真实风险与福利保障。
- **视觉锤/文字钉依赖个人 IP**：作者以自身"白发"为例，强个人符号对机构型品牌未必适用，且"甩头发"类事件在低俗/合规边界上需谨慎。
- **乙方视角**：作者鼓励"先愤怒/先制造争议"起盘，对高客单价、专业服务、医疗健康等品类并不适用（见阶段 0 批判）。

### 容易混淆的邻近方法论

- **从零三步 vs 品牌五维度**：三步是"识别符号成形"（产品级动作），五维度是"产品→文明"演进路线图；先有三步打底，再逐级长成品牌。
- **莫欺少年穷 vs 无脑接初创**：接初创客户要有眼光（投资思维），不是所有"少年"都值得接，需结合 client-selection 红线。
