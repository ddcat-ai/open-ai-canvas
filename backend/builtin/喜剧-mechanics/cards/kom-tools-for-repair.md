## I — 方法论骨架 (Interpretation)

八项幕后工具（获胜、非英雄、隐喻关系、正向行为、动态情绪、直线波浪、原型、喜剧前提）本质是**维修扳手，不是创作公式**。决策序应该是：
1. **信直觉**——正常写/演，相信本能；
2. **观感卡住**——某场戏不对劲、不响、泄气；
3. **用八工具定位**——拿对应工具诊断"哪里坏了"；
4. **修**——只修坏的那块，修好就停手。

## A1 — 书中的应用 (Past Application)

### 案例 1: 马克斯兄弟先巡演校正再拍（c59）
- **问题**: 喜剧创作者如何保证笑点成立？
- **方法论的使用**: 作者引《歌台三怪》马克斯兄弟先巡演、用现场观众校正喜剧，再拍摄；法拉利兄弟《阿呆与阿瓜》也靠试片重拍（见重写）。
- **结论**: 创作者须先把戏拿出来"跑"，哪里不响就用工具修，而非闭门按公式造。
- **结果**: 印证"先直觉创作、后观众校正维修"的循环。

### 案例 2: 滥用结构教条的警示（ce33）
- **问题**: 为什么死守"转捩点必须在75%"会害戏？
- **方法论的使用**: 作者批评盲目追求通用结构如用同一蓝图盖楼；《今天暂时停止》《恋夏500日》都不对称却优秀。
- **结论**: 结构重要但非铁律，让结构代替判断会杀死独特喜剧节奏——这也适用于八工具：别让工具代替直觉。
- **结果**: 反面佐证"工具是扳手不是蓝图"。

### 案例 3: 用抽象概念当工具的陷阱（ce06）
- **问题**: 为什么"惊喜/反差/讽刺"清单式技巧没用？
- **方法论的使用**: 作者指出这些只是"会出现在喜剧里的元素"名词，写到第二幕中段面对空白页无法告诉你下一步。
- **结论**: 真正工具须可操作；本 skill 的"维修"定位正是把八工具当可操作步骤而非概念收藏。
- **结果**: 划清"可操作扳手"与"伪工具"的边界。

### 与相邻 skill 的区分

- 与 `kom-comedy-equation` 的区别：方程本身是"总诊断框架"（一种工具），本 skill 是"何时/是否动用工具的元规则"。先问"要不要修"，再问"用方程怎么修"。
- 与 `kom-expectation-gap` / `kom-winning` 等具体工具的区别：那些是扳手，本 skill 是"扳手使用说明书"（何时拿、何时收）。
- 与 `kom-rewriting` 的区别：重写是"修完后的迭代流程"，本 skill 是"决定要不要修、用哪把扳手"的决策层。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判定是否真卡壳**
   - 完成标准: 确认这场戏是"正常流畅"还是"明显不对劲（不响/泄气/违信）"；流畅则建议相信直觉、不动工具。

2. **选对应扳手定位故障**
   - 完成标准: 若卡壳，从八工具里挑最贴近的一项（如缺动能→equation；笑点不动→expectation-gap；角色不可信→non-hero），不做全工具扫荡。

3. **只修坏处并停手**
   - 完成标准: 给出最小修复方案，并明确"修好即停，不继续套其他工具添乱"，引用 ce33/ce06 提醒别公式化。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 戏明明已卡壳却还硬凭直觉、拒绝分析（那是 ce02 分析恐惧，应先说服动用工具）。
- 把本 skill 当"创作公式"每集机械套用——本 skill 恰恰反对公式化。
- 纯表演/单句台词微调，不涉及"整体是否坏掉"的判断。

### 作者在书中警告的失败模式

- ce33（结构教条主义）：别让通用蓝图/工具代替判断。
- ce06（用抽象概念当工具）："反差/讽刺"清单不是可操作扳手；八工具须当维修步骤用。
- ce02（分析喜剧就害死它）：反向陷阱——以"分析会杀魔力"拒绝在卡壳时维修，本 skill 主张"该修就修、修完就停"。
- ce36（轻视喜剧无关紧要）：若因此不肯下功夫诊断卡壳戏，喜剧会敷衍。

### 容易混淆的邻近方法论
