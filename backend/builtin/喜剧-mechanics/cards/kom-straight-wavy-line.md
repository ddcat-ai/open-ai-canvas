## I — 方法论骨架 (Interpretation)

- 喜剧的笑点来自"有人看傻事 + 有人做傻事"的观看关系，不是某个人单纯好笑。
- 重心（focus）一次只由一个人享有；本节拍谁在挣扎、谁在旁观，笑点重心就在谁。
- 没有"直线角色"或"波浪角色"，只有某节拍里谁占重心；同一角色这场直线、下场波浪。
- 应用到单集：让做傻事（占直线），子女目瞪口呆（占波浪），下个节拍互换，群像轮流承重。
- 这是团队合作，每位成员都为喜剧时刻贡献，不是"谁讲梗谁好笑"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 阿伯特与科斯特洛《谁在一垒》（c40）
- **问题**: 表面看阿伯特"看得见"、科斯特洛"看不见"，谁是喜剧重心？
- **方法论的使用**: 近看阿伯特才是看不见的（没发现把对方搞糊涂），科斯特洛是看得见的却因非英雄无法破解。
- **结论**: 情感重心在苦苦挣扎的科斯特洛（波浪型），喜剧靠"有人看傻事有人做傻事"的重心流动。
- **结果**: 论证喜剧是团队合作，重心不在固定角色。

### 案例 2: 《欢乐单身派对》乔治禁欲（c41，重心流动）
- **问题**: 同一集里笑点重心如何分配。
- **方法论的使用**: 杰瑞先是波浪（被分散注意挣扎），乔治是直线（不知自己变天才）；当乔治抬头困惑，重心转至乔治成波浪，杰瑞变直线。
- **结论**: "没有直线/波浪角色，只有重心"——重心随节拍在角色间进出。
- **结果**: 提供"喜剧重心随节拍流动"的操作模型（如《大家都爱雷蒙》）。

### 案例 3: 《鲍勃大卫二人秀》勃根地牛肉饼（c42）
- **问题**: 男子面对"便椅餐盒"该如何反应。
- **方法论的使用**: 男子（大卫·克罗斯）是波浪型，对白极简（"你要我一边吃晚餐一边拉屎在盒子里？"）；女友是直线（看不出盒子不对）。
- **结论**: 波浪型曲线对白可少到极致，只需简单直接诚实，不必帮他写聪明话。
- **结果**: 论证"你不需要帮波浪型曲线想聪明对白"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 单集分场时不知笑点该落在谁身上、重心怎么排。
2. 主演抢走所有笑点台词，群演/配角没戏，群像失衡。
3. 设计代际观看关系——闯祸、子女在旁目瞪口呆崩溃。

### 语言信号（用户的话里出现这些就应激活）

- "笑点都给了一个人 / 怎么分配搞笑"
- "谁是捧哏、谁是逗哏 / 正经人+谐星"
- "这集重心在哪 / 单集结构"
- "为什么观众只笑不笑子女"

### 与相邻 skill 的区分

- 与 `kom-perspective-lens` 的区别（易混诱饵）: perspective-lens 管"角色怎么看世界 / 隐喻关系 / 框架"（感知滤镜）；straight-wavy-line 管"笑点重心在谁、怎么流动"（结构分配）。问"的世界观滤镜"用 perspective-lens，问"笑点落谁、单集重心"用 straight-wavy-line。
- 与 `kom-archetype` 的区别: archetype 管"固定角色谱系 / 关系引擎"（人物底座）；straight-wavy-line 管"单场重心流动"（单集结构）。原型是长期底座，重心是单场调度。
- 与 `kom-non-hero` 的区别: non-hero 管"降技能 / 缺技能"；straight-wavy-line 管"谁看谁做"的观看关系。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **标出本场"既定"与重心归属**
   - 完成标准: 每个关键节拍标出谁是直线（制造/无视问题）、谁是波浪（挣扎旁观）。

2. **检查笑点是否被一人独占**
   - 完成标准: 确认重心随节拍在 ≥2 个角色间流动，无单一角色包揽所有笑点。

3. **设计互换节拍**
   - 完成标准: 单集至少有一次重心互换（如直线变波浪），群像轮流承重。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单人独角喜剧 / 脱口秀（无"观看关系"双人组），重心流动无从谈起。
- 纯正剧冲突不需要"谁看谁做"的重心分配。

### 作者在书中警告的失败模式

- ce18（认为喜剧是"正经人＋谐星"组合）：定型是假典范，忽略重心流动才是精髓。
- ce19（独占笑点）：主演把笑台词收归己有，破坏团队聚焦，观众错过真正喜剧重心。
- ce32（过度机锋 / 乒乓球对白）：全员伶牙俐齿无挣扎，失去"不知道/苦苦挣扎"则无喜剧。

### 作者的盲点 / 时代局限
### 容易混淆的邻近方法论

- 与 `kom-perspective-lens`（感知滤镜）最易混——前者问"角色怎么看世界"，本 skill 问"笑点重心落谁"。
