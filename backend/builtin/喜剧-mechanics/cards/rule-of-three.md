## I — 方法论骨架 (Interpretation)

"三"是喜剧里最可靠的节奏工具，因为它天然契合 joke structure：
- **第 1、2 拍**：建立一种模式（并诱导一个假设）——"哦，这是在按 X 规律走"。
- **第 3 拍**：打破模式，击碎那个假设——意外在第三下爆发。

为什么是三不是二？两拍刚建立模式，观众还没"信任"规律；三拍让规律显得成立，第三下的破才够意外。排比清单、连续动作、递进台词，只要出现"一、二、三"，就是天然的埋梗位。第三拍的破法可以接 `premise-opposition`（朝更负面）或 `reveal-at-end`（翻转词置末）。

## A1 — 书中的应用 (Past Application)

### 案例 1：邮局三连 bits
- **问题**：如何把素材组织成有节奏的笑点群？
- **方法论的使用**：作者把邮局素材排成 I / II / III 三连递进，前两拍立"高效"模式，第三拍破成"用枪的高效"，并在 III 上加 tag。
- **结论**：三拍结构让单点素材变成一段有起伏的喜剧节奏。
- **结果**：成为 Rule of Three 与 tag 的联合示范。

### 案例 2：排比清单
- **问题**：为何"列三个"比"列两个"好笑？
- **方法论的使用**：两拍只立模式，三拍才破；观众在第三下等到了预期的"意外"。作者把它列为 Ch4 节奏打磨的核心法则。
- **结论**：三的节奏是 joke structure 在序列上的体现。
- **结果**：成为全书反复使用的节奏模板。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？
1. 段子里有一个列表/排比，想把它变好笑。
2. 写了"一、二、三"但第三下不好笑。
3. 想用节奏而非纯语言制造 punch。

### 语言信号
- "排比怎么埋梗 / 列表怎么好笑"
- "rule of three 怎么用"
- "三的节奏"
- "我这段有'一、二、三'但不好笑"

### 与相邻 skill 的区分
- 与 `joke-binary-structure`：binary-structure 是单 setup/punch 的原子结构；rule-of-three 是把结构铺在"序列"上的节奏法。
- 与 `tag-jokes`：tag 是同一 joke 内追加 punch；rule-of-three 是三拍递进，第三拍本身即 punch。

## E — 可执行步骤 (Execution)

1. **找出素材里的列表/排比/连续动作**
   - 完成标准：至少能列出 3 个同类项。
2. **前两拍立模式 + 诱导假设**
   - 完成标准：观众能看出"在按某规律走"；若前两拍没规律→先造规律。
3. **第三拍打破模式（破假设）**
   - 完成标准：第三下与规律相反（朝更负面/意外），reveal 置末（转 `reveal-at-end`）。
4. **（可选）第三拍后加 tag**
   - 完成标准：想多拿笑→转 `tag-jokes`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 单一 setup/punch、没有序列 → 用 `joke-binary-structure`。
- 还没有素材 → 用 `joke-prospector-map`。

### 作者在书中警告的失败模式
- 第三拍"不够破"（只是同类延续）→ 观众等到的是平淡，不是意外。
- 硬凑三拍、填充无意义项 → 拖节奏。

### 作者的盲点 / 时代局限
- 并非所有文化/语境都以"三"为最稳节奏；有时二拍或四拍更合适，需临场判断。

### 容易混淆的邻近方法论
- "重要的事说三遍"是修辞强调；rule-of-three 是"两立一破"的结构，目的是意外而非强调。
