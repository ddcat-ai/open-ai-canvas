## I — 方法论骨架 (Interpretation)

一个笑话由两部分咬合而成：
- **setup（铺垫）**：用有限信息诱导观众脑补出一个更大的"第 1 个故事"（1st story），并顺带让他们做一个"目标假设"（target assumption）。
- **punch（包袱）**：抛出一个"再诠释"（reinterpretation），揭示一个与 1st story 相反的"第 2 个故事"（2nd story），从而砸碎那个假设、制造意外与笑。
- 连接两者的那点信息叫 **connector（连结点）**——它必须能被至少两种方式解读（两路是最低要求，多路可生成多个 punch）。
- 结构成立的硬条件：setup 与 punch 的"意见"必须相反（好→坏，或坏→更坏）。没有 2nd story 就没有意外，就没有笑话。

读完这段，没读过原书的人应理解：笑话不是"一句好笑的话"，而是"两个相反故事在 connector 处碰撞"的结构工程。

## A1 — 书中的应用 (Past Application)

### 案例 1：Stephen King 笑话（good-to-bad 范本）
- **问题**：如何直观演示"相反意见碰撞"？
- **方法论的使用**：setup 讲 King"保有小男孩的童心"（好），punch 翻转成"把小男孩的心脏泡在罐子里"（坏），同一个 connector（童心）产生两种解读。
- **结论**：好→坏的结构让 punch 的恶意反转极具冲击力。
- **结果**：成为全书最常被引用的教学范例。

### 案例 2："想妻子→想狗"反例
- **问题**：为什么有些"段子"根本不好笑？
- **方法论的使用**：某句"男人为思念妻子而难过"的 punch 仍是"思念妻子"，没有 2nd story、没有推翻 target assumption。
- **结论**：缺 2nd story = 缺意外 = 不是笑话。
- **结果**：作者用此反例锚定"二元结构"的必要性。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？
1. 写了一个段子但读起来平淡、自我重复，不确定问题在哪。
2. 拿到别人的笑话想拆解、学习或改写得更好。
3. 分析"为什么某个梗冷场 / 不好笑"。

## E — 可执行步骤 (Execution)

1. **拆出 setup / punch**
   - 完成标准：能分别用一句话说出"观众被引导相信什么"和"最后揭示了什么"。
2. **找 1st story 与 2nd story**
   - 完成标准：两个故事主题相反（好→坏或坏→更坏）；若相同 → 这不是笑话，回到步骤 1 重做 punch。
3. **定位 connector 与 target assumption**
   - 完成标准：能指出"哪点信息诱导了误判"；若找不到 connector，说明 punch 与 setup 脱钩，重做。
4. **检查意见是否相反**
   - 完成标准：setup 的隐含意见与 punch 相反；若只是同调重述 → 转 `premise-opposition` 调整前提。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 纯信息查询（查某个术语定义）→ 看 GLOSSARY.md。
- 诗歌/小说/非幽默叙事结构 → 本结构只服务"制造意外笑"。

### 作者在书中警告的失败模式
- 把 setup-premise 当 setup 用（只写出一则笑话就卡住）→ 见 `joke-prospector-map`。
- punch-premise 夹带例子，限制展开 → 见 `joke-prospector-map`。

### 作者的盲点 / 时代局限
- Dean 的"二元结构"以 one-liner 与短 routine 为主，对长篇叙事喜剧、角色弧光类幽默覆盖较弱。

### 容易混淆的邻近方法论
- "反差梗"是大众口语；本 skill 的 connector / target-assumption / reinterpretation 是有可操作提问法的精确模型，不是"随便弄个反差"。
