## I — 方法论骨架 (Interpretation)

喜剧动能不是情节公式，而是四个要素的"充要条件"：
1. **平凡人**——不是英雄，不是机灵担当。
2. **难如登天的困境**——让角色真正难办的事。
3. **缺乏获胜技能/工具**——关键缺口，越多技能越不喜剧。
4. **永不放弃希望**——这是喜剧与戏剧的分水岭。

四要素缺一则削弱；**去掉"希望"一项就转为戏剧**（而非更喜剧）。所以"悲惨"不等于"喜剧"，失去希望才不是喜剧。诊断任何一场戏，拿这四个象限逐格自检即可定位"哪里泄了气"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《情怀九月天》去希望即变戏剧（c09）
- **问题**: 伍迪·艾伦后期模仿伯格曼拍出《情怀九月天》，观众觉得沉重不是喜剧。
- **方法论的使用**: 作者对比其前期（神经质纽约客屡败屡战、永不放弃希望＝喜剧）与此片（角色沉浸痛苦、毫无希望＝戏剧）。
- **结论**: 同一作者、同款神经质角色，只是拿掉了"希望"一项，喜剧动能立刻塌陷为戏剧。
- **结果**: 证明"希望"是喜剧的充要条件，去掉即转化类型。

### 案例 2: 查理士·布朗逊 vs 伍迪·艾伦对决十二枪手（c15）
- **问题**: 怎样让"一个人对决十二个持枪敌人"立刻好笑？
- **方法论的使用**: 作者把英雄（布朗逊，编剧给足技能）换成非英雄（伍迪，缺技能却不放弃），仅设定即引笑。
- **结论**: "平凡人＋难如登天的困境＋缺技能"三要素一立，喜剧当场生成，无需对白。
- **结果**: 印证要素齐备即生喜剧动能。

### 案例 3: 增减技能调节喜剧/戏剧（c21）
- **问题**: 同类型片为何有的喜剧有的不喜剧？
- **方法论的使用**: 比对《开麦拉惊魂》（无丛林技能）、《百货战警》（连抓轮椅老人都困难）与《终极警探》（威利是受训警官）。
- **结论**: 给角色技能＝英雄化、滑向戏剧；夺走技能＝喜剧化。
- **结果**: 给出可操作杠杆——想加喜剧就减技能，想加戏剧就加技能。

- "这集怎么就是不好笑/不出喜剧效果？"
- "是不是太悲惨了所以不喜剧？"（应纠正：缺的是希望不是悲惨）
- "角色突然变厉害/认命了，戏就没劲了"
- "comedy equation / 喜剧动能 / 为什么 not funny"

### 与相邻 skill 的区分

- 与 `kom-expectation-gap` 的区别：方程式是"总诊断框架"，落差引擎是"喜剧发生的具体位置"。先用本 skill 看四要素齐不齐，再用落差 skill 设计"期待 X → 现实 Y"的笑点结构。
- 与 `kom-non-hero` 的区别：非英雄只覆盖"缺技能"这一项；本 skill 还管"希望""困境""平凡人"三项的整体平衡。
- 与 `kom-funny-vs-comedy` 的区别：好笑vs喜剧是"定义辨析"，本 skill 是"四要素自检工具"，后者更偏操作落地。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出四要素自检清单**
   - 完成标准: 对当前这场戏/这集，明确写出"平凡人是谁、困境是什么、缺哪项技能、希望是否还在"四项，缺项标红。

2. **定位泄气项并修复**
   - 完成标准: 找出最弱的一项（通常是"希望消失"或"技能过多"），给出修正（如：让重新燃起一个蠢希望、夺走她某样新技能）。
   - 判停条件: 若四项都在且戏仍不动，跳到步骤 3 转入 `kom-expectation-gap` 设计落差。

3. **用案例锚定修正方向**
   - 完成标准: 引用 c15/c21 的"增减技能"杠杆或 c09 的"保住希望"原则，确认修正不把戏推成戏剧。

## B — 边界 (Boundary) ★

### 🔴 硬约束（世界层·违背就崩）

- 不能违背基本的喜剧方程式逻辑，否则观众/读者会立刻出戏
### 🟡 软约束（规则层·违背有代价）

- 纯段子/脱口秀写作（本方程是叙事喜剧诊断，不评单口台词）。
- 讽刺片只想表达理念、不在乎真人希望（见 ce27，本方程仍适用但需先补真人）。
- 用户只想"加个笑点"微调，而非诊断整体动能——那该用 `kom-joke-four-requirements`。
### 🟢 自设约束（认知层·其实可以重定义）

- 以为喜剧方程式只有一种正确用法——假墙，方法是工具，不是教条
- 以为喜剧方程式能解决所有问题——假墙，每个方法都有适用场景
