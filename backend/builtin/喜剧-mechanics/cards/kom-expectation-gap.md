## I — 方法论骨架 (Interpretation)

喜剧不在事件本身，而在角色**"期待"与"现实"的缝隙**里。这个落差由"不知道"（kom-not-knowing）创造，角色待在落差里**越久，喜剧节拍越长**——所以"慢懂比快懂更喜剧"。

关键点：
1. 主冲突来自**落差**，不是外部坏人对抗（人本身就是冲突，不用发明敌手）。
2. 可主动设计"套路期待 X → 意外现实 Y"的落差结构作为每集笑点骨架。
3. 别用"他们会觉得我疯了"人为拖延揭示（ce11），最佳喜剧允许角色最快解决，落差靠"不知道"自然维持。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《我的孩子们》艾登"偷瞄"（c07）
- **问题**: 为什么肥皂剧只有戏剧性、没有喜剧？
- **方法论的使用**: 作者分析艾登"完美到逆天"绝不偷瞄；一旦平凡男人用伍迪方式偷瞄（人性不完美），就成喜剧。
- **结论**: 落差来自角色放下"应该怎样"的期待、暴露真实局限。
- **结果**: 确立"喜剧讲述关于人的真实"的立论基石。

### 案例 2: 《哈拉玛莉》泰德"清枪"白果酱（c18）
- **问题**: 经典"恶烂"桥段笑点从哪来？
- **方法论的使用**: 法拉利兄弟没给泰德俏皮话，只让他"不知道"被误导尻枪，精液黏耳被当发胶。
- **结论**: 不靠抖机灵，靠角色不知道+期待现实落差生喜剧。
- **结果**: 示范"慢慢来"的领悟时刻最关键。

### 案例 3: 《飞进未来》乔许镜子慢懂（c19）
- **问题**: 为什么变大人戏好看？
- **方法论的使用**: 13岁男孩变30岁缓慢"不知道"地探索镜中陌生身体；对比《回到17岁》瞬间"啊啊啊"破坏不知（c23反例）。
- **结论**: 慢懂维持落差，快懂消解落差。
- **结果**: 证明"慢慢来的醒悟时刻"是喜剧核心。

### 案例 4: 勃根地牛肉饼餐厅（c42）
- **方法论的使用**: 男子面对"便椅餐桌"内心为期待现实落差挣扎，对白极简（"你要我一边吃一边拉屎在盒子里？"）。
- **结论**: 波浪型只需简单直接诚实，不需聪明对白。
- **结果**: 论证落差靠"角色遇此境脱口而出的话"而非妙答。

### 语言信号 (用户的话里出现这些就应激活)

- "这集笑点怎么设计？给我个反套路结构"
- "以为____结果____"式的构思开场
- "代际反差/幽默怎么写成喜剧？"
- "expectation gap / 期待现实落差 / 慢懂 / 喜剧主冲突 / 套路落空"

### 与相邻 skill 的区分

- 与 `kom-not-knowing` 的区别：不知道是"制造落差的原料（角色认知状态）"，本 skill 是"落差的成品结构（期待vs现实）"。先让角色不知道，再用本 skill 搭落差骨架——最容易混，记住：not-knowing 是原因，expectation-gap 是结果形态。
- 与 `kom-non-hero` 的区别：非英雄讲"角色缺技能"的状态，本 skill 讲"期待与现实错位"的机制；缺技能常导致落差，但落差也可能来自世界观/信息差而非技能。
- 与 `kom-comedy-equation` 的区别：方程是总诊断四要素，本 skill 是其中"喜剧发生的具体位置"引擎。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **设套路期待 X**
   - 完成标准: 写出角色（如）这集"以为会怎样"的预设（基于其世界观/老经验），要具体可感。

2. **设计意外现实 Y 并维持落差**
   - 完成标准: 给出与 X 错位且真实的 Y，并确认角色"不知道"而慢懂（非瞬间看穿），落差持续整段戏。
   - 判停条件: 若角色瞬间理解（ce12 知道太多），回 step1 加长不知时段。

3. **核对冲突来自落差而非敌手**
   - 完成标准: 确认本集主冲突是角色内在期待现实错位，而非外部反派推动；引用 ce11 避免人为拖延揭示。

## B — 边界 (Boundary) ★

### 🔴 硬约束（世界层·违背就崩）

- 不能违背基本的期待与现实落差逻辑，否则观众/读者会立刻出戏
### 🟡 软约束（规则层·违背有代价）

- 戏的主冲突确实是外部敌手对抗（那不是卡普兰式喜剧冲突，本引擎不适用）。
- 用户要的是"角色为什么不可笑"的总诊断——先去 `kom-comedy-equation` 查四要素。
- 用户要的是"让角色缺技能/显得笨"——那是 `kom-non-hero` / `kom-not-knowing`。
### 🟢 自设约束（认知层·其实可以重定义）

- 以为期待与现实落差只有一种正确用法——假墙，方法是工具，不是教条
- 以为期待与现实落差能解决所有问题——假墙，每个方法都有适用场景
