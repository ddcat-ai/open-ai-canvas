## I — 方法论骨架 (Interpretation)

- 喜剧角色可映射到三千年意大利即兴喜剧原型谱系（老人/仆人/泼辣妻/伤心小丑/青春恋人），这些是"关系引擎"而非刻板标签。
- 固定角色 + 变换情境 = 情景喜剧引擎；"角色创造剧情"——人物位阶战争自发长出故事。
- 喜剧是"封闭宇宙"：所有角色须彼此相连，不塞无关路人；阵容定好人设即获得关系动力。
- 应用：把→潘塔龙纳+玛莉聂塔混合、子女→青春恋人、邻居→布里盖拉，立刻有喜剧性底座。
- 原型可混合（如老人+泼辣妻），不是荣格神话原型，而是基于位阶关系的喜剧角色谱系。

## A1 — 书中的应用 (Past Application)

### 案例 1: 希腊喜剧致辞打破第四面墙（c44）
- **问题**: 喜剧角色向观众求救的传统从何而来。
- **方法论的使用**: 希腊喜剧歌队中途走向前直接对观众说话，比《安妮．霍尔》早三千年打破第四面墙。
- **结论**: 打破第四面墙是喜剧正字标记，源于原型角色的行为许可传统。
- **结果**: 确立"喜剧允许角色向观众求救"的许可。

### 案例 2: 中古演员日记亚伯拉罕以撒（c45）
- **问题**: 没有剧作家时喜剧从何而来。
- **方法论的使用**: 演员忘道具刀改用胡子戳以撒，成"第一次文字记载的即兴"，镇民砸物成"第一次剧评"。
- **结论**: 无剧作家时代演员靠原型角色即兴，即"角色创造剧情"。
- **结果**: 说明即兴喜剧与角色创造剧情的传统起源。

### 案例 3: 卓别林承哈勒坤（c47）
- **问题**: 现代肢体喜剧角色谱系从哪来。
- **方法论的使用**: 卓别林经卡尔诺哑剧剧团承袭哈勒坤（Arlecchino）原型。
- **结论**: 现代喜剧角色可溯源至三千年原型谱系。
- **结果**: 提供"把熟悉原型当样板让角色耳目一新"的依据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

### 语言信号（用户的话里出现这些就应激活）

- "人物底座 / 角色原型怎么定"
- "这角色像哪种经典喜剧人 / 固定人设"
- "封闭宇宙 / 角色都得连起来"
- "常驻阵容关系引擎"

### 与相邻 skill 的区分

- 与 `kom-non-hero` 的区别（易混诱饵）: non-hero 管"降技能 / 缺技能让角色喜剧"（个体属性）；archetype 管"把角色归入原型谱系 / 关系位阶"（阵容结构）。问"角色够不够非英雄"用 non-hero，问"整组人物关系怎么搭、谁是老人谁是仆人"用 archetype。
- 与 `kom-sitcom-family` 的区别: sitcom-family 管"失能家庭容器 / A-B 故事结构"；archetype 管"角色在谱系中的位阶与关系引擎"。家庭是容器，原型是内容物。
- 与 `kom-straight-wavy-line` 的区别: straight-wavy-line 管单场重心流动；archetype 管长期固定人物底座。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **列出常驻角色并映射原型**
   - 完成标准: 每个常驻角色有原型锚点（老人/仆人/泼辣妻/青春恋人等），允许混合。

2. **检查"封闭宇宙"**
   - 完成标准: 列出关系网，确认所有角色彼此相连，剔除游离路人角色。

3. **用原型位阶战争生成本集情境冲突**
   - 完成标准: 本集冲突来自原型关系（如老人 vs 青春恋人），而非外部突发事件。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 角色需大幅成长弧光 / 心理写实正剧（原型偏"固定"，不适合强变化弧）。
- 一次性独立短片角色，不需常驻阵容与封闭宇宙。

### 作者在书中警告的失败模式

- ce17（单一功能 / 刻板样板角色）：把角色写成"紧张佬/纯蠢"静态标签——原型≠静态脸谱，须是可变世界观。
- ce10（角色前后不一为笑料切换人格）：人格跳切让观众无法锚定"这是谁"。

### 作者的盲点 / 时代局限

- "角色创造剧情"假定固定人设 + 每周新情境的情境喜剧模式，对强情节连续剧的适配需自行调整。

### 容易混淆的邻近方法论

- 与 `kom-non-hero`（个体缺技能）最易混——前者问"整组人物底座"，本 skill 问"降技能个体"。
