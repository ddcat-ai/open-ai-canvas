## I — 方法论骨架 (Interpretation)

喜剧的重写不是"把台词改得更搞笑"，而是一条**不可逾越的红线**：

- 写作即重写；喜剧额外把"观众"视为共同编剧——戏要到观众面前才算真正存在，反馈是重写依据。
- **铁律：永远保护观众对角色的信念与同理心。** 笑话永远可以再加，但角色信念一旦牺牲，两头空（既不真也不好笑）。
- 操作上靠试片、读本、观众反应迭代修剪：哪里冷场、哪里观众抽离，就修哪里；但修的是"让角色更可信地挣扎"，不是"硬塞更响的梗"。
- 具体禁令：**不能为了更快发笑让角色突然降智、突降人格、做其不会做的事**。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《阿呆与阿瓜》雪球大战荷莉流血试片
- **问题**: 荷莉被冰击倒重現时嘴唇带血迹，试片观众瞬间冷感、二十分钟不见人影。
- **方法论的使用**: 法拉利兄弟重拍去掉血迹——不是因为血迹不好笑，而是它伤了观众对角色的同理（不想见角色受伤），护住信念笑声才接得下去。
- **结论**: 重写的目标是让观众愿意留下来，笑声才能接续。
- **结果**: 重拍后血迹无影无踪，观影体验修复。

### 案例 2: 《恋爱书成班》昏倒拖拽（反例）
- **问题**: 男主假装晕眩、女主突然变"古灵精怪"把人拖进屋。
- **方法论的使用**: 作者点名——角色行为不一、为搞笑而搞笑，哪怕只一分四十八秒，观众也失去对角色的信念。
- **结论**: 为笑话牺牲角色即触发"两头空"。
- **结果**: 成为重写铁律的反面教材。

### 案例 3: 马克斯兄弟《歌台三怪》试片校正
- **问题**: 创作者如何确保喜剧有效。
- **方法论的使用**: 马克斯兄弟先巡演、用现场观众校正喜剧再拍摄；法拉利兄弟致敬其包厢戏。
- **结论**: 尽本分了解喜剧史 + 用观众反馈迭代，是重写的正道。
- **结果**: 论证"观众共同编剧"的工作流。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

2. 有人提议"这里加个更响的梗，让显得更蠢"——需要拦下并给替代方案。
3. 进入二稿/三稿，需要建立"角色信念红线 + 观众反馈循环"的重写流程。

### 语言信号 (用户的话里出现这些就应激活)

- "这集试看观众觉得突兀/出戏了，怎么改？"
- "我想加个更搞笑的桥段，让长辈再降智一点"
- "重写怎么改？是改台词更搞笑吗？"
- "试片/读本反馈说这里冷场"

### 与相邻 skill 的区分

- 与 `kom-joke-four-requirements` 的区别: `kom-joke-four-requirements` 是静态的台词质检清单（四要件）；本 skill 是**带着红线去改**的动态流程，且红线（护角色信念）高于四要件。四要件可在本 skill 执行中调用。
- 与 `kom-silver-anti-trope` 的区别: 适配管"怎么设计笑点"；本 skill 管"改稿时角色信念不能被牺牲"，是设计的守护层。

## E — 可执行步骤 (Execution)

1. **立角色信念红线**
   - 完成标准: 明确写出"本集不可为笑话牺牲的角色信念清单"（如的体面感、子女的真心），任何修改不得越过。

2. **收集观众/试看反馈并定位断点**
   - 完成标准: 列出冷场/出戏的具体位置与原因，区分"角色假"与"节奏慢"两类。

3. **依红线修剪，保护信念优先**
   - 完成标准: 每处修改后自检——角色是否仍可信、是否仍被同理；凡"更响但伤角色"的改法一律回退，改用"让角色更诚实地挣扎"替代。
   - 判停条件: 若发现断裂源于初稿前提/人设未立，则跳回 `kom-comic-premise` / `kom-sitcom-family`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 初稿连角色与前提都还没立，谈不上"保护信念"——先 `kom-comic-premise` / `kom-sitcom-family`。
- 只是单句台词质检（非修改流程层）——`kom-joke-four-requirements` 即可。

### 作者在书中警告的失败模式

- **ce31（为笑话牺牲角色）**: 重写/punch-up 为多一个笑伤角色可信度，落得两头空。
- **ce30（作者优越感）**: 编剧居高临下操纵角色、用夸张代替真实人性，观众一眼看穿。
- **ce09（为搞笑强迫角色违信）**: 塞给角色"某件好笑的事"而其根本不会那样做，信念崩塌。
- **ce07（为搞笑而搞笑）**: 全书最大错误，重写时尤易复发。
