## I — 方法论骨架 (Interpretation)

1. THREES 是"造笑的必需成分清单"，不是随意清单：六者共同存在，幽默才立得住。
2. **任一缺失都会让整则笑话失效**（DOA, dead on arrival）——诊断笑话"为什么不好笑"本质是找缺了哪一格。
3. 六要素分工：Target 决定"打谁"；Hostility 提供燃料（冲突/批评伪装成娱乐）；Realism 给落点；Exaggeration 拉张力；Emotion 让观众共情；Surprise 给最后一击。
4. **顺序非铁律**：作者自承六要素的"结构顺序"可被挑战，但"六者皆须在场"是硬约束。

## A1 — 书中的应用 (Past Application)

### 案例：作者用"塌陷的舒芙蕾"隐喻诊断
- 作者示范：一则有 Target+Hostility 但缺 Surprise 的段子，观众只觉得刻薄；一则有 Surprise 但缺 Realism 的段子，观众觉得荒诞不接地气。
- 结论：修改时不是"重写"，而是补齐缺失的那一格——定位缺环比推倒重来高效得多。

## A2 — 触发场景 (Future Trigger) ★

### 用户在什么情境下需要这个 skill?
1. 用户说"我写的段子没人笑/不对劲，帮我看看"。
2. 用户动笔前想先核查"配方齐不齐"。
3. 用户问"幽默到底由哪些成分构成"。

### 语言信号
- "为什么不好笑" / "段子诊断" / "幽默配方" / "缺了什么" / "threes" / "造笑成分"

### 与相邻 skill 的区分
- 与 `cws-mapp-targeting` 区别：本卡管"一则笑话内部六成分齐不齐"，MAPP 卡管"写之前对谁讲/为什么讲"的外部定位。
- 与 `kom-comic-structure` 区别：本卡是"一句话/一段子"原子级，kom 是"一场戏/一集"结构级。

## E — 可执行步骤 (Execution)

1. **列六格**：把目标段子按 Target/Hostility/Realism/Exaggeration/Emotion/Surprise 各写一句。
2. **找缺环**：哪一格空白或最弱 → 它就是不好笑的根因。
3. **单点补强**：只补那格（如加一个 Surprise 反转），不推倒重来。
4. **复核平衡**：六格都在后，检查有无某一格过强压垮其余（如 Hostility 过猛变刻薄）。

---

## B — 边界 (Boundary) ★

- **不是结构卡**：一集/一场戏的整体喜剧结构请去 `kom-comic-structure`，本卡只管单则笑话成分。
- **顺序可争议**：六要素"都在场"是硬约束，"按什么顺序排"不是，别当神圣步骤。
- **Tier B 版权边界**：配方为作者原创编排，整理只抽"六成分诊断框架"；不整段复述书中笑话样例。引文 ≤150 字/段。
