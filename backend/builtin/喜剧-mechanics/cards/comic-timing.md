## I — 方法论骨架 (Interpretation)

Dean 颠覆了"timing 是可练的固定节奏"的常识：timing **不是参数，是当下互馈**。
- **互馈环**：演员影响观众，观众也影响演员，谁也不"负责"节奏——像非洲舞者与鼓手，有时你是 dancer 有时是 drummer，在"影响与被影响"中即时生成节奏。
- 结论：**与观众共舞**，而不是复刻排练时的节奏。你根据"观众此刻如何反应你"来创造 timing。
- **笑时闭嘴（Secret 14）**：观众笑时继续说话，会训练他们停笑（像跳蚤撞蜡纸）；应冻结/保持状态/让笑声影响你，而非抢话。停顿不是"等"，是"让笑声发生"。

所以"练 timing"练的不是死节奏，而是**对观众反应的敏感与信任**——把排练的节奏当参考，临场让互馈环接管。

## A1 — 书中的应用 (Past Application)

### 案例 1：舞者/鼓手顿悟
- **问题**：作者如何定义 timing？
- **方法论的使用**：他在演出中意识到"没人负责"——大家互为 leader/follower，在影响与被影响中生成节奏；由此得出"演员不'有'timing，而是依观众反应即时创造"。
- **结论**：timing 是关系，不是技巧参数。
- **结果**：成为 Ch10 对 timing 的重新定义。

### 案例 2：笑时抢话训练观众停笑
- **问题**：为何有些 comic 一抖包袱观众就收声？
- **方法论的使用**：作者观察，演员在观众笑时继续说，等于训练观众"笑会被打断→别笑了"；Secret 14 要求此时闭嘴。
- **结论**：抢话稀释笑声。
- **结果**：成为 Ch10 表演纪律第一条。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？
1. 抖完包袱不知道该停多久、何时接下一句。
2. 观众笑时总忍不住补一句，结果笑声断了。
3. 想理解"好 timing"到底是什么。

### 语言信号
- "timing 怎么练 / 停顿怎么把握"
- "观众笑时我该不该说话"
- "dancer drummer 那段什么意思"
- "为什么我一说话观众就不笑了"

### 与相邻 skill 的区分
- 与 `act-outs-pov`：POV 管"演什么视角"；timing 管"何时停顿留白"。
- 与 `fearless-bombing`：timing 是表演中的节奏；fearless 是面对怯场/砸场的心理应对。

## E — 可执行步骤 (Execution)

1. **把排练节奏当'参考'而非'脚本'**
   - 完成标准：上台允许偏离排练的停顿。
2. **抖包袱后，先让笑声发生**
   - 完成标准：观众笑时不加词、不走动抢注意；若忍不住→默数到笑势回落。
3. **感知观众反应，即时调整**
   - 完成标准：根据现场能量加快/放慢；把自己当 loop 的一环而非独奏。
4. **（若笑声被自己打断）复盘 Secret 14**
   - 完成标准：确认是"抢话"所致→下次闭嘴让笑完成。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 还在写 joke、没有成稿 → 用 `joke-prospector-mine`。
- 段子间衔接问题 → 用 `routine-builder`。

### 作者在书中警告的失败模式
- **笑时抢话** → 训练观众停笑（见 Secret 14）。
- **死守排练节奏** → 忽视互馈环，失去现场感。

### 作者的盲点 / 时代局限
- 互馈环假设"有现场观众"；录播/短视频无即时观众反馈，timing 策略需另设（如靠剪辑节奏替代）。

### 容易混淆的邻近方法论
- "卡点/踩节奏"是音乐术语；Dean 的 timing 是"演员—观众互馈的即时创造"，不可提前编排。
