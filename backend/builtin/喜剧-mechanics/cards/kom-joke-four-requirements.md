## I — 方法论骨架 (Interpretation)

在**叙事喜剧**（非脱口秀）里，一句笑话不是"能逗笑就行"，它必须同时过四关：

1. **推进行为**：笑话不能让叙事停摆。角色说这句是为了继续做事，不是为了"表演好笑"。打断行为前进动力的笑话会摧毁观众对现实与编剧才华的信念。
2. **定义角色**：笑话必须"是这个人会说的"。脱口秀者都懂把不适合自己的笑话让给同行——叙事角色亦然，违背人设的笑话松动角色信念。
3. **传达独特世界观**：二流谐星拿"谁都想过"的泛泛吐槽当笑话；好笑话带角色专属滤镜（赛恩菲尔德把洗衣机看作物件夜店）。没有独特视角，谁都能讲，就不喜剧。
4. **言简意赅**：考夫曼会数笑话音节数——能拿掉一个音节还达意，观众反应更大。留白让观众自己填空，笑话才在观众脑中引爆。

## A1 — 书中的应用 (Past Application)

### 案例 1: 马克斯兄弟《大商店》格鲁乔"看她几岁"
- **问题**: 如何用一句话示范四要件同时成立。
- **方法论的使用**: 面试店侦探时经理问"女的昏倒你怎么办"，格鲁乔答"看她几岁"——推进行为（继续面试）、定义角色（好色流氓）、独特世界观（别人看医疗他看机会）、言简意赅（四字）。
- **结论**: 四要件齐全的笑话拿掉音节反而更好，笑点在观众神经路径里完成。
- **结果**: 成为全书"叙事笑话四要件"的标准正例。

### 案例 2: 八〇年代情境喜剧"死人部长"反例
- **问题**: 作者想说明不合格的笑话长什么样。
- **方法论的使用**: 秘书说"你像个死人"，部长回"我昨天死了对吧"——既不好笑又让行为静止；若只回"谢了"让叙事继续还好些。
- **结论**: 为抖包袱让角色愣住、回软话，摧毁现实与编剧信念。
- **结果**: 反面印证"推进行为"是第一要件。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写完整场/整集后做"台词笑话审查"，逐句判断去留。
2. 有人提出一个看似好笑但"谁来说都行"的梗，需判断是否符合人设。
3. 担心某笑点太长、太满、观众没空间反应——需要压缩到言简意赅。

### 语言信号 (用户的话里出现这些就应激活)

- "这句台词好不好笑？该不该留？"
- "这个梗是不是有点打断剧情了？"
- "这笑话感觉谁都能说，不像会讲的"
- "怎么把这句写短一点还能更响"

### 与相邻 skill 的区分

- 与 `kom-perspective-lens` 的区别: `kom-perspective-lens` 管"角色怎么看世界"（世界观/隐喻关系/框架）的**整体设计**；本 skill 是把已经设计好的世界观拿去**逐句审查笑话**是否带出该世界观。世界观是原料，四要件是质检线。
- 与 `kom-rewriting` 的区别: 重写管"为笑话牺牲角色"的红线与流程；本 skill 是重写时具体执行的审查清单（四要件即护角色信念的细则）。

## E — 可执行步骤 (Execution)

1. **逐句过四要件**
   - 完成标准: 对每句候选喜剧台词标注——是否推进行为 / 是否定义角色 / 是否带独特世界观 / 是否够短；任一为"否"则标记。

2. **优先剔除打断叙事者**
   - 完成标准: 凡"让行为静止、只为抖包袱"的台词直接删或改写为推进动作的话。

3. **压缩音节、保留留白**
   - 完成标准: 在不丢概念前提下能删则删，让观众自行填空；最终每句笑话音节数最小化。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 角色本身就是专业笑话写手（如单口喜剧主角），此时四要件可放宽。
- 需要设计的是整场戏的喜剧机制（落差、非英雄），而非单句——交给 `kom-expectation-gap` / `kom-non-hero`。

### 作者在书中警告的失败模式

- **ce24（笑话打断叙事）**: 塞无关笑话让行为静止，是最直接的四要件违反。
- **ce25（笑话不符人设）**: 把作者觉得好笑的梗硬塞给不符合人设的角色，松动角色信念。
- **ce26（缺乏独特世界观）**: 用"谁都想过"的泛泛吐槽当笑话，缺角色专属滤镜。
- **ce29（缺乏细节的低俗喜剧）**: 退化为"白痴/智障"式概括嘲讽，无具体可感细节。

### 作者的盲点 / 时代局限

- 四要件默认"叙事喜剧"语境，对纯肢体/视觉笑点、特有的"慢半拍反应"笑点的适配需结合 `kom-silver-anti-trope` 与 `kom-active-emotion` 灵活处理。

### 容易混淆的邻近方法论

- `kom-perspective-lens`（易混：世界观既是四要件之一，又是该 skill 的主体）。
- `kom-rewriting`（四要件是重写护角色红线的执行工具）。
