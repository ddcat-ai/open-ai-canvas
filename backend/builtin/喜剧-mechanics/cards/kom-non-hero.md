## I — 方法论骨架 (Interpretation)

- 非英雄（non-hero）指缺乏获胜所需技能或工具的平凡男女，不是白痴、不是夸张傻子，而是天性如此、有所不足却一心求胜的人。
- 喜剧的引擎法则：**技能越多越英雄、越不喜剧；技能越少越脆弱、越喜剧**。给角色加技能（料事如神、应对完美）= 滑向戏剧。
- 麻烦必须由角色自己"作"出来（自毁式根源）；若灾难来自外部，角色就成了受害者——受害者是英雄的反面，远离非英雄。
- 核心动作是"降技能"：主动撤掉角色的某些能力，让她在困境里真诚挣扎，而非开挂通关。

## A1 — 书中的应用 (Past Application)

### 案例 1: 伍迪·艾伦对决十二枪手（c15）
- **问题**: 作者要证明"平凡人+难如登天的困境"本身就有喜剧性，无需对白。
- **方法论的使用**: 把英雄（查理士·布朗逊，编剧给足技能）换成非英雄（伍迪，缺一切技能却不放弃），仅设定即生笑。
- **结论**: 辨认的角色 + 困境 = 喜剧；技能是喜剧的稀释剂。
- **结果**: 成为"非英雄的力量"的立论基石，全书反复引用。

### 案例 2: 《终极警探》顶楼躲桌底（c17）
- **问题**: 动作英雄通常坚毅复仇，如何给硬汉片加喜剧？
- **方法论的使用**: 让麦克连目睹谋杀后"愣住、被震慑、不敢相信"，暂时撤掉英雄的应对技能。
- **结论**: 愿意失败/示弱是喜剧最重要的工具之一。
- **结果**: 论证"动作片也能靠暂时性去除英雄技能增添喜剧成分"。

### 案例 3: 《欢乐单身派对》乔治吞苍蝇（c16）
- **问题**: 麦基认为喜剧干扰叙事，乔治的蠢事算不算离题？
- **方法论的使用**: 乔治连讲话都吞苍蝇、不知所措——非英雄随叙事自然发生的真实蠢事即叙事本身。
- **结论**: 喜剧是角色试图得到想要事物时发生的事，非英雄让角色有喜剧性。
- **结果**: 反驳"喜剧干扰叙事"，确立非英雄的叙事合法性。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

2. 用户让长辈"开挂"化解危机（突然懂了、被人救了），戏变得不喜剧——需改为自己制造两难、自毁式翻车。
3. 用户担心老年角色"写出来像受害者/被时代抛弃很惨"——需把苦难转化为角色自身缺陷导致的滑稽挣扎，留住喜剧。

### 语言信号 (用户的话里出现这些就应激活)

- "主角太厉害了，感觉不喜剧 / 不好笑"
- "老人家怎么写得又蠢又可爱、不卖惨"
- "降技能"、"让他别那么全能"、"非英雄"
- "这集怎么又开挂了" / "non-hero, reduce skills"

### 与相邻 skill 的区分

- 与 `kom-winning` 的区别: 非英雄是角色的**状态**（缺技能），获胜是给角色的**许可与动力**（允许为赢不择手段）。先有非英雄的缺技能，获胜才有挣扎空间；二者常同用但维度不同。
- 与 `kom-not-knowing` 的区别: 不知道是"制造落差"的**具体手法之一**（撤掉'知情'这项技能）；非英雄是更宽泛的"整体技能缺口"总称。所有不知道都是降技能，但并非所有降技能都靠不知道（如腿慢、耳背是体能缺口）。
- 与 `kom-silver-anti-trope` 的区别: 反套路是本 skill 的**项目化综合迁移**（把非英雄+不知道+落差套到老年角色），非英雄是其中的底层工具之一。

## E — 可执行步骤 (Execution)

1. **盘点角色当前技能，标出"英雄化"项**
   - 完成标准: 列出主角拥有的技能清单，圈出"料事如神/应对完美/轻易化解"等会稀释喜剧的项（如瞬间看懂直播规则、被子女轻松说服）。

2. **主动降技能，制造自毁式缺口**
   - 完成标准: 撤掉 1–3 项能力（尤其新科技、新规则、体力），让困境真正难住她；确保灾难由她自身缺陷引发，而非外部甩锅（避免 ce35 受害者陷阱）。

3. **核对喜剧方程式四要素齐备**
   - 完成标准: 平凡人 + 难如登天的困境 + 缺技能 + 不放弃希望 四项都在；若希望消失（沦为纯惨），回退补希望。

## B — 边界 (Boundary) ★

### 🔴 硬约束（世界层·违背就崩）

- 不能违背基本的非英雄逻辑，否则观众/读者会立刻出戏
### 🟡 软约束（规则层·违背有代价）

- 纯正剧/悲剧角色塑造（如需要成长弧光、英雄逆袭的剧情），非英雄会削弱戏剧张力。
- 硬核动作/爽文场景，角色本就该全能通关。
- 用户只想写"惨"——非英雄是为喜剧服务的，缺希望即转戏剧（参见 ce28）。
### 🟢 自设约束（认知层·其实可以重定义）

- 以为非英雄只有一种正确用法——假墙，方法是工具，不是教条
- 以为非英雄能解决所有问题——假墙，每个方法都有适用场景
