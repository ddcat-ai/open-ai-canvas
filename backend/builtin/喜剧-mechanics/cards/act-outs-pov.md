## I — 方法论骨架 (Interpretation)

Act Out 是把笑话从"讲述"变成"正在发生"的实景演出。Dean 首创地把它拆成三个观点位（POV）：
- **Narrator POV（叙述位）**：你只是讲/转述这件事，不卷入。"昨天我跟 Bob 说…"
- **Self POV（自我位）**：你"成为"当时的自己，事件正在发生。"我坐在停车标志前，那家伙追尾了我。"
- **Character POV（角色位）**：你演任何他人/动物/物体/甚至"情绪"。"（角色）你受伤了吗？"

关键在于：**每切换一次 POV，就天然构成一次 joke structure 的起承**。观众想和喜剧演员"待在一起"，你越卷入，他们越投入。三种 POV 可自由混用。

## A1 — 书中的应用 (Past Application)

### 案例 1：rear-ended 邮件笑话三版本
- **问题**：同一笑话如何展示三种 POV？
- **方法论的使用**：先纯 Narrator 转述；再加 Self POV 把"我被追尾"演成正在发生；再加 Character POV 演朋友问"你受伤了吗"。
- **结论**：同一素材，POV 越往 Self/Character 沉，现场感越强。
- **结果**：成为全书 Act Outs 的标准教学案例。

### 案例 2：排练中切换 POV
- **问题**：如何把 POV 落到排练？
- **方法论的使用**：在 Performer Space 中练习"从 Narrator 走到 Self 位、再切到 Character 位"的物理走位。
- **结论**：POV 转换可 staged（走位编排），成为可复用的表演工具。
- **结果**：接 `rehearsal-process` 的感官编码。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？
1. 段子写出来不错，但台上像念稿，观众冷。
2. 想把"讲一件事"升级成"演一件事"。
3. 分不清自己该不该"入戏"、该演谁。

### 语言信号
- "我讲段子像背稿 / 观众不投入"
- "怎么把这段演出来"
- "act out / POV / narrator self character 怎么用"
- "scene work 是什么"

### 与相邻 skill 的区分
- 与 `rehearsal-process`：本 skill 是"演出时怎么用 POV"；rehearsal 是"排练时怎么用感官编码记住它"。先有 POV 设计，再排练。
- 与 `comic-timing`：POV 解决"演什么视角"，timing 解决"何时停顿留白"。

## E — 可执行步骤 (Execution)

1. **标出素材里的"讲述"部分**
   - 完成标准：找出纯 Narrator 转述的句子。
2. **把关键动作改成 Self POV**
   - 完成标准：用"我正在经历"的现在时重述；身体进入事件。
3. **识别可"演"的角色，加 Character POV**
   - 完成标准：至少 1 个对方/物体被你演出来（换声线/姿态）。
4. **编排 POV 切换走位**
   - 完成标准：每次切换有物理位置/姿态变化；确认"每次切换都制造一次结构起伏"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 只写文字稿不打算演 → 用 `joke-prospector-mine`。
- 麦克风握法/距离等技术 → 用 `comic-timing` 或查阅设备章。

### 作者在书中警告的失败模式
- 滥用道具：Dean 不反对道具，但提醒"拖着一堆道具赶场很烦"，非必要别用。

### 作者的盲点 / 时代局限
- POV 理论基于单人站立喜剧；多人/Sketch/影视表演需另补。

### 容易混淆的邻近方法论
- "演"不等于"夸张模仿"；Character POV 演的是"信息角色"，服务于 joke structure，不是单纯秀声线。
