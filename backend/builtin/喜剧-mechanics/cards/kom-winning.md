## I — 方法论骨架 (Interpretation)

停止问"怎样好笑"，改问"**角色想要什么？**"然后允许角色为赢做一切——包括显得愚蠢、自私、甚至像坏人，唯一限制是角色本性。

附"别再'该'了"（g29）：去掉社会/职业"应该"的束缚（律师该镇定、长辈该得体），角色才能有机活过来。无需硬造冲突，**人本身即冲突**——每个角色各自求胜的自然碰撞就是喜剧。编剧退场，让角色诚实求胜，笑点自生，不必写俏皮话。

## A1 — 书中的应用 (Past Application)

### 案例 1: 三个律师的经典问题（c01）
- **问题**: 怎样让毫无表演经验的人自发产生喜剧？
- **方法论的使用**: 作者给三位"律师"既定情境（迟到五分钟、法院四条街外），多数演员却陷入"该"（讨论、捏造）忘记解决问题。
- **结论**: 一旦允许角色为赢不择手段（甚至把人扔出门），不需导演/编剧也自发产生喜剧（lazzi）。
- **结果**: 证明"喜剧允许角色获胜"胜过"试图好笑"。

### 案例 2: 《安妮．霍尔》拉麦克鲁汉（c10）
- **问题**: 伍迪怎么在排队吵架里取胜？
- **方法论的使用**: 艾尔维把虚构的麦克鲁汉从海报后拉出当面驳斥，并打破第四面墙对观众说话。
- **结论**: 角色获胜不需真赢，只需"试着要赢"；打破第四面墙是喜剧行为许可象征。
- **结果**: 经典示范"角色为赢不择手段"。

### 案例 3: 《王牌大骗子》厕所自殴（c11）
- **问题**: 金·凯瑞最大笑点在哪？
- **方法论的使用**: 弗莱契因诅咒只能说真话，无路可走躲进厕所自殴拖延；作者指出笑点在"落败与永不放弃希望之间的紧绷"，非肢体胡闹。
- **结论**: 肢体喜剧是内在喜剧真实的外在表现，角色单纯想赢而非想好笑。
- **结果**: 论证"获胜"驱动一切。

### 案例 4: 史都华·斯莫利"别再该了"（c12）
- **问题**: 角色为何总被"应该"捆死？
- **方法论的使用**: SNL 角色史都华打断自己"我又在该了"，原谅自己"我够好了"。
- **结论**: 获胜让角色免于做"该做的事"的义务。
- **结果**: 确立"获胜≠该"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 的荒唐目标（直播翻红、赢回面子）显得不可信，需要"给她真诚渴求+允许不择手段"让它成立。
2. 角色行为"太得体/太合理"，喜剧动能弱，需要去掉"应该"让人物活起来。
3. 编剧卡在"怎样写才搞笑"，需要转念为"角色此刻到底想赢什么"。

### 语言信号 (用户的话里出现这些就应激活)

- "这个荒唐目标怎么让人信？"
- "角色太正经/太合理了，不好笑"
- "我该怎么写才搞笑？"（应纠正：先问角色想要什么）
- "winning / 获胜 / 角色想要什么 / 别再该了 / 允许角色不择手段"

### 与相邻 skill 的区分

- 与 `kom-non-hero` 的区别：最易混。non-hero 是"角色缺技能/工具"的**状态**（他是谁），winning 是"角色为赢不择手段"的**动机行为**（他做什么）。一个缺技能的人仍可不求胜（变受害者），一个求胜的人也可能有技能（变英雄）——二者正交。先定人物是否非英雄，再用本 skill 驱动其行为。
- 与 `kom-positive-action` 的区别：正向行为讲"每个举动出于自私希望画出角色画像"，winning 更前置——先找到"超级目标/你想要什么"，正向行为是其表现层。
- 与 `kom-expectation-gap` 的区别：获胜是角色动机，落差是戏的机制；角色求胜常制造期待现实错位，但本 skill 聚焦"想要什么"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **问角色"你想要什么"（找超级目标）**
   - 完成标准: 写出这集最真诚渴求的一件事（如"不被送养老院"），要具体、自私、可悯。

2. **移除"应该"，允许不择手段**
   - 完成标准: 检查角色行为是否受"长辈该得体/该明智"束缚，去掉后让其用自认合理的方式求胜（含显蠢/自私）。
   - 判停条件: 若行为违背角色本性（ce09）则回 step1 重找符合本性的赢法。

3. **让笑点从求胜自然长出，不写俏皮话**
   - 完成标准: 确认没有为搞笑硬塞台词（ce07），笑料来自"试图要赢却缺技能"的真实挣扎。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户在设计"角色缺什么技能"的人物状态——那是 `kom-non-hero`。
- 戏的主冲突是外部敌手对抗，而非角色各自求胜的碰撞。
- 只想加一句俏皮话——那是 `kom-joke-four-requirements`。

### 作者在书中警告的失败模式

- ce07（为搞笑而搞笑，最大错误）：把"显得好笑"设成目的；本 skill 主张让角色诚实求胜，好笑自然来。
- ce08（让角色做"该"的事）：按社会/职业模板行动，失去荒诞挣扎动能。
- ce09（为搞笑强迫角色违信）：角色做其不会做的事，观众撤信任意止。
- ce23（出于恶意而讨人厌）：纯恶意无目的不好笑；本 skill 的"不择手段"须服务于获胜而非纯粹刻薄。
- ce30（编剧自认比角色优越）：居高临下操纵角色代替真实人性。
- ce14（技能过多→英雄化）：求胜若配上过多技能就变英雄，需配合 non-hero 降技能。

### 作者的盲点 / 时代局限

- 作者假定"允许角色不择手段"在西方个人主义语境天然成立；东亚"长辈体面/家庭和睦"约束更强，反套路要更巧妙地把"想要什么"包装成合情（如"为孙辈好"），否则易显刻意。

### 容易混淆的邻近方法论

- `kom-non-hero`：最常混——获胜（行为动机）与非英雄（技能状态）被当成同一工具；记住正交关系。
- `kom-positive-action`：winning 找目标，positive-action 画画像，层级不同。
