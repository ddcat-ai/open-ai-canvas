# 喜剧创作

先判断内容属于哪一类，只读取对应索引中的 1 至 2 张卡，不要整包通读。

| 场景 | 先读 |
|---|---|
| 通用段子、笑点诊断、前提、反转、三叠、表演与职业边界 | `cards/comedy-general-index.md` |
| 情景喜剧、家庭或职场群像、暖场与整集收束 | `cards/sitcom-index.md` |
| 脱口秀、开放麦、整场排序、冷场自救 | `cards/standup-index.md` |
| 相声、捧逗、说学逗唱、三翻四抖 | `cards/xiangsheng-index.md` |
| 用户明确提到旧名或旧 ID | 对应的 `*-migration.md` 兼容卡 |

默认交付笑点结构、桥段顺序和可执行的修改建议。未指定时按三段一梗、一主笑一冷面设计；不使用贬低型笑点。每个梗要有铺垫和兑现，升级沿同一逻辑，不解释笑点。

本包负责创作与表演方法论；提示词语法和模型参数交给现有视频或提示词技能。
