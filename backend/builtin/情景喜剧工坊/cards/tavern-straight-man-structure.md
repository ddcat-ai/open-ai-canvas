## I — 方法论骨架 (Interpretation)

这个技法不产"段子"，产的是一台**能一直转的产笑机器**：把两个人的关系本身做成结构。

1. **锁定一对固定责任分工**：一方守常理（催债、讲规矩、算账、劝学），一方专门破坏常理（撒赖、越界、耍横、装大）。分工只锁"立场"，不锁具体台词。
2. **给这对分工一套互扣模板**：三连指控（你无情/你无耻/你无理取闹）、原词反弹（"你才……"）、对抽回合制、词语乒乓。模板是"话术容器"，本集换由头灌进去即可。
3. **笑点来自咬合，不来自新意**：观众已知两人各自的接法，于是把注意力放在"这回怎么绕上去"。确定性的关系 + 不确定的由头 = 每次都新鲜，却不用发明新梗。
4. **封闭舞台是加速器**：把两人塞进一个走不掉的场所（客栈、办公室、车里、直播间），冲突无法用"我走"解决，只能对话解决，于是必须互怼到底——节奏自然被逼出来。
5. **产出物是口播节奏，不是金句**：这套结构最大的收益是稳定的对白密度与语速递进（越绕越快、越快越上头），一段可以拉到十几个来回而不塌。
6. **前置成本在"养配对"**：结构寄生在人设上。两个陌生人套模板只是在念相声词；必须让同一组人反复出镜，观众记住"谁负责抛、谁负责接"之后，结构才开始免费产笑。
7. 它对应的是酒曲室"捧哏逗哏"的桥接——但把相声的两人分工，改写成情景喜剧可工程化的**可持续产出结构**（固定配对 + 封闭舞台 + 互扣模板）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 佟湘玉 × 白展堂 —— 三连指控的回合制对抽
- **问题**: 客栈日常没有大事件可讲，两个主角却要在同一场景里撑起整段戏。
- **方法论的使用**: 把一笔债的争执灌进固定模板——湘玉排比控诉（"你无情，你无耻，你无理取闹"），老白原词反弹（"你才无情，你才无耻，你才无理取闹"）、再反手认领（"那我就给你无情无耻无理取闹看看"）。分工是掌柜守账（常理方）× 跑堂赖账（破坏方）。
- **结论**: 同三个词被当乒乓球对抽，越绕越上头；关系产节奏，不靠新包袱。
- **结果**: 该三连成为客栈互怼最典型的声音样本，跨回目反复复现（同回目 line 1681/1682/1714/1723；另在 chunk_04 line 3483、3785 换回目复用），并被其他角色接龙玩梗（case c08 / term t20）。

### 案例 2: 吕秀才 × 郭芙蓉 —— "你坏你坏"的互扣甜怼
- **问题**: 一对情侣线要出笑点，又不能靠吵架伤人物关系。
- **方法论的使用**: 同一模板换情绪色号：秀才抛"你坏你坏没人比你坏"，芙蓉原句加码"你坏你坏你最坏"，秀才再用"你坏嘛，我才喜欢你啊""女不坏男不爱"收口。分工是文人绕词（抛）× 直球加码（接）。
- **结论**: 把 insult 当情话灌进互扣模板，表面对轰、内里蜜糖，怼得越密关系越亲。
- **结果**: 该组对轰在多回目原样复现（chunk_01 line 848–850、943–945，回目「算命人作法被识破 郭芙蓉洗面遭毁容」「求休书小郭盼断肠 思佳人秀才伤透心」），成为秀才芙蓉线的固定声音商标（term t15）。

### 案例 3: 佟湘玉 × 莫小贝 —— 秩序方 × 破坏方的立场对撞
- **问题**: 一老一小没有情侣张力，也没有共同利益，如何持续有戏。
- **方法论的使用**: 只锁立场不锁台词：湘玉恒守常理（"江湖上的事，一个小女娃掺和啥呀？""不知道就不要胡说"），小贝恒破常理（"我可是一派之主。""只要能让我出门，不让我上学，干啥都行。"）。每回换由头（华山论剑、逃学、赚钱），立场对撞自动生成对白。
- **结论**: 责任分工比台词模板更底层——分工在，由头随便换都有戏。
- **结果**: 该配对在多回目稳定产笑（回目「神秘客夜访七侠镇 莫掌门血战灯市街」line 1938/1915 × 2003/2001），是 f03 跨对象验证的第三组证据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 手上有两个新角色、没有现成梗，要让他们**每期都有稳定笑点**而不是每期找新段子。
2. 做双人口播 / 双人直播 / 对谈短视频，苦于"聊到一半没词了、节奏散了"，需要一套可复用的互怼骨架。
3. 写单场景短剧（客栈、办公室、出租车、宿舍），场景不变、人不能走，必须靠对白撑满时长。
4. 已有一个人设很立、另一个人设很飘，两人放一起"戏不咬"，需要重新分配责任分工。
5. 要把一段争执写成"能拉十几个来回"的长段对白，而不是三句话收场。

### 语言信号 (用户的话里出现这些就应激活)

- 「捧逗」「捧哏逗哏」「互怼」「对戏」「二人转」「一个捧一个逗」「双人搭子」「固定组合 / 固定 CP」
- 「怎么让两个角色每集都有笑点」「两个人聊天怎么不尬」「对白怎么拉长」「一个负责作一个负责收」
- "straight man and funny man" / "double act" / "comic duo" / "banter structure" / "back-and-forth bickering" / "two-hander scene" / "one plays it straight, the other pushes"

### 与相邻 skill 的区分（定稿 · 阶段 3 据真实关系回填）

> **本 skill 是唯一的"关系层"技法**：其余 7 张都在单个角色身上做文章，只有本 skill 的笑点长在两人之间。**总判据（一句话防抢调用）**：去掉第二个人，笑点还在吗？在 → 走单人技法（f02/f06/f07/f08）；必须靠"对面那位怎么接"才成立 → 本 skill。

- 与 `vocal-signature-reuse`（**depends-on，前置**）: 声口管"一个角色怎么说话被记住"（character-level 商标），本 skill 管"两个声口怎么咬合成回合"。**声口是齿形，捧逗是齿轮组——没有稳定声口，齿轮咬不上**（对应 B·x07：结构寄生在人设上）。执行顺序硬约束：若配对双方还没有各自可识别的声口，先跑 f01 给每人发一张互不重叠的商标，再回本 skill 配互扣模板；跳过这步只会得到"两个陌生人念相声词"。
- 与 `persona-contrast-builder`（**contrasts-with**）: 那个 skill 处理**单人的双层落差**——"表面名号 vs 真实里子"，笑点发生在一个角色身上，产物是人设卡；本 skill 处理**两人之间的关系结构与互怼节奏**，产物是配对分工 + 互扣模板 + 对白节奏。两者可叠加（一个反差人设放进捧逗位，反差供料、结构供节奏），但**入口只能有一个**：用户问"这个角色怎么立"→ f02；问"这两人怎么每期都有戏"→ 本 skill。
- 与 `childs-eye-misalignment`（**contrasts-with**）: f07 **单角色即生效**（一句童言平地戳破全场，不需要人接），本 skill 必须有固定二人咬合。**抢调用判据**：笑点是"一句话把场面拉平"→ f07；是"两人越绕越快、拉出十几个来回"→ 本 skill。若把童言硬塞进捧逗模板，会既拿不到戳破的锋利，也拿不到回合的节奏。
- 与 `warm-twist-payoff`（**composes-with**）: 标准搭档关系——本 skill 负责中段把情绪闹到高位（互怼密度、语速递进），f05 负责结尾把它轻轻托住。**分工铁律**：胜负不能在中段太快分出（那是本 skill 的活），暖句只放在最后一拍且只放一句（那是 f05 的活）。用户抱怨"前面笑完就划走"→ 收尾交 f05；抱怨"聊到一半没词了"→ 留在本 skill。
- 与 `catchphrase-beat-meter`（**无直接关系边**，仅需划界）: p07 是 show-level 的跨集俗谚复用（系列节奏坐标），本 skill 是**场内**的两人回合节奏（对白密度）。同一段戏里两者层级不冲突，但用户若在问"每集都像新的"→ p07；问"这场对白怎么撑满"→ 本 skill。
- 与 `performative-heroism`（**无直接关系边**）: f08 是单人"摆 pose 然后办砸"的桥段发生器（因果链在一个人身上闭合），本 skill 是两人关系的产出结构。若翻车需要"另一个人冷眼接话"才好笑，那句接话归本 skill，翻车本身仍归 f08。
- **已对接**：本 skill 即酒曲室「捧哏逗哏」bridge 卡的情景喜剧工程化版本（固定配对 + 封闭舞台 + 互扣模板 + 固化排期），阶段 3 关系已回填，无遗留待办。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **分派责任分工 —— 定"谁守常理、谁破常理"**
   - 动作：为两个角色各写一句立场（不是性格形容词，而是"他在冲突里永远站哪一边"）。例：A 守账/守规矩/守脸面；B 赖账/越界/装大。分工必须互斥且可反复触发。
   - 完成标准：能用两句话写出"A 永远要 X，B 永远要非 X"，且随便给一个由头（钱、饭、请假、上学）都能立刻生成第一句对白。
   - 判停条件：若两人立场重合、或某一方只有性格没有立场，回到本步重分派；不要带着"两个都讲道理"的配对进入步骤 2。

2. **配互扣式台词模板 —— 给回合装容器**
   - 动作：选 1–2 种互扣形式并写出骨架：三连指控（三个词排比控诉）／原词反弹（"你才……"）／加码复读（对方原句再抬一级）／词语乒乓（同一个词反复易手）。同时确认舞台封闭（两人走不掉）。
   - 完成标准：用本集由头把模板灌满，能连续跑出 ≥6 个来回且不重复语义，语速/情绪呈递进；再换一个由头，同模板仍成立。
   - 判停条件：若配对是新组合、观众没有咬合记忆，跳到步骤 3 先做固化排期，再回来加长模板（见 B · x07）。

3. **固化配对并校准复用密度**
   - 动作：排定同一组人连续出镜 3–5 期（每期只换由头、不换分工）以建立咬合记忆；同时给互扣模板设复用上限（同一模板每期出现 1–2 次，第三次起须换形式或换情境）。
   - 完成标准：产出一份「配对卡」——含 A/B 立场各一句、1–2 套互扣模板骨架、封闭舞台设定、固化排期与复用密度上限；且能指出下一期换哪个由头。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单人独白 / 单角色人设塑造（没有第二个人可接，应转人设反差构造器或声口卡）。
- 一次性小品、单条视频，且不打算复用这对配对——养咬合的前置成本收不回来，不如直接写包袱。
- 需要靠情节推进/悬念取胜的内容（本结构是"弱情节强关系"，会把剧情拖成原地对话）。
- 三人以上群戏无主次时（捧逗是二人齿轮，多人乱抛会稀释回合；先拆成若干固定二人组）。
- 需要"笑后收心"的收尾时（转温情反转落点 f05）。

### 作者在书中警告的失败模式

- **捧逗寄生在人设配对上 (x07)**：剧中最稳的笑点来自固定配对（掌柜/老白、秀才/小郭、掌柜/小贝）的咬合，一旦换组合或人设漂移，齿轮就咬不上。齿轮的齿形就是人设——只搭结构不养配对，结果是两个陌生人在念相声台词。迁移时须把"先固化至少一对可复用人设组合"当**前置条件**，短视频建议同组连续出镜 3–5 期再吃结构红利。
- **互扣模板过度复用导致笑点疲劳 (x01)**："无情无耻无理取闹"式的招牌互怼在 80 回里高频复现，早期是惊喜，后期退化为"听到即知要笑"的机械反射（剧中窦先生台词直接出现"审美疲劳"一词）。同一模板在短视频里重复超过 2–3 次即失效，每次须换触发情境或换互扣形式。
- **人设与场景高度固定导致整体倦怠 (x02)**：分工永不演化、由头模板循环（掌柜抠门/小贝逃学/小郭闯祸），观众对"下一期还是这两人这点事"倦怠。须每期给分工一点位移或新情境压力，别把分工从"冲突起点"做成"人设牢笼"。
- **纯文本整理丢失表演层 (x04)**：这套互怼的笑点约七成在表演——语速递进、崩溃表情、对手反应的节拍。纯文本只剩骨架；迁移到 AI 配音 / 纯文字载体时须另补节奏、停顿与反应镜头，否则回合再多也不响。

### 作者的盲点 / 时代局限

- 强依赖"固定人设 + 单一场景"的情景喜剧套路，长期靠重复配对有审美疲劳风险，并非所有题材（强情节剧、纪实、知识内容）都适用。
- 假设"台词可脱离表演与语境复用"——实际互怼高度依赖演员节奏与观众已建立的角色预期；纯文本整理得到的是**结构**，不是能直接上口的成品。
- 部分互怼词挂靠 2006 年前后的语境与方言语感（x05），跨代际传播时损耗明显；新内容应把互扣形式抽象为模板，挂载当下共同语境，而非照搬老词。

### 容易混淆的邻近方法论

- 与相声常识"一个捧一个逗"混淆：常识只说角色分工；本 skill 给的是可工程化的可持续产出结构（固定配对 + 封闭舞台 + 互扣模板 + 固化排期 + 复用密度），落点是"每期换由头就能产节奏"。
- 与 `persona-contrast-builder`（单人双层人设反差）混淆：见 A2 判别法——笑点是否必须依赖"对面那位怎么接"。
- 与"吵架戏 / 冲突写作"混淆：普通冲突戏求胜负与推进，本结构求**回合不断**，胜负恰恰不能太快分出。
