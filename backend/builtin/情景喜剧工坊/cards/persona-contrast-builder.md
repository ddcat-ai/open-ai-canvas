## I — 方法论骨架 (Interpretation)

这个技法不靠写段子，而靠"搭一个两层的人设"来产笑。

1. **表层（高位预期）**：先给角色贴一个光环标签——江湖名号、显赫前史、专家头衔、狠人设定。观众一旦信了，就会对"他很强 / 他很酷"产生固定预期。
2. **里子（低位真实）**：让角色在每一场日常里，用持续、温和、不刻意的方式做出违背该光环的行为——怕事、菜、软、怂。
3. **笑点 = 预期被打破**：单独一次"反差"只是 gag；当高位认知已被坐实、而里子行为反复出现，每一次违背都在消耗并刷新那个预期，观众形成条件反射式笑。
4. **关键前提**：反差必须"先立后破"。高位认知越扎实，落回低位时落差越大、越好笑。裸给一个反差人设而无前史铺垫，观众没有可打破的预期，反差不成立。
5. 它对应的是酒曲室 H 体系里的 **H1 反转（预期违背）**，但把"反转"落成了一套可工程化的人设构造步骤，而非一次性的剧情抖包袱。

## A1 — 书中的应用 (Past Application)

### 案例 1: 白展堂 —— 盗圣名号 vs 怂包跑堂
- **问题**: 需要一个底层小人物持续制造笑点，但不能靠长剧情铺垫。
- **方法论的使用**: 先立高位（江湖传说"盗圣白玉汤"的威名），再让里子反复违背（同福客栈里怕捕快、啃鸡爪、被点穴的跑堂）。名号越响，落回怂包的反差越强。
- **结论**: 反差一旦反复"自称小偷 / 不是盗圣"复用，就从一次性 gag 变成可识别的记忆点。
- **结果**: "盗圣→怂包"成为全剧最稳的 H1 反转锚，观众一听到"盗圣"就笑意拉满（case c01）。

### 案例 2: 燕小六 —— 硬汉捕快 vs 妈宝小孩
- **问题**: 同一配角要在多回目里保持喜剧张力，且不能抢主角戏。
- **方法论的使用**: 表层立"七侠镇捕快威风"（喊"打死也不怵"），里子在遇险时脱口"帮我照顾好我娘"，硬汉外壳瞬间被戳破。
- **结论**: 越是前文铺垫的"刚"，越被一句"娘"打到预期之外；反复出现形成条件反射。
- **结果**: "硬汉→妈宝"成为燕小六的喜剧锚点，观众对"要出事先喊娘"建立预期（case c14）。

### 案例 3: 郭芙蓉 —— 自认女侠 vs 总闯祸
- **问题**: 年轻女性角色需要"嘴硬"与"手菜"的稳定错位。
- **方法论的使用**: 表层立"闯荡江湖的女侠"自我认知，里子行为持续闯祸搞砸、被反噬。
- **结论**: "说最狠的话、干最怂的事"的错位，配合口头禅复用，强化人设辨识度。
- **结果**: 女侠 vs 闯祸的反差成为郭芙蓉核心喜剧特质的来源之一（verified f02 证据）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计一个全新 AI 短视频 / 漫画角色，想让它"一开口就有戏"，但不想靠长剧情铺垫。
2. 给已有 IP 或真人账号加一层"反差萌 / 反差人设"来提升记忆点与亲密度。
3. 写短剧时，主角需要一个"表面很强、实际很菜"或"表面很酷、实际很软"的可持续笑点引擎。
4. 做系列内容，想让人设每集都"稳定产笑"而非每集找新梗。
5. 文案 / 人设卡写作中，需要把"身份标签"与"真实行为"拉开落差制造戏剧张力。

### 语言信号 (用户的话里出现这些就应激活)

- 「角色反差」「人设反差」「反转设定」「表面 vs 里子」「前后反差」
- 「前世界冠军现在送外卖」「大佬人设但很怂」「嘴硬心软怎么写」
- "persona contrast" / "ironic character" / "expectation subversion" / "set up a gap between status and behavior" / "a tough guy who is actually soft"

### 与相邻 skill 的区分（定稿 · 阶段 3 据真实关系回填）

> **本 skill 是"反差族"的总入口**：`childs-eye-misalignment`（视角错位）与 `performative-heroism`（姿态落差）都是反差的具体变体，但**错位来源不同**——本 skill 换的是**身份**（表面名号 vs 真实里子，设定级、需前史铺垫、跨集持续）。凡用户的问题是"这个角色整体该怎么立才好笑"，入口在这里；一旦问题收窄到某一场戏、某一个视角或某两个人的回合，就交棒。

- 与 `tavern-straight-man-structure`（**contrasts-with**）: **单人落差 vs 关系结构**，两者是看情境选一的两条路。本 skill 的笑点长在**一个角色身上**（产物是人设卡：高位标签 + 里子行为清单 + 复用节奏）；f03 的笑点长在**两人回合里**（产物是配对卡：立场分工 + 互扣模板 + 封闭舞台）。**抢调用判据**：去掉第二个人，笑点还在吗？在 → 本 skill；必须靠"对面那位怎么接"才成立 → f03。两者可叠加（把反差人设塞进捧逗位，反差供料、结构供节奏），但入口只能有一个。
- 与 `performative-heroism`（**contrasts-with**）: **身份双层 vs 姿态落差**。本 skill 的高位是**设定级**的（名号/前史/头衔，先立后破，跨集反复消耗同一个预期）；f08 的高位是**当场租来的**（一句"我来搞定"即拉满，同一场戏内就要兑现为零）。**抢调用判据**：这个落差需要观众"先信过他很强"吗？需要 → 本 skill；只需他此刻摆个架势、立刻办砸 → f08。注意 f08 常表现为本 skill 的瞬时特例，但入口不同：本 skill 交付人设卡，f08 交付一段桥段的因果链，别互相代办。
- 与 `self-deprecation-persona`（**composes-with**）: 落差的**来源方向相反**——本 skill 是"高位标签被行为自然打破"（观众被耍，靠预期违背），f06 是"角色自己开口贬自己"（观众被邀入伙，靠主动示弱）。标准组合序：先用 f06 把角色的自贬底座立稳（讨喜、不招烦），再用本 skill 叠加身份反差产笑；缺 f06 的反差容易只剩"看他丢人"，缺本 skill 的自嘲容易平。用户在问"怎么让他讨喜"→ f06 先行；问"怎么让他好笑"→ 本 skill 主导。
- 与 `childs-eye-misalignment`（**composes-with**）: f07 是本 skill 的**视角变体**——反差同样成立，但错位来自"年龄/视角该不该懂"，而非"身份该不该强"。组合方式：给一个孩子/外行角色同时挂"名号高位"（如稚龄却顶掌门位）与"童言视角"，两层错位互相加成。**抢调用判据**：换的是眼睛 → f07；换的是身份 → 本 skill。
- 与 `vocal-signature-reuse`（**无直接关系边**，仅需划界）: 声口管"角色怎么说话被记住"（一句台词内的错位，零前史生效），本 skill 管"他是谁 vs 他实际什么样"（需要铺垫的双层设定）。用户若只要一句台词的记忆点 → f01；要一整套可持续违背的人设 → 本 skill。
- 与 `warm-twist-payoff`（**无直接关系边**）: f05 是收尾情绪兜底（笑后收心），本 skill 是过程产笑（笑来自身份落差）。阶段不同、不争入口；f05 需要"前面充分闹"的高位，本 skill 正好提供，但收尾动作请交给 f05。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **立高位预期 —— 写清表层身份**
   - 动作：给角色一个具体、有重量、可被观众一眼读懂的光环标签（战绩 / 名号 / 头衔 / 前史）。避免空泛词（如"很厉害"），用可证伪的具体信息（"前世界冠军""江湖第一盗"）。
   - 完成标准：能用一句话说清"观众以为他是谁 / 他有多强"，且该预期可被后续行为违背。
   - 判停条件：若载体是零前史的短视频 / 新 IP，且无法在 3–5 秒内建立这段高位认知（字幕 / 前情 / 旁白），则先补"建立预期"步骤，否则跳到步骤 3 会塌房（见 B · x06）。

2. **落低位里子 —— 设计持续违背的行为**
   - 动作：让真实日常行为温和、反复地违背高位标签（不是一次 gag，而是每场都露怯 / 菜 / 软）。违背要"自然长出"，不靠强行装怂。
   - 完成标准：能列出 ≥3 个可复用的"里子违背"情境，且每个都呼应步骤 1 的高位认知。

3. **校准落差与复用节奏**
   - 动作：确认反差靠"已建立的高位预期被打破"生效，而非靠解释；规划反差在系列中的复用密度（每集 1–2 次，避免疲劳，参考 x01）。
   - 完成标准：产出一份人设卡 —— 含「高位标签 / 里子行为清单 / 复用节奏」，且读起来"预期被打破即笑点"逻辑自洽。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯信息说明 / 知识梳理类任务（没有人物设定，无从立反差）。
- 已有固定人设且只需维护一致性、不必制造预期违背时（应转人设声口卡 f01）。
- 需要"喜后收心"的温情收尾时（应转温情反转落点 f05）。
- 单集一次性 gag、不打算持续复用该反差时（本技法价值在"反复打破预期"，一次性用不如直接写包袱）。

### 作者在书中警告的失败模式

- **反差裸迁移 (x06)**：把"强者装弱 / 狠人怕事"当通用配方直接套到新角色，却不铺设反差成立所需的前史与高位预期，结果反差不成立、笑点塌房。白展堂的"怂"之所以好笑，前提是观众先信了"他是盗圣"。零前史载体必须先花 3–5 秒建立高位认知。
- **人设固定导致整体审美疲劳 (x02)**：长内容里人设永不演化、反差模板循环，观众对"下一集还是这点事"倦怠。需每集给人设一点位移或新情境压力。
- **表演层丢失 (x04)**：纯文本整理只捕获台词与结构，反差真正的载体（演员从怂到耍帅的反差神态、对手反应、节奏）在文本外。迁移到 AI 配音 / 纯文字载体时笑点命中率会下降，需补表演 / 声音 / 节奏层。

### 作者的盲点 / 时代局限

- 强依赖"固定人设 + 单一场景"套路，长期靠重复人设，有审美疲劳风险（非所有题材适用）。
- 部分反差挂靠 2006 年前后的名号 / 流行语语境（如"盗圣"的江湖语境），跨时代年轻观众无即时效用；新内容应挂载当下共同语境，而非照搬老梗（x05）。

### 容易混淆的邻近方法论

- 与"反差萌"审美词混淆：本技法是可操作的"先立高位→行为持续违背→预期打破即笑点"步骤，不是人人会说的"要有反差"。
- 与"好心办坏事 (f08 表演式英雄主义)"混淆：f08 是"英雄姿态 + 能力落空"的单一桥段发生器；本构造器是覆盖角色整体的双层人设，f08 可视为本技法的一个子集情境。
