## I — 方法论骨架 (Interpretation)

官腔错位的核心是一种"语域落差"：角色把一套规格远高于事务本身的正式话语（公文、军事、学术、体制黑话），真诚地套用到琐碎家事上，落差本身产生荒诞喜感。

两条关键约束：
- (a) 方向单向——高语域降维到小事好笑，反向（家常语谈大事）显冷漠不好笑；
- (b) 角色必须一本正经地认为该语域恰如其分，一旦自觉在开玩笑就死。

更深的边界：错位只能停在语言层，不能落到真实剥夺，否则荒诞变压迫。可迁移的不是具体名词，而是"语域落差 + 借公共合法性掩护私欲"这一结构。

## A1 — 书中的应用 (Past Application)

### 案例 1: 傅老削零花钱（第1集）
- **问题**: 想削减志新的零花钱，直接说显得小气。
- **方法论的使用**: 用"开源节流""重点工程"的公文体把家务决策包装成国家经济工程，落差制造喜感。
- **结论**: 把私欲藏进公共合法性话语里，既达目的又制造笑点。
- **结果**: 观众因"拿国家工程谈零花钱"的荒诞而笑。

### 案例 2: 和平管孩子（第21集）
- **问题**: 圆圆不服管教，普通说教无效。
- **方法论的使用**: 用"人海战术外加疲劳战术"的军事体描述家庭育儿，把语域升格。
- **结论**: 军事话语降维到亲子博弈，把焦虑变成喜剧。
- **结果**: 军事术语与琐碎育儿的反差构成笑点。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户写家庭/职场吐槽，想用"大词说小事"制造荒诞。
2. 用户设计讽刺文案，需要把正式话语套进日常冲突。
3. 用户做社群/短视频玩梗，想借黑话、体制语制造反差。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么用正式话说鸡毛蒜皮的事"
- "怎么把公文/黑话套到日常里"
- "官腔错位 / bureaucratic mismatch"

### 与相邻 skill 的区分

- 与 `wojia-vocal-signature` 的区别: 声口复用是固定腔调商标化；官腔错位是临时把高语域降维到小事，不依赖角色一贯声口。
- 与 `wojia-pseudo-argument` 的区别: 伪论证篡改论证逻辑/度量单位；官腔错位只换措辞规格，不动推理结构。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别目标事务**
   - 完成标准: 事务已具体化（如"削零花钱""管孩子"），非抽象观念。

2. **选取高语域话语**
   - 完成标准: 从公文/军事/学术/体制黑话中挑一套与事务规格悬殊的语料，且角色能真诚使用（非自觉玩梗）。
   - 判停条件: 若事务涉及真实剥夺（真削钱、真收费），跳到步骤 3 加安全阀。

3. **落点校验**
   - 完成标准: 确保错位停在语言层、无实质伤害，并由第三方收尾防刻薄（参考 `wojia-warm-twist`）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要真实政策准确性的公文/严肃论述场景——此处只借技法，非真实语体。
- 事务本身涉及真实剥夺（真扣薪、真收费），错位会变压迫。

### 作者在书中警告的失败模式

- **ce04 时代梗不转译**: 直接搬"发挥余热/治理整顿"等90年代词，当代读者需背景才能get，易过期；当代应替换为大厂黑话/OKR/法律语等。
- **ce06 官腔降维推到真压迫**: 一旦官腔从语言层落到真实剥夺，荒诞即破产为压迫，须退回语言层或加温情收尾。

### 作者的盲点 / 时代局限

- 90年代单位制/国企改革语境梗需当代转译（阶段0批判段）。
- 部分性别设定（女性多承担泼辣媳妇/保姆功能）带当时旧视角。
- 纯台词剥离表演后笑点会折损，不能直接当"搞笑配方"抄。
- 叙事以傅老（父权/单位）为引力中心，视角单一。

### 容易混淆的邻近方法论

- 与 `wojia-pseudo-argument`（B2 伪论证）易混：前者换措辞规格，后者换推理结构。
