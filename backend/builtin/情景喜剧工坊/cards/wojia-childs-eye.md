## I — 方法论骨架 (Interpretation)

童言反差破防的本质是一个"功能位"：一个拥有"合法无知"的角色——不受在场默契约束，且不为发言承担后果。

破防力不来自天真，而来自"精准"：圆圆用的全是成人工具（政治口号、科学可比性、赞助话术）。"孩子说孩子话"不好笑，"孩子精准使用成人工具"才破防。

可替换角色（书里仅圆圆一个执行者，属纯外推）：新员工、外国人、方言外来者、宠物、AI、醉汉、审计员。判据只有两条：他不知道这里的忌讳，且说了不会挨罚。这条替换规则是书里从未明说的方法论外推。

## A1 — 书中的应用 (Past Application)

### 案例 1: 圆圆戳双标（第1集）
- **问题**: 成人对爷爷新恋情表面客气，私下有双标。
- **方法论的使用**: 圆圆用一句"她长得好看你们就都愿意瞧了"点破成人回避的双标。
- **结论**: 合法无知者说出成人不敢说的实质。
- **结果**: 双标被童言精准戳穿，成破防点。

### 案例 2: 圆圆用科学逻辑反杀自夸（吉尼斯集）
- **问题**: 傅老自夸家史，成人不便反驳。
- **方法论的使用**: 圆圆以"您十二岁当过几回三好学生"用可比性逻辑反将。
- **结论**: 用成人自己的科学话语（可测量、可比）反杀。
- **结果**: 自夸被精准工具击破。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户写家庭对话，需要有人点破成人伪饰/双标。
2. 用户内容里没有小孩，需找一个"合法无知者"承担破防功能。
3. 用户写反转/讽刺，想用一个角色说破真相而不显刻薄。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么让小孩/新人说破真相"
- "童言反差 / childs-eye"
- "合法无知者怎么设计"

### 与相邻 skill 的区分

- 与 `wojia-generational-deadlock` 的区别: 代际死锁是双方凭证卡死；童言破防是单方（无知者）精准戳穿，不依赖对方凭证。
- 与 `wojia-vocal-signature` 的区别: 声口是固定腔调商标；童言是功能位（可替换角色），不绑定特定腔调。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **设立合法无知者**
   - 完成标准: 挑一个"不知忌讳且说了不挨罚"的角色（小孩/新人/外来者/AI/审计员），满足两条判据——不知默契、无后果。

2. **装备成人工具**
   - 完成标准: 让他用成人的政治口号/科学逻辑/合同话术等精准武器，而非幼稚童语；发言是"成人工具的精准使用"。

3. **触发破防并收尾**
   - 完成标准: 由无知者说出成人回避的实质，末尾配温情托底防刻薄（参考 `wojia-warm-twist`）；破防点落在实质，非说教，无 ce07 失效。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要儿童真正天真视角的温情文——此处童言是武器，不是心声。
- 严肃儿童议题或让孩子承担教化功能——易失真。

### 作者在书中警告的失败模式

- **ce07 童言变说教**: 一旦让孩子替作者点题、说出显然的说教，破防力立刻失效。
- **ce02 刻薄无托底**: 只用童言戳人而无温情收尾，会滑向刻薄。

### 作者的盲点 / 时代局限

- 圆圆作为唯一儿童视角，被功能化为"童言"工具而非真正平等角色（阶段0批判段）。
- 纯台词剥离表演，破防的节奏会折损。
- 90年代语境梗需转译；叙事以傅老父权为中心，儿童主体性有限。

### 容易混淆的邻近方法论

- 与 `wojia-generational-deadlock`（S5）易混：前者是单方戳穿，后者是双方死锁。

## 相关 skills

- **depends-on `wojia-warm-twist`（S7 温情反转）**：破防是"把人剥开"的动作，若笑完无人替被戳者说一句话即 ce02 刻薄；E3 已把温情托底列入完成标准，属使用前提。
- **composes-with `wojia-vocal-signature`（S1 声口复用）**：合法无知者要戳得"准"，前提是成人的伪饰已被声口立得足够结实——先有可预判的腔调，才有可被一句话掀翻的东西。
- **composes-with `wojia-persona-contrast`（S2 人设反差）**：身份通胀者的权利主张最经不起一句天真追问，两卡在同一段里常形成"立起来—捅破"的配套。
- **contrasts-with `wojia-generational-deadlock`（S5 代际死锁）**：本卡是单方一击（合法无知者精准戳穿，不需对方出示任何凭证），S5 是双方僵持（凭证互不承认而卡死）；同一场戏择一，否则破防与死锁互相抵消。
- **cross-link `childs-eye-misalignment`（武林外传同名卡）**：同为童言错位；本卡把它外推成"合法无知者功能位"——判据只有"不知忌讳"＋"说了不挨罚"，可换成新人、外来者、AI、审计员。
