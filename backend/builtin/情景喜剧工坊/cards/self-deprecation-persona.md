## I — 方法论骨架 (Interpretation)

让一个底层/常搞砸的角色讨喜，最稳的办法不是替他辩解，而是让他**自己先开口贬自己**。

机制是三步：角色主动点出自己的短板（笨、怂、不识字）→ 用自嘲语气把它说成"我就是这样"的招牌态度 → 多数情况下再补一句自抬（"但我有志气"），把弱点翻成尊严。

为什么比"嘲他"安全且亲：嘲笑别人会树敌、冒犯具体对象；自贬只冒犯自己，观众无从被攻击，于是从"被冒犯"转为"共情"——"这人好真实"。弱点在反复自嘲中从减分项变成可识别的萌点记忆点。

关键边界：自贬必须**主动、带自嘲语气、且最好有自抬兜底**。缺了自抬，自嘲会滑向真丧/卖惨，共情就断。

## A1 — 书中的应用 (Past Application)

### 案例 1: 李大嘴"不认字但有志气"
- **问题**: 在"比文豪"的回目里，大嘴是客栈里唯一不识字的人，硬比文采必输必尬。
- **方法论的使用**: 他坦然承认短板——"我李大嘴虽然不认字，但我有志气"，先自贬再自抬。
- **结论**: 把"不识字"从丢脸事翻成憨厚厨子的尊严锚点。
- **结果**: 观众笑中带怜，憨厚人设立住；弱点变萌点，后续再出糗都讨喜而非招烦。

### 案例 2: 邢育森"酒壮怂人胆"
- **问题**: 邢捕头本是威风捕快，实际一遇险就怯场，身份与胆量严重错位。
- **方法论的使用**: 他一喝酒就给自己"怂人"定性——"酒壮怂人胆"，用一句自黑格言解释怯场。
- **结论**: 主动把"怂"说出口，把胆小变成可可爱点而非失职。
- **结果**: 这句在 corpus 中复用两次成为他的声口商标；观众预期被校准为"邢捕头=可爱的怂"，威风身份反而成了反差笑料。

### 案例 3: 白展堂"我就是一跑堂的"
- **问题**: 顶着"盗圣白玉汤"的江湖威名，现实却是怕捕快、啃鸡爪的怂包跑堂，名号与身份落差巨大。
- **方法论的使用**: 他在失忆回目里主动降格——"我就是一跑堂的"，把传奇前史自我消解成当下小人物。
- **结论**: 自贬 preempt 了观众对他"该狠"的期待，提前把人设锚在"怂但真实"。
- **结果**: 观众因他的示弱而共情，盗圣光环不再压迫人设，反而衬出反差喜感（与 H1 人设反差叠加生效）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计一个常出糗、笨拙、搞砸的职场新人/小人物 AI 角色，希望观众共情而非反感其短板。
2. 角色连续翻车，需要把"弱点"变成可识别的记忆点，而不是持续减分项。
3. 短视频/脱口秀人设需要"接地气"的亲切口播，拉近与观众距离。
4. 想用自黑化解尴尬、化解冲突，而非攻击他人或强行辩解时。
5. 塑造底层/小人物群像，需要统一的"示弱即同盟"基调。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么让这个角色讨喜 / 不招人烦"
- "他老是搞砸，怎么立人设"
- "想用自嘲 / 自黑拉近距离"
- "怎么让失败者 / 小人物可爱起来"
- "make a flawed/loser character likable"
- "self-deprecating persona / build rapport by mocking myself"

### 与相邻 skill 的区分（定稿 · 阶段 3 据真实关系回填）

> **本 skill 交付的是"共情"，不是"笑声"**：它把观众从"被冒犯/嫌弃"搬到"自己人"那一侧，是其他产笑技法的**底座**而非替代。**总判据**：用户的痛点是"这个角色老搞砸、观众烦他"→ 本 skill；痛点是"他不够好笑"→ 转 f02/f08。

- 与 `performative-heroism`（**contrasts-with**）: 两者都在处理"角色不行"，但**谁先开口**完全相反。本 skill 是角色**自己先认**（"我就是怂"），示弱在前、失败在后，观众被邀入伙；f08 是角色**先装能行**（摆英雄 pose），高位在前、落空在后，观众看他被现实打脸。**抢调用判据**：他搞砸之前有没有嘴硬？有 → f08；没有、一上来就自贬 → 本 skill。同一角色可以两套都有（先摆 pose 塌了、再自嘲收口），但那时 f08 是桥段主体、本 skill 只提供收口那一句；反之若整体人设基调就是"我不行但我真诚"，主体是本 skill，别硬给他安排英雄 pose。
- 与 `persona-contrast-builder`（**composes-with**）: 落差**来源方向相反**——本 skill 靠"主动示弱换共情"（观众被邀入伙），f02 靠"高位标签被行为打破"（观众被耍）。标准组合序：**先本 skill 立讨喜底座 → 再叠 f02 的身份反差产笑**。缺本 skill 的反差容易只剩"看他丢人"（观众冷眼），缺 f02 的自嘲容易平（有好感没笑点）。用户问"怎么让他讨喜"→ 本 skill 先行；问"怎么让他好笑"→ f02 主导。
- 与 `vocal-signature-reuse`（**composes-with**）: 本 skill 是**内容/态度层**（自贬什么、要不要补自抬），f01 是**形式/复用层**（要不要固化成商标、每期砸几次）。一句自嘲格言写出来归本 skill，把它复用成招牌归 f01（注意 f01 的复用上限：同一梗单条内 ≤2–3 次）。**判据**：用户在问"说什么"→ 本 skill；在问"怎么变成记忆点"→ f01。
- 与 `childs-eye-misalignment`（**无直接关系边**，仅需划界）: 方向相反——童言**向外**戳破他人虚伪（视角装置），自嘲**向内**拿自己开刀（人设态度）。别互替：需要"安全地讽刺别人"→ f07；需要"安全地承认自己不行"→ 本 skill。
- 与 `warm-twist-payoff`（**无直接关系边**）: 自嘲在过程中建同盟，f05 在结尾收心。本 skill 之后若强行讲大道理会冲淡喜感（x03），要收就交给 f05 且只给一句、以留白或梗收。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别真实短板**
   - 列出角色最常被嘲笑/最弱的 1–2 个具体特质（笨拙、胆小、不识字、怂），避免泛泛"他很差"。
   - 完成标准: 短板具体可指名，且明显是观众会注意到的弱点，而非内部设定。

2. **写成主动自贬句 + 自抬兜底**
   - 把短板改写成角色**自己说出**的自嘲句（"我就是个搞砸专业户"），语气带自嘲不带回护；随后补一句自抬（"但我有志气/但我靠谱"）防止滑向真丧。
   - 完成标准: 自贬句由角色第一人称开口，且存在自抬或明确自嘲姿态，弱点在句中被"翻"成态度而非纯认输。
   - 判停条件: 若用户要的是高冷/权威/精英人设，或缺陷涉及歧视/敏感议题，则跳到步骤结束，不套用本 skill。

3. **复现成同盟信号**
   - 在 2–3 个不同情境反复触发同一自贬，建立观众的条件反射式共情，让弱点逐渐可识别为萌点。
   - 完成标准: 观众从"被冒犯/嫌弃"转为"共情/喜爱"，该自贬已成为角色稳定记忆点，而非一次性 gag。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需塑造高冷、权威、精英感的人设——自贬会破坏该有的距离与可信度。
- 真实自卑、心理创伤、需被严肃安抚的场景——用自嘲消解会显得轻佻，非喜剧用途。
- 角色缺陷涉及歧视、外貌攻击、敏感社会议题时——自贬会变冒犯而非讨喜。

### 作者在书中警告的失败模式

- **表演层损失 (x04)**: 纯文本整理出的自嘲台词，迁移到 AI 配音/纯文字短视频后笑点打折——自贬靠"怎么说"（语气、停顿、表情）而非"说什么"。须补节奏/声音层，否则金句是空壳。
- **自贬变真丧**: 缺"自抬"兜底时，自嘲滑向卖惨/自卑，观众共情转为不适。本剧李大嘴"不认字但我有志气"正是示范了自贬+自抬的安全边界。
- **时代梗时效 (x05)**: 自嘲若挂 2006 年前后的老网络梗（如"地球人都知道"型），语境消失即笑点融化；须挂载**当下**共同语境。

### 作者的盲点 / 时代局限

- 本技法依赖"观众已站在角色这边"的底层善意。对小人物群像成立的自嘲，移到精英主角或零前史载体上未必亲——短视频需先花 3–5 秒建立"这人自己人"的认知。
- 全剧有说教式收尾倾向 (x03)：自嘲之后若强行讲大道理，会冲淡喜感，建议以梗收或留白收。

### 容易混淆的邻近方法论

- 与"人设反差 (H1/f02)"混淆: 反差是"观众以为他强、其实他怂"（靠预期违背）；自嘲是"他自己说怂"（靠主动示弱建同盟）。前者观众被耍，后者观众被邀入伙。
- 与"童言反差 (莫小贝)"混淆: 童言是借孩子视角戳破成人世界的算计；自嘲是角色拿自己开涮。前者是视角装置，后者是人设态度。
