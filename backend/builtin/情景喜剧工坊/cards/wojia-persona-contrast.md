## I — 方法论骨架 (Interpretation)

1. 反差落点不是"能力强弱"或外观差异，而是"身份—权利"链条。
2. 三步链：角色获得新身份 → 主张对应待遇 → 拒绝原有义务。
3. 反差能量来自"权利索取"而非属性差异；由角色自己主动主张才成笑点，旁人指出只是描写。
4. 反差必须落到一件具体家务／义务的分配上，不能停在观念层。
5. 身份一升格立刻被当作免除义务的金牌（身份通胀）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 小桂身份倒置（第101集）
- **问题**: 外来保姆如何制造喜剧反差。
- **方法论的使用**: 让她获"知识分子"新身份 → 主张待遇 → 拒做家务（"咋还让俺干这个"）。
- **结论**: 身份通胀产生反差。
- **结果**: 反差成立，笑点来自角色自主张权利。

### 案例 2: 小张阶层主张（第1集）
- **问题**: 保姆在家庭中的话语权。
- **方法论的使用**: 用"劳动人民当家作主"主张家庭话语权。
- **结论**: 以阶层身份索取权利，与傅老机关腔形成不同向反差。
- **结果**: 反差落在家务分配，笑点可指认。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写喜剧人物，反差只靠"一个精明一个糊涂"显得扁平。
2. 给 AI／虚拟角色配置喜剧人设。
3. 设计角色间冲突，想用身份落差而非正面吵架。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么让两个角色形成反差"
- "角色人设太平面了"
- "想写身份错位／身份倒置的笑点"

### 与相邻 skill 的区分

- 与 `wojia-vocal-signature` 的区别：人设反差管"身份落差冲突"，声口复用管"怎么说"。
- 与 `wojia-generational-deadlock` 的区别：代际反差聚焦"代际资历凭证死锁"，人设反差聚焦"身份通胀与权利主张"，前者代际专属，后者跨身份通用。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **设定新身份与待遇映射**
   - 完成标准：身份与可主张待遇一一对应。

2. **写出角色自主张待遇并拒义务的动作**
   - 完成标准：反差由角色自己说出（一句台词／一件家务），非旁白描述。

3. **锚定到具体家务／义务分配**
   - 完成标准：能指认"这件具体事"就是笑点落点，未停在观念层。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯观念辩论、无具体事务落点：反差停在观念层不好笑。
- 角色由旁人指出反差而非自己主张：变成描写不生成笑点。

### 作者在书中警告的失败模式

- ce03 声口失焦：人设与声口混为一谈，反差靠形容词而非权利主张。
- ce02 刻薄无托底：反差沦为嘲笑弱势身份，缺温情托底则显刻薄。

### 作者的盲点 / 时代局限

- 部分身份设定（保姆／媳妇功能性角色）带当时旧视角，复用需当代转译。
- 文本剥离表演后纯台词折损，人设反差不可直接抄台词。

### 容易混淆的邻近方法论

- 与"性格对比"混淆：常识的"人物要有对比"只到属性层；本机制要求反差落到"权利索取"且由角色自主张。

- **depends-on `wojia-warm-twist`（S7 温情反转）**：本卡的反差落点常是弱势身份（保姆、媳妇、外来者），一旦无人接住就是 ce02 刻薄无托底；写反差前先把安全阀装上。
- **composes-with `wojia-vocal-signature`（S1 声口复用）**：S1 决定角色"怎么说"，本卡决定"凭什么身份索取"，两维度正交，通常一起配置。
- **composes-with `wojia-childs-eye`（S6 童言破防）**：身份通胀最脆的地方是"权利主张说不出口的部分"，由合法无知者一句点破即爆点，两卡常共现。
- **contrasts-with `wojia-generational-deadlock`（S5 代际死锁）**：本卡是单方身份升格后索取权利（跨身份通用），S5 是双方各持不可兑换的资历凭证卡死（代际专属）；同一场冲突里择一，混用会互相削弱。
- **cross-link `persona-contrast-builder`（武林外传同名卡）**：同为人设反差构建；本卡把落点锁在"身份→待遇→免义务"三步链上，不停在属性对比。
