## I — 方法论骨架 (Interpretation)

温情反转不是"最后补一句好话"的态度建议，而是一条可操作的结构规格（安全阀）。

1. **位置约束**：归属声明必须放在段子/冲突的末尾，中途插入会泄气、破坏节奏。
2. **说话人约束**：必须由旁观第三方说出（第1集是和平，既非被议论的傅老，也非发起议论的志新）；当事人自己说会变成辩解，反而显窘。
3. **内容约束**：说的是"我们同属一个共同体"，不是"对不起"或"我错了"。
4. **检测指标**：笑完之后，有没有人替被嘲者说过一句话？没有就是刻薄。
5. **报警器属性**：若一段笑料"需要"靠温情收尾才能把压迫感盖回去，说明前文已经写过头——安全阀的存在反而是越界的警报。

## A1 — 书中的应用 (Past Application)

### 案例 1：第1集 家庭认同收束
- **问题**：全家饭桌群嘲傅老"退居二线""老糊涂"，冲突一触即发。
- **方法论的使用**：由和平（第三方）在末尾抛归属声明"家有千口，主事一人，您不当家谁当家？"
- **结论**：冲突不靠认输化解，而靠"仍是这个家"的认同收束。
- **结果**：火药味落地为家庭向心力，群嘲被托住不滑向刻薄。

### 案例 2：第22集 真情流露兜底
- **问题**：全家脑补傅老的中学同学是"琼瑶式小蜜"，群口嘲笑。
- **方法论的使用**：傅老被戳破后以"她现在还活着嘛"收在真情，而非反咬。
- **结论**：笑点归笑点，末尾用真实情感把被嘲者接住。
- **结果**：荒诞脑补与真情并置，观众笑完不觉得全家在欺负老人。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写完一段讽刺/吐槽，自己读着觉得"像在泄私愤、踩人"，需要安全收尾。
2. 设计喜剧桥段，担心冒犯被嘲对象（甲方、领导、亲戚），想保留笑点又不刻薄。
3. 群嘲或多人对线式内容收尾时，需要一句"共同体归属"把节奏托住。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么收尾才不刻薄 / 不像在骂人"
- "写完觉得有点刺，帮我垫一下"
- "warm twist / 温情反转 / 安全阀 / 归属声明"

### 与相邻 skill 的区分

- 与 `wojia-group-catch`（群口抓包）的区别：S3 制造"共识被暴露"的爆点，本卡是冲突**之后**的兜底，方向相反。
- 与 `wojia-childs-eye`（童言破防）的区别：S6 用童言戳破伪饰制造笑点，本卡解决"笑完谁来接住被戳的人"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定位冲突落点**
   - 完成标准：已标出被嘲/被吐槽对象与笑点所在句，确认存在"可能刻薄"的风险。

2. **配置承接角色 + 写归属声明**
   - 完成标准：指定一个旁观第三方（非被嘲者、非发起者），在末尾说一句"我们同属一个共同体"式的话，不出现"对不起/我错了"。
   - 判停条件：若用户内容本无冲突/纯信息，跳到步骤 3 并提示"无需安全阀"。

3. **越界自检**
   - 完成标准：确认温情收尾是"锦上添花"而非"盖回压迫感"；若去掉温情段仍显冒犯，回退修改前文而非加收尾。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯信息陈述、抒情散文、无冲突的平铺叙事——没有可被托住的刻薄风险，硬加归属声明会显矫情。
- 真实霸凌/真实伤害场景——温情收尾不能替受害者消解实质伤害，属滥用安全阀。

### 作者在书中警告的失败模式

- **ce02 刻薄无托底**：笑完无人替被嘲者说话，段子即刻薄；必须配置承接角色。
- **ce06 温情盖回报警**：若一段笑料"需要"靠温情收尾才能把压迫感盖回去，说明前文已写过头，安全阀不是万能补丁。

### 作者的盲点 / 时代局限

- "温情托底防刻薄"是结构良方，但本书假设"日常对话天然好笑"未被证明——纯台词剥离表演后笑点折损，不能直接当搞笑配方抄。
- 时代梗（发挥余热等）需当代转译，否则温情外壳下的时事梗会过期。
- 温情常收束到"父权/单位"框架的家庭认同，视角偏旧，当代写作宜拓宽"共同体"的定义。

### 容易混淆的邻近方法论

- 与"结尾补好话"混：本书明确是结构规格（位置+说话人+内容三约束），非态度修饰。
