## I — 方法论骨架 (Interpretation)

一个角色好笑不好笑，很多时候在他说什么之前就已经决定了——决定在"他怎么开口"。

这个机制的做法是：给角色挑一小段**固定的、可以反复播放的语音标签**，然后当商标用。标签可以是三种形态之一：一句口头禅（"确定一定以及肯定"）、一个方言/口癖标记（用"额"代"我"）、或一个招式名/行动口号（"葵花点穴手""放着我来"）。挑定之后不再换，每逢角色进入特定情绪或特定动作时刻，就把同一个标签原样砸出来。

关键在于它的笑点来源和普通段子不一样，靠的是三层叠加：

1. **辨识层**：声口先于语义工作。观众听到"额"就知道是掌柜，听到"子曾经曰过"就知道秀才要掉书袋——不用等说完，认人成本降到接近零。
2. **复用层**：第一次出现只是新鲜，第二三次开始形成条件反射——观众听到前半句就自动预判后面要发生什么，这种"我知道要来了"的默契本身就是笑声来源。所以这类笑点**越旧越香**，跟"每集想新梗"的逻辑正好相反。
3. **错位层**：真正让它好笑而不只是好记的，是让声口和角色状态拧着来。怂包喊霸气招式名、废柴喊英雄口号、小孩说成人流行语、严肃道理用方言撒娇着说——标签和本人越不般配，每次触发都自带反差。

所以它不是"给角色配一句口头禅"这么简单的事。它是一台**装在角色身上的、可无限次触发的笑点发生器**：一次设计，全系列复用；不靠情节推进，不靠新梗供给。代价是有寿命——复用次数一过阈值，条件反射会从"默契"退化成"疲劳"（见 B 段）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 白展堂的"葵花点穴手"——把招式名做成情绪开关

- **问题**: 白展堂是个跑堂，日常怂、怕捕快、没有武打戏份可撑。怎么让这个功能性配角每次遇冲突都有稳定笑点，且不靠新桥段？
- **方法论的使用**: 把他前身份的招式名"葵花点穴手"锁定为唯一硬气时刻的触发词——每逢危机就原样喊出，不改词、不换招。同时刻意让"霸气招式名"和"怂包本人"错位。
- **结论**: 招式名不当武功用，当**情绪开关**用：喊出来 = 老白终于支棱一下。声口本身承担了反差与解围两个功能。
- **结果**: 该台词在全剧多回目反复出现（chunk_01:11、chunk_02:1534/2228 等），成为观众对该角色最强的记忆锚——听到即预判"这次又要装完就露怯"。

### 案例 2: 佟湘玉的"额"——把方言当情绪标点和转场信号

- **问题**: 掌柜是全剧话最多的角色，说教、催债、崩溃、撒娇混在一起，容易变成噪音。
- **方法论的使用**: 不给她配特定金句，而是在**最底层**装一个方言标记：以"额"代"我"。每逢崩溃/认命/撒娇就切回陕西腔连发（"额错了，额真的错了"）。
- **结论**: 方言不是装饰，是**情绪标点**。一个口音顶半句包袱：既立住"外地寡妇老板娘"人设，又让观众凭声调判断这段是要炸笑点还是要催泪。
- **结果**: "额"成为全剧最高频、最稳定的声口标记，同时充当情绪转场信号——严肃道理用方言说出来反而喜感，成了温情落点的引子。

### 案例 3: 女性与年轻底座——"确定一定以及肯定""放着我来""地球人都知道"

- **问题**: 客栈需要多个女性角色和一个孩子同台，人设容易糊成一团"都是爱闹的姑娘"。
- **方法论的使用**: 给每人发一张**互不重叠的声口商标**，并让它们互为对照：郭芙蓉用叠词加码式肯定（"确定一定以及肯定"），祝无双用抢活口号（"放着我来！"），莫小贝用成人流行语装懂（"地球人都知道"）。
- **结论**: 声口可以承担"人设分工"——叠词=嘴比手快的虚张声势，行动口号=贤惠到委屈自己的讨好型，流行语=用大人词办孩子事的小大人。三张标签一放，无需台词量就把三人区分开。
- **结果**: 三句均在 corpus 多回目复现（郭芙蓉 chunk_01:15 / chunk_03:2426；祝无双 chunk_02:1149/1200/1230；莫小贝 chunk_01:3）。祝无双的"放着我来"与郭芙蓉的"懒"形成稳定对照笑点，莫小贝的流行语声口成为全剧最年轻化的记忆点。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **新角色/新账号人设从零起步**：用户要做一个短视频角色、直播人设、虚拟主播或 AI 数字人，没有剧情铺垫可用，需要它"一开口就被记住且好笑"。
2. **系列内容更新到疲**：用户在做连载（短剧/短视频/播客/漫剧），抱怨每期都要想新梗、产能扛不住，问有没有能"一次设计、长期复用"的笑点结构。
3. **多角色糊成一团**：群像内容里几个角色说话腔调雷同，观众记不住谁是谁，用户需要给每人发一张互不重叠的辨识标签。
4. **已有角色缺记忆点**：角色写得挺完整但"不出圈"、没有可被观众模仿/接龙的东西，用户在找那个"可以被复读的爆点"。
5. **想用方言/口癖但怕翻车**：用户想给角色加地域口音或口癖，但不确定会不会变成刻板印象、会不会劝退外地观众，需要边界判断。

### 语言信号 (用户的话里出现这些就应激活)

- "这个角色**没有记忆点** / 不出圈 / 立不起来" — no memorable hook, character doesn't stick
- "给他设计一句**口头禅** / 招牌台词 / 标志性台词" — catchphrase, signature line, tagline
- "怎么让角色**一开口就被认出来** / 有辨识度" — instantly recognizable, distinctive voice
- "要不要给他加**方言 / 口音 / 口癖**？" — dialect, accent, verbal tic
- "**每集都要想新梗**太累了 / 有没有能反复用的" — running gag, reusable bit, recurring joke
- "几个角色**说话都一个味儿** / 分不清谁是谁" — voices sound the same, indistinguishable
- "**声口** / 人设台词 / 角色语言风格怎么做" — verbal signature, character voice, speech pattern
- "招牌招式名 / 固定口号 / **喊出来那句**" — signature move name, battle cry, catch-line

### 与相邻 skill 的区分（定稿 · 阶段 3 据真实关系回填）

> **本 skill 在这组 8 张里是"底座件"**：`tavern-straight-man-structure` 与 `performative-heroism` 都 **depends-on** 本 skill（前者要齿形、后者要那句 pose 台词）。凡用户的问题落在"角色开口的那一小段固定语言"上，入口就在这里；一旦问题上升到"两人怎么咬"或"摆完 pose 怎么塌"，就交棒出去，不要在本 skill 内部代办。

- 与 `catchphrase-beat-meter`（**contrasts-with + composes-with**）: **复用层级不同**。本 skill 是 character-level——标签绑死在**某一个角色**身上，作用是认人 + 反差；p07 是 show-level——俗谚由全体角色共享跨集复现，作用是给整个系列做节奏坐标和情绪锚。**抢调用判据（唯一入口）**：这句话换个角色说还成立吗？成立 → p07；一换人就不对味 → 本 skill。落地时两者常叠加（每个角色一张商标 + 全系列一句坐标句），但同一个需求只能有一个入口。
- 与 `self-deprecation-persona`（**composes-with**）: f06 管**内容与态度**（拿自己短板开刀换共情），本 skill 管**形式与复用密度**（可原样复读、越用越熟）。分工：一句自嘲格言"由谁说、说什么"归 f06；"这句要不要固化成商标、每期砸几次"归本 skill。用户若在问"怎么让这个老搞砸的角色讨喜"→ f06 先行；问"他那句自嘲怎么变成招牌"→ 本 skill。
- 与 `childs-eye-misalignment`（**composes-with**）: f07 是**视角装置**（用孩子的常识误读拉平成人算计），管说什么内容；本 skill 管怎么说、说几次。一句流行语式童言归本 skill（可复用商标），拿常识戳破大人算计的整段归 f07。误判提示：若用户的痛点是"没有记忆点"→ 本 skill；痛点是"讽刺不够安全/不够狠"→ f07。
- 与 `tavern-straight-man-structure`（**被其 depends-on**）: f03 处理**两人之间**的咬合（固定配对 + 互扣模板），本 skill 处理**单个角色**的自带标签。声口是捧逗齿轮的齿形——先有本 skill 才吃得到 f03 的红利；但只要笑点必须靠"对面那位怎么接"才成立，就该由 f03 主导，本 skill 只供料。
- 与 `performative-heroism`（**被其 depends-on**）: f08 是**行为结构**（先摆英雄 pose → 执行翻车），写的是整段桥段的因果；本 skill 只负责那句 pose 台词的**选定与复用**。同一句请缨口号：句子归本 skill，后面怎么帮倒忙归 f08。用户只要"一句能喊的口号"停在本 skill；要"喊完怎么砸"转 f08。
- 与 `persona-contrast-builder`（**无直接关系边**，仅需划界）: 反差的**载体不同**。f02 的落差在身份/前史，需要先花成本建立高位预期；本 skill 的落差压缩在一句台词里（怂人喊霸气招式名），零前史即可生效。用户若在问"怎么设计身份落差"→ 走 f02，本 skill 只顺手给它配台词。
- 与 `warm-twist-payoff`（**无直接关系边**）: f05 是收尾的情绪结构，与"角色怎么开口"无关，二者不争入口；只有当某句暖话被反复复用成标签时才交叉（此时形式层归本 skill）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **锁定角色的"执念 + 高频动作时刻"**
   - 先问/推定：这个角色最在意什么？他每次出场几乎必做的那个动作或必进入的那个情绪是什么（发飙 / 抢活 / 掉书袋 / 装懂 / 崩溃）？
   - 完成标准: 能用一句话写出"每逢 ___，他必 ___"，且这个时刻在计划内容里每期都会出现至少一次。
   - 判停条件: 若该角色只出场一次、或没有可预期的重复时刻 → **本 skill 不适用**，停止并转向单条段子/结构类技法。

2. **在三种形态里各出 1 个候选，共 3 条**
   - 形态 A 口头禅（含叠词/排比/怪腔调，如叠词加码式肯定）；形态 B 方言或口癖标记（以方言代词/语气词做最底层标记）；形态 C 招式名或行动口号（喊出来即预告动作）。
   - 完成标准: 3 条候选写成可直接开口念的原话，每条 ≤10 字，且都能在步骤 1 的时刻自然嵌入。
   - 硬约束: 必须是**你原创的新句子**。不得直接采用源剧原台词作为成稿（见 B2）。

3. **用"错位检验"筛出 1 条主商标**
   - 逐条检验：这句话的气势/身份/年龄，和说话人本人的真实状态是**拧着**的吗？（怂人喊猛话、废柴喊英雄话、小孩说成人话、糙人说雅话）
   - 完成标准: 选中的那 1 条能写出一句"错位说明"，明确指出标签与本人哪里不般配。若 3 条都般配（气势与人设一致）→ 回步骤 2 重写，般配的标签只能做认人，做不了笑点。
   - 判停条件: 群像内容需给每个角色各跑一遍步骤 1–3，并横向查重：若两个角色的商标形态与语感重叠 → 强制其中一个换形态（参考 A1 案例 3 的三张互为对照的标签）。

4. **排复用节奏与变形，设死复用预算**
   - 定下触发点：每期在哪个情绪节点砸这句、砸几次。**同一梗在单条短视频内 ≤2–3 次**（超出即疲劳，见 x01）；跨期可长期复用，但**每次必须换触发情境**（同一句话在不同倒霉法里出现）。
   - 完成标准: 产出一张小表——列出至少 3 个不同触发情境 + 每期触发次数上限；并写明一条退场/变形条件（如"观众开始接龙但不笑了就上变体"）。

5. **补表演层挂钩，交付前自检**
   - 只给文字等于交半成品。为主商标标注：语速/停顿在哪、配什么固定小动作或表情、对手角色的固定反应是什么（谁翻白眼、谁接茬）。
   - 完成标准: 主商标旁附 ≥2 条表演提示；且回答"如果只剩这一句话、去掉表演，还剩几成笑点？"若答案是"几乎没有" → 必须补足表演提示或改写句子。
   - 完成标准（时效）: 若商标挂载了当下流行语，标注失效预期与替换位（见 x05）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **一次性内容**：单条段子、单篇稿子、一次性发言。本机制的收益全部来自跨次复用，只出现一次的标签是纯成本，第一次出现往往还不好笑。
- **角色出场极短或群演化**：没有稳定重复时刻可挂载，标签落不了地。
- **严肃/专业/危机沟通场景**：品牌致歉、医疗法律咨询、事故通报里塞可复用口癖会显得轻浮甚至冒犯。
- **用户真正的问题在结构层**：如果症状是"故事没冲突""没有笑点结构""结尾收不住"，加口头禅治不了——那是 f02/f03/f05 的活。
- **要靠身份落差搞笑**：用户想做"前世界冠军现在送外卖"这类落差，主体是 f02；本 skill 只能顺手给它配一句台词。
- **纯音色/配音技术问题**：嗓音、音高、TTS 参数调优不属于本 skill——这里说的"声口"是**语言层的可复用标签**，不是声学层的音色。

### 作者在书中警告的失败模式

- **过度复用 → 笑点疲劳（x01）**：招牌台词在 80 回里高频触发（"葵花点穴手"在 chunk 中 line 11、1534、2401、2491、3525、3775 等几乎每遇冲突即出现），早期是惊喜，后期退化成"听到即知要笑"的机械反射——喜剧靠预期违背，而商标一旦固化成默认动作，意外性就被消耗掉了。剧中窦先生台词里直接出现"审美疲劳"（line 2438），可视为剧集对自身套路化的自指。**迁移铁律：短视频单条内同一梗 ≤2–3 次，且每次换触发情境，否则变成喊麦式轰炸。**
- **纯文本复用 → 丢掉 70% 的笑点载体（x04）**："子曾经曰过"为什么好笑，语料本身答不出——它依赖演员的憋屈表情、停顿，以及众人翻白眼的节拍。把台词当金句直接抽走，得到的是空壳。**任何声口类 skill 必须显式标注"需表演/声音/节奏层补充"**，这也是本次整理的红线：交付的是造声口的方法，不是可以搬走的成品台词。
- **时代梗与方言梗有时效与地域边界（x05）**："地球人都知道"（line 3）借的是 2006 年前后的网络流行语，共同语境一散，梗就融化成需要注释的文化化石。方言声口虽强化人设，跨省/跨代际传播时损耗明显（推论）。**做法：把"借势当下共同语境"当可替换模板，挂载现在的流行语，而不是照搬老梗；方言商标要评估目标受众的地域构成。**
- **标签固化 → 人设变静态贴纸（x02）**：同一句话在 corpus 中三处原样复现（莫小贝"你小时候没有自由…"line 55/164/563），是"固定人设 + 固定冲突"循环的缩影。可预期性过强就等于无变化。**声口是起点冲突源，不是终点牢笼**——每期要给人设一点位移或新情境压力，否则观众学会跳过。

### 作者的盲点 / 时代局限

- **假设台词可以脱离表演与语境被复用**（阶段 0 未被证明的假设）。实际笑点高度依赖演员节奏、表情、情境铺垫。纯文本整理只得"声口样本"，不得完整"结构"——所以本 skill 的步骤 5 是必做项而非可选项。
- **套路化风险被低估**（阶段 0 立场盲点）。情景喜剧靠"人设固定 + 场景单一"吃 80 回红利，代价是审美疲劳；这套逻辑并非所有题材都适用，快节奏短视频与强剧情叙事的容忍度低得多。
- **本剧是"成品"不是"方法"**（阶段 0 最强反对意见）。如果从这里带走的只是一份金句集，就违反了整理红线。可迁移的是"选定—错位—定量复用—补表演层"这套构造动作，不是"葵花点穴手"这六个字。
- **2006 电视语境依赖**：部分笑点依赖当时的电视播放场景与字幕梗，脱离该场景即失效。

### 容易混淆的邻近方法论

- **品牌 slogan / 广告语设计**：目标是记住与信任，忌错位、要般配；本 skill 恰恰要求标签与本人拧着来才好笑。方向相反，别混用。
- **"角色小传/人设文档"写作**：那是把角色写全（背景、动机、关系），本 skill 只做一个高频复用接口，不求完整。
- **meme / 网络热梗跟风**：热梗是借外部共同语境的势（有时效，见 x05），声口商标是自建资产（越用越值）。两者可叠加，但不能拿追热梗代替建商标。
- **口癖 ≠ 台词风格**：整体语言风格（文白、长短句、书面/市井）是底色，本 skill 要的是可被观众原样复读、可接龙的那个**离散标签**。
