## I — 方法论骨架 (Interpretation)

金句回扣做节拍器，是把一句可迁移的俗谚、口号或老理儿，从"单次的包袱"升级为"系列的节拍器"。

机制分三步：
1. **提炼坐标句**：选出 1-3 句能跨情境成立的俗谚/金句（不绑定某一具体笑点）。
2. **跨场景回扣**：在不同集/期的不同情境里反复砸同一句，让它成为观众的预期锚——一听前半句就接后半句。
3. **节奏化而非复读**：每次回扣都换触发情境，使熟句承担"情绪坐标"功能（安抚/点题/转场），而非单纯喊麦。

关键在"越旧越香"：复用不靠新鲜，靠熟悉度累积。观众从"第一次新鲜"滑向"每次都笑"，梗越旧越成系列的呼吸节奏。这是 show-level 的节奏构造，区别于单一角色的声口商标（character-level 复用）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 燕小六"帮我照顾好我娘"跨回目复用成破防节拍
- **问题**: 燕小六的硬汉捕快人设需要一种"瞬间戳破"的喜剧落点，又不能在每集都重新铺垫。
- **方法论的使用**: 把"帮我照顾好我娘"这句口头禅当节拍器——每次他摆威风遇险，就脱口此句，硬汉外壳瞬间被打回妈宝小孩。
- **结论**: 同一句跨 chunk_01:27 / chunk_02:972 / chunk_03:2321/2374 多回目复现，观众对"要出事先喊娘"形成条件反射，成为系列固定情绪拍点。
- **结果**: 该句从一次性 gag 沉淀为燕小六的喜剧锚点，复用即笑，且与"硬汉"人设的反差越积越强。

### 案例 2: 邢育森"酒壮怂人胆"同结构复用固化声口
- **问题**: 邢捕头怯场人设需要一句能自洽解释怂态、又讨喜的固定话术。
- **方法论的使用**: 用"酒壮怂人胆"（chunk_01:200 / chunk_01:414 同结构复用）把胆小自黑成可可爱点，每次出场以此句校准观众预期。
- **结论**: 俗谚式自嘲跨场景回扣，让观众一听即定位到"怂萌捕头"，降低辨识成本。
- **结果**: 该句成为邢育森的声音坐标，复用密度稳定后，预期被精准预调，铺垫成本趋零。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 在做系列/连载内容（短视频剧集、专栏、播客、连续条漫），每期观众都觉得"像新号"，缺乏连贯的熟悉感。
2. 想给一个系列打造"系列签名"（series signature），让老观众一听某句就有归属感。
3. 已有角色声口，但整体内容缺少跨集共享的节奏坐标与情绪落点。
4. 希望降低每集的理解成本——用熟句当"认知快捷键"，新观众也能快速进入。
5. 需要在长系列里建立可预期的转场/点题节点，而非每次重新发明。

### 语言信号 (用户的话里出现这些就应激活)

- "系列没连贯感 / 每集都像新的 / 缺系列辨识度"
- "想做个固定口号 / 系列签名 / 每期都出现的梗"
- "老观众没归属感 / 怎么让观众'回老家'"
- "recurring line / catchphrase as rhythm / series signature / callback"

### 与相邻 skill 的区分（定稿 · 阶段 3 据真实关系回填）

> **本 skill 是这组 8 张里唯一的 show-level 技法**：其余 7 张都在单个角色或单场戏里做文章，只有本 skill 的作用对象是**整个系列的呼吸节奏**。**总判据（一句话防抢调用）**：这句话换个角色说还成立吗？成立（是全体共享的老理儿）→ 本 skill；一换人就不对味（绑死在某人身上）→ `vocal-signature-reuse`。

- 与 `vocal-signature-reuse`（**contrasts-with + composes-with —— 本组最大的抢调用点**）:
  - **对比面（选一个入口）**：本 skill 重"跨场景回扣的**节奏功能**"——俗谚/金句作 show-level 的节拍器与情绪坐标（安抚/点题/转场），服务整部系列的呼吸感；f01 重"声口商标的**记忆点**"——方言/口癖/招式名作 character-level 的身份标签，服务单个角色被一眼认出。一个管"系列的节奏"，一个管"角色的脸"。用户痛点是"每集都像新的、老观众没归属感"→ 本 skill；痛点是"这个角色没记忆点、分不清谁是谁"→ f01。
  - **组合面（落地时叠加）**：成熟系列通常两层都有——每个角色一张互不重叠的声口商标（f01）+ 全系列 1–3 句共享坐标句（本 skill）。两层各自计算复用预算，互不占用；同一句话不要既当角色商标又当系列坐标，否则它一响，观众分不清是"这个人来了"还是"该点题了"，两个功能互相抵消。
- 与 `warm-twist-payoff`（**无直接关系边**，但须严格划界）: 本 skill 的坐标句**必须跨集成立**（换情境仍能砸），f05 的暖句**必须只在本集成立**（换到别集就不自然）。**互斥自检**：若一句话换到任意别集都通顺，它是本 skill 的坐标句，绝不能拿去当 f05 的收尾暖话（那就是 x03 说教累赘）；反之本集专属的暖句也没法当节拍器。这是两者最容易被写混的地方，也是本组唯一"同一素材两种归属"的判定点。
- 与 `tavern-straight-man-structure`（**无直接关系边**）: f03 是**场内**两人回合的对白密度，本 skill 是**跨集**的节奏坐标。层级不冲突可同场存在：用户问"这场对白怎么撑满"→ f03；问"整季怎么有连贯呼吸"→ 本 skill。
- 与 `self-deprecation-persona` / `childs-eye-misalignment`（**无直接关系边**）: 它们产出的自嘲格言或童言句若要复用，走的是 **f01 的 character-level 通道**（绑角色），不要误挂到本 skill 的系列坐标句上——除非该句已被多个角色跨集复读（此时才升级为本 skill 的对象）。
- 与 `persona-contrast-builder` / `performative-heroism`（**无直接关系边**）: 那两张管人设与桥段的落差构造，本 skill 不参与产笑，只负责让熟句在正确的拍点上出现。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **提炼坐标句**
   - 从现有内容里挑出 1-3 句能脱离具体情境、跨场景成立的俗谚/金句/口号；避开只服务单次笑点的句子。
   - 完成标准: 列出坐标句清单，且每句都能被改写为"换情境也成立"的通用表达（而非绑定某一桥段）。

2. **铺设跨场景回扣计划**
   - 为每句规划至少 3 个**不同情境**的回扣点（如开场锚定、中段点题、结尾落拍），并标注各自承担的节奏功能（安抚/转场/收心）。
   - 完成标准: 每个坐标句都匹配到 ≥3 个异质触发情境，且每次回扣的情境不重复。
   - 判停条件: 若系列总集数 < 3，则回扣密度下调为"每集 1 次"，跳到步骤 3。

3. **节奏化校准与去疲劳**
   - 检查每次回扣是否"换情境不换句式"——保持熟句外壳、替换触发语境，避免机械喊麦；剔除已退化为纯反射、不再承担情绪功能的冗余复用。
   - 完成标准: 坐标句在全系列中既保持可识别一致性，又在每次出现时携带新的情境重量；无连续两集使用完全相同触发逻辑。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单篇、一次性内容（没有"跨集回扣"的载体，节拍器无从落地）。
- 纯信息交付/说明书类文案（不需要情绪坐标与系列节奏）。
- 需要每篇全新创意、刻意避免重复的文案（如每期独立选题的随笔）。
- 当作"角色声口设计"的替代——那是 `vocal-signature-reuse` 的职责。

### 作者在书中警告的失败模式

- **过度复用致机械反射（x01）**: 同一句固化成行为标签后，从"意外"退化为"默认动作"，新鲜感耗尽。须配套"复用密度阈值 + 新语境变形"，否则变喊麦式疲劳轰炸。
- **说教式金句变累赘（x03）**: 若为点题而硬塞俗谚，且与本集冲突弱相关，就从"暖"变"拖"。金句须由本集具体情境自然长出，短视频中超过 1 句的道理收尾即劝退。
- **纯文本丢失节奏层（x04）**: 把台词当金句抽走会丢掉真正的载体——停顿、表情、对手反应、前史铺垫。脱离表演层复用的句子，迁移到新载体后命中率显著下降。

### 作者的盲点 / 时代局限

- **时代梗时效（x05）**: 挂靠特定年代的流行语（如"地球人都知道"）会随共同语境消失而融化。须把"借势当下共同语境"抽象为可替换模板，而非照搬老梗。
- **场景单一审美疲劳（x02）**: 长在固定人设+固定场景的复用，长期有套路化风险；系列内容需每集给人设/情境一点位移，否则金句变成可跳过的静态贴纸。

### 容易混淆的邻近方法论

- `vocal-signature-reuse`（声口商标）：管角色身份记忆，本 skill 管系列节奏记忆——层级不同，可叠加不可互替。
- `招牌梗复用机制`（f01，声口复用）：偏 character-level 的招式/口头禅商标；本 skill 偏 show-level 的俗谚/金句节拍器。
