## I — 方法论骨架 (Interpretation)

表演式英雄主义把"英雄姿态"和"实际能力"拆成两截。

角色先摆出一副舍我其谁的架势（放着我来、排山倒海、我来搞定），把观众预期租到最高位——这等于在借一个"悲壮英雄"的位子。但紧接着执行兑现为零：能力撑不住、场面越弄越乱，英雄瞬间塌成小丑。

笑点不在"他坏"也不在"他蠢"，而在"姿态的崇高"与"结果的狼狈"之间的落差——观众刚被那股劲儿感染，马上被现实打脸，悲壮被自己演成了滑稽。

这个落差可反复触发：每次摆 pose 都重新租一次高位预期，每次落空都重新兑现一次笑，不必换套路，只换由头。

## A1 — 书中的应用 (Past Application)

### 案例 1: 祝无双"放着我来"越帮越忙

- **问题**: 无双怕被嫌弃、总抢活儿上，但实际常越帮越忙，好心变添乱。
- **方法论的使用**: 她先用"放着我来！"摆出全能好帮手的英雄请缨 pose，再用行动反向拖后腿，高位预期与低能兑现形成落差。
- **结论**: pose 高位 + 执行落空 = 可复用笑点，且"越抢越显其心酸"自带轻讽。
- **结果**: "放着我来"在 corpus 中多次复现（chunk_02:1149/1200/1230、chunk_03:2331），成为其"贤惠到委屈自己"的人设声口锚。

### 案例 2: 郭芙蓉"排山倒海"暴走搞砸

- **问题**: 小郭自认女侠，遇事必暴走，招式名越霸气实际翻车越惨。
- **方法论的使用**: 喊"排山倒海！"摆出开大英雄 pose，话音未落即被反噬，pose 与落空叠加成稳定节奏。
- **结论**: 喊得越响、摔得越惨，"虚张声势必被反噬"的 flag 被固化。
- **结果**: "排山倒海"在 corpus 多回目以单独一句复现，成为观众一听即预判翻车的记忆锚。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写职场/生活短剧，需要"热心同事、朋友、亲戚主动帮忙却越弄越乱"的稳定笑点。
2. 角色要逞英雄、立人设，但实际能力明显不匹配，想把它变成喜剧而非尴尬。
3. 想让一段本该"燃"的情节反转成搞笑——先扬后崩。
4. 设计"嘴上最硬、手上最怂"的记忆点，让同角色再摆 pose 观众就预判翻车。

### 语言信号 (用户的话里出现这些就应激活)

- "好心办坏事" / "越帮越忙" / "逞英雄" / "放着我来" / "嘴硬手软" / "说最狠的话干最怂的事"
- "enthusiastic helper messes up" / "hero pose backfires" / "good intentions bad results" / "over-eager volunteer" / "talks tough acts weak"

### 与相邻 skill 的区分（定稿 · 阶段 3 据真实关系回填）

> **本 skill 是"桥段发生器"，交付一段因果链（pose → 落空 → 收口），不交付人设卡也不交付台词**。**总判据**：用户要的是"这一场戏怎么写才好笑"→ 本 skill；要的是"这个角色整体怎么立"→ f02；要的是"他喊的那句口号怎么定"→ f01。

- 与 `vocal-signature-reuse`（**depends-on，前置**）: 本 skill 的步骤 1 必须写出一句 heroic pose 台词，而**那句话怎么选、气势与本人怎么错位、每期砸几次**正是 f01 的活。分工：句子归 f01，喊完怎么帮倒忙归本 skill。执行顺序硬约束：若角色还没有可复用的 pose 口号，先跑 f01 选定商标（并遵守其复用上限：单条内 ≤2–3 次、每次换触发情境），再回本 skill 铺落空链；跳过这步会写出"每场换一句新豪言"的桥段，观众攒不出"他一喊就要翻车"的预判。
- 与 `persona-contrast-builder`（**contrasts-with**）: **姿态落差 vs 身份双层**。本 skill 的高位是**当场租来的**（一句"我来搞定"即拉满，同一场戏内就要兑现为零，零前史可用）；f02 的高位是**设定级**的（名号/前史/头衔，先立后破、跨集反复消耗同一预期）。**抢调用判据**：这个落差需要观众"先信过他很强"吗？需要 → f02；只需他此刻摆个架势、立刻办砸 → 本 skill。本 skill 常表现为 f02 的瞬时特例，但**入口不同、产物不同**（本 skill 产桥段因果链，f02 产人设卡），别互相代办。
- 与 `self-deprecation-persona`（**contrasts-with**）: 两者都在处理"角色不行"，区别在**谁先开口**。本 skill 是**先装能行**（高位在前、落空在后，观众看他被现实打脸，落点是落差反讽）；f06 是**自己先认**（示弱在前，观众被邀入伙，落点是亲和共情）。**抢调用判据**：他搞砸之前有没有嘴硬？有 → 本 skill；一上来就自贬 → f06。可衔接使用：本 skill 步骤 3 的收口可以借一句自嘲把落差点破，但那时 f06 只提供收口一句，桥段主体仍是本 skill。
- 与 `warm-twist-payoff`（**composes-with**）: 本 skill 提供 f05 最好用的情绪高位——刚摆完 pose 就狼狈到底，此时一句低姿态暖话落差最大、最不像鸡汤。**组合约束**：暖话须由"他为什么非要抢着上"长出；且若本 skill 步骤 3 已用自嘲/旁观者吐槽收过口，f05 只能再给一句并留白，否则触发 x03 说教累赘。
- 与 `tavern-straight-man-structure`（**无直接关系边**，仅需划界）: 本 skill 的因果链在**一个人身上闭合**（自己摆、自己塌）；f03 的笑点必须靠"对面那位怎么接"。若翻车非得有人冷眼补一句才好笑，那句接话归 f03，翻车本身仍归本 skill。
- 与 `childs-eye-misalignment`（**无直接关系边**）: f07 的落差在"视角 vs 语境"（孩子拍平大人），本 skill 的落差在"姿态 vs 结果"。孩子摆谱且当场砸锅的段落归本 skill；只用大人腔把事情说轻、没有翻车动作的归 f07。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **立 pose（摆英雄姿态）**
   - 让角色用一句高预期台词或动作宣示"这事交给我 / 我来搞定"，姿态明显高过其实际能力。
   - 完成标准: 写出一句明确的 heroic pose 台词（如放着我来 / 排山倒海 / 我来搞定），且姿态与能力之间形成可见的高位差。

2. **落 execution（能力兑现为零）**
   - 让角色在行动中反向搞砸——越想解决越添乱，场面升级而非收束。
   - 完成标准: pose 与结果形成可见落差，且落空由"能力不足"导致，而非单纯外部运气；若落空是外部巧合（跳到步骤 3 后补一句"运气背"收口，但优先改成本角色能力问题）。

3. **收反差节拍**
   - 用一句角色自嘲或旁观者吐槽把落差点破，固化"下次还敢摆 pose"的记忆点。
   - 完成标准: 产出一句收口，使该桥段可重复触发——同角色再摆 pose，观众即预判翻车。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 角色需要真正解决问题、剧情依赖其成功时——本 skill 会破坏叙事功能性。
- 纯温情正剧，讽刺点不在"姿态与结果落差"（那是温情反转落点 f05 的地盘）。
- 讽刺对象是恶意或愚蠢而非"好心"时——那是蠢人设/反派，不是表演式英雄主义。

### 作者在书中警告的失败模式

- **招牌梗过度复用疲劳 (x01)**: 若"排山倒海 / 放着我来"无新语境变形地重复超 2–3 次即失效，变成机械反射；每次需换触发情境。
- **纯文本整理丢失表演层 (x04)**: 本技法笑点约 70% 在演员崩溃表情、语速递进与对手反应；纯文本复用台词命中率显著下降，需补表演/节奏层。
- **人设固定致审美疲劳 (x02)**: 零位移反复只会塌房，每集应给人设一点新情境压力。

### 作者的盲点 / 时代局限

- **时代梗时效 (x05)**: 姿态词需挂载当下共同语境，照搬 2006 网络梗（如"地球人都知道"式）对新观众已无即时效用。
- **未证明台词可脱离表演语境复用**: 纯文本整理只捕获"姿态→落空"的结构骨架，表演层（节奏契约、角色预期）须另补——这是 cangjie 红线"整理方法非成品"的核心。

### 容易混淆的邻近方法论

- 与 `persona-contrast-builder` 已区分（见 A2）：本重姿态与结果落差，彼重身份双层。
- 与 `self-deprecation-persona`(f06)：自嘲是主动示弱建同盟，本 skill 是先装英雄后露怯，落点不同。
