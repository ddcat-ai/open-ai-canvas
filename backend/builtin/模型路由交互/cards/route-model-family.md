# 模型族自动路由

## R — 原文要点 (Reading)

剧典原创综合方法（基于多个上游技能的模型选择逻辑整理重组）：上游技能普遍内置模型选择器——多镜叙事/快速蒙太奇短剧 → Seedance 系（或涉及对白用 Kling 3.0）；对白/商业质感/同步音效 → Veo 或 Kling 3.0（多角色对白至 15s）；角色一致性跨多平台素材 → Kling 2.6 Pro（便宜）或 3.0（带 [Character A: ...] 标签）；10-15s 连续叙事带音频 → Kling 3.0；15-30s 连续单生成弧线/大参考库（至 50 素材）/编辑延长/30-180s 长视频 → Seedance 2.5；脸部重的戏剧 → Seedance 2.5（真人对白唇形是其头牌）或 Kling/Veo，纯 2.0 管线把人脸路由到 1.5 Pro（2.0 对人脸过滤激进）。生图侧：Nano Banana 系（真实地点锚定/极端画幅 1:8/思考模式）vs GPT Image 2.5（五槽模板/质量旋钮/文字渲染纪律）。默认兜底：无线索时多镜叙事→Seedance；对白商业→Veo/Kling 3.0。

## I — 方法论骨架 (Interpretation)

1. **任务特征优先**：时长/对白/参考量/一致性要求/编辑需求是路由五要素。
2. **用户习惯是微调项**：主人历史偏好（如投放素材固定 9:16 seedance-2.0-fast）来自记忆层——命中习惯时直接套用并声明来源。
3. **默认值必须显式**：任何默认（时长 15s、画幅 16:9、模型 X）都要在输出中标注「补充默认」，绝不静默替换用户明确参数。
4. **单主模式原则**：一次只选一个主模式，专家能力按需附加（承 seedance-2.5 导演卡）。
5. **路由可解释**：每次路由给出理由一句话（为什么是这个模型族），用户可否决。

## A1 — 应用案例 (Past Application)

- 来源场景：用户说「给床垫做 30 秒素人口播」→ 对白+人像+30s → 路由 Seedance 2.5（或 Kling 3.0），画幅按投放习惯默认 9:16 并声明。
- 反例：用户已指定「就用即梦」却路由到 Veo——显式参数永远优先于路由表。

## A2 — 触发场景 (Future Trigger)

- 用户需求未指定模型/技能时。
- Agent 组装生成任务前的模型决策点。
- 用户问「我该用哪个模型」的咨询场景。

## E — 可执行步骤 (Execution)

1. **提取五要素**：时长/对白/参考量/一致性/编辑需求。
   *完成标准*：五要素已盘点（缺项按默认补并标注）。
2. **查习惯记忆**：命中用户历史习惯则套用并声明来源。
   *完成标准*：习惯命中与否均有记录。
3. **查路由表**：按任务特征定模型族（单主模式）。
   *完成标准*：模型族唯一确定。
4. **声明默认**：输出头部声明模型+补充的默认参数。
   *完成标准*：默认项显式标注。
5. **给可否决**：一句话路由理由+用户可否决。
   *完成标准*：理由句非空。
