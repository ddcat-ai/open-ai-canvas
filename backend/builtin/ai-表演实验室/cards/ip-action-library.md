## I — 方法论骨架 (Interpretation)

本 skill 管"表演层·动作"——解决"角色在配图里干什么"才能让她不是装饰立牌。核心是从**文章语义**而非"站坐抬手"姿态出发设计动作：

**语义→动作映射（动作库种子）**：
- 筛选 → 把素材放进漏斗
- 连接 → 接上断开的模块
- 修复 → 补好断裂的链路
- 判断 → 拨转盘 / 称砝码
- 拆解 → 把黑箱拆成几层
- 复盘 → 沿反馈回路回看

**与表情/视线/尺度组合（表演变量）**：动作=检查决策转盘、表情=怀疑审视（中等强度）、视线=看向转盘、头部=轻微倾斜、画风=可替换不影响表演。同一"怀疑检查"可放进线稿/毛毡/编辑卡通三种风格；同一"连接"可搭专注/吃力/轻松表情；同一 IP 可从全身切手部特写。

**验收准绳（删人测试）**：删掉人物后画面核心意思仍完整 → 动作设计失败。

## A1 — 书中的应用 (Past Application)

### 案例 1：语义→动作映射配方
- **问题**：人物每张都站在一边指流程图，姿势换了却从未进入内容。
- **方法论的使用**：按语义重设计——讲筛选让她亲手放素材进漏斗，讲连接让她接上断开模块，讲拆解让她亲手开黑箱。
- **结论**：动作让角色成为完成关系的主语，不是解说员。
- **结果**：读者多记住一个持续出现的行动者。

### 案例 2：表演组合配方（怀疑检查）
- **问题**：同一动作跨画风/跨表情要不要变。
- **方法论的使用**：动作=检查转盘、表情=怀疑审视、视线=看向转盘、头部=微倾，画风可替换；证明二次加工空间被保留。
- **结论**：表演是可组合变量而非写死。
- **结果**：同动作可复用多画风多表情。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 角色在图里总像装饰（站旁边指东西），想让她承担内容关系。
2. 要从文章语义出发设计"该用什么动作"，而非随便摆姿势。
3. 要组合"动作+表情+视线+尺度"让表演可复用、可二次加工。

### 语言信号（用户的话里出现这些就应激活）

- "IP 动作怎么设计 / 让角色参与内容"
- "动作库 / 语义映射 / 删掉人物图意思还完整吗"
- "action library / character participates / semantic mapping"

### 与相邻 skill 的区分

- 与 `emotion-action-beats`（视频侧）的区别：emotion-action-beats 管"情绪如何拆成带秒数的时间节拍"；本 skill 管"配图里动作如何承担语义关系"，媒介与维度不同（配图无时间轴）。
- 与 `ip-performance-faces` 的区别：本 skill 管动作语义（做什么），ip-performance-faces 管表情/视线/尺度（用什么态度/看哪/占多大）。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **从语义定动作**
   - 完成标准：按内容选映射（筛选/连接/修复/判断/拆解/复盘），非从"站坐抬手"出发。

2. **做删人测试**
   - 完成标准：删掉人物后画面核心意思不完整，才算动作有效；否则回炉。

3. **组合表演变量**
   - 完成标准：补表情（态度）+ 视线（注意力）+ 头部/尺度（情绪方向/占比），与动作形成可组合配方。

4. **标注可跨画风复用**
   - 完成标准：明确"画风可替换不影响表演"，保留二次加工空间。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯身份/一致性管理（走 ip-character-bible）。
- 纯画风切换（走 ip-style-decoupling）。
- 视频里需要"带秒数的情绪时间线"（走 emotion-action-beats）。

### 作者在书中警告的失败模式

- **装饰性动作**：人物站一边指东西，删掉后图意思仍完整——动作设计失败。有效动作必须承担画面关键关系。

### 作者的盲点 / 时代局限

- 动作语义映射依赖对文章的理解，agent 化时需先做好内容层（认知锚点），否则动作会错配。

### 容易混淆的邻近方法论

- 与"姿态库/姿势素材"混淆：本 skill 是语义驱动的动作设计，不是堆姿势素材。
