## I — 方法论骨架 (Interpretation)

本 skill 管"身份层"——让同一个角色跨图/跨姿势/跨镜头后仍是同一个人。核心是把"像不像"从主观感觉变成**机器可读的事实 + 可判定的失败清单**。

**四要素（角色圣经）**：
1. **视觉锚点**（主次分级）：脸型/年龄感/发型为高优先级身份锚点；服装可浮动范围；背景/标题位置/姿势不属于身份。写成事实而非形容词（"黑色低马尾+细窄眼镜"而非"知性女性"）。
2. **人格锚点**：气质与行为边界（冷静拆解 or 兴奋展示？卖萌 or 不？），直接决定表情幅度与画面尺度。
3. **参考素材证据边界**：正面照锁脸与神态、坐姿锁比例、三视图锁服装；明确"不锁定"标题/排版/背景/具体动作，防模型复制偶然信息。
4. **失败标准**：列出禁止漂移方向（写实皮肤/幼态脸/网红脸/配饰错位 → 判定重生成），把"感觉不像"变成可复查工程条件。

**小互补充——角色挑选与 IP 三定律**：用"文章类型→角色"映射（AI 焦虑→替替、打工人→牛马，一篇锁一个主角）；挑角色时以三定律为哲学：A. 弱人设/反差 > 强造型；B. 角色是"情绪代名词"；C. 特色在姿态态度不在静态奇观。

## A1 — 书中的应用 (Past Application)

### 案例 1：艾笑老师角色圣经
- **问题**：给一张满意照片说"以后都照这个人画"，单张还行，批量必漂。
- **方法论的使用**：写角色圣经——身份=成熟知性+黑低马尾+细窄眼镜；气质=知性/松弛/艺术；服装=酒红上衣+深蓝短外套；配饰=左食指银戒+左腕手环；失败标准=年龄变小/眼镜消失/配饰错位即重生成。
- **结论**：IP 从"一张参考图"升级为可检查、可复用的身份系统。
- **结果**：跨姿势跨画风仍认得出是同一个人。

### 案例 2：小互 31 角色挑选用法
- **问题**：开源 Skill 里是小互本人，别人用别扭。
- **方法论的使用**：先做 31 个统一画风原创角色，按内容映射挑（讲 AI 焦虑用替替、打工人用牛马），用 IP 三定律 B 让角色成"情绪代名词"。
- **结论**：先定"他是谁、代表什么情绪"再谈画风。
- **结果**：无自己形象也能立刻用。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 批量出图时角色每次长得不一样（漂移），想系统化管理一致性。
2. 要写一份角色档案/角色圣经，不知该写哪些、哪些分级。
3. 有一堆参考图，不知每张该锁什么、不该锁什么。
4. 要从现成角色库（如 31 角色）挑一个匹配内容的 IP。

### 语言信号（用户的话里出现这些就应激活）

- "角色圣经 / 角色一致性 / 怎么让角色不飘"
- "参考图怎么标边界 / 失败标准"
- "IP 三定律 / 选哪个角色合适"
- "character bible / role consistency / pick a character"

### 与相邻 skill 的区分

- 与 `ip-style-decoupling` 的区别：本 skill 管"她是谁"（身份），ip-style-decoupling 管"这一张怎样被画出来"（渲染）；换风格不重写本 skill 的角色档案。
- 与 `ip-action-library`/`ip-performance-faces` 的区别：本 skill 管静态身份，它们管动态表演（动作/表情）。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **写视觉锚点（分级）**
   - 完成标准：列出高优先级身份特征（脸/年龄感/发型/标志性配饰）与可浮动项（服装范围），用事实不用形容词。

2. **写人格锚点**
   - 完成标准：定气质与行为边界（是否卖萌、面对复杂问题何种态度），约束后续表情幅度。

3. **建参考素材证据边界**
   - 完成标准：每张参考图标明"锁什么"（脸/比例/服装）与"不锁什么"（标题/背景/动作）。

4. **列失败标准**
   - 完成标准：写出禁止漂移方向 + 判定动作（如不符即重生成）。

5. **（如需）从角色库挑选**
   - 完成标准：按内容类型映射 + 用 IP 三定律 B 校验"是否情绪代名词"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单张一次性出图，根本不关心跨图连续性。
- 只想换画风（走 ip-style-decoupling），身份档案不动。
- 只设计动作/表情（走 ip-action-library / ip-performance-faces）。

### 作者在书中警告的失败模式

- **单张参考图漂移**：扔一张照片说"照这个画"，批量必漂——偶然信息太多模型瞎猜。
- **参考图无边界**：文件夹无说明，模型把偶然姿势/标题位置/背景一起复制。
- **无失败标准**："像不像"永远靠当场感觉，漂移无法量化。

### 作者的盲点 / 时代局限

- 身份失败标准靠人工/规则判定，未工程化自动回归（艾笑提回归用例但未落地）。
- 对写实风与极简风的角色圣经详略差异未展开（极简角色锚点更少）。

### 容易混淆的邻近方法论

- 与"换自己形象"操作混淆：本 skill 是身份系统方法论，换脸只是其中一步（且需先有圣经）。
