## 〇、宪章

### 0.1 测量与根

**三个观众端效应**（角色设计的全部验收标准）：

1. **想看他**（魅力）
2. **心疼他**（在乎）
3. **认得出、记得住**（辨识度，与魅力正交——高辨识可以无魅力，反之亦然）

**魅力的根**：有魅力的角色，是彻底地活成了自己的人。观众被他吸引，因为每个普通人都在为合群磨掉一部分自己。"自己"指内核配置，不是表层人格（雷普利的"自己"是伪装天赋与饥饿；斯内普的"自己"藏了一生但从未动摇）。

**构造公式**：魅力 \= 稀缺的内核 × 永不背叛的自洽 × 一眼可感的外化。 三种缺失对应三种失败角色：缺稀缺 \= 路人；缺自洽 \= 抽卡式人设（怪癖堆砌的噪音）；缺可感知 \= 纸面人物（设定集很厉害，片里看不出来）。

**表里关系**（内核与表层的摆法，三态）：

* **一致**：表即是里（阿甘、孙悟空）——魅力直接给
* **压抑**：里藏着，自己清楚（斯内普）；子类**自欺**：连自己都骗（威尔），揭示对象包括他本人，行为层有"越怕什么越攻击什么"的反向过度信号
* **伪装**：明知真相、主动演假的换好处（雷普利）

压抑与伪装型必须标注**揭示节奏**（哪些藏、何时揭）——这是与故事skill的硬接口。表里差越大、藏得越久、代价越高，揭示时爆发越强。

### 0.2 依赖铁律

* 本skill不知道任何项目的存在。项目信息（世界观、画风、受众）一律从输入进来。
* 不假设上下游skill存在。有套件时的标准协作：story-developer 的人物两清单 → 本skill深化 → 角色设定包 → 资产生图skill；概念氛围图prompt → visual-director 注质感。无套件时本skill独立可用（裸想法进，设定包出）。
* 按需取用：用户只要表情表就跳到对应工序；但凡评一个角色好坏，先问功能与定位。

### 0.3 元规则

遇到体系解释不了的公认魅力角色：不打补丁，先问「哪个二元判断是被压扁的轴」，升维。（先例：压抑型角色→表里关系维度。）

### 0.4 输出纪律

结论直说，短句。每个设计决定可追溯——能回答"这个特点对应内核的什么"。回答不出的设计不交付。

### 0.5 概念设计前提（白底纪律 + 画风三层）

**白底纪律（默认前提）**：本skill是概念设计skill，一切产出图都是设计文档——白底（纯白或浅灰中性底）、无环境、无场景。签名道具是角色的一部分，可入图。角色与环境的合成图（首帧、场景中的角色）不归本skill。

**画风三层处理**：

1. 设计逻辑（内核→视觉编码）画风无关，任何画风下成立
2. 视觉参数（头身比可用域/细节密度预算/夸张许可度/五官语法）受画风约束——画风作为输入接收，不自己定
3. 生图渲染必须有画风：项目画风已定 → 穿项目画风出图（设计必须在目标画风里验证）；未定 → 中性设计稿风出验证稿并标注「画风未锁」，画风定稿后做画风落地验证（详见 references/03 第十节）

## 一、三层坐标系（速查版，详见 references/01、02）

| 层       | 刻度                                                         |
| ------- | ---------------------------------------------------------- |
| **内核层** | 渴望（外目标+内需要，可错位）、矛盾、信念（他的逻辑）、缺口、表里关系+揭示节奏；魅力机制×2-3、在乎机制×2-3 |
| **行为层** | 决策模式（压力下怎么选）、语言签名×2-3、动态签名（站姿/步态/手势）、表情域（宽窄+默认表情）          |
| **视觉层** | shape language、头身比与夸张方向、色彩（主/辅/签名色）、服装道具、缺口可视化、**2-3个强签名** |

**贯穿检验**：

* 层间关系服从表里关系设定：一致型三层同向；压抑/伪装型的表层反差是受控设计，但表层每个细节必须服务于"藏"或"演"
* 内核在每一层都留下证据（可感知检验）
* 三测试：**剪影**（涂黑认人）、**溯源**（删掉特点问丢了什么，什么都没丢\=贴纸，删）、**三距**（远读剪影色块，中读形状姿态，近读五官细节）

## 二、生成工序（六步）

### 第0步 输入

接收三样，缺什么问什么：

人物输入：story-developer的人物两清单，或裸想法（角色功能必须有——写不出功能的角色不开工） 定位：形态/受众/这个角色在群像里的位置（主角/反派/配角） 世界设定：服装的时代/职业/阶层规则（有美术设定skill就引用，没有就问） 画风状态：已定（引用影像宪法/look bible，作为视觉参数约束+渲染外衣）/ 未定（走中性设计稿风，画风定稿后补落地验证）

### 第1步 内核定盘

渴望：想要\_*\_（外目标），其实缺\_*\_（内需要），两者关系：一致/错位 矛盾：\_*\_与\_*\_同体，共存的内在解释是\_*\_ 信念：他的决策母规则，一句话（"猜不到但事后合理"的来源） 缺口：\_*\_，它影响行动的方式是\_*\_（不影响行动的缺口\=贴标签，重写） 表里关系：一致/压抑/自欺/伪装；若非一致：藏的是\_*\_，揭示节奏\_\_\_ 魅力机制（选2-3，写落点）： 在乎机制（选2-3，写落点）：

### 第2步 行为层

决策模式（给2-3个典型情境写他的选法）、语言签名×2-3、动态签名（站/走/手势）、表情域（宽窄+默认表情+泄漏点）。 表情域跟表里关系走：压抑型窄域，靠微表情泄漏，一次真笑值一场哭戏。

### 第3步 视觉概念（文字版）

按 references/02 的编码对照表，把内核逐项压进视觉：shape、比例、色彩、服装道具、缺口可视化，最后锁定**2-3个强签名**（一形状一色一道具/习惯，大致如此）。 群像同框时加查：主要角色之间形状互斥、色彩可区分、剪影不混。

### 第4步 概念图 prompt（六种图，模板见 references/03）

出 prompt 前先做两件事——翻译、构建。直接拿第1-3步的设计词填 prompt \= 标签堆砌，生图软件出不来你构思的东西（这是实测最大的坑）。

**4a 设计→画面翻译**：每个设计决策转成画面上看得见的具体物、动作、光。抽象设计词不进 prompt，只进它的视觉证据。

* 「压抑」不写「压抑」，写「肩内收、领扣到喉口、眼神低垂藏着警觉」
* 「矛盾同体」不写，写「孩童的圆脸配一双过于苍老的眼睛」
* 「缺口」不写，写「右腕一道旧烫疤从袖口露出」
* 魅力点要打成画面焦点：这角色最值得看的那点，用动作+光+构图顶成第一眼落点，不埋进标签堆
* 表里关系翻译成光影+姿态：压抑\=藏比露多（硬光只切一部分脸、身体没入暗部、姿态收）

翻译对照表与完整 prompt 范例见 references/03 第十一节。

**4b 画面构建（表现图必走，五件事）**：定妆、概念探索这类表现图，出 prompt 前定五件事，缺一项画面就单薄：

| 必定项   | 定什么                                |
| ----- | ---------------------------------- |
| 光     | 光从哪来、明暗比                           |
| 姿态/瞬间 | 在做什么动作（不是呆站陈列），暗示前一秒后一秒            |
| 焦点    | 第一眼看哪                              |
| 镜头    | 景别+焦段+视角（俯/平/仰）                    |
| 背景    | 白底/中性底怎么处理、有无角色相关氛围元素（衣摆/光尘/投影/溅水） |

这是精简版。要更强的画面表现力（复杂构图、光影叙事、命题级美学），调 visual-director 完整版（9.2阶段一+第四章）。 工程参考图（turnaround/表情表/比例图）不做画面构建——它们要均匀光、标准姿、信息优先。

**4c 六种图**：

| 图              | 用途            | 纪律              |
| -------------- | ------------- | --------------- |
| 概念探索变体         | 同一内核出3-5个视觉方向 | 唯一允许大变体的阶段      |
| 定妆立绘           | 标准像           | 全身，动态签名的标准姿     |
| 三视图 turnaround | 一致性基准         | 正/侧/背，同装同姿      |
| 表情表            | 表情域落地         | 按表情域分配格子，禁止均匀八格 |
| 姿态表            | 动态签名落地        | 站/走/跑/习惯动作      |
| 比例图            | 群像头身比对照       | 多角色同框           |

**白底纪律**：六种图全部白底、无环境（0.5条款）。**两级用途纪律**：参考图（turnaround/表情表/比例图）信息优先——均匀光、标准姿、完整可见，是工程图；表现图（探索/定妆）走 4b 画面构建，允许画风渲染与戏剧光感（visual-director注入），但仍是白底。两种prompt纪律不混用。画风后定的项目，画风定稿后做落地验证（重出定妆+三视图，三查参数）。

### 第5步 测试自审

按 references/04 清单：三测试 → 层间检验 → 对照人物两清单（机制是否真的可感）→ 生图自审（签名逐张在场、抗趋同生效）。

### 第6步 输出角色设定包

角色设定包（\= character bible 种子，交资产生图skill）： - 内核档案（第1步全项） - 行为档案（第2步全项） - 视觉设定（第3步全项） - 签名锁定清单（2-3条，措辞固定——下游每条prompt逐字复制） - 六种设定图 / prompt - 揭示节奏标注（给故事侧与editorial）

## 三、诊断模式（用户拿现成角色来）

1. **先问功能与定位**：这个角色在故事里干什么、什么形态、主角还是配角。没有功能定义不评。
2. **效应检测**：三效应哪个亏——不想看（魅力）/不心疼（在乎）/记不住（辨识度）。
3. **反查三层**：内核有没有料（稀缺？）→ 行为有没有证据（自洽？）→ 视觉有没有编码（可感？）。病灶通常在最早断掉的那层。
4. **表里关系检查**：是设计出的反差，还是真的自洽崩。
5. **输出**：问题按影响排序，每个问题给三件套——在哪层、对应内核什么、怎么修。

常见病症对照表见 references/04。

## 四、生图纪律（速查）

* **落地铁律（最重要）**：最终prompt只写生图软件认得的具象词——外形、动作、光影、材质、画家名、镜头规格。设计语言（内核/机制/表里关系/坐标系）是构思工具，禁止进prompt。出门检查：prompt里出现「矛盾同体」「压抑型」这类词\=没翻译，打回（翻译见第4步4a）。
* 全部白底无环境——本skill只出概念设计文档，带环境的角色图越界
* 画风槽位 {STYLE} 两态填法：项目画风已定填影像宪法措辞；未定填中性设计稿风并标注「画风未锁」。本skill永不自定画风
* 签名锁定项逐张必含、措辞固定
* **抗趋同**：模型会把方脸拉圆、伤疤删掉、年龄减小、比例美型化。对策：锁定项写具体（"左眉一道断疤"不是"有伤疤"）+ 否定指令保护缺口与非常规特征（"保持不对称，不修复不美化"）。这与visual-director的防AI感是两回事：那边防质感趋同，这边防设计被吃掉。

## 六、反模式（永远不做）

1. 没有功能定义就开始设计
2. 贴纸特点——溯源测试不过的设计
3. 签名超载——八个弱特点不如两个强签名
4. 缺口不影响行动——贴标签式伤痕
5. 全员高魅力——配角功能优先
6. 表情表均匀八格
7. 视觉与行为互相背叛（表里关系设计之外的）
8. skill里写死画风
9. 参考图与氛围图的prompt纪律混用
10. 抗趋同缺位——交付的prompt保不住设计
11. 出带环境/场景的角色图——那是资产生图/分镜的领土，本skill只出白底设计文档

## 内核与机制 — 根、表里关系、三层刻度、机制设计版

### 一、根的推导（为什么是"彻底是自己"）

魅力的观众端效应：注意力不自觉回到他身上。五种成熟的魅力手法全部指向同一个根——

| 机制       | 它是"彻底是自己"的哪种形式         |
| -------- | ---------------------- |
| 矛盾同体     | 普通人遇到内在矛盾必须压抑一边，他两边都活着 |
| 某维拉满     | 普通人被生活平均化，他在一个维度放任到极限  |
| 猜不到但事后合理 | 他不按别人的期待走，只按自己的逻辑走     |
| 说做风格化    | 他的自我渗透到说话走路的每个细节       |
| 替观众越界    | 规则压不住他想做的事             |

观众每天为合群磨掉自己，魅力是在角色身上看到被磨掉的那部分。

**三个测试存档**（定义边界用）：

* 雷普利测试：变色龙角色也成立——"自己"指内核配置（伪装天赋+往上爬的饥饿），不是表层人格
* 阿甘测试：纯粹本身就是一个维度的极端；五机制占一条做到极致就够
* 斯内普测试：压抑不削弱"彻底是自己"，反而强化——维持隐藏的代价证明内核的坚定

### 二、表里关系（三态+子类）

划分变量：**骗的对象**。

| 态          | 定义          | 例        | 魅力来源        | 设计要点                          |
| ---------- | ----------- | -------- | ----------- | ----------------------------- |
| 一致         | 表即是里        | 阿甘、孙悟空   | 纯粹与自由，直接给   | 三层全部同向，可感知做到最大                |
| 压抑         | 里藏着，自己清楚    | 斯内普、里昂   | 表里差+维持的代价   | 必须设计泄漏点（微表情、独处行为、签名道具）；揭示节奏标注 |
| └ 自欺（压抑子类） | 连自己都骗       | 威尔（心灵捕手） | 反向过度的张力     | 行为层写"越怕什么越攻击什么"；揭示对象包括他自己     |
| 伪装         | 明知真相，演假的换好处 | 雷普利      | 表演本身+被拆穿的悬置 | 表演的破绽要预埋；观众何时知道真相是故事侧决策       |

**揭示节奏**是与故事skill的硬接口：角色设定包里必须标注"藏什么、何时揭、揭示场的载体"。表里差越大、藏得越久、代价越高，揭示爆发越强（斯内普的"Always"攒了七本书）。

**魅力的时间结构**：即时型（杰克船长，第一场给完）vs 揭示型（斯内普，跟信息释放走）。设计时标明类型，影响概念图的表达策略——揭示型角色的定妆像就该有"读不透"的余地。

### 三、内核层刻度（怎么填）

**渴望**：外目标（他想要的）+ 内需要（他缺的），标注一致还是错位。错位是弧光的引擎（想要尊重，其实缺自我接纳）。检验：具体、有代价。

**矛盾**：选两个真矛盾的特质，写出共存的内在解释。一个就够，最多两个——堆三个以上人物碎掉。

**信念**：他的决策母规则，一句话（"利益面前先算人情""谁碰我的人谁死""万事可谈"）。它让角色"猜不到但事后合理"：意外来自手段，母规则从不漂移。

**缺口**：必须影响行动——决策回避、代偿行为、特定触发点。"他有点自卑"但行为看不出 \= 贴标签，重写。

**机制选配**：从下面两张表各选2-3条，写具体落点。不必全占——阿甘测试：一条做到极致就够。

### 四、魅力五机制（设计版——每条附设计落点）

1. **矛盾同体**：落点写法「***的***」（优雅的食人医生、想当好人的魔丸、好色又仗义的混混）。视觉落点：对立元素同体。
2. **某维拉满**：拉满维度要能持续出戏；无敌配限制（紧箍咒式）。视觉落点：比例夸张方向。
3. **猜不到但事后合理**：信念稳定，手段意外。行为落点：决策模式表里给出"常人选A，他选C，因为母规则"的例。
4. **说做风格化**：2-3个语言/行为签名，全程一致。过密则油。
5. **替观众越界**：越的界必须是观众真实压抑的；越界要付代价（不付代价\=价值观风险，中国市场注意审查）。

### 五、在乎六机制（设计版）

| 机制 | 设计落点                                 | 视觉落点                          |
| -- | ------------------------------------ | ----------------------------- |
| 渴望 | 内核层第一项，一切的地基                         | 签名道具、视线习惯                     |
| 亏欠 | 背景里写"不该受的苦"，剧情里持续付出无回报               | 代价痕迹（旧伤、磨损物）                  |
| 缺口 | 影响行动的伤口                              | 不对称、伤痕、修补过的旧物                 |
| 投入 | 故事侧用时间换；设计侧给"可积累的可见代价"（伤越来越多、物件越来越旧） | 设定图可做阶段版本（损耗递进）               |
| 连带 | 给他一个具体的依赖关系（人/动物/物）                  | 关系物入签名道具（里昂的盆栽）               |
| 代入 | 留空位：弱化个性签名、外貌去特征化                    | 与辨识度天然冲突——代入型角色牺牲辨识换穿戴感，是定位选择 |

**两通道提醒**：把他当别人疼（1-5）做厚人物；把他当自己活（6）做薄人物。先从定位确认走哪条，再设计——方向相反，不能都要。

### 六、行为层刻度

**决策模式**：写2-3个典型情境的选法（钱和义怎么选、强敌当前打不打、被冤枉辩不辩）。每个选法都应该能从信念推出来。

**语言签名**：口头禅、句式习惯、用词癖（敬语/粗口/术语）、沉默习惯。2-3个，全程一致。

**动态签名**：站姿（重心、开放度）、步态、手势习惯、待机小动作。表里关系→姿态开放度：压抑型收，遮蔽多；一致型开。

**表情域**：宽窄+默认表情+泄漏点。压抑型窄域设计：默认面无表情，泄漏靠眼神和手，爆发格只留一个。合家欢主角宽域。表情域是表情表（设定图）的直接输入。

## references/02-visual-encoding

## 视觉编码 — 内核怎么压进外形

核心原则：**视觉特点不是装饰，是内核的可见证据。** 每个特点要能向内核回答"为什么是这个"。回答不出的是贴纸，删掉或换掉。

### 一、内核 → 视觉编码对照表

| 内核元素   | 视觉载体               | 例                              |
| ------ | ------------------ | ------------------------------ |
| 矛盾     | 对立视觉元素同体           | 魔童哪吒：凶相烟熏妆×孩童身形                |
| 缺口     | 不对称、伤痕、修补过的旧物、代价痕迹 | Zuko半脸烧伤——伤口就是弧光起点，画在脸上        |
| 表里关系   | 遮蔽度、表情域宽窄、姿态开放度    | 斯内普：全黑高领长袍+极窄表情域               |
| 拉满的维度  | 比例夸张方向             | 力量型放大肩臂躯干，智力型放大头与眼，速度型拉长四肢收窄躯干 |
| 渴望     | 签名道具、视线习惯          | 里昂的盆栽：杀手随身带需要照顾的植物，温柔有了实体      |
| 信念/纪律感 | 整洁度、对称性、物件的保养状态    | 守序角色衣冠齐整物件如新；混沌角色随性磨损          |
| 出身与世界  | 服装的时代/职业/阶层逻辑      | 服从美术设定skill的世界规则，本skill不越权     |

### 二、shape language（底层字体）

| 形状          | 默认语义      | 用法              |
| ----------- | --------- | --------------- |
| 圆           | 亲和、无害、柔软  | 合家欢主角、治愈系       |
| 方           | 稳定、可靠、固执  | 卡尔（《飞屋》）整个人是个方块 |
| 三角（锐角向上/向外） | 危险、速度、攻击性 | 反派、锋利型角色        |

进阶用法：

* **混合编码矛盾**：圆脸+锐利眼角\=亲和外表下的危险；方身+圆脸\=固执但善良
* **形状即弧光**：角色转变可以做形状过渡设计（早期设定锐利，后期软化）
* **群像靠形状对比**：主角组合的基础形状要互斥（方+圆+三角），关系也用形状讲（《飞屋》卡尔方Russell圆，对比即喜剧）

### 三、头身比与夸张

| 头身比     | 默认语义       |
| ------- | ---------- |
| 2-3头身   | 幼态、萌、吉祥物   |
| 4-5头身   | 少年感、亲和     |
| 6-7头身   | 常规写实       |
| 7.5-8头身 | 英雄感、理想化    |
| 9+头身    | 神性、时尚感、压迫感 |

夸张方向跟拉满维度走（见编码表）。同一画风内，群像的头身比差本身是信息：谁更"神"、谁更"人"。 头身比的可用域由画风决定——画风是输入约束（详见03文件第十节），先问画风状态再定头身比。

### 四、色彩

* **三色结构**：主色（占面积最大，定性格基调）+ 辅色 + **签名色**（小面积高饱和，记忆点，常落在签名道具上）
* **角色间色彩关系**：对抗角色用对比色/互补色，同盟用同系色，群像先排色相环再细化
* **与环境的对比度 \= 视觉权重**：主角对环境的色彩对比度应高于配角（这条要和美术设定skill的场景色彩协调）
* **明度饱和度逻辑**：高饱和\=外放能量，低饱和灰调\=压抑/沧桑。压抑型角色常用"低饱和大面积+一点签名色"——那一点就是泄漏

### 五、服装道具（三层信息）

1. **世界逻辑**：时代、职业、阶层——从美术设定skill接收，不自创
2. **性格泄漏**：怎么穿比穿什么更说明人——纽扣系到顶（紧）vs 敞着（散）、熨帖vs皱、合身vs借来的感觉
3. **签名道具**：一件随身物，承载渴望/缺口/关系（盆栽、怀表、旧照片、断剑）。最好能进剧情，不只是挂件

### 六、缺口可视化

伤痕、不对称、旧物补丁、过早的白发、磨损的护具——**代价的痕迹**。 规则：缺口的视觉呈现要影响读感（看到就想问"他经历了什么"），并与行为层的回避/代偿呼应。 在乎机制·投入的可视化：设定图可做损耗递进版本（同一角色的阶段状态：伤增加、物变旧）。

### 七、表情域设计（表情表的输入）

* 宽窄跟表里关系：一致型宽域（合家欢主角8-12格全开）；压抑型窄域（默认面无表情，4-6格微差，1格泄漏，1格爆发）
* 默认表情\=性格的休息状态，单独设计（多数时间观众看到的是它）
* 泄漏点设计：压抑型靠眼神、手部小动作泄漏，不靠嘴
* 一次真笑值一场哭戏：爆发格留给关键剧情，设定图里也标注"此表情仅用于\_\_\_场景级别"

### 八、动态签名

站姿（重心偏移、开放度）、步态（步幅、节奏）、手势习惯、待机小动作。 表里关系→姿态开放度：压抑型收（抱臂、藏手、侧身），一致外放型开（正面、大开大合）。 姿态表（设定图）按这里的设计出格子。

### 九、群像规则（多角色同框检查）

1. 基础形状互斥：主要角色不共享同一基础形状
2. 色彩可区分：色相环上拉开，缩成豆大也能认
3. **剪影互斥**：全员涂黑站一排，每个都能指认——群像剪影测试
4. 头身比差讲关系：力量差、神性差、辈分差
5. 签名不撞车：道具、习惯动作全组去重

### 十、三测试（交付前必过）

| 测试   | 方法                               | 不过的处理                      |
| ---- | -------------------------------- | -------------------------- |
| 剪影测试 | 涂黑能认出是谁；群像涂黑能区分                  | 改轮廓级特征（发型、体型、服装外形、签名道具入剪影） |
| 溯源测试 | 逐个特点问"删掉丢什么人设信息"                 | 什么都没丢\=贴纸，删或换成有来源的         |
| 三距测试 | 远（剪影+色块）、中（形状比例姿态）、近（五官细节材质）各看一遍 | 哪距失效补哪距；只能看海报的角色\=中远距失效    |

## references/03-sheet-prompts

## 设定图 prompt 模板 — 六种图全套

### 〇、总纪律

1. **白底纪律（默认前提）**：本skill是概念设计skill，六种图全部白底——纯白或浅灰中性底，无环境、无场景、无氛围置景。签名道具是角色的一部分，可入图。角色与环境的合成图（首帧、场景中的角色）不归本skill。
2. **两级用途**：参考图（turnaround/表情表/比例图）信息优先——均匀漫射光、标准姿、完整可见；表现图（概念探索/定妆立绘）允许画风渲染与角色级光感，但仍是白底。两种prompt纪律不混用。
3. **画风两态填槽**：本skill不定画风。{STYLE}槽位按画风状态填——已定：填项目影像宪法/look bible的画风措辞（项目侧或visual-director给）；未定：填中性设计稿风（「清晰勾线，平涂上色，角色设计稿风格」），图侧标注「画风未锁·设计验证稿」，画风定稿后走画风落地验证（第十节）。
4. **签名锁定项逐张必含、措辞固定**：写一次，之后逐字复制，不改写不同义替换。
5. **抗趋同保护**（见第八节）每张参考图必带。

### 一、通用槽位

\[主体]：性别/年龄段 + 体型shape描述 + 头身比（例：五十岁上下的男人，敦实方正体型，5头身） \[签名锁定项]：2-3条，具体到位置与形态（例：左眉一道纵向断疤；深绿色旧围巾绕颈两圈；右手无名指缠着褪色红绳） \[服装道具]：时代/职业逻辑 + 穿法细节（性格泄漏） \[表情/姿态指令]：按图类型给 \[表里关系视觉指令]：姿态开放度、默认表情（例：肩内收，双手习惯藏在袖中，面部默认无表情，眼神警惕） \[排版用途指令]：按图类型给 {STYLE}：留空 \[保护指令]：抗趋同否定项

### 二、概念探索变体

用途：同一内核出3-5个视觉方向供选。唯一允许大变体的阶段——变体改的是视觉方案（形状策略/色彩策略/服装方向），不许改内核。

角色概念设计，\[主体]，\[内核的视觉化方向X：如"方形稳重方案/锐利瘦削方案/圆钝亲和方案"]， \[服装道具方向X]，全身像，自然站姿，\[表里关系视觉指令]， 角色概念探索图，纯白背景，无环境，{STYLE}

要点：每个变体单独成图；选定后立即提取签名锁定项，进入定妆。

### 三、定妆立绘（氛围图）

角色定妆立绘，\[主体]，\[签名锁定项]，\[服装道具]， 全身像，\[动态签名的标准姿：例"重心右倾，左手插袋，下颌微抬"]， \[表里关系视觉指令]，\[默认表情]， 纯白背景，无环境，{STYLE}，\[保护指令]

要点：姿态用角色自己的动态签名，不用通用站姿；揭示型角色的定妆像要留"读不透"的余地（眼神、阴影、半遮蔽）。质感交visual-director注入后再生成。

### 四、三视图 turnaround（参考图）

角色三视图设定图，同一角色的正面、侧面、背面三个全身视图并排， \[主体]，\[签名锁定项]，\[服装道具]， A字自然站姿，中性表情，三视图之间服装发型完全一致， 均匀漫射光，无投影，纯色中性浅灰背景，角色完整可见无裁切，设定图排版， {STYLE}，\[保护指令]

要点：这是下游一致性基准，信息完整压倒美感；签名锁定项必须三个视角都可见或注明所在视角；生成后人工核对三视一致性（AI最易在侧背视图丢签名）。

### 五、表情表（参考图）

角色表情设定表，同一角色头部特写网格排列共\[N]格， \[主体（头部相关项）]，\[签名锁定项（头部相关）]， 表情清单：\[按表情域分配——压抑型示例：默认无表情/轻微皱眉/眼神警惕/嘴角几不可察的讥讽/（泄漏格）目光骤然柔软/（爆发格）彻底崩溃]， 每格表情下标注名称，均匀漫射光，纯白背景，设定表排版， {STYLE}，\[保护指令]

要点：N和清单来自表情域设计，禁止均匀八格；爆发格标注使用场景级别；发型服装每格一致。

### 六、姿态表（参考图）

### 八、抗趋同（保护指令详表）

| 美型化   | 方脸拉圆、棱角磨平 | "保持方正脸型与下颌棱角，不柔化"       |
| 伤疤消失  | 缺口被"治愈"   | "左眉断疤必须存在，保持不对称，不修复不美化" |
| 减龄    | 年龄向25岁回归  | "保持五十岁年龄感：法令纹、眼袋、灰白鬓角"  |
| 比例标准化 | 头身比拉向7-8  | "严格5头身，躯干厚重四肢偏短"        |
| 服装精致化 | 旧衣变新、皱变挺  | "外套肘部磨损起球，领口变形，保持旧物感"   |
| 表情甜美化 | 默认表情上扬    | "默认表情无笑意，嘴角平直"          |
| 体型理想化 | 胖瘦向健美回归   | 写死具体体型词并在保护指令重复一次       |

规则：每张参考图的保护指令至少覆盖该角色全部"非常规特征"（缺口、年龄、体型、旧物）；表现图酌情精简但缺口保护不省。

### 九、与 visual-director 协作流程

本skill出内容prompt（设计信息完整、{STYLE}空槽） → visual-director 注入质感（画风/介质/光，填{STYLE}，按其抗稀释纪律改写） → 生图 → visual-director 审图（质感/AI感）+ 本skill审设计（签名在场/抗趋同生效/三测试） → 双方修正指令合并 → 重生成

分工记住一句话：visual-director管"像不像电影"，本skill管"是不是这个人"。

### 十、画风：参数约束与落地验证

画风三层处理（本skill的立场）：

1. **设计逻辑画风无关**：内核→视觉编码、签名逻辑、表里关系外化，任何画风下成立。
2. **视觉参数受画风约束**——画风作为输入接收，约束四项：头身比可用域、细节密度预算（平涂扛不住写实级服装细节，写实里过简则空）、夸张许可度（形变幅度）、五官语法（眼鼻嘴的风格惯例）。
3. **渲染必须有画风**：不存在无画风的图像。已定→穿项目画风出图（设计必须在目标画风里验证）；未定→中性设计稿风验证稿+标注。

**画风落地验证**（画风后定的项目，画风定稿后必做）：

1. 用目标画风重出定妆立绘 + 三视图
2. 三查：头身比在画风可用域内？细节密度匹配预算？五官语法不冲突？
3. 超界则调视觉参数（不动内核与签名逻辑），更新角色设定包并标注版本

### 十一、设计→画面翻译（出 prompt 前必做）

核心规则：设计决策是构思语言，prompt 是画面语言。每个设计概念翻译成它在画面上看得见的证据，只把证据写进 prompt。设计概念本身（矛盾同体、压抑、缺口）一个字都不进 prompt。

### 翻译对照表

| 设计概念（不进prompt） | 画面证据（进prompt）                    |
| -------------- | -------------------------------- |
| 矛盾同体           | 两个对立特征同框：枯槁的脸+稳定灵巧的手；孩童圆脸+苍老锐利的眼 |
| 某维拉满           | 把那一维做成视觉夸张：智力→高额深眼窝；力量→夸张肩背      |
| 缺口             | 具体的伤或旧物：右腕旧烫疤、缺角的耳、磨破的护腕         |
| 压抑（表里关系）       | 藏比露多：领扣到喉、肩内收、硬光只切半张脸、身体没入暗部     |
| 自欺             | 反向过度：用力的笑、绷直的姿态、躲闪的眼神            |
| 伪装             | 过于完美的表面+一处破绽（袖口磨损、眼神与表情不一致）      |
| 渴望             | 签名道具入手或入视线：攥着旧照片、望向画外            |
| 亏欠/代价          | 代价的痕迹：过早的白发、磨旧的衣物、深眼袋            |
| 信念/决策母规则       | 用一个正在发生的动作体现：神偷手稳\=正夹起齿轮         |

### 完整范例（烂 vs 好）

角色：老钟表匠，藏着年轻时是神偷（压抑型）。设计\=矛盾同体（枯槁脸/灵巧手）、缺口（右腕烫疤）、签名（稳的手、烫疤、扣到喉的旧马甲）。

**烂 prompt**（骨架槽位直填）： 一个老年男人，枯瘦，灵巧的手，右手腕有烫疤，旧马甲扣到顶，警惕的表情，全身像，纯白背景 病：标签堆砌，设计全没翻译，出来是普通老头站着。

**好 prompt**（翻译+画面构建+落地）： 一位约七十岁的枯瘦钟表匠，深陷的眼窝、满脸皱纹，但一双手修长稳定不见颤抖，正用镊子夹起一枚极小的齿轮——枯槁的脸与精准的手是画面焦点；右腕一道陈年烫疤从袖口露出；深褐旧呢马甲，最上一颗扣子扣到喉口，领口磨白。半侧身，肩微内收，眼神低垂专注却藏警觉。单盏台灯从画面左下斜射，硬光在脸上切出明暗，照亮手与齿轮，身体大半没入暗部；中性深褐背景，台灯在桌面投一小片暖光晕。85mm 古典肖像压缩，浅景深，焦点在镊尖。{STYLE：厚涂油画、可见笔触、伦勃朗式暗部透明罩染、皮肤次表面散射}。负面：均匀照明、死白高光、塑料皮肤、对称构图。

拆解：

* 矛盾同体 → 枯槁的脸+稳的手夹齿轮，并设为焦点
* 缺口 → 烫疤从袖口露出
* 压抑 → 扣到喉口、肩内收、眼神藏警觉 + 硬光只切明暗、身体没入暗部
* 画面构建五件事：光（左下单灯硬光）/瞬间（正夹齿轮）/焦点（镊尖）/镜头（85mm浅景深半侧身）/背景（中性底+小光晕）
* 落地：画家名+介质+负面词，无一个设计黑话

此范例可直接抄改。

## references/04-review-checklist

## 自审与诊断清单

自审顺序：内核 → 行为 → 视觉 → 图 → 接口。诊断病灶通常在最早断掉的那层。

### 一、内核层清单

* 功能一句话写得出？（写不出 \= 这个角色不该存在）
* 渴望具体、有代价？外目标与内需要的关系标了（一致/错位）？
* 矛盾有内在解释？数量 ≤2？
* 信念一句话能写出？给三个情境推演，他的选法都能从信念推出来？
* 缺口影响行动？（不影响 \= 贴标签，重写）
* 表里关系定了？非一致型标了揭示节奏（藏什么/何时揭/揭示场载体）？
* 魅力机制 2-3 条有具体落点？在乎机制 2-3 条有具体落点？
* 根测试：一句话回答"他哪里彻底是自己"？

### 二、行为层清单

* 决策模式有 2-3 个情境实例？
* 语言签名 2-3 个，互不重复，全程可保持？
* 动态签名（站/走/手势）与表里关系的开放度一致？
* 表情域宽窄跟表里关系走？默认表情单独设计了？压抑型有泄漏点设计？

### 三、视觉层清单

* 每个视觉特点过溯源测试（删掉丢人设信息）？
* shape、比例夸张方向、色彩三件都能回答"对应内核什么"？
* 签名锁定清单 2-3 条、措辞固定、具体到位置形态？
* 缺口可视化了？（伤痕/不对称/代价痕迹）
* 剪影测试过？三距测试过？
* 群像同框：形状互斥、色彩可区分、剪影互斥、签名不撞车？

### 四、生图自审

* 全部白底无环境？（纯白或浅灰中性底；带环境的角色图越界，砍掉）
* 签名锁定项逐张在场、逐字一致？
* 参考图走信息优先纪律（均匀光/标准姿/完整可见）？表现图才走画风渲染？
* {STYLE} 按画风两态填（已定：影像宪法措辞；未定：中性设计稿风+「画风未锁」标注），没在 skill 侧写死画风？
* 画风后定的项目：画风定稿后做了落地验证（头身比/细节密度/五官语法三查）？
* 保护指令覆盖全部非常规特征（缺口/年龄/体型/旧物）？
* turnaround 三视角核对过签名（侧背视图最易丢）？
* 表情表按表情域分配，没有均匀八格？

### 五、接口自审

* 角色设定包六件齐：内核档案/行为档案/视觉设定/签名锁定清单/设定图prompt/揭示节奏？
* 与故事侧人物两清单对得上（机制落点没漂移）？
* 设计中发现的新可能已标注回流给故事侧？

### 六、常见病症对照表（诊断模式用）

| 症状              | 先查     | 常见病因          | 修法方向                 |
| --------------- | ------ | ------------- | -------------------- |
| 没人想看他（魅力亏）      | 内核层    | 稀缺缺失——配置太常见   | 从五机制补：加矛盾或拉满一维       |
| 人设散、像抽卡         | 内核自洽   | 特质堆砌无母规则      | 砍特质，立信念，矛盾收敛到1-2个    |
| 设定厉害片里看不出（纸面人物） | 行为+视觉层 | 内核没翻译成证据      | 给决策实例、语言签名、视觉编码      |
| 记不住（辨识度亏）       | 视觉层    | 剪影平庸、签名缺失或超载  | 锁2-3强签名，改轮廓级特征       |
| 不心疼             | 在乎机制   | 六机制全空，或全靠口头宣称 | 渴望先补；亏欠/缺口给可见证据      |
| 油、做作            | 行为层    | 签名密度过高，风格化过载  | 砍到2-3个，留白            |
| 反派立不住           | 魅力机制   | 只有功能没有魅力      | 至少补2条魅力；顶级反派加1条在乎    |
| 主角被配角抢戏         | 配比     | 主角配置平庸+配角拉满   | 要么提主角稀缺度，要么降配角（功能优先） |
| 设定图张张不像同一人      | 生图纪律   | 签名措辞漂移、保护指令缺位 | 锁定清单逐字复制+补保护指令       |
| 角色越画越美型、伤疤消失    | 抗趋同    | 模型趋同引力未防      | 按03文件第八节补保护指令        |
| 群像分不清谁是谁        | 群像规则   | 形状/色彩/剪影撞车    | 重排形状与色相分布            |
| 表情表像换头          | 生图纪律   | 头部签名未逐格锁定     | 头部相关签名进每格prompt      |

### 七、设定包交付前最后三问

1. 陌生人看完设定包，能用一句话说出这个角色是谁吗？
2. 涂黑剪影，他在一群角色里能被指认吗？
3. 三个月后量产一百张图，靠签名锁定清单还能保住这个设计吗？
