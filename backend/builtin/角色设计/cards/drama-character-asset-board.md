# 角色资产板

## 何时用

- 要做角色三视图、角色设定图、人物档案或可复用的形象板。
- 同一角色跨图、跨镜出现脸、体型、服装、道具或伤痕不一致。
- 下游生成需要一条可直接复用的外观描述，而不是每次重新解释角色。

只做资产板，不负责整段视频连续性；跨镜后果与首尾帧交接分别交给镜头卡和画面衔接卡。

## 一张板解决什么

优先做一张 16:9 横版复合板，四个区各自承担不同证据：

1. **面部特写**：正侧三分之四角度，平实光，呈现骨相、眉眼、发型和辨识记点。
2. **去头全身板**：正面、侧面、背面，头部裁掉或涂成纯色块，避免模型从低清脸误学身份。
3. **手物比例板**：闭合手部与随身道具同框，给出握持方式、相对尺寸和佩戴侧。
4. **战损生命周期账本**：初始、受损、污损、修复或结局状态，按剧情顺序排列。

背景保持中性，四区使用同一色温和同一比例尺。不要在同一张板里塞场景、剧情动作或大量装饰。

## 六段身份块

资产板旁固定写这六项，后续跨镜只复用这里的事实：

```text
IDENTITY  身份一句话
BODY      年龄感、身高体型、体态与动作习惯
FACE      脸型、五官、肤色、发型、疤痣等辨识记点
ATTIRE    从内到外、从上到下的服装与配饰分层
LAYOUT    四区版面、视角、比例尺与背景
STYLE     写实/动画等介质、镜头质感与色彩范围
```

道具必须说明由谁持有、在哪一侧、尺寸参照什么。伤痕、污渍、裂纹、缺件一旦出现，后续资产板不得无解释复原。

## 跨镜复用短语

把六段压成一条固定短语，每个镜头逐字复用，禁止写“同上”或“保持原样”：

```text
<年龄感>的<身份>，<体型体态>，<五官与辨识记点>，穿<服装分层描述>，<风格与介质>
```

段落可以补充当前动作，但这条外观短语不得改写。需要变化时，只追加剧情导致的状态，例如“左袖新增裂口，右手仍握短刀”。

## 生成提示词骨架

```text
16:9 character asset board, four clearly separated panels:
1) head-and-shoulders three-quarter portrait;
2) headless full-body turnaround, front/side/back;
3) closed hand holding <prop> with scale reference;
4) ordered wear-and-damage states.
<固定外观短语>. Neutral seamless background, consistent scale,
single soft key light, no scene, no extra characters, no captions.
```

## 验收

- 四区是同一角色，骨相、发型、肤色、体型与服装层级一致。
- 全身板头部没有可被误读的低清五官。
- 道具尺寸、握法、佩戴侧在三个视角一致。
- 战损顺序说得清“何时、何因、影响哪一侧”，不是随机脏污。
- 固定短语中没有“年轻漂亮”“高级感”等无法复现的空词。
