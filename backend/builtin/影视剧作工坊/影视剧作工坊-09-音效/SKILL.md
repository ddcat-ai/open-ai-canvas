# 音效（模块 09）

> 主链定位：背景音 / 对白 / 配乐 / 对白与口型（独立一级模块）。

## 做什么

把**声音**当作与画面平等的一等元素来导演，产出可进入提示词的**并行音轨**，而不是给画面配一个背景垫。

四条纪律贯穿本模块：

1. **音频是并行轨道，不是画面附庸**——对白、音效、环境音、BGM 四层**分开描述**，各自点名内容、时机与空间感；混成一团"有氛围的音乐"会让模型随机分配。
2. **音乐不铺满**——场景音乐过满、无源音乐起止随意会让观众疲劳，并削弱画面自身的判断力；**留出安静的时刻让环境声与画面自己说话**。
3. **只在情绪手段做不到的地方才引入音乐**——用音乐去修补、粉饰失败素材是最庸俗也最无效的做法；理想状态是"一两个非常鲜明的音符"。
4. **信赖现实本身的音响**——自然音响（風声、浪涛、发报机、树叶声）优先于专门谱写的配乐；声音不必与画面形象对应，只需与心理效果对应。

## 基础引擎
本模块的底层方法论源：`engine/E09-音效.md`（本模块目录内，20 条，来自 book02/book04）。
执行本模块前先查阅该引擎，取其判断依据、创作准则与反模式清单；引擎为只读源层，本模块负责执行流程。

其中几条对本模块最关键：**主题音乐重复出现 + 分段变奏**（同曲在不同叙事阶段改节奏、唱词与嗓音质地）、**组织音响空间而不是谱写音乐**（作曲家的任务是构造整片的音响总谱）、**用真实声音的变形构造另一个世界**（铁轨撞击声→合成器分解→回声）、**沉默是结构性的**（主动让人物失语，语言缺席本身承担意义）、**剪接点配合重音**（台词不停顿时转换镜头，剪接点落在重音词上）。

## 执行流程

1. **定声音层档位与分工** —— 先声明**输出档位**：
   - **全量档（默认）**：⑧对白 + ⑨背景音 + ⑩BGM 三轨齐全，打开即成品；
   - **去配乐档**：拿掉 ⑩BGM、保留 ⑧⑨，**为后期配乐留出音区**——**⑩ 写 `NO BGM`（规格级），不是省略**（Seedance 2.0 自带音效/配乐，不声明 ≠ 不生成）；该档**不得残留任何音乐类 token**（除 `NO BGM` 本身）。
   再决定这个镜头需要几层，**不存在的层显式写"无"**（无对白 / 无 BGM），而不是省略。
2. **选写法** → `audio/01` / `audio/03`
   短提示词走**内联法**；复杂音频（多层 + 时机）走**专门块法**（视觉内容在前，`Audio:` 块在后分轨罗列）。
3. **写对白** → `audio/01`
   对白要短——每个角色每镜头 1–2 句；**指明情绪语气**（"急切地说""低语""隔着房间喊"）；非英语**指明语言与方言**（`She speaks in Cantonese: "走啦"`）。按语言核词预算（15 秒英语约 16–20 词；超预算就把次要台词转成身体行为——**保留主导权翻转的那句**）。
4. **写环境音与 SFX** → `audio/02`
   环境声元素 **2–3 个封顶**；描述空间的声学而不只是元素清单；需要冲击时用"声音—寂静"的落差。音效记法 `事件@秒`。
5. **写 BGM** → `audio/03`
   描述**配器 + 速度 + 情绪**，不给流派标签；点名音乐**进出时机**；明确压制音乐时写 **`NO BGM`**（规格级），不要只写 `no music`（偏好级）。卡点类内容写"剪切卡在强拍上""运动在 drop 处达到峰值"。
6. **过口型同步** → `audio/04`
   对白片段**保持 3–8 秒**（准确率最佳区间）、用中近景或更近取景、**每镜只有一张说话的脸**、机位锁 `locked-off static camera` 或 `slow Dolly In`；**头部/面部运动 token 与对白不能同镜**。多于一个角色要说话时走变通办法，不在一条提示里硬塞。
7. **防覆盖** —— 上传音频被生成式音频引擎覆盖时，加**时间戳锚定**（"音频 @Audio1 从 0 秒到结尾严格按上传内容播放"）并**删掉所有环境音/音效/音乐 token**。
8. **交下游** —— 音频纪律的最终校验（口型不同步、BGM 压过对白、填充嘟囔）归 **13 交付文件审核**（`review/13-失败诊断.md` §三音频两症、§4.7 填充嘟囔）；L 切/J 切用声音桥磁化接缝归 **10**（`editing/05-剪辑与连续性词汇.md`）。

## 硬规则速记

- **声音层输出档位默认「全量」**（⑧对白 + ⑨背景音 + ⑩BGM）；可切「**去配乐**」档给后期配乐让路——此时 ⑩ 写 `NO BGM`，**不是省略**。
- **四层分开写**（对白 / 音效 / 环境音 / BGM），不存在的层显式写"无"。
- **环境声元素 2–3 个封顶**——再多就浑浊。
- **BGM 描述配器 · 速度 · 情绪**，不给流派标签。
- **`NO BGM` 是规格，`no music` 只是偏好**。
- **对白片段 3–8 秒**、中近景以上、**一镜一张说话的脸**、机位锁定或慢推。
- **头部/面部运动 token 不与对白同镜**。
- **上传音频被覆盖**时：时间戳锚定 + 删除所有环境音/音效/音乐 token。
- **音乐不铺满**——留出安静让环境声与画面自己说话；只在情绪手段做不到处引入音乐。
- **剪接点配合重音**——台词不停顿时转换镜头，剪接点落在重音词上。
