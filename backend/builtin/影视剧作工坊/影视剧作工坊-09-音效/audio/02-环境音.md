## The Four Audio Layers（四层音频）

每条具备音频能力的提示词都应考虑四层。并非每条提示都需要四层俱全，但明确该纳入哪几层，能给模型清晰的方向。

### 1. Dialogue（对白）——角色说什么

对白放进引号。明确谁在说话、语气如何、说什么语言。

```
她说："我们得走了。现在。"
他低语："还不到时候。"
```

**最佳实践：**
- 对白要短——每个角色每个镜头 1-2 句
- 指明情绪语气："急切地说"、"低语"、"隔着房间喊"
- 非英语：指明语言和方言 → `She speaks in Cantonese: "走啦"`
- Seedance 1.5 Pro：支持英语、中文（含四川话、粤语、台湾国语、上海话）、日语、韩语、西班牙语、印尼语

### 3. Ambient（环境声）——背景声景

设定声学环境。这是持续铺底的声床。

```
Ambient: 安静咖啡馆的低语声，意式咖啡机，雨打窗面。
Ambient: 夜晚的森林——蟋蟀，远处的猫头鹰，风轻拂树叶。
Ambient: 繁忙的十字路口——车流，喇叭声，远处的施工。
```

**最佳实践：**
- 环境声元素最多 2-3 个——再多就浑浊
- 描述*空间*的声学："混响明显的教堂大厅"、"局促的车内"
- 用声音与寂静的对比制造冲击："死寂。然后——一声脚步。"

## 音频提示词结构

把音频提示自然地织进提示词里，或在结尾设一个专门块。

### 内联法（短提示词首选）：

```
一个女人走进安静的图书馆。高跟鞋敲在大理石地面上——每一步都在回响。
她低声问图书管理员："你们有《书信全集》吗？"
远处有翻页声。楼上某处一只钟在滴答。
```

### 专门块法（复杂音频更适用）：

```
[场景描述——视觉内容、动作、镜头]

Audio:
  Dialogue: 她说 "我们黎明出发。" 他回答："我会准备好。"
  SFX: 咖啡杯放下，椅子向后刮响
  Ambient: 清晨的厨房——窗外鸟鸣，水壶刚烧开
  BGM: 无——寂静强化紧张感
```

---

### Veo 3 / 3.1
- 英语对白与环境声的原生音频表现强劲
- 对白放进引号：`"就是这里了，"他低声说。`
- SFX 写明：`轮胎刺耳地尖叫`
- 环境声以环境声景描述的方式给出

### Grok Imagine Video
- 自 Video Imagine 1.0（2026 年 2 月）起音频已改进
- 把音频意图直接写进提示词——与其他模型相同的内联风格
- 最适用于：音频只是加分而非主角的社交短片

---

### 音频作为提示元素（SCELA）

在提示词里始终把音频写成**独立的章节**。生成引擎处理三条并行的音频轨：

1. **BGM**——背景音乐、配乐
2. **Ambient SFX**——环境声、拟音
3. **Dialogue**——角色说话、旁白

```
一位厨师在木质砧板上快速切菜。
Camera: 紧凑特写，跟随刀具。
Style: 暖色厨房灯光，浅景深。

Audio: 富有节奏的剁切声落在木头上，近旁锅里油滋滋作响，
陶瓷碗轻轻磕碰。轻柔的原声吉他 BGM。
```

【配套规则·散在其他文件】

◆ HELL-GRIND（环境音混音）
· 写混音：人声干净贴麦、环境音垫底、说话时环境音下潜
· 附带轨锁定：附加轨是唯一完整音源，禁止额外生成
  room tone/foley/ambience

◆ higgsfield-style（风格配方里的环境音契约）
· 实拍史诗：画内音；慢动作段声音落成闷沉真空感+心跳
· VFX 合成：在保留的房间底噪（room tone）之上叠加新元素画内音
· 产品广告：无音乐/旁白/文字——只有产品操作相关音效
· 怪兽片：仅画内音——低频轰鸣、咆哮、爆水、次声轰响

◆ Seedance 2.0 仅剧情内声（Diegetic-only）惯例
· prompt 正文只写场景内物理存在的声音（对白+音效+环境），
  配乐留后期——环境音属"剧情内声"，照写
