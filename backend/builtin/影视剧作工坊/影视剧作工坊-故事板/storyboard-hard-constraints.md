## 三、好莱坞影视故事板底层工业标准（全局通用硬约束）

### 3.1 三层叙事体系（画面结构强制分层）⭐

所有CG故事板分镜必须遵循好莱坞电影 Previs 预演全流程规范，画面结构分为三层：

| 层级 | 名称 | 内容 |
|------|------|------|
| **第一层** | 叙事核心层 | 人物表情、眼神、微动作、对白神态 |
| **第二层** | 空间关系层 | 人物站位、肢体语言、双人互动、场景位置 |
| **第三层** | 氛围光影层 | 光影明暗、色调情绪、景深虚实、环境氛围 |

> 三层结构**层层递进、互相支撑、缺一不可**，保证每帧画面叙事饱满、情绪精准、视觉高级。

**与⑥库法则八的关系**：⑥库「三层纵深」指**空间**三层（前景遮挡/中景主体/背景环境）；本库三层指**叙事**三层（叙事核心/空间关系/氛围光影）。两者**同时强制**，一帧画面需满足双三层。

### 3.2 轴线系统硬约束（绝对禁止跳轴错误）

**双人场景**：
- 双人对话、双人对峙、双人互动场景**永久锁定180度叙事轴线**
- 所有机位严格限制在**轴线单侧**
- **禁止**：跨轴、跳轴、反轴、乱轴
- 人物视线方向、身体朝向、肩膀角度、头部转向**必须完全统一**
- 镜头切换后人物**左右方位绝对不变**，保证观众空间认知绝对连贯

**多人场景**：
- 采用好莱坞**环形机位叙事体系**
- 机位围绕叙事核心人物匀速环绕
- 无突兀跳转、无空间错乱、无站位颠倒

**空间连续性**：
- 所有镜头切换严格遵循空间连续性
- 场景结构、建筑方位、道具位置、光线方向、阴影角度**全程统一**
- 杜绝AI常见的「换镜头即换场景、换机位即换光影」低级bug

### 3.3 景别递进节奏硬约束（好莱坞叙事节奏固化）

**五段景别功能**：

| 景别段 | 功能 |
|--------|------|
| 铺垫景别 | 全景铺垫空间 |
| 叙事景别 | 中景交代动作 |
| 情绪景别 | 近景传递情绪 |
| 爆发景别 | 特写强化细节 |
| 收尾景别 | 极特写锁定伏笔 |

**切换铁律**：
- 镜头切换必须遵循**平滑递进逻辑**
- **禁止**无逻辑大幅度跳切
- **禁止**全景直接切极特写
- **禁止**特写直接切全景
- **禁止**景别混乱无序

> v1.1.3 改定：级差≤1 旧法则四废除，统一按 10 editing/16 模式B 隔级切判（同主体级差=0/1 须豁免，≥2 合法；级序：EWS-WS-FS-MS-MCU-CU-ECU，INS不计级）。

**剧情类型对应节奏**：

| 剧情类型 | 节奏方案 |
|---------|---------|
| 常规职场写实剧情 | **慢递进、稳构图、长停留、微运动** |
| 冲突/情绪波动/对峙剧情 | **快递进、强对比、紧构图、精准卡点** |

> 所有镜头节奏贴合人物台词语速、情绪起伏、剧情张力，做到**画面与叙事完全同频**。

### 3.4 构图法则硬约束（好莱坞黄金构图永久固化）

**五大标准构图体系**（强制采用）：
1. 电影级三分构图
2. 中心构图
3. 引导线构图
4. 框架式构图
5. 纵深透视构图

**主体位置**：
- 人物主体**永远置于视觉黄金点位**
- **杜绝**：居中呆板构图、边缘挤压构图、画面空洞失衡、主体偏移杂乱

**办公室场景天然引导线**（严格利用）：
- 玻璃幕墙
- 吊顶线条
- 地面分割
- 立柱线条
- 桌椅透视

→ 强化画面纵深感、空间感、电影感

**留白美学**：
- 画面留白**克制高级**，符合院线电影极简美学
- 不堆砌道具、不填充杂乱细节、不抢夺人物主体视觉重心

**构图三绝对**：绝对平衡、绝对稳定、绝对高级

**审美定位**：适配成人向写实影视审美，**拒绝低幼、杂乱、网红、短视频廉价构图**

### 3.5 透视与空间硬约束

**透视规律**：
- 严格遵循真实人眼透视规律
- **单点透视、两点透视精准标准**
- **无**拉伸透视、扭曲透视、夸张广角畸变、近距离透视崩坏

**建筑线条**：
- 建筑墙体、地面、吊顶、幕墙线条透视**绝对收敛、绝对平行、绝对规整**
- 保证场景空间严谨可信

**画面纵深三层**：

| 层 | 处理 |
|----|------|
| 前景 | 虚化铺垫 |
| 中景 | 聚焦主体 |
| 背景 | 虚化烘托 |

> 三层层次清晰分明，空间立体感极致强烈。

- [ ] 每帧是否含**第二层空间关系**（站位/肢体语言/双人互动/场景位置）？
- [ ] 每帧是否含**第三层氛围光影**（明暗/色调情绪/景深虚实/环境氛围）？
- [ ] 每帧是否有明确的六个明确（叙事目的/人物情绪/空间关系/镜头衔接/画面重心/视觉引导线）？
- [ ] 是否做到四零（零废帧/零空镜/零无效构图/零随机画面）？

### 12.4 轴线与空间连续性自检

- [ ] 双人场景是否锁定180度叙事轴线，机位全在轴线单侧？
- [ ] 是否**无**跨轴/跳轴/反轴/乱轴？
- [ ] 人物视线方向、身体朝向、肩膀角度、头部转向是否完全统一？
- [ ] 镜头切换后人物左右方位是否**绝对不变**？
- [ ] 多人场景是否采用环形机位叙事体系？
- [ ] 场景结构、建筑方位、道具位置、光线方向、阴影角度是否全程统一？

### 12.5 景别与构图自检

- [ ] 每帧是否精准匹配**单一标准景别**（六大景别之一，无自定义模糊景别）？
- [ ] 景别切换是否平滑递进（无全景直接切极特写、无特写直接切全景）？
- [ ] 节奏是否匹配剧情类型（常规=慢递进稳构图长停留微运动 / 冲突=快递进强对比紧构图精准卡点）？
- [ ] 是否采用五大标准构图体系之一？
- [ ] 人物主体是否置于**视觉黄金点位**（无居中呆板/边缘挤压/空洞失衡/主体偏移）？
- [ ] 是否利用了场景天然引导线（幕墙/吊顶/地面分割/立柱/桌椅透视）？
- [ ] 留白是否克制高级（无堆砌道具/填充杂乱细节/抢夺人物重心）？
- [ ] 透视是否为标准单点/两点透视（无拉伸/扭曲/夸张广角畸变/近距离崩坏）？
- [ ] 建筑线条是否绝对收敛、平行、规整？
- [ ] 画面纵深是否分前景虚化铺垫/中景聚焦主体/背景虚化烘托三层？

### 12.6 机位与光学自检

- [ ] 机位是否为五大专业机位之一（平视/微仰3-5°/微俯3-5°/侧45°/正侧）？
- [ ] 仰俯角是否严格控制在 **3°-5°**（无夸张、不中二、不浮夸）？
- [ ] 焦距是否匹配景别（全景/中全景24-28mm / 中景/中近景35mm / 特写/极特写50-85mm）？
- [ ] 是否为电影级浅景深，焦点精准锁定人物眼睛与面部？
- [ ] 虚化是否自然丝滑（无AI虚假模糊/焦外噪点/边缘错乱）？
- [ ] 是否**无**大景深全清晰死板画面、**无**过度虚化丢失细节？
- [ ] 快门角度是否为 **180°** 电影标准？
- [ ] 动态模糊是否物理真实、贴合运动轨迹（无虚假/涂抹模糊）？

### 12.7 运镜自检

- [ ] 运镜是否稳、慢、丝滑、克制、叙事优先？
- [ ] 是否**无**快速抖动/急促推拉/不规则晃动/大幅度甩镜/无逻辑环绕/卡顿/变速突兀？

- [ ] 情绪流动剧情是否用微环绕运镜？

### 12.8 光影自检

- [ ] 是否统一三点式电影布光（主光45°侧前方/补光35%亮度/侧后方轮廓光）？
- [ ] 是否做到四统一（色温/光源方向/阴影角度/明暗逻辑）？
- [ ] 镜头切换是否**无**光影跳变、**无**色调偏移、**无**明暗错乱？
- [ ] 光影是否贴合人物面部骨骼、肢体结构、场景空间结构？
- [ ] 是否**无**虚假光影、AI补光、错乱明暗？

### 12.9 负面词过滤自检

- [ ] 是否过滤了§十全局负面词全部34项？
