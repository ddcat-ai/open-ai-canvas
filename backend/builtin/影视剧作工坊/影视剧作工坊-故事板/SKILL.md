# 故事板（链外技能）

> **本技能不参与 13 级导演主链，不由总路由自动分派。**只有用户明确要分镜故事板（直接要，或主链跑完后追加）时才调用。
> 主链定位：**07 分镜头设计的下游独立产出线** —— 把已经谈定的镜头落成「九格黑白故事板 + 分镜表 + 分镜头图片 + Reel 时间轴 + 配音台本」的**交付档**，直投生图，产出后不回链。

## 两种触发时机

本技能**不由总路由自动分派**，只在以下两种情形被调用：

| 时机 | 用户说什么 | 前置输入 |
|------|-----------|----------|
| **① 直接触发** | 输入提示词 + "出分镜故事板 / 九格故事板 / 故事板分镜 / Previs 预演" | 用户的提示词本身；不足时按下面的顺序问齐（人物 / 场景 / 剧情节拍） |
| **② 主链后追加** | 导演主链已跑完（通常到 07 分镜头设计，或整链走完），再说"生成交付文件的分镜故事板" | 主链产出的镜头链、资产锚定段、全局风格前缀 |

两种时机的**产出完全相同**：一份交付档（九格黑白故事板 + 分镜表 + 分镜头图片 + Reel 时间轴 + 配音台本 + 本段资产清单），见 `templates/delivery-B-故事板分镜.md`。

**默认行为**：用户不提故事板时，主链不会调用本技能——**默认走导演主链路**。

## 为什么在链外

主链（01–13）是一条**决策与语言转换链**：它决定镜头怎么拍、技术词怎么变成画面语言。故事板不是决策，是**画面预演产物**——它是主链某个时刻的一次性输出格式，不参与后续任何一级的判定：

- 它**不进** 12 的技术语言转换（九格故事板是直投生图的独立前置，不走 UE5/Arnold → 画面语言那条路）。
- 它**不经过** 13 的交付审核链（它本身就是一种交付档）。
- 主链**不消费**它的产出——生图之后返回的是图片，图片再回到 06/08/12 的常规流程。

因此它放在与 `影视剧作工坊-路由`、`影视剧作工坊-引擎` 同级的**链外技能**位，而不是塞进 07。

## 九格结构速览

```
┌─────┬─────┬─────┐
│ 1 起 │ 2 起 │ 3 承 │   1 远景定场  2 人物入场  3 细节伏笔
├─────┼─────┼─────┤
│ 4 承 │ 5 转 │ 6 转 │   4 转折触发  5 中心高潮  6 准备动作
├─────┼─────┼─────┤
│ 7 合 │ 8 合 │ 9 合 │   7 动态爆发  8 外部介入  9 静止定格
└─────┴─────┴─────┘
```

情绪曲线：`静 → 引入 → 暗示 → 紧张 → 冲击 → 决心 → 爆发 → 绝境 → 静止（留白）`。
逐格焦距：`20 / 28 / 100 / 35 / 35 / 85 / 32 / 24 / 50 mm`；景深递进本身构成节奏呼吸。

## 最重要的一条：色彩边界铁律

> **全技能包所有产出物中，只有「故事板 / 9格分镜故事版 / Previs 预演画面」采用黑白，其余一切产出物必须为彩色。**

- 锁定值：**纯黑白单色阶、0 饱和度、无任何杂色**、电影级灰阶对比。
- 故事板阶段**只提取**：明暗光影逻辑、环境空间结构、构图与视觉重心、人物姿态、景别机位、叙事节奏与情绪曲线。
- 故事板阶段**丢弃**：色彩信息、材质色、橱窗文字、肤色、色温冷暖。
- **色彩在资产生成阶段必须全部恢复**——禁止把黑白灰阶当最终成片色调，也禁止因故事板是黑白而省略色彩方案设计。

## 双渲染分支

故事板适配 **UE5（实时·Lumen+Nanite）** 与 **Arnold 7.3（离线·路径追踪）** 双管线，**镜头语言完全统一，仅渲染质感严格互斥、永不杂交**：

| 维度 | UE5 分支 | Arnold 分支 |
|------|----------|-------------|
| 黑白稿表现 | 硬边清晰、明暗对比紧致、灰阶分明 | 明暗过渡丝滑、软阴影层次丰富、灰阶柔和细腻 |
| 彩色阶段 | 几何锐利、皮肤高清毛孔、色调清冷 | SSS 通透温润、胶片颗粒、ACES 电影高级灰 |

黑白阶段的分支差异**只体现为灰阶层次与明暗过渡方式**；色彩与材质差异留到彩色资产阶段。

## 取用顺序

生成 9 格故事板时：

1. **先定渲染分支**（UE5 / Arnold，全剧锁定）→ `storyboard-hard-constraints.md` §一 §八
2. **选叙事变体** → `storyboard-template-9grid.md` §五（悬疑惊悚 / 情感爆发 / 战斗对决 / 都市日常）
3. **逐格填参数**（景别 + 机位 + 焦距 + 构图 + 光影）→ 9格模板 §二 §六 + 硬约束 §四 §五 §六
4. **过黑白色彩标准** → 硬约束 §二
5. **过全局负面词** → 硬约束 §十
6. **跑自检清单** → 硬约束 §十二 + 9格模板 §八
7. **按模板人工组织 Markdown 交付**（以 `storyboard-schema.md` 为结构依据）；本地 Python 渲染器仅供下载包用户选用。人工核对字段后再交付，不得声称 Agent 运行过渲染或校验脚本。
