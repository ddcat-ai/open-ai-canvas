# 运镜设计（模块 08）

> 主链定位：意图→镜头参数映射 / 镜头契约与运镜物理。

## 做什么

把**叙事意图**翻译成**镜头运动参数**，并落成生成层可识别的英文预设名。

- 06 管"画面里有什么、怎么摆、怎么打光"，本模块管"镜头怎么动"。
- 07 管"用几个镜、每镜讲什么"，本模块管"每镜的运动形式与参数"。

## 核心原则（五条运镜规则）

1. **一个镜头一个主运动**（单动规则）—— 叠加多个运镜是抖动、意外旋转与生成失败的头号原因；需要多个动作就拆成多个镜头，或写成带时序的先后阶段。
2. **运动必须可测量** —— 总行程、时长、速度都给单位（"在整整 7 秒里只后拉 10–15 厘米"）；"快"这类形容词是劣化最严重的提示词之一。
3. **运动由情绪驱动** —— 镜头是焦点人物的情绪替身；移动方式、焦段与时长都应当由角色的情绪状态决定，而不是由抽象的"有电影感"决定。
4. **组合必须兼容** —— 推近与拉远、上升与下降不能同镜出现；多段运动写成"0–3 秒上升，停住，然后 4–8 秒推近"的离散阶段。
5. **复杂运动优先克隆** —— 从视频参考迁移镜头运动，绕开文字解释的失真。

**术语约定**：静帧里的运动是**暗示**（动态模糊、暗示运动的构图、运动中途凝固）；视频里的运动是**指令**。`[img 1]` / `@Image1` 指第一张参考图；`@Video1` 指第一段视频参考。

## 执行流程

1. **接意图** —— 从 07 拿到"这一镜承载什么信息 + 情绪节奏"，从 06 拿到景别与角度。
2. **定运动形式** → `moves/01-运镜词汇总表.md`
   按叙事功能选类别（推 / 拉 / 升降 / 环绕 / 变焦 / 跟随 / 穿越 / 特效…）；静帧则查 `moves/02` 的运动暗示写法。
3. **立镜头契约 + 过运动语言五支柱** → `moves/04-运动语言五支柱.md`
   **先写摄影机行为，再写主体**——摄影机行为留白时模型会退回训练先验；从三条契约里选一条（零运动固定 / 仅缓慢推近 10% / 单一手持漂移），并配正向锁定 + 镜像排除。
   再把运动**分四层点名**（主体 / 内部 / 摄影机 / 环境），给运动**挑一个物理锚**（"像悬浮在蜂蜜中的尘埃""每秒 6 度"）而不是"慢/快"，并按需要指定**运动质感**；有景深事件时写成**镜头行为序列**（触发 → 转移 → 状态 → 回归 → 重复）。
4. **过情绪同步** → `moves/05-情绪同步与题材预设.md`
   镜头是焦点人物的**情绪替身**——移动方式、焦段、时长由角色情绪状态决定，不由"有电影感"决定；再按题材取预设。笼统情绪词先分解为具名类型（愤怒/平静/悲伤/震惊…），可查表末的摄影 × 表演速查对照。
5. **写法合规** → `moves/03-运镜纪律.md`
   **一镜一主运动**（单动规则）；运动必须给单位（"7 秒里后拉 10–15 厘米"），禁用"快"这类形容词；多段运动写成离散阶段；并检查"所写的移动能否产生所写的结尾取景"。
6. **查预设名** → `moves/09-镜头运动预设库.md`
   选定类别后查对应的**英文预设名与提示词短语**——这是"进生成层时写成哪个名字"的唯一依据。需现成短语另查 `moves/06-可靠短语库.md`。
7. **校验组合合法性** —— 按预设库的 CM 规则检查组合是否冲突（如变焦 + 推轨同时使用的约束）；**复杂运动优先克隆**——查 `moves/07` 从视频参考迁移。
8. **对齐摄影机基线** —— 焦距、Filmback、传感器尺寸与 06 的焦距库（`shotlang/06-焦距库.md`）保持一致；虚实混合生产时按 CL-6 / CL-7 对齐摄影机基线。
9. **查失败图谱**（出问题时）→ `moves/08-运动失败图谱.md`
10. **交下游** —— 运动描述须经 12 技术语言转换净化后才进入最终提示词。

## 硬规则速记

- **一镜一主运动**——叠加多运镜是抖动与生成失败头号原因。
- **运动必须可测量**——总行程 / 时长 / 速度给单位，禁"快"这类形容词。
- **运动由情绪驱动**——镜头是焦点人物的情绪替身，不由"有电影感"决定。
- **组合必须兼容**——推近与拉远、上升与下降不同镜；多段写离散阶段。
- **复杂运动优先克隆**——从视频参考迁移，绕开文字失真。
- **先写镜头契约再写主体**——摄影机行为留白 = 交给训练先验，必配双向约束（正向锁定 + 镜像排除）。
- **运动分层点名**（主体 / 内部 / 摄影机 / 环境）+ **物理锚替形容词**——禁"慢/快"，用"像…"/"每秒 6 度"；质感（性格）与物理锚（速度）是两条轴。
- 英文预设名查 `moves/09`，不自行编造；组合须过 CM 合法性校验。
- 焦距与 Filmback 与 06 焦距库保持一致（35mm 全画幅基准）。
- 跨片段续接时必须交代镜头运动的当前相位。
