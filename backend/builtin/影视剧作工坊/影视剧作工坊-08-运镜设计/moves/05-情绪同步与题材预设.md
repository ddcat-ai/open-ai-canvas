# 六、镜头-情绪同步

**镜头是焦点人物的情绪替身。**移动方式、焦段选择与镜头时长，都应当由角色的情绪状态决定。情绪与运动错位是 AI 视频最显眼的破绽之一：平静的场景配上抖动不停的手持镜头，即便其他一切都没问题，读起来也是错的；愤怒的场景配上平滑的推轨，即便动作本身正确，读起来也是疏离的。

| 焦点人物情绪 | 镜头处方 |
|---|---|
| 愤怒 / 暴怒 / 紧张 / 紧绷不安 | 手持呼吸感，抖动且不稳定——呼吸节奏破碎，两个轴向上都有可见的微颤，幅度小，节奏不规律。避免稳定器。 |
| 平静 / 自控 / 自信 | 手持呼吸感，平滑——呼吸频率稳定，微幅规律。稳定器用得轻，但依然有生命感。 |
| 悲伤 / 脆弱 | 手持、缓慢、低机位——呼吸频率更低，镜头略微向下漂移，摄影师手上的分量感觉更重。 |
| 震惊 / 顿悟 | 固定机位 + 极缓慢的推近（push-in）或拉远（pull-out）——在揭示的瞬间干脆地定格，之后 0.5–2 秒内只有极小的移动。 |
| 动作 | 60fps、180° 快门——干净的运动，带有快门约束下的运动模糊；避免更长快门的拖长式运动模糊。 |
| 终拍 / 定论时刻 | 顶拍定格 0.3–0.5 秒——正上方直拍，时间停止，所有位置锁定。 |
| 情绪崩溃 / 角色需要空间 | 从中景/特写缓慢拉远到远景——"让角色一个人待着"。把镜头拉远给观众一段视觉距离，读起来是情绪空间，而不是抛弃。 |

**单个镜头内的情绪弧线。**当焦点人物的情绪在一个连续镜头内*发生改变*（同一镜头里从暴怒 → 克制），镜头应当同步改变，并把弧线写成命名的阶段：

- **开场阶段**：为入场情绪指定镜头
- **过渡阶段**：描述镜头性格如何转变（手持幅度减小、漂移稳定下来、推近放慢）
- **收束阶段**：为离场情绪指定镜头

镜头跟着演员走，而不是按自己的钟点走。

**选定镜头之前，先分解情绪。**上表以*具名*情绪（愤怒、平静、悲伤、震惊）为依据。拿到笼统的情绪词（"惊讶""紧张"）时，第一步是把它分解成某个具体的具名类型——"是哪一种 X？"
**速查对照（摄影 × 表演）：**领悟 = 缓慢推轨推近，双眼睁大 · 恐惧 = 荷兰角，手持 · 力量 = 摇臂上升，360 环绕，宽站姿 · 脆弱 = 俯拍，推轨拉远，画面中显得渺小 · 亲密 = 推轨推近，浅景深 · 混乱 = 第一人称无人机，手持，快速剪辑。

# 七、按题材的运镜预设

| 题材 | 主镜头 | 次选 | 避免 |
|-------|---------------|-----------|-------|
| 产品 / 电商 | 环绕、缓慢推近、固定机位 | 摇臂下降揭示 | 手持、甩摇 |
| 生活方式 / 社交 | 手持、固定机位、缓慢横摇 | 推轨随行 | 荷兰角、急推变焦 |
| 剧情 / 叙事 | 缓慢推近、推轨拉远、跟拍 | 摇臂上升 | 快速动作、快甩变焦 |
| 音乐录影带 | 甩摇、快甩变焦、快速跟拍 | 360 环绕 | 固定机位（太沉闷） |
| 恐怖 | 缓慢潜近（推轨推近）、固定保持、荷兰角 | 摇臂下降 | 快速跟拍（破坏张力） |
| 动作 / 追逐 | 第一人称无人机、跟拍、手持奔跑 | 急推变焦 | 固定机位、缓慢环绕 |
| 风景 / 旅行 | 摇臂上升、缓慢横摇、无人机飞越 | 推轨拉远揭示 | 手持、紧凑景别 |
| 喜剧 / 社交 | 固定机位（冷面）、快甩变焦 | 甩摇 | 缓慢的戏剧性动作 |
