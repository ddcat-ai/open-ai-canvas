# 九、经视频参考迁移运镜

## 9.1 镜头迁移

实现复杂镜头运动最稳妥的办法，是从参考中克隆它：

```
匹配 @Video1（视频参考1）的镜头运动。一位舞者在日落时分的屋顶上起舞。
```

这绕开了单动规则——模型直接从参考中提取镜头数据，而不是去解释文字指令。

## 9.2 双视频参考

动作参考与镜头参考可以来自不同的视频，要把两者的职责分开：

```
@Video1（视频参考1）用于角色的动作与编排。
@Video2（视频参考2）仅用于镜头运动。
一位武者在道场里表演一记回旋踢。
```

## 9.3 智能模式（Smart Mode）

"智能"镜头控制把镜头规划委托给模型：模型根据题材与场景描述自动规划镜头语言。此时描述**感受**或**题材**，而不是具体的镜头动作：

```
题材：剧情。一个女人独自坐在咖啡馆桌旁，心不在焉地搅动着咖啡。
她透过窗子注意到某个人，表情从悲伤转为惊讶。
```

（不需要任何镜头指令——智能模式自行选择符合题材的镜头处理。需要逐场景控制时，切换到多镜头自定义模式覆盖。）

## 9.4 视频参考的能力边界

**能可靠读取**：世界设计（环境、布景、灯光逻辑、色彩基调、氛围）· 材质与质感 · 物理与运动风格（物体如何移动、动作的分量与能量）· 镜头性格（运镜的整体感觉、与主体的距离、运动语汇）· 制作质量水准 · 调色 · 天气与环境条件。

**读取得不可靠**：逐帧精确的动作衔接（参考理解的是能量与世界，不是精确的最终位置）· 精确的角色身份（锁身份用图片参考）· 具体台词或音频（声音特质可延续，精确表现无保证）。

**完全做不到**：从最后一帧继续某个具体动作（开场动作要从零写起）· 覆盖你的提示词 · 单独提供角色身份。

**按用途写明参考职责**（告诉模型参考的哪个维度是重点，让提示词其余部分驱动新内容）：

| 用途 | 模式 |
|---|---|
| 世界连续性 | `@Video1——用于世界连续性：同样的布景搭建、同样的灯光逻辑、同样的氛围、同样的制作质量水准` |
| 动作能量连续性 | `@Video1——用于动作能量连续性：同一事件仍在进行中，同样的冲击强度，同样的物理分量与动量` |
| 镜头性格 + 制作质感 | `@Video1——用于镜头性格与制作质感：同样的电影感层级、同样的摄影师存在感、同样的整体品质` |
| 嗓音 + 表演风格 | `@Video1——用于角色嗓音与表演风格：同样的声音特质、同样的表达层级、同样的表演能量` |

**核心承重规则：动作上提示词说了算，质感与世界感上参考说了算。**提示词负责写发生了什么；参考负责带出它看起来什么样。角色一致性重要时，搭配图片参考使用。
