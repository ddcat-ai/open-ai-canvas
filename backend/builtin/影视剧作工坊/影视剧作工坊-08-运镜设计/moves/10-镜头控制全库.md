## 推轨移动

| 控制项 | 作用 | 最佳用例 | 示例提示短语 |
|---------|-------------|----------|---------------|
| **推轨推近（Dolly In）** | 平滑的线性移动，朝向主体 | 亲密感、揭示、张力累积 | “镜头推轨推近，推向她的脸” |
| **推轨拉远（Dolly Out）** | 平滑的线性移动，远离主体 | 孤立感、离别、语境展开 | “镜头推轨拉远，露出空旷的广场” |
| **向左推轨（Dolly Left）** | 向左的横向轨道移动 | 跟随水平运动、揭示场景 | “镜头向左推轨，与奔跑者平行移动” |
| **向右推轨（Dolly Right）** | 向右的横向轨道移动 | 跟随水平运动、揭示场景 | “汽车加速时镜头向右推轨” |
| **推轨变焦推近（Dolly Zoom In）** | 推轨前进与变焦拉远同时进行 | 眩晕、震惊、顿悟（希区柯克效应） | “推轨变焦推近 —— 主体大小不变，背景飞速远去” |
| **推轨变焦拉远（Dolly Zoom Out）** | 推轨后退与变焦推近同时进行 | 压倒感、孤立、世界收拢逼近 | “推轨变焦拉远 —— 城市吞没人影” |
| **超级推轨推近（Super Dolly In）** | 夸张的高速冲向主体 | 突发震撼、紧迫揭示 | “超级推轨推近，冲向窗上的手印” |
| **超级推轨拉远（Super Dolly Out）** | 夸张的高速后拉 | 尺度的戏剧性揭示、语境骤变 | “超级推轨拉远，揭示整座燃烧的城市” |

## 组合镜头控制

把两个兼容的移动叠加起来，可以创造出更丰富的镜头：

| 组合 | 效果 | 示例 |
|-------------|--------|---------|
| 推轨推近 + 荷兰角 | 收拢的张力 + 不稳定感 | 反派登场揭示 |
| 摇臂上升 + 360 环绕 | 史诗级规模揭示 + 孤立感 | 最终决战结尾 |
| 第一人称无人机 + 急推变焦推近 | 动能 + 突然聚焦 | 追逐高潮 |
| 手持 + 动作奔跑跟拍 | 粗粝写实 + 追逐紧迫感 | 逃亡段落 |

**避免相互冲突的动作：** 不要在同一镜头里把推轨推近与推轨拉远组合，也不要把摇臂上升与摇臂下降组合 —— 那会造成视觉上的自相矛盾。

**顺序式组合与同时式组合。** 上表列出的是*同时式*组合（两种运动同时发生）。实际制作中也使用*顺序式*组合：先用横摇跟随角色完成第一阶段，角色停下后再推近其面部。在提示词中写明顺序与时序 —— `镜头从 0-3 秒向左横摇跟随角色，停住，然后在 4-8 秒推近面部` —— 这样模型会把运动渲染成彼此分离的阶段，而不是把它们坍缩成一个含糊的动作。

**定点横摇与滑移。** *横摇*的摄影机从固定位置转动；*滑移*的摄影机在空间中平移。实际制作中，大多数镜头覆盖更偏好定点横摇而非滑移 —— 定点横摇呈现的是一个带有指向性注意力的选定视点，滑移则显得漂移无依。写明你指的是哪一种：`摄影机停在原地，横摇跟随他` 与 `他走路时摄影机在他身旁滑移跟随` 是两回事。

> **负面约束：** 与镜头相关的时间/一致性伪影（相互矛盾的运动、
> 镜头不工作、I2V（图生视频）画面静止）及其预防短语，见
> `../shared/negative-constraints.md` — “时间/一致性伪影（Temporal/Consistency Artifacts）”一节。

## Camera-Emotion Sync（镜头-情绪同步）—— 按焦点人物情绪选择镜头运动

镜头是焦点人物的情绪替身。
移动方式、焦段选择与镜头时长，都应当由角色的情绪状态来决定 ——
而不是由抽象层面上什么看起来“有电影感”来决定。这种错位，
是 AI 视频提示词没有做好情绪同步功课的最显眼破绽之一：
平静的场景配上抖动不停的手持镜头，即便其他一切都没问题，读起来也是错的；
愤怒的场景配上平滑的推轨，即便动作本身正确，读起来也是疏离的。

六种情绪类型覆盖大多数场景：

| 焦点人物情绪 | 镜头处方 |
|---|---|
| 愤怒 / 暴怒 / 紧张 / 紧绷不安 | 手持呼吸感（handheld breathing），抖动且不稳定 —— 呼吸节奏破碎，两个轴向上都有可见的微颤，幅度小，节奏不规律。避免使用稳定器。 |
| 平静 / 自控 / 自信 | 手持呼吸感，平滑 —— 呼吸频率稳定，微幅规律。稳定器用得轻，但依然有生命感。 |
| 悲伤 / 脆弱 | 手持、缓慢、低机位 —— 呼吸频率更低，镜头略微向下漂移，摄影师手上的分量感觉更重。 |
| 震惊 / 顿悟 | 固定机位 + 极缓慢的推近（push-in）或拉远（pull-out）—— 在揭示的瞬间干脆地定格，之后 0.5-2 秒内只有极小的移动。 |
| 动作 | 60fps、180° 快门 —— 干净的运动，带有快门约束下的运动模糊；避免更长快门带来的拖长式运动模糊。 |
| 终拍 / 定论时刻 | 顶拍定格，0.3-0.5 秒 —— 正上方直拍，时间停止，所有位置锁定。 |
| 情绪崩溃 / 角色需要空间 | 从中景/特写缓慢拉远到远景 —— “让角色一个人待着”。制作团队为情绪时刻命名的技法（角色啜泣、蜷缩起来，或以其他方式需要被看见但不被施压）；把镜头拉远，给观众一段视觉距离，读起来是情绪空间，而不是抛弃。 |

### 单个镜头内的情绪弧线

当焦点人物的情绪在一个连续镜头内*发生改变*时
（例如同一个镜头里从暴怒 → 克制），镜头应当同步改变。
在提示词中把它写成命名的阶段：

- 开场阶段：为入场情绪指定镜头
- 过渡阶段：描述镜头性格如何转变
  （手持幅度减小、漂移稳定下来、推近放慢）
- 收束阶段：为离场情绪指定镜头

镜头跟着演员走，而不是按自己的钟点走。

> **选定镜头之前，先分解情绪。** 上面的 6
> 种情绪类型是以*具名*情绪（愤怒、平静、悲伤、震惊）为依据的。
> 如果用户给出的是笼统的情绪（“惊讶”“紧张”）
> 第一步是把它分解成某个具体的
> 具名类型 ——
> “是哪一种 X？”的澄清模板见 `../higgsfield-prompt/SKILL.md` 的
> “笼统情绪分解（Generic-Emotion Decomposition）”一节。

### 按镜头用途选择焦段与光圈

`[官方 —— Higgsfield shotlist-builder 技能，2026-07；由中文源重写]` ——
从镜头的*用途*出发挑选镜片，然后在提示词中同时写明焦段与光圈：

| 用途 | 焦段 | 光圈 |
|---|---|---|
| 极紧的情绪特写（额头到下巴充满画面） | 85mm 或 100mm（视场角（FOV）29° 或 18°） | F1.4 |
| 中段对话、双人镜头 | 50mm（视场角 47°） | F2.0–F2.8 |
| 广角 / 定场 | 35mm（视场角 63°） | F4–F5.6 |
| 插入镜头 / 物体细节（焦点锁定在物体上） | 50mm 或 85mm（视场角 47°/29°） | F1.4 |
| 微距（毛孔、水珠、织物） | 45mm 微距 —— 没有对应的视场角锚点；微距取景在分块提示词中按主体尺寸描述 | F2.8 |

有两条固定条款随这些选择一起使用：

- **插入镜头与紧凑特写的对焦锁定：** `“对焦平面从第一帧到
  最后一帧都锁定在[物体]上 —— 无焦点漂移、无移焦（rack focus）、
  无自动对焦来回搜寻。”`
- **广角/大光圈镜片的禁用畸变条款：** `“笔直的直线条，
  无桶形畸变或枕形畸变，无鱼眼，无广角变形。”`
  （对于 Seedance 分块提示词，视场角以度数而非毫米表示 ——
  见 `../higgsfield-seedance/SKILL.md` 的“视场角锚点”一节；
  本表的毫米/光圈词汇服务于 Cinema Studio 与非 Seedance 的界面，
  而*用途→镜片*的逻辑在两者之间通用。）

### 按类型划分的镜头时长

15 秒多镜头总时长内的时长分配 —— 用这些数值切分总时长，
并让完整的情绪弧线赢得它所需的完整长度：

| 镜头类型 | 时长 |
|---|---|
| 闪现定场 / 硬切开场（一闪而过的全景） | 0.3–0.5 秒 —— 一秒的一小部分，绝不是完整的一秒 |
| 一句中等长度的对话台词 | 3–7 秒 |
| 带情绪弧线的无台词反应 | 5–10 秒 |
| 插入 / 全景 / 定格 | 0.3–2 秒 |
| 带完整 5–7 拍弧线的情绪特写 | 8–15 秒 |

### 微动需要精确距离

对于极缓慢的推轨，要同时写明总行程**和**时间，否则模型
会把动作做过头：`“在整整 7 秒里，镜头只后拉
10–15 厘米 —— 慢到几乎察觉不到。不要变焦，不要突然推近。”`
物理移动绝不要写 `zoom` —— 要点名推轨 / 横移（track）/ 推近 / 拉远。

**而且要反向做一遍检查：所写的移动必须能产生所写的结尾取景。**
“一次缓慢推近”不可能从全景出发以大特写收尾，10 厘米的后拉
也落不出全身揭示的画面。当移动与结尾画面相互矛盾时，
这条提示词在内部就不成立 —— 模型会挑一个照做，把另一个即兴发挥。
从代价更小的一侧修复：要么放大动作（写明更大的行程），
要么缩小取景变化。`[实证 —— 第三方导演技能评测 2026-08-09；重新推导]`

## Cinema Studio 3.0 镜头最佳实践（Business/Team Plan，商业版/团队版）

> 这些最佳实践适用于 Cinema Studio 3.0 的生成引擎，该引擎仅在 **Business（商业版）和 Team（团队版）套餐**中提供。

### One-Move Rule（单动规则）

对于任何单个镜头，只指定**一个主镜头动作**。不要叠加多个动作（例如：推轨推进 + 向左横摇 + 向上竖摇）。这是抖动、意外旋转与生成失败的头号原因。

**错误：** `镜头：推轨向前推进，同时向左横摇并向上竖摇，以揭示天际线`
**正确：** `镜头：缓慢推轨推进，从中景到紧凑特写，历时 8 秒`

如果你需要多个镜头动作，请用 Cinema Studio 3.0 的 Custom 多镜头模式（Custom multi-shot）把它们拆分成多个镜头。

### 按题材划分的镜头预设

| 题材 | 主镜头 | 次选 | 避免 |
|-------|---------------|-----------|-------|
| 产品 / 电商 | 环绕、缓慢推近、固定机位 | 摇臂下降揭示 | 手持、甩摇 |
| 生活方式 / 社交 | 手持、固定机位、缓慢横摇 | 推轨随行 | 荷兰角、急推变焦 |
| 剧情 / 叙事 | 缓慢推近、推轨拉远、跟拍 | 摇臂上升 | 快速动作、快甩变焦 |
| 音乐录影带 | 甩摇、快甩变焦、快速跟拍 | 360 环绕 | 固定机位（太沉闷） |
| 恐怖 | 缓慢潜近（推轨推近）、固定保持、荷兰角 | 摇臂下降 | 快速跟拍（破坏张力） |
| 动作 / 追逐 | 第一人称无人机、跟拍、手持奔跑 | 急推变焦 | 固定机位、缓慢环绕 |
| 风景 / 旅行 | 摇臂上升、缓慢横摇、无人机飞越 | 推轨拉远揭示 | 手持、紧凑景别 |
| 喜剧 / 社交 | 固定机位（冷面）、快甩变焦 | 甩摇 | 缓慢的戏剧性动作 |

### 可靠短语库

这些短语能产生稳定、可预测的结果：

| 意图 | 可靠短语 |
|--------|----------------|
| 无镜头运动 | `固定机位的静态镜头，没有任何移动` |
| 缓慢接近 | `缓慢推轨推进，从中景到紧凑特写，历时 8 秒` |
| 跟随主体 | `手持跟踪，跟随主体，轻微晃动，但不混乱` |
| 揭示尺度 | `摇臂镜头从地面升起，直到正上方` |
| 环绕主体 | `平视高度上平滑的 180 度环绕，距离恒定` |
| 戏剧性变焦 | `急推变焦，从全景到冲击瞬间的大特写` |
| 主观视角运动 | `第一人称镜头以步行速度在环境中穿梭` |

### 通过 @Video Reference（视频参考）进行镜头迁移

实现复杂镜头运动最稳妥的办法，是从参考中克隆它：

```
匹配 @Video1（视频参考1）的镜头运动。一位舞者在日落时分的屋顶上起舞。
```

这绕开了 One-Move Rule，因为模型直接从参考中提取镜头数据，而不是去解释文字指令。

### 双视频参考

动作参考与镜头参考可以来自不同的视频。要把两者清楚地分开：

```
@Video1（视频参考1）用于角色的动作与编排。
@Video2（视频参考2）仅用于镜头运动。
一位武者在道场里表演一记回旋踢。
```

### Smart Mode（智能模式）（Cinema Studio 3.0）

Cinema Studio 3.0 的 “Smart” 镜头控制把镜头规划委托给模型。当你选择智能模式时：

- 模型会根据题材与场景描述自动规划镜头语言
- 在符合题材的镜头处理上信任它 —— 描述**感受**或**题材**，而不是具体的镜头动作
- 最适合：想要专业观感的镜头处理、又不想手动指定的用户
- 如需逐场景的镜头控制，可切换到 Custom 多镜头模式进行覆盖

**智能模式提示词示例：**
```
题材：剧情。一个女人独自坐在咖啡馆桌旁，心不在焉地搅动着咖啡。
她透过窗子注意到某个人，表情从悲伤转为惊讶。
```
（不需要任何镜头指令 —— 智能模式会自行选择符合剧情题材的镜头处理。）

## 视频参考 —— 它能读取什么、不能做什么

本仓库在多处记录了 `@Video` 参考的用法（上文的镜头迁移、
`higgsfield-motion` 的动作编排、`higgsfield-style` 的调色继承、
`higgsfield-audio` 的嗓音音色、`higgsfield-cinema` 的 Motion/Camera Sheet（运动/镜头表））。
能力边界 —— 视频参考能可靠读取什么、在哪些方面力有不逮、
以及它完全做不到什么 —— 在此一次性记录，并适用于上述所有用例。

### 它能可靠读取的内容

`@Video` 参考能把下列属性从源片段可靠地带入生成结果：

- **世界设计** —— 整体环境、布景搭建、灯光逻辑、色彩基调、氛围。
- **材质与质感** —— 表面看起来怎样（湿木头、绳索、水的表现、织物重量感）。
- **物理与运动风格** —— 物体如何移动、水如何表现、动作的分量与能量。
- **镜头性格** —— 镜头运作的整体感觉、它与主体的距离、它的运动语汇。
- **制作质量水准** —— 高预算还是低预算的质感、整体的电影感层级。
- **调色** —— 色调处理、对比度、饱和度水平。
- **天气与环境条件** —— 风暴强度、雨的密度、雾、光的品质。

### 它读取得不太可靠的内容

这些属性跨片段传递时表现不稳定。设计提示词时不要依赖它们：

- **逐帧精确的动作衔接** —— 要求模型从上一帧结束的地方精确接续是不可靠的。参考理解的是正在发生之事的能量与世界，而不是每个元素的精确最终位置。
- **精确的角色身份** —— 锁定角色身份请用图片参考，不要用视频参考。视频参考读取世界与能量的能力强于读取面部或服装的精确性。
- **具体台词或音频** —— 声音特质可以延续，但精确的声乐表现没有保证。

### 按用途划分的四种参考模式

在提示词中把参考的职责写明白。选择与你希望参考完成之事相匹配的模式：

| 用途 | 模式 |
|---|---|
| 世界连续性 | `@Video1 —— 用于世界连续性：同样的布景搭建、同样的灯光逻辑、同样的氛围、同样的制作质量水准` |
| 动作能量连续性 | `@Video1 —— 用于动作能量连续性：同一事件仍在进行中，同样的冲击强度，同样的物理分量与动量` |
| 镜头性格 + 制作质感 | `@Video1 —— 用于镜头性格与制作质感：同样的电影感层级、同样的摄影师存在感、同样的整体品质` |
| 嗓音 + 表演风格 | `@Video1 —— 用于角色嗓音与表演风格：同样的声音特质、同样的表达层级、同样的表演能量` |

这个模式之所以有效，是因为它告诉模型参考的哪个维度才是重点，
并让提示词的其余部分去驱动新内容。

### 硬性限制

这些不属于“不太可靠” —— 它们是视频参考完全做不到的事情：

- **无法从最后一帧继续某个具体动作。** 如果参考片段结束在海浪拍击船只的一刻，新片段不会自动从海浪仍在拍击的状态开始。参考提供的是世界语境；新片段的开场动作要从零写起。
- **无法覆盖你的提示词。** 参考为生成提供信息 —— 它不取代提示词指令。当提示词与参考冲突时，通常是提示词在动作上获胜，参考在质感与世界感上获胜。
- **无法单独提供角色身份。** 只要角色一致性重要，就要把视频参考与图片参考搭配使用。

### 核心承重规则（Load-Bearing Rule）

**动作上提示词说了算，质感与世界感上参考说了算。** 提示词负责写发生了什么；让参考负责带出它看起来什么样。当角色身份必须保持一致时，搭配图片参考一起使用。
