# 二、静帧中的运动暗示

对图像生成而言，运镜关键词在单帧中营造运动的*感觉*——动态模糊、暗示运动的构图，或运动中途凝固的瞬间。

**静态 / 基础**

| 运动 | 关键词 | 定义 | 用途 |
|----------|-----------|------------|---------|
| 固定镜头（Static Shot） | 固定（Static） | 摄影机不动 | 稳定与聚焦 |
| 横摇（Pan Left/Right） | 横摇（Pan） | 摄影机定点水平旋转 | 揭示或跟随动作 |
| 纵摇（Tilt Up/Down） | 纵摇（Tilt） | 摄影机定点垂直俯仰 | 揭示高度或纵深 |
| 推变焦（Zoom In） | 推变焦（Zoom In）、镜头变焦（Lens Zoom） | 视角缓缓向主体收拢 | 增强情绪强度 |
| 拉变焦（Zoom Out） | 拉变焦（Zoom Out）、宽广揭示（Wide Reveal） | 视角缓缓离开主体 | 揭示环境或孤立感 |
| 升降（Pedestal Up/Down） | 升起（Pedestal Up）、降下（Pedestal Down） | 整台摄影机垂直升降（电梯式） | 改变主体与地面的关系 |

**高级物理运动**

| 运动 | 关键词 | 定义 | 用途 |
|----------|-----------|------------|---------|
| 推轨推近（Dolly In） | 推轨推近（Dolly In） | 摄影机沿轨道向前 | 可控的电影感亲密 |
| 推轨拉远（Dolly Out） | 推轨拉远（Dolly Out） | 摄影机沿轨道向后 | 揭示尺度或情感距离 |
| 横移（Truck Left/Right） | 左移（Truck Left） | 摄影机水平平行移动 | 视差与动感 |
| 环绕镜头（Orbit Shot） | 环绕（Orbit） | 摄影机围绕主体移动 | 戏剧性强调与能量感 |
| 摇臂镜头（Crane Shot） | 摇臂（Crane） | 摄影机在摇臂上升降 | 盛大揭示或史诗尺度 |

**电影感与 AI 运动**

| 运动 | 关键词 | 定义 | 用途 |
|----------|-----------|------------|---------|
| 推轨变焦（Dolly Zoom） | 推轨变焦（Dolly Zoom）、眩晕效果（Vertigo Effect） | 后退与变焦推近同时进行 | 背景扭曲而主体大小不变——迷失方向感 |
| 急推变焦（Crash Zoom） | 急推变焦（Crash Zoom） | 快速猛烈的变焦 | 震撼或突然的强调 |
| 第一人称无人机（FPV Drone） | 第一人称无人机（FPV） | 快速沉浸式飞行运动 | 高能量与沉浸感 |
| 子弹时间（Bullet Time） | 子弹时间（Bullet Time） | 时间凝固而摄影机仍在移动 | 风格化的戏剧性强调 |
| 手持跟拍（Handheld Follow） | 手持跟拍（Handheld Follow） | 手持跟随主体 | 紧迫感与真实感 |
| 滚转（Camera Roll） | 滚转（Camera Roll） | 摄影机绕自身轴线旋转 | 迷失感或强烈感 |
| 焦点转移（Rack Focus） | 焦点转移（Rack Focus） | 焦点在主体之间切换 | 引导观众的注意力 |
| 后拉揭示（Pull Back Reveal） | 揭示（Reveal） | 后拉以揭示新语境 | 惊讶或尺度揭示 |
| 穿越飞行（Fly-Through） | 穿越飞行（Fly-Through） | 摄影机穿过环境元素之间 | 沉浸感与动势 |

静帧叠加示例：`仰拍中近景：[img 1]，镜头缓慢推轨变焦推近……`——景别 + 角度 + 运动暗示一次点名（完整构图公式见《镜头语言·纯技术文档》§构图）。

# 三、组合运镜

**同时式组合**——两种运动同时发生：

| 组合 | 效果 | 示例 |
|-------------|--------|---------|
| 推轨推近 + 荷兰角 | 收拢的张力 + 不稳定感 | 反派登场揭示 |
| 摇臂上升 + 360 环绕 | 史诗级规模揭示 + 孤立感 | 最终决战结尾 |
| 第一人称无人机 + 急推变焦 | 动能 + 突然聚焦 | 追逐高潮 |
| 手持 + 动作奔跑跟拍 | 粗粝写实 + 追逐紧迫感 | 逃亡段落 |

**冲突禁令：**不要在同一镜头里组合推轨推近与推轨拉远，也不要组合摇臂上升与摇臂下降——那是视觉上的自相矛盾。

**顺序式组合。**实际制作中同样常用*先后*发生的多段运动：先用横摇跟随角色完成第一阶段，角色停下后再推近其面部。在提示词中写明顺序与时序——`镜头从 0–3 秒向左横摇跟随角色，停住，然后在 4–8 秒推近面部`——模型会把运动渲染成彼此分离的阶段，而不是坍缩成一个含糊的动作。（多运动过载的机理与修复见 §十。）

**定点横摇与滑移。***横摇（pan）*的摄影机从固定位置转动；*滑移（truck/track）*的摄影机在空间中平移。大多数镜头覆盖更偏好定点横摇——它呈现一个带有指向性注意力的选定视点，滑移则显得漂移无依。写明你指的是哪一种：`摄影机停在原地，横摇跟随他` 与 `他走路时摄影机在他身旁滑移跟随` 是两回事。
