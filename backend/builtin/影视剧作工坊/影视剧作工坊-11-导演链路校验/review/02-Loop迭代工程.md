## 1. 风险分流与生成前预检

先复用当前项目记录中未变化的确认事实，再按`spatial_preflight.md`选择最小充分检查；L0/L1/L2的触发条件和空间验证深度只在该文件维护。每轮按最新状态重编译，不在旧稿后追加修改说明，也不把完整Loop用于所有任务。

预检完成后直接写最终稿，不先写一个无长度边界的“完整版”。

## 2. 资产提示词检查

标准资产任务只检查：上游依赖、素材职责、当前画面自包含、时间/风格/材质、构图和高风险误生项，同时确认硬删除目标已消失、每个素材编号都有真实来源。普通房间主视图只做建筑骨架、入口朝向和动作通道快检；跨门洞、多空间、镜面关系、重复空间错误或真实歧义才按`spatial_preflight.md`升级检查。

失败时只改错误字段。亲属、变异和连续性资产不得绕过上游母板重新设计。

定点360度补角视频另查：把已确认场景主图上传为真实首帧而非普通参考；第1帧复现图1原始机位、朝向与构图；图1方向定义为0度；前、右、后、左空间描述完整；摄影机光心与高度不位移；只绕自身垂直轴顺时针恒速旋转；10秒完成360度并精确回到首帧构图；无反转、停顿或缓入缓出；焦段、曝光和光源世界方向不漂移；全程无切镜、无变焦、无明显运动模糊；不可见方向仍标记为候选推演。

## 3. 视频提示词检查

L1把以下项目合并为1次通读；L2在第8项追加完整空间状态卡。不要每核对1项就重写一次：

1. 原文：没有漏接、重复或擅自增戏。
2. 单元：有起点、变化和落点。
3. 风格：影视参考已翻译成一致摄影系统；环境色卡职责明确。
4. 时长：时间码连续；2.5不超过30秒；2.0只在用户触发后不超过15秒；固定镜头不拖长。
5. 素材计划：按`batch_material_mode`判断。`mapped`和`hybrid`的提示词槽位必须与外部【本批上传ID映射】一一对应；`text`不得出现视觉图号。准备状态可以是“待用户准备”，但不得宣称已经验证。
6. 平台：即梦只有素材映射出现裸`@`，LibTV只在素材映射出现占位符；生图统一`{{Image N}}`。`text`删除视觉素材映射与图片占位符。
7. 身份：映射项由用户上传计划锁定；文字承担项以项目记录中的人物、服装、伤势、变异和道具连续性定义锁定。
8. 空间：按风险等级完成空间检查；L1用紧凑卡明确主体起点、主要方向、摄影机关系、结束状态和下一镜接口，L2再建立完整逐镜空间状态卡，并核对地势屏幕几何、轴线、视线、遮挡与在画人物。
9. 动作：触发、蓄力、接触、反馈顺序正确，单镜不过载。
10. 表演与语言：情绪有刺激和生理过程；逐字对照原文列出全部说话者/旁白。`mapped_dry_voice`为选择映射的声音建立音频槽位并逐句就近引用正确音频N；槽位可以待用户准备。`model_voice`不绑定音频编号，逐句写呼吸、语速、语调、音量和情绪变化；`post_dub`保留口型、停顿和表演节奏并注明后期替换声音。
11. 镜头：亮点服务叙事，景别和方向不过度同质化。
12. 声音：环境/动作声完整；BGM有职责与出入，或明确无BGM。
13. 卫生：删除成本解释、工作流元话语、重复禁令和批次外指代。
14. 字符：按`prompt_templates.md`的唯一预算规则和`validate_prompt.py`校验；超限先去重，仍不能通过则重新拆分微事件。
15. 2.0：不是按第15秒机械切开，每条有完整微事件。

运行：

```text
python scripts/validate_prompt.py <提示词文件> --platform jimeng|libtv --mode new|extend|edit --asset-mode mapped|text|hybrid --voice-mode mapped_dry_voice|model_voice|post_dub
```

完成结构检查后，L1只读最终提示词做1次简明冷读：模型能否明确人物、地点、动作顺序、镜头和声音；L2再执行完整反向重建。内部只允许1轮定向修正；无法通过文字继续提高确定性的内容进入“待实测”，不得无限循环。

## 4. 结果Loop B

先确认采用版本、可用区间和从哪一秒/哪个动作出错。按最小层诊断：

| 层 | 问题 | 优先修复 |
|---|---|---|
| L0 风格摄影 | CG感、色调或光线漂移 | 收紧风格/色卡职责，删冲突参考 |
| L1 身份资产 | 换脸、换装、道具漂移 | 收紧母板职责，减少冲突图 |
| L2 空间连续 | 跳轴、方向反、站位消失 | 补空间锚点/连续性帧，缩短调度 |
| L3 动作物理 | 穿模、瞬移、顺序错 | 拆蓄力/接触/反馈，降低单镜事件 |
| L4 表演台词 | 机械、突变、音色错、干声槽位漏映射、模型音色漂移或后期口型不合 | 按声音模式修映射/声音参数/口型节奏，并补刺激与生理过程 |
| L5 镜头节奏 | 拖沓、无张力、转场错 | 重分时长、换机位、删无效动作 |
| L6 声音音乐 | BGM弱/太满、音效缺 | 独立生成BGM，重写混音层级 |
| L7 模型容量 | 多项同时错、镜头融合 | 拆短、减少素材、补锚点或换模式 |

## 5. 最小修复

冻结已经正确的镜头、资产、空间和声音。一次只修改最可能负责的层并记录结果，但对外提示词必须依据最新有效状态整篇重编译，不保留修改痕迹、已删除语义或失效引用。相同问题连续2轮仍出现，停止堆禁止词，切换为拆短、全新/延长/编辑、补锚点、换机位或降低复杂度。

用户的观察是证据，不自动当作解决方案；AI重新审查全段后给出理由。

## 6. 成本纪律

- 每个节拍默认1条主线；支线由粗剪缺口触发。
- 动态资产只补当前片段阻塞项，通常不超过3张。
- 延长只上传最短必要尾段，不默认上传完整视频。
- 局部可修优先编辑，不整条重生。
- 静态空镜、极轻缓推、粒子或字幕能用定稿图和后期完成时，提示低成本路径。
- 不因成本主动切换2.0；只有用户明确要求才启用。
