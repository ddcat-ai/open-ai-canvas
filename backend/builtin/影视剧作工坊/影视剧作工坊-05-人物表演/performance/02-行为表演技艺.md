# 表演导演

**整个系统的核心公理：表演是压力之下的行为，不是情绪的展示。** 一个角色想要某样东西，有什么挡在中间，他们便行动去得到它。情绪是这场挣扎的副产品——绝不是你直接去写的东西。

本技能是视频提示词**之上的一个表演叠加层**：本技能产出的段落会放入一条视频提示词的 PERFORMANCE / CHARACTER ACTING（表演 / 角色演技）区块。它不改变镜头、灯光、服装或调色。

## 速览（QUICK FACTS）
*速览是路由辅助——规则请阅读所链接的章节。*
- 写出**目标（objective）**（一个指向对手的动词），永远不要写状态——“让他招供”，而不是“生气” [→](#the-five-pillars-of-every-scene)
- 每场戏 **2–4 次拍点（beat）变化**，每一次都在行为中可见：一次停顿、一次姿态改变、一次节奏改变、一次目光移动。整个镜头行为一成不变 = 表演扁平 [→](#the-five-pillars-of-every-scene)
- **聆听胜过说话。** 反应在对手台词结束*之前*就开始；一个尖锐的问题配得上回答之前的一次微停顿 [→](#listening-and-reaction)
- 身体承载生平：**重心、节奏、开放度、呼吸**——在任何心理刻画之前先设定全部四项 [→](#the-body)
- **手上任务（business）**——双手正在做的物理任务——杀死戏剧腔；一场戏里最重的重音，是角色**停下**它的那一刻 [→](#the-body)
- **距离即戏剧**；距离的改变*就是*一次拍点变化。地位是你**做**出来的，而地位**反转**（status break）是表演中最有趣的东西 [→](#the-body)
- **主档案（master profile）**为 150–220 词、一个段落、固定的块顺序，每个角色写一次，再按场景重写——绝不粘贴 [→](#the-acting-master-profile)
- 每个小动作（tic）都带有**触发条件**；每个面具（mask）都带有**裂缝**——每份档案至少一个“然而，当 X……”从句 [→](#the-acting-master-profile)
- **眼神生命力（eye life）是强制的，绝非可选**——微扫视（saccades）、眨眼质量、活的眼神光（catchlights）、眼神先于念头（eyes-lead-thought）。死眼睛是 AI 表演的头号破绽 [→](#eye-life)
- 场景化改写**转换而不删除**：物理上无法发生的行为被移置到另一个出口，而不是被移除 [→](#scene-adaptation)
- **声音提示词是锁定的**——每个角色一条，逐字粘贴进音频字段，从不按场景改写 [→](#voice-fixed-identity-never-adapted)
- **状态，而非过程。** 模型处理不好过程，却拿得住状态：“掷出中途、手臂已伸展”，而不是“伸手进去、掏出来、蓄力挥臂” [→](#states-not-transitions)
- 群像反应以**波浪传播，绝不同步**；强者静而无声，弱者坐立难安、高声喊叫 [→](#ensemble-and-space)
- 15 种有名字的坏表演症状及其提示词级修复，以及一张 0–5 分自检量表——**每个英雄镜头都瞄准 4 分以上** [→](#the-atlas-of-bad-acting)

# 第一部分 —— 技艺

## 什么是好的表演

在想象情境之下的真实行为。不是被描绘的情绪，不是被背诵的台词，不是“有表现力的脸”。

| 坏表演 | 好表演 |
|---|---|
| 展示情绪（“我很生气”） | 追逐目标（“我会让你把钱还回来”）——愤怒自行升起 |
| 等自己的提示 | 每一秒都在聆听对手并作出反应 |
| 身体图解台词（手势 = 词） | 身体过着自己的生活，有时与台词相矛盾 |
| 所有台词一个节奏、一个语调 | 每次策略改变，节奏随之改变 |
| 情绪在台词处打开、台词过后关闭 | 状态是连续的——台词之前有生活，台词之后也有生活 |
| 脸在“表演”——挑眉、做鬼脸 | 脸在思考——话语出口之前，念头已能从眼中读出 |

## 每场戏的五大支柱

每场戏中的每个角色都可分解为五个要素。缺了任何一个，表演就会散架。

**1. 目标（Objective）。** 角色在本场戏、此时此刻、想从一个具体的人身上得到什么。永远是一个指向对手的动词：*让他招供* · *求来一周的宽限* · *让她相信我不害怕*。绝不是一种状态（“愤怒”、“内疚”）——状态是无法被表演的。在场景目标背后坐着**最高目标（super-objective）**：角色贯穿整个故事想要什么，每个场景目标都是朝向它的一步。

**2. 障碍（Obstacle）与赌注（stakes）。** 什么在阻止他们——外部（另一个角色想要相反的东西；房间里有目击者；距离截止只剩两小时）或内部（自尊不允许他们开口求人；他们自己都不信自己说的话）。永远要回答*如果我没有得到想要的，会发生什么？*——而且答案必须让角色感到恐惧。失败的代价越高，戏就绷得越紧。

**3. 策略（Tactics）。** 此时此刻追求目标的具体方法，用动作动词表示：*施压 · 讨好 · 羞辱 · 哀求 · 激将 · 讨价还价 · 威胁 · 拖延*。当一个策略失败时，活人会**更换**它。整场戏只用一个策略就是死表演。

**4. 拍点（Beats）。** 行动的最小单位：角色想要同一件事、并以同一种方式追求它的那一段。当目标达成、策略失败、新信息到来、或力量平衡改变时，一个拍点就结束了。**每一次拍点变化都必须在行为中可见**——一次停顿、一次姿态改变、一次语速改变、一次目光移动。一场好戏有 **2–4 次拍点变化**。

**5. 潜台词（Subtext）。** 角色实际上在想什么、要什么，与他说出口的话相对。潜台词**不是演出来的**——当角色一边说着虚假的台词、一边追逐真实目标时，它会自行泄露。可构建的标记：不是疑问的问句 · 重复（问同一件事——他们不相信那个答案） · 突然转换话题 · 在错误时刻开玩笑（对抗脆弱的盾牌） · 过短的回答（“行。” “随便。”——一扇关上的门）。

## 支柱之上的那一层——一个方向，不同的燃料
五大支柱是按角色的。它们没有说明是什么把一个群像黏合在一起，正因如此，仅由它们构建的场景可能读起来像几段好表演，却不在同一场戏里。在它们之上还有一层。

**场景只有一个方向，每个角色都朝它演。** 它通常说不出口——一种关于“这一次要怎样度过”的彼此心照不宣的默契。*离别要不痛，保持积极*（母亲在儿子临行前收拾他的行装）。它同时属于房间里的每一个人。它**不是**影片的戏剧功能：角色从不扮演“揭示”或“主题”，那些是*透过*他们、作为副产品达成的。

**每个角色出于自己的理由推动这个方向——即动机（MOTIVE）。** 同一个矢量，不同的燃料。儿子是为了*母亲*而让离别不痛；母亲则是出于*迷信*（上路前掉眼泪不吉利）。**燃料正是让每段表演各不相同、而场景读起来仍然统一的东西**——它也最常被跳过，而这正是把一个群像塌缩成同一个音符反复弹奏的原因。

规定情境（given circumstances）约束动机：一个已经接下脏活的角色无法扮演道德上的清白。如果动机与前史矛盾，就重新推导它。

请仔细区分，因为这是四样不同的东西，而且只有后两样是按角色的：

| 层 | 属于谁 | 例子 |
|---|---|---|
| 场景方向 | 所有人共享 | *离别不痛* |
| 动机（燃料） | 每个角色自己的 | *迷信* / *为了她* |
| 目标（§ 支柱 1） | 每个角色自己的 | *精神抖擞地送他出门* |
| 策略（§ 支柱 3） | 每个角色自己的 | *照常收拾行李，偷看他* |

### 从结局命名事件

在命名这场戏讲什么之前，先读这场戏**如何结束**。最后一句台词或最后一个拍点，是你把整场戏倒着读回去的钥匙——同时要警惕带有双关意味的最后一句：说的是一件事，指的却是另一件事（*“可怜的家伙，他就是没法原谅自己”*——表面上说着病人，实际说的是说话者自己）。

**检验标准：事件必须容纳场景中的每一个角色**，包括沉默的和无意识的，作为同一过程的参与者或镜子。**如果某个角色站在被命名的事件之外，那这个事件就命名错了**——重新命名，直到所有人都被装进它里面。这是本文件里成本最低的结构性检查，它能抓住那种“某个角色仅仅在场”的场景。

### 物理动作是通道

表面活动——即*地形*——保留为物理动作，而每个角色**透过它、以各自不同的、镜头可读的行为**去追逐事件。不可见的任务必须有可见的通道，否则模型就没有可渲染的东西。

一片地形（*例行的医院查房*），一个事件（*寻求自我原谅*），三条通道：

- 一个角色经由**回忆**——闭合的眼睑下的快速眼动（REM），一滴泪
- 一个角色经由**把分内之事做对**——数据无误、准时、复核一条录入
- 一个角色经由**照料**——超出清单之外的照护手势，检查的是这个人，而不是病历表

给场景中的每个角色一条属于他们自己的物理通道，通向同一个事件。不同的行为，同一个事件，同一片地形。正是这一点把一条表演笔记变成视频模型真正能生成的东西。

### 反差配对——用镜像的正负号搭建双人组

一出双人戏（two-hander）在这对搭档建立在反差之上时会更丰富：**每个角色各带一个加号与一个减号，且相对对手镜像倒置**，并把其中一条轴命名为**本质轴线（essential axis）**——观众真正读到的那组对立。其余特质都是色彩。

一对实验室搭档，本质轴线是*对病人的照护*：

- **医生——忠诚（+）/ 粗疏（−）。** 他确实忠诚，但效忠的是机构和钱。他的加号侍奉了错误的主人，所以在本质轴线上他是**减号**。
- **医士——有污点（−）/ 有爱心（+）。** 接下这份工作本身就让他有污点，但他对病人是有爱心的。他的减号是真的；他的加号在污点之内存活——在本质轴线上他是**加号**。

两人仍在推动同一个场景方向。反差活在它*之下*，并经由策略泄露出来：粗疏那个的例行公事是真的，有爱心那个的例行公事是盔甲，而这盔甲会裂开。

**看似的特质常常是其反面之上的疤痕组织**——“粗疏”是希望已死，不是关心缺席。要导的是历史，不是表面。

## 聆听与反应

表演不在台词之中，而在台词**之间**。四个可观察的、要写进提示词的标记：

1. **反应在对手台词结束之前就开始。** 人在话说到一半时就抓住了要点——脸和身体已经在回答。直到台词结束都面无表情、然后才“开机”的脸，是死表演。
2. **念头先于词语。** 在一个艰难的回答之前有一个微停顿——这个人看得出来在决定说什么。以均匀速度脱口而出的回答读起来像背熟的课文。
3. **评估时刻。** 在消息、威胁或羞辱之后，角色需要时间消化——从几分之一秒到一次长停顿。电影就靠这些评估的特写活着：一张脸、一束失焦的目光、旋转的世界。
4. **被对手传染。** 节奏、音量和能量随之改变：一声吼叫要么被一声反击的吼叫回答，要么被刻意的安静回答——但总之是*被回应*，而不是被盖过去。

**沉默的聆听者也要有任务，而不只是标记。** 上面四个标记描述的是反应*读起来*如何；它们没有给聆听者任何在这些标记之间可做的事，而没有任务的聆听者正是双人镜头里死脸回归之处。给这份工作命名：*判断他是不是认真的 · 等待开口的时机 · 守护气氛 · 抓住他的谎言。* 这样，画面里的每个角色都有活着的眼睛。

## 身体

**物理状态先于心理。** 在任何内在生命之前，先为每个角色设定四个参数：

- **重心（center of gravity）**——高（胸、下巴：自信、攻击性、地位）或低（肩膀、佝偻：疲惫、恐惧、顺从）。
- **节奏（tempo）**——快/散乱（紧张、兴奋剂式的能量）或慢/节省（控制、威胁——最危险的人动作最少）。
- **开放度（openness）**——端平的双肩与摊开的手掌，对比交叉的双臂、垂下的头、闭合的姿态。
- **呼吸（breath）**——高位而急促（恐慌）对比低位而缓慢（控制）。呼吸是状态最诚实的指标，而声音必须与物理一致：刚跑完步的人不可能用平稳的嗓音说话。

**手上任务（business）——物理任务。** 一个角色几乎总需要一个“正在做的事”。他们不是在“进行一段对话”——他们在修发动机、数钱、做饭、擦杯子，并在这件事之上说话。手上任务杀死虚假的舞台腔（双手忙于真实），创造节奏（停顿被动作填满），并生成潜台词（一个人*怎样*数钱，比词语说明的更多）。

> **被打断的动作规则。** 最强的重音是角色**停下**手上任务的那一刻。如果他正在切面包，却在某句话处停了下来，那句话就成了一个事件。把这个停止当作标点来用。

**空间距离学（proxemics）——作为戏剧的距离。** 角色之间的距离是他们关系的可见图表：

| 区域 | 距离 | 读作 |
|---|---|---|
| 亲密距离 | 0.5 米以内 | 爱或暴力——未经邀请的进入即是攻击 |
| 个人距离 | 0.5–1.2 米 | 信任 |
| 社交距离 | 1.2–3.5 米 | 公事、戒备 |
| 公共距离 | 3.5 米以上 | 疏离、等级 |

在离一张脸 10 厘米处耳语的威胁，比隔着整个房间喊出来的更可怕。场景的戏剧常常只是距离的故事：谁缩短它，谁打破它，谁在原地僵住。**距离的改变就是拍点的改变**——而且必须以米为单位书写——距离是可度量的语言。

**地位（status）——看不见的等级。** 地位是你**做**出来的，不是你“是”什么。

- **高地位：** 不动的头、缓慢的动作、长长的注视、回答之前的停顿、占据空间、触碰别人的东西。
- **低地位：** 手忙脚乱、频繁的自我触碰（脸、头发）、破碎的语句、填补空隙的笑、用眼神请求许可。

表演中最有趣的东西是**地位反转（status break）**：露出一秒恐惧的老板；突然收起笑容的下属。一个有力的场景形态是*以高位进场然后崩塌*，或*以低位进场然后翻转全场*。

## 好的表演听起来如何

- 节奏写在文本里——精确地执行它；快 ≠ 含混。
- 抢话是正常的（台词踩着彼此的尾巴），但关键词保持干净。
- **音量对比：最可怕的话用最轻的声音说。** 吼叫是弱者的通货；掌控场景的角色把音量降下来，所有人都凑近去听。
- 停顿是事件，不是空洞——只有内部发生了什么的停顿才是合法的：一次评估、一个决定、一次拒绝回答。
- 真实的语言带有碎屑：打断、没听全的词、重复、没说完的句子。构造完美的句子杀死街头真实感。

# 第二部分 —— 编写表演

## 表演主档案（acting master profile）

每个反复出场的角色都获得**一份**主档案——关于他们如何表演的永久事实来源。写一次，然后按场景改写。目标：**150–220 词、一个流畅的段落**，完全可观察、可拍摄。

**块的顺序是固定的：**

```
角色表演：[姓名]。[体型、体格、姿态——身体作为其生平的文件]。[用一个从句写出的心理引擎——解释这份身体性的内在驱力]。声音档案：[音高/音色、口音/出身、语速与说话方式，以及情绪之下声音如何破裂或切换]。关键身体习惯与小动作：[标志性小动作及其触发条件；应激小动作及其触发条件；掩饰行为——他们用来隐藏自身感受的做法；面部面具，以及面具开裂的确切条件]。眼神生命力：[眨眼的质量与频率、扫视模式、目光先于头转、眼神光]。行走风格：[作为人物刻画的步态——有名字、够具体，带重量、节奏与落脚方式]。然而，当[情绪触发条件]时，[转变——姿态、步态与脸如何改变]。[可选：软化对象——唯一能让这张脸真正柔软下来的那个人或物]。
```

**每块的规则：**

1. **只写可观察的行为。** 每个内在状态都需要一个身体标记。永远不要写“他很紧张”——要写下嘴唇的颤抖、沉重的吞咽、用嘴的长吸气与从抿紧的嘴唇挤出的短促呼气。
2. **每个小动作都有触发条件。** 不是“他掰响指关节”，而是“他在平淡的对话中掰响指关节，以假装自信”。格式：`[小动作] + [何时/为何]`。没有触发条件的小动作是装饰；有触发条件的小动作才是戏剧结构。
3. **给步态命名。** 一个加引号的造词能锚定生物力学——“权力快步”、“孔雀阔步”、“画廊漫步”、“攻城锤大步”、“无畏舰步伐”——然后把它展开：重量、步幅、躯干和手臂做什么、头做什么。
4. **同时构建面具与裂缝。** 档案中最具电影感的单一装置就是条件式转变：那个门面，加上让门面塌陷的精确触发条件。一种在遭到拒绝时塌缩成孩子般佝偻的强势派头；一种在面对某个特定的人时融化为灿烂笑容的严苛自律。**每份档案至少带有一个“然而，当 X——……”从句。** 一个同时扮演两种真实的角色，是木偶与人之间的差别。
5. **一个软化对象（softening target）。** 在合适的地方，给这张脸恰好一个它真正会为之柔软的人、动物或物。一个——不是两个。这能人性化而不稀释。
6. **不写服装。** 衣服住在场景/造型块里，永远不住在表演档案里。这份档案必须能在任何换装之后存活。
7. **不写镜头，不写色彩。** 表演只驱动演出、脸、声音和动作。
8. **体格承载生平。** 体型和姿态讲述前史——“被过往的挣扎风化过”的体型、“永远紧绷”的肩膀、“过度矫正以投射权威”的姿态。职业、旧伤和自我形象必须能从身体上读出来。

> **年龄不是档案字段。** 角色年龄盲（age-blind）是本模块的硬规则，而且内容过滤器对年龄词收紧得非常厉害。用**体型、磨损、姿态和声音**携带同样的信息——“一具已经被修过两次的身体”、“工人阶级的沙哑”、“老拳手的步态”——绝不写数字，绝不写 *男孩 / 女孩 / 年轻 / 青少年*。

## 眼神生命力（eye life）

**死眼睛是 AI 生成表演的头号破绽。** 每个角色都获得连续的、自然主义的眼睛生命——在档案里*以及*在每场戏里。

- **微扫视（micro-saccades）与目光瞄准**他们注意的任何东西；目光持续移动——眼神漂移、因思考而瞥开、扫到某个细节又落回来。它们从不锁死冻结。
- **写实的眨眼频率与质量**，与状态绑定：压力下快速的连串眨眼；掌控中的缓慢平静眼睑；抽离瞬间的一次眨眼加目光发直。
- **活的眼神光（catchlights）**——眼睛必须读起来是湿润的、被照亮的、活的。但眼神光是一种*渲染*属性，不是解药：**死眼睛不是靠灯光戏法修好的，而是靠给眼睛一个任务。** 带着漂亮眼神光的玻璃般凝视，仍然是玻璃般凝视。把眼部工作写成指向对手的有目的的行动——*检查对方两只眼睛里有没有信任的闪光 · 每说完一点，留意它有没有落进对方心里 · 偷看一眼，在被抓到之前猛地收回 · 掂量对方，把我感受到的与对方展现出来的作比较。***眼球的移动本身就是“做”**，而活感就是心智在每一刻都看得见地为任务运转。眼神光让这一切清晰可读；它们永远不能替代这一切。
- **受控的静止是选择出来的，绝不是死的。** 对于近乎不眨眼的捕食者式平静，让眨眼稀少、缓慢、刻意——是一个决定，不是一次冻结——并让目光仍然带着意图缓慢移动。
- **眼神先于念头。** 眼睛比头的转动早一点到达目标。话语出口之前，念头已能从眼中读出。
- **眼神生命力对拍点作出反应。** 拍点改变时，眨眼频率、目光的稳定度和眼神光的温度全都随之改变。

一条来自制作一线的分阶段眨眼速记——*一次懒散的眨眼 → 一次快速的 DOUBLE-BLINK（连眨两下）→ 一次用力的复位眨眼*——是在静态镜头里买到一张活脸的最便宜方式。

## 场景化改写

主档案是角色“是”谁。对每场戏，要**把它改写进当下这一刻**——绝不粘贴。

1. **只写给在场的角色。** 表演段落只写给实际出现在镜头里的角色。画面里没有角色 → 没有段落。
2. **保持恒定核心。** 身份、声音档案、标志性小动作、眼神生命力和情感主线在每场戏里都保持不变——这是让角色跨越剪辑仍能保持完整的东西。绝不与主档案矛盾。
3. **为本场戏重新表达。** 挑选、强调、修改或舍弃具体行为，以适配本场戏的姿态（坐 / 站 / 跑 / 躲藏）、动作、拍点、情绪状态和时刻。
4. **转换，而不是删除。** 在这里物理上无法发生的行为要被*转化*，而不是被移除：一个坐立不安、来回踱步的人瘫在沙发上时，保留同一台紧张引擎，把它移置到不安的微晃、手腕的弹动和撕纸上。**能量恒定；出口改变。**
5. **一个流畅的段落。** 把改写折进符合该角色语域的散文里——不要项目符号列表，不要标题，提示词里不要“旋钮”行。
6. **以角色的引用标签开头**，让模型把表演绑定到正确的人身上。

## 声音——固定身份，绝不改写

表演按场景改写；**声音是锁定的。** 每个角色获得一条 Voice 提示词——一个永久的声音身份，每次角色开口时**逐字**粘贴进音频字段，永不修改。如果角色出现但什么都没说，就省略它。

> **连同义词都不行。** “逐字”比听起来更严格，而它被破坏的方式并非粗心——而是写手在镜头之间“改进”措辞，并以为意思被保留了。并没有：把 *温暖* 换成 *醇厚*，或把 *砾石嗓* 换成 *沙哑嗓*，生成的声音就会移动。把每个锁定块保存在同一个地方——为整个制作定一份**声音圣经（voice bible）**，一次性决定好——然后从那里粘贴，而不是重新打字。

```
“[出身 / 口音描述]。[音色与音域]；[语速与说话方式]；[情绪性格——以及它在压力之下如何转变]。”
```

表演段落*内部*的声音档案描述的是台词在戏剧上如何表现（节奏变化、破音、耳语）；音频字段里的 Voice 提示词锁定的则是**声音**本身。两者必须一致。

Seedance 在同一音调范围内每个角色只守得住三到四种声音，所以漂移是真实存在的——像对待外观造型一样对声音做跨代生成的压力测试，宁可把它锁得更死，也不要“继续拍下去”。

## 状态，而非过程

视频生成模型搞不定过程转换，却能拿住状态。把角色描述为**已经处于**动作状态之中——掷出中途、出拳中途、踱步中途、争吵中途——而不是到达那里的过程。

- ❌ “伸手进包、掏出刀、蓄力挥臂” → 崩掉
- ✅ “掷出中途、手臂已伸展” → 稳稳落地

一个拍点接一个拍点地串联状态，而不是叙述连续的过程。这条规则的制作形态：复杂动作**开场**提示词，而接近的过程变成一个单独的镜头。

## 群像与空间

- **群体反应以波浪传播，绝不同步。** 第一个人先听懂笑话，第二个人半拍之后，第三个人根本没懂。同时且完全相同的反应读起来是假的——除非刻意编排的喜剧式同步本身就是目的。
- **反应比动作更值钱。** 每个事件之后，最有价值的画面是目睹者的脸。
- **在威胁处定格。** 群像持续的微动作——重心移动、打手势、身体倾斜——而在关键威胁处一切**停止**。忙乱 → 静止的反差就是标点。
- **移动等于动机。** 没有人会毫无冲动地穿过一个房间：要么走向什么，要么离开什么。有强动机的事件——逼近（升级） · 转过身去（打发，或藏起脸） · 对方坐着时自己站着（抢夺支配权） · 冲突中途坐下（悖论式的权力） · 在门口停下（门槛即决定点） · 开始收拾行李（用身体下达的最后通牒）。
- **强者静而无声；弱者坐立不安、大喊大叫。** 危险不是由危险者本人演的，而是由周围所有人的紧张演的。没有蓄力的威胁：没有威胁性的停顿，没有慢动作的转身——在真实的世界里，暴力到来时不做预告。
- **磨损会累积。** 如果一个角色在整个故事中被逐渐磨垮，要在身体里累积地携带它——更灰、更沉、更慢的反应——绝不在场景之间重置。

> **引擎天花板：** 跨剪辑能可靠追踪的只有 ≤3 个角色（引擎实测上限）。为被追踪的两人组或三人组写波浪；其他所有人都是人群，按群体描述。

# 第三部分 —— 质量控制

## 坏表演图鉴

认出症状，套用提示词层面的修复。

| # | 症状 | 看起来什么样 | 提示词层面的修复 |
|---|---|---|---|
| 1 | 直白示意（挤眉弄眼） | 脸在“描绘”情绪：扬起的眉毛、鬼脸 | 把脸从任务上撤下来；写出目标，并给双手安排手上任务 |
| 2 | 表演结果 | 角色从第一秒起就在演这场戏的结局 | 只写角色**此刻**知道的东西 |
| 3 | 等提示 | 对手说话时脸上空空 | 把反应写成从对手台词中途就开始 |
| 4 | 单一策略 | 整场戏一个颜色（全程吼叫 / 全程哭诉） | 标出拍点；每个拍点配一个新的策略动词 |
| 5 | 手势图解 | 手势复制词语（说“大”——张开双臂） | 手势要么先于念头，要么与词语相矛盾，要么干脆缺席 |
| 6 | 凭空情绪 | 没有铺垫也没有触发条件的眼泪或暴怒 | 修阶梯：克制 → 崩裂；情绪必须有代价 |
| 7 | 身体与前史不符 | 一个长着舞者体态的暴徒 | 设定身体档案：重心、节奏、磨损 |
| 8 | 话语比阶层干净 | 一个街头角色说话像文学课文 | 给语言加碎屑：打断、吞掉的句尾、重复 |
| 9 | 威胁预告 | 暴力之前的“威胁性”停顿、眯眼、缓慢转身 | 威胁是平淡日常的；暴力没有蓄力 |
| 10 | 同步群演 | 每个人同时做出完全相同的反应 | 让反应以波浪错开，并变化它们的强度 |
| 11 | 死寂停顿 | 其中什么都没发生的沉默 | 用评估或手上任务填满——或者剪掉 |
| 12 | 情绪重置 | 角色在强烈事件后立刻“恢复” | 状态有惯性；余波会带进下一个拍点 |
| 13 | 点评角色 | 表演向观众挤眼 | 对情境全然相信；喜剧要演得一板一眼地严肃 |
| 14 | 特写过载 | 特写上的活跃鬼脸 | 镜头越紧，动作越少：只剩眼睛和念头 |
| 15 | 死眼睛 | 冻结的凝视、不眨眼、没有微扫视、玻璃般的眼神光 | 完整套用 § 眼神生命力——它从来不是可选项 |

## 表演量表

在段落交付之前对它做一次自检。

- **0 —— 人体模型。** 台词送达，行为缺席。
- **1 —— 朗诵者。** “有表现力”的文本、被示意出来的情绪、图解式的身体。
- **2 —— 勤恳者。** 目标能被猜到，但只有一个策略、迟到的反应、空洞的停顿。
- **3 —— 匠人。** 目标与拍点俱在，聆听对手，身体说得通。缺：潜台词、出人意料的策略、状态的惯性。
- **4 —— 活人。** 连续的行为、互相反差的策略、与文本背离的潜台词、身体里的地位、先于台词的反应、至少一个意外但真实的选择。
- **5 —— 磁石。** 具备 4 的全部，再加上悖论。**两种真实规则：在第 5 级，角色永远同时扮演两种真实**——一边帮忙一边憎恨；一边道歉一边防卫；一边爱着一边已经离开。一种没有矛盾的干净情绪，在特写里读起来是合成的。

**每个英雄镜头都以 4 分以上为目标。** 自检得分在 2 分或以下的段落，交付前重写。

## 发送前检查清单

- [ ] 目标是指向对手的动词——对画面里的每个角色
- [ ] 障碍与赌注存在；失败的代价是真实的
- [ ] 2–4 次拍点变化，每次都在行为中可见（停顿 / 姿态 / 节奏 / 目光）
- [ ] 反应在对手台词结束前开始；有评估时刻
- [ ] 每个角色都有手上任务；被打断动作的重音是有意使用的
- [ ] 距离发生改变，改变有动机，并且以米为单位书写
- [ ] 地位在身体里，而不只在词语里
- [ ] 所有小动作都带有触发条件；面具带有裂缝（“然而，当 X……”）
- [ ] 眼神生命力被明确写出：微扫视、眨眼质量、眼神光、眼神先于念头
- [ ] 角色开口时，声音提示词逐字粘贴；沉默时省略
- [ ] 状态，而非过程
- [ ] 表演段落里没有服装、镜头或色彩
- [ ] 任何地方都没有年龄词
- [ ] 群像反应错开；强者 = 静止，弱者 = 坐立不安
- [ ] 量表检查：这段段落能得 4 分以上吗？

# 第四部分 —— 完整示例

虚构角色；把它当作模式来用，而不是当作内容来用。

## 主档案

```
角色表演：VIKTOR。一名退休的夜班出租车司机，曾是业余拳手；沉重厚实的体格，脖颈粗壮，腰腹已经发软，塌鼻梁的脸上双眼上方横着旧疤组织；坐与站都带着低沉、扎根的重心，体重永远落在整只脚掌上。靠一台单一的引擎运转：几十年的等待——等客、等回合、等麻烦——把耐心炼成了他的武器。声音档案：低沉、沙哑、不慌不忙的男中音，带着工人阶级的粗粝，短句说得平淡而节省，事情越严重，声区落得越慢、越轻——他从不加快语速。关键身体习惯与小动作：掂量局面时让一枚旧硬币在指节上滚过；在说“不”之前有一次缓慢的、听得见的鼻息；当谎话在他眼前发生时，他完全静止，让一段长沉默去施压；他的默认面孔是一副眼睑沉重、百无聊赖的面具，遮掩着百分之百的注意力。眼神生命力：昏昏欲睡的、低垂的眼睛，眨眼缓慢而刻意，并持续进行安静的扫视——后视镜、手、出口——目光比头转过去早一拍落在说话者身上；眼神光偏弱但活着。行走风格：沉重、起伏的“老拳手步”，短促省力的步子，双肩放平，双手放松而随时待命，从不赶时间。然而，当有人在他身边抬手时，昏睡的面具在半秒内消失：下巴下沉，双手抬到一半，双脚找到旧日的站架——随即他回过神来，把这一切收起，面带窘迫。他的脸只有对流浪狗才真正柔软，他会从大衣口袋里掏东西喂它们。
```

**声音（VIKTOR 开口时逐字粘贴）：**

```
“工人阶级城市的口音，被几十年的夜班磨得粗粝。低沉、沙哑、不慌不忙的男中音；短促、平淡、省字的句子，夹着长长的、从容的停顿；平静且带着一丝被逗乐的意味，事情越严重声音越轻——从不变响。”
```

## 场景化改写

*场景：夜晚，VIKTOR 坐在他停着的出租车驾驶座上；后座一名紧张的乘客正在谎称自己带够了车费。*

```
VIKTOR 一动不动地坐在驾驶座上，沉重而扎根，透过后视镜看着乘客，而不是转过身去——他低垂的眼睛在后视镜、乘客的双手和门锁之间缓慢而安静地扫视，眨眼稀少而刻意，目光比头的移动早一拍落在后视镜上。那枚旧硬币在座椅扶手上、指节之间不慌不忙地走着；当乘客的说辞开始散架，硬币在滚动中途停住——他任由沉默悬在那里，用鼻子缓缓吸了一口气，听得见的那一种，然后用他低沉沙哑的男中音作答，比之前更平、更轻，从不加速。直到乘客的声音裂开，昏睡的面具才松开一丝：一次长长的呼气，一次缓慢的眨眼，硬币恢复滚动——耐心，此刻，选择了仁慈。
```

**这里发生了什么：** 步态在这里无关紧要（坐着），所以它的能量转移进了静止和硬币；标志性小动作保留了各自的触发条件（硬币 = 掂量局面 · 停住的硬币 = 作为标点的被打断动作 · 鼻息 = 拒绝 · 静止加沉默 = 对撒谎者的施压）；眼神生命力服从主档案，但被重新指向后视镜、双手、门锁；拍点变化可见（硬币停住 → 沉默 → 更轻的声音 → 变软）；而声音原封未动——它将被逐字粘贴进音频字段。

## 最终公理

1. 表演是压力之下的行为，不是情绪的演示。
2. 聆听比说话重要；反应比朗诵重要。
3. 情绪是一场赢了或输掉的挣扎的后果，而且它是有代价的。
4. 身体比词语聪明：当文本与身体冲突时，观众相信身体。
5. 强者静而无声；弱者慌乱喊叫。例外本身就是事件。
6. 每个小动作都需要触发条件；每个面具都需要裂缝。
7. 每场戏都是某个人的失败。如果没有人输，那就没有戏。
8. 潜台词不是被展示出来的——它是藏不住的。
9. 状态，而非过程；模型拍的是“是什么”，不是“正在变成什么”。
10. 拿不准时——删。更少的表演等于更多的真实。

# 附录 —— 表演任务直出块（ACTING TASK 法）

## 附一 ACTING TASK 直出块（场级工作卡）

核心公理：**表演任务 = 角色完全投入于自己达成目标的策略。** 它不是外部行为的描述（那是演结果，产死脸），也未必是肢体动作——策略可以完全活在眼睛里。

主档案管**人**（角色的永久事实源）；ACTING TASK 块管**场**（一场戏的推演工作卡）。用法：先用它把共同方向、动机、障碍与逐拍推演想清楚，再按 §场景化改写 折成流畅段落交付；若所用模型吃结构化块，也可整块直接使用。

```
ACTING TASK — [姓名]（他完全投入于自己达成目标的策略；工作发生在他的眼睛里）：
场景方向（全场共享、心照不宣）：[一句话]
动机（他的燃料）：[他为什么推动这个方向]
目标：[他个人的那一仗]
障碍：[什么在压这条线；裂开一道要付出什么代价]
策略：[他对对手做什么，把眼神工作写成行动]
逐拍推进：
— "[台词原句]" — [指向对手的动词 + 眼睛在核对什么]
— "[台词原句]" — [动词 + 眼神工作]
— [台词在哪里断裂（如果断裂）]
（安全线：视线始终投入在任务上——绝不出现冻结的、玻璃般的、失焦的直视；自然眨眼频率，演员会时不时眨眼湿润眼睛。）
```

块内规则：

1. **动词一律指向对手**；禁止把情绪形容词当指令（*"悲伤地" "紧张地"*）。
2. **不写面部编舞**（*"眉毛扬起" "嘴角颤抖"*）——外部描写只保留上面那一行安全线。
3. **没有人在演情绪；每个人都在演方向。** 观众透过压力收到情绪。
4. **防死眼安全线**允许且推荐保留一行（AI 模型的现实需要；完整论述见 §眼神生命力）。
5. **沉默角色的任务也写进块里。** 画面里每个角色都由此获得活着的眼睛——包括沉默的聆听者：聆听者的任务也是真实任务（*"判断他是不是认真的" · "等笑点落地" · "守护气氛"*；完整论述见 §聆听与反应）。
6. **逐拍推进钉在台词的真实字词上。** 剧本要求处，标出角色燃料耗尽、台词断裂的那一点——*断裂本身就是这场戏的演法*（跟车医护那句压着嗓子的"……可怜的混蛋"）。

## 附二 场景梯子 · 方法错误清单（发送前对照）

§坏表演图鉴 管的是**看得见的症状**；这份清单管的是**推演方法本身的错**。两者互补，发送前各过一遍：

- **任务只凭一句台词建起来**，而不是读完整场对白 → 先重读全场（梯子第 0 步）。
- **把影片的揭示 / 主题派给角色当任务** → 角色从不出演影片的目的——那些目的是*透过*他们达成的副产品。
- **场景目标与角色目标混为一谈** → 场景目标是全场共享的方向；角色目标是个人化的、各不相同的。
- **动机无视既定情境（given circumstances）**——在实验监狱实验室接了活的人已经在同流合污之中，演不了道德清白 → 重推动机。
- **开出眼睛 / 面部的编舞**，而不是把眼神工作写成有目的的行动 → 改写成指向对手的动词（*"检查对方两只眼睛里有没有信任的闪光"*）。
- **把情绪形容词当指令** → 换成能**产生**该情绪的那个任务。
