# 执行规范与方法边界

## 核心公理

**表演是压力之下的行为，不是情绪的展示。** 一个角色想要某样东西，有什么挡在中间，他们便行动去得到它。情绪是这场挣扎的副产品——绝不是你直接去写的东西。

## 定位与方法边界

- 本模块是**视频提示词之上的一个表演叠加层**：产出的段落放入一条视频提示词的 PERFORMANCE / CHARACTER ACTING（表演 / 角色演技）区块。
- **它不改变镜头、灯光、服装或调色** —— 这些归属 06 景别构图机位灯光 / 03 渲染表现 / 04 场景与人物设计。表演层只管身体与脸做什么。
- 本模块的产出最终要经 **12 技术语言转换** 净化后才进入提示词；表演层自身不输出最终提示词。

## 速览准则（QUICK FACTS）

*速览是路由辅助——规则请阅读所链接的子模块文件。*

- 写出**目标（objective）**（一个指向对手的动词），永远不要写状态——"让他招供"，而不是"生气" → [02 行为表演技艺]
- 每场戏 **2–4 次拍点（beat）变化**，每一次都在行为中可见：一次停顿、一次姿态改变、一次节奏改变、一次目光移动。整个镜头行为一成不变 = 表演扁平 → [02 行为表演技艺]
- **聆听胜过说话。** 反应在对手台词结束*之前*就开始；一个尖锐的问题配得上回答之前的一次微停顿 → [02 行为表演技艺]
- 身体承载生平：**重心、节奏、开放度、呼吸**——在任何心理刻画之前先设定全部四项 → [02 行为表演技艺]
- **手上任务（business）**——双手正在做的物理任务——杀死戏剧腔；一场戏里最重的重音，是角色**停下**它的那一刻 → [02 行为表演技艺]
- **距离即戏剧**；距离的改变*就是*一次拍点变化。地位是你**做**出来的，而地位**反转**（status break）是表演中最有趣的东西 → [02 行为表演技艺]
- **主档案（master profile）**为 150–220 词、一个段落、固定的块顺序，每个角色写一次，再按场景重写——绝不粘贴 → [02 行为表演技艺]
- 每个小动作（tic）都带有**触发条件**；每个面具（mask）都带有**裂缝**——每份档案至少一个"然而，当 X……"从句 → [02 行为表演技艺]
- **眼神生命力（eye life）是强制的，绝非可选**——微扫视（saccades）、眨眼质量、活的眼神光（catchlights）、眼神先于念头（eyes-lead-thought）。死眼睛是 AI 表演的头号破绽 → [02 行为表演技艺]
- 场景化改写**转换而不删除**：物理上无法发生的行为被移置到另一个出口，而不是被移除 → [02 行为表演技艺]
- **声音提示词是锁定的**——每个角色一条，逐字粘贴进音频字段，从不按场景改写 → [02 行为表演技艺]
- **状态，而非过程。** 模型处理不好过程，却拿得住状态："掷出中途、手臂已伸展"，而不是"伸手进去、掏出来、蓄力挥臂" → [02 行为表演技艺]
- 群像反应以**波浪传播，绝不同步**；强者静而无声，弱者坐立难安、高声喊叫 → [02 行为表演技艺]
- 15 种有名字的坏表演症状及其提示词级修复，以及一张 0–5 分自检量表——**每个英雄镜头都瞄准 4 分以上** → [02 行为表演技艺 · 坏表演图鉴]

## 表演体系的分层

| 层 | 子模块 | 控制什么 |
|---|---|---|
| **技艺**——角色为何去做任何事 | `02-行为表演技艺.md` | 目标、障碍、策略、拍点、潜台词、地位、手上任务 |
| 身份 | `01-角色身份与一致性.md` | 角色跨镜头如何保持一致、微表情词汇 |
| 肌肉 | `03-面部肌肉控制.md` | 面部动作单元（Action Unit）代码（AU12、AU6……） |
| 约束 | `04-表演约束与质量控制.md` | 生成瑕疵的预防措辞与正向替换 |
| 交付位置 | 视频提示词的 PERFORMANCE / CHARACTER ACTING 区块 | 本模块产出所填入的地方 |
| 前史 | （本体系不含，如需可另建） | 任何一场戏存在之前，角色是谁 |

用 `02` 决定身体**做什么**；用 FACS（面部动作编码系统）在特写里指定**哪些肌肉**来做。两者可以组合——在一篇按这些规则写成的段落里放进 FACS 拍点调度，就是当前引擎所支持的分辨率最高的表演。

## 子模块路由

| 子模块文件 | 何时进入 |
|---|---|
| `00-执行规范与方法边界.md`（本文件） | 起点：确立公理、边界与分层 |
| `01-角色身份与一致性.md` | 需要先锁定"这个角色是谁、长什么样、跨镜头如何不变"时 |
| `02-行为表演技艺.md` | 需要决定角色在一场戏里做什么、怎么反应、怎么说时 |
| `03-面部肌肉控制.md` | 需要特写级面部精度，用 AU 代码取代情绪词时 |
| `04-表演约束与质量控制.md` | 装配提示词前，按类别追加预防措辞时 |

**执行顺序建议**：00 → 01（定身份）→ 02（定行为）→ 03（特写补面部）→ 04（装配前预防）→ 交 12 转换净化。
