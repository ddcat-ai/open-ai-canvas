# 人物表演（模块 05）

> 主链定位：执行规范 → 身份一致性 → 行为技艺 → 面部肌肉(FACS) → 约束与质量控制。

## 做什么

本模块决定**角色的身体与脸在镜头里做什么**，产出填入一条视频提示词的 PERFORMANCE / CHARACTER ACTING（表演 / 角色演技）区块。

**方法边界**：它是视频提示词之上的**表演叠加层**，不改变镜头、灯光、服装或调色（那些归 06 / 03 / 04）。产出须经 **12 技术语言转换** 净化后才成为最终提示词，本模块不直接输出交付文件。

**核心公理**：表演是压力之下的行为，不是情绪的展示。写目标（指向对手的动词），不写状态。

## 基础引擎
本模块的底层方法论源：`engine/E05-人物表演.md`（本模块目录内，44 条，来自 book01/book03/book04）。
执行本模块前先查阅该引擎，取其判断依据、创作准则与反模式清单；引擎为只读源层，本模块负责执行流程。

## 执行流程

1. **读 00** —— 确立公理与边界，确认本模块只管表演层。
2. **定身份（01）** —— 建 Soul ID 与角色锚定块；硬性规则：身份块（静态）与运动块（时间/镜头）分离。
3. **定行为（02）** —— 写目标与障碍 → 排 2–4 次拍点变化 → 设定身体四项与手上任务 → 出主档案（150–220 词）→ 补眼神生命力。
4. **补面部（03）** —— 仅特写需要：把关键拍点的面部写成 AU 代码，与 02 的段落组合。
5. **过约束（04）** —— 按身体/面部/质感/时序等类别追加正向预防措辞。
6. **交 12** —— 本模块产出是内部表演层文本，必须经模块 12 转换净化后才进入提示词。

## 与其他模块的关系

- **上游**：04 场景与人物设计（人物资产、场景约束）→ 本模块在其上叠加表演。
- **并行**：06 景别构图机位灯光决定机位与光位，本模块决定表演；互不覆盖。
- **下游**：12 技术语言转换（净化 + 术语转换）→ 13 交付文件审核。
- **交叉**：09 音效中的对白轨与本模块的声音锁定规则相关——声音提示词每个角色一条，逐字粘贴，从不按场景改写。

## 硬规则速记

- 永远写目标（动词），不写情绪状态。
- 身份块与运动块必须分离，不可混写。
- 眼神生命力强制，非可选。
- 预防措辞一律写**正向句**（要什么），不写否定句。
- 声音提示词锁定，不按场景改写。
