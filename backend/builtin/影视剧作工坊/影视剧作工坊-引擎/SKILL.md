# 影视剧作工坊 · 基础引擎层（总索引）

> 定位：**整个工坊最底层的方法论源层的总索引**。方法论本体已**物理拆分到各模块目录内**（每个模块自带 `engine/`），本 skill 不重复存放模块视图，只持有：① 全局映射表、② 按书归档视图。
> 类比：模块是「执行程序」，引擎是「常识库」。模块决定怎么做，引擎解释为什么这么做、依据是什么。

## 落位原则：随模块自包含

方法论本体**不集中存放**，而是拆进对应模块，与模块 12 自带 `channels/` + `prompt/` 同构：

```
影视剧作工坊-06-景别构图机位灯光/
├── SKILL.md                      ← 执行层：定义流程
└── engine/E06-景别构图机位灯光.md  ← 基础层：提供判据（64 条）
```

好处：模块自包含、可单独分发、不依赖外部文件；改动某模块的方法论只影响该模块。

**454 条按模块切分后互不重叠**（各模块条数之和 = 各书条数之和 = 454），因此拆分不产生重复维护。

## 调用规则

1. **模块直接自查**：模块执行到需要判断依据时，读自己目录内的 `engine/E0X-*.md`，不经过本 skill。
2. **只读不重写**：引擎是源，模块只引用。若引擎与模块流程冲突，改模块，不动引擎。
3. **跨模块引用允许**：一次决策涉及多个模块时可同时读多个模块的 `engine/`（如一场戏的镜头设计可同时查 06 + 07 + 08 + 11）。
4. **出处可追溯**：每条方法论带 `> 出处：<书中章节/语境>`，深挖时回溯原书或 `by-book/`。
5. **引擎不进交付**：引擎是内部知识层，其原文不进入最终给模型的提示词。要进提示词的画面语言一律经模块 12 转换后输出。
