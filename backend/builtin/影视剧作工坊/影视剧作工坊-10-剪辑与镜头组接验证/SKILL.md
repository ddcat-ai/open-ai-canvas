# 剪辑与镜头组接验证（模块 10）

> 主链定位：连续性校验 / 剪辑语法与屏幕方向。

## 核心原则（总纲）

**镜头组接不是靠剪辑软件拼出来的，而是在三个层面上被主动保证的。**

1. **规划层** —— 全局观感与反复出现的资产只声明一次、一次锁定，逐场景提示词共享同一风格前缀与同一 @ 资产词表；序列的节奏与单调性在动笔前做预算。
2. **提示词层** —— 每条提示词自带边界锚：末帧锚、身份锚、承接状态、画外接续行。边界两侧的信息显式交接，不留让模型即兴发挥的空隙。
3. **管线层** —— 已采用的片段作为延续性参考回喂给下一次生成；链条深度有硬上限；每道接缝在生成之前就规划好，而不是留到剪辑里再解决。

## 剪辑判据（唯一：剪辑模式B）

**v1.1.3 起，组接判据唯一＝模式B·实拍学派（隔级切），缺省即此**：

- **~~默认判据（已废除）~~**：旧「相邻同主体级差 ≤1 级」判据 v1.1.3 废除，其文档中的规则语句已改写为隔级切口径。
- **模式B · 实拍学派（声明才启用）**：**隔级切**（「远全中近特，相邻景别不相切」）＋动接动＋180° 轴线/视线匹配＋反应镜头优先＋**Murch 六要素裁决序**（情绪 51% 可豁免几何连续性）——真实影视剪辑台语法。判据在 `editing/15`（总纲/选择判据/路由）＋`editing/16`（法则细则）。

两通道共享六套剪辑公式、§1.3–1.5 节奏预算、06/08 词表与装配交付；**互斥点只在景别级差方向与裁决优先序**（学派之争、场景之争，非对错之争）。机判 `chain.py cuts/split --mode b`，简写「剪辑模式B/剪辑B模式」路由（`wfkit/axis.py` SHORTHANDS）。

## 执行流程（按顺序跑，不要跳步）

**输入**：剧本 / 分镜清单（上游 07）+ 表演层产出（上游 05）
**输出**：一组彼此连通、可交付的多镜头提示词序列

1. **建连通分镜清单** → `01`
   - 写全局风格前缀（格式/灯光/色彩/镜头/皮肤/表演/物理/构图/连贯性/帧率音频），一次锁定，逐字前置于每条提示词
   - 建 @ 资产术语表：每个反复出现的资产一个稳定 @ 名 + **保真等级**（full-preserve / partial-preserve / attribute-transfer / loose-guide）
   - 多状态变体（如 `@s_hero_wet`）**预先刻意建好**，不能事后让模型补
   - 逐场景编号拆分（1a/1b、3a/3b/3c），每个 15 秒块自带完整前缀
2. **写单条提示词** → `02`
   - 先做单镜头 vs 多镜头决策；多镜头则算时长、给 LENS LOCK 与定时剪切
   - 严格按序书写：风格前缀 → Characters → Off-screen → Scene → CUT 1 / CUT 2 …
   - **画外接续行是让再入场合法的东西**，只承接一条提示词，连续两条缺席后删掉
3. **做跨片段续接** → `03`
   - 续接提示词按五条规则写；明确"必须延续的东西"
   - 链条式生产：每个场景三个输入；**链条上限 2 次延长，硬顶 3 次**
   - 每道接缝在生成前规划（干净接缝），屏幕合成时用 1:1 参考锁
4. **接缝出问题就修** → `04`
   - 先走症状决策树定工作模式，再用桥接骨架（两层撰写）或续接骨架 + 防重播短语
5. **过剪辑与连续性词汇** → `05`（剪辑模式B → `16`）
   - **模式分流**：默认按 `05`＋`08` 判据；声明「剪辑模式B」→ 判据换挂 `editing/16`（隔级切/动接动/轴线视线/Murch 裁决），机判 `--mode b`
   - **双重对比**：每个剪辑同时换景别 *和* 镜头性格，绝不在剪辑两侧重复同一模式（默认判据）
   - **重新锚定**：剪辑回到已确立空间后，重新说明谁在哪里、面朝哪方，且运动方向不翻面
   - **出画即隐性剪辑**：出画者在本镜头余下部分视为不存在，不同镜编排"出画 + 再入画"
   - 多条次微切片组装：逐条挑出每个条次最好的 1–3 秒再拼；L/J 切用声音桥磁化接缝
   - 写 next-shot 时以**相对上一镜头的机位**描述，不用绝对描述
6. **装配与剪辑** → `06`
   - 按组装工作流装配；剪辑五阶段 + 画面锁定；调色**先统一、后诠释**
   - 用截图作为工作记忆
7. **失败时查图谱、走阶梯** → `07`
   - 症状 → 成因 → 修复对照表
   - 重试四级升级，**每一级都是终点，绝不在同一级上循环**

## 硬规则速记

- 全局风格前缀只声明一次，逐字前置到每条提示词——改一次，处处生效。
- @ 资产必须带保真等级；没有等级 = 模型当天想保多少是多少。
- 多状态变体预先建，绝不事后补。
- 每条提示词自带四个边界锚：末帧锚、身份锚、承接状态、画外接续行。
- 链条延长上限 2 次，硬顶 3 次；超限从权威参考重新锚定。
- 交付前必做节奏预算 + 单调审计。
- **双重对比**——每次剪辑同时换景别与镜头性格；相邻两镜不允许同一模式重复。
- **出画即隐性剪辑**——出画者在本镜余下部分不存在；禁止同镜"出画 + 再入画"。
- **重新锚定**——回到已确立空间必重新点名谁在哪、面朝哪；屏幕方向不翻面。
- 失败时改的是计划，不只是骰子；同一级绝不循环。
- **剪辑双通道**：默认＝包内既有判据（级差 ≤1）；「剪辑模式B」声明才切换（实拍学派，`--mode b`），两通道不同时生效。
