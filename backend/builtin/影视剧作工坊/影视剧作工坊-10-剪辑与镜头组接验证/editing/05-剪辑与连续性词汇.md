# 五、剪辑与连续性词汇

- **双重对比（Double contrast）**——每次剪辑都同时改变景别与镜头性格（手持 / 固定 / 稳定跟拍 / 摇臂 / 航拍）。绝不在同一剪辑两侧重复同一模式。「景别变没变」按**六级法则尺**归档判定（06 `shotlang/01-景别.md` §1.6）：全景/远景与全身归远景档、中远景/牛仔/中景归中景档、大特写/微距/插入归大特写档——不设最小级差；坏例＝中景手持→近景手持（镜头性格未变），好例＝中景手持→大特写固定。同主体级差纪律另由隔级切管（`editing/16` §一，十级级序），两把刻度不可混用。
- **镜头性格（Camera character）**——运动方式本身：手持 | 固定/锁定机位 | 稳定跟拍 | 摇臂/垂直 | 航拍/无人机。
- **重新锚定（Re-anchoring）**——任何剪辑回到已确立的空间后，重新说明谁在哪里、面朝哪个方向。若剪辑前角色从左向右移动，剪辑后仍是同一方向。
- **出画即隐性剪辑**——角色一旦出画，在本镜头的剩余部分中即视为不存在。绝不在同一条连续镜头内编排"出画 + 再入画"。
- **因果动机的插入镜头**——亚秒级（0.3–0.5 秒）的静态细节，观众明白自己"为什么"看到它。始终点名主体（"他的手抓着金属"），绝不用泛指（"一只手"）。
- **多条次微切片组装**——一场成片往往由多个条次剪成，而不是单个保留片段：勺子来自一个生成结果，火焰来自另一个，倾倒来自第三个，啜饮来自第四个。逐条浏览每个条次，挑出其最好的 1–3 秒，把切片存好，再行组装。
- **L 切 / J 切**——下一镜头的声音先于画面进入（L），或反之（J）。L 切的**声音桥**：让出画镜头的声音延续过剪辑点，使入画画面落在一个已经确立的声音环境之中。
- **重切（Smash cut）**——突兀、生硬、无过渡柔化的剪辑；**硬切**——标准直切。
- **甩摇转场（Whip-pan transition）**——用一次单一运动中的模糊横摇衔接两个镜头。
- **相对于上一镜头的机位连续性**——规划下一个镜头时，以*相对于上一镜头机位*的方式说明机位（`摄影机现在在他身后，面朝他此前面朝的方向`），而不是绝对描述——避免剪辑点使观众迷失方向。
- 匹配剪辑与锚点动作剪辑见 `01-规划层-连通分镜清单.md` §1.6；180 度轴线规则与越轴规则见《构图·纯技术文档》（即 06 的 `shotlang/03-构图.md`）。

## 5.1 剪辑记法

在提示词内部表达时间结构与剪辑结构的记法约定：

- **`[0-Ns]` 方括号记法**——单条连续镜头内部各阶段的时长区间前缀：`[0-3s] 主体入画，[3-7s] 摄影机推近`。用于单镜头连续运动的逐秒节拍。
- **`建立 → 台词 → 反应` 箭头记法**——面向多剪辑点对话或节拍序列的剪辑流速记，读作"建立镜头，然后台词/对白，然后反应镜头"。
