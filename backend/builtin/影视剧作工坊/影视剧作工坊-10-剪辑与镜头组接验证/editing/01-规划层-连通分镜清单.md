# 一、规划层：连通分镜清单

把剧本编译成**一份彼此连通的分镜清单**，而不是一堆散装提示词。散装提示词之间没有任何共享上下文，连续性只能靠运气；连通清单让 25 条提示词保持同步。

## 1.1 三层结构

自上而下三层，每条逐场景提示词都同时继承前两层：

1. **全局风格前缀（Global Style Prefix）**——一块套用到每条提示词上的单一风格块，锁定影片的全局观感：格式/分辨率、灯光教义、色彩配比、镜头/快门、皮肤真实感、表演基调、物理、构图、连贯性、帧率与音频惯例。改一次，处处生效。它在文档中出现一次，**并且**逐字前置于每条提示词的拷贝块——这样任何一条提示词拷出去都能独立生效，无需重新拼装。
2. **@ 资产术语表**——每个反复出现的资产（演员/道具/场地）只声明一次，起一个稳定的 @ 名，生成时用同一个名字挂载对应的图片：

```
@hero — 主角                    @boss — 配角
@headphones — 产品              @sneakers · @bag — 道具
@kitchen · @stadium · @street — 场地
@s_hero — 运动感主角            @s_hero_wet — 跑步后汗湿的主角
@music_track (audio_1.wav) — 动作锁定到这条节拍
```

   **多状态变体要有自己的锁定条目**（@s_hero_wet），并且要预先刻意建好——事后再让模型"给他上汗"，它就会即兴发挥，脸就漂了。
   **每条条目还带一个保真等级**——*full-preserve（全保真）* / *partial-preserve（部分保真，指明部位）* / *attribute-transfer（属性迁移，指明目标）* / *loose-guide（宽松参考）*。每行一个词就够（`@headphones — product, full-preserve`）。没有等级，"用 @image4 做外套"就意味着模型当天想保多少是多少。
3. **逐场景命名的提示词**——每个场景编号（1、2、3……），拆成命名的 15 秒提示词（1a、1b、2a）。长场景拆成 3a/3b/3c，各自是带完整风格前缀与角色块的 15 秒块，连贯性跨块保持。

## 1.2 逐场景提示词法则

每条提示词严格按此顺序自上而下书写：

```
[风格前缀 — 完整块，逐字照抄（或该场景的覆盖版）]

Characters（角色）：
[只写本条提示词中的角色。@ 名 + 锁定的外貌描述 +
 承接状态——上一场留下的湿发、单肩背带、除非画面里换了否则同款服装。]

Off-screen（画外，仅当有人刚离场时写）：
[在上一条提示词中出现、但本场缺席的所有人：出场侧 + 最后可见状态——
 "Bo——从画面左侧离场，仍抱着板条箱。"只承接一条提示词，
 连续两条缺席之后就删掉。]

Scene（场景）：
[1–2 句。地点、时间，以及地理空间走位——每个角色相对场地与彼此的位置。]

CUT 1 — [景别、视场角（FOV）、镜头运动]：
[节拍级精确动作：手势、视线、呼吸、微停顿；镜头在做什么；
 光在做什么；如有相关，写剧情内音效（SFX）。]

CUT 2 — …
```

**画外接续行（Off-screen line）是让再入场合法的东西。**承接状态只管画面里的人；它对刚离场的人只字未提，而从错误一侧再入场是经典的连贯性破绽——观众说不出哪里不对，却能先感觉到。为每个离场角色写一行，下一条提示词的正确入场侧与手部状态就白拿了。

## 1.3 15 秒信封与密度法则

每条提示词以 15 秒为目标（生成模型产定长片段——把剪切设计得填满它，不要用死时间凑）。多数 15 秒提示词容纳 1–3 个剪切。场景更长就拆 3a/3b/3c。

**当以下条件全部成立时，把镜头行归进同一条提示词：**

1. 画面中是同一组角色
2. 同一场地（或其子区域）
3. 一个连续的情感/时间单元——没有时间跳跃，没有情绪急转
4. 在 ≤15 秒的银幕时间内可呈现
5. 合并后的提示词仍在实用长度限制之内（中文约 1,800 字符硬上限；英文块提示词要长得多）

**当以下任何一条触发时，拆成独立提示词：**

1. 场地之间的硬切（公寓 → 回忆）
2. 重要角色的进出场改变了在画面角色名单
3. 需要独立信封的镜头/机位变化（大远景建场 → 紧插入）
4. 值得独占 15 秒的表演弧线——横跨 5–7 个节拍逐渐堆起的反应戏，绝不与动作捆绑。**不要把悲伤撕碎**：一段连续的情感崩溃就是一条提示词，哪怕剧本把它写成三行。
5. 对道具或屏幕的插入/切出镜头（它们独享大特写提示词）

**每条提示词的复杂度预算**：强动作超过 2 个 · 镜头运动超过 2 个 · 重要角色超过 3 个 · 复杂 VFX 事件超过 1 个 · 场地变化超过 1 次——任何一条成立，都意味着这个场景还想要一个信封。时长阶梯：4–8 秒 = 一个强动作 · 8–12 秒 = 一个动作 + 一次揭示 · 12–15 秒 = 2–3 个简单节拍 · 复杂打斗/追逐/变身 = 多条提示词。15 秒是默认信封，不是紧身衣——节拍实际只填满 4–8 秒时，生成一条刻意更短的片段，而不是拿死时间凑满。

**拿不准时，宁可提示词更多、信封更短**——模型处理紧凑提示词好过过载提示词，而且可以按顺序逐条跑。

## 1.4 序列节奏预算（交付前的整段检查一）

动笔之前先做预算：按每剪切约 4–6 秒的平均值折算总时长，得到这部片子能承载的剪切数，并为最值钱的时刻**预留一个刻意更长的主打长镜（6–8 秒）**。粗略档位：

| 总时长 | 剪切数 |
|---|---|
| ≤15 秒 | 约 3 个 |
| 约 20 秒 | 4–5 个 |
| 约 30 秒 | 约 6 个 |
| 约 45 秒 | 7–8 个 |
| 约 60 秒 | 9–11 个 |

然后核对总和：写明的剪切时长必须**精确加总等于所要求的总时长**。加不平的预算会交付出死时间或一个不可能的剪切，而且这个错误在上时间线之前不可见。

## 1.5 单调审计（交付前的整段检查二）

草稿写完后，把每个剪切只取"景别 + 镜头运动"那一行，自上而下当作一列来读。**不允许连续三个剪切共享同一景别且同一镜头运动**；当每个剪切都读作"中景，缓慢推入"时，要变的是镜头的*功能与尺度*，而不只是时长。逐条审阅根本看不见这种失败；只有把这一列当作序列来读它才会显形，而它是生成式分镜清单最单一的常见破绽。

## 1.6 匹配剪辑：重复的锚点动作

当独立生成的场景必须剪在一起时，让相邻场景的结尾与开场落在**同一个手势**上（比如按耳机的那个动作）——复用的动作多数时候能让它们"在动作上剪切"。这是让两条独立生成的片段天然可剪的最低成本手段。

## 1.7 改一处全局生效与逐场景覆盖

像编辑一份连通文档那样对待修订，永远不要当成 20 次散装对话：

- **"改提示词 1a，做 X"** → 只改那一条。
- **"把风格前缀改成 Y，到处应用"** → 一遍传播到每条提示词的拷贝块。
- **逐场景覆盖** → 单个场景可以打破全局观感（例如场景 2 体育场："明亮，货真价实的正午烈日，硬边阴影"），只替换那一条提示词的风格前缀灯光行，其他所有场景保持全局前缀。覆盖是对某条提示词前缀的局部编辑，不是对全局块的修改。

## 1.8 空间调度图——多角色场景的俯视调度

多角色场景中，AI 视频模型会凭空捏造空间关系，除非用绝对表述声明出来。几何一旦漂移，镜头与镜头之间往往越剪越糟。

**什么时候要画调度图**：同一场景 2 个以上角色 · 关键道具放在某个特定表面上 · 复杂的镜头几何（哪个镜头从哪里拍、环绕运动、每次剪切之间视线的改变）。

**调度图上要画什么**：房间轮廓（墙、桌、门）· 角色起始位置（姓名首字母标记）· 视线箭头 · 道具精确位置 · 关键距离（约 X 米）· 方位标签（FL/FR/BL/BR，以声明的主视角为基准）。

```
                      [窗户]
                          |
  [桌子]    A(↓东)        |
    ┌─┐                   |        B(↑北)
    │ │       约2米        |          @
    └─┘                  约1.5米
                          |
                       [门]
                          |
                  （机位，西墙）
```

把调度图翻译成提示词里的绝对空间声明——"角色 A 站在桌子后面，朝东面向窗户；角色 B 站在距她 2 米处，朝北面向门"——对遵循度而言，远胜于"角色 A 在桌子附近，角色 B 在旁边"。
