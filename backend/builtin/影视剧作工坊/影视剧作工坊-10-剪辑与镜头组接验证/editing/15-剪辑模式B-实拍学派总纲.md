# 剪辑模式B · 实拍学派总纲

> **v1.1.3 改定（作者指令）：旧「级差 ≤1」默认判据废除，本通道（剪辑模式B·实拍学派）为唯一组接判据**；缺省即按本通道判，声明「剪辑模式B」同效。下文对照表保留仅作沿革记录。

## 〇、双通道定位

**同一部片子的镜头组接有两条并行通道，按声明二选一，不改默认。**

| | 默认判据（包内既有） | 模式B · 实拍学派 |
|---|---|---|
| 产生语境 | AI 生成视频——每镜由模型从零生成，跨镜一致性是最大风险 | 真实影视剪辑台——素材已存在，风险在「切了像没切」 |
| 防什么 | 防「变化过度」：级差拉大→主体/轴线/光影断裂 | 防「变化不足」：级差太小→似切非切的跳切感 |
| 景别级差判据 | ~~级差 ≤1~~（v1.1.3 已废除） | 相邻同主体**隔级切**（相邻级差=1 须豁免；同景别直切禁） |
| 裁决优先序 | 连续性优先（法则一~十一） | **Murch 六要素**：情绪 51% > 故事 23% > 节奏 10% > 视线 7% > 二维 5% > 三维 4%——情绪可豁免技术连续性 |
| 划分档位默认 | 漫剧档（微切片组装，均切长 2.5–4s，AI 遮畸变技法） | 通用档（§1.4 基准，均切长 4–6s，实拍节奏预算） |
| 共享底座 | 六套剪辑公式、§1.3 时长阶梯、§1.4 加总/主打长镜、§1.5 单调审计、06/08 词表、装配与交付 | 同左（这些判据本就出自实拍剪辑） |

**两通道是场景适配之争，不是对错之争**：隔级切口诀是实拍学派的合理经验；级差 ≤1 是 AI 生成语境的适配规则。口诀担心的问题（变化不足）在默认判据里由「同景别直切须声明 jump cut＋单调审计＋双重对比」覆盖。

## 一、选择判据（何时走 B）

**命中任一即声明剪辑模式B；一条都不中就留在默认判据**：

| 情形 | 理由 |
|------|------|
| 素材是**已拍摄/已生成完毕的成段 footage**（二创、混剪、实拍转代理） | 剪辑台语境，隔级切学派的本场 |
| 成片要投**真实影视感**评审（正片感、影展感） | 评审预期建立在实拍剪辑语法上 |
| 片子以**情绪蒙太奇/表演反应**为主导（大量反应镜头、视线剪辑） | Murch 裁决序的主场：情绪与故事高于几何连续性 |
| 用户**点名「剪辑模式B」/「剪辑B模式」/「实拍学派组接」** | 声明即路由，不再判 |

**反之留在默认判据**：AI 逐镜生成的漫剧/短剧默认线（一致性优先）、微切片组装节奏、还没有参考锁定保障的长跳级序列。

## 二、触发与机判路由

| 入口 | 落点 |
|------|------|
| 简写「**剪辑模式B**」「**剪辑B模式**」（01 SKILL.md §简写触发词表补遗） | 模块 10 B 通道 → `editing/16` 判据 + `chain.py cuts/split --mode b` |
| `chain.py cuts <spec.json> --mode b` | 人工组接按实拍学派判（隔级切/动接动/轴线/正因） |
| `chain.py split <总时长> --rhythm … --mode b` | 划分按通用档（未显式给 `--profile` 时），其余算法同 |
| `chain.py plan` / `wfkit/axis.py` SHORTHANDS | 打【简写命中】行 |
| pipeline `spec["cuts"].editing_mode` / `spec["split"].editing_mode` | `"b"` 时对应站点按 B 判 |

**默认不变式**：`--mode` 缺省＝`a`，一切现行行为逐字节不变（回归基线）。

## 三、执行流程挂点（模块 10 七步走法不变，两处换判据）

1. 连通分镜清单（`01`）——不变，双通道共用
2. 单条提示词（`02`）——不变
3. 跨片段续接（`03`）——不变
4. 接缝修复（`04`）——不变
5. **剪辑与连续性词汇（`05`→B 时改挂 `16`）**：默认判据用双重对比/重新锚定/出画即隐性剪辑；模式B 用隔级切/动接动/轴线视线/反应镜头/Murch 裁决（`editing/16`）
6. 装配与剪辑（`06`）——不变
7. 失败图谱与重试阶梯（`07`）——不变

13 `review/16` **法则四按模式分流**：默认判「级差>1 且无过渡」；模式B 判「同主体级差=0/1 且无豁免」。故事板机检第 10 项同口径分流（`storyboard-schema.md`）。
