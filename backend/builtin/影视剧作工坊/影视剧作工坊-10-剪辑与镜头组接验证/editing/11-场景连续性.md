### SCV 场景多角度空间包 / Scene View Package

`SCV` 用来解决“只有一张场景母图，反打、回切、横移、窗内外和柜台两侧容易穿帮”的问题。它是场景母版的空间补充，不是新场景，也不是首帧图。

启用等级：

1. **普通场景**：只需要 `SC` 单张空场母版，不强制 SCV。
2. **核心场景**：建议 SCV，例如主角家、便利店窗边、办公室、医院病房、餐厅包间、审讯室。
3. **高穿帮场景**：必须 SCV + SB + MAP；包括玻璃窗、吧台、柜台、车内外、门框内外、栏杆内外、镜面反射、双人对话反打、切出去又切回来的同一空间。

命名结构：

```text
SCV001_SC001_场景名_多角度空间包
SC001_PLAN_俯视空间图
SC001_V01_正向空景（主入口/主拍摄方向看空间）
SC001_V02_反向空景（从对面反打看回来）
SC001_V03_左侧空景（锁定左墙、窗、通道、家具侧面关系）
SC001_V04_右侧空景（锁定右墙、柜台、门、道具位置）
SC001_DETAIL_关键道具灯光材质参考（可选）
```

每张图职责：

- `SC001_母版图`：锁定整体美术、空间气质、固定家具、主光源。
- `SC001_PLAN`：锁定门窗、家具、可走区、不可移动区、摄影机安全区；不追求成片美感，追求空间准确。
- `SC001_V01-V04`：锁定不同拍摄方向看到的空场空间；不得新增门窗、桌椅、柜台、货架或改变内外侧关系。
- `SC001_DETAIL`：只补关键材质、灯具、招牌、柜台、窗框、特殊道具的近景参考；不替代母版。
- `SB`：锁定内外侧、柜台两侧、玻璃两侧和禁止区。
- `MAP`：锁定人物点位、移动路线和摄影机安全区。
- `FF`：只锁定某一段第 0 秒画面，不替代 SCV。

生成顺序：

```text
1. 先写场景空间解析卡。
2. 生成或确认 SC001 场景母版图。
3. 生成 SC001_PLAN 俯视空间图。
4. 基于母版图 + 空间解析卡，生成 V01-V04 多角度空景。
5. 检查四张图是否与母版一致：门窗、家具、光源、通道、内外侧不能冲突。
6. 通过后建立 SB / MAP / CL。
7. 再交给 04 选择每个镜头的推荐场景角度图。
```

多角度空景 prompt 模板：

```text
生成同一场景的空场景多角度参考图，不出现任何人物、主角、顾客、路人、群演、车辆或动态物。保持与 SC001 场景母版完全一致的空间结构、固定家具、门窗位置、光源方向、材质、色调和透视关系。当前视角为：____（V01 正向 / V02 反向 / V03 左侧 / V04 右侧 / PLAN 俯视）。画面只作为空间参考，要求门窗、桌椅、柜台、货架、沙发、灯具和主要通道位置稳定，不重新设计场景，不新增家具，不改变内外侧、柜台两侧、玻璃两侧和可走区域。
```

负面提示词：

```text
不要出现人物、顾客、路人、群演、车辆或动态人群；不要改变门窗位置；不要新增桌椅、货架、柜台、沙发或通道；不要把吧台/柜台/窗边桌改成双面餐桌；不要改变玻璃内外侧、柜台内外侧、车内外关系；不要把空间变成另一个地点；不要加入剧情动作；不要生成随机文字、水印、Logo。
```

SCV 验收标准：

- V01-V04 都必须是空场。
- 门、窗、柜台、桌椅、沙发、货架、灯具的位置不能互相矛盾。
- 光源方向要继承 CL 光影设计卡；如果尚无 CL，则至少继承母版图的主光方向。
- PLAN 与 V01-V04 不一致时，以用户确认的母版图和空间解析卡为准，重做冲突角度。
- SCV 角度图可以作为 `@图N` 交给 04/06，但必须在参考图用途映射表写清：只参考空间角度、透视、固定物和光源方向，不参考人物、人群、剧情动作或首帧构图。

### 空间侧别锁定卡 / Boundary & Side Lock

当场景存在“内外同时可见”或“桌台/玻璃/柜台两边都像能坐人”的情况时，必须建立 `SB` 空间侧别锁定卡。典型场景包括便利店窗边、餐厅落地窗、吧台、柜台、车窗、公交站玻璃、医院前台、审讯室玻璃、阳台栏杆、门框内外、镜面反射。

```markdown
# SB001_场景名_空间侧别锁定卡

## 1. 绑定信息

- SB 编号：
- 绑定场景：SC001_场景名
- 绑定场景母版：@图N / SC001_场景名_母版图
- 适用大分镜：B01-B03

## 2. 分界面定义

- P1 = 玻璃窗平面 / 门框平面 / 柜台边缘 / 吧台边缘 / 车窗平面 / 栏杆线
- P2 = 另一条重要边界（如有）
- 分界面是否可穿越：不可穿越 / 只可从门口 D1 穿越 / 剧情允许后才可穿越

## 3. 侧别命名

- IN = 室内侧 / 店内侧 / 车内侧 / 柜台内侧 / 暖光侧
- OUT = 室外侧 / 街道侧 / 车外侧 / 柜台外侧 / 冷雨侧
- CAMERA = 摄影机所在侧：IN / OUT / 玻璃外侧 / 柜台外侧
- SUBJECT = 主体必须所在侧：IN / OUT / 柜台内侧 / 吧台内侧

## 4. 人物允许区

- CH001 允许区：如 `IN-S1=玻璃后方店内吧台座位`，身体、手臂、脸、手机、餐盒都在 IN 侧。
- CH002 允许区：
- 群演允许区：

## 5. 人物禁止区

- 禁止 CH001 出现在 OUT 街道侧、玻璃前方、吧台外侧、窗外桌面一侧。
- 禁止身体穿过 P1 玻璃平面。
- 禁止把玻璃生成在角色背后，导致角色跑到窗外。
- 禁止把吧台改成双面餐桌，除非剧本明确。

## 6. 交给 04/06 的硬约束句

- 场景句：摄影机位于 ____ 侧，透过/越过 ____ 分界面看向 ____ 侧。
- 人物句：角色必须位于 ____ 侧的 ____ 点位，身体完整处在该侧。
- 禁止句：不要让角色跨过 ____ 分界面；不要让角色出现在 ____ 侧；不要改变内外关系。
```

示例：

```text
SB001_便利店窗边_内外侧：P1=雨水玻璃窗平面，P2=窗边吧台边缘。IN=便利店室内暖光侧，能看到货架和冰柜；OUT=街道冷雨侧，能看到路面反光和蓝色路灯；CAMERA=OUT 玻璃外侧，透过雨水玻璃看向店内。角色必须坐在 P1 后方的 IN-S1 店内窗边吧台座位，身体、脸、手、手机和餐盒全部在店内暖光侧；禁止坐到 OUT 街道侧、玻璃前方、吧台外侧，禁止身体穿过玻璃，禁止把窗边吧台改成双面餐桌。
```

### 场景光影设计卡 / Lighting Bible

当场景会进入 AI 视频分镜或 Seedance 2.0 提示词时，必须为核心场景建立 `CL` 光影设计卡。它不是一句“电影级布光”，而是给 04/06 继承的可执行布光母版。

```markdown
# CL001_场景名_色彩光影 光影设计卡

## 1. 适用范围

- 绑定场景：SC001_场景名
- 适用时段：白天 / 黄昏 / 夜晚 / 雨夜 / 梦境 / 回忆
- 情绪功能：压迫 / 暧昧 / 孤独 / 危险 / 温暖 / 神性 / 悬疑
- 参考资产：@图N / 场景母版 / 调色参考

## 2. 光源结构

- 主光 Key Light：方向、角度、高度、软硬、色温、照亮对象
- 辅光 Fill Light：是否存在、强弱、是否只保留少量暗部细节
- 轮廓光 / 逆光 Rim or Back Light：从哪一侧勾边，勾出头发、肩线、侧脸或道具边缘
- 背景光 Background Light：背景哪个区域有亮面，是否形成空间层次
- 实景光 Practical Light：画面内可见光源，如台灯、霓虹、屏幕、烛光、路灯
- 环境光 Ambient Light：整体冷暖、是否低照度、是否禁止整体提亮

## 3. 亮暗区域

- 主要亮区：谁的脸、哪只手、哪个道具、背景哪一块必须亮
- 主要暗区：哪些墙面、走廊、前景、人物背光面必须暗
- 明暗反差：低 / 中 / 高；可写“脸部明暗比约 1:2 / 1:3 / 1:4”
- 阴影边缘：柔和过渡 / 清晰硬边 / 窄条状阴影 / 百叶窗切割阴影
- 高光与反光：眼神光、桌面反光、雨地反光、金属高光是否保留

## 4. 空气与光束

- 是否有薄雾 / 尘埃 / 雨雾 / 烟气
- 是否出现丁达尔光效：光束从哪一侧打入，穿过什么介质，落在哪个区域
- 是否允许镜头光晕、眩光、过曝边缘

## 5. 连续性约束

- 后续分镜必须继承的光源方向：
- 后续分镜必须继承的亮暗分布：
- 不允许改变的色温 / 母题色：
- 禁止项：不要整体打亮、不要新增无来源光、不要把夜景变白天、不要让人物双脸全亮、不要丢失轮廓光。
```

光影设计卡必须和场景母版绑定。场景换了，光影可以重建；同一场景连续或回切，优先继承最近一次光影设计卡，除非剧本明确换时段、换灯、断电、开灯或情绪进入新阶段。

### 场景资产红线

- 同一场景不能每次生成都变成新空间。
- 场景定稿图和场景母版图默认必须是空场景；不要把路人、群演、顾客、学生、车流等动态元素烘焙进 SC 图片资产。
- SCV 多角度空间包必须继承同一个 SC 场景母版；V01-V04 不能变成四个不同空间，不能新增门窗、桌椅、柜台、货架、沙发或改变主光方向。
- SCV 只解决“从不同方向看同一空间”，不解决人物站位、运动路线和第 0 秒构图；这些分别交给 MAP、SB 和 FF。
- 公共空间需要人群时，必须另建 `CR` 人群/群演调度卡，由 04/06 在视频提示词里动态生成；不要让人群污染场景母版。
- 玻璃、门窗、柜台、吧台、车窗、栏杆、镜面等场景必须判断是否需要 `SB` 空间侧别锁定卡；不要只写“窗边、桌边、吧台边”，必须写清角色在分界面的哪一侧。
- 如果角色应在室内、店内、车内、柜台内侧，必须写对应禁止区：不得出现在室外、街道侧、玻璃前方、柜台外侧、窗外桌面一侧。
- 重要场景必须有“空间关系”说明，否则分镜容易轴线混乱。
- 分镜中跨段连续的场景，必须使用同一个 SC 编号。
- 调度图不能重新设计场景，只能在场景母版的空间关系上加标注。
- 多角度空间包不能替代调度图；反打和横移镜头需要 SCV 角度图，但人物走位仍必须由 MAP 点位表约束。
- 同场景连续或回切时，必须优先读取场景母版、空间解析卡和最近一次场景状态。
- 同一场景连续或回切时，必须优先读取 `CL` 光影设计卡；不要让模型自动补一盏无来源的面光。
