# 剪辑模式B · 组接法则（实拍学派）

## 〇、总则三条

1. **切必有正因**（Dmytryk 法则一）：每一刀都要说得出理由——新信息、反应、节奏拍、视线引导。说不出理由的刀，不管切点多准都是坏刀。
2. **每镜只有一个最佳切点**（Dmytryk）：切点不是区间是点；找不到这个点就先别切。
3. **Murch 裁决序高于几何连续性**：情绪 51% > 故事 23% > 节奏 10% > 视线追踪 7% > 二维平面 5% > 三维空间 4%——当情绪、故事、节奏三者都成立时，允许在二维/三维连续性上破格（这是与默认判据最根本的分歧，默认判据里连续性是硬锁）。

## 一、景别 · 隔级切（本通道核心判据）

级序沿 06 景别表十级：**大远景 → 全景/远景 → 全身 → 中远景 → 牛仔 → 中景 → 中近景 → 特写 → 大特写 → 微距**；**插入镜头（INS）/空镜为桥镜，不计级**。

同主体相邻镜头：

| 级差 | 判定 | 处理 |
|------|------|------|
| 0（同景别直切） | **禁** | 插入 INS/空镜缓冲，或声明 jump cut（焦虑感）＋豁免理由 → 降 WARN |
| 1（相邻两级，如全景→中景） | **须避免**（变化太小，似切非切） | 隔级切；确需保留须带豁免理由（如牛仔镜姿态镜独立成拍）→ 降 WARN |
| ≥2（隔级，如全景→近景） | ✅ **标准操作** | 直切合法——这正是「远全中近特，相邻景别不相切」口诀的执行 |

- **递进式句型**（隔级切的组织方式）：前进式（远→全→中→近→特，步步深入）、后退式（特→中→远，逐步远离）、片段式（同景别节奏重复须过 §1.5 单调审计）。
- **30° 法则**（机位版隔级）：同主体相邻镜头机位夹角 <30° ≈ 同机位微移，产生跳切感——隔级切在机位维度上的等价判据。
- **INS/空镜的桥梁作用**：任何级差违例，只要两镜之间插了一个 INS/空镜，级差链重置（INS 不计级、不参与前后级差计算）。
- **豁免字段**：镜条目带 `豁免`（或 `transition_note`）理由（揭示镜/主体变更/动作节拍打断等）→ FAIL 降 WARN，如实记录。
- **与六级法则尺的分工**（v1.1.4 注）：双重对比的「景别变没变」按六级法则尺归档判定（06 `shotlang/01-景别.md` §1.6）；本判据的**级差判始终按上文十级级序**，不按法则尺归档——两把刻度不可混用。

## 二、切点 · 动接动与反应镜头

| 法则 | 内容 | 书源 |
|------|------|------|
| **动接动**（cut on action） | 切点选在主体动作进行中，观众被动作吸走注意力，察觉不到切换 | Dmytryk 法则三；E10 卡茨 action cut 同源 |
| **连切后换平面** | 连续剪切后的第一刀必须换平面（景别/角度/高度变格），不能同构重复 | Dmytryk 法则五 |
| **反应镜头优先** | 表演在听者脸上——台词落在说话者，情绪落在反应者；该切反应时切反应，不是切说话 | Reisz《The Technique of Film Editing》对话剪辑章 |
| **每刀新信息** | 下一个镜头必须带来上一镜没有的信息（动作推进/揭示/反应），否则违反总则一 | Dmytryk 法则一的具体化 |

## 三、空间 · 轴线与视线

- **180° 轴线**：对话/动作场机位保持在轴线一侧；越轴必须给缓冲——中性镜（正/背面机位）、运动越轴（镜内越）、切出再入（INS/空镜桥）。无缓冲越轴 = WARN（机判在声明了朝向字段时检查）。
- **视线匹配**（eyeline match）：A 看向画外 → 下镜 B 的视线方向与 A 的注视方向衔接；正反打与反应镜头强制。E10 卡茨「视线剪辑」同源。
- **出画即隐性剪辑**：沿用 editing/05 同名法则（两通道共享——出画者在余镜不存在，再入画须换镜编排）。
- **屏幕方向不翻面**：同主体连续镜头运动方向/朝向声明不得无故反转（相对机位描述衔接 editing/05 的「相对上一镜头机位」记法）。

## 四、裁决 · Murch 六要素

| 优先 | 要素 | 权重 | 判问 |
|------|------|------|------|
| 1 | 情绪 Emotion | 51% | 这一刀此刻对观众的情绪对吗 |
| 2 | 故事 Story | 23% | 这一刀推进叙事了吗 |
| 3 | 节奏 Rhythm | 10% | 切点在节奏拍上吗（六套剪辑公式照用） |
| 4 | 视线追踪 Eye-trace | 7% | 观众眼睛在画框内的落点衔接顺吗 |
| 5 | 二维平面 | 5% | 画框内平面构图（方向、形状）连续吗 |
| 6 | 三维空间 | 4% | 场景空间几何连续吗 |

**用法**：刀与刀冲突时高位裁决低位；前三位成立即可对后两位破格（破格须在豁免字段注记「Murch 破格：情绪>空间」级别理由）。默认判据是反序（空间连续硬锁）——**这是两通道互斥的根本点，引用时先看模式**。

## 五、蒙太奇句法（含义产生于镜头之间）

- **库里肖夫效应**：同一张脸接不同画面，观众读出不同情绪——含义在镜头**之间**，不在镜头之内。本通道一切「为什么这么接」的最终答案。
- **普多夫金五技法**（《Film Technique》）：①对比（富/贫并置）②平行（两线交叉互衬）③象征（切雕像倾颓喻崩塌）④同时性（两地同时推进，悬念原型）⑤主导动机（主题物反复回切）。选句型时先声明用了哪一条。
- **爱森斯坦五法**（度量/节奏/音调/泛音/理性蒙太奇）一句话备案；**实操落点仍在包内既有库**——editing/09 百组转场库（T01–T100 五组）与 editing/10 六大蒙太奇体系本就译自实拍规范，B 通道**照用不改**。

## 六、声音桥（两通道共享）

L 切 / J 切、声音先行/延续沿用 editing/05——本就实拍手法，双通道同款。声音桥磁化接缝的优先级在 B 通道更高：Murch 节奏拍的常用载体。

## 七、机判字段对照（`chain.py cuts --mode b`）

cuts JSON 镜条目字段（`*` 为 B 通道新增/强化）：

| 字段 | 类型 | 机判行为 |
|------|------|---------|
| `id, duration, shot_size, motion` | 基础 | 双通道同：加总/信封/单调审计/词表合法 |
| `主体`* | str | 非空且相邻相同 → 启用隔级切级差判 |
| `jump_cut` | bool | 同景别直切已声明 → 降 WARN（两通道同） |
| `kind`* | str | `"INS"`/`"空镜"` → 桥镜：级差链重置 |
| `豁免` / `transition_note`* | str | 级差违例豁免理由 → FAIL 降 WARN |
| `朝向`* | str（左/右…） | 相邻同主体朝向反转且无桥镜 → WARN（越轴缓冲检查） |
| `叙事功能` / `切点`* | str | B 通道正因统计：无任何理由的刀 > 半数 → WARN（Dmytryk 一） |

共享不变：**§1.4 加总精确、主打长镜 6–8s、预算对照（HARD HUMAN LOCK 可偏离仅提示）、§1.3 信封 15s/0.3s、§1.5 单调审计、06/08 词表**。
