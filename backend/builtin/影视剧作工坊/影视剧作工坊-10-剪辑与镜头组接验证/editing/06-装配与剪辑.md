# 六、装配与剪辑

## 6.1 组装工作流

生成平台没有原生时间线编辑器——组装在剪辑工具里完成：

```
1. 导出所有片段
2. 导入 DaVinci Resolve / Premiere / CapCut
3. 导入动效标题卡/叠加层
4. 加音乐（部分模型片段已自带音频——其他模型需要另行配乐）
5. 需要时做调色（尽量少——生成输出本身已带色彩意图）
6. 按目标平台导出
```

**便于剪辑的素材**：如果想在剪辑软件里实现变形剪（morph cut）或平滑剪（smooth cut），生成源片段时要在开头和结尾各留出明确的 2 秒静止或近乎静止的时刻。

## 6.2 剪辑五阶段与画面锁定

对生成式影片来说，剪辑不是最后一步，而是一个**带声明出口的循环**：

1. **组装（Assembly）**——所有场景按剧本顺序排好，还没有节奏。目标：看到整部片子，找出松垮的段落和覆盖上的缺口。
2. **粗剪（Rough cut）**——节奏、修剪、重排。镜头重排的主要清单在这里成形。
3. **生成监督（Generation supervision）**——粗剪*之后*的一道质检环节：重新生成崩掉的镜头、清掉 AI 废片、在精剪**之前**抓住不管用的东西。生成式影片区别于实拍影片的正是这个阶段——素材还可以"重拍"，而这正是那个被声明的重拍窗口。
4. **精剪（Fine cut）**——精确贴合，给冷观众试映。
5. **画面锁定（Picture lock）**——画面定死。**锁定之后不再有任何新的生成**，除非紧急修补，且要通知调色与声音部门。

画面锁定之所以必须严格执行，恰恰*因为*重新生成太便宜：没有一个声明的终点，生成监督就永远不会结束，调色和声音也就永远无法在稳定素材上开工。

## 6.3 出厂调色与"先统一、后诠释"

每一次生成的素材都自带出厂调色。不像出自同一台摄影机的实拍素材，相邻镜头并没有一个共同的起点观感——所以生成式影片的调色师，工作首先是**统一**，其次才是诠释：把相邻镜头拉到同一种观感上，让画面读起来是一整部片子。为此留好预算，并且别再试图在单条提示词里就赢下最终调色。

## 6.4 截图作为工作记忆

两次生成之间，项目状态活在对话记忆里——已经确立了什么、当前的节拍是什么、下一场景需要对着什么锚定。截图保住那些本来会在多轮往来之间漂移的东西。"从这个实际可见的状态继续"是比"继续上一个场景"更有力的提示词指令。

五种反复出现的适用情形：

- **场景已经形成一种不愿丢掉的强烈身份**——既定的观感、取景或调度一旦因漂移而丢失，代价会很高
- **道具或物件必须保持一致**——某个具体的东西在各个镜头里都得是同一个样子
- **身体朝向很重要**——角色的朝向、姿态或手势是下一个节拍的承重结构
- **情绪延续非常精确**——上一片段结束时的状态具体到"紧张"或"警觉"这类词都接不住
- **空间复杂到纯文本可能把它写糊**——几何、布局或空间逻辑抗拒散文式描述
