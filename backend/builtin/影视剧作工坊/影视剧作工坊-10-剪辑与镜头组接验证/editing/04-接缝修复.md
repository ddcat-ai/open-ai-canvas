# 四、接缝出了问题：桥接与修复

## 4.1 工作模式与症状决策树

四类创作意图模式——探索（无锚自由发现）、续接（从上一镜头停下的地方接着来）、桥接（连接两条目前不连贯的已有镜头）、修复（把失败片段当数据，直接命中误解）。按症状诊断，再选模式：

| 你看到的现象 | 工作模式 | 原因 |
|---|---|---|
| 白纸一张，还没有任何锚 | 探索 | 没有可续接或桥接的先前镜头；先自由发现 |
| 一条强镜头需要后续 | 续接 | 这条镜头挣来了一个续篇；从它停下的地方接着来 |
| 两条强镜头接不上 | 桥接 | 镜头各自成立；接缝不成立 |
| 镜头强但感觉弱 | 续接（换角色承担） | 由另一个参考角色承担重量重拍同一拍——例如原为大远景处改用特写 |
| 序列中途空间逻辑发飘 | 桥接（附地理澄清） | 序列需要一个重新确立"谁在哪里"的节拍 |
| 一条失败镜头一直绕着生成 | 修复 | 别再围着提示词迭代；直接命中失败 |

**桥接使用两端的参考**——上游镜头的最后一帧与下游镜头的第一帧——来导航中间地带。典型参考配置：角色 + 末帧 + 环境。

## 4.2 桥接骨架（两层撰写）

骨架提示词不是不加处理直接复制进生成框的。每个骨架两层：**第 1 层简报块**写给自己（或粘贴给写作助手），用平实散文把问题定义干净；**第 2 层生产提示词**把决策翻译成模型友好的结构。

**第 1 层——桥接简报块：**

```
场景 A 结束于：
[上游场景最终的可见状态]

场景 B 开始于：
[下游场景开场的可见状态]

两者之间缺的东西是：
[反应 / 移入新空间 / 道具动作 / 情绪节拍 / 空间澄清]

桥必须保全：
[同一角色、同一着装、同一地点逻辑、同一情绪残留、同一道具连续性]

桥不得做的事：
[不引入新支线、不重复之前的动作、不加额外的威胁、不搞随机奇观]

桥的目的在于：
[解释转场 / 让剪切可读 / 承载情绪 / 让观众在空间中重新定位]
```

**第 2 层——桥接生产提示词：**

```
[参考角色]
@Image1 = 角色身份参考
@Image2 = 连续性起点或地点锚（两者都不需要时省略）

这是一条位于上一拍与下一场之间的桥接镜头。
它的目的是连续性，不是奇观。

保持同一角色、同一着装、同一空间逻辑、同一情绪延续、同一道具连续性。
展示一个可读的动作来解释转场。
不要重复之前的动作节拍。
不要引入新威胁或新支线。

场景：[这个转场时刻角色身处何处]
桥接动作：[一个小而有意义的移动或反应]
镜头：[克制且可读]
音频：[仅在需要时使用现场声]
```

一条好桥常常"小"，却做着重要的结构工作。如果产出事件过载，多半是第 1 层简报的"不得做"条款太薄——修改简报，再重新推导生产提示词。

## 4.3 续接骨架与防重播短语

**第 1 层——续接简报块：**

```
上一条片段结束于：
[收尾姿态 / 镜头方向 / 情绪状态 / 可见道具]

下一条片段必须紧接其后开始。

保持：
[身份 / 身体朝向 / 地点 / 情绪延续 / 道具]

改变：
[现在开始的新节拍]

不要重复：
[之前的动作阶段]
```

**第 2 层——续接生产提示词**（三个参考角色的典型配置）：

```
[参考角色]
@Image1 = 精确的末帧连续性锚
@Image2 = 角色身份参考
@Image3 = 可选的环境或道具连续性参考

把 @Image1 用作精确的连续性起点锚。
保持同一角色、同一光线逻辑、同一空间连续性、同一情绪延续。
从最后一帧之后立即开始。
不要重复上一拍。

场景：[保持不变的东西]
新动作：[现在开始的东西]
镜头：[观众如何读出这次续接]
音频：[仅在需要时使用现场声]
```

**如果结果一直在重播上一拍**，修正办法不是"把提示词写长"，而是强化时序语言与防重复语言。实用短语变体：

- 从最后一帧之后立即开始
- 不要重复之前的打斗
- 不要重新排演更早的那一拍
- 向前进入新动作
- 保持同样的疲惫状态与情绪延续

## 4.4 生成之后：下一镜头决策

每出一条强片段，按顺序问四个问题：**这场戏的功能是什么？缺什么它才显得连贯？什么镜头能让这个连接变得可读？下一步是续接、桥接、对比，还是重置？**

下一镜头决策树——正确的问题不是"下一个最酷的镜头是什么？"而是"这一集现在有什么问题？"

- **强但孤立** → 续接或前情/后续
- **两场戏接不上** → 桥接
- **空间逻辑不清** → 地理澄清
- **结构成立但感觉弱** → 特写或反应插入
- **有东西坏了** → 定向修复

**下一镜头由功能选择，不由兴奋选择。**
