# 七、序列与续接失败图谱

链式工作——续接、延长、首帧钉死的交接——的症状 → 可能原因 → **单一修复变量**。每次重拍只改一个修复变量：

| 症状 | 可能原因 | 修复变量（只改这一件事） |
|---------|-------------|------------------------------------------|
| 续接从*计划中的*结尾开场，而不是实际交付的结尾 | 提示词是照分镜计划写的；被采纳镜头的真实结束状态从未被核对 | 按父片段实际呈现的内容重写开场——源承载状态，提示词只承载增量 |
| 动作从头重来 | 已完成的节拍从未被标注为已完成 | 把该节拍声明为已完成（"门已经开着"），提示词只写接下来发生什么 |
| 后面的节拍提前出现 | 未来节拍的内容泄漏进了本片段的提示词 | 把所有未来节拍从提示词和端点中剥离——一个片段只拥有一个节拍 |
| 身份在多次延长中漂移 | 链条尾部挤掉了权威身份参考 | 从最初的角色参考重新锚定，绝不用漂移尾部的某一帧 |
| 剪接点处画面方向翻转 | 轴线从未锁定，或被无意重置 | 写明方向（"从画面左向画面右走"），或把轴线变化声明为有意的机位覆盖 |
| 半途中的运动戛然而止 | 开放运动矢量没有跨静帧交接传递 | 用文字承载主体/镜头的速度与方向——这是帧无法承载的三样东西之一 |
| 镜头运动从静止重新起步 | 提示词里缺失了父片段的镜头运动相位 | 从观察到的镜头相位开场（"推轨进行到一半，继续推入"） |
| 道具与上一片段矛盾 | 交接时未跟踪道具的持有者/位置/状态 | 加一行道具状态（谁拿着、放在哪、什么状况）；反复出现的道具建立道具单 |
| 对话重复了已说过的台词 | 剪切点处未传递音频相位 | 把该台词标注为已说过，从音频相位继续——帧无法承载它 |
| 每次延长都比上一次更差 | 预期之中的链深漂移——每次生成都会重新摄入上一次的产物 | 从权威参考重新锚定，或有意识地切掉；链条上限 2 次延长，硬顶 3 次 |
| 一个参考串进了错误的角色 | 缺少迁移/忽略从句 | 拆分角色：每图角色行加上显式排除 |
| 发生得太多；什么都没落地 | 多个节拍被编译进同一条提示词 | 把未来节拍重新分配给后面的片段 |

两条镜头在*同一处*以同样方式失败，就是重写绊线——停止往同一堵墙上重掷。

# 八、重试阶梯——失败的镜头改的是计划，而不只是骰子

当一条镜头失败或漂移、且确认参考与映射本来都对时，按此顺序升级。每一级都是终点——绝不在同一级上循环：

1. **原样重跑一次，逐字引用参考映射。**原本的角色 + 排除行，一字不改。如果映射本来是对的，一次干净的重掷属于正常方差。
2. **把第二次失败当作镜头超载的证据。**缩短信封和/或把多余节拍拆进一条相邻的新提示词（适用密度的拆分触发条件）。第二次一模一样的重掷，是在为同一次超载付两遍钱。
3. **只为那一个镜头换模型。**让一个镜头换引擎，好过让整部作品去迁就当前引擎拿不下的一个镜头。
4. **三次付费尝试后停下，给出具名选项**——接受最好的一条、重新界定该镜头、推迟它，或在交付物里带上明确的 `placeholder: missing clip`（占位：缺片段）备注。静默漏交绝不在选项之列。
