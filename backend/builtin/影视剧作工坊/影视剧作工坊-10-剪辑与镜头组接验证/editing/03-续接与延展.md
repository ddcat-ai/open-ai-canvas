# 三、续接与延展：跨片段交接

## 3.1 续接提示词公式（五条规则）

写续接模式提示词时套用以下五条规则。漏掉任何一条都是续接失败最常见的原因：跨界的身份漂移、动作重播、环境突变、情绪主线断裂。

1. **末帧锚。**以一段简短描述开篇，说明摄影机在上一条片段最后一帧里看到什么——姿态、在画面中的位置、角色看向哪里。这告诉模型从哪里开始渲染。一句话就够。
2. **身份锚。**把角色的身份块（原提示词里用过的同一段）逐字粘贴进续接提示词。不要改述，不要缩写。续接边界正是身份漂移之处——逐字重贴不给模型任何重新解释的空间。
3. **上一片段作为次级记忆。**用一行点出刚刚发生的事——"随着门打开"、"在那一拳命中之后"、"从她转向窗户继续"。不要详细重述该动作。一个指涉短语，然后前进。
4. **立即续接。**新动作从上一条片段最后一帧的下一帧开始。不跳时间、不淡出、不隐含剪切——除非明确要求。想要跳越，就把它描述成一个新镜头。
5. **不重复动作。**新提示词必须延伸，而不是循环。上一条结束在她拔出武器，续接**不**描述她拔出武器——而是描述她接下来用它做什么。重复一个已被描述过的动作，正是"上一拍重播"症状的成因。

**示例**——上一条片段结束在一名侦探站在门口，身后是雨，回头一瞥。续接提示词：

```
接续上一条片段——侦探框在门口，头转向后方，身后是雨。
[身份块逐字粘贴：饱经风霜的女性，四十五岁上下，深色短发，炭灰风衣，
皮手套，疲惫但警觉。] 顺着她那记回望，她完全迈入走廊，任由门在身后
摆动合上，开始朝摄影机走来。与她的步速匹配的缓慢推轨后退。
同样的冷蓝灰色调，同一盏顶光实用灯。紧张而克制的能量自上一条片段延续而来。
```

五条规则齐备：末帧锚（框在门口、头转向后方、身后是雨）、身份锚（括号块逐字）、上一片段作为次级记忆（"顺着她那记回望"）、立即续接（完全迈入走廊）、不重复动作（回望被指涉而不是重新执行）。

## 3.2 必须延续的东西

跨过续接边界，要保留：

- **角色身份**——面孔、体格、辨识标记
- **服装**——每一件衣物与配饰
- **环境**——建筑、光的质感、色调处理、空气悬浮颗粒
- **情绪延续**——角色在最后一帧所处的状态（紧绷、疲惫、警觉）应在续接开头仍能从身体上读出

## 3.3 视频参考延展工作流（extend-a-clip）

没有专门的"延长"按钮。延展工作流：

1. **把已采用的片段作为视频参考附加。**
2. **提示词以"场景继续。"（The scene continues.）开头。**模型会从片段的结尾接着演，带上动作、角色、环境，甚至声音。前传片段则改以**"让我看看之前发生了什么"（Show me what happens before）**开头——同一机制可以把过去/现在/未来的片段串成链。
3. **新生成要与源片段的分辨率和时长都匹配**（1080p→1080p，15 秒→15 秒）。1080p 的源配上 720p 的延展，接缝处会出现肉眼可见的画质跳变。
4. **喂尾巴，而不只是帧。**生产实践把成片的**最后 3–4 秒**作为视频参考回喂，而不是末帧静帧——片段把*运动*带进接缝，下一个镜头从上一镜头停下的确切姿态、取景、光线与运动处接起，而不是从冻结的姿态重新开始。
5. **被遮挡身份绑定。**如果某个身份特征在源片段结尾被遮住（被手挡住的痣、转开的脸），把角色图像作为第二参考加上，并显式绑定——"这位女性的身份是 @Image1。"

## 3.4 链条式生产：每个场景三个输入

逐场景换风格的多段式生产中，一致性最容易断——它的解法是把"上一段视频"制度化：

1. **上传本场景的关键帧**（风格参考）
2. **同时上传上一场景的视频提示词**，让写提示词的助手知道刚刚发生了什么、确立了什么风格、哪些效果需要延续下去（传送门、瞬移、着装状态）
3. **上一场景的视频作为延续性参考**——这是杠杆率最高的输入。效果、角色细节和故事节拍之所以能跨剧烈差异的风格延续，靠的就是它

链条自我强化：场景 3 知道场景 2 的结束状态，场景 4 知道场景 3 的结束状态，依此类推。**最大的坑就是跳过上一段视频的喂入**——如果只喂关键帧，故事就会碎掉；上一段视频才是让主角跨场景依然认得出来的东西。

## 3.5 源携带状态规则

附加的已采用片段自带它自己的状态——静态的（画面里是谁、着装、布局）和动态的（进行中的动作、镜头运动、声音）。**提示词文本只承载增量**——接下来要变的是什么。把重复描述附加源已经展示的内容的开场状态文字删掉：参考与文本冲突时，参考压倒文本，所以这种重复轻则是浪费预算，重则是冲突的来源。

静帧是较弱的交接方式——它只携带静态状态。有三样东西静帧带不走，用截图而不是片段来交接时，它们必须留在正文里：

- **未完成的运动矢量**——谁在动、往哪个方向、多快
- **镜头运动相位**——运动进行到一半时镜头在哪（推轨推到一半、环绕绕到一半）
- **音频相位**——切点处正在进行什么声音或对白

## 3.6 链条管理——深度上限与重新锚定

链式延展会让质量劣化：每次生成都重新吃进上一次生成的产物，一条链上大约到第 4–5 代时，漂移就属于预期之内。要管理链条，不要骑着它跑：

- **无缝延续链的上限是 2 次延展**——硬顶 3 次。
- **从最初的原始权威参考重新锚定**——项目起点用的那些角色设定表和地点参考，绝不从漂移链条的尾部取帧。
- **用 B-roll（空镜/插入镜头）打断链条**——延展之间插一个切出镜头，就能重置劣化时钟，又不破坏故事流。
- **把场景边界当成一次有意为之的剪切**，从权威参考重新开场——不要试图无缝延展跨过它。

## 3.7 干净接缝规划

在生成延展之前就规划好接缝，而不是留到剪辑里再解决：

- **让延展提示词收在镜头角度切换上**（"从角色的视角看这个场景"），这样剪切读起来像一次有意的多机位覆盖，而不是一道接缝。
- **提前规划场景与场景之间的转场**——提前把下一个场景的地点做出来，放在场景内的一台电视上当作最后还在播的频道，最后一帧就成了下一个场景的开场帧。
- 真正无缝的对拼接缝是后期剪辑的活——片段互相重叠、不透明度幽灵对齐（约 5 帧）、短促的音频叠化——这不在提示词的能力范围内。

## 3.8 屏幕合成时的 1:1 参考锁

要把一段成片合成到画面内的屏幕上（电视、手机、显示器）：用视频参考角色附加这段成片并锁死：

```
@video1 与源素材 1:1 一致——绝不重新解读、重新剪辑、裁切、提前循环或替换。

SCREEN REALISM（屏幕真实感）
屏幕表面有玻璃光泽与房间反光、隐约的亚像素网格、轻微摩尔纹、高光溢光，
屏幕以略微偏离正对轴线的角度呈现。
```

**时长匹配规则**：新生成的时长必须与参考片段的时长精确一致——否则模型会在参考片段结束之后开始自行编造。
