### 10.2.0a 单组图片参考上限

项目资产库可以保存超过 9 张图片，但每一组可投喂提示词 / 每个 Seedance 单元实际上传和引用的图片参考总数最多 9 张。计数包含人物图、场景母版、道具图、首帧图、调度图、位置参考图、SCV 场景角度图等所有图片；视频和音频不计入图片张数。连续性增强同时命中 FF、SCV、MAP/SB、PR 时，必须先筛选当前段真正需要的图片，低风险参考改写成文字约束或拆到下一组。

### 10.2.1b 道具单实例锁写法

当 `@图片1` 场景母版、`@图片N` 场景角度图或 `@图片5` 首帧图里已经可见某个固定摆放道具，同时又使用 `@图片4` 这类 PR 道具参考图时，必须输出 `道具单实例锁`。这个字段不是每段都需要，只在“同一道具可能被模型复制”的高风险段启用。第三方接入端使用 `@Image` 别名时同理。

必须写清四件事：

1. **绑定关系**：PR001 就是场景/首帧里哪一个可见物体。
2. **PR 图用途**：只参考外观、材质、裂纹、颜色、屏幕状态，不新增道具。
3. **数量与位置**：全片或本段只允许出现一个，初始位置在哪里。
4. **移动后变化**：拿起后原位置为空，放下后手中为空，不能同时保留两个。

标准写法：

```text
道具单实例锁：PR001 碎屏手机就是 @图片5 首帧中桌面右下角那一部手机。全片只允许出现这一部手机。@图片3 不是新增道具，只用于修正这同一部手机的机身颜色、裂纹形态、边框磨损和背面双摄细节；如果角色拿起手机，桌面原位置必须变为空，不得保留第二部手机。
```

素材字段写法：

```text
素材：使用 @图片5 作为本段首帧，只锁定第 0 秒构图、人物初始位置和桌面右下角那一部碎屏手机的位置；使用 @图片3 作为 PR001 碎屏手机外观参考，只参考这同一部手机的颜色、裂纹和背面双摄细节，不新增第二部手机。
```

限制字段写法：

```text
限制：不得生成第二部同款手机；不得让桌上和角色手里同时各出现一部手机；不得把手机复制到沙发、地面、背景或其他桌面。如果角色拿起手机，桌面原位置必须变为空。
```

不要写：

```text
参考 @图片3 手机道具。
添加一部和 @图片3 一样的手机。
桌上有手机，同时角色手里拿着同款手机。
```

如果道具尚未在场景/首帧中出现，而剧情需要它首次进入画面，可以写成“角色从包里拿出一部 PR001 手机”，这时 PR 是新增实例，但仍要写清数量和进入动作。

### 10.2.3 SCV 场景角度增强块

SCV 场景角度增强块不是新格式，不替代默认字段化纯净提示词模板。它只在 05/04 提供 SCV 多角度空间包，且本段属于核心场景、反打、横移、回切、同场景强连续或高穿帮空间时输出。没有 SCV 时，不输出 `场景角度参考` 行。

启用 SCV 时，`素材` 和 `场景角度参考` 必须写成模型能直接理解的视觉事实，不要只写“参考 SCV001”：

```text
素材：使用 @图片1 作为便利店窗边场景母版，只参考窗框、雨痕玻璃、窗边柜台、货架和固定光源；使用 @图片4 作为 SC001_V01_窗外看店内角度图，只参考摄影机从窗外街道侧透过玻璃看向店内的拍摄方向、空间透视、窗框/吧台/货架相对位置和冷暖光源方向；使用 @图片2 作为林小雅角色参考，只参考脸型、发型、服装和体态。
场景角度参考：本段镜头从窗外街道冷雨侧看向便利店内暖光侧，@图片4 只锁定这个拍摄方向和空间透视，不继承人物、人群、剧情动作或首帧构图；空间结构仍以 @图片1 场景母版为准。
```

SCV 增强的限制写法：

```text
限制：保持 @图片1 的便利店空间结构和 @图片4 的窗外看店内视角；不得把便利店窗边改成另一个空间，不得新增桌椅或改变窗边吧台方向，不得把角色放到窗外街道侧；SCV 角度图只控制空间方向，不控制人物动作和段末状态。
```

SCV 增强不要写：

```text
参考 SCV001。
同一场景多角度。
保持之前那个便利店。
使用 V02 保持空间。
```

这些说法对模型不够具体，必须改写成“摄影机在哪一侧、看向哪一侧、哪些固定物相对位置必须保持、哪些不能改变”。

### 10.2.4 首帧增强块

首帧增强块不是新格式，不替代默认字段化纯净提示词模板。它只在 A 必须首帧或 B 建议首帧，且用户提供/生成了 FF 首帧图时输出。没有 FF 时，不输出 `首帧参考` 行，按普通衔接或强连续模式输出。

启用 FF 时，`素材` 和 `首帧参考` 必须写成模型能直接理解的视觉事实，不要只写“参考 FF001”：

```text
素材：使用 @图片5 作为 B05 首帧图，只锁定本段第 0 秒构图、林小雅坐在便利店窗内右侧高脚凳、碎屏手机和冷便当的位置、玻璃内外侧关系和冷暖光影；使用 @图片1 作为便利店窗边场景母版，只参考窗框、雨痕玻璃、窗边柜台、货架和固定光源；使用 @图片2 作为林小雅角色参考，只参考脸型、发型、服装和体态；使用 @图片3 作为碎屏手机道具参考，只参考首帧中同一部手机的裂纹和机身外观，不新增第二部手机；使用 @图片6 作为 MAP/SB 参考，只参考 IN/OUT/GLASS/CAMERA 侧别和点位。
首帧参考：本视频第 0 秒必须从 @图片5 的画面开始：摄影机在窗外街道冷雨侧，透过雨痕玻璃看向店内；林小雅、手机、冷便当和高脚凳全部在玻璃后方的店内暖光侧。@图片5 只锁定第 0 秒，后续动作按分镜继续发展。
道具单实例锁：PR001 碎屏手机就是 @图片5 首帧中窗边柜台上的那一部手机。全片只允许出现这一部手机。@图片3 只修正这同一部手机的裂纹和机身外观，不新增第二部手机。
```

首帧增强的限制写法：

```text
限制：本段开头必须继承 @图片5 的第 0 秒构图和空间侧别；林小雅不得坐到窗外街道侧，不得把窗边柜台变成双面餐桌，不得让身体、手机或便当穿过玻璃；不得生成第二部同款手机，不得让桌上和手里同时各出现一部手机；后续动作只允许在店内窗边高脚凳和柜台范围内发生。
```

首帧增强不要写：

```text
承接 B04 首帧。
继续上一段的位置。
同一便利店，同一夜晚。
使用 FF001 保持一致。
```

这些说法对独立批量生成没有帮助，必须改写成当前视频第 0 秒能看见的事实。

### 10.2.5 强连续增强块

强连续增强块不是新格式，不替代上面的默认字段化纯净提示词模板。它只在“同场景强连续 / 回切强连续 / 批量生成连续片段 / 用户明确担心穿帮”时，叠加到默认模板中。

普通衔接模式继续使用旧版满意样式：

```text
下一段衔接：镜头停在小雅抬头看向画面右侧的反应。
下一段衔接：段末出站口外便利店冷白灯牌亮着（对应 S05A）。
[段末状态]：小雅走向雨夜出站口，便利店灯牌在前方。
```

强连续增强时，在默认模板的 `人物位置关系` 后追加：

```text
强连续增强：
本视频第一帧状态：[不用依赖上一段视频也能看懂的首帧事实；谁在什么点位、身体朝向、视线、道具、光线、摄影机安全区]
点位表：[A1=门口内侧；A2=茶几左侧；B2=沙发右端；C1=摄影机安全区]
调度图参考：使用 @ImageN 作为 MAP 调度图参考，只参考人物点位、移动路线、摄影机安全区和空间侧别，不改变场景母版；最终画面句必须把 A1/A2/B2/C1 改写成门口内侧、茶几左侧、沙发右端、摄影机在茶几正前方这一侧等可见事实。
本段目标末端状态：[本段结束时的人物点位、身体朝向、视线、道具、光线、情绪能量]
```

### 10.2.6 人群密度字段写法

`人群密度` 是可选增强字段，不替代当前 A/C 输出结构。只有公共空间、营业场所、街道、车站、学校、医院、商场、活动现场等需要路人真实感或空间压力时才输出。私密空间、空场戏、密谈戏、只有主角的情绪戏，不输出该字段，并在 `限制` 里禁止额外人物。

写法原则：

1. 不写模型不懂的管理词：不要只写 `CR001`、`承接 B01 人流`、`同上一段路人`。
2. 必须写成当前段可见画面：前景多少人、中景多少人、远景多少人，各自怎么走。
3. 场景母版若是空场图，`场景` 字段只写“只参考空间结构、店铺位置、灯光和透视”；人群另用 `人群密度` 正向写清当前段可见人数、层次、类型和移动方向。
4. 启用人群时，`限制` 不能再写“禁止额外人物”；应改写为“禁止新增主要角色，路人不得抢戏”。

示例：

```text
场景：使用 @图片1 作为铜锣湾街口空场母版，只参考街道结构、店铺位置、霓虹灯光、斑马线和空间透视。
人群密度：下班高峰的繁忙街口，前景 3-5 名路人从镜头边缘擦肩经过并轻微虚化；中景 8-12 名行人与主角同向和反向交错移动；远景街口和店铺门口 20 人以上持续进出。人群包含白领、学生、游客、快递员、提购物袋的中年人、撑伞老人，动作自然分散。
限制：路人不得看镜头，不得围观主角，不得遮挡主角脸部、关键表情和关键道具；不要复制粘贴同脸路人，不要所有路人同服装、同动作、同方向；禁止新增与剧情无关的主要角色。
```

强连续增强时，每个分镜的 `限制` 字段要使用“正确状态 + 禁止错误状态”：

```text
限制：林墨从本视频第一帧开始站在茶几左侧，位于画面左侧区域，身体朝向坐在画面右侧沙发端的苏眠；不得让林墨出现在门口或画面后方；苏眠不得站起或移动到茶几旁；摄影机保持在茶几正前方这一侧，不切到两人背后的反方向。
```

独立批量强连续模式的上下文清洗只用于“模型必须独立理解本段”的首帧和限制字段，不清洗旧版基础衔接写法。

需要清洗的错误写法：

```text
承接 B01 末帧，同一客厅，林墨仍在 A2。
上一段结束后，小雅继续站在门口。
```

改成可独立投喂的写法：

```text
本视频第一帧，林墨站在茶几左侧、画面左侧区域，身体朝向坐在沙发右端、画面右侧区域的苏眠；茶几位于两人之间；客厅布局使用 @图片1，房门在画面左后方，沙发在画面右侧靠墙，茶几在中央，台灯在沙发右侧。
本视频第一帧，小雅站在地铁车厢中段，车门在画面后方，手机握在右手，屏幕朝向手心不可见。
```

## 十三、首尾帧 / 视频延长 / 末帧延续

如果用户提供首帧和尾帧：

```text
使用 @图片1 作为首帧，使用 @图片2 作为尾帧。视频需要从 @图片1 平滑过渡到 @图片2，保持同一角色身份、服装、发型、光线方向、场景空间和环境连续性。
```

如果相邻两段是同场景顺延，下一段像继续拍下去，应优先建议 Seedance 2.0 视频延长。纯净提示词最前面使用：

```text
使用 @视频1 作为上一段成片视频，只从上一段末尾继续自然延长 X 秒，接入本段动作。不重置角色身份、服装、发型、场景空间、光线方向、镜头方向和道具状态。
```

视频延长后仍必须接完整 06 字段化提示词：

```text
素材：
事件交代：
场景：
人物位置关系：
【分镜1】
焦段：
光圈：
景深与焦点锁：
机位：
构图：
运镜：
主体动作/表情：
台词与语气：
光影：
限制：
下一段衔接：
通用后缀：
段末状态：
```

如果上一段生成结果只作为参考，而不是执行视频延长：

```text
使用 @视频1 作为上一段视频参考。从上一段末帧状态继续：[末帧状态]。保持同一角色身份、服装、发型、光线方向、镜头方向和道具状态，不要重置场景。
```

末帧延续必须继承：

- 角色身份
- 服装
- 发型
- 姿态
- 情绪能量
- 道具状态
- 光线方向
- 镜头方向

## 十四、分段输出策略

### 时长硬规则

Seedance 2.0 每个提示词包对应的视频段必须是 4-15 秒。

- 低于 4 秒：合并到前后相邻段，或扩展动作/反应/环境建立到 4 秒以上。
- 高于 15 秒：拆成多个提示词包，每包都要有独立情绪目标和 End state。
- 用户指定 1 秒、2 秒、3 秒时，必须提醒“Seedance 2.0 单段最低 4 秒”，再给出合并或扩展方案。
- 用户指定 16 秒以上时，必须提醒“Seedance 2.0 单段最高 15 秒”，再拆分。

### 单段 4-8 秒

适合：

- 单个动作
- 单句台词
- 一个情绪命中点
- 一个镜头或少量切换
- 短视频平台下通常 1-2 个镜头即可；如果包含多个动作或信息点，可扩展到 2-3 个镜头，但不要塞 5 个以上复杂动作。

### 单段 10-15 秒

适合：

- 一个完整对话节拍
- 一个动作从发生到结果
- 一个场景内的短小转折
- 短视频平台下必须继承 04 的节奏档位判定：`电影感中速` 为 10-12 秒 3-5 镜、13-15 秒 4-6 镜；`短视频中高密度` 为 10-12 秒 4-6 镜、13-15 秒 6-8 镜；`高密度动作或强钩子` 为 10-12 秒 5-7 镜、13-15 秒 7-10 镜。只有强情绪压迫、重要台词交锋、单镜头调度、反派登场、仪式感、高级悬疑凝视、同场景视频延长或用户指定电影感长停顿，才允许 1-2 个镜头，并必须写清慢镜头功能。

### 1900 字安全红线策略

单个 Seedance 提示词单元默认控制在 1900 字以内；1900 字是安全红线，2000 字是平台硬上限。控制字数时按以下顺序处理：

1. 优先保留每个分镜的必填字段：焦段、光圈、景深与焦点锁、机位、构图、运镜、主体动作/表情、台词与语气、光影、限制、下一段衔接。
2. 删减空泛形容词，如“高级、震撼、极致、电影感拉满”等。
3. 合并重复限制，把角色一致性放进素材锚定或具体镜头限制，把文字和光线限制集中到高收益通用后缀。
4. 删除代码框内的管理话术和低收益后缀，例如未启用项、无则删除说明、换场景不用什么、上一场不继承什么、某增强不替代什么、默认不输出的一致性/节奏/画面规格尾缀。
5. 如果仍超过 1900 字，优先按镜头边界拆成连续的 4-15 秒单元；不得输出超过 2000 字的单组提示词，不在单个镜头内部硬拆。
6. 不要为了压字数删除台词、段末状态、关键道具状态和跨段衔接。
7. 不要为了压字数删除 04 已确认的功能镜头。短视频平台下，必须按 04 的节奏档位检查下限；未命中慢节奏白名单时，不要把 `短视频中高密度` 或 `高密度动作或强钩子` 硬合并成 1-2 镜，也不要压扁每镜必填字段。

### 多段连续

当 04 的大分镜超过一个情绪转折，必须拆成多个 Seedance prompt 包。

拆分原则：

1. 每段只保留一个主要情绪目标。
2. 每段末尾写 End state。
3. 下一段开头继承上一段 End state，但提示词仍要写成当前段可见状态，不让模型猜上一段发生了什么。
4. 多段输出时必须先给出相邻段连续性建议表，明确 A→B、B→C 等边界是视频延长、首帧图+调度图、只首帧图、只调度图还是普通衔接。
5. 同场景顺延优先建议视频延长；同场景空间复杂但不顺延时，建议 FF/MAP/SB；切换新场景默认普通衔接。
6. 场景首次出现且人物多、站位复杂，也建议 FF 首帧图 + MAP/SB 调度图。
7. 普通衔接段保持旧版“下一段衔接 / 通用后缀 / 段末状态”写法；强连续段在此基础上增加点位、调度图、摄影机安全区和禁止错误站位。
