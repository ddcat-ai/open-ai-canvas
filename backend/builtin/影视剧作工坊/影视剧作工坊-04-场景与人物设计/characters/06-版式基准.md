## 版式C-上三视图加下局部宫格

# 版式 C：上 2/3 三视图 + 下 1/3 局部宫格

> 来源样本：水绿金绣魏晋少女、天蓝牡丹清冷仙子、林娘子月白兰草。

## 布局
```
┌────────────────────────────────────┐
│ 上 2/3：角色三视图区（横向并列3张全身） │
│ [正面全身] [侧面全身] [背面全身]      │
│ 要求：人物大小一致、比例协调、不重叠不偏移 │
├────────────────────────────────────┤
│ 下 1/3：局部细节区（宫格 4~6 个小图）   │
│ [服饰][发型][妆容][配饰][鞋履][首饰]   │
└────────────────────────────────────┘
```

## 提示词拼装
```
3D写实风格，UE5渲染，细节超高清，
全画面三分之二区域为角色三视图区，横向并列3张全身视图（正面/侧面/背面），
人物大小一致、比例协调、不重叠不偏移，
下方三分之一区域为局部细节区，
6个细节特写小图（服饰纹样、发型、妆容、配饰、鞋履、首饰），
纯白或浅灰影棚背景，高对比度，层次丰富
```

## 适用
- 服饰/配饰细节复杂，需要单独展示
- 制作参考用（导演/服装/道具分部门看）

## 出图形态-默认写死

# ⭐ 出图形态：默认全身，按需升档（写死）

> **本文件是模块 04 人物线的出图基准。**
> **默认出单张全身图**；用户明确指定形态时才切换三视图 / 半身 / 局部特写。

---

## 0. 一句话规则

**用户没指定形态 → 出单张全身图**：纯白背景、头顶到脚尖完整入画、九头身黄金比例、四肢完整可见。**不是头像，也不是多格拼装稿。**

---

## 0b. 四种出图形态

| 形态 | 触发 | 构图基准 |
|------|------|----------|
| **① 全身图**（默认，写死） | "出个角色 / 角色图 / 定妆图 / 人设图"，未指定形态 | §1a |
| **② 三视图** | "三视图 / 设定稿 / 正侧背 / 角色资产 / 建模参考" | §1b（版式 A–E） |
| **③ 半身图** | "半身 / 胸像 / 上半身 / 半身像" | §1c |
| **④ 局部特写图** | "特写 / 局部 / 细节图 / 手部 / 面部特写 / 配饰 / 纹样" | §1d |

**可叠加**：要"全身 + 面部特写"就出两张；要"三视图 + 局部宫格"走版式 C。
**形态只改构图与取景，不改画风与质量基线**——§2 通用渲染要求与全局负面词在四种形态下逐字照带。

---

## 1a. 形态① 全身图（默认）

```
角色全身立绘，纯白背景，干净无杂物，
身材高挑九头身黄金比例，四肢完整可见，从头顶到脚尖完整构图，
正面站立，[角色描述]，[配色]，
专业打光，高清细节，8K
```

布局要点：单张、单人、垂直构图、全身入画不裁切、不拼版、**不加分区标签与 cm 刻度线**（那些属于三视图设定稿）。

---

## 1b. 形态② 三视图 · 版式结构（按这个布局组织画面）

```
┌─────────────────────────────────────────────┐
│  顶部：主视觉区（三视图胸像横排）              │
│  [正面胸像]  [侧面胸像]  [背面胸像]          │
│  标注：正面 / 侧面 / 背面                    │
├──────────────┬──────────────────────────────┤
│  左侧        │  右侧：全身照比例照           │
│  ·面部特写   │  全身正面立绘                 │
│  ·配色板     │  旁附 cm 身高刻度线           │
│  ·局部细节   │  底部标"黄金比例"             │
│  (2x2~3x3小图)│                              │
└──────────────┴──────────────────────────────┘
```

四个区域缺一不可：

| 区域 | 内容 | 要求 |
|------|------|------|
| **主视觉区（顶部）** | 正面 + 侧面 + 背面 三个胸像/半身像横排 | 呈现整体身形、服饰、标志性特征；三视角服饰/发型/配饰完全一致 |
| **补充信息区（左侧）** | ① 面部大特写 ② 配色板（毛发/服饰色值色块） | 补充主视角没覆盖的脸和色彩标准 |
| **局部细节区（左下）** | 2~6 个小方图：配饰、发饰、首饰、鞋、纹样特写 | 把主视角里的模糊细节拆成制作参考 |
| **全身比例照（右侧）** | 全身正面立绘 + 身高 cm 刻度线 + 黄金比例标注 | 直观呈现全身造型与身高比例 |

---

## 1c. 形态③ 半身图

## 1d. 形态④ 局部特写图

```

[该部位的逐字描述]，纹理与材质清晰，

```

适用：制作参考（服装 / 道具 / 妆造分部门看）。**每张只聚焦一个部位**；要多个部位就出多张，或走版式 C 的局部宫格。

## 4. 触发判断

| 用户说 | 走哪一形态 |
|--------|-----------|
| "出个角色 / 建人设 / 定妆图 / 角色图"，**未指定形态** | ✅ **形态① 全身图（默认）** |
| "三视图 / 设定稿 / 角色资产 / 建模参考 / 正侧背" | 形态② 三视图（版式 A–E，未指定则 A） |
| "半身 / 胸像 / 上半身 / 半身像" | 形态③ 半身图 |
| "只要头像" | 形态③ 半身图的头肩变体（聚焦头部与肩线） |
| "特写 / 局部 / 细节图 / 手部 / 面部特写 / 配饰 / 纹样" | 形态④ 局部特写图 |
| 只给了角色文字描述没说形态 | ✅ **形态① 全身图（默认）** |

**形态可叠加**：一句里点名多个形态就出多张（"全身 + 面部特写"＝两张）。

---

## 5. 与其他版式的关系

**形态① 全身图 = 默认**（单张全身立绘，本节 §1a）。
**形态③ 半身图**、**形态④ 局部特写图** = 单一取景形态，不拼版（§1c / §1d）。

**形态② 三视图** = 正 / 侧 / 背体系，含 5 种版式：

- **版式 A**：竖版综合设定稿——顶部三视图胸像横排 + 左侧面部特写/配色板/局部细节 + 右侧全身比例照。**三视图未指定版式时的默认**
- **版式 B**：横版，左侧大面部特写 + 右侧正/侧/背全身
- **版式 C**：上 2/3 三视图全身 + 下 1/3 局部宫格
- **版式 D**：标签化竖版，带分区标签 + cm 身高线 + 比例参照物
- **版式 E**：纯白底无阴影，纯正/侧/背三个全身并排（极简）

> 用户没说形态就用**形态① 全身图**；用户说"三视图"但没说版式，用**版式 A**。

## 6. 两套版式的对照（本文件的 A–E ↔ `characters/15` 的版式一–八）

本模块有**两套版式编号**，来源不同、**并存但主责不同**：

- **本文件的版式 A–E** = **出图形态层的精简版式**，与「出图形态」（默认全身 / 三视图 / 半身 / 局部特写）直接挂钩，是**日常出图速查**用的。
- **`characters/15-风格基准库.md` §三 版式一–八** = **源库的完整版式规范**，每个版式都带完整 **Prompt 模板**，是**正式设定稿交付**用的；其中**版式六 / 版式八在本文件没有对应项**。

| `characters/15` §三 | 本文件 | 说明 |
|---------------------|--------|------|
| 版式一 三视图设定图（图A式） | ≈ 版式 A | 正/侧/背全身三等分 + 右侧面部特写 + 标注引线 + 底部信息栏 |
| 版式二 视觉设定图（图B式） | — | 中央上半身主视觉 + 左小图 + 右三块信息面板 + 4 条引线（**本文件无对应**） |
| 版式三 女性氛围设定图（图C式） | — | 左侧上半身 + 右侧四面板 + 色彩方案 4 色圆 + 底部参数栏（**本文件无对应**） |
| 版式四 完整三视图设定表（ref5式） | ≈ 版式 A / C / D | 信息最全：三等分全身 + 配色板（HEX）+ 8 头身比例参照 + 8 个细节面板；A 取其综合、C 取局部宫格、D 取比例参照 |
| 版式五 纯三视图（ref3式） | ≈ 版式 E | 白底三等分正/侧/背，无面板无标签 |
| **版式六 竖版次世代角色设定板**（9:16，微表情八宫格） | — | **本文件无对应**：9:16 竖版 + 表情三联 + 手部两联 + **眼部/唇部各四宫格微表情梯度**（须从 05 微表情库取同组递进 M 编号） |
| 版式七 横排特写三视图 | ≈ 版式 B | 左大特写胸像（约 40% 宽）+ 右三全身（正面 / 45°侧面 / 背面）。**基准 M/N/O 的参考图共用此版式** |
| **版式八 9:16 黑金暗黑 UI 次世代设定板** | — | **本文件无对应**：暗黑奢华灵兽化形 / 高智反派的面板级资产展示（结构 / 材质 / 细节 / 光效全拆解）。**基准 P 的配套版式** |

**取用规则**：

1. **日常出图**（用户随口要角色图）→ 走本文件的「出图形态」+ 版式 A–E。
2. **正式设定稿交付**（要完整 Prompt 模板、信息面板、引线、配色板 HEX）→ 走 `characters/15` §三，按其**版式选择速查**挑版式一–八。
3. **风格基准自带版式指向时以基准为准**：基准 M/N/O 说"版式七"、基准 P 说"版式八"，指的都是 `characters/15` §三 的编号，**不是本文件的 A–E**。
4. **命名冲突处理**：两套都用"版式 + 编号"，靠**字母 vs 汉字数字**区分——提到 **A–E 指本文件**，提到**一–八指 `characters/15`**。写混时以来源文件为准。
