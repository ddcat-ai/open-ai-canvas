# 人体解剖 / 面部 / 体型 / 发型词库（Anatomy Vocabulary）

> 用途：拼装②角色锚定段时从这里选具象词。**全是名词/形容词，模型能直接画。**

---

## 五、拼装示例

```
[古风男]
着玄色暗纹锦袍，肩覆银灰轻甲，腰束玉带悬长剑，
墨发高束以银玉发冠，玄色披风随风

[现代女]
穿炭灰真丝衬衫配黑色包臀裙，
踩黑色尖头红底高跟鞋，戴金色大圈耳环与细链锁骨项链，
头发松松挽起几缕碎发垂落
```
