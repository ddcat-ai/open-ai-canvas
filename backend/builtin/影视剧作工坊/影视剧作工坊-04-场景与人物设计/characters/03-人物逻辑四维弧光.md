# L2 · 人物逻辑规则库（Character Logic）

> **何时加载本库**：当你需要（1）诊断人物是否成立；（2）设计/校验欲望-需求-缺陷-恐惧四维；（3）设计人物弧光、对手、盟友、副线人物；（4）判断人物的行动选择是否合理时，加载本库。
> **回答的问题**：谁在推动故事、他为什么这么做、故事结束时他变成了谁。
> **用法**：按规则编号逐条执行；写人先建四维，写对手先答四问。
> 所有判定以本库规则编号为准。

---

## 2.1 人物四维模型

任何主要人物必须建立四维，缺一不可：

| 维度 | 定义 | 示例 |
|------|------|------|
| 欲望（Want） | 表层目标，驱动外在行动 | 想赢回公司 |
| 需求（Need） | 深层缺失，故事真正要教给他的 | 需要学会信任别人 |
| 缺陷（Flaw） | 阻碍需求达成的内在障碍 | 控制欲、逃避亲密 |
| 恐惧（Fear） | 缺陷的根源，一切防御行为的动机 | 害怕被抛弃 |

**规则 C1**：欲望与需求必须**冲突**——主角执着追求欲望的方式，恰好阻碍他获得真正需要的东西。欲望是错的解，需求才是对的题。
**规则 C2**：缺陷不是性格标签，而是**行为模式**——必须在剧本中持续产生可见的行动后果（错误决策、关系破裂、错失机会）。

## 2.2 人物弧光（弧线设计）

**规则 C3**：主角必须有一条弧光，起于「错误信念」，止于「改变/拒绝改变」，且由事件证明：

```
起点：错误信念（缺陷驱动的自我保护逻辑）
中点：动摇（证据累积，旧方法开始失效）
终点：抉择（旧信念 vs 新认知，做出选择）
结局：证明（选择带来可见后果，世界因此变化）
```

**规则 C4**：弧光改变必须**有代价**——主角改变不是免费顿悟，而是失去某样东西后换来的（安全感、旧关系、身份认同）。
**规则 C5**：配角弧光允许三种形态，写前必须选定并贯彻：①变化弧（如导师型配角完成传承）；②坚定弧（拒绝改变，作为主角的反面镜子）；③揭示弧（表面如此，实为另一人，弧光是"观众认知"的变化）。

## 2.3 对手与镜像

**规则 C6**：对手不是"坏人"，而是**价值观对立的合理者**——他的欲望同样正当，他的手段自成逻辑，他只是站在主角的对立面。没有合理动机的对手 = 纸片反派。
- ✅ 示例：主角要保护森林，对手是伐木场主——他的欲望（养家糊口）正当，他的逻辑（这是全镇唯一产业）自洽，他只是站在主角对立面。
- ❌ 反例：对手单纯"想统治世界还爱笑"——无动机，纸片反派。

**规则 C7**：对手与主角必须**共享核心缺陷或核心欲望**（镜像关系）——他们争夺同一个东西（权力/爱/真相），只是选择了相反路径。主角战胜对手的本质，是战胜自己体内同样的倾向。
- ✅ 示例：两人都想要"被认可"，主角靠实力赢得认可，对手靠踩别人获得认可——同一欲望的两条路径。
- ❌ 反例：主角要爱情、对手要金钱——争夺物不同，不构成镜像。

对手四问（写反派前必答）：
1. 他要什么？（欲望，必须正当到能说服一半观众）
2. 他为什么这么干？（动机，必须与他的背景自洽）
3. 他跟主角抢什么？（争夺物，必须唯一且不可分割）
4. 他错在哪？（他的缺陷与主角的缺陷构成镜像）

## 2.4 盟友与副线人物

**规则 C8**：盟友必须**补主角之缺**——盟主的职能是给主角提供他没有的能力/视角/情感支撑，且盟主自身有自己的欲望（不是工具人）。
**规则 C9**：副线人物（B 故事主角）必须承担「主题折射」功能——通过他/她的故事，观众看到主题在另一种处境下的变体。

## 2.5 人物决策逻辑（行动的合法性）

**规则 C10**：人物每个关键行动必须回答「为什么是他/她做这个选择」——选择由欲望×缺陷×当下信息共同决定，禁止作者替人物做选择。
**规则 C11**：人物必须在**压力下做选择**——有代价的选择才暴露性格。两个选项都轻易可得的场景，等于没有场景。
**规则 C12**：同一人物在不同压力等级下的反应必须**一致而有层次**——轻压时的处理方式升级到重压时依然可辨认，但程度加深（性格稳定性）。

## 2.6 人物关系网

**规则 C13**：主角的核心关系必须形成三角结构（争夺）——主角、对手、争夺物/人，三者缺一不可，且至少一个关系随着故事推进发生质变（盟友反目、对手成盟、恋人决裂）。

| 人物 | 与主角的关系 | 欲望 | 在故事中的功能 | 关系变化节点 |

## 2.7 人物层检查清单（Step 1/2/4 使用）

- [ ] C1 欲望与需求冲突（欲望是错的解）？
- [ ] C2 缺陷产生可见行动后果？
- [ ] C3 主角有完整弧光（起点/中点/终点/结局证明）？
- [ ] C4 弧光改变有代价？
- [ ] C5 每个配角的弧光形态已选定并贯彻？
- [ ] C6 对手有合理动机？
- [ ] C7 对手与主角构成镜像（共享缺陷/欲望）？
- [ ] C8 盟友补主角之缺且有自身欲望？
- [ ] C9 副线承担主题折射？
- [ ] C10 关键行动由欲望×缺陷×信息决定？
- [ ] C11 人物在压力下做有代价的选择？
- [ ] C12 人物反应一致而有层次？
- [ ] C13 核心关系成三角且至少一条发生质变？

## 2.8 常见缺陷与修复

| 缺陷 | 症状 | 修复方向 |
|------|------|----------|
| 人物扁平 | 只有欲望没有需求/缺陷 | 补全四维模型，让缺陷产生后果（C1/C2） |
| 工具人配角 | 配角只为主角服务 | 给配角独立欲望与功能（C8/C9） |
| 纸片反派 | 对手纯坏无动机 | 完成对手四问（C6/C7） |
| 弧光缺失 | 主角从头到尾没变化 | 设计错误信念→动摇→抉择→证明（C3） |
| 行动不合理 | 人物做作者安排的事 | 用 C10/C11 重推每个关键选择 |
