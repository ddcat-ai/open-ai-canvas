## 女01-大家闺秀贤淑

# 女原型 01：大家闺秀·贤淑温婉

> 来源样本：绿衣垂挂髻小姐、粉衣端庄闺秀、红橙金绣淑女、林娘子月白兰草。

## 外貌锚定段（30-50词，逐字带）
```
年约十六七岁，面容清丽柔和，眉如远山含黛，眼似秋水横波，
唇点浅豆沙色，皮肤白皙细腻，身形清瘦窈窕，身姿端庄温婉，
眼神清澈温和，带浅浅笑意，气质娴雅温婉，端庄柔美
```

## 发型发饰
- 垂挂髻 / 高盘温婉髻 / 堕马髻
- 珍珠步摇、玉簪、鬓边花（茉莉/海棠）
- 珍珠流苏项链、细金耳坠

## 服饰
- 月白/水绿/粉/红橙 暗纹襦裙
- 外罩半臂/披帛，领口袖口绣缠枝莲/兰草/牡丹
- 裙摆垂落如流云，软底绣花鞋（裙摆拖地遮住）

## 气质关键词
娴静、端庄、疏离、沉静、情绪不外露、大家闺秀、清婉脱俗

## 推荐配色
见 `../配色基准/经典配色组合.md`：月白+水绿 / 粉白+珍珠 / 红橙+金

## 推荐风格
风格01 真人写实国风 / 风格09 淡彩仙雾空灵

## 女02-清冷仙子

# 女原型 02：清冷仙子·出尘疏离

> 来源样本：天蓝牡丹清冷仙子、青玉仙宫美人、白发蓝裙妖冶神女、守陵女官。

## 外貌锚定段（30-50词，逐字带）
```
年约二十，冷白如玉肌肤，眉毛细淡如远山，眼型狭长清冷，
墨黑/银白长发顺直中分垂肩，仅一枚素白玉簪固定，
不施浓妆，唇色浅淡，眼神平静无波，自带疏离清冷仙气，
肩窄腰细，步履轻柔
```

## 发型发饰
- 中分黑长直 / 银白长直发
- 素白玉簪、极少珠钗、细碎珍珠耳坠
- 无浓艳首饰

## 服饰
- 天蓝/月白/青玉/素白 广袖襦裙/仙袍
- 衣身仅暗绣淡色牡丹/兰草/陨石咒纹
- 腰间细银丝带，无腰带，素净无浓烈色彩

## 气质关键词
清冷、疏离、不食人间烟火、孤高出尘、情绪淡薄、沉静

## 推荐配色
天蓝+银 / 月白+青玉 / 素白+冷灰

## 推荐风格
风格09 淡彩仙雾空灵 / 风格02 UE5次世代CG

## 男02-道袍弟子

# 男原型 02：道袍弟子·清隽/骄横

> 来源样本：浅青道袍骄横男弟子（178cm 尖瘦脸吊梢眼）。

## 外貌锚定段（30-50词，逐字带）
```
年约十八，尖瘦脸型，吊梢刻薄眼/清隽眼，乌黑束发，
肤色白皙或健康黄皮，身高约178cm，身形挺拔或清瘦，
着入门弟子道袍，气质可骄横可清冷
```

## 发型发饰
- 简单束发（木簪/布带）
- 无贵重发饰
- 可能额前碎发

## 服饰
- 浅青/灰/素色 入门弟子道袍/儒衫
- 布料朴素，无金绣
- 腰间布带或简单丝绦

## 气质关键词
清隽、谦逊（正派弟子）或 骄横、浅薄、戾气（反派弟子）

## 推荐配色
浅青+白 / 灰+白 / 素麻+木色

## 推荐风格
风格01 真人写实国风 / 风格09 淡彩仙雾空灵

## 变体
- 正派：清隽、温和、书卷气
- 反派：尖瘦脸、吊梢眼、骄横戾气、眼神不屑

## 男03-妖冶世子

# 男原型 03：妖冶世子·阴郁颓废

> 来源样本：暗黑玫瑰古风世子（链条抹额）、蓝铜金颓废忧郁美男。

## 外貌锚定段（30-50词，逐字带）
```
年约二十，冷白皮，五官俊美妖冶，狭长凤眼，唇红齿白，
蓬松凌乱黑长发垂坠拂面，发丝精细根根分明，
眼神阴冷傲慢厌世颓废，眉眼间满满的厌世感，
气质阴郁疏离
```

## 发型发饰
- 蓬松凌乱长发，随意飘散
- 精致链条抹额、铜制/银质发饰
- 金属吊坠、细链

## 服饰
- 暗红/黑/蓝铜 华丽古风华服
- 链条、荆棘、玫瑰元素
- 丝绸/薄纱/皮革拼接
- 精致但带颓废感

## 气质关键词
厌世、颓废、阴郁、妖冶、傲慢、清冷、破碎感

## 推荐配色
暗红+黑+玫瑰 / 蓝铜+金 / 黑+银

## 推荐风格
风格03 半厚涂OC / 风格05 胶片CCD油画 / 风格06 极繁暗黑华丽
