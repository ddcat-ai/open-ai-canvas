## 风格01-真人写实国风

# 风格 01：真人写实国风（默认款）

> 来源样本：绿衣大家小姐、粉衣闺秀、红橙金淑女、浅青男弟子、墨蓝唐装贵族男。

## 风格定义
真人质感 + 国风古装 + 自然光照。皮肤真实有毛孔，布料褶皱自然，8K 纹理。这是本技能**默认风格**。

## 锚定词段（逐字带）
```
超写实国风，真人写实质感，自然光线，质感光照，8K高清纹理，
布料褶皱自然，皮肤真实毛孔肌理，发丝各向异性透光，
PBR物理材质，电影级柔光灯效，艺术写实风格，震撼视觉效果
```

## 负面
```
卡通，动漫，二次元，Q版，插画感，厚涂感，手绘感，塑料皮肤，磨皮过度
```

## 适用
- 默认角色设定稿
- 大家闺秀/世家公子/古装日常
- 要求"像真人照片"的国风角色
