## 五、句式拆解（教你仿写）

以 M-01 为例拆解：

```
清冷禁欲世家贵公子   ← 气质标签（先定调）
26岁，186cm         ← 年龄身高（定位）
冷白哑光皮肤         ← 肤色质感
剑眉浅敛，狭长丹凤眼，瞳孔深棕  ← 眉+眼+瞳色
下颌锋利利落         ← 脸型/下颌
黑色狼尾长发         ← 发型发色
银白玉发簪，素色暗纹锦袍  ← 服装配饰
肩宽腰窄            ← 体型
神态淡漠疏离，克制内敛，眼底藏淡淡忧郁  ← 神态（偏抽象，可再翻肌肉词）
冷调伦勃朗光影       ← 光影
```

**仿写模板**：
```
[气质标签]，[年龄]岁，[身高]cm，[肤色]，[眉]，[眼]+[瞳色]，[脸型]，
[发型发色]，[服装配饰]，[体型]，[神态]，[光影]
```
