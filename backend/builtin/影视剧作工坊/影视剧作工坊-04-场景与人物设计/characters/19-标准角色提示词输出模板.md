# 标准角色提示词输出模板（单帧图）

> **本文件就是模块 04 走进全链路时的产出标准**：模式① 主链内触发 → 产出**单帧图提示词**（单张、完整画面）。
> 首帧图 / 尾帧图 / 常规单帧图**共用这一套格式**，只是实例不同。
>
> **⚠️ 单帧图不带声音层。**单帧图只取 **①–⑦ 七要素 + 负面约束**；**⑧对白 / ⑨背景音 / ⑩BGM 属视频与交付文件层（12 装配），不进单帧图**。本文件下方列出的十槽位是**全集**，单帧图只用到前七槽——表里已逐条标注。

## 〇、与 `14-输出模板.md` 的分工（别混用）

| 模板 | 是什么 | 用来干什么 | 背景 | 长度 |
|------|--------|-----------|------|------|
| `14-输出模板.md` 的 **prompt-output** | **角色设定图提示词**（5 段短串） | **建角色资产**：定妆图、白底设定稿 | 纯白背景 | 短 |
| **本文件** | **角色镜提示词**（十槽位） | **直接出片出镜**：有场景、有光影、有镜头、有声音 | 真实场景 | 长 |

**工作顺序不可颠倒**：**先用 `14` 出设定图锁身份 → 再用本模板出角色镜**。直接拿本模板建资产会把场景光写进设定图，污染身份锚点。

## 一、为什么 `14` 写不出角色镜标准（缺口记录）

`14` 的 prompt-output 只有五项：`{① 风格锚定段}，{② 角色锚定段}，{③ 服装道具}，{④ 表情姿态}，{⑤ 光影环境}`。

对照角色镜标准，缺六类东西：

| 缺什么 | 为什么 `14` 没有 |
|--------|-----------------|
| **体型体态分层**（肩颈／锁骨／腰肢／体态） | `14` 的 ② 只留"体型身高"一格 |
| **皮肤质感独立层**（凝脂／透粉血色／边缘透光） | `14` 把肤质塞在 ② 里，且是设定图口径（纯白背景下的肤色），不含环境光下的透光观感 |
| **头饰独立槽** | `14` 并入 ② |
| **微表情取用接口** | `14` 的 ④ 写了"表情姿态"，但 04 又规定"表情从 05 微表情库选，禁止自造"——**模板没给取用口** |
| **呼吸与细小动态** | 属 05 的"内部运动"层，`14` 完全没有 |
| **场景 / 光影 / 镜头 / 音频 / 画幅** | 分别属 04 场景线 / 06 / 06·08 / 09 / 12，`14` 只留了一句"⑤ 光影环境" |

## 三、④ 人物外观状态的内部九层（本模板的核心）

`14` 把人物压成一段，本模板**拆成九层**——因为你给的标准里，人物本身就是分层的：

| 层 | 写什么 | 例 |
|----|--------|-----|
| **1 身份** | 角色称谓（不是名字，是**可见身份**） | 皇贵妃 / 女将 / 女总裁 |
| **2 年龄段** | 具象岁数或年龄段 | 二十七八岁 |
| **3 体型体态** | 体量 + 线条，**分层写** | 身形丰腴饱满、肩颈圆润、锁骨线条柔和、腰肢柔软 |
| **4 皮肤质感** | 底色 + 血色 + **光下观感** | 皮肤白皙如凝脂、透出淡粉血色、烛光下泛暖白半透明柔光 |
| **5 面部识别点** | 脸型 / 眉 / 眼型+瞳色 / 鼻 / 唇 / 辨识标记 | 远山细眉、眼型偏长眼尾微垂、深褐瞳、唇色豆沙红唇珠饱满 |
| **6 发型** | 型 + 状态 + 发色 + 光泽 | 高髻半挽、松垂几缕碎发贴于颊侧、乌黑发丝可见单根光泽 |
| **7 头饰** | 冠 / 步摇 / 缀饰 / 镶宝 | 金饰头冠缀红珠、两侧垂珍珠流苏步摇 |
| **8 服装** | 颜色 + 材质 + 版型 + 纹样，**逐件** | 青绿色层叠薄纱衫、内层珠光素绉缎、外层蝉翼透纱、领口袖口金线缠枝纹 |
| **9 辨识标记** | 疤 / 痣 / 纹 / 梨涡 | 左颊一枚极淡的梨涡 |

**铁律**：**九层全具象**——禁"美丽/忧郁/气质出众"这类词；**皮肤质感与体型体态必须独立成层**，不能塞进"脸部"一句里。

## 四、拼装顺序

```
② 画幅 + ⑥ 景别（前置，先定画框）
→ ④ 人物外观状态（九层，锚定段逐字）
→ ⑤ 人物动作（含微表情与呼吸）
→ ③ 环境场景
→ ⑦ 光影色彩（六条）
→ ⑥ 镜头运镜（含终止条件）
→ ① 渲染规格
→ ② 画幅画质
→ 负面约束
```

**⚠️ 单帧图到此为止——不接 ⑧⑨⑩ 声音三轨。**声音层在 12 装配视频/交付文件时才加入。

**依据**：官方块顺序里 `AUDIO` 在 `STYLE` 之前、`POSITIVE LOCKS` 殿后（见 12 `prompt/14-seedance导演` §块顺序）；但那是**视频提示词**的顺序，**静帧单帧图不含 AUDIO 块**。

## 五、完整范例

### 范例 A · 皇贵妃（深夜寝殿）

> 16:9 中近景，人物居中略偏左。皇贵妃，二十七八岁，身形丰腴饱满，肩颈圆润，锁骨线条柔和，腰肢柔软；皮肤白皙如凝脂，透出淡粉血色，烛光下泛暖白半透明柔光；鹅蛋脸，眉形远山细长、眉峰极淡，眼型偏长、眼尾微垂，瞳色深褐，睫毛根根分明，鼻梁秀挺、鼻头圆润，唇色豆沙红、唇珠饱满、唇面有湿润高光，左颊一枚极淡的梨涡；高髻半挽，松垂几缕碎发贴于颊侧与颈侧，发色乌黑、可见单根光泽；金饰头冠缀红珠，两侧垂珍珠流苏步摇，金绣滚边细密；身着青绿色层叠薄纱衫，内层珠光素绉缎，外层蝉翼透纱，领口与袖口皆有金线缠枝纹刺绣，腰间系同色软带。她侧倚在明代宫廷雕花玫瑰木床榻上，右手轻抬、指尖缓缓拂过袖口金绣，左手垂落搭在膝上；眼波流转，眉心微蹙又缓缓舒展，唇线抿而微松；肩线随呼吸轻微起伏，胸口起伏压得极轻。深夜寝殿，朱漆立柱与暗红描金屏风，黄铜烛台三支烛，火焰金黄跳动，烛烟拉出细线形成斜切光柱，背景纱帘虚化成暖金与暗红色块。主光为烛台暖光、自右下低位打来；皮肤表面形成柔和暖白高光，皮肤边缘有细微透光感；发丝单根可见并被冷光勾亮；金饰红珠反光锐利；丝绸高光窄而柔；暗部保留暖色反弹、不死黑。镜头自中景缓慢推近至面部特写，推镜平稳不跳，终结在她眼波定住的一瞬。电影质感3D漫剧，UE5渲染，PBR物理材质，皮肤SSS次表面散射，细微毛孔，实体发丝，浅景深，轻微胶片颗粒。16:9，8K超高清，细节丰富，纹理清晰，画面流畅。避免：现代物品、塑料皮肤、恐怖谷、多手指、画面抖动、卡通风格、廉价影楼光。

### 范例 B · 都市女总裁（高层夜景）

> 16:9 半身至七分身，人物居右。女总裁，三十二岁，身形高挑修长，肩线平直，腰肢收紧；冷白皮肤保留毛孔，哑光质感，面颊血色偏淡；鹅蛋脸，眉形细长偏直、眉峰微挑，眼型狭长、眼尾上挑，浅琥珀瞳，眼下有极浅卧蚕，鼻梁高挺，唇色红棕偏暗、唇面哑光、下唇有细高光；乌黑长发侧分披肩、微卷，碎发拂面，发丝有自然光泽条；无头饰；黑色 oversize 羊毛西装披肩，内搭白色缎面衬衫、领口敞开一粒扣，黑色高腰阔腿裤，银色叶片流苏耳坠、细链项链、金属腕表、右手无名指素圈戒指；无辨识标记。她坐靠深色皮沙发扶手，一手持红酒杯轻晃，另一手搭在膝上，姿态松弛而掌控；嘴角微扬而眼底不达笑意，肩颈放松，呼吸平缓。高层夜景办公室，落地窗外城市夜景冷蓝 bokeh，前景烛台暖金光，深色皮沙发与深色木桌。主光为侧前暖烛光、打亮面部；皮肤表面有暖色高光但不过曝；缎面衬衫反光柔和；玻璃酒杯与酒液折射清晰；皮沙发有微弱反光；冷蓝城市光自侧后形成轮廓光，暗部不死黑。镜头自半身缓慢推近至近景，稳定不抖，终结在她抬眼的一瞬。电影质感3D漫剧，UE5渲染，PBR物理材质，皮肤SSS次表面散射，细微毛孔，实体发丝，浅景深，轻微胶片颗粒。16:9，8K超高清，细节丰富，纹理清晰，画面流畅。避免：明亮日景感、可爱风、杂乱背景、塑料玻璃、塑料皮肤、恐怖谷、多手指、画面抖动、卡通风格。

### ⚠️ 单帧图与「去配乐」档的关系

**去配乐档是视频/交付文件层的规则，与单帧图无关**——单帧图本来就不带声音层。

去配乐档的写法见 12 `prompt/32-三模式标准交付模板.md` §三之补二：把视频提示词里的 `BGM：…` 整句换成 `NO BGM。`，环境音保留。

## 六、交付前自检

**人物层（④）**
- [ ] 九层齐全（身份 / 年龄 / **体型体态** / **皮肤质感** / 面部 / 发型 / **头饰** / 服装 / 辨识标记）？
- [ ] 体型体态与皮肤质感**各自独立成层**，没塞进"脸部"一句？
- [ ] 全具象，零抽象形容（无"美丽 / 忧郁 / 气质出众"）？

**跨模块层**
- [ ] ⑤ 的微表情是**从 05 或 `characters/17` 取的具名项**，不是自造的"微微悲伤"？
- [ ] ⑤ 含**呼吸或身体微节拍**（肩线／胸口起伏）？
- [ ] ⑥ 的运镜有**预设名**与**具名终止条件**（"终结在她眼波定住的一瞬"）？
- [ ] ⑦ 光影写了**六条**里的至少四条？
- [ ] **单帧图里没有声音层**（无对白 / 无环境音 / 无 BGM 行）——有就是错的，那属视频与交付文件层？
- [ ] ① 渲染规格存在，且技术词已转画面词？
- [ ] ② 画幅已写，且与输入图（若走首帧/首尾帧）一致？

**交付层**
- [ ] 负面词来自**该风格基准的「负面词追加」+ 全局底座**，不是通用词堆？
- [ ] 全篇**无引擎名残留**（Lumen / Nanite / PBR / SSS 只在 ① 的"技术真相层"提及，交付版要转画面词）？
