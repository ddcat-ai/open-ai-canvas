# 表情表演接口（本模块 ↔ 人物表演模块）

本模块**不做表演知识的第二份拷贝**。表情与表演的完整体系已建于人物表演模块（acting / facs / soul 三主件 v2.0.0 + 负面约束表，位于 `导演skill框架\人物表演模块\`）；本文件只定分工与查表顺序。

## 查表顺序

| 需求 | 查哪 | 在哪 |
|---|---|---|
| 静帧出图要某个具体表情（"清冷""含泪回眸"） | **速查层：微表情基准 100 组** | 本目录 `微表情基准-100组面部表情.md`（ai-film-art 逐字保留） |
| 表情要精确到肌肉（AU 代码、强制性/诡异感/混合表情、对白面部节拍） | **下钻层：FACS 主件** | 人物表演模块（49 个 AU 代码 + 情绪→AU 配方 + 节拍时刻表） |
| 角色怎么动、怎么听、怎么反应、表演主档 | **表演层：acting 主件** | 人物表演模块 |
| 图像侧微表情预设（核心 9 + 扩展 10，设定表分格用） | soul 主件 § 微表情 | 人物表演模块（soul 三主件之一） |
| 表情/表演负面约束 | 负面约束表（第四件） | 人物表演模块 |

## 接口规则

1. 速查层够用不下钻——100 组按情绪→可直接出的表情词查得快；FACS 是精度工具，进场要付节拍成本。
2. 下钻时身份不换手：FACS 的 AU 表接的是**同一张身份卡**（融合版身份卡第 3 层锚定块⑩面部表情），落卡字段不变。
3. 状态卡记录表情状态变化；逐场的情绪连续性归人物表演模块的连续性账本，本模块状态表与之对账（→ `6-组织纪律.md` 账本闭环）。

## A 组｜平静内敛类（M01–M20）

**M01. 平静凝神**
眉骨平缓，眼皮自然松弛，瞳孔稳定聚焦，嘴唇自然闭合，面部肌肉无紧绷，沉静专注，细微呼吸起伏，无多余情绪

**M02. 淡默思索**
眉心极浅微蹙，视线向下落，眼睑半垂，嘴唇平直，下颌轻微内收，正在暗自思索，情绪内敛不外露

**M03. 克制淡然浅笑**
嘴角极轻微上扬，不露齿，苹果肌微微隆起，眼轮匝肌轻微收紧，眼底带柔光，淡淡的克制微笑

**M04. 冷静审视**
眉骨轻微下压，上眼睑微沉，眼神冷静打量，嘴唇平直紧闭，面部张力克制，不动声色观察对方

**M05. 放空失神**
眼神失焦，瞳孔涣散，眼睑松弛，面部肌肉全部放松，短暂失神，思绪飘向回忆

**M06. 温和倾听**
眉眼舒展，目光落在对方，嘴唇放松微开，微微侧耳，专注聆听，神态柔软平和

**M07. 漠然疏离**
眉峰平直无起伏，眼神清冷，无温度，嘴唇闭合，面部无多余肌肉动作，保持距离感

**M08. 淡淡怅然**
眼尾微微下沉，视线低垂，嘴角极轻微下撇，情绪淡淡的怅惘，没有大哭，只有心底失落

**M09. 平静确认**
瞳孔轻微收缩，目光锁定，嘴唇保持平直，内心确认事实，表面不动声色

**M10. 慵懒倦怠**
上眼睑微微下垂，眼皮半遮瞳孔，眉压低，面部肌肉松弛，长时间疲惫后的松弛神态

**M11. 安静等待**
视线平稳向前，嘴唇轻闭，呼吸均匀，面部无多余动作，安静等候，内心沉静

**M12. 内敛释怀**
眉心慢慢松开，眼尾柔和，嘴角极淡扬起，紧绷的面部肌肉缓缓舒展，放下执念

**M13. 漠然一瞥**
眼球缓慢侧移，只余光扫向一侧，面部不动，眉不变，冷淡的短暂一瞥

**M14. 轻微出神**
视线穿透前方，没有聚焦在物体上，睫毛缓慢轻眨，思绪游离，安静发呆

**M15. 沉稳笃定**
下颌收紧，嘴唇闭合呈直线，眼神稳定有力，眉峰平稳，内心坚定，不慌乱

**M16. 温柔垂眸**
眼皮缓缓向下，视线落在下方，眼睫投下浅阴影，嘴角平直，安静温柔

**M17. 平静叹息**
鼻翼轻微扩张再收回，嘴唇微张又闭合，面部没有大动作，无声轻叹

**M18. 不动声色观察**
眼球缓慢移动，跟随目标，眉保持不动，嘴唇紧闭，暗中观察，不露心思

**M19. 淡淡疲倦**
眼窝轻微下沉，下眼睑松弛，眉压低，嘴角微微下沉，长期消耗后的安静疲惫

**M20. 安静接纳**
眉眼舒展，目光柔和，嘴唇放松，没有抗拒，平静接受眼前现实

## 选表规则（技能调用时必须遵守）

### 1. 情绪强度匹配
分镜表中的「角色/动作/表情」字段决定了微表情强度，按以下梯度选表：

| 剧情情绪强度 | 选表范围 |
|------------|---------|
| 平静 / 日常 / 铺垫 | A 组（M01–M20） |
| 压抑 / 隐忍 / 内心戏 | B 组（M21–M40） |
| 转折 / 惊觉 / 对峙试探 | C 组（M41–M60） |
| 带笑意（含冷笑苦笑） | D 组（M61–M80） |
| 高潮 / 多层复合情绪 / 命运节点 | E 组（M81–M100） |

### 2. 同一场景内的微表情递进
禁止在同一场戏中重复使用同一条微表情。情绪升级路径示例：
```
M01 平静凝神 → M29 压抑不安 → M53 危险预判 → M84 决绝不舍
M02 淡默思索 → M42 怀疑审视 → M58 识破谎言 → M88 得知真相后的幻灭
```

### 3. 微表情与镜头运动搭配
| 微表情类型 | 推荐镜头 |
|-----------|---------|
| A 组（平静类） | 02 半身固定对话镜 / 11 慢速环绕镜 / 26 焦点切换移焦镜 |
| B 组（压抑类） | 03 慢推面部情绪镜 / 06 眼部特写镜 / 14 荷兰角倾斜镜 |
| C 组（警觉类） | 06 眼部特写镜 / 26 焦点切换移焦镜 / 16 前景遮挡窥视镜 |
| D 组（笑意类） | 02 半身固定对话镜 / 05 越肩视角镜 / 46 镜面反射镜 |
| E 组（复合类） | 31 升格慢动作特写镜 / 03 慢推面部情绪镜 / 49 光影扫过人物镜 |

### 4. 微表情库与拍摄镜头库的关系
- 拍摄镜头库决定**怎么拍**（景别、机位、运动、光影）
- 微表情库决定**脸上是什么**（肌肉细节、眼神、嘴唇状态）
- 两者必须**组合使用**：面部特写镜头 = 拍摄镜头模板（如 06 眼部特写镜的机位与光影参数） + 微表情描述（如 M23 克制心痛）
