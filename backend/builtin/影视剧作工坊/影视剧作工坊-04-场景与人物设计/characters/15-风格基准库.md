## 一、三种子风格基准

### 基准A：沧桑粗粝写实风（图A）

**适用**：历经磨难/落魄/逃亡/战后/底层职业角色（调查员、退伍者、流浪者）

| 维度 | 基准值 |
|------|--------|
| 背景 | 浅灰白影棚底，无装饰，突出设定图属性 |
| 肤色 | 偏灰黄，带疲惫感；眼周青黑淤色、面颊擦伤血痕等**战损细节** |
| 眼神 | 沧桑眼神：眼睑略沉、目光涣散中带锐利，眼下有明显阴影 |
| 发型 | 凌乱感黑发，发丝有翘起与碎发，非规整造型 |
| 服装 | 做旧处理：橄榄灰绿工装夹克（污渍、磨白、袖口磨损起毛）、格纹棉质衬衫、灰色长裤、磨损棕色皮鞋 |
| 色彩 | 低饱和大地色系（橄榄绿/灰褐/暗棕），无高光艳色 |
| 皮肤 | 真实皮肤纹理：毛孔、干纹、胡茬阴影、伤痕结痂 |
| 光线 | 柔和漫射光，无强烈明暗对比，偏向设定图的中性展示光 |

**质感关键词**：`沧桑眼神，真实皮肤纹理，做旧服装，磨损细节，战损痕迹，低饱和大地色，疲惫体态`

### 基准B：都市精修写实风（图B）

**适用**：职场精英/专业人士/沉稳内敛型角色（建筑师、律师、高管、学者）

| 维度 | 基准值 |
|------|--------|
| 背景 | 深炭灰至墨蓝渐变底，带微弱环境光晕，突出人物轮廓光 |
| 肤色 | 干净均匀，保留毛孔与轻微肤色不均，无瑕疵修饰过度 |
| 眼神 | 沉稳内敛：目光平视、瞳孔清晰、镜片后眼神聚焦 |
| 发型 | 规整黑发，有自然蓬松度与碎发层次 |
| 服装 | 深炭灰羊毛西装（平驳领、四粒扣袖口）、灰白格纹棉质衬衫（领口敞开一粒扣）、黑框方形金属眼镜、黑色牛津鞋 |
| 色彩 | 冷灰调（深炭灰/灰白/黑），银色金属点缀 |
| 材质 | 羊毛织物纹理、棉质格纹清晰、金属镜框各向异性高光 |
| 光线 | 主光左上45度 + 轮廓光勾边，暗部不死黑，背景渐晕 |

**质感关键词**：`沉稳内敛，羊毛西装质感，格纹面料清晰，黑框金属眼镜，轮廓光勾边，深炭灰渐变背景`

### 基准E：胶片暗调氛围风（参考：胶片低光美人图）→ **必须 3D 化转写**

⚠️ 原图为胶片摄影质感（真人向），本基准**只继承氛围与构图，不继承真人质感**。转写后仍为 UE5 3D 写实渲染。

**适用**：夜戏/神秘/仙侠暗场/宿命感氛围镜头

| 维度 | 基准值（转写后） |
|------|----------------|
| 背景 | 深墨蓝近黑夜空 + 金色星光散景（bokeh 光点）+ 冷白烟雾体积光 |
| 肤色 | 冷白通透，唇色豆沙红，眼下淡粉晕 |
| 眼神 | 回眸凝望：头微侧、目光斜向镜头，眼睑半垂带疏离 |
| 发型 | 黑色高发髻 + 垂落长发，发丝边缘被冷光勾亮 |
| 服装 | 墨蓝/玄黑织金古装 + 灰白羽毛大氅（羽毛层次分明，根根可数） |
| 配饰 | 鎏金凤冠（镂空金属+珍珠）、银色流苏步摇、金坠耳环 |
| 色彩 | 墨蓝黑主色 + 鎏金 + 冷白羽毛 + 金色星光点 |
| 材质 | 羽毛柔软次表面、织金暗纹各向异性、金属镂空高光 |

**3D 化转写要点**：胶片颗粒保留为「轻微胶片颗粒」（前缀已有），但皮肤必须保持 SSS+毛孔的 3D 写实质感，禁止出现真人照片感；羽毛/烟雾用 UE5 粒子与体积雾表达。

**质感关键词**：`暗调低光氛围，金色星光散景，冷白烟雾体积光，羽毛大氅层次分明，鎏金凤冠镂空高光，回眸凝望，暗部不死黑`

**负面词追加（本基准专用）**：
`真人照片感，摄影人像，胶片人像肤质，纪实摄影，平坦光照，高调曝光，虚假星光贴图，烟雾贴图，羽毛贴图，塑料感，均质冷调铺满全身`

### 基准H：星瞳唐风夜色情写风（参考：紫瞳唐装美人特写图）→ **插画笔触/BJD感必须转写**

⚠️ 原 prompt 含「插画风格特效、笔触、线条清晰、BJD感效果、高斯模糊柔焦」。**造型/瞳色/氛围/布光可继承，渲染质感一律转写为 UE5 3D 写实**：笔触线条→实体发丝与织物纹理；BJD感→写实美型比例+SSS皮肤（禁止关节感/塑胶感）；高斯模糊→大光圈浅景深。

**适用**：古风美人面部特写/半身情写、邪魅/清冷/宿命感眼神镜头、夜景氛围人像

| 维度 | 基准值 |
|------|--------|
| 构图 | 面部特写至半身人像，人物居中略偏，直视镜头/眼神杀，突出颈肩线条与丰盈身形 |
| 背景 | 暗调夜景 + **彩色光斑虚化**（蓝/紫/粉多色 bokeh 交错），朦胧梦幻 |
| 肤色 | 清透瓷白，细腻肌理（毛孔级），面颊微粉晕，瓷器般光滑但**保留真实肌理**（拒绝磨皮） |
| 眼神 | **狭长丹凤眼、细长眼尾、半眯**；**星光瞳孔**（紫罗兰/紫色瞳色 + 瞳孔内星点高光）；邪魅、情绪化眼神、直视镜头 |
| 眉形 | 细长柳眉，眉尾略挑 |
| 唇 | **散发温润光泽的红唇**（浆果红/正红，唇峰清晰，下唇高光点） |
| 发型 | 深棕色长发披散，**凌乱发丝拂面**（数缕碎发斜过面颊），发丝温润光泽 |
| 服装 | **淡紫色唐制露肩装长裙汉服**：纱质垂坠、露肩露锁骨、领口/裙摆织金纹样 |
| 配饰 | 小巧紫晶/粉晶耳坠（点缀级，不抢戏） |
| 色彩 | 淡紫主色 + 深棕发色 + 暗蓝紫背景 + 彩色光斑（蓝/紫/粉）+ 红唇点睛 |
| 材质 | 唐制纱裙半透明垂坠、织金纹样各向异性、发丝各向异性光泽、唇部湿润高光 |
| 光线 | **侧光 + 双色温布光**（冷主光塑形 + 暖辅光补暗部），明暗交错戏剧性光影，强化面部阴影；曝光控制保留暗部细节；大光圈浅景深 |

## 八、风格转换铁律（最高优先级）⭐

用户提供或指定的参考图可能来自**任意风格源**：2D 工笔、胶片真人摄影、2.5D 动漫、插画、手绘等。本技能的输出**永远且只能是 UE5 渲染 + 3D 写实**。

### 8.1 继承与禁止对照表

| 参考图元素 | 处理方式 |
|-----------|---------|
| 构图、机位、人物姿态、视线方向 | ✅ **继承** |
| 服装款式、纹样、配色、配饰造型 | ✅ **继承**（转写为 PBR 材质描述） |
| 氛围、色调倾向、背景元素（星光/烟雾/光斑） | ✅ **继承**（转写为 UE5 光照/体积雾/粒子） |
| 版式结构（三视图/面板/引线/配色板） | ✅ **继承** |
| 发型造型、头面结构 | ✅ **继承** |
| **工笔线描/平涂/纸本质感** | ❌ **禁止继承** → 转写为 SSS 皮肤 + PBR 织物 |
| **真人照片感/胶片人像肤质** | ❌ **禁止继承** → 转写为 3D 写实皮肤（毛孔+SSS，拒绝磨皮也拒绝照片感） |
| **2D 动漫大眼/赛璐璐色块** | ❌ **禁止继承** → 转写为写实美型比例 + 实体睫毛 |
| **厚涂笔触/清晰线条/CG插画描边** | ❌ **禁止继承** → 转写为实体发丝 + 皮草毛发物理模拟 + 金属雕刻纹理 |
| **手绘笔触/插画描边** | ❌ **禁止继承** → 转写为实体发丝 + 物理毛发 |
| **C4D/平面抽象/壁纸渲染感** | ❌ **禁止继承** → 转写为 UE5 物理材质模拟（硬纱折角、层叠半透明） |
| **参考图上的署名/水印/小字** | ❌ **绝对禁止继承** → 一律删除；输出画面不得含任何文字署名（全局负面词已含「文字，水印，logo」） |

### 8.2 转写执行步骤

收到非 3D 风格参考图时：

1. **拆解**：把参考图拆成「可继承层」（构图/服装/氛围/版式/造型）与「禁止层」（渲染质感）
2. **转写**：禁止层的每个元素替换为 3D 对等物：
   - 工笔白描线条 → `实体发丝，织物经纬纹理，刺绣浮凸立体感`
   - 平涂色块 → `PBR物理材质，各向异性织金高光，次表面散射`
   - 纸本底色 → `UE5体积雾，环境光散射`
   - 胶片人像肤质 → `皮肤SSS次表面散射，细微毛孔，拒绝磨皮`
3. **锚定**：prompt 必须含统一基础前缀（已含 UE5/PBR/SSS 锚定词），并追加本库风格基准关键词
4. **负面加固**：prompt 的全局负面词之外，针对原图风格追加对应负面词：
   - 原图为工笔/手绘 → 追加 `工笔画，线描，白描，平涂，纸本质感，水墨晕染`
   - 原图为真人/胶片 → 追加 `真人照片，摄影人像，胶片人像，纪实摄影`
   - 原图为 2D 动漫 → 追加 `2D动漫，赛璐璐，大眼萌系，卡通描边`
   - 原图为厚涂/CG插画 → 追加 `厚涂笔触，明显笔触，插画描边，线条清晰，手绘线条，油画质感`

### 8.3 一句话原则

> **参考图决定「画什么」，本技能决定「用什么画」。** 画什么（造型/服装/构图/氛围）听参考图的；用什么画（UE5 + PBR + SSS + 3D 写实）永远听本技能的，不可协商。
