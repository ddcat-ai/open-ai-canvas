# 图片解析与收录基准工作流（Image Parsing & Baseline）

> 用途：用户上传一张角色参考图，本 skill 如何**看懂这张图 → 提炼成可复用的锚定词 → 建立收录基准卡**，让以后每次都能画出"同一个人"。

---

## 一、工作流总览

```
上传参考图
  ↓
步骤1：读图（使用 view_image 查看，必要时放大或裁剪局部）
  ↓
步骤2：七层提取（只写看得见的，不臆测）
  ↓
步骤3：判风格通道（真人 / 超写实 / 次世代 / Arnold / 国漫 / UE5）
  ↓
步骤4：生成提示词（五层公式拼装）
  ↓
步骤5：建收录基准卡（默认存当前工作区 ai-film-art/archive/，含稳定锚定段）
  ↓
交付：中英提示词 + 负面词 + 收录基准卡
```

---

## 二、步骤1：读图规范

- 用当前环境的**读图工具**打开本地图片（ZCode 用 `Read`，Codex 用 `view_image`）；若图片已在对话中显示，直接查看。
- 如果文字或细节看不清，裁剪或放大对应局部后再看。
- 看局部：先整体（风格/气质/构图），再局部（五官/材质/服装/光影）。
- **禁止凭空猜**——看不清的标"待确认"，不要编。
- **边界判定**：图里没有角色（纯场景/UI 面板/风景）时，如实说明"无可提取角色"，**拒绝生成基准卡**，不要臆造角色。

---

## 三、步骤2：七层提取清单

逐项观察并记录。**只写画面里实际看到的，不脑补性格。**

### 2.1 识别层
- 性别、年龄段（如 20-25 / 30-35）、大致种族感

### 2.2 外貌层（核心，最细）
| 项 | 观察并记录 |
|----|-----------|
| 体型身高感 | 高/矮/胖/瘦/肩宽/腰细 |
| 脸型 | 鹅蛋/方/长/圆/瓜子 |
| 眉 | 剑眉/远山/浓/淡/弯 |
| 眼型+瞳色 | 丹凤/杏眼/桃花 + 深棕/琥珀/异色 |
| 鼻唇 | 高挺/小巧 + 薄/樱/唇色 |
| 发型发色 | 黑长直/高马尾/银白 + 长度 |
| 肤色质感 | 冷白/小麦/古铜 + 哑光/通透 |
| 辨识标记 | 疤/痣/纹/异瞳/义眼 |

### 2.3 服装道具
- 上衣下装款式、颜色、材质、标志性配饰、鞋

### 2.4 表情 → 肌肉词
- 观察表情，**翻成 FACS 肌肉词**（查 facs-cheatsheet.md），不写"忧郁/开心"。

### 2.5 姿态视角
- 正/侧/3/4 侧面、身体朝向、手部动作、镜头景别（胸像/半身/全身）

### 2.6 光影
- 主光方向、软硬、色温、有无轮廓光、景深、背景

### 2.7 风格通道
- 判断属于 A/B1-B6 哪一类（判不准就对照各 style 文件的视觉特征）

---

## 四、步骤3：风格通道判定

对照各通道视觉特征：

| 观察到的 | 判为 |
|---------|------|
| 明显真人照片/摄影质感 | A 真人 |
| 逼真 CG 但像真人，干净精致 | B1 超写实 |
| 游戏 CG，PBR 材质，略美化 | B2 次世代 |
| 皮肤极通透，电影级离线感 | B3 Arnold |
| 7.5-8 头身，写实美化，国漫脸 | B4 国漫 |
| 游戏引擎感，体积光，电影 CG | B5 UE5 |
| GPU 光谱渲染、广告级通透质感 | B6 Octane |

---

## 五、步骤4：生成提示词

按 SKILL.md §2 五层公式拼装：
1. ① 风格锚定段（从对应 style 文件复制）
2. ② 角色锚定段（用步骤2.2 的具象词）
3. ③ 服装道具段
4. ④ 表情姿态段（用肌肉词）
5. ⑤ 光影环境段

输出中英双版 + 负面词。

---

## 六、步骤5：建立收录基准卡（关键！）

**收录基准卡 = 这个角色的"身份证"**。以后每次复刻，只读这张卡。

### 6.1 收录基准卡必含字段

```
【角色代号】：如 CHAR-001 清冷贵公子
【风格通道】：如 B4 国漫风
【稳定锚定段】：（跨图不变的外貌，30-50词，逐字锁定）
  性别/年龄/体型/脸型/眉/眼瞳/鼻唇/发型发色/肤色/辨识标记
【可变段】：（随场景变的：服装/表情/状态/道具）
【参考图】：（用户上传图的引用/描述）
【风格锚定词】：（复制的①段，逐字不变）
【负面词】：（该通道专属+通用）
【备注】：（比例/气质/特殊约束）
```

### 6.2 存哪里

- 默认存到当前工作区的 `ai-film-art/archive/`，文件名 `CHAR-XXX-角色名.md`；用户指定路径时以用户路径为准。
- 下次用户说"还是这个人""换个动作还是他"，**直接读这张卡，把稳定锚定段逐字带进去**。

### 6.3 一致性铁律

- **稳定锚定段逐字不变**——跨镜头/跨场景一字不差。
- 可变段（服装/表情/状态）可以换，但要有依据（换了衣服/受伤了）。
- 风格锚定词也逐字不变。
- 这样 AI 才能每次画出"同一个人"。

---

## 七、解析示例

**用户上传一张黑衣古风男图。**

**提取**：
- 识别：男，约25-28岁，东亚
- 外貌：高瘦，鹅蛋偏方，剑眉，丹凤眼深棕瞳，高挺鼻薄唇，墨黑高束长发，冷白皮，右颊浅疤
- 服装：玄色劲装，皮质护腕
- 表情：淡漠（→ 表情平淡，眼神疏离）
- 姿态：3/4侧面半身
- 光影：冷调侧光
- 风格：B4 国漫风

**生成提示词** + **建收录基准卡 CHAR-001**。
