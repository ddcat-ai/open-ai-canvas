# 场景六大风格通道（Scene Styles）

> 选风格通道，决定场景渲染质感。和人物 skill 六通道对齐。

---

## A. 真人实景（Photoreal / 电影感实景）

```
中文：真人实景摄影，电影级画面，真实材质质感，真实光影，8k超清摄影，
      自然曝光，真实色彩，景深自然
English: photorealistic cinematic scene, real photography, physically accurate lighting,
         8k uhd photograph, natural exposure, true colors, shallow depth of field
负面：卡通, 3D渲染, CG感, 手绘, 插画, 油画, 塑料感, 假透视
```

---

## B1. 超写实 3D（Hyperreal）

```
中文：超写实3D场景，照片级CG，PBR物理材质，真实光影全局光照，
      材质细节极致，反射真实，8k超精细，干净精致非真人照片
English: hyperrealistic 3D scene, photorealistic CG, PBR material,
         global illumination, ultra detailed materials, real reflections,
         8k ultra detailed, pristine not a real photograph
负面：卡通, 手绘, 塑料感, 假, 低模, 贴图糊, 真人照片感
```

---

## B2. 次世代（Next-Gen Game CG）

```
中文：次世代3A游戏CG场景，PBR物理材质，高精度模型，
      电影级布光，强明暗对比，8k超高精度，游戏CG过场质感
English: next-gen 3A game CG environment, PBR material, high poly detail,
         cinematic lighting, strong chiaroscuro, 8k ultra detailed, game cinematic
负面：低模, 手绘, 卡通渲染, 塑料感, 贴图糊
```

## B3. Arnold（电影级离线渲染）

```
中文：Arnold离线电影级渲染，无偏路径追踪，物理正确光影，
      全局光照光线自然反弹，反射折射真实，ACES电影调色，
      浅景深，高采样干净，8k超精细，电影质感
English: Arnold offline cinematic render, unbiased path tracing,
         physically based lighting, ray traced global illumination,
         real reflections and refractions, ACES color grading,
         shallow depth of field, high sample clean, 8k ultra detailed
负面：噪点, 塑料感, 假, 平光, 游戏实时感
```
