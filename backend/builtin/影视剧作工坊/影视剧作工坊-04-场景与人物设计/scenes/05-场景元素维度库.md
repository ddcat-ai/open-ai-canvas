# 场景元素维度库（Environment Elements）

> 把"在哪"拆成具体可画的元素：建筑、材质、道具、植被、大气。

---

## 一、建筑结构（写空间骨架）

| 维度 | 可写元素 |
|------|---------|
| 屋顶 | 琉璃瓦/歇山/庑殿/飞檐/平顶/玻璃穹顶 |
| 墙体 | 玻璃幕墙/红砖/白墙/石墙/木墙/混凝土 |
| 地面 | 柏油/青石板/木地板/大理石/草地/沙地 |
| 空间 | 层高/纵深/走廊/中庭/台阶/天井 |
| 附属 | 阳台/栏杆/门窗/楼梯/电梯 |

---

## 二、材质（写表面质感）

> 技术词→画面词：
- PBR物理材质 → "材质真实，反射符合物理"
- 金属粗糙度 → "金属哑光/亮面，带划痕磨损"

| 材质 | 画面写法 |
|------|---------|
| 玻璃幕墙 | 带环境反射，反射柔和，映出天空/霓虹 |
| 红砖 | 颗粒感，颜色深红，墙面风化 |
| 金属 | 冷硬反光，哑光/拉丝，带使用痕迹 |
| 木材 | 木纹清晰，温润，有磨损包浆 |
| 石材 | 粗糙颗粒，冷硬，有接缝 |
| 沥青 | 深色路面，湿时反光，有裂缝 |
| 织物 | 柔软褶皱，垂坠感 |

---

## 三、道具（写生活痕迹，拒绝全新）

**克制原则**：道具轻微使用痕迹（划痕/灰尘/磨损），不崭新出厂，不杂乱堆砌。

| 场景 | 道具清单 |
|------|---------|
| 办公室 | 显示器/键盘/文件/笔筒/保温杯/绿植 |
| 街道 | 共享单车/轿车/路灯/站牌/广告牌 |
| **古风·街市外景** | 灯笼/酒旗/茶盏/书卷/香炉 |
| **古风·宫廷内景** ⭐ | 朱漆立柱/描金屏风/博山炉/宫灯/烛台/帷帐/纱帘/锦被/雕花床榻/铜镜/妆奁/瓷器/玉器/拂尘/团扇/宫漏/奏折/砚台 |
| 赛博 | 霓虹招牌/全息屏/电线/水洼 |

> ⚠️ **「古风·宫廷内景」一行为补齐项**：原表古风只列街市外景五个词，殿内陈设（屏风 / 烛台 / 纱帘 / 帷帐 / 床榻）无处取值，角色镜的 ③环境场景 写不细。配套照明见 `03-全气候光照库.md` §14 宫廷古风内景夜。

---

## 四、植被（写季节生机）

| 类型 | 写法 |
|------|------|
| 行道树 | 春季新芽/夏季浓绿/秋季橙黄/冬季枯枝 |
| 竹林 | 竹竿笔直，竹叶婆娑，光影斑驳 |
| 古松 | 盘曲苍劲，松针如盖 |
| 草坪 | 春季返青/夏季茂盛/秋季枯黄 |

---

## 五、大气（写空气感）

| 元素 | 写法 |
|------|------|
| 雾 | 近实远虚，空气透视，远景朦胧 |
| 雨 | 雨丝/湿面/水洼/涟漪 |
| 雪 | 飘落/积雪/寒冷感 |
| 光雾 | 丁达尔光束/体积光/逆光轮廓 |

---

## 六、三层空间分层（好莱坞标准）

| 层 | 距离 | 精度 |
|----|------|------|
| 英雄近景层 | 焦点1-3米 | 超高模，细节极致 |
| 次级环境层 | 中景3-10米 | 完整PBR，合理拓扑 |
| 远景层 | 10米外 | 数字绘景+HDRI，简化，保留反射 |

> 生图时：近景细节清晰，远景虚化柔和。
