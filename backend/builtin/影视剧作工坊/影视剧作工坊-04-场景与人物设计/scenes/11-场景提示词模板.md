# 场景建模提示词输出模板

> 每次生成场景提示词，按此模板输出。

---

## 输入确认（先问清/补齐）

```
风格通道：A真人 / B1超写实 / B2次世代 / B3 Arnold / B4国漫 / B5 UE5
场景类型：都市 / 古风 / 科幻 / 自然 / 室内 / 末世
时间天气：（13种之一）
空间方位：俯仰 + 朝向 + 景别
情绪氛围：（要什么感觉）
画幅：横屏16:9 / 竖屏9:16
```

---

## 输出模板

```
【场景名：______】

▶ 中文提示词
（六维拼装，连成一段通顺描述）

▶ English Prompt
（对应英文，大模型直接吃）

▶ 负面词
（风格通道负面 + 通用禁止）

▶ 关键参数
风格通道：____
方位：____
时间天气：____
画幅：____
```

## 完整示例：雨夜赛博街道（B4国漫风，竖屏）

```
【场景名：雨夜赛博都市街】

▶ 中文提示词
国漫写实风3D场景，次世代PBR材质，赛博朋克都市街道，
平视一点透视纵深全景，9:16竖屏构图，前景雨棚压下1/3虚化；
夜晚小雨时段，湿滑柏油路面强烈反射霓虹招牌，拉长暖红光带；
高楼霓虹闪烁，全息广告牌，电线交织，远处雾气朦胧；
冷暖对比，体积光雾，电影级布光，8k超高清，国漫CG质感。

▶ English Prompt
chinese donghua realistic 3D scene, next-gen PBR material,
cyberpunk city street at night light drizzle,
eye-level one-point perspective wide shot, vertical 9:16 composition,
foreground canopy blurred at lower third,
wet asphalt reflecting neon signs with long warm red light streaks,
tall neon buildings, holographic billboards, tangled wires,
misty distant fog, cool warm contrast, volumetric fog,
cinematic lighting, 8k ultra detailed, donghua CG

▶ 负面词
2D动画, 赛璐璐, 手绘, 描边, 水彩, 厚涂, 卡通, 真人照片感,
平光死黑, 过曝, 光源方向混乱, 塑料反光, 噪点

▶ 关键参数
风格通道：B4国漫
方位：平视+纵深透视+全景
时间天气：夜小雨
画幅：9:16竖屏
```
