# 世界观美术资产库（视觉宪法·等级色彩·族系形制）

> ⚠️ **只读镜像**：本文件归属 `director-workbench`（导演工作台），正式来源为其 `assets/asset-library/worldview-art-bible.md`。此处仅供 AI影视美工理解语境，**请勿在本技能内修改**；更新请改导演侧资产后同步。


> 定位：角色有设定卡、场景有资产卡，但全剧缺**世界级视觉规则**——没有它，同一部仙侠剧每集像发生在不同平行宇宙。
> 用法：**Step 2 之前**（选定风格基准之后）为全片填写一份「世界观确认表」，作为所有后续资产卡的**上位约束**；任何角色/场景/道具卡的描述不得违反宪法条目。

---

## 一、世界观确认表（每剧一份，Step 2 强制输出）
```
【世界观宪法 vX】
1 世界类型：架空古代/仙侠/玄幻/都市异能/末世/西幻 …（须明确「非现实映射」声明，供审核红线引用）
2 力量体系：修炼等级/异能类别/科技水平 —— 等级数与名称（≤6级，每级一句可视化特征）
3 阵营与地理：主要势力名+各自视觉标识色+建筑形制归属（挂SC场景卡）
4 科技/时代基线：有无电/火器/网络；照明方式（决定夜景光源逻辑，灯光库联动）
5 族系与种族：人族/妖族/灵族…各族形制锚点（耳型/瞳色/体表纹/影形）
6 生死/鬼神规则：亡者可否显形、以何视觉形式（回忆/法相/夺舍）—— 决定闪回与恐怖镜头的合法性
7 禁忌与代价：使用力量的视觉代价（折寿显老/灵光黯淡），必须在画面中可见
```

## 二、等级色彩制（服化道随实力/身份变化的可视化规则）
**原则：观众必须能仅凭画面判断一个人的实力与地位——等级写在衣服上。**
| 维度 | 规则 | 落库 |
|------|------|------|
| 色阶 | 每势力定4-5级色阶（如：灰麻→素白→靛青→绛紫→鎏金），级别越高用色越纯越金 | 写入角色卡【服装设定】选择域 |
| 纹样 | 云纹/兽纹/道纹的层数或密度=等级数字 | 材质工艺字段 |
| 配饰 | 越级者方可佩越级徽记（腰牌/额饰）；**越级佩戴=剧情伏笔**，须在备注标 | 道具卡 PROP |
| 灵光 | 玄幻剧实力显形规则（光环颜色/法相尺寸=境界），与基准S/S系神性特效一致化 | ⑤库风格基准联动 |

**角色卡扩展**：每个角色的服装设定项后追加「世界等级：Lv.X（色阶依据：宪法§3/§4）」。

## 三、建筑形制库（场景卡的风格锚点）
- 每势力定义**三件套**：屋顶形制+主结构材质+纹饰母题（如：某宗门=黛瓦歇山+黑铁梁+云雷纹；某皇宫=重檐庑殿+朱漆+龙纹）
- 所有 SC 场景卡【权威环境描述块】的背景层必须复用所属势力三件套，跨集不重写
- 室内道具等级：按财富/权力分3档器物谱（瓷铜玉/鎏金/灵玉），写入场景卡
- 建筑尺寸锚：主角站立位到主结构的相对比例固定（如仰拍时檐角压在头顶上方1/3）→ 供法则六建立镜头复用

## 四、法器/坐骑/灵兽形制规范
- 每件命名法器建 PROP 卡：形制锚点+光效色（与持有者等级色一致）+ **成长线**（随境界变化：剑鞘纹样增加、灵光范围扩大）
- 灵兽/化形：与基准L（孔雀翎羽）等既有神祇基准的图腾体系对齐，禁止同类灵兽两种画法
- 幻术显形遵循⑨库「实物→异变→还原」，并统一破绽类型（本库为全剧指定1-2种破绽符号：一闪的实体轮廓/色温跳变）

## 五、族系视觉锚点
每族 3-4 个可辨识特征（瞳色/耳廓/额纹/体表光泽/影子形态），写入角色卡的**权威描述块之前**；族系特征在跨镜描述中逐字复用（⑪库规则），混血角色须明示继承哪几条。

## 六、跨集漂移检查（与⑪库、quality-loop 联动）
- 新增资产卡时校验：是否违反宪法任一§？色阶是否越级？建筑三件套是否吻合？
- 宪法修改须升版本号（vX→vX+1）并列出受影响资产清单，**旧版保留**（同角色换版规则）
- 每10集抽查：同势力场景色温/纹样是否一致；不一致=记录 bad case（L组）

## 七、自检指针（M组）
- [ ] 全片是否输出世界观确认表（含架空声明，供审核引用）？
- [ ] 每个角色/场景/道具卡是否标注其宪法依据（等级色阶/三件套/族系）？
- [ ] 越级佩戴/破绽符号等伏笔是否登记？宪法改版是否有升版与影响清单？

# 世界观一致性（Worldview Consistency）

> 同一部剧的场景不能每集像不同平行宇宙。建一次"视觉宪法"，后续场景都遵守。

---

## 一、世界观确认表（每剧一份）

```
【世界观宪法】
1 世界类型：现代都市 / 古风仙侠 / 赛博科幻 / 末世 / …
2 时代基线：有无电/网络/火器；照明方式（决定夜景光源逻辑）
3 阵营地理：主要势力 + 各自视觉标识色 + 建筑形制归属
4 色彩基调：全片主色 / 冷暖倾向 / 饱和度
5 材质体系：常用材质组合（玻璃金属？木石？琉璃？）
6 光影逻辑：自然光为主？人工光？固定时间段偏好？
```

---

## 二、建筑形制三件套（每个势力定死）

> 跨场景复用，不每集重写。

- **屋顶形制**：如 重檐庑殿 / 飞檐歇山 / 玻璃穹顶
- **主结构材质**：如 朱漆木构 / 玻璃幕墙 / 混凝土
- **纹饰母题**：如 龙纹 / 云纹 / 霓虹电路

---

## 三、色彩一致性

| 规则 | 说明 |
|------|------|
| 主色固定 | 全剧主色不跳变（如清冷蓝调 vs 暖黄怀旧） |
| 阵营色 | 不同势力场景用不同标识色 |
| 等级色阶 | 势力内部按等级用色（灰麻→素白→青→紫→金） |

---

## 四、跨场景漂移检查

每次生成新场景，对照：
- [ ] 是否违反世界观宪法？
- [ ] 建筑三件套是否一致？
- [ ] 色温/主色是否统一？
- [ ] 材质体系是否一致？

---

## 五、收录基准卡

> 像人物收录一样，场景也建"场景基准卡"。

```
【SC-编号 场景名】
风格通道：B4国漫 / B5 UE5
类型：古风·宫殿
方位：仰视+3/4侧+全景
时间天气：黄昏黄金时刻
建筑材质：重檐庑殿+朱漆+龙纹
光影：低角度暖光，长投影
氛围：庄严肃穆
正向词：……
负面词：……
```

后续同场景/同势力场景，逐字复用三件套与主色，保证不跑偏。
