## 一、都市（Urban）

### 街道
```
中国现代城市街道，玻璃幕墙写字楼+红砖老楼混合，柏油马路，
行道树，路灯，共享单车，沿街商铺，斑马线，人行道，写实生活痕迹
```

### 写字楼/办公室
```
高层写字楼内景，大面积落地玻璃幕墙俯瞰城市天际线，层高3.2米，
无框玻璃隔断，悬浮吊顶，嵌入式筒灯，抛光混凝土地面+灰色地毯，
独立办公桌，人体工学椅，落地绿植，极简高端
```

### 老城区/居民区
```
老旧小区，6-8层红砖居民楼，墙面风化轻微剥落，空调外挂机，
落水管，小区门禁闸机，快递柜，路边停车，生活气息
```

### 便利店/小店
```
24小时便利店，货架整齐，冷柜荧光灯，收银台，玻璃门，
暖白灯光，深夜便利店氛围
```

## 二、古风（Ancient Chinese）

### 宫殿/朝堂
```
中国古代宫殿，重檐庑殿顶，朱红立柱，金色琉璃瓦，汉白玉台基，
雕梁画栋，龙纹装饰，庄严肃穆，宏大规模
```

### 庭院/园林
```
中式古典园林，飞檐歇山，青砖灰瓦，假山池塘，垂柳，石拱桥，
月洞门，竹影，幽静雅致
```

### 山巅/野外
```
高山之巅，云海翻涌，古松盘石，悬崖峭壁，孤峰耸立，
苍劲古建（亭/塔），云雾缭绕，壮阔空灵
```

### 古街市
```
古代街市，青石板路，木结构两层楼阁，悬挂灯笼酒旗，
行人古装，夜市灯火，热闹繁华
```
