# 材质词库（Material Vocabulary）

> 用途：描述皮肤、毛发、布料、金属等材质质感。3D 通道（超写实/次世代/Arnold/国漫/UE5）尤其需要。

---

## 一、皮肤质感（3D 通道核心）

| 风格档 | 皮肤写法 |
|--------|---------|
| 超写实 | 皮肤次表面散射通透有血色，可见毛孔细纹与面部细绒毛，耳尖鼻尖微红透光，T区自然微油光 |
| 次世代 | 高精度面部高模，真实皮肤毛孔肌理，面部细绒毛，瓷感肤质 |
| Arnold | 皮肤通透如玉，次表面散射，关节处微红透光，温润有光泽 |
| 国漫 | 瓷白肌，皮肤通透细腻，略带美化，非塑料感 |
| UE5 | Nanite级皮肤细节，毛孔清晰，Lumen下皮肤自然反光 |
| 真人 | 真实皮肤纹理，自然肤色不均，T区油光，毛孔，细纹 |

### 皮肤问题反面词（避免塑料感）
塑料感、蜡像感、过度磨皮、假面、无毛孔、光滑如蛋、假脸

---

## 二、毛发质感

| 部位 | 写法 |
|------|------|
| 发丝 | 发丝根根分明，有光泽高光，碎发自然飞扬，发丝带自然毛躁感 |
| 男性头发 | 短碎发有层次，发丝纹理清晰 |
| 长发 | 长发垂落有重量感，发丝带光泽，飘逸 |
| 眉毛 | 眉毛细根根分明，有自然毛流 |
| 睫毛 | 睫毛纤长，根根分明 |
| 胡子 | 胡茬青影，络腮胡纹理清晰 |

---

|------|------|

| 纱料 | 半透明纱质，轻薄飘逸，透光 |
| 棉麻 | 棉麻纹理，质朴哑光，自然褶皱 |
| 皮革 | 皮革纹理，有光泽，磨损划痕 |
| 织锦 | 织锦纹样，金丝刺绣，华丽反光 |
| 毛呢 | 毛呢厚重，绒感 |
| 针织 | 针织纹理，柔软 |
| 铠甲金属 | 金属甲片，磨损划痕，反射环境光，铆钉 |

## 五、眼睛细节

| 部位 | 写法 |
|------|------|

# 光影布光词库（Lighting Vocabulary）

> 用途：拼装⑤光影环境段。情绪和氛围靠光影定。

---

## 一、布光方式

| 布光 | 画面效果 | 适合 |
|------|---------|------|
| 三点布光 | 主光+辅光+轮廓光，立体 | 通用角色立绘 |
| 伦勃朗光 | 侧脸阴影区三角亮斑 | 男性、深沉、戏剧 |
| 蝴蝶光 | 头顶光，鼻下蝴蝶影 | 女性、美颜、glamour |
| 分割光 | 半脸亮半脸暗 | 神秘、双面、反派 |
| 轮廓光/逆光 | 身后光勾边，分离背景 | 仙气、唯美、突出轮廓 |
| 侧顺光 | 45°前侧光 | 自然、百搭 |
| 顶光 | 正上方光，眼窝阴影 | 压抑、神圣、审判 |
| 底光 | 下方光，阴影上翻 | 诡异、恐怖、反派 |

---

## 二、光质（软硬）

| 光质 | 写法 |
|------|------|
| 柔光 | 柔和光线，阴影边缘模糊，过渡自然 |
| 硬光 | 硬朗光线，阴影边缘锐利 |
| 漫射光 | 均匀漫射，无明显阴影 |
| 聚光 | 聚光灯，光束集中 |

---

## 三、色温 / 氛围

| 氛围 | 写法 |
|------|------|
| 暖调 | 暖橙色光，金色暖光，温暖治愈 |
| 冷调 | 冷蓝光，清冷天光，冷静疏离 |
| 黄金时刻 | 暖橙侧逆光，长投影，黄昏 |
| 蓝调时刻 | 冷蓝环境光，忧郁都市 |
| 霓虹 | 霓虹光，紫蓝色调，赛博 |
| 烛火 | 暖黄烛光，局部光，暗调 |
| 月光 | 冷白月光，银蓝，清冷 |
| 丁达尔 | 光束穿透尘埃/雾气，光柱 |
| 体积雾 | 空气中可见雾，光束 |

---

## 四、景深 / 镜头

| 效果 | 写法 |
|------|------|
| 浅景深 | 强烈背景虚化，只有人物清晰 |
| 中等景深 | 人物清晰，背景略虚 |
| 深景深 | 前后景都清晰 |
| 长焦压缩 | 长焦压缩感，背景压缩 |
| 广角 | 广角透视，空间感强 |
| 特写 | 面部特写，聚焦眼睛 |

---

## 五、背景 / 环境词

| 场景 | 背景写法 |
|------|---------|

| 科幻 | 飞船、霓虹都市、实验室、全息屏 |
| 战场 | 硝烟、废墟、火光、冷雾 |
| 仙幻 | 云海、天宫、桃花林、仙雾 |
