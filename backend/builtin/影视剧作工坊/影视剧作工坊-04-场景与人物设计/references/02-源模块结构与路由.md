## 模块定位

**管三件事：出什么资产、怎么把资产定死、怎么跨镜头复用。**

| 管辖 | 不管辖（去哪） |
|---|---|
| 角色开发（前提/世界观/九问/七层卡/关系网） | 角色表演落地 → **人物表演模块**（acting/facs 三主件） |
| 人物资产（身份卡/设定表/状态卡/换装卡/人群卡/比例卡/道具卡） | 技术词→画面词的翻译体系 → **语义转换模块**（ai-film-art 语义转换引擎原位引用） |
| 场景资产（五视图/GEO 地理块/先判光/反打/俯视调度/锚物） | 视频运镜与机位运动 → **镜头设计与运镜模块** |
| ~~风格资产~~（已剔除 2026-09-27 → 风格模块 / 视觉渲染色彩模块） | 交付前质检与对账 → **交付校验模块** |
| 表情速查与接口（微表情100组 → FACS 下钻） | |

## 触发边界

- **导演全链路触发时**，本模块产出即终态资产提示词，直接交给链路下一环——**不进入、不转发语义转换**。
- 语义转换模块独立触发，只服务"技术词→画面词"翻译场景，与本模块无衔接。
