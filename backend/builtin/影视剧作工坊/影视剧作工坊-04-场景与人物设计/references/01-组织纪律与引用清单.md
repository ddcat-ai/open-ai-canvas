# 组织纪律（横跨六部分的执行规则）

## 一、@ 命名法（一本辞典）

- **全项目只用一本命名辞典**：所有资产挂标签（`@roco`、`@loc_cave_front`），文档/提示词/界面同一批标签。
- **给每张参考图命名角色**：不命名，模型自己定且定错——该抄脸的抄了构图。
- **场景类参考必须显式禁止继承**："只取空间与材质，不作起始帧，不继承构图/角度/调色"（→ `3-场景资产层/地理块-GEO空间布局.md`）。

## 二、槽位惯例（融合后统一的字段位）

| 槽位 | 内容 | 槽位来源 |
|---|---|---|
| ①风格锚定段 | 词组串逐字，段首，跨图一致性之锚 | ai-film-art 五层词料 |
| ②角色锚定段 | 30-50 词具象锚定，短而硬 | 七层卡 E2 ⊕ soul 身份块 |
| ③服装道具段 | 可变段+道具，E3 剧情依据 | 七层卡 ⊕ piano 测试 |
| ④表情姿态段 | 速查词（100组）/AU 码（下钻） | 表情表演接口 |
| ⑤光影环境段 | 先判光结论 + GEO 地理块 | 场景资产层 |
| 比例槽 | 双主体必挂 size-ref 资产 | 双主体比例卡 |
| 镜头槽 | 锚定块十项 + 运动块 | 身份卡 ⊕ soul |

## 三、六条资产纪律

1. **先资产后镜头**：要复现的东西先做成资产（设定表/场景设定表/道具卡），不在场景提示词里重新描述——逐场重述是"每个镜头重新诠释环境"的根源。
2. **单卡自洽**（E1）：仅凭一张卡还原"这个人是谁"；缺层即未完成。
3. **灰底出设定表**：中性灰是常设默认，不是风格偏好。
4. **一状态一卡**：状态变化单独出锚定设定表（场记纪律），不在基础卡上堆文字。
5. **复用锁四项**：场景带回时锁建筑/光质/色彩处理/关键环境细节，场景提示词只写变化。
6. **修补不重建**：缺陷资产用编辑模型一行字修，不重写提示词重摇全部。

## 四、平台分轨

| 轨 | 规范 | 依据件 |
|---|---|---|
| **即梦 / Seedream 图像轨** | 中文自然语言**整段连缀**（五层词料连成通顺段落，具象词逐字保留）；风格锚定段逐字放段首；负面词三法融入、不单独成段；禁质量乞讨词、禁词内比例参数；图内文字直接让它渲染；**一致性出图必须关智能润色** | ai-film-art `references/jimeng-seedream-adaptation.md`（原位引用） |
| **Seedance 视频轨** | 测量语言：米数/百分比/坐标/锁句；@ 命名法；GEO 块逐字进每镜头；全局风格前缀逐字复用 | 本模块 `3-场景资产层/`、`4-风格资产层/全局风格前缀.md` |
| **通用图模轨** | 英文提示词示例保留原文；身份块/运动块分离；六格网格锁句 | `higgsfield相关包-中文/`（soul、gpt-image-2） |

技术词进提示词前先翻画面词（PBR→"材质质感真实"式）→ 语义转换引擎，归语义转换模块，原位引用。

## 五、账本闭环

- **收录**：好样本按《收录基准卡》格式建档（模板见 `2-人物资产层/收录案例/收录说明.md`），案例卡入 `收录案例/`。
- **对账**：本模块状态追踪表 ↔ 人物表演模块连续性账本，交付校验前对账。
- **复盘**：每次出图结果（留/弃/翻车原因）记入账本，反喂基准卡修订——记账纪律同人物表演模块。
