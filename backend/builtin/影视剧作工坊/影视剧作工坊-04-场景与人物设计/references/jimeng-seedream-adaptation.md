# 即梦 / Seedream 图片适配（整段出词规范）

> **定位**：目标平台是**即梦（Seedream 图片模型）**时，中文提示词按本文规范改出「即梦整段版」。本文件只管**图片端**；Seedance 视频端的 @ 引用语法归导演工作台：`director-workbench/references/seedance2-generation-syntax.md`。
> **核心区别**：Seedream 是原生中文模型——吃自然语言整段，不吃 tag 堆叠；没有独立负面词输入框；中文是正主不是备份。MJ/SD 那套五层词组串 + 独立负面词 + 英文版的规则**在即梦上不适用**。

---

## 0. 模型特性速览（出词必知）

| 特性 | 对出词的影响 |
|------|-------------|
| 原生中文训练，吃自然语言完整句子 | 五层词料要**连缀成通顺段落**，不是逗号词组串（§2） |
| 中文语义理解深（丹凤眼/交领右衽/鹤氅/岩彩直接懂） | 喂即梦用**中文原生表达**，禁止按英文版回译 |
| **无独立负面词输入框** | 负面词按 §3 三法处理，不单独成段 |
| 质量乞讨词（masterpiece / best quality）无效 | 禁止出现；"电影级质感/8K超高清"这类**风格描述词**可以留 |
| 图内文字渲染强 | 设定稿标签文字直接写进提示词让它渲染（§4） |
| 组图/多参考（同角色多视角一次出） | 三视图设定稿天然契合，写法见 §4 |
| 统一生成+编辑架构，对话式编辑强 | 迭代修订交付「编辑指令」，见 §5 |
| 比例在**界面选**，不靠词 | 词里写"竖版构图"，禁止写"9:16"类参数 |
| 提示词**自动润色/扩写**功能 | 一致性出图必须关闭（§6），否则锚定段被平台改写 |

## 1. 硬规则（写死）

1. **①风格锚定段逐字放段首，保持词组串原样**——它是跨图一致性的锚，不整段化、不改写、不翻译。
2. ②角色锚定、③服装道具、④表情姿态、⑤光影环境，用自然语言**连缀成通顺段落**（主语不断、动词衔接）。
3. ②~⑤里的具象词**逐字保留**（"丹凤眼""左眉尾一道旧疤"），连缀只负责把它们嵌进句子里，禁止同义替换。
4. 负面词**不单独成段**，按 §3 三法处理。
5. **禁止质量乞讨词**：masterpiece、best quality、trending、award-winning 及中文等价物。
6. **禁止在词里写比例参数**（9:16、--ar 等）；写构图描述（"竖版构图""横版宽幅"）。词库前缀里的"竖屏9:16"一律剔除；器材型号词（如"RED V-RAPTOR X摄影机"）可保留，有写实风格联想，无害。
7. 交付时在备注注明：**即梦整段版 · 界面选比例 · 关闭智能润色**。

## 2. 五层词料 → 即梦整段版（连缀公式）

```
段首（逐字）：①风格锚定段（词组串原样）
正文（连缀）：②角色锚定 → ③服装道具 → ④表情姿态 → ⑤光影环境
```

**连缀手法**：
- ② 转主语句："画面主体是一位28岁东亚男性，身高182，瘦长脸……"（词表照抄进句子里）
- ③ 转穿着句："他身着……，手持……"
- ④ 转神态句："他此刻眉头微蹙，眼睑半垂，嘴角平直……"（肌肉词照抄）
- ⑤ 转环境句："场景是……，主光从左前方打来，暖橙色，背景强烈虚化……"
- 收尾可接风格外延："整体电影级调色，暗部深邃，高光不过曝"

### 示例（原料 → 成品）

原料（五层词料，词组形态）：
> 国漫写实风3D CG锚定段 ／ 28岁东亚女性，鹅蛋脸，狭长丹凤眼，墨黑高马尾，冷白哑光皮，右眉骨一颗小痣 ／ 月白色交领襦裙，银线绣云纹，腰束玉带 ／ 眼睑微垂，内眉端微抬，唇线放松 ／ 秋日庭院，侧逆光，浅景深

成品（即梦整段版）：
> 国漫写实风3D CG，7.5-8头身写实比例，真人骨骼结构，面部符合真人比例，次世代PBR物理材质，皮肤次表面散射通透有血色，实体发丝根根分明，电影级布光，8K超高清，干净精致的国漫CG渲染。画面主体是一位28岁东亚女性，鹅蛋脸，一双狭长的丹凤眼，墨黑长发束成高马尾，冷白色哑光皮肤，右眉骨有一颗小痣。她身着月白色交领襦裙，裙上以银线绣云纹，腰间束一条玉带。她此刻眼睑微垂，内眉端微微抬起，唇线放松，神态安静克制。场景是秋日庭院，侧逆光勾勒发丝轮廓，浅景深让背景柔和虚化，整体电影级调色，暗部深邃。

## 3. 负面词三法（即梦没有负面词框）

| 方法 | 用法 | 示例 |
|------|------|------|
| **正向融合（首选）** | 把禁止项翻成对应的正向描述，融进段落 | 负面"塑料皮肤" → "皮肤通透有血色、可见毛孔"；负面"卡通Q版" → 锚定段已含"非大眼Q版，非2D动画"，保留即可 |
| **句内否定（少量用）** | 段尾加"不要/无/非"短句 | "画面干净，无文字无水印，不要多余肢体" |
| **转自查清单（兜底）** | 融不进词的项列进交付备注，出图后人工核对 | "多手指/畸形——出图后检查" |

- 通道专属负面项（国漫禁卡通Q版、超写实禁塑料感……）**优先正向融合**：把"禁X"写成"要非X的正确特征"。
- 一条提示词里**句内否定 ≤ 2 处**，多了互相打架。

## 4. 三视图设定稿（F1）即梦写法

**公式**：
```
[①风格锚定段 逐字] + 同一位角色的角色设定稿，同一套服装造型，纯白背景，
画面包含：正面全身、侧面全身、背面全身三视图，左侧附面部特写与配色板，
右下角附全身比例参照，标注角色名"XXX"。
```

- 用"**同一位角色 / 同一套服装**"锁一致性；已有定稿角色图时按 §5 挂参考图。
- **标签文字直接写**：'三视图分别标注"正面/侧面/背面"，左上角标注角色名"XXX"'——中文文字渲染是强项，但单图文字 ≤ 10 字稳妥。
- **组图玩法**：同一角色多套服装/多表情 → "同一角色的组图，共X张，分别表现……"。

## 5. 参考图挂法与编辑指令（图生图）

**参考图（复刻/续画）**：
- 上传已定稿角色图，提示词开头写："参考图中的角色，保持面部特征、发型、服装一致，……"
- 参考图 ≤ 4 张稳妥（上限更高但多了互相稀释）；角色主体参考 1 张即可，每张用途写明。
- **写实真人脸参考会被平台自动拦截**（主入口 §1 平台约束）——3D 通道不受影响，真人通道只走文生图。

**编辑指令（迭代修订交付物）**：
- 格式："保持（锚定区：脸型/五官/发型/服装）完全不变，只改（可变区：表情/光线/背景/某部件）"
- 示例："保持角色的面部特征、发型和服装完全不变，只把背景换成黄昏的城墙，光线改为暖橙色逆光。"
- **一次只改一个变量**，改多了结果不可归因。

## 6. 平台纪律（出图前必查）

- [ ] 界面选好比例（词里无 9:16 / --ar 残留）
- [ ] **关闭提示词"智能优化/自动扩写"**——锚定段逐字不被改写是硬前提
- [ ] 参考图每张用途明确（无归属素材不放）
