# 场景与人物设计（模块 04）

> 主链定位：开发层 / 人物资产层 / 场景资产层 / 全场景物理约束 / 都市场景库。

## 核心信条

- **人物**：技术词翻成画面词、抽象词翻成具象词、参考图翻成锚定词——模型不认识"次世代 PBR 皮肤"，它认识"皮肤通透有血色、可见毛孔与干纹"。
- **场景**：场景不是"放个背景"，是**搭一个可信的空间**——有尺度、有材质、有光影、有氛围。

## 唯一入口：单帧图触发流程

**本模块不再单独触发。**所有调用一律走**单帧图触发流程**——无论触发来自全链路的自动带起，还是来自 05 表演 / 06 景别 / 07 分镜 / 10 组接的调用。

| 项 | 定义 |
|----|------|
| **入口** | **单帧图触发流程（唯一）** |
| **产出** | **单帧图**——单张、一个时刻、一个完整画面 |
| **格式** | `characters/19`：**①–⑦ 七要素 + 负面约束**；**不带声音层** |
| **同时供出** | 人物锚定段与场景世界观约束，供 05/06/07/10 复用 |

**没有「单独出人物 / 单独出场景」这条入口。**要人物就出**人物单帧图**，要场景就出**场景单帧图**——**都是单帧图，只是主体不同**；两者的资产层（`characters/` 七层设定卡、`scenes/` 六维）照常调用。

**链内三个实例**：常规单帧图 · 首帧图 · 尾帧图（后两者走首帧 / 首尾帧生视频时出，见下节）。

## 取景（不由本模块自定，走 06 景别）

**取景 = 该镜的景别**，由 **06 景别构图机位灯光**（`shotlang/01-景别.md`）按叙事需要决定：大远景 / 全景 / 全身 / 中景 / 中近景 / 近景 / 特写 / 大特写 / 插入镜。

**本模块不再自设「出图形态」档位。**原四档（默认全身图 / 三视图 / 半身图 / 局部特写图）**已退役**：

| 原档位 | 处置 |
|--------|------|
| 全身图 / 半身图 / 局部特写图 | **本就是景别**，改由 ⑥镜头景别承载（06 `shotlang/01`） |
| **三视图 / 多格设定稿** | **不是单帧图**（多格、多时刻），**不再产出** |

**渲染要求不变**：任何取景都逐字带通用渲染要求与全局负面词（见 `characters/06` §2）——**取景只改构图与取景范围，不改画风与质量基线**。

**人物单帧图与场景单帧图走同一条流程**，只是主体不同：人物单帧图取 ④ 人物外观状态，场景单帧图取 ③ 环境场景为主。

## 单帧图提示词（本模块的唯一产出）

**本模块走进全链路时的产出：单帧图。**单张、完整画面、带场景与光影，**标准格式 = `characters/19`**：

```
② 画幅 + ⑥ 景别（前置，先定画框）
→ ④ 人物外观状态（九层：身份/年龄/体型体态/皮肤质感/面部/发型/头饰/服装/辨识标记）
→ ⑤ 人物动作（可见动作 + 微表情 + 呼吸与身体微节拍）
→ ③ 环境场景 → ⑦ 光影色彩（六条）→ ⑥ 镜头运镜
→ ① 渲染规格 → ② 画幅画质 → 负面约束
```

**⚠️ 单帧图不带声音层。**单帧图只取 **①–⑦ 七要素 + 负面约束**；**⑧对白 / ⑨背景音 / ⑩BGM 属视频与交付文件层**，由 12 装配（见 12 `prompt/32-三模式标准交付模板.md`），**不进单帧图**。

**「单帧图」的判定**：**一张、一个时刻、一个完整画面**。
**不是**三视图，**不是**多格宫格，**不是**纯白设定稿——那些**已随「出图形态」退役，本模块不再产出**。

### 单帧图在链内的三个实例

| 实例 | 何时出 | 数量 |
|------|--------|------|
| **常规单帧图** | 链内任一需要画面定稿的节点 | 每镜 1 张 |
| **首帧图** | 该镜走**首帧 / 首尾帧**生视频 | 1 张 = 视频**第 1 帧** |
| **尾帧图** | 该镜走**首尾帧**生视频 | 1 张 = 视频**最后 1 帧** |

三个实例**共用同一套格式**（`characters/19` 十槽位）；首帧图与尾帧图**额外受三条硬性衔接条件约束**：

1. **两张图必须同一画幅比例** —— 比例不一致在视频提交阶段**直接失败**；**比例在出图阶段就定死**，视频阶段补救不了。做 9:16 竖屏成片，两张图就必须都是 9:16。
2. **两张图必须是同一连续动作的起止状态** —— 不是两个无关画面。起止状态不连续时，中段会漂移到"能同时接住两端"的折中画面。
3. **两张图的人物/场景锚定段逐字一致** —— 只有状态与姿态不同；外貌描述必须完全相同，否则两端人物对不上。

**拼装方式**：按槽位取各模块素材——④ 从 `characters/01/02` 七层设定卡与 `characters/15` 风格基准；⑤ 从 05 `performance/` 与 `characters/17` 微表情；③ 从 `scenes/` 六维；⑥ 从 06 `shotlang/` 与 08 `moves/09`；⑦ 从 06 `shotlang/04`；① 从 03 `SHOT_RENDER_PROFILE` 与 02（工单优先），② 从 12。**首帧图与尾帧图共用同一段人物/场景锚定段，只有动作与姿态不同**。

**分工**：本模块只出**图的提示词**（**不含声音层**）；**视频提示词与声音三轨由 12 装配**。规格依据与交付前自检见 12 `platform/03-即梦视频生成模式与提示词规格.md` §二。

## 人物线执行流程（供 ④ 人物外观状态）

1. **判风格通道** → `characters/12`（真人 / 超写实3D / 次世代 / Arnold / 国漫 / UE5 / Octane）
   ⚠️ **链内触发先读上游工单**：渲染引擎与写实度以 01 渲染引擎轴判定与 03 `SHOT_RENDER_PROFILE` 为准，通道选择服从工单——`characters/12` 只在工单未覆盖的维度补内容；链外单独出图（无工单）才由本模块自定。
   ⚠️ 目标平台若为 Seedance/即梦：不支持上传写实真人脸部素材，优先选次世代/国漫等风格化通道，或走文生视频不传参考图。
2. **建人物内在** → `characters/03` 四维（欲望/需求/缺陷/恐惧）+ 弧光 + 对手镜像
3. **填七层设定卡** → `characters/01` + `characters/02` 模板
   核心产出：**稳定锚定段（不可变，每次必带）** 与 **可变段（服装配色/表情/动作，按场换）** 分离
4. **取外形与原型**（可选）→ `characters/04` 原型 / `characters/05` 214 角色库 / `characters/08` 词汇
5. **取景** → 不由本模块定，走 **06 `shotlang/01-景别`** 的该镜景别
6. **选角色风格基准** → `characters/15`（⑤风格基准库）
   按题材查「基准选择速查」定 **A–AC** 之一（或注明混合，如 L+F、N+J、S+J）；取其「**转化后风格关键词块**」直接复用 + 「**负面词追加**」逐条带上。参考图来自非 3D 源时，按 §八 **风格转换铁律**转写（继承构图/服装/氛围/版式/造型，禁止继承渲染质感）。需要精确约束时追加 §二 的「主光左上45度 + 焦点人物双眼」，并按全局渲染修饰项声明肤质/肤色/色温。
7. **定画风族** → `characters/07` 画风族（版式一–八 属设定图体系，**已随出图形态退役，不再调用**）
8. **参考图反推**（若有图）→ `characters/13`
9. **拼装进单帧图** → 把本线产出填进 **`characters/19` 的 ④ 人物外观状态（九层）**；`characters/14` 的 character-baseline（收录基准卡）仍作为**锚定数据源**，其 prompt-output（设定图提示词）**已退役**
10. **过 12 转换**（必经，非可选）—— 锚定段中的技术词转成画面语言。
11. **交付**：人物锚定段供 05/06/07/10 复用；单帧图经 12 净化后方可交付。

## 硬规则速记

- **本模块只有一个入口：单帧图触发流程。**不再单独触发；产出永远是**单帧图**（单张、一个时刻、一个完整画面）。
- **单帧图只取 ①–⑦ + 负面约束，不带声音层**；⑧⑨⑩ 由 12 在视频/交付文件层装配。
- **不出三视图、不出多格设定稿**——多格多时刻，不属单帧图。
- **取景走 06 景别**（`shotlang/01`），本模块不自设出图形态档位。
- **稳定锚定段必须逐字带**，可变段才按场景换。
- 面部特写/情绪镜头的表情，从模块 05 的微表情/FACS 库选，**禁止自造**。
- **渲染锚定词三选一，同一次出图只带一套**（用户指定风格族 > 默认渲染要求 > 通道锚定段），三套都带会冲突。**角色风格基准（`characters/15` 的 A–AC）是另一层，与锚定词叠加使用**——基准管"这个角色什么气质质感"（自带「转化后风格关键词块」，直接复用），锚定词管"用什么渲染"。同层内不叠加，跨层必须叠。
- 场景六维**缺一不可**，且每维只选一个。
- 所有场景遵守**同一份世界观宪法**，不每集像不同平行宇宙。

## 边界裁定（避免与相邻模块打架）

实测确认三处语义邻近，按下述裁定执行：

**1. 本模块的提示词产出，一律要过 12 转换——无例外**
`characters/12` 与 `scenes/01` 的锚定词含 UE5 / Nanite / Lumen / Arnold / PBR / SSS / ACES 等技术词。它们是**图像模型的风格标签**，出定妆图与设定稿时有效，但**不是可交付的提示词**。
**本模块只有一个入口，产出只有一种（单帧图），但净化无例外**：无论触发来自全链路带起还是上游模块调用，本模块产出的提示词都必须经 **12 技术语言转换**净化后才能交付——技术词→画面语言、数值→程度词、物理词→观感词。
**本模块的产物是资产与锚定；可交付提示词的唯一出口是 12。**

**2. 场景取景视角 vs 06 机位角度**
`scenes/04` 讲"场景空间呈现用什么角度"（平视/仰视/俯视/鸟瞰/虫眼）；06 的 `shotlang/02` 讲"镜头语言与情绪"（仰拍=力量、俯视=脆弱）。概念相邻、命名不同。
**判据**：讲镜头语言与情绪 → 06；讲场景空间呈现 → 04。**重叠时以 06 为准**，06 是镜头语言的主责模块。

**3. 三条风格轴的边界（别混写）**

| 轴 | 文件 | 管什么 | 一句话 |
|---|------|--------|--------|
| **影调轴** | 02 `style/01`–`04` | 电影类型与影调配方（类型 11 + 平台风格 + 配方 + 寄存极点）、调色板、调色情绪、胶片模拟 | **02 定影调**（整片级，只声明一次） |
| **画风轴** | 04 `characters/07-风格族基准.md` | 美术画风族 9 种：真人写实国风 / UE5次世代CG / 半厚涂OC国漫 / 厚涂板绘唯美 / 胶片CCD油画 / 极繁暗黑华丽 / 赛博水墨梦核 / 银箔岩彩敦煌赛博 / 淡彩仙雾空灵 | **04 定画风**（怎么画） |
| **基准轴** | 04 `characters/15-风格基准库.md` | **29 条角色风格基准 A–AC**：给定角色原型（落魄者 / 职场精英 / 豪门千金 / 霸总 / 特工 / 女帝 / 仙侠神女 / 冰山圣女…）的完整质感基准 + 服装谱系 + 关键词块 + 转写要点 | **04 定基准**（画谁·什么气质质感） |

三轴**正交、可叠加**：先选**基准**（A–AC）→ 再配**画风族**（01–09）→ 再受 **02 的整片影调**约束。

**4. 风格基准轴 vs 02 影视风格 —— 为什么它不在 02**

`characters/15-风格基准库.md` 名字里带"风格"，但**不属于 02**：02 的职责是**整片级影调基线 + 全局风格前缀（只声明一次）**；本库是**逐角色的设定图基准**——每条基准都写"适用：某类角色"，并自带**角色设定图版式规范、设定卡字段、风格转换铁律**，全部是 04 的出图事务。**02 定全片调子，04 定单个角色出图长什么样。**

## 与其他模块的关系

- **02 影视风格** —— 提供全局风格前缀；本模块的人物风格族与场景风格通道与之对齐，不另立一套。

- **07 分镜头设计 / 10 剪辑与镜头组接验证** —— 消费本模块的锚定段与世界观约束，保证跨镜头一致。
- **12 技术语言转换** —— 本模块产出须经 12 净化（技术词→画面语言）后才成为最终提示词。
