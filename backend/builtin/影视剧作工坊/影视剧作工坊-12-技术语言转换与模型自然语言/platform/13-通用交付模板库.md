# 通用交付 · 模板库

## 〇、收录纪律

1. 原文逐字入卡（不改写）。
2. `chain.py check` 过一遍留档（FAIL 如实记，定性为"模板固有缺项"或"真缺陷"）。
3. **模板块 → ①–⑩ 字段映射**：把模板的分块语法对到通用母版 A 版字段上——这是模板并入通用交付的整合钩子。
4. **整合补齐清单**：该模板出片时必须补的项。

块→字段映射总表（三卡通用）：

| 模板块 | 母版字段 |
|--------|---------|
| 格式头（时长/镜头数/视角/强度） | 头部声明（时长写秒＋API/UI 口径）＋ ⑥ 镜头（视角） |
| 镜头：块 | ⑥ 镜头运镜构图 |
| 场景：块 | ③ 环境场景 |
| 动作/逐秒时间戳块 | ⑤ 人物动作（逐秒式展开见 12 `prompt/17` 逐秒精细化） |
| 粒子 / 环境互动块 | ③ 环境场景（动态子层）＋ ⑦ 光影色彩（特效子层） |
| 镜头反应块 | ⑥ 镜头运镜构图（运动子层） |
| 最终时刻块 | ⑥ 终止条件（具名结束帧） |
| 风格：块 | ① 渲染规格 ＋ ② 画幅画质 |
| 音效设计（可选）：块 | ⑧⑨⑩ 声音三轨（**仅视频层装配，母版生图不带**） |
| [切换] 标记 | 10 组接剪切点声明（跨镜模板，每段各自成镜） |

## TPL-001 夜间赛车·12 秒六段（时间戳快切式）

**收录日期**：2026-10-03　**口径**：时间戳逐段式＋镜头系统块　**机判**：483 字符，G 族 FAIL×4——**全部为模板固有缺项**（G4 头声明/G7 音轨/T1 画幅画质+声音层/T2 画幅）
**结构**：悬念开场段（驾驶员特写+紧张累积）→ **镜头系统块**（车内特写→过肩→外部跟拍→低角度地面，快速摇摄+变速转场+运动模糊遮罩剪辑=连续流动错觉）→ 六段时间戳（0-2/2-4/4-6/6-8/8-10/10-12，每段：镜头+微动作+声线索引）→ 环境段（湿沥青霓虹反射/街灯拖曳成线）→ 风格尾栈（《速度与激情》风格锚/照片级光照/无变形无拉伸）
**可迁移件**：①六段 2 秒节拍的**快切蒙太奇骨架**（张力累积→触发点（4-6s NOS 按钮）→爆发→追逐）；②「运动模糊遮罩剪辑，营造连续流动的错觉」转场语；③触发点特写写法（极近特写手指按 NOS）；④「无变形，无拉伸」负向收尾
**⚠️ 平台口径**：12s 超出 API 5s/10s 两档——走 **UI 4–15s** 口径，或按生成单元切两段（6s+6s）组接（10 组接方法论）
**整合补齐清单**：文件头【模式】+API/UI 声明；画幅字段；⑧⑨⑩ 三轨补齐（呼吸声/引擎声→⑨，BGM 按 09 配乐规则）；负面规避词段殿后

## TPL-002 FPV 能量球·8 秒（标签分块式·单镜爆发）

**收录日期**：2026-10-03　**口径**：标签分块式（镜头/场景/动作/粒子/环境互动/镜头反应/最终时刻/风格/音效）　**机判**：445 字符，G 族 FAIL×4——模板固有缺项同上
**结构**：格式头（**8秒/连续镜头/第一人称视角/高强度**）→ 镜头块（手持 FPV/自然抖动/动态曝光）→ 场景块（山谷/日光/微风）→ 动作块（脉动→猛冲→亮度暴增→能量泄漏）→ **时间锚**（在2秒标记处：等离子爆发/冲击波压弯草地）→ 粒子块（速度与衰减拟真）→ 环境互动块（草地压平/尘土/地面扭曲）→ **镜头反应块**（摄像师抬手入画遮挡冲击波）→ 最终时刻块（坍缩光核+残余轨迹）→ 风格块（物理合理/无慢动作/无风格化）→ 音效设计（可选）（低音冲击波/**无音乐**）
**可迁移件**：①**九分块标签语法**——比时间戳式更适合单镜事件叙事；②「在 N 秒标记处」事件锚写法；③**镜头反应块**（操作者手入画）——第一人称专属的临场感语法；④环境互动块（爆炸对场景的物理反馈）；⑤「音效设计（可选）」显式可选块＋「无音乐」抑制
**整合补齐清单**：同上四项；9:16/16:9 画幅按交付定
**与 02 风格库关系**：FPV 变速类，配方库「食谱 FPV」同族——挂卡时按 02 路由

## TPL-003 峡谷融钟·[切换] 双镜（极简叙事式）

**收录日期**：2026-10-03　**口径**：极简叙事＋[切换] 镜段分隔　**机判**：G 族 FAIL×5——模板固有缺项＋**真缺项：无负面规避词（G5）**，整合时必须补
**结构**：镜一（全景叙事：汽车驶过超现实峡谷＋**融钟超现实意象**＋**石像双眼悄然追随**——环境有意识的巨物语法）→ [切换] → 镜二（特写：飞转车轮紧抓路面）→ [切换]
**可迁移件**：①**[切换] 极简分镜语法**——两个词拍出两镜，跨镜模板的最小形态；②「巨大时钟如蜡般融化」超现实意象植入法；③「石像双眼悄然追随其移动」**环境注视语法**（巨物/神像类 brief 通用的压迫感来源，与巨物尺度三律同族）
**整合补齐清单**：两镜各自补全八要素（T1 缺六项）——本模板是**跨镜骨架**，每段 [切换] 之间是一镜，各自过 G 族后按 10 组接；时长/画幅/声音逐镜定
**平台口径**：[切换] 不是即梦/Seedance 原生语法——即梦侧按**分段提交**落地（每镜一条提示词，人工组接）
