# 导演风格控制器 V2

> **落位说明**（并入影视剧作工坊时添加，正文保留原文）
> 来源：director-production-agent · director-style-controller
> 原文文件名：`director-style-controller.txt`
> 链路归位：见第四批提取索引 `INDEX.md`（镜头→光影→物理→分镜连续→提示词→声音BGM→连续性）

## 目标

把“像某位导演”拆成可执行、可检查、可调整的镜头语言，而不是只叠一层颜色滤镜或罗列未经证实的器材名称。最终交付给 Seedance 2.0 的内容必须描述画面后果、动作时序和禁止项。

## 三层信息必须分开

1. `VERIFIED_FACT`：有 A/B 级来源支持的影片、段落或镜头事实。器材、镜头、焦段、画幅、帧率、快门等精确参数只能放在这一层。
2. `OBSERVED_PATTERN`：从多场戏稳定观察到的空间、景别、运动、光线、调度、剪辑和声音规律。不得伪装成幕后事实。
3. `GENERATION_TRANSLATION`：把前两层翻译成生成模型能看到的画面结果，例如“近距离超广角透视、边缘拉伸、背景纵深清晰”，而不是只写“9.6mm”。

`GENERATION_TRANSLATION` 内再区分“可见结果”和“AIGC 技术执行配方”。后者可以给出焦段等效区间、机位距离/高度、景深、帧率节奏、快门角度等效和承托方式，但每一项都必须标注“生成建议、非影片史实”，不得写回 `technical_facts`。

缺少可靠证据时写 `UNKNOWN`。禁止根据单张截图猜摄影机、镜头型号、精确焦段、帧率、快门角度或胶片型号。

## 路由流程

### 1. 确定影片分支

- 用户指定影片：只使用该影片分支。
- 用户只指定导演：使用档案中的 `default_lane`，同时明确写出作为参照的影片。
- 用户描述与默认分支明显冲突：选择最接近的已验证分支并说明选择理由。
- 档案没有对应导演或影片：先按 [evidence-policy.md](evidence-policy.md) 做定向检索；精确技术事实仍无来源时保持 `UNKNOWN`，但可以建立基于可观察结果的控制方案。
- 不得把同一导演不同时期、不同摄影指导或相反镜头策略揉成一个“平均风格”。

### 2. 读取控制栈

每个分支必须完整读取并应用：

- 空间语法与摄影机距离/高度
- 镜头行为与透视后果
- 景别序列
- 运动的触发条件、路径和停止位置
- 帧率/快门的可见运动后果
- 光线与曝光
- 演员调度和表演强度
- 美术、材质与色彩
- 剪辑与声音
- 5 个硬锁、10 个可调旋钮、冲突项
- 起始状态、动作触发、摄影机路径、环境响应、停止构图

### 3. 事实与 Prompt 分栏

如用户询问器材，先给“已验证技术事实”小节，注明影片范围与来源。最终 Seedance Prompt 不复制 `UNKNOWN`，也不依赖器材品牌名；它使用 `generation_translation` 中的可见结果。

### 4. 生成最终指令

使用：

```powershell
py -3.14 scripts/compile_style_prompt.py `
  --profiles data/verified-style-profiles.json `
  --director D018 `
  --lane yi-yi-urban-observation `
  --scene "台北公寓，一家人在晚餐后沉默相对" `
  --action "父亲放下碗筷，孩子转头看向窗外" `
  --duration "12秒" `
  --aspect "16:9"
```

最终 Prompt 的固定顺序：任务与参照影片 → 5 个硬锁 → 空间与透视 → 景别序列 → 运动触发/路径/停止 → 运动呈现 → 光线曝光 → 调度表演 → 美术色彩 → 剪辑声音 → 可调旋钮 → 五段时间蓝图 → Avoid。

## 用户上传场景图

场景图只用于分析现有空间、主体位置、光源、材质和颜色，不用于反推器材。保持原场景的主体身份、动作逻辑和建筑关系，再套入选定影片分支的镜头语言。若图像空间与分支硬锁冲突，应指出冲突并优先保证空间可读性。

## 混合导演

混合时先分别选定两个具体影片分支，再分配职责。例如 A 负责空间/运动/调度，B 负责光线/材质/色彩；不要把所有字段按百分比机械平均。主导演的 5 个硬锁至少保留 3 个，次导演最多替换 2 个；冲突时以用户指定的主比例为准并显式写出取舍。

## 输出自检

- 是否明确了导演与参照影片分支？
- 是否把事实、观察和生成翻译分开？
- 精确器材参数是否都有 A/B 级证据与范围？
- 是否恰好 5 个硬锁、10 个可调旋钮？
- 摄影机为何移动、怎么移动、在哪里停，是否都已说明？
- 是否包含完整五段时间蓝图？
- Prompt 是否没有 `UNKNOWN`、空洞形容词或互相冲突的镜头指令？
- 色彩是否落在服装、布景、光源与材质上，而不只是后期滤镜？
- 是否明确给出了焦段等效、机位距离/高度、景深、帧率、快门运动表现与摄影机承托方式，并标注为生成建议？
- 如果是项目级任务，是否通过 12 章完整生产包验收，而不是只交付色卡或一条 Prompt？
