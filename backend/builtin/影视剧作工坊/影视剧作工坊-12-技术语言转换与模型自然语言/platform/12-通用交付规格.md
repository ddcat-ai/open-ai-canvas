# 通用交付 · 输出通道规格

## 〇、什么时候走通用通道

**判据**（命中任一即走本通道）：

| 情形 | 理由 |
|------|------|
| 用户没说交付到哪个平台 | 平台未定，先出母版，平台定了再派生 |
| 一份内容要投**多个平台**（MJ + 即梦 + 豆包…） | 母版一份，各平台各派生一版，改派生不改母版 |
| 交付物要**归档/进库/跨项目复用** | 平台专有语法（比例参数、手签、润色注记）会污染资产 |
| 用户只要"提示词"本身，不提任何平台 | 默认通用交付 |

**反之**：明确说了即梦 → 走 `platform/10`；明确说了视频三模式 → 走 `platform/03`。

## 一、母版纪律（本通道核心）

**母版只存一份，派生不回写。**

1. **A 版（母版真源）**：**①–⑩ 字段化**（渲染规格/画幅画质/环境场景/人物外观状态/人物动作/镜头运镜构图/光影色彩/声音三轨 + 负面约束），按 `prompt/32` 形态 A。生图交付只取 ①–⑦ + 负面（单帧图不带声音层，同 04 `characters/19`）。
2. **平台专有语法禁入母版**：比例参数（9:16/--ar）、图内文字与手签指令、智能润色开关注记、@素材引用、块状脚手架的 CUT 行——这些是**平台侧实现**，派生时才加。
3. **具象词逐字锁**：锚定段（人物九层/场景锚定）在母版中逐字定型；派生版本只做形态转换，**不改词**（措辞漂移即观感漂移）。
4. 母版文件头标注：`【通用交付母版】`＋收录日期；派生版标注来源母版与目标平台。

## 二、派生出口（B / C）

| 派生 | 目标 | 形态 | 转换规则 |
|------|------|------|---------|
| **B 版 · 词组串** | MJ / SD / Flux 等国际图模 | 五层词组串（①风格→②人物→③服装道具→④表情姿态→⑤光影环境）+ **独立负面词段** + **英文版** | 中文具象词直译；抽象词按 04 铁律具象化后译；比例走 `--ar`（此处**允许**，B 版专属） |
| **C 口径 · 即梦整段版** | 即梦 / 豆包 / 可灵等国产 | 中文自然语言整段连缀，锚定段逐字段首，负面三法融入 | 按 `platform/09` §三与 `platform/10` §五；比例界面选、关智能润色 |
| **视频派生** | 即梦视频 / Seedance | 按三模式拼装顺序（12 SKILL.md §按模式的拼装顺序） | 声音三轨仅在视频层装配 |

**转换方向永远单向：母版 → 派生**。派生版上跑出来的修订（即梦出图翻车后的改词），先改母版对应字段，再重新派生——不直接改派生版。

## 三、机判口径

| 交付物 | 命令 | 说明 |
|--------|------|------|
| 母版（视频向） | `chain.py check <文件> --mode t2v`（`--platform` 省略） | G/T/F/L 族按通用口径判 |
| 母版（生图向） | `chain.py jimeng <文件> --style prose` | 只看 J1/J3/J5 等平台无关项；J2 比例参数母版本就不该有，J8 锚定段用 `--anchor` 判 |
| B 版词组串 | 机判不覆盖（MJ 生态），按 04 `references/01` 通用图模轨人工自检 | 如实标注：无机判 |
| C 口径即梦版 | `chain.py jimeng <文件>`（auto） | 全 J 族按 platform/10 |

| 文件 | 关系 |
