# 即梦生图 · 提示词规格（文生图轨）

## 〇、本文件管什么

目标平台是**即梦图片生成（Seedream 图像模型）**时的提示词规格。触发判据：用户要的是**一张图**（角色镜单帧图 / 设定图 / 立绘 / 海报 / 概念图 / 首尾帧原料图），不是一段视频。

| 轨 | 归属 | 管什么 |
|----|------|--------|
| 即梦**视频**三模式（文生视频/首帧/首尾帧） | `platform/03` | 模式路由、图片/时长/画幅硬约束 |
| 即梦**生图**（本件） | `platform/10` | 图的提示词**写法口径**与机判 |
| 即梦交付**形态**（整段连缀/锚定段段首/负面三法） | `platform/09` | 两轨共用的形态纪律 |

## 一、两种出词口径（核心）

即梦生图实战中并存两种写法，**都能出好图，但用途不同**：

| | **工坊整段版**（默认） | **堆叠式炫技版**（社区标准） |
|---|---|---|
| 形态 | 中文自然语言整段连缀（通顺段落） | 逗号词组串（几十段短词堆叠） |
| 锚定段 | 逐字放段首（跨图一致性锚） | 无锚定概念（每张独立抽卡） |
| 景别 | 单一景别（影视镜纪律） | 允许 ≤3 段景别堆叠（多视角暗示，赌平台调和出张力） |
| 抽象词 | 禁（④九层全具象铁律） | 社区惯例可保留（信息量靠具象词承担） |
| 质量乞讨词 | **禁**（adaptation §1.5） | 可保留（无害但无信息量，建议以具体风格词替代） |
| 引擎词（虚幻引擎渲染等） | 交付口径须转画面词 | 可保留（风格联想词，adaptation §1.6 同「器材型号词」） |
| 随机声明（随机动作/随机背景） | 禁（弃锚定即弃一致性） | 可用（显式声明放弃锚定，单张炫技） |
| 适用 | **进链路的图**：角色镜、首尾帧原料、设定图、任何要复刻/一致性的图 | **单张炫技**：立绘、海报、概念图、氛围冲击图 |
| 上游格式 | 04 `characters/19` 十槽位（①–⑦ + 负面） | 无（直接堆叠，本件 §二 八段语法） |

**选口判据**：这张图以后要不要**复刻**（同一角色第二张、跨镜头一致性、进视频链）？要 → 整段版；只出这一张、要冲击力 → 堆叠式。**用户直接给来一条堆叠式提示词时按堆叠式收**，需要转整段版时按 §五 换算。

## 二、堆叠式八段解剖（幻装斗神标本）

社区堆叠词不是乱堆——有效标本都收敛在八段里。标本：用户 2026-09-03 即梦实际出图《幻装斗神》（474 字（去空白口径）/ 83 词段，出图成功，见 `路由 scripts/examples/jimeng_斗神堆叠版.txt`）：

```
① 主体核     世界上最帅气最精美的幻装斗神
② 形体量感   庞大，厚重，强壮，万夫莫敌，对称，尖锐有锋利棱角
③ 配色材质   黑红蓝色，金属光泽，赛博朋克风格
④ 装备特效   墨痕绘画成的完美披风，夸张的武器装备，生物机甲，蓝色光芒
⑤ 纹样细节   极繁主义细节，极复杂唯美的刻纹，花纹拥有独特的立体感，
             展现其外部复杂精细的各种构造，雕塑风格
⑥ 环境       星空感，随机背景，站在地面上细腻高光
⑦ 镜头构图   侧面特写，全景/全身镜头，远景/广角镜头，低角度仰拍，
             超广角强透视构图
⑧ 氛围质量词 光影交织/明暗对比强烈/电影级构图 + 8K/超清/大师杰作/完美品质/
             宿命感拉满/弥散粒子（乞讨词与氛围词混载区）
```

**出图信息量的承担者**：③④⑤⑦ 的具象词。⑧ 里的乞讨词（大师杰作/完美品质/高质量）**不增益画面**——这张图成了，靠的不是它们；删掉 ⑧ 的一半信息量不变，字数省 150+。氛围词（宿命感/弥散粒子/光影交织）在堆叠式里仍有效，因为即梦把它们当**风格语义**而非质量请求处理。

**工坊等价转换示例**（同一目标改写整段版时）：②「威武霸气」→「肩宽近三头身体量、下颌抬 15°、站姿占满竖版画幅」；⑤「极繁刻纹」→「甲片边缘密布回纹浮雕，纹路随曲面起伏产生立体光影」；⑦ 多景别堆叠 → 删到「低角度仰拍全身」单一主景别。

## 三、标本机判裁定（`chain.py jimeng` 实测）

| 判据 | 结果 | 裁定 |
|------|------|------|
| J1 长度 474 字 | ✓ PASS | ≤800 字硬顶内 |
| J2 词内比例参数 | ✓ PASS | 无（画幅靠构图词暗示） |
| J3 负面词独立段 | ✓ PASS | 无（堆叠式天然不设负面段） |
| J5 乞讨词 | ⚠ WARN | 堆叠式档保留合法；工坊档必须剔除 |
| J6 引擎名「虚幻引擎渲染」 | ⚠ WARN | 风格联想词保留无害；工程交付口径须转画面词 |
| J7 抽象词 | · INFO | 堆叠式社区惯例 |
| J9 景别堆叠 | · INFO | 特写×全身×远景共现，堆叠式允许 ≤3 段；整段版禁 |
| J10 重复词段 | ⚠ WARN | 超清×3、阴影过渡自然×2、视觉冲击×2、高级感×2——删并不损耗 |
| J11 随机声明 | · INFO | 随机动作/随机背景/自由视角=显式弃锚定，单张成立 |

**结论**：堆叠式口径下该标本**可收录、可复现**；转整段版时 J5/J7/J9/J10/J11 全部要清。

## 四、硬约束（两口径通用）

- **≤800 字**（沿用 `platform/03` §3.4 硬顶；生图提示词建议 ≤400 字，超出部分多为乞讨词与重复段）。
- **禁词内比例参数**（9:16、--ar、16:9）——比例在**界面选**；词里写「竖版构图」「横版宽幅」。器材型号词可保留（风格联想，无害）。
- **负面词不单独成段**——即梦无独立负面框，按三法处理（真源 `platform/09` §三：正向融合 / 句内否定 ≤2 / 转自查清单）。
- **一致性出图必须关智能润色**——锚定段逐字不被平台改写是硬前提。
- 参考图 ≤4 张、每张用途写明；写实真人脸不走参考图（平台拦截，adaptation §5）。

## 五、整段版出词顺序（从 04 十槽位换算）

单帧图静帧无声音层，取 ①–⑦ + 负面约束；换成整段连缀后顺序：

```
段首（逐字）：① 风格锚定段（词组串原样，不整段化）
正文（连缀）：④ 人物九层 → ⑤ 动作微表情 → ③ 环境 → ⑦ 光影六条
              → ⑥ 景别+机位（静帧无运镜、无终止条件）
收尾：        ① 渲染规格 → ② 画幅画质词 → （三法融负）
```

完整范例见 `路由 scripts/examples/jimeng_皇贵妃整段版.txt`（与 04 `characters/19` 范例 A 同源，改为生图口径）。**锚定段跨图一字不改**——措辞漂移即观感漂移。

## 六、机判（判据族 J）

```
python chain.py jimeng <提示词文件> [--style auto|prose|stack] [--anchor 锚定段] [--json]
```

| 码 | 判什么 | 整段版 | 堆叠式 |
|----|--------|--------|--------|
| J1 | 长度 >800 字 | FAIL | FAIL |
| J2 | 词内比例参数 | FAIL | FAIL |
| J3 | 负面词单独成段 | FAIL | FAIL |
| J4 | 句内否定 >2 | WARN | WARN |
| J5 | 质量乞讨词 | **FAIL** | WARN |
| J6 | 引擎名残留 | WARN | WARN |
| J7 | 抽象形容词 | WARN | INFO |
| J8 | 锚定段未逐字放段首（--anchor 给出时） | FAIL | FAIL |
| J9 | 景别冲突/堆叠 | WARN | INFO（≤3 段） |
| J10 | 重复词段 | WARN | WARN |
| J11 | 随机声明 | WARN | INFO |

`--style auto` 按「段数 ≥25 且段均长 ≤6 字 → 堆叠式」自判；J 族退出码与其余机判一致（0 过 / 2 有 FAIL）。J 族独立于 13 的 G/T/F/L 视频族——**13 不持有生图判据**，生图合规在本模块机判完成。
