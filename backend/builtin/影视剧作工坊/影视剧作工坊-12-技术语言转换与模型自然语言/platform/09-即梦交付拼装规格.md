# 即梦交付拼装规格

## 〇、为什么即梦要单独一套

**同一份内容，交到不同平台是不同形态。** 即梦（Seedream）没有独立负面词输入框，且只吃中文自然语言整段连缀。

| 项 | 块状脚手架（豆包 / Seedance） | **即梦整段版** |
|---|---|---|
| 结构 | 分行块（Characters / Scene / CUT 行） | **中文自然语言整段连缀**（五层词料连成通顺段落） |
| 锚定段 | 混在 Characters 行 | **风格锚定段逐字放段首** |
| 负面词 | 「避免：…」可单独成段 | ❌ **不单独成段**——按**三法**融入正文 |
| 具象词 | 逐字保留 | **照样逐字保留**（连缀不等于概述） |
| 长度 | 1800 字符（块状脚手架「结构取代字数上限」） | **≤800 字**（平台硬顶） |
| 比例参数 | 允许技术后缀块 | **禁词内比例参数**（画幅走 ② 或提交参数） |
| 智能润色 | — | **一致性出图必须关智能润色** |

> 出处：`04/references/01-组织纪律与引用清单.md` §平台分轨（即梦 / Seedream 图像轨）；`04/characters/16-人物资产补齐.md` §即梦整段版。

## 一、中文自然语言整段连缀

把五层词料（渲染规格 / 画幅画质 / 环境场景 / 人物外观状态 + 人物动作 / 镜头与光影）连成**通顺段落**，不是词组串，也不是分行块。

- **具象词逐字保留**——「皮肤白皙通透有血色、可见细腻毛孔」这类词照抄进段落，不许概括成「皮肤好」。
- **风格锚定段逐字放段首**，之后才是人物、场景、动作、镜头。
- 禁**质量乞讨词**（「大师作品」「最佳质量」「4k 杰作」这类无信息量的堆砌）。

## 二、锚定段逐字放段首

角色的**稳定锚定段**（身份/年龄/体型体态/皮肤质感/面部/发型/头饰/服装/辨识标记）逐字置于段首，跨镜头、跨条**一字不改**——措辞漂移即观感漂移。

## 三、负面词三法（**不单独成段**）

**出处**：`AI_ART_FUSION/ai-film-art-v5.2-source/references/jimeng-seedream-adaptation.md` §3
**本节自 13 `review/15-负面词全量（导演plus5.0）` §四 迁入，为规则归属地。**

即梦没有独立负面词输入框，负面词按以下三法处理，**不单独成段**：

| 方法 | 用法 | 示例 |
|------|------|------|
| **正向融合（首选）** | 把禁止项翻成对应的正向描述，融进段落 | 负面「塑料皮肤」 → 「皮肤通透有血色、可见毛孔」；负面「卡通Q版」 → 锚定段已含「非大眼Q版，非2D动画」，保留即可 |
| **句内否定（少量用）** | 段尾加「不要/无/非」短句 | 「画面干净，无文字无水印，不要多余肢体」 |
| **转自查清单（兜底）** | 融不进词的项列进交付备注，出图后人工核对 | 「多手指/畸形——出图后检查」 |

**配套规则**：
- 通道专属负面项优先**正向融合**：把「禁 X」写成「要非 X 的正确特征」。
- 一条提示词里**句内否定 ≤ 2 处**，多了互相打架。
- 即梦规范（`jimeng-prompt-spec.md`）：**用户需要时才**单独输出 `负面提示词：……`。

## 四、长度与禁项

- **≤ 800 字硬上限**（`platform/03` §3.4）。越过 800 字**连提交都不成立**，所以即梦档的均切长与每条承载的镜头数都要按此倒推。
- **禁词内比例参数**（16:9 之类比例走 ② 或提交参数，不混进描述句）。
- **一致性出图必须关智能润色**。

## 五、与「拼装顺序」的关系

本文件管**形态**（怎么写成一段、负面怎么融）；**顺序**（T2V 九层 / 首帧六层 / 首尾帧五层）见模块 12 `SKILL.md` §「按模式的拼装顺序」。

两者是同一件事的两面：**顺序定"先说什么后说什么"，本文件定"说成什么样"。**
