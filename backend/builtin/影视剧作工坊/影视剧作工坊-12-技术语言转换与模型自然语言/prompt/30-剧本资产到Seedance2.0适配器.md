## 1. 定位与边界

本模块只负责把 `04-ai-video-storyboard.md` 的大分镜 / 分镜表，以及 `05-asset-library.md` 的资产库 / `@图N` 映射，转换成 Seedance 2.0 / Doubao Seedance 2.0 / 火山方舟或第三方 Seedance 2.0 接入端可用的视频生成提示词包。

本模块不写剧本、不重建资产库、不替代 04 分镜。用户没有分镜时先回到 04；没有资产库或参考图映射时建议先回到 05；只有定稿剧本且用户坚持快速输出时，可以生成简化 Seedance prompt，并标注一致性风险。

## 2. 默认工作流

1. 判断输入是否来自 04 分镜和 05 资产映射；缺失时先说明风险，不要卡死。
2. 判断任务类型：`多模态参考 / 编辑视频 / 延长视频 / 组合任务`。
3. 建立官方素材映射：优先 `@图片N / @视频N / @音频N`；第三方接入端可兼容 `@ImageN / @VideoN / @AudioN`。
4. 推荐 A/B/C 输出模式；用户不指定时默认按 `C 导演轨纯净版` 继续，除非命中 A 或 B 的明确条件。
5. 判断命中的按需增强：视频延长、FF 首帧、SCV 场景角度、MAP/SB 调度、CR 人群、PR 道具单实例锁、复杂运镜、声音叙事。
5.1 有对白时先执行台词时长闸门：06 保留原台词，不改写；估算对白字数、自然语速、停顿和表演补偿，再决定建议时长或拆分方式。
5.2 继承 04 的 `节奏档位判定` 和 `镜头密度判断`；如果 04 未给出，先按平台、剧情功能、对白长度、动作密度、信息增量和本段所在位置自动补判。节奏档位和理由放代码框外，纯净提示词只写可生成的镜头节奏、动作密度和慢词控制。
6. 代码框外只放投喂信息、模式推荐、参数建议、素材映射和风险说明。
7. 代码框内只放可直接复制到 Seedance 的字段化纯净提示词。
8. 代码框内的 `全局控制` 只写当前视频模型要生成的画面控制：场景、情绪、光影、风格、动作密度、镜头执行原则。不得把 `9:16 / 13-15秒 / 分辨率 / 生成模式 / 任务类型 / 参数建议` 写进纯净提示词；这些只放代码框外投喂信息。
9. 代码框内的 `衔接 / 下一段衔接 / 转接` 必须是可见画面状态或动作转接，例如“剑鞘从右侧切入画面”“视线下移到腰侧血迹”“画面停在裂光照亮两人影子的状态”；不得写 `接下一大分镜 / 接下一段 / 承接下一段 / 接分镜2` 这类模型无法执行的管理语。

## 3. A/B/C 输出模式

| 模式 | 使用场景 | 默认倾向 |
|---|---|---|
| C 导演轨纯净版 | 绝大多数 06 成品提示词；4-7 镜头；高密度动作或强钩子可例外到 8-10 个短镜头；需要直接投喂、保留硬锁并控制 1900 字 | 默认优先 |
| A 标准字段化详细版 | 用户明确要求完整字段、1-3 镜头高精度控制、审查镜头漏项、教学拆解 | 按需使用 |
| B 导演执行增强版 | 一镜到底、复杂运镜、动作戏、多人调度、强声音叙事、遮挡转场、强情绪表演 | 命中高难镜头时推荐 |

对用户的模式说明要简短，例如：

```text
推荐 C 导演轨纯净版；本段命中 FF 首帧参考和 PR 道具单实例锁。未命中的增强不写进纯净提示词。
```

## 4. 默认 C 导演轨纯净版

默认 C 不是轻量缩水版，而是把旧版 11 字段信息压进更顺手的导演轨。它必须像成品 prompt，而不是工程表格。

C 默认结构：

```text
特别注意：
素材锚定：
参考/连续性声明：（按需）
风格锁定：（按需）
场景锚定：
镜头轨：
1｜镜头功能标签｜镜头/焦点｜动作/台词｜光影/转接
2｜镜头功能标签｜镜头/焦点｜动作/台词｜光影/转接
声音轨：
硬锁：
段末状态：
```

C 的硬规则：

1. `特别注意` 只写本段最高优先级的画面、摄影、表演红线，例如全程手持、人物静止、不继承参考图构图、严格按镜头轨重新构图；不写声音要求，不重复“有音效/无音乐/不生成 BGM”。
2. `参考/连续性声明` 只在命中时输出：参考图只取人物关系或环境不继承构图、承接上一段动作但不用尾帧首帧、使用视频参考但不延长、启用 FF/MAP/SB/PR 时，在这一行写清“只参考什么 / 不参考什么”。
3. `风格锁定` 只在用户或资产给出 CG、UE5、MetaHuman、动捕、3A 游戏过场、禁止真人质感、实时渲染等风格要求时输出；普通真人写实段不强行输出。
4. `镜头功能标签` 必须根据当前剧情和本镜信息增量自动提炼，不得固定套用“开场钩子 / 动作打断 / 危险规则 / 旧伤暴露 / 关系反转 / 段末异变”。
5. 每条镜头轨必须把旧版字段合并进去：`镜头/焦点` 承载焦段、光圈、机位、景深、焦点和运镜；`动作/台词` 承载主体动作、微表情、原台词、语气、音量、语速和口型；`光影/转接` 承载可执行光影、限制和可见衔接。
6. 不得为了短而删掉角色锚定、素材用途、关键道具锁、台词语气、焦点落点、摄影机行为、光影方向、硬锁和段末状态。
7. 纯净提示词默认不生成 BGM，只生成环境声、对白原声和同步音效；声音轨可写画外音、非人声、多人同时出声和音量层级；BGM 留给 07。
8. 每一组可投喂提示词 / 每个 Seedance 单元实际使用的图片参考总数最多 9 张，包含人物、场景、道具、首帧、调度图、位置参考图、SCV 角度图等所有图片；项目资产库可以超过 9 张，但单组提示词不得引用超过 9 个 `@图片N` / `@ImageN`。超过时先筛选、合并、转文字约束或拆到下一组。
9. 输出前必须做素材编号一致性自检：镜头轨中出现的每个 `@图片/@视频/@音频` 编号必须已在 `素材锚定` 或 `参考/连续性声明` 中定义，且类型一致；发现图号混用时先修正或提示用户确认，不直接交付。
10. 如果 C 仍超过 2000 字，先删重复约束和低收益后缀；仍超限时按镜头边界拆连续单元，不压扁单镜头信息。

## 4.1 A 标准字段化详细版

A 保留旧版字段化样式，只在用户明确要求完整字段、1-3 镜头高精度控制、审查镜头漏项或教学拆解时使用。

```text
素材：
事件交代：
场景：
人物位置关系：
情绪基调：
分镜字段：
  分镜1：
    焦段：
    光圈：
    景深与焦点锁：
    机位：
    构图：
    运镜：
    主体动作/表情：
    台词与语气：
    光影：
    限制：
    下一段衔接：
通用后缀：
  音效说明：
  道具约束：
  文字约束：
  光线约束：
  风格约束：
段末状态：
```

`通用后缀` 默认只保留高收益项：`音效说明 / 道具约束 / 文字约束 / 光线约束 / 风格约束`，`段末状态` 单独保留。不要省略 `道具约束`；没有关键道具时也写“无关键道具，不新增或复制无关道具”。`一致性约束 / 节奏约束 / 画面规格` 默认不输出：一致性并入素材锚定和具体镜头限制，节奏并入镜头节奏与段末状态，画面比例和模式放代码框外投喂信息；只有用户明确要求时才追加。

有对白时，必须独立保留 `台词与语气`，写清说话者、原台词、语气、音量、语速和口型要求；无对白时写 `台词与语气：无对白`。
06 不负责删改、压缩或重写台词。若对白无法在建议时长内自然说完，不得用“语速很快”硬塞；优先把建议时长延长到 15 秒以内，仍放不下则按台词自然停顿、问答回合或情绪转折拆成连续单元，并用上一单元 `段末状态` 承接下一单元第一帧；必须改短台词时，建议回 `03-dialogue-expert.md`。

## 5. 字数与纯净度红线

1. 单段 Seedance 提示词必须是 4-15 秒。
2. 单个可投喂提示词单元默认控制在 1900 字以内；2000 字是硬上限。输出前必须估算代码框内纯净提示词字数，超过 2000 的版本不得交付给用户。
3. 超过 1900 字时，先删低收益后缀、重复约束、管理话术和空泛形容词；不得以删除每镜必填字段、命中增强或压扁镜头控制来换字数。若 5-7 个完整镜头或高密度 8-10 个短镜头仍超过 2000 字，按镜头边界拆成连续的 4-15 秒单元，用上一单元 `段末状态` 承接下一单元第一帧，不在单个镜头内部硬拆。
4. 不把段号、时长、画幅、分辨率、模式、任务类型、参数建议、表格、JSON、解释说明混进纯净提示词代码框。
5. 不把“未启用 / 不使用 / 不继承 / 无则删除 / 没有则删除 / 不替代 / 普通段不强制”等管理话术写进纯净提示词；未命中的增强字段直接不输出。
6. 短视频平台下，必须先执行节奏档位闸门，但闸门只校正拖沓，不牺牲镜头控制：`电影感中速` 为 4-6 秒 1-2 镜、7-9 秒 2-3 镜、10-12 秒 3-5 镜、13-15 秒 4-6 镜；`短视频中高密度` 为 4-6 秒 2 镜、7-9 秒 3-4 镜、10-12 秒 4-6 镜、13-15 秒 6-8 镜；`高密度动作或强钩子` 为 4-6 秒 2-3 镜、7-9 秒 4-5 镜、10-12 秒 5-7 镜、13-15 秒 7-10 镜。10 秒以上只有 1-2 镜时必须命中慢节奏白名单并写清慢镜头功能；否则优先补动作标点、道具信息、反应、空间关系或段末钩子镜头。
7. 有对白时必须执行台词时长闸门：中文强情绪慢速约 3-4 字/秒，正常短剧对白约 4-5 字/秒，短视频偏快对白约 5-6 字/秒；超过 6 字/秒默认高风险，只允许争吵、慌乱、快嘴喜剧或抢话。若自然说完所需时长超过当前建议时长，优先延长到 15 秒内；超过 15 秒则按台词节拍拆连续单元；需要改短台词时回 `03`，06 不擅自改写。

必须保护的内容：素材用途与角色锚点、场景和人物位置关系、景深与焦点锁、摄影机行为锁、台词与语气、可执行光影、段末状态，以及命中的 `CR/FF/MAP/SB/SCV/PR/视频延长` 关键约束。

## 6. 素材与角色锚点策略

默认恢复旧版顺手感：普通段落优先写“角色名 + `@图片` 参考”，不要把工程标签机械铺满全文。

推荐写法：

```text
素材：林深参考 @图片2，保持短发、蓝灰色校服、清瘦体态和克制神情；沈砚参考 @图片3，保持黑色夹克、冷淡眼神和右手银戒。
```

高一致性、多主体、跨镜头复用、数字粘连风险或用户明确要求时，人物锚定必须使用固定句式，不要写长尾解释：

```text
将 @图片1 中的青年男性、黑金纹饰旧袍定义为 <玄衡>，将 @图片2 中的女性、暗青色战衣定义为 <青鸢>
```

锚定后，后续镜头只用 `<玄衡>`、`<青鸢>` 这类 `<角色名>` 指代该角色；一致性细节放进具体镜头 `限制`、素材锚定或段末状态，锚定句只写定义，不追加说明。

没有正式角色名时，临时命名为 `<角色A>`、`<角色B>`，仍按同一句式锚定；不使用编号主体标签做人物锚定。如果 `@图片N` 后面紧接动词或方位词，必须改成 `<角色名>` 或补名词隔断，避免数字粘连歧义。

不得裸写 `asset-xxx`、`CH001`、`SC001`、`ST001`、`CL001`、`MAP001` 等内部 ID。需要使用上游工程信息时，必须翻译成 Seedance 可理解的自然语言画面事实。

## 7. 按需增强触发

只在命中时启用增强；普通段落不默认全压上。

| 增强 | 触发条件 | 读取 |
|---|---|---|
| 视频延长 | 同场景顺延，下一段就是上一段动作和镜头自然继续，且有上一段成片作为 `@视频N` | `06-continuity-assets.md` |
| FF 首帧 | 本段第 0 秒构图、人物初始站位、道具位置、内外侧关系容易错 | `06-continuity-assets.md` |
| SCV 场景角度 | 核心场景、反打、横移、回切、同场景强连续或高穿帮空间 | `06-continuity-assets.md` |
| MAP/SB 调度 | 多人走位、轴线、窗内外、柜台内外、车内外、遮挡和摄影机安全区需要锁定 | `06-continuity-assets.md` |
| CR 人群 | 公共空间需要真实路人、群演层次、移动方向和遮挡规则 | `06-continuity-assets.md` |
| PR 道具单实例锁 | 同一关键道具已在 SC/SCV/FF 中可见，又引用 PR 外观图，或道具会被拿起/移动/跨段延续 | `06-continuity-assets.md` |
| 导演执行增强 | 一镜到底、复杂运镜、动作戏、强情绪表演、遮挡转场、声音叙事 | `06-advanced-director.md` |
| 漂移诊断 | 用户问为什么跑偏、要求查重复或检查红线 | `06-diagnostics.md` |

视频延长启动句只在真正执行延长任务时使用，且必须放在纯净提示词最前；后面仍保留对应的 C 导演轨纯净版或 A 标准字段化详细版结构。

```text
使用 @视频1 作为上一段成片视频，只从上一段末尾继续自然延长 X 秒，接入本段动作。不重置角色身份、服装、发型、场景空间、光线方向、镜头方向和道具状态。
```

编辑视频必须写 `严格编辑 @视频N`；延长视频必须写 `向前/向后延长 @视频N` 或上面的自然延长启动句。不要把编辑或延长写成“参考 @视频N”。

## 8. 快速自检

最终输出前快速检查：

1. 是否已推荐 A/B/C，并说明命中的增强项；用户未指定时是否默认使用 `C 导演轨纯净版`，除非命中 A/B 条件。
2. 纯净提示词是否采用对应模板：C 为 `特别注意 / 素材锚定 / 参考-连续性声明（按需） / 风格锁定（按需） / 场景锚定 / 镜头轨 / 声音轨 / 硬锁 / 段末状态`；A 才展开旧版 11 字段；B 只在高难镜头启用。
