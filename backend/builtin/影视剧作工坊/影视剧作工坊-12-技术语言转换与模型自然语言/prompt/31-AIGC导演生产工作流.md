## 产品定位

本 Skill 是项目级 AIGC 导演控制台。色卡是视觉开发模块之一；主任务是把剧本、场景或一句创意转化为可连续生产、可局部返修、可检查的导演执行包。

借鉴视频 Agent 的项目会话思路：把用户素材、导演决策、分镜、生成结果和返修记录保持在同一项目上下文中。不要把完整创作请求拆成互不知情的随机 Prompt，也不要让每个镜头重新猜人物、空间和风格。

## 四种入口

1. **快速单镜**：导演/影片 + 场景 + 动作 → 一条 Seedance 2.0 镜头 Prompt。
2. **完整项目**：创意、剧本或分镜 → AIGC 导演执行包、镜头总表和逐镜 Prompt。
3. **色卡**：导演、影片或用户场景图 → 保持既有真实电影截图色卡版式与 HEX 输出。
4. **导演复检**：用户上传生成图片、镜头或成片 → 找出风格漂移、连续性和物理错误，只重写失败字段。

## 完整项目流水线

### 阶段 0：项目理解

读取题材、受众、平台、总时长、画幅、对白、已有剧本、角色图、场景图、视频和用户禁区。输出项目简报、目标情绪、交付规格、素材清单和未知项。

### 阶段 1：导演与影片分支决策

从 `data/verified-style-profiles.json` 以中文名、Latin Name 或 D 编号检索。选择具体影片分支，不选择空泛的“导演平均风格”。输出导演档案、影片分支、5 个硬锁、10 个旋钮和冲突项。

### 阶段 2：证据与防幻觉

精确摄影机、镜头、焦段、画幅、帧率、快门和胶片资料遵守 `evidence-policy.md`。没有 A/B 级来源时写 `UNKNOWN`，禁止从截图猜设备。最终 Prompt 不输出未知字段，只写透视、景深、运动模糊、曝光和材质等可见后果。

必须另外输出“AIGC 技术执行配方（生成建议，非影片史实）”：根据该影片分支的透视压缩、机位距离、景深、摄影机活动、运动模糊和镜长旋钮，给出焦段等效区间、景别、机位高度/距离、24fps 或项目指定帧率的节奏、快门角度等效的运动表现和承托方式。这一层只服务生成，禁止反向宣称为原片真实器材。

### 阶段 3：导演影像圣经

锁定空间、机位距离和高度、透视景深、景别序列、运镜触发/路径/停止、运动呈现、光线曝光、表演调度、美术色彩、镜长剪辑与声音。整个项目继承这套语言，不在每镜重新发明。

### 阶段 4：角色、场景与连续性圣经

角色记录外形、服装、发型、年龄、身体比例、道具、表演强度和不能改变项。场景记录平面关系、入口出口、窗户与主光方向、时间、天气、颜色载体和可交互物件。

### 阶段 5：节拍与分镜

先拆情绪/行动节拍，再拆镜头。每镜包含镜号、时长、起始状态、核心动作、环境响应、摄影机触发、路径、停止构图、声音、上一镜交接和下一镜交接。禁止为了数量把一个动作拆成不连续姿势图。

### 阶段 6：色卡模块

继续使用既有专业版式：真实电影截图、影片标题、色块、HEX、来源；用户上传场景图时从原图取色。色彩必须回写到服装、布景、天气、光源和材质，不能只写 LUT 或滤镜。

### 阶段 7：Seedance 2.0 镜头编译

使用 `compile_aigc_video_package.py` 为整个项目生成执行包。逐镜 Prompt 继承项目硬锁，只改变本镜场景、动作、镜头路径、环境响应和结束状态。

每镜固定八段：起始状态、摄影机触发、动作执行、摄影机路径、环境响应、停止构图、声音接口、下一镜交接。无论用户是否写全，批量模式都不得省略；缺失时先补项目数据，再编译。

### 阶段 8：生成与状态记录

若当前环境能调用视频平台，保持同一项目/会话，记录镜号、版本、参考素材、Prompt、结果路径和失败原因。若不能直接调用，只交付可复制 Prompt、镜头总表和复检表，不虚构已生成结果。

### 阶段 9：导演复检与局部返修

按身份、空间、动作、摄影、光色、物理和节奏七类检查。只重写失败字段，合格字段升级为硬锁。连续两次相同失败时降低镜头复杂度、缩短动作或拆成有明确接点的两镜，不随机重生整个项目。

## 最终交付

固定 12 章：

1. 项目简报。
2. 导演与具体影片分支。
3. 证据边界与技术事实。
4. AIGC 技术执行配方（生成建议、非影片史实）。
5. 导演影像圣经。
6. 角色 / 场景 / 道具连续性圣经。
7. 色卡与美术落地（色卡仅是此模块）。
8. 节拍与镜头总表。
9. 逐镜 Seedance 2.0 指令与交接关系。
10. 剪辑与声音装配。
11. 导演复检与局部返修。
12. 完成交付验收。

编译后运行 `scripts/validate_director_package.py`。只要缺一章、缺一镜 Prompt、生成建议冒充史实、或逐镜八段不全，就不能宣告完整项目完成。
