⭐ **全局渲染铁律（v30·最高优先级，修复「配角不渲染/主角不真实」缺陷）**
> 每条生图 Prompt 与每个交付包**必须**包含「全局渲染」强制条款：
> `全局渲染：背景人物、次要角色与主角同等精度同等超写实质感渲染，背景人物具备完整五官、皮肤毛孔肌理、发丝与服装织物细节，禁止剪影人、简笔人、无脸人、低模背景人物；全画面前景中景背景统一渲染精度，禁止前景精细背景粗糙`
> 并**必须**附加扩展负面词：`背景人物简化，剪影人物，无脸背景人物，低模背景人物，背景人物省略，前景精细背景粗糙，皮克斯风格，迪士尼风格，3D动画风格，动画电影风格，玩具质感，手办质感，游戏CG质感，塑料人偶质感，大眼卡通比例，磨皮假脸，五官过度光滑`
> **背景人物不是布景**。凡画面中出现次要角色/路人/群像，一律按与主角同等的 UE5 次世代超写实标准渲染（完整五官+皮肤+发丝+服装），禁止任何形式的简化、剪影化、无脸化处理。此条款由 render.py 在每条 prompt 中自动注入，并由 regression.py 交付完整性门强制校验。

## 七、禁忌清单

### 7.1 叙事层禁忌（源自《影视动画分镜入门》）

- **禁止**跳过核心目标卡直接进入逐镜填写 —— 没想清楚本场要传递什么，就不该开始拆分镜
- **禁止**单方案定稿 —— 每场戏必须至少 2 套叙事方案对比后再选
- **禁止**保留「删掉也不影响剧情」的镜头（自检三问第③问不通过即删）
- **禁止**一格画面塞入多个叙事重点 —— 单格只突出一个重点，「叙事功能备注」出现「且/同时/另外」即违规
- **禁止**无理由的镜头运动 —— 推拉摇移跟必须服务叙事或情绪，炫技干扰故事表达；每个运动必须附理由，否则改为 Static
- **禁止**能一镜讲清却随意切镜 —— 细化前必须做最少镜头数评估，超额需说明理由
- **禁止**照搬台词代替画面叙事 —— 删掉对白后观众看不懂的镜头，判定为叙事失败，需重做
- **禁止**用台词表达内在信息 —— 角色心理与情绪必须由构图、光影、姿态、微表情传递
- **禁止**剪影不可读的画面 —— 压成剪影后无法辨识人物姿态与动作，构图判定不合格
- **禁止**只有导演能看懂的私人缩写或模糊表述 —— 分镜是全团队（美术/动画/制片）沟通文档
- **禁止**跳过动态节奏测试 —— 静态看图没问题不等于连续播放没问题
- **禁止**为画面精美牺牲信息传递 —— 信息传递优先，画质参数不得挤占叙事描述
- **禁止**单镜堆砌多重信息 —— 一镜只承载一个核心叙事信息，多信息必须拆镜（director-shot-grammar.md 铁律1）
- **禁止**单场内频繁切换主视角 —— 客观/主角POV/对手POV 三选一贯穿全场（铁律3）
- **禁止**全员同景别、同角度、同时长的平铺段落 —— 连续同节奏模式不得超过 8 镜（十大错误第4条）
- **禁止**动作在轨迹中途或起点切镜 —— 连贯动作必须在峰值处切换并标注切点

### 7.2 镜头语法层禁忌

> 本节全部条目 = **违反第二章 2.2 速查表对应编号法则**，判定标准只在速查表与各权威库定义一处：
> 违**法则一**（越轴硬切）/ 违**法则二**（视线不匹配）/ 违**法则三**（方向反转、左右手跳变、未在动作峰值切镜）/ 违**法则四**（景别级差>1且无过渡）/ 违**法则五**（时长超景别区间、超8秒红线、连续同模式>8镜）/ 违**法则六**（无建立镜头进中近景）/ 违**法则八**（缺三层纵深）/ 违**法则九**（无动机走位与运镜）/ 违**法则十一**（使用Zoom）
>
> **v1.1.3 改定（唯一口径）**：法则四按 10 `editing/16` 模式B 隔级切判——同主体级差 =0（同景别直切）或 =1（相邻）且无豁免才违规，≥2 隔级合法；旧「级差>1」口径废除。

### 7.3 风格与平台层禁忌

- **禁止**出现卡通化、Q版、大眼萌系的画面描述
- **禁止**AI prompt 缺少统一基础前缀
- **禁止**自行编写微表情描述（必须引用 M01-M96）
- **禁止**自行编写转场提示词（必须引用 T01-T100）
- **禁止**同一角色外形描述在不同镜头间出现改写
- **禁止**画面核心内容进入字幕安全区（底部 15%）
- **禁止**无开场钩子或尾钩悬念的单集结构
- **禁止**全集无任何镜头运动（全 Static）—— 注意与 7.1「禁止无理由运动」的平衡：要求的是**每个运动都有理由**，而非消灭运动

### 7.4 冲突裁决原则

当两套方法论冲突时，**叙事优先**：

| 冲突情形 | 裁决 |
|---------|------|
| 镜头符合全部场面调度法则，但通不过「删镜闸门」 | **删除该镜头** |
| 建立镜头规则要求首镜为 WS，但开场钩子需要 INS 特写冲击 | **钩子优先**，将 WS 建立镜头后移至第 2 镜 |
| 最少镜头数评估要求精简，但节奏曲线需要调剂镜头 | **保留调剂镜头**，并在方案对比中说明超额理由 |
| 微表情库无完全匹配项 | 选**最接近的一条**并在备注中说明差异，禁止自行编写 |

def build_prompt(s, shared, assets):
    """按前缀继承制拼装：prefix_full + 镜头库引用 + 资产desc_block逐字注入 + free + 全局渲染条款 + 负面词
    v30：强制注入 GLOBAL_RENDER 全局渲染条款与 EXTRA_NEG 扩展负面词（每条prompt必含，不可省略）"""
    pr = s.get("prompt_ref", {})
    body = ("镜" + str(pr.get("lib")) + "，" if pr.get("lib") else "")
    for aid in pr.get("asset_copy", []):
        blk = assets.get(aid, {}).get("desc_block") or assets.get(aid, {}).get("env_block") or ""
        body += blk + "，"
    body += pr.get("free", "")
    if pr.get("lighting"):
        body = (body.rstrip("，") + "，" if body else "") + pr["lighting"]
    return (f"{shared['prefix_full']}{body}。{GLOBAL_RENDER}。"
            f"画面干净无文字。负面：{shared['negative_global']}，{EXTRA_NEG}")

### 5.3 镜头层级物理精度适配 ⭐

| 镜头层级 | 物理精度要求 |
|---------|------------|
| **远景镜头** | 物理参数**可适度简化**，保留核心重力、受力、动态逻辑即可 |

## 七、新手十大致命错误（并入禁忌清单）

1. 单镜多信息，画面杂乱无重点（违铁律1）
2. 无逻辑景别跳跃：远景硬切特写、特写硬切全景（违法则四）
3. 频繁越轴、视线错乱（违法则一/二）
4. **全员同景别、同角度、同时长，平铺直叙毫无起伏**（节奏自查不通过）
5. 运镜泛滥全程推拉摇移，过度炫技弱化叙事（违铁律4）
6. 镜头时长不合理：该慢不沉淀、该快不紧张（对照第二章量化基准）
7. 视角频繁切换，上帝/主观随意混用，代入感割裂（违铁律3）
8. 空镜滥用、冗余镜头过多拖慢叙事（删镜闸门失守）
9. 动作剪辑断层：卡顿、重复、瞬移（违动作匹配——见下条）
10. 镜头与情绪脱节：严肃戏轻快运镜、悲情戏快速剪辑（情绪自查不通过）

### 动作峰值切镜规则（补强法则三）⭐

连贯动作拆多镜头时，**必须在上一镜的动作峰值处切换**（抬手最高点、挥拳接触瞬间），保证轨迹无缝衔接，杜绝断层/重复/瞬移。分镜表动作描述须标注切点位置（如「切换点：拳头触及面部瞬间」）。

### 方位统一细则（补强法则三）

人物入场方向=全程运动方向（从左入画则全程向左），中途反转必须有叙事原因并在备注说明。多人场景确立核心视线焦点，配角视线统一指向主体。

## 八、风格转换铁律（最高优先级）⭐

用户提供或指定的参考图可能来自**任意风格源**：2D 工笔、胶片真人摄影、2.5D 动漫、插画、手绘等。本技能的输出**永远且只能是 UE5 渲染 + 3D 写实**。

### 8.1 继承与禁止对照表

| 参考图元素 | 处理方式 |
|-----------|---------|
| 构图、机位、人物姿态、视线方向 | ✅ **继承** |
| 服装款式、纹样、配色、配饰造型 | ✅ **继承**（转写为 PBR 材质描述） |
| 氛围、色调倾向、背景元素（星光/烟雾/光斑） | ✅ **继承**（转写为 UE5 光照/体积雾/粒子） |
| 版式结构（三视图/面板/引线/配色板） | ✅ **继承** |
| 发型造型、头面结构 | ✅ **继承** |
| **工笔线描/平涂/纸本质感** | ❌ **禁止继承** → 转写为 SSS 皮肤 + PBR 织物 |
| **真人照片感/胶片人像肤质** | ❌ **禁止继承** → 转写为 3D 写实皮肤（毛孔+SSS，拒绝磨皮也拒绝照片感） |
| **2D 动漫大眼/赛璐璐色块** | ❌ **禁止继承** → 转写为写实美型比例 + 实体睫毛 |
| **厚涂笔触/清晰线条/CG插画描边** | ❌ **禁止继承** → 转写为实体发丝 + 皮草毛发物理模拟 + 金属雕刻纹理 |
| **手绘笔触/插画描边** | ❌ **禁止继承** → 转写为实体发丝 + 物理毛发 |
| **C4D/平面抽象/壁纸渲染感** | ❌ **禁止继承** → 转写为 UE5 物理材质模拟（硬纱折角、层叠半透明） |
| **参考图上的署名/水印/小字** | ❌ **绝对禁止继承** → 一律删除；输出画面不得含任何文字署名（全局负面词已含「文字，水印，logo」） |

### 8.2 转写执行步骤

收到非 3D 风格参考图时：

1. **拆解**：把参考图拆成「可继承层」（构图/服装/氛围/版式/造型）与「禁止层」（渲染质感）
2. **转写**：禁止层的每个元素替换为 3D 对等物：
   - 工笔白描线条 → `实体发丝，织物经纬纹理，刺绣浮凸立体感`
   - 平涂色块 → `PBR物理材质，各向异性织金高光，次表面散射`
   - 纸本底色 → `UE5体积雾，环境光散射`
   - 胶片人像肤质 → `皮肤SSS次表面散射，细微毛孔，拒绝磨皮`
3. **锚定**：prompt 必须含统一基础前缀（已含 UE5/PBR/SSS 锚定词），并追加本库风格基准关键词
4. **负面加固**：prompt 的全局负面词之外，针对原图风格追加对应负面词：
   - 原图为工笔/手绘 → 追加 `工笔画，线描，白描，平涂，纸本质感，水墨晕染`
   - 原图为真人/胶片 → 追加 `真人照片，摄影人像，胶片人像，纪实摄影`
   - 原图为 2D 动漫 → 追加 `2D动漫，赛璐璐，大眼萌系，卡通描边`
   - 原图为厚涂/CG插画 → 追加 `厚涂笔触，明显笔触，插画描边，线条清晰，手绘线条，油画质感`

### 8.3 一句话原则

> **参考图决定「画什么」，本技能决定「用什么画」。** 画什么（造型/服装/构图/氛围）听参考图的；用什么画（UE5 + PBR + SSS + 3D 写实）永远听本技能的，不可协商。
