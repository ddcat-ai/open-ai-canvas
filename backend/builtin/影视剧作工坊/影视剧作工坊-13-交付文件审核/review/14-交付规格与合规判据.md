# 交付规格与合规判据

> 本文件只回答一个问题：**这份交付文件，按它声明的模式，合不合格。**
> 每条判据都必须能**一眼判定**（人看或机器扫）；判定不了的写成"人工确认"并说明看哪里。

---

## 一、通用判据（三种模式都适用）

| # | 判据 | 级别 | 判法 |
|---|------|------|------|
| G1 | 交付文件**只含成品内容**——无档位编号、无转换轨迹、无验收结论、无引擎名称、无工程术语 | **FAIL** | 扫 `Lumen / Nanite / Arnold / UE5 / PBR / SSS / ACES / 85mm / f/1.4 / 3200K / 拓扑 / LOD`，命中即退 |
| G2 | 提示词长度 **≤ 800 字** | **FAIL** | 数字符；300–800 且远离 400 时给 WARN |
| G3 | 时长**按秒写**，**不写帧数** | **FAIL** | 扫"121 / 241 / 帧数 / 24fps 帧"；帧数是提交参数，不是画面语言 |
| G4 | 走 **API（5s / 10s）** 还是 **UI（4–15s）** 已声明 | **FAIL** | 文件头无声明即退——按 UI 写 8 秒而实际走 API，该镜不成立 |
| G5 | 负面规避词存在，且为**正向约束语句**（不是 `negative:` 列表语法、不是裸否定清单） | **FAIL** | 出现 `negative:` / `不要:` / 裸否定词堆即退 |
| G6 | 模式已声明（文生视频 / 首帧 / 首尾帧），且与文件内容自洽 | **FAIL** | 声明"首帧"却通篇写环境与外貌 → 按 §三 判 |
| G7 | 声音三轨按**声明的档位**写齐：**全量档**须 ⑧对白 + ⑨背景音 + ⑩BGM 齐全；**去配乐档**须 ⑧⑨ 齐全且 ⑩ 为 `NO BGM`。无对白写「无对白」，**⑨背景音轨不能为空** | **FAIL** | 档位与内容不匹配即退；⑨为空即退 |
| G8 | **声音层档位已显式声明**（全量 / 去配乐） | **FAIL** | 文件头无档位声明即退——不声明则无法判定 G7/G9 是否成立 |
| G9 | **去配乐档零音乐类 token**——`配乐`/`BGM`/`背景音乐`/`插曲`/`音乐` 一律不得出现，**唯一例外是 `NO BGM` 这处规格句本身** | **FAIL** | 逐词扫；残留即退——残留的音乐 token 会招来生成式配乐，破坏后期配乐的前提 |

## 二、文生视频（T2V）判据

| # | 判据 | 级别 | 判法 |
|---|------|------|------|
| T1 | **八要素齐备**：渲染规格 / 画幅画质 / 环境场景 / 人物外观状态 / 人物动作 / 镜头运镜构图 / 光影色彩 / 声音层 | **FAIL** | 逐项点名核对，缺一即退 |
| T2 | **画幅已显式指定**（`16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9`） | **FAIL** | 这是**唯一能指定画幅**的模式；不写就等于放弃画幅控制 |
| T3 | 主体与外观来自资产锚定段，**逐字一致** | **FAIL** | 与 04/05 的锚定段逐字比对 |
| T4 | 环境来自 GEO 场景布局块，**逐字一致** | **FAIL** | 与 04/06 的 GEO 块比对 |
| T5 | 全局风格前缀**逐字前置**，只声明一次 | **FAIL** | 前缀措辞漂移 = 观感漂移 |

## 三、首帧判据

| # | 判据 | 级别 | 判法 |
|---|------|------|------|
| F1 | **未复述输入图中已有的内容**——不复述环境、不复述主体静态外观、不复述构图 | **FAIL** | 本模式**唯一最高优先级硬项**。出现环境描写或外貌描写即退 |
| F2 | 有**明确的首帧指涉句**（声明输入图为第 1 帧） | **FAIL** | 无指涉句则模型不知从哪起 |
| F3 | 只描述**会动 / 会变**的内容：动作、表情、光影变化、环境动态 | **FAIL** | 静态名词短语占比过高即退，回 12 重拼 |
| F4 | 镜头运动**点名**（预设名或具体动词），非暗示 | **FAIL** | 含糊运镜是"图生视频几乎不动"的头号成因 |
| F5 | 输入图**画幅 = 目标成片画幅** | **FAIL** | 图生视频 `aspect_ratio` 不生效，按输入图匹配；不符即退（回 04 重出图） |
| F6 | 图片合规：JPEG/PNG、≤4.7MB、≤4096×4096、最短边≥320、长短边比≤3 | **FAIL** | 平台侧直接拒收 |

## 四、首尾帧判据

| # | 判据 | 级别 | 判法 |
|---|------|------|------|
| L1 | **只写中段**——未复述首帧内容、也未复述尾帧内容 | **FAIL** | 复述任一端即退 |
| L2 | **两张图的提示词已随交付文件附上**（由 04 产出：首帧图提示词 + 尾帧图提示词） | **FAIL** | 缺任一条即退——先生图，才谈得上首尾帧 |
| L3 | **两张图必须同一画幅比例** | **FAIL** | 比例不一致在提交阶段直接失败；**比例在出图阶段就定死**，此处不可补救 |
| L4 | 两张图的**角色/场景锚定段逐字一致**（只有状态与姿态不同） | **FAIL** | 逐字比对两段锚定文本 |
| L5 | 两张图属于**同一连续动作的起止状态** | **FAIL（人工确认）** | 逐字比对判不了，须看两张图：起止状态不连续时中段会漂移到"能同时接住两端"的折中画面 |
| L6 | 中段描述能**从起止两端推出**——观众看完两端后，中段发生的事在逻辑上必然 | **WARN** | 中段与两端无因果即 WARN |
| L7 | 图片合规（同 F6） | **FAIL** | 两张图各查一遍 |

## 五、判定与退回

| 结果 | 处置 |
|------|------|
| 全部 PASS | 放行 |
| 有 WARN | 放行，但 WARN 记入项目记忆（见 `13-失败诊断.md` §八 记录纪律） |
| **任一 FAIL** | **阻断放行**——判定**归谁改**，退回对应模块，不在本模块改写内容 |

**退回路由（按判据编号直接定位）**：

| 命中的判据 | 退回 |
|-----------|------|
| G1 · G2 · G5 · F1 · F3 | **12**（拼装与净化） |
| G3 · G4 · T2 · F5 · F6 · L3 · L7 | **12**（平台规格）→ 若涉输入图画幅则同时退 **04** |
| G7 · G8 · G9 | **09**（声音三轨与档位）——档位未声明或与内容不符时退 09 重定；残留音乐 token 退 09 清除 |
| T1 · T3 · T4 · T5 | **12**（八要素拼装）；锚定段不一致时退 **04/05** |
| F4 | **08**（运镜未点名） |
| G7（⑨背景音为空） | **09**（声音三轨） |
| L2 · L4 | **04**（首尾帧两图提示词） |
| L5 | **04**（重出首帧图/尾帧图） |

## 六、声音层档位速查

| 档位 | ⑧对白 | ⑨背景音 | ⑩BGM | 判据 |
|------|:-----:|:-------:|:-----:|------|
| **全量（默认）** | 必写或写「无对白」 | **必写，不可为空** | 必写（可用 `NO BGM` 表达"此镜无音乐"） | G7 全量分支 |
| **去配乐** | 同上 | **同上** | **必须是 `NO BGM`** | G7 去配乐分支 + G9 |

**易错点**：把「去配乐」写成**整段省略 ⑩**——那是 G7 的 FAIL。Seedance 2.0 自带音效/配乐，**不声明 ≠ 不生成**。
