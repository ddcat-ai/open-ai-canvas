# 三、构图

## 3.1 三要素叠加公式

最强的图像提示词将三者全部叠加：

**句式：**`[距离/景别] + [角度] + [运动暗示] + [主体] + [环境] + [光线]`

组合示例：

```
仰拍中近景：[img 1]，镜头缓慢推轨变焦推近。
在血红色夕阳的映衬下，她在画面中巍然耸立，风掀起她的斗篷。
电影感灯光，高对比度。
```

```
顶摄大远景，固定机位。[img 1] 是广阔冰封湖面中心的
一个小小身影，她的影子拉得很长。蓝调时刻光线，荒凉。
```

```
贴地特写，焦点转移。前景中雪晶体清晰锐利，
[img 1] 的靴子在雪晶体后虚化，随后焦点转移到她低头俯视的面部。
浅景深，冷蓝色调。
```

```
荷兰角牛仔镜头，手持质感。[img 1] 以大腿中段以上的取景
站在燃烧的村庄中，地平线倾斜，烟雾盘旋。她脸上绘着战绘，
武器出鞘。混乱而紧迫的构图。
```

## 3.2 静帧图像提示词公式

```
[景别大小] + [角度] + [运动关键词] + [img 1 / 角色描述]。
[姿势、表情或动作]。
[环境——地点、天气、氛围]。
[光线——一天中的时间、光源、质感]。
[风格——电影感、胶片类型、调色]。
```

**完整示例：**

```
中近景，仰拍，缓慢推轨推近 [img 1]。
她目光越过镜头凝视远方，双眼微眯，下颌紧绷，辫子垂落在
一侧肩头。她身后是一片冰封的战场，远处的火焰升起浓烟。
黄金时刻的逆光勾勒出她的剪影。
风格：电影感，Kodak Vision3 500T，去饱和的青色阴影，暖色高光。
```

## 3.3 画幅比例

| 比例 | 名称 | 最适用于 |
|-------|------|----------|
| 16:9 | 宽银幕 | 标准视频、长视频平台、电影 |
| 9:16 | 竖屏 | 短视频平台（Reels/Shorts/TikTok） |
| 2.35:1 | 变形宽银幕 | 史诗电影、极致宽银幕戏剧 |
| 1:1 | 方形 | 社交帖子、艺术向内容 |
| 4:5 | 竖版 | 社交信息流、人像 |
| 4:3 | 经典电视 | 复古、VHS 质感、年代感 |

**输出规格与风格语域——不要混为一谈：**

| 关注点 | 它是什么 | 在提示词中的位置 |
|---|---|---|
| 输出比例 | 硬性平台规格——模型实际输出什么 | 头部字段（如"画幅：16:9"） |
| 变形宽银幕 / 2.39:1 / 遮幅观感 | 摄影语域——变形镜头眩光、上下遮幅取景的美学 | 写在风格/观感行，作为风格请求 |

"16:9 变形宽银幕"同时请求了两件矛盾的事——输出规格说 16:9，观感说 2.39:1——模型要么忽略其一，要么产出不均匀的结果。**输出比例用枚举值；变形观感写在风格行**，让模型在所选比例之内渲染这种观感。

## 3.4 空间与构图的可测量语言纪律

- **左/右永远以摄影机为准**，不以角色为准。
- **大气用 % / 米量化**——"雾密度 40%"、"雾霭在 15 米处可见"；跨镜头分步建立（20% → 40% → 60%）。
- 多角色场景的空间关系用**绝对声明**（"角色 A 距角色 B 2 米，角色 C 在 A 身后 1.5 米"），不用"在旁边""附近"——几何一旦含糊，越剪越糟。
- **不写导演名字、代表作或设备型号名**——它们会被忽略或破坏复杂运动；改为描述观感本身。
