## 一、使用原则

1. **不替代 04 分镜结构**：最终仍按 04 的 11 必填字段输出：焦段 / 光圈 / 景深与焦点锁 / 机位 / 构图 / 运镜 / 主体动作/表情 / 台词与语气 / 光影 / 限制 / 下一段衔接。
2. **不替代 06 Seedance 适配**：本文件只帮助选择镜头和动作节奏；最终给 Seedance 的提示词仍由 06 按 A 标准字段化详细版、B 导演执行增强版或 C 导演轨纯净版转写，复杂运镜只在命中时写回字段。
3. **普通文戏不强制使用**：常规对话、普通走位、简单反应镜头，不要硬套运镜组合。
4. **一段只选少量组合**：4-8 秒单元最多 1 个核心组合；10-15 秒单元最多 2-3 个组合。不要把速查表变成炫技清单。
5. **组合编号不进最终 prompt**：`N-1 / F-3 / B-6` 只是内部选择标签，最终提示词必须写成画面语言。
6. **运镜服务情绪或动作结果**：每个运镜必须回答“为什么这么动”。不能只因为好看而动。
7. **摄影机行为锁优先**：选择任何运镜组合前，先锁定摄影机类型、位置、距离、高度、运动方向、稳定程度、速度、起止状态和禁止项。最终不要只写“手持 / 固定 / 跟拍 / 退拍”，要写成可执行摄影机行为。
8. **动作密度必须回填节奏档位**：命中打斗、追逐、强钩子、危机爆点时，默认建议 `高密度动作或强钩子`；普通紧张调度可建议 `短视频中高密度`；强情绪凝视或仪式感动作才保留 `电影感中速`。04 输出前置单元时必须写清该建议，06 只继承执行，不把动作段压回 1-2 镜。

## 二、Seedance 画面语言转换

资产和分镜阶段可以使用“轴线、点位、锚点、调度图”等工程语言；进入 06 最终 prompt 时，必须转换成模型更容易识别的画面语言。

| 给人看的工程语言 | 给 Seedance 的画面语言 |
|---|---|
| 180 度轴线锁定 | 角色A始终在画面左侧，角色B始终在画面右侧 |
| 不要越轴 | 摄影机保持在两人正前方这一侧，不切到两人背后的反方向 |
| A2 点位 / B2 点位 | 角色站在茶几左侧 / 角色坐在沙发右端 |
| 以沙盘为锚点 | 沙盘位于画面中央，人物围绕沙盘左右分布 |
| 高低落差 2 米 | 一人站在高台上俯视，另一人跪在台阶下仰视 |
| 主轴线从门到窗 | 门在画面左后方，窗在画面右前方，人物移动沿门到窗的方向 |

最终提示词优先使用：左侧、右侧、前景、中景、远景、画面中央、画面深处、摄影机在窗外/柜台外/人物正前方、角色向画面右侧移动。

最终提示词谨慎使用：东南西北、180 度轴线、不要越轴、锚点编号、A1/B2/C1 等管理编号。若必须保留点位，必须同时翻译成可见画面。

## 三、摄影机行为锁速查

本节用于把“固定、手持、退拍、跟拍”等模糊词，转成 04/06 可直接使用的摄影机行为。选择时先判断情绪和动作功能，再复制或改写“可写句”。

| 行为锁 | 适合场景 | 可写进 04/06 的摄影机行为句 | 禁止项 |
|---|---|---|---|
| 固定锁 | 对峙、审判、仪式感、冷静观察、权力压迫 | 摄影机固定在两人正前方眼平中景，茶几保持在画面中央，不推拉不摇移，只让人物动作改变画面。 | 禁止随机漂移、自动推近、无动机变焦、突然换机位。 |
| 固定过肩 | 冷静反打、潜台词对话、压住情绪 | 摄影机位于角色A左后方，过角色A右肩固定拍角色B近景，肩膀作为前景虚化，镜头不移动。 | 禁止越过肩膀另一侧，禁止突然切到背后反方向。 |
| 手持微动 | 克制焦虑、私密不安、轻纪录片质感 | 摄影机在角色右前方近景距离手持拍摄，随呼吸有轻微上下浮动，主体始终保持在画面右三分之一。 | 禁止剧烈晃动、禁止主体出画、禁止晃成动作戏。 |
| 手持跟拍 | 追逐、逃亡、慌乱移动、压迫主观感 | 摄影机在角色右侧约 1 米处手持侧跟，速度与角色步伐同步，转弯时短暂甩动后重新稳住。 | 禁止突然越轴，禁止跟丢角色，禁止空间方向反掉。 |
| 手持快摇 | 暴怒、突发危险、快速发现目标 | 摄影机先贴近角色面部，角色猛然转头时快速甩向目标，运动模糊后停在目标中景。 | 禁止无目标甩镜，禁止连续多次乱甩。 |
| 稳定器跟拍 | 角色穿场、进入空间、带观众移动 | 摄影机在角色背后三步距离稳定器跟拍，平稳穿过走廊或人群，角色肩线保持在画面中央。 | 禁止手持晃动，禁止穿过墙体/桌椅/人群。 |
| 前导倒退跟拍 | 角色逼近、边走边说、压迫感增强 | 摄影机在角色正前方胸口高度倒退跟拍，保持角色上半身中近景，角色前进一步镜头同步后退。 | 禁止倒退速度忽快忽慢，禁止撞到角色脸上。 |
| 侧跟 / 背跟 | 同步移动、追踪目标、行进对话 | 摄影机从角色左侧平行跟拍，保持半身中景；或从角色背后三步距离跟拍，前方空间逐渐展开。 | 禁止跟拍中改变角色左右位置，禁止突然跳到另一侧。 |
| 退拍 / 后撤 | 主体逼近、冲击、惊吓、揭示空间 | 主体突然冲向镜头，接近瞬间摄影机快速后撤到广角全景，露出身后的阻挡物和空间关系。 | 禁止无动机后撤，禁止后撤后空间结构改变。 |
| 缓推 / 窒息推近 | 情绪压迫、真相逼近、眼神聚焦 | 摄影机从中景缓慢推向角色眼睛特写，速度逐渐变慢，到眼神处停住。 | 禁止空泛“电影感慢推”，必须说明推向什么。 |
| 拉远 / 后拉揭示 | 孤立人物、揭示环境、反转信息 | 从手部或物件特写缓慢后拉，逐渐露出角色所处的完整房间和隐藏在画面深处的人。 | 禁止拉远后丢失主体，禁止揭示信息不明确。 |
| 横移揭示 | 多人站位、空间关系、隐藏物出现 | 摄影机沿桌边从左向右横移，前景杯子掠过后依次露出三人的左右站位。 | 禁止横移中越过轴线，禁止前景遮挡关键表情。 |
| 半环绕 | 权力变化、人物被包围、心理转向 | 摄影机围绕角色半环绕 90°，从左侧移动到正面，最后停在角色眼平近景。 | 禁止 360° 炫技连用，禁止绕到错误空间侧。 |
| 升降 / 俯仰变化 | 从人到环境、权力高低、命运感 | 摄影机从角色胸口高度缓慢升到头顶俯视，露出角色被人群围在中心。 | 禁止无功能升降，禁止高度变化导致主体比例变形。 |
| 视线摇镜 | 视线引导、发现目标、信息转移 | 先拍角色面部，角色视线移向门口后，摄影机跟随视线摇向门缝并停住。 | 禁止摇向无意义空处，禁止目标不清晰。 |
| 甩镜切 | 急促换角度、动作高潮、转场 | 动作高潮瞬间向画面右侧快速甩镜，运动模糊遮满画面后切到同方向的新角度。 | 禁止无目标甩镜，禁止甩后空间方向反掉。 |
| 遮挡转场 | 自然切换、同场换角度、换场 | 前景人物或门框完全遮住画面，遮满瞬间切到下一角度，主体重新清晰。 | 禁止遮挡物没有来源，禁止遮挡后人物站位跳变。 |
| rack focus | 信息揭示、暗线物件、心理转移 | 摄影机固定不动，先让前景手机背面清晰，随后焦点转到后景角色眼神。 | 禁止焦点对象不明确，禁止同时推拉造成混乱。 |
| 长焦压缩 | 压迫距离、监视感、人群挤压 | 使用长焦压缩空间，前景人群和后景角色距离被压近，角色像被环境挤住。 | 禁止角色和背景黏成一团，必须保留主体轮廓。 |

## 四、情绪运镜速查

| 目的 | 推荐组合 | 可写进 04 的运镜句 |
|---|---|---|
| 让观众注意关键细节 | 轻推近 | 运镜：镜头先固定半秒，再极缓慢向目标推近，推到面部/手中道具后稳住 1 秒。 |
| 揭示环境或反转 | 后拉揭示 | 运镜：从局部特写开始缓慢后拉，逐渐露出完整环境或隐藏人物，拉到全景后定格。 |
| 强调关键决定 | 点头式下压 | 运镜：关键台词落点时，镜头做一次很轻的下沉，随即回到原高度并固定。 |
| 犹豫和摇摆 | 犹豫横摇 | 运镜：镜头从 A 向 B 横摇，摇到中间短暂停顿，再继续摇向 B，最后稳住。 |
| 压迫感升级 | 窒息推近 | 运镜：镜头从中景推向眼睛特写，速度逐渐变慢，到眼神处几乎停止。 |
| 心神不宁 | 呼吸跟拍 | 运镜：侧跟角色行走，镜头跟两步短暂停一下，再继续跟，像呼吸节奏。 |
| 视线引导 | 视线上摇/横摇 | 运镜：先拍角色面部，角色视线移动后，镜头跟随视线摇向目标并停留。 |

## 五、速度与转场速查

| 目的 | 推荐组合 | 使用方式 |
|---|---|---|
| 快速穿梭 / 人群擦过 | 擦镜过场 | 前景人物或物体快速掠过镜头，短暂遮挡主体，掠过后主体重新清晰。 |
| 急促换角度 / 换场 | 甩镜切 | 动作高潮瞬间向左/右快速甩镜，运动模糊遮满画面后切到新角度。 |
| 冲击 / 惊吓 | 冲击后撤 | 主体冲向镜头，接近瞬间镜头急剧后撤，落到广角全景。 |
| 追逐加速 | 提速跟拍 | 侧跟角色奔跑，角色加速时短暂出画，镜头甩动重新追上。 |
| 重击 / 爆炸 / 撞门 | 震动强调 | 冲击发生瞬间镜头快速垂直抖动一次，随后推近到目标特写。 |
| 发现危险 / 急停 | 急停定格 | 跟拍角色快速移动，角色急停，镜头轻微前冲后回校，最终中景定格。 |
| 自然遮挡转场 | 遮挡切 | 物体或人物经过并完全遮住画面，遮满瞬间切到新场景或新角度。 |
| 相似动作/形状转场 | 匹配切 | A 画面元素占满画面，其形状、颜色或运动方向与 B 相似，在相似点切换。 |

## 六、氛围与心理速查

| 目的 | 推荐组合 | 使用方式 |
|---|---|---|
| 孤独 / 隔离 | 雨幕隔离 | 前景雨幕或玻璃水痕隔开人物，主体在雨幕后方半清晰，环境声压低对白。 |
| 内心动摇 | 灯火摇曳 | 实景灯源轻微晃动，人物脸部明暗跟着变化，情绪不稳定但不夸张。 |
| 神圣 / 时间凝固 | 尘埃浮动 | 光束穿过空气尘埃，人物动作变慢，背景压暗，光柱成为视觉中心。 |
| 人物登场 / 命运感 | 风声呼啸 | 先拍风吹动旗帜/衣摆/植物，风声变强，人物从风的方向入画。 |
| 回忆触发 | 记忆闪回 | 眼睛特写，瞳孔收缩，快切 2-3 个记忆画面，再回到现实反应。 |
| 观众知情、角色不知情 | 视线盲区 | 镜头绕到角色身后，露出危险或秘密，角色仍面向前方不知情。 |
| 紧张等待 | 呼吸同步 | 拍肩颈或胸口，镜头随呼吸轻微起伏，屏息时镜头静止，呼气时轻微后撤。 |
| 精神崩溃 / 现实裂开 | 碎裂视角 | 画面出现裂纹或分块，只在强风格化段落使用，普通现实戏慎用。 |

## 七、动作戏类型路由

本文件只保留通用摄影机行为、情绪运镜、转场和动作戏共通语法。命中具体动作类型时，不要一次性读取全部子库，只读当前段真正需要的 1 个；混合动作段最多读 2 个。

| 命中类型 | 按需读取 | 使用边界 |
|---|---|---|
| 自由格斗、拳脚、摔投、擒拿、缴械、地面控制、近身搏斗 | `04b-free-combat.md` | 传统格斗、贴身缠斗、徒手攻防、武器抢夺但不强调武侠身法。 |
| 武侠、冷兵器、刀剑枪棍、暗器、轻功、飞檐走壁、内力交锋 | `04b-wuxia-weapons.md` | 古装武侠、玄幻冷兵器、身法移动、兵器轨迹和东方动作审美。 |
| 超能力、异能、法术、念力、瞬移、护盾、元素、重力、空间裂隙 | `04b-superpower-action.md` | 能力来源、视觉形态、作用对象、物理结果和角色代价都需要清楚。 |
| 战场、军阵、群战、骑兵、弓箭、攻城、撤退、指挥官视角 | `04b-battlefield-action.md` | 大规模冲突、前中远景人群层次、战线变化、烟尘遮挡和战场声音层。 |
| 追逐、特殊转场、强情绪运镜、心理视觉化、普通摄影机行为 | 继续使用本文件 | 不需要具体招式库时，只选本文件的摄影机行为锁、情绪运镜和转场。 |

如果动作戏同时包含“武侠 + 异能”“战场 + 冷兵器”等混合类型，先用本表确定主类型，再只补读最相关的第二子库。最终输出不得写“已读取某子库”“使用组合编号”等内部管理信息。

## 八、动作戏共通语法

动作戏优先写成可见物理链条，不写成抽象评价：

```text
起手 → 接触点 → 受力结果 → 反应 → 段末状态
```

- `起手`：谁先动、从哪个方向、用哪个身体部位/武器/能力开始。
- `接触点`：拳头、手腕、剑脊、刀背、肩膀、胸口、盾面、地面、空气压缩点、能量命中点。
- `受力结果`：后退、跌倒、武器脱手、撞到墙、被压住、停在原地强撑、尘土被震起、盾阵被推开。
- `反应`：对手格挡、闪避、咬牙稳住、喘息、视线重新锁定、队形补位、能力反噬。
- `段末状态`：两人距离、左右站位、武器/道具位置、谁占上风、伤势/体力/能量变化、摄影机停在哪一侧。

写进 04 的 11 字段时：

- `运镜` 写摄影机位置、距离、高度、方向、速度、稳定程度和起止状态。
- `主体动作/表情` 写动作链条和表演反应。
- `限制` 写禁止错位、复制武器、身体变形、能力无来源、攻击方向跳变、接触点消失。
- `下一段衔接` 写动作结果和可继承状态，不写“继续打斗”。

## 九、通用动作戏限制项

动作戏必须写清：

- 谁先动、谁防守、谁被击中或谁成功闪避。
- 接触点在哪里；没有接触的能力攻击也要写作用点。
- 受力结果是什么；不要只写“很强”“很猛”“震撼”。
- 摄影机安全侧：给 Seedance 时改写成“角色A在画面左侧、角色B在画面右侧”“摄影机保持在两人正前方这一侧”。
- 不要所有攻击都打中；打斗需要试探、格挡、闪避、反击和喘息。
- 不要只写“激烈打斗、快速交锋、华丽招式”；必须拆成可见动作。
- 不要在 4-8 秒内塞超过 3 个主要打击动作；10-15 秒动作段也要保留反应和喘息。
- 不要让身体比例变形、武器忽大忽小、同一武器/道具复制、角色瞬移到错误方位。
- 群战和战场戏要写前景/中景/远景层次，禁止所有人同时抢主角戏。
- 异能和玄幻动作要写能力来源、视觉形态、作用对象、物理结果和代价，禁止无来源大爆炸。
