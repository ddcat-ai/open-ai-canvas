## 第四章 灯光、调色与画幅
### 4.1 灯光词汇

| 类型 | 描述 |
|------|------|
| Golden hour / Magic hour（黄金/魔法时刻）| 暖调定向光，太阳贴近地平线 |
| Blue hour（蓝调时刻）| 冷调、柔和，日落后不久 |
| Overcast / Softbox（阴天/柔光箱）| 漫射、柔和、无阴影 |
| Neon（霓虹）| 来自招牌/屏幕的彩色人工光 |
| Volumetric（体积光）| 光束可见（雾/尘/烟）|
| Practical only（仅实用光源）| 只来自画面内可见光源 |
| Side-lit（侧光）| 来自一侧的单一强光源 |
| Backlit / Rimlit（逆光/轮廓光）| 光源在主体背后 |
| Motivated（动机光）| 与场景中合乎逻辑的光源相匹配 |
| Hard light（硬光）| 单一强光源，阴影边缘清晰 |
| Soft light（软光）| 漫射、包裹、阴影极浅 |
| Rembrandt（伦勃朗光）| 阴影侧脸颊上的三角形光斑 |
| Butterfly / Paramount（蝴蝶光）| 头顶布光，鼻下投影（魅力人像）|
| Split lighting（分割光）| 半脸受光，半脸入影 |
| Chiaroscuro（明暗对照）| 极端明暗对比 |
| High-key（高调）| 明亮、阴影极少（喜剧、广告）|
| Low-key（低调）| 深阴影、情绪化（黑色电影、恐怖）|
| Harsh midday sun（正午烈日）| 硬质顶光，浓重清晰阴影 |

### 4.2 场景物理灯光

把灯光描述为场景中的一起**物理事件**，而不是一个风格化形容词。写明光源位置、它所反射的表面、由此形成的阴影几何 —— 模型利用每个被点名的要素在各镜头间一致地重建照明。

- **光源位置：** `key light from screen-left, ~30° above eye line`
- **反射/弹光：** `warm bounce off the wooden floor lifting under-jaw shadow`
- **阴影几何：** `hard shadow on screen-right wall reading the silhouette of the desk lamp`
- **环境光密度：** `dense ambient haze in the foreground softening contrast 6m+ out from camera`

场景物理写法用可叠加的、点名的物理机制，替换风格化形容词（`moody`、`dramatic`、`cinematic`）。模型能渲染被点名的机制；对形容词它只能给出近似。

### 4.3 夜景语域

直白提示 "Night" 常返回**亮夜** —— 被蓝青色罩一层的均匀照明（白天底板调冷），而非夜晚。电影夜景是**大面积的暗，由硬朗的实用光源切穿其中**。分两类，分野在于**什么被允许充当光源**：

**A. 室外/旷野之夜**（峡谷公路、偏远外景）。光**只来自场景内实用光源** —— 车头灯、刹车灯、仪表盘光、远处城市光晕。**没有环境月光，没有天光提亮。** 天空与四周压成深沉近黑；雾霭接住光束成为可见体积光柱；反向散射只照亮车辆近处。光锥之外一切落入近黑，主体主要作为剪影出现。极远处可有一抹微弱地平线光晕 —— 绝不足以照亮前景或中景。

**B. 室内/城市之夜**（车库、仓库、街道、车厢）。实用光源依然主导 —— 钠灯、荧光、霓虹、仪表盘。**青-琥珀双色分离在这里是合法的**，因为有实用光源提供动机。没有动机的青色泼满一切，读起来是调色而不是场景。

主导性检验：**点名光源，而不是点名情绪。** `Motivated` 与 `Practical only` 才是撑起夜景的关键；单靠 `low-key` 不够 —— 它只说了有多暗，没说光从哪里来。

### 4.4 频闪

频闪场景需要把脉冲描述成**事件**，三件事必须同时写明：

1. **脉冲本身** — 硬亮、硬灭，按写明的 BPM 运行；每次闪光瞬间凝固场景，每个间隔跌入近黑。不要渐变 —— 每次转换都是硬切。
2. **一盏辅助光** — 两次闪光之间维持微弱但持续的亮，让形体仍可辨认。
3. **连续运动条款** — *"nothing is ever frozen, held or static between flashes; every body is in continuous motion at all times, it is only the light that stops them."* 缺了它，模型会把身体渲染成真的停住。

> 逐拍的光脉冲会造成观感卡顿。收到"输出卡顿"报告时，先把脉冲放缓成缓慢连续起伏；仍存在则去掉脉冲改恒定光。脉冲通常才是元凶，不是帧率。

### 4.5 调色语言

| 情绪 | 描述 |
|------|------|
| 商业大片 | 青色阴影、橙色高光、高对比 |
| 冷冽惊悚 | 低饱和蓝灰、压黑的暗部 |
| 温暖怀旧 | 金色琥珀、抬亮的阴影、柔和颗粒 |
| 赛博朋克 | 霓虹品红＋青、深阴影、HDR |
| 恐怖 | 病态黄绿、低对比、浑浊 |
| 浪漫 | 柔粉金、抬亮的阴影、如梦 |
| 纪录片 | 自然中性、不做调色 |
| 史诗奇幻 | 深沉宝石色调、体积光 |
| 黑色电影 | 高对比黑白 |
| 科幻冷调 | 冰蓝与银、惨白光 |
| 末日后 | 低饱和橙棕、尘埃雾霭 |

### 4.6 配色规则

- **60/30/10 规则** — 60% 主导色、30% 次级色、10% 点缀色时画面色彩最干净。点名"一种主导色调＋辅助配色"比罗列五种竞争颜色更易协调。
- **只保留一种高饱和强调色，留给剧情。** 低饱和调色里，唯一高饱和强调色属于剧情关键道具（一件酸绿色的装置、一枚黄绿色 LED）。同样适用于时间维度："golden hour is reserved for the twist"（黄金时刻留给反转，之前保持平淡中性）。把这种预留显式写出来。

### 4.7 胶片型号模拟

- **Kodak Portra 400** — 暖调、饱满肤色、轻微颗粒
- **Fuji Velvia** — 鲜艳饱和、细腻颗粒
- **Kodak Vision3 500T** — 电影感、自然、微暖
- **Ilford HP5** — 经典黑白、颗粒可见
- **Kodak Ektachrome** — 明亮、高反差、干净反转片

### 4.8 画幅比例：输出规格 vs. 风格语域

| 关注点 | 它是什么 | 在提示词中的位置 | 受什么约束 |
|--------|----------|------------------|------------|
| 输出比例 | 硬性规格 —— 模型实际输出的画幅 | 头部声明（"Aspect ratio: 16:9"）| 各模型的枚举值 |
| Anamorphic / 2.35:1 / Scope | 摄影语域 —— 变形宽银幕眩光、遮幅构图美学 | 写进外观行，作为风格请求（"anamorphic-style flares, letterboxed composition"）| 风格层面 —— 模型在选定输出比例内渲染这种观感 |

把两者混为一谈会产出自相矛盾的提示词。"16:9 anamorphic" 同时请求了两件相互矛盾的事。请把它们分开。

**画幅速查：**

| 比例 | 名称 | 最适场景 |
|-------|------|----------|
| 16:9 | 宽银幕 | 标准视频、YouTube、电影 |
| 9:16 | 竖屏 | 短视频平台 |
| 2.35:1 | 变形宽银幕 | 史诗电影、宽银幕戏剧感 |
| 1:1 | 方形 | 社交帖子、艺术向 |
| 4:5 | 竖版 | 社交信息流肖像 |
| 4:3 | 经典电视 | 复古、VHS 质感、年代感 |
