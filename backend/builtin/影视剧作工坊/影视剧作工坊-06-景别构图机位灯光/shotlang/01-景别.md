# 一、景别

## 1.1 十种景别（静帧与视频通用）

| 景别 | 画面内容 | 提示词关键词 | 最适合 |
|------|--------------|------------|----------|
| 大远景（EWS） | 主体在辽阔风景中极小 | 大远景（EWS）、辽阔（Vast）、风景（Landscape） | 尺度、孤立、世界观建构 |
| 全景/远景（WS/LS） | 全身 + 完整环境 | 全景（Wide Shot）、全身（Full Body） | 背景交代、定场 |
| 全身镜头（Full Shot） | 从头到脚，主体充满画面 | 全身镜头（Full Shot）、取景（Framed） | 服装、角色登场 |
| 中远景（MLS） | 膝盖以上 | 中远景（Medium Long Shot） | 动作、对话 |
| 牛仔镜头（Cowboy） | 大腿中段以上 | 牛仔镜头（Cowboy Shot） | 姿态、戒备、动作 |
| 中景（MS） | 腰部以上 | 中景（Medium Shot） | 情绪与身体均衡 |
| 中近景（MCU） | 胸部/肩部以上 | 中近景（MCU） | 情感连接、亲密 |
| 特写（CU） | 面部 | 特写（Close-Up） | 情绪、表情 |
| 大特写（ECU） | 单一细节（眼睛、手） | 大特写（ECU） | 紧张、亲密、质感 |
| 微距（Macro） | 超近距纹理 | 微距（Macro） | 细节、材质、表面 |

静帧提示词示例（可直接改编）：

```
大远景：[img 1] 孤身一人站在辽阔而空旷的冰冻苔原上。
主体在远处显得很小，四周环绕着巍峨的雪山。电影感灯光
```

```
牛仔镜头：[img 1] 从大腿中段以上的取景。聚焦她搭在
腰带上的双手、自信的站姿，背景是带柔和焦外虚化的雪景。
```

```
大特写：对准 [img 1] 的双眼。虹膜的微距细节，
睫毛上挂着的雪花，战绘涂料的纹理。凌厉的目光
```

## 1.2 视频侧八级短语表（镜头控制侧）

视频镜头控制侧的景别短语表，每级配可直接使用的英文提示词短语（中文对照随行）：

| 控制 | 画面内容 | 适用 | 提示词短语 |
|---|---|---|---|
| 大远景（ELS） | 辽阔地貌，主体极小或不在画内 | 建场、孤立、史诗尺度 | "Extreme long shot — lone figure crossing the salt flat"（大远景——孤身的身影走过盐滩） |
| 全景/远景（WS/LS） | 全身可见 + 周边环境 | 人物在语境中的建场、动作戏 | "Wide shot of the dancer on the empty stage"（全景——舞者立于空舞台） |
| 中远景（MLS）/牛仔（Cowboy） | 大腿中段以上 | 人物站姿、西部对峙、群像 | "Medium long shot — the three outlaws face the sheriff"（中远景——三名不法之徒面对警长） |
| 中景（MS） | 腰部以上 | 对话、访谈、一般叙事 | "Medium shot — she leans against the bar, arms crossed"（中景——她倚着吧台，双臂交叉） |
| 中近景（MCU） | 胸/肩以上 | 情绪对话、反应镜 | "Medium close-up as he reads the letter aloud"（中近景——他对着信纸出声朗读） |
| 特写（CU） | 面部撑满画框 | 原始情绪、强度、亲密 | "Close-up on her face — tears welling, jaw tight"（她的面部特写——泪水涌起，下颌绷紧） |
| 大特写（ECU） | 单一特征（眼、手、嘴） | 张力、细节、心理强度 | "Extreme close-up on the twitching eye"（大特写——抽动的眼睛） |
| 插入镜头（Insert） | 物件或动作的细节 | 剧情细节、时间压力、质感 | "Insert shot — the clock hand ticking past midnight"（插入镜头——钟表的指针滴答走过午夜） |

**插入镜可在任何景别上做**——它是亚秒级（0.3–0.5 秒）的戏剧标点，不受景别档位约束。纪律：只承载静态瞬间、不承载故事节拍；必须因果有动机（观众明白"为什么"看到它）；始终点名主体（"他的手抓着金属"，绝不用泛指"一只手"）；同样遵守双重对比（真源 `10 editing/05-剪辑与连续性词汇.md`）。

## 1.3 视场角（FOV）锚点

在视频提示词文本中，视场角**只用以下离散锚点的度数**表述——绝不用毫米，绝不用中间值（不写"23°"，用 18° 或 29°）：

| FOV | 毫米等效 | 用途 |
|-----|----------|-----|
| 180° | 鱼眼 | 球面畸变——主观视角（POV）、梦境状态 |
| 107° | 14–16mm | 建筑级超广角、史诗定场 |
| 84° | 20–24mm | 广角——定场、群像走位 |
| 63° | 28–35mm | 观察式、报道纪实 |
| 47° | 40–50mm | 中性人眼透视 |
| 29° | 75–85mm | 肖像压缩、对话胸像 |
| 18° | 100–135mm | 近距离肖像、保持身份特征 |
| 12° | 180–200mm | 长焦细节——手部、物件 |
| 8° | 300–400mm | 极限压缩、远距离观察、广播感 |

- 多镜头提示词中，**为每一段单独设定 FOV**，并加"段中无漂移（no drift mid-segment）"。
- **CAMERA（镜头）块放在提示词核心层的第 3 位**（主体 → 动作 → 镜头 → 风格 → 约束）。挪到末尾，FOV 会被忽略；挪到开头，它会与身份信息冲突。
- 毫米/光圈词汇服务于图像模型与摄影式界面；块状视频提示词用度数锚点。*用途→镜片* 的逻辑在两者之间通用。

## 1.4 焦段与光圈按镜头用途

从镜头的*用途*出发挑选镜片，然后在提示词中同时写明焦段与光圈：

| 用途 | 焦段 | 光圈 |
|---|---|---|
| 极紧的情绪特写（额头到下巴充满画面） | 85mm 或 100mm（FOV 29° 或 18°） | F1.4 |
| 中段对话、双人镜头 | 50mm（FOV 47°） | F2.0–F2.8 |
| 广角 / 定场 | 35mm（FOV 63°） | F4–F5.6 |
| 插入镜头 / 物体细节（焦点锁定在物体上） | 50mm 或 85mm（FOV 47°/29°） | F1.4 |
| 微距（毛孔、水珠、织物） | 45mm 微距——无对应 FOV 锚点；块状提示词中按主体尺寸描述微距取景 | F2.8 |

两条固定条款随这些选择一起使用：

- **插入镜头与紧凑特写的对焦锁定**："对焦平面从第一帧到最后一帧都锁定在[物体]上——无焦点漂移、无移焦（rack focus）、无自动对焦来回搜寻。"
- **广角/大光圈镜片的禁用畸变条款**："笔直的直线条，无桶形畸变或枕形畸变，无鱼眼，无广角变形。"

## 1.5 按镜头类型的时长分配

15 秒多镜头总时长内的时长分配——用这些数值切分总时长，并让完整的情绪弧线赢得它所需的完整长度：

| 镜头类型 | 时长 |
|---|---|
| 闪现定场 / 硬切开场（一闪而过的全景） | 0.3–0.5 秒——一秒的一小部分，绝不是完整的一秒 |
| 一句中等长度的对话台词 | 3–7 秒 |
| 带情绪弧线的无台词反应 | 5–10 秒 |
| 插入 / 全景 / 定格 | 0.3–2 秒 |
| 带完整 5–7 拍弧线的情绪特写 | 8–15 秒 |

## 1.6 六级法则尺与折叠（双重对比的切点判定刻度）

组接词汇「双重对比」（`10 editing/05-剪辑与连续性词汇.md`：每次剪辑同时改变景别与镜头性格）判定「景别变没变」时，用的景别刻度只有六级：

```
大远景 → 远景 → 中景 → 中近 → 近景 → 大特写
(extreme wide → wide → medium → MCU → close-up → ECU)
```

镜头性格五档（editing/05 同款）：手持 | 固定/锁定机位 | 稳定跟拍 | 摇臂/垂直 | 航拍/无人机。

**双重对比切点规则（强制）**：每个切点必须**同时**改变景别与镜头性格。

- **坏例（镜头性格重复）**：中景手持 → 近景手持——只换了景别，运动方式两侧相同。
- **好例（两者都变）**：中景手持 → 大特写固定锁定。

法则尺只要求「变」，**不设最小级差，也不禁止相邻景别相切**——就双重对比本身而言，中景切中近只要镜头性格也换了即算合规；好例恰好是隔级大跳，但那是示例，不是级差下限。**分工注记**：同主体相邻镜头的级差纪律由「隔级切」管辖（唯一组接判据，v1.1.3 改定，`10 editing/16` §一按 §1.1 十级级序判级差）；法则尺只回答双重对比里「景别算不算换了」这一个问题——两把刻度不可混用。

十级（§1.1）向六级归档——**归档只影响切点判定，不影响提示词书写**（写提示词永远用十级的具体名称与画面内容）：

| 十级（§1.1） | 法则尺档位 |
|---|---|
| 大远景（EWS） | 大远景 |
| 全景/远景（WS/LS） | 远景 |
| 全身镜头（Full Shot） | 远景 |
| 中远景（MLS） | 中景 |
| 牛仔镜头（Cowboy） | 中景 |
| 中景（MS） | 中景 |
| 中近景（MCU） | 中近 |
| 特写（CU） | 近景 |
| 大特写（ECU） | 大特写 |
| 微距（Macro）／插入镜头（Insert） | 大特写 |

**与单调审计的衔接**：防同款连切的另一道闸是单调审计（`10 editing/01-规划层-连通分镜清单.md` §1.5）——连续三个剪切不得共享同一景别且同一镜头运动。逐条审阅看不见这种失败，只有把全部切口的「景别+运镜」竖读成一列才会显形；当每个剪切都读作「中景，缓慢推入」时，要变的是镜头的*功能与尺度*，而不只是时长。
