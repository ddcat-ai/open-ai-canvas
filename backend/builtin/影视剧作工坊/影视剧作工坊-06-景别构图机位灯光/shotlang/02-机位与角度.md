# 二、机位与角度

## 2.1 十种机位角度

| 角度 | 摄影机位置 | 提示词关键词 | 情绪效果 |
|-------|----------------|------------|-----------------|
| 平视（Eye-Level） | 与眼睛齐平 | 平视（Eye-Level） | 中性、写实 |
| 仰拍（Low Angle） | 低于主体，向上看 | 仰拍（Low Angle） | 力量、支配 |
| 俯视（High Angle） | 高于主体，向下看 | 俯视（High Angle） | 脆弱、渺小 |
| 顶摄（Overhead） | 正上方 | 顶摄（Overhead）、鸟瞰（Bird's Eye View） | 抽象、全局策略 |
| 虫瞰（Worm's Eye） | 地面，垂直向上看 | 虫瞰（Worm's Eye） | 极致力量、超现实 |
| 荷兰角（Dutch Angle） | 地平线倾斜 | 荷兰角（Dutch Angle）、斜角（Canted Angle） | 不安、混乱、紧张 |
| 过肩（OTS） | 越过肩膀 | 过肩（Over-the-Shoulder）、OTS | 对话、对峙 |
| 主观视角（POV） | 角色的双眼 | 主观视角（POV）、第一人称视角（First Person Perspective） | 沉浸感 |
| 自拍（Selfie） | 一臂距离、偏高 | 自拍角度（Selfie Angle）、一臂距离（Arm's Length） | 社交媒体、随性 |
| 贴地（Ground Level） | 紧贴表面 | 贴地（Ground Level）、表面视角（Surface View） | 环境沉浸 |

静帧提示词示例：

```
过肩镜头：越过前景中一个虚化的战士，聚焦正回望他们的 [img 1]。
```

```
贴地镜头：摄影机搁置在雪面上。浅景深，
前景是雪晶体，[img 1] 在背景中行走。
```

## 2.2 角度即情绪解读

角度的选择显著改变画面的情绪解读：**仰拍=力量/支配，俯视=脆弱/渺小，荷兰角=不安/混乱，虫瞰=极致力量/超现实，平视=中性/写实。**选择角度先问"观众该站在什么心理位置上看这个主体"。

## 2.3 视频侧机位角度补充词汇

| 控制项 | 作用 | 示例短语 |
|---------|-------------|---------------|
| 双人镜头（Two-Shot） | 两个主体同框——关系、对峙、对话 | "情侣漫步栈桥的双人镜头" |
| 左斜角 / 右斜角（Canted L/R） | 地平线向左/右倾（荷兰式倾斜） | "左斜角，走廊在眼前向前延伸" |
| 静态斜角（Static Oblique） | 偏轴取景的斜角透视 | "楼梯的静态斜角机位" |
| 过肩（OTS） | 对话取景、正反打 | "过肩镜头从侦探身后拍，面对嫌疑人" |
| 主观视角（POV） | 沉浸感、恐怖、主观体验 | "主观视角——双手推开厚重的木门" |
| 贴地（Ground Level） | 与地面的亲密感、微小主体、冲击力 | "贴地——蚂蚁列队行进在干裂的土地上" |
