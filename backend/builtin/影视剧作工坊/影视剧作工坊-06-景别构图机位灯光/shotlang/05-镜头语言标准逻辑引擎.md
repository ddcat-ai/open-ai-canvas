# 摄像机镜头标准逻辑引擎规则库（Camera & Lens Engine）

> **何时加载本库**：当你需要（1）把剧本场景/情绪转化为镜头语言方案/分镜表；（2）校验镜头衔接与场面调度（轴线/视线/动作/景别过渡/调度法则）；（3）量化镜头时长、组织蒙太奇、套用场景序列、控制节奏；（4）真人+超写实 3D（UE5）混合生产时按虚拟制片基线对齐虚实摄影机，加载本库。
> **回答的问题**：镜头怎么摆、怎么动、怎么衔接、怎么组接、怎么控制节奏。
> **地位**：本引擎隶属**辅助工作流**（与工程工作流并行，按需触发）——产出镜头语言方案/分镜表；**进入生成层的输出（分镜表→八要素文本）须经引擎八语义转换，再走后期终端流（引擎八→九→十一）**。
> **用法**：先定镜头链（CL-13 场景序列骨架）→ 逐镜定景别/角度/运动（CL-1~3）→ 校验衔接与调度（CL-4/4a）→ 填分镜表（CL-5 八要素）→ 时长/蒙太奇/节奏（CL-11~14）→ 虚拟制片任务走 CL-6~10。
> 所有判定以本库规则编号为准（CL 前缀）。

> **何时加载本库**：当你需要（1）把剧本场景转化为镜头语言方案（分镜表/镜头清单）；（2）设计景别、机位、镜头运动；（3）校验镜头衔接（轴线/视线/连续性）；（4）为 AI 剧分镜图环节提供镜头规范时，加载本库。
> **回答的问题**：这场戏用什么镜头拍、机位怎么摆、怎么衔接。
> **用法**：本引擎服务于主/工程工作流产出——输入为剧本分场表与角色状态表，输出为镜头语言方案；AI 剧场景下输出可直接驱动「分镜图（文生图）」环节。
> 所有判定以本库规则编号为准（CL 前缀）。

## 1. 镜头语言三要素

### CL-1 景别体系（画面范围 = 信息量）

| 景别 | 缩写 | 画面范围 | 叙事功能 |
|------|------|----------|----------|
| 大远景 | EWS | 人物 < 画面 1/10 | 环境、史诗感、渺小 |
| 远景 | WS | 全身 + 大量环境 | 空间关系、群戏站位 |
| 全景 | FS | 全身刚好入画 | 肢体语言、动作全貌 |
| 中景 | MS | 腰部以上 | 日常对话、手势交流 |
| 中近景 | MCU | 胸部以上 | 情感过渡、微表情初现 |
| 近景 | CU | 肩部以上/面部 | 情绪爆发、关键台词 |
| 特写 | ECU | 眼睛/嘴唇/手局部 | 心理暗示、细节、悬念 |
| 插入镜头 | INS | 道具/信件/物件 | 信息传递、隐喻、节奏调节 |

✅ 关键台词给 CU/ECU 强化情绪；新空间先 WS/FS 建立。
❌ 对话戏全程 MCU 不动——景别信息量单一，情绪无层次。

**CL-1a 景别专属负向约束（学习沉淀·漫剧全镜头转换规范）**：景别选定后，对应负向约束随该镜进负面词表（ST-5），防止模型在错误景别下产生典型缺陷：

| 景别 | 专属负向约束 |
|------|--------------|
| 大远景 | 人物面部细节、过近取景、人物占比过大 |
| 远景 | 人物过大、裁切肢体、环境缺失 |
| 全景 | 裁脚、人物顶天立地、背景抢戏 |
| 中景 | 裁手、面部过小、背景过度清晰 |
| 中近景 | 表情夸张、面部变形、背景干扰 |
| 近景 | 五官漂移、表情卡通化、过度锐化 |
| 特写 | 细节过度锐化、动作幅度过大 |
| 插入 | 道具变形、边缘裁切、细节糊化 |

**景别时长匹配（参考）**：大远景 3-6s（五秒/十秒档·缓慢）、远景 3-5s（五秒档·平稳）、全景 2-5s（五秒档·平稳）、中景 2-4s（五秒档·平稳）、中近景 1-3s（五秒档·短镜）、近景 1-2s（五秒档裁帧·短镜）、特写 0.5-2s（五秒档裁帧·闪切）、插入 1-2s（五秒档裁帧·短镜）。**景别八要素侧重**：远景重环境、全景重动作、近景重表情、特写重细节——按景别分配要素权重。

### CL-2 机位角度（角度 = 心理暗示）

| 角度 | 心理效果 | 适用场景 |
|------|----------|----------|
| 平视（Eye Level） | 客观中立、与角色对等 | 日常对话 |
| 俯拍（High Angle） | 弱势、被压制、命运俯瞰 | 困境、权力压迫 |
| 仰拍（Low Angle） | 强势、威胁、英雄化 | BOSS 登场、觉醒、力量展示 |
| 鸟瞰（Bird's Eye） | 上帝视角、宿命感、全貌 | 战场、追逐 |
| 荷兰角（Dutch） | 失衡、癫狂、心理扭曲 | 精神崩溃、反派空间 |
| 过肩（OTS） | 对话关系、空间连接 | 双人对话标准机位 |

✅ 角色被压制 → 俯拍；角色觉醒 → 仰拍。
❌ 角度与情绪无关乱用——正常对话场景用荷兰角，制造无端不安。

**CL-2a 机位克制边界与情绪曲线（学习沉淀·漫剧全镜头转换规范）**：

| 机位 | 视角高度 | 权力暗示 | 叙事用途 | 克制边界 |
|------|----------|----------|----------|----------|
| 平视 | 眼睛同高 | 平等客观 | 对话、纪实、中立 | 无 |
| 微仰 | 低于视线 3-5° | 权威强化 | 登场、对峙、压迫 | 3-5°（不夸张仰拍） |
| 微俯 | 高于视线 3-5° | 审视弱化 | 被审、宿命、怜惜 | 3-5° |
| 侧 45° | 眼睛同高偏侧 | 关系平衡 | 双人对话、纵深 | 45° |
| 过肩 | 主体眼睛同高 | 关系对峙 | 对话、冲突、绑定 | **成对使用**、前景 ≤ 1/3 |
| 鸟瞰 | 垂直向下 | 绝对掌控 | 定场、揭示、宿命 | **每场一次**（克制） |
| 荷兰角 | 水平倾斜 | 失衡不安 | 混乱、危险、幻觉 | **每场两镜**（上限） |

**机位情绪曲线**：铺垫期平视 → 升级期微仰/微俯 → 爆发期过肩/特写 → 失控期荷兰角 → 收束期回平视——角度随情绪曲线切换，禁止同场乱跳。

### CL-3 镜头运动（运动 = 调度情绪）

| 运动 | 叙事功能 |
|------|----------|
| 推（Dolly In） | 聚焦、紧张升级、进入角色内心 |
| 拉（Pull Out） | 揭示环境、疏离感、孤独 |
| 摇（Pan） | 空间扫描、视线引导 |
| 移（Tracking） | 伴随运动、空间穿越 |
| 升降（Crane） | 仪式感、命运升降 |
| 环绕（Arc） | 聚焦核心、时间凝固 |
| 手持（Handheld） | 临场感、不安、纪实 |
| 斯坦尼康（Steadicam） | 流畅跟随、沉浸 |
| 固定（Static） | 凝视、压迫、留白 |

✅ 关键决定 → 推；角色身处险境 → 拉。
❌ 运镜无动机——每个运动必须有叙事理由（跟随动作/揭示信息/烘托情绪），「更好看」不合法。

**CL-3a 运镜速度/幅度档位（学习沉淀·漫剧全镜头转换规范）**：运镜写句带**速度档 + 幅度档**（模型可执行），与动机表配套：

| 运镜 | 动机示例 | 速度档 | 幅度档 |
|------|----------|--------|--------|
| 推镜 | 情绪聚焦升级 | 慢 | 小 |
| 拉镜 | 情绪释放孤寂 | 慢 | 小 |
| 摇镜 | 环境扫描揭示 | 慢 | 中 |
| 俯仰摇 | 垂直空间揭示 | 慢 | 中 |
| 横移 | 跟随运动并列 | 中 | 中 |
| 跟镜 | 代入持续推进 | 中 | 中 |
| 升降 | 格局揭示收束 | 慢 | 大 |
| 环绕 | 张力旋转审视 | 慢 | 小 |
| 手持 | 混乱主观临场 | 两档 | 小-中 |
| 斯坦尼康 | 长镜连续穿行 | 中 | 中 |

**规则 CL-3a**：运镜句 = 运动名 + 速度档 + 幅度档（例"缓慢推近，幅度小"）；速度/幅度带程度词，禁止数值直出；与 CL-4a 三动机联动（有动机才动）。

## 2. 镜头衔接法则（连续性保障）

### CL-4 衔接四法则

- **轴线 180°**：同场对话机位全程轴线同侧；越轴必须经中性镜头（正面/特写/空镜）过渡
- **视线匹配**：A 看右 → B 必在画面左侧看右；仰俯与站位物理一致
- **动作连续性**：运动方向跨镜一致、左右手持物不无故切换；连贯动作在峰值处切镜
- **景别过渡（v1.1.3 改定，唯一判据＝10 editing/16 模式B）**：同主体相邻镜头**隔级切**——级差=0（同景别直切）/1（相邻）须 INS/空镜桥或豁免理由；级差≥2 合法；INS/空镜不计级

✅ 双人对话：全部机位落在轴线同侧，越轴前先插中性镜头。
❌ 越轴不插中性镜头——观众空间感断裂，方向关系混乱。

### CL-4a 场面调度法则（镜头之外的空间叙事）

场面调度的本质**不是美化画面，是操控观众注意力、情绪与认知**——人物演情绪，镜头讲感受；一切调度必须有叙事动机。

**三大空间体系**：
- **屏幕二维**：视觉重量排序 = 运动物 ＞ 亮色 ＞ 高对比 ＞ 大物体 ＞ 画面右侧——要观众先看哪里，哪里就是视觉重量最高元素（平衡=平静/压抑，失衡=紧张/冲突）
- **画内三维**：每个镜头必须三层纵深（前景遮挡 + 中景主体 + 背景环境），缺层即扁平、无电影感
- **画外空间**：悬念/压迫镜头至少用一种激活方式——①人物望画外 ②人物出入画 ③画外有声 ④人物对画外反应（未知的画外威胁 > 直接出镜）

**站位 = 权力关系**：面对面=对峙对抗；并排=同盟亲密；一前一后=支配从属；高低站位=强弱势。权力翻转节拍，站位必须随之变化（被观众看见）。

**走位五种**：横向=平稳叙事；纵深走向镜头=压迫递增、情绪升温；纵深远离=疏离逃避；斜向=最自然最具电影感；环形=困局对峙。**人物移动必须有动机**（躲避/追赶/靠近/退缩），无动机走位删除。

**运镜三大合法动机**（无以下任一动机，镜头一律 Static）：①跟随人物动作 ②揭示关键信息 ③烘托人物情绪。"画面更好看"不是合法动机。

**Dolly vs Zoom 铁律**：Dolly（机位物理移动）→ 透视变化 → 电影感；Zoom（光学放大）→ 透视不变 → 廉价感。**一律禁 Zoom 表述**，需"靠近主体"写 Dolly In。

**景别情绪阶梯**：EWS 孤独宿命 → WS 环境关系 → FS 完整动作 → MS 标准对话 → CU 微表情 → ECU 秘密/爆发。**冲突升级必须由远及近逐级收紧，禁止无逻辑跳景**。

**调度禁忌**：无动机运镜/走位、滥用 Zoom、无三层纵深、随意越轴、视线不匹配、为了好看调度（美学必须依附叙事）、大特写无节制、画外空间零利用。

## 3. 分镜表产出（CL-5）

辅助工作流输出**镜头语言方案/分镜表**，AI 剧场景直接驱动「分镜图（文生图）」环节：

| 字段 | 内容 | 示例 |
|------|------|------|
| 场次/镜头号 | 分场表对应 + 顺序号 | S3-05 |
| 景别 | CL-1 八级 | CU |
| 机位/角度 | CL-2 | 平视 + 过肩 |
| 运动 | CL-3，标注动机 | 推（聚焦决定） |
| 画面描述 | 主体/环境/光线 | 女主眼含泪光，窗外雨 |
| 时长 | 秒 | 3s |
| 衔接 | 与上下镜关系 | 切 S3-06 特写 |
| 角色呈现 | 锚定词引用（角色引擎 E2） | 引用稳定锚定段 |

- 验收：每个镜头可回答「景别/角度/运动/动机/衔接」五问；跨镜头连续性与角色一致性达标
- AI 剧链路：分镜表 + 角色锚定词 = 文生图提示词的直接输入

### 每镜生成 Prompt 八要素（视频大模型可执行）

分镜表驱动「分镜图/图生视频」时，每镜 Prompt 必须按以下八要素拼装（引擎八语义转换输出后落表），**顺序固定、要素完整**：

| # | 要素 | 内容 | 写法红线 |
|---|------|------|----------|
| ① | 渲染规格 | 写实度/风格 | 只写风格标签（电影级写实），不写渲染参数 |
| ② | 画幅画质 | 比例/分辨率/画质基调 | 标注 9:16、1080P、丝滑运镜 |
| ③ | 环境场景 | 地点/空间/三层纵深 | 语义描写（前景/中景/背景） |
| ④ | 人物外观状态 | 外貌/服装/表情（引用锚定词 E2） | 引用稳定锚定段，不用模糊词 |
| ⑤ | 人物动作 | 动作/表演/运动方向 | 动作序列可演绎（可画出/演出） |
| ⑥ | 镜头运镜构图 | 景别/机位/运动 + **焦距** + **时长节奏** | 焦距语义化（广角/长焦/浅景深）；**时长不写精确秒数**写节奏词（快切/缓慢推进/定格） |
| ⑦ | 光影色彩 | 光位/色温/影调 | 语义化（暖橙灯光/冷蓝月光/半明半暗） |
| ⑧ | 声音层 | 对白/旁白/音效 | 台词内容 + 音效提示（环境声/动作音），生成后须校验口型 |

**规则 CL-5a**：八要素拼装顺序固定（①→⑧），缺一不可；焦距/时长/色温等参数一律语义化，禁止数值直出。
**规则 CL-5b**：④人物外观必须引用角色引擎锚定段（E2），禁止脱离锚定词重写外貌。

✅ ⑥ 写"镜头缓慢推近（约3秒推进节奏），长焦压缩纵深，浅景深"。
❌ ⑥ 写"35mm f/2.8，3.5s"——模型不执行数值，回炉语义化。

✅ 一场戏先定镜头链（建立镜头 → 对话正反打 → 特写强调 → 收尾空镜），再逐镜填表。
❌ 逐镜孤立设计——不先定镜头链，场次间衔接必然断裂。

## 4. 虚拟制片摄影机基线（真人 + 超写实 3D + UE5）

> 适用场景：真人实拍与超写实 3D（UE5）混合生产——ICVFX（镜头内视效）/ LED 棚虚拟制片。本基线基于 Epic 官方文档：Cine Camera Actor 为 UE 影视摄影机（Filmback/Lens/Focus 三组设置复制真实电影机行为）；ICVFX 依赖 LED 光照 + 实时摄像机追踪 + 离轴投影实时渲染，目标是取代绿幕合成、摄影机直接拍摄最终画面。

### CL-6 摄影机类型体系

| 层 | 摄影机 | 职责 | 关键设置 |
|----|--------|------|----------|
| 实拍机 | 数字电影摄影机（如 ARRI / Sony 系列） | 拍摄真人前景，最终画面载体 | 镜头 + 传感器真实；配追踪系统 |
| 虚拟机 | UE5 Cine Camera Actor | 渲染虚拟背景（内截锥），与实拍机严格对齐 | Filmback / Lens / Focus 三组参数复制实拍机 |
| 预演机 | Unreal VCam（iPad/iPhone + Live Link） | 片场/预演实时操控虚拟机位、镜头、焦点 | Lens Presets / Filmback / Focus / ISO 可调 |

**规则 CL-6**：混合生产中**虚拟 Cine Camera 必须精确模拟物理实拍机**——位置/朝向与追踪数据一致，Filmback、焦距、时序同步，否则虚实视差穿帮。

### CL-7 Filmback 匹配（传感器一致）

- 虚拟机 Filmback 预设**必须等于实拍机身传感器**（宽高 mm 一致）：传感器尺寸决定基础 FOV 与画幅比（Sensor Aspect Ratio 只读计算）
- 全局规则：画面 FOV = 焦距 × 传感器——两者任一不匹配，虚拟背景与真人前景透视即分离

✅ 实拍机超35 传感器（宽约 28mm）→ 虚拟 Cine Camera Filmback 选同传感器预设。
❌ 实拍超35、虚拟机用全幅预设——同一焦距下 FOV 不同，虚实透视穿帮。

### CL-8 镜头与焦距基线

- **定焦优先**：虚拟镜头 Min/Max Focal Length 设为相同值以模拟定焦（Prime）；电影定焦组常用 18/25/32/40/50/75/100mm（超35 基准）
- **标准镜头**：焦距 ≈ 传感器对角线（超35 约 27-30mm 区间）→ 人眼自然透视；32-50mm 为对话/中景常用
- **广角**（18-25mm）：环境建立、空间压迫、手持纪实
- **长焦**（75mm+）：压缩背景纵深、人物特写、虚实混合中背景更凝聚
- **F-Stop/光圈**：小 f（大光圈）浅景深；虚拟景深必须与实拍光圈匹配；UE 中光圈不控制光强（避免与真实相机同时调曝光）
- **对焦**：Focal Distance 单位 cm；Focus Method = Manual（精确控制）或 Tracking（锁定目标 actor）；Smooth Focus 平滑跟焦

✅ 超35 基准：对话戏 32-50mm、环境 18-25mm、特写 75-100mm，虚拟/实拍同焦距同光圈。
❌ 实拍 50mm、虚拟机给 35mm——FOV 差导致背景放大率不一致，人物与背景关系失真。

**CL-8a 焦距十二段速查（学习沉淀·漫剧全镜头转换规范）**：焦距语义化时按叙事用途选段，数值只存工程档：

| 焦距段 | 画面语义 | 叙事用途 | 景深倾向 |
|--------|----------|----------|----------|
| 10mm | 极强近大远小 | 巨物压迫、灾难 | 大景深 |
| 14mm | 强拉伸线条汇聚 | 宏大外景、仰视对峙 | 大景深 |
| 20mm | 广角空间宏大 | 宏大场景常规 | 大景深 |
| 24mm | 空间舒展 | 环境人像、中全景 | 大景深 |
| 28mm | 叙事广角不畸变 | 故事板标配、行走对峙 | 大景深 |
| 32mm | 接近人眼 | 中近景对话首选 | 大景深 |
| 35mm | 人眼零畸变 | **万能主力镜头** | 可浅可深 |
| 50mm | 客观中立 | 冷静叙事、纪实 | 可浅可深 |
| 70mm | 轻微压缩分离 | 半身近景、压抑情绪 | 浅景深开始 |

**焦距情绪联动**：广角=大景别史诗 / 人文段=中景对话 / 长焦=特写内心——焦距、景别、情绪同步收紧。**焦距速查**：定场用广角段、对话用人文段、情绪用长焦段、道具用微距段、窥视用超长焦段。

### CL-9 ICVFX 校准与同步

- **内截锥（Inner Frustum）**：LED 墙上从实拍机视角渲染的画面 = 该机 FOV（按当前镜头焦距）；随实拍机运动实时跟踪，产生真实视差
- **外截锥（Outer Frustum）**：FOV 之外的虚拟世界内容，充当实景灯光与反射源（静态，模拟真实世界灯光不随相机移动）
- **摄像机追踪**：光学追踪（IR 相机 + 反光/主动 IR 标记）/ 特征追踪 / 惯性追踪（IMU）；推荐光学 + 惯性多源组合；Live Link 分发追踪数据（Vicon/Stype/Mo-Sys/Ncam 等）
- **镜头校准**（Camera Calibration 插件）：生成 Lens File 资产，封装焦距、镜头失真（Distortion）、节点偏移（Nodal Offset）；定焦用厂商标注焦距，首个校准点对焦距离约 150cm；焦距与节点偏移存在耦合，建议全局求解
- **同步**：Timecode + Genlock 统一全部设备时钟，防撕裂；引擎 timecode/帧生成与实拍机帧对齐
- **莫尔纹**：对焦面与 LED 面板对齐时出现；对焦放 LED 面前/后（略虚）、尽量垂直 LED 面、控制机位距离

✅ 开拍前完成镜头校准（Lens File 含失真+节点偏移）→ 全程同机身同镜头 → Genlock 锁定帧同步。
❌ 换镜头不重校准、或虚拟焦距沿用旧值——失真与透视错位，内截锥与前景无法对齐。

### CL-10 混合生产验收（虚实一致性）

| 验收项 | 基准 |
|--------|------|
| 透视一致 | 虚拟背景 FOV 与实拍镜头一致（CL-7/CL-8），无视差分离 |
| 景深一致 | 虚拟 DOF 与实拍光圈匹配；焦平面落在同一深度 |
| 同步一致 | 追踪数据/时间码/Genlock 全链路对齐，无抖动撕裂 |
| 色彩一致 | 全程同一实拍机；LED 输入线性 sRGB（Tonemapper 关闭）；OCIO 统一 |
| 灯光一致 | 外截锥作为光源与实景光照协调，无跳变 |

✅ 虚实同焦距同光圈同传感器 → 人物站位 LED 前，背景透视/景深/视差三重一致。
❌ 只对齐位置不对齐镜头参数——内截锥画面与实拍前景在透视和景深上分层，混合穿帮。

### CL-12 蒙太奇组接六体系（镜头从"记录"升级为"讲述"）

| 手法 | 定义 | 适用 | 落地 |

**学习沉淀·代表方法论（已通用化）**：
- **长镜头一镜到底**：单镜内保持物理时空绝对连续（拒绝蒙太奇碎片化），以"跟随轨迹+空间连续+终点定格"组织——对应 CL-14 慢节奏长镜，深度解析=调度能力的体现、身临其境的连续呼吸感。

### CL-13 四大场景标准镜头序列（可直接套用的分镜骨架）

- **双人对话**：全景定场（交代站位）→ 单人中景主说 → 单人中景回应 → 中近景情绪特写 → 细节补充(INS) → 全景收尾转场。约束：全程守轴线、正反打视线匹配、运镜克制（固定+轻微推拉）
- **单人情绪**：中全景交代状态 → 中近景聚焦神态 → 近景/特写放大情绪 → 细节佐证内心 → 慢拉空镜留白收尾。约束：节奏由慢到静、景别逐步收紧
- **动作冲突**：全景铺垫对峙 → 中景记动作 → 短镜快切细节 → 特写捕捉发力 → 环绕/跟镜强化 → 全景定格收尾。约束：快慢结合，每 3-5 快切插 1 慢镜
- **转场空镜**：环境光影/天气/静态景物/动态氛围。约束：四大功能=缓冲节奏/切换时空/烘托氛围/留白情绪，杜绝无意义空镜

**规则 CL-13**：拆镜前先判场景类型（对话/情绪/动作/过渡）套用骨架，再按核心目标卡增删；偏离模板须说明理由。

**CL-13a 镜头数控制（学习沉淀·漫剧全镜头转换规范）**：场景镜头数按类型限额，超出评估值 50% 须说明理由：

| 场景类型 | 镜头数区间 |
|----------|------------|
| 对话 | 6-10 镜 |
| 情绪 | 4-8 镜 |
| 动作 | 8-15 镜 |
| 空镜 | 3-5 镜 |

### CL-14 节奏模式四档（张弛调度）

| 模式 | 单镜时长 | 形态 | 适用 |
|------|---------|------|------|
| 慢节奏 | 3-6s | 长镜、慢运镜、少切换 | 抒情、铺垫、留白 |
| 中节奏 | 1.5-3s | 中短交替、匀速 | 日常对话、剧情推进（通用基线） |
| 快节奏 | 0.5-1.5s | 短镜密集+快摇/横移/跟镜 | 对峙、追逐、打斗、危机 |
| 骤停节奏 | 超长静止 | 快切后突然超长静止，极致反差 | 爆点、转折、悬念留白、尾钩 |

**规则 CL-14**：全片松紧交替、快慢结合，连续同模式不超过 8 镜须换挡；情绪高潮优先骤停节奏制造反差。

**CL-14a 场景-节奏特征与节奏曲线（学习沉淀·漫剧全镜头转换规范）**：

| 场景类型 | 主导节奏 | 辅助节奏 | 节奏特征 |
|----------|----------|----------|----------|
| 双人对话 | 中节奏 | 慢节奏 | 平稳推进，情绪处放缓 |
| 单人情绪 | 慢节奏 | 骤停节奏 | 积累留白，爆发处定格 |
| 动作冲突 | 快节奏 | 骤停节奏 | 快切密集，高光处定格 |
| 转场空镜 | 慢节奏 | 中节奏 | 留白过渡，衔接处强调 |

**节奏曲线**：铺垫平缓 → 爆发陡峭 → 余韵回落，骤停落重音；连续同模式不超 8 镜，曲线平滑无断裂。**节奏词对照**：慢=缓慢留白（五秒/十秒档）、中=平稳推进（五秒档）、快=快切密集（五秒档裁帧）、骤停=定格黑切（静帧或五秒档定格）。

### CL-15 群戏调度体系（学习沉淀·漫剧全镜头转换规范·第19章全吸收）

群戏核心：**人数决定景别、分组决定机位、视线决定焦点**——三人以上场景不按单人对话拆镜，按群戏体系调度。

**CL-15a 同框景别绑定**：人数 × 景别绑定，避免"多人挤在中景"或"单人占大全景"：

| 人数 | 同框景别 | 取景 |
|------|----------|------|
| 双人 | 中景 | 腰部以上 |
| 三人 | 全景 | 全身入画 |
| 五人以上 | 大远景 | 成组分布 |

**CL-15b 空间分组三种**：二人组=相对站位+正反打机位；三角组=三点站位+环绕机位；前景锚点组=焦点人物置前景、其余置中远景。

**CL-15c 视线接力三模式**：单焦点（全场视线集中焦点人物）；视线链（视线依次传递成链）；视线破组（某人视线偏离焦点，冲突伏笔）。

**CL-15d 焦点分配三层**：焦点人物动作/视线最清晰 → 次级人物次之 → 陪衬人物只做环境动作——注意力聚焦焦点，三层分明。

**CL-15e 四种群戏方案**：
- 双人：正面双人全景建立空间 → 侧 45° A 拍 B → 侧 45° B 拍 A → 过肩镜像 → 情绪近景收束
- 三角：全景保持三角站位 → 三点环绕机位逐一聚焦 → 单人近景视线方向匹配三角位置
- 阵列：全景对称阵列 + 横移群像逐一展示（仪式/力量）
- 人群：手持跟拍主观视角，晃动与情绪匹配（恐慌/临场）

**规则 CL-15**：群戏焦点转移用"引导镜（焦点人物动作/视线引注意力）→ 承接镜（推近新焦点）"自然过渡；越轴走 CL-4 中性镜过渡；检查清单=人数景别匹配、分组清晰、视线有焦点、焦点三层分明、机位匹配、越轴过渡、穿帮修复。

### CL-16 竖屏 9:16 构图法则（学习沉淀·漫剧全镜头转换规范·第20章全吸收）

竖屏不是横屏裁切——**横向空间压缩、纵深主导**，构图法则整体换轨：

**CL-16a 竖屏十法则**：
1. **纵深构图**：人物沿纵深轴线站位，前景/中景/背景三层分层，纵深主导、横向压缩
2. **上下正反打**：A 画面上部、B 画面下部，视线上下相交，机位上下镜像（竖屏替代左右正反打）
3. **竖向重复**：竖向排列元素强化垂直节奏（灯柱/栏杆/人群成列），人物与竖向元素呼应
4. **重心迁移**：焦点重心置于上/中/下段——上段=权力压迫、中段=对话焦点、下段=脆弱落地
5. **景别重心**：特写焦点在**眼睛与手部之间**；全景主体置垂直三分交点
6. **安全区**：底部 15% 留安全区、顶部 10% 留安全区，肢体与关键信息在安全区内，预留字幕位
7. **运镜竖屏化**：横移改纵深推拉、横向摇改上下摇、环绕改纵深环绕——运镜贴合画幅
8. **纵向排布**：多人自上而下纵向排列 + 前后纵深辅助，阵列沿垂直轴展开
9. **色彩通式**：全片饱和度/明度统一，高饱和主色块用于焦点人物区分
10. **五官优先表演**：微表情清晰、肢体动作辅助、情绪靠面部传达、近景占比高

**CL-16b 横屏→竖屏转换对照**：

| 法则 | 横屏逻辑 | 竖屏转换式 |
|------|----------|------------|
| 纵深转向 | 左右交代 | 前后纵深交代 |
| 上下正反打 | 左右镜像 | 上下镜像 |
| 竖向重复 | 水平重复 | 竖向重复节奏 |
| 重心迁移 | 左右重心 | 上中下重心 |
| 景别重心 | 眼睛焦点 | 眼睛+手部焦点 |
| 安全区 | 四边留白 | 底15%顶10% |
| 运镜转换 | 横移/摇镜 | 推拉/上下摇 |
| 纵向排布 | 横向阵列 | 纵向阵列 |
| 色彩通式 | 统一基线 | 高饱和焦点色块 |
| 表演语法 | 肢体优先 | 五官优先 |

**规则 CL-16**：竖屏镜头逐镜过十法则检查（纵深/正反打/竖向/重心/景别/安全区/运镜/排布/色彩/表演）；信息流前 5 秒设焦点、字幕预留；竖屏安全检查清单=纵深主导、上下正反打、竖向重复、重心分段、景别贴合、安全区合规、运镜竖屏化、纵向排布、色彩一致、五官优先。
