每个条目都包含：

**图像生成的提示词句式：**
```

```

## 距离与大小——景别构图

这些景别控制主体在画面中占据多少空间、
以及可见多少环境。请根据图像要表现的
是世界、角色还是细节来选择。

### 大远景（Extreme Wide Shot, EWS）
**AI 提示词关键词：**大远景（EWS）、辽阔（Vast）、风景（Landscape）
**定义：**主体几乎不可见；强调辽阔的风景或地点。
**用途：**营造辽阔感、表现孤立，或强调尺度。
**提示词示例：**
```
大远景：[img 1] 孤身一人站在辽阔而空旷的冰冻苔原上。
主体在远处显得很小，四周环绕着巍峨的雪山。
电影感灯光
```

---

### 全景（Wide Shot, WS）/ 远景（Long Shot）
**AI 提示词关键词：**全景（Wide Shot）、全身（Full Body）
**定义：**在环境中展示主体的全身。
**用途：**提供环境背景与空间感。
**提示词示例：**
```
全景：[img 1] 在暴风雪中全身站立。她身穿皮毛铠甲，
靴子可见，位于雪林空地的中央。交代环境背景。
```

---

### 全身镜头（Full Shot）
**AI 提示词关键词：**全身镜头（Full Shot）、取景（Framed）
**定义：**从头顶到脚尖取景主体，同时让主体占据更多画面。
**用途：**在角色细节与环境之间取得平衡。
**提示词示例：**
```
全身镜头：[img 1] 从头到脚的全身画面。她自信地站在雪中，
手握武器垂在身侧。精细的服装设计
```

---

### 中远景（Medium Long Shot, MLS）
**AI 提示词关键词：**中远景（Medium Long Shot）
**定义：**从膝盖以上取景主体。
**用途：**适合表现动作或对话的自然取景。
**提示词示例：**
```
中远景：[img 1] 从膝盖以上的取景。她正走过
深雪，望向地平线。3/4 侧面视角。
```

---

### 牛仔镜头（Cowboy Shot）
**AI 提示词关键词：**牛仔镜头（Cowboy Shot）
**定义：**从大腿中段以上取景主体。
**用途：**强调姿态、戒备状态或动作感。
**提示词示例：**
```
牛仔镜头：[img 1] 从大腿中段以上的取景。聚焦她搭在
腰带上的双手、自信的站姿，背景是带有柔和焦外虚化的雪景。
```

---

### 中景（Medium Shot, MS）
**AI 提示词关键词：**中景（Medium Shot）
**定义：**从腰部以上取景主体。
**用途：**情绪与形体兼顾的均衡取景。
**提示词示例：**
```
中景：[img 1] 从腰部以上的画面。她神情严肃，
直视镜头。雪花在前景中飘落。
```

---

### 中近景（Medium Close-Up, MCU）
**AI 提示词关键词：**中近景（MCU）
**定义：**从胸部或肩部以上取景主体。
**用途：**建立情感连接而不过分强烈。
**提示词示例：**
```
中近景：[img 1] 从胸部以上的取景。聚焦她的面部与皮毛领。
风吹动她的编发。亲密而富有戏剧感
```

---

### 特写（Close-Up, CU）
**AI 提示词关键词：**特写（Close-Up）
**定义：**对面部或关键细节的紧凑取景。
**用途：**突出情绪或细节。
**提示词示例：**
```
特写：[img 1]，只取她的头部与颈部。她锐利的眼神
直望镜头。寒冷的空气中可见呼出的白气。
```

---

### 大特写（Extreme Close-Up, ECU）
**AI 提示词关键词：**大特写（ECU）
**定义：**聚焦非常细小的细节。
**用途：**强化紧张感或亲密感。
**提示词示例：**
```
大特写：对准 [img 1] 的双眼。虹膜的微距细节，
睫毛上挂着的雪花，战绘涂料的纹理。凌厉的目光
```

---

### 微距镜头（Macro Shot）
**AI 提示词关键词：**微距（Macro）
**定义：**展现细腻纹理的超近距镜头。
**用途：**强调细节与质感。
**提示词示例：**
```
微距：[img 1] 的皮毛铠甲纹理与她皮肤上的霜。
雪花晶体的微观细节与皮革的纹理
```

## 机位角度

这些角度控制摄影机与主体之间的垂直与空间关系。
角度的选择会显著改变图像的情绪解读。

### 平视（Eye-Level）
**AI 提示词关键词：**平视（Eye-Level）
**定义：**摄影机与主体的眼睛齐平。
**用途：**中性、写实的视角。
**提示词示例：**
```
平视镜头：[img 1] 面对镜头。中性视角，
雪地中写实纪录片风格的人像。
```

---

### 仰拍（Low Angle）
**AI 提示词关键词：**仰拍（Low Angle）
**定义：**摄影机从下往上仰视主体。
**用途：**传达力量感或支配感。
**提示词示例：**
```
仰拍镜头：从下往上仰望 [img 1]。她在镜头前巍然耸立，
在暴风雨的天空下显得强大而有支配力。
```

---

### 俯视（High Angle）
**AI 提示词关键词：**俯视（High Angle）
**定义：**摄影机从上往下俯视主体。
**用途：**传达脆弱感或渺小感。
**提示词示例：**
```
俯视镜头：从上往下俯瞰 [img 1]。她抬头望向镜头，
雪花落在她的脸上。脆弱的视角。
```

---

### 顶摄（Overhead）/ 鸟瞰视角（Bird's Eye View）
**AI 提示词关键词：**顶摄（Overhead）
**定义：**从正上方拍摄。
**用途：**抽象或全局策略性的视角。
**提示词示例：**
```
正上方顶摄鸟瞰：[img 1] 站立在雪中。自上而下的角度，
展现她的影子在白色地面上延伸。
```

---

### 虫瞰视角（Worm's Eye View）
**AI 提示词关键词：**虫瞰（Worm's Eye）
**定义：**从地面高度垂直向上拍摄。
**用途：**极致的力量感或超现实的尺度。
**提示词示例：**
```
虫瞰视角：从地面向上仰视 [img 1] 的靴子与双腿，
她的脸在天空深处显得遥远。蚁人视角
```

---

### 荷兰角（Dutch Angle）/ 斜角（Canted Angle）
**AI 提示词关键词：**荷兰角（Dutch Angle）、斜角（Canted Angle）
**定义：**摄影机向一侧倾斜（地平线倾斜）。
**用途：**营造不安、迷失方向感或混乱感。
**提示词示例：**
```
荷兰角镜头：[img 1]，地平线倾斜。令人迷失方向且混乱的
氛围，备战姿势，充满动感的构图
```

---

### 过肩镜头（Over-the-Shoulder, OTS）
**AI 提示词关键词：**过肩（Over-the-Shoulder）、OTS
**定义：**越过一个人的肩膀看向另一个人。
**用途：**对话场景必备，为对话提供真实的空间依托。
**提示词示例：**
```
过肩镜头：越过前景中一个虚化的维京战士，
聚焦正回望他们的 [img 1]。
```

---

### 主观视角（Point of View, POV）
**AI 提示词关键词：**主观视角（POV）、第一人称视角（First Person Perspective）
**定义：**摄影机*就是*角色的双眼。
**用途：**观众亲历角色所见，沉浸感极强。
**提示词示例：**
```
第一人称主观视角镜头：某人正走向 [img 1]。她直视着
观看者，伸出手仿佛在向镜头致意。
```

---

### 自拍角度（Selfie Angle）
**AI 提示词关键词：**自拍角度（Selfie Angle）、一臂距离（Arm's Length）
**定义：**稍高的角度、一臂距离、面向主体。
**用途：**社交媒体审美中常见，非正式、亲近。
**提示词示例：**
```
手持自拍角度：[img 1] 望向镜头，手臂前伸。
随性的 vlog 风格，紧贴背景的雪山。
```

---

### 贴地（Ground Level）
**AI 提示词关键词：**贴地（Ground Level）、表面视角（Surface View）
**定义：**摄影机直接贴放在地面/表面上，常配浅景深。
**用途：**对地面或环境的沉浸式近拍。
**提示词示例：**
```
贴地镜头：摄影机搁置在雪面上。浅景深，
前景是雪晶体，[img 1] 在背景中行走。
```

## 镜头运动（在静帧图像中暗示）

对于图像生成而言，镜头运动关键词在单帧中营造运动的*感觉*——
动态模糊、暗示运动的构图，
或运动中途凝固的瞬间。

### 静态/基础（Static / Basic）

| 运动 | AI 关键词 | 定义 | 用途 | 提示词示例 |
|----------|-----------|------------|---------|----------------|
| 固定镜头（Static Shot） | 固定（Static） | 摄影机不动 | 稳定与聚焦 | "固定机位镜头：[img 1]。她纹丝不动地站立，周围大雪纷飞，风吹动她的头发。三脚架拍摄。" |
| 左右横摇（Pan Left/Right） | 横摇（Pan） | 摄影机水平旋转 | 揭示或跟随动作 | "镜头从左向右缓慢横摇，从一棵覆雪的树开始，逐渐展现出站在远处的 [img 1]。" |

## 景别 + 角度 + 运动的组合

最强的图像提示词会将三者全部叠加：

**句式：**`[距离/大小] + [角度] + [运动暗示] + [主体] + [环境] + [光线]`

**示例：**

```
仰拍中近景：[img 1]，镜头缓慢推轨变焦推近。
在血红色夕阳的映衬下，她在画面中巍然耸立，风掀起她的斗篷。
电影感灯光，高对比度。
```

```
顶摄大远景，固定机位。[img 1] 是广阔冰封湖面中心的
一个小小身影，她的影子拉得很长。蓝调时刻光线，荒凉。
```

```
贴地特写，焦点转移。前景中雪晶体清晰锐利，
[img 1] 的靴子在雪晶体后虚化，随后焦点转移到她低头俯视的面部。
浅景深，冷蓝色调。
```

```
荷兰角牛仔镜头，手持质感。[img 1] 以大腿中段以上的取景
站在燃烧的村庄中，地平线倾斜，烟雾盘旋。她脸上绘着战绘，
武器出鞘。混乱而紧迫的构图。
```

## 图像提示词公式（用于电影感静帧）

```
[景别大小] + [角度] + [运动关键词] + [img 1 / 角色描述]。
[姿势、表情或动作]。
[环境——地点、天气、氛围]。
[光线——一天中的时间、光源、质感]。
[风格——电影感、胶片类型、调色]。
```

**完整示例：**
```
中近景，仰拍，缓慢推轨推近 [img 1]。
她目光越过镜头凝视远方，双眼微眯，下颌紧绷，辫子垂落在
一侧肩头。她身后是一片冰封的战场，远处的火焰升起浓烟。
黄金时刻的逆光勾勒出她的剪影。
风格：电影感，Kodak Vision3 500T，去饱和的青色阴影，暖色高光。
```
