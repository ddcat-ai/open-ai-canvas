# 灯光·纯技术文档
（灯光方案、场景物理布光、夜景与频闪寄存、光效整合）

**总纲：四条灯光纪律。**

1. **点名光源，不点名情绪。**"有情绪的""戏剧化的""电影感的"只能被模型近似；被点名的物理机制才能被一致地渲染。单靠"低调布光"不够——它只说了有多暗，没说光从哪里来。
2. **光是场景中的物理事件。**说明光源位置、它从哪些表面反射、由此形成的阴影几何——模型用每一个被点名的要素，在各镜头之间一致地重建照明。
3. **相邻镜头没有共同的起点观感。**每条生成素材都自带出厂调色，所以灯光与调色的统一是后期第一要务——跨镜头的灯光语言要靠逐字重复与全局前缀锁定。
4. **整合时超出色彩层面。**把主体坐进新世界，只做色彩匹配是最常见的"像贴上去的"失败——主光方向、环境反光、大气、边缘落地要一起匹配。

| 蓝调时刻 | 冷调、柔和，日落后不久的钢蓝色环境光 | 忧郁、过渡、静谧张力、都市孤独 |

| 伦勃朗光 | 暗侧脸颊上的一块三角形光斑，一只眼睛被照亮 | 人物剧情、角色出场、情绪化访谈 |
| 蝶形光 / 派拉蒙光 | 头顶正上方光，鼻子正下方投下阴影 | 魅力人像、时尚、美妆、经典好莱坞 |
| 分割光 | 半脸受光，半脸完全沉入阴影 | 双重性、内心冲突、反派揭示 |

| 低调 | 深阴影占主导，只有小片光区 | 黑色电影、惊悚、恐怖、心理张力 |
| 正午烈日 | 顶光硬光，轮廓分明的浓重阴影 | 沙漠、对峙、暴露无遗的脆弱感 |

# 二、场景物理灯光（四要素）

把灯光描述为场景中的一个物理事件，说明四类要素——它们可组合、可命名，跨镜头可复现：

- **光源位置** —— "主光来自画面左侧，高于视线约 30°"
- **反射 / 回弹** —— "木地板反射的暖光回弹，抬亮下颌下方的阴影"
- **阴影几何** —— "画面右侧墙上的硬影，呈现出台灯的剪影"
- **环境密度** —— "前景浓密的环境霾，把距摄影机 6 米以外的对比度柔化"

**把时段与主光方向说具体**（"柔和的漫射正午日光，主光来自画面右侧"）。**"更柔"意味着更大、更漫射的光源**：柔和的软边阴影、低反差、平滑的高光滚降、轻微的霾——而不是一句"柔光"了事。

# 三、夜景寄存

平铺直叙地提示"夜晚"，回来的是**亮夜（bright-night）**——一个被均匀照亮的场景罩着蓝青色调，那是日景底板调成冷调的样子，不是夜的样子。剧场式夜景是**大部分漆黑，硬朗的实用光源从中切过**。夜景语域分成两支，分野在于**允许什么充当光源**（此处未经验证）：

**A. 外景 / 开阔夜**（峡谷公路、荒僻外景、任何没有建成照明的地方）。光**只来自场景中的实用光源**——车头灯、刹车灯、从打开的车门漏出的仪表盘光、远处的城市光晕。**没有环境月光，没有环境天光提升。**天空与四周陷入深、压实的近黑。空气中的霾接住光束，形成可见的体积光柱；反向散射只照亮车辆的正前方和它正前方的地面。光锥之外的一切都落到近黑，于是主体主要作为剪影被读取，由它们的光源界定前缘。极远处可以有一道微弱的地平线光晕——很小、收敛、勉强读得出是远方的文明，而且**永远不足以照亮**前景或中景中的任何东西。

**B. 内景 / 城市夜**（车库、仓库、街道、木屋）。实用光源依旧主导观感——钠蒸气灯、荧光灯、霓虹、仪表盘光、刹车灯。**青–琥珀的分裂在这里是合法的**，正因为是实用光源给了它动机：冷调的钠灯与荧光，对照暖调的仪表盘光与琥珀色。没有动机的版本——青色调浇满一切而画面内没有光源——读出来是调色，而不是场景。

# 四、频闪

频闪照明的场景，需要把脉冲描述为一个**事件**而不是一个形容词，并把三件事一起说明，否则它读起来像坏掉的素材：

1. **脉冲本身**——硬亮、硬灭，按一个给定的 BPM 进行，偶发双连和三连的抽动串。每次闪光瞬时而炽亮，把场景在运动中途清晰地定格呈现；每个间隔跌入近乎全黑。没有渐变——每一次过渡都是硬碰硬的骤变。
2. **一盏次级光源**，在两次闪光之间维持微弱的常亮，让形体在黑暗中保持可读，而不是画面彻底归零。
3. **一条连续运动条款**——"两次闪光之间没有任何东西被冻结、停驻或静止；每一具身体始终处于连续运动之中，让它们停下的只是光。"没有这一条，模型会把身体渲染成真的停住了——这正是频闪与卡顿的区别。

> **逐拍的光脉冲会造成观感卡顿。**若收到输出卡顿的报告，先把脉冲柔化为缓慢连续的涌动；若仍然存在，去掉脉冲，改为恒定。脉冲通常才是原因，而不是帧率。

# 六、题材默认布光

题材影响灯光默认与调色基线——**题材只是起点，随时可用显式提示词语言覆盖**：

| 题材 | 灯光默认 | 色彩倾向 |
|-------|-----------------|--------------|
| 通用 | 中性 | 均衡 |
| 动作 | 硬光、高对比 | 降饱和、冷 |
| 恐怖 | 低调光、硬阴影 | 降饱和、青/绿色偏 |
| 喜剧 | 明亮、均匀 | 暖、饱和 |
| 西部 | 黄金时刻 / 风尘 | 暖琥珀 |
| 悬疑 | 低调光、有动机 | 冷、收敛 |
| 亲密 | 柔、暖 | 暖、显肤质 |
| 奇观 | 戏剧性、高对比 | 大胆、饱和 |

# 七、风格前缀里的灯光教义与逐场景覆盖

连通分镜清单中，灯光教义住在**全局风格前缀**里，一次写好、逐字前置到每条提示词：

```
灯光（Lighting）：[仅自然光——柔和、均匀的晨间日光，全程淡淡的空气薄雾。
主光只来自天空和窗户。无人造光。]
```

配套的色彩纪律：`色彩（Color）：[60:30:10]——主导 / 次要 / 点缀。`

单个场景需要打破全局观感时，用**逐场景覆盖**——只替换那一条提示词的前缀灯光行，其他所有场景保持全局前缀：

```
灯光（Lighting）：仅自然光——明亮、真正晴朗的正午，来自高处和正前方的
强烈直射阳光（太阳在被摄主体的前方和上方、镜头后方），深蓝天空，
轮廓利落的硬边阴影，鲜艳饱和的色彩，低薄雾。
```

**时间维度的保留手法**：在一套灰调调色里，唯一的高光时刻可以为剧情而保留（"黄金时刻为反转而保留；它之前的所有画面都保持平坦中性"）——把这种保留明确陈述出来。

# 八、光效整合——把主体坐进新世界

视频转视频、素材变换、生物合成时，只做色彩匹配**不足以**让被保留的主体坐进新世界——这是最常见的"像贴上去的（pasted-in）"失败。

## 8.1 先定分岔——它改变一切

- **保留主体的光，只给新元素打光调色。**锁住主体原有的光；给新增的生物/环境打光并调色，去匹配主体上已有的主光，使二者整合。身份风险最低。
- **在统一外观下给全画面重新打光。**主体包括在内。用于统一的影院感/广告级调色。对面孔风险更高，所以要显式锁住身份/表情/着装，只让光与调色变。

## 8.2 四层整合配方（超出色彩层面）

- **光：**相同的主光（key）方向（点名——画面左还是画面右）、相同的软硬、主体上相同的阴影密度与方向。（"保持太阳仍是画面左侧的主光，与之前完全一致，让面孔及其上的光几乎不变。"）
- **环境反光（environmental bounce）：**让世界洒到主体上——来自上方的冷天光、来自被阳光照亮的地面/植被的暖反光、形体相交处的轻微环境光遮蔽（ambient occlusion）。
- **光学与大气：**匹配镜头特性与微对比；给主体加一点场景的大气霾（haze）与空气透视（aerial perspective），使其不至于在霾蒙蒙的背景前反常地锐利；把景深、焦点衰减与胶片颗粒匹配到画面其余部分。
- **边缘与落地（edges & grounding）：**去掉生硬的抠像边缘、光晕（halo）与不匹配的轮廓光；用可信的纵深把主体落到实处，使其与周围占据同一空间。

## 8.3 写实生物 / 元素整合的灯光要点

- 把它**系进底板**：与主体相同的太阳方向与色温，在它接触之处投下一道真实的软边接触阴影，与远处背景相同的霾与纵深。
- **把尺寸卖出来**：用画面内的参照物确立真实大小，配长焦镜头错觉与浅景深，让巨型生物被前景元素部分遮挡，再加一点运动模糊与手持的柔软感——融入而不是悬浮。
- 如果拍出来仍像 CG，可靠的修法是**第二路输入**——一张真实动物/材质的参考照片，声明为仅纹理参考。确切知道自己要什么时，给模型看胜过向模型描述。

# 九、色温与量化单位

- **白平衡用开尔文**，场景内固定：3200K（钨丝）/ 4000K / 5600K（日光）/ 8500K（浓荫天光）。
- **大气（霾/雾）用 % 和米**："雾密度 40%"、"雾霭在 15 米处可见"；跨镜头分步建立（20% → 40% → 60%）。
- **光源方向用角度与方位**："主光来自画面左侧，高于视线约 30°"。
- **左右永远以摄影机为准。**

# 十、灯光瑕疵速查

| 瑕疵 | 为什么会发生 | 预防措辞 |
|------|-------------|----------------|
| **过亮 / 平光** | 提示词没写灯光——模型默认均匀的通用布光 | 永远指定光源与光质："single side-light"（单一侧光）、"golden hour"（黄金时刻）、"practical only"（只用画面内实用光源） |
| **质感闪烁** | 跨帧灯光/风格描述不一致 | 锁定一个具名风格并逐字重复；绝不混用互相竞争的灯光语言 |
| **风格被无视 / 输出平庸** | 灯光描述太含糊或根本没写 | 确切的具名方案 + 具体调色："Style: Cinematic. Cold blue shadows, warm amber highlights, high contrast" |
| **调色不一致** | 同一序列各镜头的灯光/调色描述不同 | 把调色锁进全局前缀，或在每条提示词里逐字重复同一套灯光语言 |
| **产品镜头显廉价** | 没指定表面/背景，灯光通用 | 指定背景表面（"raw concrete" 素混凝土、"black velvet" 黑丝绒），加质感线索（"surface catches light on edges" 表面边缘吃光） |

完整的瑕疵成因与预防措辞总表见《负面约束预防总表》。
