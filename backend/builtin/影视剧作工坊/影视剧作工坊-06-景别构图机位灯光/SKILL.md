# 景别、构图、机位与灯光（模块 06）

> 主链定位：画面坐标系 / 空间约束与构图词汇 / V4 构图引擎 / 物理灯光与夜景语域。

## 核心原则（四件事各管一层）

- **景别** —— 控制主体在画面中占多大、可见多少环境。按"要表现的是世界、角色还是细节"来选。
- **机位角度** —— 控制摄影机与主体的垂直与空间关系。**角度就是情绪解读**：仰拍＝力量，俯视＝脆弱，荷兰角＝不安，虫瞰＝超现实。
- **构图** —— 三者的叠加与编排。最强的提示词把景别、角度、运动暗示（静帧）或镜头运动（视频）**全部点名**，再以光线与风格收尾。
- **灯光** —— 四条纪律：
  1. **点名光源，不点名情绪** —— "有情绪的""戏剧化的""电影感的"只能被模型近似；被点名的物理机制才能被一致地渲染。单靠"低调布光"不够——它只说了有多暗，没说光从哪里来。
  2. **光是场景中的物理事件** —— 说明光源位置、它从哪些表面反射、由此形成的阴影几何。
  3. **相邻镜头没有共同的起点观感** —— 每条生成素材都自带出厂调色，跨镜头的灯光统一靠逐字重复与全局前缀锁定。
  4. **整合时超出色彩层面** —— 只做色彩匹配是最常见的"像贴上去的"失败；主光方向、环境反光、大气、边缘落地要一起匹配。

**术语约定**：`[img 1]` 与 `@Image1` 均指"第一张参考图"；未使用参考图时替换为角色描述或 @ 元素引用。静帧与视频的差异处已分别标注。

## 执行流程（决定一个镜头的画面）

1. **先定景别** → `01`
   按"要表现世界 / 角色 / 细节"选景别；视频侧查补充规则；必要时用 FOV 锚点锁定视场角。
2. **再定机位角度** → `02`
   按"要观众感受到什么情绪"选角度——角度即情绪解读，不是构图偏好。
3. **编排构图** → `03`
   用三要素叠加公式（景别 + 角度 + 运动暗示/镜头运动）组句，再定画幅比例。**空间关系必须写成可测量语言**，不用"有点偏左"这类模糊词。
   **画幅两条不可混为一谈：**输出比例走头部字段枚举值（16:9 / 9:16 / 2.35:1…）；变形宽银幕遮幅观感写进风格行——"16:9 变形宽银幕"是自相矛盾的提示词。
4. **锁空间** → `07`
   先写**每场景一份的 GEO 空间布局块**（只写场所、含 180° 轴线、逐字粘进该场景每个镜头），再写**每镜头一份的空间布局块**（含人物位置与朝向）；场景开头留 1 秒**定场 wide**，并以**角色计数头**开头（`EXACT 3 CHARACTERS — NO DUPLICATES`）。**模型不继承上一镜的任何空间信息**——跨镜头必须成立的关系全部显式声明。
5. **定点光源** → `04`
   按四条纪律写：点名光源类型、方向、反射面、阴影几何、光比、色温，**不写情绪形容词**；查 18 种方案总表与六大预设；夜景走夜景寄存规则；要把主体合成进另一个世界时按光效整合四层配方（主光方向 / 环境反光 / 大气 / 边缘落地）匹配；最后过灯光瑕疵速查。
6. **查引擎与焦距** → `05` / `06`
   需要校验衔接与场面调度（轴线/视线/动作/景别过渡）时查 `05` 的 CL-4 / CL-4a；需要把景别落成具体焦距时查 `06`。
7. **交下游**：镜头运动的英文预设名 → 08 运镜设计（`moves/09-镜头运动预设库.md`）；跨镜头的空间重锚定与出画规则 → 10（`editing/05-剪辑与连续性词汇.md`）。

## 硬规则速记

- 景别 / 角度 / 构图三层各自独立决定，不要混为一谈。
- 角度即情绪：仰＝力量、俯＝脆弱、荷兰角＝不安、虫瞰＝超现实。
- 构图三要素全部点名（景别 + 角度 + 运动），最后以光线与风格收尾。
- **灯光只点名物理机制，不点名情绪。**
- 空间与构图用可测量语言，禁止模糊方位词。
- **左右永远以摄影机为准**（frame-left / frame-right），位置用地标 + 米数，禁"旁边""附近"。
- **GEO 每场景一份、只写场所、逐字粘进该场景每个镜头**；空间布局块每镜头一份、含人物。**模型不继承上一镜的任何空间信息。**
- 场景开头必有 1 秒**定场 wide** + **角色计数头**——去掉它，角色就开始互换位置。
- **输出比例 ≠ 变形宽银幕观感**：前者是头部字段枚举值，后者是风格行；两者不可写在同一个从句里。
- 焦距按 35mm 全画幅基准换算，保持传感器尺寸固定。
- **机位角度的边界**：本模块是镜头语言与情绪的主责（仰拍＝力量、俯视＝脆弱）。04 的 `scenes/04-场景取景视角` 讲场景空间呈现，语义相邻；**重叠时以本模块为准**。
