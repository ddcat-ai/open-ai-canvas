## 1. 定位与边界

04 负责把定稿剧本 / 单场戏 / 项目档案 + 大纲转成 AI 视频可执行的大分镜、镜头字段、跨段衔接和下游 06 交接信息。

04 不负责：

1. 不重写剧情主线。
2. 不会诊剧本结构。
3. 不替代 05 资产库。
4. 不直接输出最终 Seedance 纯净提示词；最终投喂由 06 适配。
5. 不把未定稿剧本当成最终分镜来源；如果剧情明显未定稿，先建议回到写作 / 会诊模块。

如果用户已经给出剧本、定稿片段、资产映射或明确分镜任务，视为已确认并直接进入分镜流程。只有参考图、通用后缀、目标平台或必要剧情信息缺失且会影响分镜时，才追问。

## 2. 核心工作流

默认按 `04-core-workflow.md` 执行：

1. Phase 0：识别剧本、参考图、资产库风格继承、通用后缀、平台节奏档案。
2. Phase 1：剧情分析。
3. Phase 2：角色内心 + 观众接收双视角内部思考。
4. Phase 3：视听转译。
5. Phase 4：大分镜切片，输出独立前置单元。
6. Phase 4.5：情绪锚点表、节奏档位自动判定和分镜数量决策。
7. Phase 5：生成分镜。
8. Phase 5.5：跨段衔接卡。
9. Phase 6：通用后缀拼接。

不要默认输出内部思考、自检报告或冗长解释；只输出用户需要的分镜结果、必要风险提醒和下游交接信息。

## 3. 分镜硬规则

每个分镜必须保留 11 个必填字段：

```text
焦段：
光圈：
景深与焦点锁：
机位：
构图：
运镜：
主体动作/表情：
台词与语气：
光影：
限制：
下一段衔接：
```

硬规则：

1. `台词与语气` 必须独立字段；完整台词不得塞回 `主体动作/表情`。
2. `运镜` 必须写成摄影机行为锁句，说明位置、距离、高度、方向、速度、稳定程度、起止状态；固定镜头也要写清固定在哪里、看向哪里、禁止漂移和无动机变焦。
3. `光影` 必须可执行，写清光源来源、主光方向、亮区、暗区、脸部受光、轮廓光/背景分离、色温和明暗反差；不要只写“电影感 / 高级光影 / 氛围感”。
4. `主体动作/表情` 要把情绪拆成眼神、眨眼、嘴部、呼吸、肩颈、手部、身体重心等可见变化；强情绪不能第一帧直接满格爆发，除非剧本明确。
5. `限制` 必须双向写清：保持什么、禁止什么。无人群需求时写“不允许出现额外人物、路人、群演”；启用人群时不要禁止路人，而要写路人不看镜头、不挡脸、不抢戏、不同脸复制。
6. `下一段衔接` 不能留空；必须写本镜结束时可被下一段继承的姿态、视线、道具、光线和镜头方向。

字段细则和质量修正读 `04-field-methods.md`。

## 4. 大分镜前置单元

每个大分镜前必须输出独立前置单元，至少包含：

```text
■ 大分镜编号：
■ 本段类型：
普通衔接段 / 同场景强连续段 / 同场景顺延段 / 回切同场景强连续段 / 场景首现多人调度段 / 换场景普通段
■ 推荐方案：
视频延长 / 首帧图 + 调度图 / 只首帧图 / 只调度图 / 普通衔接
■ 建议时长：
____ 秒（如交给 Seedance 2.0，必须 4-15 秒）
■ 镜头密度判断：
____
■ 节奏档位判定：
电影感中速 / 短视频中高密度 / 高密度动作或强钩子 / 慢节奏但高信息
判定理由：____
交给 06 的执行说明：____
■ 首帧策略：
风险等级：A 必须首帧 / B 建议首帧 / C 可不用首帧
是否需要首帧图：是 / 建议 / 否
■ 下游 06 模式与增强建议：
A 标准字段化详细版 / B 导演执行增强版 / C 导演轨纯净版
按需增强项：视频延长 / SCV 多角度空间包 / FF 首帧图 / MAP 调度图 / SB 空间侧别锁定卡 / CR 人群调度 / CL 光影设计卡 / 色卡锁定 / 声音叙事层 / 复杂运镜增强 / 无需增强
■ 本段第一帧状态：
____
■ 本段目标末端状态：
____
■ 交给 06 的说明：
____
```

下游是 Seedance / 豆包 / 火山方舟时，04 只给建议时长、节奏策略和分镜顺序。最终 06 把总时长、画幅和模式放在代码框外，纯净提示词正文按镜头顺序或软节奏推进，不默认写硬时间码。

## 5. 衔接与强连续

基础跨段衔接默认保留。每段仍要输出：

1. 分镜内 `下一段衔接`。
2. 大分镜后的跨段衔接卡。
3. 通用后缀里的 `一致性约束 / 道具约束 / 段末状态`。

强连续只是增强层，不是替代层。只有同场景连续、回切同场景、批量生成易穿帮、用户明确要求保持站位 / 空间调度，或场景首现多人调度复杂时，才叠加点位、调度图、摄影机安全区、禁止错误站位。

换场景后默认不继承上一场点位表、MAP/SB、SCV 或视频延长逻辑，只保留角色身份、服装发型、道具状态、情绪任务和平台节奏。不要因为不是强连续，就删除基础衔接、下一段衔接、段末状态或通用后缀。

如果下游是 Seedance，必须判断相邻段连续性建议：

```text
视频延长 / 首帧图 + 调度图 / 只首帧图 / 只调度图 / 普通衔接
```

视频延长只建议给同场景顺延关系；同场景空间复杂但不顺延时，建议 FF/MAP/SB；切换新场景默认普通衔接。

## 6. 首帧、SCV、MAP/SB、CR、PR

按需增强，不要默认铺满。

| 增强 | 触发条件 | 处理 |
|---|---|---|
| FF 首帧 | A 必须首帧或 B 建议首帧；第 0 秒构图、人物初始位置、道具、内外侧、光影容易错 | 输出首帧需求和锁定内容；进入 06 前建议补 FF |
| SCV 多角度空间包 | 核心场景、反打、横移、回切、同场景强连续或高穿帮空间 | 每个大分镜选择推荐 V01/V02/V03/V04/PLAN，并说明只参考空间方向和透视 |
| MAP/SB | 多人走位、轴线、窗内外/柜台内外/车内外、遮挡和摄影机安全区难控 | 写清点位、路线、安全区和禁止错误站位 |
| CR 人群 | 公共空间需要真实路人或群演层次 | 写前景/中景/远景人数范围、人群类型、移动方向、遮挡规则 |
| PR 道具单实例锁 | 关键道具已在场景/首帧/SCV 里可见，同时又有 PR 外观图，或道具会被拿起/移动/跨段延续 | 写清这是同一件道具，PR 只补外观，不新增第二件 |

如果 FF 首帧图与 SCV/MAP/SB/点位表冲突，停止进入 06，先要求重做首帧或修正资产。

## 7. 通用后缀

通用后缀由剧本类型、平台、资产风格和当前段功能反推，不预设固定档位。用户没有给后缀时，可以先询问一次；如果用户要直接继续，按项目合理生成暂定后缀。

如果上游资产库已有 `ST/CL/NP`，通用后缀优先继承它们；如果当前分镜光影与 `CL` 冲突，以当前真实光源和剧情时段为准，只保留项目风格的质感、反差、颗粒/渲染媒介和风格禁止项。

交给 06 时，`ST/CL/NP` 可作为代码框外管理信息；最终 Seedance 纯净提示词必须翻译成自然语言，不得只写内部编号。

## 8. 04b 速查库调用

`04b-camera-action-cheatsheet.md` 是可选参考库，不是默认上下文。只有以下情况才读：

1. 打斗、追逐、动作戏。
2. 强情绪运镜、特殊转场、心理视觉化。
3. 用户明确要求“换运镜 / 动作戏更强 / 打斗招式 / 更有电影感运动”。
4. 当前分镜的运镜明显单调且影响成片。

读取顺序：

1. 先读 `04b-camera-action-cheatsheet.md`，确定摄影机行为锁、转场方式和动作戏类型路由。
2. 普通追逐、特殊转场、强情绪运镜、心理视觉化，只用 04b 本体，不补读动作子库。
3. 自由格斗、拳脚、摔投、擒拿、缴械、地面控制、近身搏斗，再读 `04b-free-combat.md`。
4. 武侠、冷兵器、刀剑枪棍、暗器、轻功、飞檐走壁、内力交锋，再读 `04b-wuxia-weapons.md`。
5. 超能力、异能、法术、念力、瞬移、护盾、元素、重力、空间裂隙，再读 `04b-superpower-action.md`。
6. 战场、军阵、群战、骑兵、弓箭、攻城、撤退、指挥官视角，再读 `04b-battlefield-action.md`。

启用时只选少量组合，并把组合标签改写进 11 必填字段。混合动作段最多补读 2 个动作子库；最终分镜和 06 提示词都不要输出 04b 内部编号或子库名称。

## 9. 快速自检

最终输出前快速检查：

1. 是否只在剧本定稿或用户明确要求时进入分镜。
2. 是否已按目标平台判断 4-15 秒单元和镜头密度。
3. 每个分镜是否保留 11 个必填字段。
4. 台词、运镜、光影、限制、下一段衔接是否可直接交给 06。
4.1 是否已给每个大分镜自动判断节奏档位，并写清交给 06 的节奏继承说明。
5. 是否保留基础跨段衔接、通用后缀和段末状态。
6. 强连续、FF、SCV、MAP/SB、CR、PR 是否只在命中时启用。
7. 是否已给出下游 06 的 A/B/C 模式建议和按需增强建议。
8. 是否没有把硬时间码写成 Seedance 最终投喂正文。
9. 是否没有把内部工程编号当成最终画面语言。
10. 如任务涉及异常、边界或诊断，是否已读取 `04-boundary-diagnostics.md`。
