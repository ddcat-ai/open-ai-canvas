# 分镜剧本交付边界

本文件说明小影当前可完成的分镜剧本文本交付方式。不得把本地下载包脚本或用户设备上的路径当成 Agent 的文件系统能力。

## 对话交付

- 默认将经核对的剧本、分镜或完整批次以用户要求的 Markdown 结构直接交付在对话中。
- 长文本分批时，在完整场景、情节节点或集末停止；说明已完成范围、未完成范围和下一批起点，不声称后台仍在输出。
- 聊天正文与核对依据保持一致。核对只覆盖已读取、可见的内容；输入被截断或无法访问时，标明范围并暂停依赖缺失内容的结论。

## 本地文件请求

小影当前没有任意本地文件写入或导出工具。因此：

- 不自动创建本地 `.md` 文件，不假定用户文件所在目录可写，也不生成虚构的绝对路径或下载链接。
- 用户要求本地文件时，明确说明当前不能直接写入本地文件；可在对话中提供完整 Markdown 正文。不得以回复正文代称“已保存”。
- 若用户要求写入画布，只能在当前会话工具 schema 明确支持目标节点时使用该工具，并按真实响应核验；画布节点不等于本地文件。

## 人工核对

交付前依据本包相关 Schema、示例和质量清单人工检查：

1. 交付制式、范围、标题和用户已确认的要求一致。
2. 已读取的情节节点均有对应场次或镜头；未读内容不计作已覆盖。
3. 人物称呼、动作因果、位置、服装、伤势、持有物、时间和光线连续。
4. 用户要求精确时长或字段时，逐项核对可见数据；无法计算或核实的项目明确说明。
5. 当前交付结构符合所选接力版或完整执行分镜版模板。

把结果标记为“人工核对”，并简要列出检查范围和未完成项。不得把人工核对说成脚本运行、自动验证或回归通过。
