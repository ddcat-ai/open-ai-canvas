# 动态漫剧本标准格式技能

> **落位说明**（并入影视剧作工坊时添加，正文保留原文）

## 核心能力

将用户提供的原始剧本（故事梗概、对白、场景描述）转换为**标准动态漫剧本格式**。

## 输入信息清单

转换前请确认以下信息：

| 信息 | 说明 | 必填 |
|------|------|------|
| 剧本名称 | 动态漫标题 | ✅ |
| 集数 | 第X集 | ✅ |
| 主要角色 | 角色名及简要设定 | ✅ |
| 本集场景 | 涉及的场景列表 | ✅ |
| 世界观设定 | 与本集相关的核心规则/设定 | 可选 |
| 前置剧情 | 前情提要（1-3句话） | 可选 |
| 剧本内容 | 原始故事、对白、动作描述 | ✅ |

## 输出格式

严格按照以下结构输出：

```
═══════════════════════════════════════
【动态漫剧本标准格式】
═══════════════════════════════════════

一、剧本基础信息栏
剧名：《{剧本名称}》
集数：第{X}集
制作周期：____年____月____日

二、核心设定前置
1、角色设定
【角色名】角色描述（精简关键信息）

2、场景设定
【场景名】场景描述（涉及本期场景）

3、世界观补充
{单集关联设定}

二（前置剧情）：
{前情提要}

三、分镜脚本核心模块
【分镜01】
场景：{场景名称}
时间：{白天/夜晚}
人物：{出现角色}
镜头：{远景/全景/中景/近景/特写}
动作/画面描述：{画面内容详细描述}
台词/音效：
【角色名】{台词}
【环境】{环境音描述}
【动作】{动作音效描述}
【配乐】{配乐风格}({时长})
动态效果：【动・基础/中度/特效】
转场：（切/淡入/淡出/虚入/虚出/闪白/光斑转场）
备注：{补充说明}

【分镜02】
...以此类推

四、特殊标注规范
1. 动态效果分级
   【动・基础】画面元素轻微运动（呼吸起伏、光影闪烁）
   【动・中度】镜头运动+元素组合运动（推镜+人物行走）
   【动・特效】粒子效果、形变、场景转换（爆炸、幻象切换）

2. 转场类型
   （切）硬切 / （淡入/淡出）渐变 / （虚入/虚出）模糊转场 / （闪白/光斑转场）特效转场

3. 音效/配乐区分
   【环境】环境音（持续）
   【动作】动作音效（次数）
   【配乐】配乐风格+时长
   【角色名】台词

4. 字幕规范
   位置：画面下沿1/5区域（默认居中）
   样式：对话字幕（白色+黑描边）/ 旁白字幕（灰色+无描边）
   时长：朗读时长+0.5s

═══════════════════════════════════════
```

## 写作技巧模板

### 分镜脚本公式

**【镜头景别】+【主体动作】+【环境细节】+【光影氛围】+【转场方式】**

### 对白改编原则

- 精简对白，每句不超过20字
- 用括号标注情绪，例：（低声）、（愤怒地）
- 旁白用于补充画面无法表达的内心/背景信息

### 动态效果选择

| 效果等级 | 适用场景 | 标注 |
|----------|----------|------|
| 基础动态 | 呼吸起伏、光影变化、头发飘动 | 动・基础 |
| 中度动态 | 推拉镜头、人物行走、物体移动 | 动・中度 |
| 特效动态 | 爆炸、魔法、幻象切换、粒子效果 | 动・特效 |

### 转场选择

| 转场类型 | 效果 | 适用场景 |
|----------|------|----------|
| 硬切（切） | 无过渡直接切换 | 快速节奏、场景割裂 |
| 淡入/淡出 | 画面明暗过渡 | 章节开始/结束 |
| 虚入/虚出 | 模糊后清晰 | 回忆、梦境 |
| 闪白/光斑 | 特殊视觉过渡 | 魔法生效、情绪爆发 |

## 格式检查清单

输出后自动检查：
- [ ] 分镜序号连续（01,02,03...）
- [ ] 动态效果标注使用【动・基础/中度/特效】
- [ ] 转场标注使用（切/淡入/淡出/虚入/虚出/闪白/光斑转场）
- [ ] 音效区分【环境】【动作】【配乐】
- [ ] 台词标注角色名
- [ ] 备注中重要动态用"▲"标注
