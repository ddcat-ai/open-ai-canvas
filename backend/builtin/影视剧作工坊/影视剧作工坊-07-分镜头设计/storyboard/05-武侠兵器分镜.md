## 使用边界

- 适合：刀、剑、枪、棍、鞭、匕首、袖、暗器、轻功、踏墙、屋顶追逐、兵器格挡、内力对掌。
- 不适合：现代自由格斗的地面缠斗、大规模军阵、纯异能法术轰炸。
- 武侠动作要有“身法路径”和“兵器接触点”，不要只写“招式华丽”。
- 交给 04/06 时默认建议 `高密度动作或强钩子`；仪式感对峙、拔剑前的凝视、重要台词压迫可降为 `电影感中速`，但必须写清慢镜头功能。动作交接必须包含兵器路径、接触点、借力点、落点和段末站位。

## 兵器速查

| 类型 | 可写动作 | 运镜建议 |
|---|---|---|
| 剑 | 剑尖先点向喉前半寸，被对方剑脊横压偏开，剑锋擦出冷光 | 长焦中近景，焦点跟剑尖到眼神 |
| 刀 | 刀从肩后斜劈落下，对方横刀架住，刀背震得手腕下沉 | 低机位拍刀势，交击瞬间短震 |
| 枪 | 枪尖从远景直刺入前景，对手侧身避开，枪杆擦过衣摆 | 长焦压缩空间，保留枪尖轨迹 |
| 棍 | 棍尾扫向膝侧，对手跃起避开，落地用脚踩住棍身 | 广角中景保留脚步和棍身全长 |
| 鞭/软兵器 | 鞭梢绕过前景柱子抽向手腕，对手用剑缠住鞭身 | 横移跟随弧线，禁止软兵器形态乱变 |
| 匕首 | 袖中短刃贴身刺出，被对方扣住手腕停在衣襟前 | 近景手部和胸前距离必须清楚 |
| 袖/衣带 | 长袖卷住剑柄短暂牵制，另一手借力反掌逼退 | 侧拍袖布运动，禁止变成无来源绳索 |
| 暗器 | 指间银针一闪出手，目标偏头，暗器钉入身后木柱 | 暗器出手升格，落点必须可见 |

## 轻功与身法

| 类型 | 可写动作 | 限制 |
|---|---|---|
| 借力腾空 | 脚尖点上断柱边缘，身体斜向跃起，衣摆滞后一拍 | 起跳点、落点都要写清 |
| 踏墙转向 | 一脚踏墙借力，身体横向翻到对手背侧 | 不要无重力乱飞，必须有借力点 |
| 屋顶追逐 | 角色从前景屋脊掠过，落到下一片瓦面，瓦片轻震 | 保持屋顶方向和高度连续 |
| 贴地滑步 | 身体压低贴地滑过刀锋下方，手掌撑地反身起势 | 需要写地面接触和起身方向 |
| 身法残影 | 只允许短暂运动模糊表现速度，不生成多个实体角色 | 禁止复制出第二个主角 |

## 内力与武侠特效

- 内力必须有来源：掌心、剑身、脚下地面、呼吸、衣摆风压。
- 内力必须有作用对象：推退对手、震开兵器、掀起尘土、压暗烛火。
- 特效保持克制，不要网游大招感，除非用户明确要求夸张玄幻。

可写句：

```text
两人掌心相抵，接触点出现一圈极淡气流，地面灰尘向外推开；摄影机从接触点轻微后撤，露出两人脚步同时后滑半寸。
```

## 节奏模板

| 场景 | 节奏骨架 |
|---|---|
| 兵器试探 | 起手礼 -> 试探一击 -> 格挡 -> 兵器缠住 -> 分开对视 |
| 屋顶追逐 | 远景掠过屋脊 -> 脚尖落瓦 -> 转向躲箭 -> 近身交击 -> 跳落新空间 |
| 暗器反转 | 手部藏暗器 -> 对方未察觉 -> 出手 -> 闪避/命中环境 -> 眼神确认 |
| 内力对撞 | 蓄气 -> 接触点 -> 气流扩散 -> 双方后滑 -> 一方压住伤势 |

## 限制项

- 不要让兵器忽大忽小、软硬属性混乱、剑变刀、枪变棍。
- 不要让角色无来源漂浮；轻功必须写借力点和落点。
- 不要让交击没有接触点；刀剑碰撞、枪杆格挡、鞭身缠绕都要可见。
- 不要把武侠特效做成现代科幻 UI 或网游技能图标。
