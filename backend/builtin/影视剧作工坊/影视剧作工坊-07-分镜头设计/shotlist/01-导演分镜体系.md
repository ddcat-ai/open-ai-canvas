# 导演分镜体系库（《影视分镜头专业精要·导演体系》转写）

> 参考典籍：《电影语言的语法》《剪辑的语法》《导演工作》《故事板设计完全指南》《电影镜头设计》
> 定位：本库补齐技能此前四大空白——**蒙太奇组接语法、四大场景标准镜头序列、镜头时长量化基准、一镜一信息与主视角统一铁律**。
> 终极境界：**隐形叙事** —— 优秀分镜让观众完全忽略镜头存在；拙劣分镜让观众只看到技巧与漏洞。
> 底层逻辑一句话：**景别决定信息层级，角度决定心理氛围，运镜决定情绪节奏，组接决定叙事深度。**

## 一、五大底层铁律（导演必修基石，无任何创作例外）

| 铁律 | 内容 | 与本技能既有规则的关系 |
|------|------|----------------------|
| **1. 一镜一信息** ⭐新增 | 单个镜头只承载一个核心叙事信息；动作镜头只讲动作、情绪镜头只讲表情、环境镜头只讲氛围、细节镜头只讲道具；多重信息必须拆为多镜依次呈现 | 是「叙事功能备注只能填一个」的理论根源，二者互为表里 |
| **2. 视觉流畅** | 空间/动作/视线/情绪四连续性；禁止无逻辑跳跃（远景硬切特写、视线错乱、主体偏移）；流畅=观众无需适应即自然接收 | 对应法则二/四 + 自检衔接项 |
| **3. 主视角统一** ⭐新增 | **单场戏必须确立唯一核心视角**：客观上帝视角 / 主角主观POV / 对手主观POV 三选一，全程主导镜头逻辑，禁止频繁切换 | Step 1 核心目标卡新增「主视角」必填行 |
| **4. 镜头服务叙事** | 不存在"好看但无用"的镜头；炫技运镜、多余特写、冗余空镜均拖慢叙事 | 与删镜闸门同源 |
| **5. 节奏可控** | 分镜提前锁定节奏：时长×切换频率×景别松紧×运镜快慢共同定义快慢，必须贴合剧情情绪而非随心所欲 | 对应法则五 + Step 5 Reel 模拟 |

## 二、镜头时长量化基准（Step 4/5 填「时长」字段的硬性依据）⭐

**生理底线：看清基础信息 ≥0.5s，完整理解情绪需 1-2s。**

| 景别/戏型 | 标准时长 |
|-----------|---------|
| 特写 | 最短 0.5s |
| 中近景 | 1–3s |
| 全景/远景 | ≥3s |
| 长镜头 | 无固定上限（本技能仍受 8s 平台红线约束） |
| **动作戏平均单镜** | **0.5–1.5s** |
| **文戏对话单镜** | **2–5s** |

**应用规则**：每镜时长必须落在所属景别区间内；超出区间需在画面备注给出理由（情绪留白/定格等）。

### 机位角度心理对照（补充极致顶拍语义）

| 角度 | 心理语义 |
|------|---------|
| 平视 | 平等客观，最稳妥通用 |
| 仰拍 | 威严强势压迫，强者/反派/主角高光 |
| 俯拍 | 渺小无助被掌控，弱势/失败/绝望 |
| **极致顶拍** | **上帝视角=审判、宿命、无力反抗**，悬疑悲剧困境专用，冰冷疏离 |
| 倾斜 | 混乱焦虑失控精神失常，冲突惊悚心理博弈 |

## 三、六大蒙太奇组接体系（分镜从"记录画面"升级为"讲述故事"）⭐

| 手法 | 定义 | 适用 | 分镜表落地方式 |
|------|------|------|--------------|
| **叙事蒙太奇** | 按时间/因果顺序直排镜头 | 90%常规剧情 | 默认组接方式，镜号即时间线 |
| **平行蒙太奇** | 双线或多线交替剪辑，不同空间同推进 | 双线叙事、明暗线、伏笔铺垫 | 镜号前缀标注线索（S03-A/S03-B），场景调度总览说明切线节拍 |
| **交叉蒙太奇** | 多条紧急线**快速**交替，压缩时间感 | 追逐、危机、高潮戏提速 | 单镜时长压至 0.5–1.5s，两线镜头严格交替排列 |
| **对比蒙太奇** | 贫富/善恶/冷暖/动静反差镜头交替 | 强化主题与情绪 | 相邻两镜在「叙事功能备注」标对比对（如 `悬念↔调剂` 反衬） |
| **隐喻蒙太奇** | 以景物/道具镜头替代直白台词 | 文艺向高级叙事、心理外化 | 优先用 INS 插入镜头承担；与「内在信息靠画面表达」铁律直接呼应 |
| **累积蒙太奇** | 多个同调性镜头连续堆叠蓄力 | 开篇铺垫、氛围塑造、情绪递进 | 连续 ≥3 镜同情绪组微表情/同色调空镜，标注「累积段」 |

**选择规则**：每个场景在核心目标卡声明主蒙太奇策略（默认叙事蒙太奇，高潮段可局部切交叉）。

## 四、四大核心场景标准镜头序列（可直接套用的分镜模板）⭐

### 4.1 双人对话戏（最常用、最考验功底）
```
全景定场（交代空间站位）→ 单人中景主说 → 单人中景回应 → 中近景情绪特写
→ 手部/道具细节补充(INS) → 全景收尾转场
```
约束：全程坚守 180° 轴线；正反打视线严格匹配；运镜克制，以固定+轻微推拉为主。

### 4.2 单人情绪戏
```
中全景交代状态 → 中近景聚焦神态 → 近景/特写放大情绪
→ 细节镜头（眼神/手部/道具）佐证内心 → 慢拉空镜留白收尾
```
约束：节奏由慢到静，景别逐步收紧烘托情绪，拒绝频繁切换，保证情绪沉淀连贯。

### 4.3 动作冲突戏
```
全景铺垫对峙格局 → 中景记录肢体动作 → 短镜头快速切换动作细节
→ 特写捕捉表情与发力瞬间 → 环绕/跟镜强化动态张力 → 全景定格收尾
```
约束：快节奏、动静结合；与 SKILL 6.1 打斗规范叠加执行（每3-5快切插1慢镜）。

### 4.4 转场空镜戏
```
环境光影 / 天气变化 / 静态景物 / 动态氛围镜头
```
约束：空镜四大功能=缓冲节奏、切换时空、烘托氛围、留白情绪；时长适中贴合前后情绪；**杜绝无意义冗余空镜**（过删镜闸门）。

**使用规则**：拆分镜前先判定场景类型（对话/情绪/动作/过渡），套用对应序列作为初稿骨架，再按核心目标卡增删；偏离模板须在方案对比表中说明理由。

## 五、四大节奏模式（Step 5 Reel 时间轴的判级标准）⭐

| 模式 | 单镜时长 | 形态 | 适用 |
|------|---------|------|------|
| 慢节奏 | 3–6s | 长镜头、慢运镜、少切换，固定+缓推拉 | 抒情、沉淀、铺垫、留白；温情悲伤治愈 |
| 中节奏 | 1.5–3s | 中短交替、匀速切换、平稳克制 | 日常对话、剧情推进（通用基线） |
| 快节奏 | 0.5–1.5s | 短镜密集+快摇/横移/跟镜 | 对峙、争吵、追逐、打斗、危机爆发 |
| **骤停节奏** ⭐ | 超长静止 | 快切密集后**突然切入超长静止镜头**，极致反差 | 爆点、转折、悬念留白、结尾——**尾钩首选手法** |

**张弛铁律**：全片必须松紧交替、快慢结合；连续同模式不超过 8 镜须换挡；节奏时间轴上标注每段所属模式。

## 六、写实 vs 漫剧差异化分镜（配合灯光库双范式）

| 维度 | 写实真人分镜 | 漫剧分镜 | 本技能默认（3D漫剧） |
|------|------------|---------|-------------------|
| 运镜 | 平滑真实无夸张 | 允许夸张运镜、非常规角度 | 写实框架为底，冲击镜头可风格化（须标注理由） |
| 景别过渡 | 严格循序渐进 | 允许高对比景别跳跃、硬切 | 默认守法则四跳切禁忌；Smash Cut 仅限爆点 |
| 物理约束 | 透视/光影/动作完全贴合物理 | 简化物理，强化画面张力漫画感 | 介于两者之间（与灯光库第六章混合策略一致） |
| 不变共性 | **轴线、视线、景别功能、节奏逻辑两套共享，绝不豁免** | 同左 | 同左 |

## 七、新手十大致命错误（并入禁忌清单）

1. 单镜多信息，画面杂乱无重点（违铁律1）
2. 无逻辑景别跳跃：远景硬切特写、特写硬切全景（违法则四）
3. 频繁越轴、视线错乱（违法则一/二）
4. **全员同景别、同角度、同时长，平铺直叙毫无起伏**（节奏自查不通过）
5. 运镜泛滥全程推拉摇移，过度炫技弱化叙事（违铁律4）
6. 镜头时长不合理：该慢不沉淀、该快不紧张（对照第二章量化基准）
7. 视角频繁切换，上帝/主观随意混用，代入感割裂（违铁律3）
8. 空镜滥用、冗余镜头过多拖慢叙事（删镜闸门失守）
9. 动作剪辑断层：卡顿、重复、瞬移（违动作匹配——见下条）
10. 镜头与情绪脱节：严肃戏轻快运镜、悲情戏快速剪辑（情绪自查不通过）

### 动作峰值切镜规则（补强法则三）⭐

连贯动作拆多镜头时，**必须在上一镜的动作峰值处切换**（抬手最高点、挥拳接触瞬间），保证轨迹无缝衔接，杜绝断层/重复/瞬移。分镜表动作描述须标注切点位置（如「切换点：拳头触及面部瞬间」）。

### 方位统一细则（补强法则三）

人物入场方向=全程运动方向（从左入画则全程向左），中途反转必须有叙事原因并在备注说明。多人场景确立核心视线焦点，配角视线统一指向主体。

## 八、六维终审自查（Step 6 之上的导演级终检）

| 维度 | 检验问题 |
|------|---------|
| 叙事 | **不看剧本，仅凭镜头序列**能否看懂剧情、动机、情绪变化？ |
| 空间 | 无越轴、无视线错乱、无方位反转、无人物悬浮？ |
| 节奏 | 高潮紧凑、铺垫舒缓、转折有力，无平铺直叙？ |
| 镜头 | 每镜有明确叙事动机，无多余镜头、无效运镜、信息冗余？ |
| 衔接 | 动作连贯、情绪递进、时空统一，无突兀跳转？ |
| 情绪 | 景别/角度/运镜/节奏全程烘托剧情情绪，无风格割裂？ |

**执行时机**：Step 6 三层清单全部通过后，再做一轮「遮剧本盲读」测试——把对白列遮住只看画面描述与景别序列，能读懂即为隐形叙事达标。

## 九、母书增补层：导演决策与取舍（v47 · 源自 guide-books/book03《导演功课》大卫·马梅）

> 本节补⑧库缺失的**决策侧**：现有第一~八节管「镜头怎么组接」，本节管「**什么该拍、什么不该拍、每个镜头为谁服务**」。全本原文见 [guide-books/book03-导演功课.md](./guide-books/book03-导演功课.md)（深挖时才读）。
> 来源书方法底色：大卫·马梅承爱森斯坦蒙太奇理论，主张「寻找两个中性、彼此互不关联的镜头并置，让故事的概念在观众心中成型」——与③蒙太奇组接体系同源，本节补其**筛选逻辑**。

### 9.1 场是最小单位：问题的提出与解决

**定义**：当某场戏所提出的**问题解决时，这场戏便结束了**。整部影片同理——开场提出的问题被解决的时刻，就是故事的终点。

- **分镜应用**：核心目标卡的「关键信息」必须能改写为一个**待解决的问题句式**（例：「沈渊能否发现林晚在撒谎？」）。写不出问题句式的场景 = 没有戏剧驱动，需重做。
- 三段论结构：**因 A（未决事件的状况声明）→ 而 B（骚动到达平稳）**；每个镜头必须是这条因果链上的一环，不在链上的镜头删。

### 9.2 晚开场 + 提早退场（⭐ 红果钩子结构的理论原型）

> 来源书原话：「不唠叨、直接切入问题再开场，即『晚开场』，然后『提早退场』（将问题留到下一场解决），是表示对观众的尊重。」

| 手法 | 做法 | 漫剧落地 |
|------|------|---------|
| **晚开场** | 跳过寒暄与铺垫，直接切入问题的第一动作 | 对应 **5 秒开场钩子**：首镜直接落在冲突进行中，而非进入房间、坐下、寒暄 |
| **提早退场** | **在问题尚未解决时就结束本场/本集**，留到下一场解决 | 对应 **集尾钩 cliffhanger**：观众为知道「到底会怎样」而继续看下一集 |

**强制**：每集最后一场必须在**主问题解决之前**切断；若在解决之后才收尾，尾钩判定失效（无悬念可留）。付费卡点前一场尤其严禁提前解决。
**警示**：不得为凑钩子而重复 cause；「晚开场」不等于跳过必要的信息交代（仍需⑥库法则六建立镜头，只是把建立压缩到与钩子同一镜）。

### 9.3 主旨三级下沉（⭐ 从抽象到可拍摄的唯一路径）

> 来源书判例：场的主旨 = 「获得撤销成绩」 → 动作概念 = 「提早到达」 → 肢体动作 = 「走到长廊尽头 / 试着转动门把 / 坐到地上」。

| 层级 | 性质 | 举例 | 是否可拍摄 |
|------|------|------|-----------|
| ① 场的主旨 | 抽象叙事目标 | 获得撤销成绩 | ❌ **禁止直接视觉化** |
| ② 动作概念 | 达成主旨的一个动作意图 | 提早到达 | ❌ 不可直接拍摄，但决定选什么镜头 |
| ③ 肢体动作 | 单纯可见的动作 | 走到长廊尽头、转门把、坐下 | ✅ 只有这一级进画面 |

**铁律**：②③必须逐层导出，禁止从①直接跳到③（跳过动作概念 = 镜头与主旨无关 = 观众看不出这场戏在说什么）。

### 9.4 「别把主角要什么都拍下来」（⭐ 删镜闸门的理论依据）

> 来源书原话：「**你必须知道主角要什么，因为这才是这部电影的内容。但你决没必要将它拍下来。**」
> 另一句：「**是你在说故事，别让你的人物说故事。**」

- **禁拍清单**：主角的**目标、愿望、背景故事（back story）、内心活动**一律不单独立镜表现，必须靠⑥库「外部环境/动作/道具/微表情」间接承载
- **不要跟着人物跑**：不要跟着人物跑——镜头应选那些**能把主旨推进到下一步**的动作，而非记录角色的完整行为曲线
- **与实践的关系**：这是⑦删镜闸门（①方法论库）的正当性来源——「主角想要这件事」本身不产生画面，只有他**采取行动并被阻碍**时才产生画面

### 9.5 中性镜头并置：不要说出概念，让观众自己生成

**做法**：选择两个**中性、彼此互不相关**的镜头并置，导演不主动说明/叙述，而是制造情境，让观众投入并主动参与，去思索故事是怎么回事。

- 应用到分镜：相邻两镜若都能各自单独表意、且组合后生成**第三层含义**（A+B=C），即为合格蒙太奇；若第二镜只是在重复/说明第一镜，则为冗余，删
- **禁止替观众下结论**：画面描述中禁止写出「这意味着……」「暗示他内心……」等替观众做结论的表述——意义由并置产生，不在单镜描写里说明（与 Step 4「内在信息靠画面表达」一致）

### 9.6 情绪不属于演员，属于剪辑

> 来源书：「确切了解蒙太奇理论，一定不会强求演员演出心智混乱或爱憎难分等情绪，因为影片中的情绪不是演员的职责。」

- **❌ 禁止情绪指示词**：画面描述写「他很悲伤地」「愤怒地说」这类**情绪指示词**——这是让 AI 去演情绪，而非拍情绪
- **✅ 正确做法**：只写**单纯肢体动作**（走到门口、试门把、坐下），情绪由**景别收紧 + 微表情编号 + 剪辑节奏 + 光影**共同产生（分派给⑥调度、③微表情、⑦灯光、本库第五节节奏）
- **动作修饰词规则**：用最直截了当的**动词 + 副词**（"快步走""意志坚定地走"），禁止情绪形容词与心理动词
