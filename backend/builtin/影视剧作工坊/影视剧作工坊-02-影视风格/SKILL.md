# 影视风格（模块 02）

> 主链定位：氛围比对 → 导演挂卡 → 中性缺省；导演四库 + 调用引擎 + 电影类型与调色库。

## 做什么

确立**整片级的风格与调色基线**，产出"全局风格前缀"——它在文档中出现一次，并逐字前置于每一条提示词（07 分镜头设计、10 剪辑与镜头组接验证都依赖它保持跨镜头一致）。

**方法边界**：本模块定"整片看起来是什么调子"，不决定单个镜头的景别/机位（06）、镜头怎么动（08）、角色演什么（05）。

## 基础引擎
本模块的底层方法论源：`engine/E02-影视风格.md`（本模块目录内，57 条，来自 book01/book02/book03/book04）。
执行本模块前先查阅该引擎，取其判断依据、创作准则与反模式清单；引擎为只读源层，本模块负责执行流程。

## 执行流程

1. **接氛围诉求** —— 明确这部片"要让观众感受到什么"（情绪、题材、时代）。
2. **定情绪基调** → `style/03-调色情绪.md`
   从 11 种调色语言中选一种（大片感 / 冷峻惊悚 / 温暖怀旧 / 赛博朋克 / 恐怖 / 浪漫 / 纪录 / 史诗奇幻 / 黑色电影 / 冷调科幻 / 末日废土）。
3. **取类型默认** → `style/01-电影风格条目.md`
   按题材选电影类型，取它的**灯光默认 + 色彩倾向 + 运动风格**三项默认值（如：悬疑＝低调光有动机 / 冷收敛 / 慢蓄）。
   需要更强的整体形态时，再取平台命名风格、风格配方或寄存极点。
4. **定整片调色** → `style/02-调色板.md`
   从 8 个预设中定一个（如动作/惊悚→青橙史诗，赛博朋克夜景→超级霓虹）。
5. **过色彩纪律** —— **60/30/10**：画面 60% 主导色 + 30% 次要色 + 10% 点缀色，读感最干净；**每种颜色绑定一个来源与一个表面**，绝不给平铺色卡清单；**唯一饱和点缀色留给剧情关键道具**（暗调画面中独占，时间维度同理："黄金时刻留给反转"）。
6. **选胶片模拟** → `style/04-胶片模拟与调色一致性.md`
   按需要的观感选一种胶片（温暖肤色→Portra 400 / 鲜艳→Velvia / 自然电影感→Vision3 500T / 黑白→HP5 / 明亮高对比→Ektachrome），**一次只用一种**，写在风格行，不做输出规格。
7. **锁一致性** —— 整条序列的色彩语言**逐字复制粘贴**（措辞漂移＝观感漂移）；交付时按"**先统一、后诠释**"处理出厂调色。
8. **写全局风格前缀** —— 把类型默认 + 调色板 + 色彩纪律 + 胶片模拟固化成一段，逐字前置于每条提示词。
9. **交下游** —— 07 分镜与 10 组接继承此前缀；最终经 12 技术语言转换净化。

## 与其他模块的关系

- **下游 06 / 07 / 08 / 10** —— 它们逐字继承本模块产出的全局风格前缀；06 的灯光教义与逐场景覆盖也源自此处。
- **上游 01** —— 触发与任务识别确定本模块是否需要参与（单镜头任务可跳过整片级风格）。
- **12 技术语言转换** —— 风格词是触发子模块调度的信号，**本身不进输出**；最终提示词里只留画面语言。

## 硬规则速记

- 全局风格前缀**只声明一次**，逐字前置到每条提示词——改一次，处处生效。
- **60/30/10 色彩规则**：60% 主导 + 30% 次要 + 10% 点缀，比罗列五种竞争色更协调；**每个色绑来源与表面**，禁平铺色卡。
- **唯一饱和点缀色留给剧情**关键道具（时间维度同理）。
- **色彩语言逐字重复**——措辞漂移就是观感漂移；跨镜头调色**先统一、后诠释**。
- **胶片模拟一次只用一种**，写在风格行，不是输出规格字段。
- 电影类型两版互斥：Western/Suspense/Intimate/Spectacle 仅 2.5；Noir/Drama/Epic 仅 3.0+。
- 风格词本身不进交付，只用于触发子模块调度。
- **影调 vs 画风的边界**：本模块定**影调与类型配方**（电影类型、平台风格、风格配方、寄存极点）；04 的 `characters/07-风格族基准` 定**美术画风族**（国风/次世代CG/半厚涂/胶片油画）。两者不同维度、可叠加，不互相覆盖。
