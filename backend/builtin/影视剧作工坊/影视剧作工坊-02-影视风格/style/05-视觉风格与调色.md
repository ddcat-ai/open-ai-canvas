# Higgsfield 视觉风格

> **落位说明**（并入影视剧作工坊时添加，正文保留原文）

> 现行位置：`影视剧作工坊-02-影视风格/style/05-视觉风格与调色.md`

## 核心平台风格

这五种风格是 Higgsfield 的命名预设。引用时请使用其确切名称。

### Cinematic（电影感）
**外观：**精致、高对比度、色彩鲜艳、曝光均衡 —— 现代大片质感
**最适用于：**剧情、动作、叙事电影、广告、任何专业内容
**色彩倾向：**浓郁、饱和、干净
**提示词语句：**"风格：Cinematic"
**搭配：**Kling 2.6/3.0、Sora 2、推轨推进（Dolly In）、弧形运镜（Arc）、摇臂上升（Crane Up）

```
示例：一名侦探穿过一座夜市。
风格：Cinematic。冷蓝色的阴影，暖琥珀色的市集摊位灯光。
浅景深（shallow depth of field）。16:9。
```

---

### VHS（录像带）
**外观：**复古录像带颗粒，色彩渗色，轻微扫描线，模拟信号的瑕疵感
**最适用于：**80/90 年代怀旧、恐怖、惊悚、复古音乐视频、闪回
**色彩倾向：**略微褪白，暖黄与暖红，低对比度
**提示词语句：**"风格：VHS"
**搭配：**手持摄影（Handheld camera）、Wan 2.5、任意恐怖预设

```
示例：1987 年，一群青少年在一场住宅派对上。
风格：VHS。温暖、颗粒感重、轻微过曝。4:3 画幅。
```

---

### Super 8MM（超8毫米）
**外观：**温暖的胶片颗粒，柔和的暗角（vignette），灰调柔化的色彩，家庭录像质感
**最适用于：**个人故事、爱情、怀旧、独立电影、家庭时刻
**色彩倾向：**温暖、金黄、略微褪色
**提示词语句：**"风格：Super 8MM"
**搭配：**手持、自然光描述、亲密场景

```
示例：20 世纪 70 年代，一对情侣在洒满阳光的后院共舞。
风格：Super 8MM。温暖颗粒，柔和的暗角边缘。4:3。
```

---

### Anamorphic（变形宽银幕）
**外观：**超宽画幅（2.35:1），水平镜头光晕（lens flare），轻微桶形畸变（barrel distortion），
史诗般的恢弘尺度 —— 经典好莱坞宽银幕
**最适用于：**动作、史诗奇幻、战争片、壮阔风景、强戏剧性内容
**色彩倾向：**高对比度，深邃的黑色，浓郁的高光
**提示词语句：**"风格：Anamorphic" 或 "风格：Anamorphic，2.35:1 宽银幕"
**搭配：**摇臂上升、360 度环绕（360 Orbit）、大幅拉轨后退（Super Dolly Out）、Sora 2

```
示例：黎明时分，一支军队行进在冰封的平原上。
风格：Anamorphic，2.35:1。深蓝灰色调。初升朝阳上的一道镜头光晕。
```

---

### Abstract（抽象）
**外观：**非具象，超现实的配色，打破常规的形状，艺术化
**最适用于：**音乐视频、概念艺术、梦境段落、实验性内容
**色彩倾向：**鲜艳、出人意料、由概念而非写实驱动
**提示词语句：**"风格：Abstract"
**搭配：**Wan 2.5、Portal（传送门）、Multiverse（多重宇宙）、Glitch（故障）预设

```
示例：破碎的几何形体在虚空中随音乐脉动。
风格：Abstract。黑色底上的电光蓝与洋红。1:1 画幅。
```

## 调色词汇

无论使用哪种风格预设，以下内容都可用于任何提示词：

| 情绪 | 调色描述 |
|------|------------------------|
| 冷峻惊悚 | "青橙调（teal and orange），去饱和，高对比度" |
| 温暖怀旧 | "黄金时刻（golden hour）的琥珀色，柔和阴影，低对比度" |
| 赛博朋克 | "霓虹洋红与青色，深阴影，HDR" |
| 恐怖 | "病态的黄绿色，压死的暗部，去饱和" |
| 浪漫爱情 | "柔和的暖粉金色，提亮的阴影，如梦似幻" |
| 纪录片 | "中性，自然光，不做调色" |
| 史诗奇幻 | "浓郁的宝石色调，深阴影，体积光（volumetric light）" |
| 黑色电影（noir）| "高对比度黑白，或近乎单色" |
| 冷调科幻 | "冰蓝与银色，冷硬的白光" |
| 末日废土 | "去饱和的橙色与棕色，尘霾" |

## 灯光词汇

| 类型 | 描述 | 最适用于 |
|------|-------------|----------|
| 黄金时刻 | 日出后或日落前不久的温暖定向光 | 浪漫、史诗、唯美 |
| 阴天（overcast）| 柔和的漫射光，没有阴影 | 纪录片、情感、质朴写实 |
| 霓虹（neon）| 来自招牌/屏幕的彩色人工光 | 赛博朋克、夜景、都市 |
| 体积光 | 透过大气（雾/尘埃）可见的光束 | 奇幻、电影感、氛围浓烈 |
| 仅实用光源（practical only）| 所有光线都来自画面内可见的光源（灯具、火焰、屏幕）| 写实、黑色电影、亲密私密 |
| 侧光（side-lit）| 来自一侧的单个强光，造成深深的阴影 | 剧情、张力、肖像 |
| 逆光（backlit）| 主体从背后被勾成剪影或镶上轮廓光（rim light）| 神秘、浪漫、史诗式揭示 |
| 低调布光（low key）| 整体偏暗，只有小片光区 | 恐怖、惊悚、黑色电影 |
| 高调布光（high key）| 明亮、均匀、阴影极少 | 喜剧、广告、生活方式 |

## 电影级布光技法

这些是 AI 模型响应良好的具体布光方案。直接在提示词中使用这些术语，
即可精确控制光线如何塑造场景。

| 技法 | 效果 | 最适用于 |
|-----------|--------|----------|
| 伦勃朗光（Rembrandt lighting）| 暗侧脸颊上的一块三角形光斑，一只眼睛被照亮 | 人物剧情、角色出场、情绪化访谈 |
| 蝶形光／派拉蒙光（Butterfly / Paramount lighting）| 头顶光在鼻子正下方投下阴影 | 魅力人像、时尚、美妆镜头、经典好莱坞 |
| 分割光（split lighting）| 半张脸受光，另外半张完全沉入阴影 | 双重性、内心冲突、反派揭示 |
| 轮廓光／逆光 | 沿主体剪影边缘泛起的光晕 | 神秘、史诗式揭示、与背景分离 |
| 动机布光（motivated lighting）| 场景中可见或可推断的光源（灯具、窗户、火焰）| 写实感、叙事落地、自然主义剧情 |
| 实用光源布光 | 画面内的光源（霓虹招牌、蜡烛、屏幕）| 夜景、赛博朋克、亲密写实 |
| 明暗对照法（chiaroscuro）| 明暗区域之间的极端对比 | 文艺复兴质感、强戏剧性、绘画式构图 |
| 高调布光 | 明亮、阴影极少、照明均匀 | 喜剧、广告、生活方式、干净美学 |
| 低调布光 | 深阴影占主导，只有小片光区 | 黑色电影、惊悚、恐怖、心理张力 |
| 黄金时刻／魔幻时刻（magic hour）| 温暖的琥珀色定向光，修长而柔和的阴影 | 浪漫、美感、史诗风景、情感节点 |
| 蓝调时刻（blue hour）| 日落之后不久冷冽的钢蓝色环境光 | 忧郁、过渡、静谧的张力、都市孤独 |
| 正午烈日（harsh midday sun）| 硬朗的顶光，轮廓分明的浓重阴影 | 沙漠、对峙、暴露无遗的脆弱感 |
| 阴天漫射／柔光箱（softbox）| 均匀的柔光，没有硬阴影 | 人像、纪录片、质朴写实 |

## 风格最佳实践（Cinema Studio 3.0 / Seedance 2.0）

以下原则适用于 Cinema Studio 3.0 的生成引擎（仅限 Business/Team 套餐），是对上文风格词汇的补充。

### One Style Anchor Rule（单风格锚规则）

一个主风格锚胜过五个形容词。风格词一旦超过 2–3 个，模型注意力就会被稀释，输出变得泛化平庸。

**错误：**`风格：电影感、变形宽银幕、情绪化、氛围感、戏剧性布光、胶片颗粒、去饱和、黑色电影风、高对比度、复古感`

**正确：**`风格：变形宽银幕，细腻颗粒，低饱和色调`

选定你的锚（那唯一最重要的风格元素），加上 1–2 个辅助词，然后停下。

### "Cinematic" 一词毫无作用

每一段生成的视频默认都是"电影感"的。这个词不提供任何信息量。请换成具体的镜头或对比度描述：

- ~~"电影感"~~ → `浅景深，暖高光，冷阴影`
- ~~"电影感外观"~~ → `变形宽银幕，2.35:1，水平镜头光晕`
- ~~"电影感画质"~~ → `35mm 胶片，自然颗粒，Kodak Portra 色板`

### Style Transfer via @Reference（经参考的风格迁移）

视觉风格参考胜过描述性文字。一张参考图片/视频所携带的风格信息，胜过 10 个描述词：

```
匹配 @Video1 的视觉风格、调色与胶片质感。
一名女子在公园中走过秋日落叶。
运镜：与她并行的缓慢跟拍（tracking）。
```

风格参考适用于：调色、胶片模拟、灯光氛围、质感、特定年代的外观。

### CGI Material Contract（CGI 材质契约）

在为 CGI 或产品渲染写提示词时，为每个表面指定 2–4 项材质属性，以避免默认的"塑料光泽"：

| 属性 | 选项 | 示例 |
|----------|---------|---------|
| 基底 | 金属、玻璃、织物、陶瓷、木材、皮革 | `拉丝不锈钢` |
| 粗糙度 | 哑光、缎面、光亮、镜面 | `缎面处理` |
| 缺陷 | 划痕、灰尘、磨损、指纹、包浆 | `使用留下的细划痕` |
| 边缘 | 斜面、锐利、圆润、倒角 | `柔和的圆角边缘` |

**示例：**`一只哑光陶瓷花瓶，瓶身带发丝级细裂痕与淡淡包浆，瓶口边缘柔和圆润，静置于粗凿橡木之上。`

### Period Control（年代控制）

不要只报出年代 —— 要具体写出那个年代的**材质与灯光**：

- ~~"1970 年代风格"~~ → `Kodachrome 暖调，木质护墙板，橙色长绒地毯，钨丝灯泡洒下琥珀色的光`
- ~~"1940 年代黑色电影"~~ → `高对比度黑白，百叶窗阴影，软呢帽剪影，湿沥青映着街灯`
- ~~"1990 年代家庭录像"~~ → `Hi8 摄像机颗粒，自动对焦来回搜寻，时间戳叠加，过饱和的绿色`

## Register Poles（寄存极点）—— 风格刻度盘有着彼此相反的两端

`[FIELD（实战）—— 13 个项目的社区采集，2026-07-18]` —— "照片级真实的电影感
（photoreal cinematic）"并不是单一寄存（register）。实际生产项目坐落在刻度盘上
*有名字的极点*，而极点决定整套镜头语法：

| 寄存极点 | 镜头语法 | 质感堆栈 |
|---|---|---|
| **胶片寄存**（剧情/爱情长片）| 手持呼吸感，允许水平线稍有失衡，自然的运动 | 35mm 颗粒，乳白般柔和的低对比，画门晃动（gate weave），光渗（halation），"四角与中心一样亮" |
| **广播电视寄存**（2000 年代初的剧集）| **三脚架锁定机位，正面构图，充分保留的反应镜头节拍，每个镜头至多一次运镜** | 重度柔光漫射，泛光的高光，胶转磁扫描颗粒（telecine grain），平坦中性的日间影调 |
| **定格动画／手绘动画**| 步进运动 —— "真正的 12fps，按一拍二（on twos）制作：每个姿势保持两帧再瞬间切换，绝不滑行" + 持续不断的绘画式沸腾（painterly boil）| **分动规则（split-motion rule）：**大气效果（雪、呼出的白汽、烟）平滑（SMOOTHLY）运动，而人物按一拍二步进 —— 这是一条与视频模型默认平滑性相对抗的显式约束 |
| **动画／赛璐璐（cel）**| 逐镜头点名指定机位，物理/皮肤模块更少（即模板契约）| "赛璐璐着色的 2D，干净的平涂填色，二至三阶明度的赛璐璐分色 —— 不是绘画风，不是 3D，没有 CGI 平滑感" |

**风格锚槽位会随寄存切换词汇。**同一个槽位，不同的语言：照片级真实的锚落在
DP（摄影指导）/导演式外观上（仅限短片形态 —— 块状提示词则改为直接描述外观，
遵循 seedance 可度量语言规则）· 动画把锚落在**美术年代**上（"2000 年代初复古
动画，老式赛璐璐比例"）· 定格动画把锚落在**媒介物理**上（"12fps 一拍二，
绘画式沸腾"）。绝不要把一个寄存的锚带进另一个寄存。

**一种饱和的点缀色，为故事而保留。**这是贯穿整个语料库的色彩纪律：在一套灰调
调色里，只有剧情攸关的道具才拥有唯一的饱和点缀色（一台酸绿色的设备，一枚
黄绿色的遥控 LED）—— 同样的保留手法也可以在时间维度上使用（"黄金时刻为反转
而保留"；它之前的所有画面都保持平坦中性）。请把这种保留明确陈述出来。

## Style Recipes（风格配方）—— 八种久经验证的形态

`[OFFICIAL（官方）—— Higgsfield cinematic-prompt-builder 技能，2026-07]` —— 供起步
使用的配方，每一种都是一份独立的渲染契约。可以自由组合、自由偏离；每种配方
的承重部分是**"是 / 不是"（is / is-NOT）声明**与每 15 秒的镜头数形态：

| 配方 | 外观声明 | 结构 + 招牌手法 | 音频 |
|---|---|---|---|
| **真人实拍史诗**| 8K 照片级真实，变形宽银幕，细腻颗粒 —— "照片级真实，不是 3D/游戏" | 一镜到底（oner）或多镜头；一个"钩子"事件触发一个保持住的慢动作节拍，随后猛然切回；体量对比（渺小的人物 vs 庞大的主体）| 画内音（diegetic）；慢动作段声音落成闷沉的真空感 + 心跳，切回时伴一声呼啸 |
| **3D 动画长片**| 鲜亮光洁的 CGI，皮克斯级的风格化，次表面散射（subsurface）的毛发/皮肤 | **6 个镜头 / 15 秒**蒙太奇 —— "不要只用一个机位"；每个镜头都有口语台词并描述其念白方式；落下一个视觉笑点 | 允许轻量配乐；通常仍以音效为先 |
| **游戏过场动画**| UE5 引擎内实时渲染 —— "超写实，但一眼可辨是游戏渲染，不是电影" | 3 个镜头 / 15 秒，硬切；**钉在屏幕上的 HUD（平视显示器），使用锁定的点缀色十六进制色值，每个元素都逐一列出确切文字** —— HUD 永不产生视差 | 无音乐；音效 + 细微的 UI 滴答声 |
| **游戏实机画面**| AAA 街机（赛车）—— 过饱和的引擎渲染，"游戏内实机，不是电影实拍底板（plate）" | 稳如磐石的追车镜头（chase-cam）锁定在车辆上，任何地方都不用慢动作，实时 HUD（转速、助推、小地图）| 引擎声、换挡、助推、轮胎尖啸、UI 蜂鸣 |
| **FPV／POV 一镜到底**| 一条不间断的长镜，照片级真实的微距，变形宽银幕 | 在一个段落里按时间戳编排节拍；一次点名指定的变速（speed ramp）（240fps 子弹时间节拍 → 猛切回 24fps）；微距镜头擦着物体表面掠过 | 慢动作段把环境声换成被放大的节奏性声响 |
| **产品／广告**| 8K 杂志大片质感，深度的黑位下压（black crush），每个分段一套色彩世界 | 8–10 个短分段，在动作上做硬性匹配剪辑（match-cut）；0.3 秒的快速微距蒙太奇；收束于一个**英雄产品定格镜头（hero packshot）**（产品占画面三分之一，深色负空间，缓慢推轨，粒子漂浮，保持不动）| 无音乐/旁白/文字 —— 只有产品操作相关的音效 |
| **VFX 合成**（叠加在一段源素材上）| 照片级真实的实拍特效写实感；构图 + 调色从源素材原样继承 | INPUT LOCK（输入锁定）：底板保持原样不变，运镜被精确继承；唯一允许的新增 = 新元素 + 它的光 + 接触阴影；视差锁定到一个锚定平面上 | 在保留的房间底噪（room tone）之上，叠加新元素的画内音 |
| **怪兽（Kaiju）／巨型生物**| 8K 照片级真实变形宽银幕，原创设计（"不基于任何既有系列作品"）| 约 6 个剪辑点，逐剪辑点指定光学（OPTICS）；打开 CUT 1 的那个细节，正是 CUT 2 推近到眼前的对象；**收束规则（containment rule）**（"停留在海面，绝不上天"）为物理与体量感提供落点 | 仅画内音 —— 低频轰鸣、咆哮、爆水、次声轰响 |
