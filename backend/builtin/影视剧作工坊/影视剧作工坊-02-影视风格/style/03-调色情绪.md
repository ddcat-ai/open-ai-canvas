调色情绪（Color Grade Language，11 种）
来源：vocab.md 词汇表（中文版）
══════════════════════════════════════════════════════

| 情绪氛围 | 调色描述 |
|------|-------------|
| 大片感 | 青色阴影、橙色高光、高对比（teal and orange） |
| 冷峻惊悚 | 青橙调，去饱和，高对比度 |
| 温暖怀旧 | 黄金时刻的琥珀色，柔和阴影，低对比度 |
| 赛博朋克 | 霓虹洋红与青色，深阴影，HDR |
| 恐怖 | 病态的黄绿色，压死的暗部，去饱和 |
| 浪漫 | 柔和的暖粉金色，提亮的阴影，如梦似幻 |
| 纪录 | 中性，自然光，不做调色 |
| 史诗奇幻 | 浓郁的宝石色调，深阴影，体积光 |
| 黑色电影 | 高对比度黑白，或近乎单色 |
| 冷调科幻 | 冰蓝与银色，冷硬的白光 |
| 末日废土 | 去饱和的橙色与棕色，尘霾 |

配套色彩规则（vocab.md）

60/30/10 色彩规则——美术指导式的调色板纪律。
当画面的 60% 是一种主导色、30% 是次要色、10% 是点缀色时，
色彩读感最干净。点名"单一主导色调+辅助色板"的提示词，
比罗列五种互相竞争的颜色的提示词落地得更协调。

比例化 + 材质绑定——在块状提示词的调色块里，把调色写成比例，
并让每种颜色绑到一个来源和一个表面上，绝不要给一张平铺的颜色清单。
这是"色彩经由材质加光线"规则的落地形态：

色彩（Color）：[60% 主导色：低饱和的冷灰墙面与水泥地面（来源：场景建材）；
30% 次色：角色服装的深靛蓝；10% 点缀：仪表盘的酸性绿光（来源：剧情道具，
唯一饱和色）。]

唯一饱和点缀色留给剧情——剧情关键道具独占暗调画面中
唯一饱和点缀色（时间维度同理："黄金时刻留给反转"），
需显式声明保留。
