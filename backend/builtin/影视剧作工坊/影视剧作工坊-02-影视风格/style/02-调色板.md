调色板（Color Palette，8 个预设）
来源：Cinema Studio 3.5 Style Settings 面板（中文版）
══════════════════════════════════════════════════════

1. Naturalistic Clean（自然洁净）
   写实、中性调色板——角色/对白、纪录感、要读作"拍到而非调过"的品牌作品

2. Bleached Warm（漂白暖调）
   阳光晒褪的暖——海滩、白日外景、怀旧记忆

3. Hyper Neon（超级霓虹）
   高饱和霓虹——赛博朋克、夜店、夜色城市、MV

4. Teal Orange Epic（青橙史诗）
   行业标准大片调色——动作、惊悚、要即刻电影信誉的一切

5. Sodium Decay（钠灯衰变）
   钠灯橙+衰变——城市夜景、末世、粗粝犯罪

6. Cold Steel（冷钢）
   降饱和冷调——企业、监控、程序正义、科幻冷峻

7. Bleach Bypass（漂白旁路）
   高对比+降饱和——战争片、严酷剧情、年代粗粝

8. Classic B&W（经典黑白）
   黑白——黑色电影、档案感、形式与构图重于色彩

────────────────────────────────────────────────────
使用规则：
· 三轴可堆叠——调色板 + 灯光 + 运镜风格组合出完整风格
  （如：Teal Orange Epic + Soft Cross + Intimate Observer）
· 堆叠后 Style 药丸显示逗号分隔标签
· 不用预设轴时，可用 Manual Style（≤2000 字符项目法则块）替代
· 每个镜头一个主风格锚胜过五个形容词（One Style Anchor Rule）
