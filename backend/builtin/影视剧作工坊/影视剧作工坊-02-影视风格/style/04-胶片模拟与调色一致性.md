# 调色·纯技术文档（执行层）
（胶片模拟、色彩比例写法与跨镜头一致性纪律）

**总纲：三条调色纪律。**

1. **色彩经由材质与光线，而不是色卡清单。**把调色表述为比例，并让每种颜色绑定到一个来源和一个表面——绝不要给一张平铺的颜色清单。
2. **60/30/10 比例纪律**——60% 主导色 / 30% 次要色 / 10% 点缀色，画面读感最干净（完整 11 种情绪语言与比例写法见 `style/03-调色情绪.md`）。
3. **相邻镜头没有共同的起点观感**——每条生成素材自带出厂调色，同一序列的色彩语言要**逐字重复**或锁进全局前缀。

调色板预设（自然洁净 / 漂白暖调 / 超级霓虹 / 青橙史诗 / 钠灯衰变 / 冷钢 / 漂白旁路 / 经典黑白）见 `style/02-调色板.md`。

# 一、胶片模拟

| 胶片 | 观感 |
|---|---|
| Kodak Portra 400 | 温暖、肤色饱满、轻微颗粒 |
| Fuji Velvia | 色彩鲜艳饱和、细腻颗粒 |
| Kodak Vision3 500T | 电影感、自然、轻微暖调 |
| Ilford HP5 | 经典黑白、可见颗粒 |
| Kodak Ektachrome | 明亮、高对比、干净的反转片 |

**用法**：胶片模拟写在**风格行**（与《镜头语言》的镜头/画幅纪律并列），不作为输出规格；一次只用一种，不要叠加两种胶片名。

# 二、调色一致性纪律

- **先统一、后诠释。**相邻镜头没有共同的起点观感——生成式调色师的工作首先是把相邻镜头拉到同一种观感上，其次才是风格化诠释（完整机理见 10 的 `editing/06-装配与剪辑.md` §出厂调色与"先统一、后诠释"）。
- **逐字重复**：同一序列的每个镜头使用同一套色彩语言，逐字复制粘贴——**措辞漂移就是观感漂移**。
- **锁进全局前缀**：连通分镜清单中把调色行写进全局风格前缀，一次锁定、逐字前置到每条提示词；单场景需要打破时用**逐场景覆盖**（做法见 06 的 `shotlang/04-灯光.md` §风格前缀里的灯光教义与逐场景覆盖）。
- **调色不一致的预防措辞**见 13 交付文件审核的负面约束总库（质感/灯光部分，待补）。

# 三、交付前自检

- [ ] 调色是以**比例 + 材质来源**写的，不是颜色清单
- [ ] 每个色都绑定了来源（场景建材 / 角色服装 / 剧情道具）与表面
- [ ] 唯一饱和点缀色留给了剧情关键道具，并已显式声明保留
- [ ] 整条序列的色彩语言**逐字一致**（或已明确定义为有意的逐场景覆盖）
- [ ] 胶片模拟只用了一种，且写在风格行而非规格字段
