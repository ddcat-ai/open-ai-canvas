# 一、五要素引擎

## 1.1 目标（Goal）

主角为之战斗的那件**唯一且不变**的事：修复一个早已确立的问题，并尽快达成对它的解决。"早已确立"指*任何*更早铺垫过的东西——久远的背景故事、几场戏之前、或一分钟之前。

- **大目标从不改变**，主角对它永远不会判断错误。他可能在**策略**上犯错，但绝不在目标上犯错。
- **每场戏的目标都必须是指向故事目标的因果一环。**测试：删掉这场戏、链条依然成立 → 这场戏不合格。不允许孤立的戏。
- "他*应该*做什么"不是一个需要单独检验的项——正确的动作由**障碍 + 赌注**决定。主角采取一个赌注根本撑不起的策略（楼着火时还去洗澡）是一种可标记的不一致：要么标为坏写作，要么标为蓄意的自我破坏。

## 1.2 障碍（Obstacle）

一个强有力的环境态势，**危及**路径上的某一阶段、或整个目标。它是*威胁*，而不只是*代价*。

- 它可以是一张**分叉的搜索空间**（可找的地方很多，时间有限），也可以是**一堵单点的硬墙**（电池没电了——没法在一台死机上继续搜）。硬墙通常会催生一个自带地形的新子目标。
- 说出它的**规模**：*局部*（威胁当前阶段）或*全局*（威胁整个目标）。
- 障碍正是**逼主角选择或更换策略的东西**。没有危及 → 不需要策略 → 没有戏。
- 审计测试：说出什么东西处于风险之中、风险规模多大。如果实际上什么都没处于风险，障碍是假的，戏会松掉。

## 1.3 策略（Tactic）

威胁**逼**主角选出的那一招——基于他当前、常常不完整的知识做出的合情合理的猜测。这是**不确定性之下的搜索，不是把错误当愚蠢。**

- 一个"错误"的策略不是蠢；它是对一个他看不全的空间的合情合理的试探。引擎是一个**知识缺口**：他所相信的与实际所是之间的距离。
- **每一个失败的策略都必须返回信息**，让搜索收窄、重塑下一步动作。戏剧性在于收窄，不在于惩罚。
- ✅ 强：策略是对当前信息的合理下注，**而且**它的失败教会了新东西。
- ❌ 弱：一个他没有理由去试的策略；或一次返回**零信息**的失败——原地空转。失败的策略只有在失败什么都没教会时才构成弱点。

## 1.4 反转（Reversal）

一次违背预期的转折。三种形式：

1. **我自己的动作反噬我**——我为某事*做*的事，开始*反过来对付*它（我为那场提案去熨西装；熨西装让我迟到，提案泡汤）。
2. **隐藏的施动者被揭露**——我以为自己在对其*施加作用*的那个东西或人，从头到尾都在对我*施加作用*。惊悚片的招数；它常常恰好在知识缺口闭合的时刻引爆。
3. 一般形式：局面转向策略所意图的反面。

**摆放位置：**每个**序列**至少一个反转。单场戏可以是纯粹的升级，但一个*已解决的序列*如果零反转，就**不合格**。

**序列**是从某个具体的危及态势开启、到它收束之间的那串场景——被克服，或它击败主角、逼出一条新路。序列可以**嵌套**，每个收束单元都需要自己的反转。审计时标明你在哪个规模上审计。

## 1.5 价值位移（Value Shift）

**观众对一个角色的解读，因一次反转而发生的改变。**拱顶石，也是最被误解的要素：它不发生在纸面上，而发生在观看者的头脑里。每次反转都逼观众**重新评判**这个角色——一个他们不断修订的移动判决（*好人 → 有历练 → 狡猾 → 不对，他是走投无路 → 孝顺的儿子 → 真汉子*）。

> **核心规则：没有价值位移的反转是惰性的。**一次结构转折若不能移动观众的判决，就不算反转。如果你说不出观众会持有的**前判决**和**后判决**，这个转折就是死重——无论情节翻了多大。

审计**轨迹**而不只看有无：这些重新估值是在构建一幅不断加深的画像，还是只是在来回震荡？

# 二、因果链

> **目标**（固定；每场戏都是指向它的因果一环）
> → **障碍**（危及某一阶段或整个目标；说出什么处于风险 + 规模）
> → **策略**（被威胁逼出；合情合理的猜测；其结果必须返回信息）
> → **反转**（违背预期的转折；每个已解决序列 ≥1 个）
> → **价值位移**（观众重新评判角色；没有位移 → 反转白费）

# 三、审计流程

按顺序过一遍链条。反转与价值位移在**序列**层面评判，不在单场戏层面。

1. **目标**——用一行说出场景目标。它是指向故事目标的因果一环吗？做删除测试。不知道故事目标就去问——没有它无法完整审计目标。
2. **障碍**——说出环境态势、它究竟危及什么、以及规模。
3. **策略**——每个策略是否都被危及态势所逼、在当前知识下合理、其结果是否返回信息？标出原地空转与无动机的策略。
4. **反转**——定位它们，说出形式，确认每个已解决序列至少一个。
5. **价值位移**——对**每一个**反转，说出前判决 → 后判决。说不出，标记为**惰性**，列为首要修复项。然后评估轨迹。

### 审计输出格式

```
场景/序列：<一行身份说明>

链条检查
• 目标——<判定 + 一行说明>
• 障碍——<危及什么 + 规模 + 判定>
• 策略——<被逼出？合理？返回信息？判定>
• 反转——<形式 + 是否存在？序列内 ≥1 个？判定>
• 价值位移——<每个反转的前判决 → 后判决，或惰性；轨迹备注>

最弱点：<那一个元素，修好它能挽回最多>

如果……会怎样
1.（最小改动）<只改最弱点，让他们的场景其余部分依然成立>
2.（干净版）<一个完全成立的版本，即使它离原版更远>
3.（可选）<仅当它确实有所增益时>
```

三个层级各有意义：**最小改动保留用户的版本**，干净版是你的版本，第三层是可选的。不要把它们合并成一次重写。

# 四、链条成立之后——它在链路中的位置

链条成立，这场戏才值得花钱——而且只有在这之后：

| 下一步 | 归属 |
|---|---|
| 这些人是谁，以及他们的前史 | 角色与场景设计 |
| 共享的场景方向与每个角色的燃料 | 《表演行为主模块》§支柱之上的那一层 |
| 把谈定的场景拆成镜头 | 《镜头组接·纯技术文档》§规划层 |
| 写镜头本身 | 《提示词结构·纯技术文档》 |

**首先要猎杀的最常见真实失效：一个翻转了情节、却没有移动观众判决的反转。**在其他一切之前先把它揪出来——它扛得住通读、生成得很漂亮，却依然在剪辑里落得平淡。
