# 视觉意图四维本体（执行层）
（把"风格、写实程度、渲染器"拆开，避免一个词同时锁死四件事）

**为什么要拆**：用户说"次世代超写实 3D"时，往往只是在说**生产体系**和**写实度**，并没有授权某个渲染器。维度不拆开，执行时就会替用户做决定——这是本层最常出的错。

| 维度 | 问的是什么 | 常见取值 |
|---|---|---|
| **A 视觉生产体系** | 视觉生产范式 / 美术体系是什么 | 写实 3D / 次世代 / 电影 CG / 二次元 3D / 风格化 3D / 项目自定义 |
| **B 写实度** | 现实感强度是多少（**不是**资产生产范式） | 风格化 / 半写实 / 写实 / 超写实 |
| **C 渲染策略** | 最终视觉怎么算出来 | 实时 / 高质量实时 / 电影级离线 / 混合或特殊策略 |
| **D 渲染器** | 由哪个后端执行 | Arnold / UE5 / 其他可用渲染器或模型后端 |

**D 是执行后端，不属于前面三个视觉维度。**前三维描述"要什么样的画面"，第四维描述"拿什么去算"。

# 一、组合解析

同一个说法在不同语境下落的维度不同，按下表解析：

| 用户说法 | 解析结果 |
|---|---|
| "次世代" | A = 次世代；**B 不自动指定**；D 不自动指定 |
| "超写实 3D" | A = 写实 3D；B = 超写实；D 不自动指定 |
| "次世代超写实 3D" | A = 次世代；B = 超写实；D 不自动指定 |
| "次世代超写实 3D，Arnold" | A = 次世代；B = 超写实；C 倾向电影级离线高保真；D = Arnold |
| "次世代，UE5" | A = 次世代；D = UE5；**B 保持未指定**，除非用户另行指定 |

**要点**：只有被明确说出口的维度才落值。形容词（"超写实"）落在 B，生产体系名（"次世代""国漫"）落在 A，工具名（"Arnold""UE5"）落在 D。

---

# 二、三条约束

1. **不得因为某个风格名称推导用户未授权的渲染器。**"次世代"不等于 UE5，"电影 CG"不等于 Arnold。渲染器只能由用户指定、或由 `render/03` 的路由显式推导并标记。
2. **不得因为渲染器反向改变视觉意图。**渲染器是实现手段，不是画面定义。
3. **推导值必须标为推导值。**用户只给了部分维度时，其余维度由导演决策或项目默认补齐，但必须标记为推导值——**不得伪装成 Human Lock（用户锁定）**。回填给用户看时说清哪几个是补齐的。

# 三、与其他模块的边界

- **02 影视风格** 定影调、调色情绪、胶片模拟与色彩比例（"画面是什么调子"）；本层定载体 / 写实度 / 策略 / 后端（"这条画面用什么生产路径实现"）。两者不互相推导：定完青橙史诗调色板不等于选了 Arnold。
- **06 景别构图机位灯光** 定单镜画面语言；本层的构图轴（`render/05`）只提供**风格侧**的构图倾向，具体机位角度与灯光物理仍归 06。
- **12 技术语言转换** 承接本层的渲染决策，把渲染器技术词转成模型可执行的画面语言；本层产出的渲染器字段最后都要经 12 净化，**技术词本身不进最终提示词**。
