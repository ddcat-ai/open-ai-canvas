# 二、12 个具体流派 DNA

## 9.1 日系青春 / 青春回忆

清冷蓝、浅绿、暖高光；自然光；留白；青少年日常空间（列车、校园、海边、夏季、雨雪）；动作克制；轻颗粒、柔焦；固定机位或轻微呼吸感晃动；怀旧、孤独、温柔。

## 9.2 日系生活 / 治愈

低饱和暖色；原木、米白、抹茶绿；柔和侧逆光 / 漫射光；固定机位、长镜头；日常动作；框景、纸门、木格栅；安静、松弛、生活气。

## 9.3 娄烨式都市颓败

手持晃动；失衡构图；近距离 / 挤压式取景；浅景深、虚焦；裸露灯泡、路灯、弱天光；灰蓝、浊绿、暗青；潮湿、水汽、粗颗粒；都市边缘、旧厂房、昏暗室内；疏离、漂泊、压抑。

## 9.4 王家卫 / 杜可风港风

霓虹；绿色、蓝色、红色局部冲突；运动拖影；低速快门感；湿热、水雾、反射；柔焦与颗粒；倾斜 / 低角度跟拍；城市疏离与暧昧。

## 9.5 徐克 / 港式武侠

超广角；极低角度；倾斜失衡；前景遮挡；动态模糊；逆光高光溢出；沙尘 / 烟雾 / 雨雾；粗颗粒；剑光、衣摆、快速动作；肃杀、危险、江湖感。

## 9.6 李安 / 东方诗意武侠

自然环境框景；绿色植物遮挡；柔和自然光；浅景深；自然肤色；低饱和；雾、竹林、山水；克制、诗意、神秘。

## 9.7 中国古典戏剧 / 戏曲电影

人工化舞台布光；红、黑、金等符号色；戏剧化服装与妆面；正面 / 特写；稳定构图；强烈明暗关系；传统纹样、帷幕、戏台；表演性、宿命感、悲剧感。

## 9.8 90 年代华语胶片

暖黄、暗红、旧绿；生活空间（老居民区、婚礼厅、厨房、街道）；胶片颗粒；自然 / 室内暖光；慢推、慢拉；日常人物状态；怀旧、生活感。

## 9.9 英伦 / 欧洲田园古典

暖黄、自然绿、米白；黄金时刻；花园、森林、草地、湖泊、木屋；柔光、散景、逆光；复古胶片；长裙、草帽、花环等时代 / 田园服饰；浪漫、诗意、温柔。

## 9.10 巨物 / 宏大尺度

巨大主体；微小人物；大量负空间；宽银幕；强光束、尘埃、雾；中央构图或建筑几何；强烈比例关系；宏伟、神圣、压迫。

## 9.11 超现实 / 魔幻现实

不可能的空间关系；双重曝光；剪影与景观融合；象征性道具；超现实色彩；油画 / 绘画纹理；梦境逻辑；诗意、隐喻、奇幻。

## 9.12 纪实 / 真实摄影

手持；自然光；真实肤色；深景深；环境声音感 / 生活动作感；不刻意美化；真实、粗粝、即时。

# 三、调用纪律

- **每个流派取 3–5 项**决定画面的参数，不是整段照抄。
- 流派里的**空间与道具**（例如列车校园、纸门木格栅、旧厂房、戏台帷幕）交给 **04 场景与人物设计**落成场景资产；本层只标记"需要什么样的空间气质"。
- 流派里的**运动与机位**（手持、俯拍、慢推）交给 **06 / 08** 落成参数。
- 流派里的**人物状态与动作强度**交给 **05 人物表演**。
- 同时引用两个以上流派时，走 `render/10` 的五轴融合。
