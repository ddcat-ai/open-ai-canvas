# 一、兼容原则（七条）

1. **Medium 同轴互斥**——一个镜头只能有一个载体。
2. **Realism 同轴互斥**——不能同时写实又风格化。
3. **Art Direction 可与 Medium / Realism 组合**——它是叠加方向，不是替换。
4. **摄影提示不等于真人实拍载体**——`PHOTOGRAPHIC_REALISM` 只是"看起来像照片"，载体仍可是 HYPERREAL_3D。
5. **渲染器不反向改变视觉意图**（见 `render/01` 约束 2、`render/03` 禁止反向污染）。
6. **每个局部覆盖只覆盖明确修改的轴**——改一轴不影响其他轴的既有值。
7. **单一风格词产生既定的标准解释**；只有用户同时提供多个正交轴时，才形成显式组合。

## 典型组合

| 需求 | 组合 |
|---|---|
| 超写实 3D + 真人质感 | `HYPERREAL_3D` + `HYPERREAL` + `PHOTOGRAPHIC_REALISM` |
| 真人 + 超写实 | `HUMAN_REALISTIC` + `HYPERREAL` |
| 次世代 + 国漫风 | `NEXT_GEN` + `GUOMAN` |
| 次世代 + 超写实 3D + 真人质感 | `NEXT_GEN` + `HYPERREAL_3D` + `HYPERREAL` + `PHOTOGRAPHIC_REALISM` |
| 上者再叠冷钢色 + 窗光 + 经典静止 | 上述基础上叠加 `COLD_STEEL` + `WINDOW` + `CLASSIC_STATIC` |

**局部覆盖写法**：先锁定基础组合，再逐条追加被修改的轴，并注明"其余保持不变"。不要重写整组值——重写容易悄悄改掉用户已锁定的轴。
