# 六维视觉 DNA 与控制轴（执行层）

> **总原则：先建立视觉语法，再调用风格。**完整影视提示词不能只写"某导演风格"，而应同时处理镜头、主体、风格、光影、色彩、质感、情绪和画幅。

## 通用提示词骨架

```
[景别 / 镜头 / 运镜] + [主体 / 场景 / 动作] + [风格锚定]
+ [构图] + [光影] + [色彩] + [胶片 / 影像质感]
+ [氛围 / 情绪] + [画幅 / 输出参数]
```

等价的核心公式：**镜头运镜 + 主体内容 + 风格标签 + 光影 + 色彩 + 胶片质感 + 氛围情绪 + 画幅参数**。

进一步归纳为**四段式**：

1. **风格锚定** —— 导演 / 电影 / 类型 / 时代。
2. **质感设定** —— 胶片、镜头语言、摄影机感、颗粒、柔焦、运动模糊等。
3. **色彩与光影** —— 主色、辅色、冷暖关系、曝光、阴影、高光。
4. **构图与情绪** —— 景别、视角、留白、对称、失衡、空间关系、情绪。

# 一、六维视觉 DNA —— 调用核心接口

把"某种电影风格"拆成六个维度，作为本层的基础数据结构：

| 维度 | 控制内容 |
|---|---|
| **构图与镜头** | 景别、焦段、机位、角度、镜头运动、景深、构图秩序 |
| **色彩与光影** | 主色、辅色、冷暖、曝光、反差、高光、阴影、光源 |
| **质感与氛围** | 胶片、颗粒、柔焦、漏光、雾、水汽、粗粝、洁净、真实感 |
| **经典场景** | 能承载该风格的空间、时代、道具、环境 |
| **角色与动作** | 人物状态、姿态、互动方式、运动方式、表演强度 |
| **色调细节** | 饱和度、明度、黑位、肤色、局部色彩、色彩数量 |

## 调用原则

- **不要只调用风格名称。**
- 至少从六维中选择 **3–5 个**真正决定画面的参数。
- 用户指定**导演风格**时，优先提取其**视觉 DNA**（见 `render/08`），而不是堆叠导演姓名。
- 用户指定**类型风格**时，以"类型视觉模块 + 场景需求"生成（见 `render/09`），而不是机械套导演模板。

## 归属提醒

构图中的具体机位 / 角度 / 灯光物理 → **06**；角色动作与表演强度 → **05 人物表演**；运镜形式与参数 → **08**。本层给的是**风格侧的取值倾向**，不替代它们各自的决策。

# 二、构图轴：把风格变成可调参数

常用控制项：

- 极简构图 / 大量留白　- 对称构图　- 失衡构图　- 倾斜构图
- 前景遮挡　- 框中框　- 中央构图　- 对角线构图
- 低角度 / 极低角度　- 高角度 / 俯拍
- 广角空间压迫　- 长焦压缩
- 浅景深 / 深景深
- 主体孤立 / 群像
- 大尺度环境 + 微小人物

## 选择逻辑（情绪 → 构图）

| 目标情绪 | 取构图 |
|---|---|
| 孤独 / 禅意 | 大留白、远景、主体缩小 |
| 紧张 / 失控 | 倾斜、失衡、近距离、前景遮挡 |
| 绘本 / 秩序 | 对称、平面化、明确几何关系 |
| 宏大 / 史诗 | 超宽画幅、广角或空间展开、大环境比例 |
| 亲密 / 情绪特写 | 近景、浅景深、局部遮挡 |

**用法**：先定情绪，再从表里取构图组合，而不是反过来先挑好看的构图。构图必须与 06 的空间约束（`shotlang/07-空间约束.md`）兼容——本层定倾向，06 定能不能落地。
