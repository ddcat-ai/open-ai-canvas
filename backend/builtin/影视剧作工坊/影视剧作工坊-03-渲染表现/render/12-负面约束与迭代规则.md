# 执行规则与负面约束（执行层）

## 七条执行规则

**Rule 01 · 风格先拆解，后生成。**收到"做成某某电影感"时，先把它解析成：构图 / 光影 / 色彩 / 质感 / 场景 / 动作 / 情绪。

**Rule 02 · 风格名不是最终提示词。**导演 / 电影名只负责**风格锚定**，真正生成依赖视觉属性。

**Rule 03 · 优先少量高权重特征。**每次优先选择 **3–7 个**决定性视觉特征，而不是把词库全部塞入。

**Rule 04 · 镜头参数是辅助层。**摄影机、胶片、滤镜、焦段、光圈可作为风格参考与强化层；**不能替代**主体、构图、光影和色彩描述。

**Rule 05 · 图片和视频分别优化。**同一套文字用于生图和生视频，实际输出会有差异；视频必须额外处理运动、镜头、环境动态（见 `render/11`）。

**Rule 06 · 允许迭代。**生成不理想时按顺序尝试：① 换模型；② 删除无效词；③ 修改镜头参数；④ 强化主色 / 光影；⑤ 增加负面约束；⑥ 多轮测试。

**Rule 07 · 不要承诺 100% 复刻。**提示词只是风格引导，模型性能与生成参数会影响结果。本层输出的是**视觉 DNA / 风格方向**，不是"保证与原片一致"。

# 一、负面约束

> 本层不规定固定负面词表，而是**按目标风格建立反向约束**。成表与按类取用归 **13 交付文件审核（负面约束总库）**——本层只负责按类生成，不负责机械堆入最终提示词（`render/04` 第 6 条）。

## 通用反向约束

```
unwanted text
watermark
logo
random typography
overprocessed skin
plastic skin
excessive sharpening
oversaturated colors
inconsistent lighting
unnatural anatomy
uncontrolled motion blur
excessive depth of field
generic stock-photo look
```

## 按目标风格生成的示例

目标是**低饱和日系**：

```
no excessive saturation
no harsh studio lighting
no deep crushed blacks
no excessive contrast
no glossy commercial look
```

目标是**粗粝港片**：

```
no clean digital look
no sterile lighting
no excessive skin smoothing
no perfectly balanced composition
```

**生成原则**：反向约束必须与所选策略一一对应——选了"少色多阶"就禁"oversaturated"，选了"低饱和生活流"就禁"glossy commercial look"。为写而写的通用堆砌会削掉画面里本来想要的东西。

# 二、来源中的关键使用原则

- 不同模型生成效果存在差异。
- 生图与生视频使用同一套提示词时，输出效果也可能不同。
- 可按需叠加镜头、胶片、光影关键词强化质感。
- **无法保证 100% 复刻原版影视画面。**
- 建议多次调试迭代，并结合负面提示词。
