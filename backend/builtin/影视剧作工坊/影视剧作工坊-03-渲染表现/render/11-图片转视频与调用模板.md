# 图片 → 视频转换与调用模板（执行层）

## 视频提示词稳定结构

```
[运镜] + [风格标签] + [场景] + [主体动作]
+ [光效] + [色调] + [胶片颗粒 / 柔焦等质感] + [情绪]
```

## 基础运镜词

缓慢推近 / 缓慢拉远 / 横向移动 / 跟拍 / 低角度跟拍 / 固定机位 / 轻微推拉变焦 / 缓慢小幅推近 / 轻微呼吸感晃动。

> 这里的运镜词是**风格侧的自然语言**（初稿），最终仍须经 **08** 落成具体参数与预设名、经 **12** 转为模型语言。

## 视频动作五维原则

不要只写"人物走路，镜头推进"。应写清五个维度：

```
人物动作 + 镜头动作 + 环境动态 + 需要捕捉的细节 + 最终情绪
```

示例：

> 镜头缓慢推近，人物保持克制表情，发丝被微风轻轻吹动，背景树叶产生细微晃动，捕捉眼神与面部高光变化，传递安静而压抑的情绪。

**这条原则是本层与静态视觉描述的最大区别**：同一套文字用于生图和生视频，输出会有差异；进入视频链必须补齐这五维。

# 四、最终生成公式

```
主体与场景 → 叙事 / 情绪目标 → 风格锚定 → 构图与景别 → 光影
→ 色彩 → 质感 → 环境细节 → 人物动作 → 运镜 → 画幅
→ 负面约束 → 输出 → 评估 → 迭代
```

> **核心思想：风格不是一串形容词，而是一组相互关联的视觉决策。**

真正进入技能体系的不是一个可以复制的句子，而是这条链路：

```
风格识别 + 视觉 DNA 拆解 + 参数化控制 + 模块组合
+ 冲突检测 + 图片 / 视频分流 + 负面约束 + 迭代优化
```
