# 一、剂量纪律

- **质感不是越多越好。**根据目标风格选择 **2–4 个核心质感组件**。
- 典型反模式：**胶片 + 柔焦 + 漏光 + 颗粒 + 强运动模糊 + 高反差**全部同时堆叠 → 各组件互相打架，模型无所适从，画面既不像胶片也不像数字。
- **每组最多取 1–2 个**：例如"胶片组取 heavy film grain + 光学组取 halation + 环境组取 fog"，共 3 个，落在剂量内。
- 需要突破 4 个时，必须是用户显式要求（对齐 `render/04` 第 3 条风格剂量）。

## 与相邻模块的对接口

- 运动质感里的手持抖动 / 呼吸感 → 与 **08 的 `moves/09-镜头运动预设库.md`** 取同名预设，避免写完 VP 又写另一种抖动。
- 胶片颗粒 / 漂白旁路 → 与 **02 的 `style/04-胶片模拟与调色一致性.md`** 对齐，同一序列逐字重复，措辞漂移就是观感漂移。
- 环境质感里的雾 / 水汽 / 体积光 → 需要介质才能让光有形，依据见本模块 `engine/E03` 的「让光可见：先给光一个介质」。
