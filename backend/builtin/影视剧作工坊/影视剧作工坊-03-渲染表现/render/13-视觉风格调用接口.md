# 视觉风格调用接口（执行层）

其他影视技能需要视觉风格时，按以下字段取值。字段与 `render/03-渲染智能路由.md` 的 `SHOT_RENDER_PROFILE` 互补：**profile 管"怎么渲染"，本结构管"渲染出来什么样"**。

```yaml
visual_style:
  anchor: ""
  composition:
    framing: ""
    camera_angle: ""
    focal_length: ""
    depth_of_field: ""
    spatial_structure: ""
  lighting:
    source: ""
    direction: ""
    hardness: ""
    contrast: ""
    highlight_behavior: ""
    shadow_behavior: ""
  color:
    dominant: ""
    secondary: ""
    temperature: ""
    saturation: ""
    luminance: ""
    skin_tone: ""
  texture:
    film_stock_feel: ""
    grain: ""
    diffusion: ""
    flare: ""
    atmosphere: ""
    motion_texture: ""
  environment:
    setting: ""
    period: ""
    props: ""
  performance:
    posture: ""
    movement: ""
    interaction: ""
    emotional_state: ""
  cinematography:
    shot_size: ""
    camera_motion: ""
    aspect_ratio: ""
  negative_constraints:
    - ""
```

## 字段级映射规则

- **不压缩回单一风格字符串。**拆解结果必须落在各自的独立字段里（对齐 `render/04` 第 8 条）。
- 留空字段表示**该维未设计**，下游不得自行填充；需要补齐时回到 `render/05` 的六维 DNA 决策。
- `negative_constraints` 是**列表**，按来源分类追加（通用 / 风格 / 镜头与动作 / 人物 / 模型能力），见 `render/12`。
- 交付给 **12** 时，`focal_length` / `temperature` / `aspect_ratio` 这类技术字段连同转译值一起给（原值 + 模型语义版），不得只给画面语言。
- `composition` / `lighting` / `cinematography` 三项与 **06** 重叠时，**本结构给风格倾向，06 给落地参数**，以 06 为准；同理 `performance` 以 **05** 为准。
