# 一、三大光影系

## 1.1 柔和自然系

核心词：`soft diffused light` / `natural light` / `warm golden hour` / `gentle backlight` / `soft side light` / `dappled sunlight` / `dreamy glow`

适合：青春、爱情、日系治愈、田园、回忆、生活流。

## 1.2 冷峻压迫系

核心词：`deep shadows` / `hard side light` / `rear rim light` / `chiaroscuro` / `low-key lighting` / `cold ambient light` / `muted highlights`

适合：悬疑、犯罪、疏离、都市颓败、黑暗文艺。

## 1.3 戏剧化人工光

核心词：`non-naturalistic theatrical lighting` / `stage lighting` / `top light` / `strong rim light` / `blown-out highlights` / `colored gel lighting`

适合：戏曲、武侠老片、惊悚、超现实、高度人工化视觉。

**取材方向**：先定题材要去哪一类，再在该类里选 2–3 个共存的词。跨系混用（如柔光 + 极硬顶光）要走 `render/10` 的冲突检测。

# 二、色彩系统

不要把调色理解成简单的颜色滤镜。真正有效的是这八个字段的组合：

```
主色 + 辅色 + 冷暖关系 + 饱和度 + 明度 + 黑位 + 高光颜色 + 局部强调色
```

## 2.1 少色多阶

代表逻辑：减少颜色数量；用明度和纹理制造层次；整体降低饱和度；让单色系内部产生丰富层次。

适合：宏大、沉重、荒凉、科幻、历史质感。

## 2.2 高饱和符号色

代表逻辑：红、黄、蓝、绿等强色作为**视觉符号**；让颜色承担情绪或叙事功能；不追求"自然校色"。

适合：戏剧化、类型化、舞台感、强烈东方视觉。

## 2.3 冷暖对冲

典型组合：**冷蓝 / 青绿背景 + 暖黄 / 橙色局部光源**。

用于建立：人与环境的距离、危险感、温柔与疏离、城市夜景、怀旧与现实的冲突。

## 2.4 低饱和生活流

典型组合：**暖灰 + 米白 + 低饱和绿 / 蓝 + 自然肤色**。

适合：日常、家庭、治愈、纪实、生活电影。

## 落地纪律

- 落到具体颜色和比例时，走 02 的 **60/30/10**（60% 主导 + 30% 次要 + 10% 点缀）与"每个色绑定一个来源和一个表面"。
- 选完策略后回查是否与该场景的灯光系冲突——例如"低饱和生活流"配"戏剧化彩色片光"必须走冲突处理。
