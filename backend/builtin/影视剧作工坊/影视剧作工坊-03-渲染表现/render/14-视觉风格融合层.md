# 影视视觉风格融合规则

本模块是对现有主系统Visual Style / Style Composition / Camera / Lighting / Color / Continuity / D-CG 能力的扩展，不替换、不压缩原能力。

## 1. 完整保留
- 《影视视觉风格精华熔炼模块_原文.md》为完整来源资产，原文保留。
- 六维视觉 DNA、视觉控制轴、光影系统、色彩系统、影像质感、15 位导演视觉 DNA、15 种通用影视视觉风格、风格融合、冲突检测、图片→视频规则、负面约束、调用模板和执行规则全部进入融合层。

## 2. 风格不是单个标签
风格调用优先拆解为：构图与镜头、色彩与光影、质感与氛围、经典场景、角色与动作、色调细节。

## 3. 五轴融合
实际组合至少按：构图 / 光影 / 色彩 / 质感 / 动作与运镜五轴处理。导演名或电影名只作为风格锚点，不作为最终提示词的唯一内容。

## 4. 风格剂量
默认每次优先选择少量高权重特征；质感组件不无限堆叠。原文建议的 2–4 个核心质感组件作为默认控制范围，但用户显式要求时允许突破。

## 5. 风格冲突
冲突检测不得静默删除用户明确要求。默认采用主导系统 + 局部点缀；明确要求混合冲突时保留冲突，并将冲突作为视觉意图的一部分传递到 D-CG。

## 6. 视频优先增加动态
图片视觉描述进入视频链时，必须额外处理：人物动作、镜头动作、环境动态、细节捕捉、最终情绪。

## 7. 负面约束
Negative 按通用、风格、镜头/动作、人物、模型能力等来源组织。不能把所有 Negative 机械堆入最终提示词。

## 8. 参数化与不丢真相
焦段、光圈、色温、帧率、时长等技术字段可以生成模型语义，但技术真相本身不能因语义化而删除。

## 9. 统一 IR 映射
视觉 DNA 进入 Unified Director IR 的 visual.visual_dna 扩展，同时映射至 composition / lighting / color / texture / performance / camera / negative 等正式字段。

## 10. 最终输出
融合后的视觉能力最终必须回到既有链路：

Director Truth → Generation Truth → D-CG → Validation → Final Delivery Truth → ①～⑩。

# Style Composition Matrix 5.0

## 轴
- Medium：HUMAN_REALISTIC / REALISTIC_3D / HYPERREAL_3D / CINEMATIC_CG / ANIME_3D / STYLIZED_3D / SEMI_REALISTIC_3D
- Art Direction：NEXT_GEN / GUOMAN / ANIME_COMIC
- Realism：HYPERREAL / REALISTIC / SEMI_REALISTIC / STYLIZED
- Photographic Cue：PHOTOGRAPHIC_REALISM
- Palette：8种Cinema Studio色彩轴
- Lighting：6种灯光轴
- Camera Moveset：9种Cinema Studio机位运动风格
- Render Strategy：REALTIME / HIGH_QUALITY_REALTIME / OFFLINE_CINEMA
- Renderer：ARNOLD / UE5 / OCTANE

## 兼容原则
1. Medium同轴互斥。
2. Realism同轴互斥。
3. Art Direction可以与Medium/Realism组合。
4. Photographic Cue不等于Live Action Medium。
5. Renderer不反向改变Visual Intent。
6. 每个局部覆盖只覆盖明确修改的轴。
7. 单一风格词产生既定的标准解释；只有用户同时提供多个正交轴时才形成显式组合。

## 典型组合
- 超写实3D + 真人质感 → HYPERREAL_3D + HYPERREAL + PHOTOGRAPHIC_REALISM
- 真人 + 超写实 → HUMAN_REALISTIC + HYPERREAL
- 次世代 + 国漫风 → NEXT_GEN + GUOMAN
- 次世代 + 超写实3D + 真人质感 → NEXT_GEN + HYPERREAL_3D + HYPERREAL + PHOTOGRAPHIC_REALISM
- 超写实3D + 真人质感 + 冷钢色 + 窗光 + 经典静止 → 在上述基础上叠加 COLD_STEEL + WINDOW + CLASSIC_STATIC

from __future__ import annotations

import json
import re
from pathlib import Path
from typing import Any, Dict, List

ROOT = Path(__file__).resolve().parents[1]
REGISTRY_PATH = ROOT / "REGISTRY" / "VISUAL_DNA_REGISTRY.json"


def _load_registry() -> Dict[str, Any]:
    with REGISTRY_PATH.open("r", encoding="utf-8") as f:
        return json.load(f)


def _norm(text: str) -> str:
    return re.sub(r"\s+", " ", str(text or "")).strip()


def _contains(text: str, phrase: str) -> bool:
    return bool(phrase) and phrase.lower() in text.lower()


def detect_director_dna(text: str) -> List[Dict[str, Any]]:
    t = _norm(text)
    data = _load_registry()
    out: List[Dict[str, Any]] = []
    for name, dna in data.get("directors", {}).items():
        aliases = [name]
        if name == "Wong Kar-wai / Christopher Doyle": aliases += ["王家卫", "杜可风", "Wong", "Kar-wai", "Doyle", "王家卫/杜可风"]
        if name == "Takeshi Kitano": aliases += ["北野武", "Kitano Blue"]
        if name == "Hirokazu Kore-eda": aliases += ["是枝裕和"]
        if name == "Zhang Yimou": aliases += ["张艺谋"]
        if name == "Ang Lee": aliases += ["李安"]
        if name == "Denis Villeneuve / Greig Fraser": aliases += ["维伦纽瓦", "Greig Fraser"]
        if name == "Nolan / Hoyte van Hoytema": aliases += ["诺兰", "Hoyte van Hoytema"]
        if name == "Emmanuel Lubezki": aliases += ["Lubezki", "卢贝兹基"]
        if name == "Vittorio Storaro": aliases += ["斯托拉罗"]
        if name == "Dario Argento": aliases += ["阿金托"]
        if name == "Guy Ritchie": aliases += ["盖·里奇", "盖里奇"]
        if name == "Wes Anderson": aliases += ["韦斯·安德森", "韦斯安德森", "Wes"]
        if name == "David Fincher": aliases += ["大卫·芬奇", "芬奇", "Fincher"]
        if name == "Roger Deakins": aliases += ["罗杰·迪金斯", "迪金斯", "Deakins"]
        if name == "Tarantino / Robert Richardson": aliases += ["昆汀", "理查德森"]
        matched = next((a for a in aliases if _contains(t, a)), None)
        if matched:
            out.append({"name": name, "matched_alias": matched, "dna": dna, "source": "影视视觉风格精华熔炼模块"})
    return out


def detect_generic_styles(text: str) -> List[Dict[str, Any]]:
    t = _norm(text)
    data = _load_registry()
    out: List[Dict[str, Any]] = []
    for name, dna in data.get("generic_styles", {}).items():
        if _contains(t, name):
            out.append({"name": name, "dna": dna, "source": "影视视觉风格精华熔炼模块"})
    return out


def build_visual_dna(text: str, existing: Dict[str, Any] | None = None) -> Dict[str, Any]:
    data = _load_registry()
    t = _norm(text)
    directors = detect_director_dna(t)
    generic = detect_generic_styles(t)
    return {
        "source": "VISUAL_STYLE_FUSION",
        "dimensions": data["dimensions"],
        "director_dna": directors,
        "generic_styles": generic,
        "control_axes": data["control_axes"],
        "lighting_systems": data["lighting_systems"],
        "color_systems": data["color_systems"],
        "style_fusion": data["style_fusion"],
        "negative": data["negative"],
        "video_bridge": data["video_bridge"],
        "requested_text": t,
        "existing_visual_state": existing or {},
    }


def build_video_visual_bridge(text: str, camera_motion: str = "", action: str = "", environment_motion: str = "", details: str = "", emotion: str = "") -> Dict[str, Any]:
    data = _load_registry()
    return {
        "order": data["video_bridge"]["order"],
        "camera_motion": camera_motion,
        "style_anchor": detect_director_dna(text) or detect_generic_styles(text),
        "scene": None,
        "subject_action": action,
        "environment_motion": environment_motion,
        "captured_details": details,
        "emotion": emotion,
        "required_motion_dimensions": data["video_bridge"]["required_motion_dimensions"],
    }


def style_conflict_pairs() -> List[List[str]]:
    return _load_registry()["style_fusion"]["conflicts"]

源内容 → 完整源资产 → 视觉知识索引 → 视觉 DNA → 视觉参数轴 → 风格组合 → 冲突检测 → 视频化 → Prompt Compiler → D-CG → Validation

不允许：
- 用本模块替换原 VISUAL/STYLE_COMPOSITION_MATRIX_5_0.md
- 用“15 位导演”替换原有 Higgsfield / Hollywood / 其他视觉能力
- 用单一 style 字符串吞掉构图、光影、色彩、质感、动作/运镜等正交轴
- 把技术参数语义化后从导演真相删除

## 2. 章节 1：总原则 / 通用提示词骨架

源能力：
- 景别 / 镜头 / 运镜
- 主体 / 场景 / 动作
- 风格锚定
- 构图
- 光影
- 色彩
- 胶片/影像质感
- 氛围/情绪
- 画幅/输出参数
- 四段式风格锚定、质感、色彩光影、构图情绪

归位：
- FUSED_CORE/engines/director_fusion_engine.py：导演视觉决策
- FUSED_CORE/engines/style_composition.py：风格组合
- Prompt Compiler：最终提示词排序
- D-CG：技术语言 → 可观察结果
- Unified Director IR：visual / camera / composition / lighting / render / timeline

新增字段：visual.prompt_skeleton、visual.primary_intent、visual.evidence_list。

## 3. 章节 2：六维视觉 DNA

六维：
1. 构图与镜头
2. 色彩与光影
3. 质感与氛围
4. 经典场景
5. 角色与动作
6. 色调细节

归位：VISUAL/视觉智能核心。

与现有四维 Visual Intent 的关系：
- 生产体系/写实度/渲染策略/渲染器继续保持原有正交定义。
- 六维 DNA 作为更上层的“视觉决策描述层”。
- 不把 DNA 维度直接改造成 Renderer 或 Medium。

新增：visual_dna.schema.json、visual_dna_engine。

同时保留其“情绪 → 构图选择”的决策表，形成 composition_intent_map。

## 11. 章节 10：风格融合引擎

这是本模块最重要的增强项之一。

五轴：
- 构图语言
- 光影语言
- 色彩语言
- 质感语言
- 动作 / 运镜语言

融合规则：主导轴 + 局部轴 + 权重 + 场景范围 + Shot Override。

新增：STYLE_CONFLICT_MATRIX。

冲突族完整保留：
- 平面柔光 ↔ 极端硬光
- 极低饱和 ↔ 极高饱和
- 静态固定机位 ↔ 强烈高速运动
- 极致对称 ↔ 强烈失衡
- 真实自然光 ↔ 高度人工舞台光
- 极简留白 ↔ 元素密集
- 细腻洁净 ↔ 粗粝重颗粒

除非用户明确要求冲突混合，否则主导系统优先，其他作为局部增强。

## 12. 章节 11：图片 → 视频转换

进入 Video Generation Planning，不进入单纯图片 Prompt。

必须同时考虑：
- 人物动作
- 镜头动作
- 环境动态
- 需要捕捉的细节
- 最终情绪

映射：performance / camera / environment / generation_unit / timeline。

## 13. 章节 12：风格调用模板

禁止机械复制模板句式。

## 14. 章节 13：负面提示词 / 质量约束

## 15. 章节 14：技能执行规则

全部并入 Prompt Quality Policy：
- 风格先拆解，后生成
- 风格名不是最终 Prompt
- 少量高权重特征
- 镜头参数为辅助层
- 图片和视频分流
- 允许迭代
- 不承诺 100% 复刻

新增 evidence-first 规则：抽象词必须转成可见证据。

## 17. 章节 16：最终生成公式

“主体与场景 → 叙事/情绪 → 风格锚定 → 构图 → 光影 → 色彩 → 质感 → 环境 → 动作 → 运镜 → 画幅 → negative”

固化为 Prompt Compiler 的默认排序策略。

但模型适配器可以在不改变 Truth 的前提下调整表达顺序。

## 18. 章节 17：使用原则

进入运行时质量策略：
- 模型差异
- 图片/视频差异
- 镜头/胶片/光影作为强化层
- 不承诺 100% 复刻
- 多轮调试与负面约束
