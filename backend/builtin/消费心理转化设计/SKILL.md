# 消费心理：影响力/行为经济/定价锚点

> 本包由 50 张方法论重铸卡汇编重铸（卡片明细与出处见各卡 frontmatter 的 source_card / source_book）。

## 何时调用

当写带货口播、广告脚本、详情页与直播话术，需要设计转化结构时调用（本包由 41 张方法论卡汇编而成，整理自《无价：洞悉大众心理玩转价格游戏（经典版）》、《影响力（经典版）》、《怪诞行为学（全5册）》、《思考，快与慢》）。核心能力：转化心理：价格锚点/比价阻断/参考价呈现/社会证据/稀缺与承诺一致性。关键触发：“口播没转化”、“客户只问多少钱 / 拿着别家报价单来砍”、“详情页怎么摆价格”、“划线价会不会被当成虚假宣传”、“找大 V 还是素人背书”、“试用完怎么让他下单”、“涨价了怕被骂”。工位边界：本包负责创作方法论层（卖点与价格怎么讲）；提示词语法与模型参数走影策官方市场技能，两者接力不抢戏。

## 本包交付什么

用户提出需求时，本包最终交付：

1. **转化结构（钩子/信任链/价格锚点/CTA）**
2. **选择架构设计**
3. **对比与排序方案**

### 内容保真优先级

冲突时按此顺序裁决，禁止圆场：

1. **用户明确指定**（时长/风格/禁项/参考职责）；
2. **锚点真实存在不是虚构**；
3. **选择架构不欺骗只降低决策成本**；
4. 风格与质感装饰。

### 默认决策

用户未指定时采用，并在交付前用一句话说明选了什么：

- **锚点：未说则设一个高阶参照**
- **选项：默认三个（含一个明显次优）**
- **紧迫感：默认不用虚假稀缺**

### 质量门槛

交付前逐项自检，任一项不过就改完再交：

- [ ] 是否有可信锚点
- [ ] 选项数量是否可控（不超五个）
- [ ] 是否避免虚假稀缺与误导
- [ ] CTA 是否单一明确
