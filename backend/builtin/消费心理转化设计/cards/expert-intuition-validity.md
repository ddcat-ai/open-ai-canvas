## I — 解释

这一章的来历本身就是它可信度的一部分。卡尼曼与加里·克莱因立场完全对立——卡尼曼研究偏见，认为直觉常常出错；克莱因研究自然主义决策，认为消防指挥官和护士的直觉极其可靠。他们花了七八年做"**对抗性合作**"，目标是找出双方都同意的边界。所以这一章的结论不是某一派的主张，而是**两派共同签字的部分**。

结论出人意料地简洁。直觉之所以有时神奇有时灾难，取决于两个**环境属性**，与人无关：

**条件一：环境有足够的规律可循（可预测性）。**
火场的物理规律稳定，象棋的规则不变，急诊病人的生理体征有规律。长期股票走势、政治事件、企业五年后的命运——没有稳定规律，或规律被噪声淹没。

**条件二：有通过长期训练学到这些规律的机会，且反馈及时明确。**
象棋大师需要约 **10,000 小时**专注练习（约 6 年 × 每天 5 小时）。火场指挥官需要十年以上真实与虚拟演练。反馈必须**快**（几分钟到几小时）且**明确**（对/错清晰）。基金经理的反馈延迟数月且被噪声淹没；面试官的反馈延迟一年且只能看到录用者（拒掉的人没有反事实数据）。

**第三条是铁律，也是最实用的一条：主观自信不携带任何有效性信息。**

这条为什么重要？因为常识用的判据恰恰是"资历"和"自信"，而这两个都无效：

- 长期政治预测者与股票分析师在**有效性为零**的环境中工作，但他们的主观自信与消防指挥官毫无区别
- 泰特罗克的观察："**最为过度自信的专家更有可能代表全体员工出现在新闻节目中**"
- 重症监护室里自评"完全确定"的临床诊断中，**40% 是错的**
- 11,600 份 CFO 对标普指数的预测与真实值相关系数**接近零**

自信来自故事的连贯度（见 `wysiati-evidence-audit`），而故事的连贯度与环境是否可预测**毫无关系**。低效度环境里的专家不会感到不确定——他们只是在为噪声编故事，而编故事的顺畅感和真本事的顺畅感在主观上完全一样。

还需要区分一件事：**替代产生的不是直觉，是伪直觉。**《眨眼之间》里哈丁总统的当选（高个子、宽下巴、看起来像果断领袖）经常被当作"直觉的力量"，卡尼曼一句话点破——那是选民把"他会是个好总统吗"替换成了"他看上去像个好总统吗"。快速判断有两个完全不同的来源：**再认**（有效）与**替代**（无效），而它们在主观上难以分辨。

最后一层：西蒙的定义把神秘性去掉了——直觉就是**识别 + 检索**。"这个棋局给了我们提示，根据这个提示我们可以搜寻到大脑存储的信息。"因此当专家说"我说不清为什么"时，卡尼曼与克莱因**一致认为**那些线索是**可以被系统调查出来的**（阔步男孩雕像的例子）。"说不清"不等于"不可分析"——这直接通向 `formula-over-intuition`。

## A1 — 书中的应用

**案例一：克莱因的火场指挥官（正面）**
指挥官并非在两个方案间比较选择，而是**只生成一个方案**，在脑中模拟，行则执行，不行则调整或换下一个（预认知决策模式）。这需要十年以上的真实与虚拟演练。环境规律性高（火的行为遵循物理）、反馈即时（几分钟内知道对错）——两条件齐备。

**案例二：长期政治预测与股票投资（反面）**
泰特罗克的研究显示长期政治预测的准确度接近随机。卡尼曼把这类叫"**零效度环境**"。关键不是这些人不聪明或不努力，而是**环境里没有可学的规律**。在这样的环境里，经验积累的不是技能，是**更连贯的故事**和**更强的自信**。

**案例三：CFO 与临床医生的自信/准确度脱钩**
上文数据。这两组人分属完全不同的领域，却给出同样的模式：自信与准确度**互不相关**。

**案例四：阔步男孩雕像与哈丁总统（同一本书的一正一反）**
格拉德威尔《眨眼之间》开篇：艺术专家本能地认为雕像是赝品却说不清为什么——卡尼曼与克莱因认为这类线索**可以被系统调查出来**，是真直觉。同书的哈丁总统：因为长得像果断领袖而当选——**这是替代，不是直觉**。同一本书里的两个案例，一个是再认，一个是伪直觉，这个对照是本 skill 最好的教学素材。

## A2 — 触发场景

### 什么时候用

- 有人用资历或自信来支持一个判断（"我干这行 20 年了"）
- 招聘决策中面试官说"我对这个人有感觉"（**最高频场合**）
- 投资/交易中的"盘感"、"这只票不对劲"
- 代码 review 的"我觉得这里有问题但说不上来"
- 医疗、运维、安全、客服等一线人员的"不对劲"预警
- 要决定**某个岗位/流程该不该用结构化评分替代人工判断**
- 招募顾问、专家证人、行业老兵之前
- 你自己产生了一个强烈的直觉，要决定押多少

### 语言信号

> "相信我，我干这行 20 年了" / "我的直觉一向很准" / "我一眼就看出来了" / "这个我有感觉" / "老法师说了没问题" / "凭经验判断" / "数据不重要，关键看人" / "我在这行见得多了" / "说不上来，就是觉得不对"

**结构性信号**（这才是判据）：
- 该领域的**反馈延迟**有多长？（分钟 → 可信；月/年 → 不可信）
- 反馈**明确**吗？（有清晰对错 → 可信；被噪声淹没、可争辩 → 不可信）
- 该人是否见过**足够多同类案例并知道结果**？（注意：面试官几乎从不知道被拒者的结果）
- 环境近期是否**发生了结构性变化**？（规律变了，旧直觉失效）

### 与相邻 skill 的区分

| 情况 | 用这个 | 不用这个 |
|---|---|---|
| 判断**某个领域**的直觉整体上可不可信 | ✅ `expert-intuition-validity` | |
| 抓出"这一次的快答案其实是替换" | | → `question-substitution-check`（单次提问 vs 整个领域） |
| 审计"我这次的自信来自多少证据" | | → `wysiati-evidence-audit` |
| 决策将落未落，要制度化引入怀疑 | | → `premortem-doubt-injection` |
| 已判定直觉不可信，要装替代方案 | | → `formula-over-intuition`（本书已验证 · 待整理；本 skill 的标准下游） |

**本 skill 是三个预测类 skill 的前置分诊**：它只回答"这里的直觉能不能当证据"，**不产出任何预测值**。判定完成后按问题形态转交——
- 要一个**个案的概率/归类** → `base-rate-anchoring`（定起点）
- 要一个**项目的工期/成本/成败** → `outside-view-forecast`（定分布）
- 要给一个**已有直觉预测**决定收缩幅度 → `regression-prediction-moderation`（定从起点向直觉走多远）；本 skill 第 3 步给出的效度档位可直接当作那里的 r。

若你在本 skill 里开始报数字，说明已经越界，应转交上述之一。

## E — 执行

1. **先把领域写清楚**，不是把人写清楚。判定对象是"在 ____ 这类判断上"，不是"张三这个人"。同一个人的直觉在不同任务上有效性可以完全相反（急诊医生判断病情 vs 判断股票）。

2. **测条件一：环境规律性**。三个问题：
   - 同样的输入是否倾向于产生同样的结果？
   - 这个领域是否存在**对抗性主体**（竞争对手、市场对手方）在主动破坏规律？
   - 近 2–3 年环境是否发生了结构性变化（技术、监管、竞争格局）？

   有对抗性主体或刚发生结构变化 → 规律性打折。

3. **测条件二：训练与反馈**。四个问题（这一组是本 skill 的主力）：
   - 反馈**延迟**多久？（分钟/小时 → 强；天/周 → 中；月/年 → 弱）
   - 反馈**明确**吗？（结果清晰可判 → 强；可争辩、可归因于外部 → 弱）
   - 此人处理过**多少个同类案例并知道结果**？
   - **反事实是否可见**？（被拒的候选人后来如何？没投的项目后来如何？看不到反事实 = 学不到规律）

4. **⚠️ 明确不看的三样东西**：资历年限、主观自信、表达流畅度。把它们从判据里划掉。X8 的推论很硬：**一旦把"我的把握有多大"纳入判据，本 skill 立即失效。**

5. **出判定，三档**：
   - **可信**（两条件都强）：接受快速判断，但仍保留记录以便校准
   - **部分可信**（规律性强但反馈弱，或反之）：把直觉当作**一条输入**而非结论；用于**生成假设**，不用于**下结论**
   - **不可信**（任一条件严重不足）：直觉只用于生成候选项，判定改用外部程序

6. **区分再认与替代**。若判定为"部分/不可信"，追问一句："如果你不知道任何数据，仅凭那几秒能得出这个结论，那你实际在测量什么？"常见答案：他像不像典型样本、我喜不喜欢他、他看起来自不自信。这一步转 `question-substitution-check`。

7. **不可信时装替代程序**（不要停在"别信直觉"）：
   - 结构化评分表（转 `formula-over-intuition`）
   - 参考类别数据（转 `outside-view-forecast`）
   - 结构化打分**之后**再允许一次整体直觉判断（以色列军队的"闭上眼睛"方案）

8. **给可信的直觉装校准回路**。让专家**事先写下**预测与置信度，事后对账。这既是校准，也是把一个"部分可信"领域推向"可信"的唯一路径——荷兰皇家壳牌的地质学家正是这样被训练出来的。

## B — 边界

### 不适用的情况

- **紧急且无替代方案**时。火场、急诊、事故现场——没有时间做判定，且这些恰好多是高效度环境。事后再校准。
- **生成假设阶段**。即便在零效度环境里，专家的直觉也是很好的**假设来源**（"我觉得这里有问题"值得去查）。本 skill 限制的是把直觉当**结论**，不是当**线索**。
- **审美、创意、品味判断**。这里不存在客观的"准确度"，两条件不适用。
- **纯粹的领域知识问答**。"这个 API 有什么坑"是检索事实，不是直觉预测。

### 失败模式

1. **把它变成对人的贬低**。"你的直觉不可信"会被听成"你不专业"，触发 `autonomy-reactance` 式抵抗。正确说法是把判据放在**环境**上："这个领域的反馈要等一年，谁在这里都很难积累准确直觉，包括我。"
2. **判定完就结束**。宣布"直觉不可信"而不装替代程序，结果是决策照旧靠直觉，只是多了一次不愉快。第 7 步必须做。
3. **用它给自己的直觉背书**。"我这个领域反馈很快，所以我的直觉可信"——注意条件二还要求**足够多的案例**和**可见的反事实**。自评时最容易漏掉反事实那一条。
4. **一刀切**。同一个人在同一岗位上，不同任务的有效性差异极大。销售总监对"这个客户会不会签"（反馈快）可能很准，对"这个市场三年后多大"（反馈慢）几乎无效。必须按**任务**判定，不是按**人**。

### 盲点

- **低效度环境中的自信同样强烈**（X8）。这是本 skill 存在的理由，也是它最难被接受的地方——被判定者会真诚地感到自己很准，因为他确实记得很多次"我早就说过"（后见之明会补齐记忆，见 `hindsight-narrative-guard`）。
- **反事实不可见是最隐蔽的杀手**。招聘、投资、审批这些领域的共同特征是：你只能看到"通过者"的结果。没有反事实就学不到规律，无论做多少年。
- **两条件是必要条件，不是充分条件**。满足两条件只说明**有可能**形成有效直觉，不保证这个人已经形成了。第 8 步的校准记录是唯一的实证手段。
- **本书方法论的共享边界**：不要援引第 3–5 章的启动效应与自我损耗（复现失败，作者已撤回信任）。本 skill 的证据基础（克莱因的自然主义决策研究、泰特罗克的预测研究、CFO 与 ICU 数据）与之无关，且来自对立学派的共同结论，稳固性很高。
- **卡尼曼自认直觉没变好**。四十年研究后，他改善的是识别他人错误的能力和"要求安装程序"的自觉。本 skill 的正确用法是**在流程里加一个"这个领域的反馈延迟是多久"的字段**。

### 容易混淆的概念

- **直觉 ≠ 猜测**。西蒙的定义：直觉是识别 + 检索，是**真实存储的知识被线索唤起**。零效度环境里的"直觉"不是弱一点的直觉，是**别的东西**（通常是替代）。
- **自信 ≠ 有效性**。全书最锋利的一条。资历、流畅度、笃定程度全部无效。
- **"说不清" ≠ "不可分析"**。阔步男孩雕像的案例：专家说不清的线索，研究者可以调查出来。这正是 `formula-over-intuition` 的原料来源。
- **本 skill ≠ question-substitution-check**。那个抓**单次**提问中的替换动作；本 skill 判定**整个领域**的直觉基础。一个快答案在高效度环境里是技能，在低效度环境里是替代——判据是环境，不是速度。
- **不可信 ≠ 无用**。判定为不可信的直觉仍可用于生成假设、发现异常、排优先级，只是不能作为结论。

## 相关 skills

- **contrasts-with**: `question-substitution-check` — 单次判断 vs 整个领域。抓到一次替换用那个，判定领域效度用本 skill。二者经常在同一场会议里先后使用。
- **composes-with**: `wysiati-evidence-audit` — 共享同一条第一原则（自信来自连贯度而非证据）。本 skill 从**环境**侧判定，那个从**证据**侧审计。
- **composes-with**: `regression-prediction-moderation` — 判定为"部分可信"时，本 skill 的效度档位正好当作那里收缩公式中的 r，决定预测走多远。
- **composes-with**: `outside-view-forecast` — 判定直觉不可信之后，若问题是"要多久/花多少钱"，直接转那个（定分布）。
- **composes-with**: `base-rate-anchoring` — 判定直觉不可信之后，若问题是"这个个案属于哪类、概率多少"，转那个（定起点）。
- **contrasts-with**: `premortem-doubt-injection` — 若团队的信心主要来自某位资深者的直觉，先用本 skill 判定该直觉的效度，再决定事前验尸时应该给这份信心多少权重。
- **composes-with**: `formula-over-intuition`（本书已验证 · 待整理）— **标准下游**。本 skill 判定"这里的直觉不可信"，那个提供替代方案（结构化评分表）。第 21 章以色列军队方案说明二者可合作：结构化打分之后的整体直觉**仍然有效**。
