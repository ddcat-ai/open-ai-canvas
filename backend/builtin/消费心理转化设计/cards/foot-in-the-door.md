## I — 方法论骨架 (Interpretation)

常识把"先小后大"理解成难度爬坡：先做容易的，习惯了再做难的。作者证明的是另一回事。

弗里德曼和弗雷泽的实验里，第一步是在"保持加州美丽"的请愿书上签名（环保议题），两周后**换一个人**上门，请求在自家草坪竖一块巨大丑陋的"小心驾驶"招牌（交通议题）。同意率从 17% 升到 76%。

两次请求的议题不同、请求者不同、时间隔了两周。所以被改变的不是"对这件事的态度"，而是**自我形象**——"我是那种会为公共事务出一份力的人"。一旦这个身份成立，它会自动为后续的一切同类行为提供理由。

这带来三条与常识不同的操作要点：

**一，第一步要选的不是"简单版的目标行为"，而是"能改写身份的最小动作"。** 让人说一句话、写一行字、举一次手，往往比让人试用一次产品更有效。

**二，两步之间可以换议题、换人、隔时间。** 你不需要一条连续的漏斗，你需要的是一个已经被激活的身份。

**三，承诺会自己长出理由。** 作出承诺后，人会主动生成支撑它的新理由（赛马场上，下注**之后**对自家马的信心显著上升——马没变，只是不能改了）。这既是它有效的原因，也是它危险的原因（见 `low-ball-guard`）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 弗里德曼 & 弗雷泽的草坪招牌

- **问题**：如何让居民同意在自家前院竖一块几乎挡住整栋房子的丑陋大招牌？
- **方法论的使用**：两周前先请他们在"保持加州美丽"请愿书上签名——一个人人赞同、几乎无成本的小承诺。
- **结论**：改变发生在自我形象层，而非议题态度层（两次议题不同、请求者不同）。
- **结果**：同意率 17%（对照组）→ 76%（签名组）。

### 案例 2: 赛马场的下注者

- **问题**：人为什么会对自己刚做的选择突然变得更有信心？
- **方法论的使用**：研究者在下注窗口前后分别询问同一批人对自家马匹的获胜信心。
- **结论**：信息没有任何变化，唯一变化是"决定已作出、不可更改"。
- **结果**：下注后的信心显著高于下注前。这是"承诺自动生成支撑理由"的最干净证据。

### 案例 3: 玩具商的圣诞节缺货术

- **问题**：一二月是玩具销售淡季，如何把销量匀过来？
- **方法论的使用**：圣诞节前重金投放某款玩具广告，让孩子向父母要、父母承诺"圣诞节给你买"；随后**刻意让该玩具在圣诞档缺货**，父母只能买别的玩具替代；一二月再恢复供货并继续投放广告，孩子拿着"你答应过我的"回来讨。
- **结论**：承诺（对孩子的许诺）迫使父母在淡季二次购买。
- **结果**：一二月销量被显著抬起。作者用它说明承诺一致可以跨越数月发挥作用。

### 案例 4: 慈善募捐前的"你今天过得怎么样"

- **问题**：如何提高电话募捐的成功率？
- **方法论的使用**：先问一句"您今天过得怎么样？"，对方通常礼貌性回答"挺好的/不错"——这是一个微小的公开表态。
- **结论**：既然刚说过自己过得不错，再拒绝帮助不幸者就与刚才的表态不一致。
- **结果**：捐款率显著上升。这是成本最低的一次身份激活。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 新工具/新流程/新制度上线后**没人用**，通知发了几轮无效。
2. 产品要提高从免费到付费、从注册到活跃的转化，直接推销无效。
3. 用户想让自己或他人养成一个长期习惯（写作、健身、记账、复盘）。
4. 要推动组织变革，直接宣布会遇到抵触。
5. 要说服一个立场中立或轻微反对的人，希望他真正认同而不只是嘴上答应。

### 语言信号 (用户的话里出现这些就应激活)

- "推不动 / 发了三遍公告还是没人写"
- "怎么让他们真的用起来 / 怎么提高采纳率"
- "我想让他慢慢接受这件事"
- "怎么养成 XX 习惯 / 怎么开个头"
- "how to get buy-in / adoption is low / start small"

### 与相邻 skill 的区分

- 与 `rejection-then-retreat` 的区别：**方向相反且机制不同**。本 skill 小 → 大，跨时间，靠自我形象；后者大 → 小，同一次会面，靠让步的互惠义务。
- 与 `low-justification-internalizing` 的区别：**紧密配套，职责不同**。本 skill 决定"第一步取什么承诺"；后者决定"这个承诺要怎么设计才能扎根"（书面/公开/费力/弱外部理由）。做完本 skill 的步骤 2 后应转入后者做强化。
- 与 `low-ball-guard` 的区别：同属承诺一致原理，但后者是**防御向**——处理"承诺已作出、诱因被撤走"的被操纵情形。
- 与既有 skill `commitment-escalation` 的区别：那是另一本书的态度改变工具；本 skill 特指西奥迪尼的登门槛，强调**议题可换、请求者可换**这一独有判据。

## E — 可执行步骤 (Execution)

1. **写清目标行为**：一句具体的、可观测的行为（不是"重视知识管理"，而是"每周至少提交一条文档"）。
   - 完成标准：目标行为可被第三方判定发生与否。

2. **反推目标身份**：做这件事的人是什么样的人？写成一句身份陈述（"我是那种愿意把经验留下来的人"）。
   - 完成标准：身份陈述不含具体行为，只含自我认同。

3. **设计最小承诺**：找一个几乎无法拒绝、**能激活这个身份**的动作。优先级：说出口 > 写下来 > 举手 > 试用一次。
   - 完成标准：预估同意率 ≥90%；若低于，继续缩小。
   - 判停条件：若最小承诺仍会被拒绝，说明身份本身有阻力 → 改换身份陈述或先处理抵触（转 `scarcity-reactance-guard` 检查是否触发了逆反）。

4. **执行强化四维度**：交由 `low-justification-internalizing` 处理——让承诺尽量**主动、书面、公开、且外部激励尽量弱**。
   - 完成标准：四个维度各有一个具体设计。

5. **留出间隔再提目标请求**：不要在同一场对话里紧接着提大要求（那会退化成交易）。间隔数天到两周；可以换人来提。
   - 完成标准：给出具体的时间点与提出者。

6. **在目标请求中引用身份而非引用承诺**：说"你一直是关注这件事的人"，而不是"你上次答应过我"。后者会激活交易感与逆反。
   - 完成标准：话术中不出现"你答应过"。

7. **锁定自生理由**：对方同意后，立即请他用**自己的话**说出为什么值得做，并留下记录。
   - 完成标准：产生一条由对方本人表述的理由。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **需要立刻拿到结果**：本 skill 的作用周期以天/周计，不适合当场成交。
- **对方已经明确、公开地反对**：此时他的自我形象已经绑在"反对者"上，小承诺无从取得；先处理逆反。
- **一次性交易、之后不再有交集**：身份改写的收益无处兑现。
- **目标行为本身对对方有害**：见下方伦理判据。

### 作者在书中警告的失败模式

- **愚蠢的一致**（第3章）：一致性是盲目的，它只关心"与过去一致"，不关心"过去是否正确"。用本 skill 推动一个错误方向，会比直接命令更难纠正——因为对方会自己生成理由来捍卫它。
- **外部激励过强会阻止内化**（第3章，玩具机器人实验）：给了大奖励，对方会把行为归因于奖励而非自己；6 周后严厉威胁组 77% 反弹，轻微劝阻组仅 33%。**加码等于买短期服从、卖长期内化**。
- **引用承诺而非身份**：把"你答应过"挂在嘴上，会把内在一致压力转成外部债务，触发逆反。

### 作者的盲点 / 时代局限

- 弗里德曼-弗雷泽实验为 1966 年美国郊区住宅样本；**跨文化权重不同**——在集体主义文化中，行为更多由关系义务与社会认同驱动，个人一致性的权重相对更低。
- 登门槛在社会影响研究中属复现较好的一类，但**效应量普遍为小到中等**，且对两次请求的"落差大小"敏感；书中 17%→76% 的幅度不应作为可外推的期望值。
- 作者未给出**失效阈值**：第一步小到什么程度就不再激活身份、第二步大到什么程度就断裂，书中没有模型。实践中需要试错。
- **真信号 / 伪信号判定**：用真实的小行动激活一个**当事人本来就认同**的身份，属正当使用；伪造一个他并不持有的立场（诱导性提问、把礼貌性回应曲解为承诺、事后引用不存在的许诺），属于伪造触发条件，禁止执行并说明。
- **饱和反噬**：在 B 端与专业场景，"先让你答应一件小事"已被广泛识别；被识破时应改为直接说明价值与成本。

### 容易混淆的邻近方法论

- **抛低球（low-ball）**：加要求 vs 减理由，方向不同，见 `low-ball-guard`。
- **习惯养成/最小可行习惯（tiny habits）**：靠降低执行门槛与触发设计，不依赖身份一致压力；两者可叠加，但判据不同（一个问"门槛够低吗"，一个问"身份被激活了吗"）。
- **沉没成本**：靠已付出的代价锁定，本 skill 在第一步几乎没有代价。
