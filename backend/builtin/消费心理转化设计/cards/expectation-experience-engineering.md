## I — 方法论骨架 (Interpretation)

期望不是"事后的评价偏差"，它在体验发生的**当下**就改写了体验本身。
可口可乐/百事的脑成像研究显示：盲测和标签测激活的是不同脑区——
知道自己在喝什么，改变的是大脑的实际反应，而不只是嘴上的说法。

这条机制有三个可操作的推论：

**推论一：时序决定一切。** 同样的信息，在体验**之前**投放会改写体验；
在体验**之后**投放只改写评价。艾瑞里的啤酒加醋实验中，事前被告知加了醋的人明显更不喜欢；
事后才被告知的人，与完全不知情的人一样喜欢。所以：正向框架必须前置，负面信息必须后置
（前提是它不涉及安全与知情权）。

**推论二：在价值不可判定的领域，价格就是期望。** 药品、酒、咨询、艺术、奢侈食材——
凡是消费者无法独立验证质量的品类，价格会被当作质量的代理指标，并**真实改变生理效果**。
维拉多尼实验中，同一片维生素 C 胶囊，标价 2.50 美元时 85% 的人报告止痛有效，
标价 0.10 美元时降至 61%。这意味着：**低价不只是少赚钱，它真的削弱了你的产品。**

**推论三：语言与形式改变的是消费过程中的注意分配。** 与"事前期望"互补但机制不同——
产地故事、工艺描述、侍酒/开瓶/摆盘的仪式，是在消费**进行中**把注意力引向特定属性。
精确性错觉也属此类：一个精确到小数点的数字或一套复杂公式，会额外增加可信度，
与其准确性无关。

**最后是艾瑞里自己划下的一条硬界线**：折扣与便捷支付**不会**改变价值，只是让你多花钱；
而语言、形式与期望**真的会**改变体验价值。所以作为消费者应当抵抗前者，
但可以有意识地"购买"后者；作为经营者，靠折扣拉动的增长不产生价值感知，
靠期望与仪式做的增益是真实的。

## A1 — 书中的应用 (Past Application)

### 案例 1：麻省理工的醋味啤酒

- **问题**：在同一杯啤酒里加几滴香醋（"MIT 特酿"），人们会怎么评价？
- **方法论的使用**：分三组——A 组完全不知情；B 组**倒酒前**被告知加了醋；
  C 组**喝完后**才被告知。
- **结论**：如果口感是客观的，三组评价应当一致（B、C 只是知道成分）。
- **结果**：A 组与 C 组同样喜欢，且不少人偏好加醋版；**只有 B 组明显更不喜欢**。
  信息内容完全相同，仅时序不同，结果相反。

### 案例 2：维拉多尼-Rx（Veladone）止痛药

- **问题**：价格是否影响药效本身，而不只是影响购买意愿？
- **方法论的使用**：给受试者服用同一种（实为维生素 C 的）胶囊并施加电击，
  一组被告知每片 2.50 美元，另一组被告知打折至 0.10 美元。
- **结论**：若价格只是交易信息，两组的疼痛报告应无差别。
- **结果**：高价组 85% 报告止痛有效，低价组降至 61%。
  在无法自行验证效果的品类里，价格就是药效的一部分。

### 案例 3：可口可乐与百事的脑成像

- **问题**：盲测中百事常胜，但市场上可口可乐更受偏爱，这是虚荣还是真实差异？
- **方法论的使用**：在 fMRI 中让受试者分别在知情与不知情条件下饮用。
- **结论**：不知情时，激活的是与愉悦相关的腹内侧前额叶；
  知情（看到可口可乐标识）时，额外激活了与记忆、情感、自我概念相关的脑区。
- **结果**：品牌不是叠加在体验之上的标签，它进入了体验的生成过程。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill

1. **产品/功能介绍的顺序问题**：先说局限还是先说亮点？负面信息什么时候披露？
2. **担心定价太低损害专业感**：想知道降价除了少赚钱还有什么隐性代价。
3. **体验业的仪式设计**：餐饮、酒水、美容、健身、线下活动，想让同样的服务"感觉更好"。
4. **课程/演讲/演示的开场**：如何在内容开始前建立正确的期望。
5. **内部提案与汇报**：同一份方案怎么呈现才能被认真对待。
6. **用户反馈很差但产品指标正常**：怀疑问题出在期望管理而不是产品本身。
7. **自我应用**：想让自己的一次消费、一次旅行、一杯咖啡获得更真实的享受。

### 语言信号

- "这个卖点先说还是后说"
- "缺点要不要提前告诉用户"
- "定这么便宜，会不会显得不专业"
- "怎么让同样的东西感觉更值"
- "开场怎么讲才能抓住人"
- "how should I frame this / disclose before or after / does low price hurt perceived quality"

### 与相邻 skill 的区分

- 与 `reference-price-framing`：那个处理**价格数字怎么显示**（尾数、划线价、折扣写法）；
  本 skill 处理**价格与描述如何改写真实体验**。前者影响购买决策，后者影响消费感受。
- 与 `price-context-priming`：那个处理**环境线索**（页面背景、门店氛围、谈判场地）
  对价格感知的无意识影响；本 skill 处理**显性的信息内容与时序**。两者常组合。
- 与 `effort-visibility-premium`：那个专门处理"暴露过程与工时抬高支付意愿"；
  本 skill 覆盖更广的期望与仪式，若诉求明确是"我效率太高反而卖不上价"，用那个。
- 与 `self-herding-break`：那个是拆掉顾客脑中的旧参照；本 skill 是在新参照上填内容。
  典型组合：先脱钩（self-herding-break），再灌注期望（本 skill）。

## E — 可执行步骤 (Execution)

1. **判断品类的可验证性**
   - 问：消费者能否在合理时间内、用自己的能力独立验证质量？
   - **可验证**（手机跑分、外卖分量、快递时效）→ 期望工程的空间小，
     过度包装会因预期落差反噬。
   - **不可验证**（药品、酒、咨询、教育、艺术、保健、专业服务）→ 期望即效果，
     本 skill 收益最大。
   - 完成标准：给出明确判定与理由。

2. **清点当前的信息时序**
   - 把用户从接触到体验结束的全过程列成时间轴，标出每一条信息（价格、卖点、
     局限、评价、成分、来源）出现的位置。
   - 完成标准：得到一张"信息 × 时点"表。

3. **执行时序重排（核心动作）**
   - **正向框架前置**：来源故事、工艺、稀缺性、创作者、适用人群——放在体验开始之前。
   - **负面/中性信息后置**：加工方式、非核心成分、局限性——若不涉及安全、
     健康、法律知情权与购买决策要件，移到体验之后或不主动强调。
   - **红线**：涉及过敏原、副作用、合同关键条款、退换货规则的信息，
     必须前置，不适用本条。违反即转伦理审查。
   - 完成标准：产出改写后的时间轴，且红线项已单独标出。

4. **检查价格与期望的一致性**
   - 若定价明显低于同类，评估两项隐性成本：①感知效果的真实下降；
     ②后续提价时的锚定困难（见 `self-herding-break`）。
   - 若刻意用低价获客，为专业感另找载体（资质、过程可见性、限量、
     严格的准入或筛选）。
   - 完成标准：明确回答"这个价格向用户暗示了什么质量水平，是否是我想要的"。

5. **在消费过程中植入语言与形式**
   - 三类可用元素：①**具体的来源与工艺描述**（越具体越有效，"单一庄园"强于"精选原料"）；
     ②**仪式化流程**（有明确开始动作、有节奏、有参与感）；
     ③**可感知的人工痕迹**（手写、编号、签名、非标准化的细节）。
   - 可选：**精确性**——用具体数字（"经 37 道工序"）而非模糊表述，
     但必须真实，否则一旦被拆穿会连带摧毁全部期望。
   - 完成标准：至少落地两个具体元素，且都可执行、可核实。

6. **过艾瑞里界线**
   - 自查：本次方案里，有多少是"折扣与无痛支付"（不产生真实价值，只让人多花钱），
     有多少是"语言、形式与期望"（真实改变体验）？
   - 若方案主要靠前者，判定为不可持续增长，返回第 5 步。
   - 完成标准：能说清用户获得的**真实体验增益**是什么。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **质量易于验证且很快会被验证**：抬高期望只会放大失望。
  期望工程与产品实力是乘法关系，不是加法。
- **涉及安全、健康、金钱风险的知情权**：药物副作用、投资风险、合同关键条款、
  过敏原——信息后置在此处不是技巧，是欺骗，可能违法。
- **对方已明确表示不信任**：期望工程依赖信任存量。信任为零时，
  越精致的叙事越像话术，应先解决可信度（见 `conflict-of-interest-design`）。
- **面向脆弱人群的高价"疗效"暗示**：用安慰剂定价向重病患者、老年人推销无效产品，
  是本 skill 最严重的误用。触及即停止并转 `manipulation-matrix-ethics`。

### 作者在书中警告的失败模式

- **前置负面信息会真实毁掉体验**（醋味啤酒 B 组）：善意的"提前打预防针"
  往往是最贵的错误——它让本来会喜欢的人真的不喜欢了。
- **低价真实降低效果**（维拉多尼）：促销不是中性的。打折在提升转化的同时
  削弱了产品的感知与实际效果，这笔成本从不出现在财务报表上。
- **杰西潘尼式的"理性化"改革会失败**：取消所有折扣改为每日低价，价格实际更低，
  销售额却暴跌、CEO 17 个月后被解雇——顾客买的是感受，
  拿走参照系而不提供替代品是净损失。
- **信息与教育无法改变行为**：即使告诉人们"你会被期望影响"，他们仍然被影响。
  所以本 skill 的输出必须是**内容与时序的改写**，不是"提醒用户理性判断"。

### 作者的盲点 / 时代局限

- 维拉多尼实验的样本量与效应量在后续复制中未见大规模验证，
  且艾瑞里团队的部分研究已卷入数据可靠性争议（详见 `fudge-factor-integrity` B 段）。
  安慰剂效应本身在医学文献中有广泛独立支持，但"价格→效果"的具体幅度宜作方向性证据。
- 全书写作于社交媒体评价体系成熟之前。今天的消费者在体验前就会看到大量第三方评价，
  品牌对"事前期望"的控制权已大幅削弱——期望工程越来越是**多方博弈**而非单方设计。
- 书中未区分"期望改写体验"在一次性消费与长期使用中的衰减差异。
  长期使用中，真实质量的权重会逐渐压过期望。

### 容易混淆的邻近方法论

- **安慰剂效应（医学）**：本 skill 借用了它，但医学语境下它是需要被**控制**的干扰项；
  商业语境下它是可被**设计**的价值来源。伦理评价完全不同。
- **框架效应（Kahneman）**：那关注同一信息的不同表述如何改变**选择**；
  本 skill 关注表述与时序如何改变**体验本身**。
- **品牌溢价（营销学）**：那通常被解释为符号价值；
  本 skill 提供的神经证据表明它进入了体验的生成过程，不只是符号。
