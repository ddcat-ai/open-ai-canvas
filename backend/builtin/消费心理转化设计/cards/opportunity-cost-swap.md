## I — 方法论骨架 (Interpretation)

一笔钱的真实成本，是它的**最佳替代用途**。这是经济学第一课，
也是几乎没有人在生活中真正执行的一课。

艾瑞里团队在汽车经销店做过一次街头测试：问买车的人
"如果买了这辆丰田，你就买不起什么了？"——绝大多数人答不上来，
或者说"就是买不起别的车了"。他们花掉几十万，却从未把这笔钱与
**汽车之外的任何东西**比较过。

人不做机会成本比较，是因为它认知负担太重（替代用途有无限多个）。
于是大脑用三个更省力的替代品来判断值不值：

1. **打了几折**（相对参照，见 `reference-price-framing`）
2. **这笔钱装在哪个心理信封里**（见 `mental-accounting-envelope`）
3. **付起来痛不痛**（见 `pain-of-paying-tuning`）

这三个替代品都与真实价值无关。

本 skill 的动作因此只有一个，但必须做对：

> **把"这个值不值 X 元"改写成
> "这 X 元换成【具体的另一件事】，我更想要哪个？"**

关键在**具体**。艾瑞里明确指出：抽象的"其他用途"**无效**——
问"这 3000 元还能干什么"，大脑给出的是一团模糊的"别的东西"，没有比较力。
必须换算成可以想象出画面的具体项目：**20 次外卖、一次周末短途、
三个月的健身卡、半个月的房租**。

同样的置换适用于时间：这两小时会议换成什么，我更愿意要？

## A1 — 书中的应用 (Past Application)

### 案例 1：丰田经销店的街头调查

- **问题**：人在做大额消费时，会不会考虑机会成本？
- **方法论的使用**：艾瑞里团队在丰田经销店门口拦住准备买车的顾客，
  问："如果你买了这辆车，你将来买不起什么东西？"
- **结论**：如果人做机会成本比较，应当能立刻说出被放弃的具体消费。
- **结果**：极少数人能给出具体答案，多数人的回答是"就是买不了别的车了"——
  他们的比较集合被局限在同一品类内部，完全没有跨品类的机会成本概念。

### 案例 2：赌场里的乔治

- **问题**：为什么筹码会让人花得更多？
- **方法论的使用**：艾瑞里描述了一位在赌场的普通人，
  他用筹码下注时的从容与他在超市为几块钱比价时的谨慎形成极端反差。
- **结论**：同一个人对同一笔钱有完全不同的花法，
  差别只在这笔钱被装进了哪个心理容器、以什么形式呈现。
- **结果**：说明机会成本置换必须**主动执行**，它不会自然发生。

### 案例 3：具体化替代项才有效

- **问题**：提醒人"想想机会成本"够不够？
- **方法论的使用**：书中反复对比两种问法——
  抽象版"这笔钱还能做别的事"vs 具体版"这笔钱等于 X 次某个具体消费"。
- **结论**：只有后者能引发真实的取舍感，因为大脑只对可想象的画面做比较。
- **结果**：这成为本 skill 第 3 步的硬性要求。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill

1. **大额消费犹豫**：车、家电、旅行、装修、课程、设备。
2. **订阅续不续**：软件、会员、健身房、云服务。
3. **企业预算审批**：某个项目/工具/外包要不要批。
4. **时间投入取舍**：要不要参加这个会/接这个活/做这个副业。
5. **事后复盘**："这钱到底花得值不值"。
6. **给别人做决策建议**时，需要一个能推进对话的具体框架。

### 语言信号

- "这个值不值这个价"
- "该不该买 / 要不要续"
- "感觉有点贵，但好像也需要"
- "预算就这么多，先花在哪"
- "这两小时的会有必要开吗"
- "is it worth it / should I spend this / justify the budget"

### 与相邻 skill 的区分

- 与 `reference-price-framing`：那是卖方视角的价格呈现（折扣怎么写）；
  本 skill 是买方/决策方视角，且刻意**绕开折扣这个参照**。
- 与 `mental-accounting-envelope`：那处理"钱被分进了不同信封"这个结构问题；
  本 skill 处理"单笔支出值不值"这个判断问题。两者常配合：
  先用本 skill 判断值不值，再用那个决定从哪个信封出。
- 与 `pain-of-paying-tuning`：那处理支付方式如何影响花钱意愿；
  本 skill 处理支出本身的价值判断。若用户说"刷卡就没感觉"，用那个。
- 与 `ulysses-self-control-architecture`：若用户其实算得很清楚、
  只是控制不住手，那是自控问题，用那个。
- 与 `close-the-doors`：那处理"同时保留多个选项的隐性成本"；
  本 skill 处理"这一个选项值不值"。

## E — 可执行步骤 (Execution)

1. **确认这是价值判断而非自控或情绪问题**
   - 问：如果算完发现不值，你会放弃吗？
   - 若答"知道不值也还是想买" → 自控问题，转 `ulysses-self-control-architecture`。
   - 完成标准：确认对方愿意接受计算结果。

2. **把金额从相对回归绝对**
   - 剥掉所有折扣、原价、赠品的表述，只留下**你实际要付出的总金额**
     （含隐藏成本：运费、订阅期、配套支出、维护、时间）。
   - 完成标准：得到一个干净的总数字。

3. **生成 3 个具体的替代项（核心动作）**
   - 要求每一个都：①金额相当；②对当事人真实有吸引力；
     ③**可以想象出画面**。
   - 好的替代项："20 次和朋友吃饭""一次三天的短途旅行""半年的通勤打车"
   - 坏的替代项："存起来""别的东西""投资"（无画面，无比较力）
   - 对企业预算：换算成"两个月的一名工程师""三场线下活动""一年的某工具全员授权"。
   - 完成标准：写出 3 条具体替代项。

4. **做直接的两两选择**
   - 逐条问："这个 vs 这一项，我更想要哪个？"
   - 不要问"哪个更理性"，问"**更想要哪个**"——机会成本比较的是效用，不是道理。
   - 完成标准：3 次选择都有明确答案。

5. **看结果，而不是找理由**
   - 若目标项在 3 次比较中全胜 → 买，且不必再纠结。
   - 若输了 2 次以上 → 不买，且把胜出的替代项**实际执行掉**
     （否则钱不会流向更好的用途，只会流向下一次冲动）。
   - 若各胜一半 → 说明这是一个真实的边际决策，可用"推迟 7 天再判"的规则处理。
   - 完成标准：给出结论与后续动作，而不是停在"再想想"。

6. **对时间做同样的置换**
   - 把小时数换成具体的替代用途："这三小时会议 = 一次完整的深度工作 /
     陪孩子一个下午 / 写完那篇拖了两周的稿子"。
   - 完成标准：时间类决策同样有 3 个具体替代项。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **小额高频决策**：为一杯咖啡做三次机会成本比较，认知成本高于收益。
  对这类支出更适合用总量控制（见 `mental-accounting-envelope`）。
- **必需品与不可延迟支出**：医疗、房租、还款。这些没有可比替代项，
  强行置换只会制造焦虑。
- **纯情感与关系性支出**：给父母的礼物、纪念日、慈善捐赠。
  把它们放进效用比较会破坏其社会规范属性（见 `social-market-norm-switch`）。
- **决策已经做出且不可逆**：事后置换只会产生后悔，不产生更好的决策。

### 作者在书中警告的失败模式

- **抽象替代项无效**：问"这笔钱还能干什么"几乎不改变决定。
  这是本 skill 最容易被做错的一步。
- **比较集合被困在同一品类内**（丰田案例）：买车的人只与别的车比，
  买手机的人只与别的手机比。跨品类才是机会成本的意义所在。
- **不执行胜出的替代项 = 白算**：如果比较后决定不买 A，
  钱却没有流向胜出的 B，那么下一次冲动会把它花掉，本次计算无效。
- **知道机会成本这个概念完全不足以让人使用它**：艾瑞里指出，
  连受过经济学训练的人在真实消费中也不做这个比较。
  所以本 skill 必须以**执行清单**的形式出现，而不是作为提醒。

### 作者的盲点 / 时代局限

- 丰田街头调查是小样本的非正式访谈，作为**现象说明**有说服力，
  作为**证据**强度有限。
- 艾瑞里团队的部分研究已卷入数据可靠性争议（详见 `fudge-factor-integrity` B 段）；
  机会成本忽视本身在行为经济学中有独立文献支持（Frederick 等人的
  "opportunity cost neglect"研究），本 skill 的核心结论不依赖单一来源。
- 书中假定当事人有可自由支配的收入。对预算极度紧张者，
  几乎所有支出都是必需品，本 skill 的适用面收窄。
- 未讨论**机会成本置换的心理代价**：过度执行会让每一次消费都变成一场审判，
  损害生活质量。本 skill 的边界段已对此设限。

### 容易混淆的邻近方法论

- **沉没成本谬误**：那是"已经花了所以继续"（回头看）；
  机会成本是"这笔钱还能干什么"（向前看）。
- **性价比 / ROI 计算**：那在同一品类内比较；
  本 skill 强制**跨品类**比较，这正是它的价值所在。
- **心理账户**：那是描述人怎么错误地分割资金；
  本 skill 是矫正工具。二者是问题与解药的关系。
