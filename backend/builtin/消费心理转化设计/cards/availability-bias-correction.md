## I — 解释

可得性启发法的通俗版本——"最近发生的、印象深刻的事会被高估频率"——已经是常识。本 skill 的价值不在那一层，而在施瓦茨实验揭示的**精确机制**，因为这个机制直接推翻了一条流行的纠偏建议。

实验很简单。A 组：列举 6 件自己表现果断的事。B 组：列举 12 件。然后两组都自评果断程度。

常识预测：B 组写下了更多证据，应该更觉得自己果断。

实际结果：**B 组认为自己更不果断。**

原因是：被读取的信号不是"我列出了多少条"，而是"**列举的过程有多顺畅**"。前三四件很容易，到第八、第九件就要挖空心思了——这份吃力被大脑翻译成"看来我确实不够果断"。

卡尼曼补了一个决定性的对照条件：当研究者给出**外部归因**（告诉受试者"背景音乐会让回忆变困难"）时，这个效应**完全消失**。这证明起作用的确实是"提取顺畅度"这个元认知信号，而不是内容。

由此推出一串同样反直觉的衍生结论（书中列举）：

- 在被要求用**更多论据**支撑自己的选择时，**自信心下降**
- 在列出**多个避免某问题的方法**后，对避免此问题**更加不自信**
- 在列出某辆车的**优点**后，对该车**没那么感兴趣**了
- 加州大学洛杉矶分校那位教授的用法最阴：让学生列**较多**改进课程的方法 → 学生对这门课的**评价更高**（因为想不出那么多改进点）

**对本 skill 最重要的推论：「多想想反面证据」这条到处都在说的建议，会适得其反。** 如果反面证据难以想起（这在你已经相信某事时几乎是必然的），那份吃力会**强化**你的原判断。你以为自己在自我纠偏，实际上在给自己发一张确认书。

所以纠偏动作只有两条合法路径：
1. **去外部拿频率数据**（不靠回忆）
2. **把问题改写成自然频率**（"100 个里有几个"），绕开提取过程

另外两个必须掌握的衍生现象：
- **效用层叠**：一个小事件 → 媒体报道 → 公众恐慌 → 更多报道 → 政策过度反应。这是可得性的社会放大版。
- **概率忽视**：只要能想象出灾难画面，概率大小就几乎不再影响决策（斯洛维克与桑斯坦之争的核心）。

## A1 — 书中的应用

**案例一：施瓦茨的 6 vs 12（本 skill 的原型）**
除了上文的主结果，书中还有一个更精巧的变体：要求受试者列举 6 件事的同时保持特定面部表情。"皱眉者"（皱眉伴随认知紧张，让提取更费力）在提取果断行为时更困难，因此**估计自己更不果断**。同一个人、同样的记忆库、同样的题目数量，仅仅因为提取体验不同，自我评价就变了。

**案例二：心脏病家族史学生的分裂结果**
两组学生回忆自己 3 种或 8 种影响心脏健康的行为。**没有**心脏病家族史的学生跟着系统 1 走，用顺畅度判断（想起 8 件危险行为很难 → 觉得自己安全）。**有**家族史的学生（更在乎这个议题，系统 2 更投入）表现出**相反**模式——他们按内容判断（想起很多危险行为 → 觉得自己危险）。

这个案例给出了本 skill 的适用边界判据：**当事人越不投入，越受顺畅度支配**。所以在评审别人不太在乎的议题时，可得性偏见最强。

**案例三：可得性偏见在风险与资源分配上的代价**
书中的示例句极其日常：
> "因为上个月发生了两架飞机相撞事件，她现在更愿意坐火车。这真是愚蠢，风险其实并没有真正降低，这就是可得性偏见。"
> "他低估了室内污染的风险，因为媒体对此报道极少。"
> "这位执行总裁连续多次成功，因此失败不会轻易在她的脑海中出现。可得性偏见使得她过于自信。"

注意第三句：可得性不只放大风险，也**抹掉风险**——没被报道的、没发生在身边的、连续成功之后的失败，都不在可得集合里。**漏报比误报更危险**。

## A2 — 触发场景

### 什么时候用

- 判断"这类问题有多频繁""这个风险有多大"
- 一次事故/投诉/舆情之后决定投入多少资源防范（**最高频的应用场合**）
- 安全预算、风控规则、SLA 阈值、监控告警的设定
- 团队复盘时说"我们老是在 X 上栽跟头"
- 个人风险认知（坐飞机 vs 开车、体检项目取舍、买哪种保险）
- 有人正在用"你想想有多少例子"说服你（或你正在这样说服别人）
- 媒体/社群/群聊里某个话题突然密集出现

### 语言信号

> "最近老是出这个问题" / "这种事经常发生" / "你看上个月就出过一次" / "我身边好几个人都……" / "印象里挺常见的" / "这块必须重点投入" / "现在到处都在说" / "想想看有多少例子就知道了"

**结构性信号**：
- 说话人能举出 1–3 个**具体而生动**的例子，但给不出分母
- 议题最近在媒体/群聊里高频出现
- 例子中至少有一个是**当事人亲历或身边发生**的
- 讨论中出现了画面感很强的描述（概率忽视的入口）

### 与相邻 skill 的区分

| 情况 | 用这个 | 不用这个 |
|---|---|---|
| 估计一类事件的**频率/风险**，印象来自例子 | ✅ `availability-bias-correction` | |
| 判断**某个个案**属于哪一类、会怎样 | | → `base-rate-anchoring`（那是类别归属与贝叶斯，这是频率估计） |
| 怀疑自己回答的根本不是那个问题 | | → `question-substitution-check`（它是上游分诊台） |
| 估一个**项目**要多久、花多少钱 | | → `outside-view-forecast` |
| 上季度极端表现之后的变化、下一期预测 | | → `regression-prediction-moderation` |
| 证据本身太少却已形成结论 | | → `wysiati-evidence-audit` |
| 已知概率，但对小概率的**态度**扭曲（保险/彩票/诉讼） | | → `fourfold-pattern-risk`（本书已验证 · 待整理） |
| 事故发生后归因、找责任人 | | → `hindsight-narrative-guard`（本书已验证 · 待整理） |

**与三个预测类 skill 的一句话切分**：本 skill 修正的是**"这类事有多常见"的频率印象**（数据来自事件在世界上的发生率）；`base-rate-anchoring` **定起点**（个案属于哪类、概率多少）；`outside-view-forecast` **定分布**（项目工期成本）；`regression-prediction-moderation` **定从起点向直觉走多远**（极端值之后收缩多少）。判据：本 skill 的输入是**一堆容易想起的例子**，那三个的输入是**一个待预测的具体对象**。

## E — 执行

1. **先认领偏差方向**。问一句："我的印象来自频率数据，还是来自几个想得起来的例子？"若是后者，**默认它偏高**（对鲜活事件）或**偏低**（对无声风险），进入下一步。

2. **写出分母**。这是本 skill 的核心动作。把"这种事经常发生"改写成一个带分母的句子：
   - ❌ "线上事故最近很多"
   - ✅ "过去 12 个月共 X 次 P1 事故 / 共 Y 次发布，即每 Z 次发布一次"

   分母通常需要去查，这正是关键——**查的过程本身就绕开了提取顺畅度**。

3. **改用自然频率表述**。把概率语言换成计数语言："这类项目 100 个里有几个失败"，而不是"失败概率是百分之多少"。书中琳达问题的频率版把错误率大幅拉低，同一手法在这里同样有效。

4. **做"无声风险"扫描**（对抗漏报）。可得性同时会让**没被报道的风险消失**。强制问三条：
   - 哪类问题**从来不会被投诉**（用户直接流失，不出声）？
   - 哪类问题**发生了也不会被记录**？
   - 我们连续成功的那条线上，**上一次失败是什么时候**？（书中的执行总裁案例）

5. **把资源投入锚在期望损失上，而不是最近一次事故上**。计算 `频率 × 单次损失`，与拟投入资源比较。若两者差一个数量级以上，要么资源过度，要么频率被低估——两种都要显式解释。

6. **加一道时间闸**（对抗鲜活度）。对于事故驱动的大额投入，强制**延迟决策 N 天**，或要求"先呈现三年频率表再拍板"。鲜活度随时间衰减，期望损失不会。

7. **⚠️ 不要做的事**：不要用"再多想几个反例/更多论据"作为纠偏手段。见 B 段。

## B — 边界

### 不适用的情况

- **样本本身就是全部**。当你的例子已经覆盖了总体（团队只有 5 个人，三个都反馈了同一个问题），这不是可得性偏见，这是数据。
- **真正的新型风险**。历史频率为零不等于风险为零（黑天鹅）。此时应转向情景推演与冗余设计，而不是继续找频率。
- **需要动员而非估计的场合**。当目标是让团队重视一个**已经确认成立**的风险，鲜活的案例是有效的沟通工具。本 skill 用于**估计阶段**，不用于**传播阶段**——但你要知道自己在做哪一件。
- **审美、偏好、创意判断**。这里没有"客观频率"这个东西。

### 失败模式

1. **"多想想反面证据"**（本 skill 最重要的失败模式）。施瓦茨实验的直接推论：如果反例难以想起，那份吃力会**强化**原判断。想不出反例 ≠ 没有反例。纠偏动作必须是**外部查询**或**改写表述**，不能是**内部检索**。
2. **只查了容易查的分母**。用"被记录的事故数"当分母，会系统性漏掉未被记录的部分。分母的质量决定了这一步的价值。
3. **用它否定当事人的真实体验**。对一线同事说"这只是可得性偏见"极易变成消权。正确做法是：承认体验为真（"你确实遇到了三次"），同时把分母摆上桌（"我们看看这三次占多少"）。
4. **纠偏后仍不改行动**。查完频率发现投入过度，却因为"已经承诺了"而继续——这时问题已经变成沉没成本，见 `fourfold-pattern-risk` 的高概率损失格。

### 盲点

- **偏差方向不是单向的**。可得性既高估鲜活风险，也**低估无声风险**。只做"是不是被吓着了"的检查，会漏掉一半（且往往是更贵的一半）。
- **投入程度改变机制**。书中的心脏病家族史实验说明：当事人越在乎、系统 2 越投入，就越按内容判断而非顺畅度。因此本 skill 在**评审他人不太在乎的议题**时价值最高，在**当事人切身相关**的议题上效力较弱。
- **效用层叠的社会性无法靠个人纠偏解决**。当媒体—公众—政策形成正反馈，个体的正确估计不改变结果。此时本 skill 的产出应该是"预判层叠的走向"，而不是"我说服大家"。
- **本书方法论的共享边界**：不要援引第 3–5 章的启动效应与自我损耗（复现失败，作者已撤回信任）。本 skill 的证据基础（第 12 章施瓦茨系列、第 13 章风险认知）是独立的、被反复复现的。
- **不要指望自己变得更客观**。卡尼曼自认四十年研究没能改善他自己的直觉。本 skill 的可靠用法是**在流程里插入一个"必须填分母"的字段**，而不是提醒自己保持理性。

### 容易混淆的概念

- **可得性 ≠ 代表性**。可得性回答"这类事有多频繁"（靠提取顺畅度）；代表性回答"这个个案属于哪一类"（靠像不像典型样本）。后者归 `base-rate-anchoring`。
- **提取顺畅度 ≠ 例子数量**。这是本 skill 全部反直觉性的来源，也是与通俗版可得性的分界线。
- **可得性偏见 ≠ 记忆力差**。记忆力好的人同样受支配，因为读取的是**体验**不是**容量**。
- **概率忽视 ≠ 高估概率**。概率忽视是概率**根本不进入运算**——画面感一旦形成，1/1000 和 1/1000000 的决策后果相同。

## 相关 skills

- **composes-with**: `base-rate-anchoring` — 两个最常被 `question-substitution-check` 转交的下游科室。本 skill 管频率，那个管归类；实务中常需连用（先定频率，再定个案）。
- **composes-with**: `outside-view-forecast` — 都是"用外部数据替换内部印象"，本 skill 面向**频率与风险**，那个面向**工期与成本**。
- **composes-with**: `wysiati-evidence-audit` — 本 skill 的第 4 步"无声风险扫描"本质上是那个 skill 的"我不知道什么"清单在风险维度上的特化。
- **composes-with**: `question-substitution-check` — 上游分诊台。当替换形式是"我能多容易想起例子"时，转交本 skill。
- **contrasts-with**: `regression-prediction-moderation` — 本 skill 处理**频率印象被例子污染**；那个处理**极端值之后的变化与收缩**。共同点是都要回到分布，区别是本 skill 修的是"分布长什么样"，那个修的是"从分布走到个案要走多远"。
- **contrasts-with**: `fourfold-pattern-risk`（本书已验证 · 待整理）— 本 skill 修正**概率估计本身**；那个处理概率已知时**风险态度的扭曲**。二者串联使用：先估对概率，再检查态度。
- **contrasts-with**: `hindsight-narrative-guard`（本书已验证 · 待整理）— 一次事故之后，本 skill 防止"投入过度"，那个防止"归因过度"。事故复盘时通常两个都要用。
