## I — 方法论骨架 (Interpretation)

三条互相咬合的结论。

**一、0 不在价格轴上。** 从 2 分降到 1 分，和从 1 分降到 0，在数学上都是 1 分，在心理上是完全不同的两件事。正价格触发成本收益计算，零价格取消计算、直接触发获取冲动。所以"免费"不是"很便宜"的极端情形，它是一次决策模式的切换。这也意味着**这是一道单向门**：从 0 回到任何正数，心理跨度远大于从 1 涨到 2。

**二、价格标签定义体验的性质。** 阿雷利等人的《汤姆·索亚和价值构建》证明：同一场诗歌朗诵，问"你愿意付多少钱来听"和"我们要付你多少钱你才肯听"，会得到方向相反的评价。付费=享受，收费=劳动。所以收费不只是筛选机制，它是**意义框架**。书中据此驳斥"每种体验都可归类为积极或消极"这一常识——大多数体验是好坏参半的，是价格告诉了人们该往哪边归。作者的追问很锋利：去巴黎旅游是好事吗？人人都说是——因为所有人都那么说，也因为它要花老大一笔钱。假设去巴黎永远免费，这个周末你会去吗？下个周末呢？

**三、交易效用是一条独立账目。** 总效用 = 获得效用（东西本身值多少）+ 交易效用（成交价相对参考价便宜了多少）。后者能独立驱动购买，哪怕你并不需要那件东西。这就是"占便宜"作为一种消费动机的机制。

由此得出的操作原则：**免费用于破门槛与拉新，收费用于筛选、珍视与意义**。两者不可混用，且免费的账要提前算清——你换来的量，代价是不珍视、超额索取、以及未来收费的巨大阻力。

## A1 — 书中的应用 (Past Application)

### 案例 1：阿雷利的巧克力摊
- **问题**：把价格降到 0，和降到 1 分钱，效果差多少？
- **方法论的使用**：摆摊卖两种巧克力——低档的好时和更好的瑞士莲松露，索价 1 分与 1 毛 5，标牌写明每人限一块。随后把两者价格同步下调，直到好时变为免费。
- **结论**：等额降价在跨过 0 的那一步引发的不是渐变，而是选择结构的反转。
- **结果**：在正价格区间，多数人愿意为明显更好的瑞士莲多付；一旦好时免费，选择大幅倒向免费的劣质品——人们放弃了原本认为更划算的权衡。

### 案例 2：汤姆·索亚诗歌朗诵实验
- **问题**：一场活动是"值得付钱的享受"还是"要给钱才肯干的苦差"，由什么决定？
- **方法论的使用**：2006 年阿雷利在伯克利校园吸引营销系学生来听他朗诵惠特曼《草叶集》，一组被问"你愿意付多少钱来听"，另一组被问"我们要付你多少钱你才肯来"。
- **结论**：价格的方向决定了体验被编码为享受还是劳动。
- **结果**：两组给出的答案方向相反，而活动完全相同。研究者据此发表《汤姆·索亚和价值构建》。

### 案例 3：塞勒的沙滩啤酒（交易效用）
- **问题**：同一瓶啤酒，为什么在两个地方愿付价不同？
- **方法论的使用**：朋友去豪华酒店买 vs 去小杂货店买，同一品牌，都拿回沙滩喝。
- **结论**：交易效用独立于获得效用，由"这个地方该卖多少"决定。
- **结果**：高管愿为酒店的啤酒平均出两美元；同样两美元由小杂货店要，就成了敲竹杠。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 要不要做免费试用 / 免费增值（freemium），免费额度给多少。
2. 线下活动、讲座、社群聚会，收不收门票、收多少。
3. 免费用户很多但转化率极低，考虑加 paywall。
4. 要给参与者、志愿者、内测用户付钱吗？付了会不会反而削弱积极性。
5. 设计赠品、满赠、"加 1 元换购"这类交易效用型促销。
6. 共享物品/器材归还率低，考虑押金机制。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要做免费版／免费送"
- "活动收不收钱、收多少合适"
- "免费来的人都不珍惜／一堆白嫖的"
- "免费用户怎么转付费"
- "should this be free or paid"、"freemium"
- "people don't value it when it's free"

### 与相邻 skill 的区分

- 与 `reference-price-framing` 的区别：那个处理**正价格**怎么显示（尾数、划线价、折扣写法）；本 skill 处理**收不收**这个前置决策。一旦价格要降到 0，就不是呈现问题而是类别切换。
- 与 `choice-set-decoy-design` 的区别：那个决定**分几档、怎么引导**；本 skill 决定**底部那一档是 0 还是正数**。两者常配合：本 skill 先定免费档的存废，那个再排布其余档位。
- 与 `block-price-comparison` 的区别：统一费率里的"免费"项（游轮餐食）属于那个 skill 的捆绑手法；本 skill 关注真正的零价格入口。
- 与 `ultimatum-fairness-leverage` 的区别：免费转付费如果**已经**引发愤怒与抵制，主导问题变成公平归因，转过去。本 skill 处理的是决策阶段。

## E — 可执行步骤 (Execution)

1. **写下这次免费/收费的唯一目的**
   - 动作：从三选一——①破除试用门槛拉新 ②筛选高意愿用户 ③让参与者认为它有价值。
   - 完成标准：只选一个。
   - 判停条件：若三个都想要，说明目标冲突，本 skill 的结论是必须取舍。

2. **按目的取路径**
   - 动作：目的①→免费；目的②③→收费。
   - 完成标准：得出"免费"或"收费"的初步结论。

3. **若走免费，先算单向门的代价**
   - 动作：列出三项预期损失——到场率/使用率下降、珍视度下降（不珍惜、超额索取、随手废弃）、未来收费的阻力。逐项给出可承受判断。
   - 完成标准：三项都写明"可承受"或"不可承受"。
   - 判停条件：任一"不可承受"，回步骤 2 改走收费或折中。

4. **若走免费，加限量与获取成本**
   - 动作：设置"每人限一份"、需报名/需完成一个小动作。零价格触发的是获取冲动，不加限制会导致超额索取（巧克力摊的标牌正是这么做的）。
   - 完成标准：有明确的份额上限或获取门槛。

5. **若走收费，用价格标签定义意义**
   - 动作：确认收费方向朝向"参与者付钱"，并在文案中把它表述为特权/席位/名额，而非成本分摊。
   - 完成标准：文案里没有"我们成本很高所以要收费"这类把体验推向劳动侧的表述。

6. **考虑押金型折中**
   - 动作：收取押金并在履约后全额返还。既有价格标签（定义为享受、筛选高意愿），又无净支出（保留低门槛）。
   - 完成标准：能说明押金的返还条件与操作成本。
   - 判停条件：若退款流程成本高于筛选收益，放弃，直接收小额费用。

7. **设计交易效用（无论收费与否）**
   - 动作：给出一个参考价，让成交显得占了便宜——赠品标注价值、"原价 X 现在 Y"、加价换购。注意：这属于呈现层，具体写法交给 `reference-price-framing`，并须过合规门（原价可举证）。
   - 完成标准：顾客能说出"我省了多少"。

8. **规划从 0 到 1 的过渡（若未来要收费）**
   - 动作：提前设计存量用户的保留条款——永久锁价、保留一个免费档、给出过渡期。不要等到宣布时才想。
   - 完成标准：文档中写明存量用户方案。
   - 判停条件：若无法给出任何存量保护，预期会触发义愤，转 `ultimatum-fairness-leverage` 处理归因与份额。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **边际成本高的实物或算力**：免费会被套利，零价格效应带来的量正是你最不想要的量。
- **需要长期变现且无法承受收费阻力的业务**：一旦跨过免费这道单向门，后续任何收费都要对抗巨大的心理跨度。
- **法规限制的领域**：金融产品的"免费"赠与、医疗的免费诊疗、教育的免费名额，常有合规约束。
- **免费转付费已经引爆舆论**：那时不是定价问题，转 `ultimatum-fairness-leverage`。

### 作者在书中警告的失败模式

- **免费不总是更好**（X9）：零价格提升领取率，但同时改变行为性质——人们会拿走超过需要的量、降低珍视，并使后续收费极难。免费是一道单向门。
- **用免费衡量热情会得到错的答案**：作者的巴黎追问指出，人们对"是不是好事"的判断本身就受价格污染。免费活动的报名量不能证明需求真实。
- **付钱给参与者可能适得其反**：汤姆·索亚实验的方向性说明，付钱会把体验重新编码为劳动，从而削弱内在积极性。给志愿者付小额报酬前要慎重。
- **降到极低价不如降到 0，但也不如不降**：19.99 相对 20.00 只是 1% 的折扣（X1 附近的讨论），理性上微不足道，行为上却有效——这说明价格心理的非线性，不要用线性思维推演免费。

### 作者的盲点 / 时代局限

- 巧克力摊与诗歌朗诵都是**小额、一次性、低风险**的场景。零价格效应在高价值、长期承诺（如免费一年的企业软件）中的形态，书中无证据。
- 成书于订阅制与 freemium 大规模成熟之前，未讨论免费用户的长期成本结构、也未讨论"免费增值"这一今天的主流模型。
- 未涉及数据/注意力作为对价的情形——今天大量"免费"服务并非零价格，只是换了计价单位；顾客对此的公平感知，书中未处理。
- 跨文化差异未检验（X16）。

### 容易混淆的邻近方法论

- **渗透定价（penetration pricing）**：低价快速获客，属正价格策略。它与免费的区别正是本 skill 的核心——0 不是低价的极端。
- **免费增值（freemium）**：是一种商业模型，本 skill 只提供其中"免费档该不该存在、代价是什么"的判据，不涵盖转化漏斗设计。
- **损失厌恶**：能解释从免费转收费为何痛，但不能解释零价格本身的跃迁（那是类别切换而非得失评估）。
- **稀缺性营销**：步骤 4 的限量借用了它，但目的不同——这里是为了抑制超额索取，不是为了制造紧迫感。
