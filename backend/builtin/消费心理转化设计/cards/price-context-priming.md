## I — 方法论骨架 (Interpretation)

与价格无关的情境线索，能可预测地改变人对价格的判断与付费行为，而当事人不知道、并且会否认。

要点在于**它改变的不是泛泛的好感，而是比较维度的权重**。曼德尔与约翰逊的实验里，硬币背景让人更关注价格，云朵背景让人更关注舒适——同样的商品、同样的信息，只是被拿来比较的那一个维度换了。这比"页面好看能提升转化"具体得多，也更可控：你想让顾客拿什么去比，就在环境里放什么。

第二条是**社会在场**。诚实箱是独裁者博弈的现实版本——没人监督，全凭自觉。换上一张直视你的眼睛图片，投币额是花朵图片的 2.6 倍。被看见的感觉（哪怕是假的）会大幅提高守约与给予。

第三条是**注意力的可占用性**。注意力是有限资源，被占用时判断会收窄到最显著的线索上。书中用"酒精近视"说明这一点——酒精不是让人更冲动，而是让注意力收窄到当下最突出的东西，远期后果被忽略。同类效应可由认知负荷、时间压力、信息过载产生，因此是**可被设计的变量**，方向也可反用：如果你希望对方做出深思熟虑的决定，就降低负荷、给出时间。

第四条是**效力随经验递减但不消失**。专业买家的浏览行为受背景影响较小，但最终选择照样被左右——启动影响的是他们从记忆中检索出哪些事实。

这套手法效力可观，**真正的限制是伦理而非效力**。因此本 skill 内置一道强制门：如果把手法公开告知，对方是否仍愿意交易？答案为否，就属于操纵而非说服，不得采用。

## A1 — 书中的应用 (Past Application)

### 案例 1：曼德尔与约翰逊的网页背景实验
- **问题**：网页上一张与商品无关的背景图，能改变购买决策吗？
- **方法论的使用**：76 名大学生访问两个假网站（一个卖沙发、一个卖汽车），每个产品在两款之间二选一，需要做价格与质量的权衡。变量只有主页背景：沙发站是"绿底硬币"或"蓬松云彩"，汽车站是"绿色美元符号"或"红橙火焰"。
- **结论**：背景把思维定势从"价格重要"推向"质量重要"。
- **结果**：扩大实验招募 385 名全美成年互联网用户并追踪页面停留时长——被金钱图片启动的新手买家在比较价格上花了更长时间；专业买家的浏览行为受影响较小，但选择同样被左右，因为启动影响了他们从记忆中检索的事实。

### 案例 2：纽卡斯尔大学的诚实箱
- **问题**：无人监督的自觉付费，能被环境提升吗？
- **方法论的使用**：贝特森、内特与罗伯茨自制标价签替换原标签，价格完全相同，只在顶部加一幅图片——有些是一双直视你的眼睛，有些是鲜花。每周更换，统计收款额，并用牛奶消耗量校准实际饮用量。
- **结论**：被注视的暗示（哪怕只是图片）显著提高守约给予。
- **结果**：眼睛图片周的投币额平均是鲜花图片周的 2.6 倍。作者点明：诚实箱其实就是独裁者博弈的白话版。

### 案例 3：注意力与"魔力价格"的关系
- **问题**：为什么 19.99 比 20.00 只便宜 1%，却能明显改变行为？
- **方法论的使用**：书中把它归入注意力机制——"在有许多难以评估的选项时，人的注意力是漂浮不定的。它会寻找好对比的项目。"
- **结论**：注意力会自动奔向"明显更优"的项，哪怕优势极小。
- **结果**：想象中的整数价格成了 .99 价格的陪衬，"给它洒上了一轮莫名其妙的诱人光辉"。这说明环境设计与标价设计共用同一注意力资源。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 落地页/商品详情页转化不好，或用户"只盯着价格看"。
2. 想让顾客把注意力从价格转到品质、舒适、耐用性上。
3. 线下门店、餐厅、展厅的氛围与陈列设计。
4. 安排一场重要谈判的时间、地点、在场人数。
5. 无人值守收银、打赏箱、押金自觉归还、共享物品归位率低。
6. 想降低冲动下单/退款率，需要给决策"减负"而不是加压。

### 语言信号 (用户的话里出现这些就应激活)

- "用户只看价格，怎么让他们看质量"
- "详情页/落地页怎么设计"
- "门店氛围该怎么弄"
- "无人货架老是丢东西／打赏率很低"
- "谈判安排在什么时候比较好"
- "page background"、"store atmosphere"、"nudge"

### 与相邻 skill 的区分

- 与 `reference-price-framing` 的区别：那个改的是**价格本身的显示**（数字、划线、措辞）；本 skill 改的是**价格周围的一切**（图像、氛围、在场者、节奏）。
- 与 `anchor-antidote` 的区别：那个应对**显性数字**对判断的拉动；本 skill 处理**隐性线索**的影响。若桌上已有对方报的数，先用那个。
- 与 `choice-set-decoy-design` 的区别：那个改的是**有哪些选项**；本 skill 不动选项，只动环境。两者常配合：先用集合定结构，再用环境定比较维度。
- 与 `ultimatum-fairness-leverage` 的区别：那个用**显性的归因与份额**处理公平冲突；本 skill 用**无意识线索**影响行为，因此伦理约束更严。

## E — 可执行步骤 (Execution)

1. **先过伦理门（前置，不可跳过）**
   - 动作：写下你打算使用的线索，然后自问——如果把这个手法明确告知对方，他是否仍愿意交易？
   - 完成标准：答案为是。
   - 判停条件：答案为否，或目标人群包含未成年人、认知受损者、财务困境中的借款人（见 X13），立即停止，本 skill 不适用。

2. **指定你希望被比较的维度**
   - 动作：明确写出一个维度（品质 / 舒适 / 耐用 / 安全 / 价格 / 速度），只选一个。
   - 完成标准：能用一个名词说清。
   - 判停条件：若你其实希望"什么都突出"，说明目标未定，回到产品定位。

3. **选择与该维度同义的环境线索**
   - 动作：把维度翻译成视觉/听觉/材质线索。要舒适就用柔软、云朵、暖光、织物；要价格敏感就用数字、硬币、货架密度；要耐用就用金属、重量、质感特写。
   - 完成标准：线索与维度语义一致，且与商品本身无直接信息关系（这正是启动而非说明）。

4. **需要守约与自觉时，加入社会在场**
   - 动作：加入被看见的暗示——真人头像、"对方正在查看"、信用分并排、公开记录、镜面或摄像提示。
   - 完成标准：用户在关键动作（付款、归还、如实填写）前能感知到"有人在"。
   - 判停条件：若属虚假监控暗示（假摄像头、伪造的"XX人正在看"），退回步骤 1 重过伦理门。

5. **调节认知负荷，方向与目标一致**
   - 动作：希望对方深思熟虑（大额、高退款风险、需长期履约）→ 降负荷：减少同屏信息、给出冷静期、避开深夜与疲劳时段。希望快速决策（低价、低风险、试用）→ 允许高显著性线索主导。
   - 完成标准：能说出你选的方向及理由。

6. **谈判场景的环境安排**
   - 动作：选择时间（避开对方注意力收窄的时段）、地点（谁的主场）、在场人数（你需要一个盟友时就带上，见 `anchor-antidote`）。
   - 完成标准：三项都有明确安排且有理由。

7. **验证：只测方向，且用行为数据**
   - 动作：A/B 测试单一线索变量，观察**比较维度的行为指标**（价格区域的停留时长、筛选器使用、参数页浏览深度），而不是只看转化率。
   - 完成标准：能证明比较维度确实发生了迁移。
   - 判停条件：若只有转化率变化而维度指标无变化，可能是其他因素，不要归因于启动。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **目标人群处于弱势或高风险**：小额信贷借款人、赌博/成瘾相关产品、医疗决策、未成年人。南非小额贷款实验（X13）中，邮件附加女性照片对男性借款人的吸引力提升相当于利率下降数个百分点——效果显著，但这正是必须禁止的类型。
- **需要知情同意的决策**：金融产品、保险、医疗、法律服务。启动的本质是绕过意识，与知情同意冲突。
- **能用直接信息解决的问题**：如果顾客只是不知道你的产品耐用，就写清楚参数，不要绕道启动。
- **代替真实价值**：环境能改变比较维度，不能改变商品本身。用它掩盖劣质产品只会提高退款与差评。

### 作者在书中警告的失败模式

- **当事人会否认，所以别指望用户调研验证**：启动效应的特征就是无意识。问卷问"背景图影响你了吗"只会得到否定答案。必须用行为指标。
- **对专家的作用形式不同**：专业买家的浏览行为受影响小，但选择照样被左右——不要因为"我们的用户很专业"就断定无效，也不要用同一套指标去测。
- **效应显著但不等于可用**（X13）：这是本 skill 唯一的硬红线。判据是公开告知测试。
- **注意力收窄是双刃**：酒精近视式的注意力收窄会让对方忽略远期后果——用它促成的成交，往往在冷静后变成退款、投诉或毁约。

### 作者的盲点 / 时代局限

- 启动效应（priming）是心理学**可重复性危机**的重灾区。本书成书于 2010 年，未涵盖此后大量失败的重复实验。书中引用的诚实箱与网页背景实验属效应量较大、场景具体的一类，相对稳健，但**任何应用都必须自测，不得直接套用文献效应量**。
- 实验多为一次性接触，未检验长期暴露后的适应与失效。
- 跨文化差异未检验（X16）：被注视暗示与社会规范线索的强度在不同文化中可能显著不同。
- 成书时无个性化推荐与生成式内容，未讨论"每个用户看到不同环境"带来的伦理与监管问题。

### 容易混淆的邻近方法论

- **助推（nudge）/ 选择架构**：同源但更广，包含默认项、排序等非启动手段。本 skill 只覆盖情境线索这一支。
- **品牌形象/氛围营销**：目标是建立长期联想；本 skill 是即时的、可测的维度切换，二者时间尺度不同。
- **锚定**：显性数字对数值判断的拉动，属 `anchor-first-offer` / `anchor-antidote`。
- **暗黑模式（dark patterns）**：以欺骗或阻碍为手段（虚假倒计时、隐藏退订）。本 skill 明确排斥——它们过不了公开告知测试。
