## I — 方法论骨架 (Interpretation)

接受了什么，就欠了什么——这条规范在所有人类文化中都存在，作者认为它是人类协作的地基。正因为地基太深，它有三个被常识低估的属性：

**一，恩惠可以被单方面启动。** 你没要，对方硬给，义务照样成立。机场硬塞的花、免费试吃、寄来的地址标签、不请自来的免费诊断——被施惠者从未同意进入这场交换，却已经在里面了。

**二，回报量系统性大于接受量。** 亏欠感是一种**不适**，人处置不适的目标是尽快消除，而不是公平清算。所以宁可超额偿还：10 美分的可乐换来 50 美分的彩票，几美分的地址标签换来数十美元的捐款。

**三，它能压倒好感。** 这是全书最硬的一条发现：在收到可乐的条件下，"喜不喜欢对方"与购买量的相关性**消失了**。互惠可以在原理竞争中胜过喜好——这意味着一个你并不喜欢的人，只要先给你一点东西，仍然能拿到你的顺从。

解除的办法不是拒收（拒收会误伤真实善意，且成本高）。作者的办法是**重新定义**：礼物照收，但在被要求回报的那一刻，判断它到底是善意还是销售成本。一旦归类为后者，互惠规范的适用前提（善意）不成立，义务感随之解除——这不是耍赖，因为规范的对象从来是善意，不是策略。

反过来做设计时，本 skill 给出的杠杆是：**恩惠的意外性与个人化程度，比恩惠的价值更能决定回报强度**。

## A1 — 书中的应用 (Past Application)

### 案例 1: 雷根的可乐实验

- **问题**：好感和亏欠感，哪个更能预测顺从？
- **方法论的使用**：康奈尔的丹尼斯·雷根让助手"乔"在休息时或者空手回来，或者带回两瓶可乐说"我给你也买了一瓶"，随后请被试买抽奖券。
- **结论**：亏欠感独立于好感起作用。
- **结果**：收到可乐的被试购买量约为对照组两倍；更关键的是，在收到可乐的条件下，"喜欢乔的程度"与购买量的相关性消失了。

### 案例 2: 美国伤残军人协会的地址标签

- **问题**：直邮募捐的回应率如何提升？
- **方法论的使用**：在募捐信中夹入一份未经请求的小礼物——个性化地址标签。
- **结论**：未经请求的低成本恩惠足以触发完整的偿还义务。
- **结果**：回应率从约 18% 升至约 35%，礼物成本仅几美分。

### 案例 3: 餐厅薄荷糖的三种给法

- **问题**：同样数量的糖，怎么给能多拿小费？
- **方法论的使用**：① 结账时给 1 颗 → 小费 +约 3.3%；② 给 2 颗 → +约 14%；③ 先给 1 颗，转身走开后又"特意"回来多给 1 颗 → +约 23%。
- **结论**：数量相同，条件不同——**意外性 + 个人化**把效果放大了近 7 倍。
- **结果**：这组数据成为"怎么给"比"给多少"更重要的直接证据。

### 案例 4: 黑门徒的花

- **问题**：如何向不认识、也不感兴趣的机场旅客募款？
- **方法论的使用**：先给对方别上一朵花或塞一本书，坚决不收回，然后才募捐。
- **结果**：募款成功率显著提升。而多数人转身把花丢进垃圾桶，黑门徒再从垃圾桶捡回来循环使用——赤裸地暴露了"礼物"只是触发装置，与价值无关。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 收了对方的东西/服务/帮助之后被提出请求，感到"不好意思拒绝"。
2. 供应商、中介、顾问在报价或签约前送礼、请客、提供免费诊断/试用。
3. 用户要设计获客动作：免费试用、试吃、免费评估、赠品、内容免费。
4. 用户在做募捐、公益、社群运营，需要提高响应率。
5. 职场中被同事"帮过一次"，此后持续被索取，想理清边界。

### 语言信号 (用户的话里出现这些就应激活)

- "人家都帮我这么多了，我不好意思不答应"
- "他请我吃了饭，现在要我给他介绍客户"
- "免费试用到期了，要不要付费" / "送了我一堆东西才开始谈价"
- "我们要不要先给点甜头 / 先免费再收费怎么设计"
- "I feel obligated / they did me a favor first / free trial then upsell"

### 与相邻 skill 的区分

- 与 `rejection-then-retreat` 的区别：**同属互惠原理，但触发物不同**。本 skill 的触发物是**给予**（东西、服务、帮助）；后者的触发物是**让步**（对方从大要求退到小要求）。若对方什么都没给、只是降低了要求 → 用 rejection-then-retreat。
- 与 `liking-paths` 的区别：雷根实验证明二者可分离。若顺从压力来自"他人很好、聊得来" → liking-paths；若来自"我欠他的" → 本 skill。
- 与 `zero-price` 类经济学 skill 的区别：本 skill 关注**义务感**，不关注免费带来的需求曲线变化。

## E — 可执行步骤 (Execution)

**防御向（用户是被施惠方）**

1. **确认亏欠感存在且正在起作用**：问"如果这个人从没给过你任何东西，你现在会答应吗？"
   - 完成标准：得到明确的是/否。若答案是"会"，则亏欠感不是主因，退出本 skill。

2. **做四项来源核查**：① 我主动要过这个好处吗？② 它来得突然吗？③ 给予者随后是否提出了请求？④ 我的第一反应是"不好意思"还是"这个交易划算吗"？
   - 完成标准：四项命中数。命中 ≥3 → 高度疑似策略性施惠。

3. **执行重新定义**：把它从"礼物"重新归类为"销售成本/关系投资"。原话可用："这是他做生意的成本，不是他给我的人情。"
   - 完成标准：用户能说出这句归类，并意识到互惠规范的前提（善意）不成立。
   - 注意：**不要求退还，也不建议提前拒收**——拒收会误伤真实善意。

4. **把恩惠与请求分别定价**：分开评估"这个好处值多少"和"这个请求要付出多少"，明确写出两个数。
   - 完成标准：两个数被独立写出，用户能看到不对等。

5. **给出可执行的回绝或还礼方案**：若关系需要维护，用**对等且可结清**的方式还（等值回礼、明确的一次性帮忙），而不是用对方要求的方式还。
   - 完成标准：给出一个具体动作与时间。

**设计向（用户是施惠方）**

6. **选择真实、有用、可意外交付的先予物**：优先满足"对方真的用得上"而非"我成本低"。
   - 完成标准：先予物能独立成立（即使对方从不回报，它也是有价值的交付）。
   - 判停条件：若先予物是虚假的（假称"专门为你争取的"、伪装成个人赠与的批量物料）→ **停止**，属于伪造触发条件。

7. **优化呈现而非价值**：按薄荷糖实验，把重点放在**意外性**（在对方没预期的时点）与**个人化**（明确指向这个人，而非群发）。
   - 完成标准：给出具体的给予时点与个人化措辞。

8. **不要在给予的同时提出请求**：留出时间间隔，且请求要与恩惠**量级相称**。
   - 完成标准：请求量级不超过恩惠的合理倍数；否则退回步骤 6 加大先予物或降低请求。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **真实的亲密关系与长期互助**（家人、挚友、稳定的同事互助网）：这些关系依赖不精算的互惠，把它当"策略"来拆解会破坏关系本身。作者明确区分了盟友与操纵者。
- **对方并未给予任何东西**，只是态度好或让了一步 → 转 `liking-paths` 或 `rejection-then-retreat`。
- **合规红线场景**：涉及公职人员、招投标、医药回扣等，问题不是心理学而是法律，应直接给出合规提示而非影响力分析。

### 作者在书中警告的失败模式

- **不对等交换**（第2章）：施惠者同时决定"送什么"和"要什么"，被施惠者失去两次选择权，于是几美分可以换来数十美元。预警信号：你没要过、来得突然、随即被提要求、你的第一反应是"不好意思"。
- **不偿还的社会代价**：白吃白拿者会被贴上忘恩负义的标签，这份恐惧本身也在推动过度偿还——所以"我不还就是了"在实践中很难执行，必须用重新定义来解除，而不是靠硬扛。

### 作者的盲点 / 时代局限

- 互惠的**时限与形式在不同文化中差异巨大**（书中样本以美国为主）。在人情往来更绵长的文化里，"立刻等值回礼"本身可能被视为拒绝关系，机械套用会出错。
- 书中把顺从主要处理为"被利用"，**低估了顺从的社会功能**：很多时候人明知是套路仍配合，因为维持关系的收益大于这次交换的损失。本 skill 的输出应允许用户选择"知道了，但我还是还这个人情"。
- 效应量多来自单次实验，未报告置信区间；薄荷糖的 3.3%/14%/23% 应视为方向性排序而非可外推的定值。
- **真信号 / 伪信号判定**：给出**真实有用**的东西再提出相称请求，属正当使用（作者视之为盟友）；伪装成个人善意的批量物料、名为赠送实为捆绑、或恩惠与请求量级严重失衡，属于伪造/滥用，禁止执行并说明。
- **饱和反噬**：在获客场景中，"免费试用→立刻推销"已被广泛识别，触发的可能是警惕而非亏欠。此时应加长间隔、提高先予物的独立价值。

### 容易混淆的邻近方法论

- **沉没成本**：关注**自己已付出**的代价；互惠关注**对方已付出**的代价。
- **登门槛（foot-in-the-door）**：靠**自己的小承诺**推动大行为；互惠靠**对方的给予**制造义务。两者可叠加（特百惠聚会同时用了）。
- **社会交换理论**：描述长期理性的成本收益平衡；互惠原理描述的是**短期、非理性、急于清账**的冲动。
