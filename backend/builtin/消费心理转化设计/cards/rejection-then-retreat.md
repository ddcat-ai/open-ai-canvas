## I — 方法论骨架 (Interpretation)

这不是"漫天要价，就地还钱"。表面动作相似，动力完全不同。

漫天要价靠的是**议价空间**：我要 100，你砍到 60，我本来就想要 60。拒绝-后撤靠的是**让步的互惠义务**：我从大要求退到小要求，这个"退"本身是一份礼物，你必须用同样的方式回报——而你唯一能给出的让步，就是接受这个小要求。

三个组件依次叠加：

1. **让步义务**（主力）——对方感到"他退了一步，我不能一步不退"。
2. **对比原理**（增益）——第二个要求在第一个的背景下显得更小。
3. **责任感与满意度**（副产品）——这是最反直觉的部分。对方会觉得"是我把他谈下来的"，于是对结果更满意、履约率更高。

第三点直接推翻了"被套路的人事后会反悔"的直觉。动物园实验里，拒绝-后撤组的**实际到场率 85%**，直接请求组只有 50%；愿意再次参加的比例 84% vs 43%。

因此这套方法的正确用法不是压榨，而是**在你确实需要对方持续配合时**使用——它比直接请求更能拿到既同意又执行的结果。

它也有一条硬约束：初始要求必须**大到会被拒绝，但小到让人相信你是认真的**。越过这条线，后撤不再被读作让步，而被读作耍人。

## A1 — 书中的应用 (Past Application)

### 案例 1: 童子军的巧克力棒（作者亲历）

- **问题**：如何向一个既不吃巧克力、又重视钱的陌生人卖出巧克力？
- **方法论的使用**：先推销 5 美元的马戏团门票；被拒绝后，退让到 1 美元一块的巧克力棒。
- **结论**：作者买了两块，事后自问"我怎么会这样？"
- **结果**：这次亲身经历成为作者研究顺从术的起点之一。它是这套方法的最小可复现单元：两个请求、一次拒绝、一次退让，别无变量。

### 案例 2: 青少年动物园项目实验

- **问题**：如何让大学生答应带一群少年犯去动物园玩一天？
- **方法论的使用**：对照组直接请求；实验组先请求"未来两年内每周花两小时为少年犯提供咨询"（几乎全部拒绝），再退到动物园一日游。
- **结论**：让步触发让步。
- **结果**：同意率 17% → 50%（约 3 倍）。追踪显示实验组**实际到场率 85%**（对照组 50%）、**愿意再次参加 84%**（对照组 43%）——满意度与履约率同时更高。

### 案例 3: 水门事件的"戈迪计划"

- **问题**：为什么几位精明的高层会批准一个荒唐的闯入计划？
- **方法论的使用**：戈迪最初提出的是造价 100 万美元、包含绑架、抢劫、用游艇设美人计的方案，被否；第二次降到 50 万，仍被否；第三次才是 25 万的"仅闯入"版本。
- **结论**：最终获批的方案，是在两轮荒唐提案的背景下被批准的——它相比前两版显得温和且便宜。
- **结果**：作者用它说明这套机制在**高利害、高智商群体**中同样生效，而且后果可能极其严重。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要提出一个自己觉得"对方大概率会拒绝"的请求（加薪、要预算、要人手、请假、请人帮大忙）。
2. 正在设计谈判开局：报价、条款、分工比例、赔偿金额。
3. 需要对方不仅同意、还要**认真执行**（合租家务、团队协作、长期承诺）——此时本 skill 的履约率优势最有价值。
4. 用户描述"对方主动降低了要求，我一下子就答应了"，需要事后判断是否被操纵。
5. 亲子/伴侣之间反复拉锯的要求（零花钱、门禁时间、家务分配）。

### 语言信号 (用户的话里出现这些就应激活)

- "我怕他直接拒绝 / 这个要求他肯定不同意"
- "开价开多少合适 / 要不要先多要一点"
- "他从 XX 降到了 YY，我觉得不好意思再拒绝"
- "怎么才能让他不光答应，还真的去做"
- "counteroffer / should I ask for more first / he came down so I agreed"

### 与相邻 skill 的区分

- 与 `contrast-sequencing` 的区别：**最容易混淆的一对**。判据是"第一项是否需要被明确拒绝"。需要 → 本 skill（动力是让步义务）；不需要、只是当背景板甚至可能成交 → contrast-sequencing（动力是知觉放大）。
- 与 `foot-in-the-door` 的区别：**方向相反**。本 skill 是大 → 小（一次会面内完成，靠互惠）；foot-in-the-door 是小 → 大（跨时间，靠自我形象一致）。用户说"先提个小的探探路" → 那是 foot-in-the-door。
- 与 `reciprocity-debt` 的区别：同源不同触发物——让步 vs 给予。

## E — 可执行步骤 (Execution)

1. **明确真实目标**：先把你实际想要的那个请求写清楚（含具体数量、时间、范围）。
   - 完成标准：真实目标是一句可被直接答应或拒绝的话。

2. **构造初始要求并做可信度检验**：初始要求应在同一维度上更大（更多钱/更多时间/更大范围），并通过三问——① 它是我可能真的想要的吗？② 对方听完会认真考虑还是会笑？③ 如果他居然答应了，我能接住吗？
   - 完成标准：三问全部为正。
   - 判停条件：任一为负 → 缩小初始要求后重跑本步。**这是本 skill 最高频的失败点**。

3. **提出初始要求并等待明确拒绝**：不要自行退让，不要在对方回应前加"当然如果不行……"。必须让拒绝真实发生。
   - 完成标准：对方给出了明确的否定。
   - 判停条件：若对方同意 → 皆大欢喜，流程结束（这也是初始要求必须能接住的原因）。

4. **后撤到真实目标**：明确表达这是**让步**（"那这样，我把范围缩到……"），并且**只退一次**。
   - 完成标准：退让被表述为一个动作，而不是一次新的独立请求。

5. **不做额外辩解**：说完后撤方案就停住，让让步本身产生作用；补充理由会把注意力拉回内容，稀释互惠。
   - 完成标准：话术在后撤方案后结束。

6. **收尾锁定责任感**：对方同意后，用一句把功劳归给对方（"谢谢你帮我把这个方案变得可行"）。这一步是履约率优势的来源。
   - 完成标准：给出一句具体措辞。

7. **（防御向）识别自己被后撤**：问三件事——① 第一个要求是不是荒唐到不像认真的？② 第二个要求如果**单独**提出来，我会答应吗？③ 我现在的"不好意思"是不是唯一的理由？
   - 完成标准：第②问给出独立答案；若单独提出时不会答应，则应拒绝。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **对方是你需要长期共事且已识破此法的人**：一旦被看穿，"你又来这套"的代价远大于单次收益。
- **对方无法拒绝你**（下属、孩子、有权力落差的一方）：拒绝不成立，让步就不成立，实际效果退化为压迫。
- **一次性、无关系的极端交易**：没有让步义务的社会土壤。
- **请求本身不正当**：见"戈迪计划"——这套方法对荒唐提案同样有效，这正是它危险的地方。

### 作者在书中警告的失败模式

- **初始要求过于离谱则整体反噬**（第2章）：极端到不合情理时，后撤不再被解读为让步，而被解读为不诚意；对方开始质疑动机而非讨论条件，且信任受损。**预警信号**：对方笑了、说"你在开玩笑吧"、开始追问你的用意。
- **退让过多次**：连退三次会暴露"每次拒绝都能换来一次降价"的规律，把互惠义务变成议价训练。
- **戈迪教训**：高智商、高利害不构成免疫。

### 作者的盲点 / 时代局限

- 实验样本为 20 世纪美国大学生与路人，**文化差异未被检验**：在把"讨价还价"视为常态的市场文化中，让步不被读作恩惠，效果可能大幅下降。
- 作者未处理**双方都在用这套方法**的情形（今天的谈判培训已普及），此时会退化为纯议价，互惠成分被抵消。
- 履约率的数据（85% vs 50%）来自单次实验，未见复现报告；应作为方向性结论。
- **真信号 / 伪信号判定**：初始要求必须是你**真的会接受**的方案（真让步）；虚构一个自己根本不打算履行的大要求，属于伪造让步，一旦被发现即为欺骗，禁止执行并说明。
- **饱和反噬**：谈判培训已把此法列为常识，对专业采购/HR 使用时，识破概率高；此时改用透明式议价（说明成本结构）更有效。

### 容易混淆的邻近方法论

- **锚定 + 议价**：靠数字牵引，不需要"拒绝"这个动作。
- **门面效应（door-in-the-face）**：即本方法的英文名，同一件事。
- **BATNA/谈判力**：靠替代方案的强弱，属于结构性谈判力，与心理让步义务无关；二者可叠加但不可互相替代。
