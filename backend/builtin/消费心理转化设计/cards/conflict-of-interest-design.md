## I — 方法论骨架 (Interpretation)

关于利益冲突，几乎所有制度设计都建立在两个错误假设上：

- 假设一：**有冲突的人知道自己有偏**（所以可以自我约束）；
- 假设二：**披露可以解决问题**（所以加一行声明就够了）。

两条都被证据推翻。

**第一条的反面：偏移是无意识的。**
买了昂贵 CAD/CAM 设备的牙医开始把无症状的牙齿裂纹都建议做牙冠。
关键不在于他想骗钱——**他真诚地认为自己在提供更好的治疗**。
沉没成本悄然改写了临床判断的阈值，而他察觉不到这次改写。
这使得"提醒对方注意利益冲突"这类干预从根本上失效：
你提醒的是一个自认无辜、且确实感觉无辜的人。

**第二条的反面：披露会放大偏移。**
这是本 skill 最重要、也最反直觉的一条：

> **披露利益冲突不是解药，它同时向两个方向加剧问题。**
>
> - 对**建议者**：披露产生**道德许可**——
>   "我已经说了，接下来怎么建议就不算隐瞒了"，
>   于是给出更偏颇的建议；
> - 对**接受者**：披露产生**社交压力**——
>   对方坦诚相告之后，再质疑他就显得不信任，
>   于是更难拒绝这条建议。

两个方向叠加，结果是**披露后的建议比不披露时更偏、也更容易被采纳**。
监管体系里大量的"风险提示""关联关系说明""广告标识"
都在这个陷阱里：它们让机构免责，却让用户更不安全。

由此，本 skill 的核心主张只有一句：

> **要消除偏移，必须切断利益关联本身，而不是声明它的存在。**

可用的结构性手段按效力排序：

1. **利益隔断**：让建议者的收益与建议内容无关（固定费用、第三方付费）；
2. **角色分离**：诊断者与执行者分开、推荐者与评审者分开；
3. **强制回避**：有关联即退出该项决策，而非披露后继续参与；
4. **轮换与多源**：多个独立来源交叉、定期轮换评审人；
5. **决策留痕与事后审计**：让偏移可被回溯（威慑来自可见性，不来自惩罚）；
6. **披露**：**只在前五项都不可行时使用**，且必须配合下面的补偿设计。

若不得不采用披露，至少要做三件事降低其副作用：
①披露与决策**分离时间**（先披露，隔一段时间再给建议，
削弱社交压力）；②由**第三方**而非建议者本人披露；
③给接受者一个**默认的替代路径**（"你可以先去××处获得独立意见"），
把拒绝从"人际对抗"变成"流程选项"。

## A1 — 书中的应用 (Past Application)

### 案例 1：CAD/CAM 牙医与不必要的牙冠

- **问题**：购置昂贵设备是否会改变临床判断？
- **方法论的使用**：艾瑞里追踪购入 CAD/CAM 设备的牙医的诊疗倾向。
- **结论**：这些牙医开始把无临床症状的牙齿裂纹也建议做牙冠。
  一名法学院学生因此接受手术，导致牙齿坏死、两次根管失败，最终胜诉。
- **结果**：**关键在于牙医并非蓄意欺骗。**
  沉没成本改写了他的诊断阈值，而他仍认为自己在做好事。
  这决定了所有基于"揭发/警示/自律"的干预都会落空。

### 案例 2：披露悖论

- **问题**：公开利益冲突能否保护客户？
- **方法论的使用**：比较披露与不披露条件下建议的偏移程度
  与接受者的采纳率。
- **结论**：披露给了建议者道德许可（偏移增大），
  同时给了接受者社交压力（更难拒绝）。
- **结果**：**披露后的整体结果比不披露更糟。**
  这直接否定了"知情即保护"这一监管默认假设。

### 案例 3：高尔夫球的三种移球方式（中介层如何软化判断）

- **问题**：同样是把球移动 10 厘米，方式不同会影响道德感知吗？
- **方法论的使用**：调查 12000 名球手，比较用球杆拨球、
  用鞋踢球、用手拿起放下三种方式。
- **结论**：球手认为"用球杆"最可能被做，"用手拿"最不可能。
  **与自己的行为隔一层工具，就更容易骗过自己。**
- **结果**：对本 skill 的意义是——利益关联的**间接程度**
  与偏移的容易程度正相关。
  经由第三方、经由折扣、经由"行业惯例"传递的利益，
  比直接现金更难被当事人识别为冲突，因此更危险。
  （心理距离的完整机制见 `fudge-factor-integrity`。）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill

1. **设计评审/招投标/供应商评估机制**：如何防止关联方影响结果。
2. **内容合规**：广告标识、合作内容、测评的独立性设计。
3. **金融与医疗建议**：佣金驱动的推荐、销售指标与专业判断的冲突。
4. **内部治理**：晋升委员会、绩效评定、内部审计的独立性。
5. **作为建议接受方的防御**："他推荐这个，是因为好，还是因为有提成？"
6. **研究与数据**：资助方与结论方向、内部数据分析的独立性。
7. **平台与生态**：既做裁判又做选手（自营业务与第三方商家）。
8. **合规文案撰写**：正在写一份免责声明或关联关系披露时——
   **这是最需要本 skill 介入的时刻**。

### 语言信号

- "我们加一行披露就行了吧"
- "既当裁判又当选手"
- "他推荐这个是不是因为有回扣"
- "标注了广告应该就没问题"
- "评审里有关联方，但他说会公正处理"
- "自营和第三方在同一个流量池里怎么办"
- "conflict of interest / disclosure / independent / recusal / kickback"

### 与相邻 skill 的区分

- 与 `fudge-factor-integrity`：那处理**普遍性的小额自我合理化**
  （每个人偷一点，靠心理距离与自我概念驱动），治理对象是**多数人**；
  本 skill 处理**特定角色的结构性偏移**（专家、评审、顾问），
  治理对象是**少数关键位置**。
  判据：问题出在"人人都会占一点便宜"还是"这个位置的人不该同时拿两份钱"。
  两者共享心理距离机制，可组合。
- 与 `manipulation-matrix-ethics`：那是**做产品的人**自问
  "我该不该做这个功能"（第一人称伦理自查）；
  本 skill 是**设计制度的人**处理"这个位置存在结构性偏移"
  （第三人称机制设计）。
- 与 `dishonesty-contagion-governance`：那处理不诚实在群体中的**传播**；
  本 skill 处理单一角色的**判断扭曲**。
  若一个有冲突的高管公开占便宜 → 两者叠加，先用本 skill 切断结构，
  再用那个处理已发生的示范效应。
- 与 `endowment-gap-correction`：牙医案例中的沉没成本机制与那里的
  禀赋/沉没成本相通，但那处理**估价偏移**，本 skill 处理**建议偏移**。
- 与 `incentive-inverted-u`：那处理激励**额度**与绩效的关系；
  本 skill 处理激励**方向**是否与被服务方的利益对齐。
  一个是量，一个是向。销售提成设计常需两者同时用。

## E — 可执行步骤 (Execution)

1. **先定位冲突结构，不要先判断动机**
   - 画一条线：**谁给建议 → 谁获益 → 获益是否随建议内容变化**。
   - 只要第三项为"是"，冲突就存在，与当事人品行无关。
   - 明确记录：这是**结构问题**，不是指控。
     （这一措辞很重要——把它说成品行问题会立刻引发防御，
     使后续改造无法推进。）
   - 完成标准：能画出这条链条并指出可变收益的位置。

2. **假定偏移是无意识的**
   - 不要设计任何依赖"当事人自觉"的机制：
     不要自我申报为唯一手段、不要靠"提醒注意"、
     不要靠"专业操守培训"。
   - 理由：CAD/CAM 牙医真诚地认为自己在做好事。
   - 完成标准：方案中没有任何一条以"当事人会自我约束"为前提。

3. **优先尝试切断，而不是声明**（核心动作）
   - 按效力顺序逐条评估可行性：
     - ①**利益隔断**：改为固定费用、第三方付费、
       与建议内容无关的计酬方式；
     - ②**角色分离**：诊断与执行分开（判断该不该做的人，
       不能是做的人）；推荐与评审分开；
     - ③**强制回避**：有关联即退出该项决策；
     - ④**轮换与多源**：多个独立来源交叉验证、评审人定期轮换；
     - ⑤**留痕与事后审计**：决策依据可回溯，样本抽查。
   - 完成标准：至少落地一条结构性手段，且写明为何前面几条不可行。

4. **只有在 1-5 全部不可行时才用披露，并做副作用补偿**
   - 三条补偿设计：
     - **时间分离**：披露与建议不在同一时点/同一次会话发生；
     - **第三方披露**：由平台/机构而非建议者本人告知；
     - **默认替代路径**：明确给出"你可以先获取独立意见"的具体入口，
       把拒绝变成流程选项而非人际对抗。
   - **禁止**：把披露当作"风险已处理"记入合规台账。
   - 完成标准：披露方案附带三条补偿，且文档中明确写着
     "披露不构成风险缓释"。

5. **对间接利益格外警惕**
   - 直接现金最容易被识别，因而危害最小。
     真正危险的是：折扣、返点、培训赞助、行业会议、
     设备投入形成的沉没成本、"合作关系"、未来机会的暗示。
   - 高尔夫球原理：**隔一层，就更容易骗过自己。**
   - 完成标准：冲突清单包含非现金形式的利益关联。

6. **作为接受方的防御清单**
   - 三问：
     - ①**他的收入是否随我的选择而变化？**
     - ②**如果我选另一个方案，他会损失什么？**
     - ③**有没有一个与结果无关的人可以问？**
   - 关键动作：**去找独立第二意见**，而不是追问对方是否有冲突
     （追问只会触发披露，而披露会增加你的采纳压力）。
   - 特别提醒：当对方**主动坦诚**了利益关系时，
     你面临的采纳压力**更大**而非更小。此时应刻意延迟决定。
   - 完成标准：重大建议（医疗、金融、大额采购）
     至少获得一个无利益关联的第二意见。

7. **建立可回溯性，而不是加大惩罚**
   - 让决策依据留痕并可被抽查。
     威慑主要来自**可见性**而非惩罚力度
     （惩罚为何不是杠杆，见 `fudge-factor-integrity`）。
   - 完成标准：存在抽查机制与留痕要求，且抽查真实执行。

8. **平台/生态场景的专项处理**
   - "既做裁判又做选手"是本 skill 的极端形态。
   - 可用手段：自营与第三方使用**同一套公开规则**、
     排序算法与自营收益脱钩、独立申诉通道、
     关键指标对外披露（此处披露有效，因为对象是**公众监督**
     而非**被建议的个人**）。
   - 注意这个例外：**面向监管与公众的披露是有效的**，
     它触发的是外部约束；本 skill 反对的是**面向被建议者个人**的披露，
     它触发的是道德许可与社交压力。
   - 完成标准：区分了两种披露对象，未混用。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **面对的是蓄意欺诈**：本 skill 处理的是无意识偏移。
  若已有证据表明是有意为之，那是舞弊调查与法律问题，
  机制设计无法替代。
- **冲突不可避免且各方均已知情的对称场景**：
  谈判双方都是代理人、市场上所有卖家都收佣金——
  此时的正确工具是提高比价与退出能力，不是消除冲突。
- **用它给一切建议贴上不可信标签**：
  存在冲突不等于建议错误。过度使用会导致对专业意见的普遍不信任，
  代价可能高于偏移本身。
- **小额、低风险、可逆的建议**：机制成本会超过收益。
  本 skill 适用于**高风险、不可逆、信息不对称大**的决策。

### 作者在书中警告的失败模式

- **"披露即解决"是错的，且方向相反**（x05）：
  披露放大建议者的偏移，同时增加接受者的采纳压力。
  设计合规文案时，**不要把披露当成风险已被处理**。
- **"他知道自己有偏，所以会克制"是错的**：
  偏移无意识，当事人真诚。
- **"补充信息几乎从不改变行为"（p15）**：
  给用户更多关于利益关系的信息，不会改变他的选择。
  必须改结构，不是改说明。
- **间接利益更危险**：隔一层工具就更容易骗过自己（高尔夫球）。
  非现金的利益输送是识别难度最高、因而偏移最大的形态。

### 作者的盲点 / 时代局限

- ⚠️ **重要可靠性提示**：艾瑞里团队的部分诚实性研究已被证实
  存在数据造假并遭撤稿（详见 `fudge-factor-integrity` B 段
  与 `dishonesty-contagion-governance`）。**这直接影响本册（册4）
  相关结论的引用强度。**
  就本 skill 而言：
  - **披露悖论**的核心证据主要来自 Cain、Loewenstein & Moore（2005, 2011）
    的独立研究，**不属于**受争议的实验，可继续引用；
  - **CAD/CAM 牙医**为观察性叙述，非受控实验，
    应作为说明性案例而非证据；
  - **高尔夫球调查**为自陈式问卷，效力有限。
  引用时不应以"艾瑞里的实验证明"作为强度背书。
- **未讨论披露的另一种对象**：书中把披露当作单一概念否定，
  但面向**监管与公众**的强制披露（上市公司关联交易、
  临床试验注册）有独立的有效性证据。
  本 skill 第 8 步对此作了区分，属于整理时的补充。
- **未讨论算法化的利益冲突**：推荐系统、竞价排序、
  自营流量分配中的冲突不由个人判断承载，
  而由目标函数承载。此时"回避"与"角色分离"需要重新定义
  （如排序目标与变现目标的分离），书中无对应分析。
- **文化与制度差异**：回避制度的可执行性高度依赖组织规模与人才密度。
  小机构中"找一个无关联的人"常常不可行，
  书中未讨论这类现实约束下的次优方案。

### 容易混淆的邻近方法论

- **合规（Compliance）**：那以规则遵守与留痕为目标，
  披露常被计为已完成的控制措施；本 skill 明确指出
  **披露不构成风险缓释**。两者在此处直接冲突，需要显式协调。
- **代理问题（Principal-Agent Problem）**：那是经济学框架，
  假定代理人**理性地**追求自身利益；
  本 skill 强调偏移是**无意识**的，因此激励对齐之外
  还需要结构隔离。
- **信息不对称**：那认为问题源于信息缺失，解法是信息传递；
  本 skill 认为传递信息（披露）反而加剧问题。**结论相反，
  不要混用。**
- **确认偏误**：那是证据筛选偏差，无利益驱动；
  本 skill 特指由**收益关联**驱动的判断扭曲。
  两者常同时发生，但干预手段不同。
