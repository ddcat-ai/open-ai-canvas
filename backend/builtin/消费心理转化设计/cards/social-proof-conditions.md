## I — 方法论骨架 (Interpretation)

"别人都在做"这件事什么时候有力、什么时候没用，不是玄学，作者给了两个可以逐一检查的开关。

**开关一：不确定性。** 人对情况越没把握，越会向他人的行为寻找答案。反过来说，当目标对象**已经很确定**自己要什么（有明确偏好、有专业判断、有既定标准）时，社会证据几乎不起作用，甚至引起反感。所以第一步永远是问：**他现在不确定的是什么？**

而"不确定"要再分一层，这决定了你该用哪种武器：

- 不确定**事实**（这东西有没有效、安不安全、原理对不对）→ 权威更强。
- 不确定**行为**（像我这样的人该不该做、别人都怎么做的、这样做会不会显得奇怪）→ 社会认同更强。

**开关二：相似性。** 社会证据不是任何人的行为都算数，起作用的是**与自己相似的人**。这是本单元最有价值也最反常识的一条：在行为类问题上，**相似度的权重高于地位**。同龄儿童的示范治好了怕狗的孩子，成人示范则效果大减；邻居的捐款名单比名人名单更能拉动捐款。

第三条要点是关于这个机制的**自动性**：罐头笑声在观众**明知它是假的**时仍然有效，而且对**差**笑话的提升最明显。这说明社会证据不经过意识审查——你识破了它，它照样起作用。因此防御不能靠"我知道这是假的"，只能靠核查证据的**真实性**（见 B 段）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 怕狗儿童的示范治疗

- **问题**：如何让极度怕狗的幼儿园孩子敢接近狗？
- **方法论的使用**：让孩子每天观看一段 20 分钟的短片，片中一个**同龄小男孩**开心地和狗玩耍。
- **结论**：示范者的年龄相似性是关键变量；后续研究显示，**多个不同孩子与多条不同的狗**的组合效果更强。
- **结果**：仅 4 天后，67% 的孩子愿意爬进围栏与狗独处；一个月后效果仍在。而以成人为示范者时，效果显著减弱。

### 案例 2: 罐头笑声

- **问题**：观众普遍讨厌罐头笑声，电视台为什么还在用？
- **方法论的使用**：在情景喜剧中插入预录的笑声。
- **结论**：实验显示它提高了观众的笑的次数与对笑话的评价，**且对质量差的笑话提升最明显**；即便观众明知笑声是假的，效果依然存在。
- **结果**：作者用它证明社会证据的反应**不经意识审查**，且在信息质量差（不确定性高）时最强。

### 案例 3: 菲利普斯的自杀报道统计

- **问题**：为什么头版自杀报道之后，飞机与汽车事故会异常增多？
- **方法论的使用**：比对报道内容与随后事故死者的特征。
- **结论**：模仿的对象与报道中的人在**年龄、情境、事故类型**上高度匹配——单人自杀报道后单人事故上升，多人殉难报道后多人事故上升。
- **结果**：相似性作为调节变量在极端行为上同样成立。这是相似性最沉重的一条证据。

### 案例 4: 伪造社会证据的商业清单

- **问题**：从业者如何人为制造"大家都在这么做"？
- **方法论的使用**：酒保在小费罐里预先放几张钞票；教堂募捐篮里先放钱；夜总会故意在门外留一条队伍；广告词从"销量领先"到"增长最快"。
- **结论**：这些手法都在制造相似他人的行为证据，成本极低。
- **结果**：作者据此提出防御原则——不是不看社会证据，而是**核查证据本身是否被伪造**。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写落地页、详情页、方案书，纠结"放专家背书还是放用户评价"。
2. 做品牌投放，在头部 KOL 与大量素人 UGC 之间做预算分配。
3. 设计新用户引导：如何让人相信"这个用法是常规的"。
4. 推动组织内部的行为改变（用榜样还是用制度）。
5. 想让孩子/下属克服某种恐惧或抵触，考虑找谁来示范。
6. 评估一份看起来"大家都说好"的证据是否可信（防御向）。
7. 公共倡导：设计节能、垃圾分类、健康行为的宣传语。

### 语言信号 (用户的话里出现这些就应激活)

- "找谁背书 / 找大 V 还是素人"
- "要不要放用户评价 / 要不要写'已有 10 万人选择'"
- "大家都这么做 / 别人都买了"
- "怎么让新用户相信这是常规操作"
- "榜样怎么选 / 找谁来示范"
- "social proof / testimonial / UGC / influencer marketing"

### 与相邻 skill 的区分

- 与 `authority-two-questions` 的区别：**互补且需按不确定性类型分流**。事实不确定 → 权威；行为不确定 → 社会认同。最优做法是分区并置：功效区放权威，决策区放相似者证言。误用的典型是给"像我这样的人该不该买"这一问题配了一个院士。
- 与 `single-point-help` 的区别：那是社会认同**失效**（多元无知）的特例处理——人多反而没人动。本 skill 处理的是如何**利用**社会认同。若场景是"群体在场却无人响应"，直接转 `single-point-help`。
- 与 `liking-paths` 的区别：相似性在两处都出现，但作用点不同——本 skill 里相似性决定**证据是否算数**（认知参照），`liking-paths` 里相似性制造**好感**（情感联结）。前者你不必喜欢那个人。
- 与 `scarcity-pause` 的区别："已售 9 万件，仅剩 1000" 是两个武器叠加。拆开检查：销量数字是社会证据（可核查真伪），剩余数量是稀缺（触发情绪）。

## E — 可执行步骤 (Execution)

1. **定位不确定性**：写下目标对象此刻**具体不确定什么**（用一句他心里的问句表述）。
   - 完成标准：得到一句第一人称疑问句。
   - 判停条件：若他其实很确定（有明确偏好、专业判断），社会证据无效甚至招反感 → 停止，改用直接价值论证。

2. **给不确定性分类**：这句问句是**事实问题**（有没有用/安不安全）还是**行为问题**（我该不该/别人怎么做）？
   - 完成标准：明确二选一，或拆成两个分区。
   - 事实问题 → 转 `authority-two-questions` 设计权威证据；行为问题 → 继续。

3. **定义"相似"的具体维度**：目标对象会拿谁当参照？逐维度列出：年龄、性别、地域、职业、消费能力、所处阶段、面临的具体问题。
   - 完成标准：写出 3 个以上具体维度，而非"目标用户"这种笼统词。

4. **按相似度而非地位挑选证言人**：在同等成本下优先选与目标高度重合的普通人；地位只在事实问题上加分。
   - 完成标准：给出证言人画像，且能说明它在哪几个维度上与目标重合。

5. **让证言具体而非评价性**："我用它三个月，通勤时间从 50 分钟降到 30" > "很好用，推荐"。具体细节同时提供了相似性线索与可验证性。
   - 完成标准：每条证言含至少一个具体情境与一个具体结果。

6. **提供多个不同的示范者**：怕狗实验的后续版本显示，多示范者、多情境的组合效果更强。避免只有一个"完美案例"。
   - 完成标准：至少 3 个不同背景的示范者。

7. **陈述真实的多数行为**：如果多数人确实在做，直接说出准确数字；若多数人**没有**在做，**不要**编造多数——改用"增长最快"这类真实的动态描述，或转用其他武器。
   - 完成标准：每一个数字都能给出来源。
   - 硬约束：见 B 段真信号判定。

8. **防御向自检**：面对别人给你的社会证据时，问三句——这些人和我真的相似吗？这些数据可核查吗？如果这个数字是假的，我的判断会变吗？
   - 完成标准：三问各有明确答案。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **目标对象已有明确偏好或专业判断**：社会证据在此不但无效，还会传递"你不懂所以只能随大流"的暗示，引发反感。
- **诉求点恰恰是独特性**（奢侈品、小众身份、专业工具）：多数人在用是**减分项**。此时应转向稀缺与身份区隔。
- **多数人的行为正是你想改变的**（"90% 的人都没有按时归还"）：陈述这个真实数字会**强化**不良行为。改说"在与你相似的这群人中，X% 已经做到了"，或改用其他框架。
- **紧急求助场景**：人越多越没人动，见 `single-point-help`。

### 作者在书中警告的失败模式

- **多元无知**（第4章）：所有人都在观察别人以决定该不该行动，结果所有人都表现出镇定，集体读出"没事"。人数增加会让错误自我放大。
- **维特效应**（第4章，菲利普斯研究）：社会证据在极端行为上同样生效且与相似性匹配。公开报道自杀、自残、极端事件的方式会造成模仿。这是本原理最严重的负外部性。
- **明知是假仍然有效**（罐头笑声）：不要以为"我识破了"就免疫。防御必须落在**核查证据真伪**上，而不是心理上的抵抗。
- **伪造成本极低**：小费罐、募捐篮、门口的队伍、刷出来的评价与榜单——正因为伪造便宜，社会证据在商业环境中的可信度系统性偏低。

### 作者的盲点 / 时代局限

- 罐头笑声、示范治疗等为 1960–70 年代研究。其中**部分社会心理学效应在近十余年的大规模复现研究中未能稳定重现**（尤其是启动类与媒体模仿类研究）；菲利普斯的自杀模仿统计属**相关性研究**，混杂因素难以完全排除。**复现存疑，勿作硬结论**：可用于生成假设与设计方案，不宜作为量化预测依据。
- 作者写作时不存在**算法推荐与刷量产业**。今天"大家都在看"往往是推荐系统的产物而非真实多数，且可被规模化伪造。这使得"核查真伪"这一防御的成本大幅上升，是书中方法论最需要更新的部分。
- 书中未处理**社会证据的反向选择**：在评价体系被污染的市场里，用户已发展出"看差评而非好评""看具体细节而非分数"的对策，纯量级社会证据的边际效力在下降。
- 跨文化：集体主义文化下社会认同的权重更高，但**参照群体的边界更窄**（限于内群体）。用广义"大众"数据在此类文化中未必更有效。
- **真信号 / 伪信号判定**：真实地展示真实用户的真实行为（可核查的数量、可追溯的评价、真实的示范者），是在为对方提供有效的决策捷径，属正当使用；刷单、买评、伪造队列、编造"10 万人已选择"、雇佣与目标相似的演员冒充用户——属于伪造触发条件，**禁止执行并说明**，同时它污染的是所有诚实卖家共同依赖的公共信号。
- **饱和反噬**：用户对"销量第一""万人推荐"这类表述已高度脱敏，甚至将其读作低质信号。具体的、有名有姓、可交叉验证的少量证言，效力已高于笼统的大数字。

### 容易混淆的邻近方法论

- **从众实验（Asch）**：那是**判断被公开表态扭曲**（人明知答案却跟随），本 skill 是**不确定时把他人当信息**。前者靠社会压力，后者靠信息推断。
- **网络效应**：真实的价值随用户数增长；社会证据只是**感知**层面，用户数不增加产品效用时依然生效。别把两者混在一个论证里。
- **权威背书**：见 `authority-two-questions`，按不确定性类型分流。
- **口碑营销/推荐机制**：那是分发渠道问题，本 skill 是内容与选人判据。
