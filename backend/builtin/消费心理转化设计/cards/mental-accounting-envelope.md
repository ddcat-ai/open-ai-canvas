## I — 方法论骨架 (Interpretation)

金钱有一个基本属性叫**可替代性**：一元就是一元，无论它从哪来。
但人的大脑完全不这么运作。

我们把钱按**来源**（工资/奖金/退税/彩票/礼金/报销）和**用途**
（生活/娱乐/教育/应急/投资）分进一个个互不相通的心理信封。
同一笔钱在不同信封里，花法可以相差几倍：

- 年终奖被当作"额外的"，于是买了平时绝不会买的东西；
- 报销款被当作"不是我的钱"，于是花得格外松；
- 一边在储蓄账户里存着 3% 的钱，一边背着 18% 的信用卡欠款，
  因为它们在两个信封里，从不放在一起看；
- 部门预算"今年不花完明年就少给"，于是年底突击采购。

这个机制在两个方向上都有力量，而**区别只在于账户是谁设的**：

| 谁在设账户 | 性质 | 例 |
|---|---|---|
| **别人替你设** | 陷阱 | 代金券、会员余额、"专属额度"、赌场筹码、平台币、"这是奖励给你的" |
| **你自己设** | 工具 | 预算信封、专项储蓄账户、自动转存、写上用途的账户名 |

所以本 skill 不是"要消灭心理账户"——那既做不到也不划算。
而是：**把别人替你设的账户拆掉，把自己需要的账户建起来。**

自设账户之所以有效，是因为它同时利用了另外两个机制：
**决策停顿点**（要动这笔钱必须先跨过账户边界这个动作）
和**情感权重**（在信封上写"孩子学费"或家人的名字，会让挪用变得困难）。

## A1 — 书中的应用 (Past Application)

### 案例 1：赌场里的两笔钱

- **问题**：为什么同一个人在赌场对几百块毫不在意，在超市却为几块钱比价？
- **方法论的使用**：艾瑞里描述赌客把筹码归入"赌资账户"——
  这个账户里的钱被预先标记为"本来就准备输掉的"，因此每一次下注都不触发损失感。
- **结论**：账户标签改变的不是金额，是这笔钱被感知的性质。
- **结果**：赢来的钱（"庄家的钱"）会被更快地输回去，
  因为它被归入一个更松的账户。

### 案例 2：意外之财的花法

- **问题**：退税、年终奖、中奖这类"横财"会被怎么处理？
- **方法论的使用**：艾瑞里指出，人们对这类收入的处置与对工资的处置系统性不同——
  更容易用于享乐型消费，更少用于还债或储蓄。
- **结论**：但这笔钱的购买力与工资完全相同，它的机会成本也完全相同。
  唯一的差别是心理标签。
- **结果**：横财往往在几周内消失，而当事人事后说不清它去了哪。

### 案例 3：写上名字的信封

- **问题**：心理账户能不能被反过来利用？
- **方法论的使用**：艾瑞里提到把现金分装进标注用途的信封，
  并在其中一个信封上写下**子女的名字**。
- **结论**：账户边界本身是一个决策停顿点；
  而写上具体的人名，则给这个停顿点附加了情感权重，
  使"挪用"从一次转账变成一次背叛。
- **结果**：这是全书中少数明确的、可以立即执行的自控工具之一。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill

1. **意外之财到手**：年终奖、退税、卖二手、中奖、礼金，不知道怎么处理。
2. **钱不知道花哪了**：收入不低，月底却没剩下，记账也看不出问题。
3. **一边存钱一边负债**：储蓄和高息欠款并存。
4. **部门预算怪象**：年底突击花钱、跨科目挪不动、"这笔钱只能用于这个"。
5. **想建立支出控制**但意志力方案总失败。
6. **识破商家的账户设计**：预充值、会员余额、代金券、平台币、
   "您的专属额度"。
7. **家庭财务分歧**：夫妻各自有隐形账户，对同一笔钱的定性不同。

### 语言信号

- "年终奖打算怎么花"
- "反正是报销的 / 反正是白来的"
- "这笔钱是娱乐预算，不算在里面"
- "年底预算花不完就作废了"
- "记了几个月账，还是没剩下"
- "卡里还有 300 块余额，得去用掉"
- "mental accounting / windfall / use it or lose it / budget silo"

### 与相邻 skill 的区分

- 与 `opportunity-cost-swap`：那判断**单笔支出值不值**；
  本 skill 处理**钱的分配结构**。顺序通常是先结构后单笔。
- 与 `pain-of-paying-tuning`：那处理**支付形式**如何影响花钱意愿
  （刷卡/预付/自动扣款）；本 skill 处理**资金归类**。
  信号区分："刷卡就没感觉" → 那个；"这是奖金所以随便花" → 本 skill。
- 与 `ulysses-self-control-architecture`：本 skill 的自设信封是那个阶梯中的
  第 0–1 档实例。若需要更强的约束（自动扣款、账户锁定），转那个。
- 与 `future-self-vividness`：那专门解决"为未来存钱像给陌生人送钱"的问题。
  若困难在于**长期储蓄的动机**而非**当期分配**，用那个。
- 与 `zero-price-transaction-utility`：那是设计免费/收费策略的卖方视角。

## E — 可执行步骤 (Execution)

1. **把所有心理信封显性列出来**
   - 按**来源**列：工资、奖金、副业、报销、意外之财、家人给的。
   - 按**用途**列：生活、娱乐、学习、应急、投资、"以后再说"。
   - 关键问题：**哪些钱你在心里认为"不算数"？** 那些就是最危险的信封。
   - 完成标准：得到一张信封清单，并标出"不算数"的那些。

2. **拆掉"不算数"的信封（核心动作）**
   - 规则：**所有收入先进同一个池子，再重新分配。**
   - 具体做法：年终奖/退税/意外之财到账后，不做任何消费决策，
     先转入主账户，与工资混同，等待至少 7 天再按统一规则分配。
   - 效果：横财失去"额外的"标签后，会自动接受与工资相同的审视标准。
   - 完成标准：有一条明确的"横财入池"规则。

3. **做一次跨信封对账**
   - 把储蓄类与负债类放在同一张表上，按**利率**排序。
   - 典型发现：3% 的存款与 18% 的欠款并存，跨信封看一眼就无法接受，
     但在各自信封里都"很合理"。
   - 完成标准：得到一张按利率排序的资产负债表，并给出还款/调整顺序。

4. **主动建立需要的信封（反向利用）**
   - 建账户的三条要求：
     - **物理隔离**：独立账户、独立卡、独立现金信封——
       跨越边界必须是一个真实动作，而不是心里的一条线。
     - **写上具体用途或人名**：不是"储蓄"，而是"2027 年换房首付"
       或直接写孩子的名字。情感权重决定停顿点的强度。
     - **自动化流入**：发薪日自动转账，不依赖每月的决定。
   - 完成标准：至少建立 2 个物理隔离、有具名、自动流入的账户。

5. **给容易失控的类别设置小额信封**
   - 对无法用"值不值"判断的高频小额支出（外卖、打车、零食、小额网购），
     不做逐笔判断，改为**总量控制**：每周一个固定额度，用完即止。
   - 这是把决策从"每一笔"移到"每周一次"，大幅降低决策成本。
   - 完成标准：高频小额类别有明确的周期额度。

6. **识破外部设的账户**
   - 遇到预充值、会员余额、代金券、平台币、"专属额度"时，做一次换算：
     **这等于多少现金？如果现在给我等额现金，我会拿去买这个吗？**
   - 特别警惕"不用就浪费"的话术——那是在用一个虚构的损失，
     驱动一次真实的支出。
   - 完成标准：对当前持有的所有余额类资产做一次现金等价换算。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **收入极不稳定或极度紧张**：信封法假定有可分配的余量。
  月月月光时，需要的是增收与债务重组，不是分账户。
- **组织的预算科目由制度与审计要求决定**：那些"信封"有合规功能，
  不能仅因心理学理由拆除。本 skill 只适用于**可自主调整**的部分。
- **把信封法用作逃避总账的手段**：如果建了十个账户却从不做汇总，
  等于自建了新的心理账户问题。
- **伴侣间的隐形账户涉及信任问题**：那是关系议题，不是财务技术议题。

### 作者在书中警告的失败模式

- **横财必被挥霍**：不做"入池"处理的意外之财，几乎必然被花掉，
  且事后说不清去向。
- **"不用就浪费"是最有效的支出驱动话术**：会员余额、
  即将过期的券、年底预算，都利用了同一个虚构损失。
- **记账本身不改变行为**：艾瑞里明确指出，
  只是了解一件事情并不能改变行为。看清自己的账户结构之后，
  必须落到**物理隔离与自动化**上，否则无效。
- **同一机制两种用法**：心理账户既是陷阱也是工具，
  区别只在账户是谁设的。判断时先问这个问题。

### 作者的盲点 / 时代局限

- 心理账户理论主要来自 Richard Thaler（1985 及后续），
  艾瑞里在本书中是转述与应用，不是原创贡献。引用时应指向 Thaler。
- 艾瑞里团队的部分研究已卷入数据可靠性争议（详见 `fudge-factor-integrity` B 段），
  但心理账户本身是行为经济学中最稳健的发现之一，有大量独立复现。
- 书中的"现金信封"在移动支付普及后已不易执行。
  当代替代方案（多账户、子钱包、自动转存、消费额度设置）书中没有讨论，
  本 skill 的第 4 步已作现代化改写。
- 未讨论**账户过多的管理成本**，以及自动化理财工具如何改变这一权衡。

### 容易混淆的邻近方法论

- **预算管理（传统财务）**：那假定人会按计划执行；
  本 skill 明确指出计划无效，必须靠**物理隔离与自动化**。
- **零基预算（YNAB 等方法）**：实践上高度重合，
  本 skill 补充了"为什么有效"的心理机制与"横财入池"这一关键规则。
- **付款之痛**：那关注**支付形式**；心理账户关注**资金归类**。
  常同时出现（筹码既降低痛感又建立了账户），但机制不同。
