## I — 方法论骨架 (Interpretation)

人对"这东西值多少钱"的判断有刻度但没有原点。刻度（A 比 B 贵多少倍）是稳定的、可复现的、看起来非常理性的；原点（A 到底值 8 块还是 28 块）却是空的，会被任何一个先到场的数字填上——哪怕那个数字明显与商品无关，比如你社会安全号码的末两位。

这带来一个反直觉的后果：**顾客表现出的"理性比价"不是理性的证明，而是操纵已经生效的标志**。他们确实在一致地、连贯地判断价格，只不过整套判断悬挂在一个任意的原点上。阿雷利等人称之为"后推法建立自我一致性"——一旦你在某个价位上做过一次"买/不买"的决定，后续所有判断都会被迫与它兼容。

因此定价的第一动作不是"算出正确的数"（不存在），而是**决定顾客将来在哪个结构里比较**。你要植入的是一整套相对关系，而不是一个孤立的数字。首价的作用是设定原点；一旦原点被接受，它本身会隐入背景（人们记不住来源，只记得结构），此后你所有的调价空间都被这个原点框死。

同一机制在薪酬与通胀语境下表现为货币错觉：被人们固化并据以判断的是**名义数字构成的结构**，而不是真实购买力。所以老话说，富人就是总能比自家连襟多挣 100 块的家伙。

底层的心理物理学依据是：价值感是一条有刻度、无原点的主观量表（史蒂文斯量值量表），这正是原点可被外来数字设定的原因。

## A1 — 书中的应用 (Past Application)

### 案例 1：麻省理工社会安全号码拍卖
- **问题**：如果人真有稳定的"保留价格"，一个随机数字就不该影响出价。真的有吗？
- **方法论的使用**：让 MBA 考生先写下社会安全号码末两位，再回答"这瓶酒你愿意出的价高于还是低于这个数（美元）"，最后写出真实愿付价，中标者自掏腰包。
- **结论**：绝对水平被随机数捕获，相对结构不受影响。
- **结果**：末两位 00-19 的人对一瓶罗纳谷红酒平均出价 8.64 美元，80-99 的人平均出价 27.91 美元，相差三倍多；但两组内部"罕有红酒 ≈ 普通红酒 × 1.5"的比例关系一致。巧克力、无线键鼠、设计书同样成立。

### 案例 2：四季宝花生酱的凹底罐
- **问题**：成本上升，直接涨价 10% 会流失顾客。
- **方法论的使用**：不动名义价格，改动包装容量（罐底凹陷），相当于隐性涨价 10%。
- **结论**：顾客锚在名义价格上，而非单位价值上。
- **结果**：等效涨价完成而无人察觉。家乐氏 2008 年夏对多个麦片品牌改用细长纸箱，同样无人注意——购物者只看货架上的高度和宽度，伸手取下时购买决定已经做完。

### 案例 3：工资的任意连贯性（货币错觉）
- **问题**：工资是理性权衡的结果吗？
- **方法论的使用**：阿雷利等人指出，工人对工资**变化**敏感，对工资的**绝对水平**及其相对于同业的位置却相当迟钝。
- **结论**：薪酬同样是有刻度无原点的量。
- **结果**：形成了那句心照不宣的老话——所谓富人，就是总能比自家连襟多挣 100 块的家伙。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 要给一个**没有可比品**的东西定价：新品类硬件、一项从没人卖过的咨询服务、一门新课程、一个尚无市场的 SaaS 模块。
2. 要决定**首发价 / 内测价 / 早鸟价**，并担心以后涨不上去。
3. 自由职业者、设计师、顾问第一次给某类项目报价，或求职者要说出期望薪资。
4. 产品明显优于竞品却卖不上价，怀疑是"市场不认"。
5. 面对通胀或成本上涨，纠结是涨价还是缩规格。

### 语言信号 (用户的话里出现这些就应激活)

- "这个东西该定多少钱／我不知道值多少钱"
- "市面上没有同类产品，没法参考"
- "首发价定低点冲销量行不行"
- "我的产品比他们好，为什么卖不上价"
- "how much should I charge for this"
- "there's no comparable product to benchmark against"

### 与相邻 skill 的区分

- 与 `reference-price-framing` 的区别：那个 skill 处理**已有参照价时怎么呈现折扣**（ARP、魔力价、得失分合）；本 skill 处理**参照价还不存在时怎么把它造出来**。呈现 vs 建构。
- 与 `anchor-first-offer` 的区别：那个 skill 是**一对一谈判**中抢先报价的战术；本 skill 是**面向市场**的结构性定价，一次决定影响整条产品线多年。
- 与 `block-price-comparison` 的区别：那个 skill 让顾客**无法**比较；本 skill 承认顾客一定会比较，只是要决定他们**在什么坐标系里**比较。

## E — 可执行步骤 (Execution)

1. **确认原点确实是空的**
   - 动作：问三个问题——顾客能否说出一个同类产品的价格？他上一次买同类是什么时候？该品类的价格波动是否公认很大？
   - 完成标准：三项中至少两项指向"无稳定记忆价格"。
   - 判停条件：若顾客有清晰的记忆价格（如矿泉水、汽油），本 skill 失效，转 `reference-price-framing`。

2. **先设计结构，不要先想数字**
   - 动作：列出至少 3 个档位或 3 个关联产品，写出它们之间的**倍数关系**（如高配 = 标准 × 1.8，入门 = 标准 × 0.6）。这些倍数是你真正的产品语言。
   - 完成标准：结构表成立且各档差异可用一句话向顾客解释。

3. **设定原点：取"三年可守价"而非"首年好卖价"**
   - 动作：定出你希望三年后仍能维持的档位，把首发价放在它**之上**，而不是之下。
   - 完成标准：能回答"如果成本涨 30%，这个价还守得住吗"。
   - 判停条件：若答案为否，回到步骤 2 重排结构。

4. **同时发布一个更高的水平锚**
   - 动作：与目标价一起亮出一个明显更贵的版本/服务包/定制档，让原点从上方而非下方被设定。
   - 完成标准：高锚项有可解释的存在理由（哪怕它几乎不成交）。

5. **区分名义变化与实际变化**
   - 动作：明确对方在哪个层面做判断。降价时突出**名义降幅**；涨价时优先调整非价格属性（规格、容量、服务范围），避免名义涨价被记住。
   - 完成标准：写出一句对外话术，其中名义数字的方向与你希望的感知方向一致。

6. **锁定并记录原点**
   - 动作：把首价与结构表写入定价文档，注明"此后的所有调价都是在此结构内的相对移动"。
   - 完成标准：团队里任何人被问"我们的价格体系是什么"，答的是结构而不是单价。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **存在强记忆价格的标品**：汽油、鸡蛋、常购快消品。顾客的原点已经钉死，任何结构设计都撬不动，只剩成本与效率竞争。
- **受监管或成本加成定价的行业**：公用事业、医保目录内药品。原点由外部规则给定。
- **投资择时**：本 skill 能解释价格为何长期脱离价值，但完全不能预测何时回归，不可用作买卖依据（见下）。

### 作者在书中警告的失败模式

- **把心理价格点写进品牌**（X8"九毛九"）：价格点是战术资源不是战略资产。一旦成为品牌承诺，成本上涨时你就没有调价自由。
- **用低价首发换首年销量**（X7 莫里西别墅的镜像）：结构一旦被低原点固化，后续每一次提价都要对抗它，代价远超首年多卖的量。
- **透明度不是解毒剂**（X15 卡默勒实验性资产市场）：即使所有参与者都知道资产的期末清算价值，交易价仍系统性偏离并形成泡沫。所以"把成本和价值讲清楚，顾客自然会认"是错的。
- **名义与实际的混淆**（X14 沙菲尔货币错觉）：人们宁要"加薪 5%、通胀 4%"也不要"加薪 2%、通胀 0%"。别指望对方自动折算。

### 作者的盲点 / 时代局限

- 书中实验以北美/欧洲被试为主，价格惯例与讨价还价文化的跨文化差异未被系统检验（X16）。中文市场需重测。
- 大量实验是一次性、无声望后果的实验室设定；在有长期关系与口碑传播的真实市场中，任意原点被媒体、比价平台与二手市场纠偏的速度可能远快于实验室。
- 成书于电商比价与算法动态定价成熟之前，"没有可比品"的窗口在今天更窄、更短。

### 容易混淆的邻近方法论

- **成本加成定价 / 价值定价**：那两者假设存在一个"正确的数"；本 skill 主张不存在，只存在被接受的结构。可以并用（成本定下限），但不要用成本去论证顾客的接受度。
- **前景理论/损失厌恶**：属于得失呈现层面，用于解释折扣与涨价的感受，不解释原点从何而来。
- **大傻瓜理论**：解释价格为何能长期脱离价值，是本 skill 的背景而非工具。
