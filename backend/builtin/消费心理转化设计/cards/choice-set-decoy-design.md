## I — 方法论骨架 (Interpretation)

一个选项的吸引力不属于它自己，属于它所在的集合。同一个产品放进不同的集合里，可以是被回避的极端，也可以是被偏爱的中间档。因此当你想提升某档的销量时，**改集合比改产品便宜得多，也快得多**。

三条可用的机制：

**权衡对比**：人需要一个能与之做权衡的参照物才能判断某选项好不好。给一个选项配上一个"各方面都不如它"的邻居（非对称占优诱饵），它立刻显得优越。诱饵的价值恰恰在于它不该被选中——它是坐标系，不是商品。方向可控：加低价诱饵把选择往下拉，加高价诱饵把眼光往上拉。

**避免极端**：三档之中人们倾向选中间。这意味着你可以通过**在顶上加一档**，把原来的顶配变成新的中间档，从而抬升它的销量——不需要改动任何一个现有产品。

**注意力有限**：选项多而难评估时，注意力会自己去找"好对比的项目"。只要某项明显优于邻近项（哪怕差异很小），它就俘获关注。反过来说，一组势均力敌、各有长短的选项会让人放弃选择或退回最便宜的那档。

要注意的是：诱饵必须**明确劣于**目标项。如果诱饵与目标项势均力敌，它不但不引导，反而增加决策难度、推高放弃率。

## A1 — 书中的应用 (Past Application)

### 案例 1：休伯与普多的吸引效应实验
- **问题**：加入一个没人会选的劣质选项，会不会改变人们在原有两个选项之间的分配？
- **方法论的使用**：在既有的 A（便宜）与 B（高档）之外，加入被 A 完全支配的 C。
- **结论**：C 本身几乎不被选，但它把选择显著转移到 A 上；对称地，加入高价诱饵 D 会扩大 B 的份额。
- **结果**：确立了"诱饵不为被选而存在"这一可复现的设计原理，方向可由设计者指定。

### 案例 2：宝洁的帮宝适与露肤
- **问题**：1961 年推出的帮宝适纸尿布被认为"方便但太贵"，怎么让布尿布用户转过来？
- **方法论的使用**：1978 年推出更贵的一次性尿布"露肤"（Luvs）作为高价参照。
- **结论**：高价诱饵能把整个价格坐标系上移，使原产品从"奢侈"变成"合理"。
- **结果**：露肤不仅拿下高档纸尿布市场，还让布尿布用户相信帮宝适并不奢侈。到 90 年代中期家长已普遍改用纸尿布，宝洁反过来从 1994 年起把露肤**重新定位成廉价品牌**，改用低档诱饵——同一枚棋子在不同阶段扮演相反角色。

### 案例 3：陪审团的"中间选项"
- **问题**：律师摩根为什么要求陪审团罚麦当劳"一两天的咖啡销售额"，而不给一个确定数字？
- **方法论的使用**：他实际上构造了一个三档集合（小杯/中杯/大杯式的低-中-高），把自己想要的数额放在中间。
- **结论**：避免极端在完全非商业的赔偿裁决中同样成立。
- **结果**：给了迟疑的陪审员一条轻松的出路，同时把裁决额托在有利于客户的位置。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. SaaS / 会员 / 订阅要设计分档，或现有分档中"所有人都买最便宜那档"。
2. 想提高客单价但不想（或来不及）开发新功能。
3. 设计餐牌、酒单、服务价目表，决定放不放一个很贵的项目。
4. 给客户的方案书要放几个报价选项、怎么排。
5. 发现某个高价版本长期无人购买，正在考虑砍掉它。
6. 电商 SKU 组合、加购推荐位的排布。

### 语言信号 (用户的话里出现这些就应激活)

- "用户都只买最便宜的那档"
- "该设几个套餐／怎么分档"
- "高价版没人买，是不是该下架"
- "怎么把客单价提上去"
- "how many pricing tiers should I have"
- "nobody buys the premium plan"、"decoy option"

### 与相邻 skill 的区分

- 与 `reference-price-framing` 的区别：那个改变的是**单个价格怎么显示**（原价划线、9 结尾、折扣措辞）；本 skill 改变的是**有哪些选项以及它们的相对位置**。前者是标签，后者是货架。
- 与 `block-price-comparison` 的区别：那个的目的是让顾客**无法**与竞品比较；本 skill 的目的是让顾客**在你给定的内部集合里**比较。一个对外封闭，一个对内引导。
- 与 `anchor-first-offer` 的区别：双重报价是本 skill 的最小形式（两个选项），但那发生在一对一磋商中；本 skill 面向所有顾客的固定集合。

## E — 可执行步骤 (Execution)

1. **明确目标档**
   - 动作：先确定你**希望多数人买哪一档**，写下它的名字与价格。
   - 完成标准：目标档唯一且明确。
   - 判停条件：若目标是"提高整体转化"而非"推向某档"，本 skill 不适用，转 `zero-price-transaction-utility` 或 `reference-price-framing`。

2. **诊断现有集合的结构病**
   - 动作：检查两件事——①目标档有没有一个明确劣于它的邻居？②目标档是不是处在极端位（最贵或最便宜）？
   - 完成标准：能指出集合里目标档失利的具体结构原因，而不是"产品不够好"。

3. **加诱饵（非对称占优）**
   - 动作：造一个在**所有可见维度上都不如目标档、但价格接近**的选项。典型做法：同价但少一个关键额度，或略便宜但少两项。
   - 完成标准：任何顾客都能一眼看出它不如目标档。
   - 判停条件：若诱饵与目标档各有长短（互有胜负），作废重做——势均力敌只会增加决策难度。

4. **加高锚档（避免极端）**
   - 动作：在顶上增设一档，价格显著更高、服务更重（企业版、定制版、私教版）。它不需要好卖。
   - 完成标准：加完之后，原顶配落到三档中的中间位置。

5. **控制选项总数与可比性**
   - 动作：总数控制在 3-4 档；确保每两档之间的差异可以用**一个维度**说清（席位数、额度、周期），避免多维度交叉。
   - 完成标准：能用一张三行表格讲完，不需要脚注。

6. **给注意力一个落点**
   - 动作：把目标档做视觉标记（"最受欢迎"、加边框、居中放大），因为注意力会自动奔向"明显更优"的项。
   - 完成标准：闭眼三秒再睁眼看页面，第一个看到的是目标档。

7. **上线后验证方向而非绝对值**
   - 动作：只比较改版前后**各档占比**的变化，而不是总收入（总收入受季节与流量干扰）。
   - 完成标准：目标档占比上升；若诱饵档本身卖出了可观份额，说明它设计得不够劣，回步骤 3。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **顾客有清晰的外部比价渠道且各档能被逐项对照**：诱饵会被识破为凑数，损害信任。
- **高信任、长期关系的 B 端采购**：对方的采购流程会要求你解释每一档的成本构成，无法解释的诱饵会成为谈判把柄。
- **只有单一产品且不打算分档**：先回到 `arbitrary-coherence-pricing` 建立结构。
- **医疗、教育、金融等选择后果重大的领域**：用结构诱导选择的伦理成本远高于零售场景。

### 作者在书中警告的失败模式

- **诱饵被当成真实选项运营**（X8"九毛九"）：《纽约时报》评论那些店"堕落成了下诱饵的骗子，靠招牌把顾客引诱过来，实际上却是为了卖那些更贵的东西"。诱饵可以存在，但招牌承诺不能是假的——否则损害的是品牌本身。
- **套餐效应会随熟悉而衰减**（第16章捆绑）：回头客一旦熟悉了套餐价格，效应减退。这就是连锁餐厅菜单不停变化的原因——主菜换名、改份量，让顾客无法与上次精确比较。
- **加了诱饵却方向搞反**：低价诱饵把选择往下拉。若你想提客单价却加了一个更便宜的入门档，结果会与预期相反。

### 作者的盲点 / 时代局限

- 书中案例以线下货架与纸质目录为主，未涉及算法个性化定价与动态选项集合——今天每个用户看到的集合可能都不同，"避免极端"是否在个性化集合中同样稳定，书中无证据。
- 实验多为一次性选择，未检验诱饵在**长期订阅**中的留存影响：被诱饵推上高档的用户，续费率是否更低，书中未答。
- 跨文化差异未检验（X16），中间档偏好的强度在不同市场可能不同。

### 容易混淆的邻近方法论

- **二级价格歧视 / 版本划分（versioning）**：目标是按支付意愿分离顾客（见 `block-price-comparison` 中的傻瓜蛋理论）；本 skill 的目标是把人推向**同一个**目标档。两者可以并用但方向不同。
- **选择过载（choice overload）**：主张减少选项以提高转化。与本 skill 不冲突——本 skill 也要求总数 3-4 档，只是强调其中要有结构而非简单减法。
- **锚定**：诱饵效应不等于锚定。锚定是数字对判断的拉动，诱饵效应是集合结构对偏好的重排；前者作用于估值，后者作用于选择。
