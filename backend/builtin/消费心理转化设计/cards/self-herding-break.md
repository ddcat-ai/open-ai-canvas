## I — 方法论骨架 (Interpretation)

人排队跟随的不只是别人，更是自己。

第一次为某物付出的价格、花费的时间、做出的选择，往往是任意的——由当时的心情、一次促销、
一个偶然的推荐决定。但这个偶然选择一旦发生，就变成了一条证据：**"我上次这么做了，
说明它值得。"** 第二次重复它，证据链就更强一层。三五次之后，这条自证回路已经足够坚固，
本人会把它当作稳定的个人偏好，甚至写进自我认同（"我是喝手冲的人""我们公司做事一向严谨"）。

这就是自我羊群效应。它与经典锚定的区别在于：锚定问的是"第一个数字从哪来"，
自我羊群问的是"这个数字为什么至今没被推翻"。答案是——**每一次重复都在为它背书。**

因此打断它不能靠讲道理（对方会说"我就是喜欢"），也不能靠降价（价格差被纳入既有比较框架后
只会强化框架）。唯一有效的动作是**让旧参照失效**：把新选项放到一个与旧锚**不可比**的类别里，
迫使对方重新建立一个新锚。星巴克没有跟唐恩都乐比咖啡便宜，它换了杯型的名字、店里的气味、
座椅、术语和仪式，让"一杯咖啡该值多少钱"这个旧问题在店里根本无法被提出。

## A1 — 书中的应用 (Past Application)

### 案例 1：星巴克如何从一美元的咖啡市场里挣脱

- **问题**：美国人的咖啡锚点被唐恩都乐固定在约 1 美元。任何新品牌若定价更高，
  都会被顾客立刻拿旧锚衡量并判定为"抢钱"。
- **方法论的使用**：舒尔茨没有在同一比较框架里竞争价格，而是系统性拆掉所有可比维度——
  自创杯型名称（Short/Tall/Grande/Venti 而非 小/中/大）、意式术语、烘焙气味、
  座椅与音乐、店员称谓。顾客走进去时，手上没有一把能测量这里的尺子。
- **结论**：当旧锚无法被援引时，顾客只能就地建立一个新锚；而新锚一旦建立，
  自我羊群效应会替品牌把它固化下来——"我上周付了 5 美元，所以它值 5 美元"。
- **结果**：星巴克在同一批消费者身上把咖啡的可接受价格抬高了数倍，且顾客并不觉得被宰。

### 案例 2：社保号拍卖后的"任意的一致"

- **问题**：艾瑞里让 MIT 学生先写下社会保险号后两位，再对红酒、巧克力等物品出价。
- **方法论的使用**：号码高的组出价高出 216%–346%，但**所有人对不同物品的相对排序完全一致**——
  他们对好酒的出价都高于劣酒。
- **结论**：起点是纯噪声，但一旦落定，后续所有决策会与它严密自洽，而这种自洽被本人体验为"理性"。
- **结果**：证明了偏好不是被发现的，是被第一次决定所创造、再由重复所加固的。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill

1. **顾客不肯换**：产品客观更优、价格更低，但目标客户仍留在竞品那里，且说不出具体理由。
2. **自己戒不掉**：明知某项订阅、某个品牌、某种消费不划算，仍然每次都续。
3. **组织流程惯性**：某个审批环节、某份周报、某个会议没人知道为什么存在，
   但"我们一直这么做"。
4. **新品类定价**：要让市场接受一个远高于既有参照的价格，需要先让参照失效。
5. **个人偏好审计**：怀疑自己所谓的"品味"其实是若干次偶然选择的累积产物。

### 语言信号

- "客户就是不换，我们明明更便宜"
- "我也不知道为什么，习惯了吧"
- "我们公司一直是这么做的"
- "为什么星巴克能把咖啡卖到这个价"
- "我是那种一定要用 XX 的人"
- "why won't they switch / brand inertia / we've always done it this way"

### 与相邻 skill 的区分

- 与 `anchor-antidote`：那个处理**别人此刻抛给你的数字**；本 skill 处理**你自己过去的行为**
  变成的锚，对手不在场。
- 与 `arbitrary-coherence-pricing`：那个是卖方给新品定第一个价；本 skill 是买卖双方都可能
  处在的"旧锚已固化、需要打断"的后期状态。
- 与 `block-price-comparison`：那个用捆绑/费率结构让**竞品报价单**无法逐项对比（B2B 价格战）；
  本 skill 用感官与语义脱钩让**顾客脑中的旧参照**失效（品类创建）。
- 与 `hook-model-loop`：那个是主动设计习惯循环；本 skill 是拆解一个**已经形成**的、
  由自我背书维持的循环。

## E — 可执行步骤 (Execution)

1. **确认这确实是自我羊群，而不是真实偏好**
   - 问三个问题：①这个选择的**第一次**是怎么发生的？能否回忆起具体情境？
     ②从那以后有没有做过一次真正的重新评估？③如果今天完全没有历史，我/顾客会怎么选？
   - 完成标准：能指出第一次选择的偶然来源（一次促销/一个朋友推荐/入职时就有）。
   - 判停条件：若第一次选择是经过系统比较做出的、且此后复核过，则不是自我羊群，
     终止本 skill。

2. **画出旧锚的比较框架**
   - 列出对方（或自己）用来衡量该品类的**具体维度与单位**：
     一杯多少钱？一个月多少 GB？多少页 PPT？多久回复？
   - 完成标准：写出 3–5 条可量化的比较维度，这就是需要被拆掉的尺子。

3. **选择打断路径（三选一或组合）**
   - **路径 A｜类别脱钩**（对外，最强）：更换单位、名称、场景、仪式、感官环境，
     使旧维度在你的语境中无法被提出。检验：顾客说得出"这跟 XX 不一样"，但说不出差多少。
   - **路径 B｜强制重估**（对内，最直接）：把"要不要继续"改写为"**如果现在没有它，
     我会重新买/重新引入吗？**"——这一句把默认值从"续"翻转为"买"。
   - **路径 C｜切断重复证据**（对流程）：暂停执行一个周期（停一次会、停发一次周报），
     观察是否有人真的受影响。没有人提，就是纯惯性。
   - 完成标准：明确选定路径并写出具体动作，而非泛泛的"要创新"。

4. **给新锚一个可自我背书的第一次**
   - 新锚要成立，必须有一次**完整、正向、可回忆**的首次体验（首单仪式感、
     首次交付超预期、上线首周的专人陪跑）。
   - 完成标准：明确设计了"第一次"的具体内容，而不是把新方案直接混进日常流。

5. **反向自查（伦理门）**
   - 若打断旧锚的唯一目的是让对方在无参照状态下多付钱，且新方案不提供真实增益，
     停止执行并转 `manipulation-matrix-ethics`。
   - 完成标准：能回答"顾客在新锚下获得的真实增益是什么"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **对方的偏好经过真实检验**：长期使用后仍有可复述的具体优势（不是"就是好用"），
  此时打断参照是在制造混乱，不是纠正偏差。
- **高风险低试错场景**（医疗、金融合规、生产安全）：此处的"一直这么做"往往是
  沉淀下来的安全冗余，拆之前必须做失效分析。
- **你手上没有真实差异**：类别脱钩只是把顾客的尺子拿走，如果新方案本身没有增益，
  短期能卖高价，长期会以更高的流失率还回来（见杰西潘尼反例的镜像）。

### 作者在书中警告的失败模式

- **降价打不动惯性**：在同一比较框架内做价格竞争，只会让顾客用旧尺子给你打分。
  杰西潘尼取消全部折扣改"每日低价"，价格实际更低，销售额却暴跌、CEO 17 个月后被解雇——
  因为它拿走了顾客赖以判断"划算"的划线原价，却没有提供替代参照。
- **知道了也不管用**：艾瑞里反复强调，即使把锚定效应讲给受试者听，他们仍然照样被锚。
  所以本 skill 的干预必须落在**结构**（换单位、换默认值、停一个周期）上，
  不能落在"提醒自己注意"上。

### 作者的盲点 / 时代局限

- 星巴克案例是事后叙事，缺少反事实对照（同期同样做差异化却失败的品牌未被讨论），
  存在幸存者偏差。
- 自我羊群与社会羊群在真实市场中难以分离——顾客的重复购买也可能来自持续的社会证据，
  归因需谨慎。
- 社保号拍卖实验属经典行为经济学范式，但艾瑞里团队部分研究已卷入数据可靠性争议
  （见 `fudge-factor-integrity` 的 B 段），引用其数字时宜以"方向性证据"而非精确效应量对待。

### 容易混淆的邻近方法论

- **沉没成本谬误**：那是"已经投入了所以继续"；自我羊群是"我以前选了所以它值"，
  前者关于损失，后者关于价值推断。
- **禀赋效应**：那是"拥有抬高估价"（见 `endowment-gap-correction`）；
  自我羊群不需要拥有，只需要重复过选择。
- **品牌忠诚（营销学）**：那假定忠诚由满意度驱动；本 skill 指出很大一部分忠诚
  只是自证回路，与满意度弱相关。
