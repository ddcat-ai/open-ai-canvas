## I — 方法论骨架 (Interpretation)

谈判双方各自都有一个"我大概能拿到多少"的估计。这个估计感觉上很扎实——你算过成本、查过行情、想过底线——但它本质上是**一个猜测**，而猜测是可以被外来数字拉动的。第一个进入房间的数字会成为锚点，对方随后所有的还价都是从这个锚点出发的不充分调整。

关键的二阶区分是：**要得越多，得到越多；但不是要多少得多少**。收益随报价上升而增加，却是递减的，同时成交概率在下降、周期在拉长。所以正确的操作不是"报一个天价"，而是报出**你能给出理由的最高价**。理由的作用不是说服对方接受，而是让对方相信你还在认真谈判、不至于起身走人。锚点的上限不由"可信度"决定（幸运转盘证明明知随机的数字照样起效），而由"对方是否愿意继续待在谈判里"决定。

第二个要点是：**别在对方的数轴上还价**。如果对方先报了，你在他的数字上加减，你已经输了——无论加到多少。正确动作是另起一条数轴（换计价口径、换比较对象、换时间维度），这属于 `anchor-antidote` 的领域。

第三个要点是**代价核算**。高锚的收益是价格溢价，成本是时间与成交概率。当持有成本高（现金流紧、库存易腐、机会有窗口期）时，高锚是错的。

## A1 — 书中的应用 (Past Application)

### 案例 1：里托夫的模拟谈判实验
- **问题**：先报价究竟有没有优势？在一个双方都能自由选择搭档、自由退出、无规则约束的市场里还成立吗？
- **方法论的使用**：148 名工程与管理系学生分为买方与卖方，就一件假想商品谈价格、交货期与折扣，双方均可先报价，可随时退出另找搭档，可反复成交直到时间用完。
- **结论**：谁先报价，谁就把对方的期望值拖到自己一侧；且报价越高，最终成交价越高。
- **结果**：里托夫发现卖家往往主动接近买家、先行叫价，买家还价——即便游戏极为抽象，双方除了名字标签外没有实质区别，"词语依然为行为钉起了框框"。

### 案例 2：房地产经纪人的挂牌价
- **问题**：受过训练、掌握可比成交数据的专业人士，估价会被挂牌价影响吗？
- **方法论的使用**：让经纪人实地看同一套房、拿同样资料，只改变对方看到的挂牌价。
- **结论**：专业不等于校准。
- **结果**：估价随挂牌价系统性偏移；而经纪人普遍自述"我没有受挂牌价影响"。斯坦福的尼尔向财富 500 强高管讲锚定时遭遇同样抵触——"我不可能受它的影响；我已经做了很多工作，我了解情况。"

### 案例 3：管理者的抵触本身
- **问题**：为什么这条最容易应用的规则最难被商人接受？
- **方法论的使用**：尼尔的回应是一个方法论声明——"我可以把玛姬放到某个环境下，不设锚点；也可以把她放到完全相同的环境下，再设上锚点。我们的研究能办到这样的事情，你却做不到。"
- **结论**：生活没有重播键，个人经验无法提供反事实对照，因此"我凭经验知道"不构成证据。
- **结果**：这成为本 skill 在实践中最主要的阻力来源，也是必须先破除的前提。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 收到面试通过通知，即将被问"你的期望薪资是多少"。
2. 自由职业者/顾问/设计师给一个新客户报项目费用，尤其是没有行业标价的新型项目。
3. 卖房、卖车、卖二手设备、转让账号或店铺，纠结挂价。
4. 采购或供应商续约谈判，要决定第一封邮件里写不写数字。
5. 赔偿、分成、股权比例等一次性重大条款的磋商。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要先报价／该不该我先说数字"
- "报多少合适／会不会报太高把人吓跑"
- "他们问我期望薪资怎么答"
- "我这个项目怎么报价"
- "should I make the first offer"
- "what's a reasonable asking price / how do I anchor high"

### 与相邻 skill 的区分

- 与 `anchor-antidote` 的区别：本 skill 是**进攻**（你来设锚），那个是**防守**（对方已设锚，你要解毒）。同一场谈判里两者常先后使用，但触发条件相反：本 skill 触发于"还没有数字出现"。
- 与 `arbitrary-coherence-pricing` 的区别：本 skill 面向**一次一对一磋商**，那个面向**一整套市场价格结构**。
- 与 `ultimatum-fairness-leverage` 的区别：那个处理的是**对方有否决权、且会因愤怒而宁可双输**的局面（涨价、条款变更）；本 skill 处理的是**双方都想成交、只争分配**的局面。若你察觉对方的核心情绪是"被占便宜的愤怒"而非"想少付点"，切换过去。

## E — 可执行步骤 (Execution)

1. **先破除"我凭经验不会被影响"**
   - 动作：向用户（或自己）明确一句——个人经验无法提供反事实对照，所以"我谈过很多次，我知道行情"不构成防御。
   - 完成标准：用户接受"锚点对我也有效"这一前提。

2. **计算"可信上沿"，而不是"理想价"**
   - 动作：找出你能用**一句话解释来源**的最高数字。来源可以是：替代方案的成本、它替代的人力年薪、同类最高成交案例、你的时间机会成本。
   - 完成标准：写出格式为"X 元，因为 ______"的一句话，且这句话你自己念出来不脸红。
   - 判停条件：若找不到任何理由支撑，说明你的上沿定得过高，下调至能给出理由的档位。

3. **做代价核算，决定是否真的走高锚路线**
   - 动作：估算 溢价额 × 成交概率 − 持有成本 × 预计等待期。
   - 完成标准：得出一个明确结论"走高锚"或"走快速成交"。
   - 判停条件：若持有成本高、有时间窗口、或对方是唯一买家，放弃高锚，改用一口价 + 清晰理由（见 B 段 Scion 反例）。

4. **抢先报出，并同时附上理由与非价格条款**
   - 动作：在对方给出任何数字之前发出你的报价；附理由；同时抛出 2-3 项可让步的非价格条款（周期、范围、付款节奏），为后续留出"不降价的让步空间"。
   - 完成标准：你的第一条消息里既有数字也有理由，且理由不是"我觉得值这么多"。

5. **预设不成交，保留耐心**
   - 动作：事先写下你的替代方案（BATNA）与愿意等待的时长。
   - 完成标准：能坦然说出"这个价谈不成也可以"，且这不是虚张声势。

6. **若对方先报了，不要在他的数轴上还价**
   - 动作：不接他的数字，改问口径与范围；然后按另一套计价方式重抛锚点。
   - 判停条件：进入 `anchor-antidote` 的完整解毒流程。

7. **考虑双重报价（进阶）**
   - 动作：同时给出两个结构不同的方案（如"高价短周期"与"低价长周期"），把对方的注意力从"贵不贵"转移到"选哪个"。
   - 完成标准：两个方案对你的净收益接近，但对对方的感知差异明显。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **客群本身厌恶谈判**：见 Scion / 土星案例（X4）。当买家把讨价还价过程视为负效用（怕被宰、嫌麻烦、时间贵），取消谈判的确定性价值高于锚定能榨取的溢价，应改用透明一口价。
- **长期关系中的反复交易**：一次高锚可能换来对方在后续所有环节的报复性摩擦。收益是一次性的，成本是持续的。
- **对方是唯一可能的交易对手且你有时间压力**：此时成交概率的损失无法被溢价补偿。
- **对方的核心诉求是公平感而非金额**：转 `ultimatum-fairness-leverage`。

### 作者在书中警告的失败模式

- **锚点极端到对方退出**（X6）：可信度对锚定的限制极弱，但不是零。报出十倍于市价的数字可能让对方判定你不是认真谈判并直接离场。判据：你能不能给出理由——理由不必被接受，但必须存在。
- **只算溢价不算代价**（X7 莫里西别墅）：高挂牌价确实换来了高于常规估价的成交，但房子长期滞销，付出了持有成本、心理成本与买家流失。
- **误以为专业能免疫**（X10）：不要把对方的"专业报价"当作独立客观参照系，也不要相信自己的"我没被影响"。

### 作者的盲点 / 时代局限

- 里托夫实验是抽象的实验室市场，没有声誉、没有长期关系、没有法律成本；真实商业谈判中这些约束会显著压缩高锚的可行区间。
- 书中未讨论线上、异步、多方同时竞价（如平台招标）的情形，那里"先报价"往往等于暴露底牌。
- 涉及人群差异的报价结论（谁被报高价）在书中自相矛盾（艾尔斯 vs 戈德堡，X3），不得据此调整对不同人群的策略；若你怀疑自己被报了高价，正确做法是获取第三方成交基准，而不是改变自身表现。

### 容易混淆的邻近方法论

- **哈佛式"基于利益的谈判"**：主张先扩大蛋糕再分配、避免过早报数字。它与本 skill 并不完全冲突——可以先谈利益结构，但一旦要出现第一个数字，仍应由你说出。
- **"绝不先出价"的传统智慧**：本 skill 明确反对。该传统智慧成立的唯一场景是你对标的价值一无所知而对方了如指掌。
- **哭穷/装作没预算**：属于信息博弈，不是锚定；且一旦被识破损害信任。
