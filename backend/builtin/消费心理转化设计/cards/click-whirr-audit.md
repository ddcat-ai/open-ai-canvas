## I — 方法论骨架 (Interpretation)

人在信息过载时不会放弃决策，而是改用一种更省力的方式：抓住环境里**某一条通常靠得住的线索**，据此播放一整套预设反应。作者称之为"按一下就播放"。这套机制平时高度可靠，所以不该被废除；问题在于线索可以被单独伪造，而反应一旦启动就不再采集新信息。

由此得出两个不同于常识的结论。

第一，**防御不能设在触发点**。拒绝一切礼物、无视所有评价、不理会任何专家，成本极高，还会误伤真实信号。防御要设在**结算点**——即"我要作出顺从决定"的那一刻，加一次检查。作者把这称为第二道防线。

第二，**可靠的警报不是对方的话术，而是自己的状态**。识别话术需要知识和注意力，而话术种类无限；但"我现在是不是处于捷径高发状态"只有六个可观测项，任何人在任何场景下都能秒判。

于是本 skill 是一个两段结构：先做**状态自检**（我此刻的判断可信吗），再做**分离动作**（把触发线索从标的物上剥离，只评估标的物本身）。它是全书所有防御 skill 的总闸门；当无法判断该用哪个专项原理时，用它兜底。

## A1 — 书中的应用 (Past Application)

### 案例 1: 兰格的复印机插队实验

- **问题**：请求成功率到底取决于理由的**内容**，还是理由的**形式**？
- **方法论的使用**：设三种条件——无理由（60% 同意）、有真实理由"因为我有急事"（94%）、有**无信息量**的理由"因为我必须要复印几页纸"（93%）。
- **结论**：被响应的是"因为"这个结构本身，不是它后面的信息。触发特征 ≠ 信息内容。
- **结果**：当请求量从 5 页提高到 20 页（利害上升、值得思考）时，无信息量理由的效果消失——证明捷径只在低认知投入区运行，这直接给出了本 skill 的适用边界。

### 案例 2: 亚利桑那珠宝店的绿松石

- **问题**：一批绿松石首饰长期滞销，降价、挪到显眼处、督促店员推销全部无效。
- **方法论的使用**：店主出差前留字条"价格乘以½"，店员误读为"乘以2"。
- **结论**：顾客不懂绿松石，用"贵=好"这一条线索代替全面判断。
- **结果**：价格翻倍后全部售罄。产品没变，变的只是那一条被读取的线索。

### 案例 3: 作者本人的童子军巧克力棒

- **问题**：作者既不吃巧克力也重视钱，却买了两块。
- **方法论的使用**：事后自问"我怎么会这样？"——把自己的异常行为当作机制存在的证据。
- **结果**：这次自省直接促成他去做卧底研究，写成本书。示范了本 skill 最原始的用法：**用自己的困惑作为入口**。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户描述一个已经发生的决定，并对自己的行为感到困惑（"我也不知道当时怎么就同意了"）。
2. 用户正处在需要**当场拍板**的压力下：现场促销、销售在旁、限时优惠倒计时、会议上被追问表态。
3. 用户在深夜、连续加班后、情绪波动中、或同时处理多线任务时，要做一个金额较大或后果较重的决定。
4. 用户感觉"被带节奏"但说不出对方用了什么手法——即知道有问题、定位不到原理。
5. 用户在做**复盘**：想搞清楚上一次踩坑的机制，避免重演。

### 语言信号 (用户的话里出现这些就应激活)

- "我当时就稀里糊涂答应了 / 鬼使神差就买了"
- "我是不是被套路了 / 感觉哪里不对但说不上来"
- "现在必须定，你帮我看看要不要"
- "我最近状态不好，这个决定要不要先放放"
- "impulse buy / why did I say yes / I felt pressured"

### 与相邻 skill 的区分

- 与 `scarcity-pause` 的区别：本 skill 是**不定原理**的总闸门；一旦确认压力来自"限量/倒计时/有人在抢"，应转交 `scarcity-pause` 做专项处理。
- 与 `authority-two-questions` 的区别：本 skill 检查的是**我的状态**，后者检查的是**对方的资质与动机**。
- 与 `low-ball-guard` 的区别：后者专门处理"决定已作出、条件被事后修改"的情形；本 skill 处理决定**尚未**或**刚刚**作出的时刻。

## E — 可执行步骤 (Execution)

1. **六状态自检**：逐项问用户当前是否命中——① 赶时间 ② 压力大 ③ 信息不确定 ④ 事不关己/懒得想 ⑤ 心烦意乱/分心 ⑥ 疲惫。
   - 完成标准：得到一个明确的命中计数（0–6）与命中项列表。
   - 判停条件：命中 0 项且决策金额/后果较低 → 直接告知"当前不处于高发区"，结束，不必执行后续步骤。

2. **定位触发线索**：问"是哪一条**单一信息**在推着你做这个决定？"（价格、人多、专家说的、对方让了一步、只剩两件、这个人很好相处……）。
   - 完成标准：把线索写成一句话，与标的物本身的属性分开列出。
   - 判停条件：若线索可归入某一具体原理，同时给出对应专项 skill 的建议（见"与相邻 skill 的区分"）。

3. **执行分离测试**：把触发线索假设性地拿掉，重问一次。标准问法三选一——
   - "如果这个提议是我最不喜欢的人提出来的，我还答应吗？"（切好感）
   - "如果它明天原价还在、随时能买，我还买吗？"（切稀缺）
   - "如果没有任何人推荐过它，只看参数和价格，我会选它吗？"（切社会证据/权威）
   - 完成标准：用户能明确回答是/否，而不是"不好说"。

4. **按命中数给处置建议**：命中 ≥2 项 → 强制延迟（"明天上午再决定"或"离开现场再回复"）；命中 1 项 → 允许决定但要求先复述一遍分离测试的答案；命中 0 项 → 正常决策。
   - 完成标准：给出一个**具体的时间点或动作**，不是"再想想"。

5. **保留捷径**：明确告知用户，本次检查**不否定**捷径本身——如果触发线索经核实为真（销量真的第一、优惠真的截止、对方真是专家），那么顺从它是高效且正确的。
   - 完成标准：区分"信号为真 → 照做"与"信号可疑 → 延迟"，两条路径都给出。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **低利害的日常选择**（今天吃什么、买哪包纸巾）：自检成本高于错误成本，属于典型的过度防御。
- **需要快速反应的真实紧急情况**：延迟本身就是最大风险。此时应转 `single-point-help`。
- **用户只是要信息**（"稀缺原理是什么"）：那是查询，不是决策场景。
- **已经识别出具体原理**：直接用专项 skill，本 skill 会稀释精度。

### 作者在书中警告的失败模式

- **在触发点防御的代价**（第2章/第5章）：拒收一切好意、屏蔽一切社会证据，会让人失去捷径带来的效率，也会误伤真实的善意与真实的信息。作者明确反对这种做法。
- **自我防御的内在张力**（本书未解决）：作者说"识别到就能反击"，但他自己的证据表明，人最需要防御的时刻（疲惫、赶时间、情绪高涨）恰恰是最没有资源去识别的时刻。这正是本 skill 把警报从"识别话术"改成"检查状态"的原因——状态自检的认知成本足够低，才可能在低资源时执行。

### 作者的盲点 / 时代局限

- 尾声以"个人电脑"作为信息爆炸的象征，完全未覆盖算法推荐流、无限下拉、通知轰炸这些**持续制造六状态**的当代结构。今天用户的默认状态更接近"长期命中 3 项以上"，因此本 skill 的调用频率应比书中假设高得多。
- 书中六状态清单来自作者归纳而非量表，没有效应量。它是**分诊工具**，不是测量工具。
- **真信号 / 伪信号判定**：本 skill 为纯防御向，不涉及攻击性使用；但当用户反过来问"我能不能用这些来影响别人"时，必须给出判据——建立在真实存在的条件上属正当，需要伪造条件（编造限量、雇人排队、假冒资质）则越界，应拒绝执行并说明。

### 容易混淆的邻近方法论

- **和"三思而后行"不同**：后者要求提高思考量，本 skill 承认思考资源不可得，改为提高**决策时机**的质量（延迟到资源充足时）。
- **和"沉没成本谬误"不同**：沉没成本关注已付出的代价，本 skill 关注当下被读取的**单一线索**。
- **和正念/情绪管理不同**：本 skill 不要求平复情绪，只要求把情绪读作**证据**。
