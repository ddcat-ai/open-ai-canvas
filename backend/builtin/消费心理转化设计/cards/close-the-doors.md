## I — 方法论骨架 (Interpretation)

"多留几个选项总没坏处"是一句几乎无人质疑的话。它错在一个隐蔽的地方：

> **维持选项的成本是真实的、持续的，但它从不出现在任何一张账单上。**

三扇门实验的设计很干净：屏幕上有三扇门，每扇门后的收益不同；
点击进入一扇门可以赚钱，但**长时间不点的门会逐渐缩小并最终消失**。
理性策略显而易见——找到收益最高的门，然后一直点它。

实际发生的是：参与者不断浪费点击去"保住"那些收益明显更低的门，
总收益比专注单门的人低约 15%。

更关键的是**加强条件下的结果**：
即使明确告知参与者每次切换的成本、各门的收益、
**以及消失的门可以随时无成本恢复**——行为依然不变。
他们仍然回头保门。

这排除了三种常见解释：不是不知道成本（告知了）、
不是不会算（收益公开）、也不是害怕不可逆（可以复活）。
剩下的解释只有一个：**关门这件事本身让人难受**，
而这种难受与它的经济后果无关。

由此得到三条推论：

**① 选项的持有成本必须被显性计入。**
一个"暂时没动"的项目，不是零成本。它占用注意力、
占据决策带宽、在每次规划时被重新评估一遍、
让相关的人保持待命状态。这些消耗真实发生，只是没人记账。

**② 关门不会自然发生，必须被设计成一个专门的动作。**
项目不会自己死掉，它们会慢慢缩小然后一直挂着。
没有一个显式的关闭仪式，组织与个人都会无限期地维持一切。

**③ 保留选择权的收益被系统性高估。**
"万一以后需要呢"这个论证的期望值几乎从不被真正计算。
而它的成本又不可见，于是天平永远倒向保留。

需要立刻加上一条**重要边界**：本 skill 不主张"选项越少越好"。
在**高不确定性、低维持成本**的环境里，保留可选性是正确的
（真实期权、探索期、早期布局）。
关键判据是：**维持它的持续成本 vs 它被真正行使的概率×价值**。
本 skill 反对的是从不做这个计算，而不是反对可选性本身。

## A1 — 书中的应用 (Past Application)

### 案例 1：三扇门实验

- **问题**：人愿意为"保留选择权"付出多少？
- **方法论的使用**：电脑游戏中有三扇门，每扇门收益不同；
  长时间不点的门会逐渐缩小并最终消失。参与者可自由分配点击。
- **结论**：参与者反复浪费点击去"保住"低收益的门，
  总收益比专注一门的人低约 15%。
- **结果**：**即使被告知消失的门可以随时无成本恢复，行为依然不变。**
  这是本实验最重要的部分——它排除了"不可逆恐惧"这一解释，
  说明关门的痛苦是独立于经济后果的。

### 案例 2：门在缩小，而不是关上

- **问题**：为什么人对这类损失反应迟钝？
- **方法论的使用**：实验中门是**逐渐**缩小的，
  而不是突然关闭。
- **结论**：渐进的消失不触发警报。人只对"即将永久失去"作出反应，
  而对"缓慢贬值"无感。
- **结果**：现实中的对应物是那些"还在，但已经很久没进展"的项目、
  证书、关系、技能。它们不会引发决策，只会持续收费。

### 案例 3：选项的隐性支出

- **问题**：为什么明确的成本告知无法纠正行为？
- **方法论的使用**：实验公开了切换成本与各门收益。
- **结论**：参与者具备全部信息，行为不变。
- **结果**：再次印证元约束——**补充信息几乎从不改变行为**（p15）。
  因此本 skill 的执行步骤必须落在**结构**上
  （硬上限、关闭仪式、日历强制），而不是"想清楚"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill

1. **同时推进太多项目**：每个都在动，每个都不出成果。
2. **主业与副业**：副业收益不高但"舍不得关"。
3. **产品线/功能裁撤**：一堆低使用率功能，
   每一个都有维护成本与少量用户。
4. **职业方向抉择**：两个 offer、两个赛道、
   "先都保持联系"。
5. **长期观望**："再看看""保持关注""万一以后用得上"。
6. **学业与技能**：同时学四门语言，每门都停在入门。
7. **社交与感情**：保留备选、维持大量弱联系。
8. **战略聚焦**：组织层面"什么都想做"，资源被摊薄。

### 语言信号

- "什么都想做，什么都做不完"
- "舍不得砍，万一以后有用呢"
- "先留着吧，反正也没什么成本"
- "两个方向都不错，再看看"
- "项目太多，精力分散"
- "这个功能虽然没什么人用，但删了怕有人投诉"
- "keeping options open / too many projects / focus / optionality"

### 与相邻 skill 的区分

- 与 `choice-set-decoy-design`：**主语相反。**
  那是**给别人**设计一组选项以引导选择（供给侧）；
  本 skill 是**自己关掉**选项（决策侧）。
  同样谈"选项集"，一个在造，一个在砍。
- 与 `endowment-gap-correction`：那舍不得的是**已经拥有的东西**
  （估价被抬高）；本 skill 舍不得的是**尚未行使的可能性**
  （选项本身）。判据：你在心疼一个**实物/资产**，
  还是在心疼一个**未来可能**。
  "砍掉自己做了两年的项目"两者同时成立，应组合使用。
- 与 `opportunity-cost-swap`：那把一笔支出换算成**具体的替代项**
  （帮你比较两个选项）；本 skill 帮你**减少选项的数量**。
  顺序上：先用本 skill 砍到 2-3 个，再用那个做最终比较。
- 与 `ulysses-self-control-architecture`：那约束的是**热态下的冲动**；
  本 skill 处理的是**冷态下的不忍**。
  但两者的解法同源——都靠预设结构而非当场决心，可组合
  （用硬上限作为承诺装置）。
- 与 `future-self-vividness`：若"选不出来"的根因是长期收益感受不到，
  先用那个具象化未来，再用本 skill 关门。
- 与 `habit-zone-screening`：若要判断的是"这个产品方向值不值得做"
  （立项前的可行性筛），用那个；
  本 skill 用于**已经启动、需要裁撤**的场景。

## E — 可执行步骤 (Execution)

1. **列出所有开着的门**
   - 不只是项目：还包括观望中的机会、维持中的关系、
     没在用但在续费的服务、学了一半的技能、
     "有空再说"的计划。
   - 关键：**必须写下来**。开着的门之所以持续收费，
     正是因为它们分散在各处，从未被同时看见。
   - 完成标准：一张完整清单，含每扇门的当前状态与最近一次实质进展的日期。

2. **给每扇门标出持续成本**（核心动作）
   - 三类成本，逐项估：
     - **注意力**：每周会想到它几次？每次占多久？
     - **决策带宽**：每次规划/排期时它是否需要被重新评估？
     - **他人待命**：有多少人因为它没被关闭而处于等待状态？
   - 不需要精确，需要的是**让它出现在账面上**。
   - 完成标准：每扇门都有一个非零的持续成本估计。

3. **对每扇门做一次期望值对照**
   - 问：**它被真正行使的概率 × 行使后的价值** vs
     **第 2 步算出的持续成本 × 预计还要维持多久**。
   - 若前者明显小于后者 → 该门应关。
   - 注意"渐进缩小"陷阱：一扇很久没进展的门，
     其实已经在贬值，但因为它没有"突然消失"而未触发决策。
     **把"最近一次实质进展超过 X 个月"直接作为关门候选标准。**
   - 完成标准：每扇门有明确的保/关判定。

4. **给组织与个人设硬上限**
   - 个人：同时推进的重点项目 ≤ 3 个（其余进"冻结区"）。
   - 组织：并行项目数设硬上限，**新增必须先关闭一个**
     （one-in-one-out）。
   - 为什么要硬上限而不是"注意控制"：
     因为实验已经证明知道成本不改变行为，只有结构改变行为。
   - 完成标准：上限被写进流程/日程，且有一个明确的执行触发点。

5. **设计关闭仪式，让关门成为一个动作**
   - 关门不会自然发生，必须显式执行。仪式包含四件事：
     - ①**公开宣布**（对相关方，避免留下待命状态）；
     - ②**归档而非删除**（降低关门的心理成本，
       这一条针对的正是"关门本身让人难受"）；
     - ③**记录关闭理由与当时的判断依据**（便于日后复盘）；
     - ④**约定一个重启条件**——
       "若出现××信号，重新评估"。
   - 第 ④ 条至关重要：它把"永久失去"改写成"条件性暂停"，
     大幅降低执行阻力，且不产生持续成本。
   - 完成标准：每次关门都完成四个动作，有书面记录。

6. **对留下的门做投入承诺**
   - 关门的收益只有在**资源真正转移**后才兑现。
     常见失败是关了三个项目，节省的时间被自动填满，
     核心项目并未加速。
   - 完成标准：明确写出关门释放的时间/预算流向了哪一扇门。

7. **设定复查节奏，防止门悄悄重开**
   - 每季度重跑第 1-3 步。
   - 特别检查：是否有新的门在无人决策的情况下被打开
     （"顺手先做着看看"是最常见的入口）。
   - 完成标准：复查进日历，且默认执行。

8. **应用边界自检：确认你不是在关一扇应该开着的门**
   - 三个反问：
     - ①这个领域的不确定性是否**高到**探索本身就是价值？
     - ②这扇门的维持成本是否**真的很低**（不占注意力、不需决策）？
     - ③关闭是否**真的不可逆**（有些门关了就再也开不了，
       如时间窗口、人脉、执照）？
   - 若三条中有两条为"是" → 保留是正确的，不要为了聚焦而聚焦。
   - 完成标准：每一个"关"的决定都过了这三问。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **高不确定性的探索期**：早期创业、新领域学习、研究方向摸索。
  此时选项的价值主要来自可选性本身，过早聚焦是更大的错误。
  判据：你是否已经有足够信息判断哪扇门收益更高？没有，就不该关。
- **维持成本确实接近零的选项**：一个不需要注意力、
  不进入任何决策流程的可能性（如保留一张证书、
  一个休眠账号）。为它做关门仪式是浪费。
- **关闭不可逆且窗口有限**：某些机会关了就永久消失
  （年龄相关、时间窗口、稀缺牌照、关键人脉）。
  这类门的期权价值极高，应单独评估。
- **用它来合理化逃避**：把"聚焦"当作放弃困难选项的借口。
  判据：你关掉的是**低价值**的门，还是**难做**的门？
- **组织内用它作为裁撤他人项目的工具**：
  本 skill 是决策框架，不是政治武器。
  缺少第 5 步的公开理由与重启条件，会摧毁团队的试错意愿。

### 作者在书中警告的失败模式

- **"多留几个选项总没坏处"是错的**（x13）：
  实验中即使明确告知切换成本与各门收益，
  参与者仍反复回头保门，收益低于锁定单门策略。
- **无成本复活也不改变行为**：这是最关键的一条。
  关门的痛苦独立于经济后果，因此**讲道理无效**，
  必须靠结构（硬上限、one-in-one-out、关闭仪式）。
- **渐进消失不触发决策**：门是慢慢变小的。
  现实中的僵尸项目正是这样存在的——它们从不"死亡"，
  只是无限期地缩小并持续收费。
- **主动关门是一项需要专门执行的动作，不会自然发生**：
  这句话应当直接写进流程。
- **对组织：同时推进的项目数应设硬上限**——
  这是艾瑞里给出的少数明确的组织级建议之一。

### 作者的盲点 / 时代局限

- **三扇门实验的外部效度有限**：这是一个短时的实验室游戏，
  收益结构清晰、时间尺度极短。现实中的"门"往往收益不确定、
  相互关联、且关闭具有社会后果。
  实验证明了倾向的存在，**不能用来给现实中的最优选项数定量**。
  "低约 15%"是该实验条件下的结果，不是通用系数。
- **与真实期权理论直接冲突**：金融与战略领域有充分证据表明
  可选性在高不确定性下有正价值（Real Options）。
  艾瑞里未讨论这一边界，把保留选项一概处理为偏差，
  是本章最大的论证缺口。本 skill 的 I 段与第 8 步对此作了补正。
- **艾瑞里团队的部分研究已卷入数据可靠性争议**
  （详见 `fudge-factor-integrity` B 段，含一项已撤稿实验）。
  三扇门实验（Shin & Ariely, 2004）**不在受争议之列**，
  且有后续复现，但引用时仍应注意其实验室性质。
- **未讨论选项的相互关联**：现实中的门常常互补
  （一个项目的能力可迁移到另一个），
  独立评估会低估组合价值。
- **未讨论数字时代的门爆炸**：今天开一扇门的成本趋近于零
  （注册一个账号、开一个仓库、启动一个副业），
  于是门的数量级远超书写作时。这使得第 4 步的硬上限
  比书中所设想的更为必要。

### 容易混淆的邻近方法论

- **选择过载（Choice Overload）**：那说的是**面对**过多选项时
  决策质量下降、满意度降低（果酱实验）；
  本 skill 说的是**维持**过多选项的持续成本。
  一个关于选择那一刻，一个关于选择之后。
- **沉没成本谬误**：那是因为已投入而继续；
  本 skill 是为了保留未来可能而持续投入。
  一个看过去，一个看未来。二者在"砍旧项目"时同时出现。
- **真实期权（Real Options）**：**结论相反**的邻近框架——
  那论证可选性的正价值。两者的分界线是
  **不确定性水平**与**维持成本**。使用本 skill 前必须确认
  自己不在真实期权适用的区间里（第 8 步）。
- **机会成本**：那是选了 A 就失去 B 的价值
  （见 `opportunity-cost-swap`）；
  本 skill 是**不选**所付出的成本。
  常识只教了前者，本 skill 补的是后者。
- **精益创业的"保持选择"**：那主张小步试错、延迟承诺，
  与本 skill 表面冲突。实际分工是：
  探索期用那个，收敛期用本 skill。判据同样是不确定性水平。
