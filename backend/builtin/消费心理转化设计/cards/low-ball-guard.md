## I — 方法论骨架 (Interpretation)

抛低球的结构只有两步：

1. 用一个特别有吸引力的条件让你**作出决定**（不必付钱，甚至不必签字，作出决定本身就够）；
2. 在你已经决定之后，把那个条件撤掉或调差。

按理说，条件没了，决定就该撤销。但通常不会。原因不是你已经付出了成本——**抛低球的经典场景里成本可以是零**。原因是：作出决定的那一刻，你的大脑开始为它生成支撑理由，而这些理由与最初的诱因**无关**。你想到这台车的颜色正好、想到不用再跑一趟、想到已经跟家里人说了。诱因这条腿被抽走，其他几条腿还在。

所以本 skill 的核心不是"识别对方的话术"，而是**区分两种理由**：

- **原生理由**：作出决定**之前**就存在的、当时写得出来的理由。
- **自生理由**：作出决定**之后**才冒出来的理由。

自生理由在感觉上和原生理由完全一样，都真诚、都合理。唯一可靠的分辨方式是**时间戳**，不是内容。

由此得出一条判据：**当条件变化时，只用原生理由重新评估。** 这就是"时光倒流测试"——如果今天这个条件是当初的开价，我还会作出同样的决定吗？

作者还指出一个更深的层次：抛低球之所以让人难以脱身，是因为承诺一致带来的"愚蠢的一致"——一致性本身让人舒服，它不检查方向。解锁它需要的不是意志力，而是一个**被授权的撤销通道**（给自己一个不丢脸的下台阶）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 汽车经销商的抛低球

- **问题**：如何让顾客以正常价格买车，同时压过所有竞争对手的报价？
- **方法论的使用**：先报一个低于同行 400 美元的价格，让顾客决定买；随后让顾客试驾、填表、办贷款、把旧车送去估价——一系列让决定"落地"的动作。最后在临门一脚时，"发现"计算错误 / 经理不批准 / 忘算了空调，把价格调回正常水平。
- **结论**：诱因（低价）被撤走时，顾客早已生成了一堆新理由：手续都办了、试驾很满意、贷款已经批了、跟同事都说了。
- **结果**：大量顾客照买不误。作者强调，此时顾客往往**并不觉得自己被骗**——因为他们能真心说出好几条买它的理由。

### 案例 2: 能源节约实验（诱因撤走后行为反而加强）

- **问题**：如何让居民在冬季持续节约天然气？
- **方法论的使用**：告诉一批居民，节约成功者的名字会**登报表扬**（外部诱因）。一个月后，研究者写信告知：抱歉，登报计划取消。
- **结论**：按外部激励逻辑，诱因消失，行为应该回落。但这批居民在收到"取消"通知后的几个月里，节约幅度**进一步上升**——因为他们在承诺期已经为节能长出了自己的理由（环保、省钱、对得起下一代）。
- **结果**：作者用它证明抛低球的机制不是沉没成本，而是**自生理由**——这是本 skill 最干净的一个证据。

### 案例 3: 费斯廷格与基奇夫人的末日教派

- **问题**：预言的世界末日没有发生，信徒会怎么做？
- **方法论的使用**：研究者潜入该教派观察。信徒此前已辞职、变卖家产、公开宣告（承诺四维度全中）。
- **结论**：证据推翻信念时，撤销承诺的代价过高，信徒转而**加倍寻求社会支持**——用新信徒的认同替代已被证伪的事实。
- **结果**：预言落空后，原本低调的团体开始积极向公众传教。作者用它说明：承诺越深，反证越可能被转化成加固。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. SaaS/会员/保险的**首年优惠到期**，续费价大幅上涨，团队说"已经用习惯了"。
2. 买车、买房、装修、留学中介：签之前说得好好的，签完之后加价、变更条款、增加项目。
3. 招聘 offer：入职后发现薪资结构、职级、岗位与谈定的不一致。
4. 合作/外包：项目启动后对方以各种理由调整范围与价格。
5. 自己身上：项目做到一半发现前提不成立，但"都做到这份上了"。
6. 反向使用（设计侧）：想知道自己的定价与试用策略是否踩到抛低球的伦理红线。

### 语言信号 (用户的话里出现这些就应激活)

- "当初说好的不是这样 / 说好的优惠没了"
- "涨价了，但我们已经用习惯了"
- "都投入这么多了，现在退出太可惜"
- "骑虎难下 / 现在退出很没面子"
- "要不要及时止损 / 续不续费"
- "bait and switch / low-ball / they changed the terms"

### 与相邻 skill 的区分

- 与 `foot-in-the-door` 的区别：**方向相反**。登门槛是在你答应小事之后**加大要求**；抛低球是在你作出决定之后**撤走好处**。两者共享"承诺自生理由"这一机制，但识别信号完全不同：问一句"变的是要求，还是条件？"
- 与 `rejection-then-retreat` 的区别：那是在**决定之前**用让步换让步；抛低球是在**决定之后**动手。时间点是分界线。
- 与 `low-justification-internalizing` 的区别：本 skill 是同一机制的**防御向**。后者教你怎么让承诺扎根，本 skill 教你怎么在被人扎根时拔出来。
- 与 `contrast-sequencing` 的区别：汽车销售会同时用两招（先定整车价再加选配 = 对比；先报低价再涨回 = 抛低球）。判据：**你有没有为最初的价格作出过"我要了"的决定**——有则是抛低球。
- 与既有 skill `sunk-cost` 类工具的区别：沉没成本要求**已经付出**；抛低球在付出为零时同样成立（能源节约实验）。误诊为沉没成本会让你只算钱，漏掉真正的锁扣。

## E — 可执行步骤 (Execution)

1. **确认结构成立**：回答两个问题——(a) 我是否**已经作出过决定**（哪怕只是口头/心里）？(b) 当初让我决定的那个条件，现在是否**变差或消失**了？两个都是"是"，则确认为抛低球结构。
   - 完成标准：写出"当初的条件"与"现在的条件"两行对照。
   - 判停条件：若条件未变，只是我后悔了 → 不是本 skill，转常规决策复盘。

2. **做理由的时间戳分离**：列出你现在想继续的**全部理由**，逐条标注"这条理由在我作决定之前就有吗？"
   - 完成标准：每条理由标上"原生"或"自生"。
   - 常见自生理由（务必标出）：手续都办了、跟人说过了、换一家太麻烦、已经熟悉了、现在退出显得反复。

3. **执行时光倒流测试**：只保留原生理由，然后问：**"如果一开始的条件就是今天这个样子，我还会作出同样的决定吗？"**
   - 完成标准：给出明确的是/否。
   - 若"否" → 该决定在新条件下不成立，进入步骤 4。
   - 若"是" → 决定本身是好的，继续；但仍应在步骤 6 争取补偿。

4. **给迁移成本单独定价**：把"已经用习惯了/数据在里面/重新招标很麻烦"从理由里拿出来，**折算成一个数字**（多少人天、多少钱）。
   - 完成标准：得到一个具体金额或工时数。
   - 关键：这个数字是**上限**——只有当继续的溢价低于它时，继续才划算。它是成本项，不是理由。

5. **搭一个不丢脸的下台阶**：一致性压力大半来自"显得反复无常"。事先给自己或团队准备一句公开说法："条件变了，所以决定也变——这恰恰是一致的（我一致的是判断标准，不是那个选项）。"
   - 完成标准：写出一句可以对外说的话。

6. **反向利用结构提要求**：抛低球者知道自己理亏。既然对方期待你已被锁住，明确指出结构本身就是强筹码："这与最初的报价不符，我需要 X 作为补偿，否则重新评估。"
   - 完成标准：提出一个具体的补偿要求。

7. **建立预防机制**：以后凡有"限时价/首年价/内部价"，在决定时同步写下一行：**"如果这个优惠不存在，我还买吗？"** 存档。下次涨价时直接调取。
   - 完成标准：形成一条可复用的记录习惯。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **条件变化是不可抗力且对方主动补偿**：供应链涨价、汇率波动、政策变更等，对方透明告知并给出选择权时，不属于抛低球，按正常商务处理。
- **迁移成本确实高于溢价**：时光倒流测试给出"否"，但步骤 4 的定价显示换掉更贵——那就理性地继续，同时把它记为**成本决策**而非**价值决策**。
- **正在气头上**：本 skill 容易被当作"我要退出"的正当化工具。承诺一致的反面（为了证明自己不被操纵而强行退出）同样是自动反应，见 `scarcity-reactance-guard`。

### 作者在书中警告的失败模式

- **误判为沉没成本**（第3章）：能源节约实验证明，**零成本**时抛低球依然生效。只盯着"我花了多少钱"会漏掉真正的锁扣——自生理由。
- **愚蠢的一致**（第3章）：一致性不检查方向。它让人在错误的路上走得格外坚定，且**当事人会真诚地为它辩护**。作者提示的解锁信号是身体反应："胃里那种不舒服的感觉"——当你明知不该继续却在为它找理由时，那种别扭本身就是证据。
- **承诺越深，反证越会被转化成加固**（基奇夫人案例）：对已经公开、费力、书面的承诺，直接摆事实可能适得其反。此时应先降低撤销的社交代价（步骤 5），再谈事实。

### 作者的盲点 / 时代局限

- 抛低球在社会影响研究中**复现较好**，但**效应量为小到中等**，且高度依赖"决定确已作出"这一前提；书中汽车销售的成功率带有轶事色彩，**不应作为可外推的期望值**。**复现存疑，勿作硬结论**。
- 作者的例子集中在**个人消费决策**。在组织决策中，撤销承诺还要面对预算周期、责任归属、政治成本等结构性阻力，四维度之外还有第五维度（**组织可见性**），书中未处理。
- 书中未讨论**订阅制与平台锁定**这类现代形态：数据迁移、API 依赖、生态绑定使迁移成本真实且巨大，此时"自生理由"与"真实成本"更难分离——步骤 4 的量化因此格外重要。
- **真信号 / 伪信号判定**：条件变化如果是**真实且不可预见**的（成本上涨、供应中断），对方透明告知并允许你重新选择，这是真信号，不应污名化；如果条件变化是**事先设计好的**（明知会涨价却以"限时"促成决定、故意"算错"价格），这是伪造触发条件，应识破、拒绝并说明。分辨方式：问"这个变化在我决定时对方就知道吗？"
- **饱和反噬**：首年优惠 + 次年涨价已被市场普遍识别，越来越多买方在首次决策时就把三年 TCO 写进比价表。作为卖方使用抛低球，短期成交换的是长期信任损失与续费谈判劣势。

### 容易混淆的邻近方法论

- **沉没成本谬误**：要求已付出代价；抛低球不要求。误诊会导致只做财务复盘、漏掉理由结构。
- **诱饵调包（bait and switch）**：法律与营销术语，指以不存在或极少量的低价商品引流后转推他款。抛低球中**那件商品是真的**，只是价格被改——机制上更隐蔽。
- **锚定效应**：影响的是估值区间，不需要你作出决定；抛低球必须有决定这一步。
- **承诺升级（escalation of commitment）**：组织行为学概念，强调持续追加投入；抛低球是单次的条件替换。
