## I — 方法论骨架 (Interpretation)

两样东西先后出现时，人对第二样的判断会以第一样为基准，差异被知觉系统放大。关键在三点：

**一，它发生在知觉层，不是算计层。** 三桶水实验里，左手先泡冷水、右手先泡热水，再同时放进同一盆温水，两只手会同时报告"热"和"冷"。同一盆水，同一个人，同一时刻。这不是判断失误，是感知系统的相对性。

**二，被影响的人察觉不到顺序在起作用。** 他会认为自己评价的是标的物本身。这使得对比原理比明面上的打折更隐蔽，也更持久。

**三，顺序不可逆。** 先大后小与先小后大的效果不是强弱之分，而是方向相反。因此"排序"本身就是一个独立的决策变量，和内容一样值得设计。

实操上，它同时是攻和防：设计呈现顺序（把要推的放在锚之后），以及识别自己被安排的顺序（我为什么突然觉得这个便宜/这个还行）。它与"锚定效应"有交集但不等同——锚定关注**数字**对估值的牵引，对比原理关注**相邻呈现**对知觉差异的放大，后者对非数值维度（大小、难易、好坏）同样成立。

## A1 — 书中的应用 (Past Application)

### 案例 1: 男装店的"先西装后毛衣"

- **问题**：如何提高单客总成交额？
- **方法论的使用**：服饰业培训明确规定，先卖高价商品（西装约 495 美元），再卖配件（毛衣约 95 美元）。反过来则总额下降。
- **结论**：毛衣的价格没变，但在西装的背景下被知觉为小额支出。
- **结果**：先贵后贱成为行业标准做法。

### 案例 2: 房地产中介的"托儿房"

- **问题**：如何让正常房源显得物有所值？
- **方法论的使用**：中介手上长期保留一两套破旧但标价偏高的房子，专门用来**先带看**，从不指望卖掉。
- **结论**：正常房源在托儿房之后出现时，性价比的知觉被显著放大。
- **结果**：客户对随后看到的房子满意度更高、决策更快。

### 案例 3: 汽车销售的选配顺序

- **问题**：如何把利润率高的选配卖出去？
- **方法论的使用**：先把整车价谈定（数万美元），**之后**才逐项介绍音响、真皮、延保、防锈。
- **结论**：每一项数百美元的加装，在已确立的整车价背景下都显得可以忽略。
- **结果**：选配总额可占车价的可观比例，而客户在每一步都觉得自己只是"多花了一点点"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要给客户/老板呈现一组方案或报价，纠结先讲哪个。
2. 要在一次沟通里提出**两个**请求（一大一小），或要谈一笔主交易加若干附加项。
3. 要公布涨价、扣减、坏消息，想降低感知冲击（或反之，想让让利显得更大）。
4. 发现自己对某个选项的评价"好得反常"或"贵得反常"，怀疑是被前一项影响了。
5. 设计菜单、价目表、SKU 分档、落地页的模块顺序。

### 语言信号 (用户的话里出现这些就应激活)

- "先报哪个价 / 先给他看哪个方案"
- "怎么讲才显得不贵 / 怎么让他觉得划算"
- "我要一次提两件事，顺序怎么排"
- "他先带我看了一套特别破的，然后这套我就觉得挺好"
- "which should I show first / pricing order / should I anchor high"

### 与相邻 skill 的区分

- 与 `rejection-then-retreat` 的区别：**关键区分点**。后者需要对方**明确拒绝**第一个要求，动力是让步的互惠义务；本 skill 不需要拒绝，只需要先后呈现，动力是知觉放大。若你的第一个选项本来就打算被拒 → 用 rejection-then-retreat；若第一个选项只是用来当背景板（甚至对方可能接受）→ 用本 skill。
- 与 `scarcity-pause` 的区别：本 skill 处理"贵/便宜"的知觉，后者处理"来不及/被抢走"的紧迫感。
- 与 `flaw-first-credibility` 的区别：都涉及"先说什么"，但后者先说的是**自己的缺点**，目的是可信度，不是价格知觉。

## E — 可执行步骤 (Execution)

1. **确认存在可排序的多项**：至少两项、且在**同一维度**上可比（同为价格、同为工作量、同为难度）。
   - 完成标准：列出待排序项及其共同维度。
   - 判停条件：若只有一项或维度不可比 → 本 skill 不适用，说明原因并退出。

2. **明确目标知觉**：你希望对方对**哪一项**形成什么知觉（更便宜/更小/更容易接受/更慷慨）。
   - 完成标准：写成一句话，例如"让 8 万的年费显得可接受"。

3. **选锚并检验可信度**：锚必须在**同维度上更极端**，且必须**真实存在、能被认真对待**。
   - 完成标准：锚项能经受"对方问一句你为什么提这个"的追问。
   - 判停条件：若锚只能靠编造（虚构的高价、不存在的方案）→ **停止**，转用真实差异或改走 `flaw-first-credibility`。

4. **排布并压缩间隔**：锚在前、目标项紧随其后，两者之间不要插入其他议题；时间与空间上越紧邻，放大越强。
   - 完成标准：给出具体的呈现脚本或页面顺序。

5. **不做解释**：呈现顺序后不要说"你看是不是便宜多了"——点破会让对方察觉顺序的作用，效果反转。
   - 完成标准：话术里不含比较性引导句。

6. **（防御向）逆向检查**：当用户是被呈现方时，把顺序打乱重问——"如果我第一眼看到的就是它，我会给它什么评价？"
   - 完成标准：得到一个脱离前项的独立评价。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **对方会同时看到全部选项**（比价表、招标文件、公开价目表）：顺序效应大幅削弱，此时决定因素是绝对值与横向对比。
- **对方是专业买手/采购**：他们受过训练做同维度横比，且常有既定基准价，锚的作用被压缩。
- **高利害且有充分决策时间的场景**（大额采购、董事会决议）：见下"作者盲点"中的边界条件。
- **只有一个选项**：无从对比。

### 作者在书中警告的失败模式

- **锚不可信则整体反噬**（第2章 x01 的同构风险）：如果第一项极端到不合情理，对方不会形成"第二项好便宜"的知觉，而会形成"这个人在耍我"的判断，随后所有报价的可信度一并受损。
- **顺序被识破**：作者指出对比原理的力量来自不被察觉。一旦对方意识到"你是故意先给我看那个的"，效果反转为信任损失。

### 作者的盲点 / 时代局限

- 案例全部来自 20 世纪线下零售，未覆盖比价插件、聚合平台、历史价格曲线这些**削弱顺序效应**的现代基础设施。今天在电商场景中，锚的有效性显著低于书中描述。
- 书中未给出效应量，只有方向性结论；"先贵后贱能提升多少"没有可引用的数字。
- **认知资源边界**（第1章兰格实验）：当请求/金额上升到值得认真思考的量级时，捷径效应减弱。因此本 skill 在小额附加项上最强，在主决策上弱。
- **真信号 / 伪信号判定**：用**真实存在**的更贵/更大选项作锚属正当使用；虚构一个不打算成交的假报价、编造不存在的"原价"属于伪造触发条件，越界，禁止执行并向用户说明（多数司法辖区亦涉及价格欺诈）。
- **饱和反噬**：划线原价、"原价 999 现价 99"在今天已被广泛识别为套路，对该类锚的信任度普遍下降；改用可核实的真实对照（历史成交价、同规格竞品实价）。

### 容易混淆的邻近方法论

- **锚定效应（Tversky & Kahneman）**：关注数字对**估值**的牵引，即使锚是随机数也有效；对比原理关注**相邻呈现**对差异知觉的放大，要求同维度且真实。两者常同时发生，但判据不同。
- **诱饵效应（decoy effect）**：靠引入第三个劣势选项改变**选择份额**，是三项结构；对比原理两项即成立。
