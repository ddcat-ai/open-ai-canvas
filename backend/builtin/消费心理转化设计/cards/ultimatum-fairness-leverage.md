## I — 方法论骨架 (Interpretation)

在很多价格冲突里，对方并不是在做成本收益计算，他是在评估你的**动机**，然后决定要不要付出自己的代价来惩罚你。这就是最后通牒博弈的结构：一方提议分配，另一方只能接受或否决，否决则双方归零。经典结果是低于约两三成的分配常被否决——对方宁可自己也拿不到，也要让你什么都得不到。用理性测算"他不接受就一分钱没有，所以他一定会接受"，在这里系统性失效。

驱动否决的是**义愤**，而义愤是对动机的判断，不是对结果的判断。所以：同样幅度的涨价，归因于可核实的成本上涨可被接受，归因于趁火打劫就遭抵制。书中那个苹果的例子很干净——某社区"美味红"苹果短缺，一家商店按常规成本进货，售价比平时高 25%。这个幅度低于该产品一般的季节性波动，孩子们也不会因此饿肚子（还有别的苹果），但仍有 63% 的民众认为不公平。他们判的不是幅度，是意图。

义愤转成金额时还有第二层问题：**愤怒的强度是共识的，换算成钱是随机的**。卡尼曼等人指出，陪审员对被告行为的义愤评分相当一致，但把义愤换算成美元赔偿时高度离散——因为美元这条量值量表没有比较标准。这解释了为什么"大家都觉得你过分"和"大家索赔多少"是两件事，也提示你：如果冲突已经进入索赔/赔偿阶段，提供参照点（`choice-set-decoy-design` 的中间档）会显著影响结果。

独裁者博弈提供了对照：取消否决权后，分配额显著下降但通常不为零，说明其中既有真实的公平偏好，也有对惩罚的恐惧。而诚实箱实验进一步显示，"是否被看见"能大幅改变给予量——这条通向 `price-context-priming`。

因此本 skill 的核心操作有三：**改写归因**（把动机从"趁机"改成"不得不"）、**保证感知份额**（别让对方觉得自己只拿了两三成）、**卸掉否决动机**（留一条退路，因为否决冲动的来源是"我别无选择"）。

## A1 — 书中的应用 (Past Application)

### 案例 1：最后通牒博弈本身
- **问题**：面对"要么接受要么归零"的分配，人真的会接受任何正数吗？
- **方法论的使用**：卡尼曼、尼齐与泰勒在芝加哥大学的会议上公布公正研究，实验刊于 1986 年《商业周刊》。
- **结论**：讨价还价并不遵循收益最大化，人愿意付出自身代价惩罚不公。
- **结果**：确立了低分配被大量否决的稳定结果。庞德斯通引普劳图斯的古罗马剧本说明这一结构有多古老——特拉察里奥威胁要告发，格里普斯怒道"你能分到的只有麻烦，我保证"，发誓要让对方竹篮打水。作者评论："讨价还价不过是文雅一点儿的勒索，逻辑和最终结果没什么关系。"

### 案例 2："美味红"苹果涨价 25%
- **问题**：多大的涨幅算"不公平"？
- **方法论的使用**：设定情境——社区短缺，商店按常规批发成本进货，售价高于平时零售价 25%，且有其他品种苹果可买。
- **结论**：公平判断针对的是动机推断，不是幅度或后果。
- **结果**：63% 的民众认为不公平，尽管该涨幅低于该产品一般的季节性波动。

### 案例 3：陪审团的义愤与赔偿额
- **问题**：陪审团裁决的赔偿金额从哪里来？
- **方法论的使用**：卡尼曼、施卡德、桑斯坦 1998 年《公愤和出离的赔偿：惩罚性赔偿心理学》。
- **结论**：义愤评分一致，美元换算离散；赔偿额可被参照点操纵。
- **结果**：在利柏克诉麦当劳案中，律师摩根连打两记重拳——麦当劳的咖啡比许多竞争对手更烫、麦当劳对伤害无动于衷（都是**动机与态度**指控，不是损失额指控），随后要求陪审团罚"一两天的全球咖啡销售额"（约每天 135 万美元），用一个模糊的中间区间给迟疑者一条出路。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 产品要涨价、要对老用户收费、要提高抽成，担心（或已经遭遇）舆论反弹。
2. 免费服务转付费、免费额度收紧。
3. 合伙人分成、股权比例、团队奖金分配引发不满。
4. 房东涨租、供应商涨价通知发出后对方情绪激烈。
5. 客户投诉要求赔偿，金额诉求与实际损失明显不成比例。
6. 用户自述"这点钱我不在乎，但我就是气不过"、"我宁可不做这单也不能让他占便宜"。

### 语言信号 (用户的话里出现这些就应激活)

- "涨价之后用户炸了／被骂惨了"
- "他们凭什么涨／这不公平"
- "我宁可不要也不能便宜他"
- "老用户觉得被背刺了"
- "how do I announce a price increase without backlash"
- "users are outraged"、"this feels unfair"

### 与相邻 skill 的区分

- 与 `anchor-first-offer` 的区别：那个处理**双方都想成交、只争分配**的局面；本 skill 处理**对方可能宁可双输**的局面。判据：对方的主导情绪是"想少付点"（用那个）还是"被占便宜的愤怒"（用本 skill）。
- 与 `anchor-antidote` 的区别：那个处理认知偏差（数字扭曲判断）；本 skill 处理道德情绪（动机引发义愤）。
- 与 `reference-price-framing` 的区别：那个优化涨价公告的**数字与措辞呈现**；本 skill 处理更上游的**归因与份额结构**。呈现救不了归因。
- 与 `price-context-priming` 的区别：那个用无意识线索影响行为（诚实箱眼睛）；本 skill 用显性的归因与份额设计影响判断。

## E — 可执行步骤 (Execution)

1. **判定这是不是最后通牒局面**
   - 动作：问一句——对方有没有能力让双方都拿不到（退订、差评、罢工、否决票、公开曝光、拒绝合作）？他会不会愿意这么做？
   - 完成标准：两问皆是。
   - 判停条件：若对方没有否决能力或不会动用，转 `anchor-first-offer`。

2. **诊断归因，而不是幅度**
   - 动作：写下对方最可能对你的动机做出的那句推断（"他们就是想多赚"、"欺负老用户"）。
   - 完成标准：能用对方的口吻写出这句话。

3. **改写归因：把动机从"趁机"变成"不得不"**
   - 动作：找出一个**可核实**的外部成本或约束（服务器成本、合规要求、上游涨价、汇率），并给出可查证据。
   - 完成标准：陈述里有具体数字与来源，且不出现"由于市场原因"这类空话。
   - 判停条件：若确实没有可核实的成本变化，不要编造——改走步骤 4 与 5，用份额与退路换取接受。

4. **保证感知份额过线**
   - 动作：确保对方在这次变更中拿到的份额明显高于两三成的感知底线。典型做法：老用户长期锁价、存量条款优于新用户、给出过渡期、返还部分权益。
   - 完成标准：能算出"对方相比新用户/相比不作为，多得了什么"。

5. **卸掉否决动机：留一条退路**
   - 动作：保留一个免费档或低价档，或提供可导出数据、可无损退出的通道。否决冲动的心理来源是"我别无选择"。
   - 完成标准：对方可以不接受你的新方案而仍然留下来或体面离开。

6. **控制时机与并列信息**
   - 动作：不要在财报利好、融资喜讯、高管炫耀的同一周宣布；不要与裁员或降本消息并列。
   - 完成标准：公告前后两周内无相反信号。

7. **若已进入索赔/赔偿阶段，提供参照点**
   - 动作：主动给出一个三档区间并把你能接受的数额放在中间（避免极端），而不是让对方自由填空——因为义愤换成金额是没有标准的。
   - 完成标准：对方在你给的坐标系里报数。

8. **验收：用行为不用问卷**
   - 动作：观察退订率、公开投诉量、续费率，而不是满意度调查。
   - 完成标准：变更后一个周期内退订率回到基线。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **对方无否决能力且关系一次性**：用常规议价即可，本 skill 的成本（过渡期、锁价、留免费档）不划算。
- **纯粹的信息不对称问题**：对方只是不知道行情，补信息即可。
- **法律强制的变更**（合规下架、政策调价）：此时归因已经外生且可核实，直接如实说明，不需要设计。
- **你确实是在趁机涨价**：本 skill 不提供话术掩盖动机。若归因无法真实成立，唯一稳妥的路径是份额补偿与退路，而不是叙事包装。

### 作者在书中警告的失败模式

- **用理性测算预测对方会接受**：最后通牒博弈的核心发现就是这个预测会失败。"他不接受就什么都没有"不构成对方会接受的理由。
- **以为幅度小就没事**：苹果案例中 25% 的涨幅低于正常季节波动，仍有 63% 判为不公平。
- **把义愤当成可用金额安抚的量**：义愤评分一致但美元换算离散，给钱不一定能平息，且给多少缺乏共识标准。
- **动机指控比损失指控更致命**：麦当劳案中真正起作用的是"对伤害无动于衷"，不是烫伤本身的损失额。

### 作者的盲点 / 时代局限

- 最后通牒的经典结果来自**一次性、匿名、无声誉后果**的实验室设定。真实商业中有长期关系与公开声誉，否决行为的门槛与形态都不同（更可能表现为沉默流失而非当面翻脸）。
- 拒绝率的**跨文化差异**在文献中已确认，书中未系统处理（X16）。中文市场的公平感阈值需自行校准。
- 书中引述的睾丸酮/催产素与拒绝率的相关研究（X11）有趣但不可操作——不要把对方的强硬归因于人格或立场，个体差异可能来自不可观测的状态变量，据此推断长期意图是错的。
- 书中未讨论社交媒体放大效应：今天一次不公平感知可以在小时级放大到品牌层面，留给"改写归因"的窗口远小于成书时代。

### 容易混淆的邻近方法论

- **BATNA / 强硬谈判**：处理筹码结构，不处理道德情绪。筹码占优的一方在本局面里恰恰最容易翻车。
- **危机公关话术**：多为事后补救与措辞优化；本 skill 主张问题在**结构**（份额与退路），措辞救不了结构。
- **损失厌恶**：能解释为什么涨价比不降价更痛，但不能解释为什么有人宁可双输——那需要公平偏好与惩罚动机。
- **诱饵效应**：步骤 7 借用了避免极端，但那是本 skill 的一个子步骤，不是同一件事。
