## I — 解释

WYSIATI（What You See Is All There Is，眼见即为事实）不是一条关于"信息不足"的告诫，它是一条关于**自信从哪里来**的机制描述。

系统 1 的工作方式是：拿到手上有的材料 → 构建一个能把这些材料**全部串起来**的故事 → 用这个故事的**连贯度**作为置信度的读数输出给你。注意这条流水线的关键缺陷：**缺失的信息不参与运算**。不在你脑子里的东西，不会在你脑子里投反对票。

由此推出一个几乎所有人都会本能否认的结论：

> **信息越少，越容易构建出一个没有矛盾的故事，因此自信越高。**

这不是"信息不足所以判断错"（那是常识），而是"信息不足所以**感觉更对**"。三篇资料能拼出一个干净的因果链；三十篇资料里必然有互相打架的部分，故事变糙，自信下降——**但准确度是上升的**。

这条机制解释了本书里若干看似无关的现象，它们其实是同一个东西的四张脸：

| 现象 | 它其实是 WYSIATI 的哪一面 |
|---|---|
| 光环效应 | 一个先到的印象被用来填补所有未知属性，因为空着会让故事不连贯 |
| 确认偏误 | 联想记忆只调取能让故事更顺的证据 |
| 过度自信 | 连贯度被误读成准确度 |
| 框架效应 | 换一种叙述 = 换一套被激活的信息 = 换一个故事 |

杜克大学的数据把这件事量化了：11,600 份大型企业 CFO 对次年标普指数的预测，与真实值的相关系数**接近零**；他们给出的 80% 置信区间，实际意外率高达 **67%**（本应是 20%）——也就是说，他们真实的无知程度是他们自认为的**四倍以上**。这些人是全美最有资源、最懂数据的一批人。

所以本 skill 的落点不是"多查资料"（那句话谁都会说，且执行不了），而是一个可操作的转换：**把"我不知道什么"从背景变成前景，写在纸上，让它进入运算**。

## A1 — 书中的应用

**案例一：CFO 的置信区间**
卡尼曼与合作者请 CFO 给出次年标普指数的 80% 置信区间（即他们认为有 80% 把握落入的范围）。结果实际落在区间外的比例是 67%。卡尼曼的诊断不是"他们不懂概率"，而是"他们的自信来自一个连贯的宏观故事，而不是来自数据的离散程度"。

配套的社会学观察同样重要：一个诚实说出"明年回报可能在 –10% 到 +30% 之间"的 CFO **会被全办公室嘲笑**。书里那句话很冷："完全认识到自己无知的专家可能会被更自信、更能获得病人信任的竞争者取代……所以，假装知道通常是首选的解决方式。"

**案例二：谷歌的故事**
两个斯坦福研究生想出好方法、筹钱、连续做出正确决策、成为世界首富。这个故事讲起来毫无破绽，读完你会觉得自己懂了创业。卡尼曼指出被略掉的部分：他们曾试图以**不到 100 万美元**卖掉公司，**买家嫌贵拒绝了**。

关键在于他给出的检验标准——"想知道一个解释是否行得通，可以对它作一个最终测试，看它能否使这个事件事先就能被预测到。"谷歌的故事通不过这个测试。而且他补了一句更狠的："运气的成分越多，从中能学到的就越少。"

**案例三：重症监护室的 40%**
把 ICU 死亡病例的验尸报告与医生生前的诊断对照：在临床医生自评"完全确定"的那些诊断中，**40% 是错的**。这里"完全确定"这个标签本身没有携带任何准确度信息。

## A2 — 触发场景

### 什么时候用

- 一个结论**讲起来特别顺**，各方面严丝合缝，没有需要解释的矛盾
- 尽调/背调/竞品分析/用户访谈之后要下判断
- 只看了少量材料（几篇文章、一次访谈、一份 PPT）就形成了强判断
- 要给出预测区间、成功概率、风险评估
- 复盘会上出现"事情很清楚，就是因为 X"
- 招聘/投资/合作方评估——尤其在第一印象很好或很坏时（光环效应最强的场合）
- 你发现自己**不需要努力**就能解释一切

### 语言信号

> "情况很清楚" / "逻辑上完全说得通" / "所有迹象都指向" / "这不用想也知道" / "我基本可以肯定" / "毫无疑问" / "这个人一看就是那种……" / "整件事就是因为……" / "他们失败是因为管理层太保守"

**结构性信号**（比词汇更可靠）：
- 你的结论里**没有任何一处需要说"这部分我不确定"**
- 你能在 30 秒内讲完这个故事，且听众都点头
- 你说不出**什么证据会推翻这个结论**
- 你的信息全部来自**同一个来源或同一类来源**

### 与相邻 skill 的区分

| 情况 | 用这个 | 不用这个 |
|---|---|---|
| 自信很高，想审计自信的来源与证据缺口 | ✅ `wysiati-evidence-audit` | |
| 怀疑"我回答的根本不是那个问题" | | → `question-substitution-check`（通常先用它） |
| 要给一个项目估工期/估成本 | | → `outside-view-forecast` |
| 想判断"某人的直觉在这个领域能不能信" | | → `expert-intuition-validity`（那是环境属性判定） |
| 决策将落未落，需要团队层面的制度化怀疑 | | → `premortem-doubt-injection`（本 skill 是个人自审） |
| 已经发生了坏结果，在复盘归因 | | → `hindsight-narrative-guard`（本书已验证 · 待整理） |
| 想彻底不依赖印象，装一个评分表 | | → `formula-over-intuition`（本书已验证 · 待整理） |

**与三个"预测类"skill 的分界**：本 skill 审计的是"**这一次判断的自信从哪来**"，不产出任何数字。一旦问题变成"给我一个数"，就应转出：估个案概率 → `base-rate-anchoring`；估项目工期成本 → `outside-view-forecast`；给极端表现之后的下一次定数 → `regression-prediction-moderation`。本 skill 是它们的**前置体检**，不是它们的替代品。

## E — 执行

1. **写下结论和信心值**。先把结论用一句话写下，再给一个 0–100 的信心分。**必须先写死**，否则后面的步骤会被事后合理化。

2. **列证据清单（带来源与独立性标注）**。逐条列出支撑该结论的证据，每条标注：
   - 来源是什么（一手/二手/传闻/自己的推理）
   - 与其他证据**是否独立**（同一个人说的三句话算**一条**证据，不算三条）

   多数人在这一步就会发现：看起来的"大量证据"实际上是 1–2 个独立来源的多次复述。

3. **写"我不知道什么"清单**（本 skill 的核心步骤，不可跳过）。强制写满 5 条。三个提问模板：
   - 如果这个结论是错的，**最可能错在哪个环节**？
   - 谁**知道我不知道的事**？（离现场最近的人、失败过的人、竞争对手、离职员工）
   - 这个故事里有哪些角色**从未发声**？（幸存者偏差的入口）

4. **做"预注册"检验**。问自己："在知道结果之前，我会预测出这个结论吗？"以及"**什么证据出现，我会放弃这个结论？**"——第二问答不上来，说明这不是一个判断，是一个信念。

5. **重估信心值**。回到第 1 步的分数并修改。**如果分数没有下降，说明这次审计没做到位**（在信息不完整的情况下，认真列完未知清单后信心几乎必然下降）。

6. **决定行动而不是继续纠结**。信心下降后只有三个合法出口：
   - **去补最关键的那一条信息**（只补一条：最能改变结论的那条）
   - **把决策改小**（做可逆的小规模试验，而不是全押）
   - **接受不确定并写明**（"我们在 X 未知的情况下决定 Y，若观察到 Z 则回滚"）

7. **区间代替点估计**。凡是要给数字的场合，一律给区间，并把区间**主动放宽到自己觉得有点尴尬的程度**（参考 CFO 的 4 倍系数）。

## B — 边界

### 不适用的情况

- **快决策、低代价、可逆**的场合。绝大多数日常判断不需要审计，WYSIATI 正是效率的来源。
- **信息本质上无法获取**的情况。审计的产出应该是"降低押注规模"，不是无限期推迟决策。
- **需要对外表达确定性的场合**（危机指挥、临床告知、带团队冲刺）。此时正确做法是**内部审计、外部承诺**，两套语言分开——但不要自己被自己的对外语言说服了。
- **高效度环境中的专家快速判断**。见 `expert-intuition-validity`：环境规律性高 + 反馈及时的领域里，快速的高自信是技能而非幻觉。

### 失败模式

1. **审计变成拖延**。列完未知清单后不设"补哪一条、补到什么时候"，本 skill 就变成不做决定的高级借口。第 6 步必须落地。
2. **补充信息但只补同类信息**。多读十篇立场一致的报道，会让故事更连贯、自信更高——这是**反向效果**。要补的是**独立来源**与**反面证据**，尤其是"离现场最近的人"。
3. **把"我不确定"当成结论**。承认不确定之后仍然要给出行动方案与可回滚条件，否则组织会把这次审计记成"你没意见"。
4. **对他人使用时变成质询**。"你凭什么这么确定"是攻击。可用的替代问法是"如果我们错了，最可能错在哪儿"——把对方拉到同一侧。

### 盲点

- **过度自信可被驯服，不能被根除**。卡尼曼原话：过度自信"是系统 1 特性的直接结果，可被驯服但不能被彻底改变"。荷兰皇家壳牌地质学家经反馈训练后确实校准了——说明训练只在**有明确、快速、可重复反馈的窄领域**有效。不要指望通用的"我以后会更谦虚"。
- **未知清单本身也受 WYSIATI 支配**。你能写出的未知，都是你**想得到**的未知；真正的"未知的未知"写不出来。这是本 skill 的硬上限，也是为什么它必须与 `outside-view-forecast`（用历史分布捕捉未被想到的失败）连用。
- **本书方法论的共享边界**：不要援引第 3–5 章的启动效应与自我损耗结论（2011 年后大面积复现失败，作者本人已撤回信任）。本 skill 的证据基础（第 7 章连贯性、第 19 章叙事、第 24 章 CFO 数据）不依赖它们。
- **不要指望"读完就不会犯错"**。卡尼曼在结语中明确说，四十年研究并未显著改善他自己的直觉；改善的是识别错误的词汇与在关键场合**要求安装程序**的自觉。本 skill 的正确用法是装进决策流程，不是装进个人修养。

### 容易混淆的概念

- **WYSIATI ≠ 信息不足**。信息不足是客观状态；WYSIATI 是"大脑把手头信息当作全部"这个**处理方式**。信息很多时同样会发生（你依然只用被激活的那部分）。
- **连贯 ≠ 正确**。连贯度衡量的是故事内部有没有矛盾，与外部世界无关。一个精心编造的谎言比真相更连贯。
- **自信 ≠ 证据强度**。这是本 skill 与 `expert-intuition-validity` 共享的第一原则。
- **审计 ≠ 唱反调**。目标是让"未知"进入运算，不是站到结论的反面。反面立场同样会形成一个连贯故事。

## 相关 skills

- **composes-with**: `question-substitution-check` — 两个最上游的元认知检查。先问"我回答的是哪个问题"，再问"我的自信从哪来"。
- **composes-with**: `outside-view-forecast` — 本 skill 暴露"我不知道什么"，那个 skill 用参考类别的历史分布**替你填上那些你想不到的未知**。二者互补，且后者能突破本 skill 的盲点。
- **composes-with**: `premortem-doubt-injection` — 本 skill 是个人层面的自审，那个是团队层面的制度化怀疑。在组织决策中应当先做事前验尸，再各自做证据审计。
- **contrasts-with**: `expert-intuition-validity` — 本 skill 处理"这次判断的证据够不够"；那个处理"这类判断的直觉在原理上能不能信"。
- **contrasts-with**: `hindsight-narrative-guard`（本书已验证 · 待整理）— 本 skill 用于**决策前**，那个用于**结果出来后**。二者的敌人是同一个（连贯故事），出现的时点不同。
- **composes-with**: `formula-over-intuition`（本书已验证 · 待整理）— 当同类判断反复出现时，与其每次审计，不如一次性把它变成评分表。
