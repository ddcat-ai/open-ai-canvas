## I — 方法论骨架 (Interpretation)

价格战的本质不是对手太便宜，而是**你的产品可以被逐项对照**。一旦顾客能把你和竞品放在同一张表里逐行比单价，价格就是唯一变量，利润必然被压到成本线。

反过来说，**定价自由度直接等于不可比性**。这不是"讲品牌故事"的软性说法，而是一条机制：当顾客无法做外部对照时，他只能退回到自己的内部参考价——而那个参考价是可以被卖方塑造的（见 `arbitrary-coherence-pricing`）。差异化之所以有效，正是因为它阻断了单价比对，而不是因为顾客真的被故事打动。

书中给出四条互补的路径：

**捆绑**：把若干项合成一个价格，顾客无法核算其中任何一项的单价。快餐套餐、份饭、"21 件魔弹全套"都是这个逻辑。捆绑同时提供了一个正当性外衣——"整套才这个价"。

**分拆**：反向操作。把总价拆成基础价 + 若干附加费（机票的燃油费、行李费、选座费），使醒目的基础价可以低到极具竞争力，而总支出并不低。

**单位与规格模糊**：改变计价单位（不按杯按月、不按小时按项目）、采用自有规格与命名，使"同款"不再存在。电池品类的质量不透明就是天然版本。

**统一费率**：这是最强的一条，因为它同时解决两个问题——消除逐次比价，且消除**计价痛感**。人们讨厌盯着计价器跳字，愿意为"不用再算了"多付钱。

需要点破的是这套手法的另一面：定价结构的实质作用往往是把价格不敏感者与敏感者分开（书中通俗称为"傻瓜蛋"逻辑），让前者支付更多。这合法但依赖信息不对称与自我筛选，因此必须过伦理与合规两道门。

## A1 — 书中的应用 (Past Application)

### 案例 1：餐厅份饭与两枚扇贝
- **问题**：13 美元两枚扇贝，单看必然引发愤怒。
- **方法论的使用**：把它放进"份饭"结构中，与前菜、主食、饮品合成一个价格。
- **结论**：捆绑不只提供便宜的感觉，它更重要的作用是让成本核算变得不可能。
- **结果**：顾客付了钱且不觉得被宰。塞勒在《旧金山 Zagat 就餐指南》上找出了这个例子。

### 案例 2：连锁餐厅不断变动的菜单
- **问题**：捆绑效应会随回头客对套餐价格的熟悉而减退。
- **方法论的使用**：持续更换主菜、给旧菜改名、推出"超大型"版本、改变配菜（比如你没法再买到跟上回完全一样的扭扭薯条）。
- **结论**：不可比性需要**持续维护**，它会自然衰减。
- **结果**：顾客始终无法把这次的账单与上次精确对照。

### 案例 3：圣地亚哥手机用户的每分钟 3.02 美元
- **问题**：统一费率套餐真的更划算吗？
- **方法论的使用**：2009 年 UCAN 用计费总额除以总通话分钟数，算出实际每分钟成本。
- **结论**：消费者在做的是**心理成本**最小化，不是金额最小化。
- **结果**：平均每分钟 3.02 美元——因为大量用户明知打不了那么多电话，仍选择了统一费率套餐。同一心理让游轮上"免费"的食物成为卖点（尽管船票明显包含了它），也让城里人宁可养车也不愿盯着出租车计价器。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 与竞品同质化，客户拿着对方报价单逐条压价。
2. 在比价平台/电商搜索结果里，只能靠低价获得曝光。
3. 想涨价但一涨顾客就跑，因为单价直接可见。
4. 设计订阅制：纠结包月、按次、阶梯还是混合。
5. 服务业报价被要求拆成人天单价，利润透明化。
6. 加盟店/门店被顾客拿隔壁店的单品价直接对比。

### 语言信号 (用户的话里出现这些就应激活)

- "陷入价格战了／同行都在降价"
- "客户只问多少钱一个／拿着别家报价单来砍"
- "我们和竞品几乎一样，怎么卖贵"
- "包月好还是按次好"
- "we're being commoditized / stuck in a price war"
- "customers just compare unit price"

### 与相邻 skill 的区分

- 与 `choice-set-decoy-design` 的区别：那个是**对内**——在你自己的几档之间引导选择；本 skill 是**对外**——切断与竞品的对照。一个引导比较，一个消灭比较。
- 与 `reference-price-framing` 的区别：那个假定顾客会比较，因此优化"和谁比、怎么显示"；本 skill 直接让比较不成立。当外部参照太强、无法用呈现手段抵消时，用本 skill。
- 与 `arbitrary-coherence-pricing` 的区别：那个是在**原点为空时**建立结构；本 skill 是在**原点已被竞品占据时**把它遮住。

## E — 可执行步骤 (Execution)

1. **画出顾客的比价表**
   - 动作：以顾客视角写出他会用来对照的那张表：行是产品项，列是各家。
   - 完成标准：能明确指出哪几行是"可逐项对照"的致命行。
   - 判停条件：若没有任何一行可对照（顾客根本无从比较），说明你不在价格战里，本 skill 不必用。

2. **选择路径：捆绑 / 分拆 / 改单位 / 统一费率**
   - 动作：按下列判据选一到两条——
     - 顾客买的是**一组相关项** → 捆绑
     - 有一个高曝光的入口价需要拉低（搜索、比价页） → 分拆
     - 品类有强单位惯例（一杯、一小时、一个） → 改单位
     - 使用频次不确定、计价痛感强 → 统一费率
   - 完成标准：路径唯一且写出一句话理由。

3. **重建计价口径**
   - 动作：把致命对照行改造掉。捆绑就合并、分拆就抽出附加项、改单位就换分母（月卡/项目制/成果制）、统一费率就取消次数计量。
   - 完成标准：竞品的报价单无法与你的新口径逐行对齐。

4. **给不可比性一个正当理由**
   - 动作：为新口径写一句顾客能复述的解释（"我们按结果收费，不按工时"、"月卡不限次，省得每次算账"）。
   - 完成标准：这句话不提竞品，也不提"我们更好"。

5. **核算统一费率的风险敞口（若选此路径）**
   - 动作：估算重度用户占比与其消耗成本，设定隐性上限（公平使用条款）或分级。
   - 完成标准：能算出在最坏使用分布下仍不亏损。
   - 判停条件：若边际成本高（如实物、算力），统一费率会被重度用户套利，改用阶梯。

6. **建立维护节奏**
   - 动作：设定周期（如每季度）更新套餐构成/命名/规格，防止不可比性衰减。
   - 完成标准：日历上有明确的下次更新时间与负责人。

7. **过合规与伦理门**
   - 动作：检查——所有必付费用是否在成交前充分披露？总价是否可被顾客算出？若把手法公开告知，顾客是否仍愿意交易？
   - 完成标准：三问皆是。
   - 判停条件：任一为否，退回步骤 2 换路径。分拆定价尤其容易越界为隐藏收费。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **受强制价格披露监管的行业**：机票总价展示、金融产品年化利率、医疗收费清单等，法规要求可比性。
- **B 端大额采购**：专业采购方会要求拆解报价，人为的不可比性会被识别为不诚信并影响入围资格。
- **你是买方**：此时应反用本 skill——把对方的捆绑拆开、把统一费率折算成单次成本、要求统一计价口径。
- **信任本身是核心资产的关系型业务**：律师、医生、财务顾问，隐藏成本一旦被发现，损失远超收益。

### 作者在书中警告的失败模式

- **效应会衰减**：回头客熟悉套餐价格后，捆绑效应减退。不持续更新就会失效。
- **把价格点写进品牌**（X8）：如"九毛九"，一旦以某价格为招牌，成本上涨时既不能涨价也不能改口，最终"堕落成了下诱饵的骗子"。
- **免费的错觉有代价**（X9）：统一费率里的"免费"项（游轮餐食）能提升满意度，但一旦被拆出来单独收费，抵触会远大于它的实际金额——统一费率是一道不易回头的门。
- **透明不是解毒剂，但被识破是**：书中的手法建立在顾客不逐项核算之上；一旦有第三方做了核算并广泛传播（如 UCAN 算出每分钟 3.02 美元），叙事会迅速反转。

### 作者的盲点 / 时代局限

- 成书于比价插件、聚合平台、AI 购物助手普及之前。今天算法可以自动折算不同计价口径，不可比性的半衰期显著缩短。
- 书中未讨论订阅疲劳与自动续费监管——统一费率在今天面临"订阅太多、要求一键退订"的政策与舆论压力。
- 涉及"谁被多收钱"的人群结论在书中自相矛盾（X3），不得据此按人群设计费率差异。

### 容易混淆的邻近方法论

- **差异化竞争（波特）**：结论相近但机制解释不同。本 skill 主张差异化的作用是阻断单价比对，因此**只要能阻断比对的差异都算数**（包括计价口径这种非产品差异），这是波特框架不会给出的建议。
- **价格歧视（二级）**：版本划分与本 skill 常同时出现，但目标不同——价格歧视要分离人群，本 skill 要消灭对照。
- **诱饵效应**：作用于同一集合内的选择，不作用于跨品牌对照。
