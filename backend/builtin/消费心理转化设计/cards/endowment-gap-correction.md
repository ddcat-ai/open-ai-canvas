## I — 方法论骨架 (Interpretation)

一件东西一旦成为"我的"，它的估价会立刻上跳，而当事人**察觉不到这次上跳**。
这不是贪心，也不是谈判技巧，是感知层面的改变：卖方与买方看到的根本不是同一件东西。

艾瑞里把所有权的怪癖拆成三条，它们**同时**生效：

1. **爱上已经拥有的**——投入、回忆、习惯都被折算进价格；
2. **只盯着会失去什么**——买方在算"我会得到什么"，卖方在算"我会失去什么"，
   而损失的权重天然更高；
3. **默认对方与我视角相同**——卖方真诚地认为买方也应该看到这些价值，
   于是把低价解读为"不识货"或"没诚意"。

由此得到本 skill 的第一条硬结论：

> **卖买双方的估价鸿沟是结构性的，不是态度问题。**
> 把它当成对方不诚意来处理，会让本可成交的交易破裂。

第二条更反直觉的推论是**虚拟所有权**：触发禀赋效应**不需要真正拥有**。

- 竞拍中暂时领先 → 已经把它当成自己的，后续加价失去理性；
- 免费试用期 → 商品已进入禀赋，退回被记为损失；
- 看房时脑中已经安排好家具 → 议价能力瞬间下降；
- 已经做了一版方案 → 砍掉它像割肉。

这条推论把本 skill 从"卖东西"扩展到了**任何需要放弃的场景**，
包括砍项目、离职、结束关系、清理物品。

矫正的方向只有一个：**用外部信息替换内部感受**。
自我说服无效（因为你察觉不到偏移），对方说服更无效（会被读作压价）。
唯一可靠的做法是引入不受你所有权污染的参照：真实成交价、
第三方估值、以及下面那个最锋利的问题——**重新买入测试**。

## A1 — 书中的应用 (Past Application)

### 案例 1：杜克大学篮球票的 14 倍鸿沟

- **问题**：所有权能把估价抬高多少？
- **方法论的使用**：杜克大学决赛门票以抽签分配。抽签前两组学生完全同质，
  唯一差别是**随机的**所有权。随后询问卖价与买价。
- **结论**：抽中票的学生平均要价约 2400 美元，未抽中的平均只愿出约 175 美元。
- **结果**：**近 14 倍的价差，唯一变量是一次抽签。**
  这排除了"卖方更懂行"的解释——两组的信息完全一样。
  卖方在描述"那场比赛会成为一生的回忆"，买方在描述"可以用这笔钱做什么"，
  双方都真诚，且都无法理解对方。

### 案例 2：免费试用是获取手段，不是评估手段

- **问题**："先试用再决定，这样最理性"——真的吗？
- **方法论的使用**：艾瑞里指出，试用期一开始，禀赋效应就已生效。
- **结论**：退回时的心理成本被记为**损失**，因此"试用后决定"的决策
  从第一天起就已经不中立。
- **结果**：双向推论——
  ①**消费方**：把"要不要留下"改写成"如果现在手里没有它，我会花这笔钱买吗"；
  ②**供给方**：试用期的真正作用是制造所有权而非展示质量，
  所以关键动作是让用户把数据、配置、内容**留进去**
  （这与 `investment-design` 的储存价值机制在此处交汇）。

### 案例 3：拥有越久，越看不见公正价格

- **问题**："我在这个领域待得久，所以我的估价更准。"
- **方法论的使用**：持有时间与沉没成本会系统性抬高估价，且当事人无法自察。
- **结论**：经验带来的是对**这一件**东西的偏爱，不是对**市场**的准确判断。
- **结果**：卖房、卖公司、谈薪、推销自己的旧方案时，
  **必须外部化定价**，不能用自己的感觉。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill

1. **出售自有资产**：房子、车、二手物品、公司、股权。
   "挂了三个月没人问""对方出价离谱"。
2. **谈薪与离职补偿**：对自己价值的估计与市场报价之间的落差。
3. **砍掉自己主导的旧项目/功能/产品线**：舍不得的对象是自己的投入。
4. **谈判中理解对方**：对方要价高得莫名其妙时，判断是策略还是禀赋。
5. **免费试用与订阅退出设计**（供给侧）：试用期该怎么设计才有效。
6. **面对自己的试用与续订**（需求侧）：一堆用不上但退不掉的东西。
7. **囤积与断舍离**："万一以后用得上"。
8. **并购与投前估值**：创始人估值与投资人估值的结构性鸿沟。

### 语言信号

- "我这套房子明明值××，中介非说要降"
- "对方出价太低了，根本不识货"
- "这个项目投了两年，砍了太可惜"
- "试用完就懒得退了"
- "我觉得我值这个薪水，但他们只给这么多"
- "东西都还能用，扔了浪费"
- "endowment effect / seller-buyer gap / free trial / sunk cost"

### 与相邻 skill 的区分

- 与 `anchor-antidote`：那解的是**外来的数字**（对方先报价，你被压住）；
  本 skill 解的是**自有物的估价偏移**（没人报价，你自己就高了）。
  机制不同：一个是参照污染，一个是所有权+损失厌恶。
  若两者同时发生（对方先报了一个低价，而你又在卖自己的东西），
  先用本 skill 校准自己的真实区间，再用那个 skill 处理对方的锚。
- 与 `arbitrary-coherence-pricing`：那是给**没有参照的新东西**定第一个价；
  本 skill 是给**已经拥有的东西**定价，问题恰恰是参照过多（全是自己的）。
- 与 `anchor-first-offer`：那决定"要不要先开口、开多少"；
  本 skill 决定"我开的这个数字本身可不可信"。**顺序上本 skill 在前。**
- 与 `close-the-doors`：那是舍不得**关掉可能性**（尚未拥有的选项）；
  本 skill 是舍不得**放弃已拥有物**。两者常同时出现在"砍项目"场景，
  可组合。
- 与 `investment-design`：那是产品侧**主动**让用户存入价值以提高留存
  （建设视角）；本 skill 是识别这一效应并在需要时**抵消**它（矫正视角）。
  同一机制的两个方向。
- 与 `ultimatum-fairness-leverage`：若卖方的高要价源于"觉得被占便宜"
  的公平愤怒而非估价偏移，用那个 skill。判据：他在谈价值还是在谈公道。

## E — 可执行步骤 (Execution)

1. **先承认偏移存在，且你测不出它的大小**
   - 这一步不是心理建设，是防止后续步骤被"我不一样"消解。
   - 关键认识：杜克实验中的两组学生**在抽签前完全相同**。
     你的高估价里，有相当一部分只来自于"它现在是你的"。
   - 完成标准：接受"我的感受不能作为定价依据"这一前提。

2. **做重新买入测试（Repurchase Test）** ★核心动作
   - 问自己一个问题：
     > **假设我现在没有它，手上是等额的现金，我会花这笔钱把它买回来吗？**
   - 若答案是"不会" → 你的要价高于你的真实估值，
     差额就是禀赋溢价，应当剔除。
   - 变体（用于项目/功能）：
     > 如果这个项目今天还不存在，以现在的信息，我会立项吗？
   - 变体（用于试用/订阅）：
     > 如果它今天自动取消了，我会主动去重新订阅吗？
   - 完成标准：对每一项写下明确的是/否，不允许"看情况"。

3. **外部化定价：至少三个不受你污染的参照**
   - 优先级：**真实成交价 > 挂牌价 > 第三方估值 > 熟人意见**。
     （挂牌价里含着别人的禀赋溢价，可信度次一等；
     熟人意见常被你的叙述带偏，最弱。）
   - 做法：查同类近期成交、请无利益关系的第三方给区间、
     看买方实际支付过什么价。
   - 完成标准：得到一个**区间**而非一个点，且区间来自外部数据。

4. **把自己的感受单独列出，不许混进价格**
   - 单独写一行："这件东西对我的额外意义 = ××"。
   - 承认它真实存在，但明确它**不可交易**——
     买方不会为你的回忆付钱，这不是他的错。
   - 完成标准：价格表与情感清单物理分离。

5. **重写谈判叙事：从"我会失去什么"改为"他会得到什么"**
   - 卖方天然在讲损失，买方只听得懂收益。
   - 把描述逐条翻译：不说"我保养了五年"，说"你接手后三年内无需大修"。
   - 完成标准：对外材料中没有任何一条是从"我"的视角写的。

6. **理解对方的鸿沟，不要归因为恶意**
   - 当**你是买方**时：对方的高要价大概率不是策略，是真诚的禀赋溢价。
     有效做法是提供外部成交数据（让他自己看见），
     而不是论证他的东西不好（会触发防御与公平愤怒）。
   - 完成标准：谈判方案中包含"给对方看外部参照"这一动作。

7. **供给侧应用：设计试用与退出**
   - 试用期的目标不是让用户评估质量，是让商品进入用户的禀赋：
     引导导入数据、完成配置、产生内容、建立习惯。
   - **伦理硬约束**：制造所有权是合法的，但退出路径必须与进入路径
     同样容易。若靠"退不掉"留人 → 转 `manipulation-matrix-ethics`。
   - 完成标准：试用设计中同时存在"让用户存入价值"与"一键退出"。

8. **需求侧防御：给自己设一个禀赋隔离期**
   - 对试用、赠品、竞拍：在开始前先写下"我愿意付的最高价"，
     并在过程中不得上调。
   - 竞拍尤其危险——领先的那一刻你已经"拥有"了它。
   - 完成标准：存在一个事前写下的、不可修改的上限。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **标的确实稀缺或不可替代**：孤品、有真实议价权的独特资产、
  强势卖方市场。此时高要价是市场结构的结果，不是认知偏差。
  判据：**是否存在活跃的同类成交**。没有，就没有外部参照可用。
- **对方的高价是明确的谈判策略**：有意识的锚定不是禀赋效应，
  用 `anchor-antidote` 处理。判据：他是否愿意快速让步。
- **情感价值本身就是购买目的**：传家物、纪念品、
  以及买方也在为情感付钱的市场（收藏品、粉丝经济）。
  强行外部化定价会毁掉交易的意义。
- **用重新买入测试逼人清空生活**：这个问题很锋利，
  用在"是否续订 SaaS"很好，逐条用在个人物品上会制造焦虑。

### 作者在书中警告的失败模式

- **"先试用再决定最理性"是错的**（x11）：试用一开始，
  决策已不中立。这条对个人消费者是最实用的一条防御。
- **"我懂行所以我估得准"是错的**（x12）：持有时间与沉没成本
  抬高估价，且**当事人无法自察**。经验不能免疫。
- **把估价鸿沟解读为对方不诚意**：这是谈判破裂最常见的单一原因。
- **虚拟所有权在竞拍中最危险**：暂时领先就足以触发效应，
  拍卖设计正是利用了这一点。
- **信息无法修复偏移**：告诉卖方"你被禀赋效应影响了"不会降低他的要价——
  同样适用"补充信息几乎从不改变行为"（p15）这条元约束。
  必须给外部成交价，而不是给心理学解释。

### 作者的盲点 / 时代局限

- **禀赋效应的原始研究不属于艾瑞里**：概念来自 Thaler（1980）、
  Kahneman-Knetsch-Thaler（1990）的马克杯实验，
  杜克球票实验为艾瑞里与 Carmon 所做。本书是应用与普及。
- **禀赋效应的适用范围已被后续研究收窄**：
  一是**交易经验**会显著削弱效应（有经验的交易者身上几乎观察不到）；
  二是部分早期结果被指有实验需求特征（experimenter demand）的贡献；
  三是对**交换类商品**（明确用于交易的物品）效应很弱。
  因此不应假定它在所有市场普遍成立——**在专业化、高频交易的市场里，
  本 skill 的效力会明显下降**。
- **艾瑞里团队的部分研究已卷入数据可靠性争议**
  （详见 `fudge-factor-integrity` B 段，含一项已撤稿实验）。
  禀赋效应本身有独立的、广泛的研究支持，受牵连较小，
  但引用具体数字时应注明来源与年代。
- **未讨论数字化所有权**：云端订阅、账号资产、虚拟物品的禀赋效应
  与实体物差异明显（不占空间、无损耗、可无限试用），
  书中成于订阅经济成熟之前，无对应分析。

### 容易混淆的邻近方法论

- **沉没成本谬误**：那是"已经投入了所以继续"（关于**继续投入**）；
  本 skill 是"因为拥有所以估高"（关于**估价**）。
  两者在"砍旧项目"场景高度重叠，常需同时处理。
- **损失厌恶**：那是禀赋效应的**上游机制**（损失权重高于同额收益），
  是解释；本 skill 是应对方法。
- **现状偏差（Status Quo Bias）**：那是倾向于不改变（关于**行动**）；
  本 skill 关于**定价**。默认选项设计属于前者。
- **锚定效应**：参照来自外部数字；禀赋来自所有权状态。
  最容易混淆的一对，判据是**这个高估价有没有一个外部数字作为源头**。
