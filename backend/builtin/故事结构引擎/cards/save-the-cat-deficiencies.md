## I — 方法论骨架 (Interpretation)

主角的缺陷不是人物小传上的装饰，而是贯穿三幕的"定时炸弹"装置，分三步走：

- **埋雷（铺垫期 1-10 页）**：列出主角的性格缺口。"六"是虚数，3-6 个皆可；它们必须是"看得见、可被旁人察觉"的具体弱点——如《长大》里主角"身高不够坐不了过山车、追不到女孩、没有隐私"。
- **重现（第一幕到第二幕）**：每条缺憾要以反复动作（callbacks / running gags）的形式不断出现在观众眼前，变成可识别的重复信号，让观众记住它欠着。
- **引爆并治愈（第二、三幕）**：缺憾被公开展示、被击碎，然后在结局前被具体情节弥补，让观众看到缺口被填上并因此过瘾。

检验方法：如果第三幕空荡、只剩"主角知道该怎么办+大决战"两张卡，就回头检查第一幕埋的缺憾、副线故事、反派清算是否都已结清——**第三幕的内容其实是第一幕欠下的债**。

本质：把"塑造丰满人物"这句空话，变成"缺陷—重复—偿还"的对仗机关，让人物弧光有可对表的施工路径。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《长大》的缺憾清单
- **问题**: 一部"一夜长大"的喜剧，如何让第三幕有真正的弧光而不只是笑点堆砌？
- **方法论的使用**: 铺垫期先给主角埋下一组缺憾——身高不够坐不了过山车、追不到女孩、没有隐私；这些缺憾在变身后以反转形态重现（他终于"够得着"了），并在结尾被"治愈"——他体会过大人世界后选择回归并珍惜童年。
- **结论**: 缺憾既是笑点来源（重复动作），又是情感落点（治愈时刻），一条线同时服务喜剧与温情。
- **结果**: 成为作者讲解"六大缺憾"机制的首选例证。

### 案例 2: 《特工佳丽》的"不需要女人味"
- **问题**: 男人婆 FBI 主角如何完成一个观众能看见的转变？
- **方法论的使用**: 开场画面即埋缺憾——童年假小子暴揍男生、宣称"不需要女人味"；副线故事（与美甲师式佳丽们的关系）是缺憾的反复重现场；失去一切处"失去特工身份+导师送裙子"是引爆点；结局的防身术表演=正反融合，被佳丽们环绕获"最佳人缘奖"即缺憾被治愈。
- **结论**: 缺憾的治愈路径与副线、结局高度重合，形成三幕对仗。
- **结果**: 影片美国国内票房 1 亿美元，成为作者做 BS2 完整拆解时的头号示范（此处聚焦其缺憾机制视角）。

### 案例 3: 第三幕黑洞的回查
- **问题**: 作者在演示板初期几乎总要面对空荡荡的第三幕，只有"主角知道该怎么办+大决战"两张卡。
- **方法论的使用**: 治愈办法是回头检查第一幕的铺垫与六大缺憾、副线故事和反派清算是否都已安排。
- **结论**: 缺憾机制同时是"第三幕空荡"的诊断工具——第三幕的每个格子都该由第一幕的债来填。
- **结果**: 作者把"回查第一幕缺憾"固化为填满第三幕的标准动作，写进演示板方法论。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户写故事时觉得主角太完美、没有成长空间（"我的主角没什么缺点，故事写不下去"）。
2. 用户写到第二三幕发现没东西可写，尤其结局空荡（"第三幕不知道写什么，只有场大决战"）。
3. 用户想给故事埋伏笔、做前后呼应（"我想在前面埋个梗，后面收回来"）。
4. 用户想让角色有扎实的成长弧线，但不知道从哪下手（"怎么让主角在结尾真正变一个人"）。
5. 用户回看改稿，发现前面埋的线索后面忘了回收（"我前面写的这个细节后面用不上"）。

### 语言信号 (用户的话里出现这些就应激活)

- "六大缺憾" / "six things that need fixing"
- "性格缺陷 / 人物弱点" / "character flaw"、"weakness"
- "埋雷 / 埋点" / "plant"、"setup"
- "伏笔 / 呼应" / "foreshadow"、"callback"、"payoff"
- "第三幕空荡 / 结尾没东西写" / "empty third act"、"weak ending"
- "主角太完美 / 没成长空间" / "no room to grow"、"too perfect"

### 与相邻 skill 的区分

- 与 `save-the-cat-beat-sheet` 的区别: beat-sheet 管全片 15 拍的横向骨架，deficiencies 管"人物缺陷的埋-现-愈"这条纵向线索；用缺憾去填第三幕黑洞是二者协作点，但聚焦点不同。
- 与 `save-the-cat-diagnosis` 的区别: diagnosis 是初稿完成后的 9 问体检（其中第 8 问"后退一步"与角色成长相关但不同），deficiencies 是动笔前的构造机制；"写完了哪里不对"走 diagnosis，"怎么埋缺陷"走 deficiencies。
- 与 `save-the-cat-protagonist-design` 的区别: protagonist-design 定"主角是谁"（三要素+原始动机），deficiencies 定"主角缺什么、怎么被治愈"；前者选角，后者布线。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **盘点缺陷**: 列出主角的 3-6 个性格缺口，每个必须是"可见于行动、可被旁人察觉"的具体弱点（不是"缺乏勇气"这种抽象词）。
   - 完成标准: 写出 3-6 条，每条含一句话描述 + 一个在铺垫期能拍出来的具体动作画面。

2. **埋雷并设计重现信号**: 把这些缺憾写进铺垫期（前 10 页）的具体场景，并为每条缺憾设计一个"反复出现"的回声——同一情境以不同变体重复 ≥2 次。
   - 完成标准: 前 10 页有至少 3 个场景各埋入至少 1 条缺憾；每条缺憾都有一个可重复的视觉/情境信号。
   - 判停条件: 若用户的故事明确不追求人物成长（纯悬疑机关、舞台动作类型），输出缺憾盘点即止，不强推治愈设计。

3. **对表治愈**: 为每条缺憾找到它在第二、三幕的引爆点（被公开展示/被击碎）和治愈点（被弥补的具体情节），检查治愈是否与结局绑定。
   - 完成标准: 每条缺憾都有"引爆场景 + 治愈场景"两行，治愈点均落在结局之前；若有缺憾没有治愈点，回到步骤 1 删掉或合并。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 群像/无成长型故事：人物本就不需要弧光；作者自己的"人物弧光"法则也承认有例外（唯反派不变），有些类型片配角根本不承载弧光。
- 用户只是想让配角被记住：那是"跛脚和眼罩"（连续视觉记忆点+独特说话方式），不是缺憾机制。
- 非叙事内容（说明文、产品文案）：没有"人物"，机制无附着点。

### 作者在书中警告的失败模式

- 空荡荡的第三幕（ce19）：第三幕只剩"主角知道怎么办+大决战"两张卡时，回查第一幕的缺憾、副线与反派清算是否结清。
- 主角起点太高、不肯后退（ce25）：把主角写成"乐于助人的好孩子"——没有缺憾可治愈，作者为此改了七稿才改对；缺憾机制的前提是主角开局必须"缺"。
- 被动的主角（ce02）：缺憾若只是被动展示而不被主角主动面对，弧光不成立；主角必须主动去弥补，否则就退化成"强尼·熵"式的懒汉。

### 作者的盲点 / 时代局限

- "缺憾-治愈"是对好莱坞主流商业片弧光的提炼，不是普遍叙事规律：大量文艺片、反结构影片的主角缺陷从不被治愈甚至加深，仍是佳作。
- 把缺陷约简为"个体性格弱点"，回避了阶级、文化、制度性压迫等社会性缺陷，用"个人治愈"遮蔽结构性问题——这是作者生物学化约论（穴居人测试）的延伸盲点。
- "治愈必须让观众过瘾"的价值判断基于 2005 年好莱坞主流市场；当代剧集/游戏叙事中，"埋雷-回收"技巧仍然有效，但"过瘾的治愈"不是唯一解（也可以是不圆满的回收）。

### 容易混淆的邻近方法论

- "人物弧光"法则（第6章）：弧光要求每个角色都转变，缺憾机制是主角弧光的具体布线法；一个管范围（全员），一个管路径（主角的缺陷线）。
- "副线故事"节拍（第4章）：副线常承载缺憾的治愈（《特工佳丽》的美甲师线），但副线不等于缺憾线——副线还可以承载主题与爱情。
