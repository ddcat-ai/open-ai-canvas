## I — 方法论骨架 (Interpretation)

解说（Exposition）= 观众理解故事所需的事实信息（背景、人物史、人物关系），它的艺术在于"无形"：

1. **铁律是"展示不要告诉"**：解说必须戏剧化，首要目的是推进直接冲突，次要才是传达信息——把信息当作人物斗争的"弹药"。
2. **弹药化**：让人物用自己知道的信息去争取想要的东西；现实里没人会告诉另一个人两人都已知道的事，所以互诉已知的对白必删。
3. **两条戒律**：不给观众能凭常理推断的信息；不给除非缺失会引起迷惑的信息——靠"扣押"而非"倾泻"维持兴趣。
4. **进度原则**：最不重要的事实最先出现，最重要的秘密（人物最痛的真相）留到故事线终点，在压力最大时被挤出来；过早泄密，观众远在高潮前就看到高潮。
5. **兴趣三模式**：神秘（观众知道得比人物少，好奇心驱动）、悬念（双方同等知道，好奇转向结果）、戏剧反讽（观众知道得更多，好奇转为恐惧与同情）——按信息不对称设计观众关系。
6. **巧合三规则**：尽早引入给它时间构建意义、讲述中点后不再采用、绝不用于转折结局（"来自机器的神仙"是剧作家最大忌讳）。
7. **文本技巧**：无言剧本（只要能有视觉表达就不要写对白）+ 形象系统（象征被观众意识到即失效）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 鸡尾酒会上的"加州场景"（麦基亲历）
- **问题**: 两个刚认识的人坐下来就互诉最深最痛苦的童年隐私，解说虚假牵强。
- **方法论的使用**: 麦基用自己在西海岸酒会的经历作反例——解说不该是陌生人互诉衷肠，而必须由生活压力挤迫而出。
- **结论**: 最重要的秘密（人物最不想让人知道的痛点）必须留到故事线终点、在压力下才披露。
- **结果**: 成为"把握解说进度、把秘密留到最后"的反面教学素材。

### 案例 2: 《恐怖地带》开篇——注定失败的病毒解说
- **问题**: 开篇序列里丹尼尔斯少校对飞机上的医务助理详细解说厄波拉病毒的病理知识。
- **方法论的使用**: 麦基用它示范"掸桌子"——让人物向本该懂行的人解说两人都该知道的事，毫无动机、不是弹药。
- **结论**: 如果你发现自己写出的对白是人物在告诉对方两人都已知道或应该知道的事，且不是作为斗争弹药，就把它删掉。
- **结果**: 成为解说失败的教学反面案例。

### 案例 3: 《唐人街》"她是我妹妹，也是我女儿"——秘密留最后的正面示范
- **问题**: 第二幕高潮前观众以为马尔雷被害不是为财便是为情，需要一次性揭示幕后真相。
- **方法论的使用**: 伊夫林的告白被保留到幕高潮这一重大转折点，把观众送回前面场景（克罗斯那句"为我女儿"），一次获得乱伦、动机、凶手三重见解。
- **结论**: 揭示比动作冲击力更强；幕后故事解说能创造爆炸性转折点，秘密必须留到最后。
- **结果**: 新方向指向第三幕螺旋般的转折，成为解说/幕后故事运用的典范。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写开场/第一幕，担心背景交代生硬、前三十页拖着"解释性大肚子"。
2. 需要把人物前史/幕后故事透露给观众，不知从何下手。
3. 设计"秘密何时揭露"——主角或某角色的痛点真相。
4. 想制造神秘/悬念/戏剧反讽的信息不对称关系。
5. 想在剧情里用巧合，但怕被骂"来自机器的神仙"。
6. 场景对白太多，想改成纯视觉表达或形象系统。

### 语言信号 (用户的话里出现这些就应激活)

- "背景交代太生硬" / "exposition feels forced" / "backstory"
- "怎么展示不要告诉" / "show don't tell"
- "秘密/真相什么时候揭示" / "when to reveal the secret"
- "悬念 / 神秘感 / 戏剧反讽" / "mystery", "suspense", "dramatic irony"
- "巧合" / "coincidence"
- "全是对话没有画面" / "too much dialogue"

### 与相邻 skill 的区分

- 与 `mckee-scene-analysis` 的区别: 五步法是诊断/拆解已有场景；本 skill 是生成信息的释放策略。
- 与 `mckee-turning-points` 的区别: 伏笔/分晓支撑单点转折；本 skill 管理全部背景信息流与释放进度。
- 与 `mckee-controlling-idea` 的区别: 主控思想是作者的意义主张（价值+原因）；解说秘密是人物的事实信息，两者不同层。
- 与 `mckee-crisis-climax` 的区别: 末段设计链管高潮力度；本 skill 只管信息何时/何地/如何泄露。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **盘点解说清单**
   - 完成标准: 列出观众理解故事必需的"事实信息"清单并按重要性排序；能区分三类——观众凭常理可推断的、缺失才会引起迷惑的、必须由故事披露的；标出最重要的秘密（人物最痛的真相）。
   - 判停条件: 若清单里没有"必须披露"的信息，说明背景其实不重要，可大幅删除。

2. **弹药化改写**
   - 完成标准: 每条解说都能指出"谁在用什么信息当弹药争取什么"；没有"人物互诉已知"的对白；没有"掸桌子"节拍（含用闪回/梦境/蒙太奇/画外音偷懒）。
   - 判停条件: 写不出斗争用途的信息 → 删掉或挪到别处。

3. **排布进度与兴趣模式，并视觉化**
   - 完成标准: 信息释放遵循"最不重要→最重要，秘密留最后"；选定或混用神秘/悬念/戏剧反讽，并说清各场景的信息不对称关系；巧合符合三规则（早引入、中点后不用、不转结局）；能视觉表达的不写对白，形象系统静默重复。
   - 判停条件: 秘密被提前揭穿 → 往后挪；发现靠巧合转折结局 → 改为人物行动的直接结果。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯文字小说/长篇小说：麦基针对电影媒介，小说的内心独白与解说规则不同。
- 悬疑/推理类型的"叙诡"：故意误导观众不是解说失误，而是本 skill 的"神秘"模式选择。
- 用户问的是对白文笔润色（措辞、节奏）——那是文本层，不是信息释放策略。
- 剧集多季连载：秘密可以跨季保留，"留到最后"的粒度需按季/集重校准。

### 作者在书中警告的失败模式

- "加州场景"（ce22）：陌生人互诉衷肠——两个刚认识的人交换童年创伤。
- "掸桌子"（ce23）：毫无动机的解说，人物告诉另一人两人都已知的事。
- 用闪回/梦境/蒙太奇/画外音偷懒（ce24）：以装饰性摄影和剪辑取代戏剧化展示，把电影变成"有声插图磁带书"。
- 用巧合转折结局（ce25）："来自机器的神仙"，抹杀意义、侮辱观众。
- 廉价惊奇/虚假神秘（ce26）：人为扣押本可告知的信息制造冒牌好奇。

### 作者的盲点 / 时代局限

- 视觉/听觉比例约 80/20 基于录像带与院线时代，手机屏/倍速观看/多屏时代需重估。
- "展示不要告诉"与"无言剧本"针对电影媒介；有声内容、文字媒介的解说节奏不同。
- "观众知道得比电影多"是未经验证的断言，忽略了不同媒介素养群体的知识差异。

### 容易混淆的邻近方法论

- `mckee-turning-points`：伏笔/分晓支撑转折点 vs 本 skill 管理信息流。
- `mckee-scene-analysis`：诊断场景问题 vs 本 skill 设计信息释放。
