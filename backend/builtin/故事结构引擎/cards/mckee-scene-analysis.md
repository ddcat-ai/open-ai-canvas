## I — 方法论骨架 (Interpretation)

场景分析是诊断/改写任何场景的通用显微镜。前提是麦基的场景定义：场景是在相对连续时空里通过冲突表现的动作，且**至少在一个重要价值层面使情境发生转折**——没有转折的场景不是故事事件，应该删掉。在这个前提下，用五步让场景"吐露秘密"：

1. **确定冲突**：谁驱动这个场景？用目的状语表述他的欲望（"为了得到X"）；对抗力量要什么？两者必须**直接相对**，而不是平行或相切。找不到直接相对的冲突，场景就没有引擎。
2. **标注开篇价值**：确认场景开头押上台面的故事价值及其正/负负荷（爱/恨、生/死、自由/奴役等二元对立项）。
3. **分解节拍**：把场景切成动作/反应的交换单位，每个节拍用**进行时短语**标注潜文本（"正在乞求""正在恳求"），而不是表面行为——这是读潜文本的钥匙。
4. **比较结尾价值**：结尾价值与开篇相同=非事件；有正负转向=场景成立。
5. **定位转折点**：审察节拍弧光，找到期望与结果裂开鸿沟的那个瞬间——场景的价值就是在那里完成转向。

配对的**文本/潜文本原理**：文本是可感的表面（影像/对白/声音），潜文本是表面之下被行为隐藏的思想情感。任何场景必须有与文本恰成对照或矛盾的潜文本，否则无法表演——"写在鼻子上"（直说心迹）的对白是死路。一个场景诊断下来，往往同时暴露五个维度的问题：冲突是否直接相对、转折点是否明确、情感是否转变、信息是否过多、节奏是否拖沓。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《卡萨布兰卡》幕中高潮——五步法完整示范
- **问题**: 里克与伊尔莎在市场的对峙场景，主情节如何从希望急转直下？
- **方法论的使用**: 麦基亲自示范五步：第一步确定冲突——里克驱动场景、欲望是"把伊尔莎夺回来"，对抗力量源是伊尔莎；第二步标注开篇价值（充满希望的正面）；第三步分解节拍——走近她/不理他、保护她/拒绝他、道歉/拒绝他……共十一个动作/反应交流；第四步比较结尾价值（希望粉碎，主情节急转直下）；第五步定位转折点——第十一个节拍，伊尔莎披露自己与拉兹洛早已结婚。
- **结论**: 节拍链与转折点由此显形，场景结构一目了然，可据此诊断或改写。
- **结果**: 里克沦为"奸夫"，主情节从充满希望的正面跌入低谷，转折点定位精确。

### 案例 2: 《犹在镜中》卡琳"上帝"场景——身体动作的转折
- **问题**: 一场以内心冲突为主导的场景，如何用五步法分析并找到转折点？
- **方法论的使用**: 麦基示范五步法的变体应用：卡琳驱动场景想见上帝，对抗力量是丈夫与更强大的潜意识自己；二十个节拍从轻松渐趋恐怖；转折点在第十三与十四个节拍之间——期望中的上帝变成蜘蛛强奸幻觉，即主人公潜意识头脑采取的动作。
- **结论**: 与《卡萨布兰卡》的静态言语交锋形成对照——转折点不一定是言语揭示，也可以由身体动作/内心动作完成；地点转移与时间流逝不破坏场景的单一性。
- **结果**: 卡琳从希望堕入无望，对上帝的信仰灰飞烟灭，场景以令人窒息的绝望收束。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写完一个场景，直觉"哪里不对"但说不出具体问题。
2. 审读别人的剧本/自己的旧稿，要逐场景给出诊断。
3. 觉得一场戏"演员演不出来""对白像在念说明"——怀疑潜文本缺失。
4. 判断"这个场景该不该删"——是否是非事件。
5. 想学习经典影片场景，按五步拆解找它为何有效。

### 语言信号 (用户的话里出现这些就应激活)

- "帮我拆一下这个场景 / 分析这场戏" / "analyze this scene", "break down this scene"
- "场景太平 / 没戏 / 像过场" / "scene feels flat", "this scene drags"
- "对白在直说心迹 / 演不出来 / 没有潜文本" / "subtext", "too on the nose"
- "这个场景该不该删" / "is this scene necessary", "cut this scene"
- "审读剧本 / 场景诊断 / 节拍分析" / "scene analysis", "beat breakdown"

### 与相邻 skill 的区分

- 与 `mckee-gap-writing` 的区别: 鸿沟写作是从零生成场景（进主观视点→问"那一反应的对立面"），本 skill 是诊断已写好的场景。
- 与 `mckee-act-design` 的区别: 场景分析是单场景显微镜；幕设计是整片骨骼节奏。
- 与 `mckee-turning-points` 的区别: 转折点 skill 教"如何设计一个好的转折点（四重效果+伏笔分晓）"；本 skill 的"定位转折点"只是五步中的诊断动作，重点在判定场景整体是否成立。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确定冲突 + 标注开篇价值**
   - 完成标准: 能写出"谁驱动场景、他的欲望用'为了…'表述、对抗力量要什么、两者直接相对"；能写出开篇押上台面的价值及其正/负负荷。若找不到直接相对的冲突，已算诊断出第一处问题。
   - 判停条件: 若驱动者欲望与对抗者欲望平行不相交（无冲突引擎），直接判定"场景无冲突核心"，给出重构冲突的建议，不必继续拆节拍。

2. **分解节拍（用进行时短语标潜文本）+ 比较结尾价值**
   - 完成标准: 场景被切成动作/反应对，每拍用"正在X"标注潜文本（不是表面行为）；写出结尾价值并与开篇比较，判定是"价值转向"还是"非事件"。
   - 判停条件: 若结尾价值=开篇价值（非事件），按麦基原则给出"删除或并入解说"的结论，并停止继续；若价值已转向，进入步骤 3。

3. **定位转折点 + 输出五维诊断与改写建议**
   - 完成标准: 明确指出鸿沟裂开的具体节拍位置（如"第 N 个节拍"）；输出冲突/转折点/情感/信息/节奏五个维度的诊断结论，并给出可执行的改写动作（如"这句对白删掉、改为动作""在第三节拍让世界给出相反反应"）。
   - 判停条件: 若发现问题是潜文本缺失（文本=潜文本，写在鼻子上），把改写重点放在"给表面动作配上矛盾的内在生活"，而非继续磨对白字句。

## B — 边界 (Boundary) ★

### 🔴 硬约束（世界层·违背就崩）

- 不能违背基本的场景分析五步法逻辑，否则观众/读者会立刻出戏
### 🟡 软约束（规则层·违背有代价）

- 场景还没写、需要从零构思——用 `mckee-gap-writing`。
- 用户要的是整片结构/幕节奏——用 `mckee-act-design`。
- 用户只关心"这个反转能不能更狠"——用 `mckee-turning-points`。
- 极短的非叙事片段/反情节场景：五步法假设"场景=价值转折"，对以静观、意象、无冲突为目的的镜头（部分艺术电影）需重新校准甚至不适用。
### 🟢 自设约束（认知层·其实可以重定义）

- 以为场景分析五步法只有一种正确用法——假墙，方法是工具，不是教条
- 以为场景分析五步法能解决所有问题——假墙，每个方法都有适用场景
