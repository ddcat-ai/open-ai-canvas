## I — 方法论骨架 (Interpretation)

动笔之前，除了回答"它讲的是什么"，还要回答"它最像什么"。作者把主流商业故事归为十种类型：**屋里有怪物、金羊毛、愿望成真、陷入困境、人生变迁、伙伴情谊、推理调查、傻瓜获胜、体制之下、超级英雄**。与传统"喜剧/剧情"的划分不同，这十个名字直接指向故事机制，每一类都有作者明文写死的规则清单（第2章）：

| 类型 | 核心规则（要素） |
|---|---|
| **屋里有怪物** | 出色的怪物 + 封闭的屋子（空间必须封闭，曾发生罪恶事件，超自然怪物如复仇天使杀有罪者、放过悔悟者；反例《小魔星》：怪物弱到能踩死+小镇随时能逃） |
| **金羊毛** | 英雄为寻某物上路，结束时找到"他自己"——关键不是旅途事件多有趣，而是事件成为主角成长的转折点；劫盗电影也属此类 |
| **愿望成真** | 主角必须是灰姑娘型（被周围人欺压，观众希望有人给他幸福）+ 观众不想看任何人一直当赢家（主角必须明白"魔法不是一切"，当普通人才最好）+ 结尾必须得到教训、有良好寓意。反面变体"受到诅咒/因果报应"：主角非常欠扁但身上有可挽救之处，开头须设"救猫咪"桥段 |
| **陷入困境** | 普通人 + 困境（走出困境必须先战胜自我）；主角越平庸、反派越坏，戏越好看 |
| **人生变迁** | 成长阵痛（青春期/中年危机/分手/悲痛）+ 外在力量（生活）是看不见的"怪兽" + 通过向更强大力量屈服获得胜利，接受人性（"这就是生活！"） |
| **伙伴情谊** | 伙伴电影=爱情故事的伪装；规则链条：一开始互相憎恨 → 共同旅程 → 发现需要对方（"圆的两半"）→ 意识到需要对方反而更多冲突 → 快结尾有"全部抛开"段落（争吵分手解脱，但实际不会分开）→ 双双放下自我才能获胜；子类：催化剂式伙伴（一个存在进入主角生活、影响、离开） |
| **推理调查** | 为什么比是谁更重要；观众就是侦探，自己筛查信息、被真相震惊；揭露人性阴暗面（把X光转向观众自身） |
| **傻瓜获胜** | 失败者（特别废柴、所有人都低估他、设定里反复强调）+ 一个体制（对抗对象）+ 通常有"局内人"同伙（自以为掌控全局，最终被闹剧式打脸） |
| **体制之下** | 群体/体制/家庭的故事，既赞颂又暴露体制吞噬个人；外来者视角（新人被有经验者带进来）；核心问题"谁更疯狂？是我还是他们？"；常有一个突围角色揭穿集体目标是骗局 |
| **超级英雄** | 与"陷入困境"相反：超乎寻常的人身处非常普通的世界；主题是"身为异者"；必须给英雄施加与其优势紧密相连的痛苦，先引起同情才能认同 |

每个创意必然落在其中某一种，且每种都有自己的规则与俗套位置。归类的用途不是贴标签，而是拿到一张"该类型的规则清单"：先拉片研究 3-5 部同类代表作，拆出哪些剧情元素重要、俗套在哪、为什么好或坏，然后才谈得上在规则内制造转折。

制造新意的公式只有一句：**"给我相同的东西……但要不一样！"**——可以接近俗套、绕着俗套跳舞、几乎拥抱俗套，但在最后关头必须掉转方向。模板被反复复用（《惊爆点》几乎等于《速度与激情》）并不可耻，关键是先明白自己打破了什么，才谈得上真正的原创。

## A1 — 书中的应用 (Past Application)

### 案例 1: 好莱坞的黑暗小秘密——《惊爆点》就是《速度与激情》
- **问题**: 创作者常担心"我的故事像别人的"，作者要破除这种恐慌。
- **方法论的使用**: 指出冲浪版与赛车版几乎一模一样，《谁陷害了兔子罗杰》其实就是《唐人街》——模板在起作用且被反复使用，因为这有效。关键不是回避相似，而是明白自己为什么用这个俗套，再在最后关头加新转折。
- **结论**: "只有当你明白自己打破了什么，你才能开始真正的原创。"俗套从敌人变成素材。
- **结果**: 模板复用不再可耻，作者据此提出"给老故事加新转折，让它跟上时代"的日常操作。

### 案例 2: 《小魔星》——屋里有怪物的反面教材
- **问题**: 一部片想写"屋里有怪物"类型，却让观众毫无紧张感，分不清是喜剧还是恐怖。
- **方法论的使用**: 对照该类型两条铁律逐条检查：①怪物设计要出色——片中的小破蜘蛛一脚就能踩死，没有超自然力量；②空间必须封闭——小镇居民任何时候都能买张车票坐下一班长途汽车离开。
- **结论**: 写了某类型却不守该类型规则=四不像，类型原力（原始情绪、结构保障）全拿不到。
- **结果**: 成为"先懂规则才能打破/出新"的反面教材。

### 案例 3: 与谢尔顿合写金羊毛（孩子找父母的公路片）
- **问题**: 写"小孩被军校开除回家发现父母搬走"的公路喜剧，不知该往哪个方向用力。
- **方法论的使用**: 反复拉片《落难见真情》《雨人》《哈啦上路》，研究每个事件对主角的影响；得出结论——金羊毛关键不在旅途事件多有趣，而在这些事件如何成为主角成长的转折点。
- **结论**: 类型规则给出"该有什么"的清单，转折点来自"把俗套改得有新意"。
- **结果**: 与搭档反复对照《奥德赛》《格列佛游记》校准结构；此剧本后文交代共改七稿。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 有一个原创故事/点子，想确认"它属于哪种类型、这类片有什么套路和铁律"。
2. 创意被批"太俗套""像某部电影"，想知道怎么在保留熟悉感的同时做出新意。
3. 想拉片研究同类作品，但不知道拉什么、看什么、拆什么。
4. 推销创意时习惯说"是《X战警》和《炮弹飞车》的结合体"，被追问"它本身是什么"答不上来。
5. 要在某个类型化项目里找"转折切入点"，避免平铺直叙。

### 语言信号 (用户的话里出现这些就应激活)

- "这故事像什么 / 最像哪部电影 / 这是什么类型 / what genre / what is it like"
- "太俗套 / 太老套 / 像剽窃 / cliché / formula"
- "给我相同的东西但要不一样 / 相同但不同 / same but different"
- "拉片 / 拆解同类片 / 参照 / study similar films"
- "屋里有怪物 / 金羊毛 / 愿望成真 / monster in the house / golden fleece"

### 与相邻 skill 的区分

- 与 `save-the-cat-logline` 的区别: 类型学定位"它最像什么、规则是什么"（横截面知识）；logline 压缩"它讲的是什么"（一句话卖点）。本 skill 要求前提已能用一句话表达，之后再做归类。
- 与 `save-the-cat-beat-sheet` 的区别: 类型学给"这个类型该有什么俗套/规则"；节拍表给"15 个节拍第几页发生什么"（纵向结构）。用户谈"像哪部片/套路"→本 skill；谈"第几页该发生什么"→节拍表。
- 与 `save-the-cat-protagonist-design` 的区别: 类型学定故事的规则与俗套位置；主角设计定"谁"来承载故事。用户谈"这算哪类故事"→本 skill；谈"主角该是谁"→主角设计。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **把前提浓缩成一句话并归类**
   - 完成标准: 先得出一句能讲清前提的话，再逐条对照十种类型，选出 1 个主类型，并能说出该类型至少 3 条核心规则（如屋里有怪物=怪物设计出色+空间封闭）。
   - 判停条件: 若一个类型都对不上，说明前提本身还含糊，先回到 logline 层面澄清"它讲的是什么"，不要硬贴类型。

2. **拉片研究同类型 3-5 部代表作**
   - 完成标准: 列出每部片的"重要剧情元素清单"、至少 2 个俗套点、每部片好/坏在哪（是"拆开再装回去"式的分析，而非背台词）；能回答"该类型的语言、节奏、目标是什么"。
   - 判停条件: 若用户连 1 部同类代表作都说不出来，先一起去查片单补课，再进入第 3 步。

3. **对每个俗套点制造"相同但不一样"的转折**
   - 完成标准: 为至少 2 个俗套点各写 1 个方案——接近俗套、绕着俗套跳、在最后关头掉转方向；每个方案都能脱离参照片独立解释你的故事（通过"它本身是什么"测试，而非"A 片+B 片"式拼贴）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户明确做反类型/实验叙事（非线性、反结构、群像无主线）: "规则先行"思路不适用——但可以反着用：先知道规则才能决定打不打破。
- 用户只是做阅片分类/资料查询（"《记忆碎片》属于哪种类型"）: 这是知识问答，不是创作规划。
- 用户的素材是私人回忆/个人表达，不以市场类型化为目标: 强套类型会扭曲素材。

### 作者在书中警告的失败模式

- 写某类型却不守该类型规则: 《小魔星》怪物弱到能踩死+小镇随时能逃，结果"四不像"——想同时讨好两个互相对立的情绪基调。
- 用"两部电影结合体"推销创意: "这个片子是《X战警》和《炮弹飞车》的结合体！"会被大家嘲笑；说不出"它本身是什么"就是没想清。
- 缺乏阅片量、拉不动自己的类型片单: 很多新人"连引用自己专攻领域内的电影都做不到"，判断"相同但不一样"的前提是手里有足够多的"相同"样本。
- 拒绝归类，声称"我的创意是全新的": 不懂规则的"创新"大概率就是平铺直叙的俗套。

### 作者的盲点 / 时代局限

- 十类型学没有覆盖 21 世纪类型演化（超英电影宇宙、真实犯罪、慢电影、游戏化叙事、网剧结构），对非西方叙事传统（武侠、物语、宝莱坞）零覆盖。
- "所有优秀影片都符合某一种类型"是以偏概全——大量群像、反结构优秀作品是反例。
- 2005 年好莱坞生态已瓦解；"结构好=能卖出去"的因果链不成立（烂结构大卖、好结构扑街的案例大量存在）。
- 例证库全部停在 2005 年之前，作者对非线性/反结构叙事有成见（"去他的《记忆碎片》！"）。

### 容易混淆的邻近方法论

- logline（`save-the-cat-logline`）: 提炼卖点 vs 归类定规则，别把类型名称当成一句话卖点。
- BS2 节拍表（`save-the-cat-beat-sheet`）: 类型规则是横截面知识，节拍表是纵向结构坐标。
- 双重魔幻/黑人兽医（`save-the-cat-laws`）: 世界观纪律（一次一个设定）与类型判断相关但不同层，别混为一谈。
