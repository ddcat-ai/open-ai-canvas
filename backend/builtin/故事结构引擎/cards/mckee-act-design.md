## I — 方法论骨架 (Interpretation)

幕是"一系列序列的组合，以一个高潮场景为顶点，导致价值的重大逆转"。幕设计不是填表格，而是管理三条动力学规律：

1. **进展纠葛靠"不归点"推进**：每次鸿沟裂开都是一个不归点，人物在此之后必须排除一切同力度、同性质的旧行动，被迫挖掘更大意志力、冒更大风险。中段疲软（"第二幕软肚子"）的元凶就是让主角重复第一幕已失败的小行动——作者令故事循环，观众在踩水。
2. **幕节奏靠正负价值交替驱动**：情感体验服从"回报递减律"——重复同一种情感第二次力度减半、第三次甚至逆转。因此上扬高潮的倒数第二幕必须是负面，低落高潮的倒数第二幕必须是正面；"不能用来铺上扬，也不能用低落铺低落"。
3. **三幕是最低要求而非公式**：长篇幅至少需要三个重大逆转才能把观众带到体验极限；可通过幕中高潮（中点重大逆转成四幕）或加幕（五到八幕）解决长第二幕问题，但幕的繁殖会招致陈词滥调与重复感——幕数、激励事件位置都由素材与世界观灵活调配。
4. **次情节只有四种合法关系**：与主情节主控思想构成矛盾（反讽）、构成回响（同主题变奏）、作为伏笔（激励事件推迟时填补真空）、为主情节制造纠葛（额外对抗源）。无关的次情节会从中间分割并毁灭故事。
5. **让观众感受到进展的四条路径**：社会进展（影响面扩大）、个人进展（向内心深入）、象征升华（意象从具体到原始模型）、反讽升华（动作与结果分裂）。场景之间还需要"第三要素"作过渡铰链。
6. **工作流是步骤大纲先行**：先用卡片做步骤大纲（每场景一两句+结构功能，毁掉90%素材），聊故事验证，再写处理台本，最后才写银幕剧本——过早写对白会窒息创造力。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《教父2》——"最好变最坏"的不可逆进展
- **问题**: 迈克尔已成为家族老大、决定引入白道（最好），故事接下来怎么保持进展纠葛、不塌中段？
- **方法论的使用**: 麦基用它示范"最好变最坏"反转法：故事应走向人类体验极限而非中间地带。迈克尔对黑手党忠诚法典的无情执行，导致心腹被刺、妻儿疏远、兄弟被谋杀——每一个决定都越过一个不归点，旧的选择被永久排除。
- **结论**: 进展纠葛不是随机磨难，而是价值不断向更负的方向不可逆转地摆荡；每次鸿沟裂开都让"回到从前"成为不可能。
- **结果**: 迈克尔在第二部结尾成为晚景凄凉的孤家寡人，达成绝对而不可逆转的变化。

### 案例 2: 《卡萨布兰卡》——次情节的"伏笔"关系
- **问题**: 主情节激励事件（伊尔莎出现）迟到第32分钟，开场半小时如何保持观众兴趣？
- **方法论的使用**: 麦基用它示范"伏笔式次情节"：此前用不少于五个节奏紧凑的次情节激励事件（拉兹洛、乌加特、伊冯娜、保加利亚妻子、难民们）勾住观众，填补主情节激励事件缺席的真空。
- **结论**: 当主情节激励事件必须推迟时，次情节以"伏笔"关系开始故事的讲述；延迟有策略、有补偿，而非空转。
- **结果**: 迟到的激励事件成就了银幕上最伟大的爱情故事之一。

### 案例 3: 《终结者》——假结尾与幕节奏正负交替
- **问题**: 倒数第二幕高潮如何设计才能保证最后一幕不泄劲？
- **方法论的使用**: 麦基用它示范"假结尾"：里斯和莎拉炸掉终结者、情人庆贺胜利（上扬的假结尾），铬内壳却从火焰中站起——用上扬铺上一个上扬，冲击力不但不衰减反而倍增。
- **结论**: 双重假结尾步步升级，末段张力持续高能；但假结尾对大多数影片不合时宜——倒数第二幕高潮通常应强化"时至此刻还会发生什么"。
- **结果**: 直到莎拉将终结者彻底毁灭，影片保持高能到最后一刻。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写到长片/长篇的中段，感觉"第二幕注水、节奏拖沓、观众会看表"。
2. 在规划幕结构，纠结"三幕够不够、要不要加幕、要不要设中点转折"。
3. 设计次情节/支线，不确定要不要加、加几条、和主线什么关系。
4. 想让故事越到后面越紧张，但不知道如何升级对抗与风险。
5. 想判断现有剧本的中段疲软是不是因为重复了第一幕的行动。

### 语言信号 (用户的话里出现这些就应激活)

- "中段疲软 / 第二幕注水 / 节奏拖沓" / "sagging middle", "second act problem", "pacing"
- "三幕够吗 / 要不要加幕 / 幕结构怎么排" / "act structure", "three-act", "act break"
- "次情节 / 支线剧情怎么设计" / "subplot", "B story"
- "进展不够 / 主角老用同一招" / "rising action", "escalation", "point of no return"
- "怎么让结尾更有冲击力（幕高潮层面）" / "act climax", "act 2 climax"

### 与相邻 skill 的区分

- 与 `mckee-turning-points` 的区别: 转折点是"单场景内的价值转向"，本 skill 管"多个场景组成幕的宏观节奏与价值配比"。
- 与 `mckee-scene-analysis` 的区别: 场景分析是"单场景显微镜"，本 skill 是"整片骨骼"。
- 与 `mckee-inciting-incident` 的区别: 激励事件解决"故事从哪打破平衡开始"，本 skill 解决"打破之后如何一路升级到危机"。
- 与 `mckee-crisis-climax` 的区别: 后者聚焦末段"危机→高潮→结局"三件套；本 skill 覆盖全片所有幕的节奏与次情节管理。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **盘点现有幕结构，标注每幕高潮的价值负荷**
   - 完成标准: 能列出每一幕的高潮场景，并用"正/负"标注其价值方向；能指出激励事件在哪一幕、总共有几个重大逆转。
   - 判停条件: 若用户作品不足三个重大逆转（只有"坏→好"两个），标注"幕数不足"进入步骤 2。

2. **做"不归点"体检，找出重复的轻量级行动**
   - 完成标准: 逐幕检查主角的行动，标出任何"与第一幕同力度、同性质"的旧行动；对每个中段场景能说出它比前一幕新在哪、风险如何升级。
   - 判停条件: 若第二幕行动力度与第一幕相似（重复），标记为"中段疲软元凶"，返回设计者要求重写或删除；若全片进展正常，进入步骤 3。

3. **检验幕节奏与次情节关系，产出修改方案**
   - 完成标准: 相邻两幕高潮价值负荷相反（正/负交替）；每个次情节都能归入矛盾/回响/伏笔/纠葛四关系之一，无孤悬支线；给出"加幕/删次情节/调整幕高潮位置"的具体方案，并按"步骤大纲→聊故事→处理台本"的工作流建议落地顺序。
   - 判停条件: 若幕数多于五幕且次情节超过两条，检查是否已滑向"生死、生死"式重复（回报递减），如有则建议压缩幕数。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 只关心单个场景内部的转折或潜文本——那是 `mckee-turning-points` / `mckee-scene-analysis`。
- 短篇/短片/单场景戏——幕设计针对长篇幅（故事片、一小时剧集、长篇、戏剧）；短片不需要三幕节奏。
- 反情节/静观型作品（非线性、非冲突本位、以意象静观为主）——幕的"正负价值交替"假设了冲突驱动的时间观，对《周末》这类反情节或东方静观叙事不适用。
- 用户问的是激励事件本身怎么设计——用 `mckee-inciting-incident`。

### 作者在书中警告的失败模式

- 第二幕中段疲软（ce12）：作者让故事走上倒退之路，在第二幕中间给人物设计第一幕已尝试过的微小行动，观众在"踩水"。
- 幕高潮繁殖招致陈词滥调（ce13）：强行发明五到九个"辉煌场景"，最后靠"生与死、生与死"重复七八次充数，厌倦油然而生。
- 次情节与主情节毫无关联（ce14）：次情节自顾自往前跑，会从中间分割并毁灭故事效果（《第一死罪》把追凶与病妻两条线剪开，观众陷入迷惑）。
- 连续重复同一种情感（ce16）：三个悲剧场景第三个会让观众发笑——回报递减律的极端惩罚。

### 作者的盲点 / 时代局限

- "冲突是常量、无冲突则无进展"基于匮乏/时间哲学，对静观、无为、合一传统的叙事不成立——幕节奏的"必须正负交替"在那些传统中是断言而非普适律。
- "三幕是最低要求"是规范性理想；剧集单集结构（每集自带微幕）与整季结构的关系，书未系统处理。

### 容易混淆的邻近方法论

- `mckee-crisis-climax`：末段"危机-高潮-结局"链——那是最后二十分钟的收束，本 skill 是全程幕节奏。
- `mckee-story-triangle`：三角定位决定你用大/小/反情节，而本 skill 在既定定位内做幕设计。
