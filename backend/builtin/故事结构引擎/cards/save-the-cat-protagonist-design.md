## I — 方法论骨架 (Interpretation)

主角不是先喜欢上某个角色再找故事，而是反过来：前提定了之后，为它**配**一个能把故事价值放大的主角。配主角有三把尺子：

1. **引发最强烈的冲突**——主角身份与情境反差越大越好：谨小慎微的老师闯进警察的硬汉世界，比退役特种兵更有效；
2. **情感路最遥远、最曲折**——起点和终点离得越远，故事越足，主角必须从"一个极端"走到"另一个极端"；
3. **讨绝大多数人的喜欢**——盯住大众市场而不是自己的趣味，警惕自己的年龄与审美盲点。

第二套校验是**原始驱动力**：把主角的目标翻译回生存、饥饿、性、保护所爱之人、对死亡的恐惧五类本能之一。检验句是"穴居人能不能听懂"——越是具体的身份标签（股票经纪人、程序员），越要还原成"努力活着的人"这种普世欲望；目标关系优先选父女/母子/夫妻，因为这些称呼自带原始反应。

第三套纪律是**选角**：不要为特定明星写角色——你不知道演员想演什么，还会把自己逼进选角死胡同；要按"演员类型/角色原型"写（奋斗的小伙子、春心萌动的好姑娘、性感女神、迷人男神……），让一批演员都能扛起这个角色。为创意写"可被填充的容器"，而不是"指名道姓的对象"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《三年级》——为创意配最合适的主角
- **问题**: 前提"一个成年男子必须回去重念三年级"很好，但主角该是谁才最有戏？
- **方法论的使用**: 用三要素追问：什么主角能引发最强喜剧冲突、走最曲折的路、得最深刻的教训？答案是"事业有成但还没长大的人"——表面即将升迁、实际上不懂做人基本准则（给儿童设计暴力电子游戏的设计师，本身就很讽刺）。
- **结论**: "谁"要为"讲的是什么"服务——为创意配最合适的主角，而不是反过来。
- **结果**: 剧本卖给环球影业。

### 案例 2: 去掉原始性实验——《四个圣诞节》与《度假》
- **问题**: 要证明原始驱动力（性、死亡威胁）是观众注意力的前提，而不是可有可无的调味料。
- **方法论的使用**: 变量剔除实验：把《四个圣诞节》的两个主角从夫妻改成朋友→去掉性→"危机消失了，没有什么东西岌岌可危了"；把《度假》的谋杀去掉→"这就只是一部关于企业培训的电影"。
- **结论**: 主角的目标必须够原始，否则观众不感兴趣；"够不够原始"是检验故事和角色的点金石。
- **结果**: 该实验成为可复用的校验器，用于评估主角、次要角色与整条副线。

### 案例 3: 《废鹰坠落》——把自己逼进选角死胡同
- **问题**: 剧本前提好、剧情好笑、片名好（"美国总统乘坐直升机坠毁在敌人后方，还得孤身抓本·拉登"），却卖不出去。
- **方法论的使用**: 作者复盘发现，主角是"总统"，只有两个演员扛得起这个角色——可演范围被收窄到 1-2 人。
- **结论**: 不要为特定演员/特定身份写角色，要按"演员类型"写、留足选角空间。
- **结果**: 剧本至今躺在角落无人问津，成为"没有遵守选角纪律"的反面教训。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 有一个故事前提，但不确定主角该是谁、什么身份/年龄/性格最出戏。
2. 主角被批"太平淡""不可爱""没有成长"，想定位是主角选错还是写法问题。
3. 主角目标很抽象（"证明自己""事业成功""复仇"），想让它更有抓力、更原始。
4. 写主角时脑子里始终浮现某位明星，或想"为某人量身打造"，想评估风险。
5. 写群像/传记/动画，想问"这到底是谁的故事"。

### 语言信号 (用户的话里出现这些就应激活)

- "主角该是谁 / 换个人当主角会怎样 / 谁适合当主角 / who is the protagonist"
- "主角太平淡 / 不讨喜 / 不可爱 / 没有成长空间 / likable / relatable"
- "主角目标太抽象 / 动机太弱 / 够不够原始 / primal / motivation"
- "为某人量身打造 / 按某明星写 / casting / who plays"
- "这是谁的故事 / 谁的转变最重要 / whose story"

### 与相邻 skill 的区分

- 与 `save-the-cat-logline` 的区别: logline 压缩"故事讲什么"（前提与卖点）；主角设计在前提已能用一句话表达之后决定"谁"来承载它。反过来，主角设计也要求用形容词强化 logline 里的主角与反派——重叠处靠"用户问的是故事还是人"来判断。
- 与 `save-the-cat-genre-ten-types` 的区别: 类型学定"这是哪类故事、规则在哪"；主角设计定"谁来做主角"。用户谈"这算什么类型/像哪部片"→类型 skill；谈"主角该是谁/怎么设计"→本 skill。
- 与 `save-the-cat-diagnosis` 的区别: 本 skill 在动笔前设计主角；诊断 9 问在初稿后体检主角（被动/口述剧情/起点太高）。用户谈"初稿主角不对劲"→诊断 skill；谈"动笔前主角怎么设计"→本 skill。
- 与 `save-the-cat-laws` 的区别: 救猫咪法则管"主角出场如何讨喜"这一个瞬间；本 skill 管主角整体设计的三要素与原始动机。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **做"换主角"思想实验**
   - 完成标准: 为同一前提列出 3 个候选主角（不同身份/年龄/性格），逐个评估冲突强度、情感路远近、讨喜度，选出 1 个"三要素"最优者，并说明每个淘汰候选的理由（如《佐州自救兄弟》把老师换成特种兵故事就毁了）。
   - 判停条件: 若替换任何候选主角后故事都没有变化，说明冲突不来自主角身份，先回 logline 层检查前提是否真的成立。

2. **原始动机校验**
   - 完成标准: 把主角目标翻译回生存/饥饿/性/保护所爱/怕死之一；做"去掉它"思想实验——去掉该动机后，剧情明显失去风险（参考《四个圣诞节》去掉性→危机消失）。
   - 判停条件: 若去掉后故事仍成立、风险仍在，说明目标不够原始，回到第 1 步换主角或回 logline 改前提。

3. **选角兼容性检查**
   - 完成标准: 用"演员类型/角色原型"（而非明星脸）描述主角，例如"奋斗的小伙子、春心萌动的好姑娘、迷人男神"；列出至少 3 位能扛起该类型的假想人选。
   - 判停条件: 若只能列出 1-2 人，说明角色被写窄了（如《废鹰坠落》的总统），需放宽为原型化描述、给选角留足空间。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户做的是作者电影/艺术片/实验叙事: "讨绝大多数人的喜欢"本身就不是目标，三把尺子不适用。
- 用户已进入初稿后阶段、问题定位在具体情节/对白/结构: 那是诊断 skill 或节拍表 skill 的职责。
- 用户写传记/真实人物且明确不按商业化改编走: 三要素中的"讨喜"与"按类型写"会与史实约束冲突。

### 作者在书中警告的失败模式

- 为特定演员写角色: "不要坚信你写的角色一定会由某个演员来演——你通常都会失望的。"《废鹰坠落》只剩两个演员能演总统，卖不掉。
- 错误的角色设定毁掉好创意: 把《佐州自救兄弟》的老师换成退役特种兵、把警察改成胆小如鼠的巴尼·费夫，故事立刻变平庸。
- 缺乏原始驱动力: 去掉《四个圣诞节》的夫妻关系（性）→危机消失；去掉《度假》的死亡威胁→只剩企业培训。"淘汰！"
- 为具体明星/小众趣味量身打造: 曾有人推销"为胡里奥·伊格莱希亚斯量身打造"的杰作——"会有人去看这部影片的首映吗？我很怀疑。"

### 作者的盲点 / 时代局限

- 生物学化约论: 把人类动机还原为生存、性、繁衍，抹掉阶级、政治、文化、性别等社会性动机；"穴居人测试"声称的"普世性"实为美式中产白人视角的普世性。
- 彻底商业化立场: "讨绝大多数人喜欢"把好主角窄化为主流商业片主角，系统性排除反英雄、灰色人物的艺术价值。
- 例证几乎全是美国家庭喜剧、警匪、爱情喜剧，缺乏跨文化的主角类型样本。

### 容易混淆的邻近方法论

- 救猫咪（`save-the-cat-laws`）: 主角出场时"讨喜的瞬间" vs 主角整体三要素设计——一个是开场存款，一个是全程设计。
- 诊断 9 问（`save-the-cat-diagnosis`）: 初稿后体检主角 vs 动笔前设计主角，时机不同。
- 六大缺憾（`save-the-cat-deficiencies`）: 主角缺陷的埋雷—引爆—治愈 vs 三要素选人——前者是缺陷机制，后者是选谁。
