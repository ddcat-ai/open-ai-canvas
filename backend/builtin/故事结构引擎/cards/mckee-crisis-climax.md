## I — 方法论骨架 (Interpretation)

故事末段是一条"危机→高潮→结局"三件套，各有明确职责，不能互相替代：

1. **危机 = 终极两难之择**（危险+机会），是观众从激励事件起就一直在等的"必备场景"。它必须被看见：是有意的静态时刻，让观众与主人公一起被两难压住；一旦主角做出选择，被压抑的能量才爆成高潮。
2. **高潮 = 价值在最大负荷处"绝对而不可逆转"的摇摆**，是意义与情感的顶点（"意生情"——意义先于一切）。它须"不可避免而又出乎意料"：回头看是唯一路径，向前看猜不到方式。
3. **结局 = 回报递减的收束**：给次情节收尾、展示高潮余波、礼貌送观众离场。绝不能再制造一次高潮——连续重复同一种情感，力度减半甚至逆转成喜剧。
4. **工作方法是从尾到头逆向工作**：先让高潮的想法跳入想象，再为它倒推因果支撑，剪掉任何不影响结局冲击力的场景。
5. **"最后二十分钟 / 汝必留最佳于最后"**：无论前面写得如何，最后一幕失败影片就死；把最大的创造能量留给结局。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《卡萨布兰卡》第三幕——里克的无私危机决定
- **问题**: 里克追求伊尔莎直到她"就范"，第三幕该往哪走？
- **方法论的使用**: 麦基用它示范"危机=不可调和的两善之择"：留住伊尔莎（满足自觉欲望）还是把她还给拉兹洛（成全更大的正义）。这是两善取其一，不是善恶是非，两个选项价值同等分量。
- **结论**: 危机决定是对人物本性的终极表达，与自觉欲望逆反；由此爆发的高潮是"长达十五分钟的高潮动作"。
- **结果**: 里克一举解决爱情主情节与政治次情节，把雷诺上尉转变为爱国志士并杀死斯特拉瑟，重返战场。

### 案例 2: 《贪婪》——沙漠中的基调形象
- **问题**: 结局如何"不可避免而又出乎意料"地收束全部意义与情感？
- **方法论的使用**: 高潮之后用一个"基调形象"——迈克提格在沙漠上倒下，与他刚杀死的尸体铐在一起——以单一画面总结全部意义与情感。
- **结论**: 观众一回忆这个画面，整部影片就浮现；基调形象是结局收束的终极手段。
- **结果**: 该画面成为电影史上最著名的基调形象之一，令《贪婪》的结尾永载影史。

### 案例 3: 《教父2》——"最好变最坏"的绝对逆转
- **问题**: 高潮怎样才算"绝对而不可逆转"？
- **方法论的使用**: 麦基用它示范高潮的价值负荷：迈克尔成为柯里昂家族老大、决定把家族引入白道（最好），却因对黑手党忠诚法典的无情执行而众叛亲离、兄弟被谋杀、晚景凄凉（最坏）。
- **结论**: 高潮是价值最大负荷处不可逆转的摇摆，把生活带到无法回头的状态。
- **结果**: 迈克尔在第二部结尾成为晚景凄凉的孤家寡人，达成绝对而不可逆转的变化。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写第三幕/大结局，感觉"结尾没力、观众看完没感觉"。
2. 设计主人公最后的"终极两难之择"，担心不够有分量。
3. 结局写完觉得"收不住""狗尾续貂"，想用基调形象收束。
4. 想让结局"既出人意料又合情合理"。
5. 从结尾倒推全片结构，检查每个场景是否都为高潮服务。

### 语言信号 (用户的话里出现这些就应激活)

- "结局怎么写才有力" / "ending feels weak" / "how to end my story"
- "高潮" / "climax"
- "危机场景 / 终极选择 / 必备场景" / "crisis", "final dilemma", "obligatory scene"
- "结尾太突兀 / 结尾平了" / "ending is flat"
- "最后二十分钟" / "last 20 minutes"

### 与相邻 skill 的区分

- 与 `mckee-inciting-incident` 的区别: 激励事件在开头打破平衡、送人上路；本 skill 管末段"危机→高潮→结局"收束链。
- 与 `mckee-act-design` 的区别: 后者管整片幕节奏（正负价值交替、不归点）；本 skill 只聚焦最后一幕的高潮设计。
- 与 `mckee-turning-points` 的区别: 后者是单场景价值转折与伏笔分晓；本 skill 是整条末段结构链。
- 与 `mckee-controlling-idea` 的区别: 主控思想是"价值+原因"的主题句；本 skill 用高潮动作去证明它。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定位危机（必备场景）**
   - 完成标准: 能用"A 在 B 和 C 之间必须二选一"写出两难之择，且 B/C 是同等分量的两善或两恶（不是善恶是非）；它发生在画内、是有意的静态时刻，观众能看见主人公被两难压住。
   - 判停条件: 若主角的选择其实是"做好事还是坏事"（可预测、无意义），则回到设计，重新制造同等分量的价值冲突；若根本没有两难只有困境，先造两难再继续。

2. **设计高潮**
   - 完成标准: 开篇价值与结尾价值能画出"电影弧光"（不可逆的变化）；符合"不可避免而又出乎意料"——回溯看是唯一路径、前瞻猜不到；能用一句话说出这个高潮证明了什么（意生情）。
   - 判停条件: 若高潮靠巧合、外力或意外死亡解决，则删掉重写，改为"人物选择的直接结果"。

3. **收束结局并从尾到头校验**
   - 完成标准: 结局不再出现第二次高潮（回报递减律）；每个前置场景都能说出它如何为高潮供能；存在一个总结全部意义与情感的"基调形象"画面。
   - 判停条件: 若结局还想再拉一次大场面，则降格为余波或删除；若某个场景剪掉后不影响结局冲击力，则剪掉它。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 小情节/反情节/静观型作品没有完整的"危机-高潮-结局"链（麦基自己也承认《蜘蛛女之吻》等"明智的例外"）——不要硬套三件套。
- 用户只是想让某个场景"反转一下"——那是 `mckee-turning-points` 的领域。
- 用户问的是激励事件、开头太平——用 `mckee-inciting-incident`。
- 面对的是剧集/长剧，单集没有"最后二十分钟"的影院概念——需按季/集重校准收束节奏。

### 作者在书中警告的失败模式

- 用巧合转折结局（"来自机器的神仙"，ce25）：高潮靠天降巧合解决，抹杀一切意义与情感，是对观众的侮辱。
- 连续重复同一种情感（回报递减律，ce16）：结局再拉一次与高潮同负荷的大场面，力度减半甚至让观众发笑。
- 中段疲软（ce12）：第二幕让主角重复第一幕已失败的轻量级行动，导致高潮缺乏升级动力。

### 作者的盲点 / 时代局限

- "必须/绝对"类断言（危机必须留画内、高潮必须不可逆转）在经典设计语境下通常有效；对东方静观叙事、开放结局传统应降级为"通常有效"。
- 观众观过于统一化："观众只需情感满足"假设忽略了不同文化、媒介素养群体对"出人意料"的耐受度差异。

### 容易混淆的邻近方法论

- `mckee-act-design`：幕节奏正负交替——那是整片节奏，本 skill 聚焦末段三件套。
- `mckee-turning-points`：转折点四重效果——那是单场景层面，本 skill 是末段结构链。
