## I — 方法论骨架 (Interpretation)

- 故事世界不是背景板，而是主角弱点与转变的"客观对应物"：奴役人的世界要凸显、放大主角的弱点，自由的世界要呈现其成长；世界必须与主角的弧线同步变化。
- 世界由四元素构成：场域、自然环境、人造空间、科技（以及时间）；元素失衡=奴役，平衡=自由。
- 保持"单一场域"是硬规则：一旦打破，戏剧必然溃散。场域四法——①大型综合体然后横断浓缩 ②单线旅程（同一地区单一线程）③圆形旅程（回到原点、以起点为终点）④离水之鱼（带独特才能跳入另一世界）。
- 视觉对立从角色的价值对立衍生：把角色间的价值冲突翻译成空间的视觉对比（如《日落大道》狭小公寓 vs 哥特大宅、阳光 vs 黑暗）。
- 视觉七大步骤：给七大结构步骤各配一个专属的子故事世界——弱点=恐惧的体现、欲望=目标所在世界、对手=其力量巢穴、看似落败/体验死亡=最逼仄空间、对决=整个故事最封闭处、结局=自由或奴役的落脚地。
- 对决是"故事的漏斗尖"，应发生在最逼仄的空间（压力锅效应）；看似落败的世界通常也是故事到此最窄的一处。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《星球大战》——视觉七大步骤
- **问题**: 一部覆盖宇宙的史诗如何在视觉上不散乱，并让世界随主角转变而转变？
- **方法论的使用**: 特鲁比用"视觉七大步骤"拆解：弱点/欲望=杳无人烟的荒野；对手=死星；看似落败/体验死亡=塌陷中的垃圾场与水底怪兽；对决=堑壕——卢卡斯知道最出色的对决应在尽可能狭小的空间里发生，让卢克潜入狭长堑壕，在尽头那小小的一点开火；自由=英雄殿堂。
- **结论**: 每个结构步骤配一个专属子故事世界，对决落在全片最逼仄处。
- **结果**: 整部电影"在视觉和结构上都如穿越漏斗般抵达单一的一点"，成为视觉七大步骤的完整范例。

### 案例 2: 《唐人街》——洛杉矶作为欲望的物理化身
- **问题**: 侦探片的洛杉矶通常只是追逐戏的"背景"，世界与主角的欲望毫无联结。
- **方法论的使用**: 把洛杉矶重构为杰克欲望与失败的客观对应物——水与土地（欲望对象）的阴谋、克罗斯的权势网络（对手力量巢穴）、唐人街（看似落败/无法掌控之地）；环境的每处细节都按主角的弱点与对手的巢穴来设计。
- **结论**: 世界通过地、人、科技、时间四元素与主角的欲望/弱点对齐，而不是装饰。
- **结果**: 城市成为"主角欲望的物理呈现"，侦探故事获得超越案件的道德深度。

### 案例 3: 《汉娜姐妹》——感恩节作为循环标尺
- **问题**: 如何让时间与仪式成为丈量角色转变的标尺？
- **方法论的使用**: 伍迪·艾伦用三次感恩节做循环标尺：开头的错配（伴侣不是对的人）、中段的仍非对的人、结尾的成双成对；作者不谈论感恩节，而是让角色"经历了这个节日"，用节日本身的价值体系（感恩、群体）强化主题。
- **结论**: 仪式/节日是"世界的时间元素"，可与结构步骤联结成可重复的视觉单位。
- **结果**: 故事与节日融为一体，三姐妹的感情转变被同一仪式的三次重现清晰丈量。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设定写了一大堆，但读者/观众觉得"换一个背景故事也照样成立"——环境与主角毫无关系。
2. 故事发生在几十个互不相关的场所，读起来散乱、缺乏整体感。
3. 想知道对决、看似落败、体验死亡这些关键时刻该放在什么样的空间里才最有张力。
4. 想让环境跟着主角一起"变好/变坏"，呈现成长或堕落。
5. 世界观考据本身做得很多（地图/年表/族谱），却不知道怎么让它们服务于角色。

### 语言信号 (用户的话里出现这些就应激活)

- "背景设定很平 / 像个舞台布景 / 世界没性格" — "the setting is flat / just a backdrop"
- "环境怎么反映主角 / 世界是主角的什么" — "make the world reflect the hero"
- "故事发生在太多地方，太散了 / 怎么保持整体感" — "too many locations / keep it unified / single arena"
- "对决应该放在什么地方 / 最逼仄的空间" — "where should the showdown take place / confined space"
- "世界怎么跟着主角一起转变" — "world should mirror the hero's change"

### 与相邻 skill 的区分

- 与 `story-character-network` 的区别: 后者塑造人（角色网络/四角对立），本 skill 塑造空间；但视觉对立区要从角色的价值对立衍生，二者在"对立"处交汇。
- 与 `story-symbol-network` 的区别: 故事世界是主角的物理呈现（空间本身承担结构功能），象征网络是意义的浓缩（物件/人物指向其他物件/人物）；世界负责"主角被环境奴役或解放"，象征负责"意义在表层下流动"。讨论环境描写/空间结构 → 本 skill；讨论意象/隐喻网络 → 象征 skill。
- 与 `story-plot-22-steps` 的区别: 后者管"信息何时揭示"（时间序列），本 skill 管"事件发生在什么样的空间"（空间结构）；视觉七大步骤是把二者缝起来的接口。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确立主角的弱点与转变弧线（奴役→自由的坐标）**
   - 完成标准: 写出一句"主角从 X（受奴役/缺陷）走向 Y（自由/成长或更深的奴役）"的弧线；能回答"奴役人的世界如何凸显、放大主角的重大弱点"。
   - 判停条件: 若作品没有单一主角（群像/纪实/散点叙事），本 skill 的核心前提失效，跳到 B 段，改用场景层面的环境设计，不强行套"客观对应物"。

2. **用场域四法之一确立单一场域，并划分视觉对立区**
   - 完成标准: 选定一种场域法（大型综合体横断浓缩 / 单线旅程 / 圆形旅程 / 离水之鱼）；写出统一场域及其"墙"（场域外的东西不属于故事）；列出至少一对从角色价值对立衍生的视觉对立（空间/自然/人造物/科技）。
   - 判停条件: 若清点后发现互不联结的空间超过三个且无法归并，说明场域破裂，回到本步重选场域法。

3. **为七大结构步骤各配一个子故事世界，把对决/看似落败放到最逼仄空间**
   - 完成标准: 七大结构步骤（弱点/需求→欲望→对手→计划→对决→真实自我揭露→新平衡点）各有专属视觉地点；对决与看似落败落在空间上的"最窄点"（漏斗/压力锅效应）；写出一句"世界如何随主角的转变而变化"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯地理/历史/世界观考据：读者要的是资料准确，不是"世界反映主角"，套用会显得刻意。
- 无叙事目标的场景白描/氛围描写练习：没有主角弧线，就没有"客观对应物"可言。
- 多主角群像或散点纪实叙事：没有单一主角作为镜像的轴心，"世界=主角的物理呈现"无法建立。
- 极简主义舞台剧/单一房间剧：场域天然统一，本 skill 的"保持单一场域"等规则是冗余的。

### 作者在书中警告的失败模式

- ce18 "随意或俗套地选择故事的自然环境"——环境靠巧合或"要自我揭露就送上山顶"的情绪标配来硬配，世界与主角毫无联结，白白浪费浓缩/扩展力量。
- ce25（部分）"第一页就告诉观众主角的一切"——开场把世界观说明一次性倒完，信息过载把观众推离故事；世界应随情节逐步展开。
- p24 的背面：打破单一场域，戏剧必然溃散——太多场域让故事散乱且缺乏活力。

### 作者的盲点 / 时代局限

- 世界=客观对应物以"单个主角 + 个人转变弧"的好莱坞情节剧为前提（BOOK_OVERVIEW 批判 #1/#8）；对群像本位、非个人主义叙事、以"无变化"为核心的美学（契诃夫式）没有方法论供应。
- 书中引用的例子全部早于 2000 年（批判 #7），"场景=一个时间一个地点"的定义对游戏、互动叙事、虚拟世界等多场景媒介偏旧。
- 对"环境本身作为叙事主角"（如自然灾害、都市蔓延类作品）没有覆盖——那已超出"主角的对应物"框架。

### 容易混淆的邻近方法论

- 与"象征网络"的混淆: 世界是物理呈现、空间承担结构功能（对决在逼仄处）；象征是意义浓缩、靠"指引与重现"流动。同一个物件（如《教父》的"魔鬼"）既是世界元素也可以是象征——按它承担的功能区分。
- 与"场景编排"（story-scene-structure）的混淆: 后者排的是"事件在故事中的先后顺序"，本 skill 排的是"事件在空间中的分布"；视觉七大步骤是两者的接口。
