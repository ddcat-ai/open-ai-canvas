## I — 方法论骨架 (Interpretation)

这套工具箱由书名级法则"救猫咪"和五条配套纪律组成，它们把"观众为什么不投入 / 为什么出戏"翻译成六个可以逐一检查的创作动作，本质是写作中而非写作后的纪律检查表：

1. **救猫咪**：主角登场时做一件让观众喜欢上他、希望他赢的小事；附加要求是让观众从第一场戏就理解主角的处境（反英雄靠搞笑幼稚、小偷分面包给更饿的孩子都算）。
2. **泳池里的教皇**：交代枯燥背景（作案计划、人物前史）时，同时给一个视觉奇观或喜剧看点，让观众的注意力被奇观吸走，信息就悄悄吞下去了。
3. **双重魔幻 + 黑人兽医**：一部电影只能有一个超自然设定，一次只用一个概念；每多一个非现实前提就多透支一层观众的信任，堆概念等于糖太多会齁死人。
4. **小心冰川**：威胁若以"一年前进一英寸"的慢速逼近就不再可怕；危险必须是正在发生的、落在我们关心之人身上的、后果从开头就被看见的危险。
5. **人物弧光**：每个角色都要在故事中转变，唯一不变的是拒绝改变的坏人；衡量成败的标准就是"谁愿意改变"。
6. **别让媒体掺和**：媒体代表外部世界现实的确认，一旦新闻报道闯入，假定的现实情境就被打破、魔法失效；秘密要控制在"我们观众"内部。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《午夜惊情》的"救猫咪"开场（书名的由来）
- **问题**: 阿尔·帕西诺演的警察要执行诱捕行动，主角是个硬汉，观众凭什么愿意跟他走？
- **方法论的使用**: 作者把这个场景立为"救猫咪"的教科书：警察放走了带着年幼孩子的犯人父亲，还丢下一句酷台词"回头再抓你……"——用几秒钟的小动作定义他是谁。
- **结论**: 观众不需要被说服去喜欢一个"酷"的人，只需要看到他做一件有人情味的小事。
- **结果**: 书名直接取自这个桥段；"我不知道你怎么想，反正我喜欢上他了。现在无论他带着我往哪儿走我都愿意去。"

### 案例 2: 《偷油》：用"喝冰茶比赛"藏住信息交代
- **问题**: 两个蠢笨水管工卷入偷油案，坏人在会上要交代一大段作案计划，直接讲出来必然枯燥毁戏。
- **方法论的使用**: 作者应用"泳池里的教皇"——会面前安排主角们喝冰茶比赛憋尿，开会时窗外洒水车、狗撒尿、女孩倒冰茶不断刺激，笑料与信息交代同步进行。
- **结论**: 观众忙着被逗笑，枯燥的背景就被"盖"过去了；信息交代完成且非常好笑。
- **结果**: 剧本卖给迪士尼；作者称这是他"引以为傲"的一场戏。

### 案例 3: 《天崩地裂》的火山：小心冰川！
- **问题**: 整部影片的故事就是"火山随时可能爆发！仅此而已"——没有人相信科学家，观众干等一个半小时。
- **方法论的使用**: 作者用"小心冰川"法则诊断：威胁以慢速、遥远、抽象的方式逼近，风险没有落在我们关心的人身上、后果没有从开头展现在眼前，威胁感就被消解了。
- **结论**: "知道危险即将到来"不等于紧张；危险必须是进行时的。
- **结果**: 与《极度恐慌》《天地无限》一起被列为"冰川式威胁"的反面教材。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户说"我的主角一出场观众就不喜欢 / 主角太招人恨"或"我怎么让读者喜欢上这个坏人主角"——需要救猫咪存款。
2. 用户说"开头要交代好多背景设定，特别枯燥"或"世界观说明怎么塞进故事"——需要泳池里的教皇。
3. 用户说"我的故事里有两个超自然设定行不行"或"主角身份叠加太多设定"——需要双重魔幻 + 黑人兽医。
4. 用户说"我的反派/威胁不够吓人，大家不紧张"或"灾难说了很久都没发生"——需要小心冰川。
5. 用户说"角色都没有成长 / 故事很平"或"除了主角别人都没变化"——需要人物弧光检查。
6. 用户写奇幻/秘密类故事，想用"新闻报道、网友围观、外界曝光"交代事件——需要别让媒体掺和。

### 语言信号 (用户的话里出现这些就应激活)

- "让观众喜欢上主角" / "make the audience like the hero"
- "怎么交代背景不枯燥" / "how to deliver exposition naturally"
- "几个魔幻设定 / 多个超能力来源" / "too many magic systems"
- "威胁不够有紧迫感" / "the threat feels distant, not urgent"
- "角色没有成长 / 弧光" / "character arc"
- "别让媒体掺和 / 外界围观" / "keep the press out"

### 与相邻 skill 的区分

- 与 `save-the-cat-diagnosis` 的区别: 本 skill 是**写作中的预防性纪律**（写之前/写之中逐条核对），diagnosis 是**初稿完成后的体检清单**（写完再逐问打勾）；本 skill 回答"怎么写才对"，diagnosis 回答"写完哪里错了、怎么改"。
- 与 `save-the-cat-beat-sheet` 的区别: beat-sheet 管结构骨架（15 个带页码的节拍），本 skill 管观众心理与世界观纪律（好感、信息、设定、威胁、弧光、世界封闭性），二者可以叠加使用。
- 与 `save-the-cat-protagonist-design` 的区别: protagonist-design 管主角的"三要素 + 原始动机 + 按类型写"的整体设计，本 skill 的"救猫咪"只管"开场让观众喜欢并理解主角"这一个具体动作。
- 与 `save-the-cat-genre-ten-types` 的区别: genre 管"这个创意属于哪一类型、规则和俗套在哪"，本 skill 的"双重魔幻/黑人兽医"管"世界观设定别贪多"这一条纪律。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **诊断症状 → 映射到对应法则**
   - 先问用户问题的具体表现（不喜欢主角 / 背景枯燥 / 设定太乱 / 威胁不吓人 / 角色没成长 / 外界掺和），把症状归到六条法则之一或几条的管辖范围。
   - 完成标准: 能明确说出"这属于 X 法则的管辖范围"，并引用该法则的原始定义一句话。
   - 判停条件: 若用户说的是"初稿写完了、整体感觉不对劲"而非具体症状，跳到 `save-the-cat-diagnosis`（9 问体检），本 skill 不接管。

2. **按法则逐条核对当前稿件，找出违规点**
   - 把用户提供的段落/大纲逐条对照相关法则：主角开场有没有"存款"动作？背景交代有没有视觉/喜剧掩盖？设定是几个魔幻元素？威胁是进行时还是慢速预告？每个角色有没有净变化？世界有没有被外部现实闯入？
   - 完成标准: 列出"违反的法则 × 违规位置 × 为什么违规"的清单，至少一条，每条有具体证据（引用用户原文或场景描述）。
   - 判停条件: 若用户还处于概念期（只有一句话创意、没有段落/大纲），则只在概念层面检查双重魔幻、黑人兽医、别让媒体掺和三条世界设定纪律，其余法则留到有内容后再查。

3. **给出每条违规的修法并落实到动作**
   - 每条违规至少给一个可落地的修改动作（例：加一个"把面包分给更饿的孩子"式的场景；把火山改成第一幕就烧到主角家；删掉第二套能力来源）。修法之间不得互相冲突（例如加救猫咪场景时不要顺手引入第二个魔幻设定）。
   - 完成标准: 每个违规点有明确修改动作 + 修改后与其他法则自洽的说明；最终给用户一个"改前 vs 改后"对照。
   - 判停条件: 若用户的核心诉求其实是要重搭结构（"第三幕空了""整体塌方"），提醒切换到 `save-the-cat-beat-sheet` 或 `save-the-cat-board`，本 skill 只做单点纪律修补。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯信息类内容**（说明书、学术论文、产品文档）：没有"主角"和"观众代入"，救猫咪、人物弧光无从谈起。
- **艺术片 / 作者电影 / 非线性叙事**："让观众喜欢主角""每个角色都转变""危险必须正在发生"都是商业片审美，对《记忆碎片》式存在主义主角、慢电影、情绪驱动叙事不成立。
- **设定本身就是多世界观的类型**（超英电影宇宙、混合类型喜剧）：双重魔幻是作者自认的个人审美铁律，现实中被大量混合类型片证伪，别把它当普世叙事规律强制执行。

### 作者在书中警告的失败模式

- **缺救猫咪时刻、主角不可爱**（《古墓丽影2》）：创作者以为"酷"等于讨喜，把人物塑造偷换成"开一辆很酷的车"，观众不喜欢主角就不进影院（ce09）。
- **双重魔幻**（《蜘蛛侠》辐射蜘蛛 + 生化事故绿魔）：让观众在同一部片里接受两套超自然系统，信念被分散即出戏（ce06）。
- **堆砌概念**（《左》既左翼又前拳击手又左撇子）："把10磅的东西塞进5磅容量的袋子"，作者毙掉了这个创意（ce08）。
- **危险逼近太慢**（《天崩地裂》《极度恐慌》《天地无限》）：慢吞吞逼近的威胁没有任何威胁感（ce07）。
- **让媒体掺和**（《天兆》CNN 播外星人新闻）：外部现实闯入稀释了主角孤军奋战的绝望感，打破第四面墙（ce21）。
- **主角起点太高、不肯后退**（金羊毛改七稿）：主角开场就太完善，没有可转变的空间，人物弧光无从谈起（ce25）。

### 作者的盲点 / 时代局限

- **"双重魔幻是铁律"实为审美偏好**：被《哈利·波特》等大量混合类型成功片证伪；"一部电影只能有一个魔幻元素"是作者自封的规则，不是叙事铁律。
- **"所有好电影都必然有救猫咪 / 人物弧光"是把好莱坞惯例偷换成普遍规律**：大量优秀群像片、反结构片、无爱情线的影片是反例。
- **彻底商业化立场**：作者明言只写给想抓主流市场的编剧，并嘲笑"为胡里奥量身打造"式的个人化项目；"让观众喜欢主角"对反英雄、作者电影、艺术表达并不总是适用。
- **被动型主角的合法性被一笔抹杀**：本书把"主角必须主动"当作铁律，但大量文艺片的被动型主角（观察者、受害者）恰恰是作品的意义所在。

### 容易混淆的邻近方法论

- 救猫咪 ↔ 主角三要素设计（`save-the-cat-protagonist-design`）：救猫咪是"开场一个小动作"，三要素是"整部片主角该怎么配"。
- 双重魔幻 ↔ 类型定位（`save-the-cat-genre-ten-types`）：类型学管"归到哪一类、遵守哪类规则"，双重魔幻管"世界观别叠加"。
- 人物弧光 ↔ 六大缺憾机制（`save-the-cat-deficiencies`）：弧光是"人人要转变"的总原则，六大缺憾是"埋雷—引爆—治愈"的具体机关。
- 小心冰川 ↔ 反派逼近节拍（`save-the-cat-beat-sheet` 55-75 页）：节拍表定"反派逼近发生在哪"，小心冰川定"威胁感怎么才有"。
