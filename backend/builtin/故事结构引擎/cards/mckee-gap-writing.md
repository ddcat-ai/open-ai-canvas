## I — 方法论骨架 (Interpretation)

1. 故事张力的来源不是巧合或暴力，而是"鸿沟"——人物期望的结果与世界的实际反应之间的裂缝。期望与结果之间、或然性与必然性之间的断层，就是故事的材质，也是故事的能源。
2. 写作场景的标准循环：进入人物主观视点，真诚地写出他此刻想做什么（从自己视角看损失最小的"最小保守行动"）→ 走出视点，客观问"那一反应的对立面是什么" → 让世界给出相反或远强于预期的反应 → 人物被新情况逼着适应、重新行动 → 再撬下一道鸿沟，直到价值发生转折。
3. 为什么从最小保守行动开始？因为人性是保守的——人物总是预期愿望成真，而故事恰恰要扬弃这种生活常态。
4. 风险检验是诊断器：问"如果主角得不到想要的，他最坏会失去什么？"若答案是"回到正常"，故事核心已坏。
5. 冲突法则兜底：若无冲突，故事中的一切都不可能向前进展；回避冲突的剧情必然无聊，观众开始看表。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《唐人街》第二幕高潮的逐节拍拆解
- **问题**: 如何写出一场"电影中写得最好的场景之一"？写作场景有没有可操作的方法。
- **方法论的使用**: 麦基把吉提斯驾车去对质伊夫林的戏拆成超慢镜头，逐节拍潜入吉提斯、卡恩、伊夫林、凯瑟琳的主观视点自问"如果我是他，此刻我会怎么办"，再走出视点反问"那一反应的对立面是什么"。
- **结论**: 场景的每一个节拍都是"主观真诚动作 + 客观对立反应"的交替，鸿沟一个接一个裂开，张力自然累积。
- **结果**: 该场景成为鸿沟驱动写作法的核心示范教材。

### 案例 2: 麦基审读 200 个剧本的通用分析报告
- **问题**: 为什么绝大多数送审剧本注定平淡失败？
- **方法论的使用**: 用鸿沟/冲突/风险的眼光审视前 200 份审读剧本，发现坏剧本的通病高度一致。
- **结论**: 通病是同一批：没有明确主人公、主情节充满方便巧合与脆弱动机、人物塑造流于表面——也就是鸿沟不裂、冲突停顿、赌注缺失。
- **结果**: 麦基据此归纳出"通用坏剧本诊断"，反证出好故事的标准：每个场景必须有价值转折、由鸿沟驱动。

### 案例 3: 《卡萨布兰卡》市场场景的节拍链
- **问题**: 里克自信能夺回伊尔莎，这场戏凭什么让人屏息？
- **方法论的使用**: 场景按节拍推进，里克步步行动、步步期待，直到第十一个节拍，伊尔莎披露自己与拉兹洛早已结婚——期望与结果之间裂开全片最大的鸿沟，粉碎里克夺回她的希望。
- **结论**: 转折点正是鸿沟裂到最大之处；"期望落空"比"计划得逞"有力量得多。
- **结果**: 该场景成为场景分析的标准示范，也反向证明了鸿沟即场景转折的动力。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户说自己的场景"太平淡""没冲突""像流水账"，人物要什么有什么、敲门门就开——需要制造张力。
2. 用户写到某个节拍卡住，不知道人物下一步该做什么、世界该给什么反应。
3. 用户想制造反转、冲突升级，但不知道从哪下手。
4. 用户怀疑整个故事赌注不足，问"如果主角失败会失去什么"。

### 语言信号 (用户的话里出现这些就应激活)

- "场景太平" / "没有冲突" / "写不下去了" / "下一步怎么办" / "反转" / "张力" / "鸿沟" / "对立面" / "赌注" / "风险"
- "boring scene" / "no conflict" / "stuck" / "what happens next" / "reversal" / "tension" / "gap" / "opposite of that reaction" / "stakes"

### 与相邻 skill 的区分

- 与 `mckee-scene-analysis` 的区别: 场景分析是"诊断已写好的场景"（五步拆解找问题）；鸿沟写作是"生成/改写场景"（逐节拍造张力）。
- 与 `mckee-inciting-incident` 的区别: 激励事件设计故事的第一个大事件；鸿沟驱动故事内每一个节拍。
- 与 `mckee-story-structure` 的区别: 结构管全局单位（节拍→场景→幕）；鸿沟管单位内部的动力。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **锁定场景此刻的主人公欲望，写出他的最小保守行动**
   - 完成标准: 能用一句话写出"他想要 X，于是他采取了 Y"，且 Y 是他从自己视点看损失最小的选择。

2. **走出视点，问"那一反应的对立面是什么"，写出世界的实际反应**
   - 完成标准: 写出的反应与人物预期相反、或强到超预期，期望与结果之间出现可以复述的裂缝。
   - 判停条件: 若怎么都找不到对立反应，说明欲望没风险——回到步骤 1 重设欲望或提高赌注；若连续三个节拍都无法撬开鸿沟，转用 `mckee-scene-analysis` 先诊断这个场景是否根本不该存在。

3. **让人物在鸿沟中适应并重新行动，重复第 2、3 步直到价值转折**
   - 完成标准: 场景结尾的价值负荷（爱/恨、生/死、自由/奴役等）相对开头发生正负翻转；此时再用风险检验复核——"若失败，最坏会失去什么"依然能给出令人信服的答案。

## B — 边界 (Boundary) ★

### 🔴 硬约束（世界层·违背就崩）

- 不能违背基本的鸿沟驱动写作法逻辑，否则观众/读者会立刻出戏
### 🟡 软约束（规则层·违背有代价）

- **已有成稿只想知道哪里坏了** → 用场景分析五步法诊断，而不是重新生成。
- **非冲突本位的叙事** → 静观/诗性/散文式作品（小津、阿巴斯、意识流）强行制造鸿沟会破坏其美学立场。
- **纯对白润色/文本层打磨** → 那是解说管理或对白原则的领域，别拿鸿沟来救对白。
### 🟢 自设约束（认知层·其实可以重定义）

- 以为鸿沟驱动写作法只有一种正确用法——假墙，方法是工具，不是教条
- 以为鸿沟驱动写作法能解决所有问题——假墙，每个方法都有适用场景
