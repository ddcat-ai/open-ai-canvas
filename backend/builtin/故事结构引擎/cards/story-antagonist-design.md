## I — 方法论骨架 (Interpretation)

- 对手不是"看起来像坏蛋"的人，而是与主角竞逐**同一个目标**的结构性角色；只有如此，两人才会在整个故事中反复正面冲突。
- 对手七要素：①不可或缺——最能攻击主角的重大弱点，令主角成长或毁灭；②具有人性——是主角的"分身"（double），有弱点、有需求、有渴望（最好与主角同一目标）；③价值取向与主角相反；④拥有有力但有缺陷的道德论点，能为自己辩白；⑤与主角高度相似（相似处才显关键差异）；⑥与主角同处一地；⑦计划缜密、隐藏得好。
- 网球赛隐喻：对手愈强，主角被逼得愈出色；对手设定正确，故事几乎肯定成立，反之几乎肯定失败。
- 对手不一定是主角憎恨的人——他可能更讨喜、更有道德感，甚至是主角的爱人或友人；对立不在正邪，而在各有弱点和需求。
- 对手的道德论点要"尽可能强"（他说的话有些是对的），但逻辑必须含致命谬误——这是把对手从稻草人变成真人的最大单一因素。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《大审判》——对手康卡农的道德辩白
- **问题**: 如何让一个"用尽手段赢官司"的对手律师不沦为外强中干的稻草人？
- **方法论的使用**: 作者马梅让对手提出极强但含谬误的论点——"任何能导向胜利的行动都是合理的，因为胜利会带来物质报酬……我们为慈善机构和穷人提供免费专业服务，资金就来自这里"。这"神来之笔"就是康卡农论点中的谬误；作者还把辩白与情节节拍结合，让观众在独白高潮才惊觉谈话对象是弗兰克女友（实为"其实是对手的假盟友"）。
- **结论**: 对手有自己"说得通"的道德逻辑，整体却站不住脚；辩白藏在冲突场景里，而非单独讲道理。
- **结果**: 特鲁比称"道德论点与情节的这种结合，让这一刻为这个场景乃至整个故事带来极大的情感冲击"。

### 案例 2: 《欲望号街车》——斯坦利作为有人性的对手
- **问题**: 对手如何既凶猛攻击主角弱点，又有自己的道德立场，而非纯坏蛋？
- **方法论的使用**: 斯坦利自认揭露真相是保护朋友，他对"真理"的那种咄咄逼人、自以为是的观点，被特鲁比评为"比白兰芝的谎言更具破坏力"——对手不是恶的化身，而是持有一种扭曲诚实观的"分身"。
- **结论**: 主角与对手各代表同一道德难题（"凭谎言与假象争取爱情是否合理"）的一个变奏，双方都相信自己是对的，只是错的方式不同。
- **结果**: 作为"如何充实角色"的完整示范，凸显特鲁比特有的反转判断：诚实也可以是一种更深的伤害。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 反派太弱，主角赢得毫不费力，观众觉得"这个对手配不上这个故事"。
2. 反派一出场就丑、就凶、就坏，动机单薄到观众无法理解他为何那样做。
3. 反派有自己的阴谋，但和主角的欲望毫不相干，两人各追各的。
4. 想给反派一句"辩白"台词，却总是写得很假、站不住脚。

### 语言信号 (用户的话里出现这些就应激活)

- "我的反派太弱 / 对手不够格 / 主角赢得太轻松" — "the villain is too weak / not a worthy opponent"
- "反派坏得没道理 / 他为什么要这么做" — "why does the villain do this / his motivation makes no sense"
- "反派的目标和主角没关系 / 各追各的" — "the villain isn't competing for the same goal"
- "反派是主角的分身 / 镜中的另一面" — "the antagonist is the hero's double"
- "反派的辩白 / 道德论点" — "the villain's justification / moral argument"

### 与相邻 skill 的区分

- 与 `story-character-network` 的区别: 后者是全体角色的横向网络（每个配角如何共同界定主角），本 skill 是**单个主要对手**的纵向深塑（七要素逐一打磨）。用户说"配角群都单薄"→ 网络 skill；说"就这一个反派不行"→ 本 skill。
- 与 `story-moral-argument` 的区别: 后者设计整条主题的论证序列与对等道德抉择；本 skill 只借用其中"给对手一个有力但有缺陷的道德论点"这一条，服务于让对手立体化。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认对手与主角竞逐同一个目标**
   - 完成标准: 用一句话同时写清主角的欲望与对手的欲望，且两者指向同一个可验证的目标（例如侦探 vs 罪犯争夺"众人相信哪一个版本的事实"）；若两人各取所需、无须正面冲突，则换目标或判定本 skill 不适用。
   - 判停条件: 若找不到共同目标且故事并非侦探/双雄类型，说明该故事可能不需要传统对手，跳到 B 段反场景。

2. **逐项检查对手七要素并补齐缺口**
   - 完成标准: 七要素逐项有书面答案——①不可或缺（最能攻击主角弱点）②有人性（弱点/需求/渴望，渴望最好与主角同目标）③价值取向与主角相反 ④有道德论点（有力但有致命谬误）⑤与主角高度相似 ⑥同处一地 ⑦能在故事中多次正面冲突。任何一项空缺或答"没有"即未完成。

3. **写对手的道德辩白场景**
   - 完成标准: 在一个场景里让对手借对白为自己的行动做道德辩白；论点要尽可能强（"确保他就某些事所说的话是对的"），同时至少包含一个重大谬误使整体站不住脚。自查：观众能理解他的动机（产生同理心），但不会认同他的结论。
   - 判停条件: 若辩白一听就假、自相矛盾，即是"稻草人"（ce26），停止并回到步骤 2 重写第 ④ 项道德论点。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 无对手的叙事（《等待戈多》、意识流、纯氛围叙事）：没有可"竞逐同一目标"的角色。
- 对手是抽象力量（命运、体制、自然、天气）的作品：七要素中的"人性/分身/相似/同处一地"无法落位；若要保留，必须先把体制具象化为某个代表人物。
- 明确不需要对抗的温暖小品或脸谱化反派喜剧：强行深塑反而破坏类型轻快感。

### 作者在书中警告的失败模式

- ce04 "把对手当作'看起来像坏蛋'的角色"——从外表与道德定性对手，而非从结构功能定义，永远写不出好故事。
- ce05 "主角与对手不竞逐同一个目标"——两人各取所需，冲突失去结构支点，故事散掉。
- ce26 "让对手成为'稻草人'，传达软弱无力的论点"——对手辩白站不住脚，主角的胜利变得廉价。

### 作者的盲点 / 时代局限

- "对手竞逐同一目标"是目标争夺型西方戏剧传统的产物；对契诃夫式"无人对抗"、卡夫卡式"对手即体制"、阿巴斯式"冲突缺席"的叙事（BOOK_OVERVIEW 批判 #8）覆盖不足——这些作品的伟大恰恰不依赖"对手够好"。
- 对手"同处一地"的要求对跨国/多线并置的现代故事需要弹性处理。

### 容易混淆的邻近方法论

- 与"四角对立"（f15）的混淆: 四角对立属于角色网络的横向扩展，本 skill 是主要对手这一"角"的纵向深化；两者常先后使用，但判断标准不同。
- 与"幽灵/背景故事"的混淆: 对手的动机不靠堆背景故事，而靠当下的道德论点和与主角的相似性。
