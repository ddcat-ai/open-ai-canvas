## I — 方法论骨架 (Interpretation)

1. 主控思想是一个完成故事必须能用一句话表达的终极意义，公式是"价值 + 原因"。它不是"爱情""战争"这类主题背景词，而是"正义终于得到伸张，因为……"这样一条完整、闭合的陈述。
2. 提炼法（从高潮往回看）：①问高潮动作给主人公世界带来了什么正/负价值；②一路深挖到故事基石，问这一价值之所以出现的主要原因、动力或手段。两个答案合成一句，就是主控思想。
3. 主控思想确立作者的一切关键选择：什么场景该留、什么该删，它是一切取舍的仲裁。思想越聚焦，观众能发现的意义反而越多。
4. 故事结构是"对真理的创造性论证"：思想必须由事件的动态设计证明，大师从不解释——把思想塞进对白或画外音，会严重降低作品质量。
5. 防说教：给思想与反思想同等火力，把反面论证写得和正面一样有力，让高潮处正面思想凭实力胜出，而不是靠压低对方。
6. 注意区分前提与主控思想：前提是开放问题（"如果……将会发生什么"，发散），主控思想是收敛句；写作就是从发散设问走向闭合立意。

## A1 — 书中的应用 (Past Application)

> 注：原计划引用《公民凯恩》作为主控思想示范，但候选案例池中无该片条目。为遵守"案例真实来自候选池"的红线，此处改用候选池中真实存在的两个主控思想案例。

### 案例 1: 《猛龙怪客》的主控思想一句话
- **问题**: 一个完成故事的意义如何用一句话说清？故事的思想是否有真实力量？
- **方法论的使用**: 麦基用"价值+原因"句式读出该片主控思想："正义战胜邪恶，只要公民用自己的双手拿起法律的武器，杀掉所有该杀之人"。价值=正义战胜邪恶，原因=公民自行执法。
- **结论**: 主控思想必须是闭合的"价值+原因"句子；故事有极强劝诫力量——"被感觉到的思想也是思想"，好与坏的作品都在此意义上生效。
- **结果**: 该片成为"一句话概括主控思想"与"故事劝诫力"的极端例证，也引出思想自由市场的伦理讨论。

### 案例 2: 库布里克三部反战片的思想对反思想平衡
- **问题**: 为什么许多反战影片不奏效、沦为说教？
- **方法论的使用**: 对比库布里克《光荣之路》《奇爱博士》《全金属外壳》——他深入研究了反思想，揭示人类本性中与生俱来的好战嗜杀面，战争只是其逻辑延伸。
- **结论**: 必须给交战双方同样的火力，不要偏向论战任何一方；只强化己方观点、压抑对立声音，就会滑向"论文电影"。
- **结果**: 库布里克式辩证结构成为"思想vs反思想"平衡的标准示范。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户写完故事但说不清"它想表达什么"，或朋友问"你想说什么"答不上来。
2. 用户要为立意/主题定调，需要一句话统摄全部素材取舍。
3. 用户担心作品说教，角色在讲大道理、画外音在解释主题。
4. 用户在改稿时纠结"这个场景到底要不要留"，需要立意当裁判。

### 语言信号 (用户的话里出现这些就应激活)

- "主题" / "立意" / "想表达什么" / "主控思想" / "一句话概括" / "说教" / "讲道理" / "价值观" / "意义" / "论证"
- "theme" / "controlling idea" / "what is my story about" / "message" / "moral" / "didactic" / "say it in one sentence"

### 与相邻 skill 的区分

- 与 `mckee-character-design` 的区别: 人物设计回答"故事里的谁、他想要什么"；主控思想回答"整个故事在证明什么"。
- 与 `mckee-scene-analysis` 的区别: 场景分析是微观诊断；主控思想是全局的"意义层"裁定。
- 与 `mckee-antagonist-wall` 的区别: 反面之墙提供对抗力量；主控思想需要思想/反思想辩证，一个在角色层、一个在意义层。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **从结尾高潮动作往回看，写下"价值"部分**
   - 完成标准: 写出二元可判断的价值变化（如"正义得到伸张""爱战胜了恨"），不是形容词堆砌，也不是主题词。

2. **深挖原因，补全成"价值+原因"的闭合句**
   - 完成标准: 一句话，因果链清晰可复核——"最终价值出现，因为<首要原因>"。
   - 判停条件: 若写不出原因，说明高潮动作缺乏因果支撑——停下来回头检查高潮是否真由人物选择达成（而非巧合），必要时转 `mckee-crisis-climax` 修高潮。

3. **用主控思想做取舍测试 + 说教检查**
   - 完成标准: 所有保留的场景/角色都直接或间接服务该思想；全稿没有任何角色或画外音直接宣讲思想；正反双方火力大致对等。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **只问情节/事件顺序设计** → 那是结构设计（`mckee-story-structure`）的领域。
- **非叙事文体** → 论文、说明文、演讲稿的"中心论点"提炼，方法论不适用。
- **纯娱乐宣言** → 用户明确拒绝立意时，可提示麦基认为故事必有意义，但尊重其选择，不强推主控思想。

### 作者在书中警告的失败模式

- **ce19 说教倾向**: 为证明某个思想而写，好人非常好、坏人非常坏，每个场景重复同一口号，剧本变成"论文电影、欲盖弥彰的布道"。
- **ce20 借对白或画外音解释思想**: 让人物或旁白直接宣讲主题，观众既不爱听也不相信；"伟大的故事仅凭事件的动态设计来确证其思想"。
- **ce14 次情节与主控思想无关**: 次情节只顾自己跑，与主控思想不构成矛盾或回响，毁灭故事统一性。

### 作者的盲点 / 时代局限

- "故事必有可总结的主张"预设了意义导向的叙事观；对拒绝价值判断的诗性、反情节、静观作品，强行提炼主控思想会收窄作品。
- "思想自由市场"与"劝诫力量"是价值立场而非叙事学论证（见 BOOK_OVERVIEW 批判）。
- 思想vs反思想的对等框架以辩证冲突为前提，对不以冲突为本体的文化叙事需重新校准。

### 容易混淆的邻近方法论

- **前提 vs 主控思想**: 前提是开放式问题（发散起点，"如果……会怎样"），主控思想是闭合句（收敛终点）——这是 f10 的核心区分，别混用。
