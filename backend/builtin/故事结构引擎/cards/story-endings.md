## I — 方法论骨架 (Interpretation)

好故事在最后一页之后继续活着。特鲁比先给出诊断工具：三种**虚假结局**——

1. **过早结束**：真实自我揭露太早出现、主角太快达成欲望（或靠令人难以置信的行动），一切成为反高潮。
2. **任意结束**：情节缺乏有机性，没有个体或社会单位在发展，故事说停就停（"天神解围法"即典型）。
3. **封闭式结局**：主角达成目标 + 简单的自我揭露 + 新的平衡，让观众觉得故事已完成。但"欲望永不止息，平衡是暂时的"，这种圆满不够真实。

解法是让故事**永不完结**——用开放/循环结构让故事在结束后继续生长，常用技法：以结尾揭露（逆转）收束；让主角欲望未止息、或次要角色产生新欲望/新转变；把背景细节前移；让道德论点模棱两可、不写出最终抉择；用不可靠叙述者迫使观众重新阅读。

原理：好故事是有机的整体，结局的痕迹在开头就已存在；观众被要求回到开头重新体会——像莫比乌斯环，每一次循环因为视角变化都生成新意义。这同时呼应七步法的"新的平衡点"：平衡是根本的、永久的改变，但正负皆可，且不意味着一切都已了结。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《了不起的盖茨比》——永不止息的欲望
- **问题**: 如何避免"主角达成欲望、一切圆满结束"的虚假结局？
- **方法论的使用**: 菲茨杰拉德让小说结尾出现**永不止息的欲望**——人生目标远离我们，我们付出更多力量去追求它；结尾最后一句"于是颠扑向前，逆水行舟，一次又一次，退回到过往"是足以代表整个故事的主题揭露。
- **结论**: 以"欲望未止息"替代满足式圆满，让故事在读者心里继续生长。
- **结果**: 作为"放弃满足式虚假结局"的范例；该结尾并置绿灯（虚假欲望的象征）与新大陆（自然的、有潜力的美国），形成三重象征的主题揭露。

### 案例 2: 《哈克贝利·费恩历险记》——任意结局（反例）
- **问题**: 旅程式情节的终点无法自然来临，作者不知如何收束。
- **方法论的使用**: 马克·吐温让旅程"随意停止"，用"天神解围法"（让汤姆再度出现）解套——这是特鲁比反复批评的**任意结束**。
- **结论**: 缺乏持续对手、没有有机发展单位的旅程，结局只能靠偶然事件硬收，"天神解围法"瞒不过读者。
- **结果**: 作为"旅程式情节为何难成有机情节"与"任意结束=虚假结局"的双重反例。

### 案例 3: 《七武士》——以主题揭露收束的结局
- **问题**: 大战胜利后，故事如何收尾才不落入"赢了就圆满"？
- **方法论的使用**: 勘兵卫在胜利后却说"我们又输了——农民才是赢家"。结局同时是震撼的情绪转折、结尾的重大揭露（类逆转）与主题揭露（武士的生活方式已随时代消逝）。
- **结论**: 结局不必满足主角欲望；揭示主角付出的真实代价，故事反而更有力。
- **结果**: 被称为"最出色的剧本之一"，结局"令观众极为震惊，但也带来了奇妙的启发"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户说"结局太平""像草草收尾""结尾没劲"，想诊断并重设计。
2. 用户写到结尾处卡住，不知道这个故事该怎么收。
3. 用户在纠结"结尾要不要大团圆 / 开放式到底行不行"。
4. 用户希望作品有重读/重看的价值，想让故事结束后仍在读者心中生长。
5. 用户写完整个故事后做整体检查，怀疑结尾不对劲。

### 语言信号 (用户的话里出现这些就应激活)

- "结局""结尾""收尾""尾声" / "ending" "finale" "resolution" "climax"
- "大团圆""圆满""开放式结局" / "happy ending" "open ending" "closed ending"
- "草草收尾""没劲""反高潮" / "anticlimactic" "fizzles out"
- "重读""回味""意犹未尽" / "reread" "replay value" "haunting"
- "不知道怎么收""该停在哪儿" / "how to end" "where to stop"

### 与相邻 skill 的区分

- 与 `story-revelation-sequence` 的区别: 结局常用的"结尾揭露"两者都会涉及，但 revelation 管理**全故事的揭露节奏**（过程），本 skill 关注**结局形态**（故事结束后的生长）；若用户说"结尾的反转太突兀"偏 revelation，说"结局收得没劲"偏本 skill。
- 与 `story-seven-key-steps` 的区别: "新的平衡点"只是七大步骤的最后一步（决定主角停在更高还是更低的人生层次）；本 skill 扩展为"结局后故事是否继续活"的整套判断与技法。
- 与 `story-scene-structure` 的区别: 场景 skill 管单个场景的倒三角顶点；本 skill 管整个故事的最终收束，两者尺度不同。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **诊断结局属于哪种虚假结局**
   - 对照三种类型逐一检查：是否过早（自我揭露太早/欲望太快满足/行动机械）？是否任意（无有机发展/天神解围）？是否封闭（一切止息、盖棺定论）？
   - 完成标准: 明确判定结局的类型归属，并引用具体证据（哪个节拍导致过早/任意/封闭）；若结局本身健康，则说明它为何不落入三类。
   - 判停条件: 若用户只想确认"这个结局算不算虚假结局"而不打算重写，完成本步诊断即可停下。

2. **选择并设计"永不完结"技法**
   - 从六种技法中按故事类型挑 1-2 个实施：结尾揭露（逆转）、主角欲望未止息、次要角色新转变、背景细节前移、不可靠叙述者、道德模棱两可/隐藏最终抉择。
   - 完成标准: 写出新的结局方案，并说明该技法如何让读者在最后一页后仍继续思考；若与步骤1的"过早"诊断冲突（如主角欲望未止息会使"过早满足"暴露），主动指出张力。

3. **核对新的平衡点与主题揭露**
   - 确认主角抵达的是"根本的、永久的"新平衡（正向或负向皆可），且平衡只是暂时的；确认结局若带主题揭露，它是否由结构/象征承载而非说教。
   - 完成标准: 输出"结局设计说明"：原结局的问题 → 新结局方案 → 采用的技法 → 平衡点与主题揭露的落点；若用户要求，附修改后的结尾段落草稿。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户的故事是**类型片/类型小说**（侦探破案、童话、浪漫喜剧），封闭式圆满是类型的硬性契约——强行"永不完结"会违背读者期待，此时只做"新平衡点"检查即可。
- 用户还在写中段、没到结局决策阶段——先完成场景编排与情节，本 skill 是收束工具。
- 一次性消费、无重读需求的口头故事或段子——永不完结对它们没有意义。

### 作者在书中警告的失败模式

- 三种虚假结局（过早/任意/封闭式）→ "虚假的结局主要有三种……这样的结局不够真实。欲望永不止息，平衡是暂时的。"（第11章）
- 天神解围法 → "天神解围法"瞒不过读者，是"任意结束"的典型（《哈克贝利·费恩》）。
- 只做"简单自我揭露"的圆满 → "主角达成目标，获得简单的真实自我揭露……不过这样的结局不够真实。"

### 作者的盲点 / 时代局限

- **好莱坞情节剧框架**：全书的结局观默认"单个主角 + 个人转变 + 观众重读"；对群像、非个人主义叙事的结尾如何收束缺乏正向方法论。
- "永不完结"是价值偏好，不是普适标准——作者对**圆满结局**（童话、类型片、观众求治愈的作品）存在明显偏见；对反商业、以闭合为美德的作品支持不足。

### 容易混淆的邻近方法论

- **开放式结局 (open ending)**：一般理解的"不把话说死"≠特鲁比的"永不完结"——后者要求有结构技法（揭露/莫比乌斯环）让读者主动重读，单纯的留白可能是"任意结束"。
- **后记/尾声 (epilogue)**：交代人物去向是收尾手段，不是"让故事生长"——永不完结靠结构，不靠追加章节。
- **新平衡点（七步法）**：它只是结局状态（主角停在哪一层），本 skill 是判断这个"停法"是否真实、是否留有余波。
