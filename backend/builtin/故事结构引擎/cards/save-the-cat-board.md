## I — 方法论骨架 (Interpretation)

演示板是动笔前把整部电影"可视化"的推演工具，作者称它是仅次于纸笔的最重要工具，本质是一次低成本的"原型测试"。

- **物理形态**：板子上贴三条胶带分成四行，对应四幕——第一幕(1-25)、第二幕前半(25-55)、中点到第三幕(55-85)、第三幕(85-110)；每行末尾恰好是三个主要转折点（进入第二幕 / 中点 / 进入第三幕）。
- **排布顺序**：先钉"最让你兴奋的场景"卡铺底，再钉主要转折点——**先中点，再失去一切（=中点的反面），最后进入第三幕**——中点决定故事走向，所以最先定；用颜色编码区分各故事线/支线/主题。
- **数量约束**：反复排布、合并、删减，最终压到 40 张卡（每行约 9-10 张）。每张卡=一场戏。
- **双符号闸门**：每张卡必须标注 +/-（这场戏的情感变化，从 + 到 - 或 - 到 +，每场戏都是一部"迷你电影"）和 ><（这场戏的冲突双方与胜负，一场戏只写一个冲突）。写不出符号的卡就扔掉——很可能是这场戏本身有问题。
- **黑洞**：排卡时"不知道前后怎么衔接"的空白就是黑洞，每行 9-10 张的硬约束强迫你直面并填掉它；第三幕最容易空（初期只有"主角知道怎么办+大决战"两张卡）。
- **价值**：在动笔前以极低成本暴露结构问题，避免写完后才崩溃——写完再改就贵了。

## A1 — 书中的应用 (Past Application)

### 案例 1: 麦克·切达的便携速写本
- **问题**: 作者一直想不通"转幕节点"和幕与幕之间的水域，需要一个能提前"看到"整部电影的工具。
- **方法论的使用**: 导师麦克·切达用螺旋速写本演示——画三条直线分成四行，行中贴剪出的小纸片代表每个节拍，"这是便携式的"，笑得像个疯狂科学家。
- **结论**: 演示板让编剧在动笔前像"弦理论物理学家"一样打磨叙事技巧。
- **结果**: 作者从此用软木板+卡片+图钉做自己的演示板，把它称为"仅次于纸、笔和笔记本电脑的最重要工具"。

### 案例 2: 第一行塞进 20 张卡片的精简
- **问题**: 作者在布局铺垫处总塞 20 张卡片，觉得想说的太多、表达过度。
- **方法论的使用**: 用"能否合并、是否非删不可"的诚实拷问逐个精简，最终减到 9 张。
- **结论**: 很多卡片其实是"背景故事"而非场景，删掉后第一行完美；每行 9-10 张的约束逼出"少而精"。
- **结果**: 在动笔前就把表达过度的问题解决掉，而不是写完后才返工。

### 案例 3: 麦克·切达的"牛仔和印第安人"
- **问题**: 花上百万美元买来的《血海翻天》剧本，结构难题久攻不下。
- **方法论的使用**: 散步时麦克突然停在人行道上，灵光乍现为"牛仔和印第安人"的极简冲突构想。
- **结论**: 结构是可被想透的；演示板思维就是把复杂问题可视化后，找到那个极简的简化表述。
- **结果**: 剧本按新方向改写并投拍。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户有大纲但"觉得哪都不对又说不出"（"我故事里好像有个地方接不上"）。
2. 用户动笔前想把故事排一遍再写（"我想先把故事可视化一下"）。
3. 用户想对已有大纲做逐场体检（"每场戏有没有存在的必要""有没有哪场戏没有冲突"）。
4. 用户写到一半发现结构崩了，想退回卡片层重排（"我写到第 40 页发现前面有个洞"）。

### 语言信号 (用户的话里出现这些就应激活)

- "演示板" / "the board"、"story board"
- "40 张卡片" / "40 index cards"、"40 cards"
- "四行分幕" / "four rows"
- "+/-"、"情感变化" / "emotional change"
- "><"、"冲突双方" / "conflict"
- "黑洞 / 接不上" / "black hole"、"gap in the story"
- "排卡" / "lay out the cards"
- "动笔前规划" / "pre-writing"、"outline before writing"

### 与相邻 skill 的区分

- 与 `save-the-cat-beat-sheet` 的区别: beat-sheet 是一页纸的 15 拍坐标（粒度=节拍），board 是 40 张卡的逐场排布（粒度=场景）；board 每行末尾正好落在 beat-sheet 的主要转折点上——配合使用，但 board 的重心是"逐场+双符号+精简"。
- 与 `save-the-cat-diagnosis` 的区别: diagnosis 对已成稿做 9 问体检；board 在动笔前做预防性体检。若用户已有成稿且只问"哪里不对劲"，走 diagnosis；若愿意退回卡片层重排，可先用 board 暴露黑洞再对照 diagnosis。
- 与 `save-the-cat-deficiencies` 的区别: deficiencies 是"填第三幕黑洞"的具体内容来源（缺憾结清），board 是"发现黑洞在哪"的容器；board 发现问题，deficiencies/beat-sheet 提供填法。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **搭板分幕**: 把故事按 1-25 / 25-55 / 55-85 / 85-110 画成四行，行尾标注三个主要转折点（进入第二幕 / 中点 / 进入第三幕）。

2. **排卡与钉转折点**: 先钉"最让你兴奋的场景"卡铺底，再按"中点→失去一切→进入第三幕"的顺序补主要转折点，最后把其余场景并入对应行。
   - 完成标准: 四行各有 9-10 张卡，总卡数 ≤ 44；所有"接不上"的位置已被标记为黑洞。
   - 判停条件: 若连中点都定不出来（说不清它是高点假象还是低点假象），停止排卡，先回到 `save-the-cat-beat-sheet` 把中点(55)想清楚再继续。

3. **逐卡标注双符号并精简**: 给每张卡写 +/-（情感从哪到哪）和 ><（谁有目标、谁挡路、谁赢）；写不出的卡删掉或合并；每行压到 9-10 张。
   - 完成标准: 40 张卡全部标完 +/- 和 ><，无一张缺符号；黑洞已被新卡填上或明确标注为待写。
   - 判停条件: 若第三行（第三幕）仍只有"主角知道怎么办+大决战"两张卡，转向 `save-the-cat-deficiencies` / `save-the-cat-beat-sheet` 回查第一幕的缺憾与副线，不要硬编结局。

4. **动笔**: 卡排完、符号标完即开始写作，不再美化板子。
   - 完成标准: 进入正式写作；板子停留在"已完成规划"状态，不再调整。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户已写完初稿、只需润色/诊断成稿：这是 `save-the-cat-diagnosis` 的领域；强行把成稿退化成卡片是浪费。
- 非线性/多线叙事：四行分幕与"每行 9-10 张"针对单主角线性商业片；多线并行、时间跳跃的故事需要其他规划法。
- 用户连一句话故事都说不清：先做 logline / 节拍表，board 是执行工具不是起点。

### 作者在书中警告的失败模式

- 完美主义拖延（ce20）："如果你的板子太完美，或者你花了太多时间去把它变得完美，那你就已经离开了准备剧本的范畴，进入拖延症状态了"——作者自己在板子"快完成但还未完美"时就动笔。
- 空荡荡的第三幕（ce19）：初期第三幕总是只有"主角知道怎么办+大决战"两张卡，必须回查第一幕的缺憾/副线/反派清算。
- 半途而废（ce34）：提前做好演示板能最大程度避免"半个剧本"，但前提是排完真要动笔写——板子是起跑器不是终点。
- 一场戏没有情感变化或冲突（ce26）：写不出 +/- 或 >< 的卡就扔掉，很可能是这场戏本身有问题，不要硬留。

### 作者的盲点 / 时代局限

- 可视化工程化适合线性主流片；作者对非线性/反结构叙事持排斥立场（"去他的《记忆碎片》！"），不要用它去规训本就该打碎结构的作品。
- 2005 年好莱坞生态已瓦解，但"低成本原型测试"的思维（投入大成本前先用卡片验证）可迁移到一切内容规划。
- "结构好 = 能卖出去"是作者把结构和推销强绑定的断言：board 只解决结构可看性，不解决市场结果。

### 容易混淆的邻近方法论

- Trello / 看板式任务管理：board 是"叙事场景的排布与质量闸门"，不是通用任务看板；别把"写大纲的 to-do"当 scene 卡。
- 思维导图：board 是线性四行 + 数量约束，思维导图是放射结构，两者目的不同。
