## I — 方法论骨架 (Interpretation)

转折点是"期望与结果裂开鸿沟、场景开始转向新价值负荷的瞬间"。一个真正的转折点不是"剧情反转"，而是价值方向的转变，并且要经得起三重检验：

1. **四重效果检验**：好转折点依序产生①惊奇（期望落空）②增加好奇心（观众问"为什么"）③见识（记忆回溯重组合旧信息、挖出隐藏真理）④新方向（故事转向下一个转折点）。如果只有震惊而无后续见解，那是"廉价惊奇"；"让观众以为自己想通了"，其实是作者早已铺好伏笔。
2. **伏笔与分晓**：转折点靠伏笔支撑——伏笔是预先铺好的知识层，分晓是用知识闭合鸿沟。创作的关键反转：逻辑是事后回溯重建的东西，**先允许自己想象任何疯狂的念头**（"如果他在背后捅他一刀呢"），再回到开头逐层埋设使其顺理成章。埋设标准：伏笔必须足够牢固（回溯能找到）又不过于明显（一英里外看到转折就失败）；分晓闭合一个鸿沟后，又可能成为未来分晓的新伏笔——形成"伏笔→分晓→再伏笔→再见分晓"的链。
3. **两难之择三面框架**：善恶是非之间的选择根本不是选择（可预测、无意义）。真正的选择是两难之择：不可调和的两善取其一，或两恶取其轻。设计用 A-B-C 三面框架——A 在 B 与 C 之间取舍，价值须同等分量，三角关系带来闭合结局；只有正反对立（她爱我/不爱我）永远开放循环。人物在两难中的选择，是对其人性与世界的强有力表达。

这三件套是一个递进闭环：先检验"转折点是否成立"（四重效果），再确保"它凭什么成立"（伏笔分晓），最后把人物推到"真正选择"的悬崖（两难三面）。写作者可从任意一环入手诊断，但设计新转折时最好按顺序过一遍，缺一环就补一环。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《唐人街》——"她是我妹妹，也是我女儿"
- **问题**: 第二幕高潮前观众以为马尔雷被害不是为财便是为情；如何让真相揭示成为爆炸性转折点而非廉价爆料？
- **方法论的使用**: 麦基用它示范转折点+幕后故事分晓：伊夫林一句"她是我的妹妹，也是我的女儿"让鸿沟訇然中开，观众记忆飞速回溯（克罗斯那句"为我女儿"），一次性获得乱伦、谋杀动机、凶手身份三重见解——四重效果完整呈现。
- **结论**: 场景不可能只靠动作、动作、动作来转折，强有力的揭示来自幕后故事；揭示比动作冲击力更强，常被保留到幕高潮。
- **结果**: 新方向指向第三幕螺旋般的转折，成为"幕后故事解说创造爆炸性转折点"的典范。

### 案例 2: 《星球大战2》——"我是你父亲"
- **问题**: 高潮处如何用一个转折点推动最长的见解搜寻？
- **方法论的使用**: 麦基用它示范四重效果：维达说出"我是你父亲"，"父亲"一词炸开鸿沟——惊奇（期望落空）→好奇心（为什么）→见识（欧比旺为何担心、尤达为何急于教原力、卢克为何总死里逃生全部被重新解释）→新方向（导向第三部）。
- **结论**: 转折点把观众抛向故事前面寻找答案，见解洪流由此喷涌而出；这就是"讲故事就是许诺"的兑现。
- **结果**: 这一瞬间重新诠释前两部并赋予新的深层意义，直接导向《星球大战3》。

### 案例 3: 《巴黎野玫瑰》vs《红色沙漠》——摇摆不等于两难
- **问题**: 如何让主角的选择成为"真正的选择"而非冲动的滑行？
- **方法论的使用**: 麦基对比示范两难之择：贝蒂从固执滑向疯狂再到紧张症，有冲动但从未做出真正决定（摇摆）；朱利亚娜面临深刻两难——退缩到舒适幻想世界 vs 在严酷现实中找到人生意义（疯狂 vs 痛苦），必须在同等分量的价值间抉择。
- **结论**: 真正的选择是两难之择（两善取一/两恶取轻）；对立双方的冲突无法维持故事，需要三面框架才能带来闭合。
- **结果**: 《巴黎野玫瑰》被批评为"把苦难误认为戏剧"；《红色沙漠》成为最小主义艺术杰作。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计了反转/揭露，担心"太突兀、观众不信"。
2. 想知道某个伏笔该怎么埋、埋在哪、怎么回收（分晓）。
3. 想让结局"意想不到又合理"，但怕变成"廉价惊奇"或巧合。
4. 要给人物设计关键抉择，但写出来都是"做好事还是坏事"。
5. 想在故事中段制造一个重大转折，让观众记忆回溯产生新理解。

### 语言信号 (用户的话里出现这些就应激活)

- "反转 / 转折点 / 揭露" / "plot twist", "turning point", "reveal"
- "埋伏笔 / 铺垫 / 回收" / "foreshadowing", "setup", "payoff"
- "太突兀 / 太巧合 / 不合逻辑" / "too convenient", "doesn't make sense", "forced twist"
- "两难 / 道德困境 / 艰难选择" / "dilemma", "hard choice", "no-win situation"
- "想让观众猜不到 / 意想不到" / "unexpected", "surprise ending"

### 与相邻 skill 的区分

- 与 `mckee-scene-analysis` 的区别: 场景分析是"诊断场景整体成立与否"的五步显微镜；本 skill 是"设计/检验单个转折点"的专门工具。
- 与 `mckee-act-design` 的区别: 幕设计管"转折点/幕高潮放哪个位置、价值如何配比"；本 skill 管"这个转折点本身怎么成立"。
- 与 `mckee-inciting-incident` 的区别: 激励事件是故事开局的"打破平衡事件"，有其专门的定位与上银幕规则；本 skill 覆盖全片任意位置的转折点。
- 与 `mckee-crisis-climax` 的区别: 危机是末段"终极两难之择"，本 skill 的两难三面框架是构建任何真选择的基础工具（包括但不限于末段）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **四重效果体检**
   - 完成标准: 对目标转折点逐一检验：①观众会吃惊吗 ②会问"为什么"吗 ③记忆回溯能挖出旧信息的新组合吗 ④故事有新方向吗。四项齐备=合格转折点。
   - 判停条件: 若只有①有（纯震惊、无见解），判定为"廉价惊奇"，回到设计层重造——用"那一反应的对立面"重新设计，而不是直接补解释。

2. **伏笔/分晓工程**
   - 完成标准: 写清这个转折点依赖哪些"知识层"；能指出每个知识层在前文哪里埋设、埋得是否足够牢固（回溯找得到）又不过于明显（一英里外看不到）；说明该分晓是否还会成为未来分晓的伏笔。
   - 判停条件: 若发现转折依赖巧合或"机器神仙"（无铺垫、天降解决），判定不合格，建议"先想象疯狂念头、再回溯改写前文补设伏笔"，而非接受巧合。

3. **两难之择重构（若涉及人物选择）**
   - 完成标准: 把人物的选择表述为 A-B-C 三面框架：A 在 B 与 C 之间二选一，B/C 是同等人分量的两善或两恶；能说出选完的不可逆后果（闭合结局）。若选择本质是"善恶是非"（可预测），判定不是真选择。
   - 判停条件: 若只有两方正负对立（如"选她/不选她"），指出结局将永远开放，需引入第三面或重塑价值分量；若用户本意是开放式结局，则说明为何本工具不适用并停止。

## B — 边界 (Boundary) ★

### 🔴 硬约束（世界层·违背就崩）

- 不能违背基本的转折点与伏笔分晓逻辑，否则观众/读者会立刻出戏
### 🟡 软约束（规则层·违背有代价）

- 反情节/反结构作品（非线性、巧合统领全片）——麦基允许反情节以巧合言说"生活荒诞"，本 skill 的因果逻辑/伏笔分晓不适用。
- 用户只是诊断"场景该不该删"——用 `mckee-scene-analysis`。
- 整片节奏拖沓、中段疲软——用 `mckee-act-design`。
- 极简/静观叙事不追求"惊奇+见解"的转折，机械套用会误判。
### 🟢 自设约束（认知层·其实可以重定义）

- 以为转折点与伏笔分晓只有一种正确用法——假墙，方法是工具，不是教条
- 以为转折点与伏笔分晓能解决所有问题——假墙，每个方法都有适用场景
