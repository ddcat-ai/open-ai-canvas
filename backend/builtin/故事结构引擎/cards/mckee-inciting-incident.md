## I — 方法论骨架 (Interpretation)

**激励事件**是五部分设计（激励事件→进展纠葛→危机→高潮→结局）的首要导因，是"打破平衡的那件事"——而不是"开场第一件事"。它的功能链是：**打破生活平衡 → 激起恢复平衡的自觉/不自觉欲望 → 把主人公送上求索之路**。

**四性质检验**（判断一个开场事件够不够格）：
1. **彻底打破平衡**：把价值钟摆推向正或负；地址变了但生活价值没变，就不算。
2. **绝对不可逆转**：生活无法回到原状（场景/序列/幕的变化可逆，激励事件不可逆）。
3. **必须上银幕**：主情节激励事件必须让观众亲历（"大钩子"）——它提出**戏剧大问题**勾住好奇心，并在观众想象中投射**"必备场景"（危机）的影像**；次情节的激励事件可以不上银幕。
4. **尽快引入**：两小时片标准是前半小时（前四分之一）；过早观众迷惑，过迟则厌倦。准确时刻取决于"观众需要知道多少才能完全反应"。

**质量不取决于大小**：可小到"一个女人以那种特别的方式看着你"——《普通人》里贝思把法式烤面包倒进垃圾桶就够格，只要四性质全满足。

**构思技巧——"最好→最坏"反转法**：先问"可能发生在主人公身上最好/最坏的事是什么"，再让它逆转为相反方向（如《教父2》最好=迈克尔称霸，最坏=称霸让他众叛亲离成孤家寡人）。

**定位原则**：若激励事件本身具有原始模型特性（如《变形记》开篇），无需伏笔直接呈现；若需推迟（如《卡萨布兰卡》第 32 分钟），必须用伏笔式次情节填补真空——绝不能用解说填。

**启动之后**：故事进入进展纠葛，每次鸿沟裂开就是一个**不归点**——同力度/同性质的旧行动此后必须从故事中排除，人物被迫挖掘更大意志力。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《普通人》——倒进垃圾桶的法式烤面包
- **问题**: 一部关于家庭解体的电影，激励事件该是什么大事件？
- **方法论的使用**: 麦基用四性质检验：贝思抢过儿子不吃的早餐倒进垃圾桶——这个动作彻底打破父亲卡尔文的生活平衡（"仇恨又卷土重来"），激起恢复平衡的欲望，送全家上求索之路，并投射"家庭能否和解"的必备场景。
- **结论**: 激励事件可以小到一个倒面包的动作；判断标准是四性质而非场面大小。
- **结果**: 影片的戏剧大问题（家庭能否解决或终将解体）由此引出，主情节动力全系于这个小动作。

### 案例 2: 《卡萨布兰卡》——第 32 分钟的迟到激励事件
- **问题**: 激励事件迟至 32 分钟才出现，会不会让观众流失？
- **方法论的使用**: 麦基说明"尽快引入但务必等到时机成熟"：此前用不少于五个节奏紧凑的次情节激励事件（拉兹洛、乌加特、伊冯娜、保加利亚妻子、难民们）勾住观众，等到伊尔莎随《时光流逝》出现。
- **结论**: 迟到的主情节激励事件必须用伏笔式次情节填补真空，不能塞解说。
- **结果**: 成就了银幕上最伟大的爱情故事之一。

### 案例 3: 《教父2》——"最好变最坏"的构思反转
- **问题**: 如何构思一个把故事推向体验极限的激励事件？
- **方法论的使用**: 用"最好→最坏"反转法：最好=迈克尔成为家族老大并决心引入白道；最坏=他对忠诚法典的无情执行导致心腹被刺、妻儿疏远、兄弟被杀，变成晚景凄凉的孤家寡人。
- **结论**: 让"最好"逆向滑向"最坏"，把故事推向绝对而不可逆转的变化而非中间地带。
- **结果**: 迈克尔在第二部结尾成为孤家寡人，达成不可逆转的终极变化。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **新故事开场**：开了新剧本，不知道哪个事件能启动故事、把主角生活搅乱。
2. **开头拖沓**：写完发现前 30-40 页全是背景介绍，观众早走了。
3. **激励事件失格**：写了个开场（如收到一封信）但主角生活照旧，想判断它够不够格。
4. **改稿定位**：想调整激励事件的位置——提前还是推迟、要不要加次情节垫场。

### 语言信号 (用户的话里出现这些就应激活)

- "激励事件" / "inciting incident"
- "故事开头太平了" / "my opening is boring"
- "什么事件能打破主角的生活平衡" / "what can break the protagonist's balance"
- "讲了四十分钟还没进入正题" / "40 minutes without a real plot start"
- "这个开场算不算激励事件" / "does this opening count as an inciting incident"

### 与相邻 skill 的区分

- 与 `mckee-story-structure` 的区别: 结构 skill 是全局单位与价值转折度量衡；本 skill 聚焦五部分设计的第一环——启动事件的设计与定位。
- 与 `mckee-crisis-climax` 的区别: 激励事件在观众想象中**投射**"必备场景"影像；危机（必备场景）是故事末段对这一承诺的**兑现**。用户问"结局/危机/高潮怎么设计"时不要抢到本 skill。
- 与 `mckee-gap-writing` 的区别: 鸿沟驱动是场景内逐节拍制造张力的引擎；激励事件是故事级"打破平衡"的启动事件，二者是不同层级的动力。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **定位当前/草拟的激励事件并用四性质检验**
   - 操作：让用户描述故事与现状，找出或草拟候选激励事件，逐项对照四性质（打破平衡？不可逆转？上银幕？定位在前四分之一？），每项给出"是/否+证据"。
   - 完成标准: 输出一份四性质检验表（4 项逐项判定）；不满 4 项全过的列出具体缺口。

2. **构思或改写激励事件**
   - 操作：用"最好→最坏/最坏→最好"反转法为缺口生成 2-3 个候选事件（允许小动作）；对每个候选回答"它打破什么平衡、激起什么欲望、提出什么戏剧大问题、投射什么必备场景影像"。
   - 完成标准: 至少一个候选通过四性质全检，且能写出对应的戏剧大问题与必备场景画面。
   - 判停条件: 若素材不足以支撑（缺主人公欲望或世界规则不明），先补"故事脊椎提炼"（问：他要什么？自觉/不自觉？）再回到本步，不要硬造事件。

3. **验证定位时机与铺垫**
   - 操作：确定激励事件在整体进度中的位置；若在前四分之一之后，指定用哪条伏笔式次情节填补真空（对照次情节四关系：矛盾/回响/伏笔/纠葛）；检查开篇没有解说充塞。
   - 完成标准: 输出激励事件位置结论 + 铺垫方案 + "不归点"检查清单（确保此后的进展不再重复第一幕力度）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **次情节激励事件**：次情节的激励事件可以不出现在银幕上，本 skill 的"上银幕"铁律只约束主情节。
- **反情节/静观作品**：反结构影片可以以巧合统领全片；静观美学作品不以"打破平衡"为启动逻辑，本 skill 的"必须"全部失效。
- **非冲突本位文化叙事**：循环/顿悟/天人合一的时间观与主体观不预设"平衡被打破→求索"的模型。

### 作者在书中警告的失败模式

- **通病：习惯性推迟主情节、开篇塞解说**（第8章）：低估观众知识与生活经历，用繁琐细节展示人物与世界（观众凭常识便知），前三十页拖"解释性大肚子"——激励事件应按"观众能完全反应"的最早点引入。
- **"第二幕软肚子"苗头**（第9章）：激励事件后进展纠葛不越过"不归点"，让主角重复第一幕已失败的轻量级行动，故事循环、观众踩水。
- **风险缺失**（第7章）：主人公失败后"生活回到正常"则欲望无价值，激励事件再"打破平衡"也白搭。

### 作者的盲点 / 时代局限

- **"必须打破平衡"依赖冲突本体论**："冲突即生活本质"（萨特匮乏/海德格尔时间）只是诸多生活观之一，静观、无为、禅定等传统不以匮乏为本体，因而该"必须"对非冲突本位文化叙事未必成立。
- **求索故事的普遍性假设**：把一切故事收敛为"打破平衡→求索→（可能达成）"，对静观型、诗性、描绘型作品要么排除要么强加求索结构——有把描述性定义偷换为规范性标准的循环论证风险。
- **规则弹性**：作者自己承认《蜘蛛女之吻》推迟披露激励事件是"明智的例外"（为保住移情）——"必须"类断言应降级为"在经典设计语境下通常有效"，例外只在"用更重要的东西取代时"成立。

### 容易混淆的邻近方法论

- **激励事件 ≠ 开场第一件事**：激励事件是"打破平衡的事"，开场可以是平静日常（《洛奇》半小时铺垫）。
- **激励事件 ≠ 危机/高潮**：激励事件投射必备场景影像，危机/高潮是它的兑现；不要把"结局无力"的问题拉到激励事件来解决。
- **激励事件 vs 伏笔**：伏笔是早期事件为晚期事件做准备；激励事件投射必备场景是"预示"的首要组成部分。
