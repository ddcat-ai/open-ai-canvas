## I — 方法论骨架 (Interpretation)

人物内写作是一套"让作者钻进人物内部"的创作工作流，作家是笔下人物的第一个演员。起点是斯坦尼的"魔术般的如果"，但问法必须精确：不是"如果是我会怎么做"（演了自己），也不是"如果我的角色会怎么做"（坐回观众席猜测，必出陈词滥调），而是"如果我是这个人物，在此情此景我会怎么做"——只有这个问法才让作者用身体和情感即兴演绎人物，而非替人物猜情感。

要进入得够深，麦基配了三件工具：一是**四个自我**，把人格拆成社会自我（机构/权力中的面具）、个人自我（亲密关系里的角色）、核心自我（观察者）与最深层的隐藏自我（潜意识），每层都能单独成戏，层间张力即人物立体感；二是**自我故事访谈**，把人物请到对面椅子上讲他过去/现在/未来的自我故事，追问高点、低点、转折点与信仰——但一切自我陈述都自利失真，须拿他说的话与听者实际感受比对；三是**双向轮换**，内写作（从内到外）必须与由表及里（从现实/媒体/书本/实地取料）交替使用，素材不够时用四种研究（个人/想象/书本/实地）补给。整个过程遵循"创作即发现"：意义不是预设的，而是在即兴演绎中被意外撞见。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《广告狂人》——四自我在行动
- **问题**: 如何让主要人物立体到每一层都能单独成戏？
- **方法论的使用**: 麦基拆解马修·维纳的《广告狂人》：编剧们为每个角色开发了"工作生活/亲密生活/秘密生活"三层冲突，麦基补上第四层"潜意识生活"。于是唐·德雷柏被拆成四层——社会自我是能言善道的广告总监，个人自我是出轨的丈夫，核心自我是偷来身份的迪克·惠特曼（负罪良心的爱无能），隐藏自我是害怕人生无意义。
- **结论**: 对主要人物必须在四个自我层面做终极洞察；四层互相撕扯，人物立刻立体。
- **结果**: 六位主角人人四层齐备，观众被这些人物的复杂自我长期锁定。

### 案例 2: 作者演示"魔术般的如果"
- **问题**: 从零起步找故事，不知道写什么人物、什么事件。
- **方法论的使用**: 麦基把斯坦尼的"魔术般的如果"借给人物创作者，现场即兴："如果一条鲨鱼吃掉了一个度假者，什么样的人物会去追杀那条鲨鱼？""如果一个女人在经历了一个将近五十载的婚姻之后，发现她丈夫还一直暗恋着他的初恋……什么样的妻子会让这一揭示来毁掉她的幸福？"——先用如果造出激励事件，再追问"什么样的人物会如何反应"，由事件倒推出人物。
- **结论**: "如果……将会发生什么"常能激发激励事件，并进而激发出对其做出反应的人物，奠定故事走向。
- **结果**: 两个假设分别指向"鲨鱼猎人"式动作故事与《45年》式婚姻悲剧——同一句如果，两种截然不同的故事。

### 案例 3: 多克托罗——由表及里/从内到外双向轮换
- **问题**: 历史小说既要史实扎实又要人物鲜活，单走一条路径写不出两者。
- **方法论的使用**: 麦基指出多克托罗是"从两头向中间推进"的大师：先做世界级研究使自己成为该领域权威（由表及里），再进入人物内部即兴演绎、对自己的虚构添枝加叶（从内到外）。
- **结论**: 成熟作者必然双向轮换——先外部取料，再内部演绎。
- **结果**: 其虚构人物显得像历史真人，历史人物又显得像从独创头脑里即兴创作出来。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写某个场景时，人物反应怎么都像"正常人都会那样反应"，写出来是套话，用户想进入角色内心重写。
2. 要塑造"对外一套、对家人一套、心里另有秘密"的多面人物，不知道从哪几层下手。
3. 故事卡壳，想换一个切入点——从潜入人物而不是改情节来点火。
4. 人物小传/前史缺料，想用访谈方式挖出"人物自认为的自己"。

### 语言信号 (用户的话里出现这些就应激活)

- "写不出角色内心 / 他此刻在想什么"
- "怎么进入角色 / 如果我是他……"
- "人物多面 / 双重人格 / 表里不一"
- "给人物做个访谈 / 挖人物小传"
- 英文: "get inside the character" / "magic if" / "write in character" / "four selves"

### 与相邻 skill 的区分

- 与 `mckee-character-dimensions` 的区别: 维度设计器是静态地找"矛盾对"并检验三性（如一/多变/无解）；人物内写作是动态地"活进"人物去体验。先有维度可给内写作定靶向，先内写作可发现新维度，二者互哺但诉求不同。
- 与 `mckee-character-dilemma` 的区别: 两难设计器从外部构造"两个都要/两个都怕"的选择压力来逼真相；人物内写作进入内部体验人物会怎么选。两难给场景骨架，内写作给人物血肉。
- 与 `mckee-character-arc` 的区别: 弧光 skill 规划人物在整条时间轴上的"变化轨道"；内写作处理"此刻此场景里他是谁"的当下体验。
- 与 `mckee-character-essence` 的区别: 本质 skill 讲"人物≠人、矛盾之眼"的世界观；内写作是可执行的工作流。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **三问法校正：确认以"作为人物"而非"作为自己/观众"进入**
   - 完成标准: 用"如果我是这个人物，在这种情况下，我会怎么做"自问，并明确排除另外两种问法——"如果是我会怎么做"（演自己）与"如果我的角色会怎么做"（坐观众席猜测）；能说出一句人物专属的第一人称反应。
   - 判停条件: 若写出的反应是"正常人都会这样"，或你能预判它落入陈词滥调，说明落回了观众席猜测，回到本步重来。

2. **四自我分层填充：为人物配齐四层自我**
   - 完成标准: 为社会自我、个人自我、核心自我、隐藏自我各写出至少一条具体可写的行为/关系/矛盾（如"社会自我=能言善道的总监；核心自我=偷来身份的负罪者"），且层与层之间存在可感知的张力。
   - 判停条件: 若某层完全空白，用"自我故事访谈"（问高点/低点/转折点/信仰，警惕一切以"我"开头的自利陈述，比对"他说的话"与"你的感受"）把材料挖出来再回填。

3. **双向轮换校验：由表及里取料，从内到外演绎**
   - 完成标准: 把内写作的即兴结果与外部线索（背景/社会/年龄/前史/时代）对照，二者不冲突；若素材不足，按四种研究（个人记忆/想象拼贴/书本笔记/实地观察）补料后重演一遍。
   - 判停条件: 若即兴产物与设定打架，或发现其实在"主题先行"（先有观念再填人物），立即回到步骤1——意义应在演绎中被发现而非预设。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只需一份静态人物档案表格（生日/职业/爱好清单），不需要沉浸演绎。
- 主题先行型写作：用户已抱定"爱能救毒瘾"式信念，准备倒推情节与人物——这正是"创作即发现"的反向，内写作会被拿来当说教喉舌。
- 极端人物/荒诞喜剧：靠"删减"（减自我意识/深度/良心）造出的角色没有可潜入的内在，强用内写作反而失真。

### 作者在书中警告的失败模式

- 猜测式"人物内写作"（ce08）：问"如果我的人物处于这种情况会怎么做"=坐回观众席画像，猜出的情感几乎永远是陈词滥调。判据：你在"感人物之所感"还是"猜人物之所感"？
- "人物拒绝按我意图行事"=文学自恋（ce04）：声称人物有自己的意志、把写不下去推给人物"不听话"。人物是艺术品，作者永远是选择的唯一源泉——内写作里的惊奇是潜意识搅拌的结果，责任仍在作者。
- 把真人直接搬进作品（ce07）：由表及里取料不是照搬生活，要穿透浅表、挖掘沉默的真相，否则人物只是快照。
- 从信念倒推故事（ce05）：好人好到底、坏人坏到底、对白全是直奔主题的解读——这违背"创作即发现"。

### 作者的盲点 / 时代局限

- "完成人物"的黄金理想（不剩任何未表达之物）抹杀留白：麦基一边赞美现代/后现代传统里不可知的人物（品钦、贝克特），一边把"完全揭示"立为最高目标，两者未调和。内写作挖得再深，也不该把人物的不可穷尽性清空。
- 人物内写作高度依赖作者的潜意识与身体演绎，skill 只能给口令（"魔术般的如果"），无法替代体验——对不习惯即兴/表演式写作的作者可能不适用。
- 四自我框架以欧美个人主义的人格观为原型，对集体主义文化、无固定自我的叙事传统可迁移性存疑（全书样本欧美中心主义）。

### 容易混淆的邻近方法论

- "人物内写作"≠"心理现实主义分析"：不用理论标签去解剖人物，而是即兴活进人物。
- "四自我"≠"人格分裂"：四层是每个人身上都有的角色抽屉，不是病态设定。
- "自我故事访谈"≠"采访作者本人"：访谈对象是虚构人物，且默认其自我陈述自利失真。
