## I — 方法论骨架 (Interpretation)

七大关键步骤是故事的DNA，隐含于意念之中，不能从外部强加；本质是"人解决人生问题"的步骤，因此普适于任何媒介。

弱点/需求：主角内心的缺失，足以摧毁人生。必须分两层——心理层（只伤自己）与道德层（伤及他人）。道德需求测试法：主角开头须对至少一人造成明显伤害。且主角开头不得觉察自己的需求，须到结尾"真实自我揭露"时才察觉。

欲望：主角想要的具体外在目标。必须单一、从头贯穿到结尾、有可验证的时间点（观众能判定"达成/失败"），从低处起步逐步加码，不另起新欲望。

对手：与主角竞逐同一个目标的人，绝非"看起来像坏蛋"。只有对手够好、够"不可或缺"，主角才同样出色；对手是主角的分身而非仇人。

计划：击败对手的指导方针；没有计划就没有行动，且最初的计划几乎总会失败，迫使主角重寻策略。

对决：最后冲突，发生在最逼仄空间，核心是价值观之争而非力量之争。

真实自我揭露：主角首次看清自己是什么样的人。须突然、带新信息、以行动证明、不可由主角自己说出（可说教禁忌）；可由他人代受（如《教父》凯伊）。心理与道德双层。

新的平衡点：欲望消失后，主角抵达更高或更低的人生层次（堕落/毁灭亦为合法结果）。

两个推导工具：W×A=C（弱点和转变都是首要行动的对立面）；由结尾回溯（先定自我揭露→再回推需求与欲望）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《教父》七大步骤完整拆解（第3章）
- **问题**: 如何从单个故事中拆出七步骨架，并让它可复用？
- **方法论的使用**: 特鲁比完整拆《教父》——麦克弱点（年轻青涩过度自信）→心理需求（克服优越感）→道德需求（保护家族但避免残暴）→欲望（复仇护家）→对手（先索罗佐后巴兹尼）→计划（灭五族领袖）→对决（浸洗礼交叉剪辑）→真实自我揭露（麦克没有，改由凯伊代受）→新平衡（登基教父却堕落为魔鬼）。
- **结论**: 道德自我揭露可交给他人代受；七步既可从故事中拆出，也可反向构建。
- **结果**: 成为全书可复用的七步拆解模板。

### 案例 2: 《唐人街》对手竞逐同一目标（第3章）
- **问题**: 侦探故事里，凶手与侦探各忙各的，怎么算"竞逐同一目标"？
- **方法论的使用**: 克罗斯要人们相信"霍利斯意外溺毙、伊芙琳的女儿是外孙女"，杰克要人们相信"克罗斯杀人并强奸女儿"——两人真正争夺的是"谁口中的事实能取信于人"。
- **结论**: 对手即使藏为谜团直到结局，只要目标同一，多次正面冲突就成立。
- **结果**: 成为"对手与主角竞逐同一目标"的结构定义例证。

### 案例 3: 《唐人街》负向真实自我揭露（第3章）
- **问题**: 真实自我揭露只能"变好"吗？
- **方法论的使用**: 伊芙琳死后，杰克喃喃自语"愈少愈好"，相信自己的人生无用且具毁灭性——因为他再次伤害了自己爱的人。
- **结论**: 真实自我揭露可以是负向的、向下沉沦的认识。
- **结果**: 与正向揭露并列，说明新的平衡点可高可低，不必是"大团圆"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户有了前提，要"把主角和对手的骨架搭起来"。
2. 用户觉得"主角转变不可信、从头到尾没变化"。
3. 用户问"反派/对手怎么设计才不脸谱化"。
4. 用户想"从结尾倒推故事"。
5. 用户的主角的欲望说不清、没有具体的达成时刻。

### 语言信号 (用户的话里出现这些就应激活)

- "主角应该怎么转变？" / "character arc"
- "我的主角没有弱点" / "no weakness"
- "怎么设计对手/反派？" / "how to design antagonist"
- "真实自我揭露" / "self-revelation"
- "从结尾倒推设计" / "work back from the ending"
- "需求和欲望有什么区别？" / "need vs desire"
- "帮我搭故事骨架" / "skeleton of the story"

### 与相邻 skill 的区分

- 与 `story-premise` 的区别: premise 决定"写什么、值不值得写"；本 skill 把已确定的前提长成七步骨架。
- 与 `story-plot-22-steps` 的区别: 七步是骨架（一切故事的DNA）；22步是中段情节的细化地图（幽灵、触发事件、揭露、看似落败等）。用户问"中段怎么推进、信息怎么释放"时走 plot-22-steps。
- 与 `story-character-network` 的区别: 七步从"时间/发展"维度看主角；角色网络从"空间/比较"维度看所有角色彼此界定。用户问"配角为什么像纸片"时走 character-network。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **由结尾回溯**: 先定真实自我揭露（心理+道德双层）；再回推弱点/需求（注意：开头不得被主角觉察）。
   - 完成标准: 能写出一句真实自我揭露、一句心理需求、一句道德需求。
   - 判停条件: 若需求缺道德层（主角开头不伤害任何人），返回本步重设；反复无法通过则提示"道德需求测试"未通过，说明主角会沦为完美的人/受害人。

2. **依序构建欲望与冲突链**: 欲望（一句、有可验证时间点）→对手（竞逐同一目标，说出争夺物）→计划→对决。
   - 完成标准: 欲望能举出观众可判定的"达成/失败"时刻；对手与主角争夺的是同一具体目标；最初的计划明确会失败。

3. **完整性复核**: 用 W×A=C 检查弱点和转变是否都是首要行动的对立面；再按七步顺序对表，确认欲望单一、从低到高、未另起新欲望。
   - 完成标准: 七步齐全、W与C都是A的对立面、欲望线单一递增、真实自我揭露未由主角口头说出。
   - 判停条件: 若用户需要中段情节细节（触发事件、揭露序列、看似落败等），移交 story-plot-22-steps。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 仍在发散找前提、判断值不值得写 → story-premise。
- 无单一主角的群像/散点叙事 → 七步可每条线各建一套再合并，但纯散点无主角的叙事不适用。
- 追求"无人改变"的契诃夫式/反讽静止叙事 → 本 skill 默认主角转变。
- 只想要按页数切的三幕式 → 本 skill 是反三幕式的，无法提供"第一幕30页"式模板。

### 作者在书中警告的失败模式

- ce01 主角没有道德层面需求: 变成"完美的人或受害人……两种情况都是故事叙事的致命伤"（第3章）。
- ce02 混淆需求与欲望: "作者可能会犯的最大错误之一"（第3章）。
- ce03 以欲望开场跳过弱点/需求: "这不啻与魔鬼立下盟誓"（第3章）。
- ce04/ce05 对手是坏蛋、或不竞逐同一目标: "如果这样看待对立角色，你永远也无法写出好的故事"（第3章）。
- ce08 电灯开关学派的转变: 结尾按一下开关"'啪'的一声，角色就'转变了'。这种技巧行不通"（第4章）。
- ce09 主角开头觉察需求: "如果他一开始就知道自己的需求，故事也就结束了"（第3章）。

### 作者的盲点 / 时代局限

- "对手竞逐同一目标+主角个人转变"不适用于大量公认杰作（契诃夫、卡夫卡、品特、侯孝贤、阿巴斯）——本框架描述的是"一种"好故事，而非充分条件。
- 22步过度工程化风险：把七步进一步编号拆细有还原倾向，复杂故事连作者也承认难以完全套用。
- "道德论点"的规范性说教风险：对纯娱乐、纯形式实验、反道德模糊叙事的作品不友好。

### 容易混淆的邻近方法论

- 三幕式/节拍表: 按时间与页数切分；本 skill 按"人解决问题的步骤"组织，七步与页码无对应关系。
- 坎贝尔英雄之旅: 以外在旅程为主；本 skill 以弱点/需求与自我揭露的内在学习为核心，对手是结构性的"分身"，而非必须屠戮的恶龙。
