## I — 方法论骨架 (Interpretation)

前提=用一句话压缩整个故事：事件+感受+结局含义。它是灵感来源、枷锁与地基——"九成作者在前提阶段失手"，因为多数人抓住点子立刻动笔，从不探索。

正确做法是以"星期"为单位探索前提。十步检查法逐一过一遍：①写能改变你人生的东西 ②探索有哪些可能性 ③找出故事的挑战与问题 ④找出设计原则 ⑤确定最好的角色 ⑥思索中心冲突 ⑦思考单一因果关系线 ⑧确定可能的角色转变（W×A=C） ⑨找出可能的道德抉择 ⑩判定对观众的吸引力。任何一步出问题都可低成本修正。

设计原则=故事发展过程+独创性的手法，是藏在前提深处的种子；"所有故事都有前提，只有好故事有设计原则"。它是抽象深层过程（如《教父》="经典童话策略，最小的儿子成为新君王"），而前提是具体事件。

单一因果线规则：好故事只有一条主干 A→B→C→…→Z；缺主干或多主干都会崩解。用"主角的首要行动"找出主干。

探索工具："假如这样，结果会如何"——不断追问，让意念世界向内、向深处扩展，同时暴露作者自己真正关心什么。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《窈窕淑男》前提完整演练（第2章）
- **问题**: 如何把一个"男扮女装"的高概念点子撑成一个完整故事？
- **方法论的使用**: 特鲁比用它走完整十步——前提（演员找不到工作乔装成女人）、设计原则（"迫使一个男性沙文主义者过女人的生活"）、首要行动（乔装）、W×A=C（傲慢好撒谎→学会做更好的人）、道德抉择（放弃演出向茱莉道歉）。
- **结论**: 高概念只够撑两三个场景，必须靠前提阶段的完整设计补足。
- **结果**: 成为第二章的示范案例，其设计原则被反复引用，与《教父》的童话式设计原则并列。

### 案例 2: 《教父》W×A=C（第2章）
- **问题**: 若主角开头就已渴望复仇，故事还有转变吗？
- **方法论的使用**: A=复仇，取对立面得 W（事不关己、畏惧、循规蹈矩）、C（专横的家族独裁者）。
- **结论**: 首要行动必须与弱点相反，转变才可能发生；否则"原有的弱点只会不断强化"。
- **结果**: 作者称这是"解答问题的完美例子"，转变"极端却非常有说服力"。

### 案例 3: 《摩西五经》设计原则派生（第2/5/6/7章）
- **问题**: 如何证明设计原则真的是"故事的种子"？
- **方法论的使用**: 从同一设计原则（不知身份者追寻自由并接受新律令）推演出主题要旨、故事世界、象征概述。
- **结论**: 设计原则是抽象的深层过程，具体事件、世界、象征都从它生长。
- **结果**: 全书用这一个案例贯穿四章，证明子系统的同源性。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户有一个新点子，问"这个值得写吗/要不要继续"。
2. 用户发现前提"有两条主线、说不清主要讲什么"。
3. 用户没灵感、不知道写什么题材。
4. 用户担心自己的故事"太套路、像别人的翻版"。
5. 用户在动笔前想先验证"这个故事的独创性/设计原则"。

### 语言信号 (用户的话里出现这些就应激活)

- "这个点子值不值得写？" / "is this premise worth writing?"
- "我的故事好像有两条主线" / "two story lines"
- "完全没灵感，不知道写什么" / "out of ideas"
- "怎么让故事有独创性？" / "originality / design principle"
- "假如主角是……结果会如何？" / "what if ...?"
- "帮我想个故事前提" / "come up with a premise"

### 与相邻 skill 的区分

- 与 `story-organic-model` 的区别: organic-model 管总流程与"写什么>怎么写"的整体观；premise 是其中第一步的具体操作。用户已锁定具体点子要检验时走 premise。
- 与 `story-seven-key-steps` 的区别: 前提是种子、决定"该不该写"；七步是骨架、决定"故事怎么长"。前提已定要搭骨架时走 seven-key-steps。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **写一句话前提并建档**: 把点子压成一句话（事件+主角感受+结局含义），连同其他备选一起录入"故事前提清单"（每项一句）。
   - 完成标准: 前提能用单句说出且含三要素；无法压成单句即说明意念未成形。
   - 判停条件: 若用户已有确定前提且不想重新探索，跳到步骤2只做检验。

2. **用十步法逐项检验**: 对①-⑩每步给出答案，重点核对③挑战、④设计原则、⑦单一因果线、⑧W×A=C、⑨道德抉择。
   - 完成标准: 十项均有明确答案；任何一项答不上来=该前提有洞。
   - 判停条件: 若④设计原则无法用一句话说出"过程+独创手法"，判定前提不成立，回到步骤1重写。

3. **发散验证与收束**: 用"假如这样结果会如何"生成3-5条发展路径，择优深化；再复核单一因果线（只一条主干）。
   - 完成标准: 有1条被选中的路径，其前提句无分岔，能找到一句"主角的首要行动"把一切行动串成 A→Z。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 点子已成熟、用户在搭主角/对手骨架 → story-seven-key-steps。
- 已成稿要诊断结构问题 → story-plot-22-steps。
- 用户只想要类型模板（"给我一个侦探片套路"）→ 本 skill 明确反对用类型代替设计原则。
- 命题创作/委托创作（前提由外部给定）→ 十步法中"写能改变你人生的东西"不适用，只能走后半段检验。

### 作者在书中警告的失败模式

- ce11 抓住热门前提立刻动笔: "故事进行到二三十页时，你就会走进死胡同"（第2章）。
- ce12 复制某部电影的意念: "看不出作者的任何个人特质……注定失败"（第2章）。
- ce13 用类型模板代替设计原则: 完成的是"普通的、机械的、缺乏独创性的虚构故事"（第2章）。
- ce14 前提有分岔（两条因果线）: "故事如果缺少主干，或有太多主干，就会彻底崩解"（第2章）。
- ce10 虚假道德抉择（善恶二选一）: "结果未免太明显"，主题被稀释（第2章）。

### 作者的盲点 / 时代局限

- "写什么>怎么写"假定作者有能力自我探索；对委托创作、命题创作（外部给定前提）几乎没有方法论。
- 要求独特道德愿景的原创，却未给出"如何生成独特世界观"的操作路径。
- 2007年成书，其"前提需与作者个人深度相关"的立场，与高概念、类型优先、算法推荐的网生内容逻辑可能冲突。
- 反复以"好莱坞全球卖座"为正面参照，隐含市场成败作为质量尺度的预设。

### 容易混淆的邻近方法论

- logline / 高概念营销句: 那只是"看似有商业潜力的句子"，只够撑两三个场景，不是好前提。
- 故事梗概/synopsis: 梗概是概述已有故事；前提是下笔前用来探索的种子。
