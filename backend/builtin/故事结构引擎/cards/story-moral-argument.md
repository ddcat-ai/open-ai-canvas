## I — 方法论骨架 (Interpretation)

- 主题不是题材（死亡/自由/爱），而是作者"如何待人处世"的道德愿景；第一步把它压缩成一句"主题要旨"，原料来自设计原则中"只受道德影响而存在的行动"。
- 道德论点的基本策略是一条行动序列：价值取向 → 道德弱点 → 道德需求 → 第一次不道德行动 → 欲望 → 不道德行动（每步配"批判+辩白"）→ 盟友的攻击 → 执迷不悟的驱动力 → 更甚的不道德行动 → 对决 → 针对对手的最后行动 → 道德自我揭露 → 道德抉择 → 主题揭露。它描绘"主角变好之前必须先变得更坏"。
- 主题必须通过结构传达：故事中段冲突增强使结构收敛，收敛点=对决，其后自我揭露、道德抉择、主题揭露逐次扩展——"结构收敛之处即主题扩展之时"。说教是技巧失败的标志。
- 五种变奏可选：善与恶、悲剧、动之以情、讽刺/嘲讽、黑色喜剧；变奏数量不限，可合并。
- 对等道德抉择：两个选项必须尽量对等、同时正向或同时负向，让抉择真正"筛出"主题；虚假抉择（正vs负）结果太明显。
- 双重逆转：让主角与对手双双获得真实自我揭露、互相学习，观众得到"两种体悟"，作者的道德愿景=两人所学之精华。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《卡萨布兰卡》——以行动表现的道德论点
- **问题**: 如何让"牺牲爱情、投身反法西斯抗争"的主题不被说教化？
- **方法论的使用**: 特鲁比逐项填写基本策略序列：瑞克的信念（自我、诚实、朋友）→道德弱点（愤世嫉俗、自我中心、残酷）→第一次不道德行动（收下乌加特来路可疑的通行证）→欲望（得到伊尔莎）→不道德行动（称她荡妇、市集求欢）→盟友攻击（山姆劝他别沉溺）→执迷驱动力（由伤害伊尔莎转为助她逃亡）→对决（机场持枪）→自我揭露（爱不及抗纳粹重要）→道德抉择（放手让伊尔莎随拉兹洛离开）→主题揭露（雷诺转向加入抗争，双重逆转）。
- **结论**: 主题完全靠行动与结构传达，主角的道德抉择成为整个结构的顶点；观众在选项张力中自行体会论点。
- **结果**: 成为全章"以行动表现道德论点"的教科书范例；雷诺的转向被标为"双重逆转的经典例子"。

### 案例 2: 《唐人街》——负向的道德论点与自我揭露
- **问题**: 悲剧故事如何传达道德论点而不落入"善有善报"的简单框架？
- **方法论的使用**: 杰克的真实自我揭露是负向的——伊芙琳死后他喃喃自语"愈少愈好"，相信自己的人生不但无用、更具毁灭性，因为他再次伤害了自己爱的人；道德论点不要求主角变好，而是证明"人如何沉沦"。
- **结论**: 主题通过结构的负向收束传达，与《卡萨布兰卡》的正向论点形成对照——论点方向由作者道德愿景决定，而非一律"成长"。
- **结果**: 作为"负向真实自我揭露"的典型例证，与《长大》《卡萨布兰卡》等正向揭露并列。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 故事写完感觉很空，说不出它想表达什么，或主题只停留在"死亡/爱/自由"这类题材词。
2. 角色动不动就发表人生感悟、对白变成道德训诫，观众看完只觉得被说教。
3. 主角的终极选择是"好事 vs 坏事"，结果太明显，选择本身没张力。
4. 想要"主角和对手双双转变"的双重逆转式结尾，但不知道如何落地。

### 语言信号 (用户的话里出现这些就应激活)

- "故事好空洞 / 没有主题 / 不知道想表达什么" — "the story feels empty / no theme"
- "太说教了 / 角色在喊口号" — "too preachy / didactic / characters lecturing"
- "道德抉择 / 两难 / 怎么选都亏" — "moral dilemma / lose-lose / impossible choice"
- "主题要旨 / 道德论点 / 用结构传达主题" — "theme statement / moral argument"
- "双重逆转 / 主角和对手都改变" — "double reversal / both characters change"

### 与相邻 skill 的区分

- 与 `story-character-network` 的区别: 后者把主题织进角色群（每个配角是道德难题的一种变奏），本 skill 把主题织进**时间序列**（道德论点的推进步骤与结构节点）。说"配角各持一种立场"→ 网络 skill；说"主题该怎么展开、怎么收束"→ 本 skill。
- 与 `story-antagonist-design` 的区别: 后者只借用"给对手有力但有缺陷的道德论点"服务对手立体化；本 skill 用整个序列设计整条主题论证，对手辩白只是其中一个节点。
- 与 `story-seven-key-steps` 的区别: 道德抉择也出现在七步中，但本 skill 把它当作"主题筛子"系统设计（对等选项+变奏+双重逆转），而非结构步骤的组成部分。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **把道德愿景压缩成一句"主题要旨"**
   - 完成标准: 一句话写清"主角做了什么行动、这个行动的对错、以及它对人生的影响"（格式：某人做某事→对/错→带来什么后果）；对照检查：若写出的仍是"死亡/自由/爱"这类题材词而非行动论点，则重写。
   - 判停条件: 若用户明确表示"这个作品不想传达任何道德观点"，跳到 B 段反场景。

2. **按基本策略序列铺陈，并选定变奏**
   - 完成标准: 依序列出全部节点（价值取向→道德弱点→道德需求→第一次不道德行动→欲望→驱动力→不道德行动→批判→辩白→盟友攻击→执迷不悟的驱动力→更甚的不道德行动→对决→自我揭露→道德抉择→主题揭露），每个不道德行动配一对"批判+辩白"；从五种变奏（善与恶/悲剧/动之以情/讽刺/黑色喜剧）中选定并标注理由。
   - 判停条件: 若自我揭露与道德抉择落在故事中段（如《大审判》25分钟处），须把道德张力延后到接近结尾——否则停止并重排。

3. **设计对等道德抉择，并检查双重逆转**
   - 完成标准: 道德抉择的两个选项同时正向或同时负向、尽量对等、其中一个稍好；写清选择暴露了主角何种价值观。随后判断对手是否"有人性、能学习"：若是，让双方在对决中同时获得真实自我揭露，把作者的道德愿景写成两人所学之精华（双重逆转）。
   - 完成标准: 做"删口号测试"——把对白中所有主题口号删掉后，主题是否仍能从对决/揭露/抉择中被读出；若删掉即消失，说明仍在说教，回到步骤 2 用结构补足。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯娱乐、纯形式实验、反道德模糊叙事：作者并不打算传达"如何待人处世"的观点，本 skill 的规范性前提不成立。
- 作者本就意图说教的作品（如劝世文、政策宣传）：本 skill 要求隐藏论点，与目标冲突。
- 无道德维度的氛围/静物/意识流叙事：没有"主角的道德行动"可编排。

### 作者在书中警告的失败模式

- ce10 "让主角面对虚假的道德抉择"——在正与负之间二选一，结果太明显，主题被稀释。
- ce15 "用说教方式传达主题"——让道德训诫淹没故事，沉重乏味，观众却步。
- ce16 "道德层面的自我揭露与抉择过早出现"——《大审判》在25分钟处解除道德风险，后半段张力归零。
- ce17 "只使用善与恶的二元对立"——没有道德对立网络，论点过于简单。

### 作者的盲点 / 时代局限

- BOOK_OVERVIEW 批判 #4："好的故事必须是道德论点"是未经证明的规范性假设——它将艺术窄化为道德论证工具，对纯娱乐、纯形式实验、反道德模糊叙事的作品不友好；"道德论点"这一术语本身也有滑向价值观灌输的风险。
- 对契诃夫式"无人改变"的反讽性静止、东方留白美学的叙事（BOOK_OVERVIEW 批判 #3/#8），此框架只能作反例，无法提供等效的正向方法论。

### 容易混淆的邻近方法论

- 与"主题象征"（f28）的混淆: 象征网络用"指引与重现"承载主题，本 skill 用行动序列承载主题；两者可并用，但检查标准不同。
- 与"对等道德抉择"（f24）的混淆: 对等抉择只是序列的一个节点，不是全部；只设计一个漂亮抉择而不管序列，主题仍会断裂。
