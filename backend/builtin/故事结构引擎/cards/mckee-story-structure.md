## I — 方法论骨架 (Interpretation)

**故事价值**是麦基衡量一切事件是否成立的统一尺子：任何人类经验中可正负两极转化的特质——生/死、爱/恨、自由/奴役、正义/非正义——都可以押上台面，成为"此刻谁赢谁输"的计量单位。

**结构即对事件的选择与排序**，单位由小到大分五级，每一级以"价值变化的冲击力"定义，而不是以字数或时长定义：
1. **节拍**：最小的动作/反应交换单位（一个动作、一个回应）；
2. **场景**：一次完整的价值转折（正→负或负→正），是理想状态下的最小完整事件；
3. **序列**：2-5 个冲击力递增的场景，终结于"适中"转折；
4. **幕**：一串序列合成的重大价值逆转，冲击力强于前面一切；
5. **故事**：最后的幕高潮带来绝对而不可逆转的终极变化。

**场景的硬标准**：写前记下开篇价值负荷，写完记下结尾负荷并比较。若相同，则只有活动、没有行动，是"非事件"——它唯一的合法用途是解说，否则直接删除。

**三条支撑性创作纪律**（让写出的场景不陈词滥调）：①创作限制原理——背景必须"小且可知"，世界越大知识越稀释、选择越少、陈词滥调越多；②研究三法——记忆/想象/事实三路饱和研究，直到人物"自己活起来"；③创作选择清单——为一个决策列 10-20 个候选再筛（哪个对人物最真实/对世界最真实/从未上过银幕），警惕"第一个想法必是陈词滥调"。

**用法**：既可自上而下拆解（标价值→查转折→剔非事件），也可自下而上构建（让节拍建场景、场景建序列、序列建幕、幕建故事）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《克莱默夫妇》的法式烤面包场景
- **问题**: 一个丈夫笨手笨脚给儿子做法式烤面包的早餐，表面毫无情节，为何成为电影史上最难忘的场景之一？
- **方法论的使用**: 麦基用"价值转折"+冲突层面拆解：这一场景在三种价值轴上同时发生转折——父亲的自信（正→负→正）、孩子对父亲的信任与崇拜（正→负→正）、家庭生存（正→负→正），且三线在内心/个人/个人外三个层面交织。
- **结论**: "复杂型故事"不需增生人物与景点，把精力集中于在多个价值层面同时做转折的场景即可。
- **结果**: 一个几乎无对白的三分钟早餐场景，承载整部影片的情感核心。

### 案例 2: 《温柔的怜悯》——"生活故事"与"被讲述的故事"
- **问题**: 观众看完后能复述出斯莱奇从出生到落魄的整个人生，可影片根本没拍那些年。
- **方法论的使用**: 麦基以此例说明"结构=对事件的选择"：影片只选取他穷愁潦倒醒来的那个早晨及其后一年的几个瞬间，在生活漫流中取、舍、排序。
- **结论**: 大师的标志是只挑选几个瞬间，却能向观众展示其整个人生。
- **结果**: 该片曾被评论家误称"没有情节"，实则是穿越最艰难地貌（主人公内心）的精妙设计。

### 案例 3: 剧本咨询——背景是"美国"太大了吗
- **问题**: 作者回答"你的背景是什么？""美国。"然后写不出不陈词滥调的场景。
- **方法论的使用**: 用创作限制原理追问："有没有更具体的街区？"牛轭湖的夫妻分手与公园大道上的离婚诉讼绝无相似之处。
- **结论**: 世界越小，作者的知识越完善，创作选择越多；一个诚实的故事只在一个具体时空适得其所。
- **结果**: "小可知世界"成为对抗陈词滥调的源头纪律。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **改稿卡壳**：写完一稿觉得某些场景"没劲/可删可不删"，说不清为什么。
2. **大纲分层**：刚写完大纲或分场，想按节拍→场景→序列→幕重新梳理，检查结构是否成立。
3. **世界过大**：背景设定在"美国""未来世界"等大而空的范围，写不出具体细节，只能靠套路。
4. **评审他人剧本**：读别人作品时想快速判断某个场景是否成立、该不该留。

### 语言信号 (用户的话里出现这些就应激活)

- "这个场景有转折吗？" / "Does this scene turn?"
- "哪些场景是多余的？" / "which scenes are non-events?"
- "按节拍、场景、序列、幕帮我理结构" / "beat, scene, sequence, act"
- "我的故事世界太大了" / "my world is too big"
- "押上台面的价值是什么" / "what value is at stake"

### 与相邻 skill 的区分

- 与 `mckee-scene-analysis` 的区别: 本 skill 提供"价值转折"这一度量衡与五级单位坐标系；场景分析五步法是**拿到已有场景后的拆解显微镜**（冲突→价值→节拍→转折点）。先有度量衡，再有分析程序。
- 与 `mckee-inciting-incident` 的区别: 本 skill 管全局单位与场景自检；激励事件是五部分设计（激励事件→进展纠葛→危机→高潮→结局）的第一环，是"设计启动事件"的专项。
- 与 `mckee-act-design` 的区别: 本 skill 讲单位是什么、场景成立与否；幕节奏（正负交替、回报递减、三幕底线）是"多幕如何排序"的专项。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **标注每个场景的开篇与结尾价值**
   - 操作：列出剧本/大纲所有场景，逐一写出"押上台面的价值 + 开篇正负 + 结尾正负"（如"自由：开篇负→结尾正"）。
   - 完成标准: 每个场景都有一行明确的"价值：开篇=正/负，结尾=正/负"记录；找不出价值轴的场景标注"价值不明"。

2. **剔除或改写"非事件"**
   - 操作：凡开篇价值=结尾价值的场景，判断其是否承担解说功能；否则删除，是则改写为"在冲突中让价值发生转折"的解说场景（把解说转化为人物的斗争弹药）。
   - 完成标准: 全部场景的结尾价值 ≠ 开篇价值，或改写后已发生转折。
   - 判停条件: 若删掉某场景会导致关键信息缺失，不要直接删——跳到"改写为有转折的场景"而非保留原样。

3. **自下而上验证五级合成**
   - 操作：将相邻场景归为序列（2-5 个），检查每个序列终结处的冲击力是否递增；再将序列归为幕，检查幕高潮是否造成"重大逆转"且后幕与前幕价值负荷交替。
   - 完成标准: 每层都写出"序列X终结转折=适中/重大"的判断，且全片从开篇价值到故事高潮价值形成一条单调加深的"电影弧光"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **静观美学作品**：以阿巴斯、小津、蔡明亮为代表的"拒绝价值转折、拒绝因果"的影片，其美学立场恰恰是静止与留白——用"场景必须转折"要求它们等于判它们出局。
- **无叙事内容**：纯氛围散文、意象诗、图片流、音乐视频，本身不承诺"事件序列"，没有可计量的价值轴。

### 作者在书中警告的失败模式

- **非事件充数**（第2章）：开篇与结尾价值相同的"场景"只有活动没有行动，作者往往用它塞解说，自问"为什么采用这个场景"时答不上来。
- **迷信灵感**（第3章）：第一个蹦进脑海的想法是记忆库存里的陈词滥调；只设计了恰好填满剧本数量的场景，从不列候选清单再筛选。
- **幕高潮繁殖**（第9章）：为填更多幕强行制造"重大"高潮，最后靠生/死反复出现充数，观众打呵欠——"重大"是相对"适中"与"细微"而言的。

### 作者的盲点 / 时代局限

- **大情节中心主义**：把最小主义、反结构当"对经典形式的反应"，隐含以经典设计为基准的价值判断；"经典设计是人类思维的镜像"是断言而非实证。
- **荣格-坎贝尔原型依赖**："普遍叙事形式"与"集体无意识"假设缺乏跨文化实证，东方静观传统、非冲突本位文化叙事未必适用"场景必须转折"。

### 容易混淆的邻近方法论

- **"场景=地点/镜头"的常识**：麦基的场景是"价值转折的完整单元"，可跨时空游移，勿按拍摄地切分。
- **起承转合式框架**：那只是外在分段；麦基的单位定义内含价值变化的计量。
- **剧集集末钩子**：那是平台观看机制，不是本 skill 的价值转折单位。
