## I - 方法论骨架

孙子把“赢”分层：最差是硬攻，较好是打兵，更好是破坏对方联盟，更高是瓦解对方策略，最好是不用正面冲突就达成目标。全胜不是面子上的胜，而是保全资源、时间、关系、市场、组织和后续行动空间。

这个 skill 用来把“我要赢”改写成“我能不能让对方不用硬打就改变选择”。

## A1 - 书中的应用

### 案例 1：百战百胜不是最高

- 问题：把胜利理解为每次都硬打赢。
- 方法：孙子明确说百战百胜不是最高明。
- 结论：战略价值要扣除代价。

### 案例 2：伐谋优于攻城

- 问题：对方方案和联盟仍完整，硬攻成本极高。
- 方法：先伐谋，再伐交，再伐兵，最后才攻城。
- 结论：现代竞争中先处理策略、关系和选择空间。

### 案例 3：全争于天下

- 问题：赢了一个点却破坏整体资源。
- 方法：以全争，保留可持续收益。
- 结论：不要用破坏性胜利换短期爽感。

## A2 - 触发场景

### 用户会在什么情境下需要这个 skill?

1. 有冲突但不想升级成公开撕裂。
2. 竞争中可以通过定位、联盟、规则、谈判改变局面。
3. 硬攻成本太高，需要找到替代路径。
4. 用户提到不战而胜、伐谋、伐交、攻城下策。

### 语言信号

- “怎么不战而屈人之兵？”
- “有没有办法不撕破脸赢？”
- “这个冲突能不能降级？”
- “上兵伐谋在商业里怎么用？”
- “我不想打价格战，有没有别的赢法？”

### 与相邻 skill 的区别

- 与 `temple-calculation` 的区别：本 skill 已经知道目标，重点找低损路径。
- 与 `void-solid-flexibility` 的区别：后者找虚处突破；本 skill 优先避免冲突本身。
- 与 `know-self-know-enemy` 的区别：本 skill 会用情报，但重点是冲突降级。

## E - 可执行步骤

1. **定义真正目标**
   - 完成标准：把“打赢对方”改写为可交付结果，例如拿下客户、保住团队、改变规则。
2. **列四级路径**
   - 完成标准：分别写出伐谋、伐交、伐兵、攻城对应的现代动作。
3. **优先低损方案**
   - 完成标准：选择能保全价值、降低对抗、缩短周期的方案。
4. **设置不升级边界**
   - 完成标准：明确哪些动作会越界、违法、伤害关系或把冲突升级。

## B - 边界

### 不要在以下情况使用

- 用户要求操纵、诈骗、胁迫、威胁或现实伤害。
- 必须依法维权、医疗救助或安全防护时，不能为了“不战”拖延必要行动。
- 用户只想要战术动作，不关心保全价值。

### 失败模式

- 把不战误解为软弱逃避。
- 把伐谋误解为阴谋害人。
- 为了避免冲突而放弃真正目标。

### 来源边界

本 skill 依据《谋攻》为主，现代使用必须合法、非伤害、保全长期价值。
