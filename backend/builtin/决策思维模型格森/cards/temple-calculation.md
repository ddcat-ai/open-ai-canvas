## I - 方法论骨架

“庙算”就是行动前的胜算审计。孙子不鼓励先冲再说，而要求先比较五类变量：道是共同目标，天是时机周期，地是环境和路径，将是领导能力，法是组织制度。然后用七计比较双方条件，把直觉变成清单。

这个 skill 的作用是把一个“想做”的冲动，变成“能不能做、值不值得做、缺哪一算”的判断。

## A1 - 书中的应用

### 案例 1：始计以五事开篇

- 问题：战争代价巨大，不能凭情绪启动。
- 方法：先审道、天、地、将、法。
- 结论：不知道这些条件，就没有资格判断胜负。

### 案例 2：七计做敌我比较

- 问题：单看自己强弱不够，要比较双方。
- 方法：“主孰有道？将孰有能？天地孰得？法令孰行？”
- 结论：胜算来自相对优势，而不是自我感觉。

### 案例 3：多算胜

- 问题：行动前算得越少，失败概率越高。
- 方法：把未知项列出来，不能用口号填补。
- 结论：没算清时，最好的动作通常是补信息。

## A2 - 触发场景

### 用户会在什么情境下需要这个 skill?

1. 准备启动项目、竞争、谈判、投资、转型或公开冲突。
2. 不确定自己和对手谁更有优势。
3. 团队热血上头，需要冷静评估。
4. 想用孙子兵法做行动前清单。

### 语言信号

- “这仗值不值得打？”
- “帮我做个庙算。”
- “五事七计怎么套到这个项目？”
- “我胜算有多大？”
- “现在是不是少算了？”

### 与相邻 skill 的区别

- 与 `know-self-know-enemy` 的区别：本 skill 是总评估框架；后者专门补情报。
- 与 `terrain-context-diagnosis` 的区别：本 skill 包含地形但不深入场景分类。
- 与 `command-discipline-control` 的区别：本 skill 评估将与法；后者诊断组织执行。

## E - 可执行步骤

1. **列五事**
   - 完成标准：写出本行动的共同目标、时机、环境、负责人能力、制度资源。
2. **做七计比较**
   - 完成标准：逐项比较己方、对手或替代方案，标出优势、劣势、未知。
3. **计算缺口**
   - 完成标准：说明哪些变量没有证据，哪些变量是致命短板。
4. **输出行动判断**
   - 完成标准：给出可战、缓战、避战、补算、换战场或改目标。

## B - 边界

### 不要在以下情况使用

- 用户请求现实暴力、违法攻击、骚扰、诈骗或规避监管。
- 问题只是低代价日常选择，不需要复杂庙算。
- 用户已经进入执行中，核心问题是资源失控或组织纪律。

### 失败模式

- 把五事七计当空泛 SWOT。
- 只算己方，不算对手和环境。
- 用热情替代证据。

### 来源边界

本 skill 依据《始计》为主，并结合全书胜算思想；现代使用只限合法、非伤害性的战略评估。
