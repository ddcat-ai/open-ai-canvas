## I - 方法论骨架

虚实不是玄学，而是资源密度和响应能力：实处是对方准备充分、资源厚、反应快的地方；虚处是对方顾不到、反应慢、约束多或心理预期之外的地方。孙子要求避免在对方最硬处证明自己，而是通过机动、分散、错位和无形，找到低阻力突破口。

这个 skill 帮用户把“我要正面赢”改成“哪里最值得突破”。

## A1 - 书中的应用

### 案例 1：避实击虚

- 问题：正面硬攻成本高。
- 方法：避开实处，攻击虚处。
- 结论：胜利来自选择战场，而不是蛮力。

### 案例 2：趋其所不意

- 问题：对方已经准备好应对常规路线。
- 方法：走对方没有预期、响应慢的路径。
- 结论：突破点常在非主战场。

### 案例 3：至于无形

- 问题：配置被对方看透，就会被针对。
- 方法：隐藏真实重心，保持灵活。
- 结论：现代可迁移为低调试点、分阶段公开、资源不早暴露。

## A2 - 触发场景

### 用户会在什么情境下需要这个 skill?

1. 对手明显更强，正面竞争不划算。
2. 用户需要找市场、谈判、组织或产品突破口。
3. 当前路线被对手或环境卡死。
4. 用户提到虚实、避实击虚、突破点、错位竞争。

### 语言信号

- “对手太强，我该打哪里？”
- “怎么避实击虚？”
- “这个市场有没有虚处？”
- “哪里是低阻力突破口？”
- “我是不是在撞对方最硬的地方？”

### 与相邻 skill 的区别

- 与 `know-self-know-enemy` 的区别：本 skill 使用情报来选择突破口。
- 与 `deception-and-shaping` 的区别：后者造势和示形；本 skill 选虚处。
- 与 `win-without-fighting` 的区别：如果可不冲突达成目标，优先后者。

## E - 可执行步骤

1. **标出实处**
   - 完成标准：列出对方准备充分、资源密集、品牌强、渠道强、规则强的位置。
2. **寻找虚处**
   - 完成标准：列出被忽视人群、低响应场景、边缘渠道、未满足需求、对方成本高的位置。
3. **设计错位动作**
   - 完成标准：选择一个低成本试点或侧翼路径，避开主战场。
4. **保持可变形**
   - 完成标准：说明哪些信息暂不暴露，哪些资源保持机动，何时转向。

## B - 边界

### 不要在以下情况使用

- 用户想攻击弱势对象、规避法律责任或做伤害性报复。
- 问题需要公开透明处理，例如安全事故、合规披露。
- 用户没有基本能力，只想找“投机漏洞”。

### 失败模式

- 把虚处等同于弱者，忽略伦理边界。
- 只绕开强点，不建立自己的强点。
- 试点太隐蔽，导致团队也不知道方向。

### 来源边界

本 skill 依据《虚实》为主，并结合《兵势》《九变》；现代迁移限于合法竞争和项目策略。
