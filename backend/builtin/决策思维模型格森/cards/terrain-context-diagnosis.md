## I - 方法论骨架

孙子的“地形”可以迁移为环境约束：市场结构、渠道距离、资源路径、组织位置、退路、进入深度和对手反应。九地则像处境分类：散地、轻地、争地、交地、衢地、重地、圮地、围地、死地。策略不能脱离场景，同一动作在通地可行，在隘地可能堵死，在死地可能激发背水一战。

这个 skill 的作用是防止照搬策略。

## A1 - 书中的应用

### 案例 1：地形六类

- 问题：同一军队在不同地形中行动结果不同。
- 方法：区分通、挂、支、隘、险、远。
- 结论：现代要区分开放市场、卡口渠道、双边平台、监管壁垒等场景。

### 案例 2：九地看深入程度

- 问题：进入越深，退路、士气、补给、协作都会变。
- 方法：用九地判断处境。
- 结论：项目早期、扩张期、孤注一掷期不能用同一管理方式。

### 案例 3：途有所不由

- 问题：不是所有路线都值得走。
- 方法：即使有路，也要看代价和局势。
- 结论：现代策略要明确“不走哪些路”。

## A2 - 触发场景

### 用户会在什么情境下需要这个 skill?

1. 准备进入新市场、新渠道、新组织环境。
2. 想复制别人策略，但不确定场景是否一致。
3. 项目进入深水区，退路、补给、士气发生变化。
4. 用户提到地形、九地、争地、死地、围地。

### 语言信号

- “这个策略能不能照搬？”
- “我现在处在什么地形？”
- “九地怎么用于市场进入？”
- “是不是进入太深没有退路了？”
- “哪些路不该走？”

### 与相邻 skill 的区别

- 与 `temple-calculation` 的区别：本 skill 细看环境变量。
- 与 `short-war-resource-control` 的区别：环境可能导致拖长，后者处理消耗。
- 与 `void-solid-flexibility` 的区别：地形诊断后，才找虚处突破。

## E - 可执行步骤

1. **描述环境**
   - 完成标准：列出市场、渠道、组织、资源、监管、路径、退路、对手位置。
2. **匹配地形/九地**
   - 完成标准：给出 1-2 个最像的地形或九地，并解释。
3. **推导限制**
   - 完成标准：说明哪些动作不该做，哪些路线成本高，哪些位置必须抢。
4. **调整策略**
   - 完成标准：给出适合该场景的行动、退路、补给和节奏。

## B - 边界

### 不要在以下情况使用

- 用户请求现实军事部署或伤害性行动。
- 问题纯粹是个人习惯，不涉及环境差异。
- 用户只想要励志口号。

### 失败模式

- 拿一个成功案例生搬硬套。
- 只看机会，不看退路和补给。
- 把“死地”浪漫化，忽略真实风险。
