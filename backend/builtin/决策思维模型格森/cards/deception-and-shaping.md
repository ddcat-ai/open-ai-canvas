## I - 方法论骨架

孙子的“诡道”不是现代违法欺诈，而是竞争中的信息呈现、节奏控制和预期管理：能而示不能、近而示远，目的是让对手无法准确配置资源。更深一层是“势”：通过结构、节奏、配置和奇正组合，让局面自然向自己有利处倾斜，而不是靠个人硬扛。

这个 skill 的现代安全版用途是：合法地设计发布节奏、资源配置、谈判顺序、公开信号和备选路线。

## A1 - 书中的应用

### 案例 1：因利制权

- 问题：计划不能机械执行。
- 方法：根据利益和局势变化调整权变。
- 结论：策略不是固定脚本，而是随势塑形。

### 案例 2：奇正相生

- 问题：只有常规打法容易被预判。
- 方法：正面动作稳定基本盘，奇兵动作创造突破。
- 结论：现代可转为主线产品加侧翼实验、公开议程加私下谈判。

### 案例 3：求之于势

- 问题：组织总靠个人加班和英雄主义。
- 方法：设计势，让系统推动结果。
- 结论：好策略让普通执行也能产生动能。

## A2 - 触发场景

### 用户会在什么情境下需要这个 skill?

1. 需要设计竞争发布、谈判节奏、市场预期或资源配置。
2. 想用奇正组合，而不是单一路线。
3. 团队太依赖个人英雄，需要系统造势。
4. 用户提到诡道、势、奇正、示形。

### 语言信号

- “兵者诡道也，现代怎么用才不越界？”
- “我怎么造势？”
- “奇正怎么组合？”
- “怎么让对手不好判断我的节奏？”
- “不要靠个人硬扛，怎么求之于势？”

### 与相邻 skill 的区别

- 与 `void-solid-flexibility` 的区别：本 skill 设计势和信号；后者选择虚处突破。
- 与 `win-without-fighting` 的区别：本 skill 可用于竞争动作；后者优先冲突降级。
- 与 `know-self-know-enemy` 的区别：本 skill 使用情报来塑形，但不负责情报获取。

## E - 可执行步骤

1. **定义合法边界**
   - 完成标准：排除诈骗、窃密、虚假陈述、隐瞒重大风险、伤害性操控。
2. **设计正面动作**
   - 完成标准：明确稳定基本盘的公开动作、常规承诺和主线资源。
3. **设计侧翼动作**
   - 完成标准：明确低成本实验、备选路线、节奏变化或预期管理动作。
4. **形成势能**
   - 完成标准：说明这些动作如何让局面向自己有利处倾斜，并设复盘信号。

## B - 边界

### 不要在以下情况使用

- 用户要求诈骗、伪造、窃密、操纵个人或违法规避。
- 用户面对信任关系，需要透明沟通而不是信息博弈。
- 用户没有基本实力，只想靠包装制造假象。

### 失败模式

- 把诡道误解为不择手段。
- 奇招太多，正面基本盘崩掉。
- 只追求让对方误判，不考虑长期信誉。

### 来源边界

本 skill 依据《始计》《兵势》《虚实》的合法迁移，不提供伤害性或违法操作。
