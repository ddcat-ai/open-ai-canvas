# 剪辑与交付验收

## 何时用

- 用户要把一串片段装成可交付成片。
- 需要逐镜入出点、取舍理由、字幕对齐或响度统一。
- 成片“看着都对但就是不完整”，需要交付前检查。

不重新写分镜，不改提示词；素材缺镜头时明确回退到生成或补拍。

## 剪辑单

每个采用镜头至少记录：

```text
来源素材与路径
入点
出点
时长
取舍理由
字幕逐字内容
```

取舍理由只写三件事：推进信息、建立关系、提供情绪反应。三者都没有的镜头应删。

## 剪切原则

- 优先在动作变化、视线变化、信息揭示和声音落点上切。
- 动作切要让上一镜的运动在下一镜继续，不从静止重新起跑。
- 撞击、反转或关键台词前保留停顿；连续快切之间也要有长短差。
- 转场先尝试硬切或匹配切，特效转场必须有时间/空间理由。
- 生成片段首尾的重复帧、漂移帧和无效停顿必须清掉。

## 字幕

- 每句字幕都要能在剧本或确认台词中逐字找到。
- 不自行润色、不补画外解释、不把音效写成台词。
- 断句跟随语义和呼吸，不按固定字数机械切。
- 字幕避开平台底部按钮、进度条和右侧交互区。

## 声音

- 对白、环境声、拟音和音乐分别检查，不靠整体增益掩盖问题。
- 全片响度统一，接缝处不突然跳变。
- 音乐进入、退出和停顿服务情绪转折，不盖住关键台词。

## 交付验收

- [ ] 第一秒有视觉钩子，不是 logo、黑场或空镜开场。
- [ ] 每个接缝无卡顿、无重复动作、无方向翻转。
- [ ] 关键撞击或反转前有可感知的停顿。
- [ ] 字幕逐字准确，且不进入平台安全区。
- [ ] 最后一帧留有余波，不在动作中途突然黑断。
- [ ] 输出画幅、帧率、时长、响度和文件名符合交付要求。

## 输出格式

先给成片级摘要，再给逐镜剪辑单，最后列已修正问题与仍需补拍的缺口。不要用“整体不错”代替具体验收结论。
