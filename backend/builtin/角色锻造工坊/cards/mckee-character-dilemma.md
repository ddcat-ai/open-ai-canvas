## I — 方法论骨架 (Interpretation)

人物真相不靠外表、别人评价或自我表白得知，只靠**压力之下的选择**自我揭示。但并非任何选择都有揭示力：简单正负选择（幸福/苦难、对/错）毫无戏剧张力，因为"生物第一法则"决定任何人的核心自我都趋向正极，读者提前预知答案。真正揭底的是**两难**——两件价值几乎相等之事的取舍：

- **正向两难**：两个都求之不得、却不可兼得（两个恋人二选一）。
- **负向两难**：两个都唯恐躲之不及、却被迫两害取其轻（两个同样可怕的结局二选一）。

两难的揭示深度由三个旋钮共同决定：**风险**（赌上了什么）、**压力**（时势如何逼迫）、**自由选择度**（选择多大程度上出于人物自主而非外力强制）。风险与压力越大，选择的表现力越深、越真；选择越自由，揭示越深。潜意识与显意识欲望之间的拉扯，正是两难在人物内部的引擎——表面是"两个选项"，底下是"两个自我"在打架。写关键转折前先问：这是对错题还是两难题？再把风险、压力、自由三旋钮调满。

## A1 — 书中的应用 (Past Application)

### 案例 1: 哈姆雷特为何是四大悲剧中最复杂
- **问题**: 同样是悲剧主角，为什么哈姆雷特成为最复杂、最耐解读的戏剧人物？
- **方法论的使用**: 麦基用"选择自由度"对比四位悲剧主角——奥赛罗被嫉妒蒙蔽、李尔被女儿替他做决定、麦克白被女巫预言引领走向命运，唯有哈姆雷特的选择自由而多样：他可以选择自杀或不自杀、复仇或不复仇。
- **结论**: 选择越自由，其选择对人物身份的揭示越深、越真；被外力框住的选择（预言、嫉妒、他人代决）揭示力有限。
- **结果**: 哈姆雷特因拥有选择的无限自由而成为莎士比亚最复杂的人物，读者被带入其内在生活的深处。

### 案例 2: 两害相权的三种形态（莫斯/辛西娅/阿瑟）
- **问题**: 什么样的选择才有戏剧张力、才值得写成一个场景的轴心？
- **方法论的使用**: 麦基列举三例：《老无所依》的李维林·莫斯在金钱与生命之间选了金钱，付出自己与妻子的生命；《汗水》的辛西娅在罢工友谊与管理工作之间选工作，牺牲友谊；《莱斯》的阿瑟在创作完满的痛苦与悠闲生活之间选后者。三例都不是"对/错"，而是两件价值几乎相等的负向或正向取舍。
- **结论**: 只有两件价值几乎相等之事的取舍才具戏剧张力并揭示真相；简单正负选择毫无揭示力。
- **结果**: 两难中的决定令各种可能性在读者想象中驰骋，把好奇心推向高潮——"两害取其轻"的极端形态在《1984》高潮同样成立：温斯顿被逼在背叛朱莉娅与背叛党之间择轻，读者由此看清其灵魂的底线（方法论联想，非书中引文）。

### 案例 3: 《继承之战》肯达尔——自由度与人物分量
- **问题**: 为什么同一角色有时显得软弱肤浅、有时赢得移情？
- **方法论的使用**: 专横的洛根对吸毒儿子肯达尔管制极严，给他的选择几趋于无——肯达尔的反应在观众眼里显得软弱、肤浅、卑微；一旦摆脱父亲束缚、追寻自己的危险选择，他的人物真相便增加权重和复杂性，赢得移情。
- **结论**: 自由选择度直接决定人物在读者眼中的复杂度与移情权重；选择空间被剥夺时，人物显薄。
- **结果**: 肯达尔赢得移情的时刻，正是他开始自主冒险选择的时刻。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写关键转折/高潮前，需要设计一场能"揭底"人物真相的选择戏。
2. 改稿时发现某场选择"换谁都能这么选""太容易猜到"。
3. 想让冲突升级：觉得压力不够、代价不大、选择太轻松。
4. 在写终极道德困境（亲友二选一、忠诚与正义冲突、两害相权）。
5. 审稿时判断某场戏的抉择是"对错题"还是"两难题"。

### 语言信号 (用户的话里出现这些就应激活)

- "两难 / 左右为难 / 两害相权 / 怎么选都有代价" / "dilemma", "caught between", "no-win situation"
- "这个选择太容易猜到了 / 换谁都会这么选" / "the choice is too predictable", "anyone would choose the same"
- "怎么让选择揭示人物 / 揭底 / 露出真面目" / "reveal the character through choice", "show his true self"
- "压力不够 / 风险太小 / 代价要更重" / "raise the stakes", "more pressure", "higher cost"
- "自由选择 / 被迫选择 / 有没有得选" / "free choice", "forced choice", "agency"

### 与相邻 skill 的区分

- 与 `mckee-character-desire` 的区别: 欲望引擎回答"人物为什么动、想要什么"（目标装配）；本 skill 回答"关键时刻怎么选才揭底"（选择设计）。desire 造引擎，dilemma 炼试金石。
- 与 `mckee-character-dimensions` 的区别: 维度是静态的矛盾结构（一个人的复杂度）；本 skill 是把矛盾"演"出来的场景机制——一场好的两难戏正是维度在压力下的现场显影。
- 与 `mckee-character-arc` 的区别: 弧光管"人物改变什么"（跨故事的变化），本 skill 管"单点选择揭示什么"（此刻的真相，性格不变）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **盘点选择，判定类型**
   - 完成标准: 写出场景的核心抉择及其全部选项，并判定它是"简单正负选择"（一眼看出该选哪个）还是"两难"（各选项价值几乎相等、取舍艰难）。
   - 判停条件: 若判定为简单正负选择 → 跳到步骤 2 改造为两难；若已是两难 → 进入步骤 3。

2. **升级为真两难**
   - 完成标准: 把选择改造成正向两难（两个都想要、不可兼得）或负向两难（两个都怕、被迫择轻），并写出每个选项让主角付出的真实代价——选 A 失去什么、选 B 失去什么，二者大致等价。
   - 判停条件: 若改完后两个选项仍明显一好一坏（价值不等），说明激励事件或世界观没设计好，先回到故事层调整，不硬凑。

3. **调满三旋钮并验证揭示度**
   - 完成标准: 逐一上调并写明——风险（赌上性命/爱人/理想）、压力（时势/期限/不可逆）、自由选择度（移除外部强制，让选择出于人物自主）。落笔后能回答："这个选择揭示了他真相的哪一面？是显意识欲望还是潜意识欲望在推动？"
   - 判停条件: 若自由选择度被剧情绑死无法上调（人物根本没得选），回到步骤 2 重设激励事件或对抗安排。

## B — 边界 (Boundary) ★

### 🔴 硬约束（世界层·违背就崩）

- 不能违背基本的两难设计器：压力下的逻辑，否则观众/读者会立刻出戏
### 🟡 软约束（规则层·违背有代价）

- 纯情节推进/过渡场景：不需要每场都造两难，滥用会拖垮节奏。
- 喜剧与闹剧：靠误判与巧合制造笑点，角色不需要在价值相等的两难间挣扎。
- 儿童故事/寓言：需要清晰的道德示范，两难会模糊"该做什么"。
- 极端人物（减去目的/良心的类型）：其设定排除了"正常人式"的两难挣扎（奥布莱恩式的施虐不需要两难）。
### 🟢 自设约束（认知层·其实可以重定义）

- 以为两难设计器：压力下的只有一种正确用法——假墙，方法是工具，不是教条
- 以为两难设计器：压力下的能解决所有问题——假墙，每个方法都有适用场景
