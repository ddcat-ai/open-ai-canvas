## I — 方法论骨架 (Interpretation)

1. 条目是「人物体检表」：13 字段把抽象特质拆成**可观察、可写、可演**的维度，避免「他是好人」式空泛。
2. **定义 + 类别 + 相近特质**三件套先锚定「这个特质是什么、不是什么」。
3. **POSSIBLE CAUSES** 指向角色过去（成因六源，见 tct-trait-causation-tree），让特质有根。
4. **ASSOCIATED BEHAVIORS / THOUGHTS / EMOTIONS** 是 show-don't-tell 的素材库（见 tct-show-dont-tell-trait）——把特质变成具体动作、内心独白、情绪反应。
5. **POSITIVE / NEGATIVE ASPECTS** 揭示「度的双轴」（见 tct-trait-dual-axis）：同一特质过度即负面、不足即缺失。
6. **CONFLICT TRAITS + CHALLENGING SCENARIOS** 指向关系张力与压力失效边界（见 tct-trait-conflict-cast）。
7. 条目是 brainstorm 起点而非穷尽清单；同义特质归并（grumpy 父类统辖 cranky 等）。

## A1 — 书中的应用 (Past Application)

### 案例：用 Adaptable（适应力强）条目做角色体检
- **操作**：取条目 → 填 DEFINITION「随机应变」→ CATEGORIES「Achievement, interactive」→ POSSIBLE CAUSES「童年频繁搬家/天性冷静」→ ASSOCIATED BEHAVIORS「quick thinker / 多线并行 / 善 planning」→ POSITIVE「可靠、扛压」→ NEGATIVE「关系可能因缺稳定感受损」→ CONFLICT TRAITS「compulsive / judgmental / meticulous」→ CHALLENGING SCENARIOS「无法准备的模糊指令」。
- **结论**：一张表即可生成一个「能打但可能伤关系」的立体角色，且自动带出他与 compulsive 配角的冲突种子。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 用户说「我想用这本书查某个特质」或「帮我把 X 特质落成角色档案」。
2. 用户拿到一个特质词，不知道怎么展开成有血有肉的人物。
3. 用户在搭人物前，想先做一次系统化的「特质体检」。

### 语言信号
- "查特质" / "人物体检" / "特质档案" / "这个特质怎么用" / "trait entry" / "character sheet" / "把特质写具体"

### 与相邻 skill 的区分
- 与 `tct-trait-dual-axis` 的区别：本卡管「13 字段结构怎么填」，双轴卡管「正/负面怎么权衡」。
- 与 `tct-show-dont-tell-trait` 的区别：本卡管「条目的行为清单在哪」，show 卡管「怎么把行为写进场景」。
- 与 `tct-build-balanced-character` 的区别：本卡是单特质级工具，平衡搭人卡是多特质组合级。

## E — 可执行步骤 (Execution)

1. **锚定定义与类别**：写一句话 DEFINITION + 标 CATEGORIES（Moral/Achievement/Interactive/Identity 之一或多）。
2. **补相近特质**：列 2–3 个 SIMILAR，防概念漂移。
3. **回溯成因**：从六源（遗传/伦理/养育/负面经历/环境/同辈）写 POSSIBLE CAUSES，给特质扎根。
4. **列行为-想法-情绪三件套**：各写 5–8 条 ASSOCIATED，作为 show 素材（直接喂 tct-show-dont-tell-trait）。
5. **标正/负双轴**：写 POSITIVE ASPECTS（资产）与 NEGATIVE ASPECTS（过度代价）。
6. **埋冲突与失效**：写 CONFLICT TRAITS（会与谁撞）与 CHALLENGING SCENARIOS（什么情境让他失灵）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- **只想要弧光选型** → 去 tct-fatal-flaw-arc；本卡不解决「缺陷怎么驱动成长」。
- **只想要需求/道德驱动** → 去 tct-needs-morals-engine。
- **非人物驱动的观念型写作** → 强行填表会扭曲美学立场。

### 作者警告的失败模式
- **把条目当穷尽清单**：书明言条目是起点；同义特质归并，勿逐条照搬。
- **只抄 DEFINITION 不填 BEHAVIORS**：空有标签无动作，角色立不起来。

### Tier B 版权边界
- 条目正文为作者原创编排，整理只抽「字段结构」；不在卡内大段复述具体条目样例（如 Adaptable 全 13 字段原文）。引用原文 ≤150 字/段。
