## I — 方法论骨架 (Interpretation)

负弧是正向弧的镜像翻转：主角最终落在比开场更糟的状态。它的三种变体不是"坏结局"的随意分类，而是角色与 Lie/Truth 关系的三条精确走向：

1. **Disillusionment（幻灭弧）**：像正弧一样"成长进 Truth"，但那个新 Truth 是悲剧的冷硬事实——看清世界的真相反而失去希望（如 Gatsby 的旁观者 Nick）。
2. **Fall（坠落弧）**：从一条 Lie 滑向更深的 Lie——每一次被给予拥抱 Truth 的机会都拒绝，宁可在 Lie 里越陷越深（如 Heathcliff）。
3. **Corruption（腐化弧）**：开场已见 Truth，却主动拒绝它、拥抱 Lie——最典型的反派起源（如 Anakin）。
4. 三变体的共同机制：在 Third Plot Point，主角因拒绝 Truth 而失去击败 Lie 的唯一武器，唯一出路是更深地沉入 Lie——所以负弧下坠是结构使然，不是命运。
5. 关键设计点：负弧的 First Plot Point 往往表面是正面的（遇良缘、得新职、甚至一个好决定），但它必须始终被不祥预兆尾随——坏结局要成为"唯一合逻辑的走向"，读者才买账。
6. 选型只需比对"角色开场状态 + 结局走向"：可幻灭而不腐化，可腐化而不幻灭，三者是独立走向。

## A1 — 书中的应用 (Past Application)

### 案例 1: 了不起的盖茨比——Nick 的幻灭弧（Disillusionment Arc）
- **问题**: 写一个"变好"却变悲剧的角色——幻灭弧怎么运作。
- **方法论的使用**: Nick 开场是天真的中西部青年，Lie 是"有钱人正是他们看起来的样子，生活一定幸福美满"（*"He starts out the story as a naïve and optimistic young man from the Midwest."*, Chapter 18）；Want 是成为他们中的一员，Need 是看穿光鲜背后的浅薄。他像正弧一样走向 Truth，但那个 Truth 是悲剧的——东卵人群是"一群烂人"。
- **结论**: 幻灭弧的公式是"信 Lie → 克服 Lie → 新 Truth 是悲剧"：角色完成了正弧式的认知成长，收获的却是绝望。
- **结果**: Gatsby 被谋杀、葬礼门可罗雀；Nick 摘下滤镜，带着悔恨般的犬儒离开，人生观由乐观转悲观。

### 案例 2: 呼啸山庄——Heathcliff 的坠落弧（Fall Arc）
- **问题**: 写一个拒绝所有救赎、越陷越深的角色。
- **方法论的使用**: Heathcliff 的 Lie 是"必须彻底占有 Cathy 才能获得完整与幸福"（Chapter 18）；Need 本是"放手、离开这段危险关系"。但每次被给予拥抱 Truth 的机会（尤其 Cathy 死后他本可接受"没有她更好"），他都拒绝，转而拥抱更深的 Lie——宁愿被她的鬼魂纠缠到发疯也不放手。
- **结论**: 坠落弧的公式是"信 Lie → 死抓 Lie → 拒绝新 Truth → 相信更强更糟的 Lie"——每一次选择都在把退路焊死。
- **结果**: Heathcliff 在狂喜幻觉中走向死亡，毁掉自己和身边所有人。

### 案例 3: 星球大战前传——Anakin 的腐化弧（Corruption Arc）
- **问题**: 写一个"从光明堕入黑暗"的反派起源——作者明言这是"结构对、执行错"的反面教材。
- **方法论的使用**: Anakin 开场已握 Truth（爱比力量强大、他善良发光），但 Lie 的种子早被 Ghost（被压抑的奴隶身世）埋下（Chapter 18）。Midpoint 他违令杀光沙人村落（拒绝 Truth），Third Plot Point 投靠黑暗面，Climax 掐向 Padmé——公式：看见 Truth → 拒绝 Truth → 拥抱 Lie。
- **结论**: Corruption 是"结构正确 ≠ 故事成功"的实证——骨架对但执行差，作者坦言它"本可成为影史最佳腐化弧之一"。
- **结果**: Anakin 妻死己残，被改造成达斯·维达——"新希望"的银河由此开启。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户写反派起源/堕落故事，主角一步步变坏、比开场更糟。
2. 用户写"角色看清世界真相但更痛苦"的幻灭结局。
3. 用户担心悲剧结局"为黑而黑、读者觉得不公平"——需要检查不祥预兆。
4. 用户问"主角为什么自救不了"——需要"缺 Truth 无力自救"的机制解释。
5. 用户在正弧与负弧之间摇摆，拿不准结局该让他变好还是变糟。

### 语言信号 (用户的话里出现这些就应激活)

- "堕落 / 腐化 / 幻灭 / 越陷越深 / 一步步变坏 / 反派起源 / 悲剧收场"
- "结局比开场更糟 / 他拒绝了救赎 / 明知是错却回不了头"
- "negative arc / fall arc / corruption arc / disillusionment / tragic ending / he gets worse / villain origin / descent into darkness"

### 与相邻 skill 的区分

- 与 `cca-positive-arc` 的区别: 同一结构的两面镜像——看结局方向：变好是正弧，更糟是负弧；负弧的 Midpoint 也可能"接受 Truth"，但那是悲剧 Truth（幻灭）或转瞬即逝的诱惑（坠落/腐化）。
- 与 `cca-flat-arc` 的区别: 平弧主角持守 Truth 不变；负弧主角要么拒绝 Truth（Fall/Corruption）、要么接受的 Truth 是悲剧（Disillusionment）。若平弧主角最终彻底背弃 Truth → 转入本 skill 的 Corruption。
- 与 `cca-arc-selection` 的区别: selection 先选型；确定负弧后展开三变体、预兆与结构打点，才进入本 skill。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **锁定变体：比对主角与 Lie/Truth 的关系走向**
   - 完成标准: 写出一行式公式（如"信 Lie → 死抓 Lie → 拒绝新 Truth → 信更强更糟的 Lie"），从三变体挑出唯一匹配者；同时写一句"结局状态比开场差在哪"。
   - 判停条件: 若主角最终变好 → 转 `cca-positive-arc`；若主角开场持 Truth 且始终不变 → 转 `cca-flat-arc`。

2. **铺设不祥预兆（负弧最重要的 foreshadowing）**
   - 完成标准: 确认 First Plot Point 表面是正面事件（或至少是"向好处"的选择），但已被至少 3 处坏预兆尾随；能用一句话说明为什么坏结局是"唯一合逻辑的走向"。
   - 判停条件: 若找不出预兆、读者会感到"为黑而黑" → 停在此步补预兆，禁止直接进入结尾；同时检查每个"重要选择"是否两难（ce19：不能让善恶过于黑白分明）。

3. **设计 Third Plot Point 无力化 + Climax 落点**
   - 完成标准: Third Plot Point 中主角的无力感明确来自"拒绝 Truth 所以失去唯一武器"，而非外部巧合；选定 Climax 是"表面胜利但空心"还是"内外双败"，且结局与开场构成明确反差（结局状态 < 开场状态）。
   - 判停条件: 若主角在 TPP 仍能靠外部资源自救 → 那不是负弧机制，回去强化"Lie 已切断所有退路"；若三幕打点齐备但每场戏的情感逻辑说不清（ce18）→ 停下列出每场戏"他为什么这样选"，补执行而非改结构。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 主角最终变好的故事：负弧三变体只会在结构上制造假坠落。
- 没有 Lie/Truth 走向的外部悲剧（被命运碾压、天灾、他人作恶）：负弧需要角色对 Truth 的"选择或拒绝"，没有选择就没有负弧。
- 类型强制 happy ending（儿童向、部分类型约定）：负弧与类型期待冲突，先回 `cca-arc-selection` 做三问仲裁。

### 作者在书中警告的失败模式

- 结构对、执行错（ce18）：作者点名前传三部曲是"如何不做事"的教材——骨架正确但剧本/表演/对话让读者无法共鸣。打满 beat 不等于故事成立，每场戏要有可理解的情感逻辑。
- 抉择过于黑白分明（ce19）：把 Lie 与 Truth 写成善恶二选一，读者能轻松说"他当然该选另一个"——堕落就变成智商问题而非人性问题。每个重要决定都该两难：无论选哪边都要牺牲珍贵之物、也都会有所得。
- 坏结局没有足够铺垫（ce20）：负弧比其他任何弧都更需要 deft 的 foreshadowing；没有预兆的悲剧只是冒犯，读者不会共鸣。
- 为写弧光而写弧光（ce25）：悲剧若与 Lie/Truth 之争无关，删掉反而更聚焦。

### 作者的盲点 / 时代局限

- 道德绝对主义底色：负弧被定义为"拒绝 Truth = 道德堕落"，但许多悲剧与道德无关（认知悲剧、存在主义、制度碾压）；用"道德上升/下降"框架硬套会扭曲非道德主题。
- 悲剧必然性预设：作者要求"读者感到坏结局是唯一逻辑走向"，这可能让悲剧变得可预期、消解其残酷冲击；黑色电影/荒诞派的"无因之恶"不在框架内。
- 单一主角假设：群像悲剧（多人各自的绝望）无法用单条 Lie/Truth 走向概括。
- 事后贴标签：三变体是从作者挑选的好莱坞与经典小说归纳的；反英雄、亚洲作者电影的反英雄叙事很可能溢出这三条公式。

### 容易混淆的邻近方法论

- 与"无弧光的悲剧"：只有坏事发生而没有角色对 Truth 的选择/拒绝，属于 situation 或外部悲剧，不是负弧（见 `cca-arc-selection` 的 Story vs Situation 判断）。
- 与"反派的平弧"：反派也可以是平弧（抱守一个破坏性 Truth，如《训练日》的 Alonzo）——他不变，只是用 Truth 撞主角；负弧是主角自己变糟。两者方向相反。
