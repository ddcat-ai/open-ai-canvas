## I — 方法论骨架 (Interpretation)

这套方法回答两个问题：**谁负责让主角改变**，以及**配角们该有多深的弧**。

1. 主角不会凭空改变。每个需要改变的角色都必须被另一个角色"撞击"——这个 Impact Character 掌握主角缺失的 Truth，本质上是个 Flat Arc 角色：他自己不变，而是不断用与主角 Lie 相冲突的世界观去撞主角。
2. 冲突分工：反派制造**外在冲突**（目标对立），Impact Character 制造**内在冲突**（世界观对立）。冲突核心不是"抢东西"而是"信念打架"。
3. Impact Character 人选不设限：反派、contagonist、导师、伙伴、恋人、若即若离者（Obi-Wan 型）、甚至整个群体（Cars 的小镇居民）都可以担任——关键是"持续、可信地对撞"，而不是偶尔讲一句道理就退场。
4. 配角弧要分层：主角走完整弧（full arc）；每个重要的配角给一条微型弧（minor arc：个人目标 → 障碍/冲突 → 结尾解决）；其余角色只需要一个与主题相关的目标即可。
5. 配角弧的功能是让主题多角度化：不同配角从不同角度逼近同一主题；sidekick 与主角共享相似性但存在关键差异；反派与主角之间要有相似性（相似处制造主题纵深）。
6. 红线只有一条：没有任何 minor arc 可以盖过主角的主弧——主角的弧就是故事本身，若被盖过，说明他不再是主角。

## A1 — 书中的应用 (Past Application)

### 案例 1: 反派型 impact character——《训练日》Alonzo Harris
- **问题**: 主角 Jake Hoyt 天真自满，作者需要把他震出舒适区——谁来做这份撞击？
- **方法论的使用**: Weiland 把反派 Harris 列为 impact character 的范例：他虽邪恶，却用自己的道德复杂性持续与主角的天真世界观冲突，把主角"撞"进一个痛苦的新 Truth。作为反派型 impact，他本质上抱守一个破坏性的 Truth，用对立本身充当主角改变的金钩。
- **结论**: impact character 不必是好人，冲突核心是世界观对立而非目标对立。
- **结果**: 主角被永久改变；Harris 最终为自己深刻影响主角的人生付出代价。

### 案例 2: 爱慕对象型——《爱玛》Mr. Knightley
- **问题**: Emma 的自负与自私需要被持续敲打，谁来做这个持续在场、反对她的人？
- **方法论的使用**: Weiland 把 Mr. Knightley 列为 impact character 的"爱慕对象"选项：他掌握 Emma 所需的 Truth（她必须克服自私与自负），以持续的反对立场催化她的改变。
- **结论**: 恋人/爱慕对象天然适合当催化者——亲近关系反而保证了"持续、可信"的对撞。
- **结果**: Emma 先克服自私（获得 Need），之后才嫁给 Knightley（获得 Want）——先得 Need 再得 Want。

### 案例 3: 平弧催化剂——《大地惊雷》Mattie Ross
- **问题**: 一个角色自己不变、却要推动别人改变，怎么做到？
- **方法论的使用**: Mattie 是典型平弧主角：她坚信"正义值得为之牺牲"，用这份 Truth 把妥协成性的法警 Rooster Cogburn 一步步拖上正义之路；Weiland 在 CH23 引她为 impact character 的范例——平弧主角本人就是最强的催化装置。
- **结论**: Flat Arc 主角天然是 impact character：他自己不动，改变发生在被他撞击的配角们身上。
- **结果**: 结局 Rooster 杀死凶手救下 Mattie；世界在数十年间被她的信念持续改变。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 主角在某个节点突然"开悟"，读者/编辑反馈转变突兀——你在找那个"把他撞醒"的人。
2. 手上有大量配角，不知道给谁弧光、给多深、如何不让配角抢戏。
3. 想选一个催化角色，纠结于人选（反派 vs 导师 vs 恋人）以及如何让他全程与主角较劲。
4. 故事主题想被多角度照亮，想用配角群来强化主题。
5. 检查手稿时发现"主角学到了 Truth，却说不出是谁/什么把它撞进他脑子的"。

### 语言信号 (用户的话里出现这些就应激活)

- "主角改变得太突然 / 转变太突兀 / 缺个人点醒他"
- "谁该负责催化主角改变 / impact character / catalyst character"
- "配角要有弧吗 / 配角弧该多深 / 别让配角抢戏 / supporting cast arc"
- "导师、恋人、sidekick 谁更适合当催化角色"
- "配角们怎么从不同角度讲同一个主题"

### 与相邻 skill 的区分

- 与 `cca-arc-foundation` 的区别: 地基管"角色的病与药"（Lie / Ghost / Want-Need），本 skill 管"谁来把药灌进去"（改变机制）。
- 与 `cca-flat-arc` 的区别: 平弧主角本人就是催化者、自己不改变；本 skill 关注"谁催化主角改变 + 配角弧分配"。若主角是 Flat Arc，催化方向反转（主角→世界），那一部分由 `cca-flat-arc` 管。
- 与 `cca-positive-arc` 的区别: 正弧管"六大节点的逐拍落位"，本 skill 管"人物关系层的变化引擎"。
- 与 `cca-subplot-arc` 的区别: subplot-arc 管"弧光退居副线的三形态（shallow / tangential / extra）"，本 skill 管"配角弧的分层与主题化、谁不能盖过主弧"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **锁定改变引擎：画出主角的 Lie 与目标 Truth，然后回答"故事里谁在持续、可信地与这条 Lie 对撞？"**
   - 完成标准: 能用一句话指出 impact character 及其所持的 Truth；若答不出，说明弧光缺引擎，这正是要补的洞。
   - 判停条件: 若主角是 Flat Arc（开场已握 Truth、自己不改变），跳到步骤 3——此时 impact 职责转为"主角把 Truth 提供给世界的配角们"。

2. **从候选池选定人选并设计碰撞模式**
   - 逐一评估五类候选（反派 / contagonist / 导师 / 伙伴·恋人 / 若即若离者·群体），确认碰撞是"世界观对立"而非仅"目标对立"；写出至少 2–3 场贯穿全篇的"主角按 Lie 行动 → impact character 以 Truth 回击"的对峙场景。
   - 完成标准: 写下 2–3 场关键对峙的清单（场景位置 + 各自信什么 + 结果如何晃了主角一下）。
   - 判停条件: 若人选难以持续在场，改用"若即若离者 / 死后仍以理念影响"模式（Obi-Wan 型），或让反派兼任，不必硬加新角色。

3. **分配配角弧并审计主题一致性**
   - 主角给 full arc；每个 prominent 配角给 minor arc（个人目标 → 障碍/冲突 → 结尾解决）；其余角色给主题相关的目标。用"相似性/对比性"策略让配角从多角度照亮同一主题。最后过一遍红线。
   - 完成标准: 输出配角弧清单（角色 → 目标 → 障碍 → 解决 → 服务的主题角度），并逐条确认没有任何 minor arc 盖过主角弧；若某配角弧展开后主角故事显得单薄，砍掉它或降为"目标 + 冲突"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **无弧光的情景故事（situation）**: 如《夺宝奇兵》式只测试解题能力、起止同一情绪空间的故事——角色不需要改变，也就不需要 impact character。
- **群像 / 多主角作品**: 这套框架默认"一个主角 + 一个核心困境 + 一个催化者"，对多视角、无主角叙事乏力。
- **角色池极小的短篇**: 宁可让反派兼任催化者，也不要为凑数硬加角色。

### 作者在书中警告的失败模式

- **没有 impact character 就想让角色改变**: "A character can't change without something that impacts him..."（Chapter 23）——主角学到 Truth 却说不出是谁撞进来的，改变就是凭空发生、读者不信。
- **配角弧盖过主角弧**: "No minor arc can overshadow the protagonist's primary arc. Your protagonist's arc is the story"（Chapter 24）——配角变化比主角更抢眼，说明主角已不是主角。
- **配角在 Climax 抢走主角的最终胜利高光**: 若配角对 Truth 的最终宣言才是制胜关键，他实质上就成了主角（Chapter 17 对 Flat Arc 的警告）。

### 作者的盲点 / 时代局限

- **单一主角假设**: 默认"一个主角 + 一个核心人性困境"，对群像、多视角、无主角叙事乏力（阶段 0 批判）。
- **概念非原创**: Impact Character 是 Dramatica（Phillips & Huntley）的既有术语，作者做的是整合与可执行化，评估时不要当作原创理论。
- **"每个故事都需要 impact character"的强主张**与作者自己在 CH26 承认《夺宝奇兵》这类无弧光故事"伟大"存在内部张力——注意区分"有弧光的故事"与"情景故事"。

### 容易混淆的邻近方法论

- **Flat Arc（主角即催化剂）**: 区分点在"谁在变"——flat-arc 处理主角持 Truth 改变世界，本 skill 处理谁催化主角改变。
- **Antagonist 的外在冲突 vs Impact 的内在冲突**: 别把"反派抢东西"误当成"反派以 Truth 撞主角"。
- **配角弧 vs 副线弧**: 副线弧讨论"弧光放主线的哪个侧面"，配角弧讨论"每个配角配多深的弧"。
