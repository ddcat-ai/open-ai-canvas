## I — 方法论骨架 (Interpretation)

卡司不是配角的堆砌，而是以主人公为恒星的太阳系：三个同心配角圈以不同距离绕太阳旋转，距离越近、对主人公影响力越强。设计顺序从主人公开始，由内向外拓展到最外围——先定恒星，再排行星。

圈层决定权重：第一圈是能改变事件走向的主要配角，配维度；第二圈是助推或阻碍但无独立磁性的中间角色，只给一个鲜明特性；第三圈是龙套与群演，负责填充社会宇宙。维度消耗表演时间，所以按圈层递减。

按"是否改变事件进程"硬分两类配角：支持型角色能改写故事走向（验尸官的关键证据推动破案），服务型角色只执行任务不改变进程（发现尸体的警察）。判断一个配角的分量，就问：拿走他，事件走向变不变？

三条铁律：其一，每个卡司成员互相描画彼此的特性和真相——每次互动都在暴露自己的维度、勾勒对方的轮廓；其二，绝不让两个角色承担同一个职位或同一种履职方式——发现重复必须分化（改职位或改人物塑造）；其三，开篇必须权衡卡司成员间的权力平衡，并追踪谁上谁下的动态。

最后，卡司设计之前需要作者准备——三把钥匙（道德想象、逻辑暗示、自知之明）构成你的个人人性理论，决定你如何理解人物为何这么做，也就决定了卡司怎么配。作品真正的创作单元是卡司，不是单个人物。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《绝命毒师》的卡司拆解（第17章五部作品之一）
- **问题**: 一部长剧如何支撑起80+角色的庞大卡司而不失衡、不塌陷？
- **方法论的使用**: 麦基指出卡司规模与表演时间决定人物复杂性上限——沃尔特16维需要62集与80+角色互动才支撑得起；六维的杰西·平克曼需数十个支持型角色衬托，从"杀死对手熬毒师"起经历一道道变化弧光。支持型角色负责照亮主人公：杰西不断逼出沃尔特的海森伯格面。
- **结论**: 主人公复杂度与卡司规模成正比；支持型角色是主人公的镜像与催化剂，不是背景板。
- **结果**: 揭示与进化锁定观众多年；对照反例《嗜血法医》第四季起揭示耗尽、后四季停滞，铁粉弃剧——证明卡司的"揭示供给"是长剧的生命线。

### 案例 2: 《傲慢与偏见》的卡司示意图
- **问题**: 一大家子人如何不变成人海、个个鲜明？
- **方法论的使用**: 画三个同心圆——圆心放四维的伊丽莎白并给最多维度，第一圈放三维的达西及主要支持/服务型角色并标注特性维度、与主人公对位，第二圈只限一个鲜明特性（操心的父母、势利、浮夸、欺诈），第三圈填充外围（仆人、村民、商人、远亲）。四个扁平表里如一的姐妹各自反照伊丽莎白的一对维度。
- **结论**: 互相对立的设计令五姐妹个个难忘，同时把伊丽莎白牢牢固着于故事中心；维度按圈层递减分配。
- **结果**: 这张图成为麦基"卡司示意图"工具的标准示范，也是"两个角色不重复同一职位"的活教材。

### 案例 3: 《一条叫旺达的鱼》的喜剧卡司
- **问题**: 喜剧人物如何避免单薄、又保持整体向心力？
- **方法论的使用**: 每个喜剧人物都有盲目强迫症标志加1-3个维度（阿奇害怕/勇敢、律师/罪犯；旺达精于算计/冲动放纵；奥托睿智/无知），控制思想"抛弃事业家庭可得两千万钻石和梦中情人"统摄全卡司——五人共享一个核心欲求，各自以不同的强迫症方式追逐。
- **结论**: 卡司成员互为镜像、互相描画；同一控制思想把散点式人物聚成一颗恒星。
- **结果**: 五个人物个个被自己的强迫症困住，喜剧张力来自他们彼此错位地服务同一个欲望。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户觉得配角都像工具人、没存在感、扁平，想给卡司"激活"。
2. 用户在写群像/多人故事，二十多个角色，不知道每个人该分多少戏份与维度。
3. 用户发现两个角色功能重叠（两个"忠诚助手"、两个"打手"）。
4. 配角太出彩，抢了主角的戏，读者只记得配角。
5. 用户问"我这个卡司规模合不合适"——特别是长剧 vs 短篇的复杂度取舍。

### 语言信号 (用户的话里出现这些就应激活)

- "我的配角全是工具人 / 没有存在感"
- "谁该给更多戏份？怎么分配？"
- "这两个角色功能重复了 / 做的是同一件事"
- "配角比主角还抢戏，怎么办？"
- "我这剧二十几个人物，会不会太多？"
- "my supporting characters are just props"
- "who deserves more screen time / dimensions?"
- "two characters are doing the same job"
- "cast design for a full ensemble"

### 与相邻 skill 的区分

- 与 `mckee-character-essence` 的区别: 卡司管"一整套人物怎么配"（圈层、支持/服务型、对位）；essence 管"单个人物是什么"（艺术品定位、矛盾之眼、情节即人物）。用户谈角色平淡如真人 → 应激活 essence。
- 与 `mckee-character-dimensions` 的区别: 卡司决定"谁该有几个维度、各圈层分配多少、角色之间怎么对位"；维度决定"单个角色的矛盾对怎么造、怎么过三性检验"。用户要的是单个角色的矛盾清单 → 应激活 dimensions。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **画三圈太阳系**
   - 完成标准: 把主人公置于圆心，逐一将现有角色按"对事件走向的影响力"分入第一/第二/第三圈，每个角色都能说清自己落在哪圈及理由；若出现"不知道放哪圈"的角色，标记为待定。
   - 判停条件: 若用户其实只有单个角色、没有卡司要配 → 跳到 `mckee-character-essence` 做人物本质体检。

2. **支持型/服务型二分 + 职位查重**
   - 完成标准: 对第一圈每个角色执行判据"拿走他，事件走向变不变"，得出支持型/服务型标签；全卡司扫描是否有人"同职位+同履职方式"，发现重复即给出分化方案（改职位或改人物塑造）。若没有任何角色能改变事件走向，就说明第一圈是空的，需要回炉。
   - 判停条件: 若用户卡住的其实是"某个角色不够复杂"而非"卡司布局" → 跳到 `mckee-character-dimensions`。

3. **互相描画 + 权力平衡定稿**
   - 完成标准: 逐个检查主要角色间的"互为镜像"关系——A与B的每次互动能带出对方的哪个维度/真相，并给出至少一条这样的关系线；同时明确开篇权力天平（谁上谁下）及故事中权力如何易手。若发现某角色与任何人都没有镜像关系，标记为"失联角色"并决定删改。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只关心单个主角的复杂度、想加矛盾维度——那是 dimensions 的射程，卡司模型回答不了"这一对矛盾合不合格"。
- 用户在写短篇小说或小体量作品——卡司可极简（如《血童》只留两个复杂人物，其余成员单一特性夯实背景），不必强行塞满三圈。
- 用户在写纪实/传记，卡司成员由真实人物限定，无法自由调配戏份权重。

### 作者在书中警告的失败模式

- 支持型角色抢戏: "如果这样的人精变得过于有趣，超出了其卡司功能的范围，他们就可能会反叛，夺过故事讲述的船舵，将其沉没"（ce09）——配角魅力失控会把移情焦点从主人公滑走。
- 单轴对立使关系琐屑: 卡司只在一条轴上对位（善vs恶、勇vs怯），所有关系都退化成同一对立，读者兴趣衰减（ce23）。结构缜密的卡司靠"特性和维度的复杂互位"彼此区分。
- 长篇的重复与僵化杀死吸引力: 主角揭示耗尽、行为可预测，观众敬而远之（ce21，《嗜血法医》范式）。
- 两个角色承担同一职位或同一种履职方式 = 浪费卡司名额、稀释区分度（p07）。

### 作者的盲点 / 时代局限

- "支持型vs服务型"概念漂移: 正文（CH06，支持型能改变事件）与"名词解释"的定义互反，暴露了译本或原稿的概念漂移——使用时以正文为准。
- 样本的欧美中心主义: 第17章五部作品拆解全部来自英美/好莱坞，卡司原理在非西方叙事传统（东亚类型、动漫、游戏）中的可迁移性未经检验。
- 与《故事》《对白》高重复度: 卡司、主角、支持/服务型等概念与旧作大量交叠，本书真正增量集中在卡司三圈与示意图。
- 经验法则的独断: 卡司规模、圈层人数等建议缺乏实证支撑，属审美判断而非铁律。

### 容易混淆的邻近方法论

- "配角"的笼统说法 vs "支持型/服务型"的硬性二分——后者按"是否改变事件进程"判，不是按戏份多少判。
- "卡司太阳系"（思维模型）vs "卡司示意图"（可视化工具）——前者是布局逻辑，后者是把它画出来的操作手法；画图查重是前者的落地。
