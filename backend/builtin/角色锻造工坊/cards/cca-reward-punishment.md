## I — 方法论骨架 (Interpretation)

这套方法解释一个现实：**角色为什么最终愿意改变？因为世界（也就是作者）在奖惩他。**

1. 人的基本动机是趋乐避苦（pain and pleasure）——这是唯一能"从内部长出改变"的引擎。让角色改变不能靠讲道理，要靠后果。
2. 规则极其机械：角色每做出基于 Lie 的行为，就在场景结果上惩罚他——让他离 Want 更远；一旦他做出基于 Truth 的行为，就奖励他——让他离 Want（以及更重要的 Need）更近。
3. 前后配比：前半段故事以惩罚 Lie 行为为主，后半段以奖励 Truth 行为为主——惩罚负责"打破旧模式"，奖励负责"固化新模式"。
4. 精细工具是 **"yes, but..." 规则**：几乎每个场景都以灾难或部分灾难收场；"部分灾难"就是奖励信号——场景目标部分受阻，说明方向已经接近正确解。它同时推进情节、又给角色上了一课。
5. 操作要求：在每一个场景里识别角色此刻依据的信念，然后决定场景结果是惩罚还是奖励。缺少这层微观引擎，宏观结构打得再准，角色也不会真的改变——这正是 ce24 所警告的"只做宏观结构、缺场景级奖惩"。

## A1 — 书中的应用 (Past Application)

### 案例 1: Thor 被流放地球——惩罚 Lie 行为
- **问题**: Thor 开场相信"强者即真理"（Might makes right），是王位继承人——怎么让这条 Lie 开始失效？
- **方法论的使用**: Weiland 用第二幕前半的"惩罚引擎"示范：Thor 被流放到地球后，傲慢耍横的老办法连连受挫——被电击、被麻醉、被车撞，每次 Lie 行为都得到明确的惩罚后果。
- **结论**: 新世界不必讲道理，只需要让"旧方法持续失败"，角色就会被现实逼着换一条 Truth 路线。
- **结果**: Thor 在 Midpoint 举不起自己的锤子，第一次意识到"单靠力量不配挥舞它"——惩罚的累积转化为对 Truth 的接受。

### 案例 2: 赛车总动员——从惩罚 Lie 到奖励 Truth
- **问题**: Lightning McQueen 的 Lie 是"人生是一场独角戏"（我独自就能赢），他需要学会让别人进入生活——靠什么驱动？
- **方法论的使用**: Radiator Springs 这个新世界持续惩罚他的独行侠作风（损坏路面 → 罚他修路）；而每一次"与别人协作"的 Truth 行为（借来材料修路、向 Doc 学习）都得到奖励——被接纳、被指导。Climax 他冲线前刹车、帮 The King 完赛，牺牲 Piston Cup（Want），得到的是 Need。
- **结论**: 前后半奖惩配比：前半惩罚 Lie、后半奖励 Truth。奖励不一定是物质——靠近 Want 是奖励，获得 Need 是更大的奖励。
- **结果**: 他拒绝 Dinoco 赞助、回 Radiator Springs 当训练总部——新常态证明改变已从内部长出。

### 案例 3: 绿街悍将——奖励 Truth 行为的第一口
- **问题**: Matt 的 Lie 是"弱者必须服从强者"，他从没体验过 Lie 之外的生活——怎么让他第一次尝到甜头？
- **方法论的使用**: First Plot Point 之后，Weiland 让 Matt 跟姐夫所在的帮派并肩还击，第一次尝到"有人推你时反击"的爽感——这是对 Truth 行为的奖励信号：方向正确、值得继续。
- **结论**: 奖励不必巨大，一次"瞥见没有 Lie 的生活"就是够格的种子；它让 Midpoint 接受 Truth 有了心理基础。
- **结果**: 这份反击的快感成为他建立自我价值感的种子，Midpoint 深化为"为在乎的人而战"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 角色"道理都懂"但没动力改变，故事靠情节硬推——缺少场景级后果。
2. 手稿检查时发现每个场景角色都没有为自己的错误信念付出代价（对应书中 ce24 的警告）。
3. 想知道 "yes, but" 部分灾难怎么设计——如何让角色靠近目标又被绊一下、却传达"方向对了"。
4. 想让角色的改变"从内部长出来"，而不是靠旁白或觉悟台词。
5. 设计第二幕前半的挫折序列，想让挫折与角色信念精确挂钩。

### 语言信号 (用户的话里出现这些就应激活)

- "角色没动力改变 / 他怎么就被说服了 / 转变不可信"
- "每个场景都该为错误付出代价吗 / consequences"
- "reward / punishment / 奖惩 / 惩罚 / 奖励"
- "yes but 部分灾难 / 部分失败 / 接近目标又受阻"
- "motivation / 驱动力 / 让改变从内部长出来"

### 与相邻 skill 的区分

- 与 `cca-positive-arc` 的区别: 正弧管宏观节点（"惩罚 Lie"是第二幕前半的整体状态，f08 归正弧），本 skill 管"逐场景微观反馈"——前者回答"节点放哪"，后者回答"每场戏给什么结果"。
- 与 `cca-arc-foundation` 的区别: 地基定义 Lie / Truth 是什么，本 skill 管"用什么机制兑现惩罚与奖励"。
- 与 `cca-flat-arc` / `cca-negative-arc` 的区别: 奖惩极性取决于弧类型——平弧里主角因信 Truth 被惩罚（p23），负弧里 Lie 反而被"奖励"以催化堕落；不要机械套"惩 Lie 奖 Truth"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别场景中的指导信念**
   - 对每个场景，判定主角此刻的行为依据的是 Lie 还是 Truth——先写下一句话：角色在此场景"按哪条信念行动"。
   - 完成标准: 能为场景写出"行动依据的信念 → 应给的奖惩方向"这一行结论。
   - 判停条件: 若故事是 Flat Arc 或 Negative Arc，先确认极性——平弧中主角因 Truth 被惩罚，负弧中拥抱 Lie 反而被"奖励"，方向要反转后再进步骤 2。

2. **设计奖惩后果并落实 yes, but**
   - Lie 行为 → 让他离 Want 更远（目标受阻、损失升级）；Truth 行为 → 让他离 Want/Need 更近。若场景是"部分灾难"，把它写成一个明确的奖励信号——方向正确、只是代价不小。
   - 完成标准: 场景结尾能指出角色比开场更接近还是更远离目标，并写明信号类型（惩罚 / 奖励 / yes-but 部分灾难）。
   - 判停条件: 若场景结局总是全胜或全败（没有任何部分灾难），返回重设计——"yes, but" 才是推进 + 教课的双效工具。

3. **前后半程配比检查**
   - 画一遍奖惩分布：前半段 Lie 代价密度应显著高于后半段；后半段 Truth 行为开始获得连续奖励。检查"改变是否真的从内部长出"——即角色不是被推着走，而是被后果驯化。
   - 完成标准: 能画出"前半惩罚为主 / 后半奖励为主"的分布曲线，并指出 Climax 前角色已能稳定持守 Truth。
   - 判停条件: 若发现角色在 Climax 之前就已彻底正确、不再犯错，说明后半程少了残余的 Lie 反弹与再惩罚，节奏失衡——回步骤 2 补一轮"旧习复发被惩罚"。

## B — 边界 (Boundary) ★

### 🔴 硬约束（世界层·违背就崩）

- 不能违背基本的Reward/Pun逻辑，否则观众/读者会立刻出戏
### 🟡 软约束（规则层·违背有代价）

- **无弧光的情景故事（situation）**: 没有 Lie 可惩、没有 Want 可拉，奖惩引擎没有附着物。
- **纯内心顿悟 / 存在主义主题**: 行为主义的"趋乐避苦"框架解释不了义务、认同、信仰驱动的深层转变，硬套会写出行尸走肉。
- **负弧中机械套"惩 Lie 奖 Truth"**: 堕落弧的机制恰恰相反——角色拥抱 Lie 反而被"奖励"、拒绝 Truth 被"惩罚"，奖惩极性要按弧类型
### 🟢 自设约束（认知层·其实可以重定义）

- 以为Reward/Pun只有一种正确用法——假墙，方法是工具，不是教条
- 以为Reward/Pun能解决所有问题——假墙，每个方法都有适用场景
