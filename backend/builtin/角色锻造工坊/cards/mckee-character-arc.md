## I — 方法论骨架 (Interpretation)

麦基把"人物发展"这个笼统说法切成两套独立技术。**揭示**（revelation）：事件剥开人物塑造、露出人物真相，读者认知改变、人物性格不变——所有讲述过的故事里绝大多数主要人物走这条路，侦探、神秘、大部分正剧都属此类。**变化**（change）：人物性格本身发生位移，是稀有品；一个故事只需改变三样内在素质之一——道德（如何对待他人）、心智（如何看待现实与意义）、人性（整个存在状态是进化还是退化）。三条轨道各自有正向弧光（救赎/教育/进化）与负向弧光（堕落/幻灭/退化）。

弧光无论正负都不走直线，而是正负周期交替、冲击渐增；一路单调的"正正正"或"负负负"会把故事凝成肖像画。要判断该不该有弧光，用"完成四步"做体检：准备（激励事件发生时人物未完成，只有作者知道他的人性空洞/需求）→揭示→变化（沿定义性维度画弧光）→完成（高潮处需求与欲望同时兑现，不剩未表达之物）。注意**需求≠欲望**：人物永远不知道自己缺什么，只有作者看得见。

## A1 — 书中的应用 (Past Application)

### 案例 1: 杰西·平克曼 vs 德克斯特——揭示与变化决定长篇生死
- **问题**: 同样是长篇连续剧，为什么《绝命毒师》到 62 集还有看头，而《嗜血法医》第五季起铁粉弃剧？
- **方法论的使用**: 麦基对比两剧：六维的杰西·平克曼是唯一看清《绝命毒师》道德分裂的卡司成员，他从不道德到道德、从自我毁灭到自我沉迷，经历一道又一道变化弧光；反观德克斯特，第四季结束时能揭示的全揭示完了、能变化的都变化完了，五到八季停滞不前。
- **结论**: 揭示和进化能多年如一日锁定长剧观众，重复与僵化杀死吸引力；一旦主人公再无物可揭示、无可改变，行为变得可预测，观众便敬而远之。
- **结果**: 杰西的弧光成为《绝命毒师》道德心脏的标尺；德克斯特成为"揭示耗尽"的反面教材。

### 案例 2: 俄狄浦斯——跨作品的"完成"
- **问题**: 《俄狄浦斯王》高潮处俄狄浦斯抠出眼珠，这算完成人物了吗？
- **方法论的使用**: 麦基判定那是"电闪雷鸣般情感爆发麻木了思维"的未完成状态；二十三年后，90 岁的索福克勒斯在《俄狄浦斯在科洛诺斯》里让俄狄浦斯痛思前罪，意识到是冲动傲慢与缺乏自知决定了命运——一旦接受罪孽，他便完成自己、遂得安息。
- **结论**: 完成=接受真相，需求与欲望兑现；完成四步（准备/揭示/变化/完成）可以跨越作品实现。
- **结果**: 同一个俄狄浦斯在两部作品中走完"未完成→完成"，说明"完成"是衡量标准，不是篇幅的副产品。

### 案例 3: 安纳金·天行者——负向弧光
- **问题**: 变化一定要向好？悲剧主角的弧光怎么设计？
- **方法论的使用**: 麦基用《失乐园》路西弗与《星球大战》安纳金演示负向弧光：安纳金（"善"）将生死置之度外、一心追求权力指望拯救爱人，沿定义性维度从光明王国逐渐走向黑暗面，被烧伤截肢后成为达斯·维达。
- **结论**: 弧光有正负两个方向；负向弧光同样从正/负起点沿正负周期循环、冲击力不断加深直至悲剧结束。
- **结果**: 定义性维度的极性决定了弧光的轨道——同一个"为爱冒险"的维度，既可走向救赎也可走向堕落。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 读者/编辑反馈"主角没有成长"，用户想确认是缺揭示还是缺变化，并知道下一步该做什么。
2. 要写救赎/堕落/教育/幻灭类故事，需要选定弧光轨道（道德/心智/人性）与方向。
3. 写长篇连续剧（50 集以上）或系列作品，担心主角被写干、观众流失。
4. 改大纲时，想知道高潮处人物应该"变成什么样"才算是被完成。

### 语言信号 (用户的话里出现这些就应激活)

- "人物没成长 / 角色没变化"
- "想写救赎 / 堕落 / 黑化 / 醒悟"
- "主角的弧光怎么画 / character arc"
- "他把所有人都看透了 / 这个揭示够不够"
- 英文: "character growth" / "redemption arc" / "reveal vs change" / "character change"

### 与相邻 skill 的区分

- 与 `mckee-in-character-writing` 的区别: 内写作是"此刻他是谁"的当下沉浸；弧光是"他从哪来到哪去"的时间轴轨道。内写作处理单场景，弧光规划整部作品。
- 与 `mckee-character-dilemma` 的区别: 两难是单次选择的揭示引擎（正向/负向两难）；弧光里的"变化"是整条线上维度的位移。两难完全可以出现在无弧光的故事里。
- 与 `mckee-character-dimensions` 的区别: 维度是静态矛盾结构（定义性维度）；弧光是该维度在时间轴上沿正负方向的位移。有维度不等于有弧光。
- 与 `mckee-protagonist-design` 的区别: 主人公设计含"善中/下风狗/改变容量"等素质；弧光 skill 专注"改变"本身——何时该有、走哪条轨道、往哪个方向。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判定：揭示型还是变化型**
   - 完成标准: 对比故事开头与高潮，能明确回答"人物性格是否真的改变"。若只是读者对人物的认知变了（我们以为她是 X，高潮知道她是 Y），就是揭示型，不需要造弧光。
   - 判停条件: 若判定为揭示型，跳到步骤 3 只查"揭示"与"完成"两环，不强行加变化。

2. **选定轨道与方向：道德/心智/人性 × 正向/负向**
   - 完成标准: 写出一句轨道陈述，如"道德轨道：从以罪犯为客户→以黑帮为客户（堕落，负向）"；确认变化沿人物的定义性维度展开，并排出正负交替的节拍序列（避免单调同号）。
   - 判停条件: 若三条轨道都想"变"，说明把复杂度当成了变化——收敛为一条主轨道；若弧光一路直线上升/下坠，先插入反向转折再继续。

3. **用"完成四步"体检**
   - 完成标准: 准备（激励事件时的人性空洞，即只有作者知道的需求）→揭示→变化→完成（高潮处需求与欲望同时兑现）各有一段可对号；并能回答"人物的需求是什么（而非欲望）"。
   - 判停条件: 若人物是极端人物（九种删减出来的）或纯喜剧/动作片角色，变化会显得虚假（极端人物不可变）——此时明确标注"本故事不需要弧光"并停止。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 揭示型故事（侦探、神秘、大部分正剧）：只有认知改变没有性格改变，强行加弧光会破坏结构。
- 极端人物（ce20）：靠删减（减自我意识/深度/良心/信仰）造出的荒诞或邪恶人物，设定上就排除了变化，让他醒悟会瞬间崩塌成愚蠢之作。
- 纯类型片/喜剧/动作片：喜剧角色与动作英雄往往无需求无变化（麦基：没有变化的人物则没有需求）。

### 作者在书中警告的失败模式

- 重复是作家的死敌（ce19）：价值负荷一路单调同号（全正或全负）会把故事凝成肖像画；弧光必须正负周期交替、冲击渐增。
- 长篇重复与僵化杀死吸引力（ce21）：一旦主人公无物可揭示、无可改变，行为可预测，观众弃剧——《嗜血法医》第四季后四季的教训。
- 极端人物不可变化（ce20）：极端世界里的极端人物突然变复杂或醒悟，作品瞬间崩塌。
- 顿悟用力过猛（ce25）：高潮顿悟写得堆砌说教、华而不实，是最难堪的尴尬；顿悟是宁为玉碎不为瓦全的危险事件。
- 简单正负选择无揭示（ce12）：若"变化"只靠一次明确正负选择推动，读者早已预知答案，弧光会显得机械。

### 作者的盲点 / 时代局限

- "完成人物"的黄金理想抹杀留白：麦基主张"不剩任何未表达之物"，却与其自己推崇的现代/后现代传统（品钦、贝克特式身份不确定、意义不可知的人物）直接冲突。大量杰作靠人物的不可穷尽性与读者无限诠释存续——"完成"是独断的审美偏好而非通则，弧光不一定要走到"完成"。
- 弧光三轨（道德/心智/人性）是否穷尽"改变"的可能？身体性、文化规训、环境塑造等非认知维度的变化在框架中无处安放——对非欧美传统叙事可迁移性存疑。
- 全书上千案例几乎全部来自西方，所谓"人性无趋势、人人相通"建立在未经检验的单一文化样本上。

### 容易混淆的邻近方法论

- "揭示"≠"变化"：认知改变（我们知道她是谁）vs 性格改变（她真的变成另一个人）。多数故事只有前者。
- "弧光"≠"情绪起伏/情节转折"：情节再曲折，只要性格未沿三轨之一位移，就没有弧光。
- "需求"≠"欲望"：欲望人物自知，需求只有作者知道；弧光兑现的是需求，不是欲望。
