## I — 方法论骨架 (Interpretation)

1. **两大驱动源**：① 道德准绳（对错信念，深植内心，常引向自我牺牲）② 马斯洛五层需求（生理/安全/归属/尊重/自我实现）。
2. 特质在「追求最重要需求」的过程中浮现：安全已满却渴求尊重→determination/perseverance/efficiency 发展。
3. **需求未满足 → 焦虑 → 行为偏移**：饿了几天的好人可能偷窃；过度工作被卡者可能裸辞去读书。
4. **需求可撼动道德**：需求久不满足，道德准绳会摇摆——「为保家人安全愿做多违背底线的事？」
5. **共情生产线**：读者认同的不是「角色做了什么」，而是「他为什么想要、需求与道德如何驱动」。需求的普世性（人人都认）天然唤起共情。
6. 道德也受外部（社会规范/文化/榜样）影响，可设计为「被创伤 warped 的反派道德」。

## A1 — 书中的应用 (Past Application)

### 案例：Scarlett O'Hara 的深度缺陷但平衡
- **操作**：她的 determination + resourcefulness 服务于「保住 Tara」这一强烈需求（安全/归属层）；读者因理解其 why 而挺一个 selfish 角色。
- **结论**：需求引擎把「不可爱」转成「可共情」。

### 案例：未满足需求撬动道德
- **操作**：安全本满足的虔诚角色，引入战争使世界不安全 → 测试「为护家人愿违背多少道德」→ 制造 inner turmoil。
- **结论**：需求×道德二轴是内在冲突的发源地。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 用户问「怎么让读者共情一个不讨喜的角色」。
2. 用户要设计动机、特别是「看似矛盾的选择」。
3. 用户想制造内心冲突或道德两难。

### 语言信号
- "共情" / "动机" / "为什么想要" / "需求" / "道德困境" / "他图什么" / "needs" / "moral"

### 与相邻 skill 的区分
- 与 `wfs-inner-misbelief` 的区别：本卡给「需求×道德」双轴驱动；wfs 给「内在谬见」单一错误信念模型。二者常互补（谎言常是未被满足需求扭曲出的谬见）。
- 与 `mckee-character-essence` 的区别：麦基讲本质=欲望+矛盾；本卡给欲望的「需求-道德」来源分解。
- 与 `tct-fatal-flaw-arc` 的区别：本卡管「动机 why」，弧光卡管「动机如何被缺陷阻断又突破」。

## E — 可执行步骤 (Execution)

1. **定核心需求层**：角色最缺哪一层（常被未满足的层驱动行为）。
2. **定道德准绳**：他坚信什么对错（含可能被创伤 warped 的反派道德）。
3. **写特质浮现**：为追求该需求，他会发展出哪些特质（反过来校验角色档案）。
4. **设需求-道德张力**：放一个「需求久不满足→道德摇摆」的转折点测试。
5. **连共情**：确保读者能说「换我也会想要这个」——这是共情钩子。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- **只填单特质档案** → tct-trait-entry-blueprint。
- **只选弧光类型** → tct-fatal-flaw-arc。
- **纯外部冲突设计** → 本卡是内在驱动，强套会弱化动作线。

### 作者警告的失败模式
- **ce08 动机不清**：不知 inner/outer motivation→角色漂走。
- **ce05 Emotionless 反派**：无视「激情/需求驱动一切」，造出无魂反派。

### Tier B 版权边界
- 引用 Maslow 五层原文 ≤150 字/段；需求/道德机制自由迁移。
