## I — 方法论骨架 (Interpretation)

弧光不必总站在主线的最前台。当主线是强情节/世界观驱动，或某个配角需要被看见时，弧可以合法地退居副线——但要分清三种形态：Shallow Arc（浅弧）结构完整但催化剂点模糊，靠读者对熟悉套路的补全生效，效果最弱；Tangential Arc（切向弧）弧完整醒目、与主线仅间接相关，抽掉会失掉故事的心但主线照常成立；Extra Arc（附加弧）则是在主线之外叠加的关系副线弧。

另一个方向是：有的故事压根不需要弧。用 Jeff Lyons 的四条判据——①有显而易解的处境；②只测解题能力、不揭示角色；③无副线/反转/复杂化；④起止于同一情绪空间——若全中，就是 situation 而非 story。作者坦承 situation（如《夺宝奇兵》）可以伟大，但她的立场是"没见过哪个故事不能因加一条深思的弧而变好"：加不加弧，看它能否深化主题，而非出于"故事必须有成长"的义务感。

无论哪种选择，都受同一条红线约束：任何副线弧不得盖过主角主弧；副线弧的 Lie/Truth 必须与主主题织进同一张挂毯。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《夺宝奇兵》——无弧光的 situation 也可以伟大
- **问题**: 一个主角从头到尾毫无变化的故事，算不算失败？
- **方法论的使用**: 作者用 Lyons 四判据逐条核对——Indiana Jones 面对的是有"显而易见直接解决方案"的处境（找到约柜）、全程只测试解题能力、几乎无副线反转、起止于同一情绪空间。
- **结论**: 它被判定为 situation 而非 story："Indiana Jones has no character arc. He's the same guy at the end of the movie as he was at the beginning. Did that harm the story? Not at all."
- **结果**: 作者承认这类无弧光故事在动作/冒险类型中合法且伟大，但随即断言还没有哪个故事不能因加入弧光而变得更好——判断标准是"能否改善"，不是"必须要有"。

### 案例 2: 《侏罗纪公园》——Dr. Grant 的切向弧（Tangential Arc）
- **问题**: 主线是"自然不可驯服"的平弧故事，主角 Grant 开场却是个"孩子烦人"论者——这条成长线放哪儿？
- **方法论的使用**: 把 Grant 的"学会照顾孩子"正弧作为副线，与主线（基于 Truth "nature is ungovernable" 的平弧）并行。
- **结论**: 这条弧完整而醒目，却只与主线间接相关——正是 tangential arc 的标准形态；同一主角同时走"主线平弧 + 副线正弧"的叠加结构。
- **结果**: 把副线抽掉会失去故事的人性温度，但主线照常成立；作者用它示范副线弧如何为整部故事增厚。

### 案例 3: 《银河护卫队》——Peter Quill 的浅弧（Shallow Arc）
- **问题**: 动作大片里角色的成长线怎么给，又不拖累节奏？
- **方法论的使用**: 给 Quill 一条元素齐全（Ghost/Lie/Truth 都在）但只作潜台词、不推动情节的浅弧。
- **结论**: 作者判定它 "serve more as subtext for the character than as avenues of propulsion for the plot"——结构完整、催化剂点弱。
- **结果**: 浅弧是最弱的弧光呈现，但能为重情节故事叠一层角色深度；它靠读者熟悉模板而生效。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 你在写强情节/冒险/动作故事，觉得主角"不必成长"，想知道没有弧光到底行不行。
2. 你想给副线里的恋人、朋友或反派安排一条成长线，但怕抢了主线风头。
3. 你的故事被反馈"没有人物成长"，你分不清这是硬伤还是可接受的 situation。
4. 你隐约觉得"该加一条弧"，但说不清加在哪里、加到什么程度。

### 语言信号 (用户的话里出现这些就应激活)

- "主角不需要成长可以吗？" / "这故事到底要不要角色弧光？" / "没有人物成长是不是不行？"
- "我想给配角一条成长线/副线弧" / "怕副线抢主线" / "这条弧放主线还是副线"
- "My protagonist doesn't change—is that OK?" / "Does this story need a character arc?" / "no character arc" / "subplot arc" / "character arc as subplot"

### 与相邻 skill 的区分

- 与 `cca-flat-arc` 的区别: 平弧主角"开场已握 Truth、用 Truth 改造世界"，仍有 Lie/Truth 之争；本 skill 的 situation 是两者皆无。平弧是弧的合法形态，不是无弧。
- 与 `cca-impact-character` 的区别: Impact Character 是主弧的催化引擎（谁把主角撞向改变）；本 skill 处理"某条弧放在什么位置/要不要放"，不负责催化主角。
- 与 `cca-arc-selection` 的区别: 三问选"主角走哪种弧"；本 skill 判断"要不要弧 / 弧放主线还是副线"。
- 与 `cca-series-arc` 的区别: 本 skill 管单卷内弧的位置；跨卷的弧分配走系列 skill。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先定主线弧的归属**
   - 完成标准: 用一句话写出"主线上谁走什么弧（若无弧则注明），候选副线弧给谁"。
   - 判停条件: 若判定这条弧本就是主角完整主弧 → 停止，转 `cca-positive-arc` / `cca-flat-arc` / `cca-negative-arc`。

2. **用 Story vs. Situation 四判据判断故事是否需要弧**
   - 完成标准: 对①显而易见解法 ②揭示角色 ③副线/反转 ④起止情绪空间逐条作答，得出"story / situation / 混合"结论。
   - 判停条件: 若四判据全中且类型允许（冒险/动作等）→ 可直接输出"无弧合法"结论，跳到步骤 4 校验层级后结束，不必硬加弧。

3. **若需要副线弧，在三种形态中选型并规划**
   - Shallow：主题已熟、催化剂可弱、只作背景色；Tangential：完整弧 + 与主线间接相关，抽掉失心但主线照常；Extra：关系副线叠加。
   - 完成标准: 选定形态 + 一句话说明与主线的关系 + 写清该弧的 Lie→Truth 及关键催化剂点。

4. **校验层级与主题归属**
   - 完成标准: 能用一句话回答"这条副线弧如何支撑主角主弧/统一主题"，并确认没有任何配角弧盖过主角弧（No minor arc can overshadow the protagonist's primary arc）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 主角本身在主线需要完整弧光——那是主弧 skill 的工作，不要因"怕麻烦"把主角弧降级成副线。
- 你需要的是 Lie/Ghost/Want-Need 诊断或弧光强度审计——本 skill 不诊断病根。
- 故事是系列/多部曲，弧的分配横跨多卷——那是 `cca-series-arc` 的领域。

### 作者在书中警告的失败模式

- 为写弧光而写弧光（Ch26, counter-example）：作者明确警告 "never include a character arc just because you feel you have to"——不因"必须有成长"的义务感硬塞弧；为弧而弧只会制造矫情。
- 配角弧盖过主角弧（Ch24, counter-example）：副线弧越动人，主角越可能实际上不是主角——红线 "No minor arc can overshadow the protagonist's primary arc. Your protagonist's arc is the story"。

### 作者的盲点 / 时代局限

- 内部张力未解（BOOK_OVERVIEW 批判）：作者既断言"所有故事都能因加弧而变好"，又承认 Raiders 式无弧故事"伟大"——"是否伟大"是主观审美判断，四判据无法替你决定值不值得加。
- 单一主角假设：四判据默认"一个主角 + 一条弧"的参照系，对群像、多视角、无主角叙事乏力。
- 百分比锚点与"唯一正确节奏"倾向：若被教条化，会反过来抑制"无弧 + 副线浅弧"这类非常规但有效的结构。

### 容易混淆的邻近方法论

- 无弧光 situation vs. Flat Arc：前者无 Lie/Truth 之争，后者有——这是最关键的分界。
- 切向弧（Tangential）vs. 浅弧（Shallow）：前者弧完整醒目、只是与主线间接相关；后者结构在但催化剂弱、只当背景色。
