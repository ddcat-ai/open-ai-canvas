## I — 方法论骨架 (Interpretation)

1. 特质不是凭空设定，而是由**六源**合成：① Genetics（天生倾向）② Ethics & Values（伦理价值）③ Upbringing & Caregivers（养育/榜样）④ Negative Experiences（负面经历反塑正面）⑤ Physical Environment（物理环境）⑥ Peers（同辈）。
2. 写 backstory = 追溯这六源如何合成角色现状；不写过去，特质无根、反应不可信。
3. **负面经历既能生缺陷也能生正面**：受虐儿童可能长成极度滋养他人的成人（防御性补偿）。
4. **情感创伤（Wound）是缺陷的根**：过去剧痛→角色为防再痛而形成缺陷、并相信一个关于自己的 Lie（见 tct-fatal-flaw-arc）。
5. 环境剧变会改写特质：富家女嫁穷工人后须习得 efficiency/thrift/self-control。
6. 同辈既是同化源（为融入而 adopt 特质）也是反叛源（拒斥 care-giver 特质而选 free-spiritedness）。

## A1 — 书中的应用 (Past Application)

### 案例：Negative Experiences 反塑正面
- **操作**：设定「母亲虐待」→ 不写成创伤符号，而写成「成年后极度 nurturing，以防对孩子重施旧痛」→ 正面特质成了创伤的防御性果实。
- **结论**：缺陷与正面可同源；写成因能避免「为坏而坏」。

### 案例：反派的 Past（Keyser Söze）
- **操作**：妻儿惨死（wound）→ 建秘密帝国、goal=隐藏身份；其正面特质 patience/intelligence/organization 全由创伤淬炼。
- **结论**：反派也走六源树，使其真实可畏。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 用户问「这个角色为什么这样」或「帮我写他的过去」。
2. 用户觉得角色反应「假」「没来由」。
3. 用户要设计缺陷的根源（而非只贴一个缺陷标签）。

### 语言信号
- "为什么他是这样" / "backstory" / "成因" / "小时候" / "创伤" / "原生家庭" / "他怎么变成这样" / "origin"

### 与相邻 skill 的区分
- 与 `cca-arc-foundation` 的区别：cca 给弧光地基框架；本卡给「特质层面的六源追溯工具」。
- 与 `tct-fatal-flaw-arc` 的区别：本卡管「成因树」，弧光卡管「创伤→谎言→成长」的演化链。
- 与 `mckee-character-design` 的区别：麦基讲压力下的选择揭示；本卡讲选择背后的历史根源。

## E — 可执行步骤 (Execution)

1. **列六源清单**：对目标特质，逐源写「这一源贡献了什么」（有则填、无则空）。
2. **定位 Wound**：若无缺陷则跳；若有缺陷，回溯成长期剧痛事件。
3. **写 Lie**：创伤后角色相信的关于自己的错误认知（如「我不值得被爱」）。
4. **找补偿性正面**：负面经历是否反塑出某个正面特质（防御果实）。
5. **环境/同辈变量**：设一个「环境剧变」或「同辈拉力」测试特质是否会被改写。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- **只填单特质档案** → tct-trait-entry-blueprint。
- **只选弧光类型** → tct-fatal-flaw-arc。
- **纯外部情节驱动** → 六源树是内在根，强套会拖慢节奏。

### 作者警告的失败模式
- **无 past 的角色**：反应无根、前后不一（ce08 动机不清的近亲）。
- **创伤当装饰**：只写「他曾受伤」不写如何塑造现在，等于没写。

### Tier B 版权边界
- 引用六源原文 ≤150 字/段；机制自由迁移。
