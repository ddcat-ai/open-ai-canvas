## I — 方法论骨架 (Interpretation)

1. **对抗力量不是"坏蛋"**：它是阻碍人物意志与欲望的一切力量的总和——内心（自我怀疑、负疚）、个人（家人、仇敌）、个人外（社会制度、自然、时间）。负面之墙 = 主角欲望 × 对抗力量 × 代价，三者缺一则墙塌。
2. **反面人物塑造原理**：主人公的智慧魅力与情感魄力必须与对抗力量的总和相匹配。对抗越强越复杂，人物与故事发展得越充分；故事虚弱的首要导因是对抗力量过于软弱——与其美化主角，不如构筑负面之墙。
3. **匹配有分寸**：激励事件当刻，主人公应像一条"战败狗"——对抗总和看起来势不可挡，但他必须仍有一次可信的机会。超人这类超级英雄只能靠两难困境（而非更强坏人）才能成立。
4. **负面三级递进**：正面价值 → 相反价值（负面但非对立）→ 矛盾价值（直接对立）→ 否定之否定 / 负面之负面（生活从量变坏到质变坏）。故事若只停在矛盾价值，只会令人满意但绝不辉煌。
5. **从里到外写强敌**：潜入每个对抗人物的主观视点问"如果我是他，我会怎么办"，写出有自觉欲望、有理由的强敌——傻瓜式反派只会让胜利廉价。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《超人》——卢瑟毒计把超人变成战败狗
- **问题**: 超人无所不能，冲突怎么成立？
- **方法论的使用**: 普佐让卢瑟同时向相反方向发射两枚核弹头，超人不能分身两处，被迫做"救新泽西还是救加州"的两恶取轻之择——与主人公能力匹配的方式不是更强的坏人，而是两难困境。
- **结论**: 超级英雄只能靠两难困境而非更强的反派才能成立；对抗力量的总和必须与主人公的智慧魅力情感魄力相适应。
- **结果**: 超人救新泽西致加州地震、路易丝死亡，被迫违父命逆转地球复活路易丝，从战败狗变成真神。

### 案例 2: 《失踪》——到达"负面之负面"的专制深渊
- **问题**: 怎么把对抗升级到人生体验极限？
- **方法论的使用**: 霍尔曼从"不公平"（大使半真半假信息）到"非正义"（儿子被政府谋杀）再到"负面之负面/专制"（法律朝令夕改、正义根本不存在）逐级递进。
- **结论**: 只停在矛盾价值只能加入平庸之作的大合唱，伟大在于对"负面之负面"的处理。
- **结果**: 霍尔曼虽无法控告独裁者，却在全世界面前将其揭露于银幕——一种更具反讽意味的正义。

### 案例 3: 健身房里的黑手党"科尼岛先生"（麦基亲历）
- **问题**: 反面人物如何获得立体感与移情力？
- **方法论的使用**: 麦基在健身房结识的黑手党自认是"好人"——因为他们在现实中交易、不是伪君子。最坏的人都相信自己善良。
- **结论**: 反面人物也需要"善之中心"；观众会本能寻找善之中心，给反角适当的正面素质反而使其更可信、更可怖。
- **结果**: 成为"善之中心/反面人物立体化"的论证素材——观众甚至能对黑手党移情。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 觉得反派太弱、主角赢得太轻松、故事没紧张感。
2. 需要把对抗升级到"人生体验极限"，不知如何分层。
3. 写超级英雄/超强主角，不知道配什么样的反派。
4. 想给反面人物加维度、可移情性，又怕写弱。
5. 主角和反派实力/智力不匹配，故事一边倒。

### 语言信号 (用户的话里出现这些就应激活)

- "反派太弱" / "villain too weak" / "antagonist is weak"
- "对抗力量 / 冲突不够强" / "not enough opposition"
- "负面之墙" / "negative wall"
- "主角赢得太轻松" / "too easy"
- "让故事到极限强度" / "push the story to the limit"
- "超级英雄的反派" / "superhero villain"

### 与相邻 skill 的区分

- 与 `mckee-character-design` 的区别: 后者设计主角的压力选择、弧光与维；本 skill 设计主角的对抗力量（负面之墙）。
- 与 `mckee-crisis-climax` 的区别: 两难之择在危机处的具体应用在终点；本 skill 负责"为什么故事需要强对抗、如何分层"。
- 与 `mckee-gap-writing` 的区别: 鸿沟是场景内节拍级动力；本 skill 是全局对抗力量的总和设计。
- 与 `mckee-exposition` 的区别: 后者管信息释放；本 skill 管对抗强度。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出负面之墙**
   - 完成标准: 能列出主角欲望 + 三类对抗源（内心/个人/个人外）各自的内容与目标；能回答"主角失败最坏会失去什么"，答案令人信服（不是"回到正常"）。
   - 判停条件: 若对抗清单为空或只有单一的"坏蛋"，说明冲突不足 → 回到设计补充对抗源与各自欲望。

2. **匹配检验与负面递进**
   - 完成标准: 激励事件当刻主角面对对抗总和像"战败狗"（看起来势不可挡）但仍至少有一次可信的机会；对抗既不落后太多、也不超过到令主角毫无机会；价值链条从相反→矛盾→否定之否定（或触及负面之负面）。
   - 判停条件: 若对抗远超主角致其无机会达成欲望 → 给主角一次可信的机会；若对抗太弱 → 升级对抗或加深价值层次。

3. **从里到外写强敌**
   - 完成标准: 每个对抗人物有自己的自觉欲望与合理理由；不写傻瓜式反派；读者能理解其动机甚至部分移情。
   - 判停条件: 若反面人物像工具人/背景板 → 回到步骤1补充其欲望与目标。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 非冲突本位叙事（静观、诗意、东方"天人合一"传统）："对抗=一切力量的总和"的框架不一定适用。
- 用户只想让主角更有魅力、更有维——那是 `mckee-character-design`。
- 用户问的是危机处的具体两难之择设计——用 `mckee-crisis-climax`。
- 喜剧/低冲突体裁不需要把"负面之墙"推到极致。

### 作者在书中警告的失败模式

- 对抗力量过于软弱（ce21）：故事虚弱的不可避免导因，主人公轻松取胜却总觉欠缺。
- 用怪癖堆砌"三维人物"（ce28）：特征清单不是维，怪癖反而令观众敬而远之。
- 说教倾向（ce19）：把反面人物写成傻瓜、自取灭亡，论战失衡，作品沦为布道。
- 误诊戏剧腔（ce27）：动机不足而非写得太大——事件能量只能等同于原因总和。

### 作者的盲点 / 时代局限

- "冲突即生活本质"假设：静观、无为、禅定等传统并不以匮乏/冲突为本体，"无冲突即无故事"对非冲突本位文化叙事未必成立。
- 好莱坞线性叙事中心主义：反面人物塑造原理以大情节（经典设计）为基准，对非西方叙事中的集体主体、非个体英雄缺乏对等理解。
- "原始模型/普遍人性"假设：对抗力量的普遍性断言缺乏跨文化实证。

### 容易混淆的邻近方法论

- `mckee-character-design`：主角的压力选择 vs 本 skill 的对抗力量。
- `mckee-crisis-climax`：危机处的两难应用 vs 本 skill 的对抗总和的构建。
- `mckee-gap-writing`：场景鸿沟 vs 本 skill 的全局负面之墙。
