## I — 方法论骨架 (Interpretation)

1. **弧光 = 角色演化**：开局「不完整/受损」，靠改变填补缺口。
2. **致命缺陷（Fatal Flaw）**：开局卡住角色的核心负面特质，且常被误认为力量；悲剧中未克服则成 tragic flaw。
3. **根在创伤与谎言**：缺陷源于 Emotional Wound（过去剧痛）→ 角色为防再痛而形成缺陷、并相信一个关于自己的 Lie（错误自我认知）。弧光 = 直面创伤、击碎谎言。
4. **弧光四件套**：Outer Motivation（想要什么）+ Outer Conflict（谁挡）+ Inner Motivation（为什么想要=自我价值）+ Inner Conflict（缺陷/谎言）。内外旅程应镜像。
5. **缺陷须被反制**：角色不需克服所有缺陷，但 fatal flaw 必须被制服或削弱到不再主控；正面特质（如 bravery/determination/justice）是脱困工具（Jason Bourne 例）。
6. **改变是非线性的（锯齿状）**：三进二退，缺陷反复阻挡、每次失败唤起旧创伤、渴望递增，张力升级。一次性「治愈」是假成长。
7. 主角须在故事终局与开局「相反」（controlled→允许他人决策）；反派罕见情感觉醒打破 fatal flaw，但常太迟。

## A1 — 书中的应用 (Past Application)

### 案例：Jason Bourne 的弧光四件套
- **操作**：Outer Motivation「找回我是谁」+ Outer Conflict「特工追杀」+ Inner Motivation「证明我不是冷血杀手」+ Inner Conflict（Lie）「我做过恶事、不配救赎」；fatal flaw=close-mindedness（拒认自愿选择）。正面 alertness/resourcefulness/persistence 反制。
- **结论**：缺陷源于 amnesiac 前的自我，弧光 = 接纳真实自我。

### 案例：Macho Joe 的锯齿改变
- **操作**：English 不及格→承认脆弱向 Maggie 求助（小胜）→ 又因谣言自尊受挫（退）→ 再诚实求助过关（进）→ 失败英语丢位置（退）→ 终向顾问坦白。读者随锯齿共情。
- **结论**：展示 wins/losses 让缺陷「钉」在读者心里。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 用户要写「主角怎么成长 / 负弧 / 平弧」。
2. 用户说「这个缺陷我想让它驱动整条线」。
3. 用户纠结「结局该让他变多少」。

### 语言信号
- "人物弧光" / "成长" / "致命缺陷" / "创伤" / "他相信的谎言" / "character arc" / "fatal flaw" / " redemption"

- 与 `cca-positive-arc` / `cca-negative-arc` 的区别：cca 给弧光类型与节拍；本卡给「缺陷如何成为弧光引擎、如何与创伤/谎言耦合」的特质级机制。

## E — 可执行步骤 (Execution)

1. **植 Wound**：写角色成长期剧痛事件。
2. **写 Lie**：创伤后他相信的关于自己的错误认知（最怕面对之物）。
3. **定 Fatal Flaw**：把 Lie 外化为一个卡住他的负面特质，且他误当力量。
4. **搭四件套**：Outer/Inner Motivation + Outer/Inner Conflict，确保内外镜像。
5. **配反制正面**：选 2–3 个正面特质作脱困工具。
6. **排锯齿**：设计 3 进 2 退的改变节奏，每次失败唤起旧创伤、渴望递增。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- **只填单特质档案** → tct-trait-entry-blueprint。
- **只追成因** → tct-trait-causation-tree。
- **纯外部情节** → 本卡是内在演化，强套弱化动作线。

### 作者警告的失败模式
- **ce08 动机不清/弧光断裂**：不知 inner motivation→角色漂走、前后不一。
- **一次性治愈**：假成长，读者不信。

- 引用 Wound/Lie 原文 ≤150 字/段；机制自由迁移。
