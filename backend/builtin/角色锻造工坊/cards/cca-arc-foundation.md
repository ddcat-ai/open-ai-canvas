## I — 方法论骨架 (Interpretation)

弧光的地基工程，是把"角色内心有毛病"这件模糊的事，拆成三个彼此咬合、能写进大纲的构件：

1. **The Lie（角色相信的谎言）**：角色对自我或世界的一个错误信念。它必须能浓缩成一句话（可用 qualifiers 收窄到角色专属）。恐惧、愧疚、羞耻、秘密都只是它的**症状**，不是病本身。Lie 起初常伪装成优势，越往后越成为致命弱点。
2. **Want vs Need**：Want 是外在、物质性的剧情目标——角色以为拿到它就能治好 Lie 的症状（perceived cure）；Need 是内在的 Truth——Lie 的个性化解药。Want 喂养 Lie，Need 对抗 Lie，二者通常不可兼得；角色必须走到"愿意牺牲 Want 换取 Need"的节点，弧光才算有压力。
3. **The Ghost（创伤成因）**：导致角色相信 Lie 的过去创伤事件，是 Lie 的 Why 与因果锚点。规则是 Ghost 越大 → Lie 越大 → 弧越强，所以弧的强度上限由 Ghost 决定。揭示方式三种可选：第一幕前置戏剧化、全书逐片揭示、永不揭示。

三者合起来是一台**诊断器**：当角色动机模糊、内在冲突空洞时，用"症状 → Lie → Want/Need 对立 → Ghost 因果"反推，就能把"他为什么需要改变"变成可设计、可验证的单一病灶。这是所有弧光（正弧/负弧/平弧的配角）共用的地基。

## A1 — 书中的应用 (Past Application)

### 案例 1: Behold the Dawn — Marcus Annan 的 Lie（作者亲自写作案例）
- **问题**: 主角的内心缺陷写不清病根，只有一脑子情绪标签。
- **方法论的使用**: 作者从症状清单（愧疚、羞耻、秘密、自毁式生活）反推底层信念，得到一句话的 Lie——"有些罪太大，不可能被原谅"；他的 Want 是被原谅、得到幸福与圆满，但 Lie 卡死了这条路。
- **结论**: 症状只是 Lie 的产物；找到 Lie，才谈得上设计对应的 Truth 与整条正向弧。
- **结果**: 三角一旦成型，后续 Want/Need、Ghost、结构打点全部从此派生。

### 案例 2: Jane Eyre — Want vs. Need 的内在战争
- **问题**: 如何让外部情节与角色的内在冲突在动机层面咬合。
- **方法论的使用**: Jane 的 Want 是"被爱"（外在关系目标），Need 是"拥抱精神自由"（内在 Truth）；Want 喂养她的 Lie"唯一赢得爱的方式是奴役自己"，Need 才是对抗 Lie 的解药。
- **结论**: Want 与 Need 不可兼得——角色必须先愿意牺牲 Want，才可能拿到 Need。
- **结果**: Jane 最终在保持绝对精神自由的同时成为 Rochester 的爱妻——先得 Need，Want 反而随之而来（和谐式结局）。

### 案例 3: Jane Eyre 的 Ghost — 姑妈拒绝爱她
- **问题**: 角色信念悬浮无根，缺少"为什么信这条 Lie"的因果锚点。
- **方法论的使用**: Jane 的 Ghost 是姑妈反复告诉她"你邪恶且无价值"、她打心底相信了——这个过去创伤正是 Lie"不配被爱、只能靠服侍换爱"的成因。
- **结论**: 找到 Ghost 就找到 Lie 的 Why；Ghost 决定弧光强度的上限，可作悬念逐片揭示。
- **结果**: Jane 凭借对 Ghost 的最终超越实现精神自由；Ghost 的逐步揭示构成了阅读悬念。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **角色设定阶段**: 主角动机模糊，连作者自己都说不清"他为什么要做这件事"。
2. **人设体检**: 角色被贴了"害怕亲密""自卑""愧疚"等标签，但找不到病根信念；或想要一句能一句话说清的核心信念。
3. **多稿返工**: 角色扁平、像工具人，需要给内在冲突加厚度。
4. **反推因果**: 已设计好情节，但角色的内在问题与主线脱节，需要把两者绑起来。
5. **英文场景**: 用英文写角色时同样适用（writing motivation / character wound）。

### 语言信号 (用户的话里出现这些就应激活)

- "我的角色动机很模糊 / 他到底想要什么" → "motivation is unclear / what does he really want"
- "角色的内心创伤 / 心结 / 阴影怎么设计" → "character's wound / ghost / inner trauma / backstory"
- "他相信什么错误的信念？用一句话说清" → "what Lie does he believe / core belief in one sentence"
- "想要的和需要的是不是一回事" → "want vs need / what he wants vs what he needs"
- "角色为什么需要改变" → "why does he need to change / why is he broken"

### 与相邻 skill 的区分（初稿）

- 与 `cca-opening-anchors`: 本 skill 管"内在冲突的诊断"（病灶在哪），开场 skill 管"第一场戏怎么把角色演出来"（出场与舞台）。先有 Lie 三角，才谈得上用 Characteristic Moment 去暗示它。
- 与 `cca-positive-arc`: 本 skill 是地基（定位病灶），正弧 skill 是施工（三幕逐拍打点）。"动机模糊"先来这里；"成长线断了、中点以后不会写"去正弧 skill。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **反推 The Lie**
   - 列出角色的全部症状（恐惧/愧疚/羞耻/秘密/自毁行为），问："什么信念制造了这些症状？"
   - 把信念浓缩成一句可陈述的句子，可用 qualifiers 收窄到角色专属。
   - 完成标准: 能用一句中文或英文说出"他相信 ______"，且能解释该信念如何"起初像优势、最终成致命弱点"。
   - 判停条件: 若无法一句话说出 Lie，回到素材继续挖；若角色根本没有需要改变的动机（Flat Arc 主角 / 无弧光 situation），停止——本 skill 不适用，改判断弧光类型（cca-arc-selection 范畴）。

2. **拆 Want 与 Need**
   - 写出外在剧情目标（Want），再写内在 Truth（Need）。
   - 验证: Want 是否在喂养 Lie？Need 是否在对抗 Lie？二者在哪里必然冲突？
   - 完成标准: 各用一句话写出 Want 与 Need，并能说明"追 Want 为何反而让 Need 更远"。

3. **反推 Ghost 并定揭示策略**
   - 问："什么过去事件导致他相信这条 Lie？" 把它定为 Lie 的因果锚点。
   - 按想要的弧强度决定 Ghost 大小，并选择揭示方式（第一幕前置 / 逐片揭示 / 永不揭示）。
   - 完成标准: 能讲出 Ghost 事件 + 它与 Lie 的因果链 + 揭示计划；检查"Ghost 越大，弧是否越强"，强度不足就放大 Ghost。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **Flat Arc 主角**: 开场已掌握 Truth、几乎不改变——他没有需要克服的 Lie，地基诊断不适用（那是平弧 skill 的领域）。
- **无弧光的 situation 故事**: 如《夺宝奇兵》，没有 Lie/Truth 之争，强行造病灶反而画蛇添足。
- **纯情节/世界观搭建**: 用户要的是事件、设定、类型套路，不是角色内在。
- **群像/多视角**: 本 skill 默认"一个主角 + 一个核心困境"，对无主角叙事乏力。

### 作者在书中警告的失败模式

- **把症状当病**: 只给角色贴"心怀愧疚/怕亲密"标签，找不出底层信念——弧光没有可被挑战的对象（ce03）。
- **Want 只是表面目标**: "世界征服、娶妻——谁不想要呢"，目标与角色深层缺失无关，弧光无法附着（ce07）。
- **内在问题与主线脱节**: 先设计好情节再硬塞个人冲突，Lie 无法被情节挑战，两条线各走各的（ce01）。

### 作者的盲点 / 时代局限

- **单一 Ghost 归因是简化决定论**: 真实人格改变是混沌、非线性、多重归因的；"每个 Lie 都有唯一成因"在心理学上不充分。
- **"一句话化"是设计工具而非人性事实**: 许多深刻角色的困境远无法如此浓缩；压缩失败不代表角色坏，可能只是这个框架不适用。
- **道德绝对主义底色**: 作者把"拥抱 Truth"等价于"道德上升"，带基督教价值预设；对非道德主题（技艺精进、知识获得、存在主义、反讽叙事）不适用。

### 容易混淆的邻近方法论

- **泛泛的创伤背景设定**: 不是任何过去事件都算 Ghost——Ghost 必须与 Lie 有明确因果链，否则只是"心理阴影"标签。
- **心理学的人格/动机理论**: Want/Need 在这里是**结构工具**（指向 Third Plot Point 的对立选项），不是对真实人性的完整描述。
