## I — 方法论骨架 (Interpretation)

主人公设计的本质是**移情工程**——让读者/观众关心这个人，并在他身上照见自己。三大件：

1. **善中（center of good）**：不是"好人"，而是主人公内心深处的一束正向光芒（忠诚、智力、幽默、爱），被周围负向黑暗反照出来才有磁性。恶人阵营里最"好"的那个（《教父》的忠诚、《沉默的羔羊》汉尼拔的绅士风度）同样能当善中。写作顺序是：先铺黑暗世界，再在中心埋光——光靠反照，不靠罗列善良。

2. **下风狗（underdog）**：做一个双掌称量试验——一掌放主人公的全部能耐（精神/情感/身体），另一掌放全部对抗力量（内心负面想法、人际冲突、机构障碍、物理世界）。后者必须压倒性占优，主人公才是一条下风狗。因为人人心底自认是下风狗，所以不会移情于上风狗（扎克伯格式一路碾压的角色）。

3. **八素质体检**：意志力（穷尽所有意志力应对终极两难）、多才多艺、下风狗位置、移情本质（善中）、心机（最复杂的矛盾引人好奇"他是谁"）、长度与深度（成为被了解最深的人物）、改变容量（有弧光的通常是主人公）、洞察力（经历顿悟）。逐项体检，缺项就补。

此外两条**登场/留白纪律**：主人公约留白 7/10、只表达 3/10 特性，让读者用想象力脑补其余；并推迟登场，先由配角铺垫制造神秘，再在最有效的场景给主人公一个精彩亮相。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《教父》的善中：忠诚
- **问题**: 一伙黑手党恶人，如何获得观众的移情与认同？
- **方法论的使用**: 麦基指出，一个充满腐败警察与寻租法官的黑帮宇宙里，柯里昂家族的正面光芒是"忠诚"——其他犯罪家族互相背叛、背后捅刀子，唯独"教父"家族团结一心、互相守护，成为"坏人中的好人"。
- **结论**: 善中不是罗列善良，而是先铺黑暗、再在中心埋光，光靠反照。恶人阵营里最"好"的那个也能当善中。
- **结果**: 观众感知到柯里昂家族的正面中心，移情自然流动——观众本能认同黑帮分子。

### 案例 2: 《沉默的羔羊》汉尼拔——第二个善中
- **问题**: 一个吃人魔，为何能吸住观众的移情？
- **方法论的使用**: 麦基拆解托马斯·哈里斯如何为莱克特构建善中：先用黑暗世界包围他（撒谎的 FBI、施虐狂狱卒、傻瓜警察），再从他内心辐射光芒（智商超群、犀利的幽默感、身处地狱仍保持的泰然与礼貌）。读者耸肩认同："如果我是一个精神变态的食人连环杀手，我也要像莱克特那样。"
- **结论**: 两个善中（克拉丽丝的英雄主义 + 莱克特的正面品质）分割读者焦点；负面社会内的正面品质让坏人也能吸住移情。
- **结果**: 汉尼拔成为"坏人阵营里最不坏的那个"，移情成立——善中的位置决定读者站在谁那边。

### 案例 3: 下风狗试验 + 里克的迟到亮相
- **问题**: 怎么检验主人公是否处于下风狗位置？怎么让他一亮相就有冲击力？
- **方法论的使用**: 双掌称量试验——一掌放主人公全部能耐，另一掌放所有对抗力量，称量后主人公必须以压倒性劣势迎接故事，只有一线希望达成欲望目标。登场策略上，《卡萨布兰卡》用开篇众人对里克的讨论铺垫其魅力与神秘，镜头最终着落于穿白色燕尾服独自对弈的里克，观众自然发问"这家伙是谁？"
- **结论**: 移情 = 善中 + 下风狗位置 + 权力平衡；推迟登场 + 精彩亮相是最佳第一印象策略。
- **结果**: 读者不移情于上风狗（《社交网络》的扎克伯格），却会为受困的白燕尾服里克驻足——登场瞬间决定读者对主角未来的关怀。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 主角"不讨喜""没人喜欢""读者骂主角"。
2. 写恶人/反英雄主角，怕读者不接受。
3. 主角太强、一路碾压（上风狗），读者毫无紧张感。
4. 设计第一印象：主角什么时候出场、怎么亮相才震撼。
5. 开新项目，需要一次性把主人公的移情配置搭好。

### 语言信号 (用户的话里出现这些就应激活)

- "主角不讨喜 / 没人移情 / 读者讨厌主角" / "unlikeable protagonist", "no empathy", "the audience doesn't care"
- "主角太强 / 一路碾压 / 无所不能" / "protagonist too powerful", "always wins"
- "怎么让读者喜欢主角 / 关心主角" / "make the audience care", "make him likeable"
- "主角什么时候出场 / 登场 / 第一印象" / "when should the hero appear", "first appearance"
- "反派主角 / 恶人主角 / 反英雄" / "villain protagonist", "anti-hero"
- "善中 / 下风狗 / 讨喜设计" / "center of good", "underdog", "sympathetic"

### 与相邻 skill 的区分

- 与 `mckee-cast-design` 的区别: 本 skill 管"恒星"——主人公本身的移情配置（善中/下风狗/八素质）；cast-design 管"太阳系"——主角+三圈配角的功能布局。先定好恒星，再布卡司。
- 与 `mckee-character-desire` 的区别: 本 skill 管"观众为何关心"（移情工程）；desire 管"人物为何行动"（动力引擎）。善中解决"喜不喜欢"，欲望解决"做不做"。
- 与 `mckee-character-dimensions` 的区别: dimensions 管"复杂程度"（矛盾对的数量与质量）；本 skill 管"让这种复杂被喜欢"。下风狗称量是移情前提，维度是复杂度供给，二者常配合使用。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **安置善中**
   - 完成标准: 用一句话说出主人公的善中是什么（一个具体的正向价值：忠诚/智力/幽默/爱等），并写明周围哪一层负向黑暗在反照它——能回答"没有这层黑暗，这束光还亮不亮"。
   - 判停条件: 若主人公纯恶且无任何可反照的正向品质（奥布莱恩式减去良心的极端人物）→ 本 skill 不适用，改用极端人物逻辑，不硬塞善中。

2. **下风狗双掌称量**
   - 完成标准: 列出两列清单——左手：主人公全部能耐（精神/情感/身体）；右手：全部对抗力量（内心负面、人际冲突、机构障碍、物理世界）。判定右手明显压过左手，主人公仅剩一线希望。
   - 判停条件: 若对抗力量轻于主角能力（上风狗）→ 回步骤 1 重新配置，或为故事加强对抗力量（配戏规则：要给人物加深，先给他的世界加对抗）。

3. **八素质体检 + 留白与登场**
   - 完成标准: 对八项素质（意志力/多才多艺/下风狗位置/移情本质/心机/长度与深度/改变容量/洞察力）逐项给出"有/缺/补法"；写出主人公的 3/10 特性清单（其余 7/10 留白）；给出明确的登场场景设计（配角铺垫 + 精彩亮相）。
   - 判停条件: 若检查发现缺项过多且无法补救 → 判定该角色不适合作为主人公（可能只是配角材料），考虑更换主角或转交卡司设计。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 极端人物（减去良心的纯恶、减去信仰的虚无）：其设定排除了善中与常规移情路径。
- 群像戏无单一主人公（如《云图》的转世结构）：没有唯一的"恒星"供配置。
- 儿童故事/寓言主角：道德示范优先，不需要完整的八素质体检。
- 喜剧配角的"被迫害式"设计：那是服务型角色的功能问题，不是主人公的移情工程。

### 作者在书中警告的失败模式

- **上风狗无法移情**（ce22）：主人公全知全能、一路碾压，读者在"善中"里找不到自己的镜像，移情流失。
- **顿悟用力过猛**（ce25）：八素质中的"洞察力"若写成堆砌说教的顿悟场景，最容易砸成尴尬——顿悟是宁为玉碎不为瓦全的高危事件。
- **支持型角色抢戏**（ce09）：配角的趣味超出卡司功能，夺过故事讲述的船舵，读者的移情焦点从主人公滑走。
- **单一特性=小角色**（ce11）：7/10 留白的反面不是全给，而是只给 1/10——一个标签式特性（外国口音）让主人公沦为小角色。

### 作者的盲点 / 时代局限

- **7/10 留白、"理想画布密度 1.3"等数字是作者的审美独断，无实证支撑**："留白优于全给"的原则可操作，但具体比例不必照抄（阶段0批判#5）。
- "善中"是把道德还原为二元正负负荷的简化模型；现实中移情机制远比"一束正光被黑暗反照"复杂，文化熟悉度、叙事视角、社会距离都影响移情（批判#2）。
- 下风狗/善中的案例全部来自西方文本；在集体主义叙事或英雄崇拜文化里，"下风狗"未必构成移情的主因，需跨文化转译（批判#1）。
- "表达一切/完成人物"的黄金理想与"7/10 留白"存在内部张力：麦基一边主张人物比真人更可全知、不剩未表达之物，一边要求留白 7/10，二者未被真正调和（批判#3）。

### 容易混淆的邻近方法论

- **善中 ≠ 主角道德**：善中不要求主人公是好人，只要求"黑暗中有光"——《教父》的忠诚、《沉默的羔羊》的智力幽默都是善中，与道德高下无关。
- **下风狗 ≠ 弱鸡**：下风狗是"能耐不足但意志力与欲望极强"，是主动挣扎的劣势者；没有意志力的被动受气包不会赢得移情。
