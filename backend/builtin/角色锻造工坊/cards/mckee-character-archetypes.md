## I — 方法论骨架 (Interpretation)

麦基把"人物有多抽象"做成一把五级刻度尺：**原型**（本质→人物，如希腊神祇）、**寓言**（价值→人物，如真理之泉）、**类型**（行为→人物，如复仇者）、**模式**（职业→人物，如侦探）、**刻板**（偏见→人物，最劣）。越往左越好懂也越单薄，越往右越接近对真相的扭曲——刻板不是"写腻了"，而是"所有的X都是Y"的逻辑谬误，是把活人压缩成标签，比陈词滥调更恶劣。象征人物还可按辐射范围分级：个人、家庭、社区、国家、物种，范围越大越要小心被概念压垮。

三条操作规则。其一，**象征必须戴面纱**：用见所未见的人物塑造表面迷住读者，把原型"偷运"进潜意识；读者一旦说破"哦，他是XX的象征"，人物立刻扁平。其二，**主体类型四件套**：16 个主体类型（10 命运+6 性格）各由核心价值、核心事件、核心情感、核心卡司构成，是给类型故事做"故事-人物"体检的配方。其三，**长篇连续剧靠揭示与进化锁住观众**：主角复杂度要远超三个维度（沃尔特 16 维），重复与僵化是剧集杀手。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《奴隶游戏》——认知谱系卡司
- **问题**: 要写一部关于种族议题的现代寓言，如何让八个角色既不脸谱化、又能各自代表一种认知立场？
- **方法论的使用**: 麦基拆解哈里斯如何把"象征谱系"铺成一根卡司轴——"人物认知的谱系：从犀利的洞察到蠢钝的盲目"。一端是坎内夏（痛苦的自我意识），另一端是幸福自欺的吉姆，中间八人各占一个认知刻度。
- **结论**: 象征不靠单个角色背概念，而靠整条谱系承担象征；每个成员互相映照出种族两难的权力结构。
- **结果**: 第一幕象征自我与第二幕核心自我构成矛盾、第三幕二者融合即人物完成——象征人物在矛盾中立体起来。

### 案例 2: 《权力的游戏》——象征光谱两端的女王
- **问题**: 超级奇幻里人物天然带神话性，怎么写得不扁平？
- **方法论的使用**: 麦基把"现实主义 vs 象征主义"当作一根轴：右端瑟曦（倒行逆施、生活在神话中），左端丹妮莉丝（正义进步、拒绝神话），中间铺满守夜人英才教育、无垢军队平均主义等灰度。
- **结论**: 象征性是程度问题，可以在光谱上精确取点，而非二选一。
- **结果**: 160 个角色的卡司覆盖全部象征/现实主义程度与政治点位；当夜王入侵，两派张力退隐为谁生谁死。

### 案例 3: 《嗜血法医》——揭示耗尽杀死长篇
- **问题**: 长篇剧集怎么防止主角后期乏味、观众弃剧？
- **方法论的使用**: 对照《绝命毒师》的杰西（六维、持续揭示与变化）与德克斯特（第四季已全知、五至八季停滞）。
- **结论**: 长篇靠"揭示+进化"锁定观众；一旦无物可揭示、无可改变，行为可预测，铁粉也敬而远之。
- **结果**: 德克斯特弃剧潮；沃尔特以 16 维×80+角色撑满 62 集——复杂度要远超三个维度。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写/改角色时觉得"太脸谱化""太符号化""他就是代表XX的"——把人物放到五级谱系上定位抽象度。
2. 想写象征性强的作品（寓言、奇幻、社会隐喻），怕人物因象征而扁平——检查面纱是否戴牢。
3. 在写长篇剧集/系列，担心主角后期重复、无物可挖——清点"揭示存量"。
4. 在做主体类型故事（动作/爱情/教育等），想体检"故事-人物"是否匹配——跑四件套。
5. 审稿发现配角靠族裔/性别/职业贴标签——识别刻板并拆解。

### 语言信号 (用户的话里出现这些就应激活)

- "脸谱化""符号化""工具人""刻板印象""原型""象征人物""代表XX""说破了""太扁了"
- "stereotype""archetype""symbolic character""flat character""symbol of XX""preachy""type"
- "长篇""剧集""后面几季""重复""没什么可挖了""揭示""进化""season""long-running""predictable"

### 与相邻 skill 的区分

- 与 `mckee-character-dimensions` 的区别: 维度是给单个人物加矛盾对、检验"始终如一/多变/无解"；本 skill 定位人物在象征谱系上的抽象度，并把抽象人物落地为具体面纱。可组合：先定位谱系，再加维度。
- 与 `mckee-cast-chart` 的区别: 卡司图管整套人的圈层配位与权力平衡；本 skill 管单个角色的象征纯度。
- 与 `mckee-protagonist-design` 的区别: 善中/下风狗管移情工程；本 skill 管象征身份——写"象征性主角"时两者都要调。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定位谱系刻度**
   - 完成标准: 用一句话说出"该角色落在原型/寓言/类型/模式/刻板哪一级、依据是什么"，并给一个相反级别的对照。
   - 判停条件: 若人物毫无象征意图（纯写实生活流），直接输出"无需象征化"，跳到步骤 4 只做四件套体检，不强制升级抽象度。

2. **刻板筛查**
   - 完成标准: 若落在模式/刻板级，能列出至少 2 条与标签无关的具体塑造细节（外貌/言行/来历）；若只剩标签，用"形容词→反义词"拆解该标签。
   - 判停条件: 若该角色在谱系上属原型/寓言/类型（非刻板），本步通过即跳过，不逐条苛查。

3. **戴面纱检查**
   - 完成标准: 象征含义只能通过至少 1 个"无关表面细节"的间接路径传递；无一句"我是XX的象征"式台词，名字/职业/造型不直白声明象征。
   - 判停条件: 若用户做的是寓言/讽喻文体（说破是文体规则），跳过本步。

4. **主体类型四件套体检**（仅当用户在做主体类型故事）
   - 完成标准: 核心价值、核心事件、核心情感、核心卡司各有一句可检验的表述，且四者互相咬合（如动作=生/死+英雄命垂恶棍之手+兴奋+英雄/恶棍/受害者）。
   - 判停条件: 非类型故事（纯艺术片/生活流）跳过。

5. **长篇揭示存量检查**（仅当是长剧/系列）
   - 完成标准: 列出"已揭示"与"未揭示"两组清单；未揭示不足支撑剩余时长时，提出新增维度或建议终结。
   - 判停条件: 单部电影/短篇跳过本步（复杂度由卡司规模与表演时间决定）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户写的是纯现实主义生活流，人物不该有象征性——贴象征标签反而伤害可信度（先确认体裁）。
- 用户只是想让单个人物"更立体"，加矛盾对即可——那是 `mckee-character-dimensions` 的活。
- 用户要套"英雄之旅"模板批量产英雄/导师/反派——这正是麦基警告的坎贝尔滥用，本 skill 反对以"这是原型"为扁平辩护。
- 长篇刚开写一两季，尚未到揭示耗尽阶段，不必做存量预警。

### 作者在书中警告的失败模式

- **说破象征=扁平**: 读者一旦"哦，他是XX的象征！"，角色即流于扁平、冲击力流失殆尽（第12章）。
- **刻板=偏见**: 刻板起于"所有的X都是Y"，把原型削减为偏见（大地母亲→犹太母亲），是对真相的扭曲，比陈词滥调更恶劣（第12章）。
- **坎贝尔单一神话的滥用**: 把"英雄之旅"当普世公式按模板生产人物，主人公沦为无维度动作傀儡（第3章）。
- **长篇重复与僵化**: 一旦主人公没有剩下任何可揭示的东西，行为可预测且单调乏味，观众敬而远之（第17章）。

### 作者的盲点 / 时代局限

- **欧美中心主义**: 全书原型与象征案例几乎全部取自西方神话、宗教与好莱坞传统，非西方叙事（东亚类型、动漫、游戏、第三世界通俗叙事）的象征体系未被检验；"人性无趋势、人人相通"的普遍性主张建立在单一文化样本上，可迁移性存疑。
- **"完成人物"黄金理想抹杀留白**: 麦基一边赞美身份不确定、意义不可知的现代人物传统，一边把"完全揭示"立为最高目标，未真正调和；大量杰作恰恰靠人物的不可穷尽性存续。
- **"越抽象越好懂也越单薄"是经验性断言**: 五级谱系的刻度划分带有审美独断，非实证结论。

### 容易混淆的邻近方法论

- "加维度" vs "戴面纱": 维度是给人物塞矛盾对，面纱是给象征人物裹上具体表面——不要用面纱替代维度，也不要用维度替代抽象度定位。
- 类型四件套 vs 象征谱系: 四件套是主体类型配方的"体检表"，谱系是抽象纯度刻度——类型人物不必然象征，象征人物也不必然归属某一类型。
