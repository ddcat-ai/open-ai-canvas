## I — 方法论骨架 (Interpretation)

正向弧是"角色从被 Lie 奴役到克服 Lie"的完整路径，Weiland 把它精确对位到三幕结构的六大关键时刻，让角色成长可逐拍检查：

1. **First Plot Point（约 20-25%）**：把主角踢出 Normal World、确立基于 Want 的明确剧情目标，从此不可回头。自此刻起，新世界开始系统性地**惩罚**按 Lie 行动的主角（惩罚 Lie 引擎）——旧行为在新环境里不断失效，这是改变的第一台发动机。
2. **Midpoint / Moment of Truth（约 50%）**：主角从反应转为行动，第一次真正"看见"并接受 Truth；但他并不抛弃 Lie——意识上仍声称信 Lie，潜意识已按 Truth 行动，成为"分裂的人"，进入认知失调与 vacillation escalation（摇摆升级），并不断犯错。
3. **第二幕后半**：用 before/after 镜像场景证明改变（同一情境、相反反应）；以**假胜利**收尾——Want 近在咫尺，角色伸手去拿，却不知拿到 Want 就要重新臣服于 Lie。
4. **Third Plot Point（约 75%）**：弧光中最重要的一刻——反派逆转 + 意外揭示把主角逼到 Want 与 Need 之间的**灵魂级二选一**。选择 Truth 即"旧我之死"（常伴死亡意象），且必须烧断退路、落实为不可逆的行动。
5. **Climax（约 90%）**：角色证明自己能**长期持守 Truth**——反派会用 Lie 猛击他旧伤结痂处。第一法则：角色未必得到 Want，但一定得到 Need。
6. **Resolution**：双重职责——回答主题问题（不加掩饰但不拍脸）+ 展示"无 Lie 的新常态"，并与开场 Normal World 刻意镜像对照。

引擎逻辑：Lie 提供改变的理由，惩罚提供改变的动机，Truth 在 Midpoint 植入、在 TPP 决断、在 Climax 证成。

## A1 — 书中的应用 (Past Application)

### 案例 1: Thor 的完整正弧
- **问题**: 如何让正弧的六个打点与三幕结构逐一对位，而不只是"角色变好了"。
- **方法论的使用**: 开场 Lie"强者即真理"（Might makes right）使他成为王位继承人；FPP 因傲慢被逐出阿斯加德；第二幕前半新世界持续"惩罚"他的傲慢（被电击、被麻醉、被车撞）；Midpoint 举不起自己的雷神之锤，意识到"单靠力量不配挥舞它"；TPP 为救人选择停止战斗、牺牲自己；Climax 为保护九界亲手摧毁彩虹桥，看似断送回到新爱人身边的机会。
- **结论**: 六个关键时刻逐一对位三幕，改变靠"行动"证成而非叙述告知。
- **结果**: Resolution 向父亲道歉："I have much to learn."——新常态与开场傲慢构成镜像。

### 案例 2: Jane Eyre 的假胜利 → Third Plot Point
- **问题**: 第二幕如何收尾，才能让第三幕的崩塌产生最大落差。
- **方法论的使用**: Jane 在第二幕末答应嫁给 Rochester，看似同时拿到 Want（被爱）与 Need（被尊重）——但她内心并不安宁，隐约感到这桩婚姻又一次要她牺牲精神独立、把自己奴役出去。
- **结论**: 假胜利 = 角色说服自己"两全其美"，把 Truth 扔出窗外、继续抱紧 Lie，为崩溃埋雷。
- **结果**: 假胜利立即被 TPP 击碎——Rochester 已有疯妻，Jane 被逼到"留下做情妇 vs 逃走守自由"的灵魂级二选一，选择 Truth 并逃离，烧断退路。

### 案例 3: Cars 的 Climax — 拒绝 Want、证成 Truth
- **问题**: Climax 如何证明角色真的变了，而不只是打赢了反派。
- **方法论的使用**: Chick 自私地撞翻老赛车手 The King——那正是开场 Lightning 自己会做的事；他正要夺冠，却在终点线前刹车让 Chick 赢，折返陪 The King 完赛。
- **结论**: Climax 是"长期持守 Truth 能力"的证明；角色未必得到 Want（Piston Cup），但一定得到 Need——正弧第一法则。
- **结果**: Resolution 他拒绝 Dinoco 赞助、兑现对 Mater 的承诺——新常态与开场"光环喧嚣的赛道世界"构成最强对比，改变被视觉化坐实。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **成长线断裂**: 第二幕后半写不下去，主角"突然想通了"或一直原地踏步。
2. **逐拍打点**: 需要给三幕结构安放 FPP / Midpoint / TPP / Climax / Resolution 的位置与内容。
3. **结局无力**: 读者反馈"他开场也能这么干"，弧光强度存疑。
4. **中段失速**: 只有情节事件堆叠，角色的内在冲突没有在 beat 上推进。
5. **英文场景**: 用英文规划 positive arc / three-act beats 时同样适用。

### 语言信号 (用户的话里出现这些就应激活)

- "成长弧 / 正向弧 / 角色成长怎么写" → "positive arc / change arc / character growth"
- "中点 / Midpoint 该发生什么" → "midpoint / moment of truth / mirror moment"
- "第三幕 / 高潮 / 结局怎么写" → "third act / climax / resolution / finale"
- "角色变化太突然 / 成长线断了 / 没说服力" → "character change feels unearned / arc is broken / abrupt change"
- "第二幕 / 假胜利 / 终极选择" → "second act / false victory / ultimate choice / third plot point"

### 与相邻 skill 的区分（初稿）

- 与 `cca-arc-foundation`: 地基 skill 定位病灶（Lie / Want / Need / Ghost），正弧 skill 负责把病灶在三幕中逐拍清除。打点前先确认地基已建——动机模糊去地基，成长线断裂来这里。
- 与 `cca-opening-anchors`: 开场 skill 只覆盖开场两锚（Characteristic Moment + Normal World，第一幕前半）；正弧 skill 从 FPP 之后开始逐拍（FPP 的前提是 Normal World 被掀翻）。
- 与负弧/平弧: 本 skill 只做"信 Lie → 克服 Lie"的正向路径；负弧（堕落/幻灭/腐化）是镜像、平弧是"主角不变、世界在变"，机制都不同。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **铺设第一幕 → First Plot Point**
   - 确认 Normal World 已戏剧化 Lie（否则先回 cca-opening-anchors）；在第一幕安置强化 Lie、暗示潜能、给角色改变的第一课、安排一个他会拒绝的 Inciting Event。
   - 在约 20-25% 处安排"不可回头"的 FPP：事件前有角色自己的决定，事件中他决定"反应"（不转身退回旧生活），事件后迅速形成基于 Want 的明确剧情目标。
   - 完成标准: FPP 之后角色无法退回旧生活，且剧情目标能一句话写出；能指出"从此新世界开始惩罚他的 Lie"的第一处场景。
   - 判停条件: 若角色动机/信念本身模糊，停止打点，回到 cca-arc-foundation 补地基；若主角开场已掌握 Truth（Flat Arc 主角），停止——本 skill 不适用。

2. **打第二幕两拍: 惩罚 Lie 引擎 → Midpoint → 假胜利**
   - 前半（FPP 到 Midpoint）：旧行为持续被新世界惩罚 + 至少一个"没有 Lie 的生活"的一瞥 + 提供一个"可应用的 Truth"作为工具。
   - Midpoint 的 Moment of Truth：角色第一次接受 Truth，但意识仍声称信 Lie，潜意识开始按 Truth 行动——写出这个"分裂的人"的证据场景。
   - 后半（Midpoint 到 TPP）：用 before/after 镜像场景展示摇摆与改变（同一情境、相反反应），以"假胜利"收尾（Want 触手可及，角色伸手去拿）。
   - 完成标准: 能指出 Midpoint 的具体场景 + 角色"口头信 Lie、行动按 Truth"的分裂证据 + 假胜利场景；确认 Midpoint 后角色并未彻底抛弃 Lie（认知失调仍在）。

3. **打第三幕三拍: TPP → Climax → Resolution**
   - Third Plot Point（约 75%）：反派逆转 + 意外揭示，把角色逼到 Want 与 Need 的灵魂级二选一——Want 必须在触手可及处、选择必须撕心裂肺、且落实为不可逆行动（烧断退路）+ 死亡意象（旧我之死）。
   - Climax（约 90%）：角色在最大压力下证明能长期持守 Truth（反派专打旧伤处）；按正弧第一法则验收——未必得到 Want，但一定得到 Need。
   - Resolution：双重职责——回答主题问题（不加掩饰但不拍脸）+ 展示"无 Lie 的新常态"，与开场 Normal World 镜像对照。
   - 完成标准: 用"Climax 前测"自检——把 Climax 事件挪到开场，角色若同样反应则弧不够强，回炉加强；Resolution 能同时指认"主题答案"与"新常态 vs 开场"的对照。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **Flat Arc 主角**: 开场已掌握 Truth、几乎不改变，故事主轴是"世界在变"——六打点引擎不同（主角的 Truth 是武器而非目标）。
- **Negative Arc**: 堕落/幻灭/腐化是正弧的镜像，TPP 机制相反（角色因拒绝 Truth 而失去唯一武器、无力自救），照搬正弧打点会写错。
- **无弧光的 situation 故事**: 没有 Lie/Truth 之争（如《夺宝奇兵》），六打点无从谈起，强行套用反而"为弧而弧"。
- **反结构 / 非线性叙事**: 百分比锚点与逐拍对位基于三幕好莱坞范式，不适用于反结构、意识流、实验叙事。

### 作者在书中警告的失败模式

- **Midpoint 就让角色彻底抛弃 Lie**: 后面 25% 失去认知失调的冲突材料，TPP 失去二选一的前提（ce11）。
- **TPP 不是灵魂级二选一**: Want 不够近、选择没有真正失去珍视之物，弧光最重的一拍落空（ce12）。
- **教训与 Climax 因果断裂**: 角色太早学完教训，与最终胜利隔太远，胜利像运气（ce13）；或在繁忙的 Climax 里强行塞入弧光收束，决斗中做存在主义抉择（ce14）。
- **Resolution 说教**: 把"故事的道理"甩到读者脸上，主题越直白宣教越廉价（ce15）。
- **只有宏观结构、缺场景级奖惩**: 每个场景都要惩 Lie、奖 Truth（含 "yes, but..." 部分灾难），否则改变不从内部长出（ce24）。

### 作者的盲点 / 时代局限

- **百分比锚点是参考区间不是教条**: 12/25/50/75/90% 暗示"唯一正确节奏"，客观上抑制实验；写于 2016，对串流时代跨季长弧、反结构叙事基本未触及。
- **道德上升-下降框架带基督教底色**: 正弧 = 拥抱 Truth = 道德上升；对非道德主题（技艺精进、知识获得、存在主义）或反讽叙事并不适用。
- **三类弧光分类不穷尽**: 作者自己也承认无弧光故事（Raiders）可以伟大；强按六打点最可能产出"结构正确但灵魂雷同"的故事，书中没有给出避免公式化的机制。
- **人性模型简化**: 把改变简化为"认知矫正"（Lie→Truth 的一次性翻转），忽略人格改变的混沌、非线性与情境制约；案例集中于好莱坞商业片与英美经典，跨文化普适性未证。

### 容易混淆的邻近方法论

- **一般的"三幕结构"（plot beats）**: 本 skill 是"角色内在冲突在三幕中的对位"，不是情节三幕的通用指南——后者不需要 Lie/Truth 引擎。
- **"英雄之旅"（Vogler）**: 结构表面相似，但引擎是启程/考验/归来，不是"惩罚 Lie → 接受 Truth → 证成"；两者可叠加但别混为一谈。
- **弧光选型三问（cca-arc-selection）**: 那是"该用正弧还是负弧/平弧"的决策，本 skill 假定"已是正弧"之后才开始施工。
