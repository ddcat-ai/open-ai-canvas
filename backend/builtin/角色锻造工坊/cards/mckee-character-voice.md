## I — 方法论骨架 (Interpretation)

角色专属声音是"只有这个角色能说出的话"，它由两层可拆解的语言指纹构成：

1. **提问法先行**：别急着写台词，先问"这个角色在这情境下会怎么说"。同是受惊呼神，阿拉巴马人和底特律人喊法不同；找到对角色真实的字眼，标准是"这句话无法适用于任何其他角色"。
2. **词汇层=知识**：名词和动词命名角色所知道的世界。说"大钉子"还是"钉杆""补钉"，暴露说话者是外行还是木工；词库范围就是角色的阅历、职业、教育与社会圈层。
3. **修饰层=个性**：形容词、副词、语态、情态动词表达感性生活与世界观。看烟火说"好大"还是"壮丽"是两种人；用主动式还是被动式、"可以"还是"必得"，都泄露角色气质。
4. **声音是结果而非选择**：不要为不同而不同、刻意找风格。当才能拥抱内容、角色研究透了，独特声音会作为自然结果涌现；古怪不等于创意，需靠品位把关。
5. **文化语境定浓度**：高语境文化（共享背景多）少字传意、潜文本厚；低语境文化需明说详述、文本多。写对白先判断角色所在圈层的共享背景，再定文本/潜文本配比。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《裘力斯·凯撒》卡西厄斯"太阳神铜像"劝诱
- **问题**: 麦基要示范"角色专属对白"如何落到一句台词上；他先写坏版本——给卡西厄斯加修饰语，角色立刻变得胆小紧张。
- **方法论的使用**: 拆莎翁原句"他像一个太阳神铜像，跨越了这狭隘的世界"：名词"铜像""世界"命名卡西厄斯的城邦政客视野（知识范围）；动词"跨越、走着、窥探"显示贵族演说教养下的主动性格；"狭隘"是卡西厄斯眼中的世界——词汇命名知识、修饰语暴露心理同时应验。
- **结论**: 莎翁代入角色写才写得出"狭隘"；直白说"杀了他吧"违背贵族教养，加修饰语又让他变胆小，每一步都不可省。
- **结果**: 四个原理在莎翁一句台词上全部应验，成为"角色专属对白"逐句细读的典范。

### 案例 2: 《我为喜剧狂》杰克·唐纳希的词汇与语法
- **问题**: 喜剧角色杰克看似是"高端精英"，麦基要证明词汇和语法像衣服一样从内到外打扮角色。
- **方法论的使用**: 拆"费边策略"一段三场戏——名词（宝黛丽、戈德华特、游艇、麋鹿舌头）表达上层文化知识与身份认同；情态动词（不能再、你必须、假如/那么）显示支配欲；定语从句展现平衡语法风格。
- **结论**: 词汇+语法不只是文采，而是角色的身份、权力欲与世界观的直接载体；七个维度（世故vs原始、狂妄vs负罪）都能从语言指纹读出。
- **结果**: 一句台词同时完成解说、角色塑造与喜剧效果，验证"词汇=知识、修饰语=个性"的配方。

### 案例 3: 《纯真博物馆》凯末尔——语态微调改变声音
- **问题**: 叙事性对白里，同一叙述者要装三个自我（讲师/浪漫者/批判者），声音如何区分？
- **方法论的使用**: 帕慕克让凯末尔以第一人称对读者说话，"would（会）"的反复使用软化现实、制造可能或未曾发生的气息；时态从现在式转过去式，把浪漫自我"困在过去展览"。
- **结论**: 语态/情态动词层面的微调，能整体改变对白质地与情绪——正是"修饰语表达个性"在英文语态上的具体化。
- **结果**: 一个叙述者装三个自我而不混淆，示范声音不只靠选词，也靠语法层。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写完一场戏后觉得所有角色说话一个腔调，删掉名字分不清谁是谁。
2. 给特定职业/地域/阶层角色（木工、黑帮、律师、乡下人）写台词，想要他"像他"。
3. 长篇作品里主角旁白/内心独白与作者本人声音混同。
4. 做角色设定时就想要一张"语言指纹卡"，先定词汇再写话。
5. 修改稿里发现角色说了超出其知识范围的词（角色认知越界）。

### 语言信号 (用户的话里出现这些就应激活)

- "所有角色说话都一样" / "all my characters sound the same"
- "这句台词不像这个角色会说的" / "this line doesn't sound like him"
- "怎么让角色说话有自己的味道/声音" / "give my character a distinctive voice"
- "角色个性化 / 专属语言" / "individualize the dialogue"
- "角色用词/口吻/身份感" / "character diction, register, idiom"

### 与相邻 skill 的区分

- 与 `mckee-dialogue-clinic` 的区别: 诊所是全面诊断对白瑕疵（写在鼻子上/空洞字眼/动机缺失）；本 skill 只专注"每个角色声音是否专属"这一件事，是诊断中的个性化维度。
- 与 `mckee-dialogue-beats` 的区别: 节拍拆解管"潜文本里角色在做什么行动"；本 skill 管"表面文本上角色用什么词说话"，是文本层与潜文本层的分工。
- 与 `mckee-dialogue-in-character` 的区别: "在角色内写作"是从内到外的生成技法（如果魔法）；本 skill 是从外到内的检查清单（词汇/修饰语是否专属），两者常配合使用。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **为每个角色建语言指纹卡**
   - 完成标准: 对每个主要角色列出三栏——①知识库（职业/教育/社会圈层决定的名词动词，各≥5个典型词）②修饰偏好（形容词/副词/情态动词倾向，如"必得"vs"可以"、主动vs被动）③禁忌词（角色绝不会用的词）。
   - 判停条件: 若场景只有群演/一次性角色，仅需为主角建卡，跳到步骤2。

2. **用提问法逐句重写中性台词**
   - 完成标准: 挑出场景中"删掉名字可套给任何角色"的句子，逐一问"这个角色在此刻会怎么说"，按指纹卡改写；改后每句能指认唯一说话者。
   - 判停条件: 若整段台词改不动、总想用同样的话，说明角色本身没被想清楚，回到 A1 案例的"先问角色会怎么喊"，而非硬挤字眼。

3. **声音自检：去雕琢、查越界、核文化配比**
   - 完成标准: ①去掉为不同而不同的雕琢（风格需能回溯到知识或个性，否则删）；②无角色说出超出其知识范围的词；③高/低语境圈层判断明确，文本/潜文本配比与角色共享背景相符；④朗读一遍，听不出作者腔调。
   - 判停条件: 若"独特"全靠堆砌形容词而非词汇差异，判定为伪个性化，回到步骤1补知识库。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 非写实主义（神话/科幻/歌舞/动画/闹剧）：允许甚至鼓励把话说在明面上，可减少或省略潜文本，个性化要求可放宽。
- 用户要的是"台词设计"（悬疑/累积/平衡句法）或"解说投放"——那是 `mckee-dialogue-exposition` 的领域。
- 单句润色/语法修正类请求，不涉及多角色区分时，本 skill 过重。
- 舞台剧外的纯作者性叙事（如第一人称散文），角色声音与作者声音本就重叠，需先界定谁在说话。

### 作者在书中警告的失败模式

- 角色中立语言（ce15）：所有角色受惊都喊"噢，天哪！"，用普遍性取代特殊性——"这种现成的句子限制了演员发挥，剥夺了他们定义角色个性的机会"。
- 雕琢的语言（ce16）："语句常不必要地富表达性，脱离角色，好像为写作而写作"——观众察觉艺术本身即出戏，信任纽带断裂。
- 干巴巴的语言（ce17）："他的渲染是事实的虚假化"式的多音节大词与迂回句——抽象名词与被动语态拖慢冲突节奏。
- 角色认知越界（ce10）：角色说出超出自身认知的知识，"观众会觉得作者是拧着角色的耳朵在耳语"。
- 过度感知（ce11）：角色用比弗洛伊德还深刻的观点形容自己，读者不信且迁怒作者。

### 作者的盲点 / 时代局限

- 全书以欧美（尤其英语/英语剧作）语言为样本：词汇、音节长短、句法规律完全基于英语双语历史，对中文等非拉丁语系写作无法直接迁移，词长/语态层面的规则需大量转译。
- 高语境/低语境文化论以特定民族志与西方戏剧史为样本，跨文化泛化需谨慎；对中文语境（更倾向高语境）的适配要自行校准。
- "声音是结果而非选择"依赖"对白的耳朵"式的品位判断，无法程序化，本 skill 只能提供可检查的词汇/修饰语清单，终极判断仍需人脑。

### 容易混淆的邻近方法论

- 与《故事》的"角色塑造"不同：那是角色表面的行为特质总和；本 skill 是"用语言指纹落实角色塑造"。
- 与"为不同而不同"的风格炫技不同：声音是结果，不是选择——刻意造怪不是本 skill 的产物。
- 与方言/口音的表演层不同：本 skill 管文字层的词汇与修饰语，口音是演员的辅助语言层。
