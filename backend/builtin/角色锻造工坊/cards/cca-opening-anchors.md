## I — 方法论骨架 (Interpretation)

开场是弧光的第一个锚点，作者要求用两个结构件把它焊死：

1. **Characteristic Moment（特征时刻）**：主角第一次出场的场景，不是"随便露个面"，而是一次完成 11 项任务的清单——姓名/身份/人口学特征/外形/故事角色、展示主导性格、钩住读者同情与兴趣、给出场景目标与故事目标、演示或暗示 Lie、并直接推动（或至少预示）情节。作者断言：开场失败 = 故事失败。
2. **先立认同，再示缺陷**（引 Michael Hauge）：如果主角有会降低同情心的缺陷（自私、懦弱、撒谎），不要在出场戏直接砸给读者。先让读者喜欢/好奇他——展示可爱、有趣、英勇的侧面——再逐步揭示缺陷，否则读者在角色开口前就想合上书。优先任务是"让读者投资于角色"。
3. **Normal World（正常世界）**：开场环境不是普通背景，而是 **Lie 的象征性舞台**——它必须戏剧化地演出"角色被 Lie 舒服囚禁"的 before 状态，让 Lie 活得最舒适、没有理由改变。它同时是后续一切变化的对照基准：First Plot Point 掀翻它，结局 Resolution 的"新常态"再与它镜像呼应，弧的存在感由此被"演出"。

三者合起来是**开场双锚**：一场高密度的出场戏（让读者认识并投资角色）+ 一个符号化的开场世界（让读者看见他被 Lie 囚禁的样子）。先有地基（Lie 已知），双锚才能落位。

## A1 — 书中的应用 (Past Application)

### 案例 1: Cars — Lightning McQueen 的 Characteristic Moment
- **问题**: 主角首次出场要同时完成十几项任务，如何写得高密度又不显生硬。
- **方法论的使用**: 开场长段赛车戏一次完成——展示优点（顶尖车技）、埋下 Lie（"人生是一场独角戏"，他炒掉三名维修主管因为喜欢单干）、给出 Want（Piston Cup）、确立主导性格与故事角色。
- **结论**: 一个场景就能让读者从第一分钟掌握角色的全部关键信息并产生兴趣。
- **结果**: Lie 贯穿全片；Radiator Springs 的新世界持续"惩罚"他按 Lie 行事，直到他学会让别人进入他的生活。

### 案例 2: 《饥饿游戏》— Katniss 的 Normal World
- **问题**: 如何让开场世界不只是交代设定，而成为弧光的对照基准。
- **方法论的使用**: 她的 Normal World 是灰暗压抑的第十二区——在随时被政府压制的恐惧中挣扎养活母亲与妹妹；这个极权世界正是"社会靠恐惧统治"之 Lie 最舒适、最可怖的温床，同时她的 Characteristic Moment（替妹妹参加抽签）展示了她为爱牺牲的侧面。
- **结论**: Normal World 必须戏剧化角色的"之前"状态，并为世界之变提供基准。
- **结果**: 进入竞技场后，世界的 Lie 与她的 Truth 形成最强反差；结尾的"新常态"与开场对照，弧由此被看见。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **故事开头写不动**: 第一场戏主角出场很平淡、没有记忆点。
2. **读者反馈差**: "开头读不下去""主角不讨喜""不知道这主角是谁、想干嘛"。
3. **开场世界设计**: 要设计"正常世界"，让它为后面的角色变化做铺垫，而不是干巴巴交代地理时代。
4. **多稿返工**: 开头只有情节动作，没有让人投资角色的东西。
5. **英文场景**: 用英文设计 opening scene / character introduction 时同样适用。

### 语言信号 (用户的话里出现这些就应激活)

- "开场 / 第一场戏 / 主角出场怎么写" → "opening scene / character introduction / first impression"
- "主角不讨喜 / 读者不喜欢他" → "unsympathetic protagonist / make the reader like him"
- "开场世界 / 正常世界怎么设计" → "normal world / ordinary world / opening setting"
- "怎么让第一场戏就有钩子" → "hook readers / strong opening / first page"

### 与相邻 skill 的区分（初稿）

- 与 `cca-arc-foundation`: 开场 skill 管"怎么把角色演出来"（出场与舞台），地基 skill 管"角色的病根是什么"（Lie/Ghost 诊断）。开场里要暗示的 Lie，以地基诊断为输入；没有 Lie 就无从暗示。
- 与 `cca-positive-arc`: 开场 skill 只覆盖第一幕前半（Characteristic Moment + Normal World）；First Plot Point 之后的逐拍打点（Midpoint/TPP/Climax）属于正弧 skill。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **写/改 Characteristic Moment**
   - 对照 11 项清单逐项检查主角出场戏，优先保证三项核心：勾住读者 + 暗示/演示 Lie + 推动（或预示）情节。
   - 完成标准: 能用清单说明第一场戏完成了哪几项，且至少覆盖"主导性格 / Lie 暗示 / 场景+故事目标"三项核心；能用一句话说出"读者第一分钟会记住这个主角的什么"。
   - 判停条件: 若主角有会降低同情心的缺陷，先进入步骤 2 的"先认同"设计，再回来补这步。

2. **排"先立认同、再示缺陷"顺序**
   - 为出场戏安排至少一个让读者喜欢/好奇主角的具体节拍（可爱、有趣、英勇、困境中的善意），把重大缺陷的揭示推迟到这个节拍之后。
   - 完成标准: 能指出出场戏里"读者为何愿意继续读他"的那个具体时刻；确认第一印象不是负面轰炸。

3. **设计 Normal World 为 Lie 的象征性舞台**
   - 回答："什么样的世界最符合角色相信 Lie 的逻辑成因？这个世界如何喂养 Lie、让它活得最舒服？"
   - 检查它 vs 冒险世界（adventure world）的反差，以及它如何被 First Plot Point 掀翻、如何与结局新常态镜像对照。
   - 完成标准: 能用一句话说清"开场世界如何戏剧化 Lie"，并同时指出"这个世界的哪个设定将在结尾被翻转回来"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **无单一主角的开场**: 群像/多视角叙事没有"主角的第一次出场"，11 项清单无从逐人硬套。
- **强情节先行的开场**: 悬疑/动作若选择先抛事件而非先投资角色，Characteristic Moment 的职责被推迟——本 skill 的清单不必立即满足。
- **无弧光的 situation 故事**: 没有 Lie 可暗示，Normal World 的"Lie 舞台"概念失去对象。

### 作者在书中警告的失败模式

- **一上来就砸缺陷**: 主角的缺点在建立认同之前密集轰炸读者，读者在角色开口前就想合上书（ce04）。
- **Characteristic Moment 随意**: 开场后读者说不出主角是谁、想要什么、有什么毛病——"开场失败 = 故事失败"（ce05）。
- **用成段 telling 介绍人物**: 像《圣诞颂歌》开场那样旁白式宣告主角的吝啬（作者明确标注 not recommended），剥夺读者的发现感；应改用行动戏剧化（ce06）。
- **Normal World 不展示 before 状态**: 开场只交代地理/时代，没演出"角色被 Lie 囚禁"的样子，整条弧失去对照基准与力度（ce08）。

### 作者的盲点 / 时代局限

- **"读者必须喜欢主角"是商业叙事的偏好**: 对反英雄/道德暧昧主角（如《香水》《发条橙》），"先讨喜"并不普适；"第一印象决定去留"的假设跨文化成立与否未被证实。
- **11 项清单密度过高**: 机械照搬会窒息轻盈、氛围化的文学性开场；作者自己也承认可用一两场戏分担任务。
- **案例全是好莱坞电影与英美经典**: 类型依赖明显，对类型小说/纯文学的开场习惯覆盖有限。

### 容易混淆的邻近方法论

- **"第一章就爆炸"的强情节钩子**: 那解决的是"悬念钩子"，不是"让读者投资于角色"；Characteristic Moment 的钩子只是 11 项之一，而非全部。
- **一般的世界观设定铺垫**: Normal World 必须符号化角色的内心（Lie 的温床），不是地理/时代介绍。
- **正弧三幕打点**: 开场双锚止步于 First Plot Point 之前；之后的一切属于 cca-positive-arc。
