## I — 方法论骨架 (Interpretation)

人物不是"想动就动"的，他的行动有一套三级引擎：

1. **激励事件**：某个外部或内部事件打破人物生活的平衡，令其倾向正极或坠入负极。
2. **超级目标**：生活乱套后，潜意识中的"求稳欲"被激活进入显意识，成为人物的超级目标——一种笼统的、想要恢复平衡的渴望。
3. **欲望目标**：超级目标凝聚成具体的、显意识的所求——人物相信达成它就能恢复平衡（杀掉鲨鱼、娶到朱丽叶、赚到钱）。

同一链条上还有两个容易混淆的驱动源：**动机**植根于人物的过去、从后推进（童年缺失、长期匮乏），**欲望**锚定未来、向前拉（具体目标）。动机本身没有焦点，直到激励事件把它聚焦成具体的欲望目标。因此诊断"角色为什么行动"时，先问是什么事件打破了平衡、激活了什么求稳欲、又凝聚成了什么具体目标。

复杂人物的关键在于**显意识欲望与潜意识欲望必须构成直接矛盾**：人物嘴上要 X（显意识），暗地里却要非 X（潜意识），后者作为"反对欲望"阻碍、颠覆前者的意志（饿了就开冰箱式的同一欲望毫无深度）。最后，一切动作都要有欲望支撑——没有欲望的行动只是消磨时间的"活动"，改变不了任何价值。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《绝命毒师》沃尔特·怀特——欲望引擎撑起 62 集
- **问题**: 一个高中化学老师如何变成支撑 62 集长剧的复杂主人公？他的行动引擎从哪来？
- **方法论的使用**: 麦基把沃尔特的首要维度定为"沃尔特 vs 海森伯格"（他以为自己是谁 vs 他到底是谁）。用链条拆解：激励事件=癌症诊断（必死）打破生活平衡，激活潜意识超级目标（对掌控、尊严、不朽的求稳欲），凝聚为显意识欲望目标=制毒赚钱留给家人。显意识欲望是"救家人"，潜意识欲望却是"成为海森伯格、获得力量与自我实现"——二者直接矛盾，互为反对欲望。
- **结论**: 激励事件必须切合主人公的需求并催生独特的欲望目标；显意识与潜意识欲望的反差越大，人物越复杂、越有戏。
- **结果**: 沃尔特的每一步行动都由欲望驱动而非纯粹"活动"，16 个维度从这条动机主轴辐射出来，支撑起 62 集 80+ 角色的卡司规模。

### 案例 2: 《克莱默夫妇》特德——潜意识需求被事件激活
- **问题**: 一个自我沉迷的工作狂，他的"反差欲望"从哪来？
- **方法论的使用**: 麦基指出，激励事件（妻子抛夫弃子）在特德内心深处激发出一种此前一直压抑、从未表现的需求——做一个富有爱心、受人尊敬的好人的潜意识渴慕。这与他的显意识行为（只顾工作、把孩子当负担）构成直接矛盾。
- **结论**: 潜意识需求由激励事件激活，并与显意识意志构成矛盾；深层冲突在压力选择中自我揭示。
- **结果**: 高潮处特德把自身需求完全让位给儿子的需求，自爱 vs 他爱的冲突在故事事件中得到解决——欲望的对照直接定义了弧光。

### 案例 3: 埃古与萨列里——动机清单的装配示范
- **问题**: "贪欲"这类内在动机如何一步步变成行动？
- **方法论的使用**: 麦基拆解第八号内在动机"贪欲"的三步进程：贪心（对更多的渴求）→ 羡慕（你有时我没有的折磨，欲求被颠覆为摧毁欲）→ 嫉妒（有对手入场时升级为狂热）。萨列里质问"为什么是莫扎特？为什么不是我？"并毁掉对手。
- **结论**: 动机是过去植根的下意识欲求（从后推），当欲求之物不可企及时，获取欲会被颠覆为摧毁欲；十二种内在动机（不朽/生存/平衡/快乐/性/权力/移情/贪欲/兴趣/意义/实现/超越）可作为人物欲望装配的选料清单。
- **结果**: 动机清单让"反派为什么坏"从抽象变成可装配的具体欲求——给人物选定动机后，再用激励事件把它聚焦为欲望目标。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 角色"没目标""不知道他想要什么"，行动缺乏指向。
2. 设计了激励事件，但不知道它应该激活人物什么样的欲望。
3. 场景里人物做了很多事却"不推动剧情"——可能只是活动而非行动。
4. 想写"表里不一"的人物：显意识一个欲望、潜意识反着来。
5. 写前传/长篇，需要为角色动机做长线铺陈与底层装配。

### 语言信号 (用户的话里出现这些就应激活)

- "这个角色到底想要什么 / 他没有目标 / 动机不明" / "what does my character want", "no goal", "unmotivated"
- "怎么设计激励事件 / 事件之后他要追求什么" / "inciting incident", "what should he pursue after"
- "行动在原地打转 / 不推动剧情 / 活动 vs 行动" / "nothing drives the story", "activity not action"
- "潜意识 / 表里不一 / 嘴上说不要身体很诚实" / "subconscious", "hidden desire", "secret want"
- "动机和欲望有什么区别" / "motivation vs desire", "why does he do it"

### 与相邻 skill 的区分

- 与 `mckee-character-dilemma` 的区别: 欲望引擎回答"人物为什么动、想要什么"（目标装配）；两难设计器回答"关键时刻怎么选才揭底"（选择设计）。欲望目标清晰了，才能构造出有分量的两难。
- 与 `mckee-character-arc` 的区别: desire 管"人物要什么"（激励事件后的目标设定）；arc 管"人物变了什么"（跨故事的变化轨迹）。欲望是起点，弧光是展开。
- 与 `mckee-character-essence` 的区别: essence 管"人物是什么"（艺术品定位/矛盾之眼）；desire 管"人物要什么"（行动引擎）。前者定义对象，后者驱动对象。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定义激励事件**
   - 完成标准: 用一句话写明激励事件如何打破主人公生活的平衡（倾向正极或坠入负极），并说明它切合主人公的什么需求。
   - 判停条件: 若写不出激励事件 → 说明故事尚未真正"开始"，先回到事件设计（激励事件本身是故事层问题），不硬造欲望。

2. **推导超级目标与欲望目标**
   - 完成标准: 写出一句欲望句："他做 X，是为了（超级目标）的（场景目标）。"并能区分动机（过去从后推：匮乏/创伤/长期欲求）与欲望（未来向前拉：具体目标）。
   - 判停条件: 若显意识欲望与潜意识欲望完全同一（饿了开冰箱型）→ 说明还没写进潜意识层，返回本步为人物补一个方向相反的潜在欲求。

3. **校准显意识 vs 潜意识矛盾，并逐场景核对欲望支撑**
   - 完成标准: 每个主要角色的欲望句成立；显意识欲望与潜意识欲望之间至少写出一处直接矛盾或鲜明对照；场景中的关键动作都能对应到欲望目标而非纯粹"活动"。
   - 判停条件: 若某角色属于纯服务型/龙套（不改变事件进程）→ 豁免本步骤，小角色不需要完整欲望引擎。

## B — 边界 (Boundary) ★

### 🔴 硬约束（世界层·违背就崩）

- 不能违背基本的欲望与动机引擎：激励逻辑，否则观众/读者会立刻出戏
### 🟡 软约束（规则层·违背有代价）

- 服务型/龙套角色：只需要完成任务，不值得装配欲望引擎。
- 类型片套路化主角：动作/爱情等类型的主角目标已被类型常规固定，直接套用即可，不必从激励事件重新推导。
- 极端人物/荒诞剧：九种删减法中去掉"目的"的人物本就没有欲望引擎。
- 纯结构/节奏分析：欲望引擎是人物侧工具，不解决章节结构或节奏问题。
### 🟢 自设约束（认知层·其实可以重定义）

- 以为欲望与动机引擎：激励只有一种正确用法——假墙，方法是工具，不是教条
- 以为欲望与动机引擎：激励能解决所有问题——假墙，每个方法都有适用场景
