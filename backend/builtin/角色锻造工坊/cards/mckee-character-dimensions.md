## I — 方法论骨架 (Interpretation)

维度是人物复杂性的最小单位——一个"活生生的、始终如一的矛盾"。对立统一（赫拉克利特："冷会热，热会凉；湿变干，干变湿"）是复杂性的构造原理：人物的统一靠矛盾，不是靠一致。

生成维度有最短路径：想一个描述性形容词 → 找它的反义词 → 矛盾对即维度雏形。唯一的极限是想象力。特性只有转化为持续冲突的矛盾才升级为维度——滑雪冒险家+妈宝男孩，每次腾跃都是一次微型自杀。

维度要过三关：始终如一（通篇救猫突然踢狗不算）、多变（在不同情境反复显现、带进展与不可预测性）、显得无解（张力不廉价和解——无神论者渴望不朽）。三缺一，维度塌陷为噱头或平面标签。

权重必须不均衡：无论多少个维度，必有一个"定义性维度"矗立于前景，一旦移除人物就消失（格林的"严肃作家/雇佣写手"、奥德修斯的"雄才大略vs冲动任性"）；其余维度可栖居任何他人。

复杂度守恒：一个人物的复杂性不能大于他面临的对抗力量。要给人物加深，先给世界加对抗——按物理→社会→个人→内在四层逐级加码。素材可从五层同心圆（现实→媒体→类型→前史/主题→创作自我）向内扫描获得，不必死守"从生活出发"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 沃尔特·怀特的十六维（《绝命毒师》）
- **问题**: 一部长剧主角的复杂度要靠什么撑起来、避免写到中间变单薄？
- **方法论的使用**: 给沃尔特配置16个维度，分两组——"人物塑造vs真实自我"（爱家男人却反社会、温和又暴烈、科学家又罪犯、道歉却无歉疚等9对）与"私密自我vs隐藏自我"（必死而敢玩命又因必死而更爱生活、理性又冲动、深爱家人却又为自恋需求把他们置于危险等7对）；首要维度是"沃尔特vs海森伯格"。16维靠62集80+角色互动才支撑得起。
- **结论**: 维度以矛盾对为最小单元、可清点可设计；复杂度上限由表演时间与卡司规模决定。
- **结果**: 沃尔特成为"撒旦英雄"而非反英雄，其自我实现得自巨大反讽——失去一切却获得人生体验的极致。

### 案例 2: 托尼·索普拉诺的十二维
- **问题**: 黑手党老大如何区别于脸谱化的暴徒、保持几十集的张力？
- **方法论的使用**: 大卫·蔡斯在86集里给托尼配置12个维度，核心轮轴是"反社会的麻木不仁 vs 负罪的自我惩罚"（麦克白式的外在残忍 vs 内在良心），其余如骄傲/羞耻、审慎/直觉（因一条鱼报梦就杀好友）、爱家庭/恨家庭等，像辐条从轮毂放射出来。
- **结论**: 维度纵横交错于所有自我层面，是人物复杂性的现代典范；维度给了他深度，而非弧光——托尼百般图谋却无法改变核心自我。
- **结果**: 托尼的维度数远超哈姆雷特，证明"可清点维度"是设计与诊断复杂人物的实用工具。

### 案例 3: 格雷厄姆·格林的九维与定义性维度
- **问题**: 九个维度如何不变成一张矛盾标签的拼贴？
- **方法论的使用**: 为格林归出9个维度（自我憎恨/自我崇拜、严于律己/自暴自弃、笃信天主教/终身寻花问柳等），再用判定法"移除哪个维度人物即消失"——答案是"严肃作家/雇佣写手"。
- **结论**: 维度权重不能均等，必须有定义性维度矗立前景；它非他莫属，其余维度可栖居任何他者。
- **结果**: 定义性维度统摄身份，使格林成为教科书级"可清点维度"样本，也示范了"维度三性"的实战检验。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户说角色扁平、脸谱化、像纸片人，想让他立体起来。
2. 用户想给角色加复杂度，但不知道具体加什么矛盾。
3. 用户想知道"角色几个维度够、维度合不合格"。
4. 用户写复杂主角时被反馈"太堆砌、显得假"，需要验证维度的合理性。
5. 用户想检验"我设计的这个矛盾（救猫/踢狗）到底算不算维度"。

### 语言信号 (用户的话里出现这些就应激活)

- "角色太扁平 / 脸谱化 / 像纸片人"
- "怎么让角色更立体 / 更复杂？"
- "给主角加几个维度或矛盾吧"
- "这个矛盾算不算维度？合不合格？"
- "flat character / one-dimensional"
- "make the character more complex / three-dimensional"
- "give the protagonist dimensions / contradictions"

### 与相邻 skill 的区分

- 与 `mckee-cast-design` 的区别: 维度管"单个角色内部有多少矛盾、怎么造、怎么过三性检验"；卡司管"这些维度在圈层里怎么分配、角色之间怎么对位"。用户谈配角戏份/功能分配 → 应激活卡司 skill。
- 与 `mckee-character-essence` 的区别: 维度是把"矛盾之眼"工程化的具体工具；essence 管"人物≠人"的世界观与"情节即人物"的同一性。用户嫌角色"太像真人、不够戏剧" → 应激活 essence。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **头脑风暴维度对**
   - 完成标准: 对目标角色列出至少 5 对"形容词→反义词"候选维度（如独立/依赖、理性/冲动），每对都必须是两极性张力而非单纯的负面标签（"懒惰"不算，要"懒惰/专注时连命都不要"才算）。

2. **三性检验 + 定义性维度**
   - 完成标准: 逐对过三关——始终如一？多变？显得无解？对通过的维度各写一句"他在什么压力选择下会显出这一面"的具体场景；再问"移除哪个维度人物即消失"，选出唯一一个定义性维度。
   - 判停条件: 若用户的实际诉求是"谁该给多少戏份" → 跳到 `mckee-cast-design`；若用户的病症是"角色像真人一样平淡" → 跳到 `mckee-character-essence`。

3. **对抗力量配对**
   - 完成标准: 盘点角色面临的物理/社会/个人/内在四层对抗，核对"维度数量 ≤ 对抗力量层级"；若维度多于对抗，删减维度或给世界加对抗。最终每个维度都能在至少一个已规划场景中被激活，否则该维度是装饰。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只想加一次孤立的善举/矛盾点缀（救一次猫、突然踢狗）——那不是维度，是廉价同情；本 skill 不会为一次性反差背书。
- 用户写的是极端人物（通过删减法造出的荒诞、邪恶或虚无人物）——他们走"减法"路线，不需要"维度三性"这套现实主义复杂度规则。
- 用户写短篇/小品，卡司里的小角色只需单一特性——《血童》范式下只有两个复杂人物，其余成员一个特性即可。

### 作者在书中警告的失败模式

- 廉价同情不构成维度: "如果一个男人曾有一次从树上救下小猫的经历，这并不能构成一个维度，这只不过是为了博得读者/观众的廉价同情的无偿善意而已"（ce14）。
- 维度均等、无定义性维度: 维度齐平=矛盾标签拼贴，人物没有核心；必须有一个"一移除人物就消失"的定义性维度（ce15）。
- 显意识=潜意识欲望: 潜意识与显意识同一是纯冗余装置，零复杂度（ce16）。
- 一般化人物=卡通: 越可预测、越言行一致、越易理解，越像纸板人（ce01）。

### 作者的盲点 / 时代局限

- 矛盾论可能过度简化: 把全部人性复杂性还原为"两两矛盾的维度对"，非矛盾式复杂性（身体性、文化规训、环境塑造、沉默与不确定性）在框架中无处安放；"维度必须显得无解"的强制要求也会排斥大量真实可行的写法。这是便于教学的启发式模型，却被表述为"人性真相"。
- 数字与量化建议缺乏实证: 特性密度、维度数量等数字化建议属审美独断，无实证支撑。
- 样本的欧美中心主义: 维度个案（格林、奥德修斯、沃尔特、托尼）全部来自西方经典/好莱坞，非西方人物设计的可迁移性未经检验。
- 与《故事》《对白》重复: 对抗力量、复杂人物等概念基本是旧作《故事》的再表述。

### 容易混淆的邻近方法论

- "立体/丰满"的模糊直觉 vs 可清点、可检验的维度对——后者有明确的三性验收标准。
- 维度（矛盾对）vs 特性（形容词）——特性只有转化为持续冲突的矛盾才升级为维度。
- 维度 vs 弧光——维度是静态结构，弧光是沿定义性维度的动态变化（那是 `mckee-character-arc` 的内容，不在本 skill 射程内）。
