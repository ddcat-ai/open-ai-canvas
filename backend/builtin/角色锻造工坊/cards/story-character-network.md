## I — 方法论骨架 (Interpretation)

- 角色不是孤立个体，而是构成一张互相界定的网络；每个角色都有助于定义其他角色，主角由"他不是什么样的人"来界定。
- 角色之间的联结有四种方式：故事功能（主角/对手/盟友/镜子/诱惑者）、原型与影子（国王/武士/魔法师/骗术师等及其负面倾向）、主题（共同作答同一道德难题）、对立关系（价值取向的差异）。
- 四角对立把"主角—反派"的二元对立升级为"主角 + 主要对手 + 至少两个次要对手"的结构：四个角色各占一个价值取向角落，每个对手以不同方式攻击主角的同一重大弱点，从而倍增冲突数量并制造价值观冲突。
- 每个配角都应是主角核心道德难题的一种变奏——他怎样处理这个难题，就怎样定义了主角的立场。
- 观众认同来自"看到主角的动机"（同理心），而非"喜欢他的为人"（同情心）；当主角做不道德的事时，靠持续呈现原因维持认同。
- 真正的角色转变不是变富、变国王，而是基本信念受到挑战并被改变，继而采取新的道德行动。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《教父》——家庭与世界双层的四角对立
- **问题**: 一部黑帮史诗如何避免"孤胆英雄 vs 独个恶人"的单薄，在不同层面都制造价值观冲突？
- **方法论的使用**: 特鲁比把四角模式延伸到故事的每个层次：家庭层面（教父+汤姆=国王、桑尼=武士、弗雷多与凯伊=爱人、麦克=骗术师→武士→国王）和整个黑手党世界层面（柯里昂家族=国王-武士、索罗佐=武士、巴兹尼=国王、卡罗+特西欧=骗术师）各建一套四角对立；每个对手用不同方法攻击麦克"年轻、青涩、过度自信"的弱点。
- **结论**: 同一故事在两个层次产生相互嵌套的价值观冲突网络，冲突数量倍增却保持有机整体感。
- **结果**: 成为"偏史诗风格故事在两个不同层次使用四角对立"的范例。

### 案例 2: 《窈窕淑男》——每个角色都是道德难题的变奏
- **问题**: 高概念"男扮女装"天然只有两三个身份转换的搞笑场景，如何撑起整部电影？
- **方法论的使用**: 作者先让麦克面对一个核心道德难题——"男性应该如何对待女性"，再创造出好几个对手，每一位都代表这个难题的一个变奏：罗恩的撒谎辩白、茱莉的容忍摆布、约翰的好色、珊蒂的自我贬抑、雷斯的尊重、制片丽塔的隐藏自我。
- **结论**: 配角不是笑点工具，而是同一道德难题的不同答案；由此织出严密角色网络，克服高概念前提的结构弱点。
- **结果**: 被特鲁比称为"示范这个技巧的绝佳故事"，并指出大多数身份转换喜剧因不懂此技巧而"以惨败收场"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 配角写出来像工具人——只在主角需要时出现帮忙或捣乱，删除某个配角后主角形象毫无变化。
2. 故事只有主角和反派两个人正邪对立，冲突单薄、无法呈现道德复杂性。
3. 用户习惯先列主角的特征清单，再"逐项加料"让他有血有肉，但主角仍软弱无力。
4. 有群像倾向的故事，配角彼此没有关系，各演各的。

### 语言信号 (用户的话里出现这些就应激活)

- "我的配角都是工具人 / 太单薄 / 没存在感" — "supporting characters are cardboard / flat"
- "主角和他身边的人没什么关系 / 他到底是个什么样的人" — "who is this character / what makes him distinct"
- "正邪对立太简单、太二元了" — "too black and white / simple good vs evil"
- "四角对立 / 对立网络 / 镜像角色" — "4-corner opposition / foil / double"

### 与相邻 skill 的区分

- 与 `story-antagonist-design` 的区别: 后者聚焦单个对手的深塑（七要素：目标/动机/道德论点/计划/弱点），本 skill 聚焦全体角色的横向网络（每个配角如何共同界定主角）。只谈"把反派写强"→ 用对手 skill；谈"配角群互相定义"→ 用本 skill。
- 与 `story-seven-key-steps` 的区别: 后者是单主角的纵向结构弧（弱点→欲望→对手→对决→揭露），本 skill 是多角色的横向比较网。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出全部角色，分配功能标签与原型（含影子）**
   - 完成标准: 每个主要角色都获得至少一个故事功能（主角/对手/盟友/镜子/诱惑者/假盟友）与一个原型（国王/武士/魔法师/骗术师/爱人/叛逆者等），并写下该原型的"影子"（负面倾向）；若某角色无法获得任何功能标签，标记"可删除"并说明理由。
   - 判停条件: 若故事只有单一主角、无配角群（独角戏/内心独白体），本 skill 不适用，跳到 B 段反场景说明。

2. **确立核心道德难题，让每个角色作答**
   - 完成标准: 写出一句核心道德难题（例如"男性应如何对待女性"），并列出每个角色的答案、弱点/需求/价值取向；每个配角的回答必须与主角不同——他就是主角的一种"变奏"。写不出差异的角色回到步骤 1 重新分配功能。

3. **搭建四角对立**
   - 完成标准: 画一张四角图：主角 + 主要对手 + 至少两个次要对手，尽量把每个角色推向"角落"（与其他三者差异最大化）；写明四人的整组价值取向，并确认每个对手以不同方式攻击主角的同一个重大弱点。

4. **用"他不是什么样的人"反向检查主角**
   - 完成标准: 能写出至少 3 句"主角不是 X（某配角）那样的……"来完成界定，且每句都让主角的定位更清晰；反向检查失败则回到步骤 2 重新比较。
   - 判停条件: 若完成网络后主角形象反而模糊，说明配角与主角的差异未拉开，停止并重做步骤 2-3。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 独角戏/独白流叙事：没有配角群可以联网，网络概念落空。
- 刻意反主角中心的群像纪实或散点叙事：没有"主角的核心道德难题"作为变奏的中轴，四角对立与"不是什么样的人"无法建立。
- 只需脸谱化配角的轻喜剧或功能型剧情（如纯信息传递场景），强行联网反而拖累节奏。

### 作者在书中警告的失败模式

- ce07 "把主角设想为与其他角色互不相关的个体"——配角纸板化、主角软弱，作者靠不断加特征补救。
- ce08 "电灯开关学派"——转变不在网络与冲突中发展，只在结尾"啪"地一下按开关，突兀不可信。
- ce17 "只使用善与恶的二元对立"——没有道德对立网络，道德论点过于简单，失去现实生活的复杂性。

### 作者的盲点 / 时代局限

- 整套角色网络以"单主角中心 + 配角为其变奏"的好莱坞个人主义情节剧为前提；对契诃夫、侯孝贤式群像本位、非个人主义叙事（BOOK_OVERVIEW 批判 #1/#8）几乎没有方法论供应——这类作品里"每个角色都是主角道德难题的变奏"根本不成立。

### 容易混淆的邻近方法论

- 与"原型类型学"（f16）的混淆: 原型只是网络的"快速建差异"工具，网络的关键是角色之间的比较与对立关系，不是贴原型标签本身。
- 与"核心道德难题变奏法"（f17）的混淆: 后者侧重"主题如何借角色网络传达"，本 skill 侧重"角色如何借网络被塑造"；两者互补但起点不同。
