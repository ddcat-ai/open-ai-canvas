## I — 方法论骨架 (Interpretation)

把"人物"当成一件艺术品来对待，而不是把"像真人"当作目标。真人未完成、不透明、有潜文本、随生活流动；人物已完成、可全知、表达一切、被框定于故事边界内——真人只是原料，人物是用洞察重新锻造成型、比真人更清晰也更复杂的作品。

用"矛盾之眼"来观察和构造人物：把一切人物问题还原为二元对立（人物vs人、人物塑造vs真相、外在vs内在、显意识vs潜意识），再在两极之间的光谱上把玩渐变。复杂不再是模糊的感受，而是可操作的张力。

情节即人物，人物即情节——二者是同一枚故事硬币的正反两面。质问"情节驱动还是人物驱动哪个更高"是范畴错误，实为趣味与阶级的文化政治。改事件就是在改人物，改人物就是在改事件。

人物塑造（一切可见外表的集合）只锚定可信性；人物真相（不可见的内在本质）只能在压力之下的选择中自我揭示。一个故事事件 = 人物生活中一次价值负荷的瞬间变号；没有变号的场景只是"活动"，不是"行动"。

最后，作者需要三把钥匙（道德想象、逻辑暗示、自知之明）去回答"人物为何这么做"——你无法理解的东西，就写不出真实的矛盾。

## A1 — 书中的应用 (Past Application)

### 案例 1: 沃尔特·怀特（《绝命毒师》）
- **问题**: 麦基要向读者论证"人物比真人更可知、更清晰"，需要找一个人物作为反证。
- **方法论的使用**: 麦基自述"我常常希望我能够像我了解沃尔特·怀特和《绝命毒师》那样了解我自己和美国"。沃尔特·海森伯格的二重身份本身就是"矛盾之眼"的产物——人物塑造是温和的高中化学老师，人物真相是冷血的制毒师海森伯格，两条人格在高压选择中不断拉扯。
- **结论**: 人物是可被全知、表达一切的艺术品；把真人照抄进来只能得到一张快照，把矛盾焊接起来才能得到沃尔特。
- **结果**: 沃尔特成为麦基全书最常引用的样本，62集80+角色才撑起其复杂性，证明"表演中作品"比任何"发展中作品"更有生命力。

### 案例 2: 伊丽莎白·班纳特（《傲慢与偏见》）
- **问题**: 奥斯汀如何让一个乡绅女儿"超越真人"、成为可全知的复杂人物？
- **方法论的使用**: 奥斯汀给伊丽莎白配了四对矛盾——理性/冲动、社交魅力/私密信念、自尊/谦恭、独立/浪漫渴望。四个扁平、表里如一的姐妹（简的纯真、玛丽的迂腐、莉迪亚的轻佻、凯蒂的依赖）各自反照她的一对维度，卡司成员互相描画彼此的特性和真相。
- **结论**: 人物不是"像人"而是"矛盾集合体"；她的复杂度靠与其他角色的对位而被看见。
- **结果**: 四维的伊丽莎白牢牢固着于故事中心，成为麦基卡司示意图的圆心样本——一个"被完全理解"的艺术品。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 角色写得太"真人"——平淡、可预测、像路人，用户说"他就像我认识的某某"。
2. 用户在争论/纠结"这个作品是人物驱动还是情节驱动"、"哪个更重要、更高级"。
3. 用户想把自己的朋友、家人或亲身经历原样搬进故事，觉得"真实经历=好人物"。
4. 用户的场景被反馈"没意思/没意义"，但说不清问题出在哪。
5. 用户困惑"人物塑造、人物真相、性格到底有什么区别"。

### 语言信号 (用户的话里出现这些就应激活)

- "我的角色太像真人了 / 太普通了 / 没有亮点"
- "情节驱动还是人物驱动？哪个更好？"
- "我把我同学/老板写进去了"
- "这个场景有意义吗？为什么那么平淡？"
- "my character feels too real / flat / like a bystander"
- "plot-driven vs character-driven, which is better?"
- "I just copied a real person into my story"

### 与相邻 skill 的区分

- 与 `mckee-cast-design` 的区别: 本 skill 管"单个人物是什么"（艺术品定位、矛盾之眼、情节即人物）；卡司 skill 管"一整套人物怎么配"（太阳系三圈、支持型vs服务型、戏份权重）。用户谈配角分配/戏份/功能重叠 → 应激活卡司 skill。
- 与 `mckee-character-dimensions` 的区别: 本 skill 是元概念与方法论；维度 skill 是具体构造器（形容词→反义词→维度三性检验）。用户要"给角色加矛盾、验复杂度" → 应激活维度 skill。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **做"人物vs人"体检**
   - 完成标准: 能分别写出一条"人物塑造清单"（该角色一切可见外部特性）与一条"人物真相"（压力之下他到底是谁），且二者明显不同；如果二者相同，就标记该角色为"一维"。

2. **用矛盾之眼拆解**
   - 完成标准: 列出该角色至少 3 对二元矛盾（外在/内在、显意识/潜意识、人物塑造/真相……），并为每对写出一句张力句——"在某个高压选择里，他会倾向哪一边，代价是什么"。从这些对子里圈出最核心的一对。
   - 判停条件: 若用户的实际诉求是"配角们怎么分配戏份" → 跳到 `mckee-cast-design`；若用户只想要更多矛盾维度清单 → 跳到 `mckee-character-dimensions`。

3. **情节即人物落盘 + 价值负荷检查**
   - 完成标准: 把所有场景转折点改写成"我的人物身上将会发生什么、他如何反应、为何偏偏是他"，且每个场景都能指出哪一个价值负荷（生/死、爱/恨、正义/非正义……）变了号。若某场景找不到变号，标记为"活动"并建议重写。
   - 判停条件: 若用户卡住的是整体卡司结构而非单个场景的因果 → 跳到 `mckee-cast-design`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户坚持纪实/回忆录必须"忠实于真人、不能戏剧化"——本 skill 要求穿透浅表重新想象，与"照录事实"的目标冲突。
- 用户只问"谁当主角"或"配角怎么分配戏份"——那是卡司问题，不在本 skill 射程内。
- 用户要的只是一份"人物矛盾模板直接填空"——那是维度设计器的活；且麦基自己警告，把案例固化为填空模板会立刻变成陈词滥调。

### 作者在书中警告的失败模式

- 一般化人物=卡通: "人物越一般化、越言行一致、越可预测、越易理解，则越不真实、越无趣、越卡通"（ce01）——把"真实"误解为"平凡可预测"是头号死法。
- 情节驱动/人物驱动伪辩论: 争论本身是范畴错误，实际掩盖的是趣味、阶级与金钱的文化政治（ce02）。
- 莫问"将会发生什么": 开放结局式提问脱离人物，事件失去因果与情感重量（ce03）。
- "人物拒绝按意图行事"=文学自恋: 作者永远是选择与行动的唯一源泉，别把写不下去推给人物（ce04）。
- 把真人直接搬进作品: "像一张快照那样肤浅"，只有表皮、没有可全知的内在（ce07）。

### 作者的盲点 / 时代局限

- 样本的欧美中心主义: 全书上千案例几乎全来自英美文学/好莱坞/英美戏剧，非西方叙事传统近乎缺席，"人性普遍"的主张建立在未经检验的单一文化样本上。
- 矛盾论可能过度简化: 把全部复杂性还原为"两两矛盾的维度对"，非矛盾式复杂性（身体性、文化规训、环境塑造、沉默与不确定性）在框架中无处安放——这是一套便于教学的启发式模型，却被表述为"人性真相"。
- "表达一切/完成人物"抹杀留白: 麦基一边赞美不可知传统（品钦、贝克特），一边把"完全揭示"立为最高目标，未真正调和；大量杰作恰恰靠人物的不可穷尽性存续。
- 与《故事》《对白》重复: 价值负荷、激励事件、对抗力量等核心概念基本是《故事》的搬用，本书真正的增量有限。

### 容易混淆的邻近方法论

- "像真人"的赞美式直觉 vs 麦基"人物必须超越真人"——两者方向相反，别把"真实感"写成"平庸感"。
- "性格描写"（堆形容词）vs "人物真相"（压力下的选择揭示）——前者只是面具，后者才是内核。
