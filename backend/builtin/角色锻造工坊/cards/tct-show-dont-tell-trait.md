## I — 方法论骨架 (Interpretation)

1. **Tell 制造距离，Show 建立 bond**：「他是乐观的」是 tell；「她总先看光明面」是 show。读者要自己得出结论才会投入。
2. **五载体揭示特质**：
   - **Actions & Quirks**：行为与小怪癖（Jack Sparrow 的眼线/醉步/手势 = flamboyant）。
   - **Relationships**：通过人际互动与配角反衬（Odd Couple 让特质自动响亮）。
   - **Thoughts**：内心独白暴露表里不一（表面顺从内心叛逆）。
   - **Crises & Choices**：压力下的选择揭示真实本性（麦基「压力揭示」同构）。
   - **Sensitivities**：被戳中的软肋暴露伪装下的真相（Joe 被质疑智商即退缩）。
3. **Flaws as Obstacles**：缺陷应反复阻挡目标，每次失败唤起旧创伤、渴望递增——show 缺陷即 show 张力。
4. **Evolution**：展示 wins/losses 让缺陷钉在读者心里，建立共情。
5. **Avoidance**：角色刻意回避的触发物（气味/地点/人）也是 show 线索。

## A1 — 书中的应用 (Past Application)

### 案例：Macho Joe 的展示缺陷
- **操作**：不写「他很自大」，而 show——搭肩动作、swagger、物化视线、内心却焦虑智商（thought/behavior dissonance）、被 Maggie 质疑即退缩。sensitivities 暴露 machismo 是 insecure 的伪装。
- **结论**：show 让读者自己判「这人虚」，并产生「他藏什么」的追问。

### 案例：Anne Shirley / Forrest Gump
- **操作**：Anne 天然看光明面→读者自判 optimist；Forrest 对 Jenny 不离不弃→读者自判 loyal 并喜欢他。一致行为即可让读者推知特质。
- **结论**：一致性是 show 的可信底座。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 用户写出「他很勇敢/她很自私」式 tell，需要改成 show。
2. 用户要让特质「被看见」而非被说明。
3. 用户设计配角反衬或压力选择揭示。

### 语言信号
- "tell 太直白" / "怎么展示不是告知" / "show don't tell" / "用动作写性格" / "表里不一" / "软肋"

## E — 可执行步骤 (Execution)

1. **禁 tell 清单**：找出稿中「他是 X 的」式陈述，逐条转 show。
2. **选载体**：对该特质，从五载体挑 1–2 个最自然的（缺戏用 Actions，表里不一用 Thoughts）。
3. **埋软肋**：给角色一个被戳中即破防的 sensitivity，让它暴露伪装。
4. **配冲突**：用对立特质配角（见 tct-trait-conflict-cast）让特质在互动中被反衬。
5. **排演化**：在关键节点 show 缺陷的 wins/losses，让读者随锯齿共情。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- **只填单特质档案** → tct-trait-entry-blueprint。
- **只权衡度的正反** → tct-trait-dual-axis。
- **纯观念型写作** → 强 show 会失真。

### 作者警告的失败模式
- **ce07 tell 贴标签**：懒写，假定读者无能自判，制造距离。
- **只 show 不埋软肋**：角色「完美伪装」无破绽，读者看不穿。

### Tier B 版权边界
- 引用 Macho Joe 对话范例 ≤150 字/段；show 技法自由迁移。
