## I — 方法论骨架 (Interpretation)

1. 人物塑造（一切可观察素质：外貌、职业、说话方式）只是面具；人物性格真相只在压力下的选择中显现——"他选故他在"。零风险的选择证明不了任何性格。
2. 所以设计人物就是设计压力场景：结构的功能是把人逼向越来越难的选择，压力越大，揭示越深。
3. 人物弧光五步：铺陈面具 → 引入内心、用选择揭示真实本性 → 深层本性与外部面貌对照（"看似如此其实并非如此"）→ 压力与选择难度递增 → 到高潮时选择已深刻改变人性。
4. 主人公四要件：有意志力、有自觉欲望（可叠加一个矛盾的不自觉欲望）、能力令人信服、至少有一次达成欲望的机会。
5. 移情是绝对的、同情可有可无：不必把主角写成好人，但必须在深层性格上与观众接通"像我"的连接点——即便麦克白，只要给他一个良心就能移情。
6. 维 = 连贯的矛盾，不是怪癖清单；人物体系是太阳系模型：主人公是太阳，配角是行星、小角色是卫星，一切因刻画主人公而存在。
7. 主角必须是全体人物中最有维度者，否则移情焦点会偏移（善之中心危机）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 制片人心中的"三维主人公"杰西
- **问题**: 一位制片人自信地宣称发现了"三维主人公"。
- **方法论的使用**: 麦基用"维=矛盾"诊断那份特征清单——杰西出狱后是金融投资专家、会霹雳舞、空手道黑带、还能吹萨克斯。
- **结论**: 一堆技能堆在一个名字下，像电脑桌面一样平板；维是连贯的矛盾，不是怪癖，怪癖反而可能让人敬而远之。
- **结果**: 成为"维是最不被理解的概念"的经典教学案例，提醒作家用矛盾而非癖好开启性格真相。

### 案例 2: 《大审判》弗兰克·加尔文的灵魂弧光
- **问题**: 如何让一个角色在故事中真正"改变"，而不是贴标签式地"从A变B"？
- **方法论的使用**: 按弧光五步编排：先铺面具（漂亮律师），再揭示深层（酒鬼、在讣告里找生意），施压（医疗事故诉讼的两难），最终法律之战把他转变为清醒敬业的律师。
- **结论**: 最优秀的作品不仅揭示性格真相，还展现其内在本性变好或变坏的变化——弧光是压力/选择/价值变化的连锁。
- **结果**: 成为人物弧光的标准示范。

### 案例 3: 《麦克白》——恶人如何获得移情
- **问题**: 一个乘人熟睡屠杀仁慈国王的恶人，观众为什么还能投入情感？
- **方法论的使用**: 麦基指出莎士比亚给了麦克白一个良心——独白中的痛苦自责让观众听到"他像我一样有一颗良心"。
- **结论**: 移情是绝对的（"像我"），同情可有可无；即使最不可同情的人物，作者也能在他内心找到移情中心。
- **结果**: 成为"移情绝对"原则的标杆案例，证明可爱不是认同的保证。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户觉得人物扁平、像简历/技能列表，怎么堆都立不起来。
2. 用户要设计主角/反派/配角体系，想知道怎么让角色立体又前后一致。
3. 用户要写人物的成长/转变（弧光），不知道如何编排变化。
4. 用户担心主角不讨喜、观众不共情。

### 语言信号 (用户的话里出现这些就应激活)

- "人物扁平" / "没有灵魂" / "塑造人物" / "三维人物" / "人物弧光" / "成长" / "转变" / "共情" / "移情" / "主角想要什么" / "人物太完美"
- "flat character" / "character arc" / "character development" / "3D character" / "protagonist" / "empathy" / "too perfect" / "dimensional"

### 与相邻 skill 的区分

- 与 `mckee-gap-writing` 的区别: 鸿沟管场景动力（节拍怎么走）；人物设计管压力与选择的内容（人物如何被揭示）。
- 与 `mckee-antagonist-wall` 的区别: 反面之墙构建对抗力量（反派体系）；人物设计是以主角为中心的太阳系。
- 与 `mckee-scene-analysis` 的区别: 场景分析拆解已有场景；人物设计创造"谁在场景里被逼出真相"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **写下人物的塑造面具与深层性格的差距，构造 1 个"连贯矛盾"**
   - 完成标准: 矛盾可用一句话表述（如"魅力四射的小偷"、"负疚沉重的野心"），且能保证全篇前后一致。

2. **设计 2-3 个压力递增的选择场景（从低风险到两难之择），让选择揭示性格**
   - 完成标准: 每个选择都揭示出一个新的性格维度，且至少有一个是"两难之择"（两善取一或两恶取轻），不是善恶是非之间。
   - 判停条件: 若选择毫无风险、观众能提前预测答案，说明矛盾不真或压力不足——回到步骤 1 重新设计矛盾；若主角被设计成没有任何欲望，直接判定为"真正被动的主人公"失败模式并重来。

3. **用主人公四要件 + 太阳系模型检验整套人物**
   - 完成标准: 主角具备意志力、自觉欲望、至少一次达成机会；主角是全剧最多维者；配角都服务于刻画主角、小角色各给一个鲜活特征即可。

## B — 边界 (Boundary) ★

### 🔴 硬约束（世界层·违背就崩）

- 不能违背基本的人物设计：压力揭示 逻辑，否则观众/读者会立刻出戏
### 🟡 软约束（规则层·违背有代价）

- **只需要功能角色/路人** → 小角色按麦基建议轻描淡写、给一个鲜活特征即可，过度设计反而喧宾夺主。
- **非人物驱动的观念型/抽象叙事** → 强行用"压力揭示"会扭曲其美学立场。
- **纯对白润色** → 人物设计管"他是谁"，不直接管"他怎么说"。
### 🟢 自设约束（认知层·其实可以重定义）

- 以为人物设计：压力揭示 只有一种正确用法——假墙，方法是工具，不是教条
- 以为人物设计：压力揭示 能解决所有问题——假墙，每个方法都有适用场景
