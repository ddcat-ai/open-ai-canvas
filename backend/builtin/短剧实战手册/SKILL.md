# 短剧实战手册：钩子/付费墙/节奏与人物志

> 本包由 28 张方法论卡汇编重铸（卡片明细与出处见各卡 frontmatter 的 source_card / source_book）。

## 何时调用

当短剧从选题到分集的工业级打法时调用。核心能力：钩子 / 付费墙 / 节奏与人物志。

关键触发：「他是个怎样的人」、「情感钉子」、「怎么用一件事立人」、「我手头的素材太普通，写不出彩」、「一个绰号讲清一个人」、「我想写一个带着强烈地方味儿的人物」。

工位边界：本包负责创作方法论层；提示词语法与模型参数走影策官方市场技能，两者接力不抢戏。

## 本包交付什么

用户提出短剧创作需求时，本包最终交付四件东西：

1. **分集结构表**：集数、每集钩子、付费墙位、结尾反转或留白方式；
2. **人物志**：每人一个「姓+绝活/怪癖」式绰号、一句定式、一个反推性格的闲细节；
3. **开篇前 30 秒**：热开篇的第一镜与第一句，标注钩子类型；
4. **结尾方案**：反转或留白的落点，以及它重新估价了前文哪个细节。

### 内容保真优先级

冲突时按此顺序裁决，禁止圆场：

1. **用户明确指定**（集数/时长/风格/禁项/参考职责）；
2. **人物与动作逻辑自洽**（人物行动来自欲望，不来自作者方便）；
3. **短剧结构规律**（钩子前置、付费墙位、全程情绪点不断）；
4. **风格与质感装饰**（地域质感、时代细节只服务前三项）。

### 默认决策

用户未指定时采用，并在交付前用一句话说明选了什么：

- **开篇**：默认热开篇，不用冷开篇；
- **结尾**：默认反转或留白，不用总结式收尾；
- **单集时长**：未说则按 1–3 分钟设计；
- **人物数量**：未说则主角 1 人 + 关键对手 1 人，避免一上来铺群像；
- **质感来源**：默认从用户给的素材里提取，不强行添加地域特色。

### 质量门槛

交付前逐项自检，任一项不过就改完再交：

- [ ] 开篇 30 秒内是否出现钩子（不是背景介绍）；
- [ ] 每个人物是否能「一句定式」说清，不需要三段介绍；
- [ ] 付费墙位是否落在情绪峰值之后、答案揭晓之前；
- [ ] 结尾是否只敲最后一记钉子，没有替观众下结论；
- [ ] 是否有至少一个「看似离题却能反推性格」的闲细节；
- [ ] 全篇是否至少有一个信息或关系的变化（没有变化就只是说明）。

## 包内卡片名录

- `cards/czks-character.md` — 塑造有血有肉人物的系统技法：先用网络热词给角色打「标签」锁定辨识度（白骨精/病娇/腹黑/女强人/拽姐/钓系美人/人间清醒
- `cards/czks-emotion.md` — 情绪是短剧的灵魂——观众注意力极短，必须「全程无尿点」，一个情绪点接一个情绪点
- `cards/czks-genre-selection.md` — 短剧选题的第一课：先分清「类型」（故事基本分类，如喜剧/悬疑/科幻）与「题材」（所探讨的主题内容，如爱情/战争/成长）
- `cards/czks-hook-paywall.md` — 短剧「一眼定生死」——只有热开篇（无冷开篇）
- `cards/czks-structure-rhythm.md` — 把剧本比作人体：结构=骨骼，节奏=身材比例
- `cards/czks-three-points.md` — 短剧精不精彩，核心在能否时刻拉扯观众情绪
- `cards/dxj-audience-hook.md` — 短剧生存的核心技术：如何系统性制造「爽点」（即时满足+情绪峰值）和「钩子」（让人看下一集的悬念机制）
- `cards/dxj-character-empathy.md` — 颠覆「创造人物」传统观念——真正有力的人物是创作者在内心深处「发现」的已有存在
- `cards/dxj-inspiration-training.md` — 创作力的系统工程学：灵感不是天赐而是可训练的肌肉
- `cards/dxj-script-format-spec.md` — 短剧剧本的工业标准格式：场景标题/动作描述/角色名/台词/括号备注/转场的正确写法与常见错误
- `cards/dxj-short-drama-structure.md` — 系统界定短剧这一互联网原生形态：定义（时长/集数/节奏）、四大分类（付费解锁/广告变现/电商带货/品牌定制）、五种盈利模
- `cards/dxj-story-five-layers.md` — 故事的五层递进理解框架（语言补充→多态化产物→人类起源→世界即故事→痛苦恐惧）+ 故事六大内在特性（传播性/交互性/成长
- `cards/ssqr-baibai-portrait.md` — 写人物开篇时，用 2–3 句高密度感官肖像（形貌+动作+比喻标记「赛」）瞬间立住人物，绝不用「他很善良」这类抽象性格词
- `cards/ssqr-idle-detail.md` — 挑一个看似离题、却能反推性格的物件/习惯/动作细节（如层层布包、只记牙），比大段心理描写更见魂魄
- `cards/ssqr-incident-rule.md` — 先立一条「规矩」或一个哲理，再用一件决定性小事把人物与道理同时坐实
- `cards/ssqr-material-genesis.md` — 把日常琐碎/闲细节转化为故事素材——在平淡里发现落差与张力（脚指头变姨太太、油梳子变铜梳利刃），便是化腐朽为神奇的母机
- `cards/ssqr-nickname-persona.md` — 给人物起一个「姓+绝活/怪癖」式的绰号作人设总纲，用津门奇绝表象承载普遍人性——奇是钩子、常是内核
- `cards/ssqr-tianjin-lens.md` — 用天津卫市井生态作透镜看人——五方杂处、崇奇黜庸，人物的奇绝怪癖是地域性格的必然产物而非偶然个性
- `cards/ssqr-twist-ending.md` — 结尾用反转或留白重估前文——把奇人还原成「人人一尊神」的普遍感叹，或悬置疑问让读者自己品，余波比高潮更长
- `cards/ssqr-voice-identity.md` — 用方言、行话、语气节奏让对话自带阶级与身份，听众「闻声」即知人来历，不靠作者旁白交代
- `cards/sushi-episode-grain.md` — 人物颗粒度：一人一轶事——单人物、单事件、单场景、单冲突，只取"一个立得住的瞬间"，群像靠等量颗粒组装
- `cards/sushi-legend-real.md` — 传奇感与真实感的平衡：超常事件配三锚（说书人口吻、行业机理锚、人性逻辑锚），奇在外层、理在里层
- `cards/sushi-nickname-fate.md` — 给人物起"姓+绝活/怪癖"式绰号，让绰号同时埋下命运伏笔或反讽（绰号即谶）
- `cards/sushi-one-trick.md` — 传奇人物以"一件绝活"立身：全篇情节从绝活生发，绝活有边界，技能的边界即人物命运的边界
- `cards/sushi-region-soul.md` — 地域性格透镜：塑造传奇人物先问"此地百姓会怎样评价这种人"——把集体好恶铸进人物，奇人即地域性格的纪念碑
- `cards/sushi-reveal-punch.md` — 反转点题收束：结尾用一个信息翻案把前文重新赋值，再（可选）跟一句命运判词，把传奇升级为寓言
- `cards/sushi-street-flavor.md` — 市井时代质感施工：用行当术语、民俗仪式、方言口癖、物件工艺的"内行细节"浸染时代与街区，人物在质感中自动变真
- `cards/sushi-three-lines.md` — 三言两语立人：人物出场只给"一笔形貌速写 + 一个招牌动作/细节 + 一句定式"，三四十字立住一个人
