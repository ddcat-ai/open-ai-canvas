## I — 方法论骨架 (Interpretation)

人物颗粒度 = 群像叙事的"切片"决策：

1. **一人一轶事**：每个人物只分配一个"立得住的瞬间"——一个事件、一个场景、一个冲突（张大力举锁、绝盗一场戏、苏七块牌桌接骨、白四爷澡堂说书）。
2. **瞬间须"改变或暴露"人物**：这个瞬间必须让读者"看见此人是谁"（改变现状或暴露本质）；无事发生的瞬间是废篇。
3. **不写全传**：不铺生平、不写成长史；人物的"前史"只以碎屑形式点染（苏七块医术、大回的身世皆一笔带过）。
4. **等量颗粒组装群像**："人人一尊神"——每个配角都给足"一个瞬间"的尊严，不作工具人；群像的整体感来自颗粒的均等与并置。

**为什么有效**：单位篇幅内信息效率最大化——一个瞬间=一个人物的全部"可记忆单元"；读者记住的不是履历，是一个画面、一个决定、一个结局。

## S — 核心立场 (Stance) ★

- **一句话立场**：塑造群像奇人，每人只给一个立得住的瞬间——人物颗粒度越细，群像越整。
- **核心主张**：
  1. 一个瞬间（事件/场景/冲突）必须"改变或暴露"人物，否则是废篇。
  2. 群像靠等量颗粒组装：人人都有一刻的"神格"，不设工具人。
- **典型敌人**：人人写全传（群像变流水账）；工具人配角（只为推剧情存在）。
- **最适合的议题类型**：群像短篇集、单元剧/系列剧、人物列传式小说、短视频"一人一故事"系列。

## A1 — 书中的应用 (Past Application)

### 案例 1：张大力（单场景立人）
- **问题**：一个大力士怎么一个场景讲完？
- **使用**：举锁（一个动作）→ 老板点破"唯张大力举起来不算"（一个反转）→ 哈哈大笑扬长而去（一个态度）。
- **结论**：一个瞬间同时完成"立本事+立人品+立地域"。
- **结果**："当时无人不晓，现在没人知道"——三百年后读者仍记得这场举锁。

### 案例 2：绝盗（一场骗局立三人）
- **问题**：一场戏怎么立住"假爹+两假儿子+被骗夫妻"？
- **使用**：砸门骂街（行为）→ 邻居信以为真（舆论）→ 新郎"我三岁时爹就死了"（翻案）→ 十年没查到的结局。
- **结论**：单场景内完成人物群像（骗子的嚣张、邻居的愚信、新郎的懵）——颗粒极细而信息极密。
- **结果**：没人记住骗子长相，全记住"偷盗的居然做了人家的爹"。

### 案例 3：苏七块（单事件立性格）
- **问题**：规矩怎么用一个事件讲透？
- **使用**：牌桌遇急症（冲突）→ 无钱不接（规矩）→ 华大夫暗付（转折）→ 退钱不破规（点题"规矩不能改"）。
- **结论**：一个事件=性格的全套证明（认钱+认技+守规）。
- **结果**：华大夫"琢磨了三天三夜"没琢磨透，读者却全懂了。

### 案例 4：白四爷说小说（单场景立生态）
- **问题**：口述小说家怎么写才不空？
- **使用**：澡堂单间场景（一个环境）→ 编辑排队来要稿（一个生态）→ 脚趾变姨太太（一个细节）。
- **结论**：单场景+单生态=一个人物的全部职业面貌。
- **结果**："他一离开澡堂子小说就没了"——场景与人物焊死。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 群像故事，人物多、篇幅少，不知怎么分配戏份。
2. 短篇集/单元剧，每篇该讲什么、讲多少拿不准。
3. 配角沦为工具人，想给每个人"一个瞬间"的尊严。
4. 想写"人物列传/奇人录"式的合集结构。

### 语言信号

- 「群像怎么写」「短篇集结构」「单元剧」
- 「人物太多」「一人一个故事」「人物小传」
- 「配角太工具人」

### 分层编码触发关系

- `--style A1` → 高概率触发（主层：人物呈现）
- `--style A1,N3` → 高概率触发（主+副：一个瞬间=一次期望与结果的落差）
- `--style S1` → 不触发（非麦高芬主卡）

### 与相邻 skill 的区分

- 与 `sushi-one-trick`：彼卡管"人物内核是什么"（一件绝活），本卡管"选哪一片人生来写"（切片决策）——内核定方向，切片定篇幅。
- 与 `sushi-three-lines`：彼卡管"出场那几行"，本卡管"整篇只讲一件事"——出场是颗粒内部的第一格。
- 与 `mckee-scene-analysis`：彼卡诊断"单场戏有没有戏"，本卡决定"群像每人分几场戏"——决策层不同。

## E — 可执行步骤 (Execution)

1. **定人物核心（一个词）**
   - 完成标准：用一词定义此人（倔/精/义/毒/憨/滑），全篇只服务这一个词。
   - 判停条件：需要两个词才能说清=核心未凝，合并到主词。

2. **选一个"瞬间"**
   - 完成标准：挑一个事件/场景/冲突，它必须能"改变或暴露"核心词（张大力举锁=暴露出"服"与"洒脱"）。
   - 判停条件：选中的瞬间无法同时立人+推进=不是好切片，换一个。

3. **只写这个瞬间**
   - 完成标准：前史只点染（一句带过），不回头写生平；开头即入事件。
   - 判停条件：忍不住写"他从小……"的履历=破坏颗粒度，砍掉回场景。

4. **检验"抽离测试"**
   - 完成标准：拿掉这个瞬间，人物就不存在了（张大力=只有那次举锁）。
   - 判停条件：拿掉瞬间人物还在（靠背景/旁白支撑）=切片没切中，回步骤 2。

5. **群像等量装配**
   - 完成标准：每个角色都分配一个"神格瞬间"，工具人升级为人物；颗粒大小均等。
   - 判停条件：有人颗粒过大抢戏、有人颗粒过小成工具，调均。

> 💡 **圆桌调用提示**：系列创作会按角色排"颗粒清单"：每人一格（事件+核心词），格满即开机。

## B — 边界 (Boundary) ★

### 🔴 硬约束（世界层）：用了就崩

- **瞬间必须改变或暴露人物**：无事发生的瞬间=废篇（叙事无价值转折）。
- **一人多事=颗粒度破坏**：给每人两个以上完整事件，群像篇幅失控、焦点涣散。
- **全传冲动即崩**：在单篇里铺生平，短篇立刻变流水账。

### 🟡 软约束（规则层）：用了有代价

- **单颗粒人物浅**：一个瞬间立得住辨识度，立不起纵深；长篇/系列需要"多颗粒叠加"（每季给人物补新瞬间），代价是设计成本。
- **等量均分有取舍**：群像里给配角也分"神格瞬间"，代价是主角戏份被压缩（本书即如此——主角并不突出）。

### 🟢 自设约束（认知层）：其实可以重写

- **"一人一轶事"是本书体裁契约**：可重写为"一人多轶事"（连续剧）或"多人一轶事"（多视角同一事件）。
- **颗粒大小可调**：从"三行速写"到"整篇专场"是连续谱（本书每篇约 1500-2500 字）。

### 失败模式

- 切片太碎（信息不足以立人）→ 读者记不住（须"改变或暴露"兜底）。
- 切片太全（写成微传记）→ 失去颗粒感，变流水账。
- 群像不均（主角吃光戏份）→ 配角全成工具人（违反"人人一尊神"）。

### 容易混淆的邻近方法论

- 与 `mckee-scene-analysis`：单场戏质检 vs 群像切片决策。
- 与 `wfs-change-closure`：本卡管"切片选材"，彼卡管"切片有没有弧光闭合"，可组合验收。
- 与 `sushi-three-lines`：出场三笔是"颗粒内部"的第一层，本卡是"颗粒边界"的划定。

## P — 分层编码定位 (Layer Code) ★

### 所属层级

- **主层**: A1 弧光选择 / 人物呈现 — 切片服务于"立人"。
- **副层**: N3 鸿沟驱动 — 一个瞬间=一次期望与结果的落差（人物行动 vs 世界反应），麦基鸿沟在单篇尺度上的应用。
- **候选层**: 无。

### 分层说明

- **为什么主层是 A 层**：决策目标是"把人物立住"，属人物呈现。
- **为什么副层 N3**：瞬间之所以能立人，靠的是"期望与结果的落差"（张大力：以为被刁难→实为被恭维），即鸿沟驱动。
- **与 LIBRARY.md 的关系**：A1✅已有、N3✅已有（麦基 gap-writing）。
- **母题依据**：母题 M2「人人一尊神」——颗粒度是"每人一篇各不相关"的直接体现；因果结构：切片(选材)→瞬间(鸿沟)→立人(果)。母题风洞已验证（改条件测试：把"每人一个瞬间"改为"每人三个瞬间"（长篇变体），立人更快但群像焦点涣散——颗粒度对信息密度的因果不变；把"事件瞬间"改为"静态肖像瞬间"（无冲突），人物只剩辨识度无命运感，判断成立）。
