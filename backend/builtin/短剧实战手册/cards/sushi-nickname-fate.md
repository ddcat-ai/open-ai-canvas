## I — 方法论骨架 (Interpretation)

绰号是"人设压缩包 + 命运伏笔"的双面胶：

1. **压缩**：把人物最锐利的特征（行当/绝活/怪癖/丑闻）装进一个名字，读者一听绰号就预支了对这个人的全部期待。
2. **立约**：绰号在开篇向读者立下"这人奇在哪里"的契约，故事负责兑现。
3. **埋谶**：好绰号自带命运方向——"鱼绝后"（钓鱼钓绝的人，被鱼车轧死）、"死鸟"（伺候鸟的人，被鸟毁掉）、"飞熊"（笨重之人能飞一次，也止于一次）。名字里的极端，就是命运的反作用力。
4. **兑现或翻案**：结尾让命运回应绰号——字面应验（谶）、彻底反讽（骂名反成名：《狗不理》"虽是骂名，也出了名"），或由人翻案（《张大力》"唯张大力举起来不算"其实是津门夸人法）。

核心主张：**一个名字里藏着整个故事的因果**——绰号决定人物往哪儿走、怎么收。

## S — 核心立场 (Stance) ★

- **一句话立场**：绰号既是人设也是谶语——开篇用一个名字立契约，结尾用命运兑现或翻案。
- **核心主张**：
  1. 好绰号 = 最锐特征的一句话压缩，是故事的契约书。
  2. 名字里埋的极端，会以反作用力的形式在结尾找回来（谶语或反讽）。
- **典型敌人**：无信息量的名字（老王/小李）；只把绰号当称呼、不参与情节与命运的名字。
- **最适合的议题类型**：传奇人物短篇、市井群像、单元剧/系列人设的第一标签；也适用短视频 IP 人设命名。

## A1 — 书中的应用 (Past Application)

### 案例 1：大回（谶语应验）
- **问题**：钓鱼奇人怎么收束才有"命运感"？
- **使用**：外号"鱼绝后"——他"决不把任何一个坑里的鱼钓绝了。钓绝了，他玩嘛？"却还是被一车鱼轧死。
- **结论**：绰号字面应验=谶；点题句"能人全都死在能耐上"让外号升级为寓言。
- **结果**：读者记住的不是钓技，是名字与死亡的对称。

### 案例 2：飞熊（绰号反讽）
- **问题**：笨重奇人的"飞"如何被杀死？
- **使用**：成名绰号"飞熊"→ 被激将再跳一次 → 两腿发抖 → 换了个不受听的称号"狗熊"。
- **结论**：绰号可以中途翻案，翻案即人物命运的转折点。
- **结果**：名字变化=人物弧光的最短路径。

### 案例 3：狗不理（骂名反成名）
- **问题**：坏名字怎么变成资产？
- **使用**："别的包子铺干脆骂他'狗不理'……虽是骂名，也出了名。"
- **结论**：绰号的舆论性质可反转——好名没人稀罕，骂名人人好奇。
- **结果**：骂名成了全国知名品牌，名字的"反讽"反向兑现。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 人物没记忆点，读者记不住名字。
2. 想用"一个绰号讲清一个人"并让它贯穿情节。
3. 想让名字承载主题/命运（悲剧、寓言、反讽）。
4. 系列/单元剧人物需要"一喊即认"的标签。

## E — 可执行步骤 (Execution)

1. **找最锐特征**
   - 完成标准：一句话能说清（行当/绝活/怪癖/丑闻），且这个特征"可被看见"。
   - 判停条件：特征太多时取最具反差的一个；找不到就回到人物内核（一个词：倔/精/义/毒）。

2. **组装"姓 + 特征"绰号**
   - 完成标准：绰号一听即知此人最强标识，读起来顺口、好记、好传。
   - 判停条件：换地域/文化时命名法须本地化（见 B 段硬约束）。

3. **埋谶（给名字装命运方向）**
   - 完成标准：从绰号的极端里推演出"反作用力"——极端如何反过来吞噬/成全此人。
   - 判停条件：推不出反作用力，说明绰号只是标签，回步骤 1。

4. **兑现或翻案**
   - 完成标准：结尾让命运回应绰号（字面应验 / 反讽 / 由人翻案），并（可选）跟一句判词。
   - 判停条件：如果翻案是硬凹的，保留"兑现"路线。

> 💡 **圆桌调用提示**：首次完整走四步；后续轮次只引用步骤编号（如"用第 3 步给这个外号埋个谶"）。

## B — 边界 (Boundary) ★

### 🔴 硬约束（世界层）：用了就崩

- **绰号不可硬凑**：没有锐利特征的绰号=贴标签，读者记不住也没感觉。
- **谶语不可明说**：把"鱼绝后=死于鱼"提前写进叙述，悬念与反讽全失味；谶要藏在名字本身，靠结尾兑现。
- **机械兑现即崩**：每篇都用"外号字面应验"同一招，套路化（本书亦有此倾向，须变换兑现类型：应验/反讽/翻案/舆论反转）。

### 🟡 软约束（规则层）：用了有代价

- **命名法地域化**："姓+行当"生于津门市井，套异文化会架空；换地域须换命名逻辑（如潮汕"阿X"、关中"X娃"），代价是重新设计。
- **绰号太满**：绰号承载过多会剥夺人物成长空间，代价是扁平（参考 ssqr-nickname-persona B 段）。

### 🟢 自设约束（认知层）：其实可以重写

- **男权市井视角偏置**：本书奇人多男性手艺人，绰号多取"本事/怪癖"；为女性/当代人物起名时主动补全视角，避免把男权市井当普世（可重写）。
- **"人人一尊神"的颗粒观**：认为每个人都值得一个"神格绰号"是本书审美，可重写为"只有主角配绰号"。

### 失败模式

- 绰号炫奇但内核空 → 读者记住名字却不懂这人（counter-examples CE2 蓝眼：名声先于实力）。
- 谶语兑现太机械 → 套路化（见硬约束第 3 条）。

### 容易混淆的邻近方法论

- 与 `kom-non-hero`（喜剧非英雄人设）：彼卡是喜剧原型，本卡是市井绰号+命运钩连，可互补。
- 与 `tct-trait-dual-axis`（特质双轴）：彼卡管特质内部的双刃性，本卡管"名字里的极端如何被命运反噬"——机制同源，应用层不同。

## P — 分层编码定位 (Layer Code) ★

### 所属层级

- **主层**: A1 弧光选择 / 人物呈现 — 绰号是人物呈现的第一笔。
- **副层**: S3 伏笔回收 — 绰号埋的命运方向在结尾回收，属信息控制类（LIBRARY 候选编码）。
- **候选层**: 无。

### 分层说明

- **为什么主层是 A 层**：核心功能是"人物呈现+命运呈现"，去掉它人物无第一记忆点。
- **为什么副层 S3**：谶语=伏笔，兑现=回收；这是悬疑张力层的"伏笔回收"机制在人物命名上的应用。
- **与 LIBRARY.md 的关系**：A1✅已有、S3🔲候选（本卡提供跨域佐证，供 VERIFY 准入评审）。
- **母题依据**：母题 M3「能人死在能耐上」（书名式点题）——绰号是"能耐"的命名，命运是"能耐"的清算；因果结构：名字(因)→传奇(果)→名字兑现(反转因)。母题风洞已验证（见审计）。
