## I — 方法论骨架 (Interpretation)

传奇人物不是作者的凭空发明，而是**地域集体审美的纪念碑**：

1. **百姓好恶即人物来源**：奇人的价值观、行为、命运由"此地百姓集体好恶"铸造——天津人爱绝活、敬能人、好戏谑、怕栽面、恨人有笑人无。人物身上的"怪"，其实是地域性格的显影。
2. **好恶清单可考古**：从民俗、歇后语、民间评价里挖"这地方的人服什么、怕什么、嘲什么"（"天津人最服的是以假乱真"；"天津人认绝活，服绝活"；歇后语"说相声逗冷脸——自找别扭"）。
3. **人物=好恶的人格化**：把一个好恶点铸成一个人物——"服本事"铸成刷子李/马二，"好戏谑"铸成皮大嘴/冷脸，"要面子"铸成旗杆子/齐老太太，"恨人有笑人无"铸成焦七/龙袍郑的舆论。
4. **命运由众人裁决**：人物的结局常由"众人如何看他"决定（绝盗的邻居信以为真、旗杆子被谣言毁掉、告县官被真县官叫停）——地域舆论是人物命运的执行者。

核心主张：**先问"这地方的人会怎么评价这种人"，再写这个人**——人物立住了地域，地域也立住了人物。

## S — 核心立场 (Stance) ★

- **一句话立场**：塑造传奇人物先问"此地百姓会怎样评价这种人"——把集体好恶写进人物，奇人即地域性格的纪念碑。
- **核心主张**：
  1. 人物的怪，是地域性格的显影；好恶清单是人物素材库。
  2. 地域舆论参与人物命运——众人如何看他，决定他怎么活怎么死。
- **典型敌人**：无地域根的通用人物（换个城市也成立）；刻板印象（用"天津人都会说相声"式标签代替真实民俗）。
- **最适合的议题类型**：地域题材、市井群像、地方传说改编、方言剧；任何需要"人物有根"的创作。

## A1 — 书中的应用 (Past Application)

### 案例 1：刷子李（"服本事"）
- **问题**：刷墙匠怎么成为"码头一神"？
- **使用**："码头上的人，全是硬碰硬……有绝活的，吃荤，亮堂，站在大街中央"——把"服本事"的集体好恶铸进人物。
- **结论**：人物是地域价值观的化身；读者信人物=信这地方的规矩。
- **结果**：绰号响当当，代表整条码头生态。

### 案例 2：马二（"服乱真"）
- **问题**：模仿秀式人物怎么立出价值？
- **使用**："真的不难，以假乱真才难。……天津人最服的是以假乱真。"
- **结论**：用一条地域价值观把"学人"升格为"大能耐"。
- **结果**：马二成了"世面上的一号"，全城请他赴宴——地域好恶直接转化为人物际遇。

### 案例 3：冷脸（"好戏谑"的反面试金石）
- **问题**：地域的"好戏谑"怎么反向写？
- **使用**：天津人爱逗乐，冷脸就是不笑——歇后语"说相声逗冷脸——自找别扭"给人物做舆论注脚。
- **结论**：集体好恶被人物"反向顶住"，人物反而更奇。
- **结果**：冷脸成了"相声杀手"，天津没人再往南门外说相声——舆论既是压力也是地位。

### 案例 4：四十八样（"认绝活"）
- **问题**：不会吆喝的俞六怎么出头？
- **使用**：刘二爷点破"天津人认绝活，服绝活"→ 俞六把"卖"做成绝活（药糖柜+走八字+嘎话）→ 一举成名。
- **结论**：地域价值观直接给人物指路（往绝活方向使劲就对了）。
- **结果**：地域好恶=人物行动指南。

### 案例 5：旗杆子（"要面子+恨人有笑人无"的悲剧）
- **问题**：地域舆论怎么杀死一个人？
- **使用**：他高得吓人（被人笑）→ 公园当"一景"（被利用）→ 遭嫉恨被诬陷（恨人有）→ 冤屈离岗饿死。
- **结论**：人物的命运完全由"众人如何看他"支配——地域舆论的双刃。
- **结果**："人间容不得高人，只有死后再去长了"——地域性格的悲剧面。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写地域题材/市井人物，怕"换个城市也成立"。
2. 人物价值观空泛，不知道"他为什么这么想"。
3. 想让群像有"地方魂"，而不只是服装道具像那个年代。
4. 改编地方传说/奇闻，想抓住"当地人怎么看这件事"。

### 语言信号

- 「地域特色」「地方人」「市井人物」
- 「人物价值观从哪里来」「集体性格」
- 「这地方的人服什么」「太通用，没地方味」

### 与相邻 skill 的区分

- 与 `ssqr-tianjin-lens`（津门市井透镜）：彼卡是"作者用市井眼光看世界"的观察视角（perspective），本卡是"人物价值观从哪里来"的塑造输入（百姓好恶→人物）——一个向内（作者的眼），一个向外（人物的根）。
- 与 `sushi-street-flavor`：彼卡管"细节素材"（术语/民俗/方言），本卡管"价值观内核"（好恶/评价）——细节是表，价值观是里，composes-with。
- 与 `yt-persona-boundary`（杨天真 人设即边界）：彼卡是当代个人品牌的人设方法，本卡是地域群体的性格铸造法——时代与对象不同，机制可互鉴。

## E — 可执行步骤 (Execution)

1. **选地域/共同体**
   - 完成标准：锁定一个具体地域或亚文化共同体（不是"中国人"这种超大筐）。
   - 判停条件：选不出具体共同体，说明人物无根，先做地域功课。

2. **考古"集体好恶"清单**
   - 完成标准：从民俗、歇后语、民间评价、行规里列出 5-10 条"这地方的人服什么/怕什么/嘲什么/敬什么"，每条有出处。
   - 判停条件：清单全靠脑补（无民俗/文献依据）=刻板印象风险，回查证。

3. **把好恶铸进人物**
   - 完成标准：人物的绰号/绝活/规矩/动机至少对应清单中的 1-2 条好恶（"服本事"→刷子李的绝活尊严）。
   - 判停条件：人物与好恶清单无关联=人物仍是通用的，回步骤 2。

4. **让舆论参与命运**
   - 完成标准：人物的成败至少一次由"众人如何看他"决定（被服/被嘲/被毁/被传）。
   - 判停条件：人物命运完全脱离地域舆论=地域只是背景板，回步骤 3。

5. **本地话点睛**
   - 完成标准：用一句本地歇后语/谚语/嘎话给人物做舆论注脚（"说相声逗冷脸——自找别扭"式）。
   - 判停条件：点睛句是作者腔（不像本地人说出来的话）=失败，换。

> 💡 **圆桌调用提示**：人设会上问"这地方的人会怎么评价他"，即引用本卡步骤 2-4。

## B — 边界 (Boundary) ★

### 🔴 硬约束（世界层）：用了就崩

- **集体好恶不可编造**：须有民俗/文献/语料依据（本书有方言脚注与行当考据）；编造的地域性格=刻板印象。
- **不可标签化一地**：把"天津人都……"写成铁律=刻板（地域性格是"倾向"不是"宿命"）。
- **人物不可成为纯符号**：只当好恶的传声筒（没有个人欲望/选择）=概念人物，不是人物。

### 🟡 软约束（规则层）：用了有代价

- **地域浓则传播窄**：津味越足，外地读者门槛越高（本书自带注释）；代价是破圈难度。
- **舆论参与命运有双刃**：把人物命运全交给舆论，代价是人物主体性弱（旗杆子式悲剧成立，但不能人人如此）。

### 🟢 自设约束（认知层）：其实可以重写

- **"地域性格论"有本质主义风险**：可重写为"亚文化共同体性格"（同好圈子/行业共同体/网络圈层）——当代故事不必绑定地理。
- **男权市井底色可重写**：本书好恶清单带着旧时代男权印记，当代用卡须重新采集好恶（女性共同体、新市民共同体）。

### 失败模式

- 好恶清单变成刻板标签（东北人都……）→ 失真。
- 人物被舆论压扁（完全无主体性）→ 读者不同情（旗杆子式须有内在尊严支撑）。
- 地域味靠道具不靠价值观（服装像、人不像）→ 空壳。

### 容易混淆的邻近方法论

- 与 `ssqr-tianjin-lens`：作者之眼 vs 人物之根。
- 与 `sushi-street-flavor`：价值观内核 vs 细节素材。
- 与 `wojia-persona-contrast`（人设反差）：彼卡造"表层反差"的笑点，本卡给"人物价值观的根基"——可组合（反差人物+地域根基）。
