## 技能内容：

分为**交互阶段**和**执行阶段**。交互阶段用选择题收集进化变量；执行阶段分析底座、生成进化矩阵、批量调用图片工具、质量检查、输出可选择的候选方案和定稿收尾建议。本技能在候选评审后结束。

核心链路：

底座输入 → 选择题表单 → 底座身份锁 → 进化矩阵 → 批量图片生成 → 质量检查 → 候选评审 → 一次性交付

默认交付：

* 4 个进化方向候选图。
* 每个方向 1 张主图 + 结构说明 + 进化理由 + 推荐用途。
* 输出可执行收尾建议：高清化、细节图、定稿说明或移交电商素材。

模型默认：

* 图片类任务默认使用 4.7 模型的 2k 版。
* 视频类任务默认使用 seedance2.0fast\_vip。
* 用户明确指定图片或视频模型版本时，按用户指定执行，不再套用对应默认模型。

## **一、触发范围**

### **1.1 应使用本技能的情况**

* 用户想在已有珠宝图、草图、裸石图、元素图基础上做多方向演化。
* 用户希望通过选择题决定设计方向，而不是一次性写完整 prompt。
* 用户要求“给我 4 个方向 / 8 个方向，我先选一个”。
* 用户需要保留原款结构，同时尝试不同元素、材质、风格或工艺。
* 用户想做系列探索、款式创改、竞品改造、文化元素转译、设计分支评审。

### **1.2 应移交其他技能的情况**

* 用户只要单款高质量原创珠宝设计，不需要选择题或进化矩阵 → 使用 珠宝设计出款。
* 用户已经确定款式，要做亚马逊九图、上架图、详情页、短视频和文案 → 使用 珠宝电商素材Skill。
* 用户要一次规划几十款或多个 SKU 的大项目 → 先使用 大批量执行Skill 拆解，再交给本技能或其他生成技能。

## **二、工具映射**

| **工具名**                               | **本技能用途**              | **链式调用提示**                          |
| ------------------------------------- | ---------------------- | ----------------------------------- |
| generate\_form\_for\_info\_collection | 用选择题收集进化变量             | 只在初始进化问题、用户要改选项或缺少必填字段时使用；表单完成后进入矩阵 |
| creation\_agent\_search               | 可选：查询非侵权文化元素、珠宝风格、工艺参考 | 搜索后转成原创约束，不直接复制品牌款                  |
| text2image / text2image\_v3           | 无底座图时生成初始珠宝底座图         | 默认 4.7 模型 2k 版；生成后作为底座进入进化          |
| image2image / image2image\_v3         | 基于底座图、草图或元素图生成本次进化候选   | 默认 4.7 模型 2k 版；每个候选都重复底座身份锁和进化变量    |
| foreground\_segmentation              | 抽取候选主体，用于对比板或后续电商素材    | 可选，候选确认后再使用                         |
| image\_super\_resolution              | 放大优秀候选图或最终选中图          | 结构正确后再超分                            |
| image2video / multi\_modal2video      | 只在用户要求进化过程展示短片时使用      | 默认 seedance2.0fast\_vip；图片结果先完成再进视频 |
| video\_editor                         | 拼接进化过程视频或候选展示视频        | 视频流程最后调用                            |

在线版适配：

* 图片工具如存在 v3 版本，优先使用 text2image\_v3 / image2image\_v3。
* 图片生成默认选择 4.7 模型 2k 版。
* 运行时优先使用“产品设计”“商业摄影”“参考图改造”“高清细节”类在线预设。
* 不写本地 CLI 模型名、账号命令或任务查询命令。

## **三、交互阶段**

### **步骤 1：信息提取**

| **字段**                | **必填** | **缺失时处理**                                                  |
| --------------------- | ------ | ---------------------------------------------------------- |
| 底座图 / 草图 / 元素图 / 文字雏形 | 是      | 缺图且无文字雏形时，调用 generate\_form\_for\_info\_collection 提示上传或描述 |
| 目标珠宝类型                | 否      | 可从底座图判断；无法判断时默认“保留底座类型”                                    |
| 输出数量                  | 否      | 默认 4 个候选；可选 8 个候选                                          |
| 结构保留度                 | 否      | 默认“中：保留轮廓，允许局部变化”                                          |
| 进化强度                  | 否      | 默认“平衡：明显变化但保留识别度”                                          |
| 融合策略                  | 否      | 默认“纹样转译”                                                   |
| 元素主题                  | 否      | 默认由底座图和用户描述推断；也可让用户多选                                      |
| 形态语言                  | 否      | 默认“原型轮廓 + 流线曲面”                                            |
| 审美风格                  | 否      | 默认“高级珠宝 + 当代极简”                                            |
| 材质工艺                  | 否      | 默认保留底座主材质，并加入钻石或贵金属细节                                      |
| 参考图                   | 否      | 有参考图则只作为风格、材质、工艺或细节参考，不抢底座轮廓                               |
| 参考图角色                 | 否      | 默认“风格参考”；多图时按图片内容推断                                        |
| 用户补充方向                | 否      | 默认无；有则写入矩阵和每个候选提示词                                         |
| 图片模型                  | 否      | 默认 4.7 模型的 2k 版；用户指定模型版本时按指定                               |

缺少必填字段时才中断流程。可选字段用默认值，不要连续追问。

### **步骤 2：选择题表单**

当用户没有明确给出进化变量时，调用 generate\_form\_for\_info\_collection 生成选择题表单。表单字段如下：

| **题目**        | **类型** | **选项**                                                                    | **默认**        |
| ------------- | ------ | ------------------------------------------------------------------------- | ------------- |
| 本次输出几个进化方向？   | 单选     | 4 个 / 8 个                                                                 | 4 个           |
| 希望多大程度保留原款结构？ | 单选     | 高：尽量保留结构与比例 / 中：保留轮廓，允许局部变化 / 低：只保留家族相似性                                  | 中             |
| 本次进化强度？       | 单选     | 微调 / 平衡 / 重塑                                                              | 平衡            |
| 元素如何与底座融合？    | 单选     | 保形嫁接 / 纹样转译 / 结构重组                                                        | 纹样转译          |
| 想注入哪些元素主题？    | 多选     | 藤蔓花叶 / 花朵绽放 / 羽翼生灵 / 昆虫宝石 / 星月天象 / 水波海洋 / 几何徽章 / 建筑拱廊 / 护符符号 / 东方云纹 / 自定义 | 默认从底座推断 2-3 个 |
| 形态语言偏好？       | 多选     | 原型轮廓 / 流线曲面 / 几何秩序 / 镂空花丝 / 浮雕层叠 / 仿生有机 / 模块串联 / 立体雕塑                     | 原型轮廓 + 流线曲面   |
| 审美风格偏好？       | 多选     | 当代极简 / 新中式雅奢 / 东方宫廷 / Art Deco / 高级珠宝 / 自然主义 / 婚嫁典雅 / 年轻潮奢                | 高级珠宝 + 当代极简   |
| 材质工艺偏好？       | 多选     | 24K 纯金 / 珍珠母贝 / 彩色宝石 / 冷珐琅 / 热珐琅 / 钻石 / 双色贵金属                             | 保留底座主材质 + 钻石  |
| 参考图主要用于什么？    | 单选     | 风格参考 / 材质参考 / 工艺参考 / 细节参考 / 氛围参考                                          | 风格参考          |

表单完成后，必须进入“底座身份锁”和“进化矩阵”，不要停在表单摘要。

### **步骤 3：确认与跳过规则**

* 用户已经明确所有关键方向 → 不再调用表单，直接生成进化矩阵。
* 用户只给底座图，没有方向 → 自动调用选择题表单。
* 用户说“你默认帮我选” → 使用默认 4 候选、结构保留度中、进化强度平衡、融合策略纹样转译。
* 用户说“大胆一点” → 进化强度设为重塑，结构保留度可降为低或中。
* 用户说“别改太多” → 结构保留度设为高，进化强度设为微调。
* 用户要求基于某张已生成图再做变化 → 把该图视为新的底座图，重新执行一次完整的一次性进化流程；不承接历史表单状态。

## **四、执行阶段**

### **步骤 4：底座身份锁**

执行任何生成前，先建立底座身份锁。

底座身份锁字段：

| **字段**           | **说明**                    |
| ---------------- | ------------------------- |
| base\_id         | 底座编号，如 BASE-INPUT         |
| base\_type       | 戒指、项链、耳环、手链、吊坠、胸针、套装等     |
| base\_silhouette | 原始轮廓、比例、体量和视觉中心           |
| base\_structure  | 戒臂、链条、吊环、耳针、扣具、铰链、镶口等真实结构 |
| base\_material   | 金属、宝石、珐琅、珍珠、母贝等           |
| locked\_parts    | 必须保留的结构、主石、比例、佩戴逻辑        |
| editable\_parts  | 可进化的局部，如边缘、纹样、镶嵌、吊坠轮廓、戒肩  |
| reference\_roles | 参考图角色：风格、材质、工艺、细节、氛围      |

底座图不是普通参考图。底座图负责结构，参考图负责语言。

如果没有底座图但有文字雏形：

1. 调用 text2image\_v3，默认 4.7 模型 2k 版生成初始底座图。
2. 检查底座图是否清晰、结构可佩戴。
3. 合格后把生成图作为 BASE-INPUT 进入进化矩阵。

### **步骤 5：进化变量解释**

#### **5.1 结构保留度**

| **选项** | **执行约束**                            |
| ------ | ----------------------------------- |
| 高      | 尽量保持底座轮廓、比例、主石位置和佩戴结构，只改装饰、纹样、边缘和镶嵌 |
| 中      | 保留底座家族轮廓和主结构，允许局部体量、边缘、支撑结构和视觉中心变化  |
| 低      | 只保留底座识别基因，允许更大胆重组，但仍必须是可佩戴珠宝        |

如果用户提供局部蒙版或明确局部区域，只修改指定区域，其他区域保持不变。

#### **5.2 进化强度**

| **选项** | **执行约束**                       |
| ------ | ------------------------------ |
| 微调     | 适合商业款优化，只增强比例、边缘、镶嵌和材质细节       |
| 平衡     | 适合新系列探索，保留识别度，同时让元素主题清晰进入设计    |
| 重塑     | 适合概念方向探索，允许轮廓和结构重组，但不能变成不可佩戴装置 |

#### **5.3 融合策略**

| **选项** | **执行约束**                     |
| ------ | ---------------------------- |
| 保形嫁接   | 保留原结构，把元素作为局部结构、宝石排列、边缘装饰植入  |
| 纹样转译   | 把元素转化为纹样、镂空、浮雕、肌理、爪镶节奏或宝石排列  |
| 结构重组   | 把元素变成新的结构逻辑，重组局部轮廓、视觉重心或连接方式 |

#### **5.4 元素主题库**

| **元素** | **适合转译方式**              |
| ------ | ----------------------- |
| 藤蔓花叶   | 曲线戒臂、缠绕链节、叶片边缘、小钻露珠     |
| 花朵绽放   | 花簇镶嵌、中心主石、花瓣副石、层叠轮廓     |
| 羽翼生灵   | 羽片分层、轻盈开合、边缘渐变钻、耳饰垂坠    |
| 昆虫宝石   | 对称翅面、彩宝身体、细密镶嵌、胸针或戒面    |
| 星月天象   | 星点钻石、月弧轮廓、深色宝石、渐变光晕     |
| 水波海洋   | 流线曲面、波纹镶嵌、蓝绿宝石、贝壳光泽     |
| 几何徽章   | 对称结构、阶梯形、Art Deco、硬朗金属边 |
| 建筑拱廊   | 拱形结构、透空镂空、层级支撑、宫廷秩序     |
| 护符符号   | 中心护符、圆牌、平安扣、边缘纹样、寓意符号   |
| 东方云纹   | 卷云线条、祥云边缘、新中式雅奢、金属浮雕    |

#### **5.5 形态语言库**

* 原型轮廓：保留底座外形与比例。
* 流线曲面：柔和曲线、人体工学体量、自然流动。
* 几何秩序：对称、阶梯、几何切面、比例清晰。
* 镂空花丝：透空结构、精细线条、负空间可读。
* 浮雕层叠：前后层级、浅浮雕、边缘细节。
* 仿生有机：自然生长感、非机械曲线、生命节奏。
* 模块串联：重复单元、链节、可延展系列结构。
* 立体雕塑：强侧面、体积感、可从多角度观看。

#### **5.6 审美风格库**

* 当代极简：克制、干净、少量高质量细节。
* 新中式雅奢：东方文化符号现代化，避免古董化堆砌。
* 东方宫廷：仪式感、对称、华丽但结构可信。
* Art Deco：阶梯几何、清晰对称、强边框。
* 高级珠宝：精密镶嵌、收藏级比例、宝石和金属高质感。
* 自然主义：植物、动物、自然纹理的真实细节。
* 婚嫁典雅：柔和、浪漫、稳定佩戴、适合礼赠。
* 年轻潮奢：更轻快、时髦、有文化身份但不廉价。

#### **5.7 材质工艺库**

* 24K 纯金：厚重、温润、哑光或细砂质感，避免塑料黄。
* 珍珠母贝：虹彩、贝壳层次、柔和反光。
* 彩色宝石：蓝宝石、祖母绿、红宝石、粉色蓝宝石、碧玺等。
* 冷珐琅：清晰色块、现代图案、表面平整。
* 热珐琅：更深的釉色、传统工艺感、边界精致。
* 钻石：密镶、边缘强调、主石光晕、小颗露珠。
* 双色贵金属：白金 + 黄金、玫瑰金 + 白金、冷暖对比。

### **步骤 6：进化矩阵**

在调用图片工具前，先生成进化矩阵。矩阵数量必须等于用户选择的输出数量。

默认 4 个候选应覆盖不同设计逻辑：

| **候选** | **默认方向** | **目标**         |
| ------ | -------- | -------------- |
| A      | 保守商业化    | 最容易落地销售，结构变化最小 |
| B      | 元素明确化    | 元素主题更清楚，适合系列主款 |
| C      | 工艺材质化    | 重点探索材质、镶嵌和表面工艺 |
| D      | 大胆概念化    | 更强视觉记忆点，但仍可佩戴  |

8 个候选在 A-D 基础上扩展：

| **候选** | **默认方向** | **目标**           |
| ------ | -------- | ---------------- |
| E      | 高级珠宝化    | 更饱满、更华丽、更收藏级     |
| F      | 日常轻量化    | 更轻盈、更适合日常佩戴      |
| G      | 文化符号化    | 强化东方、护符、吉祥或叙事主题  |
| H      | 系列延展化    | 更适合发展成耳饰、项链、戒指套组 |

矩阵字段：

| **字段**              | **说明**                             |
| ------------------- | ---------------------------------- |
| evolution\_id       | 稳定编号，如 EVO-A                       |
| candidate\_label    | A-H                                |
| base\_id            | 使用的底座                              |
| target\_type        | 候选珠宝类型                             |
| structure\_fidelity | 高 / 中 / 低                          |
| intensity           | 微调 / 平衡 / 重塑                       |
| fusion\_strategy    | 保形嫁接 / 纹样转译 / 结构重组                 |
| element\_theme      | 元素主题                               |
| morphology          | 形态语言                               |
| style               | 审美风格                               |
| material            | 材质工艺                               |
| locked\_parts       | 必须保留                               |
| editable\_parts     | 本候选重点改动                            |
| difference          | 与其他候选的差异                           |
| prompt              | 图片提示词                              |
| model               | 图片模型；默认 4.7 模型 2k 版                |
| status              | planned / done / failed / retrying |

### **步骤 7：任务 Manifest**

批量生成前输出 manifest：

数量规则：

* requested\_count \= 用户选择的候选数。
* planned\_count 必须等于候选数。
* 每个候选必须有稳定 evolution\_id。
* 失败项保留原编号重试，不用新编号替换。
* 不能用 1 张合集图代替 4 或 8 张单独候选图，除非用户明确只要合集预览。

### **步骤 8：图片生成**

调用规则：

* 有底座图、草图或元素图 → 使用 image2image\_v3，默认 4.7 模型 2k 版。
* 只有文字雏形 → 先使用 text2image\_v3 生成底座，再使用 image2image\_v3 进化。
* 有参考图 → 底座图作为 @图片1，参考图作为 @图片2 起，明确参考图角色。
* 有局部蒙版或用户指定区域 → 蒙版作为最后一张输入图，提示只修改高亮区域。

同批候选可并发生成：

* 4 个候选默认同批生成。
* 8 个候选可分两批，每批 4 个。
* 如果前 2 个候选明显漂移，暂停后续并发，强化底座身份锁再重试。

### **步骤 9：候选提示词模板**

基于底座图生成珠宝设计进化候选 {evolution\_id}。 模型设置: 图片默认 4.7 模型 2k 版；用户指定模型版本时按用户指定。  底座身份锁: - 底座类型: {base\_type} - 原始轮廓: {base\_silhouette} - 真实结构: {base\_structure} - 主材质/主石: {base\_material} - 必须保留: {locked\_parts} - 可改动区域: {editable\_parts}  本候选进化变量: - 候选定位: {candidate\_label} / {candidate\_direction} - 结构保留度: {structure\_fidelity} - 进化强度: {intensity} - 融合策略: {fusion\_strategy} - 元素主题: {element\_theme} - 形态语言: {morphology} - 审美风格: {style} - 材质工艺: {material} - 与其他候选差异: {difference} - 用户补充方向: {direction\_prompt}  参考图规则: - @图片1 是底座图，负责结构、比例和佩戴逻辑。 - 其他参考图只提供 {reference\_roles}，不得取代底座轮廓。  画面表现: 白底或浅灰白背景，单件珠宝居中展示，专业珠宝产品摄影或高精度珠宝渲染，柔和棚拍灯光，金属真实反光，宝石火彩清晰，结构可佩戴。  禁止: 改变必须保留的底座核心结构、让主石漂浮、添加假 logo / 证书 / 价格 / 水印、生成不可佩戴装置、直接复制参考图、让 4 个候选彼此过度相似、画面出现文字或复杂背景。

### **步骤 10：候选评审与一次性交付**

候选生成后，必须把结果组织成可比较的候选评审表。本技能在这里完成一次性交付，不等待后续按钮、选项或追问。

评审格式：

```markdown
## 候选评审  
| 选项 | 方向 | 推荐用途 | 定稿建议 | |---|---|---|---| | A | {A_title} | {A_use_case} | {A_finish_hint} | | B | {B_title} | {B_use_case} | {B_finish_hint} | | C | {C_title} | {C_use_case} | {C_finish_hint} | | D | {D_title} | {D_use_case} | {D_finish_hint} |
```

收口规则：

* 输出到候选评审和定稿收尾建议为止。
* 不把 A/B/C/D 选择解释为新的图片生成任务触发。
* 如果用户选择某个候选，只执行高清化、细节图、定稿说明或电商素材移交。
* 如果用户要高清确认，对选中图调用 image\_super\_resolution。
* 如果用户要电商素材，输出产品身份锁，移交 珠宝电商素材Skill。

## **五、质量检查**

### **5.1 底座检查**

| **编号** | **标准**                 |
| ------ | ---------------------- |
| JE-B1  | 底座类型、轮廓、主石、结构和佩戴逻辑已经识别 |
| JE-B2  | 必须保留与可改动区域清楚           |
| JE-B3  | 参考图角色没有和底座图混淆          |

### **5.2 进化矩阵检查**

| **编号** | **标准**                  |
| ------ | ----------------------- |
| JE-M1  | 候选数量等于用户选择数量            |
| JE-M2  | 每个候选有稳定 evolution\_id   |
| JE-M3  | 候选之间差异清楚，不只是换颜色         |
| JE-M4  | 每个候选都包含元素、形态、风格、材质和融合策略 |

### **5.3 图片质量检查**

| **编号** | **标准**                 |
| ------ | ---------------------- |
| JE-I1  | 底座关键结构或家族相似性符合结构保留度    |
| JE-I2  | 元素主题已经珠宝化，不是平面贴图       |
| JE-I3  | 材质、宝石、镶嵌和佩戴结构真实可信      |
| JE-I4  | 候选之间有明显设计差异            |
| JE-I5  | 画面干净，无文字、logo、价格、证书或水印 |
| JE-I6  | 大胆方向仍然可佩戴，不是概念装置       |

失败处理：

* 底座漂移：提高结构保留度，重复底座身份锁，减少进化强度。
* 变化太小：提高进化强度，强化差异字段和元素主题。
* 元素贴图感强：改为纹样、镂空、浮雕、镶嵌、结构转译。
* 结构不可佩戴：补充戒臂、链条、耳针、吊环、扣具、镶口等结构约束。
* 候选重复：重写进化矩阵，锁定 A-D 的不同定位。
* 图像质量不足：结构正确后调用 image\_super\_resolution。

## **七、触发示例**

* “上传这张戒指，帮我用选择题做珠宝设计进化，先出 4 个方向。”
* “这款吊坠保留轮廓，加入东方云纹和珍珠母贝，给我 8 个进化候选。”
* “我选 A，帮我高清化并整理成最终设计档案。”
* “帮我把 B 的结构和 C 的材质整理成定稿方向说明。”
* “不要改太多，只做商业化微调。”

## **八、禁止项**

* 不把底座图当成普通风格参考而忽略结构。
* 不把参考图的整体轮廓复制到新设计中。
* 不把 4 个候选做成同一款的轻微颜色变化。
* 不生成不可佩戴、无支撑、漂浮宝石或结构断裂的珠宝。
* 不编造品牌授权、证书、克拉数、产地、价格或库存。
* 不在图片中加入文字、水印、logo、价格牌或复杂背景。
