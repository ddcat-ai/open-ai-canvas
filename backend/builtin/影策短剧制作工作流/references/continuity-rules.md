# 镜头连续性规则

## 基本模型

每个镜头都必须有：

```text
startState -> action -> endState
```

下一镜的 `startState` 必须继承上一镜的 `endState`。不能只写“继续上一镜”，必须写出可验证状态。

## 推荐空间词

只使用：画面左侧、画面右侧、画面中央、前景、后景、靠近门口、靠近桌子左侧/右侧、靠近窗户、朝画面左侧移动、朝画面右侧移动、固定摄影轴线。

避免复杂的“谁在谁前面”“从某人身后绕到另一侧”等表达。视频模型容易误解这类描述。

## 镜头衔接模板

上一镜：

```text
0-15秒。沿固定摄影轴线拍摄。角色 A 在画面右侧前景，角色 B 在画面左侧后景。两人向客栈门口移动。结束时，角色 A 停在客栈门右侧，角色 B 停在客栈门左侧。
```

下一镜：

```text
15-30秒。延续上一镜结束位置和同一摄影机轴线。开场时，角色 A 仍在画面右侧、客栈门右侧；角色 B 仍在画面左侧、客栈门左侧。保持上一镜的服装、天气和光线。角色 A 推门进入，角色 B 从画面左侧跟上。
```

## 连续性账本

建议在分镜旁建立 `FRAME-CONTINUITY-01`，每行记录镜头起始状态、结束状态和下一镜必须继承的字段。至少记录：左右位置、前后景、摄影轴线、服装、发型、伤势、道具、天气、光线、时间和空间地标。

## 连续性检查

逐镜检查：

- 左右位置是否一致；
- 前景/后景是否一致；
- 摄影轴线是否突然改变；
- 服装、发型、伤势是否连续；
- 手持道具是否连续；
- 天气、光线和时间是否连续；
- 上一镜结束动作是否成为下一镜开始动作；
- 下一镜是否引入上镜不存在的空间或道具。

发现冲突时，先输出冲突，再重写镜头；不要直接提交生成。
