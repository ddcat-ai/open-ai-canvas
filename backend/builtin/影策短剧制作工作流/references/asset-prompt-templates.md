# 资产提示词模板

## 角色三视图 turnaround

```text
同一角色三视图 turnaround 设定图。在同一张图中并排展示同一人物的正面、左侧面、背面。三个视图必须保持同一年龄、脸型、发型、妆容、身高比例、服装、颜色、材质、鞋靴和角色识别特征。三个视图大小一致，脚部位于同一水平基线。

人物采用中性站姿，双臂略微离开身体，双手空置，不做动作，不奔跑，不转身，便于查看服装和身体轮廓。纯白无缝背景，无环境、无场景、无家具。均匀平面棚拍光，全身清晰锐利。无浅景深、无电影虚化、无胶片颗粒、无烟雾、无裁切。

武器和关键道具单独生成，不在三视图中手持，除非任务明确要求道具绑定版本。
```

## 角色定妆立绘

```text
单角色全身定妆参考图，纯白无缝背景，无环境和陈设。保持已锁定角色资产的脸型、发型、服装、颜色和比例。人物正面站立，画面清晰锐利，适合作为后续镜头参考。不要改变年龄、发型或服装。
```

## 音色设定

必须记录：

```text
角色年龄感：
音高：
音色：
气息：
语速：
咬字：
情绪底色：
愤怒状态：
脆弱状态：
禁用特征：
```

音色不是“好听”或“清冷”两个词。必须能指导 TTS 和配音验收。参考音频只有在用户需要、获得授权且平台支持时建立。

## 环境母版

```text
环境空间母版图，展示完整空间布局、出入口、主要地标、人物可站区域和主光源。保持已锁定的时代、地域、材质、天气和时间。避免只生成无法复用的电影化特写。需要时分别生成日间、夜间、雨天和暖光版本。
```

## 武器/道具

```text
单件武器或道具设定图，纯净背景，正面、侧面和关键细节可见。保持尺寸比例、材质、颜色、磨损、握持位置和结构不变。不得自动增加装饰，不得改变形制。
```

## 通用负面约束

```text
不要改变角色身份，不要换脸，不要改变年龄，不要改变服装颜色，不要增加背景人物，不要改变道具形制，不要裁切全身，不要出现多余肢体，不要出现重复人物，不要使用模糊景深，不要生成电影海报构图替代设定图。
```
