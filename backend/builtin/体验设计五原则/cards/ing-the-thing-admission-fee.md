## I — 方法论骨架 (Interpretation)

两个动作，顺序不能颠倒。

**动作一：ing the thing（把名词变动词）**

不要问"我的产品怎么更好"，要问"顾客拿着我的产品/在我的场所里，真正在做的那件事是什么"，然后把那个**动词**当作真正的产出。

- 书店卖的不是书，是"读书的那个下午"。
- 胶带卖的不是胶带，是"用胶带搞事情"（ShurTech 鸭子胶带：吉祥物、20 多种颜色、胶带俱乐部、黏人达人舞会、鸭子胶带节）。
- 玩具店卖的不是玩具熊，是"亲手把一只熊做出来"（小熊工作室八阶段：挑选我/听听我/填满我/缝好我并许愿放心脏/摸摸我/起名字发出生证明/穿衣服/装进房子形状的纸盒回家）。

两条体验化路径：
1. **在既有环节里找被忽略的动词**（JoAnn 织物店把"您需要点什么"改成"您想买点产品做什么用呢"；西南航空让空乘唱着播安全须知）；
2. **造一个从来不存在的新动词**（海鸟观察游、野外高尔夫、TopGolf 的球内芯片实时排行榜、Zorb 滚球）。作者明确说：**人们更容易从新的构词表达里想出新的体验方式**——所以造词本身就是生产力。

**动作二：为这个动词单独收费**

这是全书最反直觉的一条。常识是"体验免费，用来引流卖货"；本书主张恰恰相反：

- 不单独收费，顾客会把体验当成理所当然的赠品，然后回头抱怨"你东西太贵"。
- 更致命的是**设计动机被摧毁**：不收门票的店，全部动机都指向"如何让人买东西"；一旦收了门票，动机被强制重置为"如何值回票价"——被迫每天换陈列、上表演、办竞赛、做会员试用。
- 因此收费同时是一个**可证伪的判据**：如果没有人愿意为它单独付一分钱，那它就还不是体验，只是促销。

收费的六种形式（图 3-1，两轴 = 衡量方式 × 活动类型）：

| | 特定活动 | 公开活动 |
|---|---|---|
| 预先型 | **入场收费**（影院、演出、赛事、展销会） | **启动式收费**（入会费、社群准入） |
| 活动型 | **按活动收费**（投币游戏、竞赛、研讨会） | **访问式收费**（后台参观、新手费、测试期费、试用会员） |
| 期间型 | **按期间收费**（订阅、场地使用、俱乐部会费） | **会员式收费**（协会、联盟、论坛年费） |

## A1 — 书中的应用 (Past Application)

### 案例 1：新池塘农场的 146 美元生日会（第1章 p057-p058）
- **问题**：生日蛋糕这门生意，价值链上还能往哪儿走？
- **方法论的使用**：从原料（几十美分）→ 蛋糕粉（1-2 美元）→ 蛋糕店订购（10-20 美元）→ **把"过生日"这件事本身承办下来并收费**。伊丽莎白·派恩 7 岁生日，14 个朋友刷牛、喂鸡、做苹果酒、坐干草车。
- **结论**：账单 146 美元，**且不含蛋糕**——蛋糕已降格为体验的道具（作者用它证明"上一级产出会变成下一级的免费赠品或原料"）。
- **结果**：同一个"生日"，收费提高两个数量级，靠的不是蛋糕做得更好。

### 案例 2：美国女孩娃娃店（第1章 p059-p060）
- **问题**：一家卖娃娃的零售店，怎么让人待下来？
- **方法论的使用**：把"陪娃娃过一天"体验化并逐项定价——娃娃美发厅（20 美元）、照相馆（20 美元、可做《美国女孩》杂志封面）、咖啡餐厅（17-26 美元/人）、生日会（32 美元/人，豪华 50-65）、晚间活动（200-240 美元/女孩）、娃娃医院挂号。
- **结论**：平均逗留 **4 小时以上**。作者的结论句："在今日的体验经济中，体验本身就是营销。"
- **结果**：体验不是获客成本，而是收入项 + 获客手段的合体。

### 案例 3：耐克城的反问（第3章 p107）
- **问题**：耐克城开幕就宣称"这家店是一个舞台，消费者即观众"，为什么它仍然只是一家店？
- **方法论的使用**：作者追问"为什么不收门票"，并推演如果收了会发生什么：与 NBA 退役球星单挑、与 WNBA 球员打 HORSE 投篮赛、现场定制印着你投篮照片和当日比分的 T 恤、互动宣传亭。
- **结论**：这些设计不做，不是因为想不到，而是因为**没有收门票所以没有动机**。
- **结果**：作者把"忽略对体验收费"列为一串零售商的死因：Imaginarium、Just for Feet、The Nature Company、Oshmans 倒闭；FAO Schwarz、Eddie Bauer 苦苦挣扎。

### 案例 4：迪士尼零售店的失败（第3章 p115）
- **问题**：装潢投入巨大、IP 顶级的迪士尼零售店，为什么做不成体验？
- **方法论的使用**：作者拆开看信号——白雪公主城堡电梯里放喧闹摇滚乐（信号与主题冲突）、扮成动画人物的员工互相闲聊不忠于角色（"还称不上是演职人员"）。
- **结论**：作者归因非常明确——**执行不佳正是没有对体验收费导致的**。免费的体验没人为它的质量负责。
- **结果**：迪士尼退出零售店业务。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

0. **免费的前置过程被白嫖**：免费方案、免费提案、免费打样、免费诊断、免费试听——做完客户拿去比价或自行落地。这段过程恰恰是顾客真正在消费的东西，却从没被定义成一件可售商品（典型的"没有 ing the thing"）。
1. **线下空间活不下去**：书店、咖啡馆、买手店、画廊、健身房客流尚可但不赚钱，想"加点体验"。
2. **产品同质化且无法涨价**：想做增值但只能想到"送赠品/加服务"。
3. **纠结体验要不要收费**：老板/团队坚持"收了钱就没人来了"，需要一个判断框架而不是直觉对撞。
4. **做了体验但没人记得**：快闪、市集、发布会办完就散，没有沉淀也没有收入。
5. **社群/内容想变现**：知识博主、播客、UP 主广告收入见顶，找不到第二条曲线。
6. **新品类命名**：想给一个新玩法起名字（造词即造体验，本书明确主张）。
7. **接在定级之后**：`economic-value-progression` 判定"该升到体验级"之后，本 skill 是第一个落地动作。

### 语言信号 (用户的话里出现这些就应激活)

- "想把体验感做起来 / 加点沉浸式的东西"
- "免费体验引流，再转化成交"
- "客流不少但不赚钱 / 转化率上不去"
- "要不要收门票 / 收了会不会没人来"
- "会员费 / 入场费 / 年卡 / 门票定多少"
- "快闪店怎么做 / 线下店还有没有必要开"
- "展览/市集/发布会办完就没了"
- "experience design" / "admission fee" / "free trial to convert" / "paywall the experience"

### 与相邻 skill 的区分

- 与 `economic-value-progression` 的区别：那个是**定级与选方向**（我现在在第几级、要不要升）；本 skill 是**升到"体验"这一级的具体落地手法**（把什么变成动词、怎么收第一笔钱）。
- 与 `charge-unit-redesign` 的区别：那个覆盖五档计价单位的全谱系选型（含向下移）；本 skill 只处理一个特定跃迁——把体验从捆绑价里拆出来单独收费。
- 与 `four-realms-experience-scan` / `experience-design-five-principles` 的区别：本 skill 决定**做不做、收不收钱**；那两个决定**体验内容长什么样**。本书明确的先后是：先设计出值得掏钱的体验，收费是最后一步——但**决定要收费这个念头必须在设计之前发生**，否则设计动机不成立。
- 与 `zero-price-transaction-utility`（如已装）的区别：那个讲"免费"对顾客心理的放大效应（需求侧）；本 skill 讲"免费"对供给方设计动机的摧毁效应（供给侧）。两者不矛盾，且正好构成一组张力——免费确实拉需求，代价是杀掉质量动机。
- 与 `positioning-*` 系的区别：那些解决"在心智里占什么位置"；本 skill 解决"卖的到底是什么"。

## E — 可执行步骤 (Execution)

1. **写出顾客真正在做的那个动词**
   - 句式："顾客花了这段时间在 ______（动词短语）。"
   - 不接受名词答案。"买书"不算（那是交易动作），"在这里度过一个安静的下午"才算。
   - 完成标准：动词能被一个外人复述，且他能想象自己在做这件事。
   - 判停条件：如果这段过程顾客只想尽快结束（办证、报销、退换货），**它是成本不是体验，本 skill 不适用**，转 `charge-unit-redesign` 往下移档。

2. **给这个动词起个名字（造词）**
   - 新词能让人自发想出新玩法（本书明确主张）。"购物游""黏人达人舞会""奥德赛电影之旅"都是造词。
   - 完成标准：名字里含动词或可动词化，且不是行业通用词。

3. **做收费的思想实验（关键一步，不要跳过）**
   - 问："如果从明天起进门就收 X 元，我们必须做什么才对得起这 X 元？"
   - 把答案全部列出来——**这份清单就是你的体验设计任务书**。
   - 完成标准：清单里至少有 3 条是现在完全没做的事。
   - 若清单写不出来或全是"服务态度更好"，说明动词选错了，回到步骤 1。

4. **选收费形式（对照图 3-1 六格）**
   - 特定活动 × 预先型 = 入场费；× 活动型 = 按次；× 期间型 = 按时段/订阅。
   - 公开活动 × 预先型 = 启动费/入会费；× 活动型 = 访问费/试用费；× 期间型 = 会员年费。
   - 完成标准：明确选中一格，并写出计价单位（详见 `charge-unit-redesign`）。

5. **设计抵扣桥（降低第一次付费的阻力）**
   - 洛杉矶步行街用停车费当入场费、消费可返；Chick-fil-A 用"前 100 名免费一年"把排队变成体验。
   - 抵扣不是打折，是**让顾客敢于付第一笔**，同时保留"付过费"这个心理事实。
   - 完成标准：抵扣规则一句话说清，且抵扣后仍保留可感知的付费动作。

6. **上线"值回票价"的更新节奏**
   - 收了钱就必须像剧院一样定期换节目（中美节日体验公司在同一场地轮换文艺复兴节/万圣节/圣诞宴会）。
   - 完成标准：写出更新频率与责任人。**没有更新节奏的收费体验，会在第二次到访时死掉**（见 B 段主题餐厅通病）。

7. **验证**
   - 唯一有效指标：**有没有人愿意为它单独付钱，以及有没有人第二次来付。**
   - 完成标准：跑满两个周期，看复购而非首购。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **顾客把该环节视为纯成本**（缴费、报销、就医排队、退货）：这里的正确方向是压缩甚至消灭时间，不是收费。强行"体验化"会变成折磨。
- **刚需高频低毛利品类**（便利店、加油、日用补货）：本书自己的反例就在这——把它体验化会同时抬高成本与顾客耗时。
- **B2B 采购中的合规环节**：付费门槛可能触碰商业贿赂/招投标规则。
- **收费能力尚未建立就先收费**：本书明确顺序是"先设计出值得掏钱的体验，收费是最后一步"。跳过设计直接收费 = 赶客。
- **用户问的是定价数字**（收多少合适）→ 转 `reference-price-framing` / `arbitrary-coherence-pricing`。

### 作者在书中警告的失败模式

- **DiscoveryZone 破产**（p062）：作者归因"无法持续营造体验活动，游戏开发能力太差，很少顾及那些负责付费的成人的体验"。收了钱却不更新 = 死得更快。
- **Planet Hollywood 大量关店**（p062）：无法更新体验内容。
- **主题餐厅通病**（p062）："顾客经常发现第二次再来和初次到访的体验毫无变化。"
- **迪士尼明日世界**（p062）：几十年不变，最终不得不投几十亿改造加州探险乐园。
- **免费体验的执行崩塌**：迪士尼零售店案例——不收费 → 无人为质量负责 → 员工出戏、信号冲突 → 退出业务。

### 作者的盲点 / 时代局限

- **案例全部来自 1990s 末美国的线下零售与主题餐厅**（耐克城、FAO Schwarz、美国女孩娃娃店、文艺复兴节）。**这些案例已过时，数字化与线上语境下必须重新检验**；但"收费重置设计动机"这一机制在订阅制、付费社群、付费展、Steam 抢先体验、知识付费上被反复印证，机制本身仍然成立。
- **⚠️ 免费模式的成功被系统性忽略**。本书成书于 1999 年，此后 20 余年最大的商业事实之一是**免费 + 广告 / 免费增值（freemium）建立了世界上最大的一批公司**。"不收费的体验不算体验"这句强断言在互联网产品上直接被证伪。
  **可用的修正版本是**：收费不是唯一的动机装置，但你**必须有某个装置逼迫自己对体验质量负责**——收费是最直接的一种，留存率/DAU/NPS 挂考核是另一种。真正致命的是既不收费又没有替代性质量约束。
- **未处理"付费墙杀掉网络效应"**：书中所有例子都是物理空间，容量有限，收费天然筛选人群；线上产品收费会直接切断规模效应与传播，这个代价书里完全没有讨论。
- **"造词即造体验"缺乏失败样本**：作者只举成功造词，没有讨论大量自造名词无人接受的情况。
- **共创视角缺失**（作者自己在珍藏版序言承认）：全书站在营造者角度，"体验化"是营造方设计给顾客的，而 UGC / 共创模式下体验由用户自己造出来，这套框架不完全适用。

### 容易混淆的邻近方法论

- **增值服务/会员权益设计**：那是在既有产出上叠加福利；本 skill 是**换掉产出本身的种类**（从卖东西变成卖过程）。
- **场景营销**：那讲在什么场景触达顾客（沟通问题）；本 skill 讲把场景本身做成收费产出（产出问题）。
- **免费增值（freemium）**：与本 skill 直接冲突（见时代局限）。选择时的分界线是：**边际成本近零 + 强网络效应 → freemium；边际成本高 + 容量有限 + 体验质量靠现场执行 → 收费。**
