## I — 方法论骨架 (Interpretation)

### 前提：这是本体判断，不是修辞

英文 drama 源自希腊语 **drao = "去做"**。作者明确拒绝"商业比喻风"（"我们没兴趣和大象一起跳舞、和鲨鱼一起游泳、推翻金字塔、寻找蓝海"），坚持工作在本体上**就是**表演——只要有人在看，就有表演；区别只在于**排练过还是没排练过**（戈夫曼）。

这个前提之所以重要：一旦承认它是模式而非比喻，戏剧领域两百年积累的结构工具就可以**直接搬过来用**，而不必打折扣。

### 工具一：弗莱塔克七阶段（时间结构）

（布兰达·劳瑞尔《计算机式舞台》把 19 世纪弗莱塔克三段式扩为七阶段）

| 阶段 | 作用 | 面客流程里对应什么 |
|---|---|---|
| A 引子 | 介绍人物与背景 | 进入前的环境、迎接、第一句话 |
| B 诱导事件 | 设定情节，把人卷进来 | 那个"让他决定投入注意力"的时刻 |
| C 上升情节 | 快速增加可能性与强度 | 主体内容推进 |
| D 转折点 | 增强活动与障碍 | 难点、反对意见、真正的问题浮现 |
| E **高潮** | 众多线索中只有一条抵达顶点 | 不可替代的峰值时刻 |
| F 下降情节 | 后续结果 | 收束、消化、确认 |
| G 结局 | 线索收拢，回归常态 | 离场设计、余韵、下一步 |

**失败判据（可直接拿来诊断）：三角太平缓，或高潮出现得太早/太晚。**

大多数商业流程的病相同：**只有 C（一路讲下去），没有 B、E、G。**没有把人卷进来的那一刻，没有峰值，没有结尾。

作者用它解释了两件事：速溶咖啡为什么打不过现煮（哪怕一次只煮一杯）；人们为什么一大早排队等特制咖啡——星巴克把喝咖啡变成"值得珍视的小众行为"。作者的点评很诚实："从服务的角度说此举不敢恭维，但从营造体验的角度说星巴克确实做得很出色。"

> 作者在珍藏版序言里补充了一句关键的话：**"如果无法充分建立合适的背景，无法交错表现增效作用，无法形成前后冲突的剧情，无论你制造的体验高潮多么令人兴奋，观众对表演的回忆还是会大打折扣。"**——峰值不能孤立存在。

### 工具二：谢克纳四层（责任结构）

| 戏剧层 | 定义 | 企业对应 | 归属者 |
|---|---|---|---|
| **戏剧 drama** | 写好的文本/计划，任何时间地点任何表演者都可上演 | **战略** | 战略家、总裁 |
| **剧本 script** | 预先存在于舞台现实之前的事件记录 | **流程** | 经理、团队领导 |
| **演出 theatre** | 由特定表演者扮演的活动事件 | **工作** | 一线员工 |
| **表现 performance** | 从第一个观众入场到最后一个离场之间的全部事件 | **产出** | 顾客所得 |

通式：**[戏剧=战略] → [剧本=流程] → [演出=工作] → [表现=产出]**

用途：出问题时**先定位在哪一层**。表现不好，可能是演出层（人不行）、剧本层（流程没写好）、也可能是戏剧层（战略本身就没内容）。绝大多数公司默认往演出层归因（怪员工），这是最常见的误诊。

剧本层还有一条特殊要求：员工必须**读出潜台词**（战略中未明说的观点），必要时修改剧本。"剧本必须对戏剧做出解释说明，忠实于戏剧的本来意图，以意外的方式对观众期望进行最大程度的开发。"

### 工具三：亚里士多德的三组设计追问

1. **选择（最重要）**：**哪些行为该在台上、哪些该在台下？**
   （反例：菜市场售货员隔着过道互喊下班去哪玩——对她们无所谓，对顾客就是"漠不关心"。正解是把熟练扫码的能力、请出示信用卡时的语调措辞、递现金/卡/小票的方式当作台上动作来设计。）
   作者提醒："最重要的问题往往是那些很难马上做出回答，但是你又深知其答案会给员工表现带来重大价值的问题。"
2. **顺序、进展与持续时间**：从哪里开始、在哪里到高潮、在哪里收尾。（销售老话："销售完成，闭嘴收工。"）
3. **节奏与速度**：如何设定不同节奏并管理增强、减弱、对比与释放。（联邦快递员工永远在奔跑以传达速度；高级餐厅女招待**通过察言观色暗中操作**决定何时上菜、何时撤盘、何时递账单，而不是一遍遍询问顾客。）

### 工具四：目的感（intention）与特征刻画

- **每个动作都必须有目的。**同一个"敲门"动作，在"表示我到了""为迟到道歉""来了但不想打扰""提醒会议要开始"四种目的下完全不同。
- 反转常识（埃里克·莫瑞斯，曾帮杰克·尼克尔森塑造角色）："多年来，演艺界有一个普遍看法，认为演员应当融入角色……**但是我的看法完全相反，我认为应当让角色融入你才对。**"
- 缺乏特征刻画的后果就是"表现看起来像机器人"（酒店前台单调的欢迎词、餐厅服务员的老三句）。
- 最低技术含量的岗位同样可以靠目的感成为难忘表演：宾大山顶区宿舍餐厅的芭伯，全部工作只是刷学生餐卡（绿灯有余额、红灯不足），却成为许多学生整个大学期间印象最深的工作人员。

## A1 — 书中的应用 (Past Application)

### 案例 1：芭芭拉·史翠珊的口香糖（第6章 p156）
- **问题**：试演《如君所愿》，怎么在开口前就抓住全场？
- **方法论的使用**：迟到、艳丽毛皮大衣、两只不同的鞋（说旧货店只有一只合脚）、不停嚼口香糖；坐上凳子唱两句停下、把口香糖黏到凳子底下再正式开唱。
- **结论**：散场时导演劳伦茨摸凳子底下——**根本没有口香糖**。全程是设计过的表演。
- **结果**：作者的结论句："无论在什么场合，你的每一个微小的动作都会为最终营造出来的体验加分。"这同时驳斥了"只有全部展现出来的才是真实"——真口香糖不会更真实，关键在于"是否应当使用特定的道具来影响特定的观众印象"。

### 案例 2：雅各布球场的清洁工（第6章 p158）
- **问题**：1.75 亿美元新场馆，为什么克利夫兰印第安人队成了而别队没成？此前季票年销不到 5000 张。
- **方法论的使用**：管理层意识到"新场馆也可以为棒球比赛之外的表演提供精彩的舞台"。正式赛前两天的演示赛当作**彩排**；东九大街入口外，**一个清洁工在崭新、根本没有垃圾的人行道上不停扫地**。
- **结论**：这和史翠珊的口香糖同理——纯粹是表演，为了向首次到场的球迷传达清洁、安全、舒适、激动人心，服务于新主题"这里就是你的家"。
- **结果**：连续 **455 场满座**（43368 座）。

### 案例 3：台下也是演出（第6章 p166）
- **问题**：后厨、码头、内部汇报这些顾客看不见的地方，需不需要按演出管理？
- **方法论的使用**：作者主张需要，理由是**内部行为必然外溢到付费顾客身上**；并引"言行一致"这句老话，指出它的潜台词就是"必须有观众监督"。
- **结论**：戈夫曼（《日常生活中的自我呈现》，1959）区分"愤世嫉俗的表演者"（喜欢迷惑观众）与"真诚的表演者"（相信可以利用个人表演改善他人印象）——"所有的人类活动都是表演，唯一的区别是有些表演是经过'彩排'的，有些是纯粹自发的"，并主张对行动行使"**表现控制**"。

### 案例 4：派克鱼市与 FISH! 四原则（第6章 p169）
- **问题**："表演"是不是就意味着假扮别人？
- **方法论的使用**：作者指出派克鱼市的员工"并没有假扮别人，他们本来就是普通的鱼贩"，只是在鱼市这个舞台上演一出大戏。ChartHouse 培训公司据此拍《鱼市传奇》总结四原则：玩耍 / 每天制造快乐 / 心无杂念（改编自斯坦尼斯拉夫斯基"关注当下"）/ 选择你的态度。
- **结论**："正如亚里士多德第一个指出的，表演的本质是做出各种选择。"
- **结果**：作者给出**行动第一步**（低成本、可立刻做）：审视公司内部活动，**指定一个场所作为表演舞台，然后对外宣布"这里就是我的舞台"**。

### 案例 5：微观道具——名片与姓名（第6章 p173）
- **问题**：同公司员工的名片只有姓名职务电话不同，说明了什么？
- **方法论的使用**：作者评"这种感觉就好像舞台上所有的表演者都是临时演员一样"，是规模化生产思维的残留。改法：一人携带多张代表不同角色的名片；开会时现制名片适配场合。
- **结论**：另一例——某大型计算设备制造商呼叫中心规定每个客服代表必须使用**不重名**的姓名（同名者后入职的另起一名），以便顾客多次来电时能找回同一个人。
- **结果**：道具层面的微小设计直接改变了顾客能否建立关系。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **培训/课程学员反馈"还行但记不住"**，而内容质量本身没问题。
2. **会议/评审/汇报开完什么也没留下**。
3. **直播/短视频/播客节奏平**，观众中途划走。
4. **销售拜访/客户会谈流程混乱**：不知道该先说什么、什么时候收。
5. **门店接待/就诊/办事流程"都对但体验差"**。
6. **活动/发布会/年会流程设计**：需要起承转合而不是环节堆砌。
7. **员工"像机器人"**：话术都对，但没有目的感。
8. **要判断问题出在战略/流程/执行哪一层**（谢克纳四层）。
9. **决定哪些动作该被顾客看见**（台上台下划分）。

### 语言信号 (用户的话里出现这些就应激活)

- "讲完就忘 / 记不住 / 没有记忆点"
- "平铺直叙 / 流水账 / 没有起伏 / 没有高潮"
- "会开完了，什么也没留下"
- "流程都走完了，但体验就是不好"
- "员工说话像机器人 / 老三句 / 背话术"
- "培训效果不好 / 学员当时很嗨，回去就没了"
- "客户中途走神 / 观众划走 / 中途退场"
- "哪些事该让客户看见"
- "narrative arc" / "drama structure" / "peak-end" / "stagecraft"

### 与相邻 skill 的区分

- 与 `four-performance-forms` 的区别（最紧的一组）：本 skill 处理**一段体验的时间结构与责任分层**（怎么起、怎么到高潮、怎么收；问题在哪一层）；那个处理**用哪种表演形式**（剧本该多死多活：即兴/戏台/搭配/街头）。通常先用本 skill 排结构，再用那个选形式。
- 与 `casting-and-characterization` 的区别：那个处理**谁来演、以什么面貌演**（选角与特征）；本 skill 处理**演什么、按什么顺序演**。本 skill 的"目的感/特征刻画"只是引入，完整方法在那个 skill。
- 与 `experience-design-five-principles` 的区别（★易混）：那个是**空间与信号维度**（主题、线索、纪念品、五感、动线、陈列——横截面）；本 skill 是**时间维度**（起承转合——纵剖面）。**硬判据：问句里出现「怎么摆 / 怎么布置 / 动线 / 陈列 / 放什么 / 删什么」→ 五原则；出现「怎么排 / 先后顺序 / 起伏 / 高潮 / 收尾 / 节奏」→ 本 skill。动线虽带先后感，但用户要的是空间布置方案，默认归五原则。** 两者正交，通常合用：五原则管"这一刻看到什么"，戏剧结构管"这些时刻怎么排列"。
- 与 `four-realms-experience-scan` 的区别：那个诊断**缺哪一维体验**；本 skill 诊断**时间结构塌了**。用户说"没意思" → 先 4E；说"记不住" → 本 skill。
- 与 `ra-hook` / `dbs-hook` 的区别（★易混）：那些专攻**开头几秒如何抓住人**（弗莱塔克的 A+B 两阶段，且专用于短视频）；本 skill 覆盖**完整七阶段**，尤其强调多数人忽略的 E（高潮）与 G（结局）。做短视频开头 → 那些；做一段有时长的完整体验 → 本 skill。
- 与 `emotion-action-beats` 的区别：那个把一种情绪写成带时间过程的表演节拍（用于 AI 提示词/表演生成）；本 skill 是组织与服务流程的结构设计。同源不同域。
- 与 `billboard-scan-design` 的区别：那个是几秒扫视的信息设计；本 skill 是长时段的叙事设计。

## E — 可执行步骤 (Execution)

1. **划定"从第一个观众入场到最后一个观众离场"的范围**（谢克纳对"表现"的定义）
   - 起点通常比你以为的早（路上、等待、预约确认），终点通常比你以为的晚（离场、回家、第二天）。
   - 完成标准：写出明确的起止时刻，且包含至少一段你原来不认为属于这个流程的时间。

2. **画现状的弗莱塔克曲线**
   - 把现有流程按时间排开，为每一段标注"观众此刻的紧张度/投入度"（凭判断即可，1-5 分）。
   - 完成标准：得到一条曲线。**几乎必然是一条平线或前高后低的斜线。**
   - 判停条件：若曲线本来就有清晰的高潮与结局而问题依旧，本 skill 不适用，转 `four-realms-experience-scan`（维度问题）或 `casting-and-characterization`（执行问题）。

3. **补 B（诱导事件）：找到"卷进来"的那一刻**
   - 问："哪一刻他从旁观者变成了参与者？"
   - 没有 → 造一个：一个提问、一次选择、一个交到他手上的东西、一个只对他生效的事实。
   - 完成标准：能指出具体时刻，且它在整段流程的前 15% 内。

4. **定 E（高潮）：只能有一个**
   - "众多线索中只有一条抵达矛盾顶点"——**高潮唯一**。三个高潮等于没有高潮。
   - 检查位置：太早 → 后面全是下坡；太晚 → 前面全是铺垫，人已经走了。经验位置在 60%–80% 处。
   - 完成标准：能一句话说出"这段体验的峰值时刻是 ______"，且团队里三个人给出同一个答案。

5. **补 G（结局）：设计离场**
   - 大多数流程在高潮后直接结束（甚至在高潮前就结束）。补：收束、确认、纪念品交付（见 `experience-design-five-principles` 第四原则）、下一步预告（悬念）。
   - 销售老话可作判据："销售完成，闭嘴收工"——**结局是收拢，不是加戏**。
   - 完成标准：结局动作明确，且不引入新信息。

6. **做台上/台下切分（亚里士多德第一问）**
   - 逐个动作问："这个该被顾客看见吗？"
   - 三类必须移到台下：后台协调、内部争论、为自己方便而做的事。
   - 一类要主动移到台上：**能力的展示**（熟练操作、专业判断、准备工作）——顾客看不见的努力等于不存在。
   - 完成标准：得到一份台上/台下清单，且至少各有一项发生了移动。

7. **给每个台上动作赋予目的（intention）**
   - 句式："我做这个动作，是为了让对方感到 ______。"
   - 填不出来的动作 = 机械动作，删掉或重设计。
   - 完成标准：台上动作 100% 有目的说明。

8. **用谢克纳四层做归因复盘**
   - 表现不好 → 依次上溯：是演出层（人没演好）？剧本层（流程没写这一段）？还是戏剧层（战略本身没有内容可演）？
   - 完成标准：明确归到某一层，并**避免默认归到演出层**。
   - 注意：若战略层是空的（"我们要提升客户体验"这类无内容战略），下游怎么演都没用。

9. **排练**
   - 雅各布球场把赛前演示赛当彩排。任何新流程上线前至少走一遍完整的、有人扮演顾客的排练。
   - 完成标准：排练过，且改了至少一处。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **顾客只想尽快结束的流程**：戏剧结构会拉长它。缴费、报销、退货、急诊分诊，正确目标是消灭而非设计起承转合。
- **纯异步、无连续时间的触点**（邮件、工单、通知）：没有"从入场到离场"的连续时段，七阶段不成立。
- **高风险严肃场景的核心环节**（手术、飞行操作、事故处置、司法程序）：这些环节的正确形式是清单与规程，不是戏剧结构。作者的医患案例只动了"说明情况的方式"，没有动医疗决策本身——这个界限要守住。
- **问题在内容质量本身**：结构救不了空洞。若内容确实不成立，先补内容。

### 作者在书中警告的失败模式

- **三角太平缓，或高潮太早/太晚**——这是作者给出的唯一显式失败判据。
- **只有高潮没有铺垫**（珍藏版序言）："如果无法充分建立合适的背景，无法交错表现增效作用，无法形成前后冲突的剧情，无论你制造的体验高潮多么令人兴奋，观众对表演的回忆还是会大打折扣。"
- **该在台下的事在台上做**：菜市场售货员隔着过道互喊下班安排。
- **没有目的感的动作**："如果没有目的，只是为了完成工作而做，可想而知这项工作的表现会有多么乏味。"
- **机器人式表现**：酒店前台单调的欢迎词、餐厅服务员的老三句——这是缺乏特征刻画的症状。
- **名片式的临时演员感**：所有人的道具都一样，等于宣布所有人都可互换。

### 作者的盲点 / 时代局限

- **案例来自 1990s 末的线下服务场景**（球场、餐厅、鱼市、呼叫中心、名片）。**案例已过时，数字化与远程语境下需重新检验**；但弗莱塔克七阶段与谢克纳四层是结构工具，在直播、线上课、游戏关卡、发布会、播客上直接可用，且**峰终定律（Kahneman）后来为"高潮 + 结局决定记忆"提供了独立的实验证据**——这一点作者当年并不知道，反而强化了框架。
- **⚠️ "工作即演出"的员工代价被系统性忽略**。全书站在营造者与顾客立场，几乎不谈**情绪劳动**（Hochschild《被管理的心》，1983，早于本书 16 年）——要求员工全程"在角色内"、"表现得好像工作就是你的生命"，会产生真实的情绪耗竭与自我疏离。**这是本书最大的伦理盲点**，使用时必须自补：给演员留下台下空间与真实的休息区，是这套方法可持续的前提。
- **"所有人类活动都是表演"过于普遍化**：戈夫曼的原始论述有社会学限定，作者把它当作管理授权使用，滑向了"一切都可以被设计和控制"。
- **未讨论真诚与表演的冲突**：作者用"糟糕的演员≠演出本身"来回避，但顾客识破"设计过的自然"时的反噬（今天在社交媒体上极常见）没有处理。参见 `honest-fake-authenticity`。
- **未处理排练成本**：所有案例都假定可以排练，没有讨论高流动率、低时薪岗位的现实约束。
- **共创视角缺失**（作者珍藏版序言自认）：观众被假定为被动接受表演的人，UGC 与互动直播中观众也在演。

### 容易混淆的邻近方法论

- **用户旅程地图（Customer Journey Map）**：画的是触点与流程（有没有），弗莱塔克画的是**强度曲线**（有多强）。旅程地图上一切齐备的流程，戏剧结构上可能是一条平线。两者叠用最好。
- **峰终定律（peak-end rule）**：与本 skill 的 E + G 高度一致，但它是**事后记忆规律**（描述性）；弗莱塔克是**事前设计工具**（规范性），且多出 B（诱导事件）与铺垫的要求。
- **故事营销 / StoryBrand**：那讲对外传播的叙事（顾客是主角、品牌是向导）；本 skill 讲**现场发生的过程本身**的结构。一个是说给他听，一个是让他经历。
- **服务蓝图**：它的前台/后台分界线正是本 skill 的"台上/台下"，可直接借用；但蓝图不含时间强度维度。
