## I — 方法论骨架 (Interpretation)

任何生意的产出都可以被定级到五个离散台阶上：**初级产品（commodity）→ 产品（goods）→ 服务（services）→ 体验（experiences）→ 变革（transformations）**。

这五级不是"好坏"排序，而是**买卖关系的性质**在变：

| 级别 | 顾客买走的是 | 卖方角色 | 买方称谓 | 产出性质 |
|---|---|---|---|---|
| 初级产品 | 自然物本身 | 交易商 | 市场 | 可互换 |
| 产品 | 有形的东西 | 制造商 | 用户 | 有形 |
| 服务 | 别人替你做的动作 | 提供商 | 客户 | 无形 |
| 体验 | 一段值得回忆的时间 | 营造商 | 宾客 | 可回忆 |
| 变革 | 他自己的改变 | 引导商 | 渴望者 | 有效果 |

三条关键机制：

1. **上一级的产出会降格为下一级的原料。** 体验以服务为舞台、以商品为道具；变革以体验为原料。所以升级不需要抛弃现有资产，只需要把它们**从主角改为素材**。
2. **每上一级，差异化程度与定价能力跃升一个数量级，且定价与成本脱钩。** 咖啡豆的 1000 倍价差里，原料完全相同——这排除了"成本决定价格"的解释。
3. **不主动上台阶，就被初级产品化（commoditization）拖下去。** 这不是竞争加剧，是经济引力。

**最有诊断价值的一句话**：绝大多数"卖不上价"的根因，是**你在用上一级的成本，卖下一级的东西**——你付出了体验级的心血，却按服务级收款。

## A1 — 书中的应用 (Past Application)

### 案例 1：咖啡的五段定价
- **问题**：同一份咖啡豆，为什么价格能差 1000 倍？
- **方法论的使用**：作者把咖啡沿五级台阶逐段定位，指出每一级顾客买走的东西不同：豆子（初级产品）→ 罐装咖啡（产品）→ 餐馆代冲（服务）→ 星巴克的"剧院般氛围"（体验）→ 圣马可广场 Florian 咖啡馆的威尼斯老城时光（也是体验，但主题与场地稀缺性拉满）。
- **结论**：价格是台阶的函数，不是成本的函数。
- **结果**：这个例子成为整个体验经济论述的地基，也解释了星巴克为何能在咖啡这一典型初级产品上建立全球溢价。

### 案例 2：新池塘农场的生日会（146 美元）
- **问题**：生日蛋糕生意如何摆脱几十美分的原料利润？
- **方法论的使用**：原料（几十美分）→ 蛋糕粉（1~2 美元）→ 蛋糕店订购（10~20 美元）→ Chuck E. Cheese's 承办生日体验（100~250 美元）。作者女儿伊丽莎白 7 岁生日在新池塘农场，14 个朋友刷牛、喂鸡、做苹果酒、坐干草车。
- **结论**：农场把"当一天农夫"做成收费产出，蛋糕反而降格成自带的道具。
- **结果**：账单 146 美元（不含蛋糕）。一个农场用完全既有的资产（牛、鸡、苹果、干草车）跨过了三级台阶。

### 案例 3：保险的三级跳（图 9-2）
- **问题**：一个高度受监管、看似毫无体验空间的传统行业还能怎么升级？
- **方法论的使用**：卖保单（产品）→ 卖理赔服务（服务）→ 卖风险管理体验（体验）→ 卖"你不会出事"的保证（变革：改变投保人的行为与风险状况）。
- **结论**：收费对象从赔付金额转向结果，产出从"补偿损失"转向"让损失不发生"。
- **结果**：作者用它证明递进阶梯不限于零售与休闲行业。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **报价被压 / 只被问价格**：客户拿几家报价单横向比较，除了降价说不出别的理由。
2. **同质化焦虑**：产品/服务本身不差，但和同行看起来没区别，被迫卷价格。
3. **想涨价但不知道涨的理由**：成本上升或想提利润，却找不到能说服顾客的依据。
4. **利润越做越薄**：营收在涨，毛利在跌，越努力越像在打工。
5. **在做商业模式设计或转型规划**：要判断"我们下一步该往哪个方向长"。
6. **自由职业者/独立创作者的定价困境**：明明水平不差，报价却上不去。
7. **传统行业转型讨论**："我们这行没什么体验可做"——正是本 skill 要检验的假设。

### 语言信号 (用户的话里出现这些就应激活)

- "客户只关心价格 / 只问多少钱"
- "我们和同行没什么区别 / 同质化太严重"
- "怎么提升附加值 / 怎么做溢价"
- "价格战打不动了 / 利润越来越薄"
- "我这行就是这样，做不出差异"
- "要不要涨价 / 涨价了客户会跑吗"
- "commoditization" / "price war" / "how do we differentiate" / "can't raise prices" / "race to the bottom"

### 与相邻 skill 的区分

- 与 `charge-unit-redesign` 的区别：本 skill 判断**卖哪一级**（战略定级）；后者改**以什么单位收款**（执行杠杆）。先用本 skill 定级，再用后者落地。
- 与 `ing-the-thing-admission-fee` 的区别：本 skill 覆盖全部五级；后者只处理"服务 → 体验"这一跨越，且聚焦于"是否单独收费"这一个动作。定级结果如果是"该升到体验级"，就转到后者执行。
- 与 `reference-price-framing` / `arbitrary-coherence-pricing` / `price-context-priming` 的区别：那几个处理**同一个价格数字如何被感知**（价格框架）；本 skill 处理**你到底在卖哪一级东西**（产出定级）。数字怎么摆是术，卖哪一级是道。
- 与 `positioning-*` 系列的区别：定位解决"在顾客心智里占哪个位置"，是相对于竞争对手的坐标；本 skill 解决"经济产出属于哪一级"，是相对于顾客所买之物的性质。两者正交，可叠加使用。

## E — 可执行步骤 (Execution)

1. **先问"顾客付钱后带走了什么"，而不是"我们提供了什么"**
   - 用顾客的第一人称复述："我花了 X 元，得到了 ______。"
   - 完成标准：这句话能被填成一个具体名词或事件，而不是一堆功能罗列。

2. **定级：把它对到五个台阶之一**
   - 带走的是自然物/原材料 → 初级产品；是有形成品 → 产品；是别人替他做的动作 → 服务；是一段值得回忆的时间 → 体验；是他自己的改变 → 变革。
   - 判停条件：若顾客带走的是"他自己的改变"（学会、变健康、拿到结果、成为某种人），**直接跳到步骤 6**，转 `transformation-customer-as-product`。

3. **算成本级差（诊断卖不上价的真因）**
   - 问："我们实际投入的心血属于哪一级？收款属于哪一级？"
   - 两者差一级或以上 → 病因确认为"用上一级的成本卖下一级的东西"，不是营销问题也不是渠道问题。
   - 完成标准：能说出具体差了几级，以及差在哪个环节。

4. **判断该不该往上走（不是所有情况都该升级）**
   - 关键判据：**顾客把这个环节视为"价值"还是"成本"？**
     - 视为价值（他愿意在这里多待、多参与、多讲究）→ 向上升级。
     - 视为成本（他只想快点结束、别烦我、让我自己弄）→ **向下削减才是对的**，此时应优化效率、自助化、减少交互（见 B 段）。
   - 完成标准：给出明确的向上或向下结论，并写清判据来自顾客的哪句话或哪个行为。

5. **设计升级动作：把现有资产降格为素材**
   - 列出现有的商品与服务，逐项改写为"道具"与"舞台"。
   - 问："上一级产出中，哪些可以直接当作下一级的原料，不需要新增投入？"（新池塘农场的牛、鸡、干草车都是既有资产）
   - 完成标准：产出一份"资产 → 道具/舞台"的对照清单，且至少一半条目不需要新增预算。

6. **落地交接**
   - 升到体验级 → 转 `ing-the-thing-admission-fee`（怎么把它做成可单独收费的事）+ `four-realms-experience-scan`（体验由哪些象限构成）。
   - 升到变革级 → 转 `transformation-customer-as-product`。
   - 需要改计价方式 → 转 `charge-unit-redesign`。
   - 完成标准：明确指出下一步该用哪个 skill，而不是停在"要做体验"的口号上。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **用户问的是具体定价数字**（定多少钱、怎么设锚点、要不要打折）→ 这是价格框架问题，转 `reference-price-framing` / `arbitrary-coherence-pricing` / `contrast-sequencing`。
- **用户问的是竞争位置**（怎么区别于领导者、要不要做子品牌、名字怎么起）→ 转 `positioning-*` 系列。
- **B2B 大宗采购、招投标、大宗商品交易**：买方按规格和总价决策，个人体验不进入决策函数。强行升级只会增加成本、丢标。
- **必需品、公共服务、低收入市场**：顾客对该品类的支付意愿有硬天花板，升级台阶等于把自己挤出市场。
- **纯效率型赛道**：顾客的唯一诉求就是快、便宜、别打扰（见下条）。

### 作者在书中警告的失败模式

- **收费过高但体验不持续**（第1章 p062）：DiscoveryZone 因无法持续营造体验、游戏开发能力差、且"很少顾及那些负责付费的成人的体验"而破产；Planet Hollywood 因无法更新体验被迫大量关店。**升级台阶不是免罪符**——溢价只在体验被持续提供时才成立。
- **体验的重复化**：主题餐厅群体性衰落，顾客第二次到访与初次毫无变化；连迪士尼"明日世界"几十年不变，被迫斥资几十亿改造加州探险乐园。**体验的保鲜期以"同一顾客的第 N 次访问"计量，不是以上市年数计量。**
- **把商品当主角**：宣称在做体验，但所有沟通、陈列、考核依然围绕商品本身。体验的定义是"以服务为舞台、以商品为道具"，道具不能是主角。

### 作者的盲点 / 时代局限

- **案例几乎全是 1990s 美国的线下零售、主题餐厅、主题公园、连锁店**（雨林咖啡、Planet Hollywood、DiscoveryZone、坎贝拉、Chuck E. Cheese's、LAN 网吧）。**这些案例已过时，数字化与线上体验语境下需重新检验；但五级阶梯的框架本身仍然成立。**
- **⚠️ 递进阶梯被当成单向的、不可逆的——这是本书最大的未证假设。** 过去 25 年最大的一批赢家恰恰靠**主动向下走**取胜：亚马逊一键下单（消灭购物过程）、Costco（毛坯仓库）、Uber（消灭打车交互）、SaaS 自服务、白牌供应链、拼多多。
  **正确的表述是：体验与效率是两条并行的可选路径，而非一条单向阶梯。** 判据见 E 段步骤 4——顾客把该环节视为价值还是成本。**使用本 skill 时必须先跑这一步，否则会给出错误建议。**
- **顾问式乐观**：两位作者是体验设计咨询业的开创者与既得利益者，全书对升级失败率、组织阻力、投入成本的讨论远少于对收益的渲染。
- **未讨论体验疲劳与"被安排感"**：全书站在供给侧，几乎没有处理顾客的抵抗、疲劳与识破。
- **数据止于 2009 年**（图 10-1 复合年增长率的区间），珍藏版追补的 Netflix DVD 租赁、MySpace、Foursquare 今天同样过时。

### 容易混淆的邻近方法论

- **"目的先于差异化"**（本书第10章）：本次整理已判定其与 `positioning-six-steps` 重叠且属常识，未做成独立 skill。若用户真正想问的是"我们为什么存在"，转定位系列。
- **价值链升级 / 微笑曲线**：那是产业链位置（研发—制造—品牌）的移动；本 skill 是**同一环节内产出性质**的跃迁。可以在制造环节原地升到体验级，不需要移动产业链位置。
- **"增值服务"**：常识里的增值服务是免费赠送，本 skill 的升级要求产出**可被独立计价**。免费的加法不构成升级。
