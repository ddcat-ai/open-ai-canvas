## I — 方法论骨架 (Interpretation)

一个连续谱系，按**剧本的可变性**排列：

| 形式 | 剧本状态 | 排练什么 | 演艺原型 | 企业对应 | 生产范式 |
|---|---|---|---|---|---|
| **即兴** Improv | 无剧本，**有规则** | 练反应习惯（"yes, and"） | 即兴喜剧团 | 新业务探索、创意、研发、危机首次应对 | 探索式创新 |
| **街头** Street | 无固定剧本，**有曲目库** | 练大量独立桥段 + 时机 | 杂耍、魔术、说书、小丑 | 客服、现场问答、门店零售、异议处理 | 规模化定制 |
| **搭配** Matching | **活剧本**，边做边改 | 练连戏与配合 | 电影电视（剪辑） | 跨部门协作交付同一产出、团队拜访 | 持续改进/精益 |
| **戏台** Platform | **死剧本**，严格照演 | 演出前充分排练 | 百老汇、有声书、年会路演 | 标准化脚本、快餐柜台、投资者会议 | 规模化生产 |

（注意谱系顺序：即兴 → 街头 → 搭配 → 戏台，剧本从无到死；生产范式对应创新 → 定制 → 改进 → 量产。）

### 四种形式各自的关键点

**1. 即兴**——没有剧本，但**有严格规则**："接受给出的前提（yes, and）"，不能否定同伴抛来的设定。用于尚未定型的工作。训练方式不是背台词，是练反应习惯。
> 常见误解：即兴 = 随便。恰恰相反，即兴对规则的纪律要求最高。

**2. 街头**——★本章最有价值的一格。
三步生存逻辑：**先吸引注意力 → 再用技艺征服 → 最后从观众那里赢得赏钱**。作者指出这三步恰是销售的三步。
没有固定剧本，但有大量**预先打磨好的曲目/桥段库**，现场按情境调用。
核心原则：**看起来即兴，实为排练。**"自然感来自曲目库 + 时机训练，不是来自不准备。"

**3. 搭配**——原型是电影剪辑。把不连贯的、不同时间地点产生的片段整合成统一整体。
- **穿帮镜头 = 搭配表演的失败**：同一角色前后镜头姿势/表情/服装不一致，观众出戏。
- 企业里的穿帮：任务被切给多个部门垂直分工，彼此配合不上，顾客看到前后不一致的企业面孔。
- 解法：精益/持续改进的**水平化关注**——通过表现配合把各活动无缝连接。
- 剧本特性：**用剧本，但剧本一直在变**。因为实际拍摄会暴露剧本瑕疵，正如实际生产会暴露预设流程的问题。
- 配角的"掩护"技巧：团队销售拜访中，非主讲者要用略微点头、专注聆听、看似无意实则有意的动作增强主讲者可信度。（《北非谍影》结尾女主转身的一瞥与一滴泪——"顾客看到的或许比听到的更能带来销售拜访的最后成功"。）

**4. 戏台**——剧本预先写好，严格执行，**改剧本只发生在演出之前的开发阶段**（对应规模化生产里"员工不得擅改工艺流程"）。

### 最重要的三条诊断规则

1. **误配诊断表**（本 skill 的主要用法）：

| 症状 | 误配 | 正确形式 |
|---|---|---|
| 员工"在念稿子"，顾客觉得敷衍 | 用戏台演街头（给高变数岗位写死剧本） | 街头（曲目库） |
| 表现方差极大，好的极好差的极差 | 用即兴演街头（完全放任） | 街头（曲目库） |
| 高管答记者/分析师问翻车 | 用即兴演街头 | 街头（预演问答） |
| 顾客看到前后不一致的企业面孔 | 缺搭配（各部门各演各的） | 搭配（连戏） |
| 创新会议变成流程走过场 | 用戏台演即兴 | 即兴（有规则无剧本） |
| 标准演示每次都不一样、质量不稳 | 用街头演戏台 | 戏台（写死并排练） |

2. **"看起来即兴，实为排练"**：托尼·维拉火警案例——表演时突发火灾警报，他把火把递给观众、装作无事走开、混进人群说"跟我没关系"。同行评价"整个过程如行云流水，没有一丝表演的痕迹"。要点是：**他以前肯定做过，只是时机把握娴熟。**
   推论：**未经排练的自然不是真诚，是不专业。**

3. **同一个人一天内会切换多种形式**（"琳达的一天"）。形式属于**场合**，不属于岗位。

## A1 — 书中的应用 (Past Application)

### 案例 1：托尼·维拉的火警（街头，第7章 p193）
- **问题**：街头表演进行中突发火灾警报，怎么办？
- **方法论的使用**：他把火把递给观众、装作无事走开、混进人群说"跟我没关系"。
- **结论**：同行评价"整个过程如行云流水，没有一丝表演的痕迹"——但作者点破：**他以前肯定做过。**
- **结果**：这是"街头表演法 = 曲目库 + 时机"的最纯粹演示，也是"看起来即兴，实为排练"的原型案例。

### 案例 2："电话医生"客服培训（街头，第7章 p195）
- **问题**：呼叫中心客服面对无限种情境，怎么培训？
- **方法论的使用**：南希·弗里德曼（密苏里州圣路易斯）的"电话医生"课程——18 集 DVD、**100 多种电话沟通场景**，主题含"销售技巧 ABC""如何接听愤怒的客户电话""绝对禁止的粗鲁行为"，每种场景配应对策略供反复练习。
- **结论**：培训的单位不是"一套完整话术"，而是**大量可独立调用的桥段**。
- **结果**：这是曲目库培训的标准形态。哈特福保险同样意识到"任何销售代表都不可能灵活应对所有可能问题"。

### 案例 3：高管演示 + 现场问答（戏台 → 街头切换，第7章 p194）
- **问题**：面向财务分析员的演示，该用哪种形式？
- **方法论的使用**：作者给出明确切分——**演示部分用戏台表演法**（写死、排练）；**紧接着的现场问答绝不能靠即兴发挥，必须用街头表演法**：预先准备可能遇到的各种问题，想好无懈可击的回答，拼命练习，直到听起来"像是即兴回答"。
- **结论**：同一场活动内部要切换形式。
- **结果**：这是本章最直接可迁移的操作建议。

### 案例 4：有声读物录制（戏台，第7章 p186）
- **问题**：为什么出版社请百老汇/好莱坞演员录有声书？
- **方法论的使用**：里克·哈里斯（哈伯音像执行制片人）："音乐喜剧演员非常适合录制有声读物，因为他们知道如何改变音调、如何润色故事和转换表达。"詹尼·弗罗斯特（Bantam Doubleday Dell）补充：更好的读者"在欣赏有声作品之前总是要花很大力气去读原著"。
- **结论**：戏台形式的功夫全在**演出之前**——剧本是死的，准备是活的。
- **结果**：企业年会、投资者联谊会同属戏台场合；外包商 Populous、Dick Clark Productions 收费 15 万～1000 万美元。迪克·克拉克原话点出戏台的改造空间："这些表演都有一个共同形式：一次演讲、一次带图片的财务演示，然后就是董事会主席致辞。我想我可以利用主持电视节目时采用的方式，即欢迎观众进场，想办法让他们高兴，然后把企业信息传递出去。"

### 案例 5：穿帮镜头与部门割裂（搭配，第7章 p189）
- **问题**：为什么顾客会感到"这家公司前后不像同一家"？
- **方法论的使用**：作者用电影穿帮镜头类比——同一角色前后镜头姿势/服装不一致，观众出戏。企业里的对应是任务被垂直切给多个部门，彼此配合不上。
- **结论**：这不是态度问题也不是能力问题，是**没有人负责连戏**。
- **结果**：解法是精益/持续改进的水平化关注。作者还给出岗位归属示例：营销经理用搭配（区别于外部广告公司的即兴）、快餐店柜台员工用搭配（区别于厨房的戏台）、超市零售员用搭配（区别于销售员的街头）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **话术手册/SOP 写了但没用**：员工要么不用，要么用了顾客觉得像念稿。
2. **表现方差极大**：同岗位不同人、同人不同场，质量差异巨大。
3. **直播/带货助播不稳定**：写了脚本反而更僵。
4. **要准备现场问答**：路演、发布会、媒体采访、答辩、评审。
5. **跨部门交付顾客感受割裂**：售前、实施、售后各说各话。
6. **要设计培训方案**：不知道该培训"完整流程"还是"零散技能"。
7. **创新会议流于形式**：有议程有模板，就是出不来东西。
8. **AI 客服/提示词设计**：决定给多死的脚本、留多少发挥空间。

### 语言信号 (用户的话里出现这些就应激活)

- "话术手册写了也没人用 / SOP 落不了地"
- "客户说我们像在念稿子 / 太机械"
- "每个人发挥不一样，好的特别好差的特别差"
- "全靠个人能力 / 靠老员工带"
- "要不要写脚本 / 脚本该写多细"
- "现场问答怎么准备 / 万一被问到 ______ 怎么办"
- "各部门对客户说的话不一样 / 前后不一致 / 穿帮了"
- "怎么培训新人 / 培训完还是不会"
- "improvisation" / "script" / "role play" / "playbook" / "talk track"

### 与相邻 skill 的区分

- 与 `work-is-theatre-drama-structure` 的区别：那个排**时间结构**（起承转合、高潮在哪）；本 skill 选**剧本形态**（多死多活）。同一场活动：先用那个定结构，再用本 skill 决定每一段用什么形式。
- 与 `casting-and-characterization` 的区别：那个决定**谁来演、以什么面貌演**（选角与特征）；本 skill 决定**给他多少剧本**。三者的分工：结构（演什么顺序）→ 形式（剧本多死）→ 选角（谁来演）。
- 与 `ability-simplification` 的区别：那个降低执行者完成动作的难度（把流程做简单）；本 skill 决定**给不给流程、以什么颗粒度给**。曲目库恰恰不是把流程简化，而是把它**碎片化并交出调用权**。
- 与 `experience-design-five-principles` 的区别：那个管信号与主题一致性（现场看到什么）；本 skill 管执行者的表演模式。
- 与 `mindless-click-path` 的区别：那个反对用"步数/点击数"评价流程优劣；本 skill 反对用"话术条数"评价培训质量——精神相通（数量不等于质量），但域不同。
- 与 `ra-hook` / `character-ip-master` 的区别：那些是内容创作侧（钩子、IP 人设）；本 skill 是组织执行侧（一线员工的表演模式）。

## E — 可执行步骤 (Execution)

1. **列出场合，而不是岗位**
   - 表演形式属于**场合**不属于人（"琳达的一天"：一个人一天内切换多种形式）。
   - 完成标准：把一个岗位的一天拆成 4–8 个场合。

2. **对每个场合评两个变量**
   - **变数高低**：现场会发生多少不可预测的事？
   - **一致性要求**：不同人、不同次之间必须有多一致？
   - 完成标准：每个场合都有两个评分。

3. **按谱系落格**
   - 变数极高 + 一致性要求低（探索、创新、危机首次应对）→ **即兴**（给规则不给剧本）。
   - 变数高 + 一致性要求高（客服、现场问答、异议处理、门店）→ **街头**（给曲目库）。
   - 变数中等 + 跨人跨环节交付同一产出（多部门、多触点）→ **搭配**（给活剧本 + 连戏机制）。
   - 变数低 + 一致性要求极高（标准演示、发布会、录制、合规告知）→ **戏台**（写死并排练）。
   - 完成标准：每个场合落进一格，并写出误配诊断（现在实际用的是哪一格）。

4. **街头格的落地：建曲目库（最常用，单列）**
   - 单位是**独立桥段**，不是完整话术。每条包含：触发情境 + 应对动作 + 收尾。
   - 覆盖面参照"电话医生"：**100 种场景级别**，不是 10 条金句。
   - 调用权交给一线（这是与戏台的根本区别）。
   - 练法：随机抽情境做实战演练，练**时机**而不是背诵。
   - 完成标准：曲目库有 ≥30 条，且一线可以自行组合。
   - 判据：如果一线只能按顺序背，那还是戏台，没改成功。

5. **搭配格的落地：设连戏机制**
   - 找出"交接点"（部门之间、触点之间、班次之间）。
   - 每个交接点定义：交什么、顾客此刻已知什么、下一棒的第一句话。
   - 设一个"剪辑师"角色——**必须有人对整体一致性负责**，否则每个部门只对自己那段负责。
   - 完成标准：交接点清单 + 责任人。

6. **戏台格的落地：把功夫前置**
   - 剧本写死，改动只在演出前。
   - 必须真排练（有声书演员"要花很大力气去读原著"）。
   - 完成标准：有完整脚本 + 至少一次全流程排练记录。

7. **即兴格的落地：给规则不给剧本**
   - 明确"yes, and"类规则：不许否定他人抛出的设定、不许在发散阶段评判、每人必须接上一句。
   - 完成标准：写出 3–5 条硬规则，并有人负责喊停违规。

8. **做"看起来即兴，实为排练"的验收**
   - 对街头格：随机抽一个未演练过的情境，看一线能否用曲目库拼出应对。
   - 完成标准：能拼出且不生硬。若生硬 → 曲目颗粒度太大（拆细）；若答不上 → 曲目库覆盖不足（补量）。
   - 判停条件：若一线基本功不足（连基础表达都不行），本 skill 不适用，问题在选角，转 `casting-and-characterization`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **安全与合规环节**：药品说明、金融风险告知、飞行检查单、医疗核对——**只能用戏台**，且不允许"听起来像即兴"。此处的形式选择不是管理决策，是法律义务。
- **人员流动率极高、培训窗口极短的岗位**：曲目库需要时间积累，此时死剧本（戏台）虽然生硬但更现实。**先承认约束，再谈优化。**
- **问题其实在人不在剧本**：基础能力不足、不认同工作本身——转 `casting-and-characterization` 或组织问题。
- **问题在激励结构**：员工知道怎么做但没动力（按接通量结算的客服）→ 转 `charge-unit-redesign`。给曲目库救不了错误的计价单位。

### 作者在书中警告的失败模式

- **用错形式即拙劣表演**——这是本章的核心命题。给客服写死剧本（戏台演街头）、让高管即兴答分析师问（即兴演街头），都是形式误配。
- **穿帮镜头**：垂直分工导致顾客看到前后不一致的企业面孔。
- **"一次通过"的幻觉**：作者点出企业各类会议"基本都希望一次通过"，而不同媒介（主流电影/独立电影/30 秒广告/肥皂剧）容忍的排练次数完全不同。**没有给排练预算，就不要要求戏台级的质量。**
- **把自然误当作不准备**：托尼·维拉案例的反面——真正的行云流水来自反复做过。
- **配角不掩护**：团队拜访中非主讲者放空，浪费了增强可信度的机会。

### 作者的盲点 / 时代局限

- **案例来自 1990s 末的线下场景**（有声磁带出版、DVD 培训、呼叫中心、路演）。**案例已过时，需替换载体**：街头表演法今天对应主播控评与实时答疑、社群运营的应答；搭配表演法对应异步协作与内容剪辑流水线；戏台对应预录制与标准化模板。**框架成立，载体需替换。**
- **⚠️ AI 与自动化改写了这张表**。本书假定所有表演者都是人。今天：戏台格大量被自动化取代（IVR、预录、模板生成）；街头格正在被 AI 助手承接（但 AI 的"曲目库"就是它的训练与提示词——本 skill 反而成为**设计 AI 应答策略的框架**）；即兴格与搭配格仍强依赖人。使用时应先问"这一格还需要人吗"。
- **未讨论曲目库的建设成本与维护**：100 种场景的库需要持续更新，书中只展示成品不谈维护。
- **情绪劳动缺席**（与第6章同一盲点）：街头表演对一线的心理消耗最大（高变数 + 高即时性 + 高自主责任），书中只谈技艺不谈损耗。
- **形式之间的过渡未处理**：书中承认一个人一天切换多种形式，但没有讨论**切换本身的成本**（从戏台切到街头需要不同的心理状态）。
- **"看起来即兴"的伦理问题**：刻意让排练显得自然，在顾客识破后会构成信任损伤，参见 `honest-fake-authenticity`。

### 容易混淆的邻近方法论

- **SOP / 标准作业程序**：SOP 是戏台形式的一种，只覆盖四格中的一格。**把 SOP 当作管理的唯一工具，就是对所有场合都用戏台。**
- **Playbook / 销售剧本**：多数商业 playbook 其实介于街头与搭配之间，但常被当作戏台执行（要求逐字照念），因而失效。用本 skill 可以诊断出这一点。
- **角色扮演培训（role play）**：那是训练手段；本 skill 是形式选型。用错形式的话，role play 只会把错误形式练得更熟。
- **即兴戏剧培训（Applied Improv）**：企业里流行的 improv 工作坊，实际多数场合需要的是**街头**（曲目库）而非即兴。这是最常见的一次误配——练了 improv，回到岗位仍然没有可调用的桥段。
