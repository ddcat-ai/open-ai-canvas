## I — 方法论骨架 (Interpretation)

习惯型产品的机会不是靠"头脑风暴"想出来的，而是靠**扫描三个特定窗口**找到的。
这三个窗口的共同点：它们都会造成一段"习惯尚未固化"的空窗期。

**窗口一：新生行为（Nascent Behavior）**
一小群人已经在做某件事，但用的是拼凑的、笨拙的工具。
这类行为通常被主流认为不重要或古怪。
- Facebook 之于哈佛的纸质花名册（学生本来就在传阅、评论同学照片）
- Airbnb 之于沙发客（陌生人借宿本来就存在）
- 布朗尼相机让普通人开始随手拍照

判据：**这个行为已经存在，只是没有好工具。** 不是"我觉得人们应该开始做 X"。

**窗口二：促成性技术（Enabling Technology）**
新的基础设施出现，使某类行为的成本骤降。
书中给出三段浪潮的结构：
> **基础设施 → 促成性技术 → 应用**
（如宽带 → 流媒体协议 → 视频网站）
机会通常出现在第二段刚成熟、第三段还很空的时候。

判据：这项技术把什么行为的成本从"不可接受"降到了"可接受"？

**窗口三：界面更改（Interface Change）**
这是三者中最强的一个，因为它**重置所有人的既有习惯**。
- 图形界面 → 个人电脑普及
- 简化的搜索框 → Google
- 手机 + 摄像头 + 网络 → Instagram

界面切换意味着在位者靠"图标位置 + 肌肉记忆 + 视觉习惯"建立的壁垒**归零**。
这是少数能绕过 `habit-as-business-asset` 中 9 倍效应门槛的路径——
不是"我们更好 9 倍"，而是"旧习惯在新界面里不管用了"。

**第 0 号入口：观察自己**
最容易被忽略的机会来源是自己的真实行为：
我自己想要什么却找不到好工具？（Buffer 的起源）
这个入口天然与 `manipulation-matrix-ethics` 的"我自己会用吗"重合，
从这里出发的机会自带伦理与信息优势。

## A1 — 书中的应用 (Past Application)

### 案例 1: Facebook 与哈佛的纸质花名册（新生行为）
- **问题**: 从哪里发现值得做的产品方向。
- **方法论的使用**: 学生本来就在传阅、点评纸质花名册上的同学照片——
  行为已经存在，只是载体笨拙。
- **结论**: 最好的机会是给一个**已经发生的行为**换一个好得多的载体。
- **结果**: 从校内产品起步，最终成为十亿级平台。

### 案例 2: Airbnb 与沙发客（新生行为）
- **问题**: 陌生人之间借宿被主流认为是小众且不安全的。
- **方法论的使用**: 这个行为在特定人群中已经存在，缺的是信任机制与撮合工具。
- **结论**: 主流认为"古怪"恰恰是窗口存在的证据——在位者不会去做。
- **结果**: 重塑了整个短租行业。

### 案例 3: 三段浪潮结构（促成性技术）
- **问题**: 新技术出现时，什么时候进场。
- **方法论的使用**: 作者给出"基础设施 → 促成性技术 → 应用"的顺序，
  指出应用层的机会窗口出现在促成技术刚成熟时。
- **结论**: 太早（基础设施未就位）与太晚（应用层已拥挤）都不行，
  判断的是自己站在哪一段。
- **结果**: 成为技术周期择时的实用判据。

### 案例 4: 手机 + 摄像头 = Instagram（界面更改）
- **问题**: 桌面时代的照片分享已有在位者，如何进入。
- **方法论的使用**: 移动界面重置了拍照与分享的全部路径，
  桌面时代积累的习惯在手机上完全不适用。
- **结论**: 界面切换让在位者的护城河清零，新进入者与老玩家回到同一起跑线。
- **结果**: 13 人团队、10 亿美元被收购。

### 案例 5: Buffer 起源于创始人自己的需求（第 0 号入口）
- **问题**: 机会从哪来。
- **方法论的使用**: 创始人自己想定时发推却没有好工具，先做给自己用。
- **结论**: 自身行为是成本最低、信息最真实的机会来源。
- **结果**: 成为"照镜子式"机会发现法的代表。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **要找新产品方向 / 新赛道**，正在做战略规划或创业选题。
2. **有一项新技术，想知道能做什么产品**（AI、语音、AR、新协议）。
3. **在位者太强，正面打不过**——需要找绕过壁垒的路径。
4. **平台迁移正在发生**（PC→移动、图形→语音、App→Agent），要判断要不要下注。
5. **现有产品增长见顶**，需要第二曲线。
6. **投资/立项评估**：某个方向的机会窗口是否真实存在。
7. **团队在头脑风暴但都是拍脑袋的点子**，需要一个有结构的搜索方法。

### 语言信号 (用户的话里出现这些就应激活)

- "下一个机会在哪 / 该做什么方向"
- "怎么找创业点子 / 新赛道怎么选"
- "这个新技术能做出什么产品"
- "对手太强，我们从哪切进去"
- "要不要押注这个新平台 / 新交互"
- "第二曲线在哪"
- "opportunity scan" / "nascent behavior" / "platform shift" / "enabling technology"

### 与相邻 skill 的区分

- 与 `habit-zone-screening` 的区别：**顺序关系**。
  本 skill 负责**找到候选机会**（发散），那个负责**判断值不值得做习惯**（收敛，
  按频率 × 可感知用途筛掉）。找到机会后必须过那道筛。
- 与 `habit-as-business-asset` 的区别：那个解释在位者为什么难被撼动（9 倍效应），
  本 skill 给出绕过它的具体路径（尤其是界面更改）。
  两者常联用：先用那个理解壁垒，再用本 skill 找突破口。
- 与 `habit-testing` 的区别：那个向内测量现有产品，本 skill 向外寻找新机会。
  已有产品未达 5% 时，不应用本 skill 去找新方向逃避问题（见 ce12）。
- 与 `internal-trigger-mining` 的区别：本 skill 找的是**结构性窗口**（行为/技术/界面），
  那个找的是**情绪锚点**。标准流程是本 skill 选定方向后，
  再用那个把方向落到具体的人和情绪上。

## E — 可执行步骤 (Execution)

1. **先做第 0 号扫描：观察自己**
   - 问：我自己最近为了完成某件事，用了什么拼凑的、别扭的办法？
   - 完成标准：写出至少 2 条自己真实经历的"凑合方案"。
   - 价值：这条入口成本最低、信息最真实，且天然落在健康习惯推广者象限。

2. **扫描新生行为**
   - 找法：看小众社区、看年轻人/边缘人群的用法、看"用错工具"的现象
     （用 Excel 当数据库、用微信群当项目管理、用备忘录当日记）。
   - 判据三问：这个行为**已经发生**了吗？做的人**在增长**吗？工具**很烂**吗？
   - 完成标准：列出 3–5 条候选，每条注明"谁在做、用什么凑合、为什么烂"。
   - 判停条件：若只能写出"我认为人们应该开始做 X" → 那是发明新行为，
     风险极高（对照 `autonomy-reactance` 中 MyFitnessPal 的失败）。

3. **扫描促成性技术**
   - 定位自己在三段浪潮中的位置：基础设施 / 促成性技术 / 应用。
   - 关键问句：这项技术把**什么行为的成本**从不可接受降到了可接受？
   - 完成标准：写出"技术 → 成本骤降的具体行为"的映射，而不是罗列技术名词。
   - 判停条件：若说不出具体降低了哪个行为的成本 → 这只是技术热点，不是机会。

4. **扫描界面更改**
   - 找法：正在发生的交互范式迁移（触屏、语音、可穿戴、车机、对话式/Agent）。
   - 核心问句：**在旧界面里靠什么建立的习惯，在新界面里失效了？**
     （图标位置？肌肉记忆？视觉入口？搜索框？）
   - 完成标准：明确指出在位者的哪一项壁垒会被清零。
   - 这一项优先级最高——它是唯一能系统性绕过 9 倍效应的窗口。

5. **交叉验证：三扫描是否指向同一处**
   - 最强的机会通常同时命中两到三个窗口
     （如 Instagram = 新生行为"随手拍分享" + 促成技术"手机摄像头+网络" + 界面更改"移动"）。
   - 完成标准：给候选机会标注命中了几个窗口，按命中数排序。

6. **对候选做习惯可行性初筛**
   - 转 `habit-zone-screening`：估频率 × 可感知用途，落不进习惯区间的直接淘汰
     （或改为高价值低频工具定位）。
   - 完成标准：候选从 N 条收敛到 1–3 条。

7. **对入围机会做落地化**
   - 转 `internal-trigger-mining`：给这个机会找到一个具体的人和一个具体的情绪。
   - 转 `manipulation-matrix-ethics`：过一遍"我自己会用吗 / 它改善生活吗"。
   - 完成标准：入围机会有了"人 + 情绪 + 象限判定"三项。

8. **判断窗口期与止损**
   - 窗口期信号：在位者尚未在新界面/新行为上认真投入；
     早期用户仍在用凑合方案；相关讨论还没进入主流媒体。
   - 关闭信号：在位者已推出同类产品且完成迁移；行为已被主流工具满足。
   - 完成标准：写出这个窗口"大概还开多久"的判断依据。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **现有产品还没跑通闭环**——习惯用户不足 5% 时去找新方向，
  往往是在逃避真正的问题（ce12）。先做 `habit-testing`。
- **已经选定方向、只差可行性判断**——转 `habit-zone-screening`。
- **只想要一份竞品分析或市场规模报告**——本 skill 找的是行为与界面的**结构性窗口**，
  不产出 TAM/SAM/SOM。
- **纯 B 端强制流程类机会**（合规工具、审批系统）——
  这类机会的驱动力是制度而非习惯，三扫描的解释力有限。
- **窗口早已关闭的成熟领域**——扫描的价值在于"习惯尚未固化"，
  在已固化的界面里硬拼是 ce17。

### 作者在书中警告的失败模式

- **ce17 — 忽略机会策源地，在成熟界面里硬拼**：
  在既有平台、既有交互范式下与在位者正面竞争。
  警告信号：竞品分析只看同形态产品；没有关注新兴用户行为；忽视平台迁移信号。
- **ce16 — 忽视 9 倍效应**："我们比对手好一点点"就敢做。
  本 skill 的界面更改窗口正是绕过这一门槛的解，
  但如果不换界面只做微改良，9 倍门槛依然存在。
- **ce22 — 找到窗口不等于找到价值**：机会窗口只说明"此刻习惯未固化"，
  不保证这件事有人需要。必须过 `habit-zone-screening` 的可感知用途一关。
- **ce10 — 窗口真实但频率太低**：新技术催生的行为若一年发生一次，
  仍然做不成习惯型产品。

### 作者的盲点 / 时代局限

- **三扫描只回答"窗口在哪"，不回答"能不能赢"**：
  资源、时机、分销能力、监管都不在框架内。它是一个发现工具，不是决策工具。
- **幸存者偏差严重**：书中列举的都是成功案例（Facebook、Airbnb、Instagram），
  同样的窗口里失败的项目远多于成功的。
  三扫描能提高命中率，但不能把成功率提到高位。
- **未讨论窗口期长度与竞争密度**：今天信息传播速度远快于 2014 年，
  一个"新生行为"被发现后往往数月内就有数十个团队进入，
  窗口期的判断（步骤 8）是本 skill 对书中的必要补充。
- **未涉及 AI 时代的新形态**：生成式 AI 同时构成促成性技术（能力成本骤降）
  和界面更改（对话式交互重置了图形界面的习惯），
  按本框架属于罕见的"双窗口同时打开"——书中没有这一层讨论，
  但框架本身适用。
- **"观察自己"这一入口有阶层局限**：创造者的生活经验与大众可能相距很远，
  容易把小圈子需求误认为普遍机会。

### 容易混淆的邻近方法论

- **蓝海战略 / 价值曲线**：从竞争维度重构市场；
  本 skill 从**行为与界面的时间窗口**切入，判据完全不同。
- **颠覆式创新（Christensen）**：解释低端/新市场颠覆如何发生，
  是解释性理论；本 skill 提供的是可主动执行的**扫描清单**。
  两者可互补：颠覆理论解释为什么在位者不会跟进，本 skill 找到入口在哪。
- **Gartner 技术成熟度曲线**：判断技术炒作阶段；
  本 skill 的"三段浪潮"更关注**行为成本何时降到可接受**，而非技术热度。
- **JTBD 的机会发现**：从未被满足的任务出发；
  本 skill 强调的"新生行为"要求该行为**已经在发生**，标准更严。
- **趋势报告 / 用户调研**：产出的是描述；
  本 skill 产出的是"哪一项在位者壁垒会被清零"这种可行动判断。
