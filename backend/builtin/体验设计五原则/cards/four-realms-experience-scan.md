## I — 方法论骨架 (Interpretation)

两个轴，注意**两个轴都不是"手段"，而是"关系"**：

- **纵轴 参与度**：顾客是**被动**接受（看着别人演），还是**主动**参与（自己动手影响结果）。
- **横轴 关联度**：**吸引式（absorption）**——体验走向顾客，进入他的头脑；**浸入式（immersion）**——顾客走向体验，身体进入那个环境。

> 关键判据是**方向性：谁走向谁。**不是"用了什么技术"。这条直接推翻了流行的"沉浸式 = VR/大屏/全息"的用法——看 IMAX 的人身体进入了影院环境，是浸入；戴 VR 看一段被动画面，参与度仍然是被动的。

四象限：

| | 吸引式（体验走向你） | 浸入式（你走向体验） |
|---|---|---|
| **被动参与** | **娱乐性** Entertainment（看、听） | **审美性** Esthetic（身处其中，什么都不改变，只是待着） |
| **主动参与** | **教育性** Educational（学，头脑主动） | **逃避性** Escapist（做，身体主动，成为其中的角色） |

四句话记法：
- 娱乐性 = 想**感觉**（sense）
- 教育性 = 想**学习**（learn）
- 逃避性 = 想**去做**（do）
- 审美性 = 想**待着**（just be there）

**这个模型的正确用法不是分类，是扫描找洼地。**

绝大多数人拿到四象限的第一反应是"我这个属于教育性"，然后就结束了。那是浪费。正确用法是：

1. 把现状打进象限，通常会发现**高度集中在一个象限**；
2. **空着的象限就是改进空间**——而且往往是几乎零成本的方向；
3. 补洼地的收益 > 在已占象限里继续加码。

另外两条本书的强主张：

- **体验 ≠ 娱乐。**作者在珍藏版序言里专门澄清，提出 4E 就是为了防止"体验经济 = 娱乐至死"的误读。"加点娱乐化"是最常见也最偷懒的一种体验设计。
- **审美性最容易被忽略，却常常是留住人的那一个。**它不要求顾客做任何事，只要求环境本身值得待着。滑雪场吊椅是典型洼地：全程有人被动坐着、身处景中，却几乎从未被当作体验来设计。

## A1 — 书中的应用 (Past Application)

### 案例 1：库肯霍夫花卉公园（第2章 p079）
- **问题**：一个"看花的公园"如何做成完整体验？
- **方法论的使用**：四象限齐备——审美性（花田本身，走进去待着）、娱乐性（现场演出）、教育性（品种讲解与园艺知识）、逃避性（亲手参与的园艺活动区）。
- **结论**：作者用它作为"四范围齐备 = 甜蜜点"的正面样板。
- **结果**：单一功能的观赏地被扩成全时段可停留的目的地。

### 案例 2：酒店业的逐项补齐（第2章 p081）
- **问题**：酒店的房间越修越好，为什么体验感没提升？
- **方法论的使用**：作者逐项归类现有创新——施拉格大厅的社交氛围（审美性）、天堂之床（审美性/舒适）、房内平板电视（娱乐性）、礼宾部（教育性 + 逃避性入口）。
- **结论**：多数酒店的投入压在"审美性"一格里（把房间做得更好看更舒服），教育性与逃避性长期空白。
- **结果**：作者据此推演酒店可补的方向：在地知识（教育性）、可参与的在地活动（逃避性）。

### 案例 3：滑雪吊椅洼地（第2章 p080）
- **问题**：滑雪场的价值全在雪道上，其余时间算什么？
- **方法论的使用**：吊椅上的十几分钟——顾客被动、身处景中，这是纯粹的审美性时段，却从未被设计过。
- **结论**：这是一块**零改造成本的空白象限**。
- **结果**：作者用它说明"洼地往往就在你天天路过却不认为是体验的那段时间里"。

### 案例 4：LAN 竞技场（第2章 p067）
- **问题**：网吧和电竞场地凭什么按小时/年卡收钱？
- **方法论的使用**：它同时命中主动参与（打）与浸入（进入那个空间和那个世界），落在逃避性的核心格。
- **结论**：逃避性象限天然支持按时间收费——因为顾客要的就是"待在里面的那段时间"。
- **结果**：与 `ing-the-thing-admission-fee` 的入场费逻辑闭合。

### 案例 5：洛杉矶步行街 vs 迪士尼乐园（第2章 p076-p077）
- **问题**：两者都是人造环境，体验结构有何不同？
- **方法论的使用**：步行街偏审美性（就是一条可以待着的街，承认自己是造出来的）；迪士尼偏逃避性（要求你成为故事里的人，并隐藏人造痕迹）。
- **结论**：不同象限对应不同的真实性策略（详见 `honest-fake-authenticity`）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **完课率/完播率/留存低**，团队的唯一方案是"内容做得更好"。
2. **线下空间逛一圈就走**：展览、门店、园区、书店、博物馆停留时长短。
3. **活动办完没人记得**：年会、发布会、市集、开放日。
4. **想做"沉浸式"但不知道是什么**：预算准备砸设备，先确认是不是设备问题。
5. **社群/课程/训练营中期掉队**。
6. **旅游/文旅/景区项目做规划**，需要一个内容配比框架。
7. **体验做得很累但没效果**：投入集中在一格，边际收益已经归零。
8. **接在决定"要做体验"之后**：`ing-the-thing-admission-fee` 定了要收费，本 skill 定内容配比。

### 语言信号 (用户的话里出现这些就应激活)

- "完课率只有百分之十几 / 完播率低 / 中途流失"
- "客人逛一圈就走 / 停留时间太短"
- "体验挺好的但记不住 / 不难忘 / 平淡"
- "想做沉浸式 / 要不要上 VR / 弄个大屏"
- "加点娱乐化 / 游戏化 / 互动环节"
- "用户说无聊 / 没意思"
- "活动没人参与 / 互动环节冷场"
- "experience realms" / "immersive" / "engagement design" / "四象限"

### 与相邻 skill 的区分

- 与 `experience-design-five-principles` 的区别：本 skill 回答**"补哪一格"**（配比与方向）；那个回答**"这一格怎么做好"**（主题、信号、纪念品、感官）。先扫描后设计。
- 与 `ing-the-thing-admission-fee` 的区别：那个回答**"要不要把它做成收费体验"**；本 skill 回答**"这个体验的内容结构缺什么"**。
- 与 `hook-model-loop` / `variable-reward-design` 的区别（重要，最容易混）：Hook 模型解决的是**"用户为什么会回来"**（触发—行动—酬赏—投入的循环，跨会话的留存机制）；本 skill 解决的是**"这一次体验本身够不够丰满"**（单次会话内的内容维度）。用户说"留存差"时先判断：是想不起来回来（Hook 问题），还是回来了也无聊（4E 问题）。两者常常都要做。
- 与 `variability-sustainability` 的区别：那个讲"为什么一开始新鲜后来腻"（时间维度上的衰减）；本 skill 讲"横截面上缺哪一维"。腻了 → 那个；从来就淡 → 本 skill。
- 与 `billboard-scan-design` 的区别：那个解决几秒内被扫一眼看懂（信息识别）；本 skill 解决长时段的体验丰满度。

## E — 可执行步骤 (Execution)

1. **划定体验的时间边界**
   - 从顾客决定来（甚至路上）到离开之后的余韵，画一条时间轴。
   - 完成标准：能列出至少 5 个时间段落，包括**你从没当作体验的那些**（排队、通勤、等待、吊椅、结账、离场）。

2. **逐段打象限**
   - 每一段问两个问题：①顾客是主动还是被动？②是体验走向他（吸引），还是他走进环境（浸入）？
   - 只填一格，不要写"这段兼有"。分不清就按主要感受填。
   - 完成标准：得到一张"时间段 × 象限"表。

3. **数格子，找洼地**
   - 统计四格的时长占比与设计投入占比。
   - 完成标准：明确说出"我们几乎全在 ______ 格，______ 格是空的"。
   - 判停条件：若四格分布已经均衡而问题依然存在，本 skill 不适用——转 `experience-design-five-principles`（执行质量问题）或 `hook-model-loop`（回访机制问题）。

4. **优先补"零成本洼地"**
   - 先找那些**已经存在但从未被设计**的时段（滑雪吊椅型洼地）：等待区、排队、通勤、间歇、离场路线。
   - 完成标准：至少一条改动不需要新增场地或设备。

5. **按象限套用标准打法**
   - 娱乐性（被动+吸引）：值得看/听的东西，节奏与惊喜点，不必宏大。
   - 教育性（主动+吸引）：给他一个可用的知识或技能，要求头脑主动，不能是单向灌输。
   - 逃避性（主动+浸入）：给他一个**角色和可影响的结果**——这是四格里最贵也最强的一格。
   - 审美性（被动+浸入）：让环境本身值得待着，不要求他做任何事（光、声、坐、视野、气味）。
   - 完成标准：每个空白象限至少一条具体动作。

6. **检查是否误把技术当浸入**
   - 问："顾客的身体/注意力是不是真的进到了那个环境里？"
   - 上了 VR 但顾客只是被动看片 → 仍是娱乐性，没有升级。
   - 完成标准：能说清"谁走向谁"。

7. **验证：找甜蜜点**
   - 四格齐备后，看停留时长、复访率、自发分享。
   - 完成标准：至少两格上有可观测变化。若只在新加的那一格上有反应而整体无变化，说明补的格与主题冲突（转 `experience-design-five-principles` 检查信号一致性）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **顾客要的就是"快点结束"**（缴费、报销、急诊分诊、退换货）：四格全补 = 折磨顾客。这类环节的正解是压缩。
- **单一象限就是产品定义本身**：纯听觉产品（播客）、工具型软件的核心任务流，强行补格会破坏专注。
- **资源只够做好一格**：本书主张四格齐备，但没有讨论资源约束。四格都做一半，不如一格做到极致。**优先级判据：先补那个与你主题最一致的空白格。**
- **问题其实在回访机制**（用户不是不喜欢，是想不起来）→ 转 `hook-model-loop` / `external-trigger-design`。

### 作者在书中警告的失败模式

- **误把体验等同于娱乐**：作者在珍藏版序言（p021-p024）专门澄清，称这是最常见的误读，"只要认真阅读第 2 章，大家就会发现这是一种错误的理解"。加娱乐是最偷懒的补法。
- **"蜜罐"区域的纪律**（第2章 p083）：作者主张体验区域内"凡是和这些功能无关的内容全都被清除"。补象限不是做加法堆料——补进来的东西如果与主题冲突，是负面信号（见 `experience-design-five-principles` 第三原则）。
- **一成不变的体验**：迪士尼明日世界、主题餐厅通病（p062）——四格齐备但不更新，第二次到访即失效。

### 作者的盲点 / 时代局限

- **案例几乎全是物理空间**（花卉公园、滑雪场、酒店、主题街区、网吧）。**案例已过时；线上/移动/AI 语境下需重新检验**。不过 4E 两轴（参与度 × 关联度）是关系维度而非技术维度，因此**框架本身在数字产品上依然可用**：短视频=娱乐性、在线课=教育性、开放世界游戏=逃避性、氛围类 app 与音乐流=审美性。
- **"四格齐备最好"缺乏证据**："甜蜜点"是作者的断言，没有对照数据。现实中大量极成功的体验是单象限极致（IMAX 纯娱乐、Duolingo 近乎纯教育性、Calm 近乎纯审美性）。**更稳妥的用法是把它当扫描器（发现盲点），而不是当配方（必须四格全上）。**
- **"逃避性"的伦理与成瘾面未处理**：作者只把逃避性当作最高价值格，不讨论沉迷、逃避现实的代价。游戏、短视频、元宇宙语境下这是核心问题。
- **未讨论象限之间的冲突**：教育性与逃避性常常互斥（要学就出戏，要入戏就学不进），书里当作可叠加。
- **共创缺席**：UGC 场景下顾客既是参与者也是营造者，两轴的"谁走向谁"会失效。

### 容易混淆的邻近方法论

- **"沉浸式"的流行用法**（VR、全息、大屏、Sleep No More 式演出）：那是技术/形式；本书的浸入式是**方向性关系**。混用会导致"上了设备但体验没升级"。
- **游戏化（gamification）**：那是把积分/徽章/排行榜叠加到非游戏场景（多数落在娱乐性 + 教育性）；4E 是维度诊断，不是手法。游戏化经常被用来填娱乐格，但填不了审美格与逃避格。
- **用户旅程地图（Customer Journey Map）**：那画的是流程与触点；4E 给的是每个触点的**体验性质**。两者可叠加使用——旅程地图定横轴，4E 定每格填什么。
