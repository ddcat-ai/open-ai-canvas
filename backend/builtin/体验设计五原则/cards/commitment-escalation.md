## I — 方法论骨架 (Interpretation)

常识的顺序是：**说服 → 对方认同 → 对方行动**。
本单元给出的是相反的顺序：

> **微小的自愿行动 → 态度自行调整 → 更大的行动**

三条机制解释为什么反过来更有效：

**机制一：宜家效应（劳动即估值）**
阿雷利的折纸实验：亲手折纸的人对自己作品的估价，
约是旁观者估价的 5 倍。人会高估自己劳动的成果。
推论：让对方参与做一点，比向对方展示一个完美成品更能获得认同。

**机制二：门槛效应（foot-in-the-door）**
Freedman & Fraser 的经典实验：直接请求居民在草坪竖巨型交通安全标牌，
接受率约 17%；若先请他们在窗户贴一张 3 英寸的小标语，
两周后再提出大请求，接受率升至约 76%。
机制是自我认知的改变：做过小事之后，"我是支持这件事的人"成为自我形象的一部分。

**机制三：认知失调（为已付出的合理化）**
人无法长期忍受"我做了 X，但我不认同 X"的矛盾，
于是倾向于调整态度来匹配已发生的行为
（书中以游戏玩家为已花掉的钱继续付费为例）。

**两条硬约束（缺一则反噬）：**
1. **必须自愿**。被强制的行动不产生认知失调（"我是被逼的"提供了现成的解释），
   反而触发逆反 → 先用 `autonomy-reactance` 保住自主权。
2. **必须足够小**。第一步的门槛要低到"拒绝显得小题大做"。
   起点太大 → 被拒 → 反向承诺（"我拒绝过这件事"）固化，比不问更糟。

## A1 — 书中的应用 (Past Application)

### 案例 1: 阿雷利的折纸实验（宜家效应）
- **问题**: 为什么用户对自己参与制作的东西评价异常高。
- **方法论的使用**: 让一组人亲手折纸并为自己的作品出价，另一组人为同样的作品出价。
- **结论**: 亲手做过的人估价约为旁观者的 5 倍——劳动直接转化为估值。
- **结果**: 成为"让用户干活反而更爱产品"的经典依据。

### 案例 2: Freedman & Fraser 的草坪标牌实验（门槛效应）
- **问题**: 如何让人接受一个很大的请求。
- **方法论的使用**: 先提出一个微不足道的小请求（贴 3 英寸标语），
  两周后再提出大请求（竖巨型标牌）。
- **结论**: 小请求改变的不是意愿，而是**自我认知**；
  接受率从 17% 升至 76%，四倍以上。
- **结果**: 成为"承诺与一致"最常被引用的实验。

### 案例 3: 玩家为已投入的钱继续付费（认知失调）
- **问题**: 为什么已经花了钱的玩家更容易继续花钱。
- **方法论的使用**: 作者用认知失调解释：承认"这钱白花了"太痛苦，
  于是玩家调整态度，认为这个游戏确实值得。
- **结论**: 已发生的投入会重塑对事物价值的判断，方向是向上的。
- **结果**: 解释了产品投入为何能改变用户偏好。

### 案例 4: eBay 竞拍者越出价越舍不得
- **问题**: 为什么出价次数多的人更可能继续加价。
- **方法论的使用**: 每一次出价都是一次自愿的小承诺，
  一致性驱动让后续出价变得更自然。
- **结论**: 承诺可以是渐进的，每一步都为下一步铺路。
- **结果**: 竞拍成为 eBay 早期高转化的核心机制。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **要说服一个明确反对的人**（领导、同事、客户、家人），讲道理已经失效。
2. **要推行一项变革**（新流程、新工具、新方向），团队态度冷淡。
3. **要让别人从"知道"变成"认同"**——培训讲完了，行为没变。
4. **要争取一个大承诺**（大额采购、长期合作、组织资源），需要设计路径。
5. **要改变自己的行为**（坚持锻炼、写作、学习）——同样适用，先做微小动作。
6. **招募志愿者 / 早期用户 / 内测者**，需要设计参与阶梯。
7. **方案被认为"不是我们的东西"**——需要让对方参与共创以获得认同。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么说服他 / 怎么让他改变想法"
- "道理都讲清楚了，他还是不认"
- "领导不同意 / 同事不配合 / 客户不买账"
- "改革推不动 / 大家嘴上答应行动上不动"
- "怎么让自己坚持下来"
- "foot in the door" / "change someone's mind" / "how to persuade" /
  "commitment and consistency"

### 与相邻 skill 的区分

- 与 `investment-design` 的区别：**这是最需要分清的一对**。
  那个是**产品投入阶段的设计程序**，面向产品经理，目标是储存价值与留存；
  本 skill 是**通用的态度改变机制**，面向说服、团队变革、自我改变，目标是改变认知。
  判据：如果对象是"用户在 App 里存东西" → 那个；
  如果对象是"某个具体的人要改变立场" → 本 skill。
  （两者共享宜家效应/一致性这一理论底座，但触发条件完全不同。）
- 与 `autonomy-reactance` 的区别：那个是**防守**（如何不引发抵触），
  本 skill 是**进攻**（如何让人主动迈出第一步）。
  正确的联用顺序：先用那个确保自愿，再用本 skill 设计第一步。
  若对方已经在强烈抵触状态，直接用本 skill 会失败。
- 与 `variable-reward-design` 的区别：那个靠**给予**驱动重复行为，
  本 skill 靠**付出**改变态度。方向相反，常被一起误称为"激励"。
- 与 `manipulation-matrix-ethics` 的关系：本 skill 是纯操控技术，
  威力大且价值中立，涉及重大利益时应先过那个自检。

## E — 可执行步骤 (Execution)

1. **明确目标态度，而不只是目标行为**
   - 写下："我希望【某人】从【当前立场】变成【目标立场】。"
   - 完成标准：目标立场是一句对方可能说出口的话，而非你希望的结果。

2. **先做逆反检查**
   - 问：对方目前的抵触是"不认同"还是"被强加"？
   - 若是被强加 → 停止，先用 `autonomy-reactance` 恢复自主权，否则本 skill 无效。
   - 若对方的反对有实质依据（方案确有缺陷）→ 停止，改方案。
   - 完成标准：明确判定并写出依据。

3. **设计第一步：小到不好意思拒绝**
   - 三条标准：①耗时几分钟内；②不需要公开表态；③在对方现有能力范围内。
   - 形式建议：请他提一条意见、请他看一眼草稿、请他主持一次小环节、
     请他选一个日期试一次。
   - 完成标准：写出具体动作，并自检"如果我是他，会拒绝吗"。
   - 判停条件：若第一步需要对方承担风险或公开站队 → 太大，重设计。

4. **确保这一步是"自愿 + 有作者身份"**
   - 自愿：明确给出拒绝权（"不方便就算了"）。
   - 作者身份：让他的贡献可被识别（他提的意见被采纳并署名、他改的版本被保留）——
     这是宜家效应生效的关键，纯粹执行不产生估值提升。
   - 完成标准：写出"他的痕迹将出现在哪里"。

5. **让行动先于说服发生**
   - 纪律：在他完成第一步之前，不要试图辩赢他。
   - 完成标准：明确列出"暂缓说的话"（那些你很想讲但会激起防御的论点）。

6. **设计承诺阶梯**
   - 第 1 级：给意见 / 看一眼（几分钟）
   - 第 2 级：小范围试用一次 / 主持一个小环节（一次性、私下）
   - 第 3 级：在小场合表达支持 / 参与共创（半公开）
   - 第 4 级：公开背书 / 承担角色 / 投入资源（公开、有代价）
   - 完成标准：至少 3 级，每级注明"什么信号出现才升级"。
   - 纪律：**不要跳级**。跳级被拒会形成反向承诺，比慢慢来更糟。

7. **在每一级之后强化自我认知**
   - 做法：把他的行为反馈给他（"上次你提的那条已经落地了"），
     帮助"我是支持这件事的人"这一自我形象固化。
   - 完成标准：每级配一个回馈动作。

8. **判停与止损**
   - 升级信号：他开始主动提建议、在他人面前替方案说话、询问后续安排。
   - 止损信号：连续两级被拒、出现"你是不是在套路我" → 立即停止，
     回到 `autonomy-reactance`，并考虑本 skill 不适用（可能是实质分歧）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **对方的反对有实质依据**——这时该改方案。用心理技巧绕过有效反对，
  短期得逞、长期埋雷，且会摧毁信任。**这是本 skill 最常见的误用。**
- **对方处于强抵触状态**——先处理自主权（`autonomy-reactance`），
  否则任何请求都会被解读为进一步的施压。
- **无法提供真实的拒绝权**（上下级强制、合规要求）——
  被强制的行动不产生认知失调，机制不成立。
- **涉及重大利益且信息不对称**（大额消费、金融产品、医疗决策）——
  承诺升级在这些场景中就是暗黑模式，先过 `manipulation-matrix-ethics`。
- **一次性关系**——态度改变的价值需要在后续互动中兑现，
  一锤子买卖用这套只是操纵。
- **产品内的投入设计**——那是 `investment-design`，不要用本 skill 的话术
  去设计注册流程。

### 作者在书中警告的失败模式

- **ce07 — 顺序颠倒，一上来就索取大投入**：对应到说服场景就是"起点太大"，
  第一步被拒后形成反向承诺。
  警告信号：第一次请求就要求对方公开表态或投入资源。
- **ce02 — 强制导致逆反**：强制的行动不改变态度，只积累怨气。
  警告信号：对方口头答应、行动不动（阳奉阴违）。
- **ce14 — 滑向经销商象限**：明知对对方无益仍用承诺升级榨取，
  这是本 skill 被滥用的典型形态。
- **ce15 — 忽视被说服者的退出权**：阶梯设计到后期若无退出机制，
  会把人锁在自己都不再认同的承诺里。

### 作者的盲点 / 时代局限

- 书中把宜家效应、门槛效应、认知失调三者并列引用，但**未区分它们的作用条件**：
  宜家效应需要"亲手做"，门槛效应需要"时间间隔"（原实验隔了两周），
  认知失调需要"选择感"。混用会失效，实践中需分别对待。
- 门槛效应的原始实验做于 1966 年，后续重复研究显示**效应量因场景而异**，
  在商业推销场景中因人们已具备"套路警觉"而明显衰减。
  书中当作稳定规律引用，实践中应降低预期。
- 未讨论**被识破的代价**：一旦对方意识到这是设计好的阶梯，
  信任损失远大于收益。缓解办法是把参与做成真实的共创（他的意见真被采纳），
  而不是形式化的小请求。
- 未讨论**反向承诺**风险：书中只讲"答应小请求带来大答应"，
  没讲"拒绝小请求带来更坚定的拒绝"——这是设计第一步时最重要的风险。

### 容易混淆的邻近方法论

- **Cialdini《影响力》的"承诺与一致"**：同源理论，覆盖面更广（含公开性、书面化等增强手段）；
  本 skill 的差异是给出了**产品/变革场景下的阶梯化执行程序**与自愿约束。
- **销售的 SPIN / 小额试用（Trial Close）**：操作上相似，
  但目标是成交而非态度改变，且通常不关心事后认同。
- **共创 / 参与式设计（Co-design）**：可视为宜家效应的组织化应用，
  与本 skill 步骤 4 高度一致，是最"干净"的用法（对方的贡献是真实的）。
- **助推（Nudge）**：改变的是选择环境，不要求对方付出劳动；
  本 skill 恰恰要求对方**付出**，两者机制不同。
- **投入阶段设计（`investment-design`）**：共享理论底座，
  但一个面向产品循环，一个面向人的态度，触发条件不同。
