## I — 方法论骨架 (Interpretation)

"投入"是上瘾模型的第四阶段，也是最容易被产品团队漏掉的一环。
它与前面三个阶段有一条根本区别：

> **行动的回报是即时的；投入的回报在未来。**

这条线决定了一个动作属于哪个阶段，也决定了该删还是该留。

**工具一：储存价值五形态**

| 形态 | 用户存进去的东西 | 例证 |
|---|---|---|
| 内容 | 照片、笔记、歌单、文档 | Evernote、Instagram |
| 数据资料 | 档案、偏好、历史、配置 | LinkedIn、Mint |
| 关注者 | 关系网、订阅、好友 | Twitter、Facebook |
| 信誉 | 评分、点数、等级、评价 | eBay、Stack Overflow |
| 技能 | 学会怎么用这个工具 | Photoshop |

沉淀的形态越多、越难重建，迁移成本越高。
注意：这五项都是**用户的资产**，不是公司的锁定手段——
这一区分决定了它是留存还是绑架（见 `manipulation-matrix-ethics`）。

**工具二：摩擦的符号在闭环中会反转**

- 行动阶段（酬赏**之前**）：一切多余步骤都要删。
- 投入阶段（酬赏**之后**）：适度摩擦是价值来源，删光了产品就没有沉淀。

同一个动作（比如"给照片打标签"）放在注册流程里是门槛，
放在用户刚收到一堆点赞之后就是投入。**位置决定符号，不存在普适的"越简单越好"。**

**工具三：时机 + 阶梯**

- **时机**：斯坦福的人机互惠实验显示，先受助的一组回报近两倍。
  所以顺序必须是"先给酬赏，再请求投入"（颠倒即 ce07）。
- **阶梯**：投入要分解成随循环递增的小块——
  第一次只要一次点击，第十次才要求填一份完整档案。

## A1 — 书中的应用 (Past Application)

### 案例 1: Evernote 的微笑曲线
- **问题**: 免费用户为什么会随时间变成付费用户。
- **方法论的使用**: 用户持续存入笔记（内容 + 数据资料），
  存得越多越难迁移；产品无需加强推销，价值随沉淀自动增长。
- **结论**: 储存价值让留存曲线出现"回升"（微笑曲线），这是投入阶段的典型特征。
- **结果**: 使用 33 个月后付费用户比例升至 26%。

### 案例 2: Photoshop 的技能沉淀
- **问题**: 一款上手极难的软件为何忠诚度极高。
- **方法论的使用**: 用户投入大量时间掌握它，技能本身成为储存价值。
- **结论**: 门槛应在**首次行动**处降低，在**长期使用**处积累——
  这正是摩擦符号反转的最强证据。
- **结果**: 长期主导专业图像软件市场。

### 案例 3: LinkedIn 的档案完成度进度条
- **问题**: 如何让用户持续补充个人信息。
- **方法论的使用**: 进度条制造目标渐近效应，把"填资料"拆成随时间递增的小块任务；
  每填一条都成为该用户的数据资料与信誉。
- **结论**: 阶梯式投入 + 可视进度，比一次性要求填完有效得多。
- **结果**: 档案完成率显著提升，网络效应增强。

### 案例 4: eBay 的信誉与竞拍
- **问题**: 卖家为何不愿换平台；买家为何越出价越舍不得。
- **方法论的使用**: 卖家的评分是无法迁移的信誉资产；
  买家的每一次出价都是渐进投入，沉没成本与一致性共同抬高估值。
- **结论**: 信誉是五形态中迁移成本最高的一种（它无法导出）。
- **结果**: 竞拍机制成为 eBay 早期高转化的核心引擎。

### 案例 5: 斯坦福人机互惠实验
- **问题**: 什么时候请求用户付出最有效。
- **方法论的使用**: 实验中先得到电脑帮助的一组，回报电脑的工作量接近另一组的两倍。
- **结论**: **先给后取**不是礼貌问题，是有效性问题。
- **结果**: 成为"酬赏在前、投入在后"的实验依据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **留存平坦无回升**——用户来了又走，曲线从不上翘。
2. **迁移成本近乎为零**——竞品抄一遍就能把用户端走。
3. **续费率/复购率低**，但用户满意度并不差。
4. **产品无个性化沉淀**——用了三个月和第一天没什么区别。
5. **要设计新手引导之后的第二程**——首次行动已经很顺了，接下来该要什么。
6. **要判断某个"麻烦步骤"该不该删**——本 skill 提供位置判据。
7. **线下/服务业想提高复购**（健身房、瑜伽馆、诊所），除了打折没别的招。

### 语言信号 (用户的话里出现这些就应激活)

- "留存怎么提 / 用户用一阵就流失"
- "用户走了一点都不心疼 / 迁移成本太低"
- "竞品一抄我们就没优势了"
- "怎么让用户留下点东西 / 怎么增加粘性"
- "续费率上不去，只能靠打折"
- "这一步是不是该删掉"（位置判断）
- "switching cost" / "stored value" / "user investment" / "lock-in" / "stickiness"

### 与相邻 skill 的区分

- 与 `ability-simplification` 的区别：**方向相反，必须分清**。
  那个用于酬赏**之前**（删摩擦），本 skill 用于酬赏**之后**（可留摩擦）。
  判断口诀：这一步在用户"爽到"之前 → 删；之后 → 可能要留。
  误用后果分别是 ce07（先索取后给）与 ce08（删光沉淀）。
- 与 `variable-reward-design` 的区别：酬赏是产品**给**用户的，
  投入是用户**给**产品的。顺序固定：先酬赏后投入。
- 与 `load-next-trigger` 的区别：那个是投入的**第三个作用**——
  把刚才的投入转成未来的触发。本 skill 管"存什么、什么时候要、要多少"，
  那个管"存完之后怎么把人叫回来"。两者必须联用，否则闭环断在最后一环（ce20）。
- 与 `commitment-escalation` 的区别：那个是**通用的态度改变机制**
  （用于说服、团队变革、自我改变），面向人；
  本 skill 是**产品投入阶段的设计程序**，面向产品。
  本 skill 引用宜家效应/一致性作为理论依据，那个把它当成独立工具使用。

## E — 可执行步骤 (Execution)

1. **确认酬赏已经兑现**
   - 检查：用户在被要求投入之前，是否已经体验过一次核心价值？
   - 判停条件：没有 → 停止设计投入，先回 `variable-reward-design`
     或修复首次体验路径。此时做投入设计只会制造流失（ce07）。

2. **盘点五形态：我的产品能沉淀什么**
   - 逐项打分（不可能 / 弱 / 强）：内容、数据资料、关注者、信誉、技能。
   - 完成标准：至少锁定 1 个"强"或 2 个"弱"形态作为主攻方向。
   - 判停条件：五项全为"不可能"（纯一次性服务、纯信息展示）→
     承认这不是习惯型产品，回 `habit-zone-screening` 重新定位。

3. **为主攻形态设计具体的沉淀物**
   - 内容 → 用户创建了什么？（笔记/歌单/清单/相册）
   - 数据资料 → 系统记住了什么让下次更好用？（偏好/历史/配置/画像）
   - 关注者 → 用户和谁建立了关系？（好友/订阅/小组/同伴）
   - 信誉 → 用户积累了什么身份凭证？（评分/等级/作品集/助教身份）
   - 技能 → 用户学会了什么只在本产品有效的能力？
   - 完成标准：每个形态写出 1–2 个具体的用户动作。

4. **做位置判定：这些动作在闭环的哪一段**
   - 逐个动作标注：在酬赏之前（属行动，须简化）/ 之后（属投入，可留摩擦）。
   - 完成标准：所有索取型动作都被明确排在酬赏之后。
   - 这一步是本 skill 与 `ability-simplification` 的交接口。

5. **设计投入阶梯**
   - 第 1 次循环：一次点击级（收藏、点赞、打个标签）。
   - 第 3–5 次循环：轻量创建（写一条备注、加一个同伴、设一个偏好）。
   - 第 10 次以上：重投入（完整档案、公开作品、承担角色）。
   - 完成标准：给出至少 3 级阶梯，并注明触发条件（第几次/达成什么后）。
   - 纪律：**不要把重投入前置**，也不要一直停在一次点击级。

6. **检查摩擦是否"有回报"**
   - 每一处保留的摩擦，都必须能回答："用户付出的这一点，未来换回什么？"
   - 完成标准：每条投入动作都配一句"未来收益"说明。
   - 判停条件：答不出 → 这不是投入，是纯粹的门槛，删掉。

7. **接上下一个触发**
   - 检查每一项投入能否合法生成一次未来提示（转 `load-next-trigger`）。
   - 完成标准：至少 1 条"投入 → 未来触发"的链路。
   - 判停条件：全部投入都不产生后续通知 → ce20，闭环断裂。

8. **做伦理检查**
   - 问：这些沉淀是**用户的资产**还是**我们的锁链**？
     用户能否导出、能否带走、离开时是否被惩罚？
   - 完成标准：明确回答，并给出数据导出/账号注销路径。
   - 判停条件：若沉淀的唯一作用是让用户走不掉 → 转 `manipulation-matrix-ethics`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **用户尚未体验核心价值**——顺序错，投入变纯成本（ce07）。
- **首次行动的门槛问题**——那是能力问题，摩擦要删不要加，
  转 `ability-simplification`。
- **低频品类**（年度体检、报税、婚礼）——沉淀了也没有下一次循环来兑现，
  投入设计的收益极低（ce10）。
- **一次性交易/工具**（转换格式、查快递）——用户本就不打算长期停留，
  强行索取投入只会赶客。
- **靠合同/硬性绑定实现的锁定**（长约、押金、数据不可导出）——
  那是商务手段，不是本 skill 讨论的行为设计，且常常越过伦理线。

### 作者在书中警告的失败模式

- **ce07 — 一上来就索取投入**：注册即要求填完整资料、上传头像、邀请好友、绑定账号。
  警告信号：注册流程超过 3 屏；未体验核心价值前就要求授权/付费/邀请；
  首日流失集中在引导环节。
- **ce08 — 把"降低门槛"教条化**：删掉所有需要用户投入的环节，
  结果产品没有储存价值，用户零成本迁移。
  警告信号：用户走了不心疼；产品无个性化沉淀；留存曲线始终平坦无回升。
  （ce07 与 ce08 是一对反向错误，本 skill 的位置判定就是用来同时避开两者的。）
- **ce20 — 加载下一个触发缺失**：用户投入了，但系统没把投入转成未来触发，
  闭环变成单次直线。
- **ce14 — 用沉淀绑架用户**：隐藏退出路径、不允许导出数据——
  从留存滑向经销商象限。

### 作者的盲点 / 时代局限

- 书中默认"储存价值越高越好"，未认真讨论**数据可携带权**
  （GDPR/个人信息保护法之后，数据资料这一形态的迁移成本被制度性削弱）。
  今天更可靠的是**关注者、信誉、技能**这三类难以导出的形态。
- 五形态是描述性分类，书中未给出**优先级判据**——
  哪一种形态最适合本品类需要自行判断。经验规律：
  社交产品优先关注者，工具优先内容/数据，社区优先信誉，专业软件优先技能。
- 未讨论**沉淀的负担面**：存太多东西也会让用户产生管理焦虑（收藏夹吃灰），
  过量沉淀甚至构成打开产品的心理门槛，这是书中完全没有触及的反作用。
- **B 端场景**中投入常由组织而非个人完成（配置、集成、流程沉淀），
  个人层面的宜家效应可能不成立，书中案例几乎全是 C 端。

### 容易混淆的邻近方法论

- **转换成本 / 锁定（Switching Cost, Lock-in）**：经济学视角，
  常包含合同与专有格式等强制手段；本 skill 的储存价值是**用户自愿积累的资产**，
  两者在伦理上分处两端，不要混谈。
- **网络效应**：价值随他人数量增长；储存价值是**个人**积累的沉淀，
  即使只有一个用户也成立（Evernote 的笔记）。
- **沉没成本谬误**：解释用户为何不肯放弃；本 skill 强调的是
  储存价值带来的**真实增值**（越用越好用），而不只是心理沉没。
  若你的"投入"只产生沉没成本而无实际增值，那是操控不是留存。
- **Onboarding / 激活设计**：目标是让用户尽快体验价值（属行动阶段）；
  本 skill 恰恰在其**之后**接手。
