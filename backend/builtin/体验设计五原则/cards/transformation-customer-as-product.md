## I — 方法论骨架 (Interpretation)

### 一、先定级：五种产出的完整对照（表9-1 精简）

| 维度 | 初级产品 | 产品 | 服务 | 体验 | **变革** |
|---|---|---|---|---|---|
| 经济职能 | 提取 | 制造 | 交付 | 营造 | **引导 guide** |
| 产出性质 | 可互换 | 有形 | 无形 | 可回忆 | **可改变** |
| 主要属性 | 自然性 | 标准化 | 定制化 | 个体性 | **独立性（个别化）** |
| 供应方式 | 散装储存 | 生产后库存 | 按需交付 | 周期性展示 | **长期性持续** |
| 卖方 | 交易商 | 制造商 | 提供商 | 营造商 | **诱导商** |
| 买方 | 市场 | 用户 | 客户 | 宾客 | **渴望者 aspirant** |
| 需求要素 | 特性 | 特征 | 利益 | 感受 | **特质** |

**渴望 ≠ 期望**：期望关注外部功能或利益；**渴望关注顾客自身、指向他想成为的样子**。

### 二、为什么必须升到第五级：体验也会被初级产品化

> 同一个主题餐厅第二次去的体验比第一次大打折扣，第三次更差，几次之后根本提不起兴趣。

顾客原话就是最强衰退信号：**"哦，那个啊，早去过了，早试过了！"**

逃逸方向与前四级完全一致——**定制化**。当你为每个顾客定制体验（完全贴合其当下需求），必然为每个顾客带来改变，体验自动升级为变革。

### 三、判定三条（缺一不算变革）

1. **持续性**：变化必须持续。减肥反弹、坏习惯复发、成本回升、浪费重现 → 那只是"有限提升"，**不构成变革**。任何倒退都会削弱已实现变革的强度。
2. **结构性**：不仅是量的变化更是质的突破，不仅是功能上的变化更是**结构上的更新**——影响的是消费者本身的存在状态。
3. **不可复制**：**"当变革第二次发生时，经历它的人已经不再是当初那个人了。"**

### 四、最锋利的定级判据：你在对什么收费（第10章）

> - 对**原料**收费 → 初级产品开采
> - 对**有形产物**收费 → 产品生产
> - 对**实施的活动**收费 → 服务提供
> - 对**花在顾客身上的时间**收费 → 体验营造
> - 对**顾客实现的结果**收费 → **变革引导**

健身房推演（示范）：真正的变革业务不收会员费、不按器械时长收费，而是**按帮助会员实现的健身目标收费**，未达成则不收或按已实现成果按比例收。**"它收费的目标不是顾客付出的辛苦而是得到的收获。"**

由此倒逼四项经营变化：
1. 花大量时间做**前期了解**，再决定是否接受入会（很多人并不具备坚持的意志）；
2. 停止盲目招收会员冲收入（多数会员很少来，短期赚钱长期得不偿失）；
3. **"确定需求"这个活动本身就是可收费的体验**——"早在顾客成为会员之前，变革业务就可以带来利润"；
4. 确认准备好之后再按具体目标定价，价格可达器械使用费的 **2–3 倍甚至 10 倍**。

### 五、图9-4 引导变革三阶段（本 skill 的主流程）

**① 确定顾客渴望**
- 三问：渴望的变化是什么？离目标有多大差距？该从哪些角度体现？
- 难点一：渴望者**往往说不清自己的期望和梦想**（与规模化定制同构的难题）。
- 难点二：**错误的渴望**——目标对其自身当前状态有害。
- **道德刹车条款**：如同金融机构须避免顾客错误投资、主题公园须避免宾客危险举动，**变革诱导商有道德责任避免渴望者去实现不合理或不道德的特质**。

**② 营造变革体验**
- 基础 = 能让顾客**意识到**其渴望目标（哪怕他说不清）的、可改变人生的体验。
- 4E 在变革中的功能分工：娱乐性→改变我们对世界的看法；教育性→重新思考如何更好地适应世界；逃避性→把个人能力与特征提升到新水平；审美性→灌输鉴赏能力。**最能改变人生的仍是四范围齐备的"蜜罐"。**
- 范围放大判据：高尔夫教练的目标不是改善"击球这个小动作的体验"，而是**把菜鸟变成老练的选手**（覆盖精神准备、瞄准、挥杆、树林、球杆、切球、沙坑、推杆、规则、球场管理、计分）。

**③ 后续实施过程（最难、最常缺失）**
- 判据：无法持之以恒、新鲜一阵就难以为继 = **伪变革**。
- 正例：嗜酒者互戒会——"一次不喝酒容易，彻底戒除酒瘾很难"，靠互相监督鼓励。
- **三连诊断器**：咨询只给战略分析不管落地 = 服务业务；教育只传知识不管学以致用 = 充其量体验业务；医生只治生理不管情绪 = 只做了一半。

### 六、保全 → 保障 → 保证（跨行业升级提问器，图9-2）

| 层级 | 产出 | 顾客得到 |
|---|---|---|
| 服务 | 保全 | 遇到损失时有所补偿 |
| 体验 | 保障 | 信心、鼓励、信任和满足感 |
| **变革** | **保证** | **事件、情况或结果本身** |

通用自检：**你所在行业里，什么分别对应"保全 / 保障 / 保证"？**

### 七、变革层的三件配套

- **象征物（变革层的"纪念品"）**：戒指、十字架、旗帜、奖杯、锦旗、奖章、徽章、证书。功能是**标记状态跃迁**（未婚→已婚、参赛者→冠军、士兵→英雄），并让人识别同类、形成圈子。
- **同类圈子（排练场）**：把渴望相似的顾客聚成小圈子——**不要把他们当作互不相关的市场细分，而要当作一群密切联系的角色**，彼此强化渴望目标的正确性。
- **变革性担保定价**：把一部分费用交给顾客按结果决定（见 A1 案例 4）。

### 八、赢得"被引导的信任"四步（第10章）

1. **先具备定制化能力**（没有一对一关系，没人把自己交给你）；
2. **营造真正有吸引力的体验**，直到听见顾客说"**你们让我意识到了一个全新的我**"——听到这句才可以把顾客的渴望作为业务目标；
3. **为表演者提供排练新表现的场所**（同好圈子）；
4. **引导表演者**——渴望者需要引导，**但不想在别人的命令下行事**。作者结论：**"引导即导演！"**

铁律：**"变革诱导商无法改变顾客，他们只能引导顾客实现变革。"**"强扭的瓜不甜……做出这种改变决定的只能是顾客自己。"

## A1 — 书中的应用 (Past Application)

### 案例 1：飞利浦生命线医疗报警系统（第9章，付费者≠使用者）
- **问题**：设备 + 24 小时监控 + 派人处理，看起来是产品加服务，为什么它属于变革？
- **方法论的使用**：反直觉数据——**真正紧急援助来电不到 5%**，很多人打来只是因为寂寞，聊聊会好一些。而**大部分购买者是使用者的亲人**。
- **结论**：真正被交付的产出，是购买者（子女）的**状态改变**——"内心的宁静"。
- **结果**：确立了一条判定规则：付费者与使用者分离时，先问"谁的状态被改变了"，产出定义随之改写。

### 案例 2：中哥伦比亚医疗中心（MCMC）希利罗癌症治疗中心（第9章）
- **问题**：一家俄勒冈小城的癌症中心如何吸引全美 20 多个州的病人？
- **方法论的使用**：**五维全面变革**——生理治疗（全美第二家可实施强度调控放射疗法）、社交治疗（治疗花园与家人共处）、智力治疗（医疗图书馆，含替代疗法）、环境治疗（雕塑花园、瀑布假山调节情绪）、精神治疗（内设沉思室，外建迷宫供冥想祈祷）。**把 1/3 空间用于"非功能性"场所**，因为压力是很多健康问题的来源。
- **结论**：作者的判据句——"这种做法颠覆了传统医院的形象，只因为它经营的是**超越了产品、服务和体验的变革业务**"。
- **结果**：五维模板（生理/社交/智力/环境/精神）可迁移到教育、健身、企业培训。

### 案例 3：GSK 戒烟"承诺者"项目（第9章后半）
- **问题**：卖戒烟口香糖/贴片/含片，成功率仅约 24%。
- **方法论的使用**：改为个人化项目——热线摸清吸烟习惯（每天几根、何时最想吸、最大障碍）→ 定期邮寄信件/手册/内情通报 → 电话、邮件、网站跟踪数周。即完整的"确定渴望 → 体验 → 后续实施"。
- **结论**：产品公司也能做变革，且**不必放弃产品**。
- **结果**：成功率比传统方式**高出 50%，同时卖出更多产品**——这是本 skill 最有说服力的量化证据。

### 案例 4：变革性担保定价（第10章：Priority / Celerant / Starizon）
- **问题**：如何让"按结果收费"在实务中落地而不失控？
- **方法论的使用**：
  - **Priority 管理公司**（温哥华）：确定当前生产率 → 营造培训 → 为每位顾客配专业培训师指导后续实施，**承诺达不到目标可不付费**。通常至少把生产率提高 20%。
  - **Celerant**（伦敦）：口号"永久改变企业"，收费与绩效标准挂钩。加里·泰勒："顾客需要得到的是确定的变化……我们要做的就是给他们承诺，消除他们的顾虑。"
  - **Starizon 工作室**（科罗拉多）：**25% 的咨询费用基于"变革性担保"**——顾客可自行决定全额支付、部分支付或完全拒付这部分。
- **结论**：担保不必是全额对赌，**切出一个可拒付的比例**即可完成风险信号传递。
- **结果**：Priority 明尼苏达分部**超过 95% 顾客续约**；罗杰·万根点出机制——"如果有人可能达不到共同制定的目标，我就要加倍努力才能保证对方得到想要的结果"（**担保反过来约束的是供方的投入**）。

### 案例 5：伦敦商学院的自我重定义（第9章）
- **问题**：一所商学院如何跳出"教育服务"的比价？
- **方法论的使用**：宣布"**我们从事的不是教育业务，而是变革业务**……希望每个参与项目的人，无论三天短训还是两年系统学习，都能在这种学习体验的基础上改变自己的人生"。
- **结论**：**重新定义产出，会重新激励全体员工**——"这里的每个人，从管理员到院长，都得到了前所未有的激励"。
- **结果**：本 skill 的一条附带收益：产出重定义是一次组织内部动员，不只是对外定位。

### 案例 6：美国罪犯改造公司 CCA（第9章，边界诚实）
- **问题**：监狱能不能是变革业务？
- **方法论的使用**：一半犯人无高中文凭 → 补习与教育课程；有文凭者 → 职业培训（柴油机维修、汽车修理）；戒毒服务"甚至比贝蒂福德疗养院还要好"。
- **结论**：作者同时给出**诚实的边界声明**——约 20% 的精神病患者与反社会者，**目前已知手段无法改造**。
- **结果**：成本论辩也被改写："我们认为**为每一个犯人提供希望才是最大的成本效益**。"（对照比德维尔培训中心比尔·斯特里克兰："现在，他们是一群有能力积极投入生活的人了……这就是产出，这就是产品。"）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **体验被初级产品化**：新鲜感掉得快、复购下滑、"早试过了"、同行两个月就抄完。
2. **自由职业/服务商被压价**：作品质量不差但客户只比价（因为在卖"活动"而非"结果"）。
3. **做的本来就是改变人的生意**：健身、教练、心理咨询、康复、教育、职业培训、理财顾问、宗教/冥想、戒断类项目——却按课时/会员期/人天收费。
4. **企业服务转"客户成功"**：SaaS 想做 outcome-based pricing、想降低 churn。
5. **培训/咨询交付完就失效**：课上得很好、报告写得很好，三个月后现场没变化。
6. **付费者与使用者分离**：给父母买的、给孩子买的、公司给员工买的——不知道该对谁定义产出。
7. **要设计会员体系或长期陪伴产品**：需要"持续性"而不是"周期性展示"。
8. **要给高价服务设计信任装置**：客户觉得风险大不敢签。

### 语言信号 (用户的话里出现这些就应激活)

- "客户来一次就不来了 / 早试过了 / 没新鲜感了"
- "被压价 / 只比价 / 客户觉得都差不多"
- "我们按课时（人天/会员/坐席）收费"
- "培训完没效果 / 学员完课率高但没用 / 报告交了就完了"
- "怎么做客户成功 / 续费率上不去 / churn 高"
- "想按结果收费 / 效果付费 / 对赌 / 保证 / outcome-based"
- "顾客到底想要什么 / 我们到底在卖什么"
- "减肥反弹 / 复发 / 坚持不下来"
- "transformation" / "customer success" / "aspirant" / "outcome pricing"

### 与相邻 skill 的区分

- 与 `economic-value-progression` 的区别：那个是**定级器**（判断你现在处在五级中的哪一级、要不要升级）；本 skill 只处理**最上面一级的识别、设计与定价**，深度远超前者。定级后若结论是"该升到变革"，才进入本 skill。
- 与 `charge-unit-redesign` 的区别：那个改**计价单位**（按什么收），可以停留在体验层（按时间收）；本 skill 要求**同时改产出定义**（顾客本人成为产出）。只改计价不改交付 = 空头承诺，会直接引发赔付。
- 与 `experience-design-five-principles` / `four-realms-experience-scan` 的区别：那两个把体验做好；本 skill 把做好的体验**变成变革的手段**（第②阶段调用它们）。
- 与 `customer-sacrifice-measurement` 的区别：那个测的是"顾客将就了什么"（体验层的定制化入口）；本 skill 问的是"顾客想成为谁"。**损失是缺口，渴望是方向。**
- 与 `hook-model-loop` / `habit-*` 系列的区别：那些追求**持续使用产品**（留存是目标）；本 skill 追求**顾客的持续改变**，成功的终局甚至可能是顾客不再需要你。二者的伦理姿态相反，见 `manipulation-matrix-ethics`。
- 与 `future-self-vividness` 的区别：那个是让"未来的自己"变生动以促成当下行动（单点干预）；本 skill 是把"成为未来的自己"设计成完整的商业产出。前者可作为本 skill 第①阶段的工具。
- 与 `expectation-experience-engineering` 的区别：那个改变的是**对同一事物的体验感受**；本 skill 改变的是**人本身**，且必须持续可验证。
- 与 `positioning-*` 系列的区别：那些改的是心智中的位置；本 skill 改的是产出本身。

## E — 可执行步骤 (Execution)

1. **定级：你在对什么收费？**
   - 用五句判据对号入座（原料/有形产物/实施的活动/花在顾客身上的时间/顾客实现的结果）。
   - 完成标准：写出一句"我们目前实际在对 ______ 收费"，并诚实标注这是第几级。
   - 常见结果：自称做"体验/成长/陪伴"，实际在对"活动"收费 = 服务级。

2. **做初级产品化体检**
   - 找 5 位老顾客，问他们第二次、第三次来的感受。
   - 红灯句："早去过了，早试过了。"出现即确认体验层正在衰退。
   - 完成标准：一句顾客原话 + 复购/续费数据。

3. **改称谓：把"客户/用户/宾客"改写成"渴望者"**
   - 强制回答：**他想成为谁？**（不是"他要什么功能"）
   - 区分渴望与期望：期望指向外部利益，渴望指向他自身。
   - 完成标准：写出 3 类渴望者画像，每类一句"他希望成为 ______ 的人"。
   - 若付费者≠使用者：分别写两句，并判断**产出实际发生在谁身上**（Lifeline 判据）。

4. **过三条判据，判断你能否真的做变革**
   - 持续性：交付结束 3–6 个月后，变化还在吗？可度量吗？
   - 结构性：是量的改善还是状态的跃迁？
   - 不可复制：同一个人再来一次，还是同一个产出吗？
   - 判停条件：**三条过不了两条，不要对外宣称变革**，回到体验层做扎实（转 `experience-design-five-principles`）。虚假的变革承诺是本 skill 最大的风险。

5. **①确定渴望：把"确定需求"做成独立收费环节**
   - 三问：渴望的变化是什么？离目标多远？从哪些角度体现？
   - 承认渴望者说不清 → 用具体情境、对照物、他人故事帮他说出来。
   - **道德刹车检查**：这个渴望对他当前状态是否有害？有害则拒接（金融机构避免顾客错误投资的同构义务）。
   - **定价动作**：把这一环节单独定价。依据："早在顾客成为会员之前，变革业务就可以带来利润。"
   - 完成标准：一份"渴望说明书"（现状/目标/差距/验证方式），且已收费或已明确标价。

6. **②营造变革体验：用 4E 铺满，并放大范围**
   - 逐项设计娱乐（改变看法）/教育（重新思考适应方式）/逃避（能力跃迁）/审美（鉴赏力），追求"蜜罐"。
   - 放大范围检查：你现在优化的是"某个小动作的体验"，还是"把菜鸟变成老练选手"的全过程？（高尔夫教练判据）
   - 完成标准：一张覆盖全过程的清单，且四个象限都不为空。
   - 目标信号：听到顾客说"**你们让我意识到了一个全新的我**"——听到这句才算这一步成立。

7. **③后续实施：先设计它，再谈交付（最容易漏的一步）**
   - 三连诊断先自查：只分析不落地？只传知识不管应用？只治一半？
   - 设计三件套：**追踪机制**（多久看一次、看什么指标）、**同类圈子**（渴望相似者组成的排练场）、**复发预案**（复发触发更强决心，而不是判定失败）。
   - 完成标准：交付结束后的时间轴上，至少有 3 个明确的接触点与责任人。

8. **定价：按结果 + 变革性担保**
   - 主体价格锚定**目标达成**而非时长（健身房推演：可达器械费的 2–10 倍）。
   - 切出一个可拒付比例（Starizon 用 25%）：顾客可全额付、部分付或拒付。
   - 分级：设中期目标与对应的分段收费，避免全有全无。
   - 完成标准：价格表上写明"什么算达成""谁来判定""未达成如何处理"。
   - 风控：**先算清楚在最坏达成率下是否仍能存活**，再上担保。

9. **加象征物，不要加纪念品**
   - 体验层给纪念品（唤起回忆）；变革层给**象征物**（标记状态跃迁）：证书、徽章、戒指、称号、进阶身份。
   - 判据：它是否能让持有者**被同类识别**。
   - 完成标准：设计一件在跃迁时刻交付的象征物。

10. **组织侧收尾：重新定义产出并对内宣告**
    - 学伦敦商学院，把"我们从事的不是 ______ 业务，而是变革业务"说给全员听。
    - 完成标准：至少一个非一线岗位（行政、财务）能说出顾客的渴望是什么。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **顾客并不想改变**：铁律是"变革诱导商无法改变顾客，他们只能引导"。**强扭的瓜不甜**——顾客未主动做出不同表现，变革无从谈起。此时应回到体验层。
- **结果高度受外部因素支配**：求职结果、投资收益、诉讼胜负、疾病预后。按结果收费在这些领域会诱发**筛选好客户 + 隐瞒失败**的系统性扭曲（教育与医疗的经典批评）。
- **一次性、低频、无后续接触的生意**：变革要求"长期性持续"的供应方式，没有接触点就没有第③阶段。
- **无法度量或度量成本过高**：变革的三条判据都需要验证；不可验证的"变革"就是营销话术。
- **渴望不正当**：道德刹车条款直接适用——不合理或不道德的特质，不接。
- **合规敏感领域的效果承诺**：医疗、教育、金融对"保证效果"的宣传通常有法律限制。**先过法务再谈担保。**

### 作者在书中警告的失败模式

- **伪变革**：无法持之以恒、新鲜一阵就难以为继。
- **只做一半**：咨询只分析不落地 / 教育只传知识不管应用 / 医生只治生理不管情绪。
- **盲目招收会员冲收入**：短期赚钱、长期得不偿失（不断更换到期会员），且损失了本可从渴望者身上获得的全面价值。
- **咨询业的按摩式循环**：作者引用的毒舌类比——"就像给你做按摩服务，哪怕你按摩了 180 多次之后问题还在那里，你还是要回来接着按摩。"**复购成为收入来源时，不解决问题反而更赚钱**——这是变革业务最深的利益冲突（参见 `conflict-of-interest-design`）。
- **错误的渴望被照单全收**。
- **价值观防御被低估**：《福布斯》报道有些家长把武术学习限于技击训练，不愿选"东方的武术学校"——**变革产出会触发价值观防御**，卖得越深，抵触越强。
- **象征物缺失**：跃迁没有被标记，顾客自己也感受不到"我已经不同了"。

### 作者的盲点 / 时代局限

- **⚠️ 案例时代局限**：第 9、10 章案例集中在 1990s–2010s——主题餐厅、监狱私有化（CCA）、有线医疗报警设备（Lifeline）、生日聚会连锁、戒烟邮寄计划。**载体已大量更替，框架仍成立。**当代等价形态：订阅制健康管理、SaaS 的客户成功与 outcome-based pricing、在线教育的完课与转岗承诺、AI 陪伴与心理干预、可穿戴设备的持续追踪。事实上**"体验→变革"的递进在订阅经济中反而更成立**（持续性天然可度量）。
- **⚠️ 反向风险被作者低估**：正因为今天"变革"话术极易被滥用为营销包装（"改变你的人生""重塑认知"），本 skill 必须与三条判据强绑定使用——**不能验证持续性，就不许自称变革**。作者只在第 10 章给了原则性伦理约束，没有给出可执行的滥用防线。
- **按结果收费的度量政治未讨论**：谁定义"达成"、谁掌握数据、争议如何仲裁——书中的 Priority/Celerant/Starizon 都语焉不详。实务中这是最大的落地障碍。
- **筛选渴望者 = 主动缩小市场**，对现金流紧张的小生意可能致命。书中把它当作能力，未讨论过渡期怎么活。
- **"引导即导演"与顾客自主的张力**：既说"渴望者不想在别人的命令下行事"，又说要引导，二者的边界只靠"微妙关系"四个字带过。
- **数据化追踪的隐私代价**：持续性验证在今天意味着持续采集（Safeco Teensurance 已经用 GPS 监控青少年车速与宵禁）。**监控式变革**的伦理成本书中完全未提。
- **变革的不可逆与退出权**：顾客改变到一半想退出怎么办？书中没有退出机制设计。

### 容易混淆的邻近方法论

- **Outcome-based pricing / 效果付费**：只是本 skill 第 8 步的一个环节。**只改收费不改三阶段交付 = 直接亏损**。
- **客户成功（Customer Success）**：与第③阶段高度重合，但 CS 的目标函数通常是续约与净收入留存，本 skill 的目标函数是顾客的状态改变。**当两者冲突时（顾客改变完成后应当离开），CS 会选择留人。**
- **Jobs to Be Done**：问"顾客雇你完成什么任务"（仍是功能与期望）；本 skill 问"顾客想成为谁"（渴望）。JTBD 更适合产品定义，本 skill 更适合产出定级。
- **教练技术 / Coaching**：是第②③阶段的具体手法，不含定级与定价框架。
- **习惯养成类方法（`hook-model-loop`、`investment-design`）**：目标是让用户持续回来；本 skill 目标是让用户持续改变。**留存指标漂亮但顾客毫无改变，恰恰是本 skill 判定的失败。**
- **变革管理（Change Management）**：那是组织内部推动变革的方法；本 skill 是把"引导他人变革"作为对外销售的产出。二者同名不同域。
