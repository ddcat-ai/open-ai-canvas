## I — 方法论骨架 (Interpretation)

### 一、图8-1 表演模型：五对映射（先换透镜）

| 戏剧概念 | 企业对应 |
|---|---|
| 演职人员 | 员工 |
| **角色** | **职责** |
| **特征** | **呈现** |
| 整体（ensemble） | 组织 |
| 舞台 | 工作环境 |

链式命题（上表不是比喻，是四步依赖）：**承担角色 → 开发特征 → 形成整体 → 难忘地吸引顾客**。任何一环断，后面全断。

### 二、本 skill 的第一个核心区分：角色 ≠ 特征

- **角色 = 外在表现，你要承担什么职责。**（岗位说明书写的全是这个）
- **特征 = 内在选择的集合，你以什么面貌承担它。**是"工作者为描述其演出所做的一系列选择"。

> 吉连·德雷克（为律师做表现培训的演出指导）："在表演过程中，观众看到的每一件小事都是选择的结果——演员服装上的扣子、盘头发的方式、手中的道具、灯光效果。对律师行业来说，成功的关键也在于对每个细节的选择。"

**推论（本 skill 最强的诊断句）**：
> 同岗位表现方差极大，通常不是执行力问题，是**特征从未被定义** + **选角方式选错**。
> 而**没有被详细定义的角色**，会直接把工作变成"费力不讨好、为了完成而完成的磨洋工"。

特征说明至少写六项：**语气、节奏、姿态、与顾客的物理与心理距离、允许即兴的范围、禁止即兴的范围。**

### 三、整体（ensemble）优先于个人特征

《舞台和戏剧术语词典》：整体是"演职人员作为一个团队而非一群个人表演者的形式创造整体效果的一种演出类型"。

- **抢戏 = 办公室政治**：个人利益压过整体表演效果。
- 真正的主演靠**磨炼技巧 + 长期合作**（善于观察和倾听、尊重搭档、想提高双方水平）成名，不靠抢戏份。
- 选角决定的最后一句话（一位导演原话）：你是在"**选择关系而非每个角色本身**"——新人是否适合角色是其次的，要考察的是他以后能在多大程度上和舞台全体积极互动。

### 四、本 skill 的第二个核心区分：试演 ≠ 面试

| | 面试 interview | 试演 audition |
|---|---|---|
| 测什么 | 会不会说（自述经历） | 能不能演（现场呈现） |
| 单位 | 个体 | 个体 **与关系** |
| 材料的作用 | 主要评估手段 | **只作筛选进入试演的手段** |
| 预测的是 | 语言组织能力 | 角色胜任与潜力 |

作者的顺序修正（与今天 HR 的做法完全相反）：
> 现在的做法是先面试所有应征者，最后只安排被聘用的人做试用期表演。
> 正确顺序是：**先全部试演 → 再对值得考虑的人安排面试**（此时面试才能获得有价值的信息）。

好面包餐厅（Au Bon Pain，伦纳德·施莱辛格）：最终面试前安排**两天的店内付薪工作体验**，靠自我选择 + 管理层行为观察双向淘汰。

### 五、组织试演的四条原则

1. **给真实场所**：采购给一间办公室让供应商来谈；出纳给一个窗口处理存款支票余额；呼叫中心给几部电话现场接听。必要时到客户公司或顾客家中演。不必演完整场，只演**几个重要而有表现力的场景**。
2. **环境力求简单、道具最少**：故意取消日常环境里的一般特性，观察他**在缺少额外帮助时如何创造性解决问题**（采购不许带资料、出纳台不许贴规定、坐席只有一部电话）。依据是史翠珊案例——**道具是否真实不重要，重要的是你怎样证明表演符合角色需要**。
3. **看特征，也看与全体的一致性**：既观察他如何表现角色特征，也观察他的表现是否与现有全体演员协调。
4. **不要急着做决定**：先入为主的成见会在初选中淘汰真正合适的人。要评估的**不是他在试演中的具体表现，而是他未来发挥这个角色的潜力**。

### 六、4P 型星探（托尼·卢卡德罗，50 年发掘 50 位大联盟球星）

| 类型 | 做法 | 病症 |
|---|---|---|
| 糟糕型 Poor | 毫不准备，只看台上选手 | 根本不具备挖掘潜力的能力 |
| 挑选型 Picker | 眼里只有缺点 | 优秀人才被埋没 |
| 表现型 Performance | 仅凭试演当场表现判断（**行业内占绝大多数**） | 过度依赖当场发挥（高中球星打弱旅的假象） |
| **投射型 Projection** | 认为试演结果本身不重要，问的是"当他真正投入角色时是否具备所需技巧" | 卢卡德罗本人与优秀选角导演的做法 |

**要找的人不是最"理想"的（符合先入为主的角色想象），而是"未经雕琢、但能敏锐理解表演活动、能够做出不同选择"的人。**

### 七、选角八问（由企业回答，不是由应征者回答）

1. 沟通能力如何？——特别留意**对方聆听表达的方式**。
2. 和其他人的关系如何？——在试演中怎样与其他演员建立关系，在什么情况下**寻求、给予和拒绝**帮助。
3. 希望从人际互动中得到什么？——行为动机。
4. 如何处理陌生环境、打扰和中断？——**人们只有在情况失控的时候才会寻找自我证明。**
5. 能否与观众互动时把握节奏？——能否利用试演中的突发事件巧妙组织顺序、进展与时间。
6. 是否具备幽默感？——觉得什么滑稽、是否妙语连珠，显示智力水平与学习意愿。
7. 是否做过具有独特创意的事情？——能否做出与众不同的选择。
8. 能否营造惊喜体验？——是否擅长**管理和提升观众期望**。

> 评判纪律：**不要对试演中的某个特定选择轻易做出评判**（试演毕竟是模拟）。要评估的是**选择能力**——他能否为角色（职责）创造全面的特征（呈现）。
> 补充：了解应征者**工作之外的兴趣**——生活经验越丰富，越可能做出有意思的选择。

### 八、剧中人物表（dramatis personae）

企业很少以书面形式公开承认员工表现（年报只列高管、衣服标签只写"7 号质检员"）。作者主张体验营造商应当有剧中人物表，并点明：**它的存在是为了演员自己，而不是为了观众**——包含从未登台的编剧、剧本作者、技术人员、剧务与舞台监督。

## A1 — 书中的应用 (Past Application)

### 案例 1：斯托克代尔的"我是谁？为什么要到这儿来？"（第8章开篇）
- **问题**：1992 年副总统辩论中这句开场白成为公认的失败标本。
- **方法论的使用**：作者不把它读成"这人不行"，而读成**选角失败**——角色与人不匹配。
- **结论**：用人失败的归因方向应从"人的能力"转向"角色设计 + 选角方式"。
- **结果**：这是全章的定调案例，也是本 skill 的归因反转来源。

### 案例 2：芭芭拉·史翠珊的口香糖（第8章，选角导演迈克尔·舍特列夫）
- **问题**：舍特列夫担心她的大鼻子不适合主演玛梅，但仍安排了最后一次试演。
- **方法论的使用**：史翠珊在来试演的路上从旧货店买了一双漂亮鞋子，进场后一直嚼口香糖，坐下时把"口香糖"往凳子下一粘——而**凳子下面根本没有口香糖，她试演前嘴里嚼个不停完全是设计好的**。
- **结论**：她展示的不是台词功底，是**做选择的能力**（自带道具、自造细节、把角色特征具体化）。
- **结果**：作者以此确立"试演看的是选择能力"，并推出"道具是否真实不重要"这条试演设计原则。

### 案例 3：迪士尼的选角中心（第8章 p219）
- **问题**：如何让试演本身就是一次真实的角色预演？
- **方法论的使用**：迪士尼聘请后现代主义建筑师罗伯特·斯特恩专门修建**选角中心**。应征者必须穿过狭窄坡道，两侧墙上画满故事，"用建筑形式来阐述迪士尼的招聘过程"；沿建筑前行本身就是一次旅程，让人意识到**这个乐园的最大秘密——一切都是幻觉**。
- **结论**：试演场所本身就是舞台，把公司的真相提前交给应征者。
- **结果**：既是试演舞台，也是自我选择装置（不能接受"一切都是幻觉"的人会自行退出）。

### 案例 4：好面包餐厅的两天付薪试演（第8章 p217）
- **问题**：如何在最终面试前筛掉不合适的人？
- **方法论的使用**：伦纳德·施莱辛格描述——最终面试前安排两天的店内付薪工作体验，"通过自我选择和管理层对应聘者的行为观察两方面淘汰不合格的应聘者"。
- **结论**：试演是**双向**的：他在被观察，也在决定要不要来。
- **结果**：这是可直接复制的最低成本试演形态。

### 案例 5：花衣傻瓜的小丑帽（第8章，服装设计师）
- **问题**：投资咨询公司如何让"特征"落成可见的信号？
- **方法论的使用**：The Motley Fool（盖特纳兄弟，均有演员/导演背景）在金融家标准服装外**每人加一顶小丑帽**。大卫·盖特纳大意："越了解越发现那些身穿高级西服、用复杂图表和数字糊弄人的家伙对客户没安好心；如果那些家伙自认为聪明，那我们甘愿做傻瓜。"
- **结论**：特征不是抽象气质，是**一系列可见的具体选择**（服装、道具、称呼、姿态）。
- **结果**：对照反例——1990 年代后企业着装放松，但**放松后没人协调，每个演员的表演与每一幕的衔接失去一致性**；杰斐逊东部总医院因此成立专门团队制定《医院形象手册》。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **同岗位表现方差极大**：连锁门店/客服班组/带教老师之间评价差异巨大，SOP 已经很细。
2. **招人屡屡看走眼**：面试印象很好，上岗两周就发现不行。
3. **要写或改岗位说明书 / JD**：不知道除了职责还该写什么。
4. **要招面客岗位**：客服、销售、导购、讲师、主播、前台、护士、教练。
5. **团队没有"整体感"**：每个人都不差，合起来是一盘散沙；或有人明显抢戏。
6. **换了负责人后风格全变**：说明特征依附于人而非组织。
7. **AI 时代的"人设"设计**：给 AI 助手、虚拟主播、品牌客服写角色与特征说明（本 skill 的角色/特征二分可直接迁移为 system prompt 的两段式）。
8. **组织角色重排**：谁当制作人（定战略与资源）、谁当导演（保证一致性）、谁当剧本作者（写流程）、谁当技术人员（场景道具服装）——用图8-1 六大角色重划管理职责。

### 语言信号 (用户的话里出现这些就应激活)

- "同样的流程，每个人做出来完全不一样"
- "SOP 都写到那么细了，还是不稳定"
- "面试的时候挺好的，怎么上岗就不行"
- "这个岗位到底该招什么样的人"
- "JD 怎么写 / 岗位说明书怎么改"
- "团队各干各的 / 没有配合 / 有人抢功"
- "换了个店长风格全变了"
- "给 AI 写人设 / 客服机器人要什么语气"
- "hiring" / "job description" / "audition" / "role play 面试" / "cultural fit"

### 与相邻 skill 的区分

- 与 `four-performance-forms` 的区别：那个决定**给他多少剧本**（即兴/街头/搭配/戏台）；本 skill 决定**谁来演、以什么面貌演**。链条顺序：结构（`work-is-theatre-drama-structure`）→ 形式（`four-performance-forms`）→ 选角（本 skill）。三者常需连用。
- 与 `work-is-theatre-drama-structure` 的区别：那个排时间结构与起承转合；本 skill 管人与呈现。
- 与 `ability-simplification` 的区别：那个降低执行难度（让做得到）；本 skill 提高选人精度与呈现定义（让做得对且一致）。**先判断是"做不到"还是"没定义"**：做不到→前者，方差大→本 skill。
- 与 `incentive-inverted-u` / `charge-unit-redesign` 的区别：那些管动机与计价单位。**如果员工知道怎么做也做得到，只是不愿意做，本 skill 无效。**
- 与 `experience-design-five-principles` 的区别：那个管环境信号与主题一致性（顾客看到什么）；本 skill 管人的呈现（顾客遇到谁）。二者共用"一致性"标准，但对象不同。
- 与 `liking-paths` / `cooperation-over-contact` 的区别：那些改善既有关系；本 skill 在**入口处**（选角）就决定关系构成——"选择关系而非角色本身"。
- 与 `character-ip-master` / `ip-character-bible` 的区别（★易混）：那些是**内容侧**的虚构 IP 设定，重点在视觉一致性与跨场景复用；本 skill 是**岗位侧**的角色与特征定义，重点在「以什么面貌履行什么职责」。**给 AI 客服 / 数字员工写人设属于岗位侧 → 本 skill**（它替代的是一个真人岗位，产出是角色+特征说明，不是形象设定）；给一个要反复出镜、需形象锁定的虚拟 IP 做设定 → IP 系。二者在"特征说明"的写法上可互相借用。

## E — 可执行步骤 (Execution)

1. **画出这一幕的角色表（不是组织架构图）**
   - 列出顾客在一次完整旅程中会遇到的所有角色，以及台下支撑角色（布景、幕间转换、调度）。
   - 迪士尼判据：**台下与台上同等重要**，所以全体都叫"演职人员"。
   - 完成标准：每个角色都有一句"他对顾客负责什么"。
   - 红灯：如果某个角色说不清，先停下——**未被定义的角色必然产生磨洋工**。

2. **给每个面客角色补一份"特征说明"（本 skill 的主产出）**
   - 六项必填：语气、节奏、姿态、与顾客的距离、**允许**即兴的范围、**禁止**即兴的范围。
   - 写法要求：像史翠珊的口香糖一样**具体到可执行的选择**，不要写"热情专业"这类形容词。
   - 完成标准：把特征说明交给一个没做过这岗位的人，他能照着演出大致相同的面貌。

3. **做一次方差归因**
   - 拿同岗位最好与最差的两次真实表现做对比，逐项对照特征六项，标出差异发生在哪一项。
   - 判据：差异集中在特征项 → 本 skill 有效；差异在于"根本没做完动作" → 转 `ability-simplification`；"知道但不做" → 转激励类 skill。

4. **把招聘流程倒过来：先试演，后面试**
   - 现状多为"全员面试 → 录用者试用"；改为"**候选人全部试演 → 值得考虑者再面试**"。
   - 简历与资料的角色降级为"**筛选进入试演的手段**"。
   - 完成标准：写出新的流程图，并明确面试挪到哪一步。

5. **设计试演场所（四条原则落地）**
   - 给真实场所（柜台/电话/办公室/客户现场），只演 2–3 个**重要而有表现力的场景**。
   - **道具最少化**：明确列出"不许带什么"（资料、贴纸、提词、现成话术）。
   - 安排至少一位现有员工同场，观察**关系建立**。
   - 完成标准：一份试演脚本（情境+时长+禁带清单+观察位）。

6. **用选角八问打分，且只由企业回答**
   - 八问逐条记录**行为证据**，不写印象词。
   - 强制项：第 4 问（失控时的反应）与第 8 问（惊喜与期望管理）必须制造出对应情境，否则观察不到。
   - 完成标准：每位候选人一张八问证据表。

7. **用"投射型"而非"表现型"做判断**
   - 明确写下：**这不是在评当场表现，是在评未来投入角色后的潜力。**
   - 反向清单：本次是否因先入为主的"理想人选画像"淘汰了未经雕琢者？
   - 完成标准：至少复盘一位"表现一般但选择能力强"的候选人，并给出保留或淘汰的理由。

8. **最后一问：选择关系**
   - 对入围者问：他与现有全体的互动会是什么样？会不会抢戏？
   - 判据：**抢戏倾向 = 办公室政治的前兆**，宁可要能观察、能倾听、愿意抬高搭档的人。
   - 完成标准：录用决定里写明"他将如何与全体互动"。

9. **上岗后闭环：剧中人物表**
   - 把这一幕的全部参与者（含台下）列成名单公开一次。目的是**给演员自己看**。
   - 完成标准：名单存在，且包含至少一位从未面客的台下角色。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯后台、无顾客接触、产出可完全客观度量的岗位**（数据处理、后端批任务、仓库分拣）：特征定义的边际收益很低，直接用角色定义与结果指标即可。作者也承认后台"只有后台观众看不到，可纯按功能设计"。
- **法律与合规高度约束的招聘**：试演可能触及公平就业、无薪劳动、隐私等合规红线。付薪试演（好面包餐厅模式）是较安全的形态；**未付薪的实操试演在很多法域有风险**，务必先过法务。
- **规模极大、单岗位候选人成百上千**：全员试演不现实，此时试演应放在末轮，或改为标准化情境测评。
- **问题在动机或计价单位**：员工知道怎么做、也做得到，就是不做 → 转 `charge-unit-redesign` / `incentive-inverted-u`。
- **短期用工、培训窗口极短**：特征说明来不及内化，先用死剧本（`four-performance-forms` 的戏台格）过渡。

### 作者在书中警告的失败模式

- **角色未定义 → 磨洋工**：工作变成"费力不讨好、为了完成而完成"。
- **只定义角色不定义特征 → 呈现全靠个人发挥**，方差不可控。
- **抢戏**：个人利益超越整体表演效果，即办公室政治。
- **表现型星探**：只看试演当场表现（行业内绝大多数人的做法），被"高中球星打弱旅"式的假象误导。
- **先入为主的理想画像**：在初选中淘汰真正合适的人。
- **选角导演越界**：把个人理解强加到试演评判上；他的职责是**帮制作人和导演找到"自己知道如何演绎角色的人"**。
- **服装放松却无人协调**：着装休闲化本身不是问题，**没有人负责一致性**才是问题。
- **想用道具掩盖整体表演问题**：拿不准要不要用道具时，答案是少用或不用。

### 作者的盲点 / 时代局限

- **⚠️ 案例时代局限**：本书 1999 初版、2011 珍藏版，选角讨论的载体高度依赖 1990s–2000s 线下商务场景——制服、领带、开什么车（IBM 要求销售拜访底特律客户开美国车）、满屏文字的幻灯片、DVD 培训、陪审顾问建议律师别开豪车。**这些具体道具已大量失效，但角色/特征二分与试演逻辑仍成立。**数字化等价替换：视频会议背景与打光 = 场景设计，头像/签名档/个人主页 = 服装，共享文档与演示模板 = 道具，异步协作留痕 = 台下表演。
- **未处理远程与异步组织**：书中默认所有人共处一个物理舞台。远程团队的"特征"主要通过文字表达、响应时延、会议中的镜头行为呈现，需要一套书中没有的观察项。
- **公平性与偏见风险被低估**：试演强调"敏锐理解表演活动""幽默感""能做出不同选择"，这些维度**天然偏向表达型人格与主流文化背景**，可能系统性淘汰内向者、非母语者、神经多样性人群。书中完全未讨论。使用时须配套结构化评分与多观察者，参见 `accessibility-low-hanging-fruit` 的思路。
- **情绪劳动缺席**（与第 6、7 章同一盲点）：定义特征等于对员工的表情、语气、姿态提出要求，这是有心理成本的，书中只谈效果不谈损耗。
- **"选择关系而非角色"与多样性的张力**：追求"与全体一致"容易滑向同质化招聘（culture fit 的经典批评）。作者给的解药只有"要未经雕琢的人"，不够。
- **AI 改写了部分格子**：标准化面客环节正被 AI 承接，此时"选角"的对象从人变成提示词与人设配置——本 skill 的角色/特征二分反而成为写 AI 人设的现成结构（角色段写职责与权限，特征段写语气节奏与即兴边界）。

### 容易混淆的邻近方法论

- **胜任力模型（competency model）**：列的是能力项，仍属"角色"侧，不解决呈现一致性。特征说明是它缺失的那一半。
- **结构化行为面试（STAR / BEI）**：仍是面试，测的是"会不会讲过去的事"。作者的主张是**它的预测效度低于试演**——但注意，本书未提供实证数据，这是一个主张而非研究结论。
- **试用期**：作者明确批评"先面试所有人、最后只让录用者做试用期表演"的顺序倒置。试用期是录用后的验证，不能替代选角。
- **Culture fit / 文化匹配**：与"选择关系"相近，但更容易变成同质化借口。本 skill 的判据更窄且可观察：**他在试演中如何寻求、给予和拒绝帮助。**
- **服务蓝图（service blueprint）**：画的是流程与触点（前台/后台），与图8-1 的场景六部分（前台、后台、观众席、舞台前端、入口、出口）有交集，但服务蓝图不处理"谁来演、以什么面貌演"。
