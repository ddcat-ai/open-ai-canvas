## I — 方法论骨架 (Interpretation)

### 一、前提：先承认"它不是真实的"

作者把这条放在**审美性体验**（宾客沉浸其中但不对其产生影响）的讨论里。雨林咖啡餐厅不是真雨林，坎贝拉店里的瀑布假山不是真山。建筑师迈克尔·本尼迪克特批评这类场所是"非真实"的，其建筑师"通过建造（以假示假）和伪装真实来解决真实性问题"。

但作者同时给出一条反向限定：
> **不存在完全人为的审美性体验**——因为每一种个人创造的体验，对当事人而言都是真实的。

于是问题从"真不真"转成了：**你打算怎么处理这份人造性？**

### 二、两条路（本 skill 的主结构，二选一，禁止混用）

| | **真实的伪造 honest fake** | **虚假的伪造 fake fake** |
|---|---|---|
| 原型 | 洛杉矶步行街 | 迪士尼乐园 |
| 对人造性的处理 | **坦承**：光怪陆离的外表"就像一个巨大的、色彩鲜艳的面具" | **隐藏**：真相全部藏在幕后 |
| 后台可见性 | **允许宾客走到建筑背后，看到朴实无华的内部** | 摆渡车、欢迎岗亭、十字转门外观精心连接，**以免露出破绽** |
| 标志性纪律 | 面具就是面具，大方戴着 | **米老鼠从不摘下面具，绝不会露出面具后面长满粉刺的脸** |
| 信任落在哪里 | 落在**制作质量**上 | 落在**幻觉的完整度**上 |
| 主要风险 | 沉浸感天花板较低 | **任何一次破绽都让可信度归零** |
| 造价与纪律 | 相对低，允许粗糙处外露 | 极高，要求全员全时段无破绽 |

作者对两条路都不作道德判决，并如实记录了迪士尼的辩护方："无论从哪个角度看，迪士尼都不是虚假的。你要说它是人造的，没错；但要说它是虚假的，绝不。迪士尼不是对别的事物的模仿，**它本身就是独立的事物**。"（作者本人对迪士尼公园持保留意见。）

### 三、唯一的判据（不是"真假"，是这三条）

1. **有没有愚弄宾客相信本来就不真实的东西？**——这是伦理红线，两条路都必须过。honest fake 靠坦承过关；fake fake 靠"它是独立的事物、不冒充别的事物"过关。**冒充具体的、可被查证的真实（这是百年老店、这是手工、这是真人），才是越线。**
2. **在众多仿制品中，你是不是相对有价值的那一个？**——评价尺度从真假换成**仿制品之间的优劣**。好的仿制品好在"它们在真实性方面的改进"。
3. **内在一致性**：选定一条路后，**所有细节都必须服从同一条路**。混用是最坏结果。

### 四、最坏结果：既想冒充真实，又漏出破绽

- 这是唯一被明确判定为失败的状态：**既没有 honest fake 的坦荡，也没有 fake fake 的完整**。
- 一旦被识破，**整个体验的可信度归零**——不是打折，是归零。因为宾客会追溯性地怀疑之前所有细节。
- 作者的收束句：**审美性体验必须是真实的，否则就有可能被宾客认为是在伪造感受。**

### 五、成本结构（选路的现实依据）

选 fake fake 就是选一条**高固定成本 + 高尾部风险**的路：需要全员、全时段、所有触点都不露破绽（迪士尼连摆渡车和十字转门的外观都要连接设计）。

选 honest fake 是**低维护成本 + 低尾部风险 + 沉浸上限较低**。

因此选路不是价值观题，是**你能不能长期承担无破绽纪律**的能力题。

## A1 — 书中的应用 (Past Application)

### 案例 1：洛杉矶步行街（真实的伪造，第2章 p076）
- **问题**：一个半主题公园半公共广场的商业街，如何处理它明显的人造性？
- **方法论的使用**：造型夸张到不可能被误认为真实——滚石音乐餐厅做成**四层楼高的吉他**；喷泉；停车缴进门费（用餐或看电影可返，购物不返）。关键设计：**宾客能走到建筑背后，看到朴实无华的内部**。
- **结论**：作者的评语是"光怪陆离的外表就像一个巨大的、色彩鲜艳的面具"——**通过建造，我们实现了"真实的伪造"**。
- **结果**：坦承人造之后，评价标准自动切换到"这个面具做得好不好"，而不是"它是不是真的"。

### 案例 2：迪士尼乐园（虚假的伪造，第2章 p077）
- **问题**：如何维持一个完整幻觉？
- **方法论的使用**：目的是**隐藏所有伪造感**，真相藏在幕后；摆渡车、欢迎岗亭、十字转门的外观都被精心连接，以免露出破绽；**米老鼠从不摘下面具**。
- **结论**：这被赫克斯特布尔等批为"虚假的伪造"，但作者同时记录了反方意见——它不模仿别的事物，**它本身就是独立的事物**，因此并未愚弄任何人。
- **结果**：这是 fake fake 能够成立的严格条件：**不冒充某个具体的真实对象** + **无破绽纪律**。（呼应第8章：迪士尼把全部员工称为"演职人员"，选角中心用建筑告诉应征者"这个乐园的最大秘密——一切都是幻觉"。）

### 案例 3：雨林咖啡餐厅与本尼迪克特的批评（第2章 p075-p076）
- **问题**：绿色植被、雾气、瀑布声、闪电雷鸣、热带鸟鱼、栩栩如生的蝴蝶蜘蛛猩猩——这是不是在骗人？
- **方法论的使用**：作者的辩护是**它并不是要单纯模仿雨林，而是要营造一种特定的审美性体验**（自称"购物用餐狂野之地"）。建筑师本尼迪克特则坚持这类场所"非真实"，其做法是"以假示假和伪装真实"。
- **结论**：分歧点恰好是本 skill 的判据——**目标是"提供某种感受"还是"让人相信这是真雨林"**。前者可辩护，后者越线。
- **结果**：确立了"不是模仿某个真实对象，而是营造某种体验"这一自我辩护的合法路径。

### 案例 4：赫克斯特布尔的标准切换（第2章 p076）
- **问题**：在一个到处是仿制品的世界里，评论家还能评什么？
- **方法论的使用**：她放弃真假二分，改用"**在众多仿制品中找出相对有价值的一个**"，并指出"好的仿制品就好在它们在真实性方面的改进"。
- **结论**：真实性从一个**是非属性**变成一个**程度属性**。
- **结果**：这句话是本 skill 全部可操作性的来源——它把无解的哲学争论换成了可比较的质量竞赛。

### 案例 5：坎贝拉户外用品（两者兼有，第2章 p076）
- **问题**：卖场中央 35 英尺高的带瀑布假山、100 只动物标本（多为创始人家族亲手猎杀）、四种北美生态系统、非洲透视画——算真还是假？
- **方法论的使用**：作者把审美性体验分成三档：**完全自然**（独游国家公园）、**以人为为主**（雨林餐厅）、**两者兼有**（坎贝拉）。标本是真的，环境是造的。
- **结论**：迪克·坎贝拉的定位句直接绕开了真假问题——"**我们卖的是体验。**"
- **结果**：开业首日 3.5 万人，每年游客超 100 万。说明"两者兼有"是一条现实可行的中间路线，但它的成立靠的是**真的那部分确实是真的**（标本、猎获史），而不是靠模糊。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **虚拟主播 / 数字人**：要不要公开中之人？要不要承认是虚拟的？
2. **AI 生成内容**：文章、配图、配音、客服要不要标注 AI？标到什么程度？
3. **品牌与创始人故事**：故事有加工成分，要包装到什么程度、哪里必须留实。
4. **仿古、复刻、翻新**：古镇改造、复古门店、复刻老产品、"百年配方"。
5. **网红打卡地 / 场景化门店**：明显是为拍照造的场景，怎么定位才不招黑。
6. **摆拍与剧本类内容**：短视频剧情、探店、素人访谈、"真实故事改编"。
7. **人设运营**：账号人设与真人差距变大时，是收窄人设还是加固幕后。
8. **服务里的"伪装"**：外包客服冒充自有团队、AI 客服冒充真人、代运营冒充本人回复。
9. **翻车之前的自查**：担心哪天幕后花絮/离职员工/翻车视频把幻觉戳破。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要标注是 AI 做的 / AI 生成要不要说"
- "要不要公开中之人 / 会不会掉粉"
- "看起来太假了 / 显得很假 / 怎么才不假"
- "这算不算骗人 / 会不会被说欺骗"
- "人设崩了 / 翻车了 / 被扒了"
- "仿古 / 复刻 / 打卡地 / 网红店 / 摆拍 / 有剧本吗"
- "客服是真人吗 / 要不要说是机器人"
- "authenticity" / "fake" / "AI disclosure" / "behind the scenes"

### 与相邻 skill 的区分

- 与 `experience-design-five-principles` 的区别：那个管**主题一致性与正负面信号**（体验做得好不好）；本 skill 管**人造性的披露策略**（要不要承认是造的）。一个体验完全可以五原则满分而在本 skill 上翻车。
- 与 `four-realms-experience-scan` 的区别：那个是 4E 象限扫描（补洼地）；本 skill 出自同一章的**审美性象限**讨论，但只处理真实性一条线。
- 与 `flaw-first-credibility` 的区别：那个是**先自曝缺点以换取后续可信度**的说服技巧（单次沟通）；本 skill 是**长期的人造性披露策略选择**。honest fake 与它精神相通，但 honest fake 不是"承认缺点"，是"承认人造"——**承认人造之后，制作质量反而成了可以炫耀的东西**。
- 与 `effort-visibility-premium` 的区别：那个让付出被看见以支撑溢价（露出后台是为了显得值）；honest fake 露出后台是为了**不欺骗**。两者的动作相似（开放后台），动机与判据不同，常可叠加使用。
- 与 `expectation-experience-engineering` 的区别：那个通过预期塑造真实感受；本 skill 处理"当宾客发现预期是被塑造的"这件事。**本 skill 是那个 skill 的风险控制器。**
- 与 `character-ip-master` / `ip-character-bible` 的区别：那些负责把角色设定做好；本 skill 决定这个角色**要不要承认自己是被设定出来的**。
- 与 `positioning-outside-in` 的区别：那个处理信息与既有认知的冲突；本 skill 处理体验与"真实"这一认知的冲突。
- 与 `fudge-factor-integrity` / `dishonesty-contagion-governance` 的区别：那些管组织内部的不诚实行为治理；本 skill 管对外体验设计中的诚实策略。

## E — 可执行步骤 (Execution)

1. **先说出那句话：这东西不是真实的**
   - 明确写下人造的部分是什么（场景、身份、故事、生成方式、后台）。
   - 完成标准：一句"我们这里 ______ 是造出来的"，不带修饰。
   - 若写不出来，说明你还在自我欺骗，后面每一步都会失真。

2. **过伦理红线：你在冒充什么？**
   - 逐项检查：是否让人相信某个**具体的、可被查证的**真实（真人回复、手工制作、百年历史、真实经历、非 AI 生成）？
   - 判据：**不模仿具体真实对象**（像迪士尼那样"本身就是独立的事物"）→ 未越线；**冒充具体真实**→ 已越线，必须改。
   - 完成标准：一份"冒充清单"，每项标"合规/越线"。
   - 硬约束：涉及法律强制披露（广告法、AI 标识、医疗与金融宣称）的，**法务优先，本 skill 只处理法律之上的策略空间**。

3. **算成本，再选路（不要先凭价值观选）**
   - fake fake 的代价清单：全员纪律、全触点无破绽、离职员工与幕后素材的长期封控、翻车时可信度归零。
   - 自问：**未来 3 年，你能保证没有一次破绽吗？**
   - 完成标准：给出"能/不能"的判断与依据（团队规模、外包比例、内容量、平台环境）。
   - 经验判据：**内容量越大、参与者越多、平台越鼓励幕后花絮，fake fake 越不可行。**

4. **二选一，写下来**
   - **真实的伪造**：坦承人造，把"造"这件事做到最好，允许后台可见。
   - **虚假的伪造**：彻底隐藏，接受高纪律与高尾部风险，且必须满足"不冒充具体真实"。
   - 完成标准：一句路线声明 + 一句放弃声明（"我们放弃 ______ 带来的好处"）。

5. **honest fake 路线的落地（更常用）**
   - **主动露一处后台**（洛杉矶步行街让人看到建筑背后）：制作花絮、AI 提示词、场景搭建过程、中之人角色说明。
   - **把面具做夸张**：四层楼高的吉他式设计——**夸张到不可能被误认为真实**，这本身就是诚实。
   - **把评价引到制作质量上**：宣传语从"这是真的"改成"我们卖的是体验"（坎贝拉句式）。
   - 完成标准：至少一个公开的"这是怎么造出来的"内容入口。

6. **fake fake 路线的落地**
   - **列出全部破绽点**：员工发言、离职者、供应商、后台照片、平台元数据、口音与时区、AI 痕迹。
   - **逐点设纪律与责任人**（迪士尼连摆渡车和十字转门外观都做连接设计）。
   - **面具纪律**：定义"绝不摘面具"的具体行为清单。
   - 完成标准：破绽点清单 + 责任人 + 一次红队演练（找人来戳）。

7. **一致性审计：找出混用**
   - 逐个触点检查：有没有"半遮半掩"的地方——既暗示是真人又不敢明说、既标了 AI 又用真人口吻卖惨、既说是复刻又暗示是原件。
   - **混用即最坏结果**，必须归并到已选的那条路。
   - 完成标准：混用项清零。

8. **相对价值检查（赫克斯特布尔标准）**
   - 与同类仿制品横向比：你在"真实性方面的改进"体现在哪（细节密度、材料、考据、制作诚意）？
   - 完成标准：写出 3 条比同行做得更实的具体点。
   - 判停条件：**一条都写不出 → 问题不在真实性策略，在产品本身**，转 `experience-design-five-principles`。

9. **压力测试：假设明天被扒**
   - 情景：幕后花絮泄露 / 中之人被扒 / AI 痕迹被检出 / 老照片被翻出。
   - 判据：honest fake 路线应当**基本无损**（因为早已坦承）；fake fake 路线应当能答出"我们从未声称它是 ______"。
   - 完成标准：两句话的回应稿。若两句都写不出，回到第 4 步重选路线。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **涉及安全、健康、财务后果的事实陈述**：药效、资质、检测报告、财务数据、学历。这里没有"两条路"，**只有真实**。本 skill 只适用于**体验层面的人造性**，不适用于事实层面的真伪。
- **有法定披露义务的场景**：广告代言、医疗宣称、金融产品、AI 生成内容的强制标识。**先合规，再谈策略。**
- **危机已经发生**：本 skill 是事前策略选择器，不是危机公关手册。已被扒之后的处理需要另一套工具（且大概率只能转向 honest fake）。
- **产品本身不行**：真实性策略救不了乏味的体验。赫克斯特布尔的标准是"在仿制品中找**相对有价值**的一个"——前提是你得有价值。
- **完全自然、无人造成分的体验**：独游国家公园式的场景，本 skill 不适用。

### 作者在书中警告的失败模式

- **愚弄宾客相信本来就不真实的东西**——唯一被明确判定为越线的行为。
- **混用**：既想冒充真实又漏出破绽，是最坏结果，可信度归零。
- **无个性的伪造**：呼应第8章迪士尼选树案例——他拒绝某些树种，称其"毫无个性"，因为**营造毫无个性的体验只会破坏整体表演**。做假也要做得有主张。
- **破绽的连锁效应**：迪士尼不惜为摆渡车与十字转门的外观做连接设计，说明 fake fake 路线上**任何一个未被管理的触点都是系统性风险**。
- **把"人造"等同于"不真实"**：作者反对这一点——"不存在完全人为的审美性体验，因为每一种个人创造的体验对当事人都是真实的"。**过度自责会导致不敢做设计。**

### 作者的盲点 / 时代局限

- **⚠️ 案例时代局限**：1999 年初版、2011 珍藏版，案例全是**线下建筑与实体场所**（洛杉矶步行街、迪士尼、雨林餐厅、坎贝拉）。今天的主战场是数字身份、AI 生成、算法内容。**框架成立，载体需替换。**映射：建筑外观→视觉风格与生成痕迹；"走到建筑背后"→幕后花絮/提示词公开/中之人说明；"米老鼠不摘面具"→数字人绝不出戏。
- **⚠️ 一个作者未预见的结构性变化（且改变了结论的权重）**：在社媒时代，**fake fake 的可行性被系统性摧毁**。幕后花絮、翻车视频、离职员工爆料、AI 检测工具、元数据——迪士尼式的完整隐藏在今天几乎不可维持。**honest fake 的相对优势因此显著上升**，这是原书未展开但今天必须补上的推论。
- **作者对迪士尼态度含糊**：他记录了正反双方，自己"持保留意见"，没有给出裁决。这留下了一个空档——**"独立的事物"这条辩护在什么条件下成立**，书中没有标准。实用替代：看它是否**冒充某个可查证的具体真实**。
- **未处理"部分真实"的复杂情形**：坎贝拉（真标本 + 造环境）被归为"两者兼有"就带过了。现实中大量情形是混合的（真人 + AI 辅助、真实故事 + 剧本化），书中没有给混合情形的规则。**本 skill 的第 7 步"一致性审计"是对这一空缺的补丁。**
- **未讨论受众预期的差异**：同一个 honest fake，在已经知情的核心粉丝与首次接触的路人那里，效果完全不同。书中默认宾客是同质的。
- **伦理判据偏弱**："不愚弄宾客"是底线而非高标准。在信息不对称严重的领域（老年人、儿童、医疗焦虑者），仅靠"我没明说它是真的"是不够的。

### 容易混淆的邻近方法论

- **透明化 / Radical Transparency**：主张一律公开。本 skill **不是**这个主张——它明确承认 fake fake 是一种可选且有时更优的策略。这是本条最反直觉之处。
- **品牌真诚（Brand Authenticity）营销话术**：通常只有"要真实"一个方向；本 skill 给的是二选一决策 + 混用禁令，可操作性完全不同。
- **AI 内容标注合规**：那是法律义务的下限；本 skill 处理的是下限之上的策略空间（标注之后怎么把"人造"做成优势）。
- **《真实经济》（Authenticity，派恩与吉尔摩后续著作）**：本章的收束句"审美性体验必须是真实的"正是那本书的种子。本 skill 只整理《体验经济》中的二分框架，不覆盖后续那本书的五种真实性模型。
- **kayfabe（摔角行业的"假戏真做"约定）**：与 fake fake 高度相似，但 kayfabe 是**观众共谋的公开秘密**（大家都知道是演的却配合），本质上更接近 honest fake。这是最常见的一次误判。
