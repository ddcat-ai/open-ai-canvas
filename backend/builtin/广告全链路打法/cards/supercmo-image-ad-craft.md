# 产品广告图：从张力到成品

## R — 原文要点 (Reading)

来源方法（Apache-2.0，整理自 superCMO generating-image-ads）：把产品变成成品静态广告。①读料：有产品图/URL→转产品分析拿四样（是什么/人怎么物理使用它/哪些部件会开或动及顺序/哪里必须处处相同）；**先看图再描述**（读表面吃光等画面要描述而产品事实给不了的）；没产品→不猜，成为访谈第一问。②访谈（brief 已让广告显而易见就整段跳过——访谈为补真缺口不为确认已知）：一次问全（产品——没有就等上传，拍出来的产品胜于描述的产品；品牌规范——可选，很多品牌没有；**优惠和唯一主张**——只用具给的话；投哪——投放位和比例）。用户豁免问题→直接 1:1、产品 hero 方向、一条利益线，一句话说清拿了什么默认（是声明不是检查点）。③找主意：先读广告手艺；**单念命题**——每个广告解一个消费者真相与产品真相之间的张力；洞见（关于人怎么用怎么感受这类产品的人性真相，真到说出来有点不舒服）；主意（张力解成一句话——说不出一个句子就是两个广告）；促销织进主意里做真元素不是事后贴；**表现跟从主意**（影调/语域/视觉路线为这个主意服务，可以是 hero/lifestyle/before-after/offer  familiar 形状，但是被选的不是先挑的）。**一组广告各用不同洞见**——不同人性真相不同切入角，不是同一洞见换表现；两个广告共享洞见=同一条广告发了两次。④文案最后写：只说图没说尽的；只用用户给的主张；标题（主导文字元素，永远在）；支撑层（仅当标题留下真问题时）；CTA（可选 2-4 词，**渲染成按钮**——填充形状+强调色，绝不 Floating 文字）；**不发明主张/数字/评分/角标**填空。⑤产品描述：写一份、每个提示词里原样复用（有参考图时描述只覆盖图给不了的：想要的角度/活动部件状态/正在做的动作；无参考图时描述负全责）。

## I — 方法论骨架 (Interpretation)

1. **张力是创意单位**：消费者真相×产品真相的碰撞点就是广告；没有张力只有特性罗列。
2. **一组=多洞见**：变体的多样性在人性洞察层，不在视觉花样层——换皮不换洞见是测试欺诈。
3. **文案殿后**：图先说，文字补图没说尽的——顺序倒过来就会出现图文互抄。
4. **主张白名单**：画面上的每个字都必须能指回用户说过的话。
5. **CTA 是按钮不是文字**： Floating 文字在信息流里不可点也不可扫。

## A1 — 应用案例 (Past Application)

- 床垫促销：洞见"半夜被热醒不敢吵醒身边的人"→ 主意"一张不传热的床，两个人都睡得着"→ hero 图+按钮 CTA"了解降温款"；同组第二张换洞见"搬家三次都扔不掉的旧床"（对比向），不换hero表现。
- 反例：一组四张全是 hero 图换配色换文案——同一个洞见发四遍，测试毫无信息量。

## E — 可执行步骤 (Execution)

1. **读料**：产品四样+看图。完成标准：四样有着落。
2. **访谈**：缺口一次问全。完成标准：主张白名单建立。
3. **找主意**：张力→一句话主意。完成标准：主意可一句说清。
4. **写文案**：标题/支撑/CTA按钮，只用白名单。完成标准：每个字有出处。
5. **写产品描述**：一份定稿全复用。完成标准：描述冻结。
6. **生成+验收**：按投放位画幅出图，对照白名单核字。完成标准：无发明、无 Floating CTA。

## B — 边界 (Boundary)

- **不发明主张**：没有的话去问。
- **不换皮凑数**：同洞见不发两次。
- **影策适配边界**：读图一步 Agent 无视觉通道，需用户提供产品事实与表面描述；生成走影策 generate_media，画幅以其实际参数为准。
