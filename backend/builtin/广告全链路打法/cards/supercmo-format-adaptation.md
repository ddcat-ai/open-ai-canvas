# 画幅适配：重铸，不是裁剪

## R — 原文要点 (Reading)

来源方法（Apache-2.0，整理自 superCMO adapting-formats）：**每个画幅都是重新生成，不是裁剪**——裁剪会把标题切一半、把产品挤出画；广告为新高宽比重画、原图作参考传进去，这样它还是同一条广告。①取件：广告图（要用户手里最大的版本；没有就问并停；多条广告正常——各自读各自规划，但可最后一次生成）；画幅（给了比例就用，给了渠道就从渠道表取，都没给就问）；**产品图值得讨**（广告里产品常又小又斜还被文案压着，干净产品图撑身份比广告图强得多）。**丢掉广告 already 在的那个画幅**——1:1 的图要 Meta 家族就出 4:5 和 9:16，重绘原画幅是花冤枉钱重建已有的东西。②读图（一次就够）：分开"画这幅广告的料"而非描述画面——产品（是什么+哪里必须逐像素相同：形状/颜色/标签/身上印的字）；**每一条画出来的字，逐字抓**（标题/副文/CTA/价格/角标——这些要被重绘，读错一个字就是广告里错一个字）；背景（表面/场景/光方向/透视——这是要延伸进新区域的东西）；影调（色板/字体性格）；布局（眼睛先落哪/各部分相对位置）。只取这幅广告真有的，没 CTA 不发明。**只读一次**——第二次分析是重复付费。③逐画幅规划：先读重组指南（什么长/什么移/什么填新空/什么让广告显脏）；每个画幅写清——离原图多远（1:1→4:5 是小推；1:1→9:16 是真重构；竖转 16:9/21:9 画面翻转保留极少，**接近新广告，生成前就说而不是之后**）；新区域填什么（ normally 背景按自己的光和透视延伸+产品周围刻意的负空间，**绝不发明新元素填空**）；每个部分去哪（含哪个部分被挤出了平台覆盖带）；**文案还放得下吗**（9:16 安全区大约中间半幅，文字密集的方图常没法以可读字号搬进去——**明说，而不是把字缩小到看不清**）。

## I — 方法论骨架 (Interpretation)

1. **重绘保身份**：原图作参考+产品必须逐像素相同的清单，是跨画幅一致性的全部机制。
2. **距离先说清**：画幅差得远时这是新做不是 resize——预算和预期都该在生成前对齐。
3. **读图一次原则**：分析计费，五要素一次拿全。
4. **不发明填空**：新区域用背景延伸和负空间填，加新元素就是另一条广告了。
5. **可读性优先于完整**：文案搬不进去就明说，不缩到看不清。

## A1 — 应用案例 (Past Application)

- 床垫 1:1 主图 → Meta 家族：出 4:5（微调：背景下延、标题上移）和 9:16（真重构：产品上移、文案重排三行、价格角标挪出安全区下缘）；向用户明示 9:16 接近重做，获确认才生成。
- 反例：方图直接裁成 9:16——标题剩一半、床垫出画，整批物料报废。

## A2 — 触发场景 (Future Trigger)

- 「这张图改成竖版/其他尺寸」
- 「一条素材发多个渠道」
- 「改完画幅产品变了/字丢了」
- 「这个改动大不大？」

## E — 可执行步骤 (Execution)

1. **取件**：最大版本+画幅清单+讨产品图，丢已在画幅。完成标准：件齐、目标画幅明确。
2. **读图一次**：五要素落表。完成标准：逐字文案与产品锁定项在表。
3. **逐画幅规划**：距离评估+区域填充+文案可读性。完成标准：每画幅有方案、远的已声明。
4. **重绘**：原图+产品图作参考逐画幅生成。完成标准：产品一致、文案逐字对。
5. **验收**：对照读图表逐项核。完成标准：无丢字、无变形、无新元素。

## B — 边界 (Boundary)

- **不裁剪**：任何画幅都走重绘。
- **不发明新元素**：填空白只用背景延伸+负空间。
- **不缩字硬搬**：放不下就明说。
- **影策适配边界**：读图一步 Agent 无视觉通道，需用户提供文案清单与产品锁定项（或按已知信息跳过）；生成以影策 generate_media 实际画幅参数为准。
