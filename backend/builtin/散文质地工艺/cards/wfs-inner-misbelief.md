## I — 方法论骨架 (Interpretation)

任何成立的故事都有两根轴。**外在轴**是角色「想要什么」——一个具体的表面目标（冰山一角）；**内在轴**是他「错信了什么」——关于自我或世界的一个长期、往往无意识的内隐观念（水下动力）。情节是外在轴在跑，但真正推着故事前进的是内在轴：当这个错信被现实撞击、裂开，人才会变化。

落到反套路：给每位老人先定一个**反常识的错信**（比如「我这把年纪不配再恋爱」「向子女求助=认输」），外在目标只是幌子；每集用情节把这块错信撞裂一点点，爽点正来自「错信越反常识、崩解越爽」。两个关键提醒：(1) 错信多半是**内隐**的——别让老人突然「想通」，要靠事件把他从幕后拽到台前；(2) 角色的动机常来自**社会化思维**——怕连累子女、想被需要、要面子，比「个人欲望」更贴老年处境。连「反派」（儿媳/养老院院长）也该有自己的错信与难处，扁平恶人会塌。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《风云人物》乔治·贝利——表面目标 + 反常识错信的现成模板（c07）
- **问题**: 作者用全书最长案例示范「内外双轴」如何成立。
- **方法论的使用**: 乔治表面目标是「离开小镇干大事」，真正拦住他、推动全片的却是内在错信「留下=失败」；结局他得到的是内在回报（无条件的爱），外在目标被推翻。
- **结论**: 反套路人物弧 = 表面目标 + 反常识错信 + 绕不开冲突 + 内在回报。
- **结果**: 直接套给——给她一个表面目标和一个「认老/留下=失败」式的错信。

### 案例 2: 《黑道家族》连反派也有内在重负（c36）
- **问题**: 作者要说明「所有角色都该有内在问题」，包括反派。
- **方法论的使用**: 托尼·瑟普拉诺哀叹「每个决定都影响到所有别的事」，证明反派也因内在重负挣扎。
- **结果**: 反派越有内在，正派弧越立得住——群像不塌。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计一个反套路角色，不知道「他内心到底信错什么」导致人物立不住。
2. 诊断某集角色为什么「好看但空洞」——行为没有内在驱动。
3. 想把群像里的「反派长辈/儿媳」也写出内在难处，避免扁平。

### 语言信号 (用户的话里出现这些就应激活)

- "这个老人角色怎么立？他的内在弧是什么？"
- "我想给定一个反常识的错误信念，让她反套路。"
- "这角色为什么写着写着就空了、观众不附着？"
- "儿媳/院长能不能别写成纯坏人，也给她点内在？"

### 与相邻 skill 的区分

- 与 `wfs-arc-blueprint` 的区别: 本 skill 填「内在轴的具体内容（错信）」；`wfs-arc-blueprint` 管结构蓝图/双栏自检。先用蓝图搭骨架，再用本 skill 填错信。
- 与 `wfs-conflict-engine` 的区别: 本 skill 定义「错信是什么」；`wfs-conflict-engine` 设计「用什么绕不开的冲突去撞它」。错信是弹药，冲突是枪。
- 与 `wfs-group-change` 的关系: 本 skill 是**个体**内在弧；`wfs-group-change`（组B）是群体层面多位老人的整体改变编排。关系上 `wfs-group-change` **depends-on 本 skill**（先有单人 misbelief 原理才能编排群像）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **诊断错误信念（反常识内隐错信）**
   - 完成标准: 为角色写出一句反常识的内隐错信（例：「向子女求助=认输」「老了不配再恋爱」），且与表面目标明显错位——它不是「想要什么」而是「错信什么」。

2. **给表面目标作冰山一角**
   - 完成标准: 写出角色的具体外在目标，并标注它只是错信的掩护，二者形成张力而非同一件事。

3. **设计事件把错信「推入有意识」**
   - 完成标准: 列出本集/本剧哪些事件逼角色把错信从幕后拽到台前并崩裂一点；判停条件：若只能靠「他突然想通」推进，则违背 g37（内隐须由事件逼出），需重设事件而非加独白。

## B — 边界 (Boundary) ★

### 🔴 硬约束（世界层·违背就崩）

- 不能违背基本的内外双轴·错误信念拆逻辑，否则观众/读者会立刻出戏
### 🟡 软约束（规则层·违背有代价）

- 已经清楚错信、只想把 /单集排成结构蓝图——回 `wfs-arc-blueprint`。
- 已经清楚错信、只想设计「绕不开的冲突」去撞它——回 `wfs-conflict-engine`。
- 需要的是群体多位老人整体改变编排——回 `wfs-group-change`（组B）。
### 🟢 自设约束（认知层·其实可以重定义）

- 以为内外双轴·错误信念拆只有一种正确用法——假墙，方法是工具，不是教条
- 以为内外双轴·错误信念拆能解决所有问题——假墙，每个方法都有适用场景
