## I — 方法论骨架 (Interpretation)

故事成立与否有一把硬尺：**主人公是否被逼到死角并发生内在改变**。没改变，就等于没故事。落到喜剧，这不是"大团圆"的要求，而是"信念翻转"的要求——老人开头错信的那条内隐观念（如"向子女求助=认输""老了不配再恋爱"），必须被情节（不是被角色之口说教）一点点击碎。

三把验收刀：

- **小弧 / 大弧双闭环**：每集应是一次"小信念改变"，全剧是"大弧闭合"。写完自问：这集结尾老人的世界观是否被情节推翻了一点点？全剧终看他回头重看第一集那件事。
- **回归而非重复**：结局让主人公用新眼光重看开头那件事（第一集嫌弃的养老院→终集温暖归宿），是"同场景、不同意义"，不是原样复读。
- **删场诊断（p23）**：每场前自问"如果抽掉这场，故事还成立吗？"用假设性问题快速揪出缺位的利害与因果。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《风云人物》— 内外双轴 + 改变闭环的现成模板（c07）
- **问题**: 作者要示范一个完整的"被逼改变"结构。
- **方法论的使用**: 乔治·贝利表面目标"离开小镇干大事"，内在错信"留下=失败"；真正拦住他的是正直。结局他获得的是内在回报（无条件的爱），外在目标被推翻。
- **结论**: 表面目标 + 反常识内在错信 + 绕不开冲突 + 内在回报 = 反套路弧模板，直接可套给。
- **结果**: 提供"改变来自内在回报而非外在胜利"的判定范式。

### 案例 2: 《第六感》式反转噱头警示（ce14）
- **问题**: 克龙用"脸色苍白的孩子"作"转折噱头"的反面参照。
- **方法论的使用**: 把"反转"当唯一卖点、与人物成长无关 → 看完即忘。
- **结论**: 喜剧的"反套路"必须来自人物信念反转，不是身份揭秘（"原来奶奶是特务"式机械反转撑不住场）。
- **结果**: 确立"反转须与内在弧绑定"的验收红线。

### 案例 3: 副情节必须服务主弧（p28）
- **问题**: 倒叙、次要情节、伏笔若不与主线相关就是噪音。
- **方法论的使用**: 克龙主张用"故事问题来衡量新信息的相关性"。
- **结论**: 多线用"是否推进某位老人的内在弧"筛支线，删掉某支线主线毫无影响的必是噪音。
- **结果**: 提供群像支线的取舍标尺。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写完一集，不确定"这集老人到底有没有发生改变、算不算闭环"。
2. 设计全剧结局，想做"回到当初用新眼光重看"的回归式收尾。
3. 担心某条支线/某个笑点"只是热闹、没服务主弧"。
4. 想避免"为反转而反转""原来她是 X 但和成长无关"的机械噱头。

### 语言信号 (用户的话里出现这些就应激活)

- "这集结尾的信念有没有被推翻？算不算改变闭环？"
- "全剧终怎么让她回头重看第一集那件事？"
- "这场戏删掉故事还成立吗？"
- "这个副情节/笑点是不是多余的、没服务主线？"
- "change closure / 弧线检验 / 如果抽掉这场"

### 与相邻 skill 的区分

- 与 `wfs-setup-payoff` 的区别: 本 skill 验收"改变是否发生/闭环是否成立"；`wfs-setup-payoff` 管"伏笔怎么埋—收"。用户说"呼应/回收"多指向线（setup-payoff），说"改变/闭环/成长"才指向本 skill。
- 与 `wfs-inner-misbelief`（组A）的区别: `wfs-inner-misbelief` 讲"错误信念是什么、怎么设计"的原理；本 skill 讲"它到底被推翻了没有、怎么验收"。先看 `wfs-inner-misbelief` 立信念，再用本 skill 验收崩解。
- 与 `wfs-arc-blueprint`（组A）的区别: `wfs-arc-blueprint` 是弧线蓝图规划；本 skill 是写完后的验收单。规划归蓝图，验收归本 skill。

## E — 可执行步骤 (Execution)

1. **列信念基线**
   - 完成标准: 写明本集/全剧老人开头错信的"内隐观念"一条，作为验收对照锚点（来源 `wfs-inner-misbelief`）。

2. **跑小弧/大弧闭环检验**
   - 完成标准: 结尾能答出"老人的世界观被情节（非说教）推翻了哪一点"；全剧能答出"他如何用新眼光重看开头那件事"。答不出=未闭环，标记返工。
   - 判停条件: 若改变靠角色之口说出而非情节逼出 → 跳到步骤 3 重做崩解方式。

3. **删场诊断 + 支线筛除**
   - 完成标准: 对每条支线/笑点用"如果抽掉这场故事还成立吗 / 是否推进某位老人内在弧"判定；与成长无关的反转（ce14）标记删除或重绑内在。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要的是"伏笔怎么埋—收"的结构设计——`wfs-setup-payoff`，本 skill 只验收改变、不管线。
- 需要的是"错误信念/内在问题是什么"的原理定义——`wfs-inner-misbelief`（组A）。

### 作者在书中警告的失败模式

- **反转噱头无内在弧（ce14）**: "原来奶奶是特务"式机械反转，和人物成长无关，看完即忘。"反套路"须来自信念反转而非身份揭秘。
- **不为情节牺牲内心真实（p25）**: 外部事件再热闹，若没内在驱动就是乱；别为笑点牺牲老人动机真实，荒唐行为必须来自其错误信念而非"为了搞笑"。
- **副情节不服务主弧（p28）**: 多线若不以"是否推进某老人内在弧"筛选，就是噪音。

### 作者的盲点 / 时代局限
### 容易混淆的邻近方法论

- `wfs-setup-payoff`（最易互抢：用户说"呼应/闭环"时可能指线或指改变，需分辨）。
- `wfs-inner-misbelief` / `wfs-arc-blueprint`（组A，原理与蓝图，本 skill 是其验收环节）。

### contrasts-with（易混淆，注意区分）
- `wfs-setup-payoff`：本 skill 验收改变，它管伏笔结构；"闭环"一词两 skill 都用，需分辨问的是线还是改变。
- `wfs-group-change`：本 skill 是**单集/单人改变验收**；`wfs-group-change`（组B）是**群像整体改变编排**。问"这集老人改没改"归本 skill，问"一群人怎么排布各自弧"归它。"群像改变"一词两 skill 都用，需分辨规划还是验收。

### composes-with（常配合使用）
- `wfs-inner-misbelief`：验收错信是否被情节推翻（亦以 depends-on 指向它）。
