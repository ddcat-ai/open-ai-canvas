## I — 方法论骨架 (Interpretation)

### 核心原则：非对称 + 机制化

声口护栏不是一套规则管所有角色，而是按角色在叙事中的功能分两路，方向相反：

```
叙述者/主侃人声口 ──→ 防词汇表化（禁标签词、禁演员腔移植）
功能腔角色（汇报腔/黑话腔等）──→ 防弃腔（峰值时刻必须用词库）
```

两路护栏共同保护一件事：**声口对撞**。当两个声口的对撞本身承载母题（如干 vs 湿、机器 vs 人），禁止为了"统一文风"把两腔抹平。

### 护栏一：叙述者声口（防词汇表化）

AI 最容易把"风格"当词汇表做硬替换——穿着长衫戴 VR 眼镜的假人。机制规则：

1. **幽默来源锁定**：笑点必须来自「角色视角的物理逻辑」与「人类情感逻辑」的错位，或「反差情境 + 角色动机错位」——不是来自方言词/生僻词/俏皮话的密度。
2. **禁标签词堆砌**：不得机械套用特定作家的标志性方言词（如"起腻""抽了骨头"式标签）充当风格。判断法：这个笑点**删掉标签词还成立吗**？成立=过；不成立=重写。
3. **禁人类演员腔移植**：不得把真人脱口秀演员的声口（某某式的丧、某某式的观察节奏）直接移植给非人/架空叙述者——那是人类演员长在自身性格与人生里的节奏，移植即 OOC。正确做法是**移植机制**：观察式幽默的"细节颗粒度"、消解宏大叙事的"落点选择"，装进叙述者自己的声口。
4. **固化已验证结构**：优先复用本项目已通过验货的声口机制（如"先吹后泄"丑角结构、狗式记时自嘲），而非另起炉灶换新腔。

### 护栏二：功能腔角色（防弃腔 + 峰值压力测试）

人物账 `词库` 字段 = 该角色的声口白名单。机制规则：

1. **峰值必用词**：角色在情绪峰值时刻（崩溃/高潮/表白/对峙）**必须至少调用 1 次自己的职业词库**——最情绪化时刻最能暴露角色本色，此时弃腔=人设崩塌。例：小嘉的述职式表白（"情感投入 ROI 持续提升……建立长期战略合作关系"）——把表白当项目，荒诞感与人设一致性同时成立。
2. **词库崩塌须有设计**：若人物弧需要角色"学会说人话"（词库崩塌是弧光终点），崩塌时机必须登记在人物账（如《人话》小嘉"第 8 章起词库崩塌成大白话"）——崩塌是弧光的收口，不是随时可发生的事故。
3. **压力测试自检**：写完角色峰值戏份后问——"这句最动情的话，别人替他说出来会串味吗？"会=词库生效；不会=腔丢了。

### 判决规则

| 症状 | 归属 | 处方 |
|---|---|---|
| 叙述者句里标签词密度高，删词笑点死 | 护栏一违例 | 重写为情境错位，标签词 ≤1 处点缀 |
| 叙述者突然冒出某演员标志性句式 | 护栏一违例（OOC） | 拆机制留声口：保落点，换说法 |
| 功能腔角色情绪上头就说大白话（非设计节点） | 护栏二违例（OOC） | 峰值台词补回词库调用，或登记崩塌时机 |
| 两个对撞声口越写越像 | 抹平违例 | 回读人物账双词库，各归各位 |
| 为搞笑硬塞方言/网络热梗 | 护栏一违例 | 删梗，从角色动机错位里重新找笑点 |

## A1 — 书中的应用 (Past Application)

- **《人话》验证（2026-08-16）**：小嘉全程汇报腔（OKR/ROI/复盘/甘特图），述职式表白为峰值用腔——GLM 批评其"缝合生硬"，实测恰是母题本体；来福全程靠"先吹后泄 + 狗式记时"造幽默，9 章零标签词堆砌（"被抽了骨头"1 处且为自然惯用语）。双护栏在这套文本上天然达标，证明规则不是限制而是已验证写法的固化。
- **反例警示**：若按 GLM 泛化批评禁掉小嘉的黑话——母题"干湿对撞"直接失语；若给来福搬李诞式丧腔——柴犬主侃人角色崩坏。非对称性是本卡的命门。

## A2 — 触发场景 (Future Trigger)

- 阶 6 逐拍写作：每拍写前读人物账 `词库` 字段，按角色类型套对应护栏。
- 阶 5.5 章节扩写台：同上（叙述文学的对白与叙述声口均适用）。
- 阶 7 定稿：去AI味 10 条自查的姊妹项——声口三查（标签词删测 / 峰值腔测 / 对撞完整测）。
- 语言信号："出戏 / 串味 / 角色崩了 / OOC / 文风不统一 / 怎么所有人说话一个味儿"。

## E — 可执行步骤 (Execution)

1. **写前分诊**：读人物账，把本章/本拍出场角色分两类——叙述者声口 / 功能腔声口；读各自的 `词库` 字段。
   *完成标准*：每个角色标注护栏类型 + 词库要点。

2. **叙述者侧执行**：落笔时锁定幽默来源=情境错位；标签词至多 1 处点缀；不移植真人演员句式。
   *完成标准*：本段笑点全部能答出"错位在哪"。

3. **功能腔侧执行**：标出本段角色情绪峰值点；峰值台词至少 1 次调用词库；非设计崩塌节点一律不弃腔。
   *完成标准*：峰值台词标注词库调用点。

4. **写后三查**：①标签词删测（删词笑点是否仍成立）②峰值腔测（峰值台词是否串味）③对撞完整测（双声口是否被抹平）。
   *完成标准*：三查各过，违例按处方表返修。

## 延伸弹药（related cards · 2026-08-16 接线）

本卡是"非对称机制"层，理论背书直接引库内麦基《对白》《人物》卡（配方阁\01\罗伯特·麦基虚构艺术三部曲）：

- `mckee-character-voice`：角色专属声口理论——"功能腔峰值必用词库"的经典依据（每个角色的语言是其欲望/背景/教养的指纹）
- `mckee-dialogue-in-character`：符合角色的一致性对白——防 OOC 的原理论（峰值时刻的语言选择最能暴露人物本质）
- `mckee-dialogue-clinic`：对白诊所——写后三查的姊妹自检法
- `mckee-in-character-writing`：人物视角写作——叙述者声口（护栏一）的进阶修炼

用法：本卡管"两路护栏的方向"，麦基卡管"单路深修"；冲突时以本卡非对称原则为准（麦基未覆盖"禁真人演员腔移植"这一 AI 特有风险）。

## 方法边界

- 适用于有声口设计的项目；纯画面/纯说明性文本不适用。
- "标签词 ≤1 处点缀"是允许的——完全零风格词会把叙述者写成白开水，关键是密度与不可依赖性。
- 单声口项目（无对撞设计）只需执行护栏一，护栏二的对象是有专属词库的功能角色。
