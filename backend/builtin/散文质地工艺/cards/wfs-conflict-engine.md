## I — 方法论骨架 (Interpretation)

克龙的核心动力定律：**变化只有一个来源——主人公躲不开的冲突**。大脑天生抗拒改变，所以故事不能用劝、用巧合，必须用一个「绕不开」的情境把人逼到死角，错信才肯裂。没有这个冲突，人物就静止，故事就散。

它配两个操作件：(1) **出错定律（墨菲）**——凡主人公最怕发生的事，都要让它发生，且每次出错都要加深他错信的崩裂，不是为虐而虐；(2) **行为—反应—决定链**——每个场景内部都要有「发生→老人反应→作出新决定」的微型因果来激发紧张，每屏都要有这条链，否则注水。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《飞越布谷鸟巢》——规范束缚 vs 个体反抗（c32 现成模板）
- **问题**: 作者要说明「体制/规范 vs 个体」的冲突模式如何成立。
- **方法论的使用**: 把制度（养老院规矩、打卡、不准养狗）设为具体规范束缚，老人作为个体反抗——冲突根植制度，拿掉制度故事就散。
- **结论**: 喜剧的冲突源应是「具体制度 × 老人错信」，不是外部巧合。
- **结果**: 提供把「养老院规矩」设为反套路冲突源的写法，让反抗可感、可信、可乐。

### 案例 2: 《风云人物》乔治·贝利——被正直拦住的不可避免冲突（c07 同构）
- **问题**: 作者示范内在冲突如何「绕不开」。
- **方法论的使用**: 乔治表面想离开，真正拦住他的是正直本身——每次「离开」的尝试都被自己的正直撞回，冲突来自人物内核而非外力。
- **结论**: 最稳的冲突源是角色自己的错信/特质，外部事件只是放大器。
- **结果**: 给的冲突设计指明「先有错信，冲突从错信长出」的路径。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 人物「不肯变」、整集平平，怀疑缺一个绕不开的冲突去逼他。
2. 自检某处冲突「太假/像天降意外」，担心读者觉被耍。
3. 想用「怕什么来什么」做出每集的出错定律发动机。

### 语言信号 (用户的话里出现这些就应激活)

- "这集冲突太假，像硬塞的/天降意外。"
- "主角怎么都不肯变，戏核没劲。"
- "墨菲定律/怕什么来什么怎么用到每集？"
- "这个冲突拿掉，故事还成立吗？"

### 与相邻 skill 的区分

- 与 `wfs-stakes-hook` 的区别: 本 skill 设计「用什么绕不开的冲突去逼改变」；`wfs-stakes-hook` 只查「每页有没有张力钩子」。本 skill 是发动机，它是仪表盘。
- 与 `wfs-inner-misbelief` 的区别: 本 skill 是「枪」（冲突机制）；`wfs-inner-misbelief` 是「弹药」（被撞的错信）。先用它定错信，再用本 skill 造冲突。
- 与 `wfs-causal-chain` 的区别: 本 skill 管「冲突是否根植情境逼改变」；`wfs-causal-chain` 管「每个细节是否必要、是否有因果」。前者是动力，后者是逻辑。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确立内在错误信念（前置弹药）**
   - 完成标准: 确认本集冲突所撞的错信已存在（见 `wfs-inner-misbelief`）；判停条件：若角色无错信可撞，跳回 `wfs-inner-misbelief` 先定错信，否则冲突无根。

2. **设计绕不开的情境撞击**
   - 完成标准: 列出冲突源，并通过「拿掉这个巧合，故事还成立吗？」检验——若拿掉仍成立，则属外部巧合（ce09），须改写为根植情境（时代落差/子女/身体/制度）的冲突。

3. **套出错定律服务内在弧**
   - 完成标准: 每集「凡最怕发生的事必发生」，且每次出错都加深错信崩裂而非为虐而虐；列出本集的「怕什么→真发生→错信裂一点」三连。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 还没定角色错信、只想先拆解「他错信什么」——回 `wfs-inner-misbelief`（本 skill 不造弹药）。
- 已经确认冲突成立、只想查每页张力钩子——回 `wfs-stakes-hook`。
- 已经确认冲突成立、只想审查细节因果必要性——回 `wfs-causal-chain`。

### 作者在书中警告的失败模式

- **ce09（用巧合硬塞冲突，非不可避免）**: 天降意外（车祸/中奖）制造矛盾，冲突不根植情境，读者觉被耍。检验：「拿掉这个巧合，故事就散」才是真冲突；喜剧冲突应来自「错信 × 时代落差」，而非外部巧合。
- **ce14（反转噱头无内在弧）**: 把「反转」当唯一卖点（如「原来奶奶是特务」），无内在改变支撑，看完即忘——反套路来自信念反转不是身份揭秘。

### 作者的盲点 / 时代局限

> 本书冲突案例多为个体 vs 内心/命运；喜剧的冲突常是「老人错信 × 时代/子女/制度」的多方拉扯，需把单一内心冲突本书衍生适配为代际+制度复合冲突，这是适配推导。

### 容易混淆的邻近方法论

- `wfs-inner-misbelief`（易混：本 skill 是冲突机制，它是被撞的错信内容）。
- `wfs-stakes-hook`（易混：本 skill 造冲突，它查每页钩子）。
- `wfs-causal-chain`（易混：本 skill 管动力冲突，它管细节因果必要性）。

## 相关 skills (阶段 3 填充)

### depends-on（使用前需先理解）
- `wfs-inner-misbelief`：冲突必须撞在已存在的错信上，否则无根。

### contrasts-with（易混淆，注意区分）
- `wfs-causal-chain`：本 skill 管"冲突是否根植情境逼改变"（动力）；它管"每个细节是否必要、是否有因果"（逻辑）。前者查动力，后者查逻辑。

### composes-with（常配合使用）
- `wfs-inner-misbelief`：错信是弹药，冲突是枪（亦以 depends-on 指向它）。
- `wfs-arc-blueprint`：蓝图每环的冲突落位。
- `wfs-stakes-hook`：每页张力钩子由冲突撑起（亦以 contrasts 区分二者）。
