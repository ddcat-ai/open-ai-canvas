## I — 方法论骨架 (Interpretation)
- **作者也有内在问题**: 你或许自己就藏着"老了就没用""老人是负担/是祥林嫂/是国民奶奶"的错信。这些预设会不经意的渗进每一个老人角色，让他们整齐地"符合作者的某种执念"，而非各自活成真实的人。
- **别把编剧的焦虑当角色的真实**: 一个"怕被送养老院"的执念若来自你本人而非角色处境，写出来的恐惧会假、会重、会脱离群像的真实肌理。
- **代际视角的单一化风险**: 若你只从"子女怎么看父母"的视角组织故事，整部剧会滑成"孝顺说明书"而非多声部群像。

自检动作：动笔前列出"我对老去默认相信的三句话"，逐条问"这是我的，还是我角色的？"——把属于你的部分隔离，留给角色去自行挣脱。

## A1 — 书中的应用 (Past Application)

### 案例 1: 克龙揭示"作者大脑"如何组织故事（g34 本源）
- **问题**: 全书方法论都在讲角色的内在问题，克龙在第十二章把同一套分析工具指向作者。
- **方法论的使用**: 作者自身经验/信念如何渗入并组织故事——你写的每个选择背后都有你自己的内在问题在驱动。
- **结论**: 作者须像分析角色一样分析自己：我对这个故事题材，到底藏着什么预设？
- **结果**: 确立"作者自省"是故事成立的元前提，而非可有可无的灵感谈。

### 案例 2: 隐含信念自动组织素材（g37 同源）
- **问题**: 克龙说明错误的内隐观念"一旦形成，我们便欣然误解一切发生在自己身上的事情"。
- **方法论的使用**: 这条不仅适用于角色，也适用于作者——你的内隐观念会让你"欣然"只选取符合它的素材、忽略反例。
- **结论**: 编剧若内隐相信"老人都恋旧保守"，会无意识只写守旧老人、漏掉先锋老人。
- **结果**: 提供"素材选择偏差"这一具体自检切口。

### 案例 3: 社会化思维反噬（g28 同源）
- **问题**: 大脑天生以社会关系为驱动——作者也容易只从"对他人的责任/看法"组织动机。
- **方法论的使用**: 若作者默认"老人只会为子女活"，所有角色动机都被压进同一模具。
- **结论**: 自检是否把"怕连累子女/想被需要"当成了唯一合法的动机。
- **结果**: 提示拓展动机光谱（自我实现、欲望、好奇心等非纯利他动机）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 动笔前/中，想厘清自己对"老去"的隐含预设，怕它污染角色。
2. 发现笔下的老人不自觉地都"长一个样"、符合某种作者执念。
3. 担心把编剧自身的养老焦虑当成角色的真实性。
4. 想避免全剧只有"子女视角"的单一代际立场。

### 语言信号 (用户的话里出现这些就应激活)

- "我发现自己写老人总带着某种预设，怎么排掉？"
- "怎么别把我的焦虑当成角色的真实？"
- "为什么我笔下的老人都一个模子？"
- "writer's brain / 作者自省 / 编剧隐含信念"

### 与相邻 skill 的区分

- 与 `wfs-inner-misbelief`（组A）的区别: `wfs-inner-misbelief` 是**角色**的内在错误信念（故事动力源）；本 skill 是**作者自己**的内在问题。一个对外（角色）、一个对内（编剧）。先本 skill 排作者自己的雷，再 `wfs-inner-misbelief` 给角色立 misbelief。
- 与 `wfs-change-closure` 的区别: `wfs-change-closure` 验收角色的改变；本 skill 在写作前/中自检作者的偏差，是更前置的元步骤。
- 与 `wfs-group-change` 的区别: `wfs-group-change` 设计群像各自改变的结构；本 skill 防止作者用单一执念把群像压成同一个模具。

## E — 可执行步骤 (Execution)

1. **列作者隐含信念三句话**
   - 完成标准: 写出"我对老去默认相信的 3 句话"（如"老人是负担""老了没欲望"），并标注每条是"我的"还是"我角色的"。

2. **隔离并转嫁**
   - 完成标准: 把"属于作者"的预设隔离，不允许它直接决定角色行为；若该预设想进故事，必须作为**某位角色的 misbelief** 由其自行挣脱（交 `wfs-inner-misbelief`），而非作为作者立场输出。

3. **查素材/视角偏差**
   - 完成标准: 核对群像是否出现"全守旧/全利他/全从子女视角"的单一化；若有，补至少一位打破该模具的老人或一条非子女视角线。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要的是"角色的错误信念是什么、怎么设计"——`wfs-inner-misbelief`（组A），本 skill 管作者自己。
- 需要的是"角色信念有没有被推翻"的验收——`wfs-change-closure`。

### 作者在书中警告的失败模式

- **作者把自身错信当客观**: 克龙的"作者大脑"警告——你自己的内在问题会组织并扭曲故事，且你往往不自知。
- **内隐观念自动选素材（g37）**: 你只选取符合自己预设的素材、忽略反例，导致群像单一。

### 作者的盲点 / 时代局限

- 本书无专章，"老去"这一具体题材的自省框架需结合 `wfs-anti-trope-guard` 的踩坑清单共同使用。

### 容易混淆的邻近方法论

- `wfs-inner-misbelief`（组A，角色 misbelief，最易与本 skill 互抢：用户说"错误信念"可能指作者或角色，需分辨主语）。
- `wfs-group-change`（群像结构，本 skill 防其被单一模具压扁）。
