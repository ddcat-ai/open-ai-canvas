## I — 方法论骨架 (Interpretation)
它配两条护栏：(1) **共情先于可爱**——读者不需要喜欢主人公，只需要「附着」在他处境上；反套路角色可以 prickly、固执、不讨喜（毒舌），只要动机可理解就黏人，别写成完美讨喜的「国民奶奶」；(2) 两个反例——**ce08（告知而非体验/说教）**：用「其实/显然/可想而知」替观众总结，剥夺自行得出的乐趣；**ce30（标签化人物）**：「和蔼老奶奶」「顽固老爷子」靠形容词定义，关上门，要用具体习惯/动作立人（偷穿已故老伴的拖鞋、用老年机记仇）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《苏菲的选择》——附着体验而非被告知（f11 / p23 核心范例）
- **问题**: 作者要示范「具体优于抽象」为什么关键。
- **方法论的使用**: 因为我们附着在苏菲身上，能感觉到那沉重得难以形容的一切——读者是在体验，不是被告知影响。抽象总结会切断这层附着。
- **结论**: 情绪必须用可感的具体物承载，不能靠旁白总结。
- **结果**: 提供喜剧「把『她很孤独』换成第三次把凉茶倒进花盆」的落地参照。

### 案例 2: 共情先于可爱——prickly 角色也可黏人（p04 原则）
- **问题**: 作者要破除「主角必须讨喜」的迷思。
- **方法论的使用**: 读者附着的是处境与动机（「我也可能会这样」），不是角色的完美——所以毒舌、固执的老人照样黏人。
- **结论**: 反套路角色可不讨喜，只要动机可理解；别把她写成完美「国民奶奶」反而疏远。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 角色靠形容词/标签定义（「和蔼老奶奶」），写不出具体的习惯与动作。
2. 大段讲道理、用「其实她很孤独」替观众总结，担心说教。
3. 想让观众「感受到」她的倔强/孤独，而不是靠旁白告知。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么让观众感受到她的孤独/倔强，而不是我写出来？"
- "别写『她很善良/很固执』这种标签，怎么立人？"
- "这段是不是在说教？我想展示不告知。"
- "这个老人角色太标签化了，观众记不住。"

### 与相邻 skill 的区分

- 与 `wfs-inner-misbelief` 的区别: 本 skill 是「渲染技法」（把错信/情绪落到可感动作）；`wfs-inner-misbelief` 是「错信内容本身」。它定内容，本 skill 负责呈现——前后道关系。
- 与 `wfs-stakes-hook` 的区别: 本 skill 管「怎么展示情绪/立人」；`wfs-stakes-hook` 管「每页有没有张力钩子」。展示技法不替代张力检查。
- 与 `wfs-causal-chain` 的区别: 本 skill 管具体呈现；`wfs-causal-chain` 管细节是否必要，二者不重叠。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **把抽象换成可感动作**
   - 完成标准: 每个情绪/主题找到一个具体物或动作承载（如「第三次把凉掉的茶倒进花盆」「用老年机记仇」），且删掉该具体物后情绪无法被感知。

2. **用行为让观众自己得出**
   - 完成标准: 删掉所有「其实/显然/可想而知」替观众总结的句子；某段对话去掉后若只输出观点、不影响人物，则删。

3. **立人靠具体习惯而非标签**
   - 完成标准: 角色有 ≥1 个可记忆的具体习惯/动作（而非形容词），且用「偷穿已故老伴拖鞋」式行为而非「和蔼/顽固」式标签定义。

## B — 边界 (Boundary) ★

### 🔴 硬约束（世界层·违背就崩）

- 不能违背基本的具体优于抽象·展示立逻辑，否则观众/读者会立刻出戏
### 🟡 软约束（规则层·违背有代价）

- 还没定角色错信、只想拆解「他错信什么」——回 `wfs-inner-misbelief`（本 skill 不定义内容，只管呈现）。
- 已经确认立人清晰、只想查每页张力钩子——回 `wfs-stakes-hook`。
- 已经确认立人清晰、只想审查细节因果必要性——回 `wfs-causal-chain`。
### 🟢 自设约束（认知层·其实可以重定义）

- 以为具体优于抽象·展示立只有一种正确用法——假墙，方法是工具，不是教条
- 以为具体优于抽象·展示立能解决所有问题——假墙，每个方法都有适用场景
