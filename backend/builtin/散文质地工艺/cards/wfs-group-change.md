## I — 方法论骨架 (Interpretation)
- **不是一人弧，是 N 人并行弧**: 不是"一个人的成长史"，而是 N 位老人各带一条 misbelief，在单元/主线里各自改变一点。每人改一点，整体就动了。
- **戏眼可晚出场（c03）**: 真正复杂的那位（如隐藏的"老少女"外婆）可晚几集亮相，前几集所有事件都指向他、为他铺路——主人公晚出场，但此前一切必须指向他。
- **双轴模板直接套（c07）**: 给每位主角一个"表面目标 + 反常识内在错信 + 绕不开冲突 + 内在回报"，这是《风云人物》乔治·贝利验证过的反套路弧模板。
- **年龄错位给情感线合法性（c11）**: 非常规年龄配对（老妻少夫/黄昏恋）的情感模式读者能识别，《哈洛与慕德》为其背书，避免被观众当成硬拗。
- **规范vs个体做冲突源（c32）**: 把"养老院规矩/子女安排"设成具体制度（打卡/不准养狗），让老人作为个体反抗——是反套路的天然冲突发动机。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《阳光小美女》— 群像各自改变（c39，本 skill 命名源）
- **问题**: 克龙在结尾引此说明"一群人各自改变"的写法。
- **方法论的使用**: 家庭成员各带缺陷与错信，在公路旅程里各自崩裂一点，拼成整体改变。
- **结果**: 提供群像结构总纲模板。

### 案例 2: 《破绽》— 戏眼晚出场、前情全为他铺路（c03）
- **问题**: 作者要示范"主人公可晚出场但此前一切指向他"。
- **方法论的使用**: 《破绽》前 17 分钟看似以凶手为主角，实则所有事件都在铺垫、考验检察官比查姆。
- **结论**: 真正戏眼（复杂老人）可晚几集亮相、前几集埋其因果。
- **结果**: 提供"让最复杂的老人后登场"的群像排布法。

### 案例 3: 《风云人物》— 内外双轴 + 改变闭环模板（c07）
- **问题**: 全书最长案例，示范完整"被逼改变"结构。
- **方法论的使用**: 乔治表面想离开小镇，内在错信"留下=失败"，结局获内在回报（无条件的爱），外在目标被推翻。
- **结论**: 直接套给：表面目标 + "认老=失败"式错信 + 绕不开冲突 + 内在回报。
- **结果**: 提供每位主角可复制的双轴弧模板。

### 案例 4: 《哈洛与慕德》/《飞越布谷鸟巢》— 年龄错位与规范反抗（c11/c32）
- **问题**: 克龙分别用二者说明"非常规年龄配对"与"规范vs个体"的模式。
- **方法论的使用**: 老妻少夫的情感模式读者能识别（c11）；体制/规范束缚与个体反抗是冲突源（c32）。
- **结论**: 爱情线用 c11 背书合法性；养老院/子女安排用 c32 设成具体制度冲突。
- **结果**: 提供情感线与冲突源的两条现成结构参照。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 规划 整体结构，不确定"是跟一个人还是跟一群人"。
2. 想让某位复杂老人晚几集出场，又怕前几集散。
3. 给每位主角套"表面目标+错信+冲突+回报"的双轴模板。
4. 想做黄昏恋/姐弟恋情感线，怕观众觉得硬拗。
5. 把"养老院规矩/子女安排"设为冲突发动机。

### 语言信号 (用户的话里出现这些就应激活)

- "这个最复杂的老人我想放后面几集再出场，前情怎么铺？"
- "给套个内外双轴模板该怎么定？"
- "黄昏恋观众会不会觉得硬拗？"
- "group change / 群像 / 戏眼晚出场 / 规范vs个体"

### 与相邻 skill 的区分

- 与 `wfs-change-closure` 的区别（contrasts-with，易混淆）: 本 skill 是**群像结构规划**（谁带什么 misbelief、怎么排布）；`wfs-change-closure`（组B）是**单集/单人改变验收**。二者易混淆——用户问"群像改变"时可能指本 skill 的整体编排，也可能指它的单人验收，需分辨。关系归类为 contrasts-with（对照区分），工作流上则先画地图再验收。
- 与 `wfs-inner-misbelief`（组A）的区别: `wfs-inner-misbelief` 讲"单个 misbelief 是什么"的原理；本 skill 讲"多人 misbelief 如何并行编排成群像"。原理归它，编排归本 skill。
- 与 `wfs-writer-brain` 的区别: `wfs-writer-brain` 防作者用单一执念把群像压成同模具；本 skill 是群像结构本身的设计。

## E — 可执行步骤 (Execution)

1. **画群像 misbelief 地图**
   - 完成标准: 列出 N 位主角，每人一条"表面目标 + 反常识内在错信"，确保彼此不重复、覆盖不同处境（空巢/丧偶/再婚/失能/代际）。

2. **排布出场与冲突源**
   - 完成标准: 标记哪位复杂老人晚出场、前几集如何"一切指向他"（c03）；把"养老院规矩/子女安排"设为具体制度冲突（c32）；若含情感线用年龄错位背书（c11）。

3. **套双轴模板并预留各自改变点**
   - 完成标准: 每位主角有"绕不开冲突 + 内在回报"双轴（c07），且 能落到"每人改一点、整体动"的螺旋推进（g30），非一人独大。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要的是"某集/某位老人的改变有没有闭环"——`wfs-change-closure`，本 skill 管结构规划不管验收。
- 需要的是"单个错误信念是什么"的原理——`wfs-inner-misbelief`（组A）。
- 需要的是"作者自己对老去的预设"自检——`wfs-writer-brain`。

### 作者在书中警告的失败模式

- **副情节不服务主弧（p28，群像版）**: 多线若不以"是否推进某位老人内在弧"筛选，群像会散成碎片。本 skill 的地图必须保证每条线长在某人弧上。
- **情节盖过故事（ce18）**: 群像热闹但人人无内在，看完记不住谁信啥。每位老人都必须有可附着的内在错信。
- **标签化（ce30）**: 群像最易把老人按"类型"分配（和蔼的/顽固的/抠门的），关上门读者不附着。

### 作者的盲点 / 时代局限

- 本书无专章，群像的"代际多声部"需结合 `wfs-writer-brain` 避免作者单一视角压扁。

### 容易混淆的邻近方法论

- `wfs-change-closure`（最易互抢：用户说"群像改变"可能指结构规划或单集验收，需分辨）。
- `wfs-inner-misbelief`（组A，单人 misbelief 原理）。
- `wfs-writer-brain`（防群像被单一模具压扁）。

## 相关 skills (阶段 3 填充)

### depends-on（使用前需先理解）
- `wfs-inner-misbelief`：先有单人 misbelief 原理，本 skill 才能编排多人并行弧。

### contrasts-with（易混淆，注意区分）
- `wfs-change-closure`：本 skill 是**群像结构规划**（谁带什么 misbelief、怎么排布）；它（组B）是**单集/单人改变验收**。问"群像怎么编排"归本 skill，问"某集老人改没改"归它。"群像改变"一词两 skill 都用，需分辨规划还是验收。

### composes-with（常配合使用）
- `wfs-writer-brain`：防作者单一视角/执念压扁群像。
- `wfs-anti-trope-guard`：群像编排时同步避坑（标签化 ce30 / 情节盖过故事 ce18）。
