## 〇、宪章

### 0.1 定位与测量

**做什么**：接 story-developer 的 treatment/节拍表，写成剧本文本——场景、动作、对白。按形态适配：动画项目偏对白+关键动作（结构已由 treatment 给、对白常在分镜与配音中定），剧集/真人项目出完整对白剧本。

**测量**：剧本是中间产物，先让第一读者（导演/制片/决策者）在纸上看到电影、听到人物；最终通过成片服务观众。好坏看读者端可观测效应——读起来看得见画面、对白像真人且有言外之意、场景不拖。

### 0.2 根：只写看得见、听得见的

剧本只能写两样东西：动作（看得见）和对白（听得见）。内心、情绪、动机、主题——这些内在的东西不能直接写出来（那是小说的权利），必须外化成动作和对白。

**剧本的功力在潜台词**：把内在外化成外在，同时让读者透过外在读到内在。人物在桌下撕餐巾纸（动作）让你看到他紧张，胜过一句"他很紧张"。on-the-nose 对白（人物直接说出心里想的）之所以坏，就是它跳过了外化——真人不这么说话。

### 0.3 视觉优先（取舍依据）

McKee：电影 80% 视觉、20% 听觉。能用动作表达的，就不写对白。这是动作与对白冲突时的取舍——动作 > 对白。一页对白说他爱她，不如一个他默默修好她单车的动作。

### 0.4 依赖铁律

* 本skill不知道任何项目的存在。项目信息从输入进来。
* 不假设上下游skill存在。有套件时：接 story-developer 的 treatment/节拍表/人物两清单 + character-designer 的语言签名，产出剧本文本给 sequence-director（翻译成镜头）和总导演（对白→配音）。
* 按需取用：用户只要一场戏就写一场；只要改对白就走对白诊断。

### 0.5 输出纪律

* 结论先行，平实。
* **不写镜头**：剧本写"发生什么"（动作、对白、场景），不写景别角度机位（那是 sequence-director 的事）。文学剧本不是分镜头剧本。
* 不写不可见的：不写"他想起童年""她暗暗下定决心"——这些要外化成动作或对白，否则就是没写成剧本。

## 一、三轴（速查，详见 references）

剧本作为文本的三个正交维度：

| 轴         | 标准                                   | 详见            |
| --------- | ------------------------------------ | ------------- |
| **动作可视性** | 事件和内在写成可见的画面与行为，show don't tell，可读可拍 | references/02 |
| **对白潜台词** | 不 on-the-nose，言外之意；人物声音差异；对白有功能      | references/01 |
| **场景经济**  | 晚进早出、每场有冲突（内+外）、无废场                  | references/03 |

贯穿：潜台词（动作泄漏内心 + 对白言外之意，根的核心）；页面节奏（三轴做好后的综合结果，留白和段落控制阅读速度）。

## 二、工序（六步）

### 第0步 输入

故事蓝图：story-developer 的 treatment/节拍表（每场事件/情绪/坑） 人物：人物两清单（含语言签名）+ character-designer 语言签名/表情域 定位：形态（动画偏对白+关键动作 / 剧集完整剧本）、受众

### 第1步 场景划分

把节拍表拆成场景。每场定：这场的冲突（内+外）、这场的功能（推进什么、揭示什么）、进出点（在哪开始、在哪切走）。写不出冲突的场，删或并。

### 第2步 场景写作

每场晚进早出——直接切入冲突核心，情绪转折或信息给完就收。写动作线和对白。动作线讲对白讲不了的（行为泄漏内心）。

### 第3步 对白打磨

* 先写直白版（把人物想说的直接写出来），再改写出潜台词（让他们绕着说、用别的话题说、用动作代替）。
* 人物声音差异化：对照人物的语言签名，每个人物说话方式不同（句长、用词、语气、说不说）。
* 删功能性冗余：对白不只传信息，删掉只为交代信息的台词（信息尽量靠动作和情境给）。

### 第4步 视觉优先过一遍

逐段问：这句对白能不能用一个动作替代。能就替（McKee 80/20）。这一步把剧本从"话剧"拉回"电影"。

### 第5步 自审

按 references/04 清单：三轴 + 格式 + 不可见检查（有没有写了内心/镜头）。

### 第6步 输出

剧本文本：场景标题（INT./EXT. 地点 日/夜）+ 动作描述 + 对白 附：场景表（每场冲突/功能/进出点）给 sequence-director 对白清单 给总导演（配音）

## 三、诊断模式（用户拿现成剧本/对白来）

1. 先问定位：什么形态、哪场或整本、什么意图。
2. 三轴扫描：
   * 动作可视性：有没有写不可见的（内心/抽象）、动作描述能不能让人看见画面。
   * 对白：有没有 on-the-nose（直接说心里话）、人物声音是否雷同、有没有传声筒台词。
   * 场景经济：场景有没有晚进早出、每场有没有冲突、有没有废场。
3. 视觉优先检查：有没有该用动作却用了对白的地方。
4. 输出：问题按影响排序，每个给——哪轴、具体位置、怎么改（给改写示范，不只指出）。

常见病症对照表见 references/04。

## 四、接口

| 方向                    | 内容                                            |
| --------------------- | --------------------------------------------- |
| 上游 story-developer    | treatment/节拍表（故事蓝图）+ 人物两清单（语言签名）。story 退到这里为止 |
| 上游 character-designer | 人物语言签名/表情域 → 对白的人物声音依据                        |
| 下游 sequence-director  | 剧本文本（场景/动作/对白）+ 场景表 → 翻译成镜头                   |
| 下游 总导演                | 对白清单 → 配音依据                                   |

与 story-developer 的剥离：story 管故事成不成立（结构/人物弧/情节），到 treatment/节拍表为止；本skill管文本写得好不好（动作/对白/场景）。交接点是 treatment/节拍表。 与 sequence-director 的边界：本skill写"发生什么"，分镜写"怎么拍"。本skill不带镜头。

## 五、反模式（永远不做）

1. 写不可见的——"他想起""她明白了""心中涌起"，没外化成动作或对白
2. on-the-nose——人物直接说出心里想的，没有潜台词
3. 写镜头——景别/角度/机位，越界到 sequence-director
4. 场景不晚进早出——拍停车上楼、拍道别挂电话，拖
5. 传声筒对白——只为向观众交代信息的台词
6. 人物声音雷同——所有人一个说话方式
7. 该用动作却用对白——违反视觉优先
8. 碰故事结构——改情节/人物弧（那是 story-developer 的事，发现问题反馈回去）

## references/01-dialogue

## 对白 — 潜台词、人物声音、功能

对白是"听得见的"那一半。好对白的核心不是说得漂亮，是潜台词——人物没直接说出的内心，藏在说出口的话底下。

### 一、潜台词：对白的命脉

**on-the-nose（直白对白）\= 坏**：人物直接说出心里想的。"我很生气，因为你忘了我的生日。"真人不这么说话。

**潜台词 \= 好**：人物绕着说、用别的话题说、用反话说。同样生气，她可能说"哦，今天几号来着？"——说的是日期，真正在说的是你忘了。

实用方法（业内通用）：**先写直白版，再改潜台词**。把人物想说的直接写出来（找到内核），然后改写——让他们用别的话说、用动作代替、或干脆沉默。挑言外之意最足的版本。

潜台词的手段：

* 答非所问、绕开正题
* 用具体小事说抽象大事（不说"我爱你"，说"你伞带了吗"）
* 反话、玩笑掩盖真心
* 沉默和停顿（不说，比说更重）
* 话说一半

### 二、人物声音差异化

每个人物说话方式不同，读对白不看名字也能认出是谁。差异化的维度（对照人物的语言签名）：

* 句长与节奏：长句缜密 vs 短句利落 vs 断续犹疑
* 用词层级：文雅/粗俗/术语/方言/年代感
* 语气：攻击/防御/讨好/疏离/戏谑
* 说不说：话痨 vs 惜字如金（沉默也是声音）
* 口头禅与句式习惯（接 character-designer 的语言签名，全片一致）

测试：把对白的人物名遮住，能不能认出谁说的。认不出 \= 声音雷同，重写。

### 三、对白的功能（不只传信息）

每句对白应该同时做几件事，只做"传信息"一件的是传声筒台词，删。对白的功能：

* 揭示人物（怎么说，暴露他是谁）
* 推进冲突（对白是动作——争夺、试探、操纵、防御）
* 埋潜台词（言外之意）
* 关系状态（谁主导、谁退让、亲疏）

**对白是动作不是交谈**：人物说话是为了得到什么（McKee/Mamet），不是为了交换信息。每段对白底下有一个"他想要什么"。

### 四、信息怎么不靠对白给

剧本要交代的信息（背景、关系、设定），尽量别用对白直接说（"我们认识十年了""自从你爸走后…"\= 笨拙的信息倾倒）。改用：

* 动作和情境（看他们的相处方式，看出认识多久）
* 道具和环境（墙上的照片给背景）
* 冲突中带出（吵架时甩出来的信息，比平铺直叙自然）

### 五、对白诊断（拿现成对白来）

1. 标出 on-the-nose：哪句是人物直接说心里话——改潜台词。
2. 遮名测试：人物声音雷同吗。
3. 找传声筒：哪句只为交代信息——删或改成动作给。
4. 问"他想要什么"：每段对白底下有没有欲望，没有就是空交谈。
5. 视觉优先：哪句对白能用动作替代（见 references/02）。

修法给改写示范，不只指出问题。

## references/02-action-lines

## 动作描述 — 可视化写作

动作描述是"看得见的"那一半。它把事件和内在写成可见的画面与行为。McKee：电影 80% 视觉，能用视觉表达就别写对白。

### 一、只写镜头里能看见的

动作描述的铁律：只写一台摄影机能拍到的东西。

* 能写：他攥紧拳头、她把照片塞进抽屉、雨水顺着窗玻璃下淌。
* 不能写：他想起了父亲、她下定决心、他心里五味杂陈——这些不可见，是小说的写法。要外化成动作。

诊断自查：把每句动作描述想象成画面，拍不出来的（内心、抽象、过去），改写成可见的行为或删。

### 二、内在外化：怎么把看不见的写成看得见的

这是动作描述的核心功力，也是潜台词在动作层的体现。

| 内在（不能直接写） | 外化成动作（写这个）          |
| --------- | ------------------- |
| 他很紧张      | 他在桌下把餐巾纸撕成碎条        |
| 她还爱着他     | 她留着那只缺角的旧杯子，别的都换了新的 |
| 他在说谎      | 他回答时，手指无意识地摩挲婚戒     |
| 父子关系疏远    | 两人并排吃饭，没有交谈，电视开着    |
| 她下定决心     | 她剪掉了留了十年的长发         |

方法：先写出内在（他很紧张），再问"这个内在会让他做出什么可见的动作"，写那个动作，删掉内在陈述。

### 三、动作描述讲对白讲不了的

McKee 的视觉优先：能用动作说的不写对白。

* 不写一页对白讲他多爱她，写他每天默默替她热好牛奶。
* 不写"我们好久没说话了"，写两人各看各的手机、沉默。

动作和对白冲突时，动作优先（动作 > 对白）。检查剧本时，把能转成动作的对白转掉。

### 四、写得有节奏、可读

动作描述也是给人读的，节奏影响阅读体验：

* 简洁：动作描述用短句、现在时、主动语态。避免冗长的环境描写（环境交给 worldbuilding/分镜，剧本只写和这场戏相关的）。
* 留白：一段动作描述别超过几行，长段落拖慢阅读。关键动作单独成行，强调。
* 节奏匹配内容：紧张场景短促断句，舒缓场景可以长一点。

### 五、和分镜的边界

动作描述写"发生什么"（人物做了什么动作、发生了什么事件），不写"怎么拍"（景别、角度、机位、运镜）。

* 写：他冲进房间，一把推开桌子。
* 不写：低角度特写他的脚步，快速横摇到桌子（这是分镜 sequence-director 的事）。

剧本提供可见的动作和事件，分镜决定用什么镜头拍它。剧本越界写镜头，会限制分镜的设计空间，也违反文学剧本的规范。

## references/03-scene-craft

## 场景写作 — 经济与冲突

场景是剧本的基本单位。每场戏要回答：它为什么必须存在（功能），它的冲突是什么，从哪进、从哪出。

### 一、晚进早出（enter late, leave early）

场景结构的第一法则。

* **晚进**：直接切入这场戏的冲突核心，跳过铺垫。不拍人物停车、上楼、敲门、寒暄——从门已经推开、争执已经开始的那一刻进。
* **早出**：情绪转折发生、或信息给完的瞬间就切走，不拍道别、挂电话、走出房间。让观众带着余味进下一场。

判断进出点：找到这场戏真正的"事件"（冲突点或信息点），进点设在它之前一点点，出点设在它刚完成时。前后多出来的都是赘肉。

例：一场分手戏。不从两人坐下点咖啡开始，从"所以你是要走了"这句进；不拍她哭着收拾东西离开，在他说不出话、她起身的那一刻切走。

### 二、每场必有冲突

每场戏的核心是冲突。没有冲突的场是死场，删或并入别的场。

冲突有两层，好场景两层都有：

* **外部冲突**：人物之间、人物与处境之间的可见对抗（争夺、阻挠、谈判、对峙）。
* **内部冲突**：人物内心的挣扎（想要 vs 该做、说 vs 不说）。

外部冲突推进情节，内部冲突让场景有深度。只有外部\=动作戏单薄；只有内部\=闷。

场景里的对白和动作都是冲突的武器——人物在争夺什么、试探什么、回避什么。

### 三、场景的价值转变

好场景从一个状态进、到另一个状态出，中间有转变（参考故事 skill 的麦基场景法）。

* 进场：某个情绪/关系/信息的状态（希望、信任、未知）。
* 出场：状态变了（希望→绝望，信任→怀疑，未知→揭晓）。
* 没有转变的场（进出状态一样）\= 这场戏没发生事，删。

转变可以小（一次微妙的关系松动），但必须有。

### 四、场景的功能

每场戏在整个剧本里要有功能，写之前先问这场戏干什么：

* 推进情节（发生了改变后续的事）
* 揭示人物（让我们更懂某人）
* 埋伏笔 / 还伏笔
* 转折（反转、揭晓）

一场戏最好同时做几件（推进情节的同时揭示人物）。只做一件且可有可无的，考虑并场。

接 story-developer 的节拍表——每场对应节拍表上的事件和情绪，场景写作是把节拍落成具体的戏。

### 五、场景诊断

1. 进出点：晚进早出了吗，还是有铺垫赘肉和拖尾。
2. 冲突：这场冲突是什么，内外两层都有吗，还是死场。
3. 转变：进场和出场的状态变了吗。
4. 功能：这场戏干什么，删了故事塌不塌。塌\=必要；不塌\=考虑删并。

## 剧本格式与自审

### 一、剧本格式（master scene / 文学剧本）

标准文学剧本的基本元素。本skill出文学剧本，不出分镜头剧本（不带镜头）。

场景标题（Slugline）：INT./EXT. 地点 - 日/夜   INT. 钟表铺 - 夜  动作描述（Action）：现在时、简洁、只写可见的。   老周俯在工作台前，台灯把他的影子投在墙上。门铃响。他没抬头。  人物名（Character）：对白前，大写或加粗居中（按制式）。   老周  对白（Dialogue）：   打烊了。  （动作提示 Parenthetical）：节制使用，只在必要时。   （头也不抬）

形态适配：

* 剧集/真人：完整格式，对白齐全。
* 动画：可简化——重点是场景、关键动作、对白；分镜阶段会重新组织。按定位选详略。
* 中文项目：场景标题和元素可中文化，保持结构清晰即可。

### 二、自审清单（出稿前）

#### 根：只写看得见听得见的

* 有没有写不可见的（内心/情绪/动机/过去）——找"他想/她觉得/心里"，外化成动作或对白
* 有没有写镜头（景别/角度/机位）——删，那是分镜的事

#### 动作可视性（轴1）

* 每句动作描述都能拍成画面
* 内在都外化成可见行为了
* 动作描述简洁、有节奏、留白

#### 对白潜台词（轴2）

* 没有 on-the-nose（人物直接说心里话）
* 遮名能认出谁说的（人物声音差异）
* 没有传声筒台词（只为交代信息）
* 每段对白底下有"他想要什么"

#### 场景经济（轴3）

* 每场晚进早出
* 每场有冲突（内+外）
* 每场有价值转变
* 每场有功能，没有可删的废场

#### 视觉优先

* 能用动作替代的对白，替换了（McKee 80/20）

### 三、常见病症对照表（诊断模式用）

| 症状         | 轴     | 病因                   | 修法                         |
| ---------- | ----- | -------------------- | -------------------------- |
| 台词太假、不像人话  | 对白    | on-the-nose，人物直接说心里话 | 先写直白版再改潜台词，绕着说/用动作代替       |
| 人物说话一个味    | 对白    | 声音没差异化               | 对照语言签名，拉开句长/用词/语气          |
| 台词在硬塞背景    | 对白    | 传声筒、信息倾倒             | 信息改用动作/道具/冲突中带出            |
| 读着像小说、拍不出来 | 动作可视性 | 写了内心/抽象              | 外化成可见行为，删内心陈述              |
| 画面感弱、平     | 动作可视性 | 该用动作却用对白             | 视觉优先，对白转动作                 |
| 这场戏拖       | 场景经济  | 没晚进早出，有赘肉拖尾          | 切掉铺垫和拖尾，从冲突进、转折出           |
| 这场戏可有可无    | 场景经济  | 无冲突或无功能              | 加冲突，或并入别场，或删               |
| 越权写了镜头     | 根/边界  | 写了景别角度机位             | 删镜头，只留可见动作（镜头交分镜）          |
| 改着改着动了情节   | 边界    | 碰了故事结构               | 退回，结构问题反馈给 story-developer |

### 四、输出与接口

核心产出：

* 剧本文本（场景标题 + 动作 + 对白）
* 场景表（每场：冲突/功能/进出点）→ 给 sequence-director 做分镜的依据
* 对白清单 → 给总导演做配音依据
