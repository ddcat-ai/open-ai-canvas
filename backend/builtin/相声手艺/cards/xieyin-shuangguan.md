## I — 方法论骨架 (Interpretation)

谐音是传统相声里**门槛最低、最自然**的钩子。机制只有一句话：**利用同音 / 近音异义，让一句话同时承载两层意思（字面义 + 谐音义），制造误会或俏皮双关**。

落地三步：
1. **找同音词**：在市井口语里找同音 / 近音词（如"枣"与"早"、"蟹"与"谢"、"机"与"鸡"）。越口语越自然。
2. **制造两层意思**：让听众先按字面理解，再"翻"到谐音义——落差即笑点。
3. **口语化落地**：脱口而出，不解释。文绉绉地玩谐音 = 假，会冷场。

关键直觉：**谐音不是"修辞装饰"，而是"误导机制"**——和笑话结构（铺垫误导→笑点打破）是同一套东西，只是发生在语言层。

## A1 — 书中的用法 (Past Application)

### 案例 1：序言"见机行事 / 见鸡行事"
- **情境**：古人赞某老爷"见机行事"（懂得看时机办事）。
- **方法论使用**：故意谐音成"见鸡行事"，把"德行"双关成"见鸡"的荒唐，讽刺得令人拍案。
- **结论**：一个谐音，褒义变嘲讽，四两拨千斤。

### 案例 2：《三近视》开场"近视 / 进士"
- **情境**：段子名《三近视》，观众预期是"视力差"的笑话。
- **方法论使用**：先提《四进士》（真戏名），再说"没听过三进士"——用音近制造认知错位，把"近视"偷换成"进士"，开场即钩住。
- **结论**：谐音做"开场钩子"比硬抖更自然。

### 案例 3：海量文字游戏段子
- 歪讲《三字经》《百家姓》、对春联、猜灯谜、字相、双字意、反正话——本质都是"同音异义制造误会"的变体，全书最密集的技法区。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 写短视频 / 段子开头，想要一个"低门槛、立刻抓耳"的钩子。
2. 带货口播想软植入——用产品名谐音制造俏皮双关，比硬夸自然。
3. 想玩"冷笑话 / 谐音梗"但怕硬拗、不自然。

### 语言信号
- "谐音梗" / "玩个字" / "双关" / "用蟹（谢）" / "用枣（早）" / "开头怎么抓人"

### 与相邻 skill 的区分
- 与 `fanzhuan` 区别：fanzhuan 是**结构层**反转（铺垫→打破预期）；xieyin 是**语言层**谐音（同音双关）。一个段子可同时用二者。
- 与 `kuazhang-wuhui` 区别：kuazhang 是程度放大 / 身份错位；xieyin 是同音异义。

## E — 可执行步骤 (Execution)

1. **列同音词**：把话题核心词的所有口语同音 / 近音词列出来（枣/早、蟹/谢、机/鸡…）。
   - 完成标准：至少有 2–3 个候选。
2. **选自然的一个**：挑"听众会先按字面理解、再翻到谐音"的那个，避免生僻字。
   - 完成标准：谐音义与语境能咬合。
3. **设计"先字面后谐音"展开**：先认真说字面义，最后一句翻到谐音义（底在最后）。
   - 完成标准：翻的瞬间有落差感。
4. **口语化脱口而出**：不解释、不标注"这是谐音"，让听众自己品。
   - 完成标准：读出来像日常说话。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- **为谐音而谐音、脱离语境硬拗** → 变成冷笑话，观众品不出。
- **文绉绉地玩谐音** → 不自然，像掉书袋。
- 纯结构反转需求 → 用 `fanzhuan`；纯自嘲需求 → 用 `zichao`。

### 作者 / 传统段子警告的失败模式
- 谐音滥用：每段都谐音，观众疲劳，机制失效。
- 谐音义与语境不咬合：听众翻不过去，只剩"没听懂"。

### 现代落地注意
- 带货软植入时，谐音要贴产品功能（如"蟹（谢）谢好评"），别为玩而玩。
- 短视频前 3 秒用谐音钩子，完播率友好；但全片不能超过 1–2 处。
