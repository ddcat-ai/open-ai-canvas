## I — 方法论骨架 (Interpretation)

所有传统段子的底层都是同一句话：**把观众领到一个方向，再突然拐弯**（H1 反转母体）。把它工程化，就是可操作的四步结构：

1. **铺垫（铺）**：建立强预期，让观众脑补故事1；底之前绝不泄露。
2. **三翻四抖（节奏）**：同一梗 / 结构重复铺垫三次（翻），第四次（抖）收口。**节奏决定包袱响不响**——"翻"不够则铺垫不足，抖出不响。
3. **抖包袱（抖）**：用意外但自洽的理由打破预期（故事2），**底必须置尾**。
4. **说学逗唱（补味）**：四门口技——说（台词）、学（模仿）、逗（抓哏）、唱（学唱），以说当先，增色非笑点本身。

关键直觉：**节奏 > 梗本身**。一个普通的梗，三翻四抖铺足了也响；一个绝妙梗，没铺够直接抖，观众懵。

## A1 — 书中的用法 (Past Application)

### 案例 1：曾九的讲究烟袋（提取包）
- **铺垫**：曾九讲究，乌木烟袋杆、白铜锅、翡翠嘴，非出门不用（建立"讲究"预期）。
- **三翻**：三儿用通条不通→用火烧筷子捅→用锤子砸。
- **抖**：烟袋杆劈成两半，三儿换根秤杆凑数——荒诞打破"讲究"预期。

### 案例 2：三翻四抖经典
- 《文章会》掉书袋三次铺垫，一次抖开——节奏本身就是笑点。

### 案例 3：说学逗唱
- 对口相声基本功夫，"以说当先"；贯口（报菜名/地理图）靠语言密度增色，但非笑点本身。

## E — 可执行步骤 (Execution)

1. **铺预期**：认真说一个观众会信的走向，底之前不泄露。
   - 完成标准：观众脑补出故事1。
2. **三翻**：同一梗 / 结构铺垫三次，建立节奏（别一次抖完）。
   - 完成标准：观众开始"期待"收口。
3. **四抖**：第四次意外收口，打破预期，底在最后。
   - 完成标准：翻的瞬间有落差。
4. **说学逗唱补味**：用模仿 / 抓哏 / 学唱增色（可选）。
   - 完成标准：密度与趣味提升，不喧宾夺主。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- **底提前说** → 训练观众不笑（硬规则）。
- **没三翻就抖** → 铺垫不足，包袱不响。
- **铺垫讲太快** → 不给观众产生预期的时间。

### 传统段子警告的失败模式
- 为抖而抖，反转不合情理 → 观众懵。
- 贯口当笑点 → 语言密度≠笑点，喧宾夺主。

### 现代落地注意
- 短视频"铺垫三连 + 反转收尾"是三翻四抖的现代版；前 3 秒铺，最后 1 秒抖。
- 伤害线：夸张 / 自嘲一旦变卖惨或刻薄，笑声立刻停（见 `zichao` / `kuazhang-wuhui`）。
