## I — 方法论骨架 (Interpretation)

马氏幽默的核心是**不靠表情靠结构**：说话者全程面无表情、一本正经，笑点全来自内容错位。两大件：

1. **蔫哏冷面开场**：面无表情抛一句反常/暧昧的话（"我快了"），不解释。听众/捧哏追问，追问本身就是逐层揭谜的过程——每追问一层错位加大一档，直到真相（开电梯的）与最初气派的落差完成。**说话者越一本正经，错位越强**。
2. **先吹后泄五步**（荒诞自吹人设）：①立大志/吹大话 → ②配细节让其可信（**细节垫真**：物品清单、数字、地名越细听众越信）→ ③不经意漏出破绽 → ④破绽逐次放大 → ⑤彻底自陷（"乐完了到家吃窝头"）。吹的细节密度决定泄的力度，泄的时机压到最后一句。

关键直觉：自嘲比嘲笑他人更安全更有后劲——角色是自己的笑点本身。

## A1 — 书中的应用 (Past Application)

### 案例 1：电梯工的"出国"（《似曾相识的人》）
- **问题**：开场要立一个"有派头"的人，再打破它。
- **方法论的使用**：冷面抛"我快出国了"，追问后揭底"你在曲艺团开电梯，上几个下几个"——气派与真相落差即笑点。
- **结论**：反常开场 + 追问揭谜 = 天然钩子。

### 案例 2：大善人的"吃窝头"（《开粥厂》）
- **问题**：塑造"大善人"人设并保持喜剧性。
- **方法论的使用**：吹到"舍粥舍到哈哈一乐"，随后自曝"乐完了到家吃窝头"——吹得越具体，泄得越狠。
- **结论**：细节垫真是先吹后泄的引擎。

### 案例 3："十点钟开始"的艺术家（《十点钟开始》）
- **问题**：立"未来伟大艺术家"人设。
- **方法论的使用**：立大志"十点以后我是全世界有名的伟大艺术家"，随后无限期"不开始"。
- **结论**：自曝惰性是荒诞自嘲的经典收束。

## E — 可执行步骤 (Execution)

1. **定人设标签**：给叙述者一个"吹点"（身份/成就/理想），无害不伤人。
   - 完成标准：吹点说出来显得可爱而非狂妄。

2. **细节垫真**：给吹点配 2-3 个具体细节（数字、地名、物品清单），越细越像真的。
   - 完成标准：细节让听众差点信了。

3. **设破绽点**：安排一个不经意的自曝（"其实…"），不解释。
   - 完成标准：破绽与吹点形成落差。

4. **放大自陷**：让破绽在后续叙述里逐次放大，最后彻底自陷。
   - 完成标准：收在"最惨/最平凡"的真相上，压到最后一句。
   - 判停条件：若自曝涉及贬低真实群体 → 换无害版，红线不碰。

5. **自查换壳**：吹点/细节/自曝桥段全部自创。
   - 完成标准：找不到与源书段子的对应关系。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- **需要热情亲和/权威可信**的场合（发布会、官方号、求信任场景）。
- 自嘲对象是真实受害群体——红线。
- 用户其实想表达真实愤怒——冷面需要距离感，情绪过载时先处理情绪。

### 相声界警告的失败模式
- **自吹失去"自曝开关"**：只吹不泄，人设滑向真狂妄，听众等着看翻车却等不到（ce03）。
- **陈旧价值观触发冒犯**：拿身份/性别/地域开涮的旧包袱，现代会翻车（ce08）。
- **丑角"伤害指向"错位**：自嘲可以，指向他人即欺凌（ce09）。

### 作者的盲点 / 时代局限
- 马氏段子带旧时代市井语境（身份调侃、性别预设）；迁移时自嘲对象严格限"自己"。

### 容易混淆的邻近方法论
- 与"冷幽默段子"（讲一件冷事）的区别：本 skill 是**人设层**的冷面自嘲（贯穿人设），不是单句冷幽默。
