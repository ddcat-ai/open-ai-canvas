# 画质净化

## 何时用

生成图出现以下问题时使用：

- 皮肤或材质像塑料，毛孔和纹理被磨平。
- 画面油腻、发灰、色块脏、渐变有断层。
- 噪点、颗粒、伪影、边缘毛刺或局部糊成一片。
- 过度锐化，边缘出现白边，细节像刻出来。

先定位问题，再选正向改写或负向排除，不要把所有“高级词”一起堆上。

## 两种写法

### 模型支持负向提示词

只放真正要排除的项：

```text
plastic skin, wax figure, over-smoothed, dirty color blocks,
banding, excessive noise, sharpening halos, crushed shadows,
clipped highlights, blurry product edges, AI artifacts
```

### 模型不支持负向提示词

改写成正向可见事实：

```text
保留自然皮肤纹理与细小毛孔，材质微表面真实；
阴影有层次，亮部不过曝，渐变平滑；
商品边缘干净，细节清楚但不过度锐化；
整体通透、色彩干净，真实摄影质感。
```

## 按问题修

| 问题 | 正向改写 |
| --- | --- |
| 塑料磨皮 | 自然皮肤纹理、细小毛孔、轻微肤色不均 |
| 油腻脏污 | 通透干净、色块边界明确、渐变自然 |
| 过锐化 | 边缘自然、细节真实、无白边 |
| 噪点伪影 | 低噪、连续表面、干净材质 |
| 商品变形 | 回到参考图与固定短语，先修结构再修画质 |

## 纪律

- 商品结构错误不能靠“降噪、柔化”掩盖。
- 人像净化不能把年龄、痣、疤、皱纹等身份特征一起磨掉。
- 不要同时写“超写实、8K 超锐、柔焦、胶片颗粒、无噪点”这类互相冲突的全局词。
- 一次只修一个主问题；连续两轮仍不改善就回到参考图、构图或模型选择。

## 验收

- 放大看，材质有微表面，不是整片平滑。
- 商品边缘、文字边缘和发丝没有白边。
- 明暗部都保留细节，渐变没有色带。
- 身份特征和商品识别没有被“净化”掉。
