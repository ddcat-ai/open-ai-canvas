# 电商详情页

## 何时用

- 做完整详情页、详情长图或移动端商品介绍页。
- 参考竞品拆模块，再映射到自家商品。
- 已有商品图和卖点，需要统一排版并逐模块出图。

不做单张主图；主图、海报与多角度图走商品图卡。

## 先拆模块，再写文案

### 1. 竞品模块拆解

按从上到下记录：模块名、用户问题、视觉证据、文案主张、版式结构、是否值得复用。

只借信息架构和节奏，不复制品牌素材、独特文案或受保护版式。

### 2. 自家模块映射

建议 8-12 个模块，常用顺序：

```text
首屏识别 -> 核心痛点 -> 主卖点 -> 材质/结构 -> 使用方式
-> 细节证据 -> 尺寸参数 -> 对比/信任 -> 场景代入 -> 收口行动
```

商品简单就减模块，不为凑长度重复同一条卖点。

### 3. 文案全案先行

在出图前逐模块定稿：

- 标题
- 正文
- 参数
- 小标签
- 需要预留的真实资产位置

后续提示词只粘贴定稿文字，不让模型临时改写。

## 统一排版规范

先写一段所有模块共用的 `TYPO`，并原样放进每条模块提示词：

```text
TYPO：画布宽 <px>；左右安全边 <px>；标题字号/字重/颜色；
正文字号/行距/颜色；小标签样式；模块上下留白；禁止新增字体。
```

每个模块再声明自己的小标签和视觉主角，避免全页只有一个模板。

## 逐模块出图

每模块提示词包含：

1. 本模块要回答的用户问题。
2. 商品固定短语与参考图职责。
3. 画面结构、视角与道具。
4. 逐字文案与压字位置。
5. 统一 `TYPO`。
6. 真实资产空框，例如“右上预留 320×320 透明 PNG 位，不生成内容”。

先生成完整文案版式，再处理真实产品图、认证图、人物图等需要后期置入的资产。

## 拼接与验收

- 所有模块定宽，拼接后无横向抖动。
- 字号层级、边距、颜色和标签样式一致。
- 每模块单独检查文字、产品、裁切和安全边，再做整页滚动检查。
- 相邻模块不重复同一张图、同一句文案或同一个卖点。
- 首屏 3 秒能看懂“是什么、凭什么、下一步看什么”。
