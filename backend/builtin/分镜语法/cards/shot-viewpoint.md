## I — 方法论骨架 (Interpretation)

作者把"观众该站在谁那边"做成可量化的档位旋钮，而非靠感觉：

1. **三档 + 中间档**：全知（客观、距离最远）→ 受限第三人称（跟随但不进眼）→ 修饰主观（带角色情绪滤镜但不完全第一人称）→ 第一人称 POV（角色眼睛，认同最强）。认同度随主观性增强而递增。
2. **用档位调控同情**：想让观众爱谁，就给谁强 POV/过肩；想让观众恨/疏离谁，就压低其镜头主观性（用全知/受限第三人称拉距离）。这是用镜头语言而非台词调控同情。
3. **POV 三段式语法**：角色侧脸"看"（look shot）→ 切其 POV 所见 → 回角色反应。缺了"看"的镜头，POV 就失去主语，观众问"这是谁在看"。
4. **过肩的主观性**：过肩既是几何（shot-dialog-blocking）也是认同工具——越偏向对方、越近，越把观众塞进听话者的主观位置。
5. **配合构图与机位高度**：封闭/对称构图 + 受限第三人称可量化传达"被围困/疏离"（c03《毕业生》）；机位高低再叠加审美距离。

核心是"主观性档位 = 认同度旋钮，POV 必须前置'看'"。

## A1 — 书中的应用 (Past Application)

- **《毕业生》对称构图与主观疏离（c03）**：问题——如何用镜头传达主角"被围困/旁观"心理？方法论使用——反复中轴对称、人物被门框窗框框死的封闭构图，配合受限第三人称视点保持距离。结论——构图与视点是可量化的心理调控工具。结果——量化传达窒息与疏离，而非纯美术选择。
- **主观 POV 段落（c19）**：问题——如何正确地建立一段第一人称主观？方法论使用——角色侧脸"看"→ 切其 POV 所见 → 回角色反应，前置"看"锚定主观。结论——主观镜头标准语法的可套用三段式。结果——观众认同随主观性增强而建立。

## A2 — 触发场景 (Future Trigger) ★

① **用户情境（3–5 条）**
- 用户想让观众"站在这角色这边"或"讨厌那个反派"，但不想靠台词解释。
- 用户设计主观镜头/POV，不确定要不要前置"看"的镜头。
- 用户纠结过肩"切多近算主观、会不会怼脸"。
- 用户想用受限第三人称保持对主角的疏离/窥视距离。

② **语言信号（用户原话式措辞，中英双写）**
- "怎么让观众同情/讨厌这个人 / 这段该用谁的眼睛看"
- "主观镜头怎么拍才不突兀 / POV shot 前面要加什么"
- "过肩太近像主观了，是不是该拉远 / OTS too close, feels like POV"

③ **与相邻 skill 区分（定稿）**
- 与 `shot-dialog-blocking`：过肩是两 skill 交界——彼侧重几何/机位，本 skill 侧重过肩的"主观性强度/认同"。
- 与 `shot-open-close`：视点常与开闭构图配合（c03），但本 skill 管"认同谁"，`shot-open-close` 管"参与度/画框策略"。
- 与 `shot-axis-triangle`：轴线管空间方向，POV 也需守轴线（视线即轴），但本 skill 不负责轴线校验。
- 与 `shot-storyboard`：本 skill 给每个镜的"主观性档位"，由 `shot-storyboard` 落进分镜。

## E — 可执行步骤 (Execution)

1. **定认同目标**：明确这场戏要让观众认同/疏离谁，列出主角与对手的"目标认同度"（强/中/弱）。→ *完成标准*：每个关键角色有目标认同档位标注。
2. **选视点档位**：按目标给每人分配 POV 档（全知/受限第三人称/修饰主观/第一人称）；需要主观处写清三段式（look→POV→reaction）。→ *完成标准*：每个镜头标了视点档位，所有 POV 都有前置"看"的镜头。
3. **校验过肩主观性**：检查过肩夹角/景别是否超出叙事所需亲密度（防 ce18 侵入式逼视）；与构图档（开放/封闭）对齐。→ *完成标准*：过肩紧密度与情绪匹配，无"被怼脸"失衡；构图与视点一致。
   - **判停条件**：若用户只问"两人怎么站位/机位"而非认同，转 `shot-dialog-blocking`；若只问画框开放还是封闭，转 `shot-open-close`。

## B — 边界 (Boundary) ★

① **反场景**：纯客观纪录、或作者性"零认同"疏离美学时，不必刻意调 POV 档位；本 skill 服务于"有意引导认同"的叙事。
② **书中警告的失败模式**
- ce08 主观 POV 无前置"看"的镜头：直接切 POV 所见却没先给角色"看"的镜头，观众不知这是谁的主观，认同失败。
- ce18 内反拍过度（与 `shot-dialog-blocking` 共有）：过肩/内反拍夹角过小、景别过近，亲密变侵入式逼视，观感不适——在视点维度即"主观性越界"。
③ **作者盲点/时代局限**（来自 BOOK_OVERVIEW 批判段）
- continuity 唯一正统偏见下，作者低估了"故意不给 POV、保持疏离"的反套路表达价值。
④ **易混淆邻近方法论**：与 `shot-dialog-blocking`（过肩几何）、`shot-open-close`（画框参与度）易混；记住——本 skill 只回答"观众认同谁、认同多强、POV 语法对不对"，不回答站位、轴线、画框开闭本身。
