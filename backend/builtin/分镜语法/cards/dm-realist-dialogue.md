## I — 方法论骨架 (Interpretation)

1. 对白只有一种正当功能：透露人物"想要什么"（欲望），不是用来推进剧情、塑造性格或说明身份。
2. 烂片用对白"交代"（我要去拿钱），好片用对白"施压"（你他妈昨晚到哪去了）——前者是叙述，后者是欲望的碰撞。
3. 永远努力拍"像默片一样的电影"：能用画面/镜头解决的，绝不用台词；对白是最后手段不是第一手段。
4. 凡用"因为我是……""我是谁、我和某某的关系"这类台词解释动机/身份，一律删——说出来既冗余又提前泄气。
5. 说明关系/身份的需求，改成用对峙性欲望台词或镜头情境带出，让观众自己拼。
6. 操作闭环：写/审一句台词 → 问"它透露欲望了吗" → 若只是交代剧情/身份 → 改成施压式或删掉换成镜头 → 若无法改成镜头则留作最低限度欲望表达。

## A1 — 应用案例 (Past Application)

- **问题→用法→结论→结果（烂片 vs 好片对白，第4章）**：同样"去拿钱"的信息，烂片让角色说"今晚我要去你家拿那笔你欠我的钱"（交代），好片让他说"你他妈昨晚到哪里去了"（施压）。做法＝把叙述式台词换成欲望碰撞式。结论＝对白功能仅是透露欲望；用它叙述剧情=剥夺观众自己拼意义的参与感。结果＝"你愈只是用镜头或演员来叙述，观众愈会想：这到底是怎么回事"——观众被激活。
- **问题→用法→结论→结果（教室戏"提出要求"，第2章）**：学生要"提出要求"（让老师撤销成绩），马梅不用台词说明"我要撤销成绩"，而是用物理动作（把笔记本推上空的讲桌+老师低头看）。做法＝把"要求"译成可拍动作而非对白。结论＝能用动作/镜头表达的，别用台词。结果＝老师盖章撤销，学生微笑，无需一句说明性对白。
- **问题→用法→结论→结果（童话不说明性格，第5章引申）**：童话用最简意象、无性格说明，"若有人物性格特色通常是由观众自由完成"。做法＝不写"因为我是爱尔兰人所以爱喝咖啡"式说明。结论＝身份/性格交给观众，对白不背这个锅。结果＝"故事的开始与结局都非常容易识别"，观众自行补全人物。

## A2 — 触发场景 (Future Trigger)

**用户情境（具体到可识别）**
- 剧本里某句台词在"交代"前情/身份/动机，作者不确定该不该删。
- 角色需要用台词让观众"知道我们曾是恋人"，但禁止说明。
- 对白写得很"顺"但全是信息搬运，没有张力。
- 改台词时想把"说明式"改成"施压式"以增强冲突。

**语言信号（用户原话式 trigger，关键句中英双写）**
- "这句台词是不是在交代剧情/说明身份？" — "is this line expositing / stating identity?"
- "对白怎么只透露欲望？" — "how should dialogue only reveal desire?"
- "能不能不用台词说明关系？" — "can we show the relationship without dialogue?"
- "把交代式改成施压式" — "turn the expositional line into a pressure line."

**与相邻 skill 的区分（初稿）**
- 与 `dm-montage-narrative`：本 skill 管"台词怎么写"，montage 管"镜头怎么并置"；二者都服务于"不靠说明"，但一个是文字层一个是影像层。
- 与 `dm-trim-script`：trim-script 删"不可拍的叙述文句"，本 skill 删"说明性对白"；对白也是叙述的一种，二者在"反叙述"上重叠但 trim-script 更宽（含纯描述）。
- 与 `dm-actor-blocking`：本 skill 是写台词，不是现场排演说戏。
- 与 `dm-superobjective`：本 skill 审单句台词，superobjective 审整场取舍；台词若偏离端线也可砍，但理由不同。

## E — 可执行步骤

1. **标功能**：对每句关键台词，标注它"透露欲望 / 交代剧情 / 说明身份动机"。完成标准：每句都被分类。判停：若一句同时三类，先拆或删交代部分。
2. **改或删**：交代/说明类台词→改成施压式欲望碰撞，或删掉换成镜头情境。完成标准：留下来的台词都"在透露想要什么"，且观众需自己拼关系。判停：若改完仍像在搬运信息，回到 dm-montage-narrative 用镜头替代。
3. **默片测试**：通读该场，尝试"去掉所有台词还能看懂吗"。完成标准：核心信息靠镜头/动作已成立，台词只是欲望余韵。判停：若去掉台词就垮，说明前面镜头没担起叙事，回到步骤 2 或更上游定镜。

## B — 边界与防乱调用

**① 不要使用的情况**
- 用户要的是"用镜头并置制造概念"——那是 `dm-montage-narrative`。
- 用户要的是"给演员说戏/排走位"——那是 `dm-actor-blocking`。
- 用户要的是"整场戏取舍定调"——那是 `dm-superobjective`。

**② 书中警告的失败模式（counter-examples）**
- `ce05 靠对白叙述剧情/说明身份`：用台词交代"我要去拿钱/撤销成绩"或解释"我是谁、我和某某的关系"，观众被动接收而非主动猜。
- `ce16 用"因为我是…"式说明动机`：对白用"因为我是爱尔兰人"解释行为，冗余且削弱张力，提前泄气。
- `ce20 用文字叙述解决"准备"概念`：当动作难拍时退用文字/对白说明，节奏软弱——对白别来补镜头的活。
- `ce09 事后补插对白（ADR）`：拍完才发现信息缺，靠配音硬补，观众根本不在乎；暴露前期规划不足。

**③ 作者盲点 / 时代局限（来自 BOOK_OVERVIEW 批判）**
- **贬低表演与对白的表现力**：方法适配清晰叙事/惊悚，但抒情、话唠型作者电影（如侯麦式对白美学）靠台词本身成立，机械"对白只透露欲望"会削弱其魅力。
- **假设观众永远比你聪明**：适度 exposition 在世界观陌生题材是必要的；完全禁说明性对白可能让观众迷失。
- **极端反学院派**：一概否定戏剧学校训练，忽略台词节奏、潜台词等专业打磨价值。

**④ 易混淆邻近方法论**
- 与 `dm-trim-script` 易混：都"删叙述"，但本 skill 专攻对白层，trim-script 攻剧本叙述文句层；重叠处（说明性对白）二者都管。
- 与 `dm-character-as-action` 易混：都反对"说明性格"，但本 skill 从对白功能切入，character-as-action 从"用行为替代性格设定"切入。
