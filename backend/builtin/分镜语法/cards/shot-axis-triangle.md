## I — 方法论骨架 (Interpretation)

作者把"空间为什么连得起来"上升为可画出的几何约束，三步即可实操：

1. **画轴线**：在两个主体（或动作方向）之间画一条假想线；轴线也可由"视线"而非身体朝向定义（如悬念戏角色看什么，轴线随视线走，c10）。
2. **锁半圈**：所有机位落在轴线同一侧 180° 半圈内；跨到对侧即跳轴，相邻镜主体左右/运动方向会突兀对调。
3. **布三角**：在半圈内取"标准三位"——一个双人主镜（建立关系）+ 两个斜角单人位（覆盖轴线同侧），不必拍满十种；过肩、POV 都从这三位的几何派生。
4. **守 30°**〔非本书主张·业界通例〕：任意相邻剪辑镜角度差≥30°（或换明显景别），否则视觉差异过小、显跳帧。
5. **合法越轴**：必须换侧时，先插一个正对轴线的"中性镜头"（主体正面/背面居中）重置轴线，再换到另一侧，跳轴被重置而不显突兀。

核心是"轴线定生死、三角给机位、中性镜破例"（30° 防跳动为业界通例，本书第6章未主张）。

## A1 — 书中的应用 (Past Application)

- **《群鸟》悬念调度（c05）**：问题——平淡对话如何暗藏不安？方法论使用——严守 180° 与三角机位、克制机位变化。结论——规范空间剪辑是悬疑戏的隐形地基。结果——观众专注人物关系，张力来自调度而非炫技。
- **希区柯克视线轴线（c10）**：问题——悬念靠"角色在看什么"驱动，轴线怎么定？方法论使用——轴线由视线而非身体朝向定义，POV 前置"看"的镜头锚定主观。结论——180° 规则可被视线灵活扩展。结果——扩展了轴线规则的实用性。
- **中性镜头合法越轴（c20）**：问题——需要越轴又不想让观众察觉？方法论使用——先切正对轴线的中性镜头，再换到另一侧。结论——给出守轴线的合法例外。结果——跳轴被重置而不突兀。

## A2 — 触发场景 (Future Trigger) ★

① **用户情境（3–5 条）**
- 用户设计机位图，担心"这样摆会不会跳轴"。
- 用户剪辑后发现"他刚才往右跑怎么变往左""两人左右互换"。
- 用户两镜接上像"同一镜故障跳动"，怀疑机位太近。
- 用户需要标准三位机位几何，或想合法换到轴线另一侧。

② **语言信号（用户原话式措辞，中英双写）**
- "这两镜接起来方向反了 / 怎么跳轴了 / the screen direction flipped"
- "两个镜头太像在跳帧 / 是不是机位太近 / shots look like a jump cut"
- "想换个角度又不想穿帮，怎么越轴 / how to cross the line safely with a neutral shot"

③ **与相邻 skill 区分（定稿）**
- 与 `shot-dialog-blocking`：本 skill 提供轴线/三角几何的底层校验，`shot-dialog-blocking` 在其上做对话形态与机位选择；本 skill 是前置地基。
- 与 `shot-shot-sizes`：本 skill 管空间方向一致性，景别缩写（CU/MS 等）归 `shot-shot-sizes`。
- 与 `shot-viewpoint`：轴线管"空间对不对"，POV 管"认同谁"；中性镜头是越轴工具不是认同工具。
- 与 `shot-storyboard`：本 skill 在分镜成稿前做几何合规检查。

## E — 可执行步骤 (Execution)

1. **定轴线**：标出场景中两个主体或动作方向，画 180° 假想线（悬念/视线驱动时可取视线为轴）。→ *完成标准*：轴线已画出，且明确"由身体朝向还是视线定义"。
2. **布机位 + 标角度**：在轴线同侧半圈内取标准三位（主镜+两斜角单人），给每个机位标角度与景别；相邻镜角度差≥30°〔业界通例〕。→ *完成标准*：机位清单全在轴线同侧，任意相邻两镜夹角≥30° 或景别有级差。
3. **越轴处理**：如需换侧，在换侧前插入正对轴线的中性镜头；事后逐镜核对银幕方向（左右/运动）一致。→ *完成标准*：换侧处有中性镜头，全片相邻镜银幕方向无突兀对调。
   - **判停条件**：若场景本质是单条运动长镜或固定长拍（无剪辑跳轴风险），本 skill 退化为"确认单镜内方向一致"即可；若用户只需"对话站位方案"而非轴线校验，转 `shot-dialog-blocking`。

## B — 边界 (Boundary) ★

① **反场景**：有意跳接/反剪辑（戈达尔式）、作者性长镜不追求连续性幻觉时，轴线约束可被主动打破——但须先掌握规则再破。
② **书中警告的失败模式**
- ce01 跳轴/银幕方向反转：机位落轴线对侧，相邻镜主体左右或运动方向突兀对调，空间感崩塌（含 ce20 追逐戏方向乱）。
- ce02 近似角度跳切〔业界通例〕：相邻镜角度差<30° 且景别相近，画面像故障跳动而非有意剪辑。（注：本书第6章未主张 30° 规则，此为业界通行做法。）
- ce05 把摇镜误当运动镜头：误以为 pan 能提供随主体行进的连续感，实际只扫视不位移，调度语法错乱。
- ce11 画幅后期补救失败：开拍未定画幅，后期裁切损失环境信息（与轴线构图相关的前置硬决策）。
- ce16 镜头清单不规范：缺角度/景别标注，无法事前核对轴线/角度差，现场失控。
③ **作者盲点/时代局限**（来自 BOOK_OVERVIEW 批判段）
- 非线性剪辑时代，越轴可在后期用匹配/遮幅补救，中性镜头不再是唯一合法手段。
- 作者把 continuity 当唯一正统，但蒙太奇/艺术电影故意断轴也是合法表达。
④ **易混淆邻近方法论**：与 `shot-dialog-blocking`（对话机位选择）、`shot-shot-sizes`（景别缩写）、`shot-viewpoint`（POV 认同）易混；记住——本 skill 只回答"空间方向对不对、机位跳不跳轴"，不回答"切多紧""认同谁""用多大景别"。
