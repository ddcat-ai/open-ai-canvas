## I — 方法论骨架 (Interpretation)

1. 把"情绪/意义"从演员身上拿走，还给它本来的归属——蒙太奇（剪接）。镜头并置才产生概念，演员只需把动作做出来。
2. 给演员的指令只能是可观测的物理动作：方向、速度、停顿、位置。用"以相当快的速度走到长廊尽头"而非"你心里其实很愤怒"。
3. 当演员追问"我该想什么 / 我的动机是什么"，统一回"无所谓 / 这不重要"——把追问挡在片场之外。
4. 越不让演员"演"，越可能动人。内敛的单一动作（点头、推笔记本）比满脸情绪更有力。
5. 检验标准：如果这场戏靠演员的脸/表情才能成立，说明镜头设计没做完，回去重做并置，而不是逼演员。
6. 此法最适配清晰叙事、惊悚/骗局类；抒情、慢电影、强表演型作者电影需另议（见 B 段）。

## A1 — 应用案例 (Past Application)

- **鲍嘉点头（《北非谍影》，第4章）**：问题——有人问鲍嘉那场戏"怎么演"的。怎么做——导演只给单纯肢体指令"站阳台、停一下、点头"，鲍嘉照做。结论——情绪由剪接产生，伟大演员都懂蒙太奇。结果——那场戏"看起来特别令人感动"，鲍嘉以极简单动作达成。
- **教室戏"撤销成绩"（第2章，案例 c01）**：问题——如何用镜头完成"学生想让老师撤销成绩"而不拍学生脸。怎么做——只给四个物理动作（早到、准备撕纸标签、起身致意、推笔记本上桌），从不给"内心戏"指令。结论——叙事责任由不相关镜头并置承担，不靠演技。结果——马梅自评"还算拍得不错"，圆满快乐结局。
- **失败对照（ce04）**：凡强求演员演出"心智混乱或爱憎难分"，演员愈想带出意义愈砸锅——反证了指令必须回到物理动作。

## A2 — 触发场景 (Future Trigger)

① **用户情境（可识别）**
- 现场/排练时不知道该怎么"导"演员，想让他"更有戏"。
- 演员反复问"我这个动作时脑中应该想什么 / 我的动机是什么"。
- 一场戏靠演员表情才能推进，分镜里全是特写脸。
- 方法派训练出身，习惯用内心情感带动表演，导演想一句话让他"不演"。
- 想用表演传递剧情关键信息（如对白之外的情绪交代）。

② **语言信号（用户原话式 trigger，中英双写）**
- "演员怎么演才动人？ / how should the actor play to be moving?"
- "怎么让ta入戏、体会角色？ / how to get the actor into character?"
- "这个动作他心里该想什么？ / what should the actor be thinking?"
- "情绪怎么调度出来？ / how to direct the emotion?"
- "走位/肢体动作该怎么排？ / how to block the physical movement?"

③ **与相邻 skill 的区分（依据本组+兄弟 skill 标题）**
- 不同于 **dm-montage-narrative（蒙太奇并置叙事）**：本 skill 管"给演员下什么指令"，蒙太奇 skill 管"镜头怎么并置产生概念"。演员只做动作，概念由镜头负责——二者上下游但问题不同。
- 不同于 **dm-character-as-action（角色即动作）**：角色 skill 管"用行为总和替代性格设定"，本 skill 管"现场如何用物理动作指令让演员执行"，一个在编剧层一个在片场层。
- 不同于 **dm-kiss-shot（K.I.S.S 镜头选择）**：K.I.S.S 管选哪个镜头，本 skill 管镜头里演员做什么。

## E — 可执行步骤

**步骤 1：把"情绪指令"翻译成"物理动作指令"**
- 操作：列出本场所有给演员的指令，凡含"愤怒/悲伤/爱憎/纠结"等词，改写为可观测动作（方向+速度+停顿+位置）。
- 完成标准：每条指令都能被旁观者用"他做了什么动作"一句话描述，不含心理词。
- 判停条件：若某指令无法去心理化（如"演出一种说不出的乡愁"），停止——说明该信息应交给镜头并置（转 dm-montage-narrative），不要逼演员。

**步骤 2：统一挡回"动机追问"**
- 操作：当演员问"我该想什么/动机是什么"，回答"无所谓 / 这不重要"，把注意力拉回动作本身。
- 完成标准：片场不再讨论角色内心，只讨论"下一步走到哪、停多久"。
- 判停条件：若演员坚持需要心理依据才能动，暂停——评估是否选角/类型不匹配本方法论（见 B 段盲点）。

**步骤 3：用"不拍脸也能成立"检验**
- 操作：遮住演员脸，仅看动作与镜头并置，判断戏是否成立。
- 完成标准：去掉面部特写后叙事仍清晰，则演员指令合格。
- 判停条件：若去掉脸戏就散，停止加表演——回到 dm-montage-narrative 重做并置。

## B — 边界与防乱调用

① **不要使用的情况**
- 影片类型依赖表演魅力（抒情、人物心理剧、慢电影、作者电影）时，机械套用会产出扁平疏离表演。
- 演员本身无基础训练，"只做动作"可能变成木讷而非内敛——需区分鲍嘉的"简单"是长期训练后的结果。

② **书中警告的失败模式（ce04）**
- 靠演员演技叙事：把情绪责任压在演员身上，演员越想"带出意义"越砸锅；情绪是剪接产物，要求演出情绪等于让镜头承担它不该承担的意义。

③ **作者盲点 / 时代局限（来自 BOOK_OVERVIEW 批判）**
- **贬低表演与演员**：主张"漠视演技、只取单纯肢体动作"，机械套用易产出扁平表演；鲍嘉"只是点个头"忽略了他被长期训练打磨出的"简单"而非无训练。
- **假设镜头之间必须毫不相关**：本 skill 建立在此假设上，连续性/长镜头/场面调度同样能成立表演。
- **反学院派**：一概否定电影学院训练，忽略系统训练对表演质感的价值。

④ **易混淆邻近方法论**
- dm-montage-narrative（镜头并置叙事）：常被人把"演员不演"误当成"用并置叙事"本身——前者是演员指令，后者是镜头设计。
- dm-character-as-action（角色即动作）：前者现场执行，后者编剧层设定。
