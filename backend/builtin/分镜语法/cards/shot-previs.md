## I — 方法论骨架 (Interpretation)

把"开拍前的视觉规划"拆成可作流程图：

1. **概念图先行**（2.2 独立小节，非四种基本建筑图之一）：气氛图确立场景基调、光影与空间感（非透视精确，重氛围），是美术方向的共同锚点。
2. **平面图/立面图/剖面图**：以精准比例制图——平面图是俯视横剖（地板布局），立面图是正面侧视，剖面图切开看纵深；三者同一比例互相关联，把演员与机位放进同一几何（呼应 p30 演员调度与机位同步设计）。
3. **效果图（摄影角度效果图）**：由平面/立面推演出不同机位下的成片样貌，每更换一次镜头或摄影机位置就重画一张，避免"过度搭景"。
4. **画幅制式前置**：先定 1.33/1.66/1.85/2.35 等宽高比——它直接决定机位高度、构图重心与信息容量，事后裁切无法补回缺失的环境信息（f18）。
5. **数字预视觉化**：用 FrameForge/Poser/运动控制，或今天的 AI 预览，把纸面蓝图搬进虚拟实时环境，低成本"在虚拟中拍片"、提前排雷。

核心是"概念图定调（2.2）→ 平立剖定空间（四种基本建筑图之三）→ 效果图定机位（第四种）→ 画幅前置 → 数字预演排雷"。

## A1 — 书中的应用 (Past Application)

- **案例 c04（《太阳帝国》预视觉化与制作流程）**：问题=庞大场面如何避免现场盲目与失控？方法论使用=前期影像化+故事板统筹，把复杂场景先转化为分镜与镜头清单再执行。结论=影像化+美术预视觉化是大制作的必要前提。结果=减少现场即兴，复杂制作有可控蓝图。
- **案例 c22（宽银幕对话构图）**：问题=同一对话在宽/方画幅下构图重心怎么变？方法论使用=先定画幅（1.85/2.35），宽制式容纳更多环境并置、主体更需横向错落，方制式逼主体居中亲密。结论=画幅是前置构图决策。结果=印证 f18 把画幅当作开拍前硬决策。
- **相关 c24（故事板预演复杂调度）**：在预视觉化蓝图之上，故事板进一步预演影像化、提前发现跳轴/近似镜；本 skill 的"数字预演排雷"即承接此意图。

## A2 — 触发场景 (Future Trigger) ★

① **用户情境（3–5 条）**
- 用户要规划一个场景的空间/美术，需要概念图、平面图、立面图或效果图。
- 用户开拍前要"虚拟堪景"、在软件/AI 里先跑一遍，提前发现机位或构图问题。
- 用户需要选定画幅制式（1.33/1.66/1.85/2.35）并评估电视/播放的构图流失。
- 用户想把剧本的"空间关系"固化成可沟通、可复用的视觉文档。

② **语言信号（用户原话式措辞，中英双写）**
- "这场戏的场景空间/美术怎么设计 / 帮我出概念图、平面图"
- "先虚拟拍一遍排雷 / let's previs this in FrameForge / 在虚拟中堪景"
- "用 1.85 还是 2.35 画幅，电视上会不会丢构图 / pick an aspect ratio"

③ **与相邻 skill 区分（定稿）**
- 与 `shot-storyboard`：storyboard 产出"镜头序列草图"，本 skill 产出"空间/美术/画幅的视觉蓝图"；previs 在前，storyboard 在其上排镜头，二者互补。
- 与 `shot-axis-triangle` / `shot-dialog-blocking`：它们在已定的空间蓝图内排机位与站位；本 skill 负责先把那张"空间蓝图"画出来。
- 与 `shot-movement`：本 skill 可预演运动路径，但运动镜设计细节归 shot-movement。

## E — 可执行步骤 (Execution)

2. **画平立剖与机位**：以精准比例画平面图（含演员走位与机位），配立面图/剖面图定纵深；把演员路径与机位路径画在同一几何里（p30）。→ *完成标准*：有一张标注人物位置、机位、轴线的平面图，比例可读。
3. **出效果图并数字预演**：按候选机位推演摄影角度效果图，并用 FrameForge/Poser/AI 预览在虚拟中跑一遍，列出"过度搭景/跳轴/近似镜/画幅流失"等需修项。→ *完成标准*：给出候选机位的成片预览 + "通过/待修"清单。判停：若已到分镜序列层面→转 shot-storyboard。

## B — 边界 (Boundary) ★

① **反场景**：纯文字剧本或只做台词/节奏修改、不涉及视觉空间时不需本 skill；本 skill 服务于"把文字空间变成可拍/可生成的视觉蓝图"。

② **书中警告的失败模式（counter-examples）**
- **ce11 画幅制式后期补救失败**：开拍未定画幅，构图重心与信息容量不符，事后裁切无法补齐缺失环境信息。
- **ce16 镜头清单不规范致现场失控**：镜头清单缺角度/景别/运动标注，机位决策无依据，无法事前核对 30°/轴线。
- **ce17 未影像化即开拍（凭感觉）**：跳过脑中预演与蓝图，各镜独立决策失整体连续，镜流断裂、空间对不上。

- 全书以横屏影院/胶片、专业美术部门画平立剖与摄影角度效果图为前提；今天可用 AI 生图/数字预视觉化替代 FrameForge，大幅降低执行门槛。
- 依赖专业手绘/ CAD（附录）对极低预算创作者门槛偏高，AI 工具已可替代大部分制图。

④ **易混淆邻近方法论**：与 `shot-storyboard`（镜头序列草图）易混；记住——本 skill 产出"场景空间与画幅的视觉蓝图"，storyboard 在其上产出"镜头清单草图"，两者前后互补而非同一物。
