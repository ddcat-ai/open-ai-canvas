## I — 方法论骨架 (Interpretation)

作者把"转场"从"过渡特效"还原为"时空关系的函数"，两步判定即可：

1. **先判时空是否连续**：两镜在同一时空（连续）→ 用无形转场（硬切、匹配镜头）；两镜跨时间或跨地点（断裂）→ 用有痕转场（叠化、淡、白底淡入/白底淡出、划变）。
2. **再判抒情 vs 节奏**：要柔和、抒情、时间流逝感 → 叠化/淡；要干脆、快节奏 → 硬切；要风格化/空间跳 → 划变；要观众无感衔接 → 匹配镜头（形状/动作相似）。
3. **匹配镜头是无形利器**：上一镜结束于某形状/动作，下一镜始于相似形状/动作，剪辑点被视觉相似"掩盖"，实现无缝且可主动设计（c17）。
4. **专项技法勿滥用**：叠化专用于时间跳跃/柔和过渡，不是默认万金油；硬切表"现在"，叠化表"时间流逝"。
5. **七法与延伸技法**：核心七法是剪切/淡入/叠化/白底淡入/划变/白底淡出/淡出；匹配镜头等为原书 21.4 单列的延伸技法，不属七法。七法是可事前规划、事后核对的基础集。

核心是"连续→无形、断裂→有痕；抒情→柔、节奏→切；匹配做无感衔接"。

## A1 — 书中的应用 (Past Application)

- **《公民凯恩》早餐桌蒙太奇（c01）**：问题——如何在不中断镜流的前提下压缩长篇时间？方法论使用——用相似构图/元素（桌、人位置）衔接，中间叠化或跳切跳年，观众在"相似画面"中读出时间流逝与关系变化。结论——视觉匹配+转场可压缩时间而不打断。结果——问答/因果剪辑的典范，证明转场是时空逻辑而非装饰。
- **匹配镜头无形转场（c17）**：问题——如何实现观众无感的时空转换？方法论使用——上一镜结束于圆形物体（灯/车轮），下一镜始于另一圆形，剪辑点被视觉相似掩盖。结论——匹配从构图巧合提升为主动剪辑技法。结果——实现无形转场并压缩时间，是镜流无痕手段。

## A2 — 触发场景 (Future Trigger) ★

① **用户情境（3–5 条）**
- 用户两个镜头/段落之间不知道"该硬切还是叠化"。
- 用户要处理时间跳跃（如"三年后"）或地点转换。
- 用户想做"观众无感"的衔接（匹配转场）。
- 用户觉得成片"总是在淡/拖沓"，想重选转场。

② **语言信号（用户原话式措辞，中英双写）**
- "这两段怎么接 / 用叠化还是直接切 / 转场太突兀"
- "时间跳了几年怎么过渡 / 地点变了怎么转"
- "能不能接得毫无痕迹 / how to do a seamless match cut"

③ **与相邻 skill 区分（定稿）**
- 与 `shot-shotflow`：转场是镜头间连接的具体技法，`shot-shotflow` 管连接后的整体流畅运动（镜流）；本 skill 选"用哪种接法"，彼管"接起来顺不顺"。
- 与 `shot-storyboard`：本 skill 给分镜序列里每处"接缝"的转场类型，`shot-storyboard` 负责画分镜本身。
- 与 `shot-axis-triangle`：转场不解决跳轴；跳轴是空间问题，归轴线 skill。
- 与 `shot-movement`：运动镜可在单镜内"承接"两个信息点替代转场，但运动路径设计归 `shot-movement`。

## E — 可执行步骤 (Execution)

1. **判时空连续**：对每处接缝标注"连续（同时空）/ 断裂（跳时或跳地）"。→ *完成标准*：每个转场点都有时空属性标签。
2. **选技法**：连续→硬切或匹配镜头（要无感用匹配）；断裂→叠化/淡入/淡出/白底淡入/白底淡出/划变（抒情柔化用叠化/淡，风格化空间跳用划变）。→ *完成标准*：每处转场类型已定，且与时空属性对应，无"连续时空却叠化"错配。
3. **设计匹配（如需无形）**：若选匹配镜头，找出前后镜可对应的形状/动作/运动，使剪辑点被掩盖。→ *完成标准*：匹配元素已指明（如圆→圆、同向运动→同向运动），可实现无感衔接。
   - **判停条件**：若用户纠结的是"镜头接起来整体顺不顺/节奏"（而非选哪种接法），转 `shot-shotflow`；若用户只问单镜内部运动衔接，转 `shot-movement`。

## B — 边界 (Boundary) ★

① **反场景**：作者性跳接/无转场长镜（如戈达尔式）刻意制造断裂感时，不必套"先判时空再选技法"的平滑逻辑；本 skill 服务于连续性剪辑的转场决策。
② **书中警告的失败模式**
- ce10 转场技法错配时空关系：连续时空误用有痕转场（叠化/淡）显得拖沓，或断裂时空误用硬切显得跳跃含混——违反"先判时空再选技法"。
- ce19 叠化滥用当万金油：凡转场都叠化，模糊了时空是否连续的判断，节奏拖沓、手法廉价，失去区分功能。
③ **作者盲点/时代局限**（来自 BOOK_OVERVIEW 批判段）
- 非线性剪辑 + 手机拍摄让匹配转场可后期精准对齐，降低了匹配镜头的执行门槛。
- 作者把 continuity 当唯一正统，对"故意生硬跳接"的网感/喜剧反套路价值估计不足。
④ **易混淆邻近方法论**：与 `shot-shotflow`（流畅度）、`shot-movement`（运动承接替代转场）易混；记住——本 skill 只回答"这两镜/两段之间用哪种接法、时空逻辑对不对"，不回答整体镜流顺滑度，也不回答运动路径。

## 相关 skills

- composes-with: shot-shotflow（转场是镜流的连接技法）、shot-axis-triangle（转场建立在连续空间之上）。
- contrasts-with: shot-movement（转场连接 vs 运动镜承接，二选一）。
