## I — 方法论骨架 (Interpretation)

1. 每做一个镜头/动作/场次决定前，先问一句"这场戏是关于什么"——答案就是最高主旨（端线），它是所有取舍的惟一审判标准。
2. 最高主旨不是角色的心理欲望，而是结构层面的"功能性目标"（主角追求的东西），与性格/心理彻底脱钩。
3. 当场戏同时想表达多个东西（如"父子和解"与"商业失败"），取惟一最高主旨，其余降级为从属动作或从剧本里删掉。
4. 端线不是一成不变：在推演中可被修改（如"获得重视"→"获得撤销"），改完再回看每个动作是否仍服务它。
5. 凡不能直接服务端线的点子（哪怕"可爱"或"有特殊个人意义"），一律砍掉——可爱不等于切题。
6. 操作闭环：问"关于什么"→ 定端线 → 列动作 → 逐个动作问"它服务端线吗"→ 删/改偏离项 → 端线若漂移则回头修正。

## A1 — 应用案例 (Past Application)

- **问题→用法→结论→结果（教室戏端线改写，第2章）**：原主旨"赢得老师重视"推演后改为"获得撤销成绩"。做法＝以端线"获得撤销"统摄四个动作（早到、准备、表示敬意、提出要求），每个动作都对着"撤销"服务。结论＝端线可随推演修改，且一旦明确，所有镜头取舍有了准绳。结果＝圆满结局：老师盖章撤销，学生微笑合上笔记本，马梅自评"还算拍得不错"。
- **问题→用法→结论→结果（猪故事端线，第5章）**：要把"卖猪"讲清楚，端线定为"老皮要甩掉一头危险的猪"。做法＝所有动作（遇修车农夫、擦猪嘴系手帕、去屠宰场）都围绕"甩掉危险猪"取舍。结论＝功能性目标（不是心理欲望）才是结构主轴。结果＝多个结局变体都成立，核心"老皮摆脱了危险"。
- **问题→用法→结论→结果（多表达取舍）**：一场戏想同时说"父子和解"与"商业失败"。做法＝用"这场戏是关于什么"取惟一最高主旨，另一者降级。结论＝用功能性目标而非心理欲望做审判标准。结果＝叙事不再互相拉扯。

## A2 — 触发场景 (Future Trigger)

**用户情境（具体到可识别）**
- 写完一场戏，发现塞了太多"想表达的东西"，不知道保留哪个。
- 导演/剪辑面对一个"很可爱但好像不服务主线"的点子，纠结留不留。
- 剧本评审时想快速判断某场戏是否偏题。
- 一场戏功能对但"不好看/散"，需要回看主旨是否漂移。

**语言信号（用户原话式 trigger，关键句中英双写）**
- "这场戏到底是关于什么的？" — "what is this scene really about?"
- "两个意思我都想保留，怎么选？" — "I want to keep both meanings, how to choose?"
- "这个镜头是不是偏题了？" — "is this shot off the throughline?"
- "用端线筛掉多余内容" — "use the superobjective to cut the extraneous."

**与相邻 skill 的区分（初稿）**
- 与 `dm-montage-narrative`：superobjective 管"取舍审判/定调"，montage 管"概念怎么被镜头制造"；先定主旨再谈并置。
- 与 `dm-reforming`：本 skill 是 reforming 循环的"一端"（最高主旨），reforming 是二者来回观照的循环工序本身。
- 与 `dm-trim-script`：本 skill 用"主旨"作删剪判据，trim-script 用"可拍性"作判据；二者删剪理由不同但互补。
- 与 `dm-macguffin`：容易混——macguffin 让"主角目标"保持模糊，superobjective 让"这场戏关于什么"清晰；一个是目标的模糊度，一个是取舍的清晰度。

## E — 可执行步骤

1. **问关于什么**：对当前场次/镜头，用一句话答"这场戏是关于什么"。完成标准：是一句功能性目标陈述（如"获得撤销"），不是性格描述。判停：若答成"关于一个倔强的老人"这类性格词，回到 dm-character-as-action 重想。
2. **列动作对照端线**：列出该场所有动作，逐个问"它服务端线吗"。完成标准：每个保留动作都能指向端线；偏离项被标出。判停：若多数动作都指不回端线，端线可能定错，进入步骤 3。
3. **删改或修正端线**：砍掉不服务端线的动作/点子；若端线本身在推演中漂移，则改写端线再重跑步骤 2。完成标准：留下来的每个元素都"因端线而在"。判停：若舍不得砍"可爱但偏题"的点子，回到 B 段 ce06 警告。

## B — 边界与防乱调用

**① 不要使用的情况**
- 用户要的是"用镜头并置制造概念"——那是 `dm-montage-narrative`，本 skill 不生产镜头方案。
- 用户要的是"设计模糊的麦高芬目标"——那是 `dm-macguffin`。
- 用户要的是"打磨结构循环工序"——那是 `dm-reforming`，本 skill 只给"定调/取舍"这一环。

**② 书中警告的失败模式（counter-examples）**
- `ce11 反传统文化建筑`：作品从"感觉/个人观点"出发而非功能出发，忽略观众"接下来会发生什么"的本能需求，终将垮掉——对应"不从端线（功能）出发思考"。
- `ce06 可爱/特殊个人意义点子`：因点子"可爱"或个人情怀保留，偏离场的主旨；观众无法共享其意义。
- `ce12 肥皂剧空镜头交代环境`：用空镜头+招牌交代"故事发生在哪里"，把环境当主旨，而非问"这场戏要谈什么"。
- `ce18 跟着主角陷阱`：惯性认为必须拍主角才能推进，偏离了"为端线准备素材"的判断。

**③ 作者盲点 / 时代局限（来自 BOOK_OVERVIEW 批判）**
- **"角色不存在"是选择性引用亚里士多德**：把角色还原为"习惯性行为"，回避人物内在性/心理纵深也能成就杰作；本方法最适配骗局/惊悚类清晰叙事，未必适配抒情、史诗、作者电影。
- **极端反学院派**：把"电影学院/戏剧学校"一概否定，忽略系统训练对灯光、录音、调度的价值。
- **假设观众永远比你聪明**：对通俗片成立，但对信息密度高、世界观陌生的题材，适度 exposition 必要，端线再清晰也需给观众入口。

**④ 易混淆邻近方法论**
- 与斯坦尼"内在渴望"易混：本书端线是结构功能性目标，不是心理欲望，别拿去要求演员"体验内在渴望"。
- 与 `dm-order-not-chaos`（理出秩序）：都讲"理清"，但 order-not-chaos 反对制造有趣障碍，superobjective 反对偏题，侧重点不同。
