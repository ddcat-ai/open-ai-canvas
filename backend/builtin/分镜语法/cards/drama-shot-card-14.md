# 14 字段镜头卡

## 何时用

- 用户要把一句话创意、剧本、小说段落或口播拆成可拍分镜。
- 需要排镜头、控时长、标机位、写群戏站位或检查跨镜连续。
- 已有分镜只有景别和台词，无法直接交给图片/视频模型。

## 每镜固定字段

| 字段 | 写法 |
| --- | --- |
| 镜头 ID | `S01`，按成片顺序唯一编号 |
| 节拍 | 钩子、语境、压力、破裂、加速、撞击、余波 |
| 功能 | 建立、推进、揭示、反应、误导、转折、收束 |
| 情绪 | 观众此刻应感到什么 |
| 景别 | 远、全、中、近、特写，必要时写构图中的人物占比 |
| 构图 | 主体位置、前中后景、留白方向和遮挡关系 |
| 运镜 | 固定、摇、移、跟、推、拉、升降、手持、环绕 |
| 运动理由 | 这次运动让观众多知道了什么；没有理由就改固定 |
| 动作与力学 | 谁对什么施力，支点、方向、反作用与惯性 |
| 状态延续/物理后果 | 上一镜的伤、污渍、裂纹、道具位置和体力如何延续 |
| 时长 | 秒数；动作、台词和运镜都要装得下 |
| 剪辑留白余量 | 收势后留给下一刀的时间 |
| 切型 | 硬切、动作切、匹配切、声音先入、叠化等 |
| 台词/声音 | 原句、停顿、环境声、拟音或静默 |

每镜都要重写角色视觉标记，禁止“同上”。状态字段不是复述剧情，而是记录能被下一镜看见的物理结果。

## 先锁场景 GEO

每场先写四件事，再排镜头：

```text
地标：观众用来认空间的一个固定物
分布：人物、门、窗、家具的相对位置
轴线：谁看谁，摄影机允许在哪一侧
主光：唯一主光源的方向与冷暖
```

三人以上群戏使用八方位绝对坐标，例如“北侧门、西南角 A、桌面东端 B”，不要只写“左边的人”。复杂群戏再附 2D 俯视站位图，并把机位标为 `C1-C6`。

## 节拍与时长

长片段的默认节拍比例：

| 节拍 | 占比 |
| --- | --- |
| 钩子 | 0-5% |
| 语境 | 5-15% |
| 压力 | 15-30% |
| 破裂 | 30-45% |
| 加速 | 45-60% |
| 撞击 | 60-75% |
| 余波 | 75-100% |

15 秒版可直接落成：`0-2s` 钩子、`2-5s` 语境、`5-9s` 压力、`9-12s` 破裂、`12-15s` 撞击与余波。

- 首帧预留 `0.5-1.0s` 让观众认清空间，不能空场。
- 大动作拆成准备、执行、结果三镜；不要把起跳、命中和落地塞进一个镜头。
- 动作收势后默认留约 `1.5s` 气口，除非下一刀必须抢拍。
- 台词按每 10 字约 2 秒估算，再留 `0.5-1.0s` 呼吸；单镜通常不超过 10 秒。

## 输出顺序

1. 一句话场景目标。
2. GEO 与人物方位。
3. 节拍时间轴。
4. 14 字段分镜表。
5. 连续性风险清单：最容易穿帮的伤、道具、方向和光源。

## 验收

- 遮住台词后，仍能按画面读懂因果和情绪变化。
- 每个运动镜头都有叙事理由。
- 每个物理后果都能在下一镜找到落点。
- 群戏中每个“谁在哪里”都能被机位复现。
- 所有镜头时长之和与目标总时长一致。
