## I — 方法论骨架 (Interpretation)

1. 开场不要铺垫世界观、身世或环境，直接把"问题被发现的那个时刻"抛给观众——观众比你聪明，你握有王牌。
2. 收尾不要在把前提说清之后才离开；在问题刚被说清之前就早退场，把未决的问题甩给下一场去承接。
3. 故事必须锚定在一个具体的、可被镜头拍出来的外在事件上（瘟疫、大耳朵、某人之死），而不是主角"突然有个想法"或一段内心独白。
4. 开场锚点回答的是"为什么是现在（why now）"——是某个问题被撞见的事件，不是对背景的说明。
5. 这套节奏法的根基是"尊重观众"：你保留讯息而非塞满讯息，观众会自动替你补齐因果，悬念由此而来。
6. 注意"不要重复"：每一段都应推进新动作，开场与收尾不要用爬过的阶梯再爬一遍式的回环拖慢节奏。

## A1 — 应用案例 (Past Application)

- **问题→用法→结论→结果（俄狄浦斯 / 小飞象开场，第5章）**：要开场却怕"没建立背景观众不懂"。做法＝直接以具体外在事件切入——底比斯的瘟疫、小飞象一生下来就有大耳朵、凯恩之死，而非主角内心想法。结论＝"故事的开始决不是因为主角突然间有个想法"，外在事件才能成为你领导观众的筹码。结果＝马梅赞《小飞象》为"完美的电影"，并称"如此你才能有筹码领导观众，他们也才会想要知道接下来会发生什么"。
- **问题→用法→结论→结果（卖猪农夫故事开场，第5章）**：如何开"老皮甩掉危险猪"这场戏。做法＝以猪攻击小孩、妈妈拿扫把冲出这一具体外在事件开场，删掉"吉猪出售"之类的背景说明镜头。结论＝从事件切入而非从背景说明切入，观众被拉进"接下来会发生什么"的悬念。结果＝作为全书核心演练的正面范例，观众被钩住想知道老皮怎么甩掉猪。
- **问题→用法→结论→结果（小飞象自我发现结局，第5章）**：主角达成目标时故事要不要再交代一笔。做法＝大耳朵的困扰不是靠手术割除，而是主角自我发现解除，故事在此干净收住，不拖尾巴。结论＝目标达成（平稳状态）即结束，呼应"早退场"把多余说明让位给观众。结果＝被当作"完美的电影"范例，故事在自我发现处利落结束。

## A2 — 触发场景 (Future Trigger)

**用户情境（具体到可识别）**
- 剧本开头写了两三页背景铺垫，自己都觉得沉闷、观众容易走神。
- 一场戏结尾把前因后果全说清了才切走，总觉得"收得不够利落"。
- 科幻/奇幻题材信息密集，纠结"不说明世界观观众怎么懂"。
- 用户在问"为什么大师片开场都很突然、没什么交代"。

**语言信号（用户原话式 trigger，关键句中英双写）**
- "开场怎么不啰嗦、直接进故事？" — "how to open late, cut the preamble?"
- "早退场是什么意思 / 结尾要不要把话说清？" — "what is early exit / should I spell it out before leaving?"
- "故事该用什么事件开场，而不是内心想法？" — "open with an external event, not an inner thought."
- "why now / 为什么是现在发生？" — "why now, not earlier?"

**与相邻 skill 的区分（初稿）**
- 与 `dm-montage-narrative`：本 skill 管"开场与收尾的节奏时点"，montage 管"镜头并置怎么生概念"；一个是结构的进出闸门，一个是内容的制造机制，不在同一层。
- 与 `dm-syllogism-structure`：syllogism 管"某场戏提出的问题解决时该场即结束"的结束判据；本 skill 的"早退场"是把问题移交下一场、在说清前离开。若用户问"这场戏该不该结束"→syllogism；若问"结尾要不要把话说清/早离开"→本 skill。
- 与 `dm-superobjective`：superobjective 管"这场戏是关于什么"的取舍审判；本 skill 不替代主旨判断，只在已定主旨后处理进出场节奏。
- 与 `dm-audience-meaning`：audience-meaning 是"观众意义化天性、保留信息"的理念根基；本 skill 是把这一理念落成"晚开场早退场"的具体手法。
- 与 `dm-order-not-chaos`：order-not-chaos 管"理出秩序而非制造有趣障碍"；本 skill 管节奏进出，角度不同但都反对人为添乱。

## E — 可执行步骤

1. **查开场锚点**：看你的开头是否落在"一个具体外在事件"（可被镜头拍出）而非背景说明/内心想法。完成标准：能用一句话写出"这一刻发生了什么具体的事"，且它是问题被发现的时刻（why now）。判停：若开头在交代"主角是什么样的人/世界是怎样的"，回到步骤1 改写为事件切入；若需要解释世界观才能懂，宁可保留悬念交给下一场，不在此处塞说明。
2. **查收尾切点**：看这场戏是否在"问题刚被说清之前"就离开，把未决项留给下一场。完成标准：切走时观众脑子里还挂着一个"接下来呢"的问号，而非所有因果已闭合。判停：若结尾把前因后果全讲透才切，删掉最后那段说明，提前离开；若问题本场已彻底解决（平稳状态），则应交给 dm-syllogism-structure 判定该场结束而非硬拖。
3. **排重与提速**：通读开场到第一转折，确认没有"爬过的阶梯再爬一遍"式的重复。完成标准：每一段都推进了新动作或新信息。判停：若有回环式铺陈，删掉重复段，让节奏更晚进、更早出。

## B — 边界与防乱调用

**① 不要使用的情况**
- 用户要的是"两个镜头怎么并置产生一个概念"——那应触发 `dm-montage-narrative`。
- 用户问"这一场戏到底该不该结束、问题解决了没有"——那应触发 `dm-syllogism-structure`。
- 用户问"这场戏的主旨是什么、该保留哪条动作线"——那应触发 `dm-superobjective`。
- 用户要现场给演员走位说戏——那应触发 `dm-actor-blocking`。

**② 书中警告的失败模式（counter-examples）**
- `ce12 电视肥皂剧式空镜头交代环境`：开场空镜头→摇摄→招牌（"艾文综合医院"），把"故事发生在哪里"当主旨；重点应是"要谈的是什么"而非地点。
- `p19/p28 用说明/背景开场`：以"太太，是不是那头我们养不起的猪又在偷吃杂粮"式说明开场，而非"发现问题的事件"开场，观众不被拉入悬念。
- `p20 用说明而非参与`：学习导演第一步是"不用说明来开场，而是想办法让观众参与"；靠说明开场会瞬间把观众推到旁观位。
- `p23 重复`：开场与推进中回环铺陈（爬过的阶梯再爬一遍）会拖慢节奏，违反"晚进早出"的紧凑。

**③ 作者盲点 / 时代局限（来自 BOOK_OVERVIEW 批判）**
- **假设"观众永远比你聪明、绝不需要说明"**：对通俗商业片成立，但对信息密度高、世界观陌生的题材（如硬科幻、架空奇幻），适度 exposition 是必要的；机械坚持"晚开场"可能让人完全看不懂。
- **时代局限**：全书针对的是当时片厂体系"一群人在说话的电影"；此后复杂剧集、作者化作品兴起，其"反铺陈"锋芒指向特定工业烂片，而非电影的全部可能。
- **最强反对意见**：大量公认大师作品（楚浮、帕索里尼、森田芳光、阿莫多瓦）公然违反"清晰主旨/无背景说明"法则却仍是杰作——证明"晚开场极简"是有效的一家之法，不是普适真理，对需要氛围与暧昧的影片可能适得其反。

**④ 易混淆邻近方法论**
- 常与"悬念/希区柯克式延宕"混：本 skill 的"早退场"建立在"你握有王牌、观众比你聪明"前提上，是尊重而非吊胃口；与单纯的悬念制造技巧不同。
- 与 `dm-syllogism-structure`（三段论结束判据）易混：二者都涉及"何时结束"，但 syllogism 是结构性"问题解决即结束"，本 skill 是节奏性"说清前早离开、问题移交下一场"。
- 与 `dm-macguffin`（模糊目标）易混：二者都"保留信息交给观众"，但 macguffin 是主角追逐对象的模糊化，本 skill 是进出场的节奏法则。
