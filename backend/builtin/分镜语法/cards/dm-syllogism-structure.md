## I — 方法论骨架 (Interpretation)

1. 戏剧结构 = 推论式三段论：开场是"未决事件的状态 A"（一个问题被抛出），收尾是"事件解决、达平稳状态 B"——即 If A, then B。
2. "场"是导演最该重视的单位：某场戏抛出的问题被解决时，该场即结束；一场戏=小规模电影。
3. 判断"讲完了没"的客观判据：问题(A)是否达平稳(B)。没解决=该场/段未完，应延续或留待下一场，不能硬收。
4. 一场戏拖很久还不结束，通常是因为它抛出的未决问题没被解决——回去找 A 是什么、B 该是什么。
5. 操作闭环：标出本场的未决问题(A) → 设计它达平稳(B)的节点 → 在 B 处收尾 → 若 B 没到就别收；若 A 本身不清，回到上游定戏。

## A1 — 应用案例 (Past Application)

- **问题→用法→结论→结果（《小飞象》自我发现结局，第5章）**：小飞象的未决问题是"大耳朵带来的困扰"，平稳状态是"他领悟到自己不比别人差"（自我发现解除，非手术）。做法＝让主角达成目标（自我发现）时故事即结束。结论＝"故事就在这里结束"——问题解决即收尾，给了客观结束判据。结果＝作为"完美的电影"范例，干净结束。
- **问题→用法→结论→结果（猪故事目标达成，第5章）**：老皮的未决问题是"甩掉一头危险的猪"，平稳状态是"老皮摆脱了危险"（未必甩掉猪，猪救主人亦算解决）。做法＝以具体外在事件开场、以问题解除收尾。结论＝"任何人只要有心，都可以拍一部像这部'猪'电影的影片"。结果＝多个结局变体都成立，核心皆"危险解除"。
- **问题→用法→结论→结果（一集两悬念未解，衍生自三段论）**：若一集两个悬念都没解开，按"If A then B"它无法干净结尾。做法＝要么解决当前未决事件再收，要么把未解悬念明确移交下一场（早退场）。结论＝未决事件(A)须达平稳(B)才结束。结果＝给出客观收尾时点，避免烂尾。

## A2 — 触发场景 (Future Trigger)

**用户情境（具体到可识别）**
- 一场戏拍完觉得"散/没完没了"，不确定该不该收。
- 一集剧两个悬念都没解开，编剧纠结能不能结尾。
- 评审时想快速判断"这场戏是不是一场完整的戏"。
- 导演不知道"问题抛出了，但平稳状态在哪"。

**语言信号（用户原话式 trigger，关键句中英双写）**
- "一集两个悬念都没解开，能结尾吗？" — "can I end if two threads are unresolved?"
- "这场戏讲完了没 / 该收尾了吗？" — "is this scene done / where to end?"
- "场结束怎么判定？" — "how to judge a scene is over?"
- "问题没解决这场算完吗？" — "can a scene end if the problem isn't solved?"

**与相邻 skill 的区分（初稿）**
- 与 `dm-late-open`：本 skill 管"收尾判据（问题解决即结束）"，late-open 管"开场怎么直接进问题"；二者是三段论的两头（B 与 A）。
- 与 `dm-suspense-necessity`：本 skill 管"结构完整（A→B）"，suspense-necessity 管"转折质量（惊奇+必然性）"；结构对了不代表转折好。
- 与 `dm-superobjective`：本 skill 管"场何时结束"，superobjective 管"这场关于什么"；端线达成常等于问题(A)解决。
- 与 `dm-reforming`：本 skill 给收尾判据，reforming 是打磨循环，可借判据检验循环是否到位。

## E — 可执行步骤

1. **标未决事件 A**：写出本场开场抛出的那个未决问题（如"老皮要甩掉危险猪"）。完成标准：是一句可识别的"问题/目标"，不是模糊氛围。判停：若写不出 A，回到 dm-superobjective 定端线。
2. **定平稳 B**：写出 A 达平稳的状态节点（问题解除/目标达成）。完成标准：B 是具体可拍的"解决瞬间"。判停：若 B 不清，说明戏没想清楚，先改戏再谈收尾。
3. **在 B 收尾或移交**：B 到达即收尾；若 B 没到，延续本场或把未解悬念明确移交下一场（早退场）。完成标准：成片在 B 处让观众感到"这事了了"，无悬空。判停：若硬收在 A 未解处，回到步骤 1 重确认 A 是否已变。

## B — 边界与防乱调用

**① 不要使用的情况**
- 用户要的是"开场怎么直接进问题"——那是 `dm-late-open`（晚开场/早退场）。
- 用户要的是"转折是否既意外又必然"——那是 `dm-suspense-necessity`。
- 用户要的是"整场取舍定调"——那是 `dm-superobjective`。

**② 书中警告的失败模式（counter-examples）**
- 本书 verified.md 中本 skill 的 related 仅含原则 p16，无专属 ce id；以下引用相邻结构性陷阱：
- `ce11 反传统文化建筑`：作品不从功能/观众"接下来发生什么"的需求出发，结构失焦终将垮掉——对应"不先定 A/B 就写"。
- `ce17 每个镜头求有趣`：不靠清晰结构（A→B）拴人，转而每个镜头花样翻新，导致整体无收尾逻辑。
- `ce12 肥皂剧空镜头交代环境`：把环境当主旨，忽略"这场戏要谈什么（即 A 是什么）"，未决事件不清则无 B 可收。

**③ 作者盲点 / 时代局限（来自 BOOK_OVERVIEW 批判）**
- **假设"观众永远比你聪明、绝不需要说明"**：对信息密度高、世界观陌生题材，A（未决事件）本身需要适度 exposition 才能被观众识别，否则观众不知"问题是什么"自然也无 B 可盼。
- **"导演职务是理出秩序"假设**：马梅也承认"惊奇+必然性"是好戏剧要素，完全不制造障碍可能牺牲张力，纯 A→B 直给可能平淡。
- **未被证明的普适性**：大量公认大师作品（楚浮、帕索里尼、阿莫多瓦）公然违反"清晰 A→B"却仍是杰作，证明本判据是有效一家之法而非普适真理。

**④ 易混淆邻近方法论**
- 与 `dm-late-open` 易混：都讲"开场/收尾"，但本 skill 给"收尾的客观判据"，late-open 给"开场即进问题+早离开"的节奏法则。
- 与 `dm-suspense-necessity` 易混：结构完整≠转折精彩，别用本 skill 替代审美判据。
