## I — 方法论骨架 (Interpretation)

1. 把"能不能被拍成镜头"当成内容重要性的硬判据：凡需要靠叙述文句才能成立、无法转成画面的东西，对观众而言就不重要，直接删。
2. 剧本的价值不体现在"写了多少"，而体现在"能删掉多少"——好编剧的功力是海明威式地删到只剩目标演进的必要事件。
3. 叙述文句（"一个三十来岁、浑身洋溢不凡气度的人"）拍不出来也占篇幅，是应被赶出剧本的累赘，不是"丰富"。
4. 当某个动作概念难拍时，退而用文字/对白说明会立刻让节奏软弱——正确的路是把它拆成可并置的镜头，而非用叙述兜底。
5. 编剧的任务是"说这个故事、给观众惊奇"，不是"解释为什么"；解释性句子一律是删剪对象。
6. 删剪与并置互补：删掉叙述之后，空出来的位置由镜头并置去承担叙事责任（见 dm-montage-narrative）。

## A1 — 应用案例 (Past Application)

- **问题→用法→结论→结果（街角说故事分镜，第1章）**：一段日常叙述——"雾很多、可能是月圆、一辆车驶来"——怎么变可拍。做法＝把叙述拆成并置镜头：（1）人站街角（2）多雾的夜（3）圆月在天空（4）有人说"每年这时大伙都阴阳怪气"（5）一辆逐渐驶近的车。结论＝叙述天然可电影化，只要转成影像并置、靠剪接推衍。结果＝马梅称其为"好的拍摄手法，导演只需将一些影像并置，借此导观众进入故事"。
- **问题→用法→结论→结果（教室"撤销成绩"戏，第2章）**：如何让学生戏完成叙事却不靠学生脸/性格说明。做法＝把端线从"获得重视"改为"获得撤销"，用"早到、准备、表示敬意、提出要求"四个中性动作镜头并置，删掉一切"性情急躁的消息灵通人士"式人物描写。结论＝不用学生脸的镜头也能完成叙事，性格说明纯属多余。结果＝马梅自评"还算拍得不错"，全程靠镜头而非叙述推进。
- **问题→用法→结论→结果（卖猪农夫故事，第5章）**：如何开场且不堆背景。做法＝以"猪攻击小孩、妈妈拿扫把冲出"这一具体外在事件开场，删掉"吉猪出售"之类的背景说明镜头。结论＝从事件切入而非从背景说明切入，删掉叙述反而把观众拉进悬念。结果＝作为全书核心演练范例，观众被钩住想知道老皮怎么甩掉猪。

## A2 — 触发场景 (Future Trigger)

**用户情境（具体到可识别）**
- 剧本里一段漂亮的人物小传/环境描写，不确定该不该删。
- 用户问"这段说明性格/动机的文字，保留还是删"。
- 一场戏靠旁白或字幕才讲清，想改成用画面。
- 用户说"剧本太满、节奏拖，怎么精简"。

**语言信号（用户原话式 trigger，关键句中英双写）**
- "剧本写满了叙述文句，怎么精简？" — "the script is full of prose, how to trim it?"
- "这段不可拍的内容要不要留？" — "should I keep this unshootable part?"
- "怎么把说明改写成镜头？" — "how to rewrite exposition into shots?"
- "不可拍 = 不重要？" — "if it can't be shot, it's not important?"

**与相邻 skill 的区分（初稿）**
- 与 `dm-montage-narrative`：本 skill 是"如何删（叙述）"，montage 是"如何加（并置）"，二者互补——删掉叙述后由并置填空。
- 与 `dm-realist-dialogue`：realist-dialogue 管"对白惟一功能是暴露欲望、别用对白说明"；本 skill 管"剧本里的叙述文句/描写怎么删"。若用户问对白功能→realist-dialogue；若问"一大段描写怎么删"→本 skill。
- 与 `dm-character-as-action`：character-as-action 管"用行为总和替代性格设定、反背景故事"；本 skill 与其联动（背景故事正是要删的叙述），但本 skill 范围更宽——凡不可拍的叙述都删，不止性格。
- 与 `dm-macguffin`：macguffin 管"主角目标保持模糊交给观众"；本 skill 也删解释，但角度是从"可拍性"出发，而非从"目标模糊"出发。
- 与 `dm-superobjective`：superobjective 提供"用主旨筛删"的审判标准；本 skill 提供"用可拍性筛删"的操作判据，二者可叠加使用。

## E — 可执行步骤

1. **扫不可拍句**：逐句扫剧本，标出所有"不用叙述文句就拍不出来"的内容（人物小传、环境描写、"因为我是……"式动机说明）。完成标准：列出待删清单，每项能对应一句原文。判停：若某内容看似叙述但可转成镜头（如"他很紧张"→"手抖/冒汗"的镜头），不删，转交 dm-montage-narrative 处理；只有纯叙述且无法转镜者才进步骤2。
2. **删并改写**：把标出的纯叙述整段删掉；若它承载了一个必要动作概念，改写成"可被并置的镜头"而非用文字兜底。完成标准：删完后 tester 读剧本仍能跟住"目标演进"，且没有任何"一个……的人，浑身洋溢着……"式句子残留。判停：若删后节奏反而变软（出现用文字叙述解决"准备"等概念的情况），回到步骤2 用镜头替代而非加回叙述。
3. **验可删比例**：评估"能删掉多少"作为功力指标，确认留下的全是事件演进的必要节点。完成标准：每一留存段落都能回答"这场戏是关于什么"（可交 dm-superobjective 复核）。判停：若留下大量"解释为什么"的句子，回到步骤1 继续删；若已无可删仍觉得满，检查是否混入了该用镜头而非文字表达的内容。

## B — 边界与防乱调用

**① 不要使用的情况**
- 用户问的是"对白应该怎么写、对白只暴露欲望"——那应触发 `dm-realist-dialogue`。
- 用户问"两个镜头怎么并置生概念"——那应触发 `dm-montage-narrative`。
- 用户问"主角目标保持模糊以增进认同"——那应触发 `dm-macguffin`。
- 用户要的是现场给演员走位说戏——那应触发 `dm-actor-blocking`。

**② 书中警告的失败模式（counter-examples）**
- `ce14 冗长叙述开场（"尼克三十来岁"无法拍）`：剧本写满"尼克，一个三十来岁的人，浑身洋溢着不凡的气度"这类句子，既拍不出又占篇幅；拍不出来的叙述即可删。
- `ce20 用文字叙述解决"准备"概念（节奏软弱）`：当"准备"这类动作难拍时，退而用文字/对白说明，影片节奏立刻软弱；正确做法是用镜头并置替代，而非叙述兜底。
- `ce09 事后补插对白（ADR 补戏）`：拍完才发现信息缺失，靠后期配音硬补（"我们现在要下楼梯了"），观众根本不在乎；暴露前期规划不足，本该在剧本阶段删清或改成镜头。
- `p04 编剧解释剧情`：编剧去"解释为什么"而非"说这个故事"；解释性句子是删剪对象，观众要的是戏剧不是资料。

**③ 作者盲点 / 时代局限（来自 BOOK_OVERVIEW 批判）**
- **"好编剧功力=能删掉多少"是选择性标准**：虽承海明威，但把"不可拍=不重要"极致化，会误伤那些本就靠语言/内心独白成立的作品（如文学改编、作者电影）；并非所有内容都该服从可拍性判据。
- **时代局限**：马梅针对的是好莱坞"一群人在说话的电影"与填充式说明；对需要心理纵深、氛围铺陈、世界观建构的影片，过度删剪会掏空作品。
- **最强反对意见**：楚浮、帕索里尼、森田芳光、阿莫多瓦等大师作品充满"这场戏是关于什么"的含糊、靠叙述与暧昧成立却仍是杰作——证明"极简删剪"是有效的一家之法，不是普适真理。

**④ 易混淆邻近方法论**
- 常与"一般性的精简/润色"混：本 skill 的判据是"可拍性"（不可拍即不重要），不是泛泛的"写短一点"；删的是叙述责任而非修辞。
- 与 `dm-realist-dialogue`（现实主义对白）易混：二者都"反解释"，但 realist-dialogue 聚焦对白功能，本 skill 聚焦剧本叙述文句与描写。
- 与 `dm-character-as-action`（角色即动作）易混：二者都反对性格设定/背景故事，但 character-as-action 是从"角色观"出发重构人物，本 skill 是从"可拍性"出发删内容。
