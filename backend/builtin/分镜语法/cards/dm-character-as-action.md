## I — 方法论骨架 (Interpretation)

1. "角色"在马梅体系里不是本体，只是"一个人在追求目标时采取的习惯性动作/行为的总和"——亚里士多德早说过角色不存在。
2. 观众认同的是"人物对目标的追求"，不是性格设定；你设定"她是个控制狂"，观众无感，你让她反复打断别人说话，观众就懂了。
3. 把"性格形容词"翻译成"可拍的行为序列"：控制狂→反复打断、替人做决定；沉溺美好生活→镜头里只拍他抚摸物件。行为并置即人物。
4. 背景故事（back story）是累赘：主角不需要向观众/任何人解释"为什么"，如"男子夸衣服漂亮"不必交代"我六周没和女人上床"。
5. 操作闭环：写下一个性格词 → 问"它对应什么可拍的行为" → 把该行为序列写进动作/镜头 → 删掉形容词和背景故事 → 让观众从行为中自己认出人物。

## A1 — 应用案例 (Past Application)

- **问题→用法→结论→结果（童话结构教材，第5章）**：童话用最简意象、无性格说明，"若有人物性格特色通常是由观众自由完成"。做法＝不赋予角色性格特色，把性格交给观众。结论＝"只要将这样单纯的原则用到电影或舞台剧上，导演自然可以驾轻就熟"。结果＝童话"开始与结局都非常容易识别"，观众自行补全人物。
- **问题→用法→结论→结果（猪故事，第5章）**：老皮没有"性格设定"，只有一串功能性动作（遇修车农夫、擦猪嘴系手帕、去屠宰场）。做法＝用动作推进而非说明"老皮是个怎样的人"。结论＝角色=追求目标时的习惯性行为集合。结果＝多个结局变体都成立，核心"老皮摆脱了危险"由动作定义而非性格。
- **问题→用法→结论→结果（教室戏反性格说明，第2章）**：学生"想赢得老师重视"，马梅不写"这是个渴望认可的学生"，而是用四个动作（早到、准备、表示敬意、提出要求）并置。做法＝把"渴望认可"译成可拍动作。结论＝观众认同对目标的追求而非性格。结果＝老师盖章撤销，无需一句性格说明。

## A2 — 触发场景 (Future Trigger)

**用户情境（具体到可识别）**
- 剧本人物小传写满"微瘦、结实、沉溺美好生活"类形容词，作者想让人物"立住"却只会堆词。
- 新人编剧写"她是个控制狂"，不知道怎么改成可拍的。
- 想给主角补一场童年闪回/前史解释动机。
- 评审时想判断某人物塑造是否落了"说明性格"的俗套。

**语言信号（用户原话式 trigger，关键句中英双写）**
- "这个角色是个控制狂，怎么改成可拍的？" — "how to make 'she's a control freak' filmable?"
- "别写背景故事 / 不需要前史" — "drop the back story / no need for backstory."
- "用行为代替性格设定" — "show character through action, not traits."
- "观众认同的是对目标的追求" — "audiences identify with the pursuit of the goal."

**与相邻 skill 的区分（初稿）**
- 与 `dm-realist-dialogue`：本 skill 从"行为/动作"替代性格，realist-dialogue 从"对白功能"切入；都反"说明"，但层不同（动作 vs 台词）。
- 与 `dm-superobjective`：本 skill 管"人物怎么被构建"，superobjective 管"这场戏关于什么"；人物行为应服务端线。
- 与 `dm-macguffin`：本 skill 拆掉角色本体，macguffin 拆掉目标清晰度；二者都"去确定性"，但对象不同（角色 vs 目标）。
- 与 `dm-montage-narrative`：本 skill 产出的"行为序列"常作为 montage 的并置素材。

## E — 可执行步骤

1. **抓性格词**：列出剧本里所有"性格形容词/人物小传描述"。完成标准：全部列出并标注。判停：若列不出，说明人物可能已靠行为成立，无需本 skill。
2. **译行为序列**：每个性格词→写 2-3 个可拍的动作（控制狂→打断别人、替人做决定）。完成标准：每个词都有对应动作，且动作能在镜头里成立。判停：若某性格词译不出动作，说明它是空标签，直接删。
3. **删形容词与背景**：删掉原性格描述和背景故事段落，只留行为序列+目标追求。完成标准：通读后人物靠行为被认出，无"说明性格"句。判停：若删完人物空白，回到 dm-superobjective 确认端线是否清晰（行为须服务端线）。

## B — 边界与防乱调用

**① 不要使用的情况**
- 用户要的是"写对白/改台词"——那是 `dm-realist-dialogue`。
- 用户要的是"整场取舍定调"——那是 `dm-superobjective`。
- 用户要的是"让主角目标模糊"——那是 `dm-macguffin`。

**② 书中警告的失败模式（counter-examples）**
- `ce03 设定角色性格/背景故事`：用大段字眼说明性格/环境（"一个年轻人，微瘦，结实……"），观众被当需背景灌输的对象，故事停滞；说明性格阻断观众与主角同处境的代入。
- `ce12 肥皂剧空镜头交代环境`：空镜头+摇摄+招牌交代"故事发生在哪里"，把环境当主旨——与"用行为带出人物"相反。
- `ce16 用"因为我是…"说明动机`：对白解释行为动机，冗余；动机应交由动作暗示。

**③ 作者盲点 / 时代局限（来自 BOOK_OVERVIEW 批判）**
- **"角色不存在"是选择性引用亚里士多德**：把角色还原为"习惯性行为"，却回避人物内在性、心理纵深同样能成就杰作；其方法最适配骗局/惊悚类，未必适配抒情、史诗、作者电影（如心理剧、慢电影）。
- **贬低表演与人物深度**：机械套用易产出扁平、疏离的人物；鲍嘉"简单"是被长期训练打磨出的，非无训练结果。
- **假设观众永远比你聪明**：对信息密度高、世界观陌生题材，适度人物前史/动机 exposition 必要，全删背景可能让观众无锚点。

**④ 易混淆邻近方法论**
- 与 `dm-realist-dialogue` 易混：都反"说明"，但本 skill 攻性格设定（动作层），realist-dialogue 攻对白（台词层）。
- 与 `dm-macguffin` 易混：都"去确定性"，但一个是角色本体，一个是目标清晰度。
