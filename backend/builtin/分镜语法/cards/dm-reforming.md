## I — 方法论骨架 (Interpretation)

1. 改造（reforming）不是"修改/润色"的同义词，而是特指"最高主旨 ↔ 动作"这一对关系之间的来回张力开发。
2. 起点是已有一个最高主旨（端线）和一组动作；改造的活儿是让动作越来越贴合主旨，且主旨随动作反馈被 refine。
3. 循环方向：先看动作是否服务主旨 → 不服务就改动作（或回头修主旨）→ 再看新动作是否引出新的主旨层面 → 再修主旨。
4. "功能对但不好看"时，别一次性重写，进入循环：每次只动一个变量（动作或主旨），观察其对另一端的影响。
5. 允许"基督要素"——阶段完成后仍要回头修润，不要假设初稿即终稿。
6. 判停的唯一标准：每个动作都能回答"它服务主旨的哪一点"，且主旨本身被动作反向打磨得更锋利。

## A1 — 应用案例 (Past Application)

- **教室戏"撤销成绩"（第2章，案例 c01）**：问题——初设端线为"获得重视"，戏功能成立但发散。怎么做——进入改造循环，把端线改为"获得撤销成绩"，四个动作（早到/准备/致意/提出要求）随之被观照修正，撕纸标签等动作都被主旨筛过。结论——端线可随推演修改，动作与主旨互锁。结果——结构收敛为"还算拍得不错"的圆满结局。
- **猪故事结构打磨（第5章，案例 c02/c12）**：问题——"老皮要甩掉危险猪"初稿干。怎么做——在端线与动作间反复观照，加入"遇修车农夫/擦猪嘴系手帕/屠宰场关门"等动作，并开发"猪救主人"转折。结论——循环开发出动作与主旨的互动张力。结果——生出多个结局变体，学生边听边笑。

## A2 — 触发场景 (Future Trigger)

① **用户情境（可识别）**
- 初剪/初稿发现某场"功能对但不好看"，不知道下一步怎么改。
- 一组动作写了但和这场戏要说的东西对不上，互相打架。
- 端线定了，但执行时动作不断跑偏、需要反复拉回。
- 改了一版结构，发现又引出新的主旨层面，需要再统合。
- 团队争论"这版到底定没定稿"，缺乏循环打磨的工序感。

② **语言信号（用户原话式 trigger，中英双写）**
- "这版功能对但不好看，怎么改？ / it works but feels dry, how to fix?"
- "动作不贴合这场戏的主旨 / the beats don't serve the throughline"
- "进入改造循环 / run the reforming loop"
- "结构要反复打磨吗？ / should I keep restructuring?"
- "端线和动作对不上 / superobjective and action mismatch"

③ **与相邻 skill 的区分（依据本组+兄弟 skill 标题）**
- 不同于 **dm-superobjective（最高主旨/端线检验）**：superobjective 管"这场戏关于什么"这一单一判定；reforming 管"主旨与动作来回磨"的循环过程。先有主旨（superobjective），才有可循环的 reforming。
- 不同于 **dm-trim-script（剧本极简删剪）**：trim 管"删掉不可拍的叙述"；reforming 管"保留下来的动作如何与主旨互锁"，一删一磨。
- 不同于 **dm-kiss-shot（K.I.S.S 镜头选择）**：K.I.S.S 管单镜头选最直截的；reforming 管整场动作序列与主旨的关系。

## E — 可执行步骤

**步骤 1：锁定当前端线与动作清单**
- 操作：写下本场最高主旨（一句话）和现有动作列表，逐条标注"它服务主旨的哪一点"。
- 完成标准：每个动作都能映射到主旨某一点；映射不上的标记出来。
- 判停条件：若连主旨都无法一句话写下，先转 dm-superobjective，不要进循环。

**步骤 2：单变量往返观照**
- 操作：每次只改一个变量——要么改一个动作使其更贴主旨，要么回头 refine 主旨。改完重看另一端是否被拖累。
- 完成标准：一轮后动作↔主旨契合度提升，无互相打架项。
- 判停条件：若改动作导致主旨需要大改，停下——可能初始主旨选错，回 dm-superobjective 重定。

**步骤 3：基督要素回头修润 + 判停**
- 操作：阶段完成后主动回头修润一遍；用"每个动作能否回答服务主旨哪点"做终检。
- 完成标准：全动作通过终检，主旨本身也被动作打磨得更锋利。
- 判停条件：若仍有一动作答不上来，继续循环；若全部通过则停，定稿。

## B — 边界与防乱调用

① **不要使用的情况**
- 连最高主旨都未定的阶段——reforming 的前提是已有端线，空转无益。
-   当成"随便改改"的借口无限循环——它是有判停条件的工序，不是拖延。

② **书中警告的失败模式（ce06 / 关联）**
- 把"可爱/有特殊个人意义"的点子塞进影片：在 reforming 中若放任个人情怀点子进入，会偏离主旨。凡点子与主旨关联说不清，弃之。
- 单镜头承载太多（ce19）：改造时贪心让一个动作"一次说尽"，剪接力道反而弱——保持单动作单概念。

③ **作者盲点 / 时代局限（来自 BOOK_OVERVIEW 批判）**
- **假设镜头必须毫不相关**：reforming 在此假设上运转，连续性/长镜头影片的"动作↔主旨"打磨逻辑不同。
- **反学院派**：否定系统训练价值，但 reforming 作为工序本身需要纪律，非天才直觉。
- **"角色不存在"选择性引亚里士多德**：reforming 只磨行为动作，对需心理纵深的作者电影不一定够。

④ **易混淆邻近方法论**
- dm-superobjective：常有人把"定主旨"误当"改造"——定是一次动作，改造是循环。
- dm-trim-script：删与磨常被混为一谈。
