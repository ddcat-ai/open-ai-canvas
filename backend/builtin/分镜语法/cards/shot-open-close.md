## I — 方法论骨架 (Interpretation)

作者把"画框松紧"从美术感觉提升为"观众关系"的操控工具：

1. **开放=延续**：让主体或动作溢出画外、构图似随意截取，观众感觉"世界比画框大"，产生写实窥视与高参与感（如纪实访谈想显"真实偷窥"而非摆拍，用开放）。
2. **封闭=锁死**：把主体用门框/窗框/中轴对称框死、信息在画内自足，观众被锁在画面里，呈舞台化、低参与、高审美距离。
3. **它挂钩参与度/美学距离**：开放拉近（参与），封闭推远（旁观）；常与机位高低（第14章）、视点档位（第16章）配合——如《毕业生》用中轴对称封闭+受限第三人称量化传达"被围困/疏离"（c03）。
4. **成对对比决策**：同一场景可画开放版与封闭版对照，按导演意图二选一，而非凭感觉（c18）。
5. **错配即失败**：该给世界延续的写实戏误用封闭（人物被框死别扭），或该自足的舞台戏误用开放（主体频繁出画却无意为之），意图落空。

核心是"开放=让世界溢出去（参与），封闭=把世界锁进框（旁观）"。

## A1 — 书中的应用 (Past Application)

- **《毕业生》对称封闭与疏离（c03）**：问题——如何用构图传达主角"被围困/旁观"心理？方法论使用——反复中轴对称、人物被门框窗框框死的封闭构图，配合受限第三人称视点保持距离。结论——构图是可量化的心理调控工具。结果——封闭构图量化传达窒息与疏离。
- **开放 vs 封闭对比（c18）**：问题——同一场景两种画框策略怎么取舍？方法论使用——并列两幅分镜：一幅人物溢出画框（开放），一幅人物被框死居中（封闭）。结论——按导演意图二选一。结果——直观对照帮助导演按意图选择而非凭感觉。

## A2 — 触发场景 (Future Trigger) ★

① **用户情境（3–5 条）**
- 用户纠结"这个镜头该框松还是框紧、要不要把人框死"。
- 用户想拍出"真实偷窥/纪实"感，而非舞台摆拍。
- 用户做场景想制造"被围困/疏离/旁观"的心理距离。
- 用户分镜里主体频繁出画，不确定是有意开放还是失误。

② **语言信号（用户原话式措辞，中英双写）**
- "怎么拍出偷窥/写实感，别太摆拍 / 这个镜头框松一点还是紧一点"
- "要不要把人框死，显得舞台化 / should I frame this closed"
- "人物总出画是有意还是错了 / open composition vs closed"

③ **与相邻 skill 区分（定稿）**
- 与 `shot-viewpoint`：开闭构图常与视点配合（c03），但本 skill 管"画框策略/参与度"，`shot-viewpoint` 管"认同谁"。
- 与 `shot-dialog-blocking`：对话戏的过肩/主镜也有画框属性，但站位几何归彼，画框松紧归本 skill。
- 与 `shot-axis-triangle`：轴线管空间方向，与本 skill 的画框策略正交。
- 与 `shot-storyboard`：本 skill 给每个镜的"画框属性"，由 `shot-storyboard` 落进分镜。

## E — 可执行步骤 (Execution)

1. **定参与目标**：明确这个镜头要"高参与/写实窥视"还是"低参与/舞台旁观"，或要传达何种心理距离。→ *完成标准*：每镜有参与目标标签（开放向/封闭向）。
2. **选画框策略**：高参与→开放（主体/动作溢出画外、似随意截取）；低参与/舞台→封闭（中轴对称、门框窗框框死、信息自足）。→ *完成标准*：每镜标了开放/封闭，且构图元素（框线、出画点）与之匹配。
3. **对齐邻近维度**：与视点档位（开放常配受限第三人称/窥视，封闭常配全知/旁观）和机位高度一致，避免意图冲突。→ *完成标准*：构图、视点、机位高度三者心理暗示一致，无"写实戏却框死"式错配（防 ce09）。
   - **判停条件**：若用户只问"观众该认同谁"而非画框，转 `shot-viewpoint`；若只问"两人怎么站位"，转 `shot-dialog-blocking`。

## B — 边界 (Boundary) ★

① **反场景**：纯抽象/实验影像无明确"参与意图"时，开闭二分未必适用；本 skill 服务于"有意调控观众关系"的叙事构图。
② **书中警告的失败模式**
- ce09 画框策略与意图错配：该给世界延续的写实戏误用封闭构图（人物被门框窗框过度框死），或该自足的舞台戏误用开放（主体频繁出画却无意为之），构图传递错误心理暗示，与叙事意图冲突。
③ **作者盲点/时代局限**（来自 BOOK_OVERVIEW 批判段）
- 画幅制式（第22章）与开闭构图强相关：宽银幕容纳更多环境并置利于开放，则相反，需重排构图重心。
④ **易混淆邻近方法论**：与 `shot-viewpoint`（认同）、`shot-dialog-blocking`（对话几何）易混；记住——本 skill 只回答"画框松紧/参与度/美学距离"，不回答认同档位、站位或轴线。
