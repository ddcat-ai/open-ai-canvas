## I — 方法论骨架 (Interpretation)

作者把"把剧本变成能拍的镜头"拆成一套可操作流程：

1. **两层影像化**：先用直觉式快速抓取段落里最关键的几个镜头（脑中预演），再用反思性靠故事板/平面图把它们固化、修正——直觉不是灵感，是两步可练的技能。
2. **故事板双重功能**：一是"沟通"（让摄影、美术、演员看懂你要什么），二是"预演"（在纸上先把每镜的平面图和画面画出来，模拟成片）。
3. **同一场景画多个版本**：核心论证方式——用成组对比的分镜替代纯文字说理，证明镜头选择如何改变叙事与心理效果（如同一个卧室戏画 I 形版、过肩版、POV 版对比）。
4. **预演即排雷**：复杂推轨/群戏先在故事板预演，提前发现并修正跳轴、近似镜，再到现场，减少即兴与补拍。
5. **数字预视觉化**：今天可用 FrameForge、Poser、运动控制甚至 AI 预览，把纸面分镜搬进虚拟实时环境，低成本"在虚拟中拍片"。

核心是"脑中先见 → 纸上固化 → 多版对比 → 预演排雷"。

## A1 — 书中的应用 (Past Application)

- **故事板预演复杂调度（c24，含 c06 并入）**：问题——复杂推轨群戏如何在开拍前发现跳轴/近似镜？方法论使用——先在故事板上画出每镜的平面图与画面，预演影像化，提前发现并修正问题再到现场。结论——故事板"沟通+预演"双重功能落地。结果——印证影像化是可固化的前置方法，而非现场凭感觉。
- **（c06 并入）数字预视觉化必然趋势**：作者以高密度视觉世界（如《银翼杀手》式）作注脚，说明当影像复杂度超脑中管理上限，须借 3D 故事板/预览系统——这是故事板从手工走向数字的自然延伸。

## A2 — 触发场景 (Future Trigger) ★

① **用户情境（3–5 条）**
- 用户有一段剧本/台词场，要变成"能拍的镜头序列草图"（含景别、角度、机位）。
- 用户想先预演一场戏，提前发现跳轴、近似镜、机位冲突。
- 用户需要镜头清单（shot list）作为拍摄/AI 生成的依据。
- 用户要在多个镜头方案间对比选优（同一场景多版本）。

② **语言信号（用户原话式措辞，中英双写）**
- "帮我把这场戏出成分镜 / 画个故事板 / 镜头怎么排"
- "先预演一下这场，别现场翻车 / let's previs this scene first"
- "同一个场景能不能给几个镜头版本对比 / give me alternate storyboard versions"

③ **与相邻 skill 区分（定稿）**
- 与 `shot-dialog-blocking` / `shot-axis-triangle`：本 skill 把它们的"形态/机位/轴线方案"画成多版本分镜草图，是它们的下游呈现层。
- 与 `shot-shotflow`：本 skill 产出静态分镜序列，`shot-shotflow` 管镜头连接后的流畅运动（镜流）。
- 与 `shot-movement`：本 skill 可包含运动镜的分镜，但运动路径设计细节归 `shot-movement`。
- 与 `shot-open-close` / `shot-viewpoint`：构图开闭、视点档位是分镜里每个镜头的属性，本 skill 调用它们填充单镜。

## E — 可执行步骤 (Execution)

1. **抓关键镜**：用直觉式通读段落，列出 3–8 个不可省的关键镜头（建立关系、转折、反应）。→ *完成标准*：关键镜头清单已出，覆盖段落主要信息与情绪点。
2. **画多版分镜**：每个关键镜标注景别、角度、机位（含是否过肩/POV），并画至少两套整体方案对比（如固定正反打版 vs 运动长镜版）。→ *完成标准*：每镜有景别+角度+机位标注，且≥2 套可对比的整体序列。
3. **预演排雷**：在平面图上模拟连接，检查轴线同侧、相邻镜≥30°、主镜已建立空间、无缺锚点特写；列出需修正项。→ *完成标准*：给出"通过/待修"清单，待修项指明具体镜号与问题（跳轴/近似镜/缺主镜）。
   - **判停条件**：若用户只问"这场对话站位怎么摆"而非要分镜草图，转 `shot-dialog-blocking`；若只问"镜头接起来顺不顺"，转 `shot-shotflow`。

## B — 边界 (Boundary) ★

① **反场景**：纯文字剧本梳理、或只做节奏/台词修改而不涉及镜头化时，不需本 skill；本 skill 服务于"把文字变可拍镜头"。
② **书中警告的失败模式**
- ce17 未影像化即开拍（凭感觉）：跳过脑中预演总前提，各镜独立决策失整体连续，后期镜流断裂、空间对不上。
- 与之相关：缺主镜直接切特写（ce06）、镜头清单不规范（ce16）都可在预演阶段排雷——本 skill 的预演步骤即针对这些。
③ **作者盲点/时代局限**（来自 BOOK_OVERVIEW 批判段）
- 依赖专业手绘/ CAD（附录）对极低预算创作者门槛高；今天可用 AI 生图/数字预视觉化替代，降低了本 skill 的执行成本。
- 作者把 continuity 当唯一正统，分镜默认服务隐藏剪辑；反剪辑/长镜方案也应在"多版本对比"中给予一席。
④ **易混淆邻近方法论**：与 `shot-shotflow`（连接流畅）、`shot-dialog-blocking`（对话机位）易混；记住——本 skill 产出"分镜草图与镜头清单"，不直接判定流畅度，流畅度交给 `shot-shotflow`，单镜属性交给构图/视点 skill。
