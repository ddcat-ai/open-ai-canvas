## I — 方法论骨架 (Interpretation)

作者把"对话怎么站位、机位怎么摆"这套看似靠感觉的事，做成了一套可照抄的几何系统：

1. **先定形态**：两人默认 I 形（前后一线），走廊拐角用 L 形，并排坐用 A 形；形态是俯视平面的字母轮廓，不靠灵感。
2. **再上机位**：在形态上套"十种基本位置"——主镜（建立关系）→ 斜角单人（各拍一人）→ 过肩（OTS，从肩后拍对方）→ 正反打（内/外反拍调亲密度）→ POV。
3. **正反拍调心理距离**：外反拍机位偏自己、更客观疏离；内反拍机位偏向对方、切得更紧，机位夹角越小越亲密（可量化）。
4. **三人=A 形扩展**：在 I 形加第三点成 A 形，主镜统三方，再切两两子对话，各组守各自局部轴线。
5. **群体=子群拆分**：八人圆桌拆成两对子群，每群走 I 形正反打，关键发言回总主镜收束。
6. **演员调度与机位调度同步**：二者画在同一张平面图里互相约束，推轨戏尤其如此（p30）。

核心是"形态定骨架、机位填血肉、轴线管安全"。

## A1 — 书中的应用 (Past Application)

- **卧室双人对话（c08）**：问题——如何把抽象的三角机位/十种位置套到一对具体角色？方法论使用——先双人主镜建立空间，再斜角单人、过肩、POV 拆解对白与反应，全程守轴线。结论——对话调度是可机械套用的系统而非灵感。结果——作者逐镜演示，证明框架对任意双人戏可复刻。
- **过肩正反打拆解争执（c12）**：问题——两人争执戏如何既清楚又紧绷？方法论使用——机位从各自肩后拍对方，正反打夹角≥30°，内反拍制造紧绷亲密感，轴线同侧。结论——标准化操作样板。结果——可直接复用于任何双人冲突。
- **四人会议子群拆分（c14）**：问题——圆桌会议如何不机位迷失？方法论使用——先总主镜，再拆两对子群各守局部轴线，关键发言回总主镜。结论——大群戏=可管理子系统之和。结果——避免多重轴线失控。

## A2 — 触发场景 (Future Trigger) ★

① **用户情境（3–5 条）**
- 用户写/改一段对话戏，问"这场两个人/三个人/一桌人该怎么拍、机位怎么排"。
- 用户已有分镜但担心"群戏会不会跳轴、关系乱"。
- 用户要做过肩正反打，不确定内反拍还是外反拍、切多紧。
- 用户排走廊拐角、并排沙发等受空间约束的对话位。

② **语言信号（用户原话式措辞，中英双写）**
- "这场戏的站位和机位怎么设计 / 怎么拍才不别扭"
- "过肩正反打怎么打，切太近会不会怼脸 / how to do OTS reverse shot"
- "三个人/一群人对话怎么调度不跳轴 / how to stage a group without crossing the line"

③ **与相邻 skill 区分（定稿）**
- 与 `shot-axis-triangle`：本 skill 管"对话形态与机位选择"，轴线/三角几何的底层校验归 `shot-axis-triangle`；本 skill 调用它作为前置。
- 与 `shot-viewpoint`：本 skill 管"站哪、机位在哪"，`shot-viewpoint` 管"观众认同谁"（POV 档位）；过肩属于两 skill 交界，本 skill 侧重几何、彼侧重认同。
- 与 `shot-movement`：本 skill 默认固定机位拆解；若整场用一条推轨长镜取代剪辑，转 `shot-movement`。
- 与 `shot-storyboard`：本 skill 产出对话的"形态+机位方案"，`shot-storyboard` 把它画成多版本分镜草图。

## E — 可执行步骤 (Execution)

1. **定形态**：在俯视平面图标出人物，选 A/I/L；两人默认 I，拐角用 L，并排用 A。→ *完成标准*：每个角色的平面位置与朝向已画出，形态标签明确。
2. **排机位**：先放一个双人主镜（建立关系），再按十种位置补斜角单人/过肩/正反打；内反拍收紧夹角表亲密，外反拍放宽表疏离；三人加第三点成 A 形、群体拆子群各守局部轴线。→ *完成标准*：机位清单含角度/景别/是否过肩，且都在轴线同侧、相邻镜夹角≥30°。
3. **同步校验**：把演员走位与机位画在同一张图（p30），检查运动中轴线不飘、落点清楚。→ *完成标准*：平面图同时含演员路径与机位路径，无未定义轴线的机位。
   - **判停条件**：若这场戏本质是单条运动长镜（无正反打剪辑），停止本流程，转 `shot-movement`；若用户只要"观众该认同谁"而非机位，转 `shot-viewpoint`。

## B — 边界 (Boundary) ★

① **反场景**：纯运动长镜对话、或作者性反剪辑/固定长拍（侯孝贤式）不套本系统；本 skill 服务于连续性剪辑语法的对话戏。
② **书中警告的失败模式**
- ce06 缺主镜直接切特写：跳过双人/全场主镜进特写，观众不知人物在哪、关系如何（缺空间锚点）。
- ce07 群戏多重轴线失控：不拆子群、单轴线管全场，机位在多重关系间迷失、跳轴频发。
- ce15 推轨未先定静止骨架：先运动再想静止调度，轴线飘忽、机位无依据（对话推轨戏同样适用）。
- ce18 内反拍过度：夹角过小、景别过近，亲密变侵入式逼视，观众不适。
③ **作者盲点/时代局限**（来自 BOOK_OVERVIEW 批判段）
- 手机拍摄 + 非线性剪辑时代，过肩/正反打可后期重排，不必现场拍满十种位置。
- 好莱坞 continuity 唯一正统偏见：作者把本系统当"正确方法"，但反剪辑/长镜美学同样成立，本 skill 是工具不是律令。
④ **易混淆邻近方法论**：与 `shot-axis-triangle` 的"轴线几何"、与 `shot-viewpoint` 的"POV 认同"易混；记住——本 skill 输出"形态+机位清单"，轴线安全交给 `shot-axis-triangle` 校验，认同档位交给 `shot-viewpoint`。
