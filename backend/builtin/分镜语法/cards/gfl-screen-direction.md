## I — 方法论骨架 (Interpretation)

1. **兴趣线(line of interest) = 两角色视线方向连线**；其两侧各可布一组三角形机位，但只能选一侧。
2. **180° 轴线铁律**：一旦选定一侧，所有覆盖机位须留在同一侧，否则屏幕方向(screen direction)会反，观众迷失。
3. **屏幕方向连续**：守住轴线时，A 恒在左、B 恒在右（反之亦然），正反打不跳。
4. **五类基本变体**：external reverse / internal reverse / parallel / right angle / 单体（lone player 头向决定 north-south 或 east-west 轴）。
5. **构图重心**：把主导角色放在屏幕中心，注意力始终锁在中心区。
6. 轴线可破，但有规范方式（后续章节的 crosswise change / 借 cut-away 过渡）。

## A1 — 书中的应用 (Past Application)

### 案例
- 图 4.4：两静态角色对白用三角形原则覆盖，女孩 A 始终在屏幕左、青年 B 始终在右——屏幕位置恒定由"守住轴线一侧"保证。
- 单体player：若直视前方，兴趣线 north-south；头偏向一侧则 east-west 轴；机位须平行于其视线方向。
- 五变体：base 上的 external reverse（背影内夹角）、internal reverse（向外 pivot）、parallel、L 形 right angle 等，按关系亲疏与构图需要取舍。

## E — 可执行步骤 (Execution)

1. **划兴趣线**：两角色（或主体与注目物）的视线连线在哪？
2. **选一侧**：在线的一侧布三角形机位（base 两端 + apex），只取一侧。
3. **锁屏幕方向**：A 恒左、B 恒右（或反之），正反打不跳。
4. **选变体**：按亲疏/构图选 external/internal reverse / parallel / right angle。
5. **破轴须有桥**：要换侧，用 cut-away / 中性方向 / 角色指示过渡。

---

## B — 边界 (Boundary) ★

- **轴线非绝对**：作者承认可破，但须用规范方式过渡，否则观众方向感崩。
- **勿为构图牺牲方向**：强构图若导致反轴跳戏，优先保屏幕方向连续。
- **Tier B**：只抽"三角形原则+兴趣线"机制；不复述书中图示长例。
