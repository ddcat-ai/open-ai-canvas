## I — 方法论骨架 (Interpretation)

立项/概念面临一个双约束悖论，不是二选一，而是转化：

1. **悖论**：决策方同时要求"完全新颖独特"和"和已成功者一模一样"——看似矛盾，却是真实门槛。
2. **解法**：不是抛弃类型去硬求新，而是"在 franchise 内部做原创 / 重新诠释 franchise"。熟悉的类型降低认知成本，作者声音颠覆它产生新颖。
3. **评估维度**：一个概念是否成立，看它是否同时满足两端——(a) 落在成熟 franchise（满足"像成功者"，降低风险）；(b) 带只有你有的视角/声音（满足"新颖"，产生 legs）。
4. 反例：只模仿（ce09 自我审查）则雷同无续看；只求怪则无锚点。

## A1 — 书中的应用 (Past Application)

### 案例 1: Mad Men — premise pilot 与"慢"逆袭 (case-006)
- **问题**: 一个 1960s 广告业的 premise pilot，既属成熟职场剧 franchise 又凭什么脱颖而出？
- **方法论的使用**: Matt Weiner 把主角丢进新情境（熟悉的好莱坞职场 franchise 外壳），却以 AMC 反潮流的"慢"叙事、内省作者声音重新诠释它；spec pilot→进《黑道家族》历练→最终按原样拍出，证明"类型内原创"能被看见。
- **结论**: 成熟的 franchise + 独特声音 = 既"像成功者"又"新颖"，悖论被消解。
- **结果**: 成为 premise pilot 与"系列化作者声音存活"的标杆。

### 案例 2: The Good Wife — 受克林顿夫妇启发的前提设定 (case-008)
- **问题**: 律政 procedural 已被写烂，如何再原创？
- **方法论的使用**: Kings 透露设定直接受克林顿夫妇（权力婚姻）启发——Alicia 重拾事业反过来威胁丈夫地位。这是把真实社会原型注入成熟 franchise，做出只有他们能做的诠释。
- **结论**: "重新诠释 franchise"常来自真实世界的独特观察，而非凭空发明类型。
- **结果**: 示范前提 pilot 如何与真实原型结合，向角色驱动倾斜。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

2. 立项时纠结"我的点子太像某成功剧"或"太怪没锚点"，需要悖论框架平衡两端。

### 语言信号 (用户的话里出现这些就应激活)

- "我的概念既要新颖又要像成功者，怎么平衡"
- "家庭+计谋这种成熟类型还能怎么原创"
- "怎么重新诠释 franchise / 老类型翻拍"
- "概念 uniqueness / concept 是否成立 / 怕太雷同"
- "original within franchise / paradox / 类型内原创"

### 与相邻 skill 的区分

- 与 `tvd-franchise-springboards` 的区别：本 skill 是**概念决策层**（在已定 franchise 内如何原创、悖论怎么解）；franchise-springboards 是更底层的"边界 + 引擎 + legs"（这个 franchise 是什么、能不能长）。
- 与 `tvd-pilot-design` 的区别：本 skill 只决定"概念两端是否平衡"；pilot-design 是概念确定后的"四步法 + 钩子 + 十问"落地。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **写出概念两端的归属**
   - 完成标准: 明确列出"本概念落在哪个成熟 franchise（像成功者的部分）"与"本概念独有的视角/声音（新颖的部分）"。

2. **对两端打分并找缺口**
   - 完成标准: 若"像成功者"满分而"新颖"为零 → 预警 ce09 模仿风险；若"新颖"满分而"像成功者"为零 → 缺锚点，需补类型外壳。

3. **给出 re-interpret 落点**

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户还在界定 franchise 边界与故事引擎（应改用 `tvd-franchise-springboards`）。
- 用户已定概念、在写 pilot 四步法/钩子（应改用 `tvd-pilot-design`）。
- 用户在画整季弧光图表（应改用 `tvd-season-arc-planning`）。

### 作者在书中警告的失败模式

- **ce09 pilot 只模仿已播剧、自我审查**：学生写 pilot 只复刻看过的剧，不敢跳出自身体验冒险，成品"安全但雷同"、无 legs；作者强调"停止自我审查什么是可能的"，否则没有独特声音与续看理由。

### 作者的盲点 / 时代局限
### 容易混淆的邻近方法论

- 与 `tvd-franchise-springboards` 最常混淆：记住本 skill 回答"概念怎么原创才成立"，不回答"这个 franchise 边界/引擎/续航是什么"。
