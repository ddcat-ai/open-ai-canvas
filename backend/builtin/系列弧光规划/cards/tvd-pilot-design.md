## I — 方法论骨架 (Interpretation)

建系列四步递进，核心是"先建 world 再点火续看引擎"：

1. **先建 world**：确立地点、调性、语境，让观众落地。
2. **找 story springboards**：埋下能"持续发生"的马达（每周冲突引信），这是 legs 的来源。
3. **填充世界引出常驻主演**：在 world 里让常驻角色自然登场，而非先写概念。
4. **做计划**：前 10 页（或更少）就要抓人、埋续看钩子。

关键操作点：
- **十问钩子**：首集结尾抛 ≥10 个让观众揪心的问题（角色/情节走向），锁住回流。
- **前几分钟抓人（beat the remote）**：开头必须比遥控器更快抓住人，用 story 而非 message 开场。
- **持续 Pilot**：第 2、3 集仍承担 Pilot 功能（新人可入 + 老粉有进展）。
- 张力按 Anticipation→Expectation→Surprise 循环，开场用故事而非说教。

## A1 — 书中的应用 (Past Application)

### 案例 1: Mad Men——前提 Pilot 标杆
- **问题**: 如何用一个 pilot 生发出无尽故事？
- **方法论的使用**: Matt Weiner 把 Don Draper 丢进 1960s 广告业新情境（Premise Pilot），由此 springboard 出整部系列；AMC 押注其"慢而高质"的反潮流策略。
- **结论**: 前提事件 + 世界建立 = 可持续引擎。
- **结果**: Weiner 写 spec pilot→进《黑道家族》历练→最终按原样拍出，是"好 pilot 终被看见"范本。

### 案例 2: Georgia Jeffries 的"10 个问题"法
- **问题**: pilot 如何埋 hooks 锁住回流？
- **方法论的使用**: 她要求学生为第一集末尾设计至少 10 个让观众揪心的问题，据以决定未来集的 10 条短梗概；"不能让观众以为已有答案"。
- **结论**: 钩子密度 = 续看理由。
- **结果**: 提供可执行的 pilot 钩子设计工具，强调"口袋里留 trick"而非藏谜。

### 案例 3: Lost——高成本世界构建样本
- **问题**: "困在岛上"看似没有戏剧走向，如何变成现象级？
- **方法论的使用**: 靠庞大群像 + 坠机前后双时间线 + 每集怪转折破局；$12M 两小时 pilot 建立完整世界（world-building）。
- **结论**: 世界建立 + 群像悬念 = 系列潜力。
- **结果**: 推动网络台从四幕走向五/六幕，示范 pilot 经济的天花板。

### 语言信号 (用户的话里出现这些就应激活)

- "第一集/pilot 怎么开头才能抓人"
- "前 3 秒怎么进冲突 / 怎么埋续看钩子"
- "这集结尾要留几个悬念"
- "pilot design / premise pilot / 试播集 / 十问钩子 / beat the remote"

### 与相邻 skill 的区分

- 与 `tvd-season-arc-planning` 的区别：本 skill 聚焦**第一集**的 world 建立、前几分钟抓人与结尾十问；season-arc-planning 管**整季 **首尾与情感旅程。问"第 1 集前 3 秒"→ 本 skill；问"整体走向/首尾锁哪"→ season-arc-planning。两者常配套：先用本 skill 点火，再用 season-arc-planning 规划全程。
- 与 `tvd-finding-stories-filter` 的区别：finding-stories-filter 评估"单个点子是否合格"；本 skill 是把通过筛选的 premise 落成可播的第一集结构。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **定 Pilot 类型 + 引爆事件**
   - 完成标准: 明确 Premise/Ongoing；给出第 1 集"把推进 quest"的具体事件，并确认前 3 秒直入冲突（非慢热，避 ce03/ce10）。

2. **建 world + 引出常驻主演**
   - 完成标准: 产出 world 设定卡（地点/调性/语境）+ 常驻角色登场方式，符合"在 world 里自然登场"。

3. **写结尾十问钩子清单**
   - 完成标准: 列出 ≥10 个首集末尾让观众揪心的问题，且每问对应一个未来集短梗概（口袋留 trick，不藏谜）；确认无 prematurely 闭合主弧。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要规划整季 走向——用 tvd-season-arc-planning。
- 用户只问"这个具体点子能不能做一集"——用 tvd-finding-stories-filter。
- 用户已锁定 pilot 故事、只问"这一集分几幕/多线怎么铺"——用 tvd-outline-color-cards / tvd-grid-reverse-engineering。

### 作者在书中警告的失败模式

- **ce09 只模仿已播剧、自我审查**：pilot 拼贴成功剧、不敢冒险，没有独特声音与 legs。
- **ce10 把谜题"留到后面"**：为"后面惊喜"收着写，首集平淡、赌注不清，续看引擎没点火。
- **ce03 慢热开场（throat-clearing）**：前几分钟没 jeopardy/hook，观众与审稿人流失。
- **ce23 Pitch 信息过载**：一次倾倒设定，核心 hook 模糊。
