## I — 方法论骨架 (Interpretation)

Franchise（题材/类型边界）在本书里不是商业"IP 授权"，而是**故事引擎的边界与机会**：

1. **边界**：家庭/计谋/医疗/律政等类型自带观众期待，你必须在边界内工作（也可挑战它）。
2. **机会（springboards）**：每一类天然孕育"每集冲突引信"——犯罪→追凶、病人→救治、计谋→破解。springboard 是可持续产出的故事引擎。
3. **Legs（续航力）**：判断一个前提能否撑住长系列的核心判据——单一前提能否衍生大量单集。前提够"宽"才能喂饱数百小时。
4. 公式是风险：空壳 franchise 易被取消；但用真实人物与诚实社会关切 inhabitate 它，公式也能长青。

## A1 — 书中的应用 (Past Application)

### 案例 1: Deadwood — 用 franchise 外壳做道德荒野重构 (case-011)
- **问题**: 西部/罪案 franchise 已被用烂，如何借熟套又不被其吞没？
- **方法论的使用**: 作者指出 Deadwood 表面借了"坏边境镇 + 弃徽章警长"的 franchise 外壳，但相似性仅停留在表面——它把故事变成没有外部拯救者的"道德荒野"。这是"用边界降低认知成本，再用作者声音颠覆它"。
- **结论**: franchise 是约束也是机会；重构（re-interpret）比照搬更有 legs。
- **结果**: 成为"借壳重生"的标杆，并展示 HBO 12 集短季如何重构叙事节奏。

### 案例 2: Law & Order — 以品牌而非单剧运作 (case-013)
- **问题**: 如何让一个前提衍生出无限集甚至多档衍生？
- **方法论的使用**: Dick Wolf 把 Law & Order 做成可无限衍生的 franchise 品牌（含 SVU 等 spin-off），Rene Balcer 视系列剧为"电子丝绸之路"上的全球商品。
- **结论**: 强 franchise + 充足 springboards = 可复制品牌；全球发行支撑高成本。
- **结果**: 证明"故事引擎"的商业延展逻辑（format franchising）。

### 案例 3: Ghostwriter — 强壮 franchise 托起教育使命 (case-016)
- **问题**: 面向 8 岁、鼓励阅读的设定看似与高张力故事冲突，如何成立？
- **方法论的使用**: 作者以自己 developer 经历说明：强壮的 franchise + 真实角色，能托起"教育内容"这种看似不可能的使命，同时以高张力推进故事。
- **结论**: franchise 承载力来自"角色真实 + 引擎充足"，而非题材本身。
- **结果**: 一手经验证明公式化风险可被真实情感 inhabitate。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

3. 评估一个原创前提"能不能做长系列"——用 legs 判据审视续航潜力。

### 语言信号 (用户的话里出现这些就应激活)

- "这个题材 franchise 边界是什么 / 能不能做长"
- "legs 续航力 / 这个前提能撑多少集"
- "故事引擎 story engine / 类型边界"
- "franchise / format / 题材承载力"

### 与相邻 skill 的区分

- 与 `tvd-original-within-franchise` 的区别：本 skill 解决"边界 + 引擎 + 续航力"（**是什么/能不能长**）；original-within-franchise 解决"在已定 franchise 内如何既像成功者又新颖"（**怎么原创**），是概念决策层。
- 与 `tvd-finding-stories-filter` 的区别：本 skill 从 franchise 层面判断前提是否有 leɡs；finding-stories-filter 是单集选题的四准则过滤（贴媒介/贴剧/可视觉化/真实洞察）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **界定 franchise 边界**

2. **枚举 springboards 并测 legs**

3. **识别缺情感引擎的空壳 springboard**
   - 完成标准: 标出哪些 springboard 只是模板填充（对照 ce13），需补真实人物/社会关切才能 inhabitate。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户在做概念层面的"既要新颖又要像成功者"悖论决策（应改用 `tvd-original-within-franchise`）。
- 用户在用四准则过滤单个集的故事 idea（应改用 `tvd-finding-stories-filter`）。
- 用户在写 pilot 四步法/钩子（应改用 `tvd-pilot-design`）。

### 作者在书中警告的失败模式

- **ce13 公式化模仿（formulaic imitation）**：套用 franchise 模板却无真实情感，人物只是功能位、可无限复制；作者忠告"用公式，但用真实人物与其诚实社会关切去 inhabitate 它"。

### 作者的盲点 / 时代局限
### 容易混淆的邻近方法论

- 与 `tvd-original-within-franchise` 最常混淆：记住本 skill 回答"边界/引擎/续航"，不回答"如何在边界内原创"。
