## I — 方法论骨架 (Interpretation)

1. **核心原理**：人们对"新闻"天然有好奇心和信任感，把广告标题伪装成新闻，能大幅提升打开率。
2. **三步公式**：新闻主角（傍大款）+ 即时性词语 + 重大新闻常用词。
3. **第一步——树立新闻主角**：找到产品能"傍"上的知名元素——明星地区（硅谷、好莱坞）、著名公司（苹果、谷歌）、知名人物（某个领域的权威）。这个主角越有名，标题越有分量。
4. **第二步——加即时性词语**：注入时间紧迫感，如"今天""2017年""这个夏天""刚刚"。让读者觉得这是"此刻正在发生的事"，激发即时好奇心。
5. **第三步——加重大新闻常用词**：用"全新""曝光""突破""发现""揭秘"等词，暗示这是一条"大事"，值得点击了解。
6. **关键点**：三个元素缺一不可。没有主角就没有权威感，没有即时词就没有紧迫感，没有新闻词就没有"大事感"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 咖啡产品——"硅谷2017年新发明"
- **问题**: 咖啡市场竞争激烈，普通标题如"醇香咖啡，限时特惠"难以脱颖而出。
- **方法论的使用**:
  - 新闻主角：硅谷（全球科技创新圣地，自带权威光环）
  - 即时性词语：2017年（具体年份，暗示新鲜）
  - 重大新闻词：新发明（暗示突破性成果）
- **结论**: "硅谷2017年新发明"把一杯普通咖啡包装成了科技前沿产品。
- **结果**: 标题点击率大幅提升，因为"硅谷+新发明"组合触发了强烈的好奇心和信任感。

### 案例 2: NBA球鞋——"全明星赛上场鞋曝光"
- **问题**: 运动鞋广告铺天盖地，如何让一款球鞋脱颖而出。
- **方法论的使用**:
  - 新闻主角：NBA全明星赛（全球最顶级的篮球赛事）
  - 即时性词语：隐含在赛事的时效性中
  - 重大新闻词：曝光（暗示独家揭秘）
- **结论**: "全明星赛上场鞋曝光"让读者觉得这不是广告，而是一条体育新闻。
- **结果**: 球鞋爱好者出于"想知道球星穿什么"的好奇心点进去，转化为购买意愿。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 新品上市，需要一个有新闻感的标题来吸引第一波关注。
2. 产品有技术突破、专利创新、权威认证等"硬核"卖点，适合用新闻形式呈现。
3. 产品与知名品牌/人物/地区有关联，需要放大这个关联来借势。
4. 竞品广告都是常规套路，需要用"不像广告"的标题来突围。

### 语言信号
- "标题怎么写才有点击率"
- "怎么让标题有新闻感"
- "新品推广标题怎么写"
- "怎么傍大款写标题"
- "广告标题怎么写得不像广告"

### 与相邻 skill 的区分
- 与 `friend-chat-title` 的区别: 那个走"亲切口语"路线，像朋友聊天；本 skill 走"权威新闻"路线，像媒体报道。两者风格完全不同，适用于不同产品调性。
- 与 `practical-tip-title` 的区别: 那个以"痛点+解决方案"吸引人；本 skill 以"新闻事件"吸引人，不直接点出痛点。
- 与 `justified-consumption` 的区别: 那个是购买理由重构，处理的是"犹豫下单"的问题；本 skill 处理的是"标题吸引点击"的问题。

## E — 可执行步骤 (Execution)

1. **找到产品的"傍大款"元素（新闻主角）**
   - 完成标准: 列出产品能关联的所有知名地区、公司、人物、事件，选出最有名、最自然的那一个。
2. **选择即时性词语**
   - 完成标准: 确定一个具体的时间表达（年份/季节/今天/刚刚），让标题有"正在发生"的感觉。
3. **选择重大新闻常用词**
   - 完成标准: 从"全新/曝光/突破/发现/揭秘/首度"中选出最贴合产品特性的词。
4. **组合三要素，写出完整标题**
   - 完成标准: 将"新闻主角+即时性词+新闻词"组合成一条通顺、有吸引力的标题。
5. **检验标题是否"像新闻而不像广告"**
   - 完成标准: 把标题拿给3个人看，如果他们觉得"这是一条新闻"而不是"这是一条广告"，就通过了。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 产品本身走温馨、情感、亲切路线（如母婴用品、手工糕点），新闻式标题会显得生硬违和。
- 私域运营（朋友圈、社群）场景，用户更信任"真人说话"而非"新闻播报"。
- 产品没有可"傍"的知名元素，强行编造会损害品牌诚信。
- 标题党风险高的平台（如已被监管的渠道），过度新闻化可能被处罚。

### 作者在书中警告的失败模式
- 傍的大款与产品毫无关系，读者点进去发现"被骗"，跳出率极高。
- 即时性词语过期（如"2017年新发明"在2024年看就失效了），标题需要定期更新。
- 新闻词滥用（什么都"曝光"什么都"突破"），读者审美疲劳后不再相信。

### 作者的盲点 / 时代局限
- 2017年"傍大款"策略在当前自媒体环境中可能面临合规风险（如未经授权使用名人/品牌名义）。
- 短视频时代的标题逻辑与图文时代不同，新闻式标题在抖音/小红书的信息流中可能不够"炸裂"。
- 消费者对"伪装成新闻的广告"越来越警惕，部分平台已要求广告标注"推广"标识。
