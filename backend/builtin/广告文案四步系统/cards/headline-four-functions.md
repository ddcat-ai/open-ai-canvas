## I — 方法论骨架 (Interpretation)

一个有效的广告标题应从四个维度评估和设计：

1. **吸引注意**：通过承诺好处或提供新信息，在信息洪流中"异军突起"。关键词汇：免费、如何、为什么、快速、简单、保证。
2. **筛选听众**：排除非目标群体，锁定真正有购买潜力的读者。通过特定用语暗示"这是给谁看的"。
3. **传达完整信息**：让80%只看标题的读者也能获得核心销售信息（奥格威原则）。标题应包含品牌名和核心利益承诺。
4. **引导阅读内文**：激发好奇心，让读者想继续往下读。通过提问、悬念、承诺奖赏等方式驱动。

好标题不必同时满足四项，但至少要完成第一项（吸引注意），并根据广告类型侧重其他功能。不同媒体的"标题"载体不同——平面广告是标题文字，网站是首屏，电邮是主题行。

## A1 — 书中的应用 (Past Application)

### 案例1: 日本主管标题
- **问题**: 如何吸引美国主管参加管理培训课程
- **方法论的使用**: 标题"日本主管有哪些美国主管没有的优点？"同时完成四项功能
- **结论**: 注意(挑衅性问题) + 筛选(仅主管关心) + 信息(暗示有洞察) + 引导(必须读才知道答案)
- **结果**: 完美示范四功能标题

### 案例2: 保时捷跑车标题
- **问题**: 如何筛选出真正买得起跑车的客户
- **方法论的使用**: 标题"假如你要问这部车一公升油能跑几公里，那么你就买不起"——"冒犯"非目标客户来筛选
- **结论**: 极端运用"筛选听众"功能，反向心理吸引目标群体
- **结果**: 展示了筛选功能的价值

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 正在为产品广告写标题，脑子里有几个想法但不确定哪个好
2. 评估团队提交的广告标题，需要一个系统化的检查框架
3. 设计邮件营销的主题行，希望提高打开率
4. 设计网站着陆页，确定首屏应该放什么信息

### 语言信号 (用户的话里出现这些就应激活)

- "这个标题好不好？"
- "帮我写个广告标题"
- "邮件主题怎么写能提高打开率"
- "首屏应该放什么"
- "怎么让标题更吸引人"

### 与相邻 skill 的区分

- 与 `headline-eight-types` 的区别: 本skill是评估框架（标题应该做什么），后者是创作分类（标题有哪些写法）

## E — 可执行步骤 (Execution)

1. **明确广告类型和目标读者**
   - 完成标准: 能一句话说清"这则广告要卖给谁、想达到什么效果"

2. **用四功能逐项评估标题草稿**
   - 吸引注意: 标题是否承诺了具体好处或提供了新信息？
   - 筛选听众: 是否能让目标客户产生"这是说给我听的"感觉？
   - 传达信息: 只看标题的人能否获得核心销售信息？
   - 引导内文: 读者是否有动力继续往下读？
   - 判停条件: 若标题连"吸引注意"都没做到，直接重写

3. **根据广告类型调整四功能权重**
   - 直接销售广告: 侧重功能1+3（注意+完整信息）
   - 发掘线索广告: 侧重功能1+4（注意+引导内文）
   - 品牌广告: 侧重功能1+2（注意+筛选）
   - 完成标准: 每个功能都有明确的是/否判断

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 正文段落写作——四功能仅适用于"第一印象"元素
- 纯品牌形象讨论——需要先确定文案目的才能用四功能评估
- 非广告场景（小说标题、学术论文标题）——评估标准完全不同

### 作者在书中警告的失败模式

- 标题卖弄文字游戏/双关语但不承诺好处——看起来聪明但不卖货
- 用噱头吸引注意但与产品无关——招来好奇旁观者，不招来买家
- 把最重要的好处藏在文案最后——读者可能在标题就流失了

### 作者的盲点 / 时代局限

- 奥格威的"4倍"数据来自1960年代，当代信息密度完全不同，比例可能更高
- 对品牌广告场景下"筛选听众"和"传达完整信息"的权重分配讨论不足

### 容易混淆的邻近方法论

- 不要把"四功能"和"八种类型"混淆——前者是评估标准，后者是创作分类
