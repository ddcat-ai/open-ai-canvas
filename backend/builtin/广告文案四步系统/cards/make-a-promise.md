## I — 方法论骨架 (Interpretation)

承诺(给消费者一个利益点)是广告的灵魂。

- 斯塔奇数据: 标题承诺利益的广告比不承诺的阅读人数多 4 倍。
- 多数广告竟无任何承诺——只讲调性/自夸, 等于没有灵魂。
- 市场调查最有价值的贡献是"**选承诺**": 向消费者展示多个候选承诺, 按重要性+独特性评级; 或分版测试两个承诺标题的真实回应。
- 找"既有说服力又有独特性"的承诺; 若对手已用最优承诺, 需重新找。

但调查是"路灯杆"——别用它证明自己早有的结论(别当教条)。

## A1 — 书中的应用 (Past Application)

### 案例 1: 多芬承诺胜出
- **问题**: 香皂如何打动女性。
- **方法论的使用**: 用测试选出承诺"沐浴时多芬为肌肤带来乳霜般滋养"。
- **结论**: 具体利益承诺胜过空泛"好香皂"。
- **结果**: 承诺测试胜出, 支撑 25 年定位。

### 案例 2: 壳牌换承诺重启增长
- **问题**: "里程"承诺偏好停滞。
- **方法论的使用**: 调查追踪后, 从里程示范换为"消费者证言"新承诺。
- **结论**: 承诺需随数据迭代, 不僵化。
- **结果**: 重启品牌偏好增长。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 写好的广告只讲品牌调性, 没人知道"买它能得到什么"。
2. 要在几个候选卖点里挑一个主承诺。
3. 想用调查/分版测出哪个承诺有效。

### 语言信号 (用户的话里出现这些就应激活)

- "广告写好了但没卖点 / 怎么写标题"
- "承诺什么利益 / 卖点是什么"
- "用调查选主诉求"

### 与相邻 skill 的区分

- 与 `headline-promise-benefit` 的区别: 本 skill 定"必须承诺利益"的总原则与选承诺方法; headline 是"把承诺写进标题"的具体技巧。
- 与 `claim-really-good` 的区别: claim-really-good 是"不必宣称比对手好, 只说确实好"; 本 skill 是更上游的"先要有承诺"。

## E — 可执行步骤 (Execution)

1. **列出 3–5 个候选承诺(利益点)**
   - 完成标准: 每条都说清"消费者得到什么具体好处"。
2. **用调查或分版测试选承诺**
   - 完成标准: 让消费者按重要性+独特性评级, 或 split-run 比真实回应。
3. **挑"既有说服力又独特"者为主承诺**
   - 完成标准: 避开对手已占的承诺, 或找到新角度。
4. **把承诺贯穿到标题与正文**
   - 完成标准: 标题必含承诺(见 headline-promise-benefit), 正文展开证明。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 非商业沟通(内部通知、友情提醒等)。

### 作者在书中警告的失败模式

- 不承诺利益: 多数广告的通病, 等于无灵魂无销售力。
- 把调查当教条: 用调查证明自己早有的结论(路灯杆), 而非发现真相。

### 作者的盲点 / 时代局限

- "无承诺=无销售力"在强理性品类更成立; 纯情感/身份品类承诺可更隐晦, 但内核(给个买的理由)不变。

### 容易混淆的邻近方法论

- 勿与"自夸"混: 承诺是"你得到什么", 自夸是"我多厉害", 后者不是承诺。
