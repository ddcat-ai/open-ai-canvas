## I — 方法论骨架 (Interpretation)

奥格威对"定位"的朴素定义只有一句话: **这个产品是做什么用的, 给谁用。** 它比"心智占位"那套理论更落地。

- 必须是"用途 + 人群"两个维度同时回答, 缺一就不算定位。
- 一个好定位能管几十年, 不轻易改(多芬 25 年不变)。
- 定位可以是一把手缺点转成个性(安飞士"租车第二, 只能更努力")。

定位不清, 后面的所有文案都是在赌。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 多芬香皂
- **问题**: 香皂是红海品类。
- **方法论的使用**: 定位为"帮助女人滋润干燥皮肤的沐浴皂", 配测试胜出的承诺。
- **结论**: 不堆功能, 锁定人群 + 用途。
- **结果**: 定位 25 年后依然奏效。

### 案例 2: 安飞士"你只是第二名"
- **问题**: 租车业老二, 打不过赫兹。
- **方法论的使用**: 把弱点(市场份额第二)转成个性定位"除了更努力别无他法"。
- **结论**: 残忍但真实, 反而立住形象。
- **结果**: 成为广告史最强之一, 反将赫兹一军。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 新品上市或老品转型, 要定"我们到底是给谁、解决什么"。
2. 写 slogan / 品牌故事前, 人群和用途还模糊。
3. 觉得和竞品"差不多", 说不清差异。

### 语言信号 (用户的话里出现这些就应激活)

- "产品怎么定位 / slogan 怎么写"
- "目标人群是谁 / 给谁用"
- "和竞品有什么区别 / 差异化"

### 与相邻 skill 的区分

- 与 `do-your-homework` 的区别: 做功课是收集情报; 本 skill 是把情报收敛成一句"用途+人群"的结论。
- 与 `brand-image-consistency` 的区别: 定位定"对谁说、干什么"; 品牌形象定"以什么个性说", 定位决定形象。

## E — 可执行步骤 (Execution)

1. **写出用途句**
   - 完成标准: 一句话说清产品解决什么具体问题/满足什么需求。
2. **写出人群句**
   - 完成标准: 锁定具体人群(带场景/特征, 而非"所有人")。
3. **检查是否可长期成立**
   - 完成标准: 该定位是否 10 年后仍合理; 若随风口摇摆则不稳固。
4. **把"用途 + 人群"压成一句定位陈述**
   - 完成标准: 如"帮X解决Y的Z", 供后续文案与形象沿用。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 定位已明确, 用户只缺执行文案(转 make-a-promise / headline-promise-benefit)。
- 与品牌无关的纯技术/内部文档。

### 作者在书中警告的失败模式

- 定位贪多: 想"给所有人用", 结果谁都记不住。
- 频繁改定位: 换代理/换负责人就改, 形象积累归零。

### 作者的盲点 / 时代局限

- 奥格威定位偏"大众媒介单一信息"; 今天细分社群可多定位并存, 但"用途+人群"内核不变。

### 容易混淆的邻近方法论

- 勿与 `differentiate-commodities` 混: 后者专治"看似无差异的工业品"; 本 skill 是通用定位起点。
