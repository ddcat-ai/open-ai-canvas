## I — 方法论骨架 (Interpretation)

1. **核心原理**：人在看到自己的"痛点被精准描述"时，会产生"这个人懂我"的信任感，进而对"破解方法"产生强烈兴趣。
2. **两步公式**：具体苦恼 + 完美结局/破解方法。
3. **第一步——指出具体苦恼**：关键是"具体"。不是泛泛说"你有没有理财困扰"，而是说"每个月工资刚发就花光了"——要让读者一眼认出"这就是我"。苦恼描述越具体，读者越觉得"说到我心坎上了"。
4. **第二步——给出完美结局或破解方法**：让读者看到"痛点可以解决"的希望。可以是"完美结局"（描述解决后的状态），也可以是"破解方法"（给出具体路径）。
5. **加分项——引用权威专家**：如果破解方法来自权威来源（如"央视理财专家""哈佛研究"），可信度大幅提升。
6. **关键点**：苦恼必须"具体到可识别"，笼统的痛点描述无法触发"被理解"的感觉。

## A1 — 书中的应用 (Past Application)

### 案例 1: 理财课程——"存不下钱？央视理财专家3个建议"
- **问题**: 理财课程广告众多，"轻松理财""财富自由"等泛泛标题无法打动目标用户。
- **方法论的使用**:
  - 具体苦恼："存不下钱"——精准描述了月光族的痛点，每个存不下钱的人都会在心里说"对，就是我"。
  - 破解方法："3个建议"——简单、具体、可执行。
  - 权威加分："央视理财专家"——权威背书让方法可信。
- **结论**: 标题同时完成了"我懂你的苦"+"我有靠谱的解法"，两步精准命中。
- **结果**: 月光族读者被精准触达，对课程产生"也许真能帮我"的期待。

### 案例 2: 读书课程——"拖延症晚期也能1年读完100本书"
- **问题**: 读书类课程的目标用户往往是"想读书但读不进去"的人，普通标题无法打动他们。
- **方法论的使用**:
  - 具体苦恼："拖延症晚期"——用夸张但可识别的描述，精准命中"买了书不看"的人群。
  - 完美结局："1年读完100本书"——给出了一个令人向往的结果。
- **结论**: 标题同时说出了"你的问题我了解"和"这个问题可以解决"，像一颗对症的药。
- **结果**: 有阅读意愿但缺乏执行力的人群被精准吸引，因为标题承诺了"连你这样的人都能做到"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 知识付费/在线课程推广，需要精准触达"有痛点的学习者"。
2. 工具类/效率类产品推广，需要让用户意识到"我有这个问题"且"这个产品能解决"。
3. 健康类/生活服务类推广，需要用"痛点共鸣"来吸引目标人群。
4. 任何"解决特定问题"的产品文案，需要一个让目标用户"对号入座"的标题。

### 语言信号
- "怎么写出戳中痛点的标题"
- "文案标题怎么引起共鸣"
- "怎么让读者觉得'说的就是我'"
- "解决xx问题的文案怎么写"
- "知识付费标题怎么写"

### 与相邻 skill 的区分
- 与 `news-editorial-title` 的区别: 那个用"新闻感"吸引点击，本 skill 用"痛点共鸣"吸引点击。前者适合有话题性的产品，后者适合解决具体问题的产品。
- 与 `friend-chat-title` 的区别: 那个追求"亲切对话感"，本 skill 追求"精准命中痛点"。两者可以结合使用（用口语化的方式指出痛点）。
- 与 `justified-consumption` 的区别: 那个是处理"购买负罪感"的策略，本 skill 是处理"标题吸引力"的策略，位于文案漏斗的不同环节。

## E — 可执行步骤 (Execution)

1. **列出目标用户的所有痛点/苦恼**
   - 完成标准: 写出至少5条目标用户可能有的苦恼，越具体越好（不是"缺钱"，而是"每个月工资刚发就花光了"）。
2. **选出最普遍、最有共鸣的那一条具体苦恼**
   - 完成标准: 选出的苦恼能让目标用户一眼认出"这就是我"，而不是"好像有点相关"。
3. **用一句话精准描述这个具体苦恼**
   - 完成标准: 苦恼描述具体到"可识别"——读者看到后会在心里说"对，就是这个情况"。
4. **给出完美结局或破解方法**
   - 完成标准: 用一句话描述"解决后的美好状态"或"具体可行的解决路径"，让读者看到希望。
5. **（加分项）引用权威来源**
   - 完成标准: 找到一个权威专家/机构/研究作为方法来源，增强可信度。如果没有真实的权威来源，不要编造。
6. **组合成完整标题并检验**
   - 完成标准: 把"苦恼+结局/方法"组合成一条通顺的标题，读一遍确认：目标用户看到后会不会觉得"说的就是我，而且有救了"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 品牌形象广告，目标是传递调性而非解决问题。
- 娱乐类/兴趣类内容（如"有趣的历史故事"），没有明确痛点可切。
- 产品本身解决不了标题中提出的痛点（标题党），会严重损害信任。
- 高端奢侈品，用户购买动机是"向往"而非"解决痛点"。

### 作者在书中警告的失败模式
- 痛点太笼统："你有没有生活困扰？"这种泛泛的描述无法触发共鸣。
- 破解方法不可信："一个月变成百万富翁"这种夸张承诺会引发怀疑。
- 痛点与产品脱节：描述的痛点产品根本解决不了，读者觉得被欺骗。
- 权威来源编造：虚假引用专家会被查证，一旦曝光，品牌信誉全毁。

### 作者的盲点 / 时代局限
- 2017年知识付费赛道火热，"痛点+课程"模式被大量使用，到2026年用户可能已产生免疫力。
- 短视频标题的"痛点钩子"逻辑与图文时代不同，需要更短的痛点描述（3-5秒内完成识别）。
- 过度聚焦"痛点"可能导致品牌形象偏负面，某些产品更适合"向往感"而非"解决痛苦"的叙事角度。
- 不同人群对"痛点"的表达偏好不同（如Z世代偏好自嘲式表达"摆烂""社恐"），需要调整语言风格。
