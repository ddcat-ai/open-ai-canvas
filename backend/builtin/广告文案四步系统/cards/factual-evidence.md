## I — 方法论骨架 (Interpretation)

事实证明的核心逻辑：用看得见、摸得着的事实替代空洞的自夸。

**直接证明路线（两步法）：**
1.  **收集精确数据**: 挖掘产品的可量化性能指标——不是"很好"，而是"高出行业平均37%"。
2.  **链接到熟悉事物**: 精确数据本身没有意义，只有链接到消费者熟悉的事物才有感知力。不是"噪音低于30分贝"，而是"比翻书的声音还轻"。

**间接证明路线（实验法）：**
3.  **设计视觉实验**: 当性能不便量化时，设计一个消费者能直接看到结果的实验。
4.  **创造极端对比**: 实验的关键不是展示产品多好，而是展示"用了"和"没用"之间的巨大反差。

常见实验类型：燃烧（材质纯度）、浸泡（防水/溶解性）、冷冻（耐寒性）、化学试剂（成分真实性）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 奥格威的劳斯莱斯广告
- **问题**: 如何用一句话证明劳斯莱车的安静程度？
- **方法论的使用**: 第一步收集数据——车速60英里/小时时车内最大噪音来自电子钟；第二步链接到熟悉事物——消费者对"电子钟的滴答声"有直观感知。
- **结论**: 不是说"非常安静"，而是用一个消费者能想象的具体声音来定义"安静"的程度。
- **结果**: 这条广告被公认为史上最伟大的汽车广告之一。

### 案例 2: 手工洁面皂泡沫实验
- **问题**: 手工洁面皂主打"泡沫丰富"，但"丰富"是主观描述，消费者无感。
- **方法论的使用**: 设计实验——将手工洁面皂和市售工业洁面皂分别搓揉等量时间，对比泡沫体积。手工皂的泡沫是对方的3倍高。
- **结论**: 视觉对比让"泡沫丰富"从抽象形容词变成可感知的具体事实。
- **结果**: 消费者看到对比图后对产品性能有了直观认知，转化率提升。

### 案例 3: 床垫鸡蛋实验
- **问题**: 床垫"贴合人体、分散压力"是技术语言，消费者无法理解。
- **方法论的使用**: 在床垫上放鸡蛋，人躺上去后鸡蛋不碎。这个极端实验将"分散压力"这个抽象概念转化为"连鸡蛋都不会碎"的直观画面。
- **结论**: 用脆弱的鸡蛋作为"压力传感器"，比任何数据都直观。
- **结果**: 实验视频在社交媒体上获得大量传播，远超常规产品介绍。

### 案例 4: 纯棉卫生巾燃烧实验
- **问题**: 消费者怀疑卫生巾材质不是纯棉。
- **方法论的使用**: 同时燃烧纯棉卫生巾和化纤卫生巾——纯棉燃烧后成灰（一吹即散），化纤燃烧后结成硬块（有刺鼻气味）。
- **结论**: 燃烧实验直接暴露材质差异，比任何成分表都有说服力。
- **结果**: 消费者通过实验亲眼看到材质区别，信任度大幅提升。

### 案例 5: 牙膏菌斑指示剂实验
- **问题**: 牙膏"深层清洁"难以被消费者感知。
- **方法论的使用**: 刷牙前用菌斑指示剂染色（牙菌斑显红色），刷牙后再检测——红色大幅减少。前后对比一目了然。
- **结论**: 用指示剂将"看不见的清洁效果"变成"看得见的颜色变化"。
- **结果**: 实验前后对比图成为产品最有力的卖点证明。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 产品有明确的性能参数，但不知道怎么让消费者"感受到"数据的分量。
2. 消费者对产品功效半信半疑，需要用直观事实打消疑虑。
3. 产品优势是"材质好""成分纯"等消费者无法直接判断的维度，需要通过实验间接证明。
4. 竞品也在自夸，需要用客观数据和实验拉开差距。
5. 准备拍摄产品演示视频或制作对比图。

### 语言信号
- "产品性能数据很好，但怎么让消费者感受到？"
- "怎么证明我们的产品真的更好？"
- "需要做一个产品对比实验"
- "怎么把技术参数翻译成消费者能懂的语言？"
- "想做一个直观的产品演示"
- "怎么让消费者亲眼看到效果？"

### 与相邻 skill 的区分
- 与 `authority-transfer` 的区别: authority-transfer 借第三方权威的认可来证明，factual-evidence 直接用产品自身的性能数据和实验来证明。前者是"谁说的"，后者是"事实是什么"。
- 与 `price-anchor` 的区别: price-anchor 用价格对比来凸显性价比，factual-evidence 用性能对比来凸显产品实力。前者针对价格认知，后者针对产品认知。

## E — 可执行步骤 (Execution)

1.  **判断证明路线**
    - 完成标准: 确认产品的性能优势是否可量化。如果可以（如噪音值、重量、强度），走直接证明路线；如果不方便量化（如材质纯度、清洁深度），走间接证明（实验）路线。
2.  **直接证明——收集精确数据**
    - 完成标准: 写出产品性能的具体数字，不能是"更好""更强"这种模糊描述，必须是"高出37%""只有2.3克"这样的精确数据。
3.  **直接证明——链接到熟悉事物**
    - 完成标准: 为每个精确数据找到消费者日常生活中的对应物。公式："[数据]，相当于[熟悉事物]"。如"30分贝，比翻书的声音还轻"。
4.  **间接证明——设计实验**
    - 完成标准: 设计一个消费者能直接看到结果的实验。实验必须满足：(1) 条件公平（同量、同时、同环境）；(2) 结果直观（肉眼可判断）；(3) 对比强烈（实验组和对照组差异明显）。
5.  **拍摄/记录实验过程**
    - 完成标准: 保留实验全过程，展示"实验前—实验中—实验后"三个阶段，增强可信度。
6.  **最终检查**
    - 完成标准: 确认：(1) 数据精确且来源可靠；(2) 熟悉事物的类比恰当不夸张；(3) 实验条件公平透明；(4) 消费者看完能直接得出"这产品确实好"的结论。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 产品性能没有明显优势时（数据对比反而暴露短板）。
- 产品优势在于情感价值而非功能性能时（如礼品、纪念品）。
- 实验设计可能产生安全隐患时（涉及明火、化学品等，需专业人员操作）。
- 性能差距太小，数据和实验都无法制造足够强烈的对比时。

### 作者在书中警告的失败模式
- **数据不精确**: 用"大幅提升""显著改善"等模糊词，消费者不信。必须用精确数字。
- **类比不恰当**: 链接到消费者不熟悉的事物。"噪音低于30分贝"链接到"比图书馆还安静"可以，链接到"比消音室高3分贝"就不行。
- **实验条件不公平**: 对比实验中给竞品设置不利条件（如少用材料、缩短时间），被识破后信誉全毁。
- **只展示数据不链接**: 贴出一堆技术参数表格，没有转化为消费者能理解的语言。

### 作者的盲点 / 时代局限
- 书中未讨论视频/短视频平台的实验展示策略——在抖音/快手上，实验的节奏、悬念设计和BGM配合都会影响传播效果。
- 未涉及"用户参与实验"的互动策略——让消费者自己动手实验，比观看实验更有说服力。
- 未讨论第三方检测报告的整合使用——在跨境电商、天猫国际等平台，第三方检测数据已成为标配。
