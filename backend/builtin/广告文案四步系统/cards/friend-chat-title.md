## I — 方法论骨架 (Interpretation)

1. **核心原理**：人在社交场景中天然会对"朋友发来的消息"产生注意和信任。把标题写成朋友聊天的样子，能突破广告的"心理防线"。
2. **三步公式**："你" + 口语词 + 惊叹词。
3. **第一步——加入"你"**：用"你"直接与读者对话，让标题从"一对多广播"变成"一对一私聊"。读者会觉得"这是在跟我说"。
4. **第二步——书面语改口语词**：把正式、官方的表达替换成日常说话的用词。如"购买"改成"买"，"优惠"改成"便宜"，"体验"改成"试试"。越像嘴上说的话，越亲切。
5. **第三步——加入惊叹词**：用"太""最""竟然""真""居然"等词传递强烈情绪，让标题有"朋友兴奋地跟你说一件事"的感觉。
6. **关键点**：三个元素叠加后，标题应该读起来像一条微信消息——"你一定要看这个！""你绝对想不到！"

## A1 — 书中的应用 (Past Application)

### 案例 1: 文案课程——"赚了1173万元，愿意手把手教你"
- **问题**: 文案课程市场竞争激烈，"专业文案课程"这类正式标题难以打动人。
- **方法论的使用**:
  - "你"：隐含在"教你"中（"我教你"=朋友间的对话）
  - 口语词："赚了""手把手教你"（而不是"获得收益""系统化教学"）
  - 惊叹词：具体数字"1173万元"本身就有震撼效果
- **结论**: 标题像朋友在跟你说"我赚了大钱，教你怎么做"，而不是"欢迎报名课程"。
- **结果**: 亲切感和利益承诺双重驱动，点击率和转化率显著高于正式课程标题。

### 案例 2: 眼霜测评——"25岁前看到最最靠谱的"
- **问题**: 护肤品测评铺天盖地，"专业眼霜评测报告"这类标题缺乏个人温度。
- **方法论的使用**:
  - "你"：隐含在"25岁前"（对特定年龄段读者的直接对话）
  - 口语词："最最靠谱的"（而不是"最具性价比的"）
  - 惊叹词："最最"（重复使用表达强烈情绪）
- **结论**: 标题像闺蜜在跟你说"我用过最好的眼霜就是这个"。
- **结果**: 年轻女性读者感到"这是过来人的真心话"，信任感和好奇心同时被激发。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 写朋友圈推广文案，需要让标题像"朋友在说话"而不是"商家在推销"。
2. 社群运营中推送产品信息，需要用亲切语气降低群友的排斥心理。
3. 个人IP内容创作，需要建立"知心朋友"人设而非"权威专家"人设。
4. 微信公众号标题优化，需要提升打开率。

### 与相邻 skill 的区分
- 与 `news-editorial-title` 的区别: 那个走"权威新闻"路线，本 skill 走"亲切对话"路线。两者风格完全相反，选择取决于产品调性和发布渠道。
- 与 `practical-tip-title` 的区别: 那个以"痛点+解决方案"为核心逻辑；本 skill 以"朋友对话感"为核心逻辑，不一定要点出痛点。
- 与 `justified-consumption` 的区别: 那个是处理"购买负罪感"的策略，本 skill 是处理"标题吸引力"的策略，两者在不同阶段使用。

## E — 可执行步骤 (Execution)

1. **写出产品/内容的正式标题作为底稿**
   - 完成标准: 用书面语写出一个完整但正式的标题，确保信息传达准确。
2. **加入"你"，实现一对一对话感**
   - 完成标准: 标题中出现"你"字，或者有明确的"我在跟你说话"的语气（如"教你""给你""帮你"）。
3. **逐词检查，把书面语替换成口语词**
   - 完成标准: 读出标题，如果"不会在聊天中这样说"的词，就替换成口语表达。
4. **加入惊叹词，注入情绪**
   - 完成标准: 标题中至少包含一个表达强烈情绪的词（太/最/真/竟然/居然/绝对/一定要）。
5. **朗读检验，确认"像朋友说话"**
   - 完成标准: 大声朗读标题，如果读起来像"发给朋友的一条微信消息"，就通过了。如果读起来像"广告语"或"新闻标题"，回到步骤3继续调整。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 高端奢侈品/企业品牌广告，口语化会拉低品牌调性。
- 需要建立专业权威的场景（如医疗、金融、法律），"朋友聊天"的语气可能削弱可信度。
- 正式公关稿件、新闻稿，格式和语调要求完全不同。
- 产品受众是中老年群体且品牌定位偏稳重时，过于口语化可能显得不严肃。

### 作者在书中警告的失败模式
- 口语化过度变成"轻浮"，读者觉得不专业、不靠谱。
- 惊叹词堆砌，标题看起来像"营销号"，反而引发反感。
- "你"用得生硬，比如"你应该购买这款产品"，这不是对话而是命令。

### 作者的盲点 / 时代局限
- 2017年的"朋友圈风格"在2026年可能已经过时，用户对"假亲切"的识别能力大幅提升。
- 不同平台的口语风格差异很大（抖音vs小红书vs微信），书中未做平台区分。
- Z世代和千禧一代的"口语化"标准不同，需要根据目标人群调整。
- AI 生成内容的普及让"像人说话"的辨别门槛更高，读者可能更难被"亲切感"打动。
