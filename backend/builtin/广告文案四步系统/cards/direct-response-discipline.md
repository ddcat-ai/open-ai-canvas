## I — 方法论骨架 (Interpretation)

直邮/直接反应广告可对**每一个变量**(价格、付款方式、奖励、格式)做精确对照测试, 销售效果可精确到一美元。

- **分版测试(split-run)**: 同一媒体投两个版本, 在真实广告环境中比稿, 胜者留存为"控制组"继续测更优者。
- 原则: **一次只测一个因素**, 测最可能的杠杆。
- 直邮是"什么技巧有效"的最干净实验室, 所有广告人都该偷师。

把"什么有效"从争论变成可证伪的实验。

## A1 — 书中的应用 (Past Application)

### 案例 1: 莫斯科奥运纪念币
- **问题**: 卖整套纪念币, 怎么写邮件。
- **方法论的使用**: 做对照测试——只卖银币的邮件 vs 卖整套的邮件。
- **结论**: 只卖银币的邮件反而带来更多整套订单(反直觉)。
- **结果**: 测试发现经验预判之外的最优解。

### 案例 2: 赛斯纳"活信鸽"直邮
- **问题**: 60 万美元公务机如何卖。
- **方法论的使用**: 寄活信鸽邀免费试乘, 极端创意直邮。
- **结论**: 非常规但有效。
- **结果**: 至少售出一架 60 万美元飞机。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 有两个标题/承诺/落地页, 不知道哪个好。
2. 想建立"用数据而非争论"的优化文化。
3. 做电商/获客, 需要提升转化率。

### 语言信号 (用户的话里出现这些就应激活)

- "两个版本哪个好 / A/B测试"
- "怎么测广告效果 / 分版测试"
- "转化率提不上去"

### 与相邻 skill 的区分

- 与 `make-a-promise` 的区别: make-a-promise 决定"承诺什么"; 本 skill 是用分版测试"验证哪个承诺更好"。
- 与 `repeat-winning-ads` 的区别: 本 skill 是"怎么选出赢家"; repeat 是"赢家选出后怎么用"。

## E — 可执行步骤 (Execution)

1. **选定要测的单因素**
   - 完成标准: 一次只改一个变量(如只改标题承诺), 其余一致。
2. **做分版测试**
   - 完成标准: 同媒体/同流量切两半, 真实环境中比稿。
3. **用销售/转化而非喜好判胜负**
   - 完成标准: 以订单/申请/转化数定胜者, 不以内部投票。
4. **胜者留作控制组继续迭代**
   - 完成标准: 把胜出版本当基准, 持续测更优变体, 而非一次性。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯品牌曝光广告无转化链路, 无法做变量归因。
- 样本量太小(测试结果不可信)。

### 作者在书中警告的失败模式

- 一次改多个因素, 赢了也不知道赢在哪。
- 用"我觉得好看"代替"数据说谁赢"。

### 作者的盲点 / 时代局限

- 书中直邮依赖人口统计筛选收件人, 今天需注意隐私合规; 但 split-run 思想在数字 A/B 中完全通用。

### 容易混淆的邻近方法论

- 勿与"用户调研问喜好"混: 调研是"说", 分版测试是"真金白银的行为", 后者更可信。
