## I — 方法论骨架 (Interpretation)

做任何广告之前, 有三门非 negotiable 的功课, 顺序固定:

1. **研究产品** — 读尽关于它的一切资料、规格、工艺、用法、历史。奥格威接劳斯莱斯时花 3 周读资料, 才挖出"时速 60 英里时最大噪声来自电动机械钟"这种能当标题的事实。
2. **研究竞品** — 弄清对手为同类产品做了什么广告、成了还是败了。你才知道该避开什么、能占什么空位。
3. **研究消费者** — 他们怎么看这类产品, 最看重哪个属性, 什么承诺能让他们掏钱。

懒于做功课偶尔能靠"耍滑头"碰巧成功, 但那是赌博, 不是方法。没有功课, 文案只能写空话。

## A1 — 书中的应用 (Past Application)

### 案例 1: 劳斯莱斯"60 英里噪声"
- **问题**: 接手劳斯莱斯广告, 客户是顶级车, 普通文案写不出差异。
- **方法论的使用**: 花 3 周通读车辆资料, 偶然发现"时速 60 英里最大噪声来自电动机械钟"这一工程事实。
- **结论**: 把这个事实做成标题 + 607 词事实型长文案。
- **结果**: 只花 2.5 万美元、4 份媒体, 成为史上最著名汽车广告之一。

### 案例 2: 壳牌汽油终结 7 年下滑
- **问题**: 壳牌连续 7 年市场份额下降。
- **方法论的使用**: 读客户提供的产品资料, 发现"含高辛烷值烃类能增加行驶里程"这一事实, 据此做广告。
- **结论**: 用"里程"事实替代空泛宣传。
- **结果**: 终结 7 年下滑; 后调查追踪到偏好停滞, 又换成"消费者证言"重启增长。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要写一条广告/推文/卖点文案, 但对自己产品只有模糊印象。
2. 做出来的东西空泛、像模板、没有具体事实支撑。
3. 新品上市或接手陌生品类, 不知道从哪下手。

### 语言信号 (用户的话里出现这些就应激活)

- "帮我写个广告 / 推文 / 产品介绍"
- "这个产品怎么打 / 怎么卖 / 卖点是什么"
- "新品要上市了, 文案你来"

### 与相邻 skill 的区分

- 与 `make-product-hero` 的区别: 本 skill 是"动手前的三步研究动作"; make-product-hero 是"写出成品时让产品当主角"的执笔原则, 功课是它前提。
- 与 `positioning-use-and-audience` 的区别: 定位回答"给谁、干什么用"; 做功课是产出定位之前必须先做的情报收集。

## E — 可执行步骤 (Execution)

1. **研究产品 — 列出可测量的事实**
   - 完成标准: 产出至少 5 条具体事实(规格/工艺/用法/数据/历史), 而非形容词。
2. **研究竞品 — 画出诉求地图**
   - 完成标准: 列出 3 个主要竞品各自承诺了什么、哪条赛道已拥挤、哪条还空着。
3. **研究消费者 — 找到决策属性**
   - 完成标准: 明确目标人群最看重的 1–3 个属性, 以及能让他们行动的承诺。
4. **基于三步产出 brief**
   - 完成标准: 一份含"事实清单 + 竞品空位 + 核心承诺"的一页 brief, 再进入写作。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只想要文案润色、视觉调整, 功课已做完。
- 非营销场景(写代码、写论文、做财务报表)。

### 作者在书中警告的失败模式

- 跳过功课直接写"高品质""领先"类空话, 这类广告无销售力。
- 只研究自己产品, 不研究竞品与消费者, 导致诉求撞车或自说自话。

### 作者的盲点 / 时代局限

- 书中功课依赖纸质资料/人工调查; 今天有搜索、社媒监听、问卷工具, 可更快完成, 但"先研究再写"的纪律不变。
- 未涉及数据隐私合规(今天收集消费者数据需注意个保法/GDPR)。

### 容易混淆的邻近方法论

- 容易和"头脑风暴创意"混淆: 创意应在功课填满脑子之后(见 big-idea-five-questions)。
