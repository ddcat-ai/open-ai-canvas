# 团队空间

团队是内容归属和付款边界，不是另一套创作工具。个人、公司和小组使用同一个自由画布、创作页和素材库。公司与小组的内容和账户彼此独立。

| 操作 | 使用的实现 | 空间差异 |
| --- | --- | --- |
| 编辑画布 | 自由画布的节点、连线、operations、revision 和实时连接 | 只读取当前空间的画布；请求先验证成员身份 |
| 生成文本 | 创作页或画布提交标准任务，Worker 调用系统模型，文本事件走原 SSE | 按实际成员的模型权限报价，确认后仅冻结该成员的团队额度，产物留在当前空间 |
| 管理素材 | 素材列表、分类、归档、版本及资源文件 | 成员共享当前空间的内容；贡献者或所有者可归档，只有所有者可清理未被使用的归档素材 |
| 从个人库发布 | 显式选择源素材和目标空间，生成独立版本 | 发布单负责跨空间复制及幂等；离队或删除个人原件不会撤回团队副本 |

团队管理保留定向邀请、成员关系和钱包。小组成员必须同时属于公司；离队回收可用额度，未结清的历史费用仍属于原成员账户。空间切换不改变登录账号，本地作品缓存按账号和空间隔离。未开放的 Agent、公开分享和非文本模型生成不回退到个人空间。

使用说明见[功能清单](../content/docs/overview/features.mdx)，接口见[HTTP API](../content/docs/backend/http-api.mdx)，旧内容的无损升级与回退条件见[后端数据库](../content/docs/backend/backend-database.mdx)。
