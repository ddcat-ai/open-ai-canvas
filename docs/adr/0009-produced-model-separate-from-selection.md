# ADR-0009: 媒体产出模型与选用模型分开记录

状态：已接受。日期：2026-09-22。

画布节点上的模型字段同时承担两件事：提示词面板下一次要用的选用模型，以及这份图片、视频或音频实际由哪个模型写成。改下拉并不重新生成时，后一件事会被覆盖，过一段时间无法从节点上认出资产的产出模型。

决定：产出模型在生成成功并写入节点时冻结，选用模型继续随下拉变化。角标、节点详情和版本对比只展示产出模型；没有产出模型时留空。展示名按当前模型目录解析，目录中没有则显示模型 ID。本地加工、上传和本次改动之前的旧节点不回填。

## 考虑过的方案

继续复用同一个模型字段。改动更少，但选用模型一变，产出事实就丢了。否决。
