# 图片用量计费

`image_usage` 是按渠道模型价格档启用的通用计费方式。调用协议负责请求和结果映射；计价模块负责输入图费用、逐张输出价格、积分预留和最终结算。按像素计费需要实际图片宽高，按统一张数计费可配置唯一的不限像素输出档位。

## 火山方舟官方配置

以火山方舟按量付费的原生接口为基准：

- 协议：`Volcengine Ark Seedream Images`，插件 `volcengine-ark-seedream` 版本 2.1.0。
- 接口：`POST https://ark.cn-beijing.volces.com/api/v3/images/generations`。
- 模型：`doubao-seedream-5-5-261028`。
- 先配置用户分组的 CNY 积分兑换比例；模型计价货币选 CNY，在价格档选择“图片用量”，可点击“填入 Seedream 5.5 官方公开价”。

| 项目 | 官方公开单价 |
| --- | --- |
| 输入图 | 0.05 元/张，无首张免费 |
| 输出图总像素不超过 2.61M | 0.13 元/张 |
| 输出图总像素超过 2.61M 且不超过 4.63M | 0.23 元/张 |

单次调用费用为输入图费用加各张成功输出图的档位费用。规则使用每张图的实际宽 × 高；底图属于输出图。像素计费档位与接口尺寸校验分别配置：普通生成输出像素允许 921600–4624220，输入图允许至 6000×6000。

依据：[官方价格](https://console.volcengine.com/ark/region:cn-beijing/docs/model-pricing)、[官方图片 API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)。Agent Plan 的订阅抵扣须按其独立规则配置。

## 价格合同

管理端价格档增加 `imagePricing`：

```json
{
  "billingMode": "image_usage",
  "imagePricing": {
    "inputPriceMicrocredits": 50000,
    "freeInputImages": 0,
    "outputTiers": [
      { "maxPixels": 2610000, "unitPriceMicrocredits": 130000 },
      { "maxPixels": 4630000, "unitPriceMicrocredits": 230000 }
    ]
  }
}
```

在模型计价货币为 CNY 时，配置中的整数为百万分之一元；进入订单前按用户分组兑换为微积分。`maxPixels` 为含边界上限，必须递增；0 仅可用于最后一个不限像素档。字段必须明确提交，空价格不等于免费。

成本配置为 `costPricing.imagePricing`，使用内部微积分单位；它与售价独立，不叠加销售倍率，不能从用户报价或目录响应读取。按成本批量加价的标量接口不处理图片用量档，需在模型编辑中调整输入价与各输出档价。保存和复用价格模板保留图片售价、成本配置。

## 报价、预留与结算

直连系统图片模型、逻辑模型和 Agent 共用后端订单计算。报价返回 `billingMode=image_usage`、`estimated=true` 和 `imageUsage={inputImages,maxOutputImages}`。`amountMicrocredits` 表示按最大输出数量及最高适用单价计算的预留上限，界面显示“最多冻结”。该预留策略由项目实现。

订单保存图片规则、输入数量和最大输出数量快照。响应中优先读取 `usage.input_images`、`usage.generated_images` 和 `data[].size`，与实际输入和成功输出清单核对；没有输入计数时使用后端提交的图片数量，没有像素尺寸时尝试读取原始图片文件。无法确定用量或存在冲突时进入待核对。

用量在素材下载前写入订单。结算只读取快照和实际用量，累加后统一应用倍率及舍入，并在同一事务内扣减预留、释放差额、写入账本。重复记录同一用量及重复结算均幂等；实际用量或费用超过预留和 Agent 授权上限时拒绝自动结算。

请求未发出时可释放预留；上游已接收后的超时、未知失败和下载失败不能推断为免费。官方未明确的失败输入费用需要账单核验。恢复素材不会重新生成图片，也不会重新创建计费订单。

## 普通生成与图层拆分

普通生成每次输出一张，最多 10 张参考图，不发送组图请求。批量生成通过独立任务完成，每次都计算输入费用。默认预设包含 1K、1.5K、2K，低档尺寸保持原值。

图层拆分开启 `layerDecomposition`，只输入一张图片；`maxImages` 为 2–100，含底图，默认 30。`layerSize` 可选 1K、1.5K、2K、auto。`textRecognition` 控制文字识别，`outputFormat` 控制输出格式；普通生成还可选 `background`。拆层时不发送背景参数。

宿主在任务结果和恢复信息中保留每张图的 `size`、`z_index`、`bounding_box`、名称及 OCR 等元数据。这里提供参数调用、用量计费及数据保留；图层编辑工作台的交互属于独立功能。

## 验收边界

自动测试覆盖像素边界、混合档位、显式免费、缺失字段、报价快照、独立成本、下载前用量落库、差额退款、幂等结算、超出授权、官方插件请求映射和 Schema 105 升级。

生产启用前需安装或升级官方 Seedream 插件，并完成数据库迁移。真实官方调用及账单核验需使用部署环境凭据，特别核实像素边界、失败输入费和拆层输出数量；本地模拟响应与单元测试不代表官方账单验收。
