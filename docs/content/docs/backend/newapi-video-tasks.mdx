# NewAPI Video Tasks

该协议是 NewAPI Video Generations Channel 2 的查询路径变体，供小力孩等网关使用。不要把现有 `newapi-channel-2` 渠道改到这条协议，除非确认其查询接口确实是 `/v1/video/tasks/{id}`。

## 请求流程

声明式插件使用以下接口：

- 创建：`POST /v1/video/generations`
- 查询：`GET /v1/video/tasks/{taskId}`

创建响应的任务 ID 解析顺序与 Channel 2 相同。查询成功状态包括 `succeeded`、`completed` 和 `SUCCESS`，视频地址优先读取 `data` 数组中的 `url`（如 `data.0.url`），并兼容 Channel 2 已支持的嵌套结果字段。

## 兼容边界

该协议不能与 `newapi-channel-2` 互换。查询打到错误路径时，上游可能已经扣费，但宿主只会看到 `404` /「模型或模型接口不存在」。已提交的任务应继续查询原 `provider_request_id`，不要重新创建。
