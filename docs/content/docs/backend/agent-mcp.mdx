# Agent MCP 连接与市场

Agent 可以通过远端 MCP 服务查询或操作外部系统。用户在「Agent 设置 → 工具与连接」管理个人连接；管理员在「管理后台 → MCP 管理」提供平台连接和市场条目。配置保存在服务端，后续会话可以使用已启用且已授权的工具。

当前支持 Streamable HTTP 和 SSE 两种远端连接方式。不支持在影策服务器上执行用户填写的 `npx`、shell 命令或上传的本地 MCP 程序，也没有自动完成第三方 OAuth 登录的界面。需要 OAuth 的服务应先取得适用凭据，或部署支持当前认证方式的适配服务。

## 连接和市场的区别

| 类型     | 谁配置凭据                                 | 谁可以使用和维护                                           |
| -------- | ------------------------------------------ | ---------------------------------------------------------- |
| 个人连接 | 当前用户                                   | 当前用户使用、编辑、检测和移除                             |
| 平台连接 | 平台管理员                                 | 启用后供平台用户使用；普通用户只读查看，不能修改或读取凭据 |
| 市场条目 | 不保存安装后的凭据，只定义地址、说明和参数 | 管理员发布；用户安装后形成独立的个人连接                   |

市场安装不会直接获得外部工具权限。同一个市场条目可以安装多个连接，用于不同服务地址或外部账号。工具清单、允许调用的工具和启用状态分别保存在每个连接中。

## 安装个人 MCP

1. 打开「Agent 设置 → 工具与连接 → MCP 市场」，选择条目并点击「安装」。也可以在「已安装」中添加自定义连接。
2. 填写名称、连接方式、完整服务地址和参数。自定义连接可填写可选的 Bearer 访问令牌；市场条目显示管理员定义的参数。
3. 保存。新连接默认停用，未授权任何工具。
4. 点击「检测连接」。后端实际连接服务并发现工具；失败时显示错误，不能把保存配置视为连接成功。
5. 检测成功后，勾选允许 Agent 使用的工具，打开「启用此连接」并保存。
6. 在后续 Agent 运行中提出任务。Agent 先查询可用连接与工具，再按需读取某个连接的工具参数；实际调用前会请求确认。

服务地址应与连接方式对应，例如 Streamable HTTP 服务的 `/mcp` 地址或 SSE 服务的事件端点。地址不能含账号密码、查询参数、片段或密钥占位符；认证通过请求头参数完成。没有工具的服务可以检测成功，但不能启用为空的工具授权列表。

## 参数和授权变更

凭据加密保存在后端。编辑时不返回密钥原文，只提示哪些密钥已经配置；同一地址和模板下，密钥输入留空表示保留原值。普通参数可回显和修改，密钥不会写入浏览器持久化存储。

修改地址、连接方式、参数或市场模板配置后，需要重新检测并授权工具。重新检测本身也会清空旧授权并停用连接，因为外部服务可能在同名工具下改变参数或行为。更换服务地址或模板时，旧凭据不会自动转移到新目标；需要重新填写所需密钥。

管理员编辑市场模板时，服务端会原子清空已安装连接的全部参数和密钥，同时停用连接、撤销检测和授权。用户需要重新填写、检测并授权。这能防止旧密钥在模板把参数改为普通文本后被回显。

连接带有服务端版本号。Agent 列出工具时取得该版本，审批和执行时重新校验；如果等待确认期间配置、启停状态或授权发生变化，旧操作会被拒绝，需要重新读取工具并确认。

新调用在一个短数据库事务中校验当前运行、审批、连接和模板，并登记回执；该事务提交是执行准入点。此前完成的取消、下架、停用或移除会阻止调用。已经准入的外部操作可能继续完成，撤权或取消不能撤回已发出的操作。

## 管理平台连接与市场

「管理后台 → MCP 管理」提供两个页签：

- **平台连接**：添加远端连接，检测服务，选择允许的工具，并开启「向平台用户开放」。平台凭据由管理员维护。
- **市场管理**：编辑名称、介绍、文档链接、默认地址、连接方式、用户参数和请求头模板；发布后出现在用户的 MCP 市场中。

每个参数有唯一名称、显示名称、说明、类型和是否必填。普通文本可以有默认值；密钥参数没有默认值。参数名称以字母开头，仅使用字母、数字和下划线，最多 64 个字符。

请求头使用参数占位，例如：

```json
{
  "Authorization": "Bearer {{token}}"
}
```

此时应定义名称为 `token`、类型为「密钥」的参数。市场模板里不填写真实凭据。服务地址需要用户自部署时，可以将默认地址留空，由安装者填写。

## 外部工具执行边界

- 工具发现使用 `mcp_list_tools`，只返回当前用户可用的连接和已授权工具；不把全部外部工具定义永久加入每轮提示词。
- 外部调用使用 `mcp_call_tool`，携带连接 ID、配置版本、工具名和参数。服务端检查连接归属、启用状态、工具授权和输入 schema。
- 每次外部调用都要确认，远端工具声明 `readOnly` 不能免除审批。只读运行不执行外部 MCP 调用。
- 连接和请求遵守服务端出站地址限制。可信内网服务需要管理员按已有出站规则精确放行，不能通过浏览器直连或取消出站校验绕过。
- 调用前登记执行记录，完成后保存回执。同一个已登记调用不会因重连或恢复而重复执行。已完成回执在连接停用或移除后仍可回放，不会再次访问外部服务。
- 超时、断线或回执未能保存时，外部服务可能已经完成操作。错误分类为 `external_result_uncertain`，`retryable: false`；系统不会自动重放，同一运行换调用 ID 也不能重复相同的未确认操作。应先到外部服务核对结果，再决定是否发起新的操作。
- MCP 返回 `isError` 时显示调用失败；协议响应成功不代表外部业务成功。

## 飞书反馈日报

可以连接已部署、已授权的飞书 MCP 服务，让 Agent 调用该服务提供的消息或文档工具。针对“飞书用户提出需求或 Bug，每天汇总给管理群”的固定收件场景，后台还提供独立的飞书事件回调和日报 worker：管理员在 `/api/admin/integrations/feishu` 配置应用凭证、校验 token、目标群、时区和日报时间，飞书将文本事件发送到 `/api/integrations/feishu/events`。

回调会校验 token；配置 EncryptKey 时校验 Lark 签名。首版明确只接受明文文本事件，包含 `encrypt` 字段的加密事件会拒绝并提示关闭事件加密。消息写入现有反馈收件箱，事件按租户和事件 ID 幂等；日报使用跨实例租约和持久化状态，网络结果不确定时不自动重试。MCP 参数配置和飞书收件配置相互独立，MCP 仍适合调用外部文档、查询或操作工具。

浏览器完整流程及真实 MCP 服务仍需按[待测试清单](/docs/progress/pending-test)验收。接口和数据结构分别见 [HTTP API 合同](/docs/backend/http-api)与[后端数据库](/docs/backend/backend-database)。
