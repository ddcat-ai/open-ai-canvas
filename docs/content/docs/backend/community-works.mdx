## 使用入口

用户从账号菜单进入「我的投稿」，选择已有个人素材或上传成品与封面，填写名称、简介、分类及标签，确认拥有公开这些内容的权利后提交。画布分享窗口提供投稿入口，可带入当前画布。公开制作画布为可选项；选择后使用提交时的固定快照，不跟随原画布后续修改。

管理员从「作品投稿」查看待审作品、播放成片和预览制作过程，可通过、驳回、设为精选、取消精选及下架。驳回原因对作者可见。审核通过与精选推荐是两个操作，创作首页展示已发布且被选为精选的用户作品。

作者可修改并重新投稿，也可撤回。重新投稿需要重新审核；撤回或下架后公开访问被拒绝。操作不删除作者原来的成片、封面或画布。

公开作品支持视频自动播放、点赞和分享。作者公开制作画布后，访客可以查看节点和连线，登录用户可以主动复制已审核快照到自己的画布。

## API

所有路径以 `/api` 为前缀，业务请求统一走 `http` 解包，HTTP 200 不替代 `code === 0`。

| 方法与路径 | 功能 |
| --- | --- |
| `GET /works?status=pending&page=1&pageSize=24` | 当前用户的投稿，支持状态筛选和分页 |
| `POST /works` | 提交新作品，初始为待审 |
| `PUT /works/:id` | 作者修改并重新提交 |
| `POST /works/:id/withdraw` | 作者撤回 |
| `GET /works/:id/project` | 作者或管理员查看审核中的画布快照 |
| `GET /works/:id/resources/:resourceId/file` | 作者或管理员访问投稿资源 |
| `GET /public/works?featured=true` | 已发布的精选用户作品 |
| `GET /public/works/:id` | 已发布作品详情 |
| `GET /public/works/:id/project` | 已公开的制作画布快照 |
| `GET /public/works/:id/resources/:resourceId/file` | 已发布作品白名单资源，支持 Range 和原生存储分发 |
| `POST /public/works/:id/copy` | 登录用户复制公开的已审核制作画布 |
| `GET /public/works/:id/reaction` | 已发布作品的公开点赞数 |
| `GET /works/:id/reaction` | 点赞数及登录用户的点赞状态 |
| `PUT /works/:id/like` / `DELETE /works/:id/like` | 设置或取消当前用户的点赞，重复请求保持同一状态 |
| `GET /admin/works?status=pending&page=1&pageSize=24` | 管理员审核列表，支持状态筛选和分页 |
| `PATCH /admin/works/:id/review` | `approve`、`reject`、`feature`、`unfeature`、`unlist`；驳回提供原因 |

投稿输入为 `title`、`description`、`category`、`tags`、`mediaResourceId`、`coverResourceId`、可选 `projectId` 与 `rightsConfirmed`。只允许当前用户已保存的图片或视频资源；封面必须为图片。不接收任意外部媒体地址、私有存储路径或画布正文作为可信提交内容。

作者和管理员列表结果为 `{items: [...], page, pageSize, total}`，每页默认 24 条、最大 100 条。公开列表为 `{items: [...]}`，最多返回 200 条。详情与审核返回作品 DTO，画布结果为 `{project: ...}`，点赞结果为 `{count, liked}`。公开 DTO 包含作品名称、作者展示名、媒体类型及受控访问地址。分享链接为 `/share/work/<work-id>`。

## 资源与权限

提交时检查媒体、封面、画布及依赖资源归属，固定资源白名单与脱敏快照；公开媒体不依赖普通画布分享 token，也不受其轮转或过期影响。只有发布中的作品允许匿名读取；待审、驳回、撤回和下架作品仅允许作者或管理员预览。资源访问保留原有对象存储与 Range 分发，不为投稿批量上传或复制案例素材。

制作快照沿用原生公开画布的字段白名单，保留节点位置、尺寸、连线、提示词、富文本及已有公开字段；不公开聊天、渠道凭据、任务运行态和私有外链，预演场景集合沿用原生省略策略。复制时为当前账号重建素材记录和资源归属，相同来源的重复复制复用其已保存文件；原作者资源不会出现在其他账号的个人素材库，除非该用户主动复制作品。

账号存储限制、活动状态和管理员权限沿用宿主检查。存储超额只读时停止投稿与复制，仍允许作者撤回公开作品。发表、审核、复制和撤回均为真实后端写入，失败向上返回错误；不以浏览器本地存储模拟已提交或已发布。

上传使用现有资源接口的单文件限制、每日上传额度和账号存储配额。投稿请求体上限为 32 KiB，每用户每分钟最多提交或修改 20 次。复制每用户每分钟最多 6 次，使用正常的账号资源配额，不调用模型。作品与画布媒体由已校验归属的资源记录提供。
