# 自定义更新公告

在「站点及外观 → 更新公告」编辑公告，点击页面顶部「保存修改」统一保存。开关默认关闭，此时工作台与管理后台入口展示原有内置更新日志及真实构建版本；开启后，两处入口和公告弹窗采用自定义当前版本与公告内容。后台「系统更新」继续使用真实程序版本和官方 Release。

支持最多 30 个版本；每个版本有版本号、可选标题与发布日期，以及最多 50 个可排序的文字、图片、视频内容块。文字支持换行、列表和 Markdown 加粗，原始 HTML 不执行。内容块可选择整行或半行，相邻半行并排，窄屏自动单列。编辑区域提供即时预览，视频手动播放。

图片支持 PNG、JPEG、WebP，最大 10MB；视频支持 MP4、WebM，最大 256MB。媒体使用现有平台资源存储，管理员身份、文件真实 MIME 和新资源归属均由服务端校验。未保存媒体只能由上传管理员预览；已保存媒体可由其他管理员预览；公开读取仅允许当前已启用公告引用的媒体，支持视频 Range 请求。关闭开关保留全部自定义内容及素材引用保护，公共外观响应不返回关闭的公告正文。

当前版本必须对应已添加的版本，版本号不能重复，空文字或未上传媒体不能提交；正文总大小最多 200KB，外观 PATCH 请求上限 512KB。保存成功后同步本页公共状态，其他页面在激活、聚焦或打开更新日志时重新读取；读取失败保留已有状态，过期响应不能覆盖较新的保存结果。

配置保存在现有 `system_settings` 的 `appearance` JSON 的 `updates` 中，外观合同版本为 10；不增加数据表或数据库迁移。恢复默认外观会清空自定义公告并关闭开关，恢复原日志，已上传媒体仍保留在存储资源中。

媒体接口：`POST /admin/settings/appearance/assets/update-image|update-video`；管理员预览 `GET /admin/settings/appearance/updates/:id`；公开读取 `GET /public/appearance/updates/:id`。公开媒体不接受任意外部 URL，只从当前公告引用的资源生成访问地址。
