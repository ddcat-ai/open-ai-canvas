# 代码功能地图

## 创作对话同步

- HTTP：`handler/creation_history.go` → `service/aliases_creation_history.go` → `app/creation_history.go`；持久化在 `repository/creation_history.go` 和 `model/creation_history.go`。
- Web：`services/creation-history-sync.ts` 维护账号队列、修订合并及冲突备份；`creation-history-payload.ts` 定义可持久化字段，`creation-history-media.ts` 上传本地媒体并恢复授权路径；真实入口为 `pages/create/index.tsx`。
- 迁移：Schema 101；资源引用保护在 `repository/resource_reference.go` 和 `resource_cleanup.go`，SQLite → PostgreSQL 复制清单登记三张历史表。

## Agent 记忆、Pi 与 MCP

- 用户工作回忆：`app/cloud_agent_memory_recall.go`、`repository/agent_memory_recall.go`；长期偏好沿用 `cloud_agent_memory_document*.go`。冻结注入在 `cloud_agent_skill_catalog.go`，按需检索工具为 `memory_search`。
- Pi `1.5.2` 与真实运行回归：`backend/agent-runtime/pi/agent-runtime.mjs`、`agent-runtime.compaction.test.mjs`；受管模型桥、真实 Token 计量和缓存前缀在 `app/cloud_agent_pi_model.go`。
- MCP HTTP 接口：`handler/mcp.go` → `service/aliases_mcp.go` → `app/mcp.go`；领域实现 `internal/integrations/mcp/`，持久化 `repository/mcp.go`、`model/models_mcp.go`，追加迁移 100 在 `database/migration_mcp.go`。
- MCP 工具发现、审批预览与执行：`app/cloud_agent_tools_mcp.go`；分类与 Schema 仍使用统一工具注册表。外部 IO 在检查点事务外执行，独立回执防止重复调用。
- 前端：`web/src/components/mcp/` 与 `services/api/agent-mcp.ts`；个人入口在 Agent 设置，平台市场和连接在 `pages/admin/mcp/`。

## 网站访问统计

- 匿名采集与分类：`web/src/lib/site-traffic.ts`、`services/site-traffic.ts`；后台路由 `/admin/traffic` 在 `pages/admin/traffic/`，API 校验在 `services/api/site-traffic.ts`，三类 CSV 在 `traffic-csv.ts`。
- 接口与聚合：`backend/internal/handler/site_traffic.go` → `service/aliases_site_traffic.go` → `app/site_traffic*.go` → `repository/site_traffic*.go`；表在 `model/models_site_traffic.go`，追加迁移 99 与独立租约清理在 `database/migrations.go`、`app/site_traffic_cleanup.go`。
- 真实采集范围、隐私、接收秒歧义及上游路由适配见 [HTTP API](/docs/backend/http-api)，存储和保留策略见 [后端数据库](/docs/backend/backend-database)。

## 视频请求日志生成内容

- 后台详情：`web/src/pages/admin/components/api-log-detail-drawer.tsx` 挂载 `api-log-generation-content.tsx`，提示词编号解析在 `pages/admin/logs/generation-content.ts`。原始图片可放大，视频和音频按需播放；只请求管理员日志媒体接口，不以当前账号的素材库替换原请求。
- 请求快照：`backend/internal/app/api_log_generation_content.go` 在媒体转换前保存提示词与原资源身份，详情检查来源和归属；`model/api_log_generation.go` 定义只读返回合同。请求根日志保留快照，轮询合并不覆盖。
- 资源保留：`repository/api_log_generation.go` 将日志引用纳入删除和孤儿清理；日志移除后自然释放该引用。接口在 `handler/admin_api_log_routes.go`，迁移在 `database/migrations.go`。

## 媒体资源与按需加载

- 远程 Blob：`web/src/services/resource-blob-cache.ts` 分开管理有界闲置缓存、持久化队列与活动 URL 租约；`hooks/use-cached-resource-url.ts` 对接画布图片/大图预览，`services/canvas-video-preview.ts` 在抽帧结束释放。上传预热由 `pages/canvas/use-canvas-upload.ts` 短暂借用。
- 本地降级媒体：`services/local-media-object-urls.ts` 记录同 key 的当前/旧版本 URL，供 `file-storage.ts`、`image-storage.ts` 在明确删除/会话退出时统一回收；原件继续保存在 IndexedDB。
- 媒体 Worker：`lib/canvas/canvas-video-merge.ts` 的 `runFFmpegTask` 为转码/合并/裁段/抽音轨统一串行作用域及空闲释放；`canvas-face-detection.ts` 管理识脸请求、取消、错误和空闲 Worker 回收。
- 官方插件校验：`backend/internal/app/protocol_plugins.go` 缓存每路径最新清单/摘要，不持有原包字节；落盘硬链接或流式复制核验，专项 `official_plugin_package_cache_test.go`。
- 工作区路由：`web/src/lib/workspace-route-modules.ts` 保留导航意图预取，登录不再无条件预热全部一级页面。录音测试页面仅在 `router.tsx` 的 DEV 路由注册。

## 前端主题包

主题登记与切换在 `web/src/themes/`：`registry.ts` 按皮肤 ID 查找，`load.ts` 自动载入，`apply.ts` 处理画布预设还原与品牌变量。各主题目录封装助手形象、空状态、404、字体和样式，静态资源在 `web/public/themes/`。入口通过 `application.tsx` 加载；后台外观提交在 `stores/use-appearance-store.ts` 应用当前主题。使用与扩展说明见 `web/src/themes/README.md`。

龙影水墨和云鹤仙观的皮肤参数由前端主题包与 `backend/internal/app/appearance_skins.go` 共用 `appearance_theme_packs.json`。读取旧版外观配置时，`appearance.go` 按皮肤库剩余容量补入缺少的主题，直到管理员保存新版配置。

- 纯逻辑：`backend/internal/production/`（作品圣经、分集与剧本提示词 `prompts.go`，模型输出解析 `parse.go`，分镜规则与时长 `storyboard.go` / `timing.go`，按视频模型上限切剧情段 `SegmentShotsForVideo`，段提示词素材稿 `segment_prompt.go` 与撰写要求 `segment_writer.go`，参考图方案 `assets.go`，用户分镜表直接导入 `storyboard_import.go`，原文台词逐句核对 `dialogue_check.go`）。
- 调度循环：`backend/internal/app/drama_orchestrator.go`（同步任务结果 → 推导工作 → 按优先级派发，租约保证单项目单循环；成片时间线由各段视频拼接；短剧任务进入终态后 `wakeDramaAfterTask` 立即唤醒调度）；派发并发池（文字 / 参考图 / 段视频 / 成片各按“同时生成数”计算）、先集号后类型的优先级与排队原因 `dramaDispatchWaits` 在 `drama_dispatch.go`；段视频尾帧在调度循环外后台抽取，按视频资源去重并用租约防跨实例重复，见 `drama_tail_worker.go`；剧情段视频请求的组装、提交、回写与最后一帧抽取在 `drama_segment_video.go`（`prepareDramaSegment` 同时供预览与提交使用）。

## 后端调用链

AutoDL 画面规格由 `app/model_capability_screen_spec.go` 读取官方插件工作流合同（精确工作流优先，未声明的 ID 回退到 `*` 默认预设），校验所选分辨率及默认值，允许自定义标签；`task_creation.go` 在价格选择之前归一化，任务校验与 `provider_video.go` 再次使用同一规则。前端 `lib/video-screen-specs.ts` 管理插件预设、所选规格与工作流切换，`ModelCapabilityEditor` 复用到系统及自定义渠道；无开关或独立草稿。

```text
HTTP 请求 -> handler -> service（稳定导入面 / 别名）-> app（组合根）-> 业务域包 -> repository/model
                                                                     |
                                                                     -> protocol / payment / generation / outbound
```

`internal/service` 只再导出 `internal/app` 的类型、常量和包级函数，handler/cmd 仍 import `internal/service`。组合根和尚未拆出的业务实现在 `internal/app`。已抽出的域包不得 import `service` 或 `app`（防回环）。共享错误码与 ID/字符串工具在 `internal/kernel`。

登录恢复仅初始化当前账号缓存与增量同步会话，不再自动读取 `GET /api/user-data/snapshot`。画布库通过分页摘要加载，打开、导出、重命名时按 ID 读取完整画布，引用素材通过批量 ID 接口读取；旧快照接口仍保留供显式调用。实现见 `internal/canvas/user_data_page.go` 和前端 `services/user-data-sync.ts`。用户库素材写入（`UpsertUserAsset` / `ReplaceUserAssets`）在 `internal/canvas/user_asset_document.go` 校验 SPA 合同：`kind`、`coverUrl`、`tags` 字符串数组，以及按类型完整的 `data`。不完整 payload 在入库时拒绝；GET 仍返回已保存的原始 JSON。上游异构 JSON 的可选字符串仍走 `stringField`；任务 ID 等关键字段走 `firstJSONString`，数字 ID 不再被当成“缺字段”。

后端托管的文本生成通过 `GET /api/tasks/:id/text-events` 返回 `progress`、`delta` 和 `terminal` 事件。`delta` 的递增事件 ID 是断线续传游标，前端使用 `?after=<id>` 恢复；分镜任务复用该通道实时接收阶段和进度，但分镜结构和 Agent 工具参数仍在完整响应结束并校验通过后原子应用，不执行半截 JSON。

## 修改原则

- HTTP 参数与响应只在 handler 处理，业务规则进入 service。
- 页面保留流程协调；可独立理解和测试的算法进入同业务域的 `lib`。
- 新增功能时只更新本页的主要入口，不增加逐文件清单。

## 画布工具链路

- `backend/internal/handler/tools.go`：登录态工具列表、详情、收藏、创建与删除。
