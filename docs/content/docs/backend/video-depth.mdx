# 相对深度视频

相对深度工具逐帧估计视频空间层次，生成时间连续的深度视频，用于动作、角色替换和运镜参考。产物是视频，不是骨骼、BVH 或三维动画文件。

## 管理员配置

1. 在插件中心启用独立插件 `volcengine-mediakit-depth`。插件默认关闭，不随已有画质增强插件启用，无需安装推理模型。
2. 在系统渠道配置 MediaKit API Key，为视频模型选择协议 `volcengine-mediakit-video-depth`。上游固定使用 `standard` 档，系统模型 ID 可作为展示别名。
3. 确认模型能力默认操作为 `depth`，按需收紧 `video.processing.maxSourceSeconds`（默认且最大 600 秒）。不用配置输出分辨率、帧率或码率。
4. 配置按次或按秒的价格，允许目标用户组使用该渠道，再启用模型。深度不套用画质增强的价格、分辨率或帧率档。

协议创建接口为 `POST https://mediakit.cn-beijing.volces.com/api/v1/tools/video-depth`，通过 `GET /api/v1/tasks/{taskId}` 轮询。参数和响应详见插件包内 `docs/interface.md` 及[官方接口](https://docs.volcengine.com/docs/intelligent-processing/submit-deep-motion-capture-task-api?lang=zh)。

## 视频节点使用

专业画布中，已有视频节点的处理菜单在存在可用深度模型时显示「相对深度」。点击只打开确认面板；取消不创建节点或任务。确认开始后，在原视频右侧创建结果节点并连线，原视频保留。失败重试按结果节点保存的深度模型和源节点重建请求，不进入普通视频生成。

仅接受一个当前用户有权访问且已就绪的源视频资源，不接受图片或音频。服务端按资源记录重算时长和尺寸，不信任客户端时长、处理标记或额外参数。执行复用既有媒体地址转换、SSRF、用户组、任务归属、配额和失败处理。

官方限制源视频最长 10 分钟、分辨率不超过 2K，必须包含有效视频流。官方未定义 2K 的具体像素边界，分辨率交上游校验，不套用增强工具的 1080p 输入限制。

## 结果与计量

输出为 HEVC 相对深度视频。临时结果链接默认 24 小时有效，插件声明 `resultEphemeral: true`，由既有任务媒体流程及时下载并持久化，不把临时链接作为永久素材。

价格选择保留独立 `operation=depth`，不归入普通 `video_to_video`。按秒时以服务端源时长向上取整预扣；成功后优先按持久化资源探测时长、其次按上游 `result.duration`（映射为 `usage.outputDurationSeconds`）结算，多退少补。缺少有效输出时长进入待核对，不按估算值伪装为成功结算。本功能没有预设供应商单价。

## 验收边界

自动回归使用本地 Stub，覆盖协议、资源归属、任务输入、节点连线、重试和结果保存，没有真实付费调用。真实深度效果、处理耗时、HEVC 跨浏览器播放、输出时长与供应商账单仍需独立验收，见[待测试](/docs/progress/pending-test)。
