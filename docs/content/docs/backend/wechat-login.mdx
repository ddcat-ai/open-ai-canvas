# 微信网站应用登录

后台 `/admin/settings/access` 的微信登录区域配置微信开放平台**网站应用**的 AppID、AppSecret 与完整 HTTPS 回调地址，保存并启用后，登录弹窗和独立登录页展示微信入口。

## 接入准备

1. 在微信开放平台完成网站应用与微信登录权限审核，取得该网站应用的 AppID 和 AppSecret。
2. 在微信开放平台填写经审核的授权回调域名；本站填写完整地址 `https://你的域名/api/auth/wechat/callback`。路径固定，不包含查询参数或片段；HTTPS 入口须将 `/api/` 代理到后端。
3. 保存并启用配置，在 HTTPS 站点完成一次真实授权。授权跳转到微信官方页面，支持扫码和符合客户端条件的快速确认。

AppSecret 沿用系统设置密钥加密，管理读取接口仅返回 `hasAppSecret`。编辑时留空保留已有密钥；更换 AppID 时须填写对应的新 AppSecret。AppID 决定身份范围，更换网站应用需要规划已有绑定迁移，不能仅修改 AppID 后期待旧身份继续匹配。

本接入使用 `snsapi_login`；公众号微信内网页授权和小程序登录属于不同接入流程。参考[官方登录指南](https://developers.weixin.qq.com/doc/oplatform/Website_App/WeChat_Login/Wechat_Login.html)及[授权后接口调用](https://developers.weixin.qq.com/doc/oplatform/Website_App/WeChat_Login/Authorized_Interface_Calling_UnionID.html)。

## 账号行为

- 已绑定微信：使用原账号登录，沿用项目、余额、权限和账号状态；关闭新用户注册不影响已绑定账号登录。
- 未绑定微信：创建十分钟有效的注册补全票据，进入注册页面。按当前注册策略补齐邮箱或短信验证并同意服务协议，再创建普通用户并绑定微信；可以退出此步骤，使用已有账号登录后手动绑定。
- 已有账号：在个人设置点击「绑定微信」，在原浏览器与原登录会话完成授权。绑定不新建账号，不自动按昵称、头像或邮箱合并账号；当前账号已有微信绑定、或微信已属于其他账号时拒绝绑定。
- 纯微信账号：通过已绑定微信重新核验后，可在当前会话中设置密码或修改邮箱。核验有效期为五分钟，其他会话和其他微信身份不能代替本次核验。

身份存储使用 `provider=wechat`、`subject=AppID:OpenID`；暂不使用 UnionID 自动合并跨应用身份。微信昵称与头像映射为公开身份信息，个人头像选择仍优先。首次微信注册无需设置密码，可在个人设置中核验后设置。

## 状态与安全边界

授权 state 与注册票据均为随机值，数据库仅保存哈希。授权 state 还通过 `Secure`、`HttpOnly`、`SameSite=Lax` 的 `__Host-` Cookie 绑定发起浏览器；绑定与核验同时检查原账号和原会话。开始授权后更换 AppID 或停用微信登录会使流程失效。

注册补全票据只保存在 HttpOnly Cookie 中，不放入页面 URL。邮箱／短信验证、一次性注册票据、用户和微信身份在同一数据库事务中提交；失败时回滚。成功消费后清空票据行的临时资料，过期票据不能继续使用。

AppSecret、access_token、refresh_token 不返回浏览器或写入登录日志。后端只调用固定的微信 HTTPS 端点，禁止上游重定向，并将包含敏感查询参数的网络错误替换为固定错误。微信的 OAuth 凭证仅用于本次身份读取，本站登录有效期仍由原有会话管理。

## 升级与验收

Schema 102 `wechat_oauth` 为 `o_auth_states` 增加 `purpose`、`client_id`、`profile_json`，保留现有 Linux.do 与 OIDC 状态。受管部署先通过正式迁移服务升级，再启动新后端；本地开发沿用自动迁移配置。

自动化测试使用模拟微信响应，不能代替平台审核和真实微信授权。上线前还需在正式回调域名验证首次注册、已有账号绑定、再次登录、桌面客户端确认、过期／取消授权与个人设置核验，并检查明暗主题和窄屏布局。
