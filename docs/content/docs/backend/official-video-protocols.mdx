# 官方视频模型与插件版本

**渠道管理地域和凭据，渠道模型选择协议，生成模式决定素材的语义。** 同一张图片在“图生”里是首帧，在“全能参考”里是外观参考。不能仅以图片数量决定端点，也不能把模型商品名、上游模型 ID、provider ID、插件发行版本当作同一个标识。

## 三家官方接口的差异

| 接口与地域 | 文生 / 关键帧 | 全能参考与音频 | 宿主开放边界 |
| --- | --- | --- | --- |
| [火山方舟 Seedance 2.0](https://docs.volcengine.com/docs/ark/seedance-2-0)，`volcengine-ark-video` | 同一 Contents Generations Tasks 接口；图片角色区分首帧、首尾帧和参考图 | 最多 9 图、3 视频、3 音频；音频须搭配图或视频。`generate_audio` 决定输出声轨，不表示允许单独输入音频 | 标准、Fast、Mini 按精确模型 ID 提供不同默认规格。默认不开放标准版的 4K；不能把 4K 价格、权限和并发假定为普通清晰度档位。 |
| [火山方舟 Seedance 2.5](https://docs.volcengine.com/docs/ark/seedance-2-5)，`volcengine-ark-seedance-25` | 首帧/首尾帧要求 `ratio=adaptive` | 允许纯音频；标准版上限 30 图、10 视频、10 音频，Flash 为 10/5/5。全模态编辑要求参考视频、`adaptive` 与智能时长 `-1`，延长要求参考视频与 `adaptive` | 普通正整数时长控件不代表已开放智能时长、所有编辑模式或样片。`ep-` 推理接入点本身不说明其背后是哪一型号，需管理员确认。 |
| [阿里云百炼 Wan 3.0](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)，`dashscope-wan3-video` | 单一创建接口；纯文本，或首帧，或首帧+尾帧。仅尾帧不合法；关键帧与其他素材互斥 | `input.media` 按角色映射 10 图、5 视频、5 音频；图音视频可组合。视频、音频各合计最多 15 秒，输入视频与指定输出合计不超过 30 秒。可附 1 个 `file` 或 `link`，二者互斥且要求 `prompt_extend=true`。`parameters.audio` 独立控制输出声轨 | 默认 1080P、5 秒、自适应；不开放 4K。2.1.0 包检查角色、数量、已知时长及输出规格。缺少可信时长时不能据此证明合规。文件/网页是声明式扩展，不是画布上传入口。必须填写**业务空间**的地域 Endpoint，用同地域 Key 和模型，不使用公共缺省域名。 |
| 可灵 4.0 / Flash，`kling-v4-official` | 文生、图生、Omni 分别使用独立端点。图生的画幅随素材。标准版可接首帧、中间帧和尾帧，Flash 图生只接一个首帧。[Flash 图生](https://kling.ai/document-api/api/video/4-0-flash/image-to-video.md) | 两种型号的 Omni 都能用参考图、特征参考视频、待编辑视频和主体。标准版还支持多关键帧和音色 ID。[标准版 Omni](https://kling.ai/document-api/api/video/4-0/video-omni.md) · [Flash Omni](https://kling.ai/document-api/api/video/4-0-flash/video-omni.md) | 标准版 3～30 秒、720p/1080p，Flash 3～20 秒、720p。文生支持六种固定比例，Omni 另支持 `adaptive`。画布提供首尾帧和参考图入口。中间帧、主体与音色 ID 可经插件参数传入。 |

读表的顺序是 **上游合同 → 插件能表达的请求 → 当前模型开放的参数 → 可结算的 SKU**。某组合只有前三层支持，不代表能够报价或付费提交。不能将不支持的参考视频删掉改做文生，也不能把“无参考视频”的价套给有参考视频的请求。

对照 `video-canvas`，值得采用的是模型绑定具体插件版本、枚举值直接点星选默认，以及用真实节点控件预览设置。它的 `backend/plugins/kling.js` 根据有没有图片选择旧 `/v1/videos/text2video` 或 `image2video`；一张图作首帧还是作特征参考在这里无法区分，这条路由规则不适用于可灵 4.0。

## 可灵 4.0 接入与恢复

1. `kling-v4-official.yingce-plugin` **1.2.0** 由社区维护，调用可灵官方 API。SHA-256 为 `db91510fd014f549afa4ff87784dd7f4a9d206e9c331de0ed8c84d9aae61a1c6`。从仓库根目录运行 `node plugin-packages/generate-catalog.mjs kling-v4-official` 和 `sh plugin-packages/build-packages.sh --protocol kling-v4-official` 可重建该包。旧接口保留独立的 `kling-video` 协议。
2. 管理员可在系统渠道导入 `plugin-packages/kling-v4-official/config/kling-v4-channels-CN.json`。**新渠道停用、无密钥**；同名导入会合并，先检查目标。中国区用 `https://api-beijing.klingai.com`，国际区按独立渠道使用 `https://api-singapore.klingai.com`。本仓库只随附 CN 示例；填写对应区域的新 API Key，不用旧协议的 AK/SK JWT。
3. 启用前核对账号当前的币种、售价与成本。两版 Omni 都接受参考视频。CN 示例只开放无输入视频的可结算组合。参考图按图生档计价，有输入视频按 `video_to_video` 档匹配。输入视频与视频 Element 的用量需要单独核价。可灵 API 可省略目标时长，由上游推断。示例按秒预扣，提交时使用模型配置中的显式时长。
4. 新任务的创建回执以插件声明的 `data.id` 为准；`request_id` 是本次 HTTP 调用追踪号。分离式回查以 `GET /tasks?task_ids=…` 查询，在 `data[]` 里匹配原 ID。轮询合并次数、状态和用量，不改任务、订单的关联 ID，也不覆盖创建回执正文。没有声明取消接口，不把停止本地等待解释为上游撤单。
5. **已有错单不批量改写、不重提。** 在原区域的供应商控制台核实任务 ID、素材和扣费，再用现有管理员失败任务的查询/恢复入口指定正确 ID。历史根日志可能已被旧版轮询覆盖；只有 HTTP 追踪号而无可靠回执时先对账。修复不能还原已丢的正文。48 小时是宿主等待上限，不是供应商查询有效期；例如 Wan 的任务 ID 及结果 URL 都有 24 小时有效期。

## 模型设置：配置什么

- **输入**：按生成方式列角色、数量、大小、时长和互斥组合。首尾帧不是“两张普通图”；音色库 ID 不是音频文件；参考音频上限不要和输出声轨放在同一个开关里。
- **输出**：比例、分辨率、时长使用模型自己的允许值。星标选择默认项，删除默认项后取首个剩余项，清空枚举则清空默认。画面规格旁的只读预览复用画布通用视频设置控件，随未保存草稿更新；它不是实际报价，也不是所有专用模型面板的完整复刻。
- **计价**：价格维度由真实 SKU 决定，不因为用户能选比例或生成声音就假定有价差；一次生成多个结果和多次提交计费是不同语义。预设按钮只改当前能力草稿，不套价格、不保存、不启用渠道。
- 新模型的默认建议来自 `backend/internal/app/video_model_presets.json`。可灵 1.2.0 的 `videoModes` 按型号与模式声明图片数和画幅，`videoOutputs` 按型号声明输出分辨率与时长。后台按所选版本展示选项，保存时由服务端校验。切版后，旧草稿中失效的选项仍可见，可移除或显式应用新版本的预设。

### 按模式配置，而不是增加通用开关（设计）

模型设置保留三个管理动作：**选上游**（地域、模型 ID、插件发行版），**设能力**（逐模式收窄输入输出、选默认，右侧预览），**定价格**（按可计费组合报价）。开启一种生成方式，不等于开启其中所有输入，也不自动生成价格档。

| 谁定义 | 具体内容 | 示例 |
| --- | --- | --- |
| 插件发行件，按上游型号及模式 | 输入角色、数量和组合；参数类型、允许值、固定值或必须省略；发往哪个端点及如何读回执。附官方合同来源。 | 可灵图生的 `aspect_ratio` 是**请求中禁止发送**，不是“前端隐藏、后台仍发默认”。Flash 不能继承标准版的尾帧。 |
| 渠道模型，按地域和账号 | 在插件允许范围内关模式、缩小枚举/范围、选默认；配置参数是否对创作者可见。隐藏的必填项必须有合法固定值。 | 可灵 CN 暂不开放参考视频；Wan 管理员可只卖 720P，但不能添加上游不支持的 4K。 |
| 报价与执行 | 从同一份已解析输入得到价格维度和请求；缺价格档不提交。扩展参数归所属 provider，不允许绕过角色限制或改写宿主管理的媒体。 | Wan 参考音频是输入素材，`audio=false` 是输出选项；两者不能互相推断。可灵 Voice ID 也不能由一段上传音频代替。 |

验收用同一张图切换模式：选“首帧”时，预览显示首帧位，提交走可灵图生且不含比例；选“全能参考”时，预览显示参考图位，提交走 Omni。若切换后已有尾帧、参考视频或音频不合法，应标明冲突素材并阻止提交，让用户决定移除或换回原模式。画布、工作台和 Agent 的请求都过同一服务端校验。批量生成 N 个独立任务必须展示 N 份报价，不能把它当作供应商单次响应含 N 个结果。

## 同渠道多模型：现在怎么用

例如一个北京方舟渠道可以让 Seedance 2.0 的 SKU 选 `volcengine-ark-video`，2.5 的 SKU 选 `volcengine-ark-seedance-25`，不需要为协议差异复制 Key。反过来，可灵标准版和 Flash 可以使用同一个插件发行件，但绑定**不同上游模型与能力配置**。只有地址、地域、凭据或治理边界不同时才拆渠道。

同一 `providerId` 的多个已安装发行版也能并行使用。对于尚未记录插件发行版本的渠道模型，服务端按本实例当前启用的发行版解析，任务入队时会把当时的版本摘要写入任务快照。明确选择某个版本后，该模型持续使用对应摘要，直到管理员重新切换。进入**后台 → 渠道管理 → 编辑参数 → 基本信息 → 插件发行版本**，可以为每个渠道模型分别选择版本并保存。「能力与参数」显示模型所选版本，插件详情列出归档版本和摘要。要将一个 SKU 升级或回滚，只需重新选择该 SKU 的版本，核对模式、默认值与价格后保存。

请求包升级时保留原始归档。同一插件同一版本只接受同一摘要。内置包随发布升级，历史版本来自该实例保存过的归档。模型导出保留 SHA-256，导入目标实例需要备有对应版本。

如果旧站启动时提示 `seedance-videos-compatible@2.0.1` 已安装但包摘要不同，请更新到内置 `2.0.2` 的影策版本，并保留插件数据目录。启动后，已有任务仍可使用本站原来的 `2.0.1` 归档，插件的启用或停用设置也会保留。

从尚未记录插件发行版本的旧版升级后，模型会自动使用该实例当前启用的发行版；需要保持旧行为时，再在渠道模型的「基本信息」中明确选择实例保留的旧版。维护官方请求插件时，已发布的 `.yingce-plugin` 包字节一旦变化，就要递增插件版本并重新打包，单独更新文档也遵循此约定。

新建系统渠道任务在入队时记录渠道模型、实际使用的上游型号、版本摘要、能力配置、报价修订和渠道连接指纹。每次路由尝试保留对应快照。供应商受理后，轮询、支持的取消操作和失败任务人工查询使用原任务 ID 和归档。若原包不可用或渠道地址、凭据发生变化，宿主停止此次请求，运维可依据创建回执与供应商对账。旧库迁移只添加字段，历史任务如果缺少快照且版本存在歧义，需要人工核对。
