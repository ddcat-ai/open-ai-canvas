1. 管理员设置启用系统渠道模型的按次价格为 `0` 后，普通用户刷新设置即可看到并成功创建任务。
2. 前台逻辑模型使用统一按次价格 `0` 后，普通用户可见并能成功创建任务。
3. 零价任务完成后，账单状态为已结算，用户可用积分和预留积分均不变化。
