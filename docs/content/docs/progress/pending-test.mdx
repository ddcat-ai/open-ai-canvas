# 待测试清单

## 分镜脚本资产关联

1. 在同一画布放入角色、场景图片、参考视频和音频后生成分镜，确认各镜头只关联模型返回的真实画布资产，不出现失效或编造 ID。
2. 分镜卡片按“序号、时长、视频提示词、台词/旁白、关联资产”五列显示；图片、视频和音频缩略图可点击并打开对应预览。
3. 从单个镜头及批量入口创建视频节点，确认脚本行输出和每个关联资产都自动连到视频节点，重复同步不会产生重复连线。
4. 打开视频节点提示词，确认关联资产以标准 `@资产` 缩略图展示，生成请求能解析图片、视频和音频引用。
5. 修改镜头资产关联后再次同步，确认已移除的托管资产连线被清理，而用户手工创建的普通连线仍保留。

## 零价免费模型

1. 管理员设置启用系统渠道模型的按次价格为 `0` 后，普通用户刷新设置即可看到并成功创建任务。
2. 前台逻辑模型使用统一按次价格 `0` 后，普通用户可见并能成功创建任务。
3. 零价任务完成后，账单状态为已结算，用户可用积分和预留积分均不变化。
4. 零价 Token 任务在上游未返回 usage 时仍能以 `0` 结算；正价 Token 任务继续依赖 usage 结算。
5. 管理端提交任一负价格仍会被拒绝。
6. 未勾选价格已配置的默认零价模型仍不会向普通用户公开。
