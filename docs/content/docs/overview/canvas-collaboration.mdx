# 共享协作画布与独立方案

协作以服务端画布为共同事实：本地编辑即时显示，REST 提交受校验的操作，WebSocket 通知已提交结果。独立方案是有独立 ID 和版本的持久画布，通过共同基线与来源或其他目标合并。

本次将定制分支的协作实现移植到上游画布领域层，保留分页读取、按需加载、Agent 同步和主题组件。共享覆盖画布正文及其中已授权的图片、视频、音频和素材详情，editor/viewer 都可以查看。

## 成员与入口

| 身份 | 能力 |
| --- | --- |
| 所有者 owner | 读取、编辑、恢复；搜索用户、邀请、调整角色和移除成员；删除自己的画布 |
| 编辑者 editor | 读取、协作操作、恢复历史、创建方案；有目标写权限时合并 |
| 查看者 viewer | 读取画布、历史及可见方案、查看在线状态；服务端拒绝编辑、恢复及创建/合并方案 |

画布库的分页接口包含个人与直接受邀画布，分别标记“协作”和“共享给我的”。普通模式和专注模式共用协作入口；成员、方案是主要内容，历史记录和本机备份是次级导航。公开分享保留独立的只读预览链接，成员邀请不等于公开分享。

权限按画布检查，媒体读取范围限定为该画布合法引用的对象。其他人的项目、任务、账单、未共享素材与资源保持私有；个人素材库列表仍只列自己的素材。积分入口只统计当前用户在该画布的任务账单。

## 共享媒体

保存正文、协作操作、创建方案和合并时，服务端确认媒体属于发布者，或已获得目标/经校验来源画布的授权，再将授权与正文在同一事务提交。仅向 JSON 填入资源或素材 ID 不能获得读取权。编辑者放入自己的媒体后，画布其他成员同样可读；媒体所有者不变。

资源文件、元数据、视频播放副本和按 ID 加载的素材都检查当前成员关系。对象存储按资源所有者配置读取；跨所有者文件请求经后端代理，返回 `private, no-store`，即使带 `direct=1` 也不返回 CDN 重定向。移除成员后，后续服务端读取失效，旧 ETag 不能绕过校验；已经下载到本机的内容无法撤回。

曾合法放入画布的媒体授权保留，支持操作恢复和历史查看。独立方案只复制其内容需要的授权并拥有独立成员关系：从来源移除某成员，不会撤销该成员在已有独立方案中的权限。公开预览链接继续使用自己的令牌和正文范围校验，成员撤权不等于关闭公开链接。

当前媒体引用及保留历史继续阻止物理资源删除。删除画布时清理该画布的媒体授权、成员和协作日志；仅画布所有者可执行。

共享媒体可作为本人生成任务的参考输入。创建任务前校验资源读权，执行时重新校验画布编辑权与媒体读权；任务、渠道、密钥和计费属于实际操作者。editor 可在共享画布生成，viewer 仅查看。页面只恢复当前账号的任务、自动保存自己的生成素材；其他成员的任务进度与结果通过画布同步展示，其私有任务日志不随画布开放。

外部服务使用绑定读取成员的临时资源地址，每次下载均重新检查成员权限并代理所有者存储，保留 Range。普通外部使用有效期 5 分钟，生成上游输入有效期 4 小时；撤权后旧地址的下一次读取失效。该地址为短期 bearer capability，得到地址的一方可在其有效授权期间下载，已下载字节无法撤回。

「保存素材」会将他人的共享资源复制到自己的存储再建立个人素材，同一来源重试幂等，并经过上传配额检查。副本可独立重命名、分类、删除，来源撤权不删除已复制的个人副本。共享节点继续引用原媒体，受邀者的自动归档不写入画布所有者的业务项目；原资源管理仍由资源所有者负责。

## 操作同步

自动保存采用 150ms 防抖、持续编辑最多 500ms 进入调度；它不代表网络或远端可见延迟保证。开启协作后拒绝普通全量自动保存，转为带 `opId`、`baseRevision`、字段变更前值和节点 `incarnation` 的操作。

| 操作 | 校验与原子范围 |
| --- | --- |
| create_nodes | ID 不碰撞，关联节点存续，节点组和连线在一次事务内创建 |
| update_node | 节点 incarnation 匹配；metadata 对象递归合并叶字段，数组/标量原子比较，不覆盖无关字段 |
| delete_node / restore_delete | 生命周期、变更前内容和连线关系匹配；迟到请求不能复活旧节点 |
| restore_nodes | 批量撤销本人的删除；从服务端删除快照恢复内容和所选原连线，逐节点递增 incarnation |
| update_connections | 按 ID 提取相对基线的连线增删和字段修改；检查端点及其 incarnation，保留别人独立修改的连线 |
| update_canvas | 受允许的画布字段及其基线；业务项目关联另做归属检查 |
| restore_snapshot | 强校验当前 revision、快照访问与结构，更新生命周期并要求重新同步 |

服务端锁定画布，在事务内校验权限、修改结构、推进 revision 并保存请求/回执。幂等键为 `(canvas_id, actor_id, op_id)`，同键不同请求拒绝；事务成功后才广播。一个自动保存可能拆为多次 REST 操作，整个保存批次不保证一次性原子提交。

WebSocket 只承载已提交的通知。连续 revision 原地投影，消息缺口补拉事件或快照；恢复和合并通知 resync，5 秒轮询兜底。连接校验登录、画布访问和 Origin，发送前重新检查权限，包含 ping/pong、读写超时、消息上限和 Hub 溢出处理。

## 在线状态

presence 与内容版本分开：光标、视口和查看/输入/拖动/缩放状态不写画布历史。客户端约 120ms 合并发送、5 秒心跳、2.5 秒轮询；服务端状态 15 秒过期。离开画布取消请求并清理会话，坐标根据实时视口换算，姓名标签保持屏幕尺寸。

配置 Redis 时，presence 和已提交正文通知均可跨实例传播。正文使用 `canvas:collaboration:committed:v1` 频道，本机来源去重；大于 256 KiB 的通知降为 resync。订阅重连时要求本机房间补拉；每条 WebSocket 连接每 5 秒检查数据库 revision 和当前读权，补偿 Redis 漏通知及提交后进程退出的窗口。数据库操作日志是持久事实，Redis 不存放未提交正文。未配置 Redis 时仍有同实例通知与定期补拉。

## 草稿、重试和冲突

IndexedDB 按账号和画布保存共同基线、提交时内容、已确认内容、待提交原请求与阻塞状态，借助 Web Locks/进程队列串行写入。按需登录入口和全量快照入口都恢复未完成队列，不能把缓存草稿误当作服务端已确认内容。

丢失回执时重发相同请求；部分成功时只继续剩余请求；保存期间的新编辑在回执之上 rebase。草稿写入失败阻止替换当前编辑器内容。账号切换、加载过程中的编辑和视口变化沿用上游保护语义。

三方比较以共同起点、本机内容、远端内容为输入。不同节点/字段与相同最终值可自动合并；同字段不同结果、删除与编辑、同 ID 新增等需要人工确认。冲突保留本机内容并暂停该画布后续提交，其他画布可以继续同步。

界面提供快速处理和完整合并工作区，可选择本机/最新内容、展开修改前值、编辑文本、批量选择或下载草稿。提交时重新核对远端版本；旧回执不能把未解决冲突标为已同步。

撤销/重做在当前内容上构造条件反向修改，进入同一操作队列。远端变更不进入本人的历史；同字段已被他人修改则跳过该字段，仍可撤销其他叶字段。重做只重放上一次撤销实际改变的内容。删除恢复使用服务端保存的本人删除记录，不能靠客户端快照替换内容或复活别人删除的节点；恢复回执更新本机历史的 incarnation。撤销创建时，若其他成员新增了关联边，则保留该节点。撤销栈保留在当前页面，不提供跨设备撤销历史。

## 独立方案与合并

创建前先同步当前画布，可从当前内容或仍保留的历史版本创建。创建者成为方案 owner，来源成员按原角色复制；来源 owner 在编辑者创建的方案中成为 editor。跨所有者创建会清除不属于创建者的业务项目关联。

方案有真实画布、独立 revision、来源和共同基线；支持多层方案、返回直接来源、继续编辑、归档。默认合并回来源，也可显式选择其他有编辑权限的目标。

预览只读计算基线、方案与目标的三方差异。正式合并要求双方预览 revision，锁定方案关系及两个画布，校验目标写权限和人工选择，通过 CAS 写入目标、历史快照及合并记录。保留目标 ID、所有者、业务关联与创建时间。

成功合并推进共同基线，保留方案供下次修改；重复请求返回已经提交的结果。前端将合并与自动保存串行，收到回执后保留期间新增编辑并打开接收画布，在线成员收到 resync。只有方案 owner 可归档；归档不删除画布，后续合并被拒绝。

## 历史与存储

数据库迁移接续为 v30/v31/v32，添加协作开关、成员、节点生命周期、操作日志、方案关系及媒体授权；不改写已发布迁移。v32 为既有正文/历史中的所有者媒体补授权，再按来源授权与方案内容交集补齐独立方案。历史快照和资源引用继续使用上游机制。普通协作操作写操作日志，不为每项操作生成完整历史快照；恢复和分支合并保留快照事务。

详见 [数据库合同](../backend/backend-database) 和 [HTTP API](../backend/http-api)。

## 已知限制与验收

- 数组、画布根字段仍为原子合并；含点号的扩展对象键回退为对象整体冲突，避免歧义路径。真实冲突暂停该画布，提交路径保留全局串行队列。
- 撤销仅撤回基线仍匹配的内容；发生竞争时保留他人的后续修改，不能保证每个撤销都恢复整份旧快照。
- Redis 通知配合数据库补偿，不承诺通知恰好一次送达；presence 仍使用 HTTP 心跳/轮询，也没有端到端毫秒级性能验收。
- 自动化测试不替代两个真实登录账号、媒体权限、PostgreSQL 并发、Nginx/外层代理和浏览器明暗主题/窄屏验收。本次未部署生产。

待验收项维护在 [待测试](../progress/pending-test)。产品与架构调研见 [实时协作对照](./canvas-collaboration-realtime) 和 [协作演进方案](./canvas-collaboration-figma-plan)。
