# 电商平台风格与图片规则

电商 Agent 的跨境平台包含 SHEIN（希音）。选择平台后，风格推荐、逐张策划和图片提示词使用对应平台的资料。平台选择面板可查看规则、来源和待核实范围。

## 资料状态与维护

当前内置资料版本为 `commerce-platform-20261102-v1`，共36个平台，15个平台已查到部分官方资料，21个平台的详细政策仍待后台核实。“部分核对”只表示表中明确列出的要点有来源，不表示已获取完整规则、所有站点或完整禁词表。每个条目分别记录官方要点、视觉建议、风险、适用范围、来源和核对日期。规则库由前后端读取同一份JSON，变更后须同步发布前后端；当前没有自动抓取和定期刷新。

SHEIN 的时尚目录摄影、默认推荐3:4和主图不加字是保守设计方案，具体类目和销售模式的图片比例、张数、尺寸必须核对商家后台。不会把这些建议描述为SHEIN全平台硬规则。Amazon和TikTok美国站、Etsy、eBay、noon等规则存在差异，不能直接套用同一白底模板。

## 生成约束

- 商品主图、SKU图、副图、详情素材与站外广告分别处理。TikTok美国站商品图与短视频大字封面分开；其他站点未核实时采用无新增文字的保守方案。
- eBay刊登图的主副图均不新增营销文字、水印和边框。Etsy多数实体商品须额外保留真实背景下未经编辑的实物照片，生成图不能充当该原始照片。
- noon时尚类有浅灰背景例外；Mercado Libre配饰类不统一强制数字白底。背景要求与视觉家族分别维护。
- 高风险宣传词的示例词库用于本应用的保守文案检查，支持全角、空白、标点和不可见分隔符，不是所有平台的完整官方禁词表，也不能识别全部语言、同义词、隐喻或图内文字。新策划保存与提交生成前检查消费者文案；已绑定生成任务的历史图片保留。
- 普通生成与手动提示词都附加平台约束；图片模型可能不遵守提示词，因此提示词注入不代表成片合规。
- 缺失的商品参数、材质、资质与功效不能由平台风格补全。现有事实核验和发布前商家核对仍然适用。

## 发布前仍需核对

生成结果并非“可直接上架”认证。当前不读取真实店铺的站点类目配置、不执行平台上传审核，也没有成片OCR、像素背景检测、图片格式/文件大小自动转换、模型人物元数据写入或商品资质自动验证。商家发布前须核对成片文字、真实外观与随附件、格式尺寸、权利授权、商品准入和当前后台规则。Amazon含逼真AI人物的图片还须按官方要求处理元数据。

## 待验收

- 真实页面切换SHEIN、Amazon、TikTok、eBay、Etsy，确认选择持久化与规则展示。
- 普通生成和手动编辑各生成一张，核对主图文字、背景和商品保真；核对同一商品在不同平台的风格差异。
- 使用真实目标站点及类目在商家后台审核图片；缺少授权、受限商品或资质时不能仅凭图片判定可上架。
