# 精灵宠物

在“站点及外观 → 画布配置 → Agent 形象”导入宠物，预览就绪后选择“精灵宠物”，点击页面顶部“保存修改”。角色不内置在程序中，不限定画风。现有动态球与 Live2D 仍可独立选择。

上游已有的 `avatar.json` / MP4 状态动画包继续保留，并与动态球、Live2D、精灵图集统一接入形象库。视频 ZIP 导入与状态映射沿用上游功能；本文的 Codex ZIP 和图集动作编辑针对新增的精灵形象。

## 导入方式

- Codex v1/v2：上传包含 `pet.json` 和其引用图片的 ZIP，自动识别 192×208 单帧、标准动作和 v2 的 16 向注视。旧包未声明 `spriteVersionNumber` 时，仅按标准图集尺寸 1536×1872（v1）或 1536×2288（v2）识别；已声明版本仍须与图片一致，其他排列需要提供 `yinghui` 动作配置。
- 自定义图集：直接选择 PNG / 静态 WebP 图片，导入后设置单帧宽高、动作行列和帧数。图片初始作为一张静态帧，不猜测排列。
- 自定义包：ZIP 包内 `pet.json` 使用 `yinghui` 对象声明下面的配置；可附带 `.txt` / `.md` 授权文件。

ZIP 最大 16 MiB，最多 16 个条目，解压累计 24 MiB。直接导入图片最大 15 MiB。图片最大 4096×4096、最多 64 行/列，单帧至少 8px。只读取包内图片，不运行脚本或加载包提供的远程 URL。素材会发送到浏览器，请确认公开使用授权。

## 编辑动作

每个动作有唯一标识、显示名、行、起始列、帧数、帧率和循环开关。行、列和中立帧序号从 0 开始，动作在同一行内顺序播放，最多 48 个动作。图片尺寸由服务端确认；更换图片需要重新导入。

状态映射包括待机、工作、等待审批/回答、失败、完成、左右拖动、悬停互动、问候、睡觉和醒来。待机必须绑定；其他动作可关闭并使用待机。没有睡眠图片时不应把普通帧标成完整睡眠动画。

空闲自动睡眠默认关闭。绑定睡眠动作后可设为 60–3600 秒；键鼠活动会唤醒，运行任务、清理和待处理审批会阻止入睡。睡眠只改变形象，不会暂停 Agent 或更改权限。

动作优先表达真实业务状态，再处理拖拽与互动。完成只在当前任务确实转为完成且清理结束时短暂播放；加载历史记录或 SSE 重连不重复庆祝。停止、拒绝回到待机；断线保留最后可信任务状态。失败动作播放后可定格，错误详情仍由原有界面提供。

悬浮入口支持拖动、键盘移动和位置保存。对话面板标题栏保持无头像布局；欢迎区域使用当前用户所选宠物，精灵显示中立帧。后台“试播动作”不会启动真实任务。

## 用户选择与大小

右键宠物打开同心弧形菜单：换形象、调大小、锁位置和关闭菜单。圆角扇区共用内外半径与固定角度间距，按屏幕可用空间向内展开；形象缩略图沿外弧连续排列，不为凑满整圆而拉大间距，空缺自然保留。宠物保持原来的大小与位置，不换成缩小的预览；关闭按钮紧邻宠物。外弧最多三个形象和一个更多入口；超过数量可打开列表。大小使用 50%–150% 的滑块，步长 5%，100% 为系统默认宠物展示尺寸。滑动直接缩放当前宠物，面板保持稳定，松手保存。锁位置只阻止拖动和方向键移动，不影响打开对话。眼睛按钮关闭菜单，宠物与对话入口继续显示。

手机长按 500ms 打开底部面板；移动达到拖动阈值时取消长按并执行拖动，避免同时打开菜单。键盘可用菜单键或 Shift+F10 打开、Esc 关闭；Agent 设置也提供“宠物外观”入口。

用户切换形象后，画布悬浮宠物、对话欢迎区和创作首页 Agent 卡片同步显示所选形象；各位置保持适合自身布局的尺寸，大小滑块只调整悬浮宠物。位置锁定仅作用于悬浮入口，不改变对话标题、助手身份、任务权限或其他账号。登录用户按账号跨设备保存，游客按浏览器保存，游客设置不转入登录账号。保存失败显示本机暂存和重试入口；版本检查防止旧页面静默覆盖其他页面。系统减少动态效果变化会立即反映到悬浮宠物和首页。

不同形象共享相同的正方形展示区域，按原始宽高比居中放入，避免切换时尺寸或锚点跳变。悬浮区域采用系统默认高度乘个人倍率；欢迎区为88px、首页为112px、缩略图为44px。宽角色受宽度约束，不拉伸或裁切；动态球不再额外缩成小尺寸。后台素材自身动作与画布原有文字不受影响。

菜单仅保留操作项与关闭按钮，不额外显示常驻设置按钮、标题标签或默认说明；准备形象、加载、保存及错误状态按需显示，正常状态不占位。首页单独进入也会读取账号偏好；已下架形象统一回退系统默认。

菜单整体展开和收起、形象切换及展示入口采用约 160–200ms 的淡入淡出和轻微位移，弧形按钮按短间隔依次浮现，操作不等待动画结束；减少动态效果开启时取消位移、缩放与过渡。首次读取账号偏好期间显示加载状态，后台刷新保留已显示的形象，避免闪回系统默认。

后台形象库最多支持 64 个形象，可搜索、按发布状态筛选并分页浏览。支持批量导入精灵 ZIP，按顺序处理并显示进度；单个失败保留成功结果，已存在的相同资源跳过。可选择导入后发布，导入结果仍需统一保存才生效。选中形象后编辑名称、发布状态、排序与系统默认，助手身份与高级动作设置默认折叠。默认项必须已发布；未发布的形象不对普通用户提供资源。后台默认大小为 120–360px 滑块，保留统一保存/撤销流程。用户端“更多形象”支持搜索和滚动查看完整已发布形象库。

## 自定义配置示例

将以下 `pet.json` 与一张 256×128、每格 64×64 的 `atlas.png` 一起打包。图集第一行四帧待机、第二行四帧睡眠。实际图片必须与配置一致。

```json
{
  "displayName": "我的角色",
  "spritesheetPath": "atlas.png",
  "yinghui": {
    "displayName": "我的角色",
    "atlasWidth": 256,
    "atlasHeight": 128,
    "frameWidth": 64,
    "frameHeight": 64,
    "neutralFrame": 0,
    "lookStartFrame": -1,
    "lookDirections": 0,
    "speed": 1,
    "sleepAfterSeconds": 300,
    "author": "",
    "source": "",
    "license": "",
    "actions": [
      {"id":"idle","label":"待机","row":0,"start":0,"frames":4,"fps":4,"loop":true},
      {"id":"sleep","label":"睡觉","row":1,"start":0,"frames":4,"fps":3,"loop":true}
    ],
    "bindings": {"idle":"idle","sleep":"sleep"}
  }
}
```

可导出后台调整后的 `pet.json`，与原图片一起重新打包复用。导出不包含图片或授权转让。增加睡觉、跳跃等动作时，先制作对应帧，再扩展图集、重新导入和绑定。

减少动态效果模式使用中立帧，任务文字和审批标识继续工作。角色隐藏、离开视口或浏览器后台时暂停播放。原始单帧尺寸决定清晰度，放大显示不会补出新细节。

未发布且未入库的包只能由上传管理员预览；形象库引用的包可由其他管理员维护。当前启用形象和已发布形象通过专用公开接口读取；下架后用户回到系统默认。草稿和已发布条目的资源都受引用删除保护；先移除引用并保存，再清理资源。

形象列表使用独立的中立帧透明PNG（最长边88px），只在可见区域及下一行附近加载，最多同时下载3张。完整动画图集只为正在展示的角色加载，并保留独立请求通道。小图淡入，短暂网络失败自动重试一次，不增加常驻文字或控制按钮。

浏览器按账号隔离图片缓存，退出或切换账号时释放；未使用图集最多保留3张、估算64 MiB、2分钟，缩略图最多64张、4 MiB、10分钟，超额先释放未使用项。当前正在展示的图片保留到组件释放。服务器在资源目录的`cache/sprite-v1`缓存派生图片，预算256 MiB，可自动淘汰和重新生成；原始ZIP与动作配置保持。新导入时预生成，既有形象首次访问时补齐。图片接口支持ETag重新验证，取消发布和草稿权限仍先于缓存读取校验。
