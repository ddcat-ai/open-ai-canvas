# 人声与伴奏分离

在有音频内容的节点上打开「音频处理 → 人声 / 伴奏」。可以提取人声、提取伴奏，或同时输出两轨；默认同时输出，两轨共用一次推理。

配置面板使用三张选轨卡片，并将首次下载和输入限制收在「首次使用与处理说明」中。开始后立即关闭配置，左下角任务卡展示进度；处理期间可以继续编辑、拖动画布、播放媒体。任务卡可收起，关闭配置不会取消任务，只有任务卡中的「取消」会中止处理。完成后不会自动切换选中节点或抢走输入焦点，点击「查看结果」才定位结果；失败可在卡片直接重试。

分离在当前浏览器的 Worker 中执行 Demucs ONNX 模型，使用单线程 WASM，不消耗模型渠道额度。输入解码为 44.1 kHz 双声道，单声道复制到左右声道。人声取 vocals，伴奏由 drums、bass、other 相加；输出统一为 44.1 kHz 双声道 16-bit PCM WAV。只对过载结果整体衰减，不自动放大安静片段。

支持不超过 128 MiB、180 秒的音频。首次使用需下载约 172 MiB 模型；浏览器 Cache Storage 可用时会缓存。模型固定上游 revision，并核对文件长度和 SHA-256；缓存不可用时本次仍可处理。默认下载源为 `https://hf-mirror.com`，部署时可通过 `VITE_AUDIO_STEM_MODEL_BASE_URL` 指定 HTTPS 模型镜像根地址，镜像需保留相同仓库路径并允许浏览器跨域读取。此变量在前端构建时生效。

任务卡分别显示读取、模型下载校验、推理、保存阶段。阶段百分比不代表整体剩余时间，推理阶段最多显示 99%；初始化或未获得进度时显示「处理中」，不会长期显示误导性的 0%。推理超时为 15 分钟，模型下载超时为 10 分钟。同一页面一次只运行一个分离任务。解码与传输使用异步接口，模型推理和 WAV 编码在 Worker 内执行，进度按阶段及百分比去重并以低优先级更新。

点击任务卡「取消」会终止模型下载或推理 Worker，并中断本次素材读取等待与结果上传。素材缓存下载可能由播放器等其他调用方共享，取消分离只释放本次等待，不影响其他读取者；源素材读取取消后可以立即重新分离，旧读取完成不会继续推理或写回。浏览器音频解码本身不提供强制中断能力，取消会在解码返回后停止后续操作。切换画布、退出页面、切换账号、删除或替换源音频都会阻止旧结果继续写入。

结果上传绑定任务开始时的账号及取消信号。音频元数据读取期间切换账号不会发起旧任务上传；实际上传请求也会校验预期账号。取消和会话失效不会被当作上传失败而降级为本地暂存。

结果沿用现有媒体上传与素材同步流程，在源节点右侧创建新音频节点并连线，原素材和节点保留。分离过程中源音频留在本机；分离完成的结果会按现有流程上传。上传暂时失败而回退本地缓存时会明确提示「尚未上传至服务端」。两轨逐条保存，后续保存失败时已经生成的节点仍保留；取消不会撤销已经保存的节点。

分离质量取决于混音与录音条件，可能残留背景音或人声。本机需要足够内存，当前实现未提供服务端分离或自动切换计算位置。真实设备速度、听感、浏览器资源路径与缓存持久化仍需按待测试清单验收。
