# 姿势库

姿势库是站点级的人物动作参考图库。用户在画布里浏览姿势、切换视角、多选后插入画布，再把姿势图连到生图节点，让人物按这个姿势生成。

影策代码仓库和发布镜像**不包含任何姿势图片**。站长部署后导入元数据，再让服务器把图片下载到本站数据目录。首批数据来自开源项目 [anhao/ai-pose-gallery-zh](https://github.com/anhao/ai-pose-gallery-zh)，之后可以在后台逐张新增，或用通用姿势包导入其他来源。

## 版权与内容边界

- ai-pose-gallery-zh 的代码以 MIT 协议开源，但它明确说明 MIT **不覆盖** `img/`、`thumbs/`、`data/` 中的图片与原始数据。姿势素体的版权归原作者 ギア（@giaaibusi），仓库禁止把图片打包倒卖。
- 影策只提供导入和同步工具，不分发图片。站长在自己的站点使用前，需要自行确认原作者的使用条件，商业运营尤其要先取得授权。
- 画布弹窗不显示任何来源或署名：姿势库可以只装站点自己的素材。来源名称、署名和主页只记录在后台（「姿势库」列表与按体系管理）；使用第三方素材时，按原作者要求在站点协议或说明页里注明，由站长负责。
- 原始数据有 4 个体系：全身单人・标准系（365）、上半身单人（400）、全身单人・性感系（399）、双人缠绵（275）。后两个是成人向内容，导入时**默认不勾选**。导入后所有登录用户都能看到，是否导入由站长按用户协议和当地法规决定，之后也可以在后台按体系停用或删除。

## 站长：从 ai-pose-gallery-zh 导入

### 1. 下载 pose-zh.json

只需要一个文件：仓库的 [data/pose-zh.json](https://github.com/anhao/ai-pose-gallery-zh/blob/main/data/pose-zh.json)，约 0.6 MB，只有中文元数据（1439 条：体系、分类、姿势名称、编号、视角、图片相对路径），不含图片。在 GitHub 页面点「Download raw file」，或在能访问 GitHub 的机器上执行：

```bash
curl -L -o pose-zh.json https://raw.githubusercontent.com/anhao/ai-pose-gallery-zh/main/data/pose-zh.json
```

不需要下载整个仓库（约 1.1 GB，还包含服装、人像等本功能用不到的图）。

### 2. 后台导入

1. 管理员进入后台「创作与扩展 → 姿势库」，点「导入数据」。
2. 选择 `pose-zh.json`。页面会列出 4 个体系和条数，标准系和上半身默认勾选（共 765 条）。
3. 「图片来源地址」默认是作者演示站 `https://ai-pose-gallery.anhao.app/`。JSON 里的 `thumbs/…`、`img/…` 会拼在这个地址后面。
4. 点「导入」。新条目进入「待同步」，这时用户还看不到。

同一份文件可以重复导入：已有条目按 ID 只更新名称、分类等元数据，已同步的图片不动；之前同步失败的条目重新排队。以后想追加成人向体系，再导入一次并勾选即可。

### 3. 同步图片

在后台点「同步图片」。服务器按批（每批 12 条）下载缩略图和原图，页面显示进度，可以随时停止、下次继续；失败的条目点「重试失败」。

| 范围 | 条数 | 约占磁盘 |
| --- | --- | --- |
| 标准系 + 上半身 | 765 | 约 220 MB |
| 全部 4 个体系 | 1439 | 约 700 MB |

原图是 900×1200 PNG（约 270 KB/张），缩略图是 300×400 JPEG（约 15 KB/张）。同步速度取决于服务器到来源站点的网络，765 条一般需要十几到几十分钟。

图片保存在后端数据目录的 `pose-library/<条目ID>/` 下（Docker 部署即 backend 的数据卷），不进 `resources` 表，也不计入任何账号的容量。备份时随数据目录一起备份；如果数据目录丢失，在「按体系管理」里点「重新同步」，再点「同步图片」。

### 4. 服务器访问不了来源站点时

国内服务器访问 GitHub 或 Cloudflare 常常不稳定。图片来源地址可以换成任何你能控制的 HTTPS 静态地址，只要目录结构保持 `thumbs/<文件名>`、`img/<文件名>`：

1. 在能访问 GitHub 的机器上只取姿势需要的文件：

   ```bash
   git clone --depth 1 --filter=blob:none --sparse https://github.com/anhao/ai-pose-gallery-zh.git
   cd ai-pose-gallery-zh
   git sparse-checkout set --no-cone 'data/pose-zh.json' 'thumbs/full_single_*' 'img/full_single_*' 'thumbs/upper80v2_*' 'img/upper80v2_*'
   ```

   需要成人向体系时再加 `full_sexy_*`、`pair60_*` 两组。

2. 把 `thumbs/` 和 `img/` 两个目录原样上传到自己的对象存储（公共读）或静态站，例如 `https://cdn.example.com/poses/thumbs/…`。
3. 导入时把「图片来源地址」填成 `https://cdn.example.com/poses/`。已经导入过的，重新导入一次并改地址即可。

来源地址经过出站 SSRF 防护，本机、内网地址默认被拒绝。确实要用内网静态服务时，在后端环境变量 `CANVAS_ALLOWED_PRIVATE_UPSTREAM_HOSTS` 里精确列出该主机名，不要放开全部私网。

## 用户：在画布里使用

- 入口：画布底部工具条的「姿势库」按钮、「添加节点」菜单的「导入资源」分区，或画布空白处右键「添加节点 → 姿势库」（插到右键位置）。工具条按钮可在「工具栏设置」里隐藏。
- 浏览：按名称、分类或编号搜索，按体系、分类和视角（正面、斜侧、侧面、背面、俯视、仰视）筛选，下拉自动加载更多。卡片下方切换视角，悬停时点右下角查看原图。
- 选择：点卡片选中当前视角，同一姿势的不同视角可以都选，一次最多 16 张，底部可移除或清空。
- 插入：点「插入画布」。服务器先把原图复制成你自己的资源，再生成图片节点，标题为「姿势参考·姿势名·视角」，可以直接 @ 引用。复制按普通上传计入你的每日上传额度和账号容量（每张约 270 KB）。同一张图重复插入会复用已有资源，不重复占用。
- 生成：把姿势图连到生图节点作为参考图，在提示词里写明「人物保持参考图的姿势」，再配合人物、服装参考图使用。

管理员删除或停用姿势后，用户已插入画布的图片不受影响，因为那是各自名下的副本。

## 站长：新增与扩展

### 后台逐张新增

后台「新增姿势」上传一张图（JPEG/PNG/WebP，20 MB 以内），填写名称、体系、分类、视角和可选编号；缩略图自动生成。编号相同的多张图会合并为同一个姿势的不同视角。这类姿势的来源显示为「站点自建」，不需要同步。

### 通用姿势包格式

要批量导入其他来源，按下面的格式写一个 JSON，在「导入数据」里选择即可：

```json
{
  "format": "yingce-pose-library",
  "version": 1,
  "source": {
    "key": "my-studio-poses",
    "name": "工作室动作库",
    "attribution": "摄影：某某工作室",
    "homepage": "https://example.com/poses",
    "baseUrl": "https://cdn.example.com/poses/"
  },
  "items": [
    {
      "key": "walk_001_front",
      "group": "walk_001",
      "code": "W001",
      "system": "全身单人",
      "category": "走姿",
      "name": "回头走路",
      "angle": "正面",
      "thumb": "thumbs/walk_001_front.jpg",
      "image": "img/walk_001_front.png",
      "keywords": ["回眸", "街拍"]
    }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `source.key` | 来源标识，2–64 位小写字母、数字、`-`、`_`，不能是 `custom`。同一 key 重复导入时按条目 `key` 更新 |
| `source.baseUrl` | 相对图片路径的根地址；后台填写的「图片来源地址」优先 |
| `items[].key` | 来源内唯一 ID，必填 |
| `items[].group` | 同一姿势多视角共用的分组，缺省时每条单独成组 |
| `items[].image` | 原图，必填；相对路径（拼到 baseUrl 后，不能以 `/` 开头或含 `..`）或 http/https 绝对地址 |
| `items[].thumb` | 缩略图，可省略，省略时同步阶段由原图生成 |
| `items[].angle` | 中文视角，或 `front/diag/side/back/high/low`；缺省为正面 |
| `system`、`category`、`name`、`code`、`keywords` | 展示、筛选和搜索用；`name` 必填 |

导入时仍要勾选体系。图片同样由「同步图片」下载到本站，只支持 JPEG/PNG/WebP，单张 20 MB、8192×8192 以内。

ai-pose-gallery-zh 里的深度图（`thumbs/depth/<id>.webp`、`img/depth/<id>.webp`，可用于 ControlNet Depth）、服装库和人像库目前没有内置导入。需要时可以按上面的格式生成一个独立来源的姿势包。

## 实现边界

- 接口见 [HTTP API 合同](/docs/backend/http-api) 的「姿势库」，数据表见 [后端数据库](/docs/backend/backend-database) 的 Schema 85。
- 图片文件在后端本机数据目录，不走对象存储；多个后端副本必须共享同一数据目录。
- 用户浏览时只访问本站接口，不请求来源站点；只有管理员同步时服务器才访问来源地址。
- 弹窗文案目前只有中文。
