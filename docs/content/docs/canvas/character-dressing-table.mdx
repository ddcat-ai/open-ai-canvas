# 角色梳妆台

在自由画布角色卡上单击「梳妆台」，或在角色工作室切换到「梳妆台」。先在「形象」中选择本次基础人物图，再输入需要调整的内容，选择支持参考图的图片模型和图片参数，点击「生成新形象」。模型选择器继续显示站点原有价格信息，任务沿用原有额度与计费规则。

生成完成后选择一张图片，输入形象名称，点击「保存为角色形象」。保存会新增同一角色的造型，保留原形象、声音与设定，并让发起节点选用新形象；同角色其他节点保持自己的选用形象。新形象可以在原有形象库中重命名和重新选用。

生成成功与保存角色成功是两个步骤。保存失败时保留产出，重试保存不会再次调用图片模型。角色被其他操作更新时，刷新角色后重新保存；不会静默覆盖其他形象。生成结果来源记录在角色造型中，重命名不会删除来源。

分享画布中的角色仅供查看；官方只读角色需要先沿用原有复制能力保存为自己的角色。身份一致性取决于模型与参考图，梳妆台会表达保留身份的意图，但不能保证每个模型都准确执行。
