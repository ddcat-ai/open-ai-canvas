# 角色梳妆台

在自由画布角色卡上单击「梳妆台」，或在角色工作室切换到「梳妆台」。先在「形象」中选择本次基础人物图，再输入需要调整的内容，选择支持参考图的图片模型和图片参数，点击「生成新形象」。模型选择器继续显示站点原有价格信息，任务沿用原有额度与计费规则。

生成完成后选择一张图片，输入形象名称，点击「保存为角色形象」。保存会新增同一角色的造型，保留原形象、声音与设定，并让发起节点选用新形象；同角色其他节点保持自己的选用形象。新形象可以在原有形象库中重命名和重新选用。

衣服、表情、姿势、配饰、发型、五官六个槽位均为选填，每类最多一张图片。点击槽位复用素材选择器搜索、预览并选择个人素材，也可以上传后自动归入当前类别。素材库的新增、编辑和批量上传均可手动设置业务分类；旧道具不会自动改成衣服或配饰，需要自行整理。

选择任何参考图后，附加提示词可以留空。未选素材时需要填写提示词。模型的参考图上限包含基础人物图，同图用于多个类别只传一份；不支持或超限时需要减少参考图或更换模型，系统不会静默丢弃素材。

素材选择器支持「官方素材」和「我的素材」。梳妆台选用官方图片时，先通过已有导入能力加入个人库，再作为参考使用；重复选用不会重复导入。站点未启用官方素材库或没有内容时，仍可使用个人素材。

管理员在原有官方素材后台设置六类业务分类，维护标题、说明、标签、来源、授权、排序与发布状态。未发布素材不对用户显示；下架停止新导入，已经导入的副本沿用原有保留规则。梳妆台不增加独立素材表或管理后台。

点击「从姿势库选择动作与视角」可复用站点已有姿势库。梳妆台中一次选一张，切换视角后确认，服务器将原图复制为当前用户资源并填入姿势槽；不需要插入临时画布节点。姿势库的原有画布入口仍支持多选插入，图库仍由原后台维护。

生成成功与保存角色成功是两个步骤。保存失败时保留产出，重试保存不会再次调用图片模型。角色被其他操作更新时，刷新角色后重新保存；不会静默覆盖其他形象。生成结果来源记录在角色造型中，重命名不会删除来源。

关闭面板不会取消任务。再次打开梳妆台会读取该角色的历史生成，最新任务自动恢复；展开「历史生成」可选择之前的结果，或加载更早记录。生成中可以使用「取消任务」，状态以服务端结果为准。角色或画布节点被删除时，已生成图片仍可从有权访问的任务中心记录找到；不会自动重建节点。

分享画布中的角色仅供查看；官方只读角色需要先沿用原有复制能力保存为自己的角色。身份一致性取决于模型与参考图，梳妆台会表达保留身份的意图，但不能保证每个模型都准确执行。
