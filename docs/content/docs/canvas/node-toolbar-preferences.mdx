title: 节点工具栏个人配置

本文记录节点工具栏个人配置的产品边界与验收场景。核心实现已落地，真实画布及跨设备手工验收见待测试清单。

## 目标

用户可以把常用的已有工具固定到节点工具栏，减少打开分组菜单寻找工具的步骤。例如，将「调整尺寸」或「去除背景」固定为图片节点工具栏上的直接入口。

## 已确认范围

- 自定义的是已有工具的入口位置，工具本身的处理功能沿用现有实现。
- 固定入口属于个人偏好，仅作用于当前用户。
- 同类型节点在该用户的所有画布中共用一套配置，不按画布或单个节点分别配置。
- 首版覆盖图片、视频、音频和文本节点，四类分别配置。

## 工具栏行为

- 保留「画面调整」「镜头」「创作预设」「图片工具」等现有分类菜单，沿用当前的分类组织。
- 分类菜单和具体工具统一作为工具栏入口管理，都支持固定、取消固定和调整顺序。
- 用户可以选择哪些入口直接显示，并调整外层入口的顺序。
- 分类菜单保留当前节点适用的完整工具清单。固定具体工具后，该工具仍保留在原分类中。
- 具体工具与所属分类菜单的固定状态相互独立；例如，取消固定「图片工具」不影响已固定的「调整尺寸」。
- 取消固定只将入口收回菜单，工具和分类菜单仍可从「更多」或保留的分类入口找到。
- 入口继续沿用现有节点类型、内容状态和功能可用性判断，固定状态不改变工具的执行条件。
- 未配置时沿用现有默认布局，恢复默认作用于当前编辑的节点类型。

## 配置入口

- 统一入口为节点工具栏的「更多 → 自定义工具栏」。
- 固定、取消固定、调整顺序和恢复默认全部在该面板中完成。
- 已固定入口的卡片提供前移、后移按钮及拖动把手，支持方向键调整顺序；首尾入口禁用越界方向。
- 面板顶部展示草稿的实时工具栏预览，固定、排序、恢复默认都会立即反映到预览中；预览复用真实工具栏的样式和宽度收纳规则，不执行工具。
- 点击保存前，预览和排序只影响当前草稿；取消关闭不会写入账号配置。
- 菜单中的工具项继续用于执行工具，入口的固定状态由配置面板统一管理。
- 取消全部固定入口后，仍可通过「更多 → 自定义工具栏」重新配置。

## 空间不足时的展示

- 按用户配置的顺序优先展示固定入口，末尾放不下的入口自动收入「更多」。
- 空间变宽后，按原顺序恢复外层展示。
- 自动收纳只影响当前展示，不改变固定状态或已保存的顺序。
- 「更多」及其配置入口始终保持可达。

## 保存与同步

- 配置跟随账号保存，换浏览器或设备后仍可读取同一套配置。
- 服务端保存当前用户按节点类型划分的固定入口和顺序，浏览器副本作为缓存。
- 仅本地缓存成功不能表示账号配置已保存；服务端保存失败必须向用户反馈。

保存边界同时记录在仓库决策文档 `docs/adr/0056-node-toolbar-preferences-account-storage.md`。

## 领域词汇

- **节点工具栏**：在画布节点旁提供该节点操作入口的工具栏，可用工具取决于节点类型及内容状态。
- **工具栏入口**：节点工具栏中的操作项，包括具体工具入口和分类菜单入口。
- **固定入口**：用户选定、优先在节点工具栏外层展示的工具栏入口。

术语定义维护在仓库根目录的 `CONTEXT.md`。

## 实施边界

- 复用已有工具定义、分类、图标、文案与执行处理，不另建一套工具执行链路。
- 统一面板复用现有工具栏配置能力，补齐四类节点的入口目录及账号保存读取链路。
- 此次仅调整节点工具栏个人配置，其他工具栏继续沿用各自的现有配置方式。

## 待执行的验收场景

| 场景 | 预期结果 |
| --- | --- |
| 将「调整尺寸」或「去除背景」固定到图片节点工具栏 | 外层出现直接入口，点击沿用现有处理流程，原分类中仍可找到该工具。 |
| 取消固定「图片工具」，保留「调整尺寸」 | 分类菜单收回「更多」，「调整尺寸」继续按个人顺序展示。 |
| 固定分类菜单并调整顺序 | 分类菜单与具体工具按用户设置的混合顺序展示，分类内容保持完整。 |
| 通过前移、后移按钮或拖动调整位置 | 顶部预览立即按新顺序展示；拖过同一卡片内部元素不会反复交换位置。 |
| 查看预览并取消配置 | 预览不执行工具，取消后账号配置保持原样。 |
| 切换节点类型与画布 | 四类节点分别使用各自配置，同类型节点跨画布共用。 |
| 同一账号换浏览器或设备 | 读取服务端已保存的固定入口及顺序；不同账号的配置相互隔离。 |
| 缩小后再恢复可用宽度 | 末尾入口自动收纳并按原顺序恢复，保存的固定状态与顺序不变。 |
| 取消全部固定入口并恢复默认 | 始终能够进入「更多 → 自定义工具栏」，恢复当前节点类型的默认布局。 |
| 服务端保存失败 | 明确反馈失败，本地展示或缓存不被表示为账号配置已保存。 |
