# 电商批量换装

批量换装位于创作模式的电商入口。选择换装功能后，添加人物、服装或姿势参考图，选择模型与输出规格，再提交生成。不同功能使用不同的参考图角色；服装图用于保持服装款式、颜色与图案，人物图用于保持人物身份，姿势图用于指定动作。

规划使用所选文本模型理解参考图并生成各张图片的提示词，出图使用工作台图片任务。规划与出图分别按模型计费；提交前应核对模型、参考图和数量。生成结果按批次展示，可查看原图、下载和恢复历史批次。

## 姿势库与服装库

换装页面提供姿势和服装素材选择。两类素材使用站点图库服务，按类别筛选，可搜索并预览。选中后先复制为当前用户的资源，再作为参考图参与任务；管理员后续停用或删除图库条目，不会删除用户已保存的副本。

后台分别提供「姿势库」和「服装库」管理入口，支持新增、导入、图片同步、启停和删除。只有已启用且同步完成的条目对普通用户可见。导入格式和图片存储边界见[姿势库](/docs/canvas/pose-library)。

代码仓库不随附第三方姿势或服装图片。空库部署由管理员上传自有素材，或在取得相应使用授权后导入；图库未配置时用户仍可上传自己的参考图。

## 后台功能开放

电商 Agent 的「功能开放」页面管理电商总开关和各项批量换装功能。保存成功后，页面与服务端使用同一份配置。单项关闭时仅管理员可使用，普通用户不能通过直接调用换装任务接口绕过；电商总开关关闭时停止新的电商规划与生成，保留历史记录。

配置保存在已有功能开放设置中，不携带站点账号、模型渠道或密钥。部署者仍需配置自己的可用文本模型与图片模型。

## 批次删除

只有当前用户的已结束批次可以删除；排队中或执行中的批次必须等待结束。删除操作同时处理批次任务与对应作品记录，资源清理遵循已有引用保护规则。删除前请先下载需要保留的结果。

## 验证边界

单元测试与构建检查覆盖接口、权限和数据流，不能证明实际模型的换装质量。部署后还需使用测试账号检查空图库、素材导入、功能开关、历史恢复及批次删除，并分别验收人物身份、服装细节和姿势保持效果。
