# 电商智能创作插件

`电商智能创作` 是官方应用插件，内部 ID 为 `igo-studio-ecommerce-agent`。它在现有创作 Composer 旁增加“智能创作”模式按钮，用 Agent 理解自然语言意图并规划生成任务。原有“AI 提示词优化”按钮保持不变；两个插件同时启用时，两个按钮会并列显示。智能创作继续使用原 Composer，不新增第二个对话输入框。

## 本地安装与启用

官方包位于仓库根目录的 `plugin-packages/igo-studio-ecommerce-agent.yingce-plugin`。宿主启动或重启时自动扫描官方 `plugin-packages` 目录并同步包，不需要打开浏览器上传。开发环境如需使用其他目录，可设置 `CANVAS_OFFICIAL_PLUGIN_DIR` 后重启宿主。

插件中心只控制用户是否启用。启用 电商智能创作 后显示“智能创作”；停用或卸载后按钮隐藏，图片、视频、文本创作和“优化”功能继续可用。

## Agent 如何工作

用户用自然语言描述商品、平台、市场、语言、卖点和参考素材。Agent 先理解目标，再返回可审阅的结构化计划：

- 明确的信息直接写入计划；
- 已有提示词和参考图时使用合理默认值直接规划；只有无法推断且会改变结果的关键歧义才追问，每轮最多一个问题；用户说“直接生成”或“不要管细节”时直接执行；
- Amazon 产品套图会自行判断站点语言、主图/卖点图/场景图/细节图用途、图片尺寸、比例和平台合规规则；
- 多张附图按卖点、场景或细节拆成独立任务；宿主一次性并发提交每张图片的独立请求，并按完成顺序返回，非智能模式继续保留原对话的多图返回；
- Amazon 套图会生成一条可复用的 `visualDirection`，锁定产品身份、材质、色彩、布光、镜头语言和高级橱窗陈列感，并注入每张任务提示词；没有普通生活方式快照和廉价库存图的默认风格；
- 商品事实、功效、认证和参数只能来自用户输入或参考素材。

每个已确认的计划会同时写入当前创作对话和后台 Agent 记忆，分类为“智能创作”（`smart_creation`）。后续消息会复用当前对话中最近一次计划和参考图，只把用户新增的修改交给 Agent；重新打开该对话也会恢复这份计划上下文。

智能创作打开期间，Composer 的分辨率、宽高比、质量和生成数量不参与请求，Agent 计划中的任务设置是唯一参数来源。关闭智能创作后，手动设置恢复原有行为。模型请求或计划解析失败时，界面保留对话并提示重试，不静默套用固定模板。

计划明确后，宿主为每个任务独立调用现有图片生成链路并一次性提交，记录计划版本、目标平台、市场、语言、视觉指导和任务设置。每张结果按完成顺序写入同一个套图批次的聚合消息，任务状态、失败重试和资源持久化沿用现有创作运行时。
