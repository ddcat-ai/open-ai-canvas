# 插件显示形态

画布插件支持三种显示形态：

- 非全屏（`node`）：插件作为画布节点嵌入当前画布，适合素材引用、角色卡、提示词、分析结果和轻量编辑。
- 全屏（`fullscreen`）：插件打开独立的全屏工作台，适合素材浏览、时间线、批量生成、复杂编辑和外部服务管理。退出后返回原画布和原节点上下文。
- 混合（`node` + `fullscreen`）：同时提供紧凑节点和全屏编辑器。节点负责预览与输入输出，全屏界面负责复杂操作；Eagle 素材连接器建议采用这种形态。

全屏界面由宿主提供 `openSurface` / `closeSurface` 能力，插件不能自行修改宿主路由。宿主负责传入当前项目、当前节点、主题、权限和未保存状态。

插件清单可以声明支持的显示形态：

```json
{
  "surfaces": ["node", "fullscreen"]
}
```
