# 卡藏 Midjourney

统一声明式 `yingce.plugin/v2` 插件，提供三个生图协议入口：`kacang-midjourney-special`（V6/V8 特惠）、`kacang-midjourney-v7`（V7 特惠）、`kacang-midjourney`（稳定/高速）。使用宿主鉴权、出站校验、轮询、资源保存和计费合同，不执行额外插件代码。

选择协议后，“能力与参数”自动填入对应比例、默认比例、参考图上限和一次提交。特惠默认 16:9；稳定/高速默认 9:16。V7 特惠与稳定/高速支持 auto 和 9:21。单次 n=1 表示一次提交；所有实际返回的图片均保存，包含上游提供的可选四宫格封面。

稳定/高速使用任务接口，首响应只是受理确认。插件保留公开任务 ID 并查询 `/v1/tasks/{task_id}`，不会将受理当作成功，也不会重新提交收费任务。特惠走标准图片接口。模型 ID 必须填写卡藏公开 API 模型 ID。

完整请求、模型清单、默认参数和结果合同见 [docs/interface.md](docs/interface.md)。
