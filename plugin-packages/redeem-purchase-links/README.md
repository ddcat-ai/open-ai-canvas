# 购买兑换码

在积分中心增加独立的“购买兑换码”选项，支持没有在线支付渠道或支付回调的站点。

1. 此版本已自带插件，可直接在后台找到。已支持购买入口接口但未自带该插件的宿主，可上传本目录对应的 `.yingce-plugin` 包；不要覆盖同 ID 的内置插件。
2. 在后台插件管理的设置按钮中配置套餐名称、价格、介绍和购买链接。
3. 保存配置并启用插件，用户即可在积分中心打开外部售码平台。
4. 用户在外部平台付款取得兑换码后，返回积分中心兑换到账。

随版本自带的插件默认关闭。独立上传沿用宿主自动启用策略，请先关闭入口，配置实际购买地址后再启用。示例地址不是有效商店。外部平台应发放由本站生成的有效兑换码；插件不负责外部库存或发码。

购买链接使用新标签页，不创建宿主支付订单、不接收支付回调、不自动增加余额。实际到账只通过现有兑换码接口完成。
