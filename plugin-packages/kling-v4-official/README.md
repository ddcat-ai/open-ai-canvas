# Kling 4.0 Official API

使用对应区域的新版 Bearer API Key。中国区地址为 https://api-beijing.klingai.com，国际区为 https://api-singapore.klingai.com。两种型号都可在 Omni 中引用视频。单独提供的北京渠道示例只对无输入视频的组合报价。模型设置从绑定版本读取模式、分辨率和时长范围。

后端从生成的 `kling-v4-official.yingce-plugin` 包加载，不依赖系统内置 `host:` 适配器。

完整接口见 [docs/interface.md](docs/interface.md)。
