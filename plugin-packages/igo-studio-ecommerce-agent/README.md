# 电商智能创作

`电商智能创作` 是官方应用插件，为创作页现有的对话 Composer 增加“智能创作”模式。它和“AI 提示词优化”是两个并列控制：原有“优化”功能继续保留；启用本插件后，现有创作输入框旁会额外出现“智能创作”按钮，但不会新增第二个对话框。

## 本地官方包

插件包位于仓库根目录的 `plugin-packages/igo-studio-ecommerce-agent.yingce-plugin`。宿主启动或重启时会从官方 `plugin-packages` 目录自动同步并加载这个包，不需要通过浏览器上传。自定义目录可通过 `CANVAS_OFFICIAL_PLUGIN_DIR` 指定。插件中心只负责按用户启停，不改变官方包的加载来源。

启用后，智能创作按钮才会显示；停用或卸载后按钮隐藏，原有图片、视频、文本创作和提示词优化继续可用。卸载不会删除已经生成的资产、任务或历史记录。

## Agent 行为

智能创作接收自然语言和参考素材，由模型理解目标并形成可审阅的结构化计划。已有提示词和参考图时会直接从上下文推断产品外观与用途并使用合理默认值；只有无法推断且会改变结果的关键歧义才追问，每轮最多一个问题。用户说“直接生成”或“不要管细节”时直接执行，不用固定套图模板代替用户意图。参考图会以多模态图片输入交给 Agent，不会只把 URL 当普通文本。

已确认的计划会保存在当前创作对话，并同步到后台 Agent 记忆的“智能创作”（`smart_creation`）分类。后续消息自动沿用最近计划和参考图，只处理新增修改；重新打开对话也会恢复上下文。

以 Amazon 产品套图为例，计划会给出用途、语言、提示词、参考素材、平台规则和整套复用的 `visualDirection`、`styleBible`。视觉指导锁定产品身份、材质、色彩、受控主光与轮廓光、镜头语言和高级橱窗陈列感；多张附图按卖点、场景或细节拆成独立任务，宿主按 manifest 中的 `execution.maxConcurrency` 有界并发调用图片模型，并按完成顺序写入同一个批次消息，界面以堆叠缩略图展示并可展开预览。账号活动任务达到上限时，宿主按 `capacityWaitMs` 等待空位，不把暂时拥塞误判成生成失败；只有完成数加失败数达到计划总数时批次才结束。普通 Composer 手动选择多图也复用这套聚合预览。只有用户明确要求同一用途的重复变体时，才在计划中使用 `count`。用户说不要白底时不创建白底主图，也不向任务提示词加入纯白背景。用户在 Composer 中手动选择的分辨率、宽高比、质量和张数不会覆盖 Agent 计划。Agent 规划失败会保留原对话并显示错误，用户可以重试；宿主不会静默改用本地模板。

完整接口见 [docs/interface.md](docs/interface.md)。
