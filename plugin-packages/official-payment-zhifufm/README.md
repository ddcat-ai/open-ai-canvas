# 支付FM 聚合支付插件

支持对接支付FM免签个人收款码与签约支付通道，支持支付宝/微信扫码及收银台跳转。

### 插件配置参数
- **服务器公网地址**: 本站对外公网地址，用于接收 `notifyUrl` 异步回调通知。
- **商户号 (merchantNum)**: 支付FM商户后台【用户中心】查看的商户号。
- **接入密钥 (secretKey)**: 支付FM商户后台【用户中心】查看的接口接入密钥。
- **接口根地址**: 支付FM后台显示的专属根地址，例如 `https://api-5a0zvlcbi80.zhifu.fm.it88168.com/api`。
- **默认支付通道 (payType)**: 推荐使用 `aloop` / `tloop` 或 `alipay` / `wechat`。
- **收银方式**: 默认为 `redirect` 跳转模式。
