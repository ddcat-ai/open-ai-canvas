# SeedanceMINI1

SeedanceMINI1 视频生成插件，支持文字、最多 9 张参考图、3-15 秒成片、清晰度增强和异步任务。

插件没有预设服务地址。在后台插件管理中上传发行包，启用后选择 **SeedanceMINI1** 协议，由管理员在渠道连接配置中填写服务地址和 API Key。服务地址可填写站点根地址或带 `/v1` 的地址；模型 ID 按实际渠道配置填写。

首次配置建议：时长 3-15 秒、步长 1 秒、默认 5 秒；比例默认 16:9；清晰度为 720p、1080p、2k、4k；参考图上限 9 张，不启用参考音频和参考视频。

接口、扩展参数和打包方式见 [docs/interface.md](docs/interface.md)。
