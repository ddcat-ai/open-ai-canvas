# 影策启动器产品约定

## Platform

web（Tauri 跨平台桌面外壳，真实影策在系统默认浏览器运行）。

## 已确认产品事实

用户已审阅并批准 `../docs/specs/feature-001-local-launcher.md` 的实现方向。面向希望在本机使用影策、不必操作终端的用户。应用管理独立代码副本；支持启动、停止、默认浏览器打开及更新；使用影策图标；支持可信镜像以解决 GitHub 不可达问题。

## Stack

用户批准方案中的 Tauri 2、React、TypeScript、Rust 技术方向。用户已选择源码启动方案：应用在独立目录下载公共仓库的固定 Release 提交，准备工具链并在本机编译，不依赖上游预先发布桌面运行包。

## 品牌与边界

继承影策现有图标及黑白中性色操作界面，不创造新品牌。不将发布服务器、镜像、签名密钥、三平台验收描述为已经具备。不得修改用户开发仓库或覆盖持久数据。

## 未决事项

无需用户配置公钥、证书或云账号。跨平台原生验收与安装器分发仍须逐平台完成；第三方镜像不等于发布者身份认证。
